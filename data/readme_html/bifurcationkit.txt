<p dir="auto">This Julia package aims at performing <strong>automatic bifurcation analysis</strong> of possibly large dimensional equations F(u, λ)=0 where λ is real by taking advantage of iterative methods, dense / sparse formulation and specific hardwares (<em>e.g.</em> GPU).</p>
<p dir="auto">It incorporates continuation algorithms (PALC, deflated continuation, ...) based on a Newton-Krylov method to correct the predictor step and a Matrix-Free/Dense/Sparse eigensolver is used to compute stability and bifurcation points.</p>
<blockquote>
<p dir="auto">The idea is to be able to seamlessly switch the continuation algorithm a bit like changing the time stepper (Euler, RK4,...) for ODEs.</p>
</blockquote>
<p dir="auto"><code>BifurcationKit</code> can also seek for <a href="https://bifurcationkit.github.io/BifurcationKitDocs.jl/stable/periodicOrbit/" rel="nofollow">periodic orbits</a> of Cauchy problems. <strong>It is by now, one of the only software which provides shooting methods <em>and</em> methods based on finite differences / collocation to compute periodic orbits.</strong></p>
<p dir="auto">The current focus is on large scale nonlinear problems and multiple hardwares. Hence, the goal is to provide Matrix Free methods on <strong>GPU</strong> (see <a href="https://bifurcationkit.github.io/BifurcationKitDocs.jl/dev/tutorials/tutorials2b/#The-Swift-Hohenberg-equation-on-the-GPU-(non-local)-1" rel="nofollow">PDE example</a> and <a href="https://bifurcationkit.github.io/BifurcationKitDocs.jl/dev/tutorials/tutorialsCGL/#Continuation-of-periodic-orbits-on-the-GPU-(Advanced)-1" rel="nofollow">Periodic orbit example</a>) or on <strong>cluster</strong> to study non linear PDE, nonlocal problems, compute sub-manifolds...</p>
<blockquote>
<p dir="auto">Despite this focus, the package can easily handle low dimensional problems and specific optimizations are regularly added.</p>
</blockquote>

<p dir="auto">Most plugins are located in the organization <a href="https://github.com/bifurcationkit">bifurcationkit</a>:</p>
<ul dir="auto">
<li><a href="https://github.com/bifurcationkit/HclinicBifurcationKit.jl">HclinicBifurcationKit.jl</a> bifurcation analysis of homoclinic / heteroclinic orbits of ordinary differential equations (ODE)</li>
<li><a href="https://github.com/bifurcationkit/DDEBifurcationKit.jl">DDEBifurcationKit.jl</a> bifurcation analysis of delay differential equations (DDE)</li>
<li><a href="https://github.com/bifurcationkit/AsymptoticNumericalMethod.jl">AsymptoticNumericalMethod.jl</a> provides the numerical continuation algorithm <strong>Asymptotic Numerical Method</strong> (ANM) which can be used directly in <code>BifurcationKit.jl</code></li>
<li><a href="https://github.com/bifurcationkit/GridapBifurcationKit">GridapBifurcationKit.jl</a> bifurcation analysis of PDEs solved with the Finite Elements Method (FEM) using the package <a href="https://github.com/gridap/Gridap.jl">Gridap.jl</a>.</li>
<li><a href="https://github.com/bifurcationkit/PeriodicSchurBifurcationKit.jl">PeriodicSchurBifurcationKit.jl</a> state of the art computation of Floquet coefficients, useful for computing the stability of periodic orbits.</li>
</ul>
