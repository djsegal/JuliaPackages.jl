<p dir="auto"><code>Chamber.jl</code> is a Julia package for simulating the eruption of a volcano using a model for the frequency of eruptions of upper crustal magma chambers based on Degruyter and Huber (2014). The package generates a CSV file and figures with the solution data for various variables over time.</p>

<p dir="auto">The main function in the <code>Chamber</code> package is <code>chamber</code>, which simulates the evolution of a magma chamber over time and returns a <code>DataFrame</code> with the solution data. The function takes the following arguments:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="chamber(composition, end_time, log_volume_km3, InitialConc_H2O, InitialConc_CO2, log_vfr, depth, output_dirname; kwargs...)"><pre><span class="pl-c1">chamber</span>(composition, end_time, log_volume_km3, InitialConc_H2O, InitialConc_CO2, log_vfr, depth, output_dirname; kwargs<span class="pl-k">...</span>)</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Arguments</h3><a id="user-content-arguments" class="anchor" aria-label="Permalink: Arguments" href="#arguments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>composition</code>: The magma composition. Use <code>Silicic()</code> for rhyolite composition (arc magma) or <code>Mafic()</code> for basalt composition (rift).</li>
<li><code>end_time</code>: Maximum magma chamber evolution duration in seconds.</li>
<li><code>log_volume_km3</code>: The initial volume of the chamber in logarithmic scale. The actual initial chamber volume is calculated as 10^(log_volume_km3) in km³.</li>
<li><code>InitialConc_H2O</code>: The initial weight fraction of water in the magma (exsolved + dissolved).</li>
<li><code>InitialConc_CO2</code>: The initial weight fraction of CO₂ in the magma (exsolved + dissolved).</li>
<li><code>log_vfr</code>: Magma recharge rate in km³/yr calculated as 10^(<code>log_vfr</code>).</li>
<li><code>depth</code>: Depth of the magma chamber in meters.</li>
<li><code>output_dirname</code>: (Optional) Name of the output directory. Defaults to current timestamp.</li>
</ul>

<ul dir="auto">

</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Returns</h3><a id="user-content-returns" class="anchor" aria-label="Permalink: Returns" href="#returns"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <code>DataFrame</code> containing the solution with columns:</p>
<ul dir="auto">
<li><code>time</code>: Simulation timestamps (sec).</li>
<li><code>P+dP</code>: Pressure (Pa).</li>
<li><code>T</code>: Temperature (K).</li>
<li><code>eps_g</code>: Gas volume fraction.</li>
<li><code>V</code>: Volume of the magma chamber (m³).</li>
<li><code>rho_m</code>: Density of the melt (kg/m³).</li>
<li><code>rho_x</code>: Density of magma crystal (kg/m³).</li>
<li><code>X_CO2</code>: Mole fraction of CO2 in the gas.</li>
<li><code>total_mass</code>: Total mass of magma chamber (kg).</li>
<li><code>total_mass_H2O</code>: Total mass of water in the magma (kg).</li>
<li><code>total_mass_CO2</code>: Total mass of CO₂ in the magma (kg).</li>
<li><code>eps_x</code>: Crystal volume fraction.</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Outputs</h3><a id="user-content-outputs" class="anchor" aria-label="Permalink: Outputs" href="#outputs"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A directory named after <code>output_dirname</code> or the default value, containing the following files:</p>
<ul dir="auto">
<li><code>out.csv</code>: A comma-delimited ascii file containing the solution columns listed above.</li>
<li><code>eruptions.csv</code>: A comma-delimited ascii file. It is organized as follows:
<ul dir="auto">
<li><code>time_of_eruption</code> (sec)</li>
<li><code>duration_of_eruption</code> (sec)</li>
<li><code>mass_erupted</code> (kg)</li>
<li><code>volume_erupted</code> (km³).</li>
</ul>
</li>
<li>Figures for P+dP(t), T(t), eps_g(t), V(t), X_CO2(t), total_mass(t).</li>
</ul>
