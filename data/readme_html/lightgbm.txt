<p dir="auto"><strong>LightGBM.jl</strong> provides a high-performance Julia interface for Microsoft's
<a href="https://lightgbm.readthedocs.io/en/latest/" rel="nofollow">LightGBM</a>.</p>
<p dir="auto">The package adds a couple of convenience features:</p>
<ul dir="auto">
<li>Automated cross-validation</li>
<li>Exhaustive grid search search procedure</li>
<li>Integration with <a href="https://github.com/alan-turing-institute/MLJ.jl">MLJ</a>, which also provides the above via different interfaces (verified only on Julia 1.6+)</li>
</ul>
<p dir="auto">Additionally, the package automatically converts all LightGBM parameters that refer to indices
(e.g. <code>categorical_feature</code>) from Julia's one-based indices to C's zero-based indices.</p>
<p dir="auto">A majority of the C-interfaces are implemented. A few are known to be missing and are
<a href="https://github.com/IQVIA-ML/LightGBM.jl/issues">tracked.</a></p>
<p dir="auto">All major operating systems (Windows, Linux, and Mac OS X) are supported. Julia versions 1.6+ are supported.</p>

<p dir="auto">Running tests for the package requires the use of the LightGBM example files,
download and extract the <a href="https://github.com/microsoft/LightGBM/archive/v3.3.5.zip">LightGBM source</a>
and set the environment variable <code>LIGHTGBM_EXAMPLES_PATH</code> to the root of the source installation.
Then you can run the tests by simply doing</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Pkg.test(&quot;LightGBM&quot;)"><pre>Pkg<span class="pl-k">.</span><span class="pl-c1">test</span>(<span class="pl-s"><span class="pl-pds">"</span>LightGBM<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">To skip MLJ testing when running tests, set the env var <code>DISABLE_MLJ_TESTS</code> to anything. (You might want to do this to get the tests to run faster)</p>

<p dir="auto">LightGBM.jl core includes a separate estimator <code>LGBMRanking</code> with parameters suitable for ranking applications as described in <a href="https://lightgbm.readthedocs.io/en/v3.3.5/Parameters.html#query-data" rel="nofollow">group query</a>. Similar to other
wrapper libraries it is possible to pass a one-dimensional array with <code>group</code> information parameter.</p>
<p dir="auto">Here's an example of how to use <code>LGBMRanking</code>:</p>

<p dir="auto">The MLJ interface models are</p>

<p dir="auto">MLJ Is only officially supported on 1.6+ (because this is what MLJ supports). Using older versions of the MLJ package may work, but your mileage may vary.</p>
