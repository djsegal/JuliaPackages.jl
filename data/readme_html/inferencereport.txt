<p dir="auto"><code>InferenceReport</code> is a Julia package to generate nice report from MCMC runs.
Compatible with <a href="https://pigeons.run/" rel="nofollow"><code>Pigeons.jl</code></a> and
a <a href="https://turinglang.org/MCMCChains.jl" rel="nofollow"><code>MCMCChains.jl</code></a>.</p>
<p dir="auto">Basic idea:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using InferenceReport
using Pigeons

pt = pigeons(target = Pigeons.toy_turing_unid_target(), record = [traces])
report(pt)"><pre class="notranslate"><code>using InferenceReport
using Pigeons

pt = pigeons(target = Pigeons.toy_turing_unid_target(), record = [traces])
report(pt)
</code></pre></div>
