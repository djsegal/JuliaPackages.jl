<p dir="auto">JutulDarcy.jl: Darcy-scale and subsurface flow (CO2 sequestration, gas/H2 storage, oil/gas fields) using <a href="https://github.com/sintefmath/Jutul.jl">Jutul.jl</a> developed by the <a href="https://www.sintef.no/en/digital/departments-new/applied-mathematics/applied-computational-sciences/" rel="nofollow">Applied Computational Science group</a> at <a href="https://www.sintef.no/en/digital/" rel="nofollow">SINTEF Digital</a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">JutulDarcy is a general purpose porous media simulator with high performance written in Julia. It is fully differentiable with respect to forces and discretization parameters.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Physical systems</h3><a id="user-content-physical-systems" class="anchor" aria-label="Permalink: Physical systems" href="#physical-systems"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Immiscible multi-phase flow</li>
<li>Black-oil type models with support for both dissolved vapor (Rs) and vaporized liquid (Rv)</li>
<li>Equation-of-state compositional flow with up to three phases and any number of components</li>
<li>Geothermal systems</li>
</ul>
<p dir="auto">All solvers can incorporate general multisegment wells with rigorous mass balance, friction pressure loss, complex well limits and time-dependent controls.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Architecture</h3><a id="user-content-architecture" class="anchor" aria-label="Permalink: Architecture" href="#architecture"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Written in pure Julia, with automatic differentiation and dynamic sparsity detection</li>
<li>Support for sensitivities with respect to any model parameters using the adjoint method</li>
<li>High performance assembly and linear solvers, with support for two-stage CPR BILU(0)-CPR Krylov solvers</li>
<li>MPI support with domain decomposition and BoomerAMG-CPR solver with automatic METIS partitioning</li>
<li>Support for consistent discretizations (AvgMPFA / NTPFA)</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Input/output and workflow tools</h3><a id="user-content-inputoutput-and-workflow-tools" class="anchor" aria-label="Permalink: Input/output and workflow tools" href="#inputoutput-and-workflow-tools"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Support for reading in and running .DATA files with corner point grids, with support for non-conformal faults and inactive cells.</li>
<li>Unstructured grids and complex cases input from <a href="https://www.mrst.no" rel="nofollow">the Matlab Reservoir Simulation Toolbox (MRST)</a> using the <code>jutul</code> module</li>
<li>3D visualization of grids and wells by loading a <a href="https://docs.makie.org/stable/" rel="nofollow">Makie.jl</a> backend (requires Julia 1.9, <code>GLMakie</code> for interactivity)</li>
<li>Interactive plotting of well curves</li>
</ul>
<p dir="auto">The compositional simulator has been matched against commercial offerings, AD-GPRS and MRST. The blackoil simulator has been validated on the standard SPE benchmarks (SPE1, SPE9, ...).</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">A few of the packages used by Jutul and JutulDarcy</h2><a id="user-content-a-few-of-the-packages-used-by-jutul-and-jutuldarcy" class="anchor" aria-label="Permalink: A few of the packages used by Jutul and JutulDarcy" href="#a-few-of-the-packages-used-by-jutul-and-jutuldarcy"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Jutul builds upon many of the excellent packages in the Julia ecosystem. Here are a few of them, and what they are used for:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a> implements the Dual number class used throughout the code</li>
<li><a href="https://github.com/PALEOtoolkit/SparsityTracing.jl/">SparsityTracing.jl</a> provides sparsity detection inside Jutul</li>
<li><a href="https://github.com/JuliaSmoothOptimizers/Krylov.jl">Krylov.jl</a> provides the iterative linear solvers</li>
<li><a href="https://github.com/mcovalt/ILUZero.jl/blob/master/src/ILUZero.jl">ILUZero.jl</a> for ILU(0) preconditioners</li>
<li><a href="https://github.com/JuliaLinearAlgebra/AlgebraicMultigrid.jl">AlgebraicMultigrid.jl</a> for AMG preconditioners</li>
<li><a href="https://github.com/fredrikekre/HYPRE.jl">HYPRE.jl</a> for robust AMG preconditioners with MPI support</li>
<li><a href="https://github.com/fverdugo/PartitionedArrays.jl">PartitionedArrays.jl</a> for MPI assembly and linear solve</li>
<li><a href="https://github.com/mcabbott/Tullio.jl">Tullio.jl</a> for automatically optimized loops and <a href="https://github.com/JuliaSIMD/Polyester.jl">Polyester.jl</a> for lightweight threads</li>
<li><a href="https://github.com/KristofferC/TimerOutputs.jl">TimerOutputs.jl</a> and <a href="https://github.com/timholy/ProgressMeter.jl">ProgressMeter.jl</a> gives nice output to terminal.</li>
<li><a href="https://makie.juliaplots.org/" rel="nofollow">Makie.jl</a> is used for the visualization features</li>
<li><a href="https://github.com/moyner/MultiComponentFlash.jl">MultiComponentFlash.jl</a> provides many of the compositional features</li>
</ul>
