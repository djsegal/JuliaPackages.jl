<p dir="auto">The DiffFusion.jl package implements a framework for joint simulation of financial risk factors, risk-neutral valuation of financial instruments and calculation of portfolio risk measures.</p>
<p dir="auto">The intended purpose of the package is efficient exposure simulation for XVA and Counterparty Credit Risk (CCR).</p>
<p dir="auto">An overview of the architecture of the framework is illustrated in below figure.</p>

<p dir="auto">Cross-asset exposure simulation can be a complex procedure. Here, we give a minimal example to illustrate the usage of the package.</p>
<p dir="auto">For a more realistic examples, see the unit tests and component tests.</p>
<p dir="auto">The basic usage can be decomposed into the following steps:</p>
<ul dir="auto">
<li>model setup,</li>
<li>Monte Carlo simulation,</li>
<li>Monte Carlo <em>path</em> construction,</li>
<li>financial instrument setup,</li>
<li>scenario valuation.</li>
</ul>
<p dir="auto">All methods are implemented in the <code>DiffFusion</code> module and accessible via:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using DiffFusion"><pre class="notranslate"><code>using DiffFusion
</code></pre></div>
