<p dir="auto">SUNDMRG.jl: traditional DMRG code with full SU(N) symmetry implementation.
A part of the code is influenced by Simple DMRG. <a href="https://github.com/simple-dmrg/simple-dmrg">https://github.com/simple-dmrg/simple-dmrg</a></p>

<p dir="auto">If you want to run the simulation of the SU(2) Heisenberg model on the 4x4 square lattice
with a default setting, please use the following.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="rank, dmrg = run_DMRG(SU(2)HeisenbergModel(), SquareLattice(4, 4), 100, [100, 200, 400, 800], 1600, CPUEngine)"><pre>rank, dmrg <span class="pl-k">=</span> <span class="pl-c1">run_DMRG</span>(<span class="pl-c1">SU</span>(<span class="pl-c1">2</span>)<span class="pl-c1">HeisenbergModel</span>(), <span class="pl-c1">SquareLattice</span>(<span class="pl-c1">4</span>, <span class="pl-c1">4</span>), <span class="pl-c1">100</span>, [<span class="pl-c1">100</span>, <span class="pl-c1">200</span>, <span class="pl-c1">400</span>, <span class="pl-c1">800</span>], <span class="pl-c1">1600</span>, CPUEngine)</pre></div>
<p dir="auto"><code>dmrg</code> is returned only when <code>rank == 0</code> when you are using the MPI parallelization.</p>
<p dir="auto">For a more detailed configuration, please look at the examples directory.</p>
<p dir="auto">Please be careful that the expectation value of the bond operator is returned
in the format of P<sub>ij</sub> - 1 / N<sub>c</sub> for SU(N<sub>c</sub>) for the accuracy.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">SU(2)</h2><a id="user-content-su2" class="anchor" aria-label="Permalink: SU(2)" href="#su2"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">SUNDMRG.jl supports an on-the-fly calculation of SU(2) symmetry coefficients (Wigner symbols).
The bond Hamiltonian is <strong>S</strong><sub>i</sub>・<strong>S</strong><sub>j</sub> in the SU(2) case, not P<sub>ij</sub> = 2 <strong>S</strong><sub>i</sub>・<strong>S</strong><sub>j</sub> + 1 / 2.
SiSj is also evaluated by <strong>S</strong><sub>i</sub>・<strong>S</strong><sub>j</sub>, not P<sub>ij</sub> - 1 / 2.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Density matrix mixing</h2><a id="user-content-density-matrix-mixing" class="anchor" aria-label="Permalink: Density matrix mixing" href="#density-matrix-mixing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The density matrix mixing (sometimes called a noise term) is a technique to have a better convergence
in DMRG. It perturbs the density matrix a little, avoiding being stuck in some local minima.
The small perturbation is specified in the second term of the tuple for each sweep as follows.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="rank, dmrg = run_DMRG(SU(3)HeisenbergModel(), SquareLattice(6, 6), (100, 1e-5), [(100, 1e-5), (200, 1e-6), (400, 1e-7), (800, 1e-8)], (1600, 0.0), CPUEngine; widthmax = widthmax, tables = tables)"><pre>rank, dmrg <span class="pl-k">=</span> <span class="pl-c1">run_DMRG</span>(<span class="pl-c1">SU</span>(<span class="pl-c1">3</span>)<span class="pl-c1">HeisenbergModel</span>(), <span class="pl-c1">SquareLattice</span>(<span class="pl-c1">6</span>, <span class="pl-c1">6</span>), (<span class="pl-c1">100</span>, <span class="pl-c1">1e-5</span>), [(<span class="pl-c1">100</span>, <span class="pl-c1">1e-5</span>), (<span class="pl-c1">200</span>, <span class="pl-c1">1e-6</span>), (<span class="pl-c1">400</span>, <span class="pl-c1">1e-7</span>), (<span class="pl-c1">800</span>, <span class="pl-c1">1e-8</span>)], (<span class="pl-c1">1600</span>, <span class="pl-c1">0.0</span>), CPUEngine; widthmax <span class="pl-k">=</span> widthmax, tables <span class="pl-k">=</span> tables)</pre></div>
<p dir="auto">The value has to become zero or a negligibly small value in the last few sweeps.</p>
