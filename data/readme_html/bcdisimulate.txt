<p dir="auto">Bragg Coherent Diffraction Imaging (BCDI) Simulate implements methods to simulate the BCDI problem. This package is part of a collection of packages that solve the BCDI problem.</p>
<p dir="auto">While this package is marked as BCDI specific, the methods are more general and can be used in many phase retrieval problems. In the future, this package may be incorporated into a more general phase retrieval core package.</p>
<p dir="auto">Currently, this entire package must be run with access to GPUs. This may change in the future (especially if Issues requesting it are opened), but for our research group, using GPUs is a necessity.</p>
