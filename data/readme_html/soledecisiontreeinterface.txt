<p dir="auto">Ever wondered what to do with a trained decision tree? Start by inspecting its knowledge, and end up evaluating it in a dedicated framework!
This package allows you to convert learned <a href="https://github.com/JuliaAI/DecisionTree.jl">DecisionTree</a> models to <a href="https://github.com/aclai-lab/Sole.jl">Sole</a> decision tree models.
With a Sole model in your hand, you can then treat the extracted knowledge in symbolic form, that is, as a set of logical formulas, which allows you to:</p>
<ul dir="auto">
<li>Evaluate them in terms of
<ul dir="auto">
<li>accuracy (e.g., confidence, lift),</li>
<li>relevance (e.g., support),</li>
<li>interpretability (e.g., syntax height, number of atoms);</li>
</ul>
</li>
<li>Modify them;</li>
<li>Merge them.</li>
</ul>
