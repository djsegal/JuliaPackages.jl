<p dir="auto">A Julia package that provides <code>@test</code>-like macros with more informative error messages.</p>
<p dir="auto">The inspiration comes from <code>python</code> <a href="https://docs.python.org/3/library/unittest.html#assert-methods" rel="nofollow">asserts</a>, which customize their error message based on the type of unit test being performed; for example, by showing the differences between two sets or lists that should be equal.</p>
<p dir="auto"><code>PrettyTests</code> exports drop-in replacements for <code>@test</code> that are designed to (a) provide concise error messages tailored to specific situations, and (b) conform with the standard <a href="https://docs.julialang.org/en/v1/stdlib/Test/" rel="nofollow"><code>Test</code></a> interface so that they fit into to any unit-testing workflow.</p>
