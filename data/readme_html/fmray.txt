<p dir="auto">This module is mostly a port of some key elements of the C++ programmes FaATSO, which implements:</p>
<ul dir="auto">
<li>Fast Marching Method to compute arrival times in 3D, VTI (elliptical) wave velocity structures,</li>
<li>Ray tracing and computation of derivatives of arrival times,</li>
<li>Event location method by gridsearch methods with least L1 norm.</li>
</ul>
<p dir="auto">Immediate applications can be written to solve the Local Earthquake Tomography problem (as was done originally in FaATSO), but this is left for future work, and maybe another package.</p>
<p dir="auto">Since this package is mostly a port to Julia, the key original paper describing this code is:</p>
<p dir="auto">Brantut, N. (2018), Time-resolved tomography using acoustic emissions in the laboratory, and application to snadstone compaction, <em>Geophys. J. Int.</em>, 213, 2177-2192.</p>
<p dir="auto">and references therein.</p>
<hr>
<p dir="auto">The package is not registered. You should add it using:
<code> pkg&gt; add https://github.com/nbrantut/FMRay.jl</code></p>
<p dir="auto">Then test using:
<code> pkg&gt; test</code></p>
<hr>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Velocity model</h2><a id="user-content-velocity-model" class="anchor" aria-label="Permalink: Velocity model" href="#velocity-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">FMRay main tool is an implementation of the Fast Marching Method to solve the Eikonal equation in 3D, possibly anisotropic media.</p>
<p dir="auto">The type of anisotropy is restricted to VTI, with the following parameterisation:
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="456868822f64531f3cc5351fb7ba55cb">$$V(\theta) = V_v \cos^2(\theta) + V_h \sin^2(\theta),$$</math-renderer>
where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="456868822f64531f3cc5351fb7ba55cb">$V_v$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="456868822f64531f3cc5351fb7ba55cb">$V_h$</math-renderer> are the vertical and horizontal phase velocities, respectively, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="456868822f64531f3cc5351fb7ba55cb">$\theta$</math-renderer> is the phase angle, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="456868822f64531f3cc5351fb7ba55cb">$V(\theta)$</math-renderer> is the phase velocity. Note that the solver is not valid for anisotropy that is too large.</p>

<p dir="auto">A velocity model is defined in a <code>Grid</code> structure, which contains the grid spacing (only regular grids can be used), vertical and horizontal phase velocities, and the coordinates of the origin. The velocity structure are 3-dimensional arrays.</p>
<p dir="auto">The origin point must be entered as the coordinates of that point in the default coordinate system, where the point indexed (1,1,1) is at position (0.0, 0.0, 0.0).</p>
<p dir="auto">An example with 2D uniform velocity equal to 1.0, and grid spacing 0.1:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FMRay

G = Grid(0.1, fill(1.0, (100,100,1)))

T = march(CartesianIndex(1,1,1), G)"><pre><span class="pl-k">using</span> FMRay

G <span class="pl-k">=</span> <span class="pl-c1">Grid</span>(<span class="pl-c1">0.1</span>, <span class="pl-c1">fill</span>(<span class="pl-c1">1.0</span>, (<span class="pl-c1">100</span>,<span class="pl-c1">100</span>,<span class="pl-c1">1</span>)))

T <span class="pl-k">=</span> <span class="pl-c1">march</span>(<span class="pl-c1">CartesianIndex</span>(<span class="pl-c1">1</span>,<span class="pl-c1">1</span>,<span class="pl-c1">1</span>), G)</pre></div>
<p dir="auto">The function <code>march</code> is the Eikonal solver. The first argument is the index of the source, and must be entered as a CartesianIndex.</p>
