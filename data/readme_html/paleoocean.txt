<p dir="auto">The PALEOocean Julia package provides:</p>
<ul dir="auto">
<li>a catalog of ocean circulation models, including low-dimensional box models and GCM transport-matrix representations of the global ocean at resolutions up to 1 deg.</li>
<li>air-sea exchange</li>
<li>vertical tracer and light transport</li>
<li>biological production</li>
<li>parameterisations of burial fluxes</li>
</ul>
<p dir="auto">It can be used to create standalone ocean models, or combined with other components in the <a href="https://github.com/PALEOtoolkit">PALEOtoolkit</a> biogeochemical model framework to create coupled Earth and exo-Earth system models.</p>

<p dir="auto">To install and run the PALEOocean examples, clone this github repository to local directory <code>PALEOocean</code> and run the examples from the Julia REPL.</p>
<p dir="auto">Quickstart assuming a recent Julia installation: from a linux bash prompt or a Windows terminal,</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ git clone https://github.com/PALEOtoolkit/PALEOocean.jl.git PALEOocean"><pre class="notranslate"><code>$ git clone https://github.com/PALEOtoolkit/PALEOocean.jl.git PALEOocean
</code></pre></div>
<p dir="auto">Start julia and navigate to the <code>PALEOocean/examples</code> folder, and run <code>setup.jl</code> to configure the <code>PALEOocean/examples</code>
Julia environment to use the local (downloaded) version of the PALEOocean package:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; cd(&quot;PALEOocean/examples&quot;)
julia&gt; include(&quot;setup.jl&quot;) # use the local version of PALEOocean packages to allow local modifications"><pre class="notranslate"><code>julia&gt; cd("PALEOocean/examples")
julia&gt; include("setup.jl") # use the local version of PALEOocean packages to allow local modifications
</code></pre></div>
<p dir="auto">Examples are in subfolders of <code>PALEOocean/examples/</code> and use the <code>PALEOocean/examples</code> Julia environment.</p>
<p dir="auto">See <a href="https://paleotoolkit.github.io/PALEOtutorials.jl/dev/ExampleInstallConfig/" rel="nofollow">Installation and getting started</a>
in the <a href="https://github.com/PALEOtoolkit/PALEOtutorials.jl">PALEOtutorials</a> repository for more details including installation and configuration of Julia.</p>
