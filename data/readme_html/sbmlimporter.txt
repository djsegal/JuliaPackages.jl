<p dir="auto">SBMLImporter is a Julia package for importing dynamic <a href="https://sbml.org/" rel="nofollow">Systems Biology Markup Language (SBML)</a> models into either a <code>JumpProblem</code> for Gillespie simulations, a <code>SDEProblem</code> for chemical Langevin simulations, or an <code>ODEProblem</code> for deterministic simulations. Some major highlights of SBMLImporter are:</p>
<ul dir="auto">
<li>It imports models into a <a href="https://github.com/SciML/Catalyst.jl">Catalyst.jl</a> <code>ReactionSystem</code>. This allows for easy conversion to a <code>JumpProblem</code>, a <code>SDEProblem</code>, or an <code>ODEProblem</code>.</li>
<li>It supports a majority of SBML features, such as dynamic compartments, events, rules, piecewise (ifelse) expressions, and units.</li>
<li>It is thoroughly tested against both the SBML test suite and a large collection of published models.</li>
<li>It integrates with <a href="https://github.com/sebapersson/PEtab.jl">PEtab.jl</a> for fitting SBML models to data.</li>
</ul>
<p dir="auto">Additional information on features and tutorials can be found in the <a href="https://sebapersson.github.io/SBMLImporter.jl/stable/" rel="nofollow">documentation</a>.</p>

<p dir="auto">There are currently three other SBML related packages in Julia:</p>
<ol dir="auto">
<li><a href="https://github.com/LCSB-BioCore/SBML.jl">SBML.jl</a> wraps a subset of the <a href="https://sbml.org/software/libsbml/" rel="nofollow">libSBML</a> functionality and is used by SBMLImporter and other SBML related packages for parsing SBML models.</li>
<li><a href="https://github.com/COBREXA/COBREXA.jl">COBREXA.jl</a> is designed for constraint-based metabolic modeling. Constraint-based models, which are often referred to as flux-balance analysis (FBA) models, are not supported by SBMLImporter.</li>
<li><a href="https://github.com/SciML/SBMLToolkit.jl">SBMLToolkit.jl</a> is the most similar package to SBMLImporter as it imports an SBML model into a <code>ReactionSystem</code>. Still, we recommend to use SBMLImporter as it supports more SBML features, has more efficient event handling, and supports efficient <code>JumpProblem</code> (Gillespie) simulations. An extensive list of differences can be found in the <a href="https://sebapersson.github.io/SBMLImporter.jl/stable/differences/" rel="nofollow">documentation</a>.</li>
</ol>
