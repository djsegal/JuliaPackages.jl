<p dir="auto">This package offers an interface to create matrices from a Julia string. It uses wildcards to represent the sparsity pattern of a matrix. For instance, we represent a sparse matrix of dimension 3 x 3 x 5 where all non-zero elements lie in the <code>row</code> (3,2) by</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="matrix_s = &quot;&quot;&quot;
: 2 : 1 : * 1
&quot;&quot;&quot;"><pre class="notranslate"><code>matrix_s = """
: 2 : 1 : * 1
"""
</code></pre></div>
<p dir="auto">where the first colon represents the start of a specification, and the three subsequent characters (2,1,*) specify that the value 1 should be stored to all elements of the row (3,2). Our default standard is to adopt a zero-based indexing of the matrix entries, but this can be changed according to the user preference.</p>

<p dir="auto">WildcardArrays.jl exports a julia type called WildcardArray that can parse string representations.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="WildcardArray(s::String, values::Vector{T}; default=0.0, startindex=0) where T &lt;: Union{Any, Int, Vector{String}}"><pre class="notranslate"><code>WildcardArray(s::String, values::Vector{T}; default=0.0, startindex=0) where T &lt;: Union{Any, Int, Vector{String}}
</code></pre></div>
<p dir="auto">The (optional) default parameter is the value to be returned when querying a WildcardArray at an index that is not explicitly specified in its string definition, e.g., this would lead to zero being returned when querying the matrix in the above example at the index 1,1,1. Startindex can be used to change the indexing of a WildcardArray.</p>
<p dir="auto">The Julia code below can be used to create a WildcardArray from <code>matrix_s</code></p>

<p dir="auto">The inspiration for this package arose due to our intention to parse the .POMDP file format described in <a href="http://pomdp.org/code/pomdp-file-spec.html" rel="nofollow">POMDP.org</a>. Recognizing that this data structure could be of wider interest, we decide to wrap its functionality into this package and share it with the Julia community!</p>
<p dir="auto">In the near future, we will use the above functionalities to bring the examples from <a href="http://pomdp.org/code/pomdp-file-spec.html" rel="nofollow">POMDP.org</a> into the <a href="https://github.com/JuliaPOMDP">JuliaPOMDP</a> ecosystem by releasing a new version of the <a href="">POMDPFiles</a> package. Here is a teaser on how this package can be used to parse reward transitions using the syntax described in <a href="http://pomdp.org/code/pomdp-file-spec.html" rel="nofollow">POMDP.org</a>.</p>
