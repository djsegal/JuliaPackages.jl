<p dir="auto">REPLSmuggler is meant to evaluate code coming from various clients in your REPL. The main goal is for an editor to send a bunch of lines of code with some metadata giving the name of the file and the line. <code>REPLSmuggler</code> will evaluate the code and send back the return value. If an error is raised, it will send the traceback to the client.</p>
