<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Version 1.2.2</h2><a id="user-content-version-122" class="anchor" aria-label="Permalink: Version 1.2.2" href="#version-122"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">QuantumMAMBO provides structures for many-body objects in quantum computing. They can all be seen in <code>src/UTILS/structures.jl</code>. In particular, it provides the fermionic operators <code>F_OP</code> specially geared towards two-electron number-conserving operators, <code>Q_OP</code> for qubit operators, and <code>M_OP</code>for Majorana operators coming from fermionic operators. All operators and unitaries have structured classes, which in the future will be used for efficient compilation of quantum circuits and resource estimates.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Using QuantumMAMBO.jl</h2><a id="user-content-using-quantummambojl" class="anchor" aria-label="Permalink: Using QuantumMAMBO.jl" href="#using-quantummambojl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>QuantumMAMBO.jl</code> includes efficient implementations for fermionic and qubit operators. To obtain results shown in Ref.(1), run on a terminal (e.g. for LiH):</p>
<p dir="auto"><code>julia L1.jl lih</code></p>
<p dir="auto">All options and tolerances can be seen in <code>src/config.jl</code>. By default, <code>QuantumMAMBO.jl</code> will use the package <a href="https://github.com/cjdoris/PythonCall.jl"><code>PythonCall</code></a> for calling Python, installing all necessary Python packages on a fresh conda environment using <a href="https://github.com/cjdoris/MicroMamba.jl"><code>MicroMamba</code></a>. Change the <code>PY_ENV</code> variable in <code>src/config.jl</code> to <code>"Null"</code> for using local Python enviornment instead. There are three ways in which QuantumMAMBO can be used, which are now decribed.</p>

<ul dir="auto">
<li><code>bliss.jl</code> : functions for BLISS routine (see Ref. 2)</li>
<li><code>circuits.jl</code> : julia wrappers for interfacing QuantumMAMBO LCU decompositions with cirq circuit building</li>
<li><code>circuits.py</code> : python wrapper which includes all cirq building tools in cirq folder</li>
<li><code>cirq</code> : folder containing all python functions for building cirq LCU oracles</li>
<li><code>cost.jl</code> : functions for calculating different norms of operators. Mainly 1- and 2-norms of fermionic operators.</li>
<li><code>decompose.jl</code> : CSA, DF, and related decompositions of fermionic operators</li>
<li><code>ferm_utils.py</code> : utilities for fermionic operators in python, interfaces with openfermion</li>
<li><code>fermionic.jl</code> : utilities for QuantumMAMBO fermionic operators class (F_OP, defined in structures.jl)</li>
<li><code>gradient.jl</code> : gradients for CSA and CSA_SD optimizations</li>
<li><code>guesses.jl</code> : initial guesses for decomposition routines</li>
<li><code>ham_utils.py</code> : python utilities for the electronic structure Hamiltonian, interfaces with openfermion</li>
<li><code>lcu.jl</code> : calculation of lcu 1-norms for different decompositions</li>
<li><code>linprog.jl</code> : linear programming routines for symmetry-shift optimization (see Refs. 1 and 2, corresponds to "partial" routine in Ref. 2)</li>
<li><code>majorana.jl</code> : utilities for QuantumMAMBO Majorana operators class (M_OP, defined in structures.jl)</li>
<li><code>orbitals.jl</code> : orbital optimization routine for 1-norm minimization (see Koridon et al., Phys. Rev. Res. 3 (3), 2021. Material is also covered in Refs. 1 and 2)</li>
<li><code>parallel.jl</code> : code with parallel capabilities, mainly for trotter bounds (under construction)</li>
<li><code>planted.jl</code> : routines for obtaining planted solutions for a given Hamiltonian</li>
<li><code>projectors.jl</code> : builds projectors of Fock space into constant number of electrons subspace, useful for Trotter bounds (under progress)</li>
<li><code>py_qubits.jl</code> : python utilities for qubit operators, interfaces with openfermion</li>
<li><code>py_utils.jl</code> : julia interface to all python modules and openfermion</li>
<li><code>qubit.jl</code> : utilities for QuantumMAMBO qubit operators class (Q_OP, defined in structures.jl)</li>
<li><code>saving.jl</code> : save-load utilities for decompositions and optimization results, uses HDF5</li>
<li><code>structures.jl</code> : definition of classes for many-body operators</li>
<li><code>symmetries.jl</code> : building of symmetry operators, e.g. Sz, Ne</li>
<li><code>symplectic.jl</code> : utilities for representing and manipulating qubit space as symplectic vectors</li>
<li><code>trotter.jl</code> : Trotterization implementation, errors and bounds (under construction)</li>
<li><code>unitaries.jl</code> : unitary transformations related to fermionic QuantumMAMBO operators (i.e. F_OP)</li>
<li><code>wrappers.jl</code> : runner functions which run workflows for obtaining all necessary quantities for e.g. tables in Refs. 1 and 2</li>
</ul>
