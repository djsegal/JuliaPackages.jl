<p dir="auto">TidierText.jl is a 100% Julia implementation of the R tidytext package. The purpose of the package is to make it easy analyze text data using DataFrames.</p>
<p dir="auto">An extensive guide to tidy text analysis by Julia Silge and David Robinson is available here: <a href="https://www.tidytextmining.com" rel="nofollow">https://www.tidytextmining.com/</a>.</p>
