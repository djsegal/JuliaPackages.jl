<p dir="auto">This project is a Julia wrapper for the <a href="https://github.com/BrunoLevy/geogram">geogram C++ project</a>.</p>
<p dir="auto">For the moment the only functionality exposed by this wrapper is the remeshing (<code>vorpalite</code>) functionality in Geogram, which enables smooth remeshing of surfaces. Secondly the wrapper currently works by exporting a .obj file, calling Geogram as an external executable using <code>run</code> with desired parameters set, and importing of the output .obj file. In the future the wrapper should feature a more complete and efficient interface by directly interfacing with the C++ code through Julia (e.g. using <code>ccall</code>).</p>

<p dir="auto">This project is a wrapper for Geogram. Currently the project ships with executables for <code>vorpalite</code> (which is part of geogram) for <a href="https://github.com/COMODO-research/Geogram.jl/tree/main/ext/geogram">Linux, Windows, and Mac</a>. Depending on your operating system, you may want to or need to compile the source yourself, here are some basic instructions for Linux:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="git clone --recurse-submodules https://github.com/BrunoLevy/geogram.git

<p dir="auto">In future releases the above should not be needed as the source code will be called by Julia directly.</p>
