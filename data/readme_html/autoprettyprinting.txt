<p dir="auto">The goal of <code>AutoPrettyPrinting</code> is to remove some of the tedium of rolling your own custom pretty printing code for your custom types. To a given object <code>x</code>, this package associates a horizontally-oriented layout (akin to the default <code>Base.show</code> layout) as well as a vertically-oriented layout. The choice of whether to use one or both of these layouts when rendering an object <code>x</code> is made dynamically, both by the heuristics defined in this package, as well as of the dynamic block choice given in .</p>
<p dir="auto"><code>AutoPrettyPrinting</code> provides macros that enable straightforward pretty printing of custom types using <a href="https://github.com/MechanicalRabbit/PrettyPrinting.jl"><code>PrettyPrinting.jl</code></a>. Custom pretty printing code can be specified on a per-<code>MIME</code> type basis and, for a given type, can either be automatically generated using the <code>@def_pprint</code> macro or custom-provided by the user with the <code>@custom_tile</code> macro.</p>
