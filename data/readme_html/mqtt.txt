<p dir="auto">This is an interface package for MQTT Messaging. See the <a href="https://JuliaMessaging.github.io/MQTT.jl" rel="nofollow">documentation</a> for more information.</p>

<p dir="auto">You will need to use a MQTT backend to connect to a broker. This Package is intended to make it easier for developers to integrate with MQTT without locking themselves into the syntax of a specific MQTT Backend.</p>
