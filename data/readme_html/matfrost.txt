<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">MATFrost.jl - Embedding Julia in MATLAB</h1><a id="user-content-matfrostjl---embedding-julia-in-matlab" class="anchor" aria-label="Permalink: MATFrost.jl - Embedding Julia in MATLAB" href="#matfrostjl---embedding-julia-in-matlab"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">MATFrost enables quick and easy embedding of Julia inside MATLAB. It is like Bifrost but between Julia and MATLAB</p>
<p dir="auto">Characteristics:</p>
<ol dir="auto">
<li>Interface defined on Julia side.</li>
<li>Nested datatypes supported.</li>
<li>Leveraging Julia environments for reproducible builds.</li>
<li>Julia runs in its own mexhost process.</li>
</ol>
