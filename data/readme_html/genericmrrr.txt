<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">A Symmetric Tridiagonal Eigen-solver in Julia: MRRR and dqds methods</h2><a id="user-content-a-symmetric-tridiagonal-eigen-solver-in-julia-mrrr-and-dqds-methods" class="anchor" aria-label="Permalink: A Symmetric Tridiagonal Eigen-solver in Julia: MRRR and dqds methods" href="#a-symmetric-tridiagonal-eigen-solver-in-julia-mrrr-and-dqds-methods"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides methods for computing some or all of the
eigenvalues and (optionally) eigenvectors of a real symmetric
tridiagonal matrix. It is designed to work with
element types supported by arithmetic similar to IEEE standards (especially
NaN propagation), such as <code>BigFloat</code>, <code>Quadmath.Float128</code>, and
<code>DoubleFloat</code>.</p>

<p dir="auto">The package exports <code>geigen!</code> and <code>geigvals!</code> functions with the
same API as the <code>SymTridiagonal</code> versions of <code>eigen!</code> and <code>eigvals!</code>
in the <code>LinearAlgebra</code> standard library. For example,</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Algorithms</h2><a id="user-content-algorithms" class="anchor" aria-label="Permalink: Algorithms" href="#algorithms"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The methods implement the Relatively Robust Representation scheme
of Dhillon, Parlett, and associates, along with the dqds scheme for
computing eigenvalues to high precision where feasible. The implementations
closely follow those in LAPACK.</p>

<p dir="auto">There are a few matrices for which the <code>Float64</code> implementations in
LAPACK fail; our implementation typically also fails for them -
but often succeeds after promoting the same matrices to a wider type.
In most such cases a <code>RepresentationFailure</code> exception is thrown.</p>
<p dir="auto">Although these algorithms are usually more efficient than the Francis-QR
scheme (which is implemented in <code>GenericLinearAlgebra</code>), they are far
more complicated so the initial compilation takes several seconds.</p>
<p dir="auto">A small pseudo-random perturbation is used in the algorithm.
Unlike the LAPACK implementation, we use the default Julia RNG(s) without
altering the seed, so there will be variations between results on a given matrix.
These should almost always be roundoff-level, except for eigenvectors of effectively
indistinguishable eigenvalues.</p>

<p dir="auto">Almost all of this package was translated from LAPACK subroutines
written by Dhillon, Parlett, Marques, et al. Translation errors are
(of course) not their responsibility. Efforts have been made to
be consistent with LAPACK behavior, but the agreement is not perfect.</p>
<p dir="auto">Special thanks to Osni Marques for providing a collection of matrices
for testing and debugging.</p>
