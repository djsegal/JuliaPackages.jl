<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="screenshot.png"><img src="screenshot.png" alt="ElectronDisplay.jl screenshot" width="50%" align="right" style="max-width: 100%;"></a></p>
<p dir="auto">This package provides a display for figures, plots and tables. When you load the package, it will push a new display onto the julia display stack and from then on it will display any value that can be rendered as png, svg, vega, vega-lite or plotly in an electron based window. This is especially handy when one works on the REPL and wants plots or tables to show up in a nice window.</p>
<br clear="all">

<p dir="auto">You can install the package via the normal julia package manger:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Pkg.add(&quot;ElectronDisplay&quot;)"><pre>Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>ElectronDisplay<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">As soon as you load the package with <code>using ElectronDisplay</code>, it will start to show plots that have the correct <code>show</code> methods in an electron window.</p>
<p dir="auto"><code>ElectronDisplay</code> also exports a function <code>electrondisplay</code>.  You can use <code>electrondisplay(x)</code> to show <code>x</code> explicitly in <code>ElectronDisplay</code> (e.g., when another display has higher precedence).  You can also use <code>electrondisplay(mime, x)</code> to specify a MIME to be used.  For example, to read the docstring of <code>reduce</code> in <code>ElectronDisplay</code>, you can use <code>electrondisplay(@doc reduce)</code>.</p>
<p dir="auto">See the original <a href="https://www.queryverse.org/2019/02/13/electrondisplay/" rel="nofollow">announcement</a> for a quick start guide.</p>

<p dir="auto">You can use the following configuration option to reuse existing window for displaying a new content.  The default behavior is to create a new window for each display.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ElectronDisplay
ElectronDisplay.CONFIG.single_window = true"><pre><span class="pl-k">using</span> ElectronDisplay
ElectronDisplay<span class="pl-k">.</span>CONFIG<span class="pl-k">.</span>single_window <span class="pl-k">=</span> <span class="pl-c1">true</span></pre></div>
<p dir="auto">To control objects to be handled by <code>ElectronDisplay</code>, you can set <code>ElectronDisplay.CONFIG.showable</code>.  By default, <code>ElectronDisplay</code> does not show markdown, HTML, and <code>application/vnd.dataresource+json</code> output.  To show everything in <code>ElectronDisplay</code> whenever it's supported, you can use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ElectronDisplay.CONFIG.showable = showable"><pre>ElectronDisplay<span class="pl-k">.</span>CONFIG<span class="pl-k">.</span>showable <span class="pl-k">=</span> showable</pre></div>
<p dir="auto">To override the default configuration temporary, use the keyword arguments to <code>electrondisplay</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="electrondisplay(@doc reduce; single_window=true, focus=false)"><pre><span class="pl-c1">electrondisplay</span>(<span class="pl-c1">@doc</span> reduce; single_window<span class="pl-k">=</span><span class="pl-c1">true</span>, focus<span class="pl-k">=</span><span class="pl-c1">false</span>)</pre></div>
