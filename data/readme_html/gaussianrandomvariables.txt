<p dir="auto">This implements a numeric type, <code>GVar</code>, representing a Gaussian (normal) random variable. Some elementary mathematical functions of these variables are implemented, and these also return <code>GVar</code>s giving the approximate distribution of the output.</p>
<p dir="auto">Demo:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using GaussianRandomVariables

<p dir="auto">Related package: <a href="https://github.com/JuliaPhysics/Measurements.jl">Measurements.jl</a> is a much more fully-developed and featureful package which also handles arithmetic with Gaussian random variables. However, it implements first-order (linear) error propagation, which leads to different rules of arithmetic: compare</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using GaussianRandomVariables

julia&gt; (0 ± 1)^2

<span class="pl-c1">1.0</span> <span class="pl-k">±</span> <span class="pl-c1">1.4142135623730951</span></pre></div>
<p dir="auto">with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Measurements

<span class="pl-c1">0.0</span> <span class="pl-k">±</span> <span class="pl-c1">0.0</span></pre></div>
<p dir="auto">Measurements is recommended for most users, but GaussianRandomVariables can be recommended if second-order accuracy matters in your application.</p>
<p dir="auto">GaussianRandomVariables is built on top of <a href="https://github.com/timholy/ThickNumbers.jl">ThickNumbers</a>, and the API for working with <code>GVar</code>s is described in detail there.</p>
