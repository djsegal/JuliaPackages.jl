<p dir="auto">This is a developer-facing project and most users <strong>should not</strong> depend on it directly. As
such, we don't have tutorials for this package. Instead, we recommend you check out the
<a href="http://lux.csail.mit.edu/" rel="nofollow">Lux tutorials</a>.</p>

<p dir="auto">This is currently a place to hold more specialized kernels and layer implementations for
Lux.jl. Anyone is free to move these to NNlib.jl (this package is MIT licensed), but I
probably don't have the time to do so myself. But incase you do, open an issue here and let
me know I will delete the code from this package.</p>
