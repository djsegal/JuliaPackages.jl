<ul dir="auto">
<li>由<a href="https://github.com/opennars/opennars/wiki/Narsese-Grammar-(Input-Output-Format)">Narsese Grammar (IO Format)</a>定义，</li>
<li>在各类NARS(Narsese)实现中，最先产生规范，且最广为接受的一种语法</li>
<li>基本是各路NARS实现之Narsese语法的<strong>交集</strong></li>
</ul>
<p dir="auto">与其它方言、超集的不同点举例：</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Atom 原子词项</h4><a id="user-content-atom-原子词项" class="anchor" aria-label="Permalink: Atom 原子词项" href="#atom-原子词项"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>一律使用<code>$</code>、<code>#</code>、<code>?</code>、<code>^</code>区分「独立变量」「非独变量」「查询变量」「操作」</li>
<li>一律使用单独的<code>_</code>表示「像占位符」</li>
<li>一律不在名称中包含特殊符号
<ul dir="auto">
<li>如<code>^goto</code>（不允许<code>^go-to</code>）</li>
</ul>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Compound 复合词项</h4><a id="user-content-compound-复合词项" class="anchor" aria-label="Permalink: Compound 复合词项" href="#compound-复合词项"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>一律使用特殊括弧<code>{词项...}</code>、<code>[词项...]</code>表示「外延集」「内涵集」</li>
<li>一律使用「圆括号+前缀表达式」<code>(连接符, 词项...)</code>形式表示「非外延集、内涵集的复合词项」
<ul dir="auto">
<li>如<code>(&amp;, &lt;A --&gt; B&gt;, ^op)</code></li>
<li>对「否定」不使用前缀表达式</li>
<li>对其它「二元复合词项」不使用中缀表达式</li>
</ul>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Statement 陈述</h4><a id="user-content-statement-陈述" class="anchor" aria-label="Permalink: Statement 陈述" href="#statement-陈述"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>一律使用尖括号表示陈述，没有其他选项
<ul dir="auto">
<li>如<code>&lt;A --&gt; B&gt;</code></li>
</ul>
</li>
<li>不使用「回顾性等价」<code>&lt;\&gt;</code>系词
<ul dir="auto">
<li>一律用表义能力等同的「预测性等价」<code>&lt;/&gt;</code>系词代替</li>
<li>如<code>&lt;A &lt;\&gt; B&gt;</code>将表示为<code>&lt;B &lt;/&gt; A&gt;</code></li>
</ul>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Sentence 语句</h4><a id="user-content-sentence-语句" class="anchor" aria-label="Permalink: Sentence 语句" href="#sentence-语句"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>「真值缺省」：解析语句时，允许不输入一部分真值
<ul dir="auto">
<li>此类真值将在输入具体NARS实现时被补全
<ul dir="auto">
<li>如：OpenNARS的「默认真值」<code>%1.0; 0.9%</code></li>
<li>如：OpenJunars的「默认真值」<code>%1.0; 0.5%</code></li>
</ul>
</li>
<li>具体形式
<ul dir="auto">
<li>单缺省（单真值）：f已指定，缺c值
<ul dir="auto">
<li>如<code>A. %1.0%</code></li>
</ul>
</li>
<li>全缺省（空真值）：f、c均未指定
<ul dir="auto">
<li>如<code>A.</code></li>
</ul>
</li>
</ul>
</li>
</ul>
</li>
</ul>

<p dir="auto">JuNarsese包含两个主要模块：</p>
<ul dir="auto">
<li>Narsese: Narsese的数据结构
<ul dir="auto">
<li>词项(NAL-1 ~ NAL-8)</li>
<li>语句(+标点、真值、时间戳)</li>
<li>任务(+预算值)</li>
</ul>
</li>
<li>Conversion: 用于数据结构间的转换
<ul dir="auto">
<li>提供解析器API
<ul dir="auto">

<ul dir="auto">
<li>字符串</li>
<li>AST（抽象语法树，对应Julia的<code>Expr</code>类型）</li>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">自带解析器</h3><a id="user-content-自带解析器" class="anchor" aria-label="Permalink: 自带解析器" href="#自带解析器"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">JuNarsese自带的解析器有：</p>
<ul dir="auto">
<li><strong>字符串解析器<code>StringParser</code></strong>
<ul dir="auto">
<li>支持类<a href="#commonnarsese">CommonNarsese</a>语法的解析</li>
<li>均在一定程度上支持Unicode字符</li>
<li>可以使用字符串宏尾缀<code>narsese"待解析文本"FLAG</code>指定，以便从某种形式快速构造文本
<ul dir="auto">
<li>例：<code>nse"&lt;A --&gt; B&gt;"ascii</code>意味着以ASCII解析器解析Narsese文本「&lt;A --&gt; B&gt;」</li>
<li>各类尾缀在下方以「子类型名称（尾缀）列出」</li>
</ul>
</li>
<li>共有三种子类型
<ul dir="auto">
<li>ASCII（<code>ascii</code>）：忠于<a href="#commonnarsese">CommonNarsese</a>语法，可解析基本ASCII字符串</li>
<li>LaTeX（<code>latex</code>）：支持LaTeX语法，可解析LaTeX字符串</li>
<li>漢文（<code>han</code>）：支持简体中文风格的纯中文<a href="#commonnarsese">CommonNarsese</a>语法</li>
</ul>
</li>
</ul>
</li>
<li><strong>AST解析器<code>ASTParser</code></strong>
<ul dir="auto">
<li>使Narsese对象可与Julia原生的<code>Expr</code>对象相互转换</li>
<li>其中只会包含：
<ul dir="auto">
<li>符号<code>Symbol</code></li>
<li>数值<code>Number</code></li>
<li>其它<code>Expr</code></li>
</ul>
</li>
</ul>
</li>
<li><strong>原生对象解析器<code>NativeParser</code></strong>
<ul dir="auto">
<li>使Narsese对象可与原生Julia对象相互转换</li>
<li>其中只会包含：
<ul dir="auto">
<li>字符串<code>String</code></li>
<li>数组<code>Vector</code></li>
<li>字典<code>Dict</code>（在使用子类型「字典解析器」时）</li>
</ul>
</li>
<li>共两种子类型：
<ul dir="auto">
<li>字典解析器<code>NativeParser_dict</code>：以字典形式封装复合词项、陈述、语句和任务</li>
<li>数组解析器<code>NativeParser_vector</code>：以数组形式封装复合词项、陈述、语句和任务</li>
</ul>
</li>
</ul>
</li>
<li><strong>快捷构造解析器<code>ShortcutParser</code></strong>
<ul dir="auto">
<li>可以直接使用Julia代码构建词项</li>
<li>只有解析，没有构造：暂不能通过<code>narsese2data</code>将Narsese对象转化为相应字符串</li>
<li>⚠不推荐使用</li>
</ul>
</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">数据结构</h3><a id="user-content-数据结构" class="anchor" aria-label="Permalink: 数据结构" href="#数据结构"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">使用JuNarsese构建Narsese的数据结构（词项、语句、任务），只需使用<code>narsese"【CommonNarsese】"</code>或缩写<code>nse"【CommonNarsese】"</code>，此举会自动将字符串形式的<a href="#commonnarsese">CommonNarsese</a>转换成相应的Narsese数据结构</p>
<ul dir="auto">
<li>对原子词项而言，亦可使用如下字符串宏：
<ul dir="auto">
<li><code>w"word"</code>：构造「词语」<code>word</code></li>
<li><code>i"ind_var"</code>：构造「独立变量」<code>$ind_var</code></li>
<li><code>d"i_var"</code>：构造「非独变量」<code>#d_var</code></li>
<li><code>q"q_var"</code>：构造「查询变量」<code>?q_var</code></li>
<li><code>n"123"</code>：构造「间隔」<code>+123</code></li>
<li><code>o"op"</code>：构造「操作符」<code>^op</code></li>
</ul>
</li>
<li>在构造复合词项/陈述时，亦可：
<ul dir="auto">
<li>使用JuNarsese导出的Unicode运算符，如用<code>w"S"→w"P"</code>生成「继承陈述」<code>&lt;S --&gt; P&gt;</code>。</li>
<li>直接调用数据结构的构造函数，例如用<code>Inheritance(S, P)</code>生成「继承陈述」<code>&lt;S --&gt; P&gt;</code>。</li>
</ul>
</li>
</ul>

<p dir="auto">使用JuNarsese解析以其它形式呈现的Narsese对象，只需使用两个函数：</p>
<ul dir="auto">
<li><code>narsese2data</code>：从Narsese对象转换成其它类型数据
<ul dir="auto">
<li>参数：<code>narsese2data(解析器, Narsese对象)</code></li>
</ul>
</li>
<li><code>data2narsese</code>：从其它类型数据转换成Narsese对象
<ul dir="auto">
<li>参数：<code>data2narsese(解析器, 转换的目标类型, 其它类型数据)</code></li>
<li>其中「转换的目标类型」仅在「转换可能发生歧义」时使用
<ul dir="auto">
<li>不关注「目标类型」时可填<code>Any</code>，意为「兼容模式」（自动将输入识别成Narsese对象）</li>
<li>当填写类型后，转换将只返回是「目标类型」的对象
<ul dir="auto">
<li>例如<code>Term</code>将只返回词项（非词项对象将报错）</li>
</ul>
</li>
</ul>
</li>
</ul>
</li>
</ul>
<p dir="auto">或更简单地，直接调用解析器对象</p>
<ul dir="auto">
<li>如<code>解析器对象(待翻译对象/待转换Narsese对象)</code></li>
