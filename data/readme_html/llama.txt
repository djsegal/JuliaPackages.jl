<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Downloading the model weights</h2><a id="user-content-downloading-the-model-weights" class="anchor" aria-label="Permalink: Downloading the model weights" href="#downloading-the-model-weights"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">You will need a file with quantized model weights in the right format (GGUF).</p>
<p dir="auto">You can either download the weights from the <a href="https://huggingface.co" rel="nofollow">HuggingFace Hub</a> (search for "GGUF" to download the right format) or convert them from the original PyTorch weights (see <a href="https://github.com/ggerganov/llama.cpp">llama.cpp</a> for instructions.)</p>
<p dir="auto">Good weights to start with are the Dolphin-family fine-tuned weights, which are Apache 2.0 licensed and can be downloaded <a href="https://huggingface.co/TheBloke/dolphin-2.6-mistral-7B-dpo-GGUF" rel="nofollow">here</a>. Click on the tab "Files" and download one of the <code>*.gguf</code> files. We recommend the Q4_K_M version (~4.4GB).</p>
<p dir="auto">In the future, there might be new releases, so you might want to check for new versions.</p>
<p dir="auto">Once you have a <code>url</code> link to a <code>.gguf</code> file, you can simply download it via:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Llama

model = download_model(url)
# Output: &quot;models/dolphin-2.6-mistral-7b-dpo.Q4_K_M.gguf&quot;"><pre><span class="pl-k">using</span> Llama
