<p dir="auto">A julia package for visualizing holomorphic and meromorphic functions.</p>
<p dir="auto">I used it for explanations in a complex analysis course in summer 2021.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Why this package?</h2><a id="user-content-why-this-package" class="anchor" aria-label="Permalink: Why this package?" href="#why-this-package"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">I wanted</p>
<ul dir="auto">
<li>to try out some programming concepts (e.g. <a href="./docs/composition.md">composition</a>)
with julia</li>
<li>to have a tool for interactively showing/explaining meromorphic functions
(see <a href="./examples#user-content-examples">examples</a>)</li>
<li>to have fun programming in julia</li>
</ul>

<p dir="auto">There is a very thin "layer" to show the functions in a <code>GtkDrawingArea</code> in a native window (using Gtk) in an extra package <a href="https://github.com/luchr/ComplexVisualGtk.jl">ComplexVisualGtk.jl</a>.</p>
<p dir="auto">This package can also be used "standalone" (without windows and interactivity) to save the visualizations as images.</p>
