<p dir="auto">The purpose of SMDGraphs.jl is to enable efficient support for graph operations and analysis
on custom user-defined datatypes. It achieves so by offering a set of light-weight wrappers
around <a href="https://github.com/JuliaGraphs/Graphs.jl">Graphs.jl</a>.</p>
