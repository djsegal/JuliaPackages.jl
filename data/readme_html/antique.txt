<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Antique"><pre><span class="pl-k">using</span> Antique</pre></div>
<p dir="auto">The energy <code>E()</code>, the wave function <code>ψ()</code>, the potential <code>V()</code> and some other functions will be exported. There are two ways to avoid function name conflicts. Run <code>import Antique</code> instead of <code>using Antique</code>, and use the energy <code>Antique.E()</code>, the wave function <code>Antique.ψ()</code> and the potential <code>Antique.V()</code>. Or try giving other function names like <code>using Antique: V as potential, E as energy, ψ as wavefuntion, HydrogenAtom</code>. Here are examples for the hydrogen-like atom. The analytical notation of the energy (the eigen value of the Hamiltonian) is written as</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$$E_n = -\frac{Z^2}{2n^2} E_\mathrm{h}.$$</math-renderer>
<p dir="auto">The Hydrogen atom has the symbol <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$\mathrm{H}$</math-renderer> and atomic number 1 (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$Z=1$</math-renderer>). Therefore the ground state (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$n=1$</math-renderer>) energy is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$-\frac{1}{2} E_\mathrm{h}$</math-renderer>.</p>

<p dir="auto">This is an example of a variational calculation for the hydrogen atom based on <a href="https://doi.org/10.1017/CBO9781139171397" rel="nofollow">Thijssen(2007)</a>. We check the accuracy of the numerical solution by comparison with the analytical solution. Comparing wavefunctions can be difficult, but Antique.jl makes it easy. You can extend it to excited states (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$n&amp;gt;1$</math-renderer>) as well as the ground state (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4ddb474c648e089c4daa178e678ab451">$n=1$</math-renderer>). Thus, Antique.jl is useful for testing numerical methods. We hope many numerical methods to be developed using Antique.jl.</p>

<p dir="auto">This is the guideline for adding new models. Adding a new model may take from a few days to a few weeks due to reference search, test implementation, and writing documentation.</p>
<ol dir="auto">
<li>First, please submit a new issue or comment <a href="https://github.com/ohno/Antique.jl/issues">here</a>. I will assign you to the issue. We need to find orthodox references (textbooks or papers, not Wikipedia) for the analytical solutions (eigenvalues and eigenfunctions) before the development. This will take more time than you think.</li>
<li>Fork <a href="https://github.com/ohno/Antique.jl">the repository</a> on GitHub.</li>
<li>Clone the forked repository to your local machine by Git.</li>
<li>Please create 3 files:</li>
</ol>

We recommend that you copy these files. First create a structure <code>struct ModelName</code> with the same name as the model name (The best way is Find &amp; Replace). Because the function names conflict, you must always give the struct <code>ModelName</code> as the first argument to V, E, ψ and other functions. Multi-dispatch avoids conflicts. We recommend using Revice.jl while coding. Run <code>include("./dev/revice.jl")</code> on the REPL or use dev.ipynb.</td>
