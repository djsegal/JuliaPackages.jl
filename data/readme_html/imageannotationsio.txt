<p dir="auto">ImageAnnotationsIO provides methods for loading and saving <a href="https://github.com/IHPSystems/ImageAnnotations.jl">image annotations</a> using common formats, like the <a href="https://opencv.github.io/cvat/docs/manual/advanced/xml_format/" rel="nofollow">CVAT XML annotation format</a>, or the <a href="https://github.com/CSAILVision/LabelMeAnnotationTool/blob/master/Annotations/example_folder/img1.xml">LabelMe XML format</a>.</p>
<p dir="auto">There is currently support for loading and saving:</p>
<ul dir="auto">
<li>Bounding box annotations (for object detection).</li>
<li>Image annotations (for image classification).</li>
<li>Oriented bounding box annotations (for object detection).</li>
<li>Polygon annotations (for object detection).</li>
</ul>
