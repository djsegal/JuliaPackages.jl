<p dir="auto"><strong>Network Data Formats</strong></p>
<ul dir="auto">
<li>PowerModels ".json" files</li>
</ul>
<p dir="auto"><strong>Resevoir Data Formats</strong></p>
<ul dir="auto">
<li>JSON ".json" files</li>
</ul>
<p dir="auto"><strong>Problem Specifications and Network Formulations</strong></p>
<ul dir="auto">
<li>Problem Specifications and Network Formulations are handled by <a href="https://github.com/lanl-ansi/PowerModels.jl">PowerModels.jl</a>.</li>
</ul>
<p dir="auto"><strong>Solution Method</strong></p>
<ul dir="auto">
<li>Solution method is handled by <a href="https://github.com/odow/SDDP.jl">SDDP.jl</a>.</li>
</ul>

</ul>
