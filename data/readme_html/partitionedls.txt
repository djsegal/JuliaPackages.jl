<p dir="auto">Linear least squares is one of the most widely used regression methods among scientists in many fields. The simplicity of the model allows this method to be used when data is scarce and it is usually appealing to practitioners that need to gather some insight into the problem by inspecting the values of the learnt parameters.</p>
<p dir="auto">PartitionedLS is a <strong>variant</strong> of the linear least squares model allowing practitioners to <strong>partition the input features into groups of variables</strong> that they require to contribute with the same sign to the final result.</p>
<p dir="auto">For instance, when analyzing complex chemical compounds, it is possible to group together fine-grained features to obtain a partition which refers to high-level properties of the compound (such as structural, interactive and bond-forming among others), and knowing how much each high-level property contributes to the result of the analysis is often of great practical value. The PartitionedLS squares problem allows a practitioner to specify how to group the variables together.</p>
<p dir="auto">Then, the target value for a new sample <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$x$</math-renderer> will be predicted as:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$$f(x) = \sum_{k=1}^{K} \beta_i \sum_{m \in P_k} \alpha_m x_m + t$$</math-renderer>
<p dir="auto">where:</p>
<ul dir="auto">
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$K$</math-renderer> is the number of groups;</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$P_k$</math-renderer> is the set of indices of the variables in the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$k$</math-renderer>-th group;</li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$\sum_{m \in P_k} \alpha_m = 1$</math-renderer></li>
<li>we have a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$\beta$</math-renderer> variable for each group, specifying how much (and in which direction) the group contributes to the final result;</li>
<li>an <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$\alpha$</math-renderer> variable for each feature in the group, specifying how much the feature contributes to the group.</li>
</ul>
<p dir="auto">The optimization problem is solved by minimizing the sum of the squared residuals, with the additional constraint that the sum of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2837e046a63fb091e9f822ec4fdddf4d">$\alpha$</math-renderer> variables in each group is equal to 1.</p>
<p dir="auto">While the interpretability angle is important, it is worth noticing that the constraint posed by the algorithm also act as an inductive bias, which can lead the optimization to a better solution when it matches the structure of the underlying phenomenon.</p>

<p dir="auto">You can choose between three algorithms to solve the problem: <code>Opt</code>, <code>Alt</code>, and <code>BnB</code>. The <code>Opt</code> algorithm is the optimal one, but it is exponential in the number of partitions. The <code>Alt</code> algorithm is an iterative one, based on the Alternating Least Squares approach. The <code>BnB</code> algorithm is a variant of the <code>Opt</code> algorithm that is often faster in practice and still guarantees the optimal solution.</p>
