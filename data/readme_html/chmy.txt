<p dir="auto">Hey, that's Chmy.jl 🚀</p>
<p dir="auto">Chmy.jl (pronounce <em>tsh-mee</em>) provides a backend-agnostic toolkit for finite difference computations on multi-dimensional computational staggered grids. Chmy.jl features task-based distributed memory parallelisation capabilities.</p>
