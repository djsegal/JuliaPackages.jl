<p dir="auto"><strong>MultiQuad.jl</strong> is a convenient interface to perform 1D, 2D and 3D numerical integrations.
It uses <a href="https://github.com/JuliaMath/QuadGK.jl">QuadGK</a>, <a href="https://github.com/giordano/Cuba.jl">Cuba</a> and <a href="https://github.com/stevengj/HCubature.jl">HCubature</a> as back-ends.</p>

<p dir="auto">It is possible to use <code>quad</code> to perform 1D integrals of the following kind:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/f4298f96222bb5e9f2cce3f2946cdc99adbf08df1d79ca8ea0b2bc306a9de308/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f706e672e6c617465783f5c6470697b3135307d2673706163653b5c696e745f7b78317d5e7b78327d662878296478"><img src="https://camo.githubusercontent.com/f4298f96222bb5e9f2cce3f2946cdc99adbf08df1d79ca8ea0b2bc306a9de308/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f706e672e6c617465783f5c6470697b3135307d2673706163653b5c696e745f7b78317d5e7b78327d662878296478" title="\int_{x1}^{x2}f(x)dx" data-canonical-src="https://latex.codecogs.com/png.latex?\dpi{150}&amp;space;\int_{x1}^{x2}f(x)dx" style="max-width: 100%;"></a></p>
<p dir="auto">The supported adaptive integration methods are:</p>
<ul dir="auto">
<li><code>:quadgk</code></li>
<li><code>:vegas</code></li>
<li><code>:suave</code></li>
</ul>
<p dir="auto">There are several fixed order quadrature methods available based on <a href="https://github.com/JuliaApproximation/FastGaussQuadrature.jl"><code>FastGaussQuadrature</code></a></p>
<ul dir="auto">
<li><code>:gausslegendre</code></li>
<li><code>:gausshermite</code></li>
<li><code>:gausslaguerre</code></li>
<li><code>:gausschebyshev</code></li>
<li><code>:gaussradau</code></li>
<li><code>:gausslobatto</code></li>
</ul>
<p dir="auto">If a specific integration routine is not needed, it is suggested to use <code>:quadgk</code> (the default option).
For highly oscillating integrals, it is advised to use <code>:gausslegendre</code>with a high order (~10000).</p>
<p dir="auto">Please note that <code>:gausshermite</code> and <code>:gausslaguerre</code> are used to specific kind of integrals with infinite bounds.</p>
<p dir="auto">For more informations on these integration techniques, please follow the official documentation <a href="https://juliaapproximation.github.io/FastGaussQuadrature.jl/stable/gaussquadrature/" rel="nofollow">here</a>.</p>
<p dir="auto">While using fixed order quadrature methods, it is possible to use multithreading to compute the 1D quadrature, by passing the keyword argument <code>mutithreading=true</code> to <code>quad</code>. If the forseen integration time is long, it is also possible to display a progress bar by passing the keyword argument <code>verbose=true</code>.</p>
<p dir="auto">See <a href="https://github.com/JuliaMath/QuadGK.jl">QuadGK</a> and <a href="https://giordano.github.io/Cuba.jl/stable/" rel="nofollow">Cuba.jl</a> for all the available keyword arguments.</p>
