<p dir="auto"><strong>FastGeoProjections</strong> is intended to provide highly optimized native Julia geospatial coordinate transformations from one coordinate reference system (CRS) to another as defined by EPSG codes. It is not intended to replace, nor to be as comprehensive as, <a href="https://github.com/JuliaGeo/Proj.jl">Proj</a>. The package will natively support only the most common geospatial transformations and relies on <strong>Proj.jl</strong> for all others.</p>
<p dir="auto"><em>Supported Projection EPSGs</em></p>
<ul dir="auto">
<li>3031:     WGS 84 / Antarctic Polar Stereographic</li>
<li>3413:     WGS 84 / NSIDC Sea Ice Polar Stereographic North</li>
<li>4326:     WGS84 - World Geodetic System 1984</li>
<li>326XX:    WGS 84 / UTM zone XXN</li>
<li>327XX:    WGS 84 / UTM zone XXS</li>
</ul>
