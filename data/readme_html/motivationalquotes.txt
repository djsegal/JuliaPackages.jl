<p dir="auto">This fun package greets you with a random motivating quote. In case you feel too motivated you can use the <code>demotivate_me</code> command to bring you down to earth again.</p>

<p dir="auto">You can select topics by using the <code>topics</code> argument and you can return the quote instead of printing it using <code>print_quote</code> (true/false).
Currently, the only available topics are: general, academia, economics</p>

<p dir="auto">The following keyword arguments are available.
<code>topics</code> allows to select a specific topic of quotes.
<code>print_quote</code> (true/false) either prints the quote as output or only returns the quote. Default is <code>true</code>.
<code>nodownload</code> (true/false) surpresses the attempt to download new quotes (once a week) from my DataHub. Default is <code>false</code>.</p>
