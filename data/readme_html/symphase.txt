<p dir="auto">A high-performance Julia module for sampling stabilizer circuits by symbolizing the phases of Pauli strings.
See <a href="http://arxiv.org/abs/2311.03906" rel="nofollow">the arXiv paper describing SymPhase</a>.</p>

<p dir="auto">We have compared SymPhase.jl with Stim in <a href="http://arxiv.org/abs/2311.03906" rel="nofollow">the arXiv paper</a>.</p>
<p dir="auto">To reproduce the experiment, follow the procedure:</p>
<ol dir="auto">
<li>
<p dir="auto">Install Stim (as of 7/11/2023, the latest stable version is 1.12.0) with <code>pip</code>.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pip install stim==1.12.0"><pre>pip install stim==1.12.0</pre></div>
</li>
<li>
<p dir="auto">Follow the instruction <a href="#installation">Installation</a> to install Symphase.jl.</p>
</li>
<li>
<p dir="auto">Clone this repo and go to the <code>example</code> directory.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="git clone https://github.com/njuwfang/SymPhase.jl.git &amp;&amp; cd ./SymPhase.jl/example/"><pre>git clone https://github.com/njuwfang/SymPhase.jl.git <span class="pl-k">&amp;&amp;</span> <span class="pl-c1">cd</span> ./SymPhase.jl/example/</pre></div>
</li>
<li>
<p dir="auto">Generate benchmark files (in <code>.stim</code> format).</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia generate_randomcircuits.jl"><pre>julia generate_randomcircuits.jl</pre></div>
<p dir="auto">Each circuit is made up of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$n$</math-renderer> qubits with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$n$</math-renderer> layers. Each layer randomly applies an <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$H$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$S$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$I$</math-renderer> gate to each qubit, then applies <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\mathit{CNOT}$</math-renderer> gates, then samples 5% of the qubits to measure in the computational basis. At the end of the circuit, each qubit is measured in the computational basis.</p>
<ul dir="auto">
<li>for <code>./stim_benchmark/randomxxx.stim</code>, each layer randomly selects 5 pairs (1 pair in Stim's paper) of qubits to apply <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\mathit{CNOT}$</math-renderer> gates.</li>
<li>for <code>./stim_benchmark/randomxxx_xxxCNOT.stim</code>, each layer randomly selects <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\lfloor\frac{n}{2}\rfloor$</math-renderer> pairs of qubits to apply <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\mathit{CNOT}$</math-renderer> gates.</li>
<li>for <code>./stim_benchmark/randomxxx_xxxCNOT_dep.stim</code>, each layer randomly selects <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\lfloor\frac{n}{2}\rfloor$</math-renderer> pairs of qubits to apply <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="926b26e9376f753c717e76c879b2818a">$\mathit{CNOT}$</math-renderer> gates and additionally applies single-qubit depolarize noise to each qubit.</li>
</ul>
</li>
<li>
<p dir="auto">Benchmark Stim and SymPhase.jl.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="python3 benchmark_stim.py"><pre>python3 benchmark_stim.py</pre></div>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia benchmark_symphase.jl"><pre>julia benchmark_symphase.jl</pre></div>
<p dir="auto">The benchmark results are stored in files with the <code>.dat</code> suffix.</p>
</li>
</ol>
