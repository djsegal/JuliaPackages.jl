<p dir="auto">Pure Julia implementation of the Byte Pair Encoding (BPE) method. Support
<a href="https://github.com/openai/gpt-2">openai-gpt2</a> byte-level bpe
and <a href="https://github.com/openai/tiktoken">openai tiktoken</a>. <code>BytePairEncoding.jl</code> rely on
<a href="https://github.com/chengchingwen/TextEncodeBase.jl">TextEncodeBase.jl</a> and support different tokenization method.</p>
