<p dir="auto"><code>PowerModelsITD.jl</code> is an extention package based on <a href="https://github.com/lanl-ansi/PowerModels.jl">PowerModels.jl</a> and <a href="https://github.com/lanl-ansi/PowerModelsDistribution.jl">PowerModelsDistribution.jl</a> for steady-state Integrated Transmission-Distribution (ITD) power network optimization. It is designed to enable the computational evaluation of emerging power network formulations and algorithms in a common platform. The code is engineered to decouple problem specifications (e.g. Power Flow, Optimal Power Flow, ...) from power network formulations (e.g. AC polar, AC rectangular, linear-approximation, SOC-relaxation, ...) on both transmission and distribution system(s). Thus, enabling the definition of a wide variety of ITD power network formulations and their comparison on common problem specifications.</p>
