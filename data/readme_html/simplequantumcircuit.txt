<p dir="auto">A simple module to build quantum circuits that is also easy to learn. It uses Julia's native types. The module is designed to be easily extendable and also perform calculation at higher precisions.
This module provides a Unitary Evolution Matrix "U" for a sequence of gates. The U can be applied to any wavefunction which is represented as an array</p>

<p dir="auto">Define a new gate. This is an alternative to defining the Matrix directly in the crcuit. It is helpful if a custom gate is used in multiple places or circuits</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="H(qubitOrder=missing) = gate([1 1; 1 -1]/sqrt(2), qubitOrder, &quot;H&quot;)"><pre class="notranslate"><code>H(qubitOrder=missing) = gate([1 1; 1 -1]/sqrt(2), qubitOrder, "H")

<p dir="auto">The function paramter qubitOrder is optional while defining the gate but is nedded while using it in circuit. This is because the gate called without the qubitOrder returns the matrix representation of the gate.
There is a global variable "T" in the module that defines the precision. If you are planning to use higher precision, define gates as</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="H(qubitOrder=missing) = gate([T(1) T(1); T(1) T(-1)]/sqrt(T(2)), qubitOrder, &quot;H&quot;)"><pre class="notranslate"><code>H(qubitOrder=missing) = gate([T(1) T(1); T(1) T(-1)]/sqrt(T(2)), qubitOrder, "H")
