<p dir="auto">The <code>OliveImages</code> module provides <a href="https://github.com/ChifiSource/Olive.jl">Olive</a> with the ability to read and work with image files, including</p>
<ul dir="auto">
<li>SVG files</li>
<li>PNG files</li>
<li>GIF files</li>
<li>and JPG files.</li>
</ul>
<p dir="auto">For now, the only feature offered is opening and viewing images in a project alone. Future functionality will include sourcing images from files in projects and editing images.</p>
<ul dir="auto">
<li>To add this <code>Olive</code> extension, add <code>using OliveImages</code> to your <code>olive</code> home after adding this package. For information on this, check out <a href="https://github.com/ChifiSource/Olive.jl#installing-extensions">installing extensions</a>.</li>
</ul>
