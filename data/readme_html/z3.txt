<p dir="auto">Uses <a href="https://github.com/JuliaInterop/Clang.jl">Clang.jl</a> to wrap
around Z3's <a href="https://z3prover.github.io/api/html/group__capi.html" rel="nofollow">C API</a>,
and <a href="https://github.com/JuliaPackaging/BinaryBuilder.jl">BinaryBuilder.jl</a> to build the Z3 binary
(build script <a href="https://github.com/JuliaPackaging/Yggdrasil/blob/master/Z/z3/build_tarballs.jl">here</a>).</p>
<p dir="auto">Design follows <a href="https://ericpony.github.io/z3py-tutorial/guide-examples.htm" rel="nofollow">Z3Py</a>.
In particular, we provide an implicit global <code>Context</code>, and overload operators (like <code>+</code>,<code>-</code>,<code>*</code>, <code>/</code>)
to create Z3 expressions.</p>
