<p dir="auto">This package wraps some R (GPL-2/3) libraries for fitting IRT models.</p>
<p dir="auto">The wrapped libraries are:</p>
<ul dir="auto">
<li><a href="https://github.com/philchalmers/mirt">mirt</a> (GPL-3)</li>
<li><a href="https://cran.r-project.org/web/packages/KernSmoothIRT/index.html" rel="nofollow">kernsmoothirt</a> (GPL-2)</li>
</ul>

<p dir="auto">Using wrappers typically come with a bunch of drawbacks. The main purpose of
these wrappers is for use in demos and for contently comparing results with
Julia code, i.e., more notebook and script level code than final applications.</p>
