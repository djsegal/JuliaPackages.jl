<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Pipette: A Smoother Pipe Operator</h1><a id="user-content-pipette-a-smoother-pipe-operator" class="anchor" aria-label="Permalink: Pipette: A Smoother Pipe Operator" href="#pipette-a-smoother-pipe-operator"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If you love the Julia REPL and the pipe operator,</p>
<p dir="auto">if you have a problem with typing the prickly <code>" |&gt; "</code> sequence<sup><a href="#user-content-fn-1-b39937c314fcaf4d3d566f8ab5c3a0f6" id="user-content-fnref-1-b39937c314fcaf4d3d566f8ab5c3a0f6" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>,</p>
<p dir="auto">and if no one else can help,</p>
<p dir="auto">maybe <strong>you</strong> can hire Pipette and insert <code>" |&gt; "</code> with double-tapping arrow-right [➔] at the end of the line:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; get_transmogrifying_iterator()#..now just double tap [➔].."><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">get_transmogrifying_iterator</span>()<span class="pl-c"><span class="pl-c">#</span>..now just double tap [➔]..</span></pre></div>
<p dir="auto">Voilà:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; get_transmogrifying_iterator() |&gt; #&lt;- ta ta-da TAAAA!"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">get_transmogrifying_iterator</span>() <span class="pl-k">|&gt;</span> <span class="pl-c"><span class="pl-c">#</span>&lt;- ta ta-da TAAAA!</span></pre></div>
<br>
<p dir="auto">Alternatively, press <code>[Ctrl+➔]</code> to insert the string <code>" |&gt; "</code> anywhere on a line.</p>
<br>
<br>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Usage</h3><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">The delay between [➔]-taps must be &lt;300 milli-seconds to register as double-tap.</p>
<p dir="auto">It also must be &gt;100 milli-seconds -- this avoids pipes galore when you keep pressing the cursor to reach the end of a line.</p>
<p dir="auto">You can configure this with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; Pipette.set_doubletap_delay(from=100, to=300)"><pre>julia<span class="pl-k">&gt;</span> Pipette<span class="pl-k">.</span><span class="pl-c1">set_doubletap_delay</span>(from<span class="pl-k">=</span><span class="pl-c1">100</span>, to<span class="pl-k">=</span><span class="pl-c1">300</span>)</pre></div>
</li>
<li>
<p dir="auto">To tune this, find out your tapping speed and keyboard repeat delay with <code>Pipette.tune_doubletap_delay()</code>.</p>
</li>
<li>
<p dir="auto">To turn Pipette on or off, use <code>Pipette.on()</code> or <code>Pipette.off()</code>. To keep the <code>[Ctrl+➔]</code>-behavior, and just turn off the double-tap one, set the range to zeros.</p>
</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Install</h3><a id="user-content-install" class="anchor" aria-label="Permalink: Install" href="#install"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Just <code>]add Pipette</code> and keep <code>using Pipette</code>.</p>
<p dir="auto">To turn it on by default, you can modify <code>.julia/config/startup.jl</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="atreplinit() do repl
    try         @eval using Pipette  
    catch e;    @warn &quot;Pipette startup error&quot; e  end
end"><pre><span class="pl-c1">atreplinit</span>() <span class="pl-k">do</span> repl
    <span class="pl-k">try</span>         <span class="pl-c1">@eval</span> <span class="pl-k">using</span> Pipette  
    <span class="pl-k">catch</span> e;    <span class="pl-c1">@warn</span> <span class="pl-s"><span class="pl-pds">"</span>Pipette startup error<span class="pl-pds">"</span></span> e  <span class="pl-k">end</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">(Pipette exports nothing, btw.)</p>
