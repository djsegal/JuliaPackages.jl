<p dir="auto">This package provides efficient tools for generating sparse covariance matrices, estimating sparse precision matrices using the graphical lasso (glasso) algorithm (Friedman, Hastie, and Tibshirani 2008; Meinshausen and Bühlmann 2006), and selecting optimal regularization parameters.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key Features:</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key Features:" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><strong>Sparse Covariance Matrix Generation</strong>: Generate random sparse covariance matrices with customizable sparsity thresholds.</li>
<li><strong>Graphical Lasso (glasso) Implementation</strong>: Apply the glasso algorithm to estimate sparse precision matrices from empirical covariance matrices.</li>
<li><strong>Extended Bayesian Information Criterion (EBIC)</strong>: Calculate EBIC for model selection from Foygel and Drton (2010), supporting edge counting with thresholding.</li>
<li><strong>Tuning Parameter Selection</strong>: Automatically select optimal regularization parameters for the glasso algorithm using EBIC.</li>
<li><strong>Covariance Matrix Validation</strong>: Functions to check if a matrix is a valid covariance matrix (square, symmetric, positive semi-definite).</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Functions Included:</h2><a id="user-content-functions-included" class="anchor" aria-label="Permalink: Functions Included:" href="#functions-included"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>softthresh(x, λ)</code>: Applies soft thresholding to an array.</li>
<li><code>cdlasso(W11, s12, λ; max_iter=100, tol=1e-5)</code>: Solves the coordinate descent Lasso problem.</li>
<li><code>glasso(s, obs, λ; penalizediag=true, γ=0.0, tol=1e-05, verbose=true, maxiter=100, winit=zeros(size(s)))</code>: Estimates a sparse inverse covariance matrix using the glasso algorithm.</li>
<li><code>countedges(x, thr)</code>: Counts the number of edges in an array exceeding a threshold.</li>
<li><code>ebic(θ, ll, obs, thr, γ)</code>: Calculates the EBIC for a given precision matrix.</li>
<li><code>critfunc(s, θ, rho; penalizediag=true)</code>: Computes the objective function for the graphical lasso.</li>
<li><code>tuningselect(s, obs, λ; γ=0.0)</code>: Selects the optimal regularization parameter using EBIC.</li>
<li><code>randsparsecov(p, thr)</code>: Generates a random sparse covariance matrix.</li>
<li><code>iscov(x)</code>: Checks if a matrix is a valid covariance matrix.</li>
</ul>

<p dir="auto">Here is an example of how to use this package to generate a sparse covariance matrix, apply the graphical lasso algorithm, and select the optimal tuning parameter:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using LinearAlgebra, GraphicalLasso, Random, Distributions

p = 20
thr = 0.5
Σ = randsparsecov(p, thr)

# Check if this is a valid covariance matrix
iscov(Σ)

# Generate data from the true covariance matrix, create sample covariance matrix
obs = 100
μ = zeros(p)
unstddf = rand(MvNormal(zeros(p), Σ), obs)
df = (unstddf .- mean(unstddf, dims=2)) ./ std(unstddf, dims=2)
s = df * df' / obs

# Select the optimal tuning parameter from a range
λvalues = 0.0:0.01:2.0
optimalλ = tuningselect(s, obs, λvalues, verbose=false)
println(&quot;Optimal λ: &quot;, optimalλ)

# Apply the graphical lasso algorithm

# Extract results

θ = result.θ
ll = result.ll
bicval = result.bicval

println(&quot;Log-Likelihood: &quot;, ll)
println(&quot;EBIC Value: &quot;, bicval)

# Validate if the result is a valid covariance matrix
is_valid_cov = iscov(W)
