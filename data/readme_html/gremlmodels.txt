<p dir="auto"><strong>GREMLModels.jl</strong> is a Julia package for fitting variance component models that are structured according to known, dense, relationship matrices.
The intended use case is the analysis of genetic and environmental components of variance for quantitative traits, when genetic relationship matrices are computed from genome-wide SNP data.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Models</h2><a id="user-content-models" class="anchor" aria-label="Permalink: Models" href="#models"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><strong>GREMLModels.jl</strong> can fit models of the form
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\boldsymbol{y} \sim N(\bf{X} \boldsymbol{\beta}, \bf{V}).$$</math-renderer></p>
<p dir="auto">In this model <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{\beta}$</math-renderer> is the fixed effects of covariates <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{X}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{V}$</math-renderer> is the covariance matrix of the conditional responses. <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{V}$</math-renderer> can be modelled with the following structure</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{V} = \sum_{i=1}^q \delta_i \bf{R}_i$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\delta_i$</math-renderer> are variance component parameters and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{R}_i$</math-renderer> are symmetric matrices that are provided by the user.</p>
<p dir="auto">The variance component parameters can be defined as functions of the vector of parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{\theta}$</math-renderer> that are optimized. This may for instance be needed if <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\delta_i$</math-renderer> is a covariance parameter that is bounded by the values of other parameters. This was the motivation for creating this package.</p>

<p dir="auto">This first creates an object of type <code>GREMLData</code> that is used to hold the data input to a <code>GREMLModel</code>. Then a model, represented by an object of type <code>GREMLModel</code> is created from a constructor that accepts a <code>GREMLData</code>, a vector of initial values for the variance component parameters <code>[1.0, 1.0]</code> and a vector of lower bounds for those parameters <code>[0.0, 0.0]</code>. And in the last line that model is fitted <code>fit!(m2)</code>. The <code>!</code> signals that the function modifies the model, which is a convention in julia.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Example 2</h2><a id="user-content-example-2" class="anchor" aria-label="Permalink: Example 2" href="#example-2"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Consider the model for responses obtained from offspring</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\boldsymbol{y} = \bf{X} \boldsymbol{\beta} + \boldsymbol{m} + \boldsymbol{p} + \boldsymbol{o} + \boldsymbol{\epsilon},$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{o}$</math-renderer> are direct additive effects of offspring own genes, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{m}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{p}$</math-renderer> are indirect effects of maternal and paternal genes and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{\epsilon}$</math-renderer> errors. Parameters of the model are the variances and covariances among the genetic effects and the error variance. Among individuals the genetic effects are correlated according to their genetic relatedness. Conditional on the covariates, this model has covariance matrix</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{V} = \sigma_o^2\bf{A}_{mm} + \sigma_m^2\bf{A}_{pp} + \sigma_p^2\bf{A}_{oo} + \\\
\sigma_{mp}(\bf{A}_{mp}+\bf{A}_{pm}) + \sigma_{mo}(\bf{A}_{mo} + \bf{A}_{om}) + \\\
\sigma_{po}(\bf{A}_{po}+\bf{A}_{op}) + \sigma_\epsilon^2\bf{I}.$$</math-renderer>
<p dir="auto">The genetic relatedness matrices <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{A}_{ij}$</math-renderer> are blocks of the genetic relatedness matrix of all individuals when structured accordingly</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{A} = \begin{bmatrix} \bf{A}_{mm} &amp; \bf{A}_{mp} &amp; \bf{A}_{mo}\\\
\bf{A}_{pm} &amp; \bf{A}_{pp} &amp; \bf{A}_{po}\\\
\bf{A}_{om} &amp; \bf{A}_{op} &amp; \bf{A}_{oo} \end{bmatrix}.$$</math-renderer>
<p dir="auto">In order to fit the model, the first step is to compute the gneetic relationship matrices. The genetic relationships will be estimated from a simulated dataset of 10000 SNPs from 6000 parent-offspring trios stored in <em>plink</em> format. The julia package <code>SnpArrays</code> is used to read snp-data and compute genetic relationships.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using VCModels, LinearAlgebra, DataFrames, StatsModels, SnpArrays

r <span class="pl-k">=</span> [Amm, App, Aoo, Dpm, Dom, Dop, R]</pre></div>
<p dir="auto">It is also necessary to define a matrix of covariates for the means, which is just a constant here</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="X = ones(K)"><pre>X <span class="pl-k">=</span> <span class="pl-c1">ones</span>(K)</pre></div>
<p dir="auto">The dataset also contains some simulated responses</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="y = parse.(Float64, trio.person_info[oid, :phenotype])"><pre>y <span class="pl-k">=</span> <span class="pl-c1">parse</span>.(Float64, trio<span class="pl-k">.</span>person_info[oid, <span class="pl-c1">:phenotype</span>])</pre></div>
<p dir="auto">A challenge with this model is that some of the variance terms represent covariances, which puts restrictions on which values the parameters can take. If we collect the genetic parameters in a covariance matrix</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{G} = \begin{bmatrix} \sigma^2_m &amp; \sigma_{mp} &amp; \sigma_{mo}\\
\sigma_{pm} &amp; \sigma^2_p &amp; \sigma_{po}\\
\sigma_{om} &amp; \sigma_{op} &amp; \sigma^2_o \end{bmatrix},$$</math-renderer></p>
<p dir="auto">this should be positive semidefinite. One way to enforce this is to let the parameters of the model be the elements of the lower-triangular Cholesky factorization <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{L}$</math-renderer> of the covariance matrix for genetic effects</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{L} \bf{L}' = \bf{G}.$$</math-renderer></p>
<p dir="auto">If <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\boldsymbol{\theta}$</math-renderer> is a vector of unique parameters of the model, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\bf{L}$</math-renderer> can be described as</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{L} = \begin{bmatrix} \theta_1 &amp; 0 &amp; 0\\
\theta_2 &amp; \theta_4 &amp; 0\\
\theta_3 &amp; \theta_5 &amp; \theta_6 \end{bmatrix}.$$</math-renderer></p>
<p dir="auto">Then</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$$\bf{G} = \begin{bmatrix} \sigma^2_m &amp; \sigma_{mp} &amp; \sigma_{mo}\\
\sigma_{pm} &amp; \sigma^2_p &amp; \sigma_{po}\\
\sigma_{om} &amp; \sigma_{op} &amp; \sigma^2_o \end{bmatrix} =
\begin{bmatrix} \theta^2_1 &amp; \theta_1\theta_2 &amp; \theta_1\theta_3\\
\theta_2\theta_1 &amp; \theta^2_2 + \theta^2_4 &amp; \theta_2\theta_3 + \theta_4\theta_5\\
\theta_3\theta_1 &amp; \theta_3\theta_2 + \theta_5\theta_4 &amp; \theta^2_3 + \theta^2_5 + \theta^2_6\end{bmatrix}$$</math-renderer></p>
<p dir="auto">This can be implemented by overriding the default <code>VCModels.transform!</code> method. This is used to define the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$q$</math-renderer> dimensional vector of variance component parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\delta$</math-renderer> as a function of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$q$</math-renderer> dimensional vector of parameters that are optimized <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1291c78c33ddac0ccbc9e7fc30754d1b">$\theta$</math-renderer>. In this case, this could be implemented as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function GREMLModels.transform!(δ::Vector, θ::Vector)
