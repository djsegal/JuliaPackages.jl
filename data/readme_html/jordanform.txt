<p dir="auto"><a href="https://github.com/Zinoex/JordanForm.jl">JordanForm.jl</a> is an implementation for computing the Jordan form, also known as Jordan normal form and Jordan canonical form, <strong>intended for educational use</strong>. The Jordan form <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$J$</math-renderer> is a useful almost diagonal structure that is always computable, even if a matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer> is not diagonaliziable. It is commonly used in the study of linear algebra and differential equations. In particular, if we consider a linear system of differential equations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$\dot{x} = Ax$</math-renderer>, then the Jordan form of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer> can be used to find the general solution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$x(t) = e^{At}x_0 = Se^{Jt}S^{-1}x_0$</math-renderer> of the system where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$S$</math-renderer> is the transformation matrix between <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$J$</math-renderer>. That is, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$AS = SJ$</math-renderer>. Furthermore, there exists an analytic formula for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$e^{Jt}$</math-renderer>. The transformation matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$S$</math-renderer> is computed as the concatenation of the generalized eigenvectors of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer>.</p>
<p dir="auto">However, the structure of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$J$</math-renderer> is very unstable under perturbation, as it depends on repeated eigenvalues of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer>. Therefore, it is not recommended to use the Jordan form for numerical computations. So why did we write a library to compute the Jordan form? The Jordan form is a useful tool for studying and understanding matrices and linear systems - and it is fun to write code!</p>
<p dir="auto">You can read more about the Jordan form on <a href="https://en.wikipedia.org/wiki/Jordan_normal_form" rel="nofollow">Wikipedia</a>.</p>

<p dir="auto">As previously noted, the Jordan form is not numerically stable. Therefore, we restrict the input to integer and rational matrices. The Jordan form of a matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5925330b1fc4fbd5f0897f85f3e86253">$A$</math-renderer> is computed using the function <code>jordan_form(A)</code>. The function returns a factorization struct <code>F = (S, J)</code> where <code>J</code> is the Jordan form of <code>A</code> and <code>S</code> is the transformation matrix such that <code>A * S = S * J</code>.</p>
