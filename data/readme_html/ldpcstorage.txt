<p dir="auto"><em>Reads and writes file formats for storing sparse matrices containing only zeros and ones.
Intended for use with low density parity check (LDPC) matrices.
Also supports efficient storage for quasi-cyclic LDPC codes.</em></p>

<ul dir="auto">
<li><code>alist</code> (by David MacKay et al., see <a href="http://www.inference.org.uk/mackay/codes/alist.html" rel="nofollow">http://www.inference.org.uk/mackay/codes/alist.html</a>)</li>
<li><code>cscmat</code> (our custom format) DEPRECATED</li>
<li><code>bincsc.json</code> (Based on compressed sparse column (CSC). Valid <code>json</code>.)</li>
<li><code>qccsc.json</code> (Based on compressed sparse column (CSC). Valid <code>json</code>. Store exponents of quasi-cyclic LDPC matrices)</li>
<li><code>hpp (C++ header)</code> CSC of matrix as static data (write-only, reading not supported!)</li>
</ul>
