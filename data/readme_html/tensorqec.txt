<p dir="auto">This package utilizes the tensor network to study the properties of <em>quantum error correction</em> (QEC).The main features include</p>
<ul dir="auto">
<li>Quantum error correction code decoder with tensor network,</li>
<li>Quantum circuit simulation with tensor network to estimate the threshold of QEC.</li>
</ul>
<p dir="auto">Also, we include more general QEC tools, including</p>
<ul dir="auto">
<li>Commonly used QEC code stabilizer generators,</li>
<li>QEC code distance calculation,</li>
<li>QEC encoding circuit construction,</li>
<li>Decoding truth table construction,</li>
<li>Measurement circuit construction.</li>
</ul>
