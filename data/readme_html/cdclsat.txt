<p dir="auto">Check satisfiability (SAT) of a propositional logic formula in Conjunctive Normal Form (CNF) using the Davis-Putnam-Logemann-Loveland (DPLL) algorithm with Boolean Constraint Propagation (BCP), Conflict-Driven Clause Learning (CDCL), and the Variable State Independent Decaying Sum (VSIDS) decision heuristics.</p>

<p dir="auto">Create a model using the constructor <code>Model()</code>.</p>
<p dir="auto">The following model parameters / fields may be set:</p>
<ul dir="auto">
<li><code>decision::Bool</code> – assignment used when making a heuristics-based decision for a variable</li>
<li><code>vsids_increment::Int</code> – increment of the VSIDS conflict counter for variables involved in a conflict</li>
<li><code>vsids_increase::Int</code> – increase of the VSIDS increment after each conflict</li>
<li><code>vsids_period::Int</code> – number of conflicts per VSIDS period</li>
<li><code>vsids_decay::Float64</code> – multiplier for both VSIDS increment and conflict counters at the end of a period</li>
<li><code>output::BoolOrNothing</code> – output events and assignments (<code>true</code>), only model and solution (<code>false</code>), or <code>nothing</code></li>
</ul>
<p dir="auto">Add variables using the macro <code>@variable &lt;model&gt; &lt;name&gt; (&lt;priority&gt;|ε)</code>.</p>
<p dir="auto">Add clauses using the macro <code>@clause &lt;model&gt; &lt;name&gt; [ (¬|!|ε)&lt;variable&gt; ... ]</code>.</p>
<p dir="auto">Solve the model with the function <code>solve!(model::Model)</code>.</p>
<p dir="auto">If the formula is satisfiable, a satisfying assignment can be obtained from the model field <code>variables</code> by accessing the field <code>assignment</code> of each <code>Variable</code>.</p>
<p dir="auto">Note that a model should not be reused.</p>
