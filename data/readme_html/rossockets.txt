<p dir="auto"><a href="https://github.com/CLeARoboticsLab/RosSockets.jl/actions/workflows/test.yml"><img src="https://github.com/CLeARoboticsLab/RosSockets.jl/actions/workflows/test.yml/badge.svg" alt="RosSockets" style="max-width: 100%;"></a></p>
<p dir="auto">Tools for sending and receiving information from ROS via TCP that can be used to control robots.
This package is meant to communicate with the ROS nodes from <a href="https://github.com/CLeARoboticsLab/ros_sockets">ros_sockets</a>, but also provides a framework for communication with TCP server in general.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">General TCP Communication</h3><a id="user-content-general-tcp-communication" class="anchor" aria-label="Permalink: General TCP Communication" href="#general-tcp-communication"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First, open a connection to the TCP server, setting setting <code>ip</code> and <code>port</code> to match that of the server:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ip = &quot;192.168.1.135&quot;

<p dir="auto">Send messages with <code>send</code>. Note: some TCP servers may be require the message be formatted a certain way (such as JSON), and may also require an end of line character, such as <code>\n</code>, to terminate the message. Here is an example of sending a JSON formatted message:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import JSON

# create a JSON formatted message with property name &quot;action&quot; and value &quot;start_experiment&quot;

# send the message
send(connection, START_CMD)"><pre><span class="pl-k">import</span> JSON

<span class="pl-c"><span class="pl-c">#</span> create a JSON formatted message with property name "action" and value "start_experiment"</span>
<span class="pl-k">const</span> START_CMD <span class="pl-k">=</span> JSON<span class="pl-k">.</span><span class="pl-c1">json</span>(<span class="pl-c1">Dict</span>(<span class="pl-s"><span class="pl-pds">"</span>action<span class="pl-pds">"</span></span> <span class="pl-k">=&gt;</span> <span class="pl-s"><span class="pl-pds">"</span>start_experiment<span class="pl-pds">"</span></span>)) <span class="pl-k">*</span> <span class="pl-s"><span class="pl-pds">"</span><span class="pl-cce">\n</span><span class="pl-pds">"</span></span>

<span class="pl-c"><span class="pl-c">#</span> send the message</span>
<span class="pl-c1">send</span>(connection, START_CMD)</pre></div>
<p dir="auto">Send a message and wait for a response with <code>send_receive</code>. Note: some TCP servers may be require the message be formatted a certain way (such as JSON), and may also require an end of line character, such as <code>\n</code>, to terminate the message. This function blocks execution while waiting, up to the timeout duration provided. If the timeout duration elapses without the arrival of data, throws a <code>TimeoutError</code> exception. Note: the payload which is returned will be in a raw format. To convert to a string, use <code>String(payload)</code>. This string may further converted to other formats such as JSON. Here is an example of sending a JSON formatted message, receiving a response, and parsing the response.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import JSON

# create a JSON formatted message with property name &quot;action&quot; and value &quot;get_time_elapsed&quot;

# send the message and wait for a response

# convert the payload to a String, parse the String as a JSON, extract the data, 
# and print it

elapsed_time = data[&quot;elapsed_time&quot;]
println(&quot;Elapsed time: $(elapsed_time)&quot;)"><pre><span class="pl-k">import</span> JSON

<span class="pl-c"><span class="pl-c">#</span> send the message and wait for a response</span>

<span class="pl-c"><span class="pl-c">#</span> convert the payload to a String, parse the String as a JSON, extract the data, </span>
<span class="pl-c"><span class="pl-c">#</span> and print it</span>
data <span class="pl-k">=</span> JSON<span class="pl-k">.</span><span class="pl-c1">parse</span>(<span class="pl-c1">String</span>(payload))

<p dir="auto">Open a connection to the ROS node, setting <code>ip</code> and <code>port</code> to match that of the node:</p>

<p dir="auto">When complete with tasks, be sure to close the connection:</p>
