<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">p, Exposure Basis</h2><a id="user-content-p-exposure-basis" class="anchor" aria-label="Permalink: p, Exposure Basis" href="#p-exposure-basis"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In summary, there's three options for calculating the basis:</p>
<ul dir="auto">
<li><code>ExperienceAnalysis.Anniversary(period)</code> will give exposures periods based on the first date</li>
<li><code>ExperienceAnalysis.Calendar(period)</code> will follow calendar periods (e.g. month or year)</li>
<li><code>ExperienceAnalysis.AnniversaryCalendar(period,period)</code> will split into the smaller of the calendar or policy period.</li>
</ul>
<p dir="auto">Where <code>period</code> is a <a href="https://docs.julialang.org/en/v1/stdlib/Dates/#Period-Types" rel="nofollow">Period Type from the Dates standard library</a>.</p>

<p dir="auto"><code>ExperienceAnalysis.Anniversary(DatePeriod)</code> will give exposures periods based on the first date. Exposure intervals will fall on anniversaries, <code>start_date + t * dateperiod</code>.

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Principles</h2><a id="user-content-principles" class="anchor" aria-label="Permalink: Principles" href="#principles"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>An exposure means a unit exposed to a particular decrement for an interval of time and that the risk <em>entered into that interval</em> exposed to that risk.</li>
<li>When the decrement of interest occurs during an exposure interval, the exposure continues to the end of the <em>current</em> interval.</li>
<li>Calculating an <code>AnniversaryCalendar(Year(1),Year(1))</code> is different than splitting an <code>Anniversary(Year(1))</code> or <code>Calendar(Year(1))</code> basis due to the prior two bullet points. Two implications of this:
<ul dir="auto">
<li>Exposures with <code>AnniversaryCalendar(Year(1),Year(1))</code> will tend to end sooner than the latter two because the former is by definition split into two periods.
<ul dir="auto">
<li>This is illustrated by <code>e2</code> and <code>e3</code> being the same or longer exposures than <code>e1</code> in the example below.</li>
</ul>
</li>
<li>If you take a <code>Calendar(Year(1))</code>/<code>Anniversary(Year(1))</code> exposure basis and split it into two pieces split by Anniversary / Calendar breakpoints, you need to take into account that in the latter pieces of exposure the expected claims needs to be reduced by the surviving exposures from the prior interval.
<ul dir="auto">
<li>This is saying that if you were to divide the last interval in <code>e3</code> into two parts, split by the anniversary date, that the second part of that exposure needs to take into account that not all lives in force on <code>2012-01-01</code> would survive past the anniversary that splits the interval. Pretend we actually know that the decrement should be <code>0.01</code> per day. Then the expected number of claims over the <code>(from = Date("2012-01-01"), to = Date("2012-12-31"), policy_timestep = missing)</code> exposure is <code>1 - 0.99^366 = 0.97474</code>. If we split the interval and did not take into account the reduced lives entering in the second part of the split exposure, then we would have <code>1- 0.99 ^191 + 1 - 0.99^175 = 1.6811</code> expected claims. To correct for this, the second term needs to be adjusted for the amount surviving from the first.</li>
<li>It is for this reason that ExperienceAnalysis.jl does not currently provide a way to "split" a <code>Calendar</code>/<code>Anniversary</code> exposure basis.</li>
</ul>
</li>
</ul>
</li>
</ul>

<p dir="auto">When a policy is issued on a leap day (February 29th), it is preferable to have the next policy year start on the 28th.         cp <span class="pl-k">=</span> <span class="pl-c1">flatten</span>(cp, <span class="pl-c1">:exposures</span>)

        <span class="pl-c"><span class="pl-c">#</span> did claim happen before cutoff</span>
        cp<span class="pl-k">.</span>claim <span class="pl-k">=</span> <span class="pl-c1">map</span>(cp<span class="pl-k">.</span>exposures, cp<span class="pl-k">.</span>death) <span class="pl-k">do</span> e, d
            e<span class="pl-k">.</span>from <span class="pl-k">&lt;=</span> d <span class="pl-k">&lt;=</span> e<span class="pl-k">.</span>to
        <span class="pl-k">end</span>

        cp<span class="pl-k">.</span>exp_days <span class="pl-k">=</span> <span class="pl-c1">map</span>(cp<span class="pl-k">.</span>exposures) <span class="pl-k">do</span> e
            <span class="pl-c1">length</span>(e<span class="pl-k">.</span>from<span class="pl-k">:</span><span class="pl-c1">Day</span>(<span class="pl-c1">1</span>)<span class="pl-k">:</span>e<span class="pl-k">.</span>to)
        <span class="pl-k">end</span>
        cp<span class="pl-k">.</span>expected <span class="pl-k">=</span> <span class="pl-c1">@.</span> <span class="pl-c1">1</span> <span class="pl-k">-</span> (<span class="pl-c1">1</span> <span class="pl-k">-</span> q)<span class="pl-k">^</span>cp<span class="pl-k">.</span>exp_days

        cp<span class="pl-k">.</span>cal_year <span class="pl-k">=</span> <span class="pl-c1">map</span>(cp<span class="pl-k">.</span>exposures) <span class="pl-k">do</span> e
            <span class="pl-c1">year</span>(e<span class="pl-k">.</span>from)
        <span class="pl-k">end</span>

        cp<span class="pl-k">.</span>pol_year <span class="pl-k">=</span> <span class="pl-c1">map</span>(cp<span class="pl-k">.</span>exposures, cp<span class="pl-k">.</span>issue) <span class="pl-k">do</span> e, i
            y <span class="pl-k">=</span> <span class="pl-c1">year</span>(e<span class="pl-k">.</span>from)
            <span class="pl-k">if</span> <span class="pl-c1">monthday</span>(e<span class="pl-k">.</span>from) <span class="pl-k">&lt;</span> <span class="pl-c1">monthday</span>(i)
                y <span class="pl-k">-=</span> <span class="pl-c1">1</span>
            <span class="pl-k">end</span>
            y
        <span class="pl-k">end</span>

        cp<span class="pl-k">.</span>exp_amt <span class="pl-k">=</span> <span class="pl-c1">map</span>(cp<span class="pl-k">.</span>exposures) <span class="pl-k">do</span> e
            <span class="pl-c1">yearfrac</span>(e<span class="pl-k">.</span>from, e<span class="pl-k">.</span>to <span class="pl-k">+</span> <span class="pl-c1">Day</span>(<span class="pl-c1">1</span>), DayCounts<span class="pl-k">.</span><span class="pl-c1">ActualActualISDA</span>())
        <span class="pl-k">end</span>
        cp

    <span class="pl-k">end</span>

    <span class="pl-c"><span class="pl-c">#</span> not needed for test, but demonstrates how to do cal/pol year grouping</span>
    summary <span class="pl-k">=</span> <span class="pl-c1">map</span>([<span class="pl-c1">:pol_year</span>, <span class="pl-c1">:cal_year</span>]) <span class="pl-k">do</span> grouping
        <span class="pl-c1">combine</span>(<span class="pl-c1">groupby</span>(cp, (grouping))) <span class="pl-k">do</span> gdf
            exposures <span class="pl-k">=</span> <span class="pl-c1">sum</span>(gdf<span class="pl-k">.</span>exp_amt)
            claims <span class="pl-k">=</span> <span class="pl-c1">sum</span>(gdf<span class="pl-k">.</span>claim)
            expected <span class="pl-k">=</span> <span class="pl-c1">sum</span>(gdf<span class="pl-k">.</span>expected)

            q̂ <span class="pl-k">=</span> claims <span class="pl-k">/</span> exposures
            ae <span class="pl-k">=</span> claims <span class="pl-k">/</span> expected

            (; claims, expected, exposures, q̂, ae)
        <span class="pl-k">end</span>
    <span class="pl-k">end</span>


    <span class="pl-c1">@show</span> summary
    <span class="pl-c1">@show</span> <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>claim) <span class="pl-k">/</span> <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>expected), <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>claim), <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>expected), <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>exp_days), <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>exp_amt)
    <span class="pl-c1">@test</span> <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>claim) <span class="pl-k">/</span> <span class="pl-c1">sum</span>(cp<span class="pl-k">.</span>expected) <span class="pl-k">≈</span> <span class="pl-c1">1.0</span> rtol <span class="pl-k">=</span> <span class="pl-c1">5e-3</span>

<p dir="auto">Calcualte the exposure periods and returns an array of named tuples with fields:</p>
<ul dir="auto">
<li><code>from</code> (a <code>Date</code>) is the start date of the exposure interval</li>
<li><code>to</code> (a <code>Date</code>) is the end of the exposure interval</li>
<li><code>policy_step</code> will either be an <code>Int</code> if an Anniversary or AnniversaryCalendar basis is used, otherwise will be <code>nothing</code></li>
</ul>
<p dir="auto">If <code>continued_exposure</code> is <code>true</code>, then the final <code>to</code> date will continue through the end of the final exposure period. This is useful if you want the decrement of interest is the cause of termination, because then you want a full exposure.</p>
<p dir="auto">If <code>left_partials</code> or <code>right_partials</code> is set to false, then the exposure will not return partial exposure periods that overlap with the <code>study_start</code> and <code>study_end</code> respectively.</p>
