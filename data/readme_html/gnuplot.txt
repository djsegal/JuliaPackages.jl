<p dir="auto"><strong>Gnuplot.jl</strong> is a simple package able to send both data and commands from Julia to an underlying <a href="http://gnuplot.sourceforge.net/" rel="nofollow">gnuplot</a> process.  Its main purpose it to provide a fast and powerful data visualization framework, using an extremely concise Julia syntax. It also has automatic display of plots in Jupyter, Juno and VS Code.</p>
