<p dir="auto">Package <code>Enlsip.jl</code> is the Julia version of ENLSIP, an open source algorithm originally written in Fortran77 and designed to solve nonlinear least-squares problems subject to nonlinear constraints.
The optimization method implemented in ENLSIP is described in</p>
<blockquote>
<p dir="auto">Per Lindström and Per-Åke Wedin, <em>Gauss Newton based algorithms for constrained nonlinear least squares problems</em>.
Technical Report S-901 87, Institute of Information processing, University of Umeå, Sweden, 1988.</p>
</blockquote>
<p dir="auto">The source code of the Fortran77 library is available at <a href="https://plato.asu.edu/sub/nonlsq.html" rel="nofollow">https://plato.asu.edu/sub/nonlsq.html</a>.</p>
<p dir="auto">Problems that can be solved using <code>Enlsip.jl</code> are modeled as follows:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$$\begin{aligned}
\min_{x \in \mathbb{R}^n} \quad &amp;  \dfrac{1}{2} \|r(x)\|^2 \\\
\text{s.t.} \quad &amp; c_i(x) = 0, \quad i \in \mathcal{E} \\\
&amp; c_i(x) \geq 0, \quad i \in \mathcal{I}, \\\
&amp; l_i \leq x_i \leq u_i, \quad i \in \{1,\ldots,n\}, 
\end{aligned}$$</math-renderer>
<p dir="auto">where:</p>
<ul dir="auto">
<li>the residuals <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$r_i:\mathbb{R}^n\rightarrow\mathbb{R}$</math-renderer> and the constraints <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$c_i:\mathbb{R}^n\rightarrow\mathbb{R}$</math-renderer> are assumed to be <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$\mathcal{C}^2$</math-renderer> functions;</li>
<li>norm <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$||\cdot||$</math-renderer> denotes the Euclidean norm;</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$l$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9bf033bab65fffdb125ea86ee0172ba">$u$</math-renderer> are respectively vectors of lower and upper bounds.</li>
</ul>
<p dir="auto">In the formulation above, bound constraints are written seperately but they are treated as classical inequality constraints in the method implemented in ENLSIP.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How to Use</h2><a id="user-content-how-to-use" class="anchor" aria-label="Permalink: How to Use" href="#how-to-use"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Solving a problem with Enlsip is organized in two steps.</p>
<p dir="auto">First, you need to create a model of your problem with the <code>CnlsModel</code> structure.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Creating a model</h3><a id="user-content-creating-a-model" class="anchor" aria-label="Permalink: Creating a model" href="#creating-a-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An object of type <code>CnlsModel</code> can be created using a constructor, whose arguments are the following:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>residuals</code> : function that computes the vector of residuals</p>
</li>
<li>
<p dir="auto"><code>nb_parameters</code> : number of variables</p>
</li>
<li>
<p dir="auto"><code>nb_residuals</code> : number of residuals</p>
</li>
<li>
<p dir="auto"><code>stating_point</code> : initial solution</p>
</li>
<li>
<p dir="auto"><code>jacobian_residuals</code> : function that computes the jacobian matrix of the residuals. If not passed as argument, it is computed numericcaly by forward differences</p>
</li>
<li>
<p dir="auto"><code>eq_constraints</code> : function that computes the vector of equality constraints</p>
</li>
<li>
<p dir="auto"><code>jacobian_eqcons</code> : function that computes the jacobian matrix of the equality constraints. If not passed as argument, it is computed numericcaly by forward differences</p>
</li>
<li>
<p dir="auto"><code>nb_eqcons</code> : number of equality constraints</p>
</li>
<li>
<p dir="auto"><code>ineq_constraints</code> : function that computes the vector of inequality constraints</p>
</li>
<li>
<p dir="auto"><code>jacobian_ineqcons</code> : function that computes the jacobian matrix of the inequality constraints. If not passed as argument, it is computed numericcaly by forward differences</p>
</li>
<li>
<p dir="auto"><code>nb_ineqcons</code> : number of inequality constraints</p>
</li>
<li>
<p dir="auto"><code>x_low</code> and <code>x_upp</code> : respectively vectors of lower and upper bounds</p>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Solving a model</h3><a id="user-content-solving-a-model" class="anchor" aria-label="Permalink: Solving a model" href="#solving-a-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Then, once your model is instantiated, you can call the <code>solve!</code> function to solve your problem.</p>
