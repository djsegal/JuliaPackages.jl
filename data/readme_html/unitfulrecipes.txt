<p dir="auto"><a href="https://github.com/jw3126/UnitfulRecipes.jl">UnitfulRecipes.jl</a> makes it easy to plot data with units.</p>
<p dir="auto">It works by providing <a href="http://docs.juliaplots.org/latest/recipes/#recipes" rel="nofollow">recipes</a> for the <a href="https://github.com/JuliaPlots/Plots.jl">Plots.jl</a> package that can deal with units from <a href="https://github.com/PainterQubits/Unitful.jl">Unitful.jl</a>.
For a quick example,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Unitful, UnitfulRecipes, Plots
const a = 1u&quot;m/s^2&quot;
v(t) = a * t
x(t) = a/2 * t^2
t = (0:0.01:100)*u&quot;s&quot;
plot(x.(t), v.(t), xlabel=&quot;position&quot;, ylabel=&quot;speed&quot;)"><pre><span class="pl-k">using</span> Unitful, UnitfulRecipes, Plots
<span class="pl-k">const</span> a <span class="pl-k">=</span> <span class="pl-c1">1</span><span class="pl-s"><span class="pl-pds"><span class="pl-c1">u</span>"</span>m/s^2<span class="pl-pds">"</span></span>
<span class="pl-en">v</span>(t) <span class="pl-k">=</span> a <span class="pl-k">*</span> t
<span class="pl-en">x</span>(t) <span class="pl-k">=</span> a<span class="pl-k">/</span><span class="pl-c1">2</span> <span class="pl-k">*</span> t<span class="pl-k">^</span><span class="pl-c1">2</span>
