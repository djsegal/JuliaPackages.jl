<p dir="auto">LightweightCharts is a convenient Julia wrapper for the <a href="https://github.com/tradingview/lightweight-charts">Lightweight Charts™</a> library by <a href="https://www.tradingview.com/" rel="nofollow">TradingView, Inc.</a>, designed to output graphical data to an HTML page.</p>
