<p dir="auto"><a href="https://www.youtube.com/watch?v=ONBHkzimRbg" rel="nofollow">Tomographic Volumetric Additive Manufacturing</a> is a novel 3D printing technique
which is based on a tomographic principle.
Light is illuminated from different angles onto a glass vial which contains a photosensitive resin.
Once a voxel in the resin receives enough light, polymerization starts.</p>
<p dir="auto">This toolbox is developed to solve the optimization challenge around TVAM.
What are the required patterns on the projector such object voxels polymerize and not-object voxels stay unpolymerized?</p>
<p dir="auto">This package is written in <a href="https://julialang.org/" rel="nofollow">Julia Lang</a> and features CUDA and multithreaded CPU support. CUDA can accelerate reconstruction typically 10-20x times.</p>
<p dir="auto">It runs on Windows, Linux and macOS!</p>

The general principle behind TVAM. a) a set of 2D projection patterns is
propagated into space. b) shows how a slice of the pattern propagates through the
volume and c) how the incoherent sum results in a total energy dose. d) the object
polymerizes if it reaches an energy threshold. e) polymerization threshold results in a
printed slice. f) is the intensity histogram of b). g) is the 3D view of the Benchy boat.
h) is the general setup.
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Features</h1><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>3D parallel Radon transform for ray optical simulation</li>
<li>rigorous simulation of absorption and air -&gt; vial -&gt; resin refraction</li>
<li>CUDA acceleration -&gt; high performance</li>
<li>3D coherent wave optical optimization (see this <a href="https://opg.optica.org/oe/fulltext.cfm?uri=oe-32-8-14705&amp;id=548744" rel="nofollow">publication</a> for details and limitations). Note this has been only theoretical demonstrated and experimentally not validated.</li>
</ul>
