<p dir="auto">Render Markdown text in your Genie apps</p>
<p dir="auto">This package provides two new Stipple components: <code>markdowntext</code> and <code>markdowncard</code>. As arguments, You can either pass a string of Markdown text or a symbol that refers to a variable containing Markdown text.</p>

end
