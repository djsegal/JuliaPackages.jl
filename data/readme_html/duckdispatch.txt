<p dir="auto"><code>DuckDispatch.jl</code> is an experimental package which attempts to make it easy to dispatch a method based on the behavior of a type, not its place in the type hierarchy. At a high-level, it allows the user to define a number of method signatures which constitute a <code>DuckType</code>. Then, any type which has an implementation for those methods can be wrapped in a <code>Guise{D&lt;:DuckType, T}</code>. This <code>Guise</code> type is then hooked into the normal Julia dispatch machinery.</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Why?</h1><a id="user-content-why" class="anchor" aria-label="Permalink: Why?" href="#why"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">It often does not matter if an input is of a specific type (like a vector, a channel, or a set); it matters that it is has a certain functionality (like iterable). While creating a method with a completely generic argument will work, it also provides no guarantees that the input will have the necessary methods.</p>
<p dir="auto">By dispatching on a <code>DuckType</code>, we get:</p>
<ol dir="auto">
<li>compile time guarantees that there won't be any method errors for the <code>Behavior</code>s defined for the <code>DuckType</code></li>
<li>helpful errors for calls to a method that is not defined for the <code>DuckType</code></li>
<li>a method signature that is more informative about the meaning of is arguments</li>
</ol>

<p dir="auto">Now, we can create a new function that dispatches on this <code>DuckType</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@duck_dispatch function my_collect(arg1::Iterable{T}) where {T}

<p dir="auto"><code>Iterable</code> is pretty limited without <code>length</code>. We can compose it with some new behaviors to build a more feature-rich <code>DuckType</code>!</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@duck_type struct FiniteIterable{T} &lt;: Union{Iterable{T}}

    @narrow T -&gt; FiniteIterable{eltype(T)}
end
