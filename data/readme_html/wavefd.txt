<p dir="auto">WaveFD.jl contains a reference collection of single time step wavefield propagation codes.</p>

<p dir="auto">These single time step propagators are used to contruct nonlinear modeling operators and their linearizations in the <a href="https://github.com/ChevronETC/JetPackWaveFD.jl">JetPackWaveFD</a> package. An extensive suite of unit tests guaranteeing correctness is implemented in <code>JetPackWaveFD</code>, and therefore is not re-implemented here.</p>
<p dir="auto">Coverage statistics for tests in this package do not reflect the code as exercised by the unit tests in <code>JetPackWaveFD</code>.</p>

<p dir="auto">In addition to propagators, the Julia components of WaveFD.jl are meant to provide:</p>
<ul dir="auto">
<li>imaging conditions</li>
<li>wavelets</li>
<li>wavefield injection/extraction</li>
<li>wavefield compression (via CvxCompress)</li>
<li>absorbing boundary construction</li>
<li>extraction of a subset of an earth model for a given experiment aperture (ginsu)</li>
</ul>
