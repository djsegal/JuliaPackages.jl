<p dir="auto">This package provides algorithms for learning <em>decision trees</em> and <em>decision forests</em> with enhanced abilities.
Leveraging the express power of Modal Logic, these models can extract <em>temporal/spatial patterns</em>, and can natively handle <em>time series</em> and <em>images</em> (without any data preprocessing). Currently available via <a href="https://github.com/alan-turing-institute/MLJ.jl">MLJ.jl</a> and <a href="https://github.com/aclai-lab/Sole.jl"><em>Sole.jl</em></a>.</p>

<p dir="auto">The MLJ models provided (<code>ModalDecisionTree</code> and <code>ModalRandomForest</code>) can act as drop in replacements for DecisionTree.jl's tree and forest models. The main difference is that the two models provided are <a href="https://alan-turing-institute.github.io/MLJ.jl/dev/adding_models_for_general_use/#Overview" rel="nofollow">probabilistic</a> and can perform both classification (with y labels of type <code>String</code> or <code>CategoricalValue</code>), and regression (with numeric y labels).</p>

<p dir="auto">Additionally, these models:</p>
<ul dir="auto">
<li>Are able to handle variables that are <code>AbstractVector{&lt;:Real}</code> or <code>AbstractMatrix{&lt;:Real}</code>;</li>
<li>Support <a href="https://en.wikipedia.org/wiki/Multimodal_learning" rel="nofollow">multimodal</a> learning (e.g., learning from <em>combinations</em> of scalars, time series and images);</li>
<li>A unique algorithm that extends CART and C4.5;</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Want to know more?</h2><a id="user-content-want-to-know-more" class="anchor" aria-label="Permalink: Want to know more?" href="#want-to-know-more"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://link.springer.com/chapter/10.1007/978-3-031-27181-6_4" rel="nofollow">Della Monica, Dario, et al. "Decision trees with a modal flavor." International Conference of the Italian Association for Artificial Intelligence. Cham: Springer International Publishing, 2022.</a></p>
<p dir="auto">Most of the works in <em>symbolic learning</em> are based either on Propositional Logics (PLs) or First-order Logics (FOLs); PLs are the simplest kind of logic and can only handle <em>tabular data</em>, while FOLs can express complex entity-relation concepts. Machine Learning with FOLs enables handling data with complex topologies, such as time series, images, or videos; however, these logics are computationally challenging. Instead, Modal Logics (e.g. <a href="https://en.wikipedia.org/wiki/Interval_temporal_logic" rel="nofollow">Interval Logic</a>) represent a perfect trade-off in terms of computational tractability and expressive power, and naturally lend themselves for expressing some forms of <em>temporal/spatial reasoning</em>.</p>
<p dir="auto">Recently, symbolic learning techniques such as Decision Trees, Random Forests and Rule-Based models have been extended to the use of Modal Logics of time and space. <em>Modal Decision Trees</em> and <em>Modal Random Forests</em> have been applied to classification tasks, showing statistical performances that are often comparable to those of functional methods (e.g., neural networks), while providing, at the same time, highly-interpretable classification models. Examples of these tasks are COVID-19 diagnosis from cough/breath audio <a href="https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4102488" rel="nofollow">[1]</a>, <a href="https://drops.dagstuhl.de/opus/volltexte/2021/14783/pdf/LIPIcs-TIME-2021-7.pdf" rel="nofollow">[2]</a>, land cover classification from aereal images <a href="https://arxiv.org/abs/2109.08325" rel="nofollow">[3]</a>, EEG-related tasks <a href="https://link.springer.com/chapter/10.1007/978-3-031-06242-1_53" rel="nofollow">[4]</a>, and gas turbine trip prediction.
This technology also offers a natural extension for <em>multimodal</em> learning <a href="http://ceur-ws.org/Vol-2987/paper7.pdf" rel="nofollow">[5]</a>.</p>
