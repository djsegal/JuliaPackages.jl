<p dir="auto">This package implements the determinant quantum Monte Carlo (DQMC) method for Hubbard,
and electron-phonon interactions, including both Holstein and Su-Schrieffer-Heeger (SSH) style
electron-phonon coupling.</p>

<p dir="auto">The <a href="https://github.com/SmoQySuite/SmoQyDQMC.jl">SmoQyDQMC.jl</a> re-exports certain packages using
the <a href="https://github.com/simonster/Reexport.jl.git">Reexport.jl</a> package in order to simplify the installation process.</p>
<ul dir="auto">
<li><a href="https://github.com/SmoQySuite/LatticeUtilities.jl.git">LatticeUtilties.jl</a>: Used to represent arbitrary lattice geometries.</li>
<li><a href="https://github.com/SmoQySuite/JDQMCFramework.jl.git">JDQMCFramework.jl</a>: Implements and exports the basic framework for running a DQMC simulation.</li>
<li><a href="https://github.com/SmoQySuite/JDQMCMeasurements.jl.git">JDQMCMeasurements.jl</a>: Implements various global, local and correlation measurements for a DQMC simulation.</li>
<li><a href="https://github.com/cohensbw/MuTuner.jl.git">MuTuner.jl</a>: Impelments and exports an algorithm for tuning the chemical potential to achieve a target density in grand canonical Monte Carlo simulations.</li>
</ul>

<ul dir="auto">
<li><a href="https://github.com/SmoQySuite/StableLinearAlgebra.jl.git">StableLinearAlgebra.jl</a>: Implements optimized numerical stabilizaiton methods required by DQMC simulations.</li>
<li><a href="https://github.com/SmoQySuite/Checkerboard.jl.git">Checkerboard.jl</a>: Implements and exports the checkerboard method for approximating exponentiated hopping matrices by a sparse matrix.</li>
<li><a href="https://github.com/JuliaIO/JLD2.jl.git">JLD2.jl</a>: Package used to write data to binary files in an HDF5 compatible format. It is also recommended this package be used at the scripting level to implement checkpointing in a simulation.</li>
</ul>
