<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The GEneralized Newton Inexact Operator Splitting (<code>GeNIOS</code>) package contains an
experimental inexact ADMM solver for convex problems. We both approximate the
ADMM subproblems and then solve these subproblems inexactly. The algorithm is
inspired by <a href="https://arxiv.org/abs/2302.03863" rel="nofollow">Frangella et al. 2023</a>.</p>
<p dir="auto">We provide interfaces for machine learning problems (<code>MLSolver</code>) and quadratic
programs (<code>QPSolver</code>). In addition, convex optimization problems may be specified
directly.</p>
<p dir="auto"><em><strong>For more information, check out the <a href="https://tjdiamandis.github.io/GeNIOS.jl/dev/" rel="nofollow">documentation</a> and <a href="https://arxiv.org/abs/2310.08333" rel="nofollow">our paper</a>.</strong></em></p>

do this directly if we want to modify the per-sample loss function or regularization.
The equivalent problem, with the <code>MLSolver</code> interface, can be defined as follows.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><code>QPSolver</code> interface</h3><a id="user-content-qpsolver-interface" class="anchor" aria-label="Permalink: QPSolver interface" href="#qpsolver-interface"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Since the lasso problem is a quadratic program, we can use the <code>QPSolver</code> interface
as well. Note that we must introduce an additional variable <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="22f6b942b75aeb88c928a2e56585737b">$t$</math-renderer> and the constraint
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="22f6b942b75aeb88c928a2e56585737b">$-t \leq x \leq t$</math-renderer> to enforce the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="22f6b942b75aeb88c928a2e56585737b">$\ell_1$</math-renderer> norm. The problem then becomes</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="22f6b942b75aeb88c928a2e56585737b">$$\begin{array}{ll}
\text{minimize}     &amp; (1/2)x^TA^TAx + b^TAx + \gamma \mathbf{1}^Tt \\\
\text{subject to}   &amp;  
\begin{bmatrix}0 \\ -\infty\end{bmatrix} 
\leq \begin{bmatrix} I &amp; I \\ I &amp; -I \end{bmatrix} \begin{bmatrix}x \\ t\end{bmatrix}  
\leq \begin{bmatrix}\infty \\ 0\end{bmatrix}
\end{array}$$</math-renderer>
