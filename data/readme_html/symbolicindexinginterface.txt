<p dir="auto">The symbolic indexing interface has 2 levels:</p>
<ol dir="auto">
<li>The user level. At the user level, a modeler or engineer simply uses terms from a
domain-specific language (DSL) inside of SciML functionality and will receive the requested
values. For example, if a DSL defines a symbol <code>x</code>, then <code>sol[x]</code> returns the solution
value(s) for <code>x</code>.</li>
<li>The DSL system structure level. This is the structure which defines the symbolic indexing
for a given problem/solution. DSLs can tag a constructed problem/solution with this
object in order to endow the SciML tools with the ability to index symbolically according
to the definitions the DSL writer wants.</li>
</ol>

@parameters σ ρ β
@variables t x(t) y(t) z(t) w(t)
D = Differential(t)

eqs = [D(D(x)) ~ σ * (y - x),
    D(y) ~ x * (ρ - z) - y,
    D(z) ~ x * y - β * z,
    w ~ x + y + z]

@mtkbuild sys = ODESystem(eqs)

u0 = [D(x) =&gt; 2.0,
    x =&gt; 1.0,
    y =&gt; 0.0,
    z =&gt; 0.0]

p = [σ =&gt; 28.0,
    ρ =&gt; 10.0,
    β =&gt; 8 / 3]

tspan = (0.0, 100.0)
prob = ODEProblem(sys, u0, tspan, p, jac = true)
sol = solve(prob, Tsit5())
