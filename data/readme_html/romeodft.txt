<p dir="auto">Software package to perform <strong>R</strong>obust <strong>O</strong>ccupation <strong>M</strong>atrix <strong>E</strong>nergy <strong>O</strong>ptimization using DFT.
At this moment it is based on the implementation of occupation matrix constraining in <a href="https://gitlab.com/louisponet/q-e/-/tree/broyden_constraints" rel="nofollow">a patched version of Quantum Espresso</a>.</p>
<p dir="auto">See <a href="https://louisponet.github.io/RomeoDFT.jl/dev" rel="nofollow">Documentation</a> for more information.</p>
