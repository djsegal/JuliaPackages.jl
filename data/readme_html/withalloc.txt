<p dir="auto">This package implements a very small extension to <a href="https://github.com/MasonProtter/Bumper.jl">Bumper.jl</a>. Bumper strongly enourages (almost enforces) that it is used purely from within <code>@no_escape</code> blocks. Bumper-allocating an array in a function and passing it back to the caller should generally be avoided. This results in a common pattern:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@no_escape begin 
   # determine the type and size a required array
   T, N = determine_array(x1, x2, x3)
   # preallocate some arrays
   A = @alloc(T, N)
   # do a computation on A 
   calculate_something!(A, x1, x2, x3)
end "><pre><span class="pl-c1">@no_escape</span> <span class="pl-k">begin</span> 
   <span class="pl-c"><span class="pl-c">#</span> determine the type and size a required array</span>
   T, N <span class="pl-k">=</span> <span class="pl-c1">determine_array</span>(x1, x2, x3)
   <span class="pl-c"><span class="pl-c">#</span> preallocate some arrays</span>
   A <span class="pl-k">=</span> <span class="pl-c1">@alloc</span>(T, N)
   <span class="pl-c"><span class="pl-c">#</span> do a computation on A </span>
   <span class="pl-c1">calculate_something!</span>(A, x1, x2, x3)
<span class="pl-k">end</span> </pre></div>
<p dir="auto">The goal of <code>WithAlloc.jl</code> is to replace the above 3 lines with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@no_escape begin 
   A = @withalloc calculate_something!(x1, x2, x3)
end"><pre><span class="pl-c1">@no_escape</span> <span class="pl-k">begin</span> 
   A <span class="pl-k">=</span> <span class="pl-c1">@withalloc</span> <span class="pl-c1">calculate_something!</span>(x1, x2, x3)
<span class="pl-k">end</span></pre></div>

<p dir="auto">For now, there are just a few simple use-case examples. Proper documentation will follow once the packages has been tested a bit and there is some agreement it will be long-term useful.</p>
