<p dir="auto">WorldDynamics.jl is an open-source framework written in Julia for world dynamics modeling and simulation.
Check out the <a href="https://github.com/worlddynamics">WorldDyanmics Organization</a> for information on the World Dynamics project.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Getting started</h3><a id="user-content-getting-started" class="anchor" aria-label="Permalink: Getting started" href="#getting-started"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">From the Julia REPL, install the package with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="]add WorldDynamics"><pre>]add WorldDynamics</pre></div>
<p dir="auto">You can now use the package, e.g. for reproducing Figure 7.7 from the book <a href="https://archive.org/details/dynamicsofgrowth0000unse" rel="nofollow"><em>Dynamics of growth in a finite world</em></a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using WorldDynamics
World3.fig_7()"><pre><span class="pl-k">using</span> WorldDynamics
World3<span class="pl-k">.</span><span class="pl-c1">fig_7</span>()</pre></div>
<p dir="auto">Here is the output superposed to the original picture:
<a target="_blank" rel="noopener noreferrer nofollow" href="https://user-images.githubusercontent.com/2920162/194111344-8682a97f-f4de-4e2d-ba7e-980546e1bfaf.png"><img src="https://user-images.githubusercontent.com/2920162/194111344-8682a97f-f4de-4e2d-ba7e-980546e1bfaf.png" alt="image" style="max-width: 100%;"></a></p>
<p dir="auto">For how to produce different figures (and much more), please see <a href="https://worlddynamics.github.io/WorldDynamics.jl/stable/" rel="nofollow">the documentation</a>.</p>
