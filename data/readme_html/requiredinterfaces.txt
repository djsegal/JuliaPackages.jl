<p dir="auto">RequiredInterfaces.jl is a small package, allowing abstract-type based definition of interface methods, as well as
some methods for checking whether a type that claims to implement an interface, actually implements the required methods.</p>
<p dir="auto">Please check out the <a href="https://seelengrab.github.io/RequiredInterfaces.jl/" rel="nofollow">documentation</a> to learn how you can use RequiredInterfaces.jl to provide basic "implement me" style interfaces in your library.</p>
<p dir="auto">If you want to learn more about the motivation &amp; philosophy behind this package, check out <a href="https://seelengrab.github.io/RequiredInterfaces.jl/dev/interfaces.html" rel="nofollow">this writeup</a> about APIs and their surface in Julia, which is part of the documentation of this package.</p>
