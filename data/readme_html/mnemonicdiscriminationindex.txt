<p dir="auto">To install this package to you environment, run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ]add MnemonicDiscriminationIndex.jl"><pre>julia&gt; ]add MnemonicDiscriminationIndex<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">in the Julia REPL. To prevent breakage, add a compat entry to the version you install in your environment's <code>Project.toml</code> as the API might be improved over time.</p>
