<p dir="auto">Arrange tabular or non-tabular datasets into groups according to a specified key function.</p>
<p dir="auto">The main principle of <code>FlexiGroups</code> is that the result of a grouping operation is always a collection of groups, and each group is a collection of elements. Groups are typically indexed by the grouping key.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>group</code>/<code>groupview</code>/<code>groupmap</code></h2><a id="user-content-groupgroupviewgroupmap" class="anchor" aria-label="Permalink: group/groupview/groupmap" href="#groupgroupviewgroupmap"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>group([keyf=identity], X; [restype=Dictionary])</code>: group elements of <code>X</code> by <code>keyf(x)</code>, returning a mapping <code>keyf(x)</code> values to lists of <code>x</code> values in each group.</p>
<p dir="auto">The result is an (ordered) <code>Dictionary</code> by default, but can be changed to the base <code>Dict</code> or another dictionary type.</p>
<p dir="auto">Alternatively to dictionaries, specifying <code>restype=KeyedArray</code> (from <code>AxisKeys.jl</code>) results in a <code>KeyedArray</code>. Its <code>axiskeys</code> are the group keys.</p>

<p dir="auto"><code>groupview([keyf=identity], X; [restype=Dictionary])</code>: like the <code>group</code> function, but each group is a <code>view</code> of <code>X</code> and doesn't copy the input elements.</p>
<p dir="auto"><code>groupmap([keyf=identity], mapf, X; [restype=Dictionary])</code>: like <code>map(mapf, group(keyf, X))</code>, but more efficient. Supports a limited set of <code>mapf</code> functions: <code>length</code>, <code>first</code>/<code>last</code>, <code>only</code>, <code>rand</code>.</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Margins</h1><a id="user-content-margins" class="anchor" aria-label="Permalink: Margins" href="#margins"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>addmargins(dict; [combine=flatten])</code>: add margins to a grouping for all combinations of group key components.</p>
<p dir="auto">For example, if a dataset is grouped by <code>a</code> and <code>b</code> (<code>keyf=x -&gt; (;x.a, x.b)</code> in <code>group</code>), this adds groups for each <code>a</code> value and for each <code>b</code> value separately.</p>
<p dir="auto"><code>combine</code> specifies how multiple groups are combined into margins. The default <code>combine=flatten</code> concatenates all relevant groups into a single collection.</p>

<ul dir="auto">
<li>margins support;</li>
<li>more flexibility in the return container type - various dictionaries, keyed arrays;</li>
<li>group collection type is the same as the input collection type, when possible; for example, grouping a <code>StructArray</code>s results in each group also being a <code>StructArray</code>;</li>
<li>better return eltype and type inference;</li>
<li>often performs faster and with fewer allocations.</li>
