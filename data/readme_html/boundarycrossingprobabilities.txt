<p dir="auto">This is a julia package for computing accurate approximations of the time-dependent boundary crossing probability for a general diffusion process. The implemented algorithm is based on a Brownian bridge corrected Markov chain algorithm proposed in:</p>
<p dir="auto">Liang, V. and Borovkov, K.: On Markov chain approximations for computing boundary crossing probabilities of diffusion processes. J. Appl. Probab. 60 1386–1415 (2023).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Time-dependent boundary crossing probabilities of diffusion processes</h2><a id="user-content-time-dependent-boundary-crossing-probabilities-of-diffusion-processes" class="anchor" aria-label="Permalink: Time-dependent boundary crossing probabilities of diffusion processes" href="#time-dependent-boundary-crossing-probabilities-of-diffusion-processes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$T&amp;gt;0,$</math-renderer> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$x_0 \in \mathbb{R},$</math-renderer> let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$X$</math-renderer> be a solution to the following stochastic differential equation:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ \begin{cases}
dX_t = \mu(t,X_t)dt +\sigma(t,X_t)dW_t, \quad t \in (0,T),\\
X_0 = x_0.
\end{cases}$$</math-renderer></p>
<p dir="auto">where we assume <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$\mu$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$\sigma$</math-renderer> satisfy the usual sufficient for the existence and uniqueness of a strong solution to the above SDE.</p>
<p dir="auto">For two continuous functions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$g_-$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$g_+,$</math-renderer> this package computes an approximation of the non-crossing probability</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$
F(g_-,g_+) := \mathbf{P}(g_-(t) &lt; X_t &lt; g_+(t) , t\in [0,T]).
$$</math-renderer></p>
<p dir="auto">More generally, the tool can compute expressions of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ v(t,x) = \mathbf{E}[e^{-\int_t^TV(s,X_s),ds}\psi(X_T);g_{-}(s) &lt; X_s &lt; g_+(s), s \in [t,T] | X_t = x], $$</math-renderer></p>
<p dir="auto">and</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ u(t,x) = \frac{\partial}{\partial x}\mathbf{E}[e^{-\int_0^tV(s,X_s),ds} ; X_t \leq x, g_{-}(s) &lt; X_s &lt; g_+(s), s \in [0,t]|X_0 = x_0], $$</math-renderer></p>
<p dir="auto">which are known to be probabilistic solutions to the Dirichlet problem for the following parabolic PDEs:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ Lv = 0, \quad v(t,g_{\pm}(t)) =0, \quad v(T,x)= \psi(x). $$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ L^*u = 0, \quad u(t,g_{\pm}(t)) =0, \quad u(0,x)= \delta_{x_0}(x) $$</math-renderer></p>
<p dir="auto">where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$L f(s,x) := \dot{f}(s,x) - V(s,x)f(s,x) + \mu(s,x) f'(s,x) + \frac{1}{2}\sigma^2(s,x)f''(s,x).$$</math-renderer></p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Sensitivity of boundary crossing probabilities with respect to boundary perturbations</h2><a id="user-content-sensitivity-of-boundary-crossing-probabilities-with-respect-to-boundary-perturbations" class="anchor" aria-label="Permalink: Sensitivity of boundary crossing probabilities with respect to boundary perturbations" href="#sensitivity-of-boundary-crossing-probabilities-with-respect-to-boundary-perturbations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">It was proved by Liang and Borovkov (2024) that the boundary non-crossing probability functional <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$F(g) := F(-\infty,g)$</math-renderer> is Gateaux differentiable and the derivative admits the following representation:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$$ \nabla_h F(g) := \lim_{\varepsilon \to 0}\frac{F(g+\varepsilon h) -F(g) }{\varepsilon} = -\int_0^T h(t)v'(t,g(t))f_{\tau}(t),\quad h \in H, \quad g \in C^2.$$</math-renderer></p>
<p dir="auto">The Markov chain approximation can be used to obtain approximations for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$v'(t,g(t))$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$f_{\tau}(t)$</math-renderer> for all <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$t \in [0,T].$</math-renderer></p>

<p dir="auto">To set up the boundary crossing probability algorithm, we need to specify parameters of the diffusion process (initial position, drift, diffusion and potential), and the time interval. Let's take the Brownian motion example (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$\mu \equiv 0,$</math-renderer> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$\sigma \equiv 1$</math-renderer>) with a complex potential term <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5b291557ac906df7149828b426265cc6">$V(t,x):= ix^2$</math-renderer>.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="x0 = 0 # Initial condition
