<p dir="auto">Julia already has a very good dataframe story with <a href="https://github.com/JuliaData/DataFrames.jl">DataFrames.jl</a>, which provides a more Julian experience since any types of collections can be used as a column. On the other hand, Polars works through the Arrow data format and therefore only supports certain physical vectors (materialized in memory) such as <code>Vector{Int}</code>. Polars.jl focuses on wrapping operations on lazy frames since it is one of the main differentiating factor with DataFrames. Indeed eager operations are implemented as <code>collect∘op∘lazy</code>. Consider trying DataFrames.jl if your problem involves a lot of Julia "interopability" where Polars would not offer the same level of interopability.</p>
