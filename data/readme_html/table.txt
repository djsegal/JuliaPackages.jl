<p dir="auto"><code>Tables.jl</code> is a package for displaying tables in plain text, HTML and LaTeX.</p>
<p dir="auto">Tables in <code>Tables.jl</code> consist of data, styles and their associated layouts
(which are ranges).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Layouts</h2><a id="user-content-layouts" class="anchor" aria-label="Permalink: Layouts" href="#layouts"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Layouts describe areas in the table where a style should be applied or data
should be located. They consist of a vector of ranges. Ranges have a box and
an ID.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Styles</h2><a id="user-content-styles" class="anchor" aria-label="Permalink: Styles" href="#styles"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A style has text, cell and range level properties.</p>
<p dir="auto">Text level properties format only the cell text content. They describe how
many digits of precision to print, alignment, whether or not to append an
asterisk to a text based on its value etcetera.</p>
<p dir="auto">Cell level properties apply to all cells in the range. In HTML, this could be
colour or border information.</p>
<p dir="auto">A style elements position in the style vector provides an index to look up its
associated range.</p>

<p dir="auto">Data is a vector of matrices. Each matrix contains information to be displayed
in the table.</p>
<p dir="auto">A data elements position in the data vector provides an index to look up its
associated range.</p>
