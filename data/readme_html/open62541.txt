<p dir="auto">Open62541.jl is a <a href="https://julialang.org" rel="nofollow">Julia</a> package that interfaces with the <a href="https://www.open62541.org/" rel="nofollow">open62541</a>
library written in C (<a href="https://github.com/open62541/open62541">source</a>).</p>
<p dir="auto">As such, it provides functionality following the <a href="https://en.wikipedia.org/wiki/OPC_Unified_Architecture" rel="nofollow">OPC Unified Architecture (OPC UA) standard</a>
for data exchange from sensors to cloud applications developed by the <a href="https://opcfoundation.org/" rel="nofollow">OPC Foundation</a>.</p>
<p dir="auto">In short, it provides the ability to create OPC servers that make data from different
sources available to clients and, naturally, also a client functionality that allows
to read data from OPC UA servers. Features are summarized further on the <a href="https://www.open62541.org/" rel="nofollow">open62541 website</a>.</p>
<p dir="auto">Open62541.jl's <em>ultimate</em> aim is to provide the full functionality of open62541 to
Julia users through a convenient high level interface without the need to engage
in manual memory management etc. (as required in open62541).</p>
<p dir="auto">At its current development stage the high level interface is implemented for a
(commonly used) subset of functionality. An essentially feature-complete lower
level interface that wraps all functionality of open62541 is, however, available.</p>

<p dir="auto">Note that Open62541.jl is still under active development and has not reached a maturity
that would make it safe to use in a production environment.</p>
<p dir="auto">The developers aim to observe <a href="https://semver.org/" rel="nofollow">semantic versioning</a>, but
accidental breakage and evolutions of the API have to be expected.</p>
<p dir="auto">Documentation is also a work in progress.</p>

<p dir="auto">Starting up a server with a default configuration in Open62541.jl is very simple.
Just execute the following code in the REPL or as a script:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Open62541
server = JUA_Server()
config = JUA_ServerConfig(server)
JUA_ServerConfig_setDefault(config)
JUA_Server_runUntilInterrupt(server)"><pre><span class="pl-k">using</span> Open62541
server <span class="pl-k">=</span> <span class="pl-c1">JUA_Server</span>()
config <span class="pl-k">=</span> <span class="pl-c1">JUA_ServerConfig</span>(server)
<span class="pl-c1">JUA_ServerConfig_setDefault</span>(config)
<span class="pl-c1">JUA_Server_runUntilInterrupt</span>(server)</pre></div>
<p dir="auto">This will configure a server with the default configuration (address: opc.tcp://localhost:4840/)
and start it. The server can be shut down by pressing CTRL+C multiple times.</p>
<p dir="auto">While the server is running, it can be accessed via the Client API of Open62541.jl
or it can be browsed and accessed with a graphical client, such as <a href="https://www.unified-automation.com/products/development-tools/uaexpert.html" rel="nofollow">UA Expert</a>.</p>

<p dir="auto">In order to showcase the Client API functionality, we will use the above server
and read some basic information from it, namely the software version number and
the current time. Note that this information should be contained in all OPC UA
servers, so you could also connect to a different server that you know is running.</p>

config = JUA_ClientConfig(client)
JUA_ClientConfig_setDefault(config)
JUA_Client_connect(client, &quot;opc.tcp://localhost:4840&quot;)

#define nodeids that we are interested in 
nodeid_currenttime = JUA_NodeId(0, UA_NS0ID_SERVER_SERVERSTATUS_CURRENTTIME)
nodeid_version = JUA_NodeId(0, UA_NS0ID_SERVER_SERVERSTATUS_BUILDINFO_SOFTWAREVERSION)

#read data from nodeids
currenttime = JUA_Client_readValueAttribute(client, nodeid_currenttime) #Int64 which represents the number of 100 nanosecond intervals since January 1, 1601 (UTC)
version = JUA_Client_readValueAttribute(client, nodeid_version) #String containing open62541 version number

#Convert current time into human understandable format
dts = UA_DateTime_toStruct(currenttime)

    dts.day, dts.month, dts.year, dts.hour, dts.min, dts.sec, dts.milliSec)
