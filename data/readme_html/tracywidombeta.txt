<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto">Compute the cumulative distribution function (CDF) and probability density function (PDF) of the Tracy-Widom distribution for arbitrary β&gt;0 using finite-difference and Fourier spectral methods.</p>
<p dir="auto">This respository contains the code for: <a href="https://doi.org/10.3842/SIGMA.2024.005" rel="nofollow">https://doi.org/10.3842/SIGMA.2024.005</a></p>
<p dir="auto">A basic example usage follows.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="β = 3 #value of β

f = TW(β; pdf = true) #PDF

F(s)
f(s)"><pre>β <span class="pl-k">=</span> <span class="pl-c1">3</span> <span class="pl-c"><span class="pl-c">#</span>value of β</span>

<p dir="auto">Additionally, discrete values obtained prior to interpolation are accessible. Example usage follows.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="β = 3 #value of β

F_cdf = F[2] #CDF evaluated at these discrete points"><pre>β <span class="pl-k">=</span> <span class="pl-c1">3</span> <span class="pl-c"><span class="pl-c">#</span>value of β</span>
F <span class="pl-k">=</span> <span class="pl-c1">TW</span>(β; interp <span class="pl-k">=</span> <span class="pl-c1">false</span>)

<p dir="auto">For β = 4, s should be divided by an extra factor of 2^(1/6), as many published results adhere to a distinct scaling convention.</p>
