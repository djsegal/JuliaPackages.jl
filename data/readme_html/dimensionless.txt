<p dir="auto">Dimensionless is a package built on top of <a href="https://github.com/PainterQubits/Unitful.jl">Unitful.jl</a>. It contains tools to conduct dimensional analysis and solve similitude problems based on <a href="https://en.wikipedia.org/wiki/Buckingham_%CF%80_theorem" rel="nofollow">the Buckingham Π theorem</a>.</p>

<p dir="auto">Install the package using Julia's package manager:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add Dimensionless"><pre>pkg<span class="pl-k">&gt;</span> add Dimensionless</pre></div>

<p dir="auto">The main functionality of this package is to find and make use of bases made of problem-specific variables and their units. Such bases can then be used to transform additional variables that describe a physical problem to corresponding dimensionless values and back to a dimensional form.</p>
<p dir="auto">For example, if a problem is, among other variables, characterized by a mass <code>m = 15 kg</code>, a length <code>L = 75 cm</code>, and the gravitational constant <code>g = 9.81 m/s^2</code>, a corresponding basis for the problem can be calculated:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Dimensionless, Unitful

julia&gt; basis = DimBasis(&quot;m&quot;=&gt;15u&quot;kg&quot;, &quot;L&quot;=&gt;75u&quot;cm&quot;, &quot;g&quot;=&gt;9.81u&quot;m/s^2&quot;)
DimBasis{...}"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Dimensionless, Unitful

<p dir="auto">This basis can now be used to coherently tranform any variable within the spanned space of this basis to a dimensionless value and back to a dimensional value again:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; p_dimless = dimless(0.2u&quot;bar&quot;, basis)

<p dir="auto">This procedure enables reducing the number of simulations or experiments as well as streamlining problem formulations. A full <a href="https://martinkosch.github.io/Dimensionless.jl/dev/example/" rel="nofollow">examplary use case</a> can be found in the documentation.</p>
