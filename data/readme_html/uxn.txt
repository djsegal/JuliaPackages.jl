<p dir="auto">To build the Uxn emulator, you must install <a href="https://wiki.libsdl.org/" rel="nofollow">SDL2</a> for your distro. If you are using a package manager:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="sudo pacman -Sy sdl2             # Arch
sudo apt install libsdl2-dev     # Ubuntu
brew install sdl2                # OS X"><pre>sudo pacman -Sy sdl2             <span class="pl-c"><span class="pl-c">#</span> Arch</span>
sudo apt install libsdl2-dev     <span class="pl-c"><span class="pl-c">#</span> Ubuntu</span>
brew install sdl2                <span class="pl-c"><span class="pl-c">#</span> OS X</span></pre></div>
<p dir="auto">Build the assembler and emulator by running the <code>build.sh</code> script. The assembler(<code>uxnasm</code>) and emulator(<code>uxnemu</code>) are created in the <code>/bin</code> folder.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="./build.sh
	--debug # Add debug flags to compiler
	--format # Format source code"><pre>./build.sh
	--debug <span class="pl-c"><span class="pl-c">#</span> Add debug flags to compiler</span>
	--format <span class="pl-c"><span class="pl-c">#</span> Format source code</span></pre></div>
<p dir="auto">If you wish to build the emulator without graphics mode:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="cc src/uxn.c -DNDEBUG -Os -g0 -s src/uxncli.c -o bin/uxncli"><pre>cc src/uxn.c -DNDEBUG -Os -g0 -s src/uxncli.c -o bin/uxncli</pre></div>

<p dir="auto">To launch a <code>.rom</code> in the emulator, point the emulator to the target rom file:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="bin/uxnemu bin/piano.rom"><pre>bin/uxnemu bin/piano.rom</pre></div>
<p dir="auto">You can also use the emulator without graphics by using <code>uxncli</code>. You can find additional roms <a href="https://sr.ht/~rabbits/uxn/sources" rel="nofollow">here</a>, you can find prebuilt rom files <a href="https://itch.io/c/248074/uxn-roms" rel="nofollow">here</a>.</p>
