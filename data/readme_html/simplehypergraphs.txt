<p dir="auto"><code>Simplehypergraphs</code> can optionally use (among other options) the Python's <a href="https://github.com/pnnl/HyperNetX">hypernetx</a> library so if you want the <code>hypernetx</code> plotting to work you need to install it first along with its all dependent libraries. In Julia command line REPL press <code>]</code> for the Julia package manager and run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(v1.5) pkg&gt; add PyCall Conda"><pre class="notranslate"><code>(v1.5) pkg&gt; add PyCall Conda
</code></pre></div>
<p dir="auto">Now press <em>backspace</em> to exit the package manager and run the following installation code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PyCall
using Conda
Conda.runconda(`install matplotlib --yes`)
Conda.runconda(`install networkx --yes`)
Conda.runconda(`install pandas --yes`)
run(`$(PyCall.python) -m pip install hypernetx==1.2.5`)"><pre><span class="pl-k">using</span> PyCall
<span class="pl-k">using</span> Conda
Conda<span class="pl-k">.</span><span class="pl-c1">runconda</span>(<span class="pl-s"><span class="pl-pds">`</span>install matplotlib --yes<span class="pl-pds">`</span></span>)
Conda<span class="pl-k">.</span><span class="pl-c1">runconda</span>(<span class="pl-s"><span class="pl-pds">`</span>install networkx --yes<span class="pl-pds">`</span></span>)
Conda<span class="pl-k">.</span><span class="pl-c1">runconda</span>(<span class="pl-s"><span class="pl-pds">`</span>install pandas --yes<span class="pl-pds">`</span></span>)
<span class="pl-c1">run</span>(<span class="pl-s"><span class="pl-pds">`</span><span class="pl-v">$(PyCall<span class="pl-k">.</span>python)</span> -m pip install hypernetx==1.2.5<span class="pl-pds">`</span></span>)</pre></div>
<p dir="auto">In case of throubleshooting to check whether <code>hypernetx</code> is properly configured with Julia you can always run the following test:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using PyCall
pyimport(&quot;hypernetx&quot;)"><pre class="notranslate"><code>using PyCall
pyimport("hypernetx")
</code></pre></div>
<p dir="auto">For plotting we also use the Jupyter notebook. The installation instructions are <a href="https://github.com/JuliaLang/IJulia.jl#installation">here</a></p>
<p dir="auto">Note that recently a new version of hypernetx has been released (2.0.0), however as of today SimpleHyprgraphs.jl is integrated with the previous versions up to 1.2.5.</p>
