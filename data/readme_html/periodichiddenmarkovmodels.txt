<p dir="auto">This package is an extension of the package <a href="https://github.com/gdalle/HiddenMarkovModels.jl">HiddenMarkovModels.jl</a> that defines a lot of the Hidden Markov Models tools (Baum Welch, Viterbi, etc.).
The extension adds the subtype <code>PeriodicHMM</code> to the type <code>HiddenMarkovModels.AbstractHMM</code> that deals with non-constant transition matrix <code>A(t)</code> and emission distribution <code>B(t)</code>.</p>
<p dir="auto">Before v0.2 this package depended on the no longer maintained <a href="https://github.com/maxmouchet/HMMBase.jl">HMMBase.jl</a>. It is now inspired by this <a href="https://gdalle.github.io/HiddenMarkovModels.jl/dev/examples/temporal/" rel="nofollow">Tutorial</a> of the <a href="https://github.com/gdalle/HiddenMarkovModels.jl">HiddenMarkovModels.jl</a> model, meaning that it should benefit from all the good stuff there. In particular mutli-sequence support.
The major notable difference is that <code>PeriodicHMM</code> here do not have to be periodic, they can be completely time inhomogeneous.
This is controlled by the <code>n2t</code> vector which indicates the correspondance between observation <code>n</code> and the associated element of the HMM <code>t</code>. See example bellow.</p>
