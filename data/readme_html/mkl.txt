<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Using Julia with Intel's MKL</h2><a id="user-content-using-julia-with-intels-mkl" class="anchor" aria-label="Permalink: Using Julia with Intel's MKL" href="#using-julia-with-intels-mkl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">MKL.jl is a Julia package that allows users to use the Intel MKL library for Julia's underlying BLAS and LAPACK, instead of OpenBLAS, which Julia ships with by default. Julia includes <a href="https://github.com/staticfloat/libblastrampoline">libblastrampoline</a>, which enables picking a BLAS and LAPACK library at runtime. A <a href="https://www.youtube.com/watch?v=t6hptekOR7s" rel="nofollow">JuliaCon 2021 talk</a> provides details on this mechanism.</p>
<p dir="auto">This package requires Julia 1.8+, and only covers the forwarding of BLAS and LAPACK routines in Julia to MKL. Other packages like <a href="https://github.com/JuliaMath/IntelVectorMath.jl">IntelVectorMath.jl</a>, <a href="https://github.com/JuliaSparse/Pardiso.jl">Pardiso.jl</a>, etc. wrap more of MKL's functionality. The <a href="https://github.com/JuliaGPU/oneAPI.jl">oneAPI.jl</a> package provides support for Intel OneAPI and Intel GPUs.</p>

<p dir="auto">If you want to use <code>MKL.jl</code> in your project, make sure it is the first package you load before any other package. It is essential that MKL be loaded before other packages so that it can find the Intel OMP library and avoid <a href="https://github.com/JuliaPackaging/BinaryBuilder.jl/issues/700" data-hovercard-type="issue" data-hovercard-url="/JuliaPackaging/BinaryBuilder.jl/issues/700/hovercard">issues resulting out of GNU OMP being loaded first</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">To Install:</h2><a id="user-content-to-install" class="anchor" aria-label="Permalink: To Install:" href="#to-install"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Adding the package will replace the system BLAS and LAPACK with MKL provided ones at runtime. Note that the MKL package has to be loaded in every new Julia process. Upon quitting and restarting, Julia will start with the default OpenBLAS.</p>
