<p dir="auto">This package contains the Julia reference implementation of AutoGP, a
method for automatically discovering Gaussian process models of univariate
time series data, as described in</p>
<blockquote>
<p dir="auto"><em>Sequential Monte Carlo Learning for Time Series Structure Discovery</em>.<br>
Saad, F A; Patton, B J; Hoffmann, M D.; Saurous, R A; Mansinghka, V K.<br>
ICML 2023: Proc. The 40th International Conference on Machine Learning.<br>
Proceedings of Machine Learning Research vol. 202, pages 29473-29489, 2023.</p>
</blockquote>
<p dir="auto">Whereas traditional Gaussian process software packages focus on inferring
the numeric parameters for a fixed (user-specified) covariance kernel
function, AutoGP learns both covariance kernel functions and numeric
parameters for a given dataset. The plots below show two examples of online
time series structure discovery using AutoGP, which discovers periodic
components, trends, and smoothly-varying temporal components.</p>

<p dir="auto">AutoGP can be installed using the Julia package manager. From the Julia
REPL (version 1.8+), type <code>]</code> to enter the Pkg REPL mode and run</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add AutoGP"><pre class="notranslate"><code>pkg&gt; add AutoGP
</code></pre></div>
<p dir="auto">Alternatively, use the terminal command
<code>julia -e 'import Pkg; Pkg.add("AutoGP")'</code>.</p>

<ol dir="auto">
<li>Obtain <a href="https://julialang.org/downloads/" rel="nofollow">Julia 1.8</a> or later.</li>
<li>Clone this repository.</li>
<li>Set environment variable: <code>export JULIA_PROJECT=/path/to/AutoGP.jl</code></li>
<li>Instantiate dependencies: <code>julia -e 'using Pkg; Pkg.instantiate()'</code></li>
<li>Build PyCall: <code>PYTHON= julia -e 'using Pkg; Pkg.build("PyCall")'</code></li>
<li>Verify import works: <code>julia -e 'import AutoGP; import PyPlot; println("success!")'</code></li>
</ol>
