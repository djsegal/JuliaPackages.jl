<ul dir="auto">
<li>arbitrary nonlinear regression models</li>
<li>scalar or vector-valued response variable</li>
<li>variance-covariance matrix may depend on covariate</li>
<li>Bayesian and locally optimal design</li>
<li>design criteria: D, A</li>
<li>composite design problems</li>
<li>separation of design variables and model covariates</li>
<li>particle swarm optimization</li>
<li>direct maximization and exchange algorithm</li>

<li>minimal dependencies</li>

<p dir="auto">Why yet another package for optimal design?</p>
<p dir="auto">In <code>R</code>, there is already the <a href="https://cran.r-project.org/package=ICAOD" rel="nofollow">ICAOD</a> package
for finding optimal designs in any model
of which you can implement the Fisher information matrix.
However,
it is not as efficient as it could be
and the code base is hard to extend for more complicated design problems.
There are also various other packages (e.g., <a href="https://cran.r-project.org/package=DoseFinding" rel="nofollow">DoseFinding</a> or <a href="https://cran.r-project.org/package=PopED" rel="nofollow">PopED</a>)
for optimal design with special criteria or special kinds of nonlinear regression models.
In <code>Julia</code>, there is already <a href="https://github.com/phrb/ExperimentalDesign.jl">ExperimentalDesign.jl</a>
for block, factorial and response-surface designs in linear regression/ANOVA and polynomial regression models.</p>
<p dir="auto">Kirstine.jl is an attempt to provide applied statisticians
with a <code>Julia</code> package for optimal design in arbitrary nonlinear regression models.
Its development goals are speed and modularity,
as well as a small, stable and well-documented code base.</p>
