<p dir="auto"><strong>TrixiGPU.jl</strong> is a component package of the <a href="https://github.com/trixi-framework/Trixi.jl"><strong>Trixi.jl</strong></a> ecosystem and provides GPU acceleration support for solving hyperbolic partial differential equations (PDEs). This package was initialized through the <a href="https://summerofcode.withgoogle.com/archive/2023/projects/upstR7K2" rel="nofollow"><strong>Google Summer of Code</strong></a> program in 2023 and is under active development and testing.</p>
<p dir="auto">The acceleration focus of this package is currently on the semidiscretization part (with plans to extend to other parts) of the PDE solvers, and <a href="https://github.com/JuliaGPU/CUDA.jl"><strong>CUDA.jl</strong></a> is our primary support (will expand to more types of GPUs using <a href="https://github.com/JuliaGPU/AMDGPU.jl"><strong>AMDGPU.jl</strong></a>, <a href="https://github.com/JuliaGPU/oneAPI.jl"><strong>OneAPI.jl</strong></a>, and <a href="https://github.com/JuliaGPU/Metal.jl"><strong>Metal.jl</strong></a> in the future).</p>
<p dir="auto">The complete documentation for this project (and now is available as a package) can be accessed here <a href="https://huiyuxie.github.io/gsoc23/" rel="nofollow"><strong>GSoC</strong></a>. Please note that this package is intended to be part of the <a href="https://github.com/trixi-framework"><strong>trixi-framework</strong></a> organization in the end. Due to constrained GPU resources and ease of development, it is now under a temporary organization.</p>
