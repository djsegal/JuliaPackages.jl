<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This is a package for generating LaTeX maths and designed to improve documentation for your calculations. This package was designed to work in both jupyter and pluto.</p>
<p dir="auto">This package supplies macros to generate <code>\LaTeX</code> formatted strings from mathmatical formulas. This package takes inspiration from <a href="https://github.com/connorferster/handcalcs">handcalcs.py</a> which is a python package that works best in jupyter notebooks. The goal is to get the functionalities of that package and bring them to Julia. At this point, I believe most (if not all) of the features from the python package are here. The package integrates well with <a href="https://painterqubits.github.io/Unitful.jl/stable/" rel="nofollow">Unitful.jl</a>. This package is an extension of <a href="https://github.com/korsbo/Latexify.jl">Latexify.jl</a>. The <code>@latexdefine</code> macro is similar to the main <code>@handcalcs</code> macro, but instead of only a symbolic rendering it also renders the numeric substitution.</p>
<p dir="auto"><strong>Note: This package now renders properly in Quarto/Weave!! You can change the default settings to your liking. See <a href="https://co1emi11er2.github.io/Handcalcs.jl/stable/" rel="nofollow">docs</a> for more info.</strong></p>
