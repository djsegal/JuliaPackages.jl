<p dir="auto">MeanFieldToolkit.jl is a Julia package meant for solving generalized self-consistent mean-field equations on a lattice.</p>
<p dir="auto">Currently supported :</p>
<ul dir="auto">
<li>Lattice implementation is done through <a href="https://github.com/Anjishnubose/TightBindingToolkit.jl">TightBindingToolkit.jl</a>. Any custom lattice in d=1,2,3 is supported.</li>
<li>User can input any two-site interaction in the form of arrays, and their corresponding mean-field equations. Simple four-fermion interactions are already built in (such as Hubbard, Spin-Spin interactions etc.).</li>
<li>Can track any hopping and pairing order parameters.</li>
<li>Self-consistentcy solver is implemented using <a href="https://github.com/Anjishnubose/FixedPointToolkit.jl">FixedPointToolkit.jl</a>. Can customize the solver, the tolerance of convergence, the maximum number of iterations and so on.</li>
<li>Can checkpoint and save results into JLD2 files, and resume iterations from reading such files.</li>
<li>Can plot results of order parameters, and the mean-field ground state energy as a function of iterations.</li>
</ul>
