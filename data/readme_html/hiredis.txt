<p dir="auto">A Julia wrapper for <a href="https://github.com/redis/hiredis">hiredis</a>, a minimalistic C client library for the <a href="https://redis.io" rel="nofollow">Redis</a> database.</p>
<p dir="auto">Importantly, in contrast to <a href="https://github.com/JuliaDatabases/Redis.jl">Redis.jl</a>, Hiredis.jl supports TLS connections.</p>
