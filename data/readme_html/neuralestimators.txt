<p dir="auto"><code>NeuralEstimators</code> facilitates the user-friendly development of neural point estimators, which are neural networks that transform data into parameter point estimates. They are likelihood free, substantially faster than classical methods, and can be designed to be approximate Bayes estimators. The package caters for any model for which simulation is feasible. See the <a href="https://msainsburydale.github.io/NeuralEstimators.jl/dev/" rel="nofollow">documentation</a> to get started!</p>
