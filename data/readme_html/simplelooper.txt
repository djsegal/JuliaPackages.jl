<p dir="auto">A simple looper.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@loop call
@loop n call
@loop bool_expr call
@loop 1.0 call"><pre><span class="pl-c1">@loop</span> call
<span class="pl-c1">@loop</span> n call
<span class="pl-c1">@loop</span> bool_expr call
<span class="pl-c1">@loop</span> <span class="pl-c1">1.0</span> call</pre></div>
<p dir="auto">Repeat <code>call</code> indefinitely until interrupt or <code>n</code> times and discard the output.
If an expression is given as a first argument it must return a <code>Bool</code> and
repeats will occur until <code>false</code>. If a float is given the loop will run for that
many seconds.</p>
