<p dir="auto">A lightweight library that converts simple HTML markdown and Unicode characters to the corresponding latex strings.</p>
<p dir="auto">This package can be used to convert names or HTML-formatted chemical formulas to a tex-friendly format.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Text2Tex

julia&gt; text2tex(&quot;Straße&quot;)
&quot;Stra{\\ss}e&quot;

julia&gt; text2tex(&quot;I can handle&lt;sub&gt;subscripts&lt;/sub&gt;&quot;)
&quot;I can handle\\textsubscript{subscripts}&quot;

julia&gt; text2tex(&quot;I can handle special characters like å, ä, ö&quot;)
&quot;I can handle special characters like {\\aa}, {\\\&quot;a}, {\\\&quot;o}&quot;
