<p dir="auto">WaveSpec provides functions related to ocean-wave input for numerical models.
These include</p>
<markdown-accessiblity-table><table>
<thead>
<tr>
<th>Function</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>dispersionRel(h, T)</code></td>
<td>Function for calculation the wave-length for a ocean wave with period <code>T</code> and in water-depth <code>h</code>,</td>
</tr>
<tr>
<td><code>jonswap(Hs, Tp)</code></td>
<td>Function for calculation jonswap spectrum, for a given significant wave height <code>Hs</code> and peak time period <code>Tp</code>)</td>
</tr>
<tr>
<td><code>waveAiry1D(sp, t, x, z)</code></td>
<td>Generate time-series for wave-elevation and particle velocity at location <code>(x,z)</code> at at time-instances <code>t</code> for a ocean-wave spectrum defined by <code>sp</code></td>
</tr>
</tbody>
</table></markdown-accessiblity-table>
