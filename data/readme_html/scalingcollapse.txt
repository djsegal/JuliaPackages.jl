<p dir="auto">This is a package for automatic finite size scaling. Finite size scaling is a method to determine the critical parameters of a phase transition by exploiting, so called, finite size effects. This package implements an automatic optimization algorithm to find the best parameters for a finite size scaling collapse.</p>
<p dir="auto">It is still in early development, so expect bugs and breaking changes. Feel free to create issues in case you stumble upon any problems!</p>

<p dir="auto">To find the best parameters for a finite size scaling analysis, we need to create a <code>ScalingProblem</code>. Lets say we have data for the binder cumulant of the 2D Ising model <code>binder</code> for different temperatures <code>Ts</code> and different system sizes <code>Ls</code>. We want to find the critical temperature and the critical exponent of the correlation length. Let's create a <code>ScalingProblem</code> as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ScalingCollapse
sp = ScalingProblem(Ts, binder, Ls;
    sf = ScalingFunction(:x),
    dx = [-1.0, 1.0],
)"><pre><span class="pl-k">using</span> ScalingCollapse
sp <span class="pl-k">=</span> <span class="pl-c1">ScalingProblem</span>(Ts, binder, Ls;
    sf <span class="pl-k">=</span> <span class="pl-c1">ScalingFunction</span>(<span class="pl-c1">:x</span>),
    dx <span class="pl-k">=</span> [<span class="pl-k">-</span><span class="pl-c1">1.0</span>, <span class="pl-c1">1.0</span>],
)</pre></div>
<p dir="auto">The kwarg <code>sf</code> is used to set the scaling function. In this case we use the scaling function preset <code>:x</code> which only rescales the x-axis as <code>x -&gt; (x - p1)/p1 * L^(1/p2)</code>. We can also give the parameters custom names by passing the kwarg <code>p_names::Vector{String}</code> to the <code>ScalingFunction</code> constructor.
We use the kwarg <code>dx</code> to limit the optimization to a fixed interval because powerlaw dependece is usually only accurate close to the critical point. The default value is <code>dx = [-Inf, Inf]</code>.
Other kwargs are:</p>
<ul dir="auto">
<li><code>p_space = [0.1:0.1:3.0 for _ in 1:n_parameters(sf)]]</code> This sets the parameter space that will be scanned for local minima of the cost function. The optimization algorithm will start from the determined local minima to find the global minimum. Note that the the optimal parameters should lie within the given parameter space. Also note, that the initial scan can take a while for too small stepsizes. If you have a good idea where the optimal parameters should lie, you can set the parameter space accordingly. You can also skip the local minima search completely, by setting the kwarg <code>starting_ps</code>.</li>
<li><code>starting_ps::Vector{Float64}</code> This kwarg can be used to skip the local minima search. If <code>starting_ps</code> is set to a specific parameter set, the optimization algorithm will start from this point. This can be useful if you already have a good guess for the optimal parameters. Note that you might not find the optimal parameters if you start from a bad guess.</li>
<li><code>error::Bool=false</code> This kwarg can be used to turn the error calculation on or off. If <code>error=true</code>, the error of the parameters will be calculated using a <code>2S</code> method. This means that we fix all but one parameter and vary the free paramter, such that we double the cost function value. The error is then the maximum of the variation in plus and minus direction.</li>
<li><code>verbose::Bool=false</code> This kwarg can be used to turn the verbose output on or off. If <code>verbose=true</code>, the algorithm will print some information about the optimization process.</li>
</ul>
<p dir="auto">There are also other preset ScalingFunctions:</p>
<ul dir="auto">
<li><code>:x</code> Rescales the x-axis as <code>x -&gt; (x - p1)/p1 * L^(1/p2)</code>.</li>
<li><code>:xy</code> This is the default scaling function. It rescales the x-axis as <code>x -&gt; (x - p1)/p1 * L^(1/p2)</code> and the y-axis as <code>y -&gt; y * L^(p3/p2)</code>.</li>
<li><code>:xny</code> This scaling function is similar to <code>:xy</code> but it rescales the y-axis as <code>y -&gt; y * L^(-p3/p2)</code>. In this case the critical exponent <code>p3</code> has a negative sign.</li>
</ul>
<p dir="auto">Note that you can also create your own scaling function! We can make our scaling function looking a little bit cooler by giving our parameters custom names with the kwarg <code>p_names::Vector{String}</code>.</p>
<p dir="auto">Now that we know the basics, let us solve another scaling problem. This time we know that the critical temperature is somewhere between <code>T_c = 2.0</code> and <code>T_c = 2.4</code> and the critical exponent is somewhere between <code>nu = 0.5</code> and <code>nu = 1.5</code>. We set the parameter space accordingly:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ScalingCollapse
sp = ScalingProblem(Ts, binder, Ls;
    sf = ScalingFunction(:x; p_names = [&quot;T_c&quot;, &quot;nu&quot;]),
    dx = [-1.0, 1.0],
    p_space = [2.0:0.1:2.4, 0.5:0.1:1.5],
    error = true,
)"><pre><span class="pl-k">using</span> ScalingCollapse
sp <span class="pl-k">=</span> <span class="pl-c1">ScalingProblem</span>(Ts, binder, Ls;
    sf <span class="pl-k">=</span> <span class="pl-c1">ScalingFunction</span>(<span class="pl-c1">:x</span>; p_names <span class="pl-k">=</span> [<span class="pl-s"><span class="pl-pds">"</span>T_c<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>nu<span class="pl-pds">"</span></span>]),
    dx <span class="pl-k">=</span> [<span class="pl-k">-</span><span class="pl-c1">1.0</span>, <span class="pl-c1">1.0</span>],
    p_space <span class="pl-k">=</span> [<span class="pl-c1">2.0</span><span class="pl-k">:</span><span class="pl-c1">0.1</span><span class="pl-k">:</span><span class="pl-c1">2.4</span>, <span class="pl-c1">0.5</span><span class="pl-k">:</span><span class="pl-c1">0.1</span><span class="pl-k">:</span><span class="pl-c1">1.5</span>],
    error <span class="pl-k">=</span> <span class="pl-c1">true</span>,
)</pre></div>
<p dir="auto">We limited the parameter space so the algorithm runs faster, calculated some error bars and made everything look cooler by giving the parameters custom names!</p>

<p dir="auto">Let's say that we know from our statistical mechanics course that the critical exponent of the correlation length is <code>nu = 1</code>. We can fix this parameter by passing it as a kwarg to the <code>ScalingFunction</code> constructor.</p>

<p dir="auto">Now the algorithm will only optimize the critical temperature <code>T_c</code> and the critical exponent of the correlation length will be fixed to <code>nu = 1</code>.</p>
