<p dir="auto">This is a <strong>Julia</strong> package for fractional differential equations and ODEs. It provides numerical solutions for nonlinear fractional ordinary differential equations (in the sense of Caputo).</p>
<p dir="auto">Related work includes the independent <a href="https://github.com/SciFracX/FractionalDiffEq.jl">FractionalDiffEq</a> Julia Package that provides solutions of differential equations with different fractional operators, and earlier tools that are available in <a href="https://www.dm.uniba.it/members/garrappa/software" rel="nofollow">Matlab</a>.</p>
<p dir="auto">The implemented models are generic and broadly applicable to modeling
multivariate signals from a single source or collected across multiple
sources. The dynamical models implemented in this package were
initially developed for modeling dynamics of interacting microbial
communities (Khalighi et al. 2022) but the models are more broadly
applicable and applicable to studying multi-omic and host-microbiome
interactions.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Method</h2><a id="user-content-method" class="anchor" aria-label="Permalink: Method" href="#method"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We implement the <a href="https://doi.org/10.1023/A:1016592219341" rel="nofollow">predictor-corrector</a> algorithms with a sufficient <a href="https://doi.org/10.1023/B:NUMA.0000027736.85078.be" rel="nofollow">convergence and accuracy</a>, including fast Fourier transform technique that gives us high computation speed. Interested readers can also find the <a href="https://doi.org/10.1080/00207160802624331" rel="nofollow">stability</a> of the methods and see how to implement the methods for solving <a href="https://doi.org/10.1007/s00607-003-0033-3" rel="nofollow">multi-term</a> fractional differential equations.</p>
<p dir="auto">Let us suppose the following initial value problem with the Caputo fractional derivative for  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="46db02f8d231c118ada39bc5bc2ceb63">$\beta&amp;gt;0$</math-renderer>:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="46db02f8d231c118ada39bc5bc2ceb63">$${}_{C}\!D_{t_0}^{\beta}y(t)=f(t,y(t))$$</math-renderer>
<p dir="auto">with the initial condition:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="46db02f8d231c118ada39bc5bc2ceb63">$$y(t_0)=y_0,y^{(1)}(t_0)=y^{(1)}_0,...,y^{(m-1)}(t_0)=y^{(m-1)}_0$$</math-renderer>
<p dir="auto">where m is the smallest integer or equal to the order of derivative.</p>
<p dir="auto">We solve the problem by using <a href="https://www.mdpi.com/2227-7390/6/2/16#" rel="nofollow">predictor corrector and Newton Raphson method</a>.</p>
