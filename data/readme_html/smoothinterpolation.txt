<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">CachedInterpolations.jl</h1><a id="user-content-cachedinterpolationsjl" class="anchor" aria-label="Permalink: CachedInterpolations.jl" href="#cachedinterpolationsjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>CachedInterpolations.jl</code> exports interpolation types in the style of <a href="https://github.com/SciML/DataInterpolations.jl">DataInterpolations.jl</a>:</p>
<ul dir="auto">
<li><code>CLinearInterpolation</code>, regular old linear interpolation;</li>
<li><code>CSmoothedLinearInterpolation</code>, a type of linear interpolation with well-behaved smoothed corners;</li>
<li><code>CSmoothedLinearInterpolationIntInv</code>, the inverse of the antiderivative of a <code>CSmoothedLinearInterpolation</code> if it exists;</li>
<li><code>CLinearInterpolationInvInv</code>, the inverse of the antiderivative of a <code>(C)LinearInterpolation</code> if it exists.</li>
</ul>
<p dir="auto">These interpolations make as much use as possible of cached data computed at initialization, for a speed against memory usage tradeoff.</p>
