<p dir="auto"><a href="https://github.com/varnerlab/BSTModelKit.jl/actions"><img src="https://github.com/JuliaStats/Distributions.jl/workflows/CI/badge.svg" alt="Build Status" style="max-width: 100%;"></a>
<a href="https://varnerlab.github.io/BSTModelKit.jl/dev/" rel="nofollow"><img src="https://camo.githubusercontent.com/c21574baf34c81b3651a5274c8b074471bc1e142a9516c0cfa75dea9223d93fe/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6c61746573742d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-latest-blue.svg" style="max-width: 100%;"></a></p>
<p dir="auto"><code>BSTModelKit.jl</code> is a package for constructing, solving, and analyzing Biochemical Systems Theory (BST) models of biochemical networks written in the <a href="https://julialang.org" rel="nofollow">Julia</a> programming language. In particular, <code>BSTModelKit.jl</code> provides a set of tools for constructing and solving S-system BST representations of the form:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$$
\frac{dX_{i}}{dt} = \alpha_{i}\prod_{j\in\mathcal{P}}X_{j}^{g_{ij}} - \beta_{i}\prod_{j\in\mathcal{R}}X_{j}^{h_{ij}}\qquad{i=1,\dots,n}
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$X_{i}$</math-renderer> is the concentration of the species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$i$</math-renderer>, the values <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$\alpha_{i}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$\beta_{i}$</math-renderer> are kinetic parameters (rate constants), <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$\mathcal{P}$</math-renderer> is the set of species that produce <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$X_{i}$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$\mathcal{R}$</math-renderer> is the set of species that consume <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$X_{i}$</math-renderer>, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$g_{ij}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$h_{ij}$</math-renderer> are the kinetic order coefficients relating species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$i$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1ea1ac405ee7de7bf624bf6f282cc80">$j$</math-renderer>.</p>
<p dir="auto">The S-system BST representation was developed by <a href="https://en.wikipedia.org/wiki/Michael_Antonio_Savageau" rel="nofollow">Savageau, Voit, and coworkers</a>. For a nice introduction to the S-system representation, see:</p>
<ul dir="auto">
<li><a href="https://www.sciencedirect.com/science/article/pii/0025556487900071" rel="nofollow">Savageau M, Voit E, Irvine D. Biochemical systems theory and metabolic control theory: 1. fundamental similarities and differences. Math Biosci. 1987 86(2): 127-45. doi.org/10.1016/0025-5564(87)90007-1.</a></li>
<li><a href="https://www.amazon.com/Biochemical-Systems-Analysis-Function-Molecular/dp/1449590764/ref=sr_1_1?crid=1MRBJ5U79CTTH&amp;keywords=Biochemical+systems+analysis&amp;qid=1690469004&amp;sprefix=biochemical+systems+analysis%2Caps%2C69&amp;sr=8-1" rel="nofollow">Savageau M. Biochemical systems analysis: a study of function and design in molecular biology. Reading, MA: Addison-Wesley; 1976.</a></li>
</ul>
<p dir="auto">Finally, <code>BSTModelKit.jl</code> is a research code, expect there will be (many) bugs, breaking changes (often), etc.</p>

<p dir="auto"><code>BSTModelKit.jl</code> can be installed, updated, or removed using the <a href="https://docs.julialang.org/en/v1/stdlib/Pkg/" rel="nofollow">Julia package management system</a>. To access the package management interface, open the <a href="https://docs.julialang.org/en/v1/stdlib/REPL/" rel="nofollow">Julia REPL</a>, and start the package mode by pressing <code>]</code>.
While in package mode, to install <code>BSTModelKit.jl</code>, issue the command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(@v1.1.x) pkg&gt; add BSTModelKit"><pre class="notranslate"><code>(@v1.1.x) pkg&gt; add BSTModelKit
</code></pre></div>
<p dir="auto">To use <code>BSTModelKit.jl</code> in your projects, issue the command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; using BSTModelKit"><pre class="notranslate"><code>julia&gt; using BSTModelKit
</code></pre></div>
