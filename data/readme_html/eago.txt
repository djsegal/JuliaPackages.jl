<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">EAGO's Optimizer Capabilities</h2><a id="user-content-eagos-optimizer-capabilities" class="anchor" aria-label="Permalink: EAGO's Optimizer Capabilities" href="#eagos-optimizer-capabilities"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">EAGO is a deterministic global optimizer designed to address a wide variety of optimization problems, emphasizing nonlinear programs (NLPs), by propagating McCormick relaxations along the factorable structure of each expression in the NLP. Most operators supported by modern automatic differentiation (AD) packages (e.g., <code>+</code>, <code>sin</code>, <code>cosh</code>) are supported by EAGO and a number utilities for sanitizing native Julia code and generating relaxations on a wide variety of user-defined functions have been included. Currently, EAGO supports problems that have a priori variable bounds defined and have differentiable constraints. That is, problems should be specified in the generic form below:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$$
\begin{align*}
f^{*} = &amp; \min_{\mathbf y \in Y \subset \mathbb R^{n_{y}}} f(\mathbf y) \\
{\rm s.t.} \;\; &amp; \mathbf h(\mathbf y) = \mathbf 0 \\
&amp; \mathbf g(\mathbf y) \leq \mathbf 0 \\
&amp; Y = [\mathbf y^{\mathbf L}, \mathbf y^{\mathbf U}] \in \mathbb{IR}^{n} \\
&amp; \qquad \mathbf y^{\mathbf L}, \mathbf y^{\mathbf U} \in \mathbb R^{n}
\end{align*}
$$</math-renderer></p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">EAGO's Relaxations</h2><a id="user-content-eagos-relaxations" class="anchor" aria-label="Permalink: EAGO's Relaxations" href="#eagos-relaxations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For each nonlinear term, EAGO makes use of factorable representations to construct bounds and relaxations. In the case of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$f(x) = x (x - 5) \sin(x)$</math-renderer>, a list is generated and rules for constructing McCormick relaxations are used to formulate relaxations in the original decision space, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$X$</math-renderer> [<a href="#references">1</a>]:</p>
<ul dir="auto">
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$v_{1} = x$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$v_{2} = v_{1} - 5$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$v_{3} = \sin(v_{1})$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$v_{4} = v_{1} v_{2}$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$v_{5} = v_{4} v_{3}$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$f(x) = v_{5}$</math-renderer></li>
</ul>
<p align="center" dir="auto">
<a target="_blank" rel="noopener noreferrer" href="https://github.com/PSORLab/EAGO.jl/blob/master/docs/src/mccormick/Figure_1.png"><img src="https://github.com/PSORLab/EAGO.jl/raw/master/docs/src/mccormick/Figure_1.png" width="60%" height="60%" style="max-width: 100%;"></a>
</p><p dir="auto">Either these original relaxations, differentiable McCormick relaxations [<a href="#references">2</a>], or affine relaxations thereof can be used to construct relaxations of optimization problems useful in branch and bound routines for global optimization. Utilities are included to combine these with algorithms for relaxing implicit functions [<a href="#references">3</a>] and forward-reverse propagation of McCormick arithmetic [<a href="#references">4</a>].</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Sample Usage</h2><a id="user-content-sample-usage" class="anchor" aria-label="Permalink: Sample Usage" href="#sample-usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">EAGO makes use of the JuMP algebraic modeling language to improve the user's experience in setting up optimization models. Consider the familiar "process" problem instance [<a href="#references">5</a>]:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1781cbe666e6cf7fce3d934902f575e8">$$
\begin{align*}
&amp; \max_{\mathbf x \in X} 0.063 x_{4} x_{7} - 5.04 x_{1} - 0.035 x_{2} - 10 x_{3} - 3.36 x_{2} \\
{\rm s.t.} \;\; &amp; x_{1} (1.12 + 0.13167 x_{8} - 0.00667 x_{8}^{2}) + x_{4} = 0 \\
&amp; -0.001 x_{4} x_{9} x_{6} / (98 - x_{6}) + x_{3} = 0 \\
&amp; -(1.098 x_{8} - 0.038 x_{8}^{2}) - 0.325 x_{6} + x_{7} = 0 \\
&amp; -(x_{2} + x_{5}) / x_{1} + x_{8} = 0 \\
&amp; -x_{1} + 1.22 x_{4} - x_{5} = 0 \\
&amp; x_{9} + 0.222 x_{10} - 35.82 = 0 \\
&amp; -3.0 x_{7} + x_{10} + 133.0 = 0 \\
&amp; X = [10, 2000] \times [0, 16000] \times [0, 120] \times [0, 5000] \\
&amp; \qquad \times [0, 2000] \times [85, 93] \times [90,9 5] \times [3, 12] \times [1.2, 4] \times [145, 162]
\end{align*}
$$</math-renderer></p>
<p dir="auto">This model can be formulated using JuMP code as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP, EAGO

JuMP<span class="pl-k">.</span><span class="pl-c1">optimize!</span>(m)</pre></div>
<p dir="auto">Special handling has been included for linear/quadratic functions defined using the <code>@constraint</code> macro in JuMP and these can generally be expected to perform better than specifying quadratic or linear terms with the <code>@NLconstraint</code> macro.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">A Cautionary Note on Global Optimization</h2><a id="user-content-a-cautionary-note-on-global-optimization" class="anchor" aria-label="Permalink: A Cautionary Note on Global Optimization" href="#a-cautionary-note-on-global-optimization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">As a global optimization platform, EAGO's solvers can be used to find solutions of general nonconvex problems with a guaranteed certificate of optimality. However, global solvers suffer from the curse of dimensionality and therefore their performance is outstripped by convex/local solvers. For users interested in large-scale applications, be warned that problems generally larger than a few variables may prove challenging for certain types of global optimization problems.</p>

<p dir="auto">The EAGO package has numerous features: a solver accessible from JuMP/MathOptInterface (MOI), domain reduction routines, McCormick relaxations, and specialized nonconvex semi-infinite program solvers. A full description of all EAGO features is available on the <a href="https://psorlab.github.io/EAGO.jl/dev/" rel="nofollow">documentation website</a>. A series of example have been provided in the form of Jupyter Notebooks in the separate <a href="https://github.com/PSORLab/EAGO-notebooks">EAGO-notebooks</a> repository.</p>
