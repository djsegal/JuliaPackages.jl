<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">VTTrac: Velocimetry by Template Tracking</h2><a id="user-content-vttrac-velocimetry-by-template-tracking" class="anchor" aria-label="Permalink: VTTrac: Velocimetry by Template Tracking" href="#vttrac-velocimetry-by-template-tracking"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This library provides the julia-language implementation for <code>VTTrac</code> (<a href="https://github.com/thorinouchi/VTTrac">https://github.com/thorinouchi/VTTrac</a>). It does not use module variables, so it should be good for parallel execution.</p>
<p dir="auto">The algorithm used in this library is the simple template matching of PIV (particle image velocimetry) for monochromatic image-like data, but the matching is conducted multiple times in a Lagrangian manner as in PTV (particle tracking velocimetry) over a number of times specified by the parameter named <code>ntrac</code>. The default scoring method for template matching is the cross correlation coefficient, as in the basic PIV. Both forward and backward tracking is available. Use the parameter <code>itstep</code>; tracking is backward along time sequence, if it is negative.</p>
