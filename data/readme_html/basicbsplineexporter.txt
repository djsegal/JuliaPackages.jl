<p dir="auto">This package supports export <code>BasicBSpline.BSplineManifold{Dim,Deg,&lt;:StaticVector}</code> to:</p>
<ul dir="auto">
<li>PNG image (<code>.png</code>)</li>
<li>SVG image (<code>.png</code>)</li>
<li>POV-Ray mesh (<code>.inc</code>)</li>
</ul>
