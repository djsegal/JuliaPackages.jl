<p dir="auto">This package is not meant for public use!</p>
<p dir="auto">Please contact us if you plan to depend directly on this package as we frequently coordinate breaking changes to it.</p>
<p dir="auto">On the other hand, we do respect semantic versioning, so at worst you would be stuck on an old version of the package, but you should not have your code break unexpectedly due to a change made by us.</p>
<p dir="auto">This package contains formal and informal definitions of common interfaces used by:</p>
<ul dir="auto">
<li><a href="https://github.com/qojulia/QuantumOpticsBase.jl/"><code>QuantumOpticsBase.jl</code></a> - a library defining data structures for Schroedinger-style quantum simulations (e.g. dense and sparse matrix operators and vector kets)</li>
<li><a href="https://github.com/qojulia/QuantumOptics.jl/"><code>QuantumOptics.jl</code></a> - provides dynamic equations over types defined in <code>QuantumOpticsBase</code></li>
<li><a href="https://github.com/QuantumSavory/QuantumClifford.jl"><code>QuantumClifford.jl</code></a> - implements the typical stabilizer tableaux formalism</li>
<li><a href="https://github.com/QuantumSavory/QuantumSymbolics.jl"><code>QuantumSymbolics.jl</code></a> - general purpose symbolic algebra for quantum information science, focusing on automatically transforming symbolic expressions into other formalisms (vectors, tableaux, etc)</li>
<li><a href="https://github.com/QuantumSavory/QuantumSavory.jl"><code>QuantumSavory.jl</code></a> - a multi-formalism simulator building up on the other tools</li>
<li><a href="https://juliahub.com/ui/Packages/QuantumInterface/a9rji/?page=2" rel="nofollow"><code>and others</code></a></li>
</ul>
