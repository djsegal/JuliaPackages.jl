<p dir="auto">Creating a package to interface the YODA format for Histograms into Julia. This format is predominantly used in high-energy particle physics such as for the MC validation tool RIVET.
For more information on the YODA file format visit the YODA homepage <a href="https://yoda.hepforge.org/" rel="nofollow">https://yoda.hepforge.org/</a> or the GitLab at
<a href="https://gitlab.com/hepcedar/yoda" rel="nofollow">https://gitlab.com/hepcedar/yoda</a></p>
