<p dir="auto">The only name exported by this package is <code>AbstractGraphInterface</code>.</p>
<p dir="auto">Suppose you define a new graph type <code>MyGraphType &lt;: Graphs.AbstractGraph</code>.
To declare that you implement the interface, you need to provide a list of (small) <code>test_graphs</code>, then use the macro <code>Interfaces.@implements</code> like so:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Interfaces.@implements AbstractGraphInterface MyGraphType test_graphs"><pre>Interfaces<span class="pl-k">.</span><span class="pl-c1">@implements</span> AbstractGraphInterface MyGraphType test_graphs</pre></div>
<p dir="auto">Then, you can validate your implementation as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Interfaces.test(AbstractGraphInterface, MyGraphType)"><pre>Interfaces<span class="pl-k">.</span><span class="pl-c1">test</span>(AbstractGraphInterface, MyGraphType)</pre></div>
