<p dir="auto">A Julia package wrapping <a href="https://www.github.com/dynamicsandneuralsystems/catchaMouse16"><em>catchaMouse16</em></a>, which is a set of 16 time-series features shown to be performant in BOLD fMRI time-series classification problems. This package mirrors <a href="https://www.github.com/brendanjohnharris/Catch22.jl">Catch22.jl</a>, which is a set of 22 features for general time-series problems.</p>
<p dir="auto">The <a href="https://www.github.com/dynamicsandneuralsystems/catchaMouse16"><em>catchaMouse16</em></a> repository provides these 22 features, originally coded in Matlab as part of the <a href="https://github.com/benfulcher/hctsa"><em>hctsa</em></a> toolbox, as C functions (in addition to Matlab and Python wrappers). This package simply uses Julia's <code>ccall</code> to wrap these C functions from a shared library that is accessed through <a href="https://github.com/JuliaBinaryWrappers/catchaMouse16_jll.jl">catchaMouse16_jll</a> and compiled by the fantastic <a href="https://github.com/JuliaPackaging/BinaryBuilder.jl">BinaryBuilder</a> package.</p>
<p dir="auto">Below we provide a brief getting-started guide to using CatchaMouse16.jl. For more detailed information on the <em>catchaMouse16</em> feature set, such as in-depth descriptions of each feature and a list of publications that use <em>catchaMouse16</em>, see the <a href="https://time-series-features.gitbook.io/time-series-analysis-tools/feature-subsets/catchamouse16" rel="nofollow"><em>catchaMouse16</em> wiki</a>.</p>

<p dir="auto">A list of features (as symbols) can be obtained with <code>getnames(catchaMouse16)</code> and their short descriptions with <code>getdescriptions(catchaMouse16)</code>. Each feature can be evaluated for a time series array or vector with the <code>catchaMouse16</code> <code>FeatureSet</code>. For example, the feature <code>AC_nl_035</code> can be evaluated using:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="f = catchaMouse16[:AC_nl_035](𝐱) # Returns a scalar Float64

<p dir="auto">All <em>catchaMouse16</em> features can be evaluated with:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="𝐟 = catchaMouse16(𝐱)
F = catchaMouse16(X)"><pre>𝐟 <span class="pl-k">=</span> <span class="pl-c1">catchaMouse16</span>(𝐱)
F <span class="pl-k">=</span> <span class="pl-c1">catchaMouse16</span>(X)</pre></div>
<p dir="auto">If an array is provided, containing one time series in each of N columns, then a 22×N <code>FeatureArray</code> of feature values will be returned (a subtype of <a href="https://github.com/rafaqz/DimensionalData.jl">AbstractDimArray</a>).
A <code>FeatureArray</code> has most of the properties and methods of an Array but is annotated with feature names that can be accessed with <code>getnames(F)</code>.
If a vector is provided (a single time series) then a vector of feature values will be returned as a <code>FeatureVector</code>, a one-dimensional <code>FeatureArray</code>.</p>
<p dir="auto">Finally, note that since <code>catchaMouse16</code> is a <code>FeatureSet</code> it can be indexed with a vector of feature names as symbols to calculate a <code>FeatureArray</code> for a subset of <em>catchaMouse16</em>. For details on the <code>Feature</code>, <code>FeatureSet</code> and <code>FeatureArray</code> types check out the package docs.</p>
