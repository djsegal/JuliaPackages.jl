<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">What is <code>SubmitPaper.jl</code>?</h1><a id="user-content-what-is-submitpaperjl" class="anchor" aria-label="Permalink: What is SubmitPaper.jl?" href="#what-is-submitpaperjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>SubmitPaper.jl</code> is very simple package to automate submitting a paper to arXiv or journal which requires a flat directory structure with a single <code>.tex</code> file, while being able to keep your code clean and well-structured. The aim is to eliminate any manual copying and pasting to produce output that can be used by the journals' compilers.</p>
<p dir="auto">The main command will analyse a supplied directory for a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0fa014e19bf4ae9e610efa308fe0c7d9">$\LaTeX$</math-renderer> project and create a new submission folder with the modified files. The package <strong>does not</strong> modify any existing files in the directory. <code>SubmitPaper.jl</code> assumes a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0fa014e19bf4ae9e610efa308fe0c7d9">$\LaTeX$</math-renderer> project directory structure with a <code>main.tex</code> file (<code>main</code> could be something else) which contains a <code>\documentclass</code> line as well as a <code>\begin{document}</code> line. The package will search for these <code>root</code> files within a specified directory. It will then look for any <code>\input</code> or <code>\include</code> commands in the <code>.tex</code> file and replace them with the actual contents of the corresponding file. Additionally, any figures referenced by the <code>\includegraphics</code> command will have the path modified to point at the file name of the figure and copy the original figure into the submission directory.</p>

<ul dir="auto">
<li>A <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0fa014e19bf4ae9e610efa308fe0c7d9">$\LaTeX$</math-renderer> distribution must be installed on the system.</li>
<li>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basic Usage</h2><a id="user-content-basic-usage" class="anchor" aria-label="Permalink: Basic Usage" href="#basic-usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First, make sure you have Julia installed on your system. We recommend using <code>juliaup</code>(<a href="https://github.com/JuliaLang/juliaup">https://github.com/JuliaLang/juliaup</a>) if you have not installed Julia already. Then, run the following command to install the <code>SubmitPaper.jl</code> package:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia -e 'using Pkg; Pkg.add(&quot;SubmitPaper&quot;);'"><pre>julia -e <span class="pl-s"><span class="pl-pds">'</span>using Pkg; Pkg.add("SubmitPaper");<span class="pl-pds">'</span></span></pre></div>
<p dir="auto">This will install to your global directory, allowing use of the package from anywhere.</p>
<p dir="auto">Next, find the absolute path to the directory containing your <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0fa014e19bf4ae9e610efa308fe0c7d9">$\LaTeX$</math-renderer> project (e.g. <code>"path/to/project"</code>), making sure to use the escaped characters <code>\\</code> on Windows, and run the following from the command line to create the submission folder:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia -e 'using SubmitPaper; package(&quot;path/to/project&quot;)'"><pre>julia -e <span class="pl-s"><span class="pl-pds">'</span>using SubmitPaper; package("path/to/project")<span class="pl-pds">'</span></span></pre></div>
<p dir="auto">This should create your submission at <code>"path/to/project/submission"</code> by default.</p>
