<p dir="auto">DispersionRelations.jl is a small package for estimating linear dispersion relations from data.
It is intended for use in computational physics, where it is often necessary to compare the
measured growth rate of some instability or damping process to linear theory.</p>
<p dir="auto">The package consists of two functions:</p>
<ul dir="auto">
<li><code>fit_pure_growth_rate(t, E, time_range)</code>, which fits <code>E</code> as a purely growing exponential function of <code>t</code>.
This function uses a very simple least-squares method to estimate <code>log.(E) ≈ γ * t + log(E₀)</code>.
It is up to the user to supply the time range over which the growth looks linear.</li>
<li><code>fit_complex_frequency(t, E)</code>, which fits an exponential with complex frequency <code>ω</code>.
The correct way to estimate a complex dispersion relation is by skimming just the peaks
of the trace on a log plot. Thus, this function is slightly more involved--it must first
find the "best" set of peaks, and then perform a linear fit of both growth rate and real
frequency.</li>
</ul>
