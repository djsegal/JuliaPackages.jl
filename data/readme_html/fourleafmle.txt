<p dir="auto">This Julia package implements statistical inference using maximum likelihood estimation (MLE) to
estimate a 4-leaf phylogenetic tree from DNA sequence data. The assumed model is the
Cavendar-Farris-Neyman (CFN) model from phylogenetics.</p>
<p dir="auto">Unlike other methods, the implementation in this package does not rely on a heuristic search to solve
the global optimization problem. Instead, the solution to the MLE problem is obtained through direct
computation of the critical points of the likelihood function using both analytical methods as well as
tools from numerical algebraic geometry.</p>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Background: tree topologies and the tree of life</h1><a id="user-content-background-tree-topologies-and-the-tree-of-life" class="anchor" aria-label="Permalink: Background: tree topologies and the tree of life" href="#background-tree-topologies-and-the-tree-of-life"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">One of the core motivations in evolutionary biology is to reconstruct
the <em>tree of life</em> that describes how species have evolved over time. A
common approach is to use DNA sequence alignment data from present-day
taxa to infer a <em>phylogenetic tree</em>, understood as a leaf-labelled tree
with edges representing ancestral populations, vertices representing
common ancestors, and leaves representing extant taxa. The edge weights,
or <em>branch lengths</em> represent some measure of evolutionary time (usually
expected number of mutations per site), and the tree <em>topology</em>
describes clade structure of the taxa. For instance,
<a href="#fig1">Figure 1</a> has four leaves that are labeled
in such a way to indicate species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$1$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$2$</math-renderer> have a more recent common
ancestor with one another than with species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$3$</math-renderer> or <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$4$</math-renderer>.</p>
<p dir="auto">A phylogenetic tree thus represents a hypothesis about the evolutionary
history of a set of taxa; the statistical inference problem is to infer
the tree topology and branch lengths from a DNA sequence of fixed
length. Our implementation solves polynomial systems to perform
this inference.</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Maximum likelihood estimation and quartet methods</h1><a id="user-content-maximum-likelihood-estimation-and-quartet-methods" class="anchor" aria-label="Permalink: Maximum likelihood estimation and quartet methods" href="#maximum-likelihood-estimation-and-quartet-methods"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A standard approach to inferring a phylogenetic tree is to use maximum
likelihood estimation. By summarizing data as a vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$(u_1,\dots,u_n)$</math-renderer>
of counts, the goal is to maximize the likelihood of the data. In other
words, we seek the value of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$\theta$</math-renderer> that maximizes
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$p_1^{u_1}\cdots p_n^{u_n}$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$p_i$</math-renderer> is the probability of observing
event <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$i$</math-renderer> and each <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$p_i$</math-renderer> depends on the parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$\theta$</math-renderer> of the
model. The maximum likelihood problem addressed in <code>fourLeafMLE</code>
involves estimating the branch lengths and unrooted tree topology of a
4-leaf tree from sequence data of a fixed length <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$k$</math-renderer> generated according
to the Cavendar-Farris-Neyman (CFN) model [12].</p>
<p dir="auto">Considerable research has focused on understanding the properties of
maximum likelihood estimation. Even in the simplest cases of 3- and
4-leaf trees, the problem exhibits substantial complexity, with a
general solution known for 3-leaf trees, but not 4-leaf trees
[1,4,6,7,8,9,11,16].
The <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$4$</math-renderer>-leaf case considered here is of special interest first due to
the popularity of quartet-based inference methods for inferring both
phylogenetic trees and networks [15], and second because it
is the simplest case in which the phenomenon of <em>long-branch attraction</em>
can be observed, a form of estimation bias which is only partially
understood [2,14].</p>
<p dir="auto">Two challenges in optimizing the likelihood function are its non-convex
nature and the presence of numerous boundary cases during optimization.
Moreover, there can be multiple distinct maximizers of the likelihood
function, and the maximizers can have branch lengths which are
infinitely long or zero [5,13]. This package resolves
these two obstacles for the CFN model by using computer algebra and the
theory of maximum likelihood (ML) degrees [10]. One feature
distinguishing this software is that it implements a framework to
characterize case when the tree estimates have infinite or zero-length
branches. We believe this is useful in obtaining an understanding of
the ways that maximum likelihood inference can fail, and as a first step
leads to <a href="#fig1">Figure 1</a>.</p>

custom tailored solver for algebraic statisticians. Given data in the
form of a site frequency vector, the main functionality is to return a
list of global maximizers of the likelihood function. The output
includes information about each of the maximizers, for example the tree
configuration and optimal branch lengths.</p>

<p dir="auto">For complete details on the code, see the code documentation provided here, but now we
give a broad overview about our software. The CFN model is a
parameterized semialgebraic set in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$\mathbb{R}^8$</math-renderer> with dimension <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$6$</math-renderer>. We
optimize the likelihood function by partitioning the semialgebraic set
according to boundaries from the parameterization, similiar to the
approach in [1] for a different model. There are <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cfc9723adc4d797f609659170af181e1">$10$</math-renderer>
different boundaries up to symmetry. All but one of them have ML degree
less than two. The last one has ML degree 92 while the main component of
the semialgebraic set has ML degree fourteen.<sup><a href="#user-content-fn-1-cfc9723adc4d797f609659170af181e1" id="user-content-fnref-1-cfc9723adc4d797f609659170af181e1" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup> We optimize the
likelihood function on each of the boundary cases by solving the
likelihood equations [10] by using analytic expressions when the
ML degree is less than two and
<code>Homotopy Continuation.jl</code> [@HomotopyContinuation.jl] to compute the
critical points otherwise.</p>

<p dir="auto">Note this will return a (harmless) deprecation warning about the use of <code>LU</code>. Most of the tests involve
generating random 4-leaf trees and then performing maximum likelihood estimation on each tree using the
model as data. When a test is passed, that means the randomly-generated trees were all (or almost all)
correctly estimated. Some of these tests will fail on occasion due to approximation errors in the
arithmetic. Additional commentary and details about failure rates and causes can be found in
