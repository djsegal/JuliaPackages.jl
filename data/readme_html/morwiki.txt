<ul dir="auto">
<li>
<p dir="auto">What triggers a download?</p>
<p dir="auto">A data set is downloaded when it is references via its <code>datadep""</code> identifier.
This happens only when calling <code>assemble(...)</code>;
creating <code>SteelProfile(1357)</code> or any other <code>MORWiki.Benchmark</code> does not download any data.</p>
</li>
<li>
<p dir="auto">Where are the data sets stored?</p>
<p dir="auto">This is handled purely by <a href="https://docs.juliahub.com/General/DataDeps/0.7.13/z10-for-end-users/" rel="nofollow">DataDeps.jl</a>.
As of version 0.7.13, data is by default stored at
<code>~/.julia/scratchspaces/124859b0-ceae-595e-8997-d05f6a7a8dfe/datadeps/</code>.
Please refer to <a href="https://docs.juliahub.com/General/DataDeps/0.7.13/z10-for-end-users/" rel="nofollow">DataDeps.jl</a>'s end-user documentation for further information.</p>
</li>
<li>
<p dir="auto">How are the data sets being stored?</p>
<p dir="auto">Currently, only <code>SteelProfile</code> is stored as plain MatrixMarket <code>.mtx</code> files.
All other data sets are stored as a single <code>.zip</code> archive containing several <code>.mtx</code> files.</p>
</li>
</ul>
