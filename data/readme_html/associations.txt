<p dir="auto">Associations.jl is a package for quantifying associations, independence testing and causal inference.</p>
<p dir="auto">All further information is provided in the
<a href="https://juliadynamics.github.io/Associations.jl/dev" rel="nofollow">documentation</a>, which you can either
find online or build locally by running the <code>docs/make.jl</code> file.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><strong>Association API</strong>: includes measures and their estimators for pairwise, conditional and other forms of
association from conventional statistics, from dynamical systems theory, and from information theory: partial correlation, distance correlation, (conditional) mutual information, transfer entropy, convergent cross mapping and a lot more!</li>
<li><strong>Independence testing API</strong>, which is automatically compatible with
every association measure estimator implemented in the package.</li>
<li><strong>Causal (network) inference API</strong> integrating the association measures and independence testing framework.</li>
</ul>

<p dir="auto">Extending on features from <a href="https://github.com/JuliaDynamics/ComplexityMeasures.jl">ComplexityMeasures.jl</a>,
we also offer</p>
<ul dir="auto">
<li>Discretization API for multiple (multivariate) input datasets.</li>
<li>Multivariate counting and probability estimation API.</li>
<li>Multivariate information measure API</li>
</ul>
