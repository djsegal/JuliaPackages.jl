<p dir="auto"><code>MetaCommunityMetrics</code> is a collection of tools and utilities for analyzing meta-communities in Julia. The current version is compatible with <code>julia</code> version 1.9.3.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">An Overview</h2><a id="user-content-an-overview" class="anchor" aria-label="Permalink: An Overview" href="#an-overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package is a comprehensive toolkit designed to characterize the spatiotemporal structure and dynamics of a metacommunity—a network of communities linked by the dispersal of multiple, interacting species, each with unique niche breadths. It includes functions to calculate a range of specific metrics, which have been previously implemented in R and proven valuable for metacommunity analysis.</p>
<p dir="auto">However, they come with high computational costs, especially for large species community datasets. To address this issue, MetaCommunityMetrics.jl was developed in Julia, a programming language known for its efficiency in handling computationally intensive tasks. This implementation significantly improves the efficiency of calculating these metrics, making it a powerful tool for metacommunity analysis.</p>
<p dir="auto">These metrics include:</p>
<ul dir="auto">
<li>Averaged beta diversity decomposition in space/time: total diversity, species replacement (turnover), and richness differences for both presence-absence and abundance data</li>
<li>Dispersal-niche continuum index to evaluate the degree to which communities are influenced by dispersal processes and niche breadth</li>
<li>Niche overlap indices to determine the extent of niche sharing among species within the metacommunity</li>
<li>The proportion of habitat patches occupied by each species</li>
<li>The variability of community composition across different spatial and temporal scales</li>
</ul>
