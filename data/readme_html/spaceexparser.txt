<p dir="auto">This package requires Julia v1.0 or later. Refer to the
<a href="https://julialang.org/downloads" rel="nofollow">official documentation</a> on how to install and
run Julia in your system.</p>
<p dir="auto">To install the package <code>SpaceExParser</code>, use the following command inside Julia's REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.clone(&quot;https://github.com/JuliaReach/SpaceExParser.jl&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">clone</span>(<span class="pl-s"><span class="pl-pds">"</span>https://github.com/JuliaReach/SpaceExParser.jl<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto"><em>Dependencies</em>. This package relies on the interfaces defined in <a href="https://github.com/blegat/HybridSystems.jl">HybridSystems.jl</a> and <a href="https://github.com/JuliaReach/MathematicalSystems.jl">MathematicalSystems.jl</a>. To handle XML files, we use <a href="https://github.com/bicycle1885/EzXML.jl">EzXML.jl</a>. Symbolic algebraic manipulations are performed with <a href="https://github.com/symengine/SymEngine.jl">SymEngine</a>.</p>
