<p dir="auto">Tests are run against the Solcast API, you will need a key to run them.
They are executed on <code>unmetered locations</code> and as such won't consume your credits.</p>
<p dir="auto">To run the tests, run Julia REPL inside the project repo:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project=."><pre class="notranslate"><code>julia --project=.
</code></pre></div>
<p dir="auto">Open package management mode using <code>]</code> and run the tests using <code>test</code> command inside the REPL Pkg prompt.</p>
