<p dir="auto">This package implements a tensor network based algorithm for simulating Rydberg atom dynamics.
It allows to simulate Analog Hamiltonian Simulation programs for problem sizes of hundreds of atoms, which is unaccessible by statevector simulation methods.
Matrix Product States (MPS) are used to represent the many-body quantum state.</p>
<p dir="auto">The core of the tensor network simulation is enabled by <a href="https://github.com/ITensor/ITensors.jl">iTensor.jl</a>. The input Analog Hamiltonian Simulation (AHS) program can be constructed using <a href="https://github.com/amazon-braket/Braket.jl">Braket.jl</a> interface.</p>

<p dir="auto">We use Time Evolving Block Decimation (TEBD) algorithm to compute state updates for each time step.
After each TEBD step the quantum state is truncated based on the SVD decomposition of the matrix product state.
The second order Suzuki-Trotter product formula is used for improved simulation accuracy.</p>
<p dir="auto">A step of TEBD evolution acting on a matrix product state is pictorially shown below.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="assets/tebd.png"><img src="assets/tebd.png" alt="Alt text" style="max-width: 100%;"></a></p>
<p dir="auto">Computational cost (for each evolution step): <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="02f0d87636a8ea3def9b93dc9e072377">$O(χ^3)$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="02f0d87636a8ea3def9b93dc9e072377">$χ$</math-renderer> is the current MPS bond dimension.
For the purpose of efficient MPS simulation we perform truncation of the van der Waals terms for distances exceeding a fixed <code>interation-radius</code> (supplied as an input argument).</p>

<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">The optional arguments are:</h4><a id="user-content-the-optional-arguments-are" class="anchor" aria-label="Permalink: The optional arguments are:" href="#the-optional-arguments-are"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>--experiment-path</code>: directory where all experiment results are saved (default is <code>examples/experiment_braket</code>).</li>
<li><code>--interaction-radius</code>: interaction radius [in meters], only interaction between atoms within the interaction radius are taken into account during MPS simulation (van der Waals tail is truncated for <code>Rij&gt;interaction_radius</code> resulting in <code>Vij=0</code>). The default value is <code>interaction-radius=7e-6</code>.</li>
<li><code>--cutoff</code>: SVD truncation cutoff parameter for each step of TEBD evolution. The default value is <code>cutoff=1e-7</code>.</li>
<li><code>--shots</code>: number of bitstring samples at final time step. Samples are saved in <code>&lt;experiment_path&gt;/samples.csv</code>. Default value is <code>shots=1000</code>.</li>
<li><code>--max-bond-dim</code>: maximum MPS bond dimension throughout TEBD evolution. In case if the bond dimension competes with <code>cutoff</code> parameter, the <code>max-bond-dim</code> takes priority - the MPS bond dimension can not grow beyond maximum value.</li>
<li><code>--tau</code>: Trotter time step [in seconds]. Default value is <code>tau=1e-8</code> (seconds).</li>
<li><code>--n-tau-steps</code>: total number of Trotter steps. The total evolution time is <code>tau*n-tau-steps</code>. Default value is <code>n-tau-steps=400</code>, corresponds to total evolution time <code>4 microseconds</code>.</li>
<li><code>--C6</code>: Rydberg interaction C6 constant, default value is <code>C6=5.42e-24</code> (CI units).</li>
<li><code>--compute-truncation-error</code>: computes MPS truncation error for each time step and saves truncation error evolution in <code>&lt;experiment_path&gt;/error_log.txt</code>. Use with CAUTION, since enabling this option dramatically slows down runtime (requires calculation of exact MPS evolution for each time step).</li>
<li><code>--compute-correlators</code>: compute <code>&lt;Z_i Z_j&gt;</code> correlators for all pairs of atoms at the end of the evolution.</li>
<li><code>--compute-energies</code>: compute energies from samples at the end of the evolution.</li>
<li><code>--generate-plots</code>: generate plots after experiment is finished</li>
</ul>

<p dir="auto">Output files from MPS simulaiton are stored in <code>&lt;experiment_path&gt;</code>:</p>
<ul dir="auto">
<li><code>ahs_program.json</code>: copy of the AHS program .json file.</li>
<li><code>atom_coordinates.csv</code>: Atom coordinates in 2D plane [in meters].</li>
<li><code>mps_density.csv</code>: evolution of <code>&lt;n_i&gt;(t)</code> for each atom as a function of time.</li>
<li><code>mps_samples.csv</code>: bitstring samples from MPS at <code>t=T</code>.</li>
<li><code>correlator_zz.csv</code>: ZZ correlation function at final time <code>t=T</code>: <code>&lt;Sz_i Sz_j&gt;</code>.</li>
<li><code>energies.csv</code>: final energies corresponding to the MPS samples at <code>t=T</code>.</li>
<li><code>summary.txt</code>: summary file with the experiment information (runtime, input args, etc.)</li>
</ul>
