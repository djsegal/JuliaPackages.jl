<p dir="auto">Wrapper of the library
<a href="https://github.com/mlabbe/nativefiledialog">mlabbe/nativefiledialog</a> for
opening native OS dialogues for selecting files (or Gtk for Linux/FreeBSD).
Inspired by <a href="https://discourse.julialang.org/t/file-choose-in-julia/69703" rel="nofollow">this discourse
post</a>.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Path selection</h3><a id="user-content-path-selection" class="anchor" aria-label="Permalink: Path selection" href="#path-selection"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>path</code> positional argument sets the directory in which the dialog will be
open, by default <code>path</code> is set to <code>""</code> and the default open point is operating
system dependent.</p>
<p dir="auto">The <code>path</code> argument accepts <code>AbstractPath</code>s from
<a href="https://github.com/rofinn/FilePathsBase.jl">FilePathsBase.jl</a>. When
a <code>&lt;:AbstractPath</code> has been passed it returns <code>nothing</code> on cancellations for
every one of the functions.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">File filter lists</h3><a id="user-content-file-filter-lists" class="anchor" aria-label="Permalink: File filter lists" href="#file-filter-lists"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>filterlist</code> keyword argument allows you to define multiple extension
filters for the dialogues. The syntax for doing this is <code>"ext1,ext2;ext3"</code>
where <code>ext1</code> and <code>ext2</code> are extensions of the first filter list and <code>ext3</code> is
an extension for the second one.</p>
<p dir="auto">Notice that multiple extensions for one list are separated by a comma (<code>,</code>),
while the different lists are separated by a semicolon (<code>;</code>).</p>
<p dir="auto">By default <code>filterlist</code> is set to <code>""</code> which means all kind of files are
accepted.</p>
