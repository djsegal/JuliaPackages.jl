<p dir="auto">Julia wrapper of the C++ implementation of the graph colouring algorithm
<a href="https://userweb.cs.txstate.edu/~burtscher/research/ECL-GC/" rel="nofollow">ECL-GC</a> with
shortcutting by M. Burtscher and his coworkers.</p>

<p dir="auto">The library has been thoroughly tested on various Linux machines.
The assumption is that <code>g++</code> is capable of compiling OpenMP programs.</p>
<p dir="auto">The library at the moment does not compile on Windows.</p>
<p dir="auto">The library compiles on the Mac using the homebrew <code>clang++</code> (18.1.5 should be good).</p>
