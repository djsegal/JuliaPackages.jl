<p dir="auto">BioDemultiplexer is a Julia package designed for demultiplexing reads based on barcodes. It efficiently classifies sequences from FASTQ files, making it a valuable tool in bioinformatics workflows.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The primary function of this package is <code>execute_demultiplexing()</code>. It classifies sequences in an R2 FASTQ file by calculating similarity scores from R1 sequences and barcodes in a reference file. Usage is as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="execute_demultiplexing(file_R1, file_R2, bc_file, output_dir)"><pre><span class="pl-c1">execute_demultiplexing</span>(file_R1, file_R2, bc_file, output_dir)</pre></div>
<p dir="auto"><strong>Arguments</strong></p>
<ul dir="auto">
<li><code>file_R1::String</code>: Path to the input R1 FASTQ file.</li>
<li><code>file_R2::String</code>: Path to the input R2 FASTQ file.</li>
<li><code>bc_file::String</code>: Path to the reference barcode file in TSV format.</li>
<li><code>output_dir::String</code>: Path to the directory where demultiplexed files will be saved.</li>
</ul>
<p dir="auto"><strong>Optional Arguments</strong></p>
<ul dir="auto">
<li><code>max_error_rate::Float64 = 0.22</code>: Maximum permissible error rate for sequence assignment.</li>
<li><code>min_delta::Float64 = 0.1</code>: Minimum difference between the highest and second-highest barcode similarity scores.</li>
<li><code>classify_both::Bool = false</code>: Set to true to classify both R1 and R2 sequences.</li>
<li><code>bc_rev::Bool = true</code>: Set to true to reverse the barcode for demultiplexing.</li>
</ul>
<p dir="auto">Demultiplexing can also be performed with a single FASTQ file:</p>
