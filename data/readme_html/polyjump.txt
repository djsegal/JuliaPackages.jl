<p dir="auto"><a href="https://github.com/jump-dev/PolyJuMP.jl">PolyJuMP.jl</a> is a <a href="https://github.com/jump-dev/JuMP.jl">JuMP</a>
extension for formulating and solving polynomial optimization problems.
This extension includes the following:</p>
<ul dir="auto">
<li>Polynomial functions on JuMP decisions variables. These can be solved with the <code>PolyJuMP.QCQP.Optimizer</code> or <code>PolyJuMP.KKT.Optimizer</code>.</li>
<li>Constraints that a polynomial is nonnegative where the coefficients of the polynomials depend on JuMP decision variables.
These nonnegativity constraints can be reformulated using sufficient conditions using <code>PolyJuMP.RelativeEntropy</code> submodule or <a href="https://github.com/jump-dev/SumOfSquares.jl">SumOfSquares.jl</a>.</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Polynomial nonnegativity constraints</h3><a id="user-content-polynomial-nonnegativity-constraints" class="anchor" aria-label="Permalink: Polynomial nonnegativity constraints" href="#polynomial-nonnegativity-constraints"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>PolyJuMP</code> allows encoding a constraint that a polynomial should be nonnegative for all values of some
symbolic variables defined with <code>DynamicPolynomials.@polyvar</code> or <code>TypedPolynomials.@polyvar</code> as follows.
For instance, the following constrains the JuMP decision variable <code>a</code> to be such that
<code>a * x * y^2 + y^3 - a * x</code> is nonnegative for all real values of <code>x</code> and <code>y</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DynamicPolynomials
@polyvar x y
using JuMP
model = Model()
@variable(model, a)
@constraint(model, a * x * y^2 + y^3 &gt;= a * x)"><pre><span class="pl-k">using</span> DynamicPolynomials
<span class="pl-c1">@polyvar</span> x y
<span class="pl-k">using</span> JuMP
model <span class="pl-k">=</span> <span class="pl-c1">Model</span>()
<span class="pl-c1">@variable</span>(model, a)
<span class="pl-c1">@constraint</span>(model, a <span class="pl-k">*</span> x <span class="pl-k">*</span> y<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">+</span> y<span class="pl-k">^</span><span class="pl-c1">3</span> <span class="pl-k">&gt;=</span> a <span class="pl-k">*</span> x)</pre></div>
<p dir="auto">Determining the nonnegativity of a multivariate polynomial is however NP-hard so sufficient conditions
are used instead.
You need to specify which sufficient condition is used explicitly.
To use Sum-of-Arithmetic-Geometric-Exponentials (SAGE), use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import PolyJuMP
PolyJuMP.setpolymodule!(model, PolyJuMP.SAGE)"><pre><span class="pl-k">import</span> PolyJuMP
PolyJuMP<span class="pl-k">.</span><span class="pl-c1">setpolymodule!</span>(model, PolyJuMP<span class="pl-k">.</span>SAGE)</pre></div>
<p dir="auto">To use Sum-of-Squares (SOS), use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import SumOfSquares
PolyJuMP.setpolymodule!(model, SumOfSquares)"><pre><span class="pl-k">import</span> SumOfSquares
PolyJuMP<span class="pl-k">.</span><span class="pl-c1">setpolymodule!</span>(model, SumOfSquares)</pre></div>
<p dir="auto">or replace <code>model = Model()</code> by <code>model = SOSModel()</code>.</p>
<p dir="auto">Alternatively, the nonnegativity constraint can be explicit:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@constraint(model, a * x * y^2 + y^3 - a * x in PolyJuMP.SAGE.Polynomials())
@constraint(model, a * x * y^2 + y^3 - a * x in SumOfSquares.SOSCone())"><pre><span class="pl-c1">@constraint</span>(model, a <span class="pl-k">*</span> x <span class="pl-k">*</span> y<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">+</span> y<span class="pl-k">^</span><span class="pl-c1">3</span> <span class="pl-k">-</span> a <span class="pl-k">*</span> x <span class="pl-k">in</span> PolyJuMP<span class="pl-k">.</span>SAGE<span class="pl-k">.</span><span class="pl-c1">Polynomials</span>())
<span class="pl-c1">@constraint</span>(model, a <span class="pl-k">*</span> x <span class="pl-k">*</span> y<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">+</span> y<span class="pl-k">^</span><span class="pl-c1">3</span> <span class="pl-k">-</span> a <span class="pl-k">*</span> x <span class="pl-k">in</span> SumOfSquares<span class="pl-k">.</span><span class="pl-c1">SOSCone</span>())</pre></div>
<p dir="auto">This allows mixing SAGE and SOS constraints in the same model.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Polynomial optimization</h3><a id="user-content-polynomial-optimization" class="anchor" aria-label="Permalink: Polynomial optimization" href="#polynomial-optimization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">PolyJuMP also allows solving polynomial optimization problems using the <code>QCQP</code> and <code>KKT</code> solvers.
Polynomial optimization problems do not involve any symbolic variables from DynamicPolynomials or TypedPolynomials,
instead all variables are JuMP decision variables.</p>
<p dir="auto">The <code>QCQP</code> solver is parametrized by a nonconvex QCQP inner solver.
It reformulates the polynomial optimization problem into a nonconvex <code>QCQP</code>
and relies on the inner solver to solve it.
For instance, to use the <code>QCQP</code> solver with JuMP with <code>Gurobi.Optimizer</code> as inner solver, use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP, PolyJuMP, Gurobi
model = Model(() -&gt; PolyJuMP.QCQP.Optimizer(Gurobi.Optimizer))"><pre><span class="pl-k">using</span> JuMP, PolyJuMP, Gurobi
model <span class="pl-k">=</span> <span class="pl-c1">Model</span>(() <span class="pl-k">-&gt;</span> PolyJuMP<span class="pl-k">.</span>QCQP<span class="pl-k">.</span><span class="pl-c1">Optimizer</span>(Gurobi<span class="pl-k">.</span>Optimizer))</pre></div>
<p dir="auto">The <code>KKT</code> solver is parametrized by an inner solver of algebraic systems of equations implementing the <a href="https://github.com/JuliaAlgebra/SemialgebraicSets.jl">SemialgebraicSets interface</a>.
It reformulates the polynomial optimization problem into a system of polynomial equations
and relies on the inner solver to solve it.
For instance, to use the <code>QCQP</code> solver with JuMP with
<code>HomotopyContinuation.SemialgebraicSetsHCSolver</code> as inner solver, use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP, PolyJuMP, HomotopyContinuation
model = Model(optimizer_with_attributes(
    PolyJuMP.KKT.Optimizer,
    &quot;solver&quot; =&gt; HomotopyContinuation.SemialgebraicSetsHCSolver(),
))"><pre><span class="pl-k">using</span> JuMP, PolyJuMP, HomotopyContinuation
model <span class="pl-k">=</span> <span class="pl-c1">Model</span>(<span class="pl-c1">optimizer_with_attributes</span>(
    PolyJuMP<span class="pl-k">.</span>KKT<span class="pl-k">.</span>Optimizer,
    <span class="pl-s"><span class="pl-pds">"</span>solver<span class="pl-pds">"</span></span> <span class="pl-k">=&gt;</span> HomotopyContinuation<span class="pl-k">.</span><span class="pl-c1">SemialgebraicSetsHCSolver</span>(),
))</pre></div>
