<br>
<p dir="auto">Flux3D.jl is a 3D vision library, written completely in Julia. This package utilizes <a href="https://github.com/FluxML/Flux.jl">Flux.jl</a> and <a href="https://github.com/FluxML/Zygote.jl">Zygote.jl</a> as its building blocks for training 3D vision models and for supporting differentiation. This package also have support of CUDA GPU acceleration with <a href="https://github.com/JuliaGPU/CUDA.jl">CUDA.jl</a>.The primary motivation for this library is to provide:</p>
<ul dir="auto">
<li>Batched Data structure for 3D data like PointCloud, TriMesh and VoxelGrid for storing and computation.</li>
<li>Transforms and general utilities for processing 3D structures.</li>
<li>Metrics for defining loss objectives and predefined 3D models.</li>
<li>Easy access to loading and pre-processing standard 3D datasets.</li>
<li>Visualization utilities for PointCloud, TriMesh and VoxelGrid.</li>
<li>Inter-Conversion between different 3D structures.</li>
</ul>
<p dir="auto">Any suggestions, issues and pull requests are most welcome.</p>
