<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Thermodynamic Integration</h2><a id="user-content-thermodynamic-integration" class="anchor" aria-label="Permalink: Thermodynamic Integration" href="#thermodynamic-integration"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="">Thermodynamic integration</a> is a technique from physics to get an accurate estimate of the log evidence.
By creating a schedule going from the prior to the posterior and estimating the log likelihood at each step one gets a stable ad robust estimate of the log evidence.
You can find a good reference for the method in the paper <a href="https://academic.oup.com/sysbio/article/55/2/195/1620800?login=true" rel="nofollow">"Computing Bayes Factors Using Thermodynamic Integration"</a>
Additionally I wrote a <a href="https://theogf.github.io/bayesiantribulations/blogposts/thermint/" rel="nofollow">short blog post</a> about it.</p>
<p dir="auto">For a different way of computing the evidence integral see also my <a href="https://github.com/theogf/BayesianQuadrature.jl">BayesianQuadrature package</a>.</p>

<p dir="auto">A simple package to compute Thermodynamic Integration for computing the evidence in a Bayesian setting.
You need to provide the <code>logprior</code> and the <code>loglikelihood</code> as well as an initial sample:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    using Distributions, ThermodynamicIntegration
    D = 5
    prior = MvNormal(Diagonal(0.5 * ones(D))) # The prior distribution
    likelihood = MvNormal(Diagonal(2.0 * ones(D)))
    logprior(x) = logpdf(prior, x) # The log-prior function
    loglikelihood(x) = logpdf(likelihood, x) # The log-likelihood function

    alg = ThermInt(n_samples=5000) # We are going to sample 5000 samples at every step

    logZ = alg(logprior, loglikelihood, rand(prior)) # Compute the log evidence
    # -8.244829688529377
    true_logZ = -0.5 * (logdet(cov(prior) + cov(likelihood)) + D * log(2π)) # we compare twith the true value

<p dir="auto">The algorithm also works on multiple threads by calling :</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    alg = ThermInt(n_samples=5000) 
    logZ = alg(logprior, loglikelihood, rand(prior), TIThreads())"><pre>    alg <span class="pl-k">=</span> <span class="pl-c1">ThermInt</span>(n_samples<span class="pl-k">=</span><span class="pl-c1">5000</span>)

<p dir="auto">or on multiple processes:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    alg = ThermInt(n_samples=5000) 
    logZ = alg(logprior, loglikelihood, rand(prior), TIDistributed())"><pre>    alg <span class="pl-k">=</span> <span class="pl-c1">ThermInt</span>(n_samples<span class="pl-k">=</span><span class="pl-c1">5000</span>)

<p dir="auto">Right now sampling is based on <a href="https://github.com/TuringLang/AdvancedHMC.jl"><code>AdvancedHMC.jl</code></a>, with the <a href="https://github.com/JuliaDiff/ForwardDiff.jl"><code>ForwardDiff.jl</code></a> AD backend.
To change the backend to <a href="https://github.com/FluxML/Zygote.jl"><code>Zygote</code></a> or <a href="https://github.com/JuliaDiff/ReverseDiff.jl"><code>ReverseDiff</code></a> (recommended for variables with large dimensions) you can do:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    using Zygote # (or ReverseDiff)
    ThermoDynamicIntegration.set_adbackend(:Zygote) # (or :ReverseDiff)"><pre>    <span class="pl-k">using</span> Zygote <span class="pl-c"><span class="pl-c">#</span> (or ReverseDiff)</span>
