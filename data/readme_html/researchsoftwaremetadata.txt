<p dir="auto"><strong>ResearchSoftwareMetadata</strong> is a <a href="http://www.julialang.org" rel="nofollow">Julia</a> package that
provides functionality for to allow a crosswalk between Project.toml, codemeta.json, .zenodo.json and the package LICENSE file to allow a consistent way of providing metadata for research software which allows the Julia General Registry to pick up the same metadata as GitHub and Zenodo while following the Research Software MetaData <a href="https://fair-impact.github.io/RSMD-guidelines/" rel="nofollow">guidelines</a>.</p>

<p dir="auto">First you need to add a small amount of additional metadata into your <code>Project.toml</code> file.</p>
<p dir="auto">To  capture the license you are using and propagate it throughout the metadata files and through your julia code, add an <a href="https://spdx.org/licenses/" rel="nofollow">SPDX license identifier</a> to the file:</p>
<div class="highlight highlight-source-toml notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="license = &quot;BSD-2-Clause&quot;"><pre><span class="pl-smi">license</span> = <span class="pl-s"><span class="pl-pds">"</span>BSD-2-Clause<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">To supplement the metadata on the authors of the package, add the <a href="https://orcid.org" rel="nofollow">ORCID</a> for each author and the <a href="https://ror.org" rel="nofollow">ROR</a> for the organisation(s) they are affiliated with. You can add as many authors and as much or as little information as you like about each one by adding additional <code>[[author_details]]</code> blocks.</p>
<div class="highlight highlight-source-toml notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="[[author_details]]
name = &quot;Richard Reeve&quot;
orcid = &quot;0000-0003-2589-8091&quot;

    [[author_details.affiliation]]
    ror = &quot;00vtgdb53&quot;"><pre>[[<span class="pl-en">author_details</span>]]
<span class="pl-smi">name</span> = <span class="pl-s"><span class="pl-pds">"</span>Richard Reeve<span class="pl-pds">"</span></span>
<span class="pl-smi">orcid</span> = <span class="pl-s"><span class="pl-pds">"</span>0000-0003-2589-8091<span class="pl-pds">"</span></span>

    [[<span class="pl-en">author_details</span>.<span class="pl-en">affiliation</span>]]
    <span class="pl-smi">ror</span> = <span class="pl-s"><span class="pl-pds">"</span>00vtgdb53<span class="pl-pds">"</span></span></pre></div>

<p dir="auto">If you want to add in some additional metadata (the <code>category</code> of the software, or the <code>keywords</code> associated with it, or you want to increase the package version during the crosswalk, this is possible as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Add in additional metadata

# Increase version number during crosswalk
ResearchSoftwareMetadata.increase_patch() # Bump patch version (e.g. 0.4.1 -&gt; 0.4.2)
ResearchSoftwareMetadata.increase_minor() # Bump minor version (e.g. 0.4.1 -&gt; 0.5.0)
ResearchSoftwareMetadata.increase_major() # Bump major version (e.g. 0.4.1 -&gt; 1.0.0)"><pre><span class="pl-c"><span class="pl-c">#</span> Add in additional metadata</span>
