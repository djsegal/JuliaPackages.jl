<p dir="auto">This is an alpha-quality implementation of a conversion from the JSON
cohort definitions used in the OHDSI ecosystem into an SQL transaction.</p>

<p dir="auto">This project has only implemented a subset of the OHDSI Circe format
which we are able to verify via the OHDSI PhentotypeLibrary. Other
permutations are left as an <code>assert</code> error. If you encounter one of
these, you could <a href="https://github.com/MechanicalRabbit/OHDSICohortExpressions.jl/issues/new?assignees=&amp;labels=Circe+Fields&amp;projects=&amp;template=implement-circe-query-permutation.md&amp;title=Implement+Circe+Parameter%3A+...">open</a> a gap issue. We've not implemented
these permutations since it's important to have a regression test,
therefore providing an example cohort definition and results is helpful.</p>

<p dir="auto">First, load or generate a cohort definition in OHDSI Circe format.
In this example, we load the cohort definition from <code>demo/ex-10-2.json</code>,
which corresponds to <a href="https://ohdsi.github.io/TheBookOfOhdsi/Cohorts.html#exr:exerciseCohortsSql" rel="nofollow">excercise 10.2</a> from the Book of OHDSI.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="cohort_definition = read(&quot;demo/ex-10-2.json&quot;, String)"><pre>cohort_definition <span class="pl-k">=</span> <span class="pl-c1">read</span>(<span class="pl-s"><span class="pl-pds">"</span>demo/ex-10-2.json<span class="pl-pds">"</span></span>, String)</pre></div>
<p dir="auto">Next, use <code>OHDSICohortExpressions.translate()</code> to convert this cohort
definition to a FunSQL query object.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OHDSICohortExpressions: translate

q = translate(cohort_definition, cohort_definition_id = 1)"><pre><span class="pl-k">using</span> OHDSICohortExpressions<span class="pl-k">:</span> translate

q <span class="pl-k">=</span> <span class="pl-c1">translate</span>(cohort_definition, cohort_definition_id <span class="pl-k">=</span> <span class="pl-c1">1</span>)</pre></div>
<p dir="auto">Run <code>DBInterface.connect()</code> to create a connection to an OMOP CDM database.
The arguments of <code>DBInterface.connect()</code> depend on the database engine and
connection parameters.  Consult FunSQL documentation for more information.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FunSQL, DBInterface

db = DBInterface.connect(FunSQL.SQLConnection{ … }, … )"><pre><span class="pl-k">using</span> FunSQL, DBInterface

db <span class="pl-k">=</span> DBInterface<span class="pl-k">.</span><span class="pl-c1">connect</span>(FunSQL<span class="pl-k">.</span>SQLConnection{ <span class="pl-k">…</span> }, <span class="pl-k">…</span> )</pre></div>
<p dir="auto">Execute the query to return the corresponding cohort.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DataFrames
