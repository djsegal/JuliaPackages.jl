<p dir="auto">Advanced optics/lenses and relevant tools, based on the <code>Accessors.jl</code> framework.</p>
<p dir="auto">The <a href="https://github.com/JuliaObjects/Accessors.jl">Accessors.jl</a> package defines a unified interface to modify immutable data structures — so-called optics or lenses. See its docs for details and background. <br>
<code>AccessorsExtra.jl</code> defines more optics and relevant tools that are too involved/opinionated/experimental to be included into a package as foundational as <code>Accessors</code> itself.</p>
<p dir="auto">Following <code>Accessors</code> itself, optics and operations in <code>AccessorsExtra</code> aim to have as little overhead as possible, often zero, with tests checking this.</p>
<p dir="auto">Some highlights:</p>
