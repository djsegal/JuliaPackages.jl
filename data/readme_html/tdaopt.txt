<p dir="auto"><code>TDAOpt.jl</code> is a Julia package to optimize statistical and topological loss functions defined on point-clouds and functions defined on fixed grids.</p>

<p dir="auto">There are 3 (and a haf) main functions exported by the current API.</p>
<ul dir="auto">
<li><code>dist()</code> : computes a distance between two point-clouds/measures</li>
<li><code>val()</code> : evaluates a loss functional on a source point-cloud/measure</li>
<li><code>backprop()</code> : performs minimization of loss functional starting from a source point-cloud/measure
<ul dir="auto">
<li><code>∇w</code> : computes the Wasserstein gradient of a loss functional (used in <code>backprop</code> when specified)</li>
</ul>
</li>
</ul>
<p dir="auto">These functions belong to the following parts of the current API:</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">§2.1 <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$-$</math-renderer> Discrepancies</h4><a id="user-content-21---discrepancies" class="anchor" aria-label="Permalink: §2.1 $-$ Discrepancies" href="#21---discrepancies"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A discrepancy is a <code>struct</code> which configures the parameters for measuring a distance between two input matrices (<code>x</code> and <code>y</code>), or two input measures (<code>μ</code> and <code>ν</code>). The ones currently implemented are:</p>
<ul dir="auto">
<li>Statistical (MMD, Sinkhorn)</li>
<li>Topological (Wasserstein Matching)</li>
</ul>
<p dir="auto">Every discrepancy should dispatch on (i.e. extend) the function <code>dist</code></p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">§2.2 <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$-$</math-renderer> Losses</h4><a id="user-content-22---losses" class="anchor" aria-label="Permalink: §2.2 $-$ Losses" href="#22---losses"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Losses are <code>structs</code> which define methods of computing loss functionals. The abstract supertype is <code>AbstractLossFunction</code>. Every loss is expected to extend the function <code>val</code> which takes in a <code>source</code> (i.e. matrix <code>x</code> or measure <code>μ</code>) and an <code>AbstractLossFunction</code>, and evaluates the loss functional <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$\ell(\texttt{source})$</math-renderer> to be minimized.</p>
<p dir="auto">Currently, the implemented <code>AbstractLossFunctions</code> fall into the following categories:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>StatLoss</code>: Fixes a reference discrepancy <code>d</code> and <code>target</code> (matrix or measure)</p>
<blockquote>
<p dir="auto"><code>val(source, Loss) = dist(Loss.d, source, Loss.target)</code></p>
</blockquote>
</li>
<li>
<p dir="auto"><code>TopLoss</code>: Fixes a reference discrepancy <code>d</code>, a persistence diagram constructor <code>dgmFun</code> and <code>target</code> (persistence diagram)</p>
<blockquote>
<p dir="auto"><code>val(source, Loss) = dist(Loss.d, Loss.dgmFun(source), Loss.target)</code></p>
</blockquote>
</li>
<li>
<p dir="auto"><code>BarycenterStatLoss</code>: Fixes a reference discrepancy <code>d</code> along with <code>targets</code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">${\nu_1, \nu_2 \dots \nu_M}$</math-renderer> and the <code>weights</code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">${\lambda_1, \lambda_2, \dots, \lambda_n}$</math-renderer></p>
<blockquote>
<p dir="auto"><code>val(source, Loss) = </code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$\sum\limits_{i=1}^{M}$</math-renderer> <code>weights[i] * dist(Loss.d, source, Loss.target)^2</code></p>
</blockquote>
</li>
<li>
<p dir="auto"><code>BarycenterTopLoss</code>: Fixes a reference discrepancy <code>d</code> along with <code>dgmFun</code>, the precomputed persistence diagram <code>targets</code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">${D_1, D_2 \dots D_M}$</math-renderer> and the <code>weights</code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">${\lambda_1, \lambda_2, \dots, \lambda_n}$</math-renderer></p>
<blockquote>
<p dir="auto"><code>val(source, Loss) = </code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$\sum\limits_{i=1}^{M}$</math-renderer> <code>weights[i] * dist(Loss.d, Loss.dgmFun(source), Loss.target)^2</code></p>
</blockquote>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">§2.2 <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="99b31be5a10f39f377bb38af89fc1193">$-$</math-renderer> Abstract Backprop</h4><a id="user-content-22---abstract-backprop" class="anchor" aria-label="Permalink: §2.2 $-$ Abstract Backprop" href="#22---abstract-backprop"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An <code>AbstractBackprop</code> object configures the parameters for performing backpropagation for a specified <code>AbstractLossFunction</code>. It dispatches different instances of the function <code>backprop</code>.</p>
<p dir="auto">The main difference between an <code>AbstractBackprop</code> and <code>AbstractGradflow</code> is how the gradients are computed. <code>AbstractBackprop</code> methods compute the usual gradients while <code>AbstractGradflow</code> computes the Wasserstein gradient (or using the JKO method).</p>
