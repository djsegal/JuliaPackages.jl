<p dir="auto">This provides a set of the financial holiday calendars that can be integrated with <a href="https://github.com/InfiniteChai/RDates.jl">RDates</a>, the relative date library. It is built to be easy to understand but heavily optimised for
integration with financial models.</p>

<p dir="auto"><code>HolidayCalendars</code> can be installed using the Julia package manager. From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add HolidayCalendars"><pre>pkg&gt; add HolidayCalendars</pre></div>

<p dir="auto">At this point you can now start using <code>HolidayCalendars</code> in your current Julia session using the following command</p>
