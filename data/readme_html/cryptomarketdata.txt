<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Goals</h2><a id="user-content-goals" class="anchor" aria-label="Permalink: Goals" href="#goals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol dir="auto">
<li><strong>Be able to save 1 minute candle data from a variety of cryptocurrency exchanges.</strong>
<ul dir="auto">
<li>I only want 1 minute candles, because I can derive higher timeframes myself.</li>
<li>Implement extremely minimal exchange drivers for this purpose.
<ul dir="auto">
<li>Don't try to do everything.</li>
<li>Focus on fetching 1 minute and 1 day candles well.</li>
</ul>
</li>
<li>Save all the candle data the exchange gives us.
<ul dir="auto">
<li>Save even the non-OHLCV data.</li>
<li>I don't care about it, but maybe someone else does.</li>
<li>Each day worth of 1 minute candles should be saved in its own date-stamped CSV file.</li>
</ul>
</li>
</ul>
</li>
<li><strong>After saving, be able to load that data into a DataFrame.</strong>
<ul dir="auto">
<li>1m candles are the default.</li>
<li>Other arbitrary timeframes should be supported.</li>
</ul>
</li>
</ol>
