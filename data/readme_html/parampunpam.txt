<p dir="auto">ParamPunPam.jl computes Groebner bases in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b976a9b96eb4a2cce42fff7331d72cab">$\mathbb{Q}(\mathbf{a})[\mathbf{x}]$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b976a9b96eb4a2cce42fff7331d72cab">$\mathbf{a}$</math-renderer> are treated as transcendental numbers.</p>
<p dir="auto">ParamPunPam.jl is primarily designed to work in cases when the coefficients of the basis are sparse and of low degree.</p>
<p dir="auto">You can install ParamPunPam.jl with the following command in Julia:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg; Pkg.add(&quot;ParamPunPam&quot;)"><pre><span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>ParamPunPam<span class="pl-pds">"</span></span>)</pre></div>

<p dir="auto">ParamPunPam.jl provides a single function: <code>paramgb</code>.
This function works in combination with polynomials from Nemo.jl.
See the following example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ParamPunPam, Nemo
