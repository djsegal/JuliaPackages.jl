<p dir="auto">A package to create and visualise 3D Skyrmions in the Skyrme model.</p>
<p dir="auto">A beginners tutorial written in Jupyter notebook can be downloaded from this repo.</p>
<p dir="auto">The documentation can currently be found <a href="http://solitonsatwork.net/chris/Skyrmions3D/" rel="nofollow">here</a>.</p>
