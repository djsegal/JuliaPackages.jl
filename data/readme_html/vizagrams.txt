<p dir="auto">Vizagrams is a visualization framework that integrates
<strong>diagramming</strong> and <strong>data visualization</strong>, with the goal
of providing high expressiveness with intuitive usability.</p>
<p dir="auto">The framework implements a diagramming DSL together
with a visualization grammar, thus allowing users to
create diagrams by combining and transforming plots,
as well as to create new visualization specifications using diagram construction
operations.</p>
<hr>

<p dir="auto">The moto for Vizagrams is "high expressiveness with intuitive usability."
In other words, the goal is for users to be able to produce (complex) visualizations without having to become
power-users or resorting to ad-hoc methods, where the complexity is hidden by several
lines of code.
To achieve this, Vizagrams uses a novel approach to data visualization construction,
which integrates graphic specification and diagramming.</p>
<p dir="auto">The framework implements a <em>diagramming DSL</em>, and builds a <em>visualization grammar</em> on top of it.
The idea of constructing data visualization tools on top of diagramming frameworks is not new<sup><a href="#user-content-fn-1-8139b55e01da9e459fb86ca566128e8b" id="user-content-fnref-1-8139b55e01da9e459fb86ca566128e8b" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.
What makes Vizagrams distinct is how it uses the concepts of
<em>graphical marks</em> and <em>graphic expressions</em><sup><a href="#user-content-fn-2-8139b55e01da9e459fb86ca566128e8b" id="user-content-fnref-2-8139b55e01da9e459fb86ca566128e8b" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup> to
blur the distinction between data visualization and diagramming.
This allows users to produce plots and manipulate
them using diagramming operations such as composition, translation, rotation, style transformations,
and so on.</p>
<p dir="auto">One of the core assumptions of Vizagrams is that once users understand the basics of the framework,
the task of creating new visualizations becomes similar to diagramming, hence the "intuitive usability."
In terms of "expressiveness," we let the gallery of examples speak for itself.</p>

<p dir="auto">Here is a summary of the features provided by Vizagrams:</p>
<ul dir="auto">
<li>Diagramming DSL inspired by the Haskell library <a href="https://archives.haskell.org/projects.haskell.org/diagrams/" rel="nofollow">Diagrams</a>;</li>
<li>Visualization grammar with syntax similar to <a href="https://vega.github.io/vega-lite/" rel="nofollow">Vega-Lite</a>;</li>
<li>Ability to define custom graphical marks;</li>
<li>Use graphic expressions to create new data visualization specifications;</li>
<li>Manipulate and combine plots using diagramming operations;</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Related Packages in the Julia Ecosystem</h2><a id="user-content-related-packages-in-the-julia-ecosystem" class="anchor" aria-label="Permalink: Related Packages in the Julia Ecosystem" href="#related-packages-in-the-julia-ecosystem"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><strong>Compose.jl</strong> - A vector graphics library for Julia, that can be used for diagram drawing. Similar to Vizagrams, it is also inspired by the Haskell library Diagrams.</li>
<li><strong>Gadfly.jl</strong> - A data visualization package based largely on Hadley Wickhams's <code>ggplot2</code>. It has been developed for many years, thus, it is a good choice for those who want a robust data visualization package with a visualization grammar implementation.</li>
<li><strong>Luxor.jl</strong> - Package for drawing simple static 2D vector graphics. The focus of Luxor is on simplicity and ease of use.</li>
<li><strong>Thebes.jl</strong> - A little extension package for the package Luxor.jl that provides some rudimentary 3D (2.5D?) wireframe functionality.</li>
<li><strong>Javis.jl</strong> - A tool focused on providing an easy to use interface for making animations and developing visualizations quickly.</li>
<li><strong>Makie.jl</strong> - Implements an interactive plotting ecosystem. Similar to Python's Matplotlib, it does not implement a visualization grammar, instead, users can pick from a collection of charts and arrange them using layouts and other customization options.</li>
<li><strong>AlgebraOfGraphics.jl</strong> - Defines an algebra of graphics where plot specifications are constructed by combining layers using <code>+</code> and <code>*</code> operations. Visualizations are powered by Makie.</li>
<li><strong>Plots.jl</strong> - A visualization interface and toolset. It does not implement a visualization grammar, instead relying on the concept of plot attributes as the building block of plot specifications.</li>
