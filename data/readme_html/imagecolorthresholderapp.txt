<p dir="auto"><strong>ImageColorThresholderApp</strong> is a GUI application powered by <a href="https://github.com/MakieOrg/Makie.jl">Makie.jl</a>, Inspired by MATLAB <a href="https://www.mathworks.com/help/images/ref/colorthresholder-app.html" rel="nofollow">Color Thresholder</a> app.</p>
<p dir="auto">ImageColorThresholderApp is a GUI tool for segmenting color images. By using it threshold individual color channels or combinations of channels in different color spaces, such as RGB, HSV, Lab and YCbCr. This app generates binary segmentation mask and thresholded image for color images.</p>
<p dir="auto">Here are features of ImageColorThresholderApp:</p>
<ul dir="auto">
<li>Threshold individual color channels or combinations of channels in different color spaces (RGB, HSV, Lab, YCbCr, etc.).</li>
<li>Adjust the threshold levels interactively.</li>
<li>Preview the thresholded image in real time.</li>
<li>Generate julia code to work space as well as external file.</li>
<li>Generate thresholded images and segmentation masks.</li>
</ul>
<p dir="auto">ImageColorThresholderApp needs one of <a href="https://docs.makie.org/dev/explanations/backends/" rel="nofollow">Makie backend</a>.</p>
<ul dir="auto">
<li>Using GLMakie it opens app window.</li>
<li>using WGLMakie It integrate with <a href="https://github.com/fonsp/Pluto.jl">Pluto.jl</a> notebook.</li>
</ul>
