<p dir="auto">This is the repository of the CliMA land model code. Here are some notable features:</p>
<ul dir="auto">
<li>ClimaLand has a modular design, models can be run as standalone (e.g., soil moisture only) or integrated (e.g., soil moisture and energy AND canopy AND snow, etc.)</li>
<li>ClimaLand can simulate single columns, regional boxes, and global runs</li>
<li>ClimaLand is CPU and GPU compatible</li>
<li>ClimaLand welcome contributions: please feel free to reach out to us with questions about how to get started, create a branch, and extend our code. For example, a modeler might want to test a new stomatal conductance model.</li>
<li>ClimaLand provides APIs and UIs at multiple levels.</li>
</ul>

<p dir="auto">In our code base, a "model" define a set of prognostic variables which must be timestepped. The equations which govern the time evolution likely contain parameters and are informed by parameterization and physical domain choices. Any ClimaLand model contains all of the information needed to evaluate these equations. Below are the current models we support:</p>
<p dir="auto"><strong> Component Models: </strong></p>
<ul dir="auto">
<li>
<p dir="auto">RichardsModel &lt;: AbstractSoilModel &lt;: AbstractModel (runnable only in standalone mode)</p>
</li>
<li>
<p dir="auto">EnergyHydrologyModel &lt;: AbstractSoilModel &lt;: AbstractModel (runnable in standalone mode, or as part of a land model)</p>
</li>
<li>
<p dir="auto">CanopyModel &lt;: AbstractVegetationModel &lt;: AbstractModel  (runnable in standalone mode, or as part of a land model)</p>
</li>
<li>
<p dir="auto">SnowModel &lt;: AbstractSnowModel &lt;: AbstractModel (runnable in standalone mode, or as part of a land model)</p>
</li>
</ul>
<p dir="auto"><strong> Combined Models: </strong></p>
<ul dir="auto">
<li>SoilCanopyModel &lt;: AbstractLandModel &lt;: AbstractModel (an example of a land model, made of individual component models which are solved simultaneously but taking into account interactions between the components)</li>
</ul>

<p dir="auto">Recommended Julia Version: Stable release v1.10.0. CI no longer tests earlier
versions of Julia.</p>
<p dir="auto">ClimaLand.jl is a different model from the original CliMA Land,
which aims to utilize remote sensing data through more complex canopy RT
and plant physiology modules. For more details, please refer to
<a href="https://github.com/CliMA/Land">https://github.com/CliMA/Land</a>.</p>
