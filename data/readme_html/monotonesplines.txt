<p dir="auto"><em>MonotoneSplines.jl</em> is a Julia package for monotone splines, which impose a monotonicity constraint on the smoothing splines.</p>
<p dir="auto">Check the following paper for more details.</p>
<blockquote>
<p dir="auto">Lijun Wang, Xiaodan Fan, Huabai Li, and Jun S. Liu. “Monotone Cubic B-Splines with a Neural-Network Generator.” arXiv, November 17, 2023. <a href="https://doi.org/10.48550/arXiv.2307.01748" rel="nofollow">https://doi.org/10.48550/arXiv.2307.01748</a>.</p>
</blockquote>

<p dir="auto"><g-emoji class="g-emoji" alias="bangbang">‼️</g-emoji><g-emoji class="g-emoji" alias="bangbang">‼️</g-emoji> <strong>R is required, but Python is optional.</strong> <g-emoji class="g-emoji" alias="bangbang">‼️</g-emoji><g-emoji class="g-emoji" alias="bangbang">‼️</g-emoji></p>
<p dir="auto">The package offers two deep-learning backends for the Multi-Layer Perceptrons (MLP) generator:</p>
<ul dir="auto">
<li><a href="https://github.com/FluxML/Flux.jl">Flux</a>: pure Julia</li>
<li>PyTorch: Call Python via <a href="https://github.com/JuliaPy/PyCall.jl">PyCall.jl</a></li>
</ul>
<p dir="auto">The statistical software R has offered several powerful packages on splines, such as <code>splines</code> and <code>fda</code>. We do not reinvent the wheel. Instead, we stand on the shoulders of the R giant by calling several basic core functions with the help of <a href="https://github.com/JuliaInterop/RCall.jl">RCall.jl</a>.</p>
