<p dir="auto">EnergyModelsGUI enables a graphical user interface for the <a href="https://github.com/EnergyModelsX/EnergyModelsBase.jl">EnergyModelsBase</a> package and other packages building upon this package (like <a href="https://github.com/EnergyModelsX/EnergyModelsInvestments.jl">EnergyModelsInvestments</a> and <a href="https://github.com/EnergyModelsX/EnergyModelsGeography.jl">EnergyModelsGeography</a>).
It is designed to give a simple visualization of the topology of the model and enable the user to interactively navigate through the different layers of the model design.
Visualization of the results after simulations will be added at a later stage.</p>
<p dir="auto">The EnergyModelsGUI package has taken inspiration from the source code of <a href="https://github.com/bradcarman/ModelingToolkitDesigner.jl">ModelingToolkitDesigner</a> as a starting point for development.</p>
