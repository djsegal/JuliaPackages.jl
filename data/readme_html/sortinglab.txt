<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">SortingLab</h1><a id="user-content-sortinglab" class="anchor" aria-label="Permalink: SortingLab" href="#sortinglab"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An alternative implementation of sorting algorithms and APIs. The ultimate aim is to contribute back to Julia base or SortingAlgorithms.jl. However, there is commitment to keep this package's API stable and supported, so other developers can rely on the implementation and API here.</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Faster Sort and Sortperm</h1><a id="user-content-faster-sort-and-sortperm" class="anchor" aria-label="Permalink: Faster Sort and Sortperm" href="#faster-sort-and-sortperm"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The main function exported by SortingLab is <code>fsort</code> and <code>fsortperm</code> which generally implements faster algorithms than <code>sort</code> and <code>sortperm</code> for <code>CategoricalArrays.CategoricalVector</code>, <code>Vector{T}</code>,  <code>Vector{Union{T, Missing}}</code> where <code>T</code> is</p>
<ul dir="auto">
<li>Int*, UInt*, Float*, String</li>
</ul>
<p dir="auto"><strong>Note</strong>: The reason why we restrict the type to <code>Vector</code> is that SortingLab.jl assumes something about memory layout and hence <code>Vector</code> provides that guarantee in the types supported.</p>

<p dir="auto">For vectors that contain <code>missing</code>, the <code>sort</code> and <code>sortperm</code> performance is often sub-optimal in <code>Base</code> and is not supported in <code>SortingAlgorithms.jl</code>'s radixsort implementation. This is solved by <code>SortingLab.jl</code> <code>fsort</code>, see Benchmarks Section</p>
