<p dir="auto"><code>FishTank.jl</code> creates an e-fish for you in case you feel lonely when you are coding 🐟. The game is visualized using <a href="https://github.com/JuliaPlots/PlotlyJS.jl"><code>PlotlyJS.jl</code></a> and <a href="https://github.com/akjake616/PlotlyGeometries.jl"><code>PlotlyGeometries.jl</code></a>.</p>

</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><strong>Customized Fish Tank</strong>: Set up your unique fish tank environment 💥</li>
<li><strong>Interactive Fish Feeding</strong>: Add fish feed and wait for your fish to eat them up <g-emoji class="g-emoji" alias="diamonds">♦️</g-emoji></li>
<li><strong>Realistic Fish Behavior</strong>: Fish can sleep occasionally, mimicking natural behavior 💤</li>
<li><strong>Decorate with Water Plants</strong>: Enhance the tank with water plants for a more vibrant look 🌱</li>
<li><strong>Random Landscape</strong>: Landscape created with a random Gaussian surface (using <a href="https://github.com/JuliaMath/FFTW.jl"><code>FFTW.jl</code></a> under GPL license ❗)</li>
</ul>

<p dir="auto">In order to start a fish tank, you simply need to use the package and call the <code>init()</code> function.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FishTank
init() # creates a random colored fish by default."><pre><span class="pl-k">using</span> FishTank
<span class="pl-c1">init</span>() <span class="pl-c"><span class="pl-c">#</span> creates a random colored fish by default.</span></pre></div>
<p dir="auto">To feed the fish with, for example, six grains, call the following:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="feed(6) # add 6 grains to the fish tank, if the input is not specified, 10 grains are added"><pre><span class="pl-c1">feed</span>(<span class="pl-c1">6</span>) <span class="pl-c"><span class="pl-c">#</span> add 6 grains to the fish tank, if the input is not specified, 10 grains are added</span></pre></div>
<p dir="auto">To decorate the fish tank with waterweed:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="plant() # randomly plant one waterweed bunble"><pre><span class="pl-c1">plant</span>() <span class="pl-c"><span class="pl-c">#</span> randomly plant one waterweed bunble</span></pre></div>
<p dir="auto">You can also set the az/el view angle by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="look(0, 10) # az = 0 deg, el = 10 deg"><pre><span class="pl-c1">look</span>(<span class="pl-c1">0</span>, <span class="pl-c1">10</span>) <span class="pl-c"><span class="pl-c">#</span> az = 0 deg, el = 10 deg</span></pre></div>
<p dir="auto">or even do some animations:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@async for n in 1:360

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">APIs</h2><a id="user-content-apis" class="anchor" aria-label="Permalink: APIs" href="#apis"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The following APIs are used to interact with the fish.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="init(color::String)"><pre><span class="pl-c1">init</span>(color<span class="pl-k">::</span><span class="pl-c1">String</span>)</pre></div>
<p dir="auto">Initialization of the fish and tank. The fish is specified with the color=<code>color</code>. If <code>color</code> is not specified, the color of the fish is set to be random. Currently only one fish tank can be initialized per process.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pause()"><pre><span class="pl-c1">pause</span>()</pre></div>
<p dir="auto">Pause simulation. If you want to rotate the tank (for a different view), one should pause the simulation first. I have no better solution for this (rotating the plot and continuing the simulation at the same time), so feel free to contribute if you know how to solve this issue 😘</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="go()"><pre><span class="pl-c1">go</span>()</pre></div>
<p dir="auto">Continue simulation.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mute()"><pre><span class="pl-c1">mute</span>()</pre></div>
<p dir="auto">Turn off sound effects. The default is on.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="unmute()"><pre><span class="pl-c1">unmute</span>()</pre></div>
<p dir="auto">Turn on sound effects.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="feed(n::Int=10)"><pre><span class="pl-c1">feed</span>(n<span class="pl-k">::</span><span class="pl-c1">Int</span><span class="pl-k">=</span><span class="pl-c1">10</span>)</pre></div>
<p dir="auto">Add <code>n</code> grains (add 10 if <code>n</code> not specified).</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="check()"><pre><span class="pl-c1">check</span>()</pre></div>
<p dir="auto">Check the number of grains.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="plant()"><pre><span class="pl-c1">plant</span>()</pre></div>
<p dir="auto">Plant waterweed.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="replot()"><pre><span class="pl-c1">replot</span>()</pre></div>
<p dir="auto">Replot the fish tank window (if it is accidentally closed).</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="look(az::Real, el::Real)"><pre><span class="pl-c1">look</span>(az<span class="pl-k">::</span><span class="pl-c1">Real</span>, el<span class="pl-k">::</span><span class="pl-c1">Real</span>)</pre></div>
<p dir="auto">Set the <a href="https://matplotlib.org/stable/api/toolkits/mplot3d/view_angles.html" rel="nofollow">az/el view angle</a>.  A word on the view: currently in order to solve memory usage issues, I have to purge the plot every period of time, and this resets the view angle if you rotates the plot by <code>pause() -&gt; iteractive rtation -&gt; go()</code>. It is better to set the default view angle by this function. Think of <code>pause()</code> and <code>go()</code> as some debug functionalities please 😆</p>
