<p dir="auto"><code>LanguageIdentification.jl</code> is a Julia package for identifying the language of a given text. It currently supports <code>50</code> languages (see below). This package is lightweight and has no dependencies.</p>

<ul dir="auto">
<li><code>langid</code>: returns the language code of the tested text.</li>
<li><code>langprob</code>: returns the probabilities of the tested text for each language.</li>
</ul>

<p dir="auto">We tested four language identification packages: <code>LanguageIdentification.jl</code> (this package), <a href="https://github.com/JuliaText/Languages.jl"><code>Languages.jl</code></a>, <a href="https://github.com/SeanLee97/LanguageDetect.jl"><code>LanguageDetect.jl</code></a>, and <a href="https://github.com/nusretipek/LanguageFinder"><code>LanguageFinder</code></a> on a hold-out test set. The test set was sourced from <a href="https://tatoeba.org" rel="nofollow"><code>tatoeba</code></a> and <a href="https://www.wikipedia.org/" rel="nofollow"><code>wikipedia</code></a> and comprised of the 50 languages supported by this package. The complete test results can be found <a href="https://github.com/guo-yong-zhi/langid_expirement/blob/main/benchmarks/compare/compare.md">here</a>.</p>

<p dir="auto">You can manually initialize the package using the <code>LanguageIdentification.initialize</code> function. By adjusting the parameters, you can achieve different balances between accuracy, speed, and memory usage. The default setting is <code>ngram=1:4</code>, <code>cutoff=0.85</code>, and <code>vocabulary=1000:5000</code>. However, this setting may not be optimal for your specific use case.<br>
For example, the table below shows that using a single-ngram setting of <code>ngram=4</code>, <code>cutoff=1.0</code>, and <code>vocabulary=5000</code> can achieve better accuracy on our tatoeba test set while also being much faster than the multi-ngrams setting. We choose the multi-ngrams as the default due to its stability. You can refer to our detailed benchmark results <a href="https://github.com/guo-yong-zhi/langid_expirement/tree/main/benchmarks/matrix">here</a> as a reference for parameter tuning.</p>
