<p dir="auto">CodecInflate64 implements deflate64 decompression for the <a href="https://github.com/JuliaIO/TranscodingStreams.jl">TranscodingStream.jl</a> interface.</p>
<p dir="auto">This package aims to read entries of ZIP files created by the default Windows File Explorer.</p>
<p dir="auto">Deflate64 is an incompatible variant of deflate that Windows File Explorer sometimes uses when making ZIP files.</p>
<p dir="auto">The deflate algorithm is described in <a href="https://www.ietf.org/rfc/rfc1951.txt" rel="nofollow">RFC 1951</a>.</p>
<p dir="auto">Deflate64 has a reference implementation in <a href="https://github.com/dotnet/runtime/tree/e5efd8010e19593298dc2c3ee15106d5aec5a924/src/libraries/System.IO.Compression/src/System/IO/Compression/DeflateManaged">dotnet</a></p>
<p dir="auto">It is also described unofficially in <a href="https://libzip.org/specifications/appnote_iz.txt" rel="nofollow">https://libzip.org/specifications/appnote_iz.txt</a></p>
<p dir="auto">Some of the code from <a href="https://github.com/GunnarFarneback/Inflate.jl">Inflate.jl</a> is used here, but modified to work with deflate64.</p>
