<p dir="auto"><a href="https://www.sympy.org/" rel="nofollow">SymPy</a> is a Python library for symbolic mathematics.</p>
<p dir="auto">At present, there are two means to call <code>Python</code> code from <code>Julia</code>. As such, two packages have been developed to call into SymPy:</p>
<ul dir="auto">
<li>
<p dir="auto"><a href="https://github.com/JuliaPy/SymPy.jl">SymPy.jl</a> is a long-standing <code>Julia</code> package using <code>PyCall.jl</code> to provide a "<code>Julia</code>n" interface to SymPy.</p>
</li>
<li>
<p dir="auto"><a href="https://github.com/jverzani/SymPyPythonCall.jl">SymPyPythonCall.jl</a> is a <code>Julia</code> package using <code>PythonCall.jl</code> to provide a "<code>Julia</code>n" interface to SymPy providing a nearly identical experience as <code>SymPy.jl</code>.</p>
</li>
</ul>
<p dir="auto">The <code>SymPyCore</code> package aims to unify the underlying code, leaving only a small amount of glue code in the primary packages. As of version <code>0.2</code> of <code>SymPyPythonCall.jl</code>  and version <code>2.0</code> of <code>SymPy</code> the <code>SymPyCore</code> package is used.</p>
<p dir="auto">To use <code>SymPyCore</code> you should install one of the two primary packages, and load that into a session. Installation of either <code>SymPyPythonCall</code> or <code>SymPy</code> should install the core package, the glue package, and arrange for the underlying sympy library of Python to be installed.</p>
