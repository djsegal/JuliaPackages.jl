<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">General information</h2><a id="user-content-general-information" class="anchor" aria-label="Permalink: General information" href="#general-information"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>CorrelationFunctions.jl</code> is a library to compute all classical correlation
functions from 2D and 3D images.</p>
<p dir="auto">Currently, we provide functions to compute:</p>
<ol dir="auto">
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$S_2$</math-renderer> (two-point probability)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$L_2$</math-renderer> (lineal path function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$C_2$</math-renderer> (cluster function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$F_{ss}$</math-renderer> (surface-surface function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$F_{sv}$</math-renderer> (surface-void function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$P$</math-renderer> (pore-size function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$p$</math-renderer> (chord length function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$\rho$</math-renderer> (phase cross-correlation function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$F_{sss}$</math-renderer> (surface-surface-surface function)</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$F_{svv}$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="791e2155def60dcf73408aa4d37dac76">$F_{ssv}$</math-renderer>, … (other three-point surface-void functions)</li>
</ol>
<p dir="auto">Some additional three-point or non-classical CFs currently under
development. The general scheme of computations for all major functions is shown
in figure below:
<a target="_blank" rel="noopener noreferrer" href="docs/cf_1.png"><img src="docs/cf_1.png" alt="" style="max-width: 100%;"></a></p>
<p dir="auto">Salvatore Torquato's book
<a href="https://link.springer.com/book/10.1007/978-1-4757-6355-3" rel="nofollow">"Random Heterogeneous Materials"</a>
provides a comprehensive theoretical summary on all classical CFs.</p>

<p dir="auto">The package is available through Julia's Pkg ecosystem.
For example, from Julia REPL: <code>import Pkg; Pkg.add("CorrelationFunctions")</code></p>

<p dir="auto">All functions are described in the documentation, you can also get help on each
function in the REPL (using <code>?</code>). The documentation for the most recent release
is available here on
<a href="https://fatimp.github.io/CorrelationFunctions.jl/stable/index.html" rel="nofollow">GitHub Pages</a>.</p>
<p dir="auto">Alternatively, to build a documentation locally do the following:</p>
<ol dir="auto">
<li>From Julia REPL: <code>import Pkg; Pkg.add("Documenter")</code></li>
<li>From shell, this directory being the working directory: <code>cd docs &amp;&amp; julia make.jl</code></li>
</ol>

<p dir="auto">The functionality of the package is described in following scientific papers,
please, support us by citations if you find our code useful:</p>
<ol dir="auto">
<li>The main paper describing the package and its CPU and GPU implementations for
all classical CFs <a href="https://www.sciencedirect.com/science/article/abs/pii/S0010465524000572" rel="nofollow">Postnicov, V., Samarin, A., Karsanina, M. V., Gravey M.,
Khlyupin, A. &amp; Gerke, K. M. (2023). Evaluation of classical correlation
functions from 2/3D images on CPU and GPU architectures: introducing
CorrelationFunctions.jl. Computer Physics Communications, 299,
109134.</a></li>
<li>The digital approach to compute 2-point surface functions; also this paper
introduces the C0.5 criterion (the package contains the function to evaluate it
for input images) to judge the quality of the image to access such CFs
<a href="https://journals.aps.org/pre/abstract/10.1103/PhysRevE.107.065306" rel="nofollow">Samarin, A., Postnicov, V., Karsanina, M. V., Lavrukhin, E. V., Gafurova, D.,
Evstigneev, N. M., Khlyupin, A. &amp; Gerke, K. M. (2023). Robust
surface-correlation-function evaluation from experimental discrete digital
images. Physical Review E, 107(6),
065306.</a></li>
<li>The truly exact approach to compute 2- and 3-point correlation functions on
smooth boundary sets, improved edge filter, computation of 3-point surface
functions for digital images
<a href="https://www.sciencedirect.com/science/article/abs/pii/S0378437123006921" rel="nofollow">Postnicov, V., Karsanina, M. V., Khlyupin, A., &amp; Gerke, K. M. (2023). The 2-and
3-point surface correlation functions calculations: From novel exact continuous
approach to improving methodology for discrete images. Physica A: Statistical
Mechanics and its Applications, 628,
129137.</a></li>
<li>Evaluation of 3-point correlation functions from structural images on CPU and GPU
architectures: accounting for anisotropy effects [Postnicov, V., Karsanina, M.V.,
Khlyupin, A., Gerke, K.M. (2024) in revision with Physical Review E.]</li>
</ol>
