<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is a Tensor Train?</h2><a id="user-content-what-is-a-tensor-train" class="anchor" aria-label="Permalink: What is a Tensor Train?" href="#what-is-a-tensor-train"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <a href="https://tensornetwork.org/mps/" rel="nofollow">Tensor Train</a> is a type of tensor factorization involving the product of 3-index tensors organized on a one-dimensional chain.
In the context of function approximation and probability, a function of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$L$</math-renderer> discrete variables is in Tensor Train format if it is written as</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$$f(x^1, x^2, \ldots, x^L) = \sum_{a^1,a^2,\ldots,a^{L-1}} [A^1(x^1)]_{a^1}[A^2(x^2)]_{a^1,a^2}\cdots [A^{L-1}(x^{L-1})]_{a^{L-2},a^{L-1}}[A^L(x^L)]_{a^{L-1}}$$</math-renderer>
<p dir="auto">where, for every choice of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$x^l$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$A^l(x^l)$</math-renderer> is a real-valued matrix and the matrix sizes must be compatible.
The first matrix must have 1 row and the last matrix should have 1 column, such that the product correctly returns a scalar.</p>
<p dir="auto">The Tensor Train factorization can be used to parametrize probability distributions, which is the main focus of this package. In this case, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$f$</math-renderer> should be properly normalized and always return a non-negative value.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Tensor Trains with Periodic Boundary Conditions</h3><a id="user-content-tensor-trains-with-periodic-boundary-conditions" class="anchor" aria-label="Permalink: Tensor Trains with Periodic Boundary Conditions" href="#tensor-trains-with-periodic-boundary-conditions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A slight generalization, useful to describe systems with periodic boundary conditions is the following:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$$f(x^1, x^2, \ldots, x^L) = \sum_{a^1,a^2,\ldots,a^{L}} [A^1(x^1)]_{a^1,a^2}[A^2(x^2)]_{a^2,a^3}\cdots [A^{L-1}(x^{L-1})]_{a^{L-1},a^{L}}[A^L(x^L)]_{a^{L},a^1}$$</math-renderer>
<p dir="auto">In other words, to evaluate <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$f$</math-renderer> one takes the trace of the product of matrices.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Notation and terminology</h2><a id="user-content-notation-and-terminology" class="anchor" aria-label="Permalink: Notation and terminology" href="#notation-and-terminology"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Tensor Trains are the most basic type of <a href="https://tensornetwork.org/" rel="nofollow">Tensor Network</a>. Tensor networks are a large family of tensor factorizations which are often best represented in diagrammatic notation. For this reason, the term <em>bond</em> is used interchangeably as <em>index</em>. The indices <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$a^1,a^2,\ldots,a^{L-1}$</math-renderer> are usually called the <em>virtual indices</em>, while <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$x^1, x^2, \ldots, x^L$</math-renderer> are the <em>physical indices</em>.</p>
<p dir="auto">Tensor Trains are used to parametrize wavefunctions in many-body quantum physics. The resulting quantum state is called <a href="https://en.wikipedia.org/wiki/Matrix_product_state" rel="nofollow">Matrix Product State</a>. In such context, the entries are generally complex numbers, and a probability can be obtained for a given state by taking the squared absolute value of the wavefunction.</p>
<p dir="auto">In this package we focus on the "classical" case where the Tensor Train directly represents a probability distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$p(x^1, x^2, \ldots, x^L)$</math-renderer>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What can this package do?</h2><a id="user-content-what-can-this-package-do" class="anchor" aria-label="Permalink: What can this package do?" href="#what-can-this-package-do"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This small package provides some utilities for creating, manipulating and evaluating Tensor Trains interpreted as functions, with a focus on the probabilistic side.
Each variable <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$x^l$</math-renderer> is assumed to be multivariate.
Whenever performing some probability-related operation, it is responsability of the user to make sure that the Tensor Train always represents a valid probability distribution.</p>
<p dir="auto">Common operations are:</p>
<ul dir="auto">
<li>
<code>evaluate</code> a Tensor Train at a given set of indices</li>
<li>
<code>orthogonalize_left!</code>, <code>orthogonalize_right!</code>: bring a Tensor Train to <a href="https://tensornetwork.org/mps/" rel="nofollow">left/right orthogonal form</a>
</li>
<li>
<code>compress!</code> a Tensor Train using <a href="https://en.wikipedia.org/wiki/Singular_value_decomposition" rel="nofollow">SVD</a>-based truncations</li>
<li>
<code>normalize!</code> a Tensor Train in the probability sense (not in the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cdb090c83dad6c62dff3135ff108ee37">$L_2$</math-renderer> norm sense!), see above</li>
<li>
<code>sample</code> from a Tensor Train intended as a probability ditribution, see above</li>
<li>
<code>+</code>,<code>-</code>: take the sum/difference of two TensorTrains</li>
</ul>
