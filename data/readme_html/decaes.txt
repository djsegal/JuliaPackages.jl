<p dir="auto">DECAES is a <em>fast</em> Julia implementation of the <a href="https://mriresearch.med.ubc.ca/news-projects/myelin-water-fraction/" rel="nofollow">MATLAB toolbox</a> from the <a href="https://mriresearch.med.ubc.ca/" rel="nofollow">UBC MRI Research Centre</a> for computing voxelwise <a href="https://doi.org/10.1016/0022-2364(89)90011-5" rel="nofollow">T2-distributions</a> from multi spin-echo MRI images using the extended phase graph algorithm with stimulated echo corrections.
Post-processing of these T2-distributions allows for the computation of measures such as the <a href="https://doi.org/10.1002/mrm.1910310614" rel="nofollow">myelin water fraction (MWF)</a> or the <a href="https://doi.org/10.1148/radiol.2017161687" rel="nofollow">luminal water fraction (LWF)</a>.</p>
<p dir="auto">DECAES is written in the open-source <a href="https://julialang.org/" rel="nofollow">Julia programming language</a>.
Julia and command line interfaces are available through this package.
The <a href="https://github.com/jondeuce/mwiexamples">examples repository</a> additionally provides a MATLAB interface via the MATLAB function <a href="./api/decaes.m"><code>decaes.m</code></a>.</p>
<p dir="auto">If you use DECAES in your research, please <a href="./CITATION.bib">cite our work</a>:</p>
<ul dir="auto">
<li>Doucette J, Kames C, Rauscher A. DECAES - DEcomposition and Component Analysis of Exponential Signals. Zeitschrift für Medizinische Physik 2020; 30: 271–278.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Using Julia v1.9 or later you can install DECAES as follows:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ julia --project=@decaes -e 'import Pkg; Pkg.add(&quot;DECAES&quot;); Pkg.build(&quot;DECAES&quot;)'"><pre>$ julia --project=@decaes -e <span class="pl-s"><span class="pl-pds">'</span>import Pkg; Pkg.add("DECAES"); Pkg.build("DECAES")<span class="pl-pds">'</span></span></pre></div>
<p dir="auto">This will do two things:</p>
<ol dir="auto">
<li>Add DECAES.jl to a named Julia project environment separate from your global environment</li>
<li>Build the <code>decaes</code> launcher script at <code>~/.julia/bin</code> for running DECAES from the command line</li>
</ol>
<p dir="auto">DECAES can then be run from the command line via <code>decaes &lt;COMMAND LINE ARGS&gt;</code>, provided <code>~/.julia/bin</code> is added to your <code>PATH</code>.
Run <code>decaes --help</code> for available arguments.</p>
