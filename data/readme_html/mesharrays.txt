<p dir="auto"><strong>MeshArrays.jl</strong> defines the <code>MeshArray</code> data structure (or type) that can contain collections of inter-connected arrays as generally done in climate models. This provides a simple yet efficient and general way to e.g. analyze climate system simulations and manipulate their output.</p>
<p dir="auto">Please refer to the <a href="https://juliaclimate.github.io/MeshArrays.jl/dev/" rel="nofollow">Docs</a>, <a href="https://juliaclimate.github.io/MeshArrays.jl/dev/tutorials/" rel="nofollow">Tutorials</a>, and <a href="https://juliaclimate.github.io/MeshArrays.jl/dev/videos/" rel="nofollow">videos</a> for more information.</p>

<p dir="auto">Some features and related packages:</p>
<ul dir="auto">
<li>interpolate to geographic coordinates and visualize as maps</li>
<li>visualize on the sphere, in geographic coordinates, in projection, or grid coordinate</li>
<li>examples include interaction and animation using <code>Makie.jl</code> and <code>Pluto.jl</code></li>
<li>accurately derive planetary scale transports on a global <a href="https://en.wikipedia.org/wiki/Arakawa_grids" rel="nofollow">climate model grid</a></li>
<li>compute trajectories of materials over any supported grid via <a href="https://github.com/JuliaClimate/IndividualDisplacements.jl">IndividualDisplacements.jl</a></li>
<li>read/write <a href="https://en.wikipedia.org/wiki/NetCDF" rel="nofollow">NetCDF</a>, files and other formats often used in climate sciences</li>
<li>support domain decomposition via <a href="https://gaelforget.github.io/NCTiles.jl/stable/" rel="nofollow">NCTiles.jl</a> that</li>
<li>support for <a href="https://mitgcm.readthedocs.io/en/latest/" rel="nofollow">MITgcm</a> model ouput via <a href="https://github.com/gaelforget/MITgcm.jl">MITgcm.jl</a></li>
<li>support for <a href="https://doi.org/10.5194/gmd-8-3071-2015" rel="nofollow">ECCO</a> ocean estimates via <a href="https://github.com/gaelforget/OceanStateEstimation.jl">OceanStateEstimation.jl</a></li>
</ul>
<p dir="auto"><code>MeshArrays.jl</code> was first introduced in <a href="https://youtu.be/RDxAy_zSUvg" rel="nofollow">this presentation</a> at JuliaCon 2018.</p>
