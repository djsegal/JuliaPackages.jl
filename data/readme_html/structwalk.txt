<p dir="auto">Transform functions for Julia struct. Can be viewed as a general version of <code>MacroTools</code>'s <code>prewalk</code>/<code>postwalk</code> or <code>Functors</code>'s <code>@functor</code>/<code>fmap</code>.</p>

<p dir="auto">In this first example, we walk over a struct <code>xs</code>, applying a function <code>f</code> which increments integers.
Using <code>prewalk</code>, <code>f</code> sees the node first and then the transformed leaves.
Using <code>postwalk</code>,  <code>f</code> sees the leaves first and then the transformed node:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="xs = (a=2, b=(c=4, d=0))

<p dir="auto">To avoid infinite recursion using <code>prewalk</code>, return values can be wrapped in <code>StructWalk.LeafNode</code>.</p>
<p dir="auto">In the following example, this is required to avoid recursion over the <code>Integer</code> fields of the <code>Rational</code> number struct:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; postwalk((3, 5)) do x

           return x
       end
