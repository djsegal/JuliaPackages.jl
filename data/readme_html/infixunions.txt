<p dir="auto">InfixUnions defines 3 separate infix operators that can be used to define <code>Union</code> types: <code>|</code>, <code>∪</code>, and <code>∨</code>.
Since <code>|</code> and <code>∪</code> are defined and exported by <code>Base</code>, <code>InfixUnions</code> also defines a fallback method which forwards non-type
arguments to the functions in <code>Base</code>. InfixUnions.jl does <em>not</em> commit type piracy on these functions.</p>
<p dir="auto">In order to use <code>InfixUnions</code>, simply choose which operator you want with a <code>using</code> statement, and go:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using InfixUnions: |

struct Foo
    data::(Int|Nothing)
end"><pre><span class="pl-k">using</span> InfixUnions<span class="pl-k">:</span> <span class="pl-k">|</span>

<span class="pl-k">struct</span> Foo
    data<span class="pl-k">::</span><span class="pl-c1">(Int|Nothing)</span>
<span class="pl-k">end</span></pre></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; Foo(1)
Foo(1)

julia&gt; Foo(nothing)
Foo(nothing)

julia&gt; true | false # Fallback to the Base method
true"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">Foo</span>(<span class="pl-c1">1</span>)
<span class="pl-c1">Foo</span>(<span class="pl-c1">1</span>)

julia<span class="pl-k">&gt;</span> <span class="pl-c1">true</span> <span class="pl-k">|</span> <span class="pl-c1">false</span> <span class="pl-c"><span class="pl-c">#</span> Fallback to the Base method</span>
<span class="pl-c1">true</span></pre></div>

<p dir="auto">Similarly, one can use the <code>∪</code> operator (written by typing <code>\cup</code> and then hitting the <code>TAB</code> key)</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using InfixUnions: ∪
