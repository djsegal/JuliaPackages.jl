<p dir="auto">This package implements a series of string algorithms in Julia, including:</p>
<ul dir="auto">
<li>Manacher's Algorithm</li>
<li>Prefix Function &amp; Prefix Automaton</li>
<li>Z Algorithm</li>
<li>Suffix AutoMaton (SAM)
<ul dir="auto">
<li>Find number of occurrences of a pattern (<code>Base.count</code>)</li>
<li>Find the first occurrence of a pattern (<code>Base.findfirst</code>)</li>
<li>Find all occurrences of a pattern (<code>Base.findall</code>)</li>
<li>Longest common substring (of two or more strings/vectors)</li>
<li>Minimum/Maximum rotation</li>
</ul>
</li>
<li>Palindromic AutoMaton (PAM)</li>
</ul>
