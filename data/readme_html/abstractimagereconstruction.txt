<p dir="auto">This package contains an interface and type hierarchy for image reconstruction algorithms and their parameters, together with associated utility tools.</p>

<p dir="auto">Concrete construction of reconstruction algorithms depend on the implementation of the reconstruction package. Once an algorithms is constructed with the given paramters, images can be reconstructed as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using AbstractImageReconstruction, MPIReco

params = ... # Setup reconstruction paramter
algo = ... # Setup chosen algorithm with params
raw = ... # Setup raw data

image = reconstruct(algo, raw)"><pre><span class="pl-k">using</span> AbstractImageReconstruction, MPIReco

params <span class="pl-k">=</span> <span class="pl-k">...</span> <span class="pl-c"><span class="pl-c">#</span> Setup reconstruction paramter</span>
algo <span class="pl-k">=</span> <span class="pl-k">...</span> <span class="pl-c"><span class="pl-c">#</span> Setup chosen algorithm with params</span>
raw <span class="pl-k">=</span> <span class="pl-k">...</span> <span class="pl-c"><span class="pl-c">#</span> Setup raw data</span>

image <span class="pl-k">=</span> <span class="pl-c1">reconstruct</span>(algo, raw)</pre></div>
<p dir="auto">Once an algorithm is constructed it can be transformed into a <code>RecoPlan</code>. These are mutable and transparent wrappers around the nested types of the algorithm and its paramters, that can be stored and restored to and from TOML files.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="plan = toPlan(algo)
savePlan(MPIReco, &quot;Example&quot;, plan)
plan = loadPlan(MPIReco, &quot;Example&quot;, [MPIReco, RegularizedLeastSquares, MPIFiles])

algo2 = build(plan)
algo == algo2 # true"><pre>plan <span class="pl-k">=</span> <span class="pl-c1">toPlan</span>(algo)
<span class="pl-c1">savePlan</span>(MPIReco, <span class="pl-s"><span class="pl-pds">"</span>Example<span class="pl-pds">"</span></span>, plan)
plan <span class="pl-k">=</span> <span class="pl-c1">loadPlan</span>(MPIReco, <span class="pl-s"><span class="pl-pds">"</span>Example<span class="pl-pds">"</span></span>, [MPIReco, RegularizedLeastSquares, MPIFiles])

algo2 <span class="pl-k">=</span> <span class="pl-c1">build</span>(plan)
algo <span class="pl-k">==</span> algo2 <span class="pl-c"><span class="pl-c">#</span> true</span></pre></div>
<p dir="auto">Unlike concrete algorithm instances, a <code>RecoPlan</code> may still be missing certain values of its fields and it can encode the structure of an image reconstruction algorithm without concrete parameterization.</p>
<p dir="auto">It is also possible to attach <code>Listeners</code> to <code>RecoPlan</code> fields, that call user-specified functions if they are changed. This allows specific <code>RecoPlans</code> to provide smart default paramter choices or embedding a plan into a GUI.</p>
