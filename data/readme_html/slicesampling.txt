<p dir="auto">This package implements slice sampling algorithms accessible through the <code>AbstractMCMC</code> <a href="https://github.com/TuringLang/AbstractMCMC.jl">interface</a>.
For general usage, please refer to <a href="https://turinglang.org/SliceSampling.jl/dev/general/" rel="nofollow">here</a>.</p>

<p dir="auto">The following slice samplers can also be used as a conditional sampler in <code>Turing.Experimental.Gibbs</code> sampler:</p>
<ul dir="auto">
<li>For multidimensional variables:
<ul dir="auto">
<li><code>RandPermGibbs</code></li>
<li><code>HitAndRun</code></li>
</ul>
</li>
<li>For unidimensional variables:
<ul dir="auto">
<li><code>Slice</code></li>
<li><code>SliceSteppingOut</code></li>
<li><code>SliceDoublingOut</code></li>
</ul>
</li>
</ul>
<p dir="auto">See the following example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Distributions
using Turing
using SliceSampling

@model function simple_choice(xs)
    p ~ Beta(2, 2)
    z ~ Bernoulli(p)
    for i in 1:length(xs)
        if z == 1
            xs[i] ~ Normal(0, 1)
        else
            xs[i] ~ Normal(2, 1)
        end
    end
end

sampler = Turing.Experimental.Gibbs(
    (
        p = externalsampler(SliceSteppingOut(2.0)),
        z = PG(20, :z)
    )
)

n_samples = 1000
model     = simple_choice([1.5, 2.0, 0.3])
sample(model, sampler, n_samples)"><pre><span class="pl-k">using</span> Distributions
