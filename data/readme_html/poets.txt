<p dir="auto">POETs.jl is a <a href="http://http://julialang.org" rel="nofollow">Julia</a> package that implements the Pareto Optimal Ensemble Techniques (POETs) method for multiobjective optimization. For background on the original POETs algorithm see:</p>
<p dir="auto"><a href="http://www.ncbi.nlm.nih.gov/pmc/articles/PMC3021968/" rel="nofollow">Song S, Chakrabarti A, and J. Varner (2010) Identifying ensembles of signal transduction models using Pareto Optimal Ensemble Techniques (POETs). Biotechnology Journal DOI: 10.1002/biot.201000059</a></p>
<p dir="auto">and for its updated implementation in Julia:</p>
<p dir="auto"><a href="http://biorxiv.org/content/early/2016/05/30/056044" rel="nofollow">Bassen D, Vilkhovoy M, Minot M, Butcher J and J. Varner (2016) JuPOETs: A Constrained Multiobjective Optimization Approach to Estimate Biochemical Model Ensembles in the Julia Programming Language. bioArXiv doi: http://dx.doi.org/10.1101/056044</a></p>

<p dir="auto">Within <a href="http://http://julialang.org" rel="nofollow">Julia</a>, use the <code>clone</code> command of the package manager to download and install the POETs repository:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="Pkg.clone(&quot;git://github.com/varnerlab/POETs.jl&quot;)"><pre class="notranslate"><code>Pkg.clone("git://github.com/varnerlab/POETs.jl")
</code></pre></div>
<p dir="auto">To use POETs in your project (following installation) simply issue the command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using POETs"><pre class="notranslate"><code>using POETs
</code></pre></div>
<p dir="auto">To test the POETs installation use:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="Pkg.test(&quot;POETs&quot;)"><pre class="notranslate"><code>Pkg.test("POETs")
</code></pre></div>
<p dir="auto">which runs test examples from the <code>test</code> directory. Lastly, to delete the JuPOETs package use the command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="Pkg.rm(&quot;POETs&quot;)"><pre class="notranslate"><code>Pkg.rm("POETs")
</code></pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How do I get started with JuPOETs?</h2><a id="user-content-how-do-i-get-started-with-jupoets" class="anchor" aria-label="Permalink: How do I get started with JuPOETs?" href="#how-do-i-get-started-with-jupoets"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First, make sure <a href="http://http://julialang.org" rel="nofollow">Julia</a> is installed on your computer. Next, clone the JuPOETs package to your Julia installation (using the <code>Pkg.clone()</code> command shown above). Lastly, write your problem specific functions (<code>objective</code>,<code>neighbor</code>,<code>cooling</code> and <code>acceptance</code>) which are required by JuPOETs, and your ready to go. We've included sample code to help you get started with JuPOETs in your project. The sample can be found in the <code>sample/biochemical</code> subdirectory. The sample encodes the estimation of an ensemble of biochemical model parameters from four conflicting training data sets. The driver for this sample is given in the <code>run_biochemical_test.jl</code> file, while the <code>objective</code>,<code>neighbor</code>,<code>cooling</code> and <code>acceptance</code> functions (required by JuPOETs) are encoded in the <code>hcmem_lib.jl</code> library.</p>
