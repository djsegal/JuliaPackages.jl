<p dir="auto">This package is a simpler Julia implementation of the Matlab function <a href="https://www.mathworks.com/help/matlab/ref/filloutliers.html" rel="nofollow">filloutliers</a>.</p>
<p dir="auto">This packages finds the outliers in a vector and fills them with a linear interpolation between closest non outlier/NaN/missing neighbours.</p>
<p dir="auto">Three different methods are implemented to find the outliers:</p>
<ul dir="auto">
<li><code>median</code>: Outliers are those values that are 3 times the standard deviation calculated based on mad, <code>std</code>, away from the median.</li>
<li><code>mean</code>: Outliers are those values that are 3 times the standard deviation, <code>std</code>, away from the mean.</li>
<li><code>quartiles</code>: Outliers are those values that are outside the 25 and 75 quartile.</li>
<li><code>moving mean</code>: Outliers are those values that are 3 times the standard deviation, <code>std</code>, away from the moving mean. In that case the window size is <code>window</code> and needs to be provided as input.</li>
<li><code>moving median</code>: Outliers are those values that are 3 times the standard deviation calculated based on mad, <code>std</code>, away from the moving median. In that case the window size is <code>window</code> and needs to be provided as input.</li>
</ul>
<p dir="auto">The input data must be a a vector of numbers (1xn or nx1). The output is a vector of the same size as the input, converted to Float64. The input of matrices is not supported, but it can be done by applying the function to each column/row.</p>
<p dir="auto">In this version the if teh input data starts or finishes with a series of outliers, the first and last values will be filled with the first and last non outlier value of the data vector.</p>
<p dir="auto">Example:
filloutliers(data, method, window)
data = [1, 2, 100000, 4, 5, 7, 9, 15, NaN, 8, 9]</p>
