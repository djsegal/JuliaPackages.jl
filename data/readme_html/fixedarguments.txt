<p dir="auto">This package serves as a straightforward and lightweight extension of Julia's <code>Base.Fix1</code> and <code>Base.Fix2</code> functionalities. The key distinction of this package is its simplicity and lightweight design. Its single purpose is to generate <strong>a function with fixed values</strong> for specific arguments <strong>programmatically</strong>, incurring <strong>no additional computational overhead</strong>. Notably, it is not using macro-based sugar-syntax in favor of an ultra-minimalistic API. Additionally, the package offers the ability to modify fixed values using a custom transform function.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Simple example</h2><a id="user-content-simple-example" class="anchor" aria-label="Permalink: Simple example" href="#simple-example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Consider a basic function where you wish to set specific arguments:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="foo(x, y, z) = x * y + z"><pre><span class="pl-en">foo</span>(x, y, z) <span class="pl-k">=</span> x <span class="pl-k">*</span> y <span class="pl-k">+</span> z</pre></div>
<p dir="auto">This package supports two fixing methods: position-based fixing and sequential-based fixing.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Position-based Fixing</h3><a id="user-content-position-based-fixing" class="anchor" aria-label="Permalink: Position-based Fixing" href="#position-based-fixing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Suppose you want to fix the first and third arguments of this function. Using position-based fixing, it would look like this:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import FixedArguments: fix, FixedArgument

# Fixes the argument at position `1` with the value `1.0`
#       the argument at position `3` with the value `3.0`
fixed_foo = fix(foo, (FixedArgument(1, 1.0), FixedArgument(3, 3.0))) "><pre><span class="pl-k">import</span> FixedArguments<span class="pl-k">:</span> fix, FixedArgument

<span class="pl-c"><span class="pl-c">#</span> Fixes the argument at position `1` with the value `1.0`</span>
<span class="pl-c"><span class="pl-c">#</span>       the argument at position `3` with the value `3.0`</span>
fixed_foo <span class="pl-k">=</span> <span class="pl-c1">fix</span>(foo, (<span class="pl-c1">FixedArgument</span>(<span class="pl-c1">1</span>, <span class="pl-c1">1.0</span>), <span class="pl-c1">FixedArgument</span>(<span class="pl-c1">3</span>, <span class="pl-c1">3.0</span>))) </pre></div>
<p dir="auto">The resulting function can be called as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="fixed_foo(2.0) # 5.0"><pre><span class="pl-c1">fixed_foo</span>(<span class="pl-c1">2.0</span>) <span class="pl-c"><span class="pl-c">#</span> 5.0</span></pre></div>
<p dir="auto"><strong>Note</strong>: While not strictly necessary, for optimal performance and to avoid dynamic dispatch, it is recommended to have positions known at compile-time. Also, ensure that positions are specified in ascending order.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Sequential based fixing</h3><a id="user-content-sequential-based-fixing" class="anchor" aria-label="Permalink: Sequential based fixing" href="#sequential-based-fixing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For sequential-based fixing, the same example would be written as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Fixes the argument at position `1` with the value `1.0`
#       the argument at position `2` is not being fixed
#       the argument at position `3` with the value `3.0`
fixed_foo = fix(foo, (FixedArgument(1.0), NotFixed(), FixedArgument(3.0))) "><pre><span class="pl-c"><span class="pl-c">#</span> Fixes the argument at position `1` with the value `1.0`</span>
<span class="pl-c"><span class="pl-c">#</span>       the argument at position `2` is not being fixed</span>
<span class="pl-c"><span class="pl-c">#</span>       the argument at position `3` with the value `3.0`</span>
fixed_foo <span class="pl-k">=</span> <span class="pl-c1">fix</span>(foo, (<span class="pl-c1">FixedArgument</span>(<span class="pl-c1">1.0</span>), <span class="pl-c1">NotFixed</span>(), <span class="pl-c1">FixedArgument</span>(<span class="pl-c1">3.0</span>))) </pre></div>
<p dir="auto"><strong>Note</strong>: Both scenarios are valid, but to prevent ambiguity, position-based and sequential-based fixing methods are not compatible.
Attempting to combine them will result in an error:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="fix(foo, (FixedArgument(1.0), FixedArgument(2, 1.0))) # throws an error"><pre><span class="pl-c1">fix</span>(foo, (<span class="pl-c1">FixedArgument</span>(<span class="pl-c1">1.0</span>), <span class="pl-c1">FixedArgument</span>(<span class="pl-c1">2</span>, <span class="pl-c1">1.0</span>))) <span class="pl-c"><span class="pl-c">#</span> throws an error</span></pre></div>
<p dir="auto">The <code>NoFixed()</code> argument can be employed in both regimes, but in the position-based regime, it is simply disregarded.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Custom transformation of the fixed values</h3><a id="user-content-custom-transformation-of-the-fixed-values" class="anchor" aria-label="Permalink: Custom transformation of the fixed values" href="#custom-transformation-of-the-fixed-values"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>fix</code> function also accepts a custom transformation function as its second argument, which gets called each time the fixed arguments are placed in their respective slots. The default transformation function doesn't alter anything and simply returns the fixed value (aka <code>identity</code>), but in more complex scenarious it provides the ability to dynamically change the fixed values based on their position. For instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import FixedArguments: FixedPosition

function unpack_from_ref(::FixedPosition{P}, ref::Ref) where {P}
    return ref[]
end

var1 = Ref(1.0)
var2 = Ref(2.0)
var3 = Ref(3.0)

cached_foo = fix(foo, unpack_from_ref, (FixedArgument(var1), FixedArgument(var2), FixedArgument(var3)))

cached_foo() # 5.0

var1[] = 3.0
var2[] = 2.0
var3[] = 1.0

cached_foo() # 7.0"><pre><span class="pl-k">import</span> FixedArguments<span class="pl-k">:</span> FixedPosition

    <span class="pl-k">return</span> ref[]
<span class="pl-k">end</span>
