<p dir="auto">Cthonios - Continuum THermodynamic Optimization-based Numerical Implementations Of Solid mechanics</p>
<p dir="auto">This is a collection of tools for solving solid mechanics problems via optimization methods. This is larrgely inspired by the python package <a href="https://github.com/sandialabs/optimism">OptimiSM</a>.</p>
<p dir="auto">The tools build on several other packages such as <a href="https://github.com/cthonios/Exodus.jl">Exodus.jl</a>, <a href="https://github.com/Cthonios/ReferenceFiniteElements.jl">ReferenceFiniteElements.jl</a>, <a href="https://github.com/Cthonios/FiniteElementContainers.jl">FiniteElementContainers.jl</a>, and <a href="https://github.com/Cthonios/ConstitutiveModels.jl">ConstitutiveModels.jl</a> to name a few of the direct dependencies developed by the <a href="https://github.com/Cthonios">Cthonios organization</a>.</p>
