<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto">Add-ons and standalone modules for <a href="https://github.com/heyx3/B-plus">B+</a>. Refer to the main repo for documentation.</p>
<p dir="auto">The modules contained here are:</p>
<ul dir="auto">
<li>ECS</li>
<li>Fields</li>
<li>SceneTree</li>
<li>A few uncategorized helpers like <code>Cam3D</code></li>
</ul>
<p dir="auto">If you want just this package, without the rest of B+, you can add this package directly to your project and then do <code>using BplusTools; @using_bplus_tools</code>.</p>
</article></div>
