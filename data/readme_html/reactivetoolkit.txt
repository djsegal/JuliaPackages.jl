<p dir="auto">Hello! This package provides some tools to enable asynchronous, concurrent, reactive, "soft real-time" programming in Julia. The target audience of this package consists of roboticists working at the intersection of controls theory and experimental hardware. It should prove useful for single developers or small teams who are not willing or able to implement a full real-time stack just to test their control implementation on benchtop hardware.</p>
<p dir="auto"><strong>ReactiveToolkit.jl is not suitable for mission- or safety-critical applications.</strong></p>
<p dir="auto">For more information, please see the <a href="https://narijauskas.github.io/ReactiveToolkit.jl/dev" rel="nofollow">documentation</a>!</p>

<p dir="auto">Topics represent the time-varying states of the system, and can safely share data between tasks. Their current value is used or updated using <code>[]</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# making topics
@topic x = 0
@topic y::Number = 0

# using topics

<p dir="auto">ReactiveToolkit also provides several macros to transform arbitrary code into asynchronous tasks which can react to topic updates, time, or arbitrary events.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# react to topics
tk1 = @on x y[] = sin(x[])
tk2 = @on y &quot;y monitor&quot; println(&quot;y is now: &quot;, y[])

# react to time
tk3 = @every Hz(10) println(&quot;...is this annoying yet?&quot;)
tk4 = @after seconds(3) kill(tk1)

# support for initializers/finalizers
tk5 = @every Hz(10) begin
    println(&quot;task initialized - hello!&quot;)
end begin
    println(&quot;...is this annoying yet?&quot;)
end begin
    println(&quot;finalizing a task - goodbye!&quot;)
end

# react to events
tk6 = @loop &quot;serial monitor&quot; println(readline(port))

# stacktraces for debugging
tk7 = @on x throws_error()
# why did my task fail?
debug(tk7)

# these might come in handy :)
kill(ans)
kill(last(rtk_tasks()))
rtk_kill_all()"><pre><span class="pl-c"><span class="pl-c">#</span> react to topics</span>
