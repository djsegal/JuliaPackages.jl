<p dir="auto"><code>UnetUtils.jl</code> provides commonly used utilities that are helpful when working with <a href="https://unetstack.net/" rel="nofollow">UnetStack</a> and Julia. Currently, it contains utilities to work with UnetStack signal dumps (<code>signals-*.txt</code> files) and passband recordings (<code>rec-*.dat</code> files).</p>

<p dir="auto">This will create a <code>rec.wav</code> file in the same folder as the original recording.</p>
