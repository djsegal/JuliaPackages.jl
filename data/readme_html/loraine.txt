<p dir="auto"><em>Sweet Lor(r)aine, let the party carry on<sup><a href="#user-content-fn-1-17d9a4c677e5792da50a43f7532d026d" id="user-content-fnref-1-17d9a4c677e5792da50a43f7532d026d" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>...</em></p>
<p dir="auto">Loraine.jl is a Julia implementation of an interior point method algorithm for
linear semidefinite optimization problems.</p>
<p dir="auto">Special features of Loraine:</p>
<ul dir="auto">
<li>Use of an iterative solver for linear systems. This is to be used for problems with (very) low rank solution matrix. Standard (non-low-rank) problems and linear programs can be solved using the direct solver; then the user gets a standard IP method akin SDPT3.</li>
<li>Use of high-precision arithmetic (by means of MultiFloats.jl). Only to be used with a direct solver (and relatively small problems). <em>(New in version 0.2.0.)</em></li>
</ul>
<p dir="auto">There is also a MATLAB version of the code at <a href="https://github.com/kocvara/Loraine.m">kocvara/Loraine.m</a>.</p>

<p dir="auto">If the solution does not have low rank, it is recommended to use a direct
solver <code>kit = 0</code>. However, if you know that your data matrices are all rank-one,
use the option <code>datarank = -1</code> to get a significant reduction in the complexity
(and CPU time). Examples of such problems are <code>maxG11</code> and <code>thetaG11</code> from the
<code>SDPLIB</code> collection.</p>
