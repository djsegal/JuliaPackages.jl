<p dir="auto">Small package which provides convenience tools to access quantities based on <a href="https://github.com/PainterQubits/Unitful.jl">Unitful.jl</a> and <a href="https://github.com/JuliaPhysics/PhysicalConstants.jl">PhysicalConstants.jl</a> in an "unitless" way -- as floating point numbers representing the numerical value of a quantity expressed in preferred units (SI base units by default). This appears to be useful in projects using code which cannot easily made unit-aware, e.g. due to the use of sparse linear algebra.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Breaking changes in v1.1</h2><a id="user-content-breaking-changes-in-v11" class="anchor" aria-label="Permalink: Breaking changes in v1.1" href="#breaking-changes-in-v11"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>Unitful.@u_str</code> is not anymore re-exported. Instead,  <code>using Unitful</code> should be used.</li>
<li>The functor method  <code>(::Unitful.FreeUnits)(x::Real)</code> is now exported by the submodule <code>LessUnitful.MoreUnitful</code>.
So if  something like <code>x=1|&gt;u"cm"</code> is required (which should give 100cm because <code>1</code> is assumed to be a value
in the SI Basic units in this method), one needs <code>LessUnitful.MoreUnitful</code>. Due to the type piracy behind this,
using this in packages should be avoided.</li>
<li>Calculation of physical constants like <code>ph"N_A*e"</code> has been removed as this depended on undocumented internals of
<code>Unitful.jl</code>. Just replace this by  <code>ph"N_A"*ph"e"</code>.</li>
</ul>
