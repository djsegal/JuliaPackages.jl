<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Behavioural agent-based economic forecasting</h1><a id="user-content-behavioural-agent-based-economic-forecasting" class="anchor" aria-label="Permalink: Behavioural agent-based economic forecasting" href="#behavioural-agent-based-economic-forecasting"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Welcome to BeforeIT.jl, a package for <strong>B</strong>ehavioural agent-based <strong>e</strong>conomic <strong>fore</strong>casting,
from the <strong>IT</strong> research unit of the Bank of Italy.</p>
<p dir="auto">BeforeIT.jl is a Julia-based implementation of the agent-based model presented in
<a href="https://www.sciencedirect.com/science/article/pii/S0014292122001891" rel="nofollow"><em>Economic forecasting with an agent-based model</em></a>,
the first ABM matching the forecasting performance of traditional economic tools.</p>
<p dir="auto">With BeforeIT.jl, you can perform economic forecasting and explore different counterfactual scenarios.
Thanks to its modular design, the package is also a great starting point for anyone looking to extend its
capabilities or integrate it with other tools.</p>
<p dir="auto">Developed in Julia, a language known for its efficiency, BeforeIT.jl is both fast and user-friendly,
making it accessible whether you’re an expert programmer or just starting out.</p>
<p dir="auto">The package currently contains the original parametrisation for Austria, as well as a parametrisation for Italy.
Recalibrating the model on other nations is possible of course, but currently not easily supported.
So get in contact if you are interested!</p>

<p dir="auto">To run this software, you will need a working Julia installation on your machine.
If you don't have Julia installed already, simply follow the short instructions
available <a href="https://julialang.org/downloads/" rel="nofollow">here</a>.</p>

<p dir="auto">To be able to run the model, you can activate a new Julia environment in any folder from the terminal by typing</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project=."><pre class="notranslate"><code>julia --project=.
</code></pre></div>
<p dir="auto">Then, whithin the Julia environment, you can install BeforeIT.jl as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;BeforeIT&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>BeforeIT<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">You can ensure to have installed all dependencies via</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Pkg.instantiate()"><pre>Pkg<span class="pl-k">.</span><span class="pl-c1">instantiate</span>()</pre></div>
<p dir="auto">Now you should be able to run the the following code</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using BeforeIT

parameters = BeforeIT.AUSTRIA2010Q1.parameters
initial_conditions = BeforeIT.AUSTRIA2010Q1.initial_conditions

T = 20
model = BeforeIT.initialise_model(parameters, initial_conditions, T)
data = BeforeIT.run_one_sim!(model)"><pre><span class="pl-k">using</span> BeforeIT

parameters <span class="pl-k">=</span> BeforeIT<span class="pl-k">.</span>AUSTRIA2010Q1<span class="pl-k">.</span>parameters
initial_conditions <span class="pl-k">=</span> BeforeIT<span class="pl-k">.</span>AUSTRIA2010Q1<span class="pl-k">.</span>initial_conditions

T <span class="pl-k">=</span> <span class="pl-c1">20</span>
model <span class="pl-k">=</span> BeforeIT<span class="pl-k">.</span><span class="pl-c1">initialise_model</span>(parameters, initial_conditions, T)
data <span class="pl-k">=</span> BeforeIT<span class="pl-k">.</span><span class="pl-c1">run_one_sim!</span>(model)</pre></div>
<p dir="auto">This will simulate the model with the original Austrian parametrisation for 20 quarters and save the results in the <code>data</code> object.
To plot the time series within the <code>data</code> object, make sure you install Plots.jl in the same environment using</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Pkg.add(&quot;Plots&quot;)"><pre>Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Plots<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">and then try running</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Plots

plot(data.real_gdp)"><pre><span class="pl-k">using</span> Plots

<span class="pl-c1">plot</span>(data<span class="pl-k">.</span>real_gdp)</pre></div>
<p dir="auto">In you want to run the script without opening a REPL, you can copy and paste the above lines into a file,
say <code>main.jl</code>, and run it directly from the terminal by typing</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project=. main.jl"><pre class="notranslate"><code>julia --project=. main.jl
</code></pre></div>
