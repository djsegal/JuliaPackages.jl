<p dir="auto">This package <code>SparseArraysCOO.jl</code> provides simple convenience
functions for creating sparse vectors and sparse matrices. After
creating a <code>SparseMatrixCOO</code> matrix or a <code>SparseVectorCOO</code> vector, it
records all assignments made to it. There are no other operations
defined on these types, except converting them to the efficient
<code>SparseMatrixCSC</code> and <code>SparseVector</code> types. This is no more or less
efficient than the way described in the documentation of
<code>SparseArrays</code>, but it is more convenient.</p>
<p dir="auto">The suffix <code>COO</code> stands for "coordinate format". This means that the
internal representation stores both indices <code>i</code> and <code>j</code> for every
nonzero value.</p>
