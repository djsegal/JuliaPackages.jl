<p dir="auto">PlotPWM is a package for plotting <a href="https://en.wikipedia.org/wiki/Position_weight_matrix" rel="nofollow">position weight matrices (PWMs)</a>,  which is commonly used to characterize and visualize motifs — the binding sites where proteins interact with DNA or RNA.</p>

<p dir="auto">The function <code>logoplot(pfm, background)</code> produces a plot where:</p>
<ul dir="auto">
<li>The x-axis shows the positions in the PWM.</li>
<li>The y-axis shows the information content (bits) for each position.</li>
</ul>
<p dir="auto">The <code>background</code> is an array representing the background probabilities for A, C, G, and T. These should sum to 1. In this example, a uniform background of <code>[0.25, 0.25, 0.25, 0.25]</code> is used, assuming equal probabilities for each base.</p>
<p dir="auto">You can also call:</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Plot your PWMs with crosslinking tendencies</h2><a id="user-content-plot-your-pwms-with-crosslinking-tendencies" class="anchor" aria-label="Permalink: Plot your PWMs with crosslinking tendencies" href="#plot-your-pwms-with-crosslinking-tendencies"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Cross-linked PWMs not only display the PWM but also account for crosslinking tendencies, which are particularly relevant for the binding sites of <a href="https://en.wikipedia.org/wiki/RNA-binding_protein" rel="nofollow">RNA-binding proteins (RBPs)</a> from <a href="https://en.wikipedia.org/wiki/Cross-linking_immunoprecipitation" rel="nofollow">CLIP-Seq</a>.</p>
<p dir="auto">To plot these, you'll need to estimate the crosslinking tendencies along with the PFM. For a PFM with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$L$</math-renderer> columns, provide a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$K \times L$</math-renderer> matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$C$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$\sum_{k,\ell}C_{k\ell} \leq 1$</math-renderer>.</p>
<p dir="auto">For example, when <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$K=1$</math-renderer>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="C = [0.01  0.04  0.05  0.0  0.74  0.05  0.03  0.05  0.03  0.0] "><pre class="notranslate"><code>C = [0.01  0.04  0.05  0.0  0.74  0.05  0.03  0.05  0.03  0.0] 
</code></pre></div>
<p dir="auto">and the background:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="background = [0.25, 0.25, 0.25, 0.25]"><pre class="notranslate"><code>background = [0.25, 0.25, 0.25, 0.25]
</code></pre></div>
<p dir="auto">You can then plot the cross-linked PWM using:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="logoplotwithcrosslink(pfm, background, C; rna=true)"><pre class="notranslate"><code>logoplotwithcrosslink(pfm, background, C; rna=true)
</code></pre></div>
<p dir="auto">This will generate:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="demo/demo2.png"><img src="demo/demo2.png" alt="pfm" style="max-width: 100%;"></a></p>
<p dir="auto">Setting the tag <code>rna=true</code> will change the logo from using thymine <code>T</code> to uracil <code>U</code>.</p>
<p dir="auto">Alternatively, you can use:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="logoplotwithcrosslink(pfm, C; rna=true)"><pre class="notranslate"><code>logoplotwithcrosslink(pfm, C; rna=true)
</code></pre></div>
<p dir="auto">which will automatically assume a uniform background of <code>[0.25, 0.25, 0.25, 0.25]</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Multiplexed crosslinking tendencies</h3><a id="user-content-multiplexed-crosslinking-tendencies" class="anchor" aria-label="Permalink: Multiplexed crosslinking tendencies" href="#multiplexed-crosslinking-tendencies"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Multiplexed crosslinking tendencies occur when multiple crosslinking signatures are present in the dataset. Each signature can be applied to each sequence before performing motif discovery tasks. This situation corresponds to cases where the crosslink matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$C$</math-renderer> has more than one row, i.e., <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4781a7b53f42914df7f194af41664296">$K &amp;gt; 1$</math-renderer>."</p>
<p dir="auto">Suppose we have</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="C2 = [0.01  0.01  0.03  0.0   0.37  0.03  0.02  0.03  0.01  0.0
     0.01  0.0   0.11  0.01  0.26  0.0   0.03  0.01  0.02  0.01]"><pre class="notranslate"><code>C2 = [0.01  0.01  0.03  0.0   0.37  0.03  0.02  0.03  0.01  0.0
     0.01  0.0   0.11  0.01  0.26  0.0   0.03  0.01  0.02  0.01]
</code></pre></div>
<p dir="auto">Now, using</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="logoplotwithcrosslink(pfm, background, C; rna=true)"><pre class="notranslate"><code>logoplotwithcrosslink(pfm, background, C; rna=true)
</code></pre></div>
<p dir="auto">You'd get</p>
