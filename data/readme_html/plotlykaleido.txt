<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Windows Note</h2><a id="user-content-windows-note" class="anchor" aria-label="Permalink: Windows Note" href="#windows-note"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Many people on Windows have issues with the latest (0.2.1) version of the Kaleido library (see for example <a href="https://discourse.julialang.org/t/plotlyjs-causes-errors-cant-figure-out-how-to-use-plotlylight-how-to-use-plotly-from-julia/108853/29" rel="nofollow">discourse</a>, <a href="https://github.com/JuliaPlots/PlotlyKaleido.jl/pull/17#issuecomment-1969325440" data-hovercard-type="pull_request" data-hovercard-url="/JuliaPlots/PlotlyKaleido.jl/pull/17/hovercard">this PR's comment</a> and <a href="https://github.com/plotly/Kaleido/issues/134" data-hovercard-type="issue" data-hovercard-url="/plotly/Kaleido/issues/134/hovercard">this issue</a> on the Kaleido repository).</p>
<p dir="auto">Many people have succesfully fixed this problem on windows by downgrading the kaleido library to version 0.1.0 (see <a href="https://github.com/plotly/Kaleido/issues/134" data-hovercard-type="issue" data-hovercard-url="/plotly/Kaleido/issues/134/hovercard">the previously mentioned issue</a>). If you experience issues with <code>PlotlyKaleido.start()</code> hanging on windows, you may want try adding <code>Kaledido_jll@v0.1</code> explicitly to your project environment to fix this. You can do so by either doing:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="add Kaleido_jll@v0.1"><pre>add Kaleido_jll<span class="pl-c1">@v0</span>.<span class="pl-c1">1</span></pre></div>
<p dir="auto">inside the REPL package enviornment, or by calling the following code in the REPL directly:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="begin
    import Pkg
    Pkg.add(; name = &quot;Kaleido_jll&quot;, version = &quot;0.1&quot;)
end"><pre><span class="pl-k">begin</span>
    <span class="pl-k">import</span> Pkg
    Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(; name <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>Kaleido_jll<span class="pl-pds">"</span></span>, version <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>0.1<span class="pl-pds">"</span></span>)
<span class="pl-k">end</span></pre></div>
