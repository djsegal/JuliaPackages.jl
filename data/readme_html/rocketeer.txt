<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto"><a href="https://AP6YC.github.io/Rocketeer.jl/dev" rel="nofollow"><img src="https://github.com/AP6YC/FileStorage/raw/main/Rocketeer/header.png?raw=true" alt="rocket-header" style="max-width: 100%;"></a></p>
<p dir="auto">A <a href="https://julialang.org/" rel="nofollow">Julia</a> implementation of the <a href="https://doi.org/10.1007/s10618-020-00701-z" rel="nofollow">Rocket</a> method of using random feature kernels for time series classification.</p>
<p dir="auto">This project is not programmed by the original authors of the original paper; please see the <a href="#attribution">Attribution</a> section for more details on the original paper and software.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For detailed usage instructions, please see the <a href="https://AP6YC.github.io/Rocketeer.jl/dev" rel="nofollow">Documentation</a>.</p>
<p dir="auto">To use the package, you must:</p>
<ol dir="auto">
<li>Load <code>Rocketeer</code>,</li>
<li>Create a <code>RocketModule</code> object (with optionally specified <code>input_length</code> and <code>n_kernels</code> hyperparameters),</li>
<li><code>apply_kernels</code> to your dataset to extract the Rocket features,</li>
<li>Optionally <code>save_rocket</code> and <code>load_rocket</code> if you intend to utilize the exact same kernels in future experiments.</li>
</ol>
<p dir="auto">For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Load the module
using Rocketeer

# Set some parameters of the example
filepath = &quot;my_rocket&quot;  # Point to a save file
input_length = 10       # The length of the input window
n_kernels = 200         # The number of kernels to generate

# Create a rocket module
my_rocket = RocketModule(input_length, n_kernels)

# Save it for future use
save_rocket(my_rocket, filepath)

# Load the module back into a new object
my_new_rocket = load_rocket(filepath)

# Create some random data
X = rand(input_length)

# Apply the kernels to get features
features = apply_kernels(my_new_rocket, X)"><pre><span class="pl-c"><span class="pl-c">#</span> Load the module</span>
