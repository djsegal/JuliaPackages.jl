<p dir="auto">The database is currently limited to dispersion and extinction ('n-k') data. Future versions of the package may include the new <a href="https://refractiveindex.info/n2" rel="nofollow">n₂</a> (nonlinear index) database - please file an issue if this functionality is important to you.</p>
