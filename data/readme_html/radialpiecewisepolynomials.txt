<p dir="auto">A Julia package for a hierarchical hp-finite element basis on disk and annuli. The mesh is an innermost disk (omitted if the domain is an annulus) and concentric annuli. The basis consists of Zernike (annular) polynomials modified into hat (external shape) and bubble (internal shape) functions.</p>
<p dir="auto">This package utilizes <a href="https://github.com/JuliaApproximation/AnnuliOrthogonalPolynomials.jl">AnnuliOrthogonalPolynomials.jl</a> and <a href="https://github.com/JuliaApproximation/SemiclassicalOrthogonalPolynomials.jl">SemiclassicalOrthogonalPolynomials.jl</a> for the construction of the FEM basis.</p>
<p dir="auto">See the <a href="https://github.com/ioannisPApapadopoulos/RadialPiecewisePolynomials.jl/tree/main/examples">examples/</a> folder for examples. Some basic usage:</p>

julia&gt; Φ = ContinuousZernike(10, points); # H¹ conforming disk FEM basis up to degree 10
ContinuousZernike at degree N=10 and endpoints [0.0, 0.49999999999999994, 0.6299605249474365, 0.7937005259840997, 1.0].

julia&gt; Ψ = ZernikeBasis(10, points, 0, 0); # L² conforming disk FEM basis up to degree 10

julia&gt; f = Ψ \ (xy -&gt; sin(first(xy))+last(xy)).(xy); # Expand sin(x+y)

julia&gt; M = Φ' * Φ; # mass matrix

julia&gt; D = Derivative(axes(Φ,1)); A = (D*Φ)' * (D*Φ); # stiffness matrix

julia&gt; b = (Φ' * Ψ) .* f; # load vector

julia&gt; u = Matrix.(A .+ M) .\ b; # Solve (-Δ + I)u = f with zero Nuemann bcs
