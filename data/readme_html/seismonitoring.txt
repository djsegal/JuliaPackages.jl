<p dir="auto">Currently we have a problem when adding the <code>SeisIO.jl</code> using Mac M1 chip.
To avoid the error, try one of the options below:</p>
<ul dir="auto">
<li>Option 1. Use the forked version of SeisIO. Type the follwing command in the Julia REPL:</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Pkg; Pkg.add(url=&quot;https://github.com/kura-okubo/SeisIO.jl&quot;);"><pre class="notranslate"><code>using Pkg; Pkg.add(url="https://github.com/kura-okubo/SeisIO.jl");
</code></pre></div>
<ul dir="auto">
<li>
<p dir="auto">Option 2. Use the Docker container following
<a href="https://github.com/kura-okubo/SeisMonitoring_Example"><strong>SeisMonitoring_Example</strong></a>.</p>
</li>
<li>
<p dir="auto">Option 3.  Follow (<a href="https://github.com/jpjones76/SeisIO.jl/pull/94/commits/9a8b4510636e442e89f3d0a76f63abc56f1ab054">https://github.com/jpjones76/SeisIO.jl/pull/94/commits/9a8b4510636e442e89f3d0a76f63abc56f1ab054</a>).
We need to install the <code>SeisIO.jl</code> in develop directory:</p>
</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="]dev SeisIO "><pre class="notranslate"><code>]dev SeisIO 
</code></pre></div>
<p dir="auto">Then, edit the <code>~/.julia/dev/SeisIO/Project.toml</code> such that</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="HDF5 = &quot;0.12.3, 0.13, 0.14.2&quot;
LightXML = &quot;0.8.1, 0.9&quot;"><pre class="notranslate"><code>HDF5 = "0.12.3, 0.13, 0.14.2"
LightXML = "0.8.1, 0.9"
</code></pre></div>
<p dir="auto">You can avoid the precompile error for those packages. We corrected these dependencies in the forked version used in the option 1 above.</p>
