<p dir="auto">Enums without named instances.</p>
<p dir="auto">The <code>Base.@enum</code> macro creates <em>named</em> instances for the subtypes of <code>Enum</code>. However, providing unique names for those instances can sometimes be problematic, especially when it comes to code generation.</p>
<p dir="auto">To address these issues, some packages (such as <a href="https://github.com/fredrikekre/EnumX.jl">EnumX.jl</a>) offer alternatives to the <code>Base.@enum</code> macro. These alternatives involve implementing instances in a module.</p>
<p dir="auto">This package takes it a step further by not naming the instances at all! The idea is that knowing the subtype of <code>Enum</code> should be sufficient to understand the values of an enum. Therefore, it should be possible to manipulate the instances using their symbols. Additionally, since the Julia compiler propagates constant symbols, no performance impact is expected.</p>

<p dir="auto">The package provides the exported <code>@anonymousenum</code> macro for creating an <code>Enum</code> subtype. This macro can be used similarly to <code>Base.@enum</code>.</p>

<p dir="auto">This package was developed to generate enums from type schemas while keeping the generated types and scopes as implementation details of the code generator.</p>
<p dir="auto">Using this package allows generating an API like the following:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; writer.fruit.type = :apple
julia&gt; if reader.fruit.type == :apple
           # do something
       elseif reader.fruit.type == :banana
           # do something else
       end"><pre>julia<span class="pl-k">&gt;</span> writer<span class="pl-k">.</span>fruit<span class="pl-k">.</span>type <span class="pl-k">=</span> <span class="pl-c1">:apple</span>
julia<span class="pl-k">&gt;</span> <span class="pl-k">if</span> reader<span class="pl-k">.</span>fruit<span class="pl-k">.</span>type <span class="pl-k">==</span> <span class="pl-c1">:apple</span>
           <span class="pl-c"><span class="pl-c">#</span> do something</span>
       <span class="pl-k">elseif</span> reader<span class="pl-k">.</span>fruit<span class="pl-k">.</span>type <span class="pl-k">==</span> <span class="pl-c1">:banana</span>
           <span class="pl-c"><span class="pl-c">#</span> do something else</span>
       <span class="pl-k">end</span></pre></div>
<p dir="auto">Note that in the example above, the symbols <code>:apple</code> and <code>:banana</code> are constant, enabling the same performance as traditional enums.</p>
