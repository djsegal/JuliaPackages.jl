<p dir="auto">This package provides read / write functionality for <a href="http://www.xcrysden.org/doc/XSF.html" rel="nofollow">XCrySDen XSF</a> atomic structure files.</p>
<p dir="auto">It is <strong>strongly</strong> recommended <strong>not</strong> to use this package directly, but rather through <a href="https://github.com/mfherbst/AtomsIO.jl">AtomsIO.jl</a>, which provides a uniform interface (based on <a href="https://github.com/JuliaMolSim/AtomsBase.jl">AtomsBase</a>) for reading and writing a large range of atomistic structure files.</p>

<p dir="auto">Currently supports</p>
<ul dir="auto">
<li>r/w of molecular structures (<code>ATOMS</code>)</li>
<li>r/w of periodic structures (<code>POLYMER</code> 1D, <code>SLAB</code> 2D, <code>CRYSTAL</code> 3D)</li>
<li>r/w of molecular/periodic trajectories (<code>.axsf</code> / <code>ANIMSTEPS</code>)</li>
<li>r/w of forces, using the data key <code>:force</code> in parsed <code>AtomsBase.Atom</code> instances</li>
</ul>
<p dir="auto">Currently does <em>not</em> support</p>
<ul dir="auto">
<li>Data grids (2D and 3D)</li>
<li>Band grids (<code>.bxsf</code>)</li>
</ul>
