<p dir="auto"><code>TreeWidthSolver.jl</code> is a Julia package for solving the minimal treewidth and the corresponding tree decomposition of graphs. Currently we implemented the Bouchitte-Todinca algorithm<sup><a href="#user-content-fn-Bouchitt%C3%A9-a4e1dafa603ef8780fd01deccb8128bc" id="user-content-fnref-bouchitt%c3%a9-a4e1dafa603ef8780fd01deccb8128bc" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup><sup><a href="#user-content-fn-Korhonen-a4e1dafa603ef8780fd01deccb8128bc" id="user-content-fnref-korhonen-a4e1dafa603ef8780fd01deccb8128bc" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup>, which is a dynamic programming algorithm for solving the exact minimal treewidth problem of graphs. This package is used as a bacakend of <a href="https://github.com/TensorBFS/OMEinsumContractionOrders.jl">OMEinsumContractionOrders.jl</a> for finding the optimal tensor network contraction order.</p>
<p dir="auto">For more details about this pacakage please see the <a href="https://ArrogantGao.github.io/TreeWidthSolver.jl/stable/" rel="nofollow">docs</a>, and please refer to this <a href="https://arrogantgao.github.io/blogs/treewidth/" rel="nofollow">blog</a> for more about the algorithm we implemented.</p>
