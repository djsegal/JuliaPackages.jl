<p dir="auto">Execute a string containing a Brainfuck program using the <code>brainfuck</code> function:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Brainfuck
brainfuck(&quot;&lt;--&gt;&quot;)"><pre class="notranslate"><code>using Brainfuck
brainfuck("&lt;--&gt;")
</code></pre></div>
<p dir="auto">To work with a program stored in a file, use <code>readall</code> to generate a string
to pass to <code>brainfuck</code>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Brainfuck
path = Pkg.dir(&quot;Brainfuck&quot;, &quot;test&quot;, &quot;programs&quot;, &quot;hello2.bfk&quot;)

path = Pkg.dir("Brainfuck", "test", "programs", "hello2.bfk")
brainfuck(readall(path))
</code></pre></div>
<p dir="auto">If you want to observe the program state evolve operation-by-operation, you
can set the <code>debug</code> keyword argument to <code>false</code> when running <code>brainfuck</code>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Brainfuck

path = Pkg.dir("Brainfuck", "test", "programs", "hello2.bfk")
brainfuck(readall(path), debug = true)
</code></pre></div>
<p dir="auto"><em>Be warned that the state evolution of the Brainfuck interpreter will produce
a lot of output for even the simplest programs.</em></p>

<p dir="auto"><strong>OP1: <code>&gt;</code></strong></p>
<p dir="auto">Move the Memory Pointer to the next array cell.</p>
<p dir="auto"><strong>OP2: <code>&lt;</code></strong></p>
<p dir="auto">Move the Memory Pointer to the previous array cell.</p>
<p dir="auto"><strong>OP3: <code>+</code></strong></p>
<p dir="auto">Increment the array cell pointed at by the Memory Pointer.</p>
<p dir="auto"><strong>OP4: <code>-</code></strong></p>
<p dir="auto">Decrement the array cell pointed at by the Memory Pointer.</p>
<p dir="auto"><strong>OP5: <code>,</code></strong></p>
<p dir="auto">Read a character from STDIN and put its ASCII value into the cell
pointed at by the Memory Pointer.</p>
<p dir="auto"><strong>OP6: <code>.</code></strong></p>
<p dir="auto">Print the character with ASCII value equal to the value in the cell
pointed at by the Memory Pointer.</p>
<p dir="auto"><strong>OP7: <code>[</code></strong></p>
<p dir="auto">Move to the command following the matching <code>]</code> if the value in
the cell pointed at by the Memory Pointer is zero. Note that
<code>[</code> and <code>]</code> commands nest like pairs of parentheses, and
matching pairs are defined in the same way as for parentheses.</p>
<p dir="auto"><strong>OP8: <code>]</code></strong></p>
<p dir="auto">Move to the command following the matching <code>[</code> if the value in
the cell pointed at by the Memory Pointer is non-zero. <strong>Note that this
implies that the interpreter will work its way backwards through the
source code, rather than forwards.</strong></p>
