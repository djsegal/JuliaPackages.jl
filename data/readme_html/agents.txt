<p dir="auto">Agents.jl is a pure <a href="https://julialang.org/" rel="nofollow">Julia</a> framework for agent-based modeling (ABM): a computational simulation methodology where autonomous agents react to their environment (including other agents) given a predefined set of rules.
Some major highlights of Agents.jl are:</p>
<ol dir="auto">
<li>It is fast (faster than MASON, NetLogo, or Mesa)</li>
<li>It is simple: has a very short learning curve and requires writing minimal code</li>
<li>Has an extensive interface of thousands of out-of-the box possible agent actions</li>
<li>Straightforwardly allows simulations on Open Street Maps</li>
<li>Allows both traditional discrete-time ABM simulations as well as continuous time
"event queue based" ABM simulations.</li>
</ol>
<p dir="auto">More information and an extensive list of features can be found in the documentation, which you can either find <a href="https://juliadynamics.github.io/Agents.jl/stable/" rel="nofollow">online</a> or build locally by running the <code>docs/make.jl</code> file.</p>
