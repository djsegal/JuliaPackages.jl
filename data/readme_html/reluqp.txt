<p dir="auto">To run the examples, first set up the examples environment by running the following in a Julia REPL
in the examples folder (this only needs to be done once).</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Pkg
