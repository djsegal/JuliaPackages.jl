<p dir="auto">This package has the purpose to provide a way to render numbers in a more visual way for
data analysis. Currently, we only have the text back end.</p>
<p dir="auto">The function to pretty print the numbers have the following signature:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pretty_number([io::IO, | String, ]number::Number; kwargs...)"><pre><span class="pl-c1">pretty_number</span>([io<span class="pl-k">::</span><span class="pl-c1">IO</span>, <span class="pl-k">|</span> String, ]number<span class="pl-k">::</span><span class="pl-c1">Number</span>; kwargs<span class="pl-k">...</span>)</pre></div>
<p dir="auto">If the first argument is an <code>io</code>, the number is printed to it. If it is a <code>String</code>, a string
is returned with the printed number. It it is omitted, it defaults to <code>stdout</code>.</p>
<p dir="auto">The number will be printed using the specified <code>backend</code>. The following options are
available:</p>
<ul dir="auto">
<li><code>Val(:latex)</code>: LaTeX back end.</li>
<li><code>Val(:text)</code>: Text back end.</li>
</ul>

<p dir="auto">These are the general keywords available in all back ends. Notice that each back end defines
a set of specific keywords as shown in the sections below.</p>
<p dir="auto">All keywords depends on the type of the <code>number</code>.</p>

</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Numbers</h3><a id="user-content-numbers" class="anchor" aria-label="Permalink: Numbers" href="#numbers"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Otherwise, the <code>number</code> is printed using the scientific notation in the base 10. In this
case, the following keywords are available:</p>
<ul dir="auto">
<li><code>always_print_base::Bool</code>: If <code>true</code>, the base is always printed even if the base exponent
is 0.
(<strong>Default</strong> = <code>false</code>)</li>
<li><code>significand_format::String</code>: The format that will be used to print the signifcand, as
described by the function <code>Printf.@printf</code>.
(<strong>Default</strong> = <code>"%g"</code>)</li>
<li><code>show_base::Bool</code>: If <code>true</code>, the base will be printed. Otherwise, it will be omitted.
(<strong>Default</strong> = <code>true</code>)</li>
<li><code>show_significand::Bool</code>: If <code>true</code>, the significand will be printed. Otherwise, it will
be omitted.
(<strong>Default</strong> = <code>true</code>)</li>
<li><code>new_decimal_base::Union{Nothing, Number}</code>: If it is a number, the decimal base of the
number will be converted to this number. If it is <code>nothing</code>, the base is not changed.
(<strong>Default</strong> = <code>nothing</code>)</li>
</ul>

<p dir="auto">Those keywords apply for the LaTeX back end only and for all supported number types.</p>
<ul dir="auto">
<li><code>math_env::Symbol</code>: The math environment type to wrap the output in if <code>wrap_in_math_env</code>
is <code>true</code>. The possible options are <code>:inline</code> for inline LaTeX math environment (<code>\$</code>),
or <code>:equation</code> for using <code>\begin{equation} .. \end{equation}</code>.
(<strong>Default</strong>: <code>:inline</code>)</li>
<li><code>wrap_in_math_env::Bool</code>: If <code>true</code>, the output will be wrapped in a math environment. The
user can select which environment the function will use in the keyword <code>math_env</code>.
(<strong>Default</strong>: <code>false</code>)</li>
</ul>
