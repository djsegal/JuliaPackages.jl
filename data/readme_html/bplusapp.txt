<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto">The graphics, input, and GUI packages for <a href="https://github.com/heyx3/B-plus">B+</a>. Refer to the main repo for documentation.</p>
<p dir="auto">The modules contained here are:</p>
<ul dir="auto">
<li>GL</li>
<li>Input</li>
<li>GUI</li>
<li>ModernGL fork (see below for explanation)</li>
</ul>
<p dir="auto">If you only want this package, without the rest of B+, you can add <code>BplusApp</code> to your project and then do <code>using BplusApp; @using_bplus_app</code> to import all modules.</p>

<p dir="auto">This project keeps a fork of <a href="https://github.com/JuliaGL/ModernGL.jl">ModernGL</a>, called <code>ModernGLbp</code>, which adds ARB extensions and some UX improvements.</p>
<p dir="auto">It is technically kept as a copy rather than a git submodule, because I don't know if Yggdrasil (Julia's package build system) can handle git submodules. However, <code>ModernGLbp</code> is also maintained as a true fork <a href="https://github.com/heyx3/ModernGL.jl">here on Github</a>, and if you're working on <code>BplusApp</code> you can quite easily treat this in-repo copy like a git submodule, with the following steps:</p>
<ol dir="auto">
<li>Clone the ModernGL fork somewhere else.</li>
<li>Copy <em>.git/</em> from that cloned repo, into this repo at <em>BplusApp/src/ModernGL_fork/</em></li>
</ol>
<p dir="auto">This project's <em>.gitignore</em> file is configured to ignore the inner <em>.git/</em> folder.
The forked code will belong to both repos, BplusApp and ModernGL.
<code>cd</code> into <em>BplusApp/src/ModernGL_fork/</em> to work within ModernGL, and move outside there to work within BplusApp.</p>
