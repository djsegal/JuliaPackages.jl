<p dir="auto"><strong>StatisticalProcessMonitoring.jl</strong> is a comprehensive package for Statistical Process Monitoring, which provides users with tools for monitoring the stability of sequential processes.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Package Features</h2><a id="user-content-package-features" class="anchor" aria-label="Permalink: Package Features" href="#package-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package implements a number of univariate and multivariate control charts, as well as control charts for monitoring partially-observed processes, profiles, and support for multi-chart designs.</p>
<p dir="auto">Various type of control limits are implemented, with dedicated algorithms for estimating their values based on common metrics such as in-control average run length and in-control run length quantiles.</p>
<p dir="auto">Hyperparameter tuning is supported with a native grid search implementation, as well as black-box optimization.</p>
<p dir="auto">To ensure the package loads quickly, two extensions are <a href="https://pkgdocs.julialang.org/v1/creating-packages/#Conditional-loading-of-code-in-packages-(Extensions)" rel="nofollow">conditionally loaded</a> only if needed:</p>
<ul dir="auto">
<li><strong>PlottingSPM.jl</strong>: functionalities for plotting the results of applying a control chart to a dataset. This extension can be loaded by running <code>using Plots</code> after loading the <strong>StatisticalProcessMonitoring.jl</strong> package.</li>
<li><strong>NLoptSPM.jl</strong>: functionalities for hyperparameter tuning using the <a href="https://github.com/JuliaOpt/NLopt.jl">NLopt</a> package. This extension can be loaded by running <code>using NLopt</code> after loading the <strong>StatisticalProcessMonitoring.jl</strong> package.</li>
</ul>
<p dir="auto">The package is highly extensible and can incorporate custom monitoring statistics.</p>
