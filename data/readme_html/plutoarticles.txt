<blockquote>
<p dir="auto">A Pluto.jl styling and utilities library for notebooks intended to be articles.</p>
</blockquote>
<p dir="auto">For text-heavy notebooks like articles, this package helps shift the "feel" from that of a notebook environment to an article.</p>
<p dir="auto"><em><a href="https://glassnotebook.io/r/jEft6_lPVdJLsD56RTtBl/docs/TH-with.jl" rel="nofollow">See live example</a></em></p>

<p dir="auto">It's super easy! Just add the following to your existing Pluto.jl notebook:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PlutoArticles
article()  # make sure this is in its own cell!"><pre><span class="pl-k">using</span> PlutoArticles
<span class="pl-c1">article</span>()  <span class="pl-c"><span class="pl-c">#</span> make sure this is in its own cell!</span></pre></div>
<p dir="auto">You won't see anything happen - the updated styles will only apply <strong>once the notebook is exported</strong>. If you want to try them out in your editor, specify the <code>preview</code> keyword argument.</p>

<p dir="auto">Most of the changes are subtle. Here's a list of the most notable ones:</p>
<ul dir="auto">
<li>More ergonomic font choice for reading</li>
<li>Increased font size for devices with large screens</li>
<li>Widened notebook column for larger screens</li>
<li>Slightly adjusted header spacing</li>
</ul>
