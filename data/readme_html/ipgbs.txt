<p dir="auto">The IPGBs package provides tools for the solution of Integer Programs with Gröbner Bases. Currently, it provides
a state-of-the-art implementation of the Geometric Buchberger algorithm and a work in progress implementation
of Project-and-lift.</p>
<p dir="auto">It also provides a Julia interface to <a href="https://github.com/4ti2/4ti2">4ti2</a>, another state-of-the-art
Gröbner basis solver. In particular, it allows using the <code>groebner</code>, <code>normalform</code> and <code>minimize</code>
commands with either input matrices, as in the original 4ti2 interface, or using a JuMP model.</p>
<p dir="auto">For implementation details and documentation, see <a href="https://gmlangeloh.github.io/IPGBs.jl/" rel="nofollow">the docs page</a>.</p>

<p dir="auto">The IPGBs interface to 4ti2 depends on a local installation of 4ti2 and on the desired 4ti2 commands being available in the PATH.
4ti2 is not otherwise necessary to use any IPGBs functionality aside from the IPGBs.FourTi2 module.</p>

<p dir="auto">The easiest way to use IPGBs is by building an IP with JuMP and then calling IPGBs <code>groebner_basis</code> command.
For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    using IPGBs

    using IPGBs.FourTi2 #To access the 4ti2 interface

    A = [10 6 2 5 3]
    b = [13]

    @variable(model, x[1:5] &gt;= 0, Int)
    @objective(model, Max, c' * x)
    @constraint(model, A * x &lt;= b)

    gb_ipgbs = groebner_basis(model)

<p dir="auto">Current experimental results for IPGBs can be found in the <a href="https://github.com/gmlangeloh/IPGBs-Experiments">IPGBs-Experiments</a>
repository. It provides .mps files for each instance and logs from which results can be extracted with
the <code>generate_tables.jl</code> script. The script <code>full_groebner_basis.jl</code> can be used to
rerun IPGBs and 4ti2 over all instances in this directory.</p>
