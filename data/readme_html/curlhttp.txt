<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto"><code>CurlHTTP</code> is a wrapper around <a href="https://github.com/JuliaWeb/LibCURL.jl">LibCURL</a> that provides a more Julia like interface to doing HTTP via <code>Curl</code>.</p>

<p dir="auto">In particular, this module implements the <code>CurlEasy</code> and <code>CurlMulti</code> interfaces for curl, and allows using Client TLS certificates.</p>
<p dir="auto">This module reexports <code>LibCURL</code> so everything available in <code>LibCURL</code> will be available when this module is used.</p>
<p dir="auto">See <a href="https://curl.se/libcurl/c/libcurl-tutorial.html" rel="nofollow">https://curl.se/libcurl/c/libcurl-tutorial.html</a> for a tutorial on using libcurl in C. The Julia interface should be similar.</p>
