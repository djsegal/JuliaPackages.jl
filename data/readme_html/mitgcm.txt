<p dir="auto">Julia interface to <a href="https://mitgcm.readthedocs.io/en/latest/?badge=latest" rel="nofollow">MITgcm</a> that allows user not only to analyze model output, but also to download the source code, build the model executable, modify run-time parameters, run model simulations, or verify model results against a benchmark.</p>
<p dir="auto">Notebooks and tutorials are found in <a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/" rel="nofollow">the docs</a>.</p>
<details>
  <summary><b>Examples / How-To </b></summary>
<p dir="auto">To open a notebook using <a href="https://featured.plutojl.org" rel="nofollow">Pluto.jl</a>:</p>
<ol dir="auto">
<li>open <code>julia</code> in terminal window</li>
<li>type command below at the <code>Julia</code> prompt</li>
<li><em>new web browser tab should show <code>Pluto</code> prompt</em></li>
<li>copy/paste a notebook URL from <a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/" rel="nofollow">the docs</a></li>
</ol>

</code></pre></div>
</details>
<details>
  <summary><b>Examples / Running Models </b></summary>
<ul dir="auto">
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/MITgcm_configurations.html" rel="nofollow">MITgcm_configurations.jl</a> : explore MITgcm configurations and their parameters.</li>
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/MITgcm_worklow.html" rel="nofollow">MITgcm_worklow.jl</a> : build, setup, run, and plot for any standard configuration.</li>
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/MITgcm_run.html" rel="nofollow">MITgcm_run.jl</a> : a more detailed look into compiling and running the model.</li>
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/MITgcm_scan_output.html" rel="nofollow">MITgcm_scan_output.jl</a> : scan <code>output.txt</code>, read grid, viz with <code>Makie.jl</code></li>
</ul>
</details>
<details>
  <summary><b>Examples / Analyzing Results </b></summary>
<ul dir="auto">
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/HS94_animation.html" rel="nofollow">HS94_animation.jl</a> : run <code>hs94.cs-32x32x5</code>, read output, interpolate, and animate map</li>
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/HS94_particles.html" rel="nofollow">HS94_particles.jl</a> : compute particle trajectories from <code>hs94.cs-32x32x5</code> output</li>
<li><a href="https://gaelforget.github.io/MITgcm.jl/dev/examples/HS94_Makie.html" rel="nofollow">HS94_Makie.jl</a> : example using <code>Makie.jl</code> instead of <code>Plots.jl</code></li>
</ul>
</details>
