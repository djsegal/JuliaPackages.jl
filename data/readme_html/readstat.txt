<p dir="auto">The ReadStat.jl Julia package uses the <a href="https://github.com/WizardMac/ReadStat">ReadStat</a> C library to parse binary and transport files from Stata, SPSS and SAS. All functions return a <code>ReadStatDataFrame</code> whose fields hold the various informations contained in the passed file (column names, column data, labels, formats...).</p>
<p dir="auto">For integration with packages like <a href="https://github.com/JuliaData/DataFrames.jl">DataFrames.jl</a> you should use the <a href="https://github.com/queryverse/StatFiles.jl">StatFiles.jl</a> package.</p>
