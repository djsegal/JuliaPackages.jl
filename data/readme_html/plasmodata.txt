<p dir="auto">PlasmoData.jl is a package for <a href="https://julialang.org/" rel="nofollow">Julia</a> designed for representing and modeling data as graphs and for building graph models that contain large amounts of data on the nodes or edges of the graph. This package also has an accompanying package <a href="https://github.com/zavalab/PlasmoDataPlots.jl">PlasmoDataPlots.jl</a> which can be used for plotting the graphs.</p>
<p dir="auto">PlasmoData.jl is built on the abstraction called a <code>DataGraph</code>. The manuscript <a href="https://arxiv.org/abs/2401.11404" rel="nofollow">"PlasmoData.jl -- A Julia Framework for Modeling and Analyzing Complex Data as Graphs"</a> details the abstraction and this package.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">PlasmoData.jl is designed to store data within the graph structure and to manipulate that graph based on the data. It extends the package <a href="https://github.com/JuliaGraphs/Graphs.jl">Graphs.jl</a>, which is a highly optimized and efficient package in Julia. PlasmoData.jl enables representing datasets (such as matrices, images, or tensors) as graphs and for performing some topological data analysis (TDA). Some of these concepts can be found in <a href="https://www.sciencedirect.com/science/article/pii/S0098135421002416?ref=pdf_download&amp;fr=RR-2&amp;rr=76810ff31b5361c2" rel="nofollow">this paper</a>.</p>
<p dir="auto">PlasmoData.jl uses an object <code>DataGraph</code> (or <code>DataDiGraph</code> for directed graphs) to store information. These objects contain the following features:</p>
<ul dir="auto">
<li><code>g</code>: <code>SimpleGraph</code> (or <code>SimpleDiGraph</code> for directed graphs) containing the graph structure.</li>
<li><code>nodes</code>: A vector of nodes, where the entries of the vector are node names. These names are of type <code>Any</code> so that the nodes can use a variety of naming conventions (strings, symbols, tuples, etc.)</li>
<li><code>edges</code>: A vector of tuples, where each tuple contains two entries, where each entry relates to a node.</li>
<li><code>node_map</code>: A dictionary that maps the node names to their index in the <code>nodes</code> vector</li>
<li><code>edge_map</code>: A dictionary that maps the edges to their index in the <code>edges</code> vector.</li>
<li><code>node_data</code>: An object of type <code>NodeData</code> that includes a matrix of data, where the first dimension of the matrix corresponds to the node, and the second dimension corresponds to attributes for the nodes. Any number of attributes is allowed, and <code>NodeData</code> also includes attribute names and a mapping of the attribute name to the column of the data matrix.</li>
<li><code>edge_data</code>: An object of type <code>EdgeData</code> that includes a matrix of data, where the first dimension fo the matrix corresponds to the edges, and the second dimension corresponds to attributes for the edges. Any number of attributes is allowed, and <code>EdgeData</code> also includes attribute names and a mapping of the attribute name to the column of the data matrix.</li>
<li><code>graph_data</code>: An object of type <code>GraphData</code> that includes a vector of data whose dimension corresponds to the number of attributes for the graph. Any number of attributes is allowed, and <code>GraphData</code> also includes attribute names and a mapping of the attribute name to the entry in the vector.</li>
</ul>
<p dir="auto">PlasmoData.jl includes several functions for building graphs from specific data structures, including functions like <code>matrix_to_graph</code>, <code>symmetric_matrix_to_graph</code>, and <code>tensor_graph</code> which build specific graph structures an save data to those structures.</p>
<p dir="auto">PlasmoData.jl also includes functions for manipulating graph structure and analyzing the resulting topology of those structures. Functions <code>filter_nodes</code>, <code>filter_edges</code>, or <code>aggregate</code> change the graph structure based on the arguments passed to the functions. There are also functions such as <code>get_EC</code>, <code>run_EC_on_nodes</code>, and <code>run_EC_on_edges</code> that get the Euler Characteristic or the Euler Characteristic Curve for a graph, and other functions such as <code>cycle_basis</code>, <code>diameter</code>, or <code>average_degree</code> (largely extensions of Graphs.jl) for finding other topological descriptors.</p>
<p dir="auto">Support for <code>DataDiGraph</code>s is still underway. However, for <code>DataGraph</code> objects, all functions shown above have doc strings, which can be accessed through the REPL by first typing <code>?</code> and then the function or object name.</p>
