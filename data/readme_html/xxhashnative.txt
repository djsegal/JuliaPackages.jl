<p dir="auto">For a wrapper package, see <a href="https://github.com/hros/XXhash.jl">XXhash.jl</a>.</p>
<p dir="auto">We referred to the <a href="https://github.com/Cyan4973/xxHash/blob/v0.8.2/doc/xxhash_spec.md#xxh3-algorithm-overview">reference spec</a> from the official repository.</p>
<p dir="auto">This package provides native Julia implementations for some of the
<a href="https://github.com/Cyan4973/xxHash/">XXHash</a> algorithms. Currently, only
one-shot hashing is supported. And see the following table for the supported
algorithms:</p>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> XXH32</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> XXH64</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> XXH3_64</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> XXH3_128</li>
</ul>
