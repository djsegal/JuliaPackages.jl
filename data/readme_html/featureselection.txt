<p dir="auto">Repository housing feature selection algorithms for use with the machine learning toolbox <a href="https://juliaai.github.io/MLJ.jl/dev/" rel="nofollow">MLJ</a>.</p>
<p dir="auto">This package provides a collection of feature selection algorithms designed for use with MLJ, a powerful machine learning toolbox in Julia. It aims to facilitate the process of selecting the most relevant features from your datasets, enhancing the performance and interpretability of your machine learning models.</p>
