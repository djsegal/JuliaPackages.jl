<p dir="auto">A Julia module that offers various tools for analysing nonlinear dynamics and chaotic behaviour.
It can be used as a standalone package, or as part of <a href="https://juliadynamics.github.io/DynamicalSystemsDocs.jl/dynamicalsystems/dev/" rel="nofollow">DynamicalSystems.jl</a>.</p>
<p dir="auto">To install it, run <code>import Pkg; Pkg.add("ChaosTools")</code>.</p>
<p dir="auto">All further information is provided in the documentation, which you can either find online or build locally by running the <code>docs/make.jl</code> file.</p>
<p dir="auto"><em>ChaosTools.jl is the jack-of-all-trades package of the DynamicalSystems.jl library: methods that are not extensive enough to be a standalone package are added here. You should see the full DynamicalSystems.jl library for other packages that may contain functionality you are looking for but did not find in ChaosTools.jl.</em></p>
