<p dir="auto"><em>A julia wrapper for the <a href="http://porta.zib.de/" rel="nofollow">PORTA</a> polyhedral analysis software.</em></p>
<p dir="auto"><a href="https://JuliaPolyhedra.github.io/XPORTA.jl/dev" rel="nofollow"><img src="https://camo.githubusercontent.com/45c316268f541933640ad68f61395986888f4d46bc9641b40e53d337576c6456/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6465762d626c75652e737667" alt="Dev" data-canonical-src="https://img.shields.io/badge/docs-dev-blue.svg" style="max-width: 100%;"></a><a href="https://github.com/JuliaPolyhedra/XPORTA.jl/actions/workflows/run_tests.yml"><img src="https://github.com/JuliaPolyhedra/XPORTA.jl/actions/workflows/run_tests.yml/badge.svg" alt="Test Status" style="max-width: 100%;"></a></p>
<p dir="auto">XPORTA provides two features:</p>
<ul dir="auto">
<li>a thin wrapper around the complete PORTA API</li>
<li>an interface to <a href="https://github.com/JuliaPolyhedra/Polyhedra.jl">Polyhedra</a></li>
</ul>
