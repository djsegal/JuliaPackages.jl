<p dir="auto">This is a package for solving equations of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$$
\frac{\partial u}{\partial t} = \frac{\partial}{\partial x}\left(D(u, x, t)\frac{\partial u}{\partial x}\right) + R(u, x, t)
$$</math-renderer></p>
<p dir="auto">using the finite volume method over intervals <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$a \leq x \leq b$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$t_0 \leq t \leq t_1$</math-renderer>, with support for the following types of boundary conditions (shown at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$x = a$</math-renderer>, but you can mix boundary condition types, e.g. Neumann at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$x=a$</math-renderer> and Dirichlet at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$x=b$</math-renderer>):</p>
<ul dir="auto">
<li>
<code>Neumann</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$\dfrac{\partial u(a, t)}{\partial x} = a_0\left(u(a, t), t\right)$</math-renderer>.</li>
<li>
<code>Dirichlet</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$u(a, t) = a_0\left(u(a, t), t\right)$</math-renderer> (this is not an implicit equation for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$u(a, t)$</math-renderer>, rather <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$u(a, t)$</math-renderer> is mapped from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4d76d065c73a1a5a6d7892cc1d2d8e28">$a_0\left(u(a, t), a, t\right)$</math-renderer>.</li>
</ul>
<p dir="auto">For examples on how to use it, please see the docs. If you want a more complete two-dimensional version, please see my other package <a href="https://github.com/SciML/FiniteVolumeMethod.jl">FiniteVolumeMethod.jl</a>.</p>
