<p dir="auto">ClimaAtmos.jl is the atmosphere components of the CliMA software stack. We strive for a user interface that makes ClimaAtmos.jl as friendly and intuitive to use as possible, allowing users to focus on the science.</p>

<p dir="auto">Recommended Julia: Stable release v1.10.0</p>
<p dir="auto">ClimaAtmos.jl is a <a href="https://julialang.org/packages/" rel="nofollow">registered Julia package</a>. To install</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg

julia&gt; Pkg.add(&quot;ClimaAtmos&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg

julia<span class="pl-k">&gt;</span> Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>ClimaAtmos<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Alternatively, download the <code>ClimaAtmos</code>
<a href="https://github.com/CliMA/ClimaAtmos.jl">source</a> with:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ git clone https://github.com/CliMA/ClimaAtmos.jl.git"><pre class="notranslate"><code>$ git clone https://github.com/CliMA/ClimaAtmos.jl.git
</code></pre></div>
<p dir="auto">Now change into the <code>ClimaAtmos.jl</code> directory with</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Running instructions</h2><a id="user-content-running-instructions" class="anchor" aria-label="Permalink: Running instructions" href="#running-instructions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Currently, the simulations are stored in the <code>test</code> folder. Run all the test cases with the following commands.</p>
<p dir="auto">First, we instantiate the test environment, by launching (from <code>ClimaAtmos.jl/</code>) Julia with the <code>test/</code> environment active:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia --project=test"><pre class="notranslate"><code>$ julia --project=test
</code></pre></div>
<p dir="auto">Then, once in the Julia REPL, we switch to the package manager by pressing <code>]</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ]"><pre>julia<span class="pl-k">&gt;</span> ]</pre></div>
<p dir="auto">Once in the package manager, we <code>develop</code> the <code>ClimaAtmos.jl/</code> directory:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="test&gt; dev ."><pre lang="pkg" class="notranslate"><code>test&gt; dev .
</code></pre></div>
<p dir="auto">Now, we can switch back to the Julia REPL by escaping and run the test suite interactively:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; include(joinpath(&quot;test&quot;, &quot;runtests.jl&quot;))"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">include</span>(<span class="pl-c1">joinpath</span>(<span class="pl-s"><span class="pl-pds">"</span>test<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>runtests.jl<span class="pl-pds">"</span></span>))</pre></div>
<p dir="auto">Or escape the Julia REPL and run from the command line:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia --project=test test/runtests.jl"><pre class="notranslate"><code>$ julia --project=test test/runtests.jl
</code></pre></div>
<p dir="auto">If you run into issues when running the test suite this way, please open an issue.</p>

<p dir="auto">If you're interested in contributing to the development of ClimaAtmos we want your help no matter how big or small a contribution you make! It's always great to have new people look at the code with fresh eyes: you will see errors that other developers have missed.</p>
<p dir="auto">Let us know by <a href="https://github.com/CliMA/ClimaAtmos.jl/issues/new">opening an issue</a> if you'd like to work on a new feature.</p>
