<p dir="auto">A fast implementation of Almost Banded Matrices in Julia. Primarily developed for use in
<a href="https://github.com/SciML/BoundaryValueDiffEq.jl">BoundaryValueDiffEq.jl</a>.</p>
<p dir="auto"><a href="https://github.com/JuliaLinearAlgebra/SemiseparableMatrices.jl">SemiseparableMatrices.jl</a>
provides an alternate implementation of almost banded matrices, but that had considerable
overhead for our use-case. This implementation borrows a lot of details from that
repository.</p>
