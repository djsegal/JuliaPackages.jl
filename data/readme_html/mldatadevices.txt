<p dir="auto"><code>MLDataDevices.jl</code> is a lightweight package defining rules for transferring data across
devices. It is used in deep learning frameworks such as <a href="https://lux.csail.mit.edu/" rel="nofollow">Lux.jl</a>.</p>
<p dir="auto">Currently we provide support for the following backends:</p>
<ol dir="auto">
<li><code>CUDA.jl</code> for NVIDIA GPUs.</li>
<li><code>AMDGPU.jl</code> for AMD ROCM GPUs.</li>
<li><code>Metal.jl</code> for Apple Metal GPUs. <strong>(Experimental)</strong></li>
<li><code>oneAPI.jl</code> for Intel GPUs. <strong>(Experimental)</strong></li>
</ol>
