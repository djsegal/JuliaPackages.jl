<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">🧪 Testing</h3><a id="user-content--testing" class="anchor" aria-label="Permalink: 🧪 Testing" href="#-testing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The full test of <code>Lux.jl</code> takes a long time, here's how to test a portion of the code.</p>
<p dir="auto">For each <code>@testitem</code>, there are corresponding <code>tags</code>, for example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@testitem &quot;SkipConnection&quot; setup=[SharedTestSetup] tags=[:core_layers]"><pre><span class="pl-c1">@testitem</span> <span class="pl-s"><span class="pl-pds">"</span>SkipConnection<span class="pl-pds">"</span></span> setup<span class="pl-k">=</span>[SharedTestSetup] tags<span class="pl-k">=</span>[<span class="pl-c1">:core_layers</span>]</pre></div>
<p dir="auto">For example, let's consider the tests for <code>SkipConnection</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@testitem &quot;SkipConnection&quot; setup=[SharedTestSetup] tags=[:core_layers] begin
    ...
end"><pre><span class="pl-c1">@testitem</span> <span class="pl-s"><span class="pl-pds">"</span>SkipConnection<span class="pl-pds">"</span></span> setup<span class="pl-k">=</span>[SharedTestSetup] tags<span class="pl-k">=</span>[<span class="pl-c1">:core_layers</span>] <span class="pl-k">begin</span>
    <span class="pl-k">...</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">We can test the group to which <code>SkipConnection</code> belongs by testing <code>core_layers</code>.
To do so set the <code>LUX_TEST_GROUP</code> environment variable, or rename the tag to
further narrow the test scope:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="export LUX_TEST_GROUP=&quot;core_layers&quot;"><pre><span class="pl-k">export</span> LUX_TEST_GROUP=<span class="pl-s"><span class="pl-pds">"</span>core_layers<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">Or directly modify the default test tag in <code>runtests.jl</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# const LUX_TEST_GROUP = lowercase(get(ENV, &quot;LUX_TEST_GROUP&quot;, &quot;all&quot;))
const LUX_TEST_GROUP = lowercase(get(ENV, &quot;LUX_TEST_GROUP&quot;, &quot;core_layers&quot;))"><pre><span class="pl-c"><span class="pl-c">#</span> const LUX_TEST_GROUP = lowercase(get(ENV, "LUX_TEST_GROUP", "all"))</span>
<span class="pl-k">const</span> LUX_TEST_GROUP <span class="pl-k">=</span> <span class="pl-c1">lowercase</span>(<span class="pl-c1">get</span>(<span class="pl-c1">ENV</span>, <span class="pl-s"><span class="pl-pds">"</span>LUX_TEST_GROUP<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>core_layers<span class="pl-pds">"</span></span>))</pre></div>
<p dir="auto">But be sure to restore the default value "all" before submitting the code.</p>
<p dir="auto">Furthermore if you want to run a specific test based on the name of the testset, you can
use <a href="https://github.com/JuliaTesting/TestEnv.jl">TestEnv.jl</a> as follows. Start with activating the Lux environment and then run the following:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using TestEnv; TestEnv.activate(); using ReTestItems;

# Assuming you are in the main directory of Lux
ReTestItems.runtests(&quot;tests/&quot;; name = &quot;NAME OF THE TEST&quot;)"><pre><span class="pl-k">using</span> TestEnv; TestEnv<span class="pl-k">.</span><span class="pl-c1">activate</span>(); <span class="pl-k">using</span> ReTestItems;

<span class="pl-c"><span class="pl-c">#</span> Assuming you are in the main directory of Lux</span>
ReTestItems<span class="pl-k">.</span><span class="pl-c1">runtests</span>(<span class="pl-s"><span class="pl-pds">"</span>tests/<span class="pl-pds">"</span></span>; name <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>NAME OF THE TEST<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">For the <code>SkipConnection</code> tests that would be:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ReTestItems.runtests(&quot;tests/&quot;; name = &quot;SkipConnection&quot;)"><pre>ReTestItems<span class="pl-k">.</span><span class="pl-c1">runtests</span>(<span class="pl-s"><span class="pl-pds">"</span>tests/<span class="pl-pds">"</span></span>; name <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>SkipConnection<span class="pl-pds">"</span></span>)</pre></div>
