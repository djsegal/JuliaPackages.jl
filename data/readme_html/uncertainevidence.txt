<p dir="auto">This package provides methods for handling epistemic uncertainty, primarily implementing the <a href="https://en.wikipedia.org/wiki/Dempster%E2%80%93Shafer_theory" rel="nofollow">Dempster-Shafer Theory of Evidence (DST)</a>. It is, to some extend, a port of the <a href="https://www.uni-due.de/il/ipptoolbox.php" rel="nofollow">IPP toolbox</a> to the Julia language.</p>
<p dir="auto">This package is still in an early development phase, but the basic principles of the Dempster-Shafer framework are already present.</p>

<p dir="auto">Let's consider a simple introductory example. Two experts, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$X_1$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$X_2$</math-renderer>, state their opinions on the possible causes (<em>focal elements</em>; <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$A$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$B$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$C$</math-renderer>) of a situation. Using UncertainEvidence.jl,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using UncertainEvidence"><pre><span class="pl-k">using</span> UncertainEvidence</pre></div>
<p dir="auto">these opinions can be formulated in the following way:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# expert one

<p dir="auto">The basic probability assessment (<code>BPA</code>) is the fundamental data structure for computations. To generate a general assessment of the situation, <code>BPA</code>s can be combined with Dempster's rule of combination (more combination rules coming soon):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="X12 = combine_dempster(X1, X2)"><pre>X12 <span class="pl-k">=</span> <span class="pl-c1">combine_dempster</span>(X1, X2)</pre></div>
<p dir="auto">Based on this combined structure, the lower (<em>belief</em>) and upper bound (<em>plausibility</em>) of the likelihood of a cause can be queried:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# lower bound
bel('A', X12)

# upper bound
pls('A', X12)"><pre><span class="pl-c"><span class="pl-c">#</span> lower bound</span>
<span class="pl-c1">bel</span>(<span class="pl-s"><span class="pl-pds">'</span>A<span class="pl-pds">'</span></span>, X12)

<span class="pl-c"><span class="pl-c">#</span> upper bound</span>
<span class="pl-c1">pls</span>(<span class="pl-s"><span class="pl-pds">'</span>A<span class="pl-pds">'</span></span>, X12)</pre></div>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="X = bpa(

<p dir="auto">Note the use of <code>Set</code>s in this example; if the sum of masses is lower than 1, the remaining mass is automatically assigned to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b5875eb7fc4da8fef31bf5d6a887eff9">$\Omega$</math-renderer>, the set of all focal elements. This would fail, if all other focal elements would be of type <code>Char</code>.</p>
