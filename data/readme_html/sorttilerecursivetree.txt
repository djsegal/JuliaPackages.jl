<p dir="auto">An STR tree implementation for GeoInterface compatible geometries.</p>
<p dir="auto">Usage:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SortTileRecursiveTree
using Extents

tree = STRtree(geometries)
query_result = query(tree, Extent(X=(0, 100.5), Y=(0, 1.5)))
# or 
query_result = query(tree, query_geometry)"><pre><span class="pl-k">using</span> SortTileRecursiveTree
<span class="pl-k">using</span> Extents

tree <span class="pl-k">=</span> <span class="pl-c1">STRtree</span>(geometries)
query_result <span class="pl-k">=</span> <span class="pl-c1">query</span>(tree, <span class="pl-c1">Extent</span>(X<span class="pl-k">=</span>(<span class="pl-c1">0</span>, <span class="pl-c1">100.5</span>), Y<span class="pl-k">=</span>(<span class="pl-c1">0</span>, <span class="pl-c1">1.5</span>)))
<span class="pl-c"><span class="pl-c">#</span> or </span>
query_result <span class="pl-k">=</span> <span class="pl-c1">query</span>(tree, query_geometry)</pre></div>
<p dir="auto">The query result is a <code>Vector{Int}</code> that you can use to index into the collection of geometries from which the tree was created, under the assumption that it has not changed since then.</p>
