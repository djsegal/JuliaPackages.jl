<p dir="auto"><a href="https://github.com/alan-turing-institute/MLJ.jl">MLJ</a> is a Julia framework for
combining and tuning machine learning models. MLJFlow is a package that extends
the MLJ capabilities to use <a href="https://mlflow.org/" rel="nofollow">MLflow</a> as a backend for
model tracking and experiment management. To be specific, MLJFlow provides a
close to zero-preparation to use MLflow with MLJ; by the usage of function
extensions that automate the MLflow cycle (create experiment, create run, log
metrics, log parameters, log artifacts, etc.).</p>

found <a href="https://summerofcode.withgoogle.com/programs/2023/projects/iRxuzeGJ" rel="nofollow">here</a>.

</li>
<li class="task-list-item">
<p dir="auto"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Extends MLJ's <code>MLJ.save</code> method, to save trained machines as retrievable MLflow

</li>
<li class="task-list-item">
<p dir="auto"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Provides MLflow integration with MLJ's <code>TunedModel</code> wrapper (to log <strong>hyper-parameter

</li>
<li class="task-list-item">
<p dir="auto"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Provides MLflow integration with MLJ's <code>IteratedModel</code> wrapper (to log <strong>controlled

</li>
<li class="task-list-item">
<p dir="auto"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Plays well with <strong>composite models</strong> (pipelines, stacks, etc.)</p>
</li>
</ul>

<p dir="auto">Set <code>logger</code> as the global logging target by running <code>default_logger(logger)</code>. Then,
unless explicitly overridden, all loggable workflows will log to <code>logger</code>. In particular,
to <em>suppress</em> logging, you will need to specify <code>logger=nothing</code> in your calls.</p>

DecisionTreeClassifier = @load DecisionTreeClassifier pkg=DecisionTree
