<p dir="auto">Tempo.jl is an astronomical library that enables fast, efficient and high-accuracy
time transformations between common and user-defined time scales and time representations.</p>

<p dir="auto">Tempo.jl and AstroTime.jl are very similar libraries that allow transformations between
various astronomical time representations. The major differences are:</p>
<ul dir="auto">
<li>AstroTime.jl supports accurate Epoch transformations by leveraging high
precision arithmetics.</li>
<li>Tempo.jl is more efficient when multiple timescales conversions must be
performed to convert a given Epoch (e.g., it does not allocate memory).</li>
</ul>
