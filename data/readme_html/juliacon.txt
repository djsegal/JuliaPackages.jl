<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Terminal links</h3><a id="user-content-terminal-links" class="anchor" aria-label="Permalink: Terminal links" href="#terminal-links"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Wouldn't it be nice if one could click on talk titles in the schedule table and jump to the webpage of the respective talk? Some terminals, such as iTerm2 and GNOME Terminal, support the displaying of <a href="https://gist.github.com/egmontkob/eb114294efbcd5adb1944c9f3cb5feda">terminal-hyperlinks</a> (clickable without printing the URL). We use this terminal feature to indeed make the talk titles clickable! The only thing you need to do is call <code>JuliaCon.today(; terminal_links=true)</code>. If you like what you see, you can use <code>JuliaCon.set_terminallinks(true)</code> to set a permanent default.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Time zones</h3><a id="user-content-time-zones" class="anchor" aria-label="Permalink: Time zones" href="#time-zones"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Utilizing <a href="https://github.com/JuliaTime/TimeZones.jl">TimeZones.jl</a>, we try to respect your local time zone and try to convert all the JuliaCon UTC times appropriately. By default, we will use <code>TimeZones.localzone()</code> to figure out your local time zone. But you can also manually set your time zone via <code>set_local_timezone(tz::AbstractString)</code>. Note that you need to restart Julia to see the effect of the change.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Caching</h3><a id="user-content-caching" class="anchor" aria-label="Permalink: Caching" href="#caching"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">When it is needed, the package fetches the JuliaCon schedule (<code>schedule.json</code>) from the <a href="https://github.com/JuliaCon/JuliaConDataArchive">JuliaConDataArchive</a> and keeps the information in memory for further usage. Hence, by default, the fetching happens once per Julia session. To force an update of the JuliaCon schedule you can call <code>update_schedule()</code>.</p>
<p dir="auto">If fetching the <code>schedule.json</code> takes longer than 5 seconds - you can change this default via <code>JuliaCon.set_timeout(secs)</code> - the package will fall back to using the last cached version (which might be stale).</p>
<p dir="auto">As per default, the location of the cache is <code>.julia/datadeps/JuliaConSchedule</code>. You can use <code>JuliaCon.set_cachedir(path)</code> to change this default.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Cache modes</h4><a id="user-content-cache-modes" class="anchor" aria-label="Permalink: Cache modes" href="#cache-modes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">There are three cache modes: <code>:DEFAULT</code>, <code>:NEVER</code>, <code>:ALWAYS</code>. You can switch between them by calling <code>JuliaCon.set_cachemode(mode)</code> appropriately.</p>
<ul dir="auto">
<li><code>:DEFAULT</code>: As described above: tries to download / update the schedule and falls back to the cache if necessary.</li>
<li><code>:NEVER</code>: The cache will never be used / created. If the download fails it fails.</li>
<li><code>:ALWAYS</code>: Always use the cached <code>schedule.json</code>. Never attempts to download / update it.</li>
</ul>
