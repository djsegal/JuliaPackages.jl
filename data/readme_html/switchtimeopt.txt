<p dir="auto"><strong>SwitchTimeOpt.jl</strong> is a <a href="https://github.com/JuliaLang/julia">Julia</a> package to easily define and efficiently solve switching time optimization (STO) problems for linear and nonlinear systems. SwitchTimeOpt.jl supports a wide variety of nonlinear solvers through <a href="https://github.com/JuliaOpt/MathProgBase.jl">MathProgBase.jl</a> interface such as <a href="https://github.com/JuliaOpt/Ipopt.jl">Ipopt</a>, <a href="https://github.com/JuliaOpt/KNITRO.jl">KNITRO</a>, <a href="https://github.com/JuliaOpt/NLopt.jl">NLopt</a>.</p>
<p dir="auto"><strong>Documentation</strong> The complete interface documentation can be found <a href="http://switchtimeoptjl.readthedocs.io/en/latest/" rel="nofollow">here</a>.</p>
