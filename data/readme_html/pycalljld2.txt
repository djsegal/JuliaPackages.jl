<div id="readme" class="md" data-path="README.md"><article class="markdown-body entry-content container-lg" itemprop="text"><p dir="auto"><a href="https://AP6YC.github.io/PyCallJLD2.jl/dev" rel="nofollow"><img src="https://github.com/AP6YC/FileStorage/raw/main/PyCallJLD2/header.png?raw=true" alt="pycalljld2-header" style="max-width: 100%;"></a></p>
<p dir="auto">This package is to <a href="https://github.com/JuliaIO/JLD2.jl">JLD2</a> what <a href="https://github.com/JuliaPy/PyCallJLD.jl">PyCallJLD</a> is to <a href="https://github.com/JuliaIO/JLD.jl/">JLD</a>, implementing a serializer for saving and loading <a href="https://github.com/JuliaPy/PyCall.jl">PyCall</a> <a href="https://github.com/JuliaPy/PyCall.jl#pyobject"><code>PyObject</code></a>s with JLD2.</p>
<p dir="auto">Please see the official <a href="https://AP6YC.github.io/PyCallJLD2.jl/dev" rel="nofollow">documentation</a> for usage and contribution guidelines.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Please see the <a href="https://AP6YC.github.io/PyCallJLD2.jl/dev" rel="nofollow">documentation</a> for full usage.</p>
<p dir="auto">To save and load <code>JLD2</code>, load <code>PyCall</code>, <code>JLD2</code>, and <code>PyCallJLD2</code> in the same scope as where you intend to use the <code>JLD2.save</code> and <code>JLD2.load</code> functions.
If you are coming from <code>PyCallJLD</code>, simply replace <code>JLD</code> with <code>JLD2</code> everywhere in your usage.</p>
<p dir="auto">The following example is take from <a href="https://github.com/JuliaPy/PyCallJLD.jl">PyCallJLD</a> for direct comparison:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PyCall, JLD2, PyCallJLD2

@pyimport sklearn.linear_model as lm

# Create some Python objects
m1 = lm.LinearRegression()
m2 = lm.ARDRegression()

# Save them to models.jld2
JLD2.save(&quot;models.jld2&quot;, &quot;mods&quot;, [m1, m2])

# Load them back
models = JLD2.load(&quot;models.jld2&quot;, &quot;mods&quot;)

<p dir="auto">This package is heavily based upon the <a href="https://github.com/JuliaPy/PyCallJLD.jl"><code>PyCallJLD.jl</code></a> package; the funky-monkey-wrenching of PyCall <code>ccall</code>s, pointers, and other low-level tomfoolery would have been arcane and indecipherable without this prior work.
This package merely modifies its internal usage to match the modified <a href="https://github.com/JuliaIO/JLD2.jl"><code>JLD2</code></a> API for custom serialization.</p>
