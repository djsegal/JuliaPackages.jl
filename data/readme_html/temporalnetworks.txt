<p dir="auto"><code>TemporalNetworks.jl</code> is a package to construct and analyze graphs/networks that vary in time. The instances <code>MultilayerGraph</code>, <code>SpectralPartition</code> and <code>SEBAPartition</code>  construct temporal networks, find partitions using spacetime spectral partitioning and disentangle them using SEBA respectively. More details in the <a href="https://mkalia.com/TemporalNetworks.jl/dev/" rel="nofollow"><img src="https://camo.githubusercontent.com/45c316268f541933640ad68f61395986888f4d46bc9641b40e53d337576c6456/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6465762d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-dev-blue.svg" style="max-width: 100%;"></a>.</p>
