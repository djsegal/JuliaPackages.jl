<p dir="auto">Someimes we have code that generates random values, but we don't really care about the randomness. Maybe we just need to know the shape of the result, or we're doing <a href="https://en.wikipedia.org/wiki/Smoke_testing_(software)" rel="nofollow">smoke testing</a>. In these cases, the result of random sampling would be fine, but we might like to have something simpler without unnecessary overhead.</p>
<p dir="auto">For example,</p>
