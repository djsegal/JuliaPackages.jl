<p dir="auto"><code>MoYe.jl</code> is NVIDIA's <a href="https://github.com/NVIDIA/cutlass/blob/main/">Cutlass/CuTe</a> implemented in Julia.
The primary purpose of developing this library is my desire to learn CuTe.</p>
<p dir="auto">The name <strong>Mo Ye</strong> is derived from an ancient Chinese <a href="https://en.wikipedia.org/wiki/Gan_Jiang_and_Mo_Ye" rel="nofollow">legend of swordsmiths</a>.</p>
<p dir="auto">The documentation is mostly my learning notes. Please refer to CuTe's documentation for more details.</p>
<p dir="auto">GEMM essentially faces two main performance hurdles not implemented yet:</p>
<ol dir="auto">
<li>Swizzling to prevent bank conflicts.</li>
<li>An efficient epilogue, which involves transferring data from registers to shared memory, followed by a vectorized copy back to global memory.</li>
</ol>
<p dir="auto">Since I've sold my old laptop, I no longer have access to an NVIDIA GPU, thus the development of this library will be put on hold indefinitely.</p>
