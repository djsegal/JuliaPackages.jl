<p dir="auto">We also wrap up the correcting procedure for MARS as a standalone R package <a href="https://github.com/szcf-weiya/earth.dof.patch">earth.dof.patch</a>. By its name, it can be viewed as a patch package on the <code>earth</code> package for MARS. You can quickly try our approach after loading <code>earth</code> and <code>earth.dof.patch</code>. A toy example can be found <a href="https://hohoweiya.xyz/earth.dof.patch/articles/MSE-Comparisons.html" rel="nofollow">here</a>.</p>
