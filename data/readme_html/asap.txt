<p dir="auto">Asap is...</p>
<ul dir="auto">
<li>the anti-SAP (2000)</li>
<li>results as Soon As Possible</li>
<li>another Structural Analysis Package</li>
</ul>
<p dir="auto">Designed first-and-foremost for information-rich data structures and ease of querying, but always with performance in mind.</p>
<p dir="auto">See also: <a href="https://github.com/keithjlee/AsapToolkit">AsapToolkit</a>, <a href="https://github.com/keithjlee/AsapOptim">AsapOptim</a>, <a href="https://github.com/keithjlee/AsapHarmonics">AsapHarmonics</a>.</p>
