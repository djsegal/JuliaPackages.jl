<p dir="auto">This package contains Pluto's dependency sorting algorithm. Given a list of cell codes, PlutoDependencyExplorer can tell you in which order these cells should run. For example:</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">ExpressionExplorer.jl</h2><a id="user-content-expressionexplorerjl" class="anchor" aria-label="Permalink: ExpressionExplorer.jl" href="#expressionexplorerjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">PlutoDependencyExplorer.jl uses the low-level package <a href="https://github.com/JuliaPluto/expressionexplorer.jl">ExpressionExplorer.jl</a> to find the assignments and references of each cell. PlutoDependencyExplorer uses this information to build a dependency graph between cells (i.e. a <code>NotebookTopology</code>), which can be used to find the order to run them in (a <code>TopologicalOrder</code>).</p>
<p dir="auto">If you are interested in <strong>ordering a list of expressions</strong> in execution order (the order that Pluto runs cells in), then use PlutoDependencyExplorer.jl. If you just want to know which variables are assigned or referenced in a <strong>single expression</strong>, use ExpressionExplorer.jl.</p>

<p dir="auto">To work on this package, clone both the Pluto.jl and PlutoDependencyExplorer.jl repositories to your local drive. Then:</p>
<ol dir="auto">
<li>In your global environment (or another one), develop the Pluto and PlutoDependencyExplorer packages:
<code>(@1.10) pkg&gt; dev ~/Documents/Pluto.jl</code>
<code>(@1.10) pkg&gt; dev ~/Documents/PlutoDependencyExplorer.jl</code></li>
<li>You can <code>(@1.10) pkg&gt; test PlutoDependencyExplorer</code> to run the tests</li>
<li>You can also run Pluto, or <code>(@1.10) pkg&gt; test Pluto</code>, and it will use your local copy of PlutoDependencyExplorer. This lets you test how your changes to PlutoDependencyExplorer integrate into Pluto.</li>
</ol>
