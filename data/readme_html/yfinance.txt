<p dir="auto">The implementation of <code>YFinance.jl</code> is similar to the python package <code>yahooquery</code> in that it accesses data through API endpoints. Therefore, <strong><code>YFinance.jl</code> does not experience the same decryption issues</strong> that python’s <code>yfinance</code> faces at the moment.</p>
