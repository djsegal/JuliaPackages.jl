<p dir="auto">This package provides an interface to CUTEst, a repository of
constrained and unconstrained nonlinear programming problems for testing and
comparing optimization algorithms, derived from the abstract model on
<a href="https://github.com/JuliaSmoothOptimizers/NLPModels.jl">NLPModels.jl</a>.</p>

<p dir="auto">This package will automatically install the CUTEst binaries for your platform.
The <code>gfortran</code> compiler is required to compile decoded SIF problems.
Users on all platforms except Windows must install it to use <code>CUTEst.jl</code>.
For Windows users, a small artifact containing <code>gfortran.exe</code> is installed automatically.
No other Fortran compiler is supported.</p>
<p dir="auto">The following command installs the CUTEst binaries and the Julia interface:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add CUTEst"><pre>pkg<span class="pl-k">&gt;</span> add CUTEst</pre></div>

<p dir="auto">After installation, you can create instances of <a href="https://github.com/JuliaSmoothOptimizers/NLPModels.jl">NLPModels</a>
models using the <code>CUTEstModel</code> constructor:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CUTEst

nlp = CUTEstModel{Float64}(&quot;BYRDSPHR&quot;)"><pre><span class="pl-k">using</span> CUTEst

nlp <span class="pl-k">=</span> <span class="pl-c1">CUTEstModel</span><span class="pl-c1">{Float64}</span>(<span class="pl-s"><span class="pl-pds">"</span>BYRDSPHR<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">This model supports the same functions as other NLPModels, for example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NLPModels

fx = obj(nlp, nlp.meta.x0)
gx = grad(nlp, nlp.meta.x0)
Hx = hess(nlp, nlp.meta.x0)

cx = cons(nlp, nlp.meta.x0)
Jx = jac(nlp, nlp.meta.x0)"><pre><span class="pl-k">using</span> NLPModels

fx <span class="pl-k">=</span> <span class="pl-c1">obj</span>(nlp, nlp<span class="pl-k">.</span>meta<span class="pl-k">.</span>x0)
gx <span class="pl-k">=</span> <span class="pl-c1">grad</span>(nlp, nlp<span class="pl-k">.</span>meta<span class="pl-k">.</span>x0)
Hx <span class="pl-k">=</span> <span class="pl-c1">hess</span>(nlp, nlp<span class="pl-k">.</span>meta<span class="pl-k">.</span>x0)

cx <span class="pl-k">=</span> <span class="pl-c1">cons</span>(nlp, nlp<span class="pl-k">.</span>meta<span class="pl-k">.</span>x0)
Jx <span class="pl-k">=</span> <span class="pl-c1">jac</span>(nlp, nlp<span class="pl-k">.</span>meta<span class="pl-k">.</span>x0)</pre></div>
<p dir="auto">Problems can also be instantiated in single and quadruple precision:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CUTEst, Quadmath

nlp_single = CUTEstModel{Float32}(&quot;BYRDSPHR&quot;)
nlp_quadruple = CUTEstModel{Float128}(&quot;BYRDSPHR&quot;)"><pre><span class="pl-k">using</span> CUTEst, Quadmath

nlp_single <span class="pl-k">=</span> <span class="pl-c1">CUTEstModel</span><span class="pl-c1">{Float32}</span>(<span class="pl-s"><span class="pl-pds">"</span>BYRDSPHR<span class="pl-pds">"</span></span>)
nlp_quadruple <span class="pl-k">=</span> <span class="pl-c1">CUTEstModel</span><span class="pl-c1">{Float128}</span>(<span class="pl-s"><span class="pl-pds">"</span>BYRDSPHR<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">To retrieve the list of available SIF problems, use the function <code>list_sif_problems</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CUTEst

available_problems = list_sif_problems()"><pre><span class="pl-k">using</span> CUTEst

available_problems <span class="pl-k">=</span> <span class="pl-c1">list_sif_problems</span>()</pre></div>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CUTEst
