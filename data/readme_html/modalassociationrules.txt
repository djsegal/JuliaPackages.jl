<p dir="auto">This package is currently dependent on unregistered Julia packages. To compile the project, it is necessary to use the <code>dev</code> command of Pkg.jl, Julia's official package manager, targetting specific branch of <a href="https://github.com/aclai-lab/Sole.jl">Sole</a> ecosystem.</p>
<p dir="auto">The following instructions assume <code>~/.julia/dev/</code> as the only working directory.</p>
