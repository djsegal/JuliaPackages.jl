<p dir="auto"><a href="https://github.com/giordano/PkgCleanup.jl/actions"><img src="https://github.com/giordano/PkgCleanup.jl/workflows/CI/badge.svg" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">The <a href="https://julialang.github.io/Pkg.jl/v1/api/#Pkg.gc" rel="nofollow"><code>Pkg.gc()</code></a> command
garbage collects packages and artifacts that are no longer reachable, but will
not touch existing packages or artifacts requested by existing active
environments, which are listed in your <code>~/.julia/logs</code> directory.  One option
for a more deep cleaning is to run <code>]gc --all</code>, but this will
remove... well... all packages.</p>
<p dir="auto">If you prefer a more controlled way to clean package installations in your Julia
depot, you can remove the undesired manifests lingering in <code>~/.julia/logs</code>.
<code>PkgCleanup.jl</code> provides a couple of functions which let you interactively
remove active environments or artifacts you do not care about any longer but
cannot be removed by <code>Pkg.gc()</code>.</p>

<p dir="auto">To load the package, run in the Julia REPL the command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PkgCleanup"><pre><span class="pl-k">using</span> PkgCleanup</pre></div>
<p dir="auto"><code>PkgCleanup.jl</code> provides the following interactive functions:</p>
<ul dir="auto">
<li><code>PkgCleanup.artifacts()</code>: to remove unneeded <code>Artifacts.toml</code> from your
<code>~/.julia/logs/artifact_usage.toml</code>;</li>
<li><code>PkgCleanup.manifests()</code>: to remove unneeded <code>Manifest.toml</code> from your
<code>~/.julia/logs/manifest_usage.toml</code>.</li>
</ul>
<p dir="auto">Execute the following line in your terminal to create a temp environment, install this package, and then clean up everything:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --startup-file=no --project=$(mktemp -d) -e 'using Pkg; Pkg.add(; url=&quot;https://github.com/giordano/PkgCleanup.jl&quot;); using PkgCleanup, Dates; PkgCleanup.artifacts(); PkgCleanup.manifests(); Pkg.gc(; collect_delay=Dates.Day(0))'"><pre>julia --startup-file=no --project=<span class="pl-s"><span class="pl-pds">$(</span>mktemp -d<span class="pl-pds">)</span></span> -e <span class="pl-s"><span class="pl-pds">'</span>using Pkg; Pkg.add(; url="https://github.com/giordano/PkgCleanup.jl"); using PkgCleanup, Dates; PkgCleanup.artifacts(); PkgCleanup.manifests(); Pkg.gc(; collect_delay=Dates.Day(0))<span class="pl-pds">'</span></span></pre></div>
