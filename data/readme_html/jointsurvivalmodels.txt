<p dir="auto">This package implements joint models in Julia. It was designed to support the modeling of joint models with probabilistic programming, for example using the <a href="https://github.com/TuringLang/Turing.jl">Turing.jl</a> framework. Install it with:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;JointSurvivalModels&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>JointSurvivalModels<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">The <code>JointSurvivalModel</code> implements a canonical formulation of joint models. It based on a hazard function
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$h(t) = h_0(t) \exp(\gamma' \cdot L(M(t)))$</math-renderer> with a baseline hazard <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$h_0$</math-renderer> and a link to joint models <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$L(M(t))$</math-renderer>. For a more detailed explanation see the <a href="https://insightsengineering.github.io/JointSurvivalModels.jl/dev/" rel="nofollow">documentation</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Example</h2><a id="user-content-example" class="anchor" aria-label="Permalink: Example" href="#example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The hazard of the exponential distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$\text{Exp}(\alpha)$</math-renderer> is the constant function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$x\mapsto \alpha$</math-renderer>. For the joint longitudinal model we use a simple cosinus function. The joint hazard is then <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bfe0e79590a305ffbabbca921a8a5a14">$h(t) = \alpha \exp(\gamma * \cos(t))$</math-renderer>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JointSurvivalModels
constant_alpha(x) = 0.2
γ = 0.5
jm = JointSurvivalModel(constant_alpha, γ, cos)"><pre><span class="pl-k">using</span> JointSurvivalModels
<span class="pl-en">constant_alpha</span>(x) <span class="pl-k">=</span> <span class="pl-c1">0.2</span>
γ <span class="pl-k">=</span> <span class="pl-c1">0.5</span>
jm <span class="pl-k">=</span> <span class="pl-c1">JointSurvivalModel</span>(constant_alpha, γ, cos)</pre></div>
