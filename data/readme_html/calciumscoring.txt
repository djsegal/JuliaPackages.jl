<p dir="auto">CalciumScoring.jl is a Julia package for calculating coronary artery calcium scores from CT images using different quantification algorithms. The main function is <code>score()</code> which calculates the calcium mass within a CT scan. See the <a href="https://glassnotebook.io/r/7uus7O8aIcLsGebjQFqxU/docs/(00)%20Getting%20Started.jl" rel="nofollow">documentation</a> for more details.</p>

<p dir="auto">The general workflow is:</p>
<ol dir="auto">
<li>Prepare the region of interest from the CT image</li>
<li>Gather scan information like voxel size, spacing, calibration intensity, etc</li>
<li>Call <code>score()</code> with the ROI, scan info, and desired algorithm</li>
</ol>

<p dir="auto">For example, calculating the amount of calcium via Agatston scoring looks like:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# 1
roi = ct_scan .* coronary_artery_mask

# 2
spacing = [1, 1, 1]
mass_cal_factor = density_cal / intensity_cal

# 3
agatston_score, volume_score, mass_score = score(roi, spacing, mass_cal_factor, Agatston())"><pre><span class="pl-c"><span class="pl-c">#</span> 1</span>
roi <span class="pl-k">=</span> ct_scan <span class="pl-k">.*</span> coronary_artery_mask

<span class="pl-c"><span class="pl-c">#</span> 2</span>
spacing <span class="pl-k">=</span> [<span class="pl-c1">1</span>, <span class="pl-c1">1</span>, <span class="pl-c1">1</span>]
mass_cal_factor <span class="pl-k">=</span> density_cal <span class="pl-k">/</span> intensity_cal

<span class="pl-c"><span class="pl-c">#</span> 3</span>
agatston_score, volume_score, mass_score <span class="pl-k">=</span> <span class="pl-c1">score</span>(roi, spacing, mass_cal_factor, <span class="pl-c1">Agatston</span>())</pre></div>
<p dir="auto">The <code>score()</code> function takes the region of interest, voxel spacing, mass calibration factor, and an <code>Algorithm</code> specifying which algorithm to use.</p>

<p dir="auto">The main algorithms available are:</p>
<ul dir="auto">
<li><code>Agatston()</code>: Traditional Agatston scoring</li>
<li><code>VolumeFraction()</code>: Volume fraction calcium mass</li>
<li><code>Integrated()</code>: Integrated calcium mass</li>
<li><code>SpatiallyWeighted()</code>: Spatially weighted calcium scoring</li>
</ul>
