<p dir="auto">This is a Julia package to define equality and hash for structs.
It is similar to <a href="https://github.com/JuliaServices/AutoHashEquals.jl">AutoHashEquals.jl</a>,
<a href="https://github.com/jolin-io/StructEquality.jl">StructEquality.jl</a> and
<a href="https://github.com/jw3126/StructHelpers.jl">StructHelpers.jl</a>.
It aims to be lightweight and does not use <code>@generated</code> code.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The macro call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@struct_equal_hash T [fields]"><pre><span class="pl-c1">@struct_equal_hash</span> T [fields]</pre></div>
<p dir="auto">generates definitions for <code>==</code>, <code>isequal</code> and <code>hash</code> for the struct <code>T</code>,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    function x::T == y::T
    function isequal(x::T, y::T)
    function hash(x::T, h0::UInt)"><pre>    <span class="pl-k">function</span> x<span class="pl-k">::</span><span class="pl-c1">T</span> <span class="pl-k">==</span> y<span class="pl-k">::</span><span class="pl-c1">T</span>
    <span class="pl-k">function</span> <span class="pl-en">isequal</span>(x<span class="pl-k">::</span><span class="pl-c1">T</span>, y<span class="pl-k">::</span><span class="pl-c1">T</span>)
    <span class="pl-k">function</span> <span class="pl-en">hash</span>(x<span class="pl-k">::</span><span class="pl-c1">T</span>, h0<span class="pl-k">::</span><span class="pl-c1">UInt</span>)</pre></div>
<p dir="auto">The equality tests are applied, using short-circuit logic, to the fields of <code>T</code>
specified by the tuple <code>fields</code>. The default for <code>fields</code> is all fields of <code>T</code>
in the order in which they have been declared. The hash is similarly computed
over the type name <code>T</code> as well as over the fields given by <code>fields</code>.
Empty structs are allowed.</p>
<p dir="auto">The type can be a <code>UnionAll</code> type like <code>T{P} where P</code>. In this case the
definitions are</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    function x::T{P} == y::T{P} where P
    function isequal(x::T{P}, y::T{P}) where P
    function hash(x::T{P}, h0::UInt) where P"><pre>    <span class="pl-k">function</span> x<span class="pl-k">::</span><span class="pl-c1">T{P}</span> <span class="pl-k">==</span> y<span class="pl-k">::</span><span class="pl-c1">T{P}</span> <span class="pl-k">where</span> P
    <span class="pl-k">function</span> <span class="pl-en">isequal</span>(x<span class="pl-k">::</span><span class="pl-c1">T{P}</span>, y<span class="pl-k">::</span><span class="pl-c1">T{P}</span>) <span class="pl-k">where</span> P
    <span class="pl-k">function</span> <span class="pl-en">hash</span>(x<span class="pl-k">::</span><span class="pl-c1">T{P}</span>, h0<span class="pl-k">::</span><span class="pl-c1">UInt</span>) <span class="pl-k">where</span> P</pre></div>
<p dir="auto">Here the methods for <code>==</code> and <code>isequal</code> only apply if <code>x</code> and <code>y</code> are of the same type <code>T{P}</code>
(for the same <code>P</code>). If you do not want this for a parametric type, you can simply use the
form without parameters.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Types with several parameters</h2><a id="user-content-types-with-several-parameters" class="anchor" aria-label="Permalink: Types with several parameters" href="#types-with-several-parameters"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If <code>T</code> has two parameters, then</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @struct_equal_hash T{P,Q} where {P,Q}"><pre>    <span class="pl-c1">@struct_equal_hash</span> T{P,Q} <span class="pl-k">where</span> {P,Q}</pre></div>
<p dir="auto">defines methods where the types <code>P</code> and <code>Q</code> must agree for the two arguments of <code>==</code> and <code>isequal</code>.
If you only want the first types to agree, you can say</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @struct_equal_hash T{P,Q where Q} where P"><pre>    <span class="pl-c1">@struct_equal_hash</span> T{P,Q <span class="pl-k">where</span> Q} <span class="pl-k">where</span> P</pre></div>
<p dir="auto">or, equivalently,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @struct_equal_hash T{P} where P"><pre>    <span class="pl-c1">@struct_equal_hash</span> T{P} <span class="pl-k">where</span> P</pre></div>
<p dir="auto">If you only want the second types to agree, you can say</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @struct_equal_hash T{P where P,Q} where Q"><pre>    <span class="pl-c1">@struct_equal_hash</span> T{P <span class="pl-k">where</span> P,Q} <span class="pl-k">where</span> Q</pre></div>
<p dir="auto">If both types may differ, you can say</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @struct_equal_hash T{P where P,Q where Q}"><pre>    <span class="pl-c1">@struct_equal_hash</span> T{P <span class="pl-k">where</span> P,Q <span class="pl-k">where</span> Q}</pre></div>
<p dir="auto">or again omit the parameters.</p>
