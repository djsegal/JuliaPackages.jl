<p dir="auto">A collection of tools that one can use to reason with GATs and organize models of GATs.</p>

<ul dir="auto">
<li>Declaration of GATs</li>
<li>Multiple inheritance of GATs via pushouts</li>
<li>Parameterized models of GATs ala Standard ML modules/functors</li>
<li>E-Graph backed rewriting and type inference in arbitrary GATs</li>
<li>Backwards compatibility with the Catlab implementation of GATs</li>
</ul>
