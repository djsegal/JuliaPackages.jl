<p dir="auto">This package contains the code to reproduce the figures in
<a href="https://arxiv.org/abs/2302.03863" rel="nofollow">On the (linear) convergence of Generalized Newton Inexact ADMM</a>.</p>
<p dir="auto">You can add the package locally directly from this repo:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(url=&quot;https://github.com/tjdiamandis/GeNIADMM.jl&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(url<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>https://github.com/tjdiamandis/GeNIADMM.jl<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">All numerical experiments can be found in the <code>experiments</code> folder.</p>
<p dir="auto">For a full solver that leverages the same ideas, check out <a href="https://github.com/tjdiamandis/GeNIOS.jl">GeNIOS.jl</a>.</p>
