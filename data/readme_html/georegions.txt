<p dir="auto"><code>GeoRegions.jl</code> is a Julia package that aims to streamline the following processes:</p>
<ul dir="auto">
<li>query if a point / grid is within a specified boundary</li>
<li>extract point data (given coordinates) from a given region</li>
<li>extract gridded data (given grid boundaries) from a larger (parent) region (grid must be entirely within the parent region)</li>
</ul>
<p dir="auto">In general, these boundaries can be specified either using <code>[N,S,E,W]</code> coordinates, or by <code>longitude</code> and <code>latitude</code> vectors.</p>
<p dir="auto"><code>GeoRegions.jl</code> can be installed via</p>
