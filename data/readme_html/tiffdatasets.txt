<p dir="auto">This package implements the <a href="https://github.com/JuliaGeo/CommonDataModel.jl">CommonDataModel.jl</a> interface for TIFF files, which means that the datasets can be accessed in the same way as netCDF files opened with <a href="https://github.com/Alexander-Barth/NCDatasets.jl">NCDatasets.jl</a> or GRIB files opened with <a href="https://github.com/JuliaGeo/GRIBDatasets.jl">GRIBDatasets</a>. For GeoTIFF files the project information will be available as additional variables following the <a href="https://cfconventions.org/cf-conventions/cf-conventions.html#use-of-the-crs-well-known-text-format" rel="nofollow">CF Conventions</a>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using TIFFDatasets

<p dir="auto">The dataset <code>ds</code> will also have the virtual variables <code>x</code>, <code>y</code>, <code>lon</code> and <code>lat</code>
(unless there is no projection defined in the GeoTiff file)
representing the projected coordinates and the corresponding longitude and latitude.
The projection information as the so-called <a href="https://en.wikipedia.org/wiki/Well-known_text_representation_of_coordinate_reference_systems" rel="nofollow">Well Known Text</a> is available as attribute <code>crs_wkt</code> of the virtural variable <code>crs</code> following the <a href="https://cfconventions.org/cf-conventions/cf-conventions.html#use-of-the-crs-well-known-text-format" rel="nofollow">CF Conventions</a>.</p>
<p dir="auto">For example, the first band and the corresponding lon/lat coordinates can be loaded with using the API of <a href="https://github.com/JuliaGeo/CommonDataModel.jl">CommonDataModel.jl</a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="data = ds[&quot;band1&quot;][:,:];

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ds = TIFFDataset(fname,catbands = true)
