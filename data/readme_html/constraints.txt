<p dir="auto">A back-end package for JuliaConstraints front packages, such as <code>LocalSearchSolvers.jl</code>.</p>
<p dir="auto">It provides the following features:</p>
<ul dir="auto">
<li>
<p dir="auto">A dictionary to store usual constraint: <code>usual_constraint</code>, which contains the following entries (in alphabetical order):</p>
<ul dir="auto">
<li>:<code>all_different</code></li>
<li>:<code>all_equal</code></li>
<li>:<code>at_least</code></li>
<li>:<code>at_most</code></li>
<li>:<code>cardinality</code></li>
<li>:<code>cardinality_closed</code></li>
<li>:<code>cardinality_open</code></li>
<li>:<code>channel</code></li>
<li>:<code>circuit</code></li>
<li>:<code>conflicts</code></li>
<li>:<code>count</code></li>
<li>:<code>cumulative</code></li>
<li>:<code>decreasing</code></li>
<li>:<code>dist_different</code></li>
<li>:<code>element</code></li>
<li>:<code>exactly</code></li>
<li>:<code>extension</code></li>
<li>:<code>increasing</code></li>
<li>:<code>instantiation</code></li>
<li>:<code>maximum</code></li>
<li>:<code>mdd</code></li>
<li>:<code>minimum</code></li>
<li>:<code>no_overlap</code></li>
<li>:<code>no_overlap_no_zero</code></li>
<li>:<code>no_overlap_with_zero</code></li>
<li>:<code>nvalues</code></li>
<li>:<code>ordered</code></li>
<li>:<code>regular</code></li>
<li>:<code>strictly_decreasing</code></li>
<li>:<code>strictly_increasing</code></li>
<li>:<code>sum</code></li>
<li>:<code>supports</code></li>
</ul>
</li>
<li>
<p dir="auto">For each constraint <code>c</code>, the following properties</p>
<ul dir="auto">
<li>arguments length</li>
<li>concept (predicate the variables compliance with <code>c</code>)</li>
<li>error (a function that evaluate how much <code>c</code> is violated)</li>
<li>parameters length</li>
<li>known symmetries of <code>c</code></li>
</ul>
</li>
<li>
<p dir="auto">A learning function using <code>CompositionalNetworks.jl</code>. If no error function is given when instantiating <code>c</code>, it will check the existence of a composition related to <code>c</code> and set the error to it.</p>
</li>
</ul>

<p dir="auto">Contributions to this package are more than welcome and can be arbitrarily, and not exhaustively, split as follows:</p>
<ul dir="auto">
<li>Adding new constraints and symmetries</li>
<li>Adding new ICNs to learn error of existing constraints</li>
<li>Creating other compositional networks which target other kind of constraints</li>
<li>Just making stuff better, faster, user-friendlier, etc.</li>
</ul>
