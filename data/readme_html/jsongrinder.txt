<p dir="auto"><code>JsonGrinder.jl</code> is a library that facilitates processing of JSON documents into
<a href="https://github.com/CTUAvastLab/Mill.jl"><code>Mill.jl</code></a> structures for machine learning. It provides
functionality for JSON schema inference, extraction of JSON documents to a suitable representation
for machine learning, and constructing a model operating on this data.</p>
<p dir="auto">Watch our <a href="https://www.youtube.com/watch?v=Bf0CvltIDbE" rel="nofollow">introductory talk</a> from JuliaCon 2021.</p>
