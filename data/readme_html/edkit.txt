<p dir="auto">Julia package for general many-body exact diagonalization calculation. The package provides a general Hamiltonian constructing routine for specific symmetry sectors. The functionalities can be extended with user-defined bases.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add EDKit"><pre>pkg<span class="pl-k">&gt;</span> add EDKit</pre></div>
<p dir="auto">Alternatively, you can install <code>EDKit</code> directly from GitHub using the following script.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add https://github.com/jayren3996/EDKit.jl"><pre>pkg<span class="pl-k">&gt;</span> add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>jayren3996<span class="pl-k">/</span>EDKit<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">This is useful if you want to access the latest version of <code>EDKit</code>, which includes new features not yet registered in the Julia Pkg system but may also contain bugs.</p>

<p dir="auto">Instead of providing documentation, I have chosen to introduce the functionality of this package through practical calculation examples. You can find a collection of Jupyter notebooks in the <a href="https://github.com/jayren3996/EDKit.jl/tree/main/examples">examples</a> folder, each showcasing various computations.</p>
<p dir="auto">Here are a few basic examples:</p>

<p dir="auto">Consider the Hamiltonian</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="62d546eefba4687ecee6cac209d88b3c">$$H = \sum_i\left(\sigma_i^x \sigma^x_{i+1} + \sigma^y_i\sigma^y_{i+1} + h_i \sigma^z_i\sigma^z_{i+1}\right).$$</math-renderer>
<p dir="auto">We choose the system size to be <code>L=10</code>. The Hamiltonian needs 3 pieces of information:</p>
<ol dir="auto">
<li>Local operators represented by matrices;</li>
<li>Site indices where each local operator acts on;</li>
<li>Basis, if using the default tensor-product basis, only need to provide the system size.</li>
</ol>
<p dir="auto">The following script generates the information we need to generate XXZ Hamiltonian:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="L = 10

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; H = operator(mats, inds, L)

<p dir="auto">The constructor returns an Operator object, a linear operator that can act on vector/ matrix. For example, we can act <code>H</code> on a random state:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ψ = normalize(rand(2^L))

ψ2 <span class="pl-k">=</span> H <span class="pl-k">*</span> ψ</pre></div>

<p dir="auto">Consider the AKLT model</p>
