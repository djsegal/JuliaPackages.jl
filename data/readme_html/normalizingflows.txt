<p dir="auto">A normalizing flow library for Julia.</p>
<p dir="auto">The purpose of this package is to provide a simple and flexible interface for variational inference (VI) and normalizing flows (NF) for Bayesian computation or generative modeling.
The key focus is to ensure modularity and extensibility, so that users can easily
construct (e.g., define customized flow layers) and combine various components
(e.g., choose different VI objectives or gradient estimates)
for variational approximation of general target distributions,
without being tied to specific probabilistic programming frameworks or applications.</p>
<p dir="auto">See the <a href="https://turinglang.org/NormalizingFlows.jl/dev/" rel="nofollow">documentation</a> for more.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quick recap of normalizing flows</h2><a id="user-content-quick-recap-of-normalizing-flows" class="anchor" aria-label="Permalink: Quick recap of normalizing flows" href="#quick-recap-of-normalizing-flows"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Normalizing flows transform a simple reference distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$q_0$</math-renderer> (sometimes known as base distribution) to
a complex distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$q$</math-renderer> using invertible functions.</p>
<p dir="auto">In more details, given the base distribution, usually a standard Gaussian distribution, i.e., <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$q_0 = \mathcal{N}(0, I)$</math-renderer>,
we apply a series of parameterized invertible transformations (called flow layers), <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$T_{1, \theta_1}, \cdots, T_{N, \theta_k}$</math-renderer>, yielding that</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$$Z_N = T_{N, \theta_N} \circ \cdots \circ T_{1, \theta_1} (Z_0) , \quad Z_0 \sim q_0,\quad  Z_N \sim q_{\theta},$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$\theta = (\theta_1, \dots, \theta_N)$</math-renderer> is the parameter to be learned, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$q_{\theta}$</math-renderer> is the variational distribution (flow distribution). This describes <strong>sampling procedure</strong> of normalizing flows, which requires sending draws through a forward pass of these flow layers.</p>
<p dir="auto">Since all the transformations are invertible (technically <a href="https://en.wikipedia.org/wiki/Diffeomorphism" rel="nofollow">diffeomorphic</a>), we can evaluate the density of a normalizing flow distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$q_{\theta}$</math-renderer> by the change of variable formula:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$$q_\theta(x)=\frac{q_0\left(T_1^{-1} \circ \cdots \circ
T_N^{-1}(x)\right)}{\prod_{n=1}^N J_n\left(T_n^{-1} \circ \cdots \circ
T_N^{-1}(x)\right)} \quad J_n(x)=\left|\text{det} \nabla_x
T_n(x)\right|.$$</math-renderer>
<p dir="auto">Here we drop the subscript <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$\theta_n, n = 1, \dots, N$</math-renderer> for simplicity.
Density evaluation of normalizing flow requires computing the <strong>inverse</strong> and the
<strong>Jacobian determinant</strong> of each flow layer.</p>
<p dir="auto">Given the feasibility of i.i.d. sampling and density evaluation, normalizing flows can be trained by minimizing some statistical distances to the target distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$p$</math-renderer>. The typical choice of the statistical distance is the forward and backward Kullback-Leibler (KL) divergence, which leads to the following optimization problems:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$$\begin{aligned}
\text{Reverse KL:}\quad
&amp;\arg\min _{\theta} \mathbb{E}_{q_{\theta}}\left[\log q_{\theta}(Z)-\log p(Z)\right] \\\
&amp;= \arg\min _{\theta} \mathbb{E}_{q_0}\left[\log \frac{q_\theta(T_N\circ \cdots \circ T_1(Z_0))}{p(T_N\circ \cdots \circ T_1(Z_0))}\right] \\\
&amp;= \arg\max _{\theta} \mathbb{E}_{q_0}\left[ \log p\left(T_N \circ \cdots \circ T_1(Z_0)\right)-\log q_0(X)+\sum_{n=1}^N \log J_n\left(F_n \circ \cdots \circ F_1(X)\right)\right]
\end{aligned}$$</math-renderer>
<p dir="auto">and</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$$\begin{aligned}
\text{Forward KL:}\quad
&amp;\arg\min _{\theta} \mathbb{E}_{p}\left[\log q_{\theta}(Z)-\log p(Z)\right] \\\
&amp;= \arg\min _{\theta} \mathbb{E}_{p}\left[\log q_\theta(Z)\right] 
\end{aligned}$$</math-renderer>
<p dir="auto">Both problems can be solved via standard stochastic optimization algorithms,
such as stochastic gradient descent (SGD) and its variants.</p>
<p dir="auto">Reverse KL minimization is typically used for <strong>Bayesian computation</strong>, where one
wants to approximate a posterior distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0a217548f2a36a38ba8f8b3d01b915e">$p$</math-renderer> that is only known up to a
normalizing constant.
In contrast, forward KL minimization is typically used for <strong>generative modeling</strong>,
where one wants to learn the underlying distribution of some data.</p>
