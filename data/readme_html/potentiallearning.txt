<p dir="auto"><ins><strong>Reduce expensive <em><strong>Density functional theory</strong></em> calculations</strong></ins>  while maintaining training accuracy by intelligently subsampling your atomistic dataset:</p>
<ol dir="auto">
<li>Subsample your <a href="https://github.com/JuliaMolSim/AtomsBase.jl">atomistic configurations</a> using a Determinantal Point Process (<a href="https://github.com/dahtah/Determinantal.jl">DPP</a>) based algorithm that compares energy descriptors computed with the Atomic Cluster Expansion (<a href="https://github.com/ACEsuit">ACE</a>).</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ds = DataSet(conf_train .+ e_descr)
dataset_selector = kDPP(ds, GlobalMean(), DotProduct())
inds = get_random_subset(dataset_selector)
conf_train = @views conf_train[inds]"><pre>ds <span class="pl-k">=</span> <span class="pl-c1">DataSet</span>(conf_train <span class="pl-k">.+</span> e_descr)
dataset_selector <span class="pl-k">=</span> <span class="pl-c1">kDPP</span>(ds, <span class="pl-c1">GlobalMean</span>(), <span class="pl-c1">DotProduct</span>())
inds <span class="pl-k">=</span> <span class="pl-c1">get_random_subset</span>(dataset_selector)
conf_train <span class="pl-k">=</span> <span class="pl-c1">@views</span> conf_train[inds]</pre></div>
<ol start="2" dir="auto">
<li>Export the reduced dataset, use Density functional theory (<a href="https://docs.dftk.org/stable/" rel="nofollow">DFT</a>) on it, and fit your model.</li>
</ol>
<p dir="auto">See <a href="https://cesmix-mit.github.io/PotentialLearning.jl/dev/generated/DPP-ACE-aHfO2-1/fit-dpp-ace-ahfo2/" rel="nofollow">example</a>.</p>
<p dir="auto">We are working to provide different intelligent subsampling algorithms based on <a href="https://github.com/dahtah/Determinantal.jl">DPP</a>, <a href="https://docs.google.com/document/d/1SWAanEWQkpsbr2lqetMO3uvdX_QK-Z7dwrgPaM1Dl0o/edit" rel="nofollow">DBSCAN</a>, and <a href="https://github.com/JuliaLinearAlgebra/LowRankApprox.jl">CUR</a>; highly scalable parallel subsampling via hierarchical subsampling and <a href="https://github.com/JuliaParallel/Dagger.jl">distributed parallelism</a>; and optimal subsampler selection.</p>
<p dir="auto"><ins><strong>Get fast and accurate interatomic potential models</strong></ins>  through parallel multi-objective hyper-parameter optimization:</p>
<ol dir="auto">
<li>Define the interatomic potential model, hyper-parameter value ranges, and custom loss function. Then, <a href="https://github.com/baggepinnen/Hyperopt.jl">optimize</a> your model.</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="model = ACE
pars = OrderedDict( :body_order        =&gt; [2, 3, 4],

    return w_e * e_mae + w_f * f_mae + w_t * time_us

<span class="pl-k">end</span>
iap, res <span class="pl-k">=</span> <span class="pl-c1">hyperlearn!</span>(model, pars, conf_train; loss <span class="pl-k">=</span> custom_loss);</pre></div>
<ol start="2" dir="auto">
<li>Export optimal values to your molecular dynamic workflow.</li>
</ol>
<p dir="auto">See <a href="https://cesmix-mit.github.io/PotentialLearning.jl/dev/generated/Opt-ACE-aHfO2/fit-opt-ace-ahfo2/" rel="nofollow">example</a>.</p>
<p dir="auto">The models are compatible with the interfaces of our sister package <a href="https://github.com/cesmix-mit/InteratomicPotentials.jl">InteratomicPotentials.jl</a>. In particular, we are interested in maintaining compatibility with <a href="https://github.com/ACEsuit">ACESuit</a>, as well as integrating <a href="https://www.lammps.org/" rel="nofollow">LAMMPS</a> based potentials such as <a href="https://docs.lammps.org/Packages_details.html#pkg-ml-pod" rel="nofollow">ML-POD</a> and <a href="https://docs.lammps.org/Packages_details.html#ml-pace-package" rel="nofollow">ML-PACE</a>. We are also working to provide neural network potential architecture optimization.</p>
<p dir="auto"><ins><strong>Compress your interatomic potential data and model</strong></ins> using dimensionality reduction of energy and force descriptors:</p>
<ol dir="auto">
<li>Define a PCA state, fit PCA with your the energy and force descriptors of your dataset, and transform all dataset descriptors.</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pca = PCAState(tol = n_desc)
fit!(ds_train, pca)
transform!(ds_train, pca)"><pre>pca <span class="pl-k">=</span> <span class="pl-c1">PCAState</span>(tol <span class="pl-k">=</span> n_desc)
<span class="pl-c1">fit!</span>(ds_train, pca)
<span class="pl-c1">transform!</span>(ds_train, pca)</pre></div>
<ol start="2" dir="auto">
<li>Export PCA fitted data to be used in your workflow.</li>
</ol>
<p dir="auto">See <a href="https://cesmix-mit.github.io/PotentialLearning.jl/dev/generated/PCA-ACE-aHfO2/fit-pca-ace-ahfo2/" rel="nofollow">example</a>.</p>
<p dir="auto">We are working to provide feature selection of energy and force descriptors based on <a href="https://github.com/JuliaLinearAlgebra/LowRankApprox.jl">CUR</a>.</p>
<p dir="auto">Additionally, this package includes utilities for loading input data (such as XYZ files), computing various metrics (including MAE, MSE, RSQ, and COV), exporting results, and generating plots.</p>
