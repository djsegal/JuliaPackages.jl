<p dir="auto">PlutoMapPicker is a package for <a href="https://julialang.org/" rel="nofollow">Julia</a>. It is is designed to be used in <a href="https://github.com/fonsp/Pluto.jl">Pluto notebooks</a>. If you are using Pluto, you're ready to use this package!</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">PlutoMapPicker is designed to be simple to use. Basic usage looks like this:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PlutoMapPicker

# to pick a single location
@bind place MapPicker(0.0, 0.0, 1)

# to pick multiple locations
@bind places MapPickerMultiple(0.0, 0.0, 1)"><pre><span class="pl-k">using</span> PlutoMapPicker

<span class="pl-c"><span class="pl-c">#</span> to pick a single location</span>
<span class="pl-c1">@bind</span> place <span class="pl-c1">MapPicker</span>(<span class="pl-c1">0.0</span>, <span class="pl-c1">0.0</span>, <span class="pl-c1">1</span>)

<span class="pl-c"><span class="pl-c">#</span> to pick multiple locations</span>
<span class="pl-c1">@bind</span> places <span class="pl-c1">MapPickerMultiple</span>(<span class="pl-c1">0.0</span>, <span class="pl-c1">0.0</span>, <span class="pl-c1">1</span>)</pre></div>
<p dir="auto">For both <code>MapPicker</code> and <code>MapPickerMultiple</code>, the input parameters are the initial coordinates that the map should centre on, and the zoom level.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Tile layer</h3><a id="user-content-tile-layer" class="anchor" aria-label="Permalink: Tile layer" href="#tile-layer"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Maps use a <em>raster tile layer</em> to show the actual map. This layer is built of images of the world map. To load in these tiles as needed, the map must request the tiles from an API.</p>
<p dir="auto">The default setting will request tiles from <a href="https://openstreetmap.org" rel="nofollow">Open Street Map</a>, but you can change this setting. The package also includes some ready-to-go configurations for <a href="https://stadiamaps.com/" rel="nofollow">Stadia Maps</a>. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="MapPicker(0.0, 0.0, 1; tile_layer=stadia_tile_layers.outdoors)"><pre><span class="pl-c1">MapPicker</span>(<span class="pl-c1">0.0</span>, <span class="pl-c1">0.0</span>, <span class="pl-c1">1</span>; tile_layer<span class="pl-k">=</span>stadia_tile_layers<span class="pl-k">.</span>outdoors)</pre></div>
<p dir="auto">You can also create a custom <code>TileLayer</code> to use a different server or make requests with an API key.</p>
<p dir="auto">Please note that PlutoMapPicker is not affiliated with Open Street Map or Stadia Maps. The <code>TileLayer</code> configurations for these services are provided for convenience, but it is up to you whether the way you're using these services complies with their usage policy. See <a href="https://operations.osmfoundation.org/policies/tiles/" rel="nofollow">Open Street Map's usage policy</a> and <a href="https://docs.stadiamaps.com/" rel="nofollow">Stadia Map's documentation</a> for more information.</p>
