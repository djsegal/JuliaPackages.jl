<p dir="auto"><strong>CellularPotts.jl</strong> is a Julia package designed to simulate behaviors observed in biological cells like division and adhesion. Users of this package can create 2D and 3D environments with any number of cell types, sizes, and behaviors. Simulations can be recorded and visualized as animations with the help of the Plots.jl package. The goal of this package is to create a flexible coding environment to explore how cell behaviors can coalesce into complex dynamics while still maintaining high performance. Compared to other excellent software for Cellular Potts modeling (e.g., <a href="https://morpheus.gitlab.io/" rel="nofollow">Morpheus</a>, <a href="https://artistoo.net/" rel="nofollow">Artistoo</a>, <a href="https://compucell3d.org/" rel="nofollow">CompuCell3D</a>), CellularPotts.jl is unique in its approach for a few reasons:</p>
<ul dir="auto">
<li>
<p dir="auto">CellularPotts.jl is written completely in Julia, avoiding the "<a href="https://www.nature.com/articles/d41586-019-02310-3" rel="nofollow">two language problem</a>"</p>
<ul dir="auto">
<li>This unites developers and users to one language, simplifies the code base, and makes customization easier.</li>
</ul>
</li>
<li>
<p dir="auto">The space cells occupy is modeled as a network/graph</p>
<ul dir="auto">
<li>
<p dir="auto">Representing the model as a graph allows access to decades of graph theory research, for example:</p>
<ul dir="auto">
<li>Calculating articulation points to avoid cell fragmentation</li>
<li>Using graph partitioning algorithms to simulate cellular division</li>
<li>Avoiding cumbersome boundary conditions by adding edges that wrap around the defined space</li>
<li>Using graphical Laplacians to simulate diffusion</li>
</ul>
</li>
</ul>
</li>
<li>
<p dir="auto">CellularPotts.jl can be composed with other Julia packages.</p>
<ul dir="auto">
<li>For example, we can use state-of-the-art differential equation solving techniques from <a href="https://diffeq.sciml.ai/stable/" rel="nofollow">DifferentialEquations.jl</a> as opposed to simple Euler methods. (Check out the [BringingODEStoLife](<a href="https://robertgregg.github.io/CellularPotts.jl/dev/ExampleGallery/BringingODEsToLife/BringingODEsToLife/" rel="nofollow">Bringing ODEs To Life · CellularPotts.jl</a>) example.)</li>
</ul>
</li>
</ul>

<p dir="auto">To create a basic Cellular Potts Model, you need to provide 3 pieces of information:</p>
<ol dir="auto">
<li>
<p dir="auto">What space will the cells occupy?</p>
</li>
<li>
<p dir="auto">What cells do you want to include in the model?</p>
</li>
<li>
<p dir="auto">What penalties do you want to encourage certain behaviors?</p>
</li>
</ol>
