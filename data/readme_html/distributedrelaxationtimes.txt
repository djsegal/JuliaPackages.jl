<p dir="auto">A Julia package to calculate the <strong>Distribution of Relaxation Times (DRT)</strong> of a given set of electrochemical impedance spectroscopy measurements and frequency values. The current implementation uses the Tikhonov regularisation approach with radial basis function discretization.</p>

<p dir="auto">The DRT is a method to analyse <strong>electrochemical impedance spectroscopy (EIS)</strong> measurements. Two of its main benefits are</p>
<ul dir="auto">
<li>that it does not require a specific prior equivalent electrical circuit model assumption.</li>
<li>it is capable of resolving polarisation processes with similar time constants, which are indistinguishable when using traditional EIS data representation methods, such as Nyquist and Bode plots.</li>
</ul>
<p dir="auto">The main function exported in this module is the  <code>compute_DRT</code> function. Its two essential arguments are a set of frequencies and the complex-valued impedances measured at those frequencies.</p>

<p dir="auto">The <code>compute_DRT</code> function has four outputs, these are the relaxation times of the DRT peaks, their amplitudes, the time values over which the DRT is calculated, and the calculated DRT, respectively. Apart from the two essential arguments, the <code>compute_DRT</code> function also accepts several keyword arguments:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>method</code> : Determines whether the DRT is calculated using the real part of the measurements ("re"), the imaginary part of the measurements ("im"), or both ("re_im"). The default value is "re_im".</p>
</li>
<li>
<p dir="auto"><code>rbf_kernel</code> : The radial basis function used for the discretisation of the DRT.  The default value is KernelFunctions.jl's <code>SqExponentialKernel()</code>.</p>
</li>
<li>
<p dir="auto"><code>width_coeff</code> : hyperparameter related to the shape factor of the radial basis functions, lower values lead to wider DRT peaks. The default value is 0.08.</p>
</li>
<li>
<p dir="auto"><code>λ</code> :  The hyperparameter tuning the regularisation during ridge regression. The default value is 1e-2.</p>
</li>
</ul>
<p dir="auto">While there is no universal way to automatically find the most suitable value for the regularisation hyperparameter <code>λ</code>,  the discrepancy minimisation and Re-Im crossvalidation methods proposed by  <a href="https://www.sciencedirect.com/science/article/abs/pii/S0013468614018763" rel="nofollow">Saccoccio et al.</a> are implemented in this package as the <code>find_optimal_lambda</code> function.</p>
