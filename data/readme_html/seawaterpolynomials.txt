<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">SeawaterPolynomials.jl</h1><a id="user-content-seawaterpolynomialsjl" class="anchor" aria-label="Permalink: SeawaterPolynomials.jl" href="#seawaterpolynomialsjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides approximations to the Boussinesq equation of state for seawater expressed as polynomial functions of conservative temperature, absolute salinity, and geopotential height.</p>
<p dir="auto">Computationally efficient polynomial approximations to the <a href="https://doi.org/10.1175/2009JPO4294.1" rel="nofollow">Boussinesq seawater</a> equation of state are crucial components of ocean modeling software.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The Seawater Boussinesq approximation</h2><a id="user-content-the-seawater-boussinesq-approximation" class="anchor" aria-label="Permalink: The Seawater Boussinesq approximation" href="#the-seawater-boussinesq-approximation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In the seawater Boussinesq approximation, the density of seawater is expanded around a constant reference value <code>ρᵣ</code>,</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="ρ = ρᵣ + ρ′(Θ, Sᴬ, Z)"><pre class="notranslate"><code>ρ = ρᵣ + ρ′(Θ, Sᴬ, Z)
</code></pre></div>
<p dir="auto">where the anomaly, <code>ρ′</code>, is a function of conservative temperature <code>Θ</code>, absolute salinity <code>Sᴬ</code>, and geopotential height <code>Z</code>.
One choice for <code>ρᵣ</code> is the average density at the surface of the world ocean, <code>ρᵣ = 1024.6 kg m⁻³</code>, according to <a href="https://doi.org/10.1175/JPO-D-15-0080.1" rel="nofollow">Roquet et al. (2015)</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The TEOS-10 standard</h2><a id="user-content-the-teos-10-standard" class="anchor" aria-label="Permalink: The TEOS-10 standard" href="#the-teos-10-standard"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <a href="http://www.teos-10.org" rel="nofollow">Thermodynamic Equation of SeaWater (TEOS-10)</a> is a Gibbs function formulation of seawater themodynamics.</p>
<p dir="auto">The error between the polynomials implemented in this package and the TEOS-10 is minimized for current 'climatological' ocean distributions of conservative temperature and absolute salinity. For more information, see</p>
<ul dir="auto">
<li>
<p dir="auto"><a href="https://doi.org/10.1016/j.ocemod.2015.04.002" rel="nofollow">Roquet et al., "Accurate polynomial expressions for the density and specific volume of seawater using the TEOS-10 standard", Ocean Modelling (2015)</a></p>
</li>
<li>
<p dir="auto"><a href="https://doi.org/10.1175/JPO-D-15-0080.1" rel="nofollow">Roquet et al., "Defining a Simplified Yet “Realistic” Equation of State for Seawater", Journal of Physical Oceanography (2015)</a></p>
</li>
</ul>
