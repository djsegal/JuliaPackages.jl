<p dir="auto">Julia Client for the NERSC Superfacilty API. The Julia client is currently under
active development, and therefore might change a bit more. It's based on
<code>v1.2</code>: of the <a href="https://docs.nersc.gov/services/sfapi/" rel="nofollow">Superfacility API</a>.</p>
<p dir="auto">It largely follows the <a href="https://github.com/NERSC/sfapi_client">Python Client</a>.</p>

<p dir="auto">Store the <code>clientid.txt</code>, and <code>priv_key.pem</code> from
<a href="https://iris.nersc.gov/" rel="nofollow">Iris</a> in the same folder (which is not publically
accessible). The create a token container as follows:</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Running functions remotely</h3><a id="user-content-running-functions-remotely" class="anchor" aria-label="Permalink: Running functions remotely" href="#running-functions-remotely"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>Executable.run</code> and <code>Executable.result</code> use the API to remotely run a command
(as your user account corresponding to the client token). A command is run
asynchronously -- that is to say <code>run</code> <em>starts</em> a process, and <code>result</code> starts a
Julia async taks which keeps checking the output fromt he process. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="cmd = SFAPI.Executable.run(&quot;ls $(home_path)&quot;, token_container)
t = SFAPI.Executable.result(cmd, token_container)
while ! istaskdone(t)
    println(&quot;Wating for result ...&quot;)
    sleep(1)
end"><pre>cmd <span class="pl-k">=</span> SFAPI<span class="pl-k">.</span>Executable<span class="pl-k">.</span><span class="pl-c1">run</span>(<span class="pl-s"><span class="pl-pds">"</span>ls <span class="pl-v">$(home_path)</span><span class="pl-pds">"</span></span>, token_container)
t <span class="pl-k">=</span> SFAPI<span class="pl-k">.</span>Executable<span class="pl-k">.</span><span class="pl-c1">result</span>(cmd, token_container)
<span class="pl-k">while</span> <span class="pl-k">!</span> <span class="pl-c1">istaskdone</span>(t)
    <span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>Wating for result ...<span class="pl-pds">"</span></span>)
    <span class="pl-c1">sleep</span>(<span class="pl-c1">1</span>)
<span class="pl-k">end</span></pre></div>
<p dir="auto">This is how you would repeatedly poll the SFAPI to check if the command is done
running. <code>SFAPI.Executable.result</code> does repeatedly check the status, and fetches
the result when done (continuously refreshing the API token). So progress is
made even when not checking <code>istaskdone</code>.</p>
