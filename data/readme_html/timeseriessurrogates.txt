<p dir="auto">A Julia package for generating timeseries surrogates.
TimeseriesSurrogates.jl is the fastest and most featureful open source code for generating timeseries surrogates.
It can be used as a standalone package, or as part of other projects in JuliaDynamics such as DynamicalSystems.jl or CausalityTools.jl.</p>
<p dir="auto">To install it, run <code>import Pkg; Pkg.add("TimeseriesSurrogates")</code>.</p>
<p dir="auto">All further information is provided in the documentation, which you can either find online or build locally by running the <code>docs/make.jl</code> file.</p>
