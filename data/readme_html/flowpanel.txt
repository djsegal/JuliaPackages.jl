<blockquote>
<p dir="auto"><strong>Structured mesh generation:</strong>
<em>Lofts</em>
<em>• Bodies of revolution</em>
<em>• User-defined space transformations</em></p>
<p dir="auto"><strong>Unstructured mesh import:</strong>
<em><a href="https://openvsp.org" rel="nofollow">OpenVSP</a></em>
<em>• CAD (e.g., SolidWorks) + <a href="https://gmsh.info" rel="nofollow">Gmsh</a></em>
<em>• <a href="https://juliageometry.github.io/MeshesDocs" rel="nofollow">Meshes.jl</a></em></p>
<p dir="auto"><strong>Multi Element:</strong>
<em>Source-panel or doublet/vortex-ring for non-lifting bodies</em>
<em>• Doublet/vortex-ring for lifting bodies with rigid wake model</em></p>
<p dir="auto"><strong>Flexible Solver:</strong>
<em>Direct LU decomposition</em>
<em>• Iterative Krylov (GMRES)</em>
<em>• Handling of both watertight and open meshes</em>
<em>• Multiple bodies</em></p>
<p dir="auto"><strong>Fast Computation:</strong>
<em>GPU enabled</em>
<em>• CPU threaded</em>
<em>• Low memory allocation</em>
<em>• Type stable</em>
<em>• Adjoint solver through <a href="https://github.com/byuflowlab/ImplicitAD.jl">ImplicitAD</a> for gradient-based optimization</em>
<em>• Support for both <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff</a> and <a href="https://github.com/JuliaDiff/ReverseDiff.jl">ReverseDiff</a></em></p>
<p dir="auto"><strong>Current Limitations:</strong>
<em>Inviscid (no viscous drag nor stall)</em>
<em>• Incompressible</em>
<em>• No fast multipole method (though a 30,000 panel problem can still be solved in as fast as 90 seconds on a laptop)</em></p>
<p dir="auto"><em>Coded in <a href="https://www.infoworld.com/article/3284380/what-is-julia-a-fresh-approach-to-numerical-computing.html" rel="nofollow">the Julia language</a> for Linux, MacOS, and Windows WSL.</em></p>
</blockquote>
<p dir="auto">Tested in Julia v1.10</p>

<ol dir="auto">
<li>Download and install <a href="https://julialang.org/" rel="nofollow">Julia</a></li>
<li>Type in the Julia REPL: <code>] add FLOWPanel</code></li>
<li><em>(optional)</em> For visualization, install <a href="https://www.paraview.org/" rel="nofollow">ParaView</a> and make sure that <a href="https://flow.byu.edu/FLOWUnsteady/installation/general/#paraview" rel="nofollow">it is callable from the terminal</a> typing <code>paraview</code></li>
</ol>
<p dir="auto">Copy and paste any of <a href="https://flow.byu.edu/FLOWPanel.jl/dev/examples/sweptwing-4p2aoa/" rel="nofollow">the examples</a> directly in the Julia REPL to run your first simulation</p>
