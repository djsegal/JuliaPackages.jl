<p dir="auto">The fastest Tropical matrix multiplication in the world! Supported matrix element types include</p>
<ul dir="auto">
<li>max-plus algebra: <code>Tropical{BlasType}</code></li>
<li>min-plus algebra numbers: <code>TropicalMinPlus{BlasType}</code></li>
<li>max-times algebra numbers: <code>TropicalMaxMul{BlasType}</code></li>
</ul>
<p dir="auto">Please check <a href="https://github.com/TensorBFS/TropicalNumbers.jl"><code>TropicalNumbers.jl</code></a> for the definitions of these types. The <code>BlasType</code> is the storage type, which could be one of <code>Bool, Float16, Float32, Float64, Int16, Int32, Int64, Int8, UInt16, UInt32, UInt64, UInt8, SIMDTypes.Bit</code>.</p>
