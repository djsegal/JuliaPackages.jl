<p dir="auto">This package allows to combine multiple heterogeneous types in a single one. This helps to write
type-stable code by avoiding <code>Union</code> performance drawbacks when many types are unionized. Another
aim of this library is to provide a syntax as similar as possible to standard Julia
structs to facilitate its integration within other libraries.</p>
<p dir="auto">The <code>@sumtype</code> macro takes inspiration from <a href="https://github.com/MasonProtter/SumTypes.jl">SumTypes.jl</a>,
but it offers a more idiomatic interface. Working with it is almost like working with <code>Union</code> types.</p>
