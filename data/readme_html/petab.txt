<p dir="auto">PEtab.jl is a Julia package to create ODE parameter estimation problems in Julia. Parameter estimation problems can be directly imported if they are specified in the <a href="https://petab.readthedocs.io/en/latest/" rel="nofollow">PEtab</a> standard format, alternatively problems can be directly specified in Julia where the dynamic model can be provided as a <a href="https://github.com/SciML/ModelingToolkit.jl">ModelingToolkit.jl</a> <code>ODESystem</code> or a <a href="https://github.com/SciML/Catalyst.jl">Catalyst</a> <code>ReactionSystem</code>. Once a problem has been parsed PEtab.jl provides wrappers to Optim, Optimization, Ipopt, and Fides to perform efficient multi-start parameter estimation.</p>
<p dir="auto">The <a href="https://github.com/sebapersson/SBMLImporter.jl">SBMLImporter.jl</a> package is used to import SBML models when parameter estimation problems are given in the PEtab standard format. If your goal is solely to import and simulate SBML models, SBMLImporter offers extensive support for various SBML features.</p>
<p dir="auto">For installation instructions and a quick start see below. For additional details, the <a href="https://sebapersson.github.io/PEtab.jl/stable/" rel="nofollow">documentation</a> contains a comprehensive list of all options and recommended settings for different model sizes.</p>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ] add PEtab"><pre>julia<span class="pl-k">&gt;</span> ] add PEtab</pre></div>
<p dir="auto">or enter</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg; Pkg.add(&quot;PEtab&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>PEtab<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">PEtab.jl is compatible with Julia version 1.6 and above. However, for best performance, we strongly recommend using Julia version 1.10.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quick start</h2><a id="user-content-quick-start" class="anchor" aria-label="Permalink: Quick start" href="#quick-start"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For how to define a parameter estimation problem directly in Julia, see the <a href="https://sebapersson.github.io/PEtab.jl/stable/Define_in_julia/" rel="nofollow">documentation</a>.</p>
<p dir="auto">If the parameter estimation problem is provided in the <a href="https://petab.readthedocs.io/en/latest/" rel="nofollow">PEtab standard format</a>, importing it is straightforward. Consider the Boehm model (the model files can be downloaded from <a href="https://github.com/Benchmarking-Initiative/Benchmark-Models-PEtab/tree/master/Benchmark-Models/Boehm_JProteomeRes2014">here</a>), given the path to the PEtab YAML file, the problem can be imported via:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PEtab
boehm_model = PEtabModel(yaml_path)"><pre><span class="pl-k">using</span> PEtab
boehm_model <span class="pl-k">=</span> <span class="pl-c1">PEtabModel</span>(yaml_path)</pre></div>
<p dir="auto"><code>PEtabModel</code> converts the SBML ODE model into a format compatible with <a href="https://github.com/SciML/ModelingToolkit.jl">ModelingToolkit.jl</a>, which with other things allows for symbolic Jacobian computations. It also automatically generates functions for computing initial values, observation functions, and events based on the data in the PEtab files.</p>
<p dir="auto">With a <code>PEtabModel</code> a <code>PEtabODEProblem</code> can be created. This enables the computation of cost, gradient, and Hessian for the parameter estimation problem. For instance, to simulate the ODE with the <a href="https://docs.sciml.ai/DiffEqDocs/stable/solvers/ode_solve/" rel="nofollow">Rodas5</a> solver, to compute the gradient with <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff</a>, and to approximate the Hessian with the Gauss-Newton method do:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OrdinaryDiffEq
petab_problem = PEtabODEProblem(boehm_model,
                                ode_solver=ODESolver(Rodas5()),
                                gradient_method=:ForwardDiff,
                                hessian_method=:GaussNewton)"><pre><span class="pl-k">using</span> OrdinaryDiffEq
petab_problem <span class="pl-k">=</span> <span class="pl-c1">PEtabODEProblem</span>(boehm_model,
                                ode_solver<span class="pl-k">=</span><span class="pl-c1">ODESolver</span>(<span class="pl-c1">Rodas5</span>()),
                                gradient_method<span class="pl-k">=</span><span class="pl-c1">:ForwardDiff</span>,
                                hessian_method<span class="pl-k">=</span><span class="pl-c1">:GaussNewton</span>)</pre></div>
<p dir="auto">If no ODE-solver, gradient and/or Hessian method are provided, good defaults are used. To compute the cost, gradient, and Hessian, first define the parameter vector <code>x</code>, then initialize the gradient and Hessian matrices:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x = petab_problem.θ_nominalT
∇f = zeros(length(x))
H = zeros(length(x), length(x))

f = petab_problem.compute_cost(x)
petab_problem.compute_gradient!(∇f, x)
petab_problem.compute_hessian!(H, x)"><pre>x <span class="pl-k">=</span> petab_problem<span class="pl-k">.</span>θ_nominalT
∇f <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(<span class="pl-c1">length</span>(x))
H <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(<span class="pl-c1">length</span>(x), <span class="pl-c1">length</span>(x))

f <span class="pl-k">=</span> petab_problem<span class="pl-k">.</span><span class="pl-c1">compute_cost</span>(x)
petab_problem<span class="pl-k">.</span><span class="pl-c1">compute_gradient!</span>(∇f, x)
petab_problem<span class="pl-k">.</span><span class="pl-c1">compute_hessian!</span>(H, x)</pre></div>
<p dir="auto">Calibrating the model to data with multistart optimization is also straightforward. For example, to use the <a href="https://github.com/jump-dev/Ipopt.jl">Ipopt</a> optimizer with 10 Latin-Hypercube sampled start guesses and to save the results in <code>dir_save</code> do:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Ipopt
alg = IpoptOptimiser(false)
res = calibrate_model_multistart(petab_problem, alg, 10, dir_save)"><pre><span class="pl-k">using</span> Ipopt
alg <span class="pl-k">=</span> <span class="pl-c1">IpoptOptimiser</span>(<span class="pl-c1">false</span>)
res <span class="pl-k">=</span> <span class="pl-c1">calibrate_model_multistart</span>(petab_problem, alg, <span class="pl-c1">10</span>, dir_save)</pre></div>
<p dir="auto">For additional examples and a list of available optimizers for parameter estimation, see the <a href="https://sebapersson.github.io/PEtab.jl/stable/" rel="nofollow">documentation</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Full <a href="https://github.com/PEtab-dev/PEtab">PEtab</a> support, which with other things include:
<ul dir="auto">
<li>Support for multiple observables.</li>
<li>Support for multiple simulation conditions.</li>
<li>Suport for pre-equilibration (steady-state simulations).</li>
<li>Support for parameter specific to a simulation condition.</li>
</ul>
</li>
<li>Ability to import ODE systems defined in SBML files.</li>
<li>Support for models created in Julia, either as a <a href="https://github.com/SciML/ModelingToolkit.jl">ModelingToolkit.jl</a> ODE-system or as <a href="https://github.com/SciML/Catalyst.jl">Catalyst</a> reaction systems.</li>
<li>Model selection via <a href="https://github.com/PEtab-dev/petab_select">PEtab Select</a>.</li>
<li>Symbolic model pre-processing using ModelingToolkit.jl.</li>
<li>Compatibility with all ODE solvers in DifferentialEquations.jl.</li>
<li>Several options for computing gradients:
<ul dir="auto">
<li>Forward-mode automatic differentiation with ForwardDiff.jl.</li>
<li>Forward sensitivity analysis using ForwardDiff.jl or SciMLSensitivity.jl.</li>
<li>Adjoint sensitivity analysis with algorithms from SciMLSensitivity.jl.</li>
<li>Automatic differentiation via Zygote.jl.</li>
</ul>
</li>
<li>Several options for computing Hessians:
<ul dir="auto">
<li>Exact calculation using Forward-mode automatic differentiation with ForwardDiff.jl.</li>
<li>Approximate block approach with ForwardDiff.jl.</li>
<li>Gauss-Newton method, which is often more performant than (L)-BFGS.</li>
</ul>
</li>
<li>Support for models incorporating discrete events and logical operations.</li>
</ul>
