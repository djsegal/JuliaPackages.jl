<p dir="auto">Julia interface to <a href="https://plot.ly/javascript" rel="nofollow">plotly.js</a> visualization library.</p>
<p dir="auto">This package constructs plotly graphics using all local resources. To interact or save graphics to the Plotly cloud, use the  <a href="https://github.com/plotly/Plotly.jl"><code>Plotly</code></a> package.</p>
