<p dir="auto"><strong>Note: This package is currently unmaintained. Functionality in this package has been moved into various different packages within <code>ACEsuit</code>. For machine learning interatomic potentials see <a href="https://github.com/ACEsuit/ACEpotentials.jl">ACEpotentials.jl</a></strong></p>
<hr>
<p dir="auto">This package implements approximation schemes for permutation and isometry invariant functions, with focus on modelling atomic interactions. It provides constructions of symmetric polynomial bases, such as permutation and isometry invariance.
Heavy use is made of trigonometric polynomials and spherical harmonics to obtain rotation invariance. Implementations of other symmetries are in preparation.</p>
<ul dir="auto">
<li>Main new development towards nonlinear models and AD is on <code>main</code> branch</li>
<li>AD is still a WIP, but expect this to be ready soon</li>
<li>All previous branches are now in maintenance mode.</li>
</ul>
<p dir="auto">See <a href="https://acesuit.github.io/ACE.jl/dev/" rel="nofollow">Documentation</a> for more details on ACE and for references.</p>
