<ul dir="auto">
<li><code>GDAC</code> module to access and retrieve files from Argo server</li>
<li><code>MITprof</code> format of <a href="http://dx.doi.org/10.5194/gmd-8-3071-2015" rel="nofollow">Forget, et al 2015</a> for <a href="https://doi.org/10.7910/DVN/EE3C40" rel="nofollow">standard depth data</a></li>
<li><code>MITprofPlots</code> module (in <code>examples/MITprof_plots.jl</code>)</li>
<li><code>MITprofAnalysis</code> for cost functions and data manipulations</li>
<li><code>MITprofStat</code> for gridded geospatial statistics</li>
<li><code>Notebooks</code>
<ul dir="auto">
<li><a href="https://juliaocean.github.io/OceanRobots.jl/dev/examples/Float_Argo.html" rel="nofollow">ArgoData</a> 🚀 interactive vizualisation</li>
<li><a href="https://euroargodev.github.io/ArgoData.jl/dev/ArgoToMITprof.html" rel="nofollow">MITprof</a> 🚀 simplified format</li>
<li><a href="https://euroargodev.github.io/ArgoData.jl/dev/Argo_argopy.html" rel="nofollow">argopy</a> 🚀 python API via Julia</li>
</ul>
</li>
</ul>
