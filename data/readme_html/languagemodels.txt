<p dir="auto">This repo contains one external file, <a href="https://github.com/google/sentencepiece/blob/635fe8423a249b6e081aacd290d8aef7476c6a28/src/sentencepiece_model.proto">sentencepiece_model.proto</a>, which has its own <a href="https://github.com/google/sentencepiece/blob/635fe8423a249b6e081aacd290d8aef7476c6a28/LICENSE">copyright and license</a>.
This file is used to generate a Julia interface in the <a href="https://github.com/rai-llc/LanguageModels.jl/tree/main/src/sentencepiece">sentencepiece</a> subdirectory,
which is then used to load the tokenizer model for llama2.</p>

<p dir="auto">Supported keyword arguments:</p>
<ul dir="auto">
<li><code>checkpoint_filename</code>: defaults to stories15M artifact which is downloaded when package is built</li>
<li><code>tokenizer_filename</code>: ditto.
The <code>tokenizer.model</code> file should be in the <code>sentencepiece</code>
<a href="https://github.com/google/sentencepiece/blob/master/src/sentencepiece_model.proto"><code>ModelProto</code> Protocol Buffers format</a>.</li>
<li><code>temperature::Float32</code>: how much randomness to use in sampling. Default: <code>0.9f0</code></li>
<li><code>steps</code>: How many tokens to generate. Default: 256. Must not exceed <code>seq_len</code> in the model definition.</li>
<li><code>mmap</code>: Whether to use <a href="https://docs.julialang.org/en/v1/stdlib/Mmap/#Mmap.mmap" rel="nofollow">memory mapped I/O</a>
to load models that are too large to fit in memory. Default: <code>false</code></li>
<li><code>stop_on_special_tokens</code>. Stop sampling tokens once the special tokens such as UNK (unknown), BOS (beginning-of-sentence) or EOS (end of sentence) are encountered. Default: <code>true</code>. For behavior similar to <code>llama2.c</code>, set to <code>false</code>.</li>
</ul>

<p dir="auto">This implementation by default uses the <code>stories15M</code> model from Andrej Karpathy's tinyllamas project on HuggingFace, and its corresponding <code>tokenizer.model</code> from the <code>llama2.c</code> repo.
This model is automatically downloaded when the package is built.</p>
