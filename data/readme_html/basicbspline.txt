<p dir="auto">This package provides basic mathematical operations for <a href="https://en.wikipedia.org/wiki/B-spline" rel="nofollow">B-spline</a>.</p>
<ul dir="auto">
<li>B-spline basis function</li>
<li>Some operations for knot vector</li>
<li>Some operations for B-spline space (piecewise polynomial space)</li>
<li>B-spline manifold (includes curve, surface and solid)</li>
<li>Refinement algorithm for B-spline manifold</li>
<li>Fitting control points for a given function</li>
</ul>

<p dir="auto">There are several Julia packages for B-spline, and this package distinguishes itself with the following key benefits:</p>
<ul dir="auto">
<li>Supports all degrees of polynomials.</li>
<li>Includes a refinement algorithm for B-spline manifolds.</li>
<li>Delivers high-speed performance.</li>
<li>Is mathematically oriented.</li>
<li>Provides a fitting algorithm using least squares. (via <a href="https://github.com/hyrodium/BasicBSplineFitting.jl">BasicBSplineFitting.jl</a>)</li>
<li>Offers exact SVG export feature. (via <a href="https://github.com/hyrodium/BasicBSplineExporter.jl">BasicBSplineExporter.jl</a>)</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">B-spline basis function</h3><a id="user-content-b-spline-basis-function" class="anchor" aria-label="Permalink: B-spline basis function" href="#b-spline-basis-function"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The value of B-spline basis function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f7dfe65f193d6ae0a4d56ffca6114537">$B_{(i,p,k)}$</math-renderer> can be obtained with <code>bsplinebasis₊₀</code>.</p>
<p dir="auto">$$
\begin{aligned}
{B}<em>{(i,p,k)}(t)
&amp;=
\frac{t-k</em>{i}}{k_{i+p}-k_{i}}{B}<em>{(i,p-1,k)}(t)
+\frac{k</em>{i+p+1}-t}{k_{i+p+1}-k_{i+1}}{B}<em>{(i+1,p-1,k)}(t) \
{B}</em>{(i,0,k)}(t)
&amp;=
\begin{cases}
&amp;1\quad (k_{i}\le t&lt; k_{i+1})\
&amp;0\quad (\text{otherwise})
\end{cases}
\end{aligned}
$$</p>
