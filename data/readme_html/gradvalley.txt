<p dir="auto">GradValley.jl is a new lightweight package for Deep Learning written in 100% Julia. GradValley offers a high level interface for flexible model building and training. It is based on Julia’s standard array type and needs no additional tensor type. <br>
To get started, see <a href="https://github.com/jonas208/GradValley.jl/blob/main/README.md#installation">Installation</a> and <a href="https://github.com/jonas208/GradValley.jl/blob/main/README.md#getting-started">Getting Started</a>. After that, you could look at the <a href="https://jonas208.github.io/GradValley.jl/dev/tutorials_and_examples/" rel="nofollow">Tutorials and Examples</a> section in the <a href="https://jonas208.github.io/GradValley.jl/" rel="nofollow">documentation</a>. Or directly start using a <a href="https://jonas208.github.io/GradValley.jl/dev/(pre-trained)_models/" rel="nofollow">pre-trained model</a>, for example a <a href="https://jonas208.github.io/GradValley.jl/dev/(pre-trained)_models/#ResNet18/34/50/101/152-(Image-Classification)" rel="nofollow">pre-trained ResNet</a>.</p>
<p dir="auto">The <a href="https://jonas208.github.io/GradValley.jl/" rel="nofollow">documentation</a> can be found on the GitHub Pages site of this repository: <a href="https://jonas208.github.io/GradValley.jl/" rel="nofollow">https://jonas208.github.io/GradValley.jl/</a>
<br> Further <a href="https://jonas208.github.io/GradValley.jl/dev/tutorials_and_examples/" rel="nofollow">tutorials and examples</a> can be found there as well.</p>

<p dir="auto">This example shows the basic workflow on model building (using <a href="https://jonas208.github.io/GradValley.jl/dev/reference/#Containers" rel="nofollow">containers</a>) and how to use loss functions and optimizers to train the model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GradValley

using GradValley.Optimization # The &quot;Optimization&quot; module provides different loss functions and optimizers.

# Definition of a LeNet-like model consisting of a feature extractor and a classifier
feature_extractor = SequentialContainer([ # a convolution layer with 1 in channel, 6 out channels, a 5*5 kernel and a relu activation
                                         Conv(1, 6, (5, 5), activation_function=&quot;relu&quot;),
                                         # an average pooling layer with a 2*2 filter (when not specified, stride is automatically set to kernel size)
                                         AvgPool((2, 2)),
                                         Conv(6, 16, (5, 5), activation_function=&quot;relu&quot;),
                                         AvgPool((2, 2))])
flatten = Reshape((256, ))
classifier = SequentialContainer([ # a fully connected layer (also known as dense or linear) with 256 in features, 120 out features and a relu activation
                                  Fc(256, 120, activation_function=&quot;relu&quot;),
                                  Fc(120, 84, activation_function=&quot;relu&quot;),
                                  Fc(84, 10),
                                  # a softmax activation layer, the softmax will be calculated along the first dimension (the features dimension)
                                  Softmax(dims=1)])
# The final model consists of three different submodules, 
# which shows that a SequentialContainer can contain not only layers, but also other SequentialContainers
model = SequentialContainer([feature_extractor, flatten, classifier])
                                  
# feeding the network with some random data
# After a model is initialized, its parameters are Float32 arrays by default. The input to the model must always be of the same element type as its parameters!
# You can change the device (CPU/GPU) and element type of the model's parameters with the function module_to_eltype_device!

prediction = model(input) # layers and containers are callable, alternatively, you can call the forward function directly: forward(model, input)

optimizer = MSGD(model, learning_rate, momentum=0.5) # momentum stochastic gradient decent with a momentum of 0.5

# backpropagation
zero_gradients(model)
loss, derivative_loss = mse_loss(prediction, target) # mean squared error

step!(optimizer) # making a optimization step with the calculated gradients and the optimizer"><pre><span class="pl-k">using</span> GradValley
