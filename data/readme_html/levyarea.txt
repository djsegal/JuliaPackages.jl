<p dir="auto">This package implements state-of-the-art methods for the simulation of iterated stochastic integrals.
These appear e.g. in higher order algorithms for the solution of stochastic (partial) differential equations.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage Example</h2><a id="user-content-usage-example" class="anchor" aria-label="Permalink: Usage Example" href="#usage-example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Load the package and generate a Wiener increment:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using LevyArea
julia&gt; m = 5; # dimension of Wiener process
julia&gt; h = 0.01; # step size or length of time interval
julia&gt; err = 0.05; # error bound
julia&gt; W = sqrt(h) * randn(m); # increment of Wiener process"><pre>julia&gt; <span class="pl-k">using</span> LevyArea
julia&gt; m <span class="pl-k">=</span> <span class="pl-c1">5</span>; <span class="pl-c"><span class="pl-c">#</span> dimension of Wiener process</span>
julia&gt; h <span class="pl-k">=</span> <span class="pl-c1">0.01</span>; <span class="pl-c"><span class="pl-c">#</span> step size or length of time interval</span>
julia&gt; err <span class="pl-k">=</span> <span class="pl-c1">0.05</span>; <span class="pl-c"><span class="pl-c">#</span> error bound</span>
julia&gt; W <span class="pl-k">=</span> <span class="pl-c1">sqrt</span>(h) <span class="pl-k">*</span> <span class="pl-c1">randn</span>(m); <span class="pl-c"><span class="pl-c">#</span> increment of Wiener process</span></pre></div>
<p dir="auto">Here, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$W$</math-renderer> is the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$m$</math-renderer>-dimensional vector of increments of the driving
Wiener process on some time interval of length <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$h$</math-renderer>.</p>
<p dir="auto">The default call uses h^(3/2) as the precision and chooses the best algorithm automatically:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; II = iterated_integrals(W,h)"><pre>julia&gt; II <span class="pl-k">=</span> <span class="pl-c1">iterated_integrals</span>(W,h)</pre></div>
<p dir="auto">If not stated otherwise, the default error criterion is the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$\max,L^2$</math-renderer>-error
and the function returns the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$m \times m$</math-renderer> matrix <code>II</code> containing a realisation
of the approximate iterated stochastic integrals that correspond
to the given increment <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$W$</math-renderer>.</p>
<p dir="auto">The desired precision can be optionally provided
using a third positional argument:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; II = iterated_integrals(W,h,err)"><pre>julia&gt; II <span class="pl-k">=</span> <span class="pl-c1">iterated_integrals</span>(W,h,err)</pre></div>
<p dir="auto">Again, the software package automatically chooses the optimal
algorithm.</p>
<p dir="auto">To determine which algorithm is chosen by the package without simulating any iterated
stochastic integrals yet, the function <code>optimal_algorithm</code> can
be used. The arguments to this function are the dimension of the Wiener
process, the step size and the desired precision:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; alg = optimal_algorithm(m,h,err); # output: Fourier()"><pre>julia&gt; alg <span class="pl-k">=</span> <span class="pl-c1">optimal_algorithm</span>(m,h,err); <span class="pl-c"><span class="pl-c">#</span> output: Fourier()</span></pre></div>
<p dir="auto">It is also possible to choose the algorithm directly using the
keyword argument <code>alg</code>. The value can be one of
<code>Fourier()</code>, <code>Milstein()</code>, <code>Wiktorsson()</code> and <code>MronRoe()</code>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; II = iterated_integrals(W,h; alg=Milstein())"><pre>julia&gt; II <span class="pl-k">=</span> <span class="pl-c1">iterated_integrals</span>(W,h; alg<span class="pl-k">=</span><span class="pl-c1">Milstein</span>())</pre></div>
<p dir="auto">As the norm for the considered error, e.g., the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$\max,L^2$</math-renderer>- and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$\mathrm{F},L^2$</math-renderer>-norm
can be selected using a keyword argument. The corresponding
values are <code>MaxL2()</code> and <code>FrobeniusL2()</code>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; II = iterated_integrals(W,h,err; error_norm=FrobeniusL2())"><pre>julia&gt; II <span class="pl-k">=</span> <span class="pl-c1">iterated_integrals</span>(W,h,err; error_norm<span class="pl-k">=</span><span class="pl-c1">FrobeniusL2</span>())</pre></div>
<p dir="auto">If iterated stochastic integrals for some <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$Q$</math-renderer>-Wiener process need to
be simulated, like for the numerical simulation of solutions to SPDEs,
then the increment of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$Q$</math-renderer>-Wiener process together with the
square roots of the eigenvalues of the associated covariance
operator have to be provided:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; q = [1/k^2 for k=1:m]; # eigenvalues of cov. operator
julia&gt; QW = sqrt(h) * sqrt.(q) .* randn(m); # Q-Wiener increment
julia&gt; IIQ = iterated_integrals(QW,sqrt.(q),h,err)"><pre>julia&gt; q <span class="pl-k">=</span> [<span class="pl-c1">1</span><span class="pl-k">/</span>k<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">for</span> k<span class="pl-k">=</span><span class="pl-c1">1</span><span class="pl-k">:</span>m]; <span class="pl-c"><span class="pl-c">#</span> eigenvalues of cov. operator</span>
julia&gt; QW <span class="pl-k">=</span> <span class="pl-c1">sqrt</span>(h) <span class="pl-k">*</span> <span class="pl-c1">sqrt</span>.(q) <span class="pl-k">.*</span> <span class="pl-c1">randn</span>(m); <span class="pl-c"><span class="pl-c">#</span> Q-Wiener increment</span>
julia&gt; IIQ <span class="pl-k">=</span> <span class="pl-c1">iterated_integrals</span>(QW,<span class="pl-c1">sqrt</span>.(q),h,err)</pre></div>
<p dir="auto">In this case, the function <code>iterated_integrals</code> utilizes a
scaling of the iterated stochastic integrals and also adjusts the error
estimates appropriately such that the error bound holds w.r.t.\ the
iterated stochastic integrals <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$\mathcal{I}^{Q}(h)$</math-renderer> based on the
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$Q$</math-renderer>-Wiener process. Here the error norm defaults to the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="66f738c393ef2a518c11b845558e192b">$\mathrm{F},L^2$</math-renderer>-error.</p>
<p dir="auto">Note that all discussed keyword arguments are optional and can be
combined as needed.</p>
