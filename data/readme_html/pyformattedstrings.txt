<p dir="auto">Julia implementation of Python-like <em>formatted string literals</em> or <em>f-strings</em>. See <a href="https://www.python.org/dev/peps/pep-0498/" rel="nofollow">PEP 498</a> for the original motivation and background for f-strings in Python.</p>
<p dir="auto"><code>PyFormattedStrings.jl</code> mirrors the corresponding Python behavior as closely as possible without reimplementing formatting from scratch. Actual formatting is performed by the <code>Printf</code> stdlib, this package just converts the formatted string syntax. There is no additional runtime overhead compared to a manually-written corresponding <code>@printf</code> call.</p>
<p dir="auto">Supports all f-string features that are directly available in <code>Printf</code>. Compared to Python, these are not implemented: (1) postfix modifiers (<code>!a</code>, <code>!s</code>, <code>!r</code>), (2)  <code>=</code> and <code>^</code> alignment options, (3) <code>=</code> sign to show expression.</p>
