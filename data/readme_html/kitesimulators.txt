<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Hardware requirements</h2><a id="user-content-hardware-requirements" class="anchor" aria-label="Permalink: Hardware requirements" href="#hardware-requirements"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A fast computer helps to reduce the installation time, otherwise, it works well even on dual-core computers with 4G RAM, and 2G RAM might be sufficient. OpenGL is a hard requirement. A dedicated graphics card is useful, but not always required. If you have a Windows laptop please enable the dedicated graphics card in the settings.</p>
<p dir="auto">The program was tested with a "Logitech Extreme 3D pro" Joystick, but most likely any Joystick will do. If not, please create an issue on GitHub. The installation was tested on Windows 10 and Ubuntu 18.04, 20.04, 22.04 and 24.04, but should also work on Mac.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">KiteApps for non-programmers</h2><a id="user-content-kiteapps-for-non-programmers" class="anchor" aria-label="Permalink: KiteApps for non-programmers" href="#kiteapps-for-non-programmers"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides two GUI applications that can be used by non-programmers:</p>
<ul dir="auto">
<li><a href="docs/autopilot.md">autopilot</a></li>
<li><a href="docs/joystick.md">joystick</a></li>
</ul>
<p dir="auto">The first app can be used to run one of the provided demo simulations, but you can also run your own simulation by copying and modifying the configuration files.</p>
<p dir="auto">The second app can be used to learn how to steer a kite and how to operate the winch manually using a joystick.</p>
