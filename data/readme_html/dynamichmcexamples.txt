<p dir="auto">This repository contains examples for my the libraries related Bayesian inference I maintain. Install this with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add https://github.com/tpapp/DynamicHMCExamples.jl"><pre>pkg<span class="pl-k">&gt;</span> add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>tpapp<span class="pl-k">/</span>DynamicHMCExamples<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">which will download a working and tested set of versions. Optionally, you can <code>pkg&gt; up</code> after this.</p>
<p dir="auto">The examples are in the <a href="./src/">src/</a> directory as Julia source files, marked up for <a href="https://github.com/fredrikekre/Literate.jl">Literate.jl</a>. This means that they can be executed directly, but they are also available as <a href="https://tpapp.github.io/DynamicHMCExamples.jl/latest" rel="nofollow">webpages</a>.</p>
<p dir="auto">Note that this is <em>not</em> an introduction to Bayesian inference, merely an implementation in Julia using a certain approach that I find advantageous. The focus is on coding the (log) posterior as a function, then passing this to a modern Hamiltonian Monte Carlo sampler (a variant of NUTS, as described in <a href="https://arxiv.org/abs/1701.02434" rel="nofollow">Betancourt (2017)</a>.</p>
<p dir="auto">The advantage of this approach is that you can <a href="https://github.com/JuliaDebug/Debugger.jl">debug</a>, <a href="https://github.com/JuliaCI/BenchmarkTools.jl">benchmark</a>, and <a href="https://docs.julialang.org/en/v1/manual/performance-tips/" rel="nofollow">optimize</a> your posterior calculations directly using the tools in Julia, like any other Julia code. In contrast to other libraries,</p>
<ol dir="auto">
<li>you don't need to use a DSL,</li>
<li>you are not formulating your model as a directed acyclic graph,</li>
<li>and you can calculate some are all derivatives manually.</li>
</ol>
<p dir="auto">The implicit requirement for this approach is of course that you need to understand how to translate your model to a posterior function and code it in Julia.</p>
<p dir="auto">The examples show how to do transformations and automatic differentiation with related libraries that wrap a log posterior function. However, if you prefer, you can use other approaches, such as manually coding the transformations or symbolic differentiation.</p>
