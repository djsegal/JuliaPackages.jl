<p dir="auto">Programa para el equilibrio liquido/vapor y calculo de propiedades usando ecuaciones cubicas de estado.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Caracteristicas</h2><a id="user-content-caracteristicas" class="anchor" aria-label="Permalink: Caracteristicas" href="#caracteristicas"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">TermoQuimica puede calcular el equilibrio liquido y vapor de n componentes, haciendo uso de distintos métodos y sin hacer molestas conversiones de unidades.</p>
<p dir="auto">Métodos utilizados:</p>
<ul dir="auto">
<li>Ideal</li>
<li>Van Laar</li>
<li>Margules</li>
<li>Wilson</li>
<li>Wilson mod.</li>
<li>NRTL</li>
<li>UNIQUAC</li>
<li>UNIFAC</li>
</ul>
<p dir="auto">Ecuaciones de estado:</p>
<ul dir="auto">
<li>Van Der Waals</li>
<li>Redlich Kwong</li>
<li>Soave Redlich Kwong</li>
<li>Peng Robinson</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Ejemplo de uso</h2><a id="user-content-ejemplo-de-uso" class="anchor" aria-label="Permalink: Ejemplo de uso" href="#ejemplo-de-uso"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Para el equilibrio <strong>P-X-Y</strong> la mezcla <strong>etanol(1)-agua(2)</strong> a 273.15 K, usando el modelo de actividad de <strong>Van Laar</strong>, las coeficientes de Van Laar son: <code>A12 = 1.6798</code> y <code>A21 = 0.9227</code>, las constantes de Antoine para el etanol son: <code>A = 8.12875</code>, <code>B = 1660.8713</code>, <code>C = 238.131</code> y para el agua <code>A = 8.05573</code>, <code>B = 1723.6425</code>, <code>C = 233.08</code></p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="vanlaar.pxy(n,T,CA,Λ,xx;uni=u&quot;Torr&quot;)"><pre class="notranslate"><code>vanlaar.pxy(n,T,CA,Λ,xx;uni=u"Torr")
</code></pre></div>
<p dir="auto">Donde:</p>
<ul dir="auto">
<li><strong>n</strong> Es el numero de componentes</li>
<li><strong>T</strong> Es la temperatura del sistema</li>
<li><strong>CA</strong> Constantes de Antoine para los <code>n</code> componentes</li>
<li><strong>Λ</strong> Parámetros de interacción entre los componentes en grados kelvin</li>
<li><strong>xx</strong> Son los puntos en el liquido donde se buscara el equilibrio con el vapor</li>
<li><strong>uni</strong> Son las unidades en las que se desea el resultado, por defecto esta en Torr</li>
</ul>
<p dir="auto">Entonces se deberá hacer lo siguiente</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="n = 2
T = 273.15u&quot;K&quot;
CA = [8.12875, 1660.8713, 238.131; 8.05573, 1723.6425, 233.08]
Λ = [0 , 1.6798; 0.9227, 0]
xx = 0:0.1:1
unidad = &quot;Pa&quot;

vanlaar.pxy(n,T,CA,Λ,xx;uni=u&quot;Torr&quot;)"><pre class="notranslate"><code>n = 2
