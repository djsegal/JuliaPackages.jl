<p dir="auto">Pads arrays of any dimension with various border options including constants, periodic, symmetric, mirror and smooth. Can control amount of padding applied to the left and right side of each dimension. Fully differentiable (compatible with <code>Zygote.jl</code> <code>Flux.jl</code>)</p>
<p dir="auto"><code>pad</code> eagerly allocates new bigger array while <code>pad!</code> mutates original array in place. For <code>pad!,</code> the effective border is set back by the padding amount when evaluating various border options. <code>pad</code> is AD (automatic differentiation) compatible while <code>pad!</code> requires <code>Zygote.Buffer</code> for AD (see usage )</p>

<ul dir="auto">
<li>any constant value <code>v</code>: a b c | v v</li>
<li><code>:periodic</code>: a b c | a b</li>
<li><code>:replicate</code>: a b c | c c</li>
<li><code>:symmetric</code>: a b c | c b</li>
<li><code>:mirror</code>: a b c | b a</li>
<li><code>:smooth</code>: a b c | 2c-b (Maintains C1 continuity)</li>
</ul>
