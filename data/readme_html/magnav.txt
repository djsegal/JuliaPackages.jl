<p dir="auto">MagNav.jl contains a full suite of tools for airborne <strong>Mag</strong>netic anomaly <strong>Nav</strong>igation (MagNav), including flight path &amp; INS data import or simulation, mapping, aeromagnetic compensation, and navigation. This package was developed as part of the <a href="https://aia.mit.edu/" rel="nofollow">DAF-MIT Artificial Intelligence Accelerator</a>. More information on this effort, including a list of relevant publications, is provided on the <a href="https://magnav.mit.edu/" rel="nofollow">challenge problem website</a>. The package has been tested on the long-term support (LTS) and latest stable versions of Julia, which may be downloaded from <a href="https://julialang.org/downloads/" rel="nofollow">here</a>. The recommended IDE for Julia is <a href="https://code.visualstudio.com/" rel="nofollow">Visual Studio Code</a> (with the Julia extension).</p>

<p dir="auto">A Docker image is available, which contains Julia, MagNav.jl, and the example notebooks. Install <a href="https://www.docker.com/products/docker-desktop/" rel="nofollow">Docker Desktop</a>, search and pull <code>jtaylormit/magnav</code>, and run with the host port set to <code>8888</code>. Alternatively, from the command line, run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="docker pull jtaylormit/magnav
docker run -p 8888:8888 jtaylormit/magnav"><pre class="notranslate"><code>docker pull jtaylormit/magnav
docker run -p 8888:8888 jtaylormit/magnav
</code></pre></div>
<p dir="auto">A Docker container will spin up and provide a URL that then must be opened in a local browser, which will launch JupyterLab. It will look something like this: <code>http://127.0.0.1:8888/lab?token=###</code>. Jupyter notebooks can be opened directly, but for Pluto notebooks, click <code>Pluto Notebook</code> from the Launcher, then select and open the desired Pluto notebook. Note that any changes to the notebooks occur inside the Docker container only, so a notebook must be manually downloaded to be saved.</p>
<p dir="auto">The above Docker image is <a href="https://hub.docker.com/r/jtaylormit/magnav" rel="nofollow">hosted on Docker Hub</a>, and it is manually and sporadically updated. For the most recent Docker image, from the command line, run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="docker pull ghcr.io/mit-ai-accelerator/magnav.jl
docker run -p 8888:8888 ghcr.io/mit-ai-accelerator/magnav.jl"><pre class="notranslate"><code>docker pull ghcr.io/mit-ai-accelerator/magnav.jl
docker run -p 8888:8888 ghcr.io/mit-ai-accelerator/magnav.jl
</code></pre></div>

This dataset can also be directly downloaded from <a href="https://doi.org/10.5281/zenodo.4271803" rel="nofollow">here</a>.
