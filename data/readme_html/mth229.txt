<p dir="auto">To run the <code>MTH229</code> package remotely, we have three options:</p>
<ul dir="auto">
<li>
<p dir="auto">If registered in a class, we have been provided a service we call <code>JuliaBox</code></p>
</li>
<li>
<p dir="auto">You can run freely through the resource-limited binder: <a href="https://mybinder.org/v2/gh/mth229/229-projects/lite?labpath=blank-notebook.ipynb" rel="nofollow"><img src="https://camo.githubusercontent.com/7861126a7eb56440456a50288331e87b9604edbaa125354195637561fd400014/68747470733a2f2f6d7962696e6465722e6f72672f62616467655f6c6f676f2e737667" alt="Run on Binder" data-canonical-src="https://mybinder.org/badge_logo.svg" style="max-width: 100%;"></a></p>
</li>
<li>
<p dir="auto"><a href="https://colab.research.google.com/" rel="nofollow">Google colab</a> offers a free service. To run this, you need to execute a command that downloads <code>Julia</code> and installs this package and a plotting package:</p>
</li>
</ul>
