<p dir="auto"><a href="https://github.com/dss-extensions/OpenDSSDirect.jl/actions/workflows/ci.yml"><img src="https://github.com/dss-extensions/OpenDSSDirect.jl/workflows/CI/badge.svg" alt="GitHub Actions: Tests" style="max-width: 100%;"></a></p>
<p dir="auto">OpenDSSDirect.jl is a cross-platform Julia package implements a "direct" library interface to <a href="http://smartgrid.epri.com/SimulationTool.aspx" rel="nofollow">OpenDSS</a> using <a href="https://github.com/dss-extensions/dss_capi/">DSS C-API</a>, an alternative implementation.</p>
<p dir="auto">OpenDSS is an open-source distribution system simulator.</p>
<p dir="auto">Originally, the package used the OpenDSSDirect library from the official OpenDSS repository. Since OpenDSS is officially Windows-only, this package was migrated to use DSS C-API in 2019. The DSS C-API library is a community implementation of the OpenDSS engine built with the Free Pascal compiler, targeting cross-platform compatibility and an extended API. See its repository <a href="https://github.com/dss-extensions/dss_capi">here</a> for the full Pascal/Delphi code, or <a href="https://dss-extensions.org/" rel="nofollow">https://dss-extensions.org/</a> for an overview of the projects around it.</p>
<p dir="auto">For a general FAQ and many other links, see <a href="https://github.com/dss-extensions/dss-extensions#readme">https://github.com/dss-extensions/dss-extensions#readme</a></p>
<p dir="auto">See also <a href="https://github.com/dss-extensions/OpenDSSDirect.py">OpenDSSDirect.py</a> for a package in Python with similar calling style, or <a href="https://github.com/dss-extensions/dss_python">DSS-Python</a>, <a href="https://github.com/dss-extensions/dss_matlab">DSS_MATLAB</a> and <a href="https://github.com/dss-extensions/dss_sharp">dss_sharp</a> for packages that mimic the OpenDSS COM API organization and style.</p>
<p dir="auto"><strong>This package is available for Windows, macOS (x86 and ARM processors), and Linux (x86 and ARM processors).</strong></p>

<p dir="auto">This package interfaces with the OpenDSS engine using a library interface, so a good understanding of OpenDSS will help troubleshooting.
There are plenty of useful resources located <a href="https://sourceforge.net/p/electricdss/code/HEAD/tree/trunk/Version8/Doc/" rel="nofollow">here</a>. If you
have experience with the official OpenDSS COM implementation, the following document compares our two Python modules, DSS-Python
(same structure as the OpenDSS COM module) and OpenDSSDirect.py (similar structure to OpenDSSDirect.jl):
<a href="https://dss-extensions.org/python_apis.html" rel="nofollow">DSS-Extensions — OpenDSS: Overview of Python APIs</a>.</p>
<p dir="auto">If you are having issues using this Julia interface, feel free to open an Issue on GitHub <a href="https://github.com/dss-extensions/OpenDSSDirect.jl/issues/new">here</a> or
post at our <a href="https://github.com/orgs/dss-extensions/discussions/categories/general">general Discussions page</a>.</p>
