<p dir="auto">To use Thunderbolt you first need to install Julia, see <a href="https://julialang.org/" rel="nofollow">https://julialang.org/</a> for details.
Installing Thunderbolt can then be done from the Pkg REPL; press <code>]</code> at the <code>julia&gt;</code> promp to
enter <code>pkg&gt;</code> mode:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add Ferrite#b6976d3, https://github.com/termi-official/Thunderbolt.jl#main"><pre class="notranslate"><code>pkg&gt; add Ferrite#b6976d3, https://github.com/termi-official/Thunderbolt.jl#main
</code></pre></div>
<div class="markdown-alert markdown-alert-note" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-info mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M0 8a8 8 0 1 1 16 0A8 8 0 0 1 0 8Zm8-6.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM6.5 7.75A.75.75 0 0 1 7.25 7h1a.75.75 0 0 1 .75.75v2.75h.25a.75.75 0 0 1 0 1.5h-2a.75.75 0 0 1 0-1.5h.25v-2h-.25a.75.75 0 0 1-.75-.75ZM8 6a1 1 0 1 1 0-2 1 1 0 0 1 0 2Z"></path></svg>Note</p><p dir="auto">The package is under codevelopment with Ferrite.jl, which is why you will need the currently (unreleased)
1.0 version of Ferrite.jl and the (unregistered) Thunderbolt.jl package. Please use <a href="https://ferrite-fem.github.io/Ferrite.jl/dev/" rel="nofollow">these Ferrite.jl docs</a>
for Ferrite specific questions.</p>
</div>
<p dir="auto">This will install Thunderbolt and all necessary dependencies. Press backspace to get back to the
<code>julia&gt;</code> prompt. (See the <a href="https://pkgdocs.julialang.org/" rel="nofollow">documentation for Pkg</a>, Julia's
package manager, for more help regarding package installation and project management.)</p>
<p dir="auto">Finally, to load Thunderbolt, use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Thunderbolt"><pre><span class="pl-k">using</span> Thunderbolt</pre></div>
<p dir="auto">You are now all set to start using Thunderbolt!</p>

<p dir="auto">To build the docs you first need to install Julia, see <a href="https://julialang.org/" rel="nofollow">https://julialang.org/</a> for details.
Then you need to install the packages. To accomplish this you first start a julia shell in the
docs fonder and open the Pkg REPL; i.e. press <code>]</code> at the <code>julia&gt;</code> promp to
enter <code>pkg&gt;</code> mode. Then you <a href="https://pkgdocs.julialang.org/v1/environments/#Using-someone-else's-project" rel="nofollow">activate and instantiate</a> via</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(@v1.9) pkg&gt; activate .
(docs) pkg&gt; instantiate"><pre class="notranslate"><code>(@v1.9) pkg&gt; activate .
(docs) pkg&gt; instantiate
</code></pre></div>
<p dir="auto">This has to be done only once. Now you can use the provided liveserver to build and open the docs via</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia --project=. liveserver.jl"><pre class="notranslate"><code>$ julia --project=. liveserver.jl
</code></pre></div>
<p dir="auto">Now you can view the documentation at <a href="https://localhost:8000" rel="nofollow">https://localhost:8000</a> . All further information will be provided there.</p>
