<p dir="auto">You can make a <em>holdable</em> smooth surface model with this repository.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/img/overview.png"><img src="docs/src/img/overview.png" alt="" style="max-width: 100%;"></a></p>
<p dir="auto">The main part of this project is how to determine a planer shape from a strip on the target curved surface.
In mathematics, this mapping is called "embedding".
We determined the embedding by minimizing its elastic strain energy.
This is the meaning of "Elastic Surface Embedding".</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">step 1: Define a shape of a surface (and split it into strips)</h3><a id="user-content-step-1-define-a-shape-of-a-surface-and-split-it-into-strips" class="anchor" aria-label="Permalink: step 1: Define a shape of a surface (and split it into strips)" href="#step-1-define-a-shape-of-a-surface-and-split-it-into-strips"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The definition must consist of parametric mapping and its domain.
For example, a paraboloid can be parametrized as below.</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="54ad8f0c7c3f4188b92dac558531fdc0">$$\begin{aligned}
\boldsymbol{p}_{[0]}(u^1,u^2)
&amp;= \begin{pmatrix}
u^1 \\\
u^2 \\\
(u^1)^2+(u^2)^2
\end{pmatrix} &amp;
(u^1, u^2)
\in [-1,1] \times [-1,1]
\end{aligned}$$</math-renderer>
<p dir="auto">The domain will be split into <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54ad8f0c7c3f4188b92dac558531fdc0">$D^{(i)}$</math-renderer>.</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="54ad8f0c7c3f4188b92dac558531fdc0">$$\begin{aligned}
D^{(i)}
= [-1,1] \times \left[\frac{i-1}{10}, \frac{i}{10}\right] \qquad (i = 1,...,10)
\end{aligned}$$</math-renderer>

Split the surface into strips, and compute the embeddings.</p>
