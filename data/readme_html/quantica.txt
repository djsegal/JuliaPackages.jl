<p dir="auto">The Quantica.jl package provides an expressive API to build arbitrary quantum systems on a discrete lattice, and a collection of algorithms to compute some of their properties.</p>
<p dir="auto">Quantica.jl requires Julia v1.9 or later.</p>

<ul dir="auto">
<li>Build and visualize Hamiltonians on discrete lattices of arbitrary dimensions, using tight-binding models with arbitrary number of orbitals</li>
<li>Compute and visualize band structures of periodic systems</li>
<li>Couple arbitrary Hamiltonians and compute non-interacting Green functions</li>
<li>Compute transport and spectral observables, such as local density of states, current densities, conductance and Josephson currents</li>
</ul>
<p dir="auto">Some of this functionality, particularly visualization, requires loading some plot backend from the Makie repository, such as GLMakie (GPU-accelerated interactive visualization), CairoMakie (for pdf/svg output) or WGLMakie (Web-GL backend for use inside browsers)</p>
