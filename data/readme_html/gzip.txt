<p dir="auto">This module provides a wrapper for the gzip related functions of
<a href="http://zlib.net" rel="nofollow">zlib</a>, a free, general-purpose, legally
unencumbered, lossless data-compression library. These functions
allow the reading and writing of gzip files.</p>

<ul dir="auto">
<li>This interface is only for gzipped files, not the streaming zlib compression interface. Internally, it depends on/uses the streaming interface, but the gzip related functions are higher level functions pertaining to gzip files only.</li>
<li><code>GZipStream</code> is an implementation of <code>IO</code> and can be used virtually anywhere <code>IO</code> is used.</li>
<li>This implementation mimics the <code>IOStream</code> implementation, and should be a drop-in replacement for <code>IOStream</code>, with some caveats:
<ul dir="auto">
<li><code>seekend</code> and <code>truncate</code> are not available</li>
<li><code>readuntil</code> is available, but is not very efficient. (But <code>readline</code> works fine.)</li>
</ul>
</li>
</ul>
<p dir="auto">In addition to <code>open</code>, <code>gzopen</code>, and <code>gzdopen</code>, the following <code>IO</code>/<code>IOStream</code> functions are supported:</p>
<ul dir="auto">
<li><code>close()</code></li>
<li><code>flush()</code></li>
<li><code>seek()</code></li>
<li><code>skip()</code></li>
<li><code>position()</code></li>
<li><code>eof()</code></li>
<li><code>read()</code></li>
<li><code>readuntil()</code></li>
<li><code>readline()</code></li>
<li><code>write()</code></li>
<li><code>peek()</code></li>
</ul>
<p dir="auto">Due to limitations in <code>zlib</code>, <code>seekend</code> and <code>truncate</code> are not available.</p>
