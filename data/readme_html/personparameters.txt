<p dir="auto"><a href="https://github.com/juliapsychometrics/PersonParameters.jl">PersonParameters.jl</a> implements estimation of person parameters for Item Response Theory models. Item parameters used in the estimation of person parameters are treated as fixed and known.</p>
<p dir="auto">It is tightly integrated with <a href="https://github.com/juliapsychometrics/ItemResponseFunctions.jl">ItemResponseFunctions.jl</a> allowing the estimation for all models defined in the package. Currently these are:</p>
<ul dir="auto">
<li>Models for dichotomous responses
<ul dir="auto">
<li>1 Parameter Logistic Model</li>
<li>2 Parameter Logistic Model</li>
<li>3 Parameter Logistic Model</li>
<li>4 Parameter Logistic Model</li>
<li>5 Parameter Logistic Model</li>
</ul>
</li>
<li>Models for polytomous responses
<ul dir="auto">
<li>Partial Credit Model</li>
<li>Generalized Partial Credit Model</li>
<li>Rating Scale Model</li>
<li>Generalized Rating Scale Model</li>
</ul>
</li>
</ul>
<p dir="auto">Available estimation methods are:</p>
<ul dir="auto">
<li>Maximum Likelihood (MLE)</li>
<li>Weighted Maximum Likelihood (WLE)</li>
<li>Maximum A Posteriori (MAP)</li>
<li>Expected A Posteriori (EAP)</li>
</ul>
<p dir="auto">For more details see the <a href="https://juliapsychometrics.github.io/PersonParameters.jl/" rel="nofollow">documentation</a></p>
