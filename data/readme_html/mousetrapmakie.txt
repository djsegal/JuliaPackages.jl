<p dir="auto">Experimental package that adds <code>GLMakieArea</code>, a <a href="https://github.com/Clemapfel/Mousetrap.jl/">Mousetrap</a> widget that allows displaying <a href="https://github.com/MakieOrg/Makie.jl">GLMakie</a> plots, similar to how <a href="https://github.com/JuliaGtk/Gtk4Makie.jl">Gtk4Makie.jl</a> allows the same for GTK4.jl.</p>
<p dir="auto">This package is not production ready and should be considered in early alpha. The following features are still missing:</p>
<ul dir="auto">
<li>Applying a post-processing config is not yet implemented</li>
<li>Modifying the screen after it is realized remains untested</li>
<li>Setups with multiple <code>GLMakie.Screen</code>s remain untested</li>
<li><code>runtests.jl</code> is unimplemented, meaning CI through GitHub actions is not yet set up</li>
<li>The Makie event model is ignored completely, only Mousetraps event controllers allow for user input</li>
</ul>
<p dir="auto">If you are experienced with Makie, consider opening a PR to fully implement this package and extend its functionalities. Any significant contributor will be credited as an author. See <a href="./src/MousetrapMakie.jl"><code>src/MousetrapMakie.jl</code></a>, which is heavily commented to make understanding and extending the package easier.</p>
<p dir="auto">See the <a href="https://clemens-cords.com/mousetrap/01_manual/12_opengl_integration/" rel="nofollow">Mousetrap.jl manual chapter on OpenGL integration</a> for more information.</p>
