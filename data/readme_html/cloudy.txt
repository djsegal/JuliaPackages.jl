<p dir="auto">🌧️ A multi-moment cloud microphysics toy model.</p>
<p dir="auto">Currently Cloudy.jl only supports collisions with simple kernels.</p>
<p dir="auto">Examples can be found in the examples folder.</p>
<p dir="auto">Installation hints can be found in .travis.yml file.</p>
<p dir="auto">To build the docs locally:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>julia --project=docs</code></p>
</li>
<li>
<p dir="auto"><code>include(docs/make.jl)</code></p>
</li>
</ul>
