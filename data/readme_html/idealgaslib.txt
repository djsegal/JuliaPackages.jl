<p dir="auto">The <code>IdealGasLib.jl</code> package is a Ideal Gas Library for Engineering Thermodynamics in Julia
based on the <code>EngThermBase.jl</code> infrastructure.</p>
<p dir="auto">The ideal gas type, <code>idealGas</code> is <code>PREC</code>-ision, <code>EXAC</code>-tness, and heat-capacity model
parameterized, so that in order to instantiate an ideal gas object, a heat capacity model object
must be instantiated first.</p>
<p dir="auto"><code>EngThermBase</code> heat capacity model hooks include:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using EngThermBase, TypeTree

julia&gt; print.(TypeTree.tt(Heat));
Heat
 ├─ BivarHeat
 ├─ ConstHeat
 ├─ GenerHeat
 └─ UnvarHeat"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> EngThermBase, TypeTree

julia<span class="pl-k">&gt;</span> <span class="pl-c1">print</span>.(TypeTree<span class="pl-k">.</span><span class="pl-c1">tt</span>(Heat));
Heat
 ├─ BivarHeat
 ├─ ConstHeat
 ├─ GenerHeat
 └─ UnvarHeat</pre></div>
<p dir="auto">The heat models are thus classified by the amount of variable parameters, from zero (for the
<code>ConstHeat</code> model), to one (for the <code>UnvarHeat</code> model), to two (for the <code>BivarHeat</code> model), to
any (for the <code>GenerHeat</code> model).</p>
<p dir="auto">The available <code>IdealGasLib</code> heat capacity model is of an all-temperature, constant specific
heats one suitable for ideal gases, therefore, when the library is loaded, the <code>Heat</code> model tree
becomes:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using IdealGasLib

<p dir="auto">Thus demosntrating that it hooks the <code>nobleGasHeat</code> model under <code>ConstHeat</code> <code>Heat</code> model, which
is a subtype of <code>MODEL</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; supertype(Heat)

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Ideal Noble Gas Heat Model</h2><a id="user-content-ideal-noble-gas-heat-model" class="anchor" aria-label="Permalink: Ideal Noble Gas Heat Model" href="#ideal-noble-gas-heat-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The ideal noble gas heat model is a constant-specific-heat for all temperatures. There are no
explicit bounds in temperature included in this model's implementation.</p>
<p dir="auto">The model is instantiated with a mandatory (i) molar molecular mass, of type <code>m_amt{𝕡,𝕩,MO} where {𝕡,𝕩}</code>, a mandatory (ii) molar specific heat at constant pressure, of type <code>cpamt{𝕡,𝕩,MO} where {𝕡,𝕩}</code>, and optional [iii] reference temperature, <code>T_amt{𝕡,𝕩} where {𝕡,𝕩}</code>, and [iv]
reference pressure, <code>P_amt{𝕡,𝕩} where {𝕡,𝕩}</code>, and [v] molar specific entropy at the reference
state, <code>s_amt{𝕡,𝕩,MO} where {𝕡,𝕩}</code>.</p>

<code>M</code>, and <code>cp</code>, in a mass base, in which the value of <code>M</code> is explicitly and manually used prior
to the instantiation, so as to change the specific heat base, from <code>MA</code> to <code>MO</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; wMass = m_(18.015, MO)

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Ideal Gas Model</h2><a id="user-content-ideal-gas-model" class="anchor" aria-label="Permalink: Ideal Gas Model" href="#ideal-gas-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Once underlying heat models are understood, <code>idealGas</code>es are simple and easy to instantiate, as
they only require a name and a chemical formula, beyond the heat model. This makes it possible
to have a substance modeled in different ways, as it is common in engineering thermodynamics.</p>
<p dir="auto">It is possible to pick a heat model from a tiny library, implemented in this package, as
follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using IdealGasLib

<p dir="auto">Here, the <code>HEAT</code> variable is a dictionary of noble gas models parameterized by dictionary keys,
so that <code>HEAT[:He][Float32][MM]</code> points to the 32-bit precision, <code>MM</code> (i.e., measurements)
exactness noble gas heat model of constant specific heat for Helium. The output explicitly
states the 32-bit precision, as well as each quantity's uncertainties, after the "±" sign.</p>
