<p dir="auto">QuasiGrad.jl is a parallelized, adam-based solver for reserve and security constrained AC unit commitment problems. Solver details are sketeched out in a recent <a href="https://arxiv.org/pdf/2310.06650.pdf" rel="nofollow">pre-print</a> and the associated <a href="https://samchevalier.github.io/docs/SI.pdf" rel="nofollow">SI</a>. QuasiGrad.jl is a parallelized, adam-based solver for reserve and security constrained AC unit commitment problems. Solver details are sketeched out in a recent <a href="https://arxiv.org/pdf/2310.06650.pdf" rel="nofollow">pre-print</a> and the associated <a href="https://samchevalier.github.io/docs/SI.pdf" rel="nofollow">SI</a>.</p>
<p dir="auto">The QuasiGrad solver recently competed in the <a href="https://gocompetition.energy.gov/challenges/challenge-3" rel="nofollow">3rd Grid Optimizaiton Competition</a>, scoring reasonably well in the day-ahead market clearing problem. QuasiGrad's internal gradient-based solver (Adam) can easily be substituted for other ML-inspired solvers (e.g., AdaGrad, AdaDelta, RMSProp, etc.).</p>

<p dir="auto">QuasiGrad can be installed using the Julia package manager via</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] add QuasiGrad"><pre class="notranslate"><code>] add QuasiGrad

<p dir="auto">Julia 1.9.3 or higher is reccomended for use with QuasiGrad. Julia should be launched with as many CPU threads as you wish to dedicate to the solve. More threads, more parallelization.</p>

<p dir="auto">This package is a work-in-progress, and contributions are more than welcome. A valid Gurobi license is needed to run the solver (with some effort, this solver can be swapped out). Note: no QuasiGrad functions are exported to Julia's namespace.</p>
