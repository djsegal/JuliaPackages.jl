<p dir="auto">SimpleIterator.jl is a Julia package that provides a simple Python-like iterator interface for Julia.
It enables the iteration of an object <code>x</code> becomes iteration over <code>iterator(x)</code>.
The iteration behavior can be easily customized by overloading the <code>iterator</code> function and returning the desired iterator object.</p>
