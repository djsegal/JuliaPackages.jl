<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides an image reconstruction pipeline for real-world non-Cartesian MRI, designed particularly for spiral diffusion imaging. It is completely implemented in Julia using original code and external packages, e.g., <a href="https://magneticresonanceimaging.github.io/MRIReco.jl/latest/" rel="nofollow">MRIReco.jl</a> for the off-resonance (B<sub>0</sub>) corrections &amp; core iterative reconstruction tasks, and <a href="https://github.com/BRAIN-TO/MRIGradients.jl">MRIGradients.jl</a> for the correction of gradient waveforms due to system imperfections via the Gradient Impulse Response Function (GIRF).</p>
<p dir="auto">This repository includes working <a href="./docs/lit/examples/">examples</a> for spiral reconstruction with GIRF correction of k-space trajectory (kx-ky-kz, or k<sub>1</sub> as the first order GIRF) and B<sub>0</sub> eddy currents (k<sub>0</sub> as zeroth order GIRF), iterative reconstruction (cg-SENSE) and a Cartesian reconstruction example for coil sensitivity and off-resonance map calculation.</p>
<p dir="auto">The data for the phantom reconstruction <a href="./docs/lit/examples/joss_demo.jl"><code>joss_demo.jl</code></a> is publicly available <a href="https://www.doi.org/10.5281/zenodo.7779045" rel="nofollow">here</a>. The path of the data, <code>params_general[:project_path]</code>, needs to be modified accordingly in the <a href="./docs/lit/examples/recon_config_joss_demo.jl">config file</a>.</p>
<p dir="auto">For a full introduction, please refer to our <a href="./paper/paper.md">manuscript</a> for a full description of this package, including background, purpose, implementation, and the information of dependent packages.</p>

<ol dir="auto">
<li>To get started, make sure you have Julia installed (&gt;=1.9).</li>
<li>Clone the GIRFReco.jl project from Github to a local directory by <code>git clone git@github:BRAIN-TO/GIRFReco.jl</code> or to copy it to the dev directory using the Quick Installation and the following command:</li>
</ol>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; ]dev GIRFReco"><pre class="notranslate"><code>julia&gt; ]dev GIRFReco
</code></pre></div>
<ol start="3" dir="auto">
<li>Open a Julia REPL under the path of your local <code>GIRFReco.jl</code> folder. Our own development configuration is Visual Studio Code with the Julia extension. Other environments for Julia should work in a similar way with possible extra configurations.</li>
<li>In the Julia REPL, type <code>]</code> to enter the package manager.</li>
<li>In Julia package manager, Type <code>activate .</code> to activate a the Julia environment defined in <code>Project.toml</code> file in the <code>GIRFReco.jl</code> repo.</li>
<li>Add the <code>MRIGradients.jl</code> package by <code>add MRIGradients</code>.</li>
<li>Install all additional dependent packages:
<ul dir="auto">
<li><code>add MRIReco</code></li>
<li><code>add MRIFiles</code></li>
<li><code>add MRIBase</code></li>
<li><code>add ImageUtils</code></li>
<li><code>add MRICoilSensitivities</code></li>
<li><code>add FileIO</code></li>
</ul>
</li>
<li>Use command <code>instantiate</code> in Julia package manager to install all of the dependencies. This may be all you need to do (i.e you might be able to skip steps 7,8).</li>
<li>Download the demonstrating data from Zenodo (<a href="https://doi.org/10.5281/zenodo.6510020" rel="nofollow">https://doi.org/10.5281/zenodo.6510020</a>) and extract to your local folder. <strong>Make sure you have both reading and writing privileges on the data folder.</strong>
<ul dir="auto">
<li>Note: The data downloading might take a few minutes.</li>
</ul>
</li>
<li>Open the demo script <code>joss_demo.jl</code> under the folder <code>docs/lit/examples/</code>, make sure to set <code>rootProjPath</code> as the folder that stores demo data, then run it in Julia REPL.</li>
</ol>
