<p dir="auto">While key-value pairs are standard in sorting, oftentimes these keys and values are kept in separate arrays (see Explanation below); we can sort multiple secondary vectors following the values of a primary key vector using a new sorting interface:</p>

xcoords = rand(num_particles)
ycoords = rand(num_particles)

# Reordering applied to `ids` will be done in sync with `xcoords` and `ycoords`
syncsort!(ids, xcoords, ycoords)"><pre><span class="pl-c1">syncsort!</span>(v, rest<span class="pl-k">...</span>)

<p dir="auto">Key-value pair sorting assumes an <em>Array of Structures</em> (AoS) format - e.g., a <code>Vector{Particle}</code> where <code>struct Particle</code> contains some fields <code>coord::Float64</code> and <code>id::Int64</code>. However, in many applications, it is more performant to store these fields as a <em>Structure of Arrays</em> (SoA), i.e. separate <code>coords::Vector{Float64</code> and <code>ids::Vector{Int64}</code>.</p>
<p dir="auto">If we had an Array of Structures, using standard sorting interfaces - as is the case in virtually all programming languages - we'd do something like:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# One primary key and two secondary values
struct Particle
    id::Int64
    xcoord::Float64
    ycoord::Float64
end

# Array of structures
particles = [Particle(rand(Int64), rand(Float64)) for i in 1:10_000]

# Sort by the field `id`
sort!(particles; by=p-&gt;p.id)"><pre><span class="pl-c"><span class="pl-c">#</span> One primary key and two secondary values</span>
<span class="pl-k">struct</span> Particle

    xcoord<span class="pl-k">::</span><span class="pl-c1">Float64</span>

<p dir="auto">In high-performance applications, we'd use a Structure of Arrays, where we have separate arrays for our keys and values; the typical solution would involve creating a mask of indices sorting the primary array, in Julia named <code>sortperm</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Keys and values held in separate vectors
ids = rand(Int64, 10_000)
xcoords = rand(Float64, 10_000)
ycoords = rand(Float64, 10_000)

# Get indices permutation that sorts the primary array
sorted_indices = sortperm(ids)

# Use indices mask to permute arrays
ids = ids[sorted_indices]
xcoords = xcoords[sorted_indices]
ycoords = ycoords[sorted_indices]"><pre><span class="pl-c"><span class="pl-c">#</span> Keys and values held in separate vectors</span>
ids <span class="pl-k">=</span> <span class="pl-c1">rand</span>(Int64, <span class="pl-c1">10_000</span>)
xcoords <span class="pl-k">=</span> <span class="pl-c1">rand</span>(Float64, <span class="pl-c1">10_000</span>)
ycoords <span class="pl-k">=</span> <span class="pl-c1">rand</span>(Float64, <span class="pl-c1">10_000</span>)

<span class="pl-c"><span class="pl-c">#</span> Get indices permutation that sorts the primary array</span>
sorted_indices <span class="pl-k">=</span> <span class="pl-c1">sortperm</span>(ids)

<span class="pl-c"><span class="pl-c">#</span> Use indices mask to permute arrays</span>
ids <span class="pl-k">=</span> ids[sorted_indices]
xcoords <span class="pl-k">=</span> xcoords[sorted_indices]
ycoords <span class="pl-k">=</span> ycoords[sorted_indices]</pre></div>
