<p dir="auto"><strong>Note: starting with version 2.0.0, GtkObservables.jl is based on <a href="https://github.com/JuliaGtk/Gtk4.jl">Gtk4</a>.</strong></p>
<p dir="auto">GtkObservables is designed to simplify the creation of graphical user interfaces (GUIs) using <a href="https://github.com/JuliaGtk/Gtk4.jl">Gtk4</a> and Julia.
GtkObservables descended from
<a href="https://github.com/jverzani/GtkInteract.jl">GtkInteract</a>, and mimics
aspects of the design of
<a href="https://github.com/JuliaGizmos/Interact.jl">Interact</a>. To learn how
to use this package, please see the documentation:</p>
<p dir="auto"><a href="https://juliagizmos.github.io/GtkObservables.jl/stable" rel="nofollow"><img src="https://camo.githubusercontent.com/31126cd56c42376320c59ea685a7ca65ff3a83d09a66363ed7115f882be1222c/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d737461626c652d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-stable-blue.svg" style="max-width: 100%;"></a>
<a href="https://juliagizmos.github.io/GtkObservables.jl/dev/" rel="nofollow"><img src="https://camo.githubusercontent.com/c21574baf34c81b3651a5274c8b074471bc1e142a9516c0cfa75dea9223d93fe/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6c61746573742d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-latest-blue.svg" style="max-width: 100%;"></a></p>
<p dir="auto">GtkObservables is probably a more future-oriented package than the similar <a href="https://github.com/JuliaGizmos/GtkReactive.jl">GtkReactive</a> upon which this started.</p>
