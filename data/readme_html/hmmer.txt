<p dir="auto">A thin Julia wrapper of <a href="http://hmmer.org" rel="nofollow">hmmer</a>. Functions have the same name as the HMMER programs (and Easel miniapps). Keyword arguments are named consistently with the command line arguments of the respective programs. The package creates temporary files for output and returns the path.</p>
