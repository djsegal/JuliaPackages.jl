<p dir="auto">Additional algorithms for the <code>SimplePoset</code> type. Relies on
<code>SimpleGraphAlgorithms</code>. See that module for more information.</p>
<p dir="auto"><strong>Note</strong>: Calculations are done via an integer linear program and
there can be quite slow.</p>

<ul dir="auto">
<li>
<p dir="auto"><code>max_chain(P)</code> returns a maximum size chain of the <code>SimplePoset</code>.</p>
</li>
<li>
<p dir="auto"><code>max_antichain(P)</code> returns a maximum size antichain of the
<code>SimplePoset</code></p>
</li>
<li>
<p dir="auto"><code>width(P)</code> returns the size of a largest antichain in the
<code>SimplePoset</code>. [<strong>Note</strong>: The function <code>height</code> (which gives the size
of a largest chain) is already defined in the <code>SimplePosets</code> module
and does not rely on integer linear programming.]</p>
</li>
<li>
<p dir="auto"><code>realizer(P,d)</code> returns a realizer of <code>P</code> with <code>d</code> linear extensions,
or throws an error if none exists. This is returned as a matrix with
<code>d</code> columns.</p>
</li>
<li>
<p dir="auto"><code>realize_poset(R)</code> creates a poset from a realizer. Here <code>R</code> is a
matrix whose columns are the linear orders of the realizer.</p>
</li>
<li>
<p dir="auto"><code>dimension(P)</code> returns the minimum size of a realizer. Use
<code>dimension(P,true)</code> for verbose reporting.</p>
</li>
</ul>
