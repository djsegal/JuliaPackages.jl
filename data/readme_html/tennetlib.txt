<p dir="auto">TenNetLib.jl features widely-used Tensor Network (TN) codes, designed with a <strong>multi-layered abstraction</strong>
to cater to diverse user needs. The library provides users with varying levels of control over their computations.
Currently, TenNetLib.jl presents an array of functionalities for:</p>
<ul dir="auto">
<li><em>(a)</em> <strong>Finite-size Matrix-Product States (MPS)</strong>: Different variants of Density Matrix Renormalization Group (DMRG) and Time Dependent Variational Principle (TDVP) (including subspace expansion) methods.</li>
<li><em>(b)</em> <strong>Tree Tensor Network (TTN)</strong>: Variational search for the ground state and first few excited states.</li>
</ul>

<p dir="auto">Here is a list for future additions in the decreasing order of priority. Any help / suggestion is welcome.</p>
<ul dir="auto">
<li><strong>Augmented Tree Tensor Network (aTTN)</strong> for variational ground state search for 2D problems.</li>
<li><strong>Infinite DMRG (iDMRG)</strong> and/or <strong>Variational Uniform Matrix Product States (VUMPS)</strong> to tackle 1D / quasi-1D problems directly at the thermodynamic limit.</li>
<li><strong>Projected Entangled Pair States (PEPS)</strong> for 2D problems.</li>
<li>Real-time evolution method using PEPS and TTN.</li>
</ul>
<p dir="auto">Also, please feel free to ask about a new feature by adding a new request to the
<a href="https://github.com/titaschanda/TenNetLib.jl/issues">GitHub issue tracker</a> labelled
<code>feature request</code>. Note that submitting a pull request, providing the needed changes to
introduced your requested feature, will speed up the process.</p>
