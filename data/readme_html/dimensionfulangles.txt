<p dir="auto">Extends <a href="https://painterqubits.github.io/Unitful.jl/" rel="nofollow">Unitful.jl</a> to include <em>angle</em> as a dimension and allow <a href="https://docs.julialang.org/en/v1/manual/methods/" rel="nofollow">dispatching</a> on <em>angles</em>.</p>

<p dir="auto">Use <em>DimensionfulAngles.jl</em> for units containing angles and <em>Unitful.jl</em> for all other units.
The units in <em>DimensionfulAngles.jl</em> are differentiated from their dimensionless counterparts with a superscript <code>ᵃ</code>.
Simply add this superscript to any angle units to make it dimensionful.
In Julia environments this can be typed as <code>\^a&lt;tab&gt;</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Unitful

julia&gt; using DimensionfulAngles

julia&gt; dimensionless_angle = 1u&quot;rad&quot;

1 rad

julia&gt; dimensionful_angle = 1u&quot;radᵃ&quot;
1 rad

julia&gt; typeof(dimensionless_angle)
Quantity{Int64, NoDims, Unitful.FreeUnits{(rad,), NoDims, nothing}}

julia&gt; typeof(dimensionful_angle)
Quantity{Int64, 𝐀, Unitful.FreeUnits{(rad,), 𝐀, nothing}}"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Unitful

<p dir="auto">When defining quantities with units from <em>DimensionfulAngles.jl</em> you can use the <code>ua</code> string instead and omit the superscript <code>ᵃ</code>.
But when defining quantities with units from both it is more convenient to use the <code>u</code> string.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; dimensionful_angle = 1ua&quot;rad&quot;

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Converting to/from <code>Unitful.jl</code></h3><a id="user-content-converting-tofrom-unitfuljl" class="anchor" aria-label="Permalink: Converting to/from Unitful.jl" href="#converting-tofrom-unitfuljl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To convert a quantity to or from <code>Unitful.jl</code> use the <code>uconvert</code> function with first
argument either <code>:Unitful</code> or <code>:DimensionfulAngles</code>.
For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Unitful, DimensionfulAngles

julia&gt; ω = 3.2u&quot;radᵃ/s&quot;
3.2 rad s⁻¹

julia&gt; ω̄ = uconvert(:Unitful, ω)
3.2 rad s⁻¹

julia&gt; dimension(ω)
𝐀 𝐓⁻¹

julia&gt; dimension(ω̄)
𝐓⁻¹"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Unitful, DimensionfulAngles
