<p dir="auto">A hackable, single-file, 320-line Julia package for command-line argument parsing. <code>SimpleArgParse</code> offers 95% of the functionality of  <code>ArgParse</code> using ~10% of the lines-of-code (LOC).</p>
<p dir="auto">Does this need to be more complicated?</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Motivation</h2><a id="user-content-motivation" class="anchor" aria-label="Permalink: Motivation" href="#motivation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Parsing command-line arguments should not be complicated. Metaprogramming features such as macros and generators, while cool, are overkill. I wanted a simple command-line argument parsing library in the spirit of Python's <a href="https://docs.python.org/3/library/argparse.html" rel="nofollow"><code>argparse</code></a>, but could not find one. The closest thing I found was <a href="https://www.juliapackages.com/p/argparse" rel="nofollow"><code>ArgParse</code></a>, but I desired something even simpler. There's nothing worse than having to security audit a massive package for a simple task.</p>
<p dir="auto">Here it is, a single, simple, 320-line file with one dependency (<code>OrderedCollections::OrderedDict</code>), a single nested data structure, and a few methods. Hack on it, build on it, and use it for your own projects. You can read all of the source code in around one minute.</p>
<p dir="auto">Enjoy! 😎</p>

<p dir="auto">We approximate the <a href="https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/command-line-syntax-key" rel="nofollow">Microsoft command-line syntax</a>. <p dir="auto">That is about as simple as it gets and closely follows Python's <a href="https://docs.python.org/3/library/argparse.html" rel="nofollow"><code>argparse</code></a>. You will notice that we instead make extensive use of the visitor pattern, rather than member methods, to modify the state of the <code>ArgumentParser</code> object instance. That is because the Julia language (rather shockingly) does not support member methods. In other words, Julia does not fully support the object-oriented paradigm, but is more functional and data-oriented in design. In some ways, that is a good thing.</p>
