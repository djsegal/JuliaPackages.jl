<p dir="auto">To run this function, the <code>telnet</code> command line utility should be locally installed and
enabled.</p>
<p dir="auto"><code>HORIZONS.jl</code> also has Julia functions for some of the scripts authored by
Jon D. Giorgini for automated generation of small-body binary SPK files and tables.
These scripts were originally written in <code>expect</code>, and can be found at the
JPL's Solar System Dynamics group ftp server <code>ftp://ssd.jpl.nasa.gov/pub/ssd/SCRIPTS/</code>.
Below, we describe these functions <code>smb_spk</code>, <code>smb_spk_ele</code>, and <code>vec_tbl</code>, as
well as the <em>observer table</em> function <code>obs_tbl</code> and the <em>osculating orbital
elements table</em> function <code>ooe_tbl</code>.</p>
