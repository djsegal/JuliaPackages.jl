<p dir="auto">PyMBAR.jl is a Julia package that functions as a lightweight wrapper for the Python <a href="https://pymbar.readthedocs.io/en/master/" rel="nofollow">pymbar package</a>, facilitating the calculation of free energy differences. Leveraging <a href="https://github.com/JuliaPy/PyCall.jl">PyCall.jl</a> to call Python packages, it aims to be a drop-in replacement, making it simpler to add pymbar as a dependency in your Julia projects.</p>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;PyMBAR&quot;)"><pre><span class="pl-k">using</span> Pkg

<p dir="auto">Note that this requires that PyCall be able to install pymbar in the python environment. It will automatically be installed if PyCall is configured to use a conda environment. Otherwise, you will need to install pymbar in whatever python environment PyCall is configured to use.</p>

<p dir="auto">In this example, we generate dummy data and compute the statistical inefficiency.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PyMBAR, Random, Distributions

timeseries = PyMBAR.pymbar.timeseries

function dummy_data()
    N = 10000
    K = 1
    var = ones(N)

    for replica = 2:K
        var = vcat(var, ones(N))
    end

    X = reshape(rand(Normal(0.0, 1.0), K * N) .* var / 10.0, (K, N))
    Y = reshape(rand(Normal(0.0, 1.0), K * N) .* var, (K, N))

    energy = 10 * (X .^ 2) / 2.0 .+ (Y .^ 2) / 2.0

    return X, Y, energy
end
