<p dir="auto">WebP.jl is a Julia library for handling <a href="https://developers.google.com/speed/webp" rel="nofollow">WebP</a> images. WebP provides both lossy and lossless compression of images, and may offer smaller file sizes compared to JPEG and PNG.</p>
<p dir="auto">The core functionality of this package is supported by the <a href="https://developers.google.com/speed/webp/docs/api" rel="nofollow">libwebp</a> C library.</p>

<p dir="auto">This package provides functions for reading and writing WebP image files,</p>
<ul dir="auto">
<li><code>WebP.read_webp</code></li>
<li><code>WebP.write_webp</code></li>
</ul>
<p dir="auto">as well as functions for decoding and encoding WebP image data,</p>
<ul dir="auto">
<li><code>WebP.decode</code></li>
<li><code>WebP.encode</code></li>
</ul>
