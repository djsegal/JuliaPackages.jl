<p dir="auto">Create and maintain local registries for Julia packages. This package
is intended to provide a simple workflow for maintaining local
registries (private or public) without making any assumptions about
how the registry or the packages are hosted.</p>
<p dir="auto">For registration in the General registry, see
<a href="https://github.com/JuliaComputing/Registrator.jl">Registrator</a>.</p>
<p dir="auto">For serving local packages through a <a href="https://github.com/JuliaLang/Pkg.jl/issues/1377" data-hovercard-type="issue" data-hovercard-url="/JuliaLang/Pkg.jl/issues/1377/hovercard">Package
Server</a> see the
companion package
<a href="https://github.com/GunnarFarneback/LocalPackageServer.jl">LocalPackageServer</a>.</p>

<p dir="auto">This package requires Julia 1.6 or later. Older versions of the
package work back to Julia 1.1.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Create Registry</h2><a id="user-content-create-registry" class="anchor" aria-label="Permalink: Create Registry" href="#create-registry"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The recommended way to create a registry is</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using LocalRegistry
create_registry(name, repository_url; description = &quot;My private registry&quot;, push = true)"><pre class="notranslate"><code>using LocalRegistry
create_registry(name, repository_url; description = "My private registry", push = true)
</code></pre></div>
<p dir="auto">where <code>name</code> is the name of your registry and <code>repository_url</code> points
to an <em>empty</em> upstream repository where you will host your registry.</p>
<p dir="auto">There are a number of options to customize this. Read more about that
and further explanations in the <a href="docs/create_registry.md">detailed
instructions</a>.</p>

<p dir="auto">To activate the registry, do</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Pkg
pkg&quot;registry add &lt;repository url&gt;&quot;"><pre class="notranslate"><code>using Pkg

</code></pre></div>
<p dir="auto">This only needs to be done once per Julia installation.
<a href="docs/troubleshooting_general.md">Troubleshooting advice</a> if you
cannot find packages from the General registry.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Register a Package or a New Version of a Package</h2><a id="user-content-register-a-package-or-a-new-version-of-a-package" class="anchor" aria-label="Permalink: Register a Package or a New Version of a Package" href="#register-a-package-or-a-new-version-of-a-package"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The recommended way to register a package or a new version of a
package is simply:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using LocalRegistry
register()"><pre class="notranslate"><code>using LocalRegistry
register()
</code></pre></div>
<p dir="auto">For this to work you need to either have the package in your current
directory or have the package activated.</p>
<p dir="auto">Actually there are some more requirements but those are usually
satisfied. Read more about that, a number of options to customize the
call, and some additional features in the <a href="docs/register.md">detailed
instructions</a>.</p>
