<p dir="auto"><a href="https://github.com/jump-dev/Xpress.jl">Xpress.jl</a> is a wrapper for the <a href="https://www.fico.com/products/fico-xpress-solver" rel="nofollow">FICO Xpress Solver</a>.</p>
<p dir="auto">It has two components:</p>
<ul dir="auto">
<li>a thin wrapper around the complete C API</li>
<li>an interface to <a href="https://github.com/jump-dev/MathOptInterface.jl">MathOptInterface</a></li>
</ul>

<p dir="auto">First, obtain a license of Xpress and install Xpress solver, following the
<a href="https://www.fico.com/products/fico-xpress-solver" rel="nofollow">instructions on the FICO website</a>.
Ensure that the <code>XPRESSDIR</code> license variable is set to the install location by
checking the output of:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ENV[&quot;XPRESSDIR&quot;]"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">ENV</span>[<span class="pl-s"><span class="pl-pds">"</span>XPRESSDIR<span class="pl-pds">"</span></span>]</pre></div>
<p dir="auto">Then, install this package using:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg
Pkg.add(&quot;Xpress&quot;)"><pre><span class="pl-k">import</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Xpress<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">If you encounter an error, make sure that the <code>XPRESSDIR</code> environmental variable
is set to the path of the Xpress directory. This should be part of a standard
installation. The Xpress library will be searched for in <code>XPRESSDIR/lib</code> on Unix
platforms and <code>XPRESSDIR/bin</code> on Windows.</p>
<p dir="auto">For example, on macOS, you may need:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ENV[&quot;XPRESSDIR&quot;] = &quot;/Applications/FICO Xpress/xpressmp/&quot;

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Skipping installation</h3><a id="user-content-skipping-installation" class="anchor" aria-label="Permalink: Skipping installation" href="#skipping-installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">By default, building Xpress.jl will fail if the Xpress library is not found.</p>
<p dir="auto">This may not be desirable in certain cases, for example when part of a package's
test suite uses Xpress as an optional test dependency, but Xpress cannot be
installed on a CI server running the test suite.</p>
<p dir="auto">To skip the error, set the <code>XPRESS_JL_SKIP_LIB_CHECK</code> environment variable to
<code>true</code> to make Xpress.jl installable (but not usable).</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ENV[&quot;XPRESS_JL_SKIP_LIB_CHECK&quot;] = true

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Options</h2><a id="user-content-options" class="anchor" aria-label="Permalink: Options" href="#options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For other parameters see the <a href="https://www.fico.com/fico-xpress-optimization/docs/latest/solver/optimizer/HTML/" rel="nofollow">Xpress Optimizer manual</a>.</p>
<p dir="auto">If <code>logfile</code> is set to <code>""</code>, the log file is disabled and output is printed to
the console (<a href="https://www.fico.com/fico-xpress-optimization/docs/latest/solver/optimizer/HTML/OUTPUTLOG.html" rel="nofollow">there might be issues with console output on windows (it is manually implemented with callbacks)</a>).</p>
<p dir="auto">If <code>logfile</code> is set to a file's path, output is printed to that file. By
default, <code>logfile = ""</code> (console).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Custom options</h3><a id="user-content-custom-options" class="anchor" aria-label="Permalink: Custom options" href="#custom-options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>MOI_POST_SOLVE::Bool</code>: set this attribute to <code>false</code> to skip <code>XPRSpostsolve</code>.
This is most useful in older versions of Xpress that throw an error if the
model is infeasible.</li>
<li><code>MOI_IGNORE_START::Bool</code>: set this attribute to <code>true</code> to skip setting
<code>MOI.VariablePrimalStart</code></li>
<li><code>MOI_WARNINGS::Bool</code>: set this attribute to <code>false</code> to turn off the various
warnings printed by the MathOptInterface wrapper</li>
<li><code>MOI_SOLVE_MODE::String</code>: set the <code>flags</code> argument to
<a href="https://www.fico.com/fico-xpress-optimization/docs/latest/solver/optimizer/R/HTML/lpoptimize.html" rel="nofollow"><code>lpoptimize</code></a></li>
<li><code>XPRESS_WARNING_WINDOWS::Bool</code>: set this attribute to <code>false</code> to turn of
warnings on Windows.</li>

@variable(model, 0 &lt;= x &lt;= 2.5, Int)
@variable(model, 0 &lt;= y &lt;= 2.5, Int)

function my_callback_function(cb_data)
    prob = cb_data.model
    p_value = Ref{Cint}(0)
    ret = Xpress.Lib.XPRSgetintattrib(prob, Xpress.Lib.XPRS_MIPINFEAS, p_value)
    if p_value[] &gt; 0
        return  # There are integer infeasibilities. The solution is fractional.
    end
    p_obj, p_bound = Ref{Cdouble}(), Ref{Cdouble}()
    Xpress.Lib.XPRSgetdblattrib(prob, Xpress.Lib.XPRS_MIPBESTOBJVAL, p_obj)
    Xpress.Lib.XPRSgetdblattrib(prob, Xpress.Lib.XPRS_BESTBOUND, p_bound)
    rel_gap = abs((p_obj[] - p_bound[]) / p_obj[])
    @info &quot;Relative gap = $rel_gap&quot;
    # Before querying `callback_value`, you must call:
    Xpress.get_cb_solution(unsafe_backend(model), cb_data.model)
    x_val = callback_value(cb_data, x)
    y_val = callback_value(cb_data, y)
    # You can submit solver-independent MathOptInterface attributes such as
    # lazy constraints, user-cuts, and heuristic solutions.
    if y_val - x_val &gt; 1 + 1e-6
        con = @build_constraint(y - x &lt;= 1)
        MOI.submit(model, MOI.LazyConstraint(cb_data), con)
    elseif y_val + x_val &gt; 3 + 1e-6
        con = @build_constraint(y + x &lt;= 3)
        MOI.submit(model, MOI.LazyConstraint(cb_data), con)
    end
    if rand() &lt; 0.1
        # You can terminate the callback as follows:
        Xpress.Lib.XPRSinterrupt(cb_data.model, 1234)
    end
    return
end
