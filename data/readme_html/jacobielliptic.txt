<p dir="auto">JacobiElliptic is an implementation of Toshio Fukushima's &amp; Billie C. Carlson's for calculating <a href="https://ieeexplore.ieee.org/document/7203795" rel="nofollow">Elliptic Integrals and Jacobi Elliptic Functions</a>.
The default algorithms are set to the Carlson algorithms.</p>
