<p dir="auto">A Julia package for simulating quantum states of photon wavepackets using a discrete-time formalism <a href="https://journals.aps.org/pra/abstract/10.1103/PhysRevA.101.042322" rel="nofollow">Phys. Rev. A 101, 042322</a>. The package works as an extension to <a href="https://qojulia.org/" rel="nofollow">QuantumOptics.jl</a> where bases and operators from WaveguideQED.jl can be used together with operators and bases from QuantumOpics.jl.</p>

<p dir="auto">Define a waveguide basis, containing a two-photon wavepacket for a time interval from 0 to 20 with timesteps of 0.2:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using WaveguideQED
times = 0:0.1:10
bw =  WaveguideBasis(2,times)"><pre><span class="pl-k">using</span> WaveguideQED
times <span class="pl-k">=</span> <span class="pl-c1">0</span><span class="pl-k">:</span><span class="pl-c1">0.1</span><span class="pl-k">:</span><span class="pl-c1">10</span>
bw <span class="pl-k">=</span>  <span class="pl-c1">WaveguideBasis</span>(<span class="pl-c1">2</span>,times)</pre></div>
<p dir="auto">Define waveguide creation and annihilation operators from this basis:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="w = destroy(bw)
wd = create(bw)"><pre>w <span class="pl-k">=</span> <span class="pl-c1">destroy</span>(bw)
wd <span class="pl-k">=</span> <span class="pl-c1">create</span>(bw)</pre></div>
<p dir="auto">Combine with QuantumOptics.jl operators:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using QuantumOptics
bc = FockBasis(2)
a = destroy(bc)
ad = create(bc)
wda = a ⊗ wd
adw = ad ⊗ w"><pre><span class="pl-k">using</span> QuantumOptics
bc <span class="pl-k">=</span> <span class="pl-c1">FockBasis</span>(<span class="pl-c1">2</span>)
a <span class="pl-k">=</span> <span class="pl-c1">destroy</span>(bc)
ad <span class="pl-k">=</span> <span class="pl-c1">create</span>(bc)
wda <span class="pl-k">=</span> a <span class="pl-k">⊗</span> wd
adw <span class="pl-k">=</span> ad <span class="pl-k">⊗</span> w</pre></div>
<p dir="auto">Finally, we can define an initial two-photon Gaussian wavepacket state with view_twophoton and zero photons in the cavity, a Hamiltonian, and simulate the evolution:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ξfun(t1,t2,σ1,σ2,t0) = sqrt(2/σ1) * (log(2)/pi)^(1/4)*exp(-2*log(2)*(t1-t0)^2/σ1^2)*sqrt(2/σ2)*(log(2)/pi)^(1/4)*exp(-2*log(2)*(t2-t0)^2/σ2^2)
ψ_cw = twophoton(bw,ξfun,1,1,5)
psi = fockstate(bc,0) ⊗ ψ_cw
dt = times[2] - times[1]
H = im*sqrt(1/dt)*(adw-wda)
ψ = waveguide_evolution(times, psi, H)"><pre><span class="pl-en">ξfun</span>(t1,t2,σ1,σ2,t0) <span class="pl-k">=</span> <span class="pl-c1">sqrt</span>(<span class="pl-c1">2</span><span class="pl-k">/</span>σ1) <span class="pl-k">*</span> (<span class="pl-c1">log</span>(<span class="pl-c1">2</span>)<span class="pl-k">/</span><span class="pl-c1">pi</span>)<span class="pl-k">^</span>(<span class="pl-c1">1</span><span class="pl-k">/</span><span class="pl-c1">4</span>)<span class="pl-k">*</span><span class="pl-c1">exp</span>(<span class="pl-k">-</span><span class="pl-c1">2</span><span class="pl-k">*</span><span class="pl-c1">log</span>(<span class="pl-c1">2</span>)<span class="pl-k">*</span>(t1<span class="pl-k">-</span>t0)<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>σ1<span class="pl-k">^</span><span class="pl-c1">2</span>)<span class="pl-k">*</span><span class="pl-c1">sqrt</span>(<span class="pl-c1">2</span><span class="pl-k">/</span>σ2)<span class="pl-k">*</span>(<span class="pl-c1">log</span>(<span class="pl-c1">2</span>)<span class="pl-k">/</span><span class="pl-c1">pi</span>)<span class="pl-k">^</span>(<span class="pl-c1">1</span><span class="pl-k">/</span><span class="pl-c1">4</span>)<span class="pl-k">*</span><span class="pl-c1">exp</span>(<span class="pl-k">-</span><span class="pl-c1">2</span><span class="pl-k">*</span><span class="pl-c1">log</span>(<span class="pl-c1">2</span>)<span class="pl-k">*</span>(t2<span class="pl-k">-</span>t0)<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>σ2<span class="pl-k">^</span><span class="pl-c1">2</span>)
ψ_cw <span class="pl-k">=</span> <span class="pl-c1">twophoton</span>(bw,ξfun,<span class="pl-c1">1</span>,<span class="pl-c1">1</span>,<span class="pl-c1">5</span>)
psi <span class="pl-k">=</span> <span class="pl-c1">fockstate</span>(bc,<span class="pl-c1">0</span>) <span class="pl-k">⊗</span> ψ_cw

H <span class="pl-k">=</span> im<span class="pl-k">*</span><span class="pl-c1">sqrt</span>(<span class="pl-c1">1</span><span class="pl-k">/</span>dt)<span class="pl-k">*</span>(adw<span class="pl-k">-</span>wda)
ψ <span class="pl-k">=</span> <span class="pl-c1">waveguide_evolution</span>(times, psi, H)</pre></div>
