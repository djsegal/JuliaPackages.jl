<p dir="auto"><strong>SimpleBoids</strong> is a Julia package for simulating the behavior of boids, which are agents that exhibit flocking behavior, inspired by the famous Boids algorithm. This package provides tools to simulate the movement and interaction of boids within a given environment.</p>

<ul dir="auto">
<li><code>numboids</code>: The number of boids in the simulation.</li>
<li><code>steps</code>: The number of simulation steps to run.</li>
<li><code>size</code>: The size of the simulation environment (2D space).</li>
<li><code>vel</code>: The initial velocity of boids.</li>
<li><code>paramMaxRad</code>: The maximum radius for boid interactions.</li>
<li><code>paramMinRad</code>: The minimum radius before boids repel.</li>
<li><code>paramPosWeight</code>: Weight for position-based interactions.</li>
<li><code>paramRepWeight</code>: Weight for repulsion-based interactions.</li>
<li><code>paramVelWeight</code>: Weight for velocity-based interactions.</li>
</ul>
