<p dir="auto">StippleMathjs adds <a href="https://mathjs.org/" rel="nofollow">mathjs</a> to your <a href="https://github.com/GenieFramework/Stipple.jl">Stipple</a> or <a href="https://github.com/GenieFramework/GenieFramework.jl">GenieFramwork</a> project.</p>
<p dir="auto">Furthermore, it adds automatic conversion of all types of <code>Complex</code> numbers between server and client.</p>

using StippleUI
using StippleMathjs


x0 = 1.0
y0 = 2.0

@app begin
    @in x = x0
    @in y = y0
    @in z = x0 + y0 * im
    @in z2::ComplexF64 = x0 + y0 * im

    @onchange x, y begin
        # update z without triggering `@onchange z`
        z[!] = x + y * im

        # update x and y of the client(s)
        @push z
    end

    @onchange z begin
        # update x and y without triggering `@onchange x, y`
        x[!] = z.re
        y[!] = z.im

        # update x and y of the client(s)
        @push x
        @push y
    end
end

@deps StippleMathjs

function ui()
    [
        card(class = &quot;q-pa-md&quot;, [
            numberfield(class = &quot;q-ma-md&quot;, &quot;x&quot;, :x)
            numberfield(class = &quot;q-ma-md&quot;, &quot;y&quot;, :y)
        ])

        card(class = &quot;q-pa-md q-my-md&quot;, [
            row([cell(col = 2, &quot;z&quot;),        cell(&quot;{{ z }}&quot;)])
            row([cell(col = 2, &quot;z.mul(z)&quot;), cell(&quot;{{ z.mul(z) }}&quot;)])
            row([cell(col = 2, &quot;z.abs()&quot;),  cell(&quot;{{ z.abs() }}&quot;)])

            btn(class = &quot;q-my-md&quot;, &quot;square(z)&quot;, color = &quot;primary&quot;, @click(&quot;z = z.mul(z)&quot;))
        ])
    ]
end

<ul dir="auto">
<li>
<p dir="auto">Due to a current bug in Stipple you need to define <code>x0</code> and <code>y0</code> outside the loop in order to guarantee that z is of the correct type.
Alternatively, you could declare <code>z</code> explicitly, e.g. as <code>z::ComplexF64</code></p>
</li>
<li>
<p dir="auto">This package can serve as a good example how to embed other javascript sources into your own project.</p>
