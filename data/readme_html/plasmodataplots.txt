<p dir="auto">PlasmoDataPlots.jl is designed for plotting the <code>DataGraph</code> object. Node positions are saved under the NodeData of the <code>DataGraph</code> object. For these positions to be recognized, they must be called "x_positions" and "y_positions". If the user does not define these, the node positions are determined by NetworkLayout.jl's <code>sfdp</code> function (stands for Scalable Force Directed Placement). Alternatively, when the <code>DataGraph</code> was constructed from a matrix or a tensor, the user can set the node positions using <code>set_matrix_node_positions!</code> or <code>set_tensor_node_positions!</code> functions which take the argument of the <code>DataGraph</code> and the original matrix or tensor.</p>
<p dir="auto">The primary function in PlasmoDataPlots.jl is <code>plot_graph</code>, which takes the following, optional keyword arguments:</p>
<ul dir="auto">
<li><code>get_new_positions::Bool</code>: If true, calculates new positions using NetworkLayout.jl's <code>sfdp</code> function.</li>
<li><code>plot_edges::Bool</code>: If false, only the nodes of the <code>DataGraph</code> will be plotted. The edges take the longest time to plot, so this can reduce the plotting time for graphs with many nodes where the edges are less important to visualize (e.g., large matrices formed as graphs)</li>
<li><code>C</code>, <code>K</code>, <code>iterations</code>, <code>tol</code>: These are arguments used by NetworkLayout.jl's <code>sfdp</code> function for determining node positions.</li>
<li><code>xdim</code>, <code>ydim</code>: Determing the dimensions of the final plot (default is 800 for both)</li>
<li><code>linewidth</code>: Determines the width of the edges</li>
<li><code>linealpha</code>: Determines the alpha value (how transparent the edge is).</li>
<li><code>linecolor</code>: The color used for the edges. When <code>line_z</code> is defined, this should be a color gradient.</li>
<li><code>line_z</code>: The set of data corresponding to edge weights. This should be a vector of length equal to the number of edges. Can be used if the edges should be color coded by weight</li>
<li><code>nodecolor</code>: Color of the node markers. When <code>node_z</code> is defined, this should be a color gradient.</li>
<li><code>nodesize</code>: size of the node markers</li>
<li><code>nodestrokewidth</code>: Width of the border on the node markers</li>
<li><code>nodestrokecolor</code>: Color of the border on the node markers</li>
<li><code>nodestrokealpha</code>: alpha (transparency) of the border on the node markers</li>
<li><code>node_z</code>: Set of data corresponding to node weights. This should be a vector of length equal to the number of nodes. Can be used if the nodes should be color coded by weight</li>
<li><code>framestyle</code>: framestyle of plot</li>
<li><code>rev</code>: Boolean indicating, if node_z or line_z is defined, that the color gradient from node or line color will be reversed</li>
<li><code>legend</code>: Boolean determining whether there should be a colorbar when <code>node_z</code> is defined</li>
<li><code>save_fig</code>: Boolean to determine if the figure should be saved or not</li>
<li><code>fig_name</code>: Name of the file name that the saved figure should have.</li>
</ul>
