<p dir="auto">A little Julia package for visualizing DICOM file metadata in the form of a tree. The main function is the Tree function, which is simply a dispatch of the eponymous function in the <a href="https://github.com/FedeClaudi/Term.jl">Term.jl</a> package to the <code>DICOMData</code> type in the <a href="https://github.com/JuliaHealth/DICOM.jl">DICOM.jl</a> package.
The package have been tested with CT Scanner, RTDose and RTStruct files.</p>

</p>

<ul dir="auto">
<li>
<p dir="auto"><code>with_keys = true</code> will replace the name with the associated tag (e.g. : (0x0010, 0x0020) if true and PatientID if false). Default is false.</p>
</li>
<li>
<p dir="auto"><code>maxdepth</code> defines the depth at which the DICOM tree is explored. Default is 2. Note that a high scan depth may take a few seconds to be displayed.</p>
</li>
</ul>
