<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Custom Subtype</h2><a id="user-content-custom-subtype" class="anchor" aria-label="Permalink: Custom Subtype" href="#custom-subtype"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To create a custom subtype define the following data</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="SubType{T, P, Ctx}
        ^  ^  ^
        |  |  |
        |  |  L ______ Type Context
        |  L _________ Predicate Data
        L ____________ Underlying Type"><pre class="notranslate"><code>SubType{T, P, Ctx}
        ^  ^  ^
        |  |  |
        |  |  L ______ Type Context
        |  L _________ Predicate Data
        L ____________ Underlying Type
</code></pre></div>
<p dir="auto">and a predicate processing function</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="check_predicate(P, Val(Ctx), x::T)"><pre><span class="pl-c1">check_predicate</span>(P, <span class="pl-c1">Val</span>(Ctx), x<span class="pl-k">::</span><span class="pl-c1">T</span>)</pre></div>
<p dir="auto">which checks if <code>x::T</code> should be of type <code>SubType{T, P, Ctx}</code>. The context <code>Ctx</code> is the way to mark the subtypes for overloading.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Predefined Custom Subtypes</h2><a id="user-content-predefined-custom-subtypes" class="anchor" aria-label="Permalink: Predefined Custom Subtypes" href="#predefined-custom-subtypes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The custom subtypes <code>Constrained</code> and <code>ConstrainedSymbol</code> are predefined in the <code>SubType</code> module. They emulate set inclusion subtyping, i.e.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x::Constrained{T, S}  &lt;=&gt;  x.value::T in S"><pre>x<span class="pl-k">::</span><span class="pl-c1">Constrained{T, S}</span>  <span class="pl-k">&lt;=&gt;</span>  x<span class="pl-k">.</span>value<span class="pl-k">::</span><span class="pl-c1">T</span> <span class="pl-k">in</span> S</pre></div>
<p dir="auto">The <code>ConstrainedSymbol</code> type emulates set inclusion for <code>Symbol</code> types. The <code>Constrained</code> type is defined as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const Constrained{T,S} = SubType{T,S,:Constrained}"><pre><span class="pl-k">const</span> Constrained{T,S} <span class="pl-k">=</span> SubType{T,S,<span class="pl-c1">:Constrained</span>}</pre></div>
<p dir="auto">Inspiration for this type comes from <a href="https://discourse.julialang.org/t/creating-custom-type-of-enumerations-of-symbols/18635/7" rel="nofollow">this post</a> by Mohamed Tarek <a href="https://github.com/mohamed82008">@mohamed82008</a>.</p>
