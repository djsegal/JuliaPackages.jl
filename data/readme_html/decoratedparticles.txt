<p dir="auto">This is a small package, spun out of <a href="https://github.com/ACEsuit/ACE.jl"><code>ACE.jl</code></a>. The original intended use case is managing (lists of) decorated particles, i.e., point clouds embedded in some vector space, where each point is decorated with additional features such as chemical species, charge, mass, etc. Documentation for now is this readme.</p>

<p dir="auto">Both AosSystem and SoaSystem are fully flexible regarding the
properties of the particles. Both DecoratedParticles implementations
have the same performance as <code>FastSystem</code> but both are fully flexibly
regarding the types of particles.</p>
