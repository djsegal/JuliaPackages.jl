<p dir="auto"><a href="https://github.com/JuliaDocs/DocumenterCitations.jl#readme">DocumenterCitations.jl</a> uses <a href="https://github.com/Humans-of-Julia/Bibliography.jl">Bibliography.jl</a> to add support for BibTeX citations in documentation pages generated by <a href="https://github.com/JuliaDocs/Documenter.jl">Documenter.jl</a>.</p>
<p dir="auto">By default, <a href="https://github.com/JuliaDocs/DocumenterCitations.jl#readme">DocumenterCitations.jl</a> uses a numeric citation style common in the natural sciences, see e.g. the <a href="https://journals.aps.org" rel="nofollow">journals of the American Physical Society</a>, and the <a href="https://www.ctan.org/tex-archive/macros/latex/contrib/revtex/auguide" rel="nofollow">REVTeX author's guide</a>.  Citations are shown in-line, as a number enclosed in square brackets, e.g., "Optimal control is a cornerstone in the development of quantum technologies [<a href="#screenshot">1</a>]."</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/assets/references.png"><img id="user-content-screenshot" src="docs/src/assets/references.png" alt="Rendered bibliography of two references, [1] and [2]" width="830px" style="max-width: 100%;"></a></p>
<p dir="auto">Alternatively, author-year and alphabetic citations styles are available, see the <a href="https://juliadocs.github.io/DocumenterCitations.jl/dev/gallery/" rel="nofollow">Citation Style Gallery</a>. Prior to version 1.0, the author-year style was the default, see <a href="NEWS.md">NEWS.md</a>. It is possible to define custom styles.</p>

<p dir="auto">The <code>DocumenterCitations</code> package can be installed with <a href="https://pkgdocs.julialang.org/v1/" rel="nofollow">Pkg</a> as</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add DocumenterCitations"><pre class="notranslate"><code>pkg&gt; add DocumenterCitations
</code></pre></div>
<p dir="auto">In most cases, you will just want to have <code>DocumenterCitations</code> in the project that builds your documentation (e.g. <a href="https://github.com/JuliaDocs/DocumenterCitations.jl/blob/master/test/Project.toml"><code>test/Project.toml</code></a>). Thus, you can also simply add</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="DocumenterCitations = &quot;daee34ce-89f3-4625-b898-19384cb65244&quot;"><pre class="notranslate"><code>DocumenterCitations = "daee34ce-89f3-4625-b898-19384cb65244"
</code></pre></div>
<p dir="auto">to the <code>[deps]</code> section of the relevant <code>Project.toml</code> file.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Place a BibTeX <a href="https://github.com/JuliaDocs/DocumenterCitations.jl/blob/master/docs/src/refs.bib"><code>refs.bib</code></a> file in the <code>docs/src</code> folder of your project.  Then, in <a href="https://github.com/JuliaDocs/DocumenterCitations.jl/blob/master/docs/make.jl"><code>docs/make.jl</code></a>, instantiate the <code>CitationBibliography</code> plugin with the path to the <code>.bib</code> file. Assuming <code>Documenter &gt;= 1.0</code>, pass the plugin object to <a href="https://documenter.juliadocs.org/stable/lib/public/#Documenter.makedocs" rel="nofollow"><code>makedocs</code></a> as element of the <code>plugins</code> keyword argument:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DocumenterCitations

bib = CitationBibliography(joinpath(@__DIR__, &quot;src&quot;, &quot;refs.bib&quot;))
makedocs(; plugins=[bib], ...)"><pre><span class="pl-k">using</span> DocumenterCitations

bib <span class="pl-k">=</span> <span class="pl-c1">CitationBibliography</span>(<span class="pl-c1">joinpath</span>(<span class="pl-c1">@__DIR__</span>, <span class="pl-s"><span class="pl-pds">"</span>src<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>refs.bib<span class="pl-pds">"</span></span>))
<span class="pl-c1">makedocs</span>(; plugins<span class="pl-k">=</span>[bib], <span class="pl-k">...</span>)</pre></div>
<p dir="auto">In older versions of <a href="https://github.com/JuliaDocs/Documenter.jl">Documenter.jl</a>, <code>bib</code> had to be passed as a positional argument to <code>makedocs</code>.</p>
</li>
<li>
<p dir="auto">Optional, but recommended: <a href="https://juliadocs.github.io/DocumenterCitations.jl/dev/styling/" rel="nofollow">add CSS to properly format the bibliography</a></p>
</li>
<li>
<p dir="auto">Somewhere in your documentation include a markdown block</p>
<div class="highlight highlight-text-md notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="```@bibliography
```"><pre><span class="pl-s">```</span><span class="pl-en">@bibliography</span><span class="pl-c1"></span>
<span class="pl-c1"></span><span class="pl-s">```</span></pre></div>
<p dir="auto">that will expand into a bibliography for all citations in the documentation.</p>
</li>
<li>
<p dir="auto">Anywhere in the documentation or in docstrings, insert citations as, e.g., <code>[GoerzQ2022](@cite)</code>, which will be rendered as "[<a href="#screenshot">2</a>]" and link to the full reference in the bibliography.</p>
</li>
</ul>
<p dir="auto">See the <a href="https://juliadocs.github.io/DocumenterCitations.jl" rel="nofollow">documentation</a> for additional information.</p>
