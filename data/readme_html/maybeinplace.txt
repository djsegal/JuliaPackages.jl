<p dir="auto">MaybeInplace.jl does a simple thing: If you write a code for mutable arrays, that won't work for immutable arrays. This package provides a macro <code>@bb</code> or <code>@bangbang</code> that will automatically convert the code to make it work for immutable arrays as well.</p>

<p dir="auto">The code is simple enough to be self-explanatory. The basic idea is as follows, if you have the following code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@bb @. x = y + z"><pre><span class="pl-c1">@bb</span> <span class="pl-c1">@.</span> x <span class="pl-k">=</span> y <span class="pl-k">+</span> z</pre></div>
<p dir="auto">This macro will convert it to:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="if setindex_trait(x) === CanSetindex()
    @. x = y + z
else
    x = @. y + z
end"><pre><span class="pl-k">if</span> <span class="pl-c1">setindex_trait</span>(x) <span class="pl-k">===</span> <span class="pl-c1">CanSetindex</span>()
    <span class="pl-c1">@.</span> x <span class="pl-k">=</span> y <span class="pl-k">+</span> z
<span class="pl-k">else</span>
    x <span class="pl-k">=</span> <span class="pl-c1">@.</span> y <span class="pl-k">+</span> z
<span class="pl-k">end</span></pre></div>
