<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is JulGame?</h2><a id="user-content-what-is-julgame" class="anchor" aria-label="Permalink: What is JulGame?" href="#what-is-julgame"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">JulGame is an open-source game engine meant for creating 2D games (and 3d games... eventually) using the <a href="https://julialang.org/" rel="nofollow">Julia programming language</a>. JulGame uses <a href="https://github.com/JuliaMultimedia/SimpleDirectMediaLayer.jl/">SDL2</a>, and <a href="https://github.com/Gnimuc/CImGui.jl">CImGui</a> for the editor. The plan for 3d will be to use OpenGL.</p>

<p dir="auto">Because I find Julia interesting and I've always wanted to create a game engine. I would like to see a game dev scene around it as there isn't much of one now. I am not a Julia programmer (nor an experienced game engine creator), so I am sure there is a lot I am doing wrong. If you see anything that I can fix, please just let me know with a discussion or an issue.</p>

<p dir="auto">I thought that JulGame would be a great play on Pygame. I also think it just rolls off the tongue. Also, I recently found out that "Jul" is the etymological root of “<a href="https://en.m.wiktionary.org/wiki/j%C3%B3l#Icelandic" rel="nofollow">jolly</a>”, so it makes for a great pun :)</p>
