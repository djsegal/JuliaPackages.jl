<p dir="auto">This package aims at providing a fully-fledged finite-element toolbox in pure Julia, with support for different computing systems from laptops to supercomputers and GPUs.</p>
<p dir="auto">NB. This package is work in progress; a proof-of-concept API is already available (for CPUs). The package is not production ready at this point. Planned performance and documentation improvements are needed.</p>

<p dir="auto">This package follows a new approach to implement finite-element methods based on the lessons learned in the <a href="https://github.com/gridap/Gridap.jl">Gridap</a> project.</p>

<p dir="auto">This code solves the same boundary value problem, but using an auxiliary field of Lagrange
multipliers to impose Dirichlet boundary conditions.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import GalerkinToolkit as GT
import ForwardDiff
using LinearAlgebra
mesh = GT.mesh_from_gmsh(&quot;assets/demo.msh&quot;)
GT.label_boundary_faces!(mesh;physical_name=&quot;boundary&quot;)
Ω = GT.interior(mesh)
Γd = GT.boundary(mesh;physical_names=[&quot;boundary&quot;])
k = 2
V = GT.lagrange_space(Ω,k)
Q = GT.lagrange_space(Γd,k-1; conformity=:L2)
VxQ = V × Q
dΓd = GT.measure(Γd,2*k)
gradient(u) = x-&gt;ForwardDiff.gradient(u,x)
∇(u,x) = GT.call(gradient,u)(x)
a((u,p),(v,q)) =
    GT.∫( x-&gt;∇(u,x)⋅∇(v,x), dΩ) +
    GT.∫(x-&gt;
        (u(x)+p(x))*(v(x)+q(x))
        -u(x)*v(x)-p(x)*q(x), dΓd)
l((v,q)) = GT.∫(x-&gt;u(x)*q(x), dΓd)
x,A,b = GT.linear_problem(Float64,VxQ,a,l)
x .= A\b
uh,qh = GT.solution_field(VxQ,x)
GT.vtk_plot(&quot;results&quot;,Ω) do plt
    GT.plot!(plt,u;label=&quot;u&quot;)
    GT.plot!(plt,uh;label=&quot;uh&quot;)
end"><pre><span class="pl-k">import</span> GalerkinToolkit as GT
