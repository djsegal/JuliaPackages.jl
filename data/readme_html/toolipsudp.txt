<p dir="auto"><code>ToolipsUDP</code> provides high-level <a href="https://github.com/ChifiSource/Toolips.jl">toolips</a>-style functionality to UDP networking projects. This functionality is facilitated via the <code>UDPServer</code> and <code>UDPConnection</code> types.</p>
<div class="markdown-heading" dir="auto"><h6 class="heading-element" dir="auto">creating a UDP server</h6><a id="user-content-creating-a-udp-server" class="anchor" aria-label="Permalink: creating a UDP server" href="#creating-a-udp-server"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Whereas a <code>Toolips</code> <code>WebServer</code> typically comes with a router, the <code>UDPServer</code> takes a <code>Function</code> directly and provides this function with a <code>UDPConnection</code>. To create a UDP server, we provide a connection handler function. Use the UDPServer constructor with a <code>do</code> block to specify the behavior when a connection is received. Here's an example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ToolipsUDP

# Define a connection handler function
function my_connection_handler(c::UDPConnection)
    println(&quot;Received packet: &quot;, c.packet)
    println(&quot;From IP: &quot;, c.ip)
    println(&quot;On port: &quot;, c.port)
end

# Create and start a UDPServer with the connection handler using do block
UDPServer(&quot;127.0.0.1&quot;, 2000) do c::UDPConnection
    my_connection_handler(c)
end"><pre><span class="pl-k">using</span> ToolipsUDP

<p dir="auto">A <code>UDPServer</code> may also be constructed without a handler <code>Function</code>, and this might be ideal for sending data.</p>
<div class="markdown-heading" dir="auto"><h6 class="heading-element" dir="auto">sending data</h6><a id="user-content-sending-data" class="anchor" aria-label="Permalink: sending data" href="#sending-data"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">ToolipsUDP provides convenient functions for sending data to UDP servers. Packets may be sent from</p>
<ul dir="auto">
<li>A <code>UDPServer</code></li>
<li>A <code>UDPConnection</code></li>
<li>or just sent once with a quick socket binding.</li>
</ul>
<p dir="auto">The dispatches for these are:</p>
<ul dir="auto">
<li><code>send(c::UDPServer, data::String, to::String = "127.0.0.1", port::Int64 = 2000)</code></li>
<li><code>send(c::UDPConnection, data::String, to::String = "127.0.0.1", port::Int64 = 2000)</code></li>
<li>and <code>send(data::String, to::String = "127.0.0.1", port::Int64 = 2000; from::Int64 = port - 5)</code> respectively.</li>
</ul>

<p dir="auto">Like toolips, <code>ToolipsUDP</code> provides an extensible server infastructure which allows for the addition of new, reproducible features to a server. In <code>ToolipsUDP</code>, these extensions are facilitated using multiple dispatch, the <code>UDPExtension</code> type, and the functions <code>serve</code> and <code>onstart</code>. To add an extension, first import one of these functions. For this example, we will import <em>both</em>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import ToolipsUDP: serve, onstart"><pre><span class="pl-k">import</span> ToolipsUDP<span class="pl-k">:</span> serve, onstart</pre></div>
<p dir="auto">The <code>serve</code> function is called on our <code>UDPConnection</code> each time we recieve an incoming packet. The <code>onstart</code> function is called on our <code>Connection</code> data on start.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ToolipsUDP
import ToolipsUDP: serve, onstart

onstart(data::Dict{Symbol, Any}, ue::UDPExtension{:loaddata}) = push!(data, :mydata =&gt; &quot;hello world!&quot;)

serve(c::UDPConnection, ue::UDPExtension{:printdata}) = println(c[:mydata])"><pre><span class="pl-k">using</span> ToolipsUDP
