<p dir="auto">Graphs are read using either the <code>loadgraph</code> function or, for formats that support multiple graphs in a single file,
the <code>loadgraphs</code> functions. <code>loadgraph</code> returns a Graph object, while <code>loadgraphs</code> returns a dictionary of Graph objects.</p>
<p dir="auto">For example, an edgelist file could be loaded as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="graph = loadgraph(&quot;path_to_graph/my_edgelist.txt&quot;, &quot;graph_key&quot;, EdgeListFormat())"><pre>graph <span class="pl-k">=</span> <span class="pl-c1">loadgraph</span>(<span class="pl-s"><span class="pl-pds">"</span>path_to_graph/my_edgelist.txt<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>graph_key<span class="pl-pds">"</span></span>, <span class="pl-c1">EdgeListFormat</span>())</pre></div>

<p dir="auto">All <code>*Format</code> types are readily accessible.
However, in order to use some of them with <code>loadgraph</code>, additional packages are required.
You may thus need to install and load the following dependencies before using parts of GraphIO.jl:</p>
<ul dir="auto">
<li>Reading <a href="https://en.wikipedia.org/wiki/DOT_(graph_description_language)" rel="nofollow">DOT</a> or <a href="https://en.wikipedia.org/wiki/Graph_Modelling_Language" rel="nofollow">GML</a> files: do <code>using ParserCombinator</code></li>
<li>Reading <a href="https://gephi.org/gexf/format/" rel="nofollow">GEXF</a> or <a href="https://en.wikipedia.org/wiki/GraphML" rel="nofollow">GraphML</a> files: do <code>using EzXML</code></li>
<li>Reading <a href="https://en.wikipedia.org/wiki/Graph_Modelling_Language" rel="nofollow">GML</a> files: do <code>using CodecZlib</code></li>
</ul>
<p dir="auto">The current design avoids populating your environment with unnecessary dependencies.</p>
<blockquote>
<p dir="auto"><strong><em>IMPLEMENTATION NOTE:</em></strong>
The current design uses package extensions, introduced in Julia v1.9.
At the moment, package extensions cannot conditionally load types, that is one of the main reasons why all <code>*Format</code> types are readily accessible.
However, the functionality of <code>loadgraph</code> is extended for the various types only when the appropriate dependencies are available.
We are searching for more intuitive ways to design this interface.</p>
</blockquote>
