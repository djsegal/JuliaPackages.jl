<p dir="auto">A Julia client for the <a href="http://juliahub.com/" rel="nofollow">JuliaHub platform</a> APIs.
It allows you to programmatically interact with the platform to, for example, upload or download datasets, start jobs, and so on.</p>
<p dir="auto">The package is an open-source and available in the <a href="https://github.com/JuliaRegistries/General">Julia General registry</a>, and can simply be installed via the package manager.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add JuliaHub"><pre class="notranslate"><code>pkg&gt; add JuliaHub
</code></pre></div>
<p dir="auto">To get started, you must first authenticate with a JuliaHub instance.
The package can be used to interact with both <code>juliahub.com</code> and enterprise instances.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuliaHub
JuliaHub.authenticate(&quot;juliahub.com&quot;)"><pre><span class="pl-k">using</span> JuliaHub
JuliaHub<span class="pl-k">.</span><span class="pl-c1">authenticate</span>(<span class="pl-s"><span class="pl-pds">"</span>juliahub.com<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Once your session is authenticated, you can start interacting with the JuliaHub instance.
For example, to list datasets you can call <code>JuliaHub.datasets()</code> or to upload a new dataset you can call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="JuliaHub.upload_dataset(&quot;my-new-dataset&quot;, &quot;local/file.csv&quot;)"><pre>JuliaHub<span class="pl-k">.</span><span class="pl-c1">upload_dataset</span>(<span class="pl-s"><span class="pl-pds">"</span>my-new-dataset<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>local/file.csv<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Or you can also start JuliaHub jobs to offload computations to the cloud.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="JuliaHub.submit_job(

<span class="pl-s">    <span class="pl-pds">"""</span></span>
)</pre></div>
