<p dir="auto">A package of LDPC decoders for decoding certain LDPC Quantum Error Correcting Codes using Julia. It currently has a simple iterative decoder and belief propagation (BP) decoder, which also has variation with post processing using Ordered Statistics Decoding (BP+OSD).</p>

<p dir="auto">To use decoders and structs from LDPCDecoders.jl in your project, add it to your <code>Project.toml</code>, and automatically to <code>Manifest.toml</code></p>
<p dir="auto">Inside your project folder (which contains the <code>Project.toml</code> and <code>Manifest.toml</code>), run Julia in package mode (enabled by pressing <code>]</code> in Julia REPL)</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; activate .
(YourProject) pkg&gt; add LDPCDecoders.jl"><pre>pkg<span class="pl-k">&gt;</span> activate <span class="pl-c1">.</span>
(YourProject) pkg<span class="pl-k">&gt;</span> add LDPCDecoders.jl</pre></div>
<p dir="auto">When prompted, press <code>Y/y</code> for yes.</p>

<p dir="auto">The code and user interface for the belief propagation decoder lies in <code>src/decoders/belief_propagation.jl</code>. First step is to set up the decoder, with your parity check matrix <code>H</code>, physical error rate <code>per</code> and max number of decoding iterations for belief propagation algorithm.</p>
