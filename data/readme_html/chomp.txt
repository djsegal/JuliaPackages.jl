<p dir="auto">This package is a julia wrapper around the Computational Homology Project (CHomP) with python bindings. The wrapper is very barebones, really it just provides a way to call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CHomP"><pre><span class="pl-k">using</span> CHomP</pre></div>
<p dir="auto">and have <a href="https://pypi.org/project/pychomp2/" rel="nofollow">pychomp2</a> be available for use (via <a href="https://github.com/JuliaPy/PyCall.jl">PyCall.jl</a>).</p>
<p dir="auto">If you are a fellow mathematician or computer scientist and want to create a true julia implementation of CHomP, please contact April Herwig (via <code>April-Hannah-Lena</code> on GitHub or <code>april.herwig@tum.de</code>), I will happily transfer ownership rights of this package to you.</p>

<p dir="auto">CHomP.jl requires julia 1.7 or later. To install CHomP.jl, call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="] add https://github.com/April-Hannah-Lena/CHomP.jl.git"><pre>] add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>April<span class="pl-k">-</span>Hannah<span class="pl-k">-</span>Lena<span class="pl-k">/</span>CHomP<span class="pl-k">.</span>jl<span class="pl-k">.</span>git</pre></div>
<p dir="auto">Upon first install, this will run a build process, which downloads and installs the python pakage pychomp2. After any updates to python, PyCall.jl, Conda.jl, or CHomP.jl, it is recommended (though probably not necessary) to rebuild:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="build CHomP"><pre>build CHomP</pre></div>
<p dir="auto">One can now use CHomP.jl through PyCall.jl, which is automatically exported by CHomP.jl</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CHomP"><pre><span class="pl-k">using</span> CHomP</pre></div>
<p dir="auto">(you do not need to call <code>using PyCall</code>)</p>
<p dir="auto">The python module <code>chompjl</code> is then made available to the namespace (via <code>pyimport</code>).</p>

<p dir="auto">Ensure that <code>python</code> and <code>pip</code> are accessible in your systems PATH environment variable.</p>
<p dir="auto">The python instance created by PyCall.jl should include the packages <code>sys</code> and <code>subprocess</code>. These are all the python packages required to build CHomP.jl. If <code>pip</code> is available in your PATH, then a failed build step is most likely an issue with PyCall.jl. See for reference <a href="https://github.com/JuliaPy/PyCall.jl#troubleshooting">PyCall.jl's torubleshooting section</a> or the <a href="https://github.com/JuliaPy/PyCall.jl/issues">PyCalll.jl issues page</a>.</p>
<p dir="auto">If a problem occurs that seems to bee related to julia, open an issue in the <a href="https://github.com/April-Hannah-Lena/CHomP.jl/issues">package repository on GitHub</a>.</p>
<p dir="auto">If a problem occurs that seems to be related to chomp (resp. pychomp2 or the original C++ chomp), open an issue in the chomp repository on Github (resp. <a href="https://pypi.org/project/pychomp2/issues" rel="nofollow">pychomp2</a> or <a href="https://github.com/shaunharker/CHomP/issues">chomp</a>).</p>
