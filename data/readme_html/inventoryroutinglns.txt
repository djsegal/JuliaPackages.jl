<p dir="auto">This package tackles large-scale multi-attribute inventory routing problems, as defined in our paper</p>
<blockquote>
<p dir="auto"><a href="https://arxiv.org/abs/2209.00412" rel="nofollow">Solving a Continent-Scale Inventory Routing Problem at Renault</a></p>
</blockquote>
<p dir="auto">In our setting, routes last several days, and the instances have 15 depots, 600 customers, 30 commodities and a 21-day horizon on average.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Solution pipeline</h3><a id="user-content-solution-pipeline" class="anchor" aria-label="Permalink: Solution pipeline" href="#solution-pipeline"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol dir="auto">
<li>To create an IRP instance from a folder architecture, we call <code>read_instance_CSV</code>. This function is designed to browse multiple CSV files and combine them into an <code>Instance</code> object..</li>
<li>A lower bound can be computed on the given instance using a flow relaxation, with <code>lower_bound</code>.</li>
<li>The initialization + local search algorithm is implemented as <code>initialization_plus_ls!</code>. It can be applied with two passes, re-estimating the transport costs on the arcs of the commodity flow graphs with a call to <code>modified_capa_initialization_plus_ls!</code>.</li>
<li>The large neighborhood search can then used applied to improve the initial solution with <code>LNS!</code>.</li>
</ol>
<p dir="auto">The complete pipeline is encapsulated in the <code>paper_matheuristic!</code> function.
The algorithm called "route-based matheuristic" in the paper is implemented as <code>route_based_matheuristic!</code>.
Note that what we call "LNS" in our paper corresponds to the combination of <code>initialization_plus_ls!</code> and <code>LNS!</code> in our code.</p>
