<p dir="auto">This is a tiny package that allows data sets to be documented in the same manner
  as functions/variables.</p>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Usage</h1><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Add <code>DataToolkitDocumenter</code> along with <code>Documenter</code> when generating the
  documentation, and ensure that any data collection(s) you want to document are
  loaded.</p>
<p dir="auto">In the documentation source files themselves, use <code>@datasets</code> in the same manner
  as <code>@docs</code> to document some data sets by their identifier, e.g.</p>
<div class="highlight highlight-text-md notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="```@datasets
iris
[other identifiers...]
```"><pre><span class="pl-s">```</span><span class="pl-en">@datasets</span><span class="pl-c1"></span>
<span class="pl-c1">iris</span>
<span class="pl-c1">[other identifiers...]</span>
<span class="pl-c1"></span><span class="pl-s">```</span></pre></div>
<p dir="auto">For documenting an entire data collection with ease, one can use <code>@autodatasets</code>.
  With no content it will document the first collection on the stack, but specific
  collections can be documented by setting a <code>Collections</code> value, like so:</p>
<div class="highlight highlight-text-md notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="```@autodatasets
Collections = [nothing, &quot;foo&quot;, &quot;bar&quot;, &quot;ded0d04d-deda-4bd8-95cb-5b214a5e3ce6&quot;]
```"><pre><span class="pl-s">```</span><span class="pl-en">@autodatasets</span><span class="pl-c1"></span>
<span class="pl-c1">Collections = [nothing, "foo", "bar", "ded0d04d-deda-4bd8-95cb-5b214a5e3ce6"]</span>
<span class="pl-c1"></span><span class="pl-s">```</span></pre></div>
<p dir="auto">The value of <code>nothing</code> is special, and refers to the top entry of the data
  collection stack. Other collections can be referenced by name or UUID.</p>
