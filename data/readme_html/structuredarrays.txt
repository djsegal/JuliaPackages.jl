<p dir="auto"><code>StructuredArrays</code> is a small <a href="https://julialang.org/" rel="nofollow">Julia</a> package which provides multi-dimensional
arrays behaving like regular arrays but whose elements have the same given value or are
computed by applying a given function to their indices. The main advantage of such arrays
is that they are very light in terms of memory: their storage requirement is <code>O(1)</code>
whatever their size instead of <code>O(n)</code> for an ordinary array of <code>n</code> elements.</p>
<p dir="auto">Note that <code>StructuredArrays</code> has a different purpose than
<a href="https://github.com/JuliaArrays/StructArrays.jl"><code>StructArrays</code></a> which is designed for
arrays whose elements are <code>struct</code>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Uniform arrays</h2><a id="user-content-uniform-arrays" class="anchor" aria-label="Permalink: Uniform arrays" href="#uniform-arrays"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">All elements of a uniform array have the same value. A uniform array thus require to only
store this value and the dimensions (or the axes) of the array. In addition, some
operations (e.g., <code>minimum</code>, <code>maximum</code>, <code>extrema</code>, <code>all</code>, <code>any</code>, <code>sum</code>, <code>prod</code>, <code>count</code>,
<code>findmin</code>, <code>findmax</code>, <code>reverse</code>, or <code>unique</code>) may be implemented so as to be very fast for
uniform arrays.</p>
<p dir="auto">To build a uniform array, call:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = UniformArray(val, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">UniformArray</span>(val, args<span class="pl-k">...</span>)</pre></div>
<p dir="auto">which yields an array <code>A</code> behaving as a read-only array whose values are all <code>val</code> and
whose axes are defined by <code>args...</code>. Each of <code>args...</code> define an array axis and can be an
integer for a 1-based index or an integer-valued unit step range. It is thus possible to
have offset axes as in the
<a href="https://github.com/JuliaArrays/OffsetArrays.jl"><code>OffsetArrays</code></a> package.</p>
<p dir="auto">Uniform arrays implement conventional linear indexing: <code>A[i]</code> yields <code>val</code> for all linear
indices <code>i</code> in the range <code>1:length(A)</code>.</p>
<p dir="auto">The statement <code>A[i] = x</code> is however not implemented because uniform arrays are considered
as read-only. You may call <code>MutableUniformArray(val,dims)</code> to create a mutable uniform
array. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="B = MutableUniformArray(val, args...)"><pre>B <span class="pl-k">=</span> <span class="pl-c1">MutableUniformArray</span>(val, args<span class="pl-k">...</span>)</pre></div>
<p dir="auto">For <code>B</code>, the statement <code>B[i] = x</code> is allowed to change the value of all the elements of
<code>B</code> provided index <code>i</code> represents all possible indices in <code>B</code>. Typically <code>B[:] = x</code> or
<code>B[1:end] = x</code> are accepted but not <code>B[1] = x</code>, unless <code>B</code> has a single element.</p>
<p dir="auto">Apart from all values being the same, uniform arrays behave like ordinary Julia arrays.</p>
<p dir="auto">When calling a uniform array constructor, the element type <code>T</code> and the number of
dimensions <code>N</code> may be specified. This is most useful for <code>T</code> to enforce a given element
type. By default, <code>T = typeof(val)</code> is assumed. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = UniformArray{T}(val, args...)
B = MutableUniformArray{T,N}(val, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">UniformArray</span><span class="pl-c1">{T}</span>(val, args<span class="pl-k">...</span>)
B <span class="pl-k">=</span> <span class="pl-c1">MutableUniformArray</span><span class="pl-c1">{T,N}</span>(val, args<span class="pl-k">...</span>)</pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Fast uniform arrays</h2><a id="user-content-fast-uniform-arrays" class="anchor" aria-label="Permalink: Fast uniform arrays" href="#fast-uniform-arrays"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A fast uniform array is like an immutable uniform array but with the value of all elements
being part of the signature so that this value is known at compile time. To build such an
array, call one of:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = FastUniformArray(val, args...)
A = FastUniformArray{T}(val, args...)
A = FastUniformArray{T,N}(val, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">FastUniformArray</span>(val, args<span class="pl-k">...</span>)
A <span class="pl-k">=</span> <span class="pl-c1">FastUniformArray</span><span class="pl-c1">{T}</span>(val, args<span class="pl-k">...</span>)
A <span class="pl-k">=</span> <span class="pl-c1">FastUniformArray</span><span class="pl-c1">{T,N}</span>(val, args<span class="pl-k">...</span>)</pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Structured arrays</h2><a id="user-content-structured-arrays" class="anchor" aria-label="Permalink: Structured arrays" href="#structured-arrays"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The values of the elements of a structured array are computed on the fly as a function of
their indices. To build such an array, call:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = StructuredArray(func, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">StructuredArray</span>(func, args<span class="pl-k">...</span>)</pre></div>
<p dir="auto">which yields a read-only array <code>A</code> whose values at index <code>i</code> are computed as <code>func(i)</code> and
whose axes are defined by <code>args...</code>. In other words, <code>A[i]</code> yields <code>func(i)</code>.</p>
<p dir="auto">An optional leading argument <code>S</code> may be used to specify another index style than the
default <code>IndexCartesian</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = StructuredArray(S, func, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">StructuredArray</span>(S, func, args<span class="pl-k">...</span>)</pre></div>
<p dir="auto">where <code>S</code> may be a sub-type of <code>IndexStyle</code> or an instance of such a sub-type. If <code>S</code> is
<code>IndexCartesian</code> (the default), the function <code>func</code> will be called with <code>N</code> integer
arguments, a <code>Vararg{Int,N}</code>, <code>N</code> being the number of dimensions. If <code>S</code> is <code>IndexLinear</code>,
the function <code>func</code> will be called with a single integer argument, an <code>Int</code>.</p>
<p dir="auto">A structured array can be used to specify the location of structural non-zeros in a sparse
matrix. For instance, the structure of a lower triangular matrix of size <code>m×n</code> could be
given by:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="StructuredArray((i,j) -&gt; (i ≥ j), m, n)"><pre><span class="pl-c1">StructuredArray</span>((i,j) <span class="pl-k">-&gt;</span> (i <span class="pl-k">≥</span> j), m, n)</pre></div>
<p dir="auto">but with a constant small storage requirement whatever the size of the matrix.</p>
<p dir="auto">Although the callable object <code>func</code> may not be a <em>pure function</em>, its return type shall be
stable and structured arrays are considered as immutable in the sense that a statement
like <code>A[i] = x</code> is not implemented. The type, say, <code>T</code> of the elements of structured array
is inferred by applying <code>func</code> to the unit index or may be explicitly specified:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="StructuredArray{T}(S, func, dims)"><pre><span class="pl-c1">StructuredArray</span><span class="pl-c1">{T}</span>(S, func, dims)</pre></div>
<p dir="auto">where, if omitted, <code>S = IndexCartesian</code> is assumed. The <code>StructuredArray</code> constructor also
supports the number of dimensions <code>N</code> and the indexing style <code>S</code> as optional type
parameters. The two following examples are equivalent:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = StructuredArray{T,N}(S, func, args...)
A = StructuredArray{T,N,S}(func, args...)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">StructuredArray</span><span class="pl-c1">{T,N}</span>(S, func, args<span class="pl-k">...</span>)
A <span class="pl-k">=</span> <span class="pl-c1">StructuredArray</span><span class="pl-c1">{T,N,S}</span>(func, args<span class="pl-k">...</span>)</pre></div>
