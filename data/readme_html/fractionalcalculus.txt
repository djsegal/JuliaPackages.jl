<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Derivative</h3><a id="user-content-derivative" class="anchor" aria-label="Permalink: Derivative" href="#derivative"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To compute the fractional derivative in a specific point, for example, compute <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$\alpha = 0.2$</math-renderer> derivative of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$f(x) = x$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$x = 1$</math-renderer> with step size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$h = 0.0001$</math-renderer> using <strong>Riemann Liouville</strong> sense:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; fracdiff(x-&gt;x, 0.2, 1, 0.0001, RLDiffL1())
1.0736712740308347"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">fracdiff</span>(x<span class="pl-k">-&gt;</span>x, <span class="pl-c1">0.2</span>, <span class="pl-c1">1</span>, <span class="pl-c1">0.0001</span>, <span class="pl-c1">RLDiffL1</span>())
<span class="pl-c1">1.0736712740308347</span></pre></div>
<p dir="auto">This will return the estimated value with high precision.</p>

<p dir="auto">To compute the fractional integral in a specific point, for example, compute the semi integral of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$f(x) = x$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$x = 1$</math-renderer>  with step size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b50ad1971af728b4c7b517e6d274658f">$h = 0.0001$</math-renderer> using <strong>Riemann-Liouville</strong> sense:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; fracint(x-&gt;x, 0.5, 1, 0.0001, RLIntApprox())

<p dir="auto">This will return the estimated value with high precision.</p>
