<p dir="auto">WorldTimeAPI.jl is a lightweight Julia package that offers a convenient interface to interact with the <a href="http://worldtimeapi.org/" rel="nofollow">WorldTimeAPI</a>. Easily retrieve the current time and date for any specified timezone, or use UTC by default.</p>
