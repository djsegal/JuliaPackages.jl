<p dir="auto">A partial implementation of the CryoGrid permafrost model in Julia, with a focus on parameter estimation and uncertainty quantification.</p>
<p dir="auto">Part of the broader research project: <a href="https://drive.google.com/file/d/1wB_EXtlO_PMXFSzZ-bRV8cg0a0DGDtAB/view?usp=sharing" rel="nofollow">Quantifying and explaining uncertainty in permafrost modeling under a warming climate</a></p>
<p dir="auto">Author: Brian Groenke (<a href="mailto:brian.groenke@awi.de">brian.groenke@awi.de</a>)</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Fast and modular interface for defining multi-physics permafrost models including:
<ul dir="auto">
<li>Two-phase heat and water transport in porous media (i.e. soil and snow)</li>
<li>Soil freeze-thaw dynamics from <a href="https://github.com/cryogrid/FreezeCurves.jl">FreezeCurves.jl</a></li>
<li>Surface energy balance</li>
<li>Snow cover</li>
<li>Salt diffusion</li>
</ul>
</li>
<li>Flexible interface for model parameter handling via <a href="https://rafaqz.github.io/ModelParameters.jl/stable/" rel="nofollow">ModelParameters.jl</a></li>
<li>Support for automatic differentiation via <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a></li>
<li>Compatibility with ODE solvers <a href="https://github.com/SciML/OrdinaryDiffEq.jl">OrdinaryDiffEq.jl</a> as well as other <a href="https://github.com/SciML">SciML</a> tools for analyzing dynamical systems</li>
</ul>

<p dir="auto">Here we define a multi-layer heat conduction model on the pre-defined soil profile for Samoylov Island.</p>
<p dir="auto">Make sure that you have the <code>Plots</code> package installed in addition to <code>CryoGrid</code> in order to run this example code.</p>

<p dir="auto">The <code>examples/</code> folder contains a number of other examples that should help users get started with the model.</p>
<p dir="auto">In order to run these examples, it is recommended to clone the repository or add it as a development package via the package manager (i.e. <code>dev CryoGrid</code> instead of <code>add CryoGrid</code>). In the latter case, you can find the repository in <code>$JULIA_HOME/.dev/CryoGrid</code>.</p>
<p dir="auto">Then <code>cd</code> into the <code>CryoGrid</code> repository and start julia with the <code>examples</code> folder set as the project environment; e.g. <code>julia --project=examples</code> or <code>julia</code> followed by <code>activate examples</code> in the package manager.</p>
<p dir="auto">The package manager will install all additional dependencies needed for the examples (e.g. plotting and analysis packages). After this is finished, you should be able to run all of the examples without issue. If you encounter any errors while running the examples, please create an issue on GitHub so that we can fix it.</p>
