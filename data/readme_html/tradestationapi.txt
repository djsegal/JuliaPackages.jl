<p dir="auto">This will output a URL where you can enter into a web browser in exchange for a 16 digit Authorization Code</p>
<p dir="auto">Step 2</p>
<p dir="auto">authorization_code = 16 digit Authorization Code recieived in Step 1</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="TradeStationAPI.access_token_req(client_id, client_secret, authorization_code, redirect_uri)"><pre>TradeStationAPI<span class="pl-k">.</span><span class="pl-c1">access_token_req</span>(client_id, client_secret, authorization_code, redirect_uri)</pre></div>
<p dir="auto">Step 3</p>
<p dir="auto">Each access token will last for 20 minutes.</p>
<p dir="auto">However, a refresh token is long-lived. This means you do not need to continually perform the full sign-in process. A refresh token can be used, as needed, to generate new access tokens.</p>
<p dir="auto">To generate a new access token</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="TradeStationAPI.refresh_token_req(client_id, client_secret, refresh_token_out)"><pre>TradeStationAPI<span class="pl-k">.</span><span class="pl-c1">refresh_token_req</span>(client_id, client_secret, refresh_token_out)</pre></div>
<p dir="auto">Given each access tokens life span is 20 minutes. Inside a trading application one may call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="TradeStationAPI.refresh_token_timer(expiry_seconds; offset_seconds, client_id, client_secret, refresh_token_out, stop_date_time=DateTime(&quot;2023-12-03T22:15:00&quot;))"><pre>TradeStationAPI<span class="pl-k">.</span><span class="pl-c1">refresh_token_timer</span>(expiry_seconds; offset_seconds, client_id, client_secret, refresh_token_out, stop_date_time<span class="pl-k">=</span><span class="pl-c1">DateTime</span>(<span class="pl-s"><span class="pl-pds">"</span>2023-12-03T22:15:00<span class="pl-pds">"</span></span>))</pre></div>
<p dir="auto">This function refreshes the access token after each countdown duration in seconds. It runs recursivley until a specified stop date/time. Use case may be running in a trading application and stopping at a session end. An example of calling this with @async</p>
