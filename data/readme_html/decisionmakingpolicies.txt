<p dir="auto">The repository contains code useful for representing policies used in decision making problems. This library utilizes the <a href="https://github.com/LuxDL/Lux.jl">Lux.jl</a> framework for managing the functional structure and parameters of the policy. A policy is a function that returns distribution over actions. For example:</p>

<p dir="auto">Here <code>policy(...)</code> returns a distribution over four possible actions. Since the policy takes not state or context as input we refer to it as a stateless (bandit) policy. The main functions for policies defined in this repo are:</p>
<ul dir="auto">
<li><code>policy(...)</code> compute a distribution over actions (as shown above),</li>
<li><code>logpdf(policy, x, a, ps, st)</code> compute the log probability of an action,</li>
<li><code>grad_logpdf(policy, x, a, ps, st)</code> compute the gradient of the log probability of the action, and</li>
<li><code>sample_with_trace(policy, x, ps, st)</code> sample an action and compute gradient of the log probability of the sampled action (useful for online algorithms).</li>
</ul>
<p dir="auto">Below is an example use of these for a LinearSoftmax policy.</p>

<p dir="auto">These functions cause allocations so to make them faster we created a buffered implementation. To preallocate all the necessary arrays, the buffers are stored in the state of the policy. To use it simply at the buffered=true keyword in the constructor.</p>

<p dir="auto">The buffers are intended for fast linear policies working with a single samples. The buffers are ignored for batched input and are not always used for autodifferention. This may be extended in the future (taking pullrequests).</p>
<p dir="auto">The policies can also be used with autodifferentiation packages that support ChainRulesCore rules. For example:</p>

    X = env.X 
    n = size(X,1)
    num_actions = length(env.A)
    
    act_fn = Lux.tanh  # can be whatever you want
