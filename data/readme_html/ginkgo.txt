<p dir="auto">Ginkgo.jl is a Julia wrapper for the high-performance numerical linear algebra library <a href="https://ginkgo-project.github.io/" rel="nofollow">Ginkgo</a> that aims to leverage the hardware vendor’s native programming models to implement highly tuned architecture-specific kernels. Separating the core algorithm from these architecture-specific kernels enables high performance while enhancing the readability and maintainability of the software. Seamlessly integrating Julia with Ginkgo, Ginkgo.jl interoperates with the C++ source library through a C API.</p>
