<p dir="auto">This software solves <strong>nonlinear control problems</strong> at a <strong>high-level</strong> very <strong>quickly</strong>.</p>
<p dir="auto">Adds to <a href="http://www.juliaopt.org/" rel="nofollow">juliaOpt</a> community by:</p>
<ul dir="auto">
<li>Providing an implementation of direct-collocation methods for solving optimal control problems in julia</li>
<li>Solving nonlinear optimal control problems at a high-level</li>
<li>Visualizing the solution</li>
</ul>

<p dir="auto">If you are using <strong>Linux</strong> make sure that you have <strong>gfortran</strong> to run <strong>Ipopt</strong>:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="sudo apt-get update

sudo apt-get install libblas-dev"><pre>sudo apt-get update
sudo apt-get install gfortran
sudo apt-get install liblapack-dev
sudo apt-get install libblas-dev</pre></div>
<p dir="auto">Also, make sure that you are using at least julia 1.0.0</p>
<p dir="auto">Then open up julia and install NLOptControl</p>
