<p dir="auto"><a href="https://en.wikipedia.org/wiki/Stop_word" rel="nofollow">Stop words</a> are the words in a negative dictionary which are filtered out before or after processing of natural language data (text) because they are insignificant. This julia package contains a collection of stop words for multiple languages. The data is sourced from: <a href="https://github.com/stopwords-iso/stopwords-iso">https://github.com/stopwords-iso/stopwords-iso</a>. Currently, this package supports 57 languages, identified by their <a href="https://en.wikipedia.org/wiki/ISO_639_macrolanguage" rel="nofollow">ISO 639-3</a> codes:</p>
<blockquote>
<p dir="auto">afr ara ben bre bul cat ces dan deu ell eng epo est eus fas fin fra gle glg guj hau hbs heb hin hun hye ita jpn kor kur lat lav lit mar msa nld nor pol por ron rus slk slv som sot spa swa swe tgl tha tur ukr urd vie yor zho zul</p>
</blockquote>

<p dir="auto">The <code>stopwords</code> variable is the only exported symbol of this package. It can be regarded as a lazy dictionary of stop words for multiple languages. You can access the stop words for a given language using the language name or <a href="https://en.wikipedia.org/wiki/ISO_639" rel="nofollow">ISO 639</a> code. For example, to get the stop words for English, you can use <code>stopwords["eng"]</code>, <code>stopwords["en"]</code>, or <code>stopwords["English"]</code>.</p>

<p dir="auto">The <code>StopWords.supported_languages()</code> function returns a set of all the languages currently supported by the package. To check if a specific language is supported, you can use the <code>haskey</code> function. And for multiple languages, you can pass a list to the <code>haskey</code> function.</p>
