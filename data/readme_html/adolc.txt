<p dir="auto"><em>A Julia wrapper of the automatic differentiation package ADOL-C</em></p>
<p dir="auto">This package wraps the C/C++ automatic differentiation library <a href="https://github.com/coin-or/ADOL-C">ADOL-C</a> for use in <a href="https://julialang.org/" rel="nofollow">Julia</a>.</p>
<p dir="auto">Currently, the ADOL-C binaries are built for Julia 1.9, 1.10, and 1.11, and they are not compiled for musl libc.<br>
To add this package, use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg; Pkg.add(&quot;ADOLC&quot;)
using ADOLC"><pre><span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>ADOLC<span class="pl-pds">"</span></span>)
<span class="pl-k">using</span> ADOLC</pre></div>

<p dir="auto">There are various available modes for <a href="https://timsiebert1.github.io/ADOLC.jl/dev/lib/derivative_modes/#First-Order" rel="nofollow">first-</a> and <a href="https://timsiebert1.github.io/ADOLC.jl/dev/lib/derivative_modes/#Second-Order" rel="nofollow">second-order</a> calculations. The computation of higher-order derivatives is explained <a href="https://timsiebert1.github.io/ADOLC.jl/dev/lib/derivative_modes/#Higher-Order" rel="nofollow">here</a> and works as sketched below</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="f(x) = [x[1]^2*x[2]^2, x[3]^2*x[4]^2]

<p dir="auto">You can also define parameters (<code>param</code>) not used for differentiation, which can be changed
in subsequent calls without retaping. The given function <code>f</code> is expected to have the shape <code>f(x, param)</code>:</p>

<p dir="auto">In addition, there is the possibility to compute univariate Taylor polynomials with the <a href="https://timsiebert1.github.io/ADOLC.jl/stable/lib/guides/utpp/" rel="nofollow"><code>univariate_tpp</code></a> driver:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="f(x) = sin(x[1]) + x[2]
