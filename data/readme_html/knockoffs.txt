<p dir="auto">This is a Julia implementation of the <a href="https://web.stanford.edu/group/candes/knockoffs/" rel="nofollow">knockoff filter</a>, taking many inspirations from the MATLAB/R implementation of <a href="https://github.com/msesia/knockoff-filter">knockoff-filter</a>, python implementation of <a href="https://github.com/amspector100/knockpy">knockpy</a>, and also the C++/R code of <a href="https://github.com/msesia/knockoffgwas">knockoffgwas</a>. The knockoff filter is a general framework for controlling the false discovery rate when performing variable selection. As the name suggests, the knockoff filter operates by manufacturing knockoff variables that are cheap — their construction does not require collecting any new data — and are designed to mimic the correlation structure found within the original variables. The knockoffs serve as negative controls and they allow one to identify the truly important predictors, while controlling the false discovery rate (FDR) — the expected fraction of false discoveries among all discoveries.</p>
<p dir="auto">For more information, please see the <a href="https://web.stanford.edu/group/candes/knockoffs/" rel="nofollow">main webpage</a></p>

<ul dir="auto">
<li>Fast coordinate descent algorithms for MVR, ME, and SDP model-X knockoffs</li>
<li>Grouped MVR/ME/SDP knockoffs for improved power when there are highly correlated features. We also provide a representative group knockoff approach, based on graphical models, which is much more computationally efficient and empirically has superior power.</li>
<li>Preliminary support for many other kinds of knockoffs (ghost, HMM, IPAD...etc), see documentation.</li>
<li>Built-in functions to compute feature importance scores via Lasso/marginal regressions</li>
</ul>
