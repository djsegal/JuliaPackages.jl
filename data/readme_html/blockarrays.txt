<p dir="auto">A block array is a partition of an array into blocks or subarrays, see <a href="https://en.wikipedia.org/wiki/Block_matrix" rel="nofollow">wikipedia</a> for a more extensive description. This package has two purposes. Firstly, it defines an interface for an <code>AbstractBlockArray</code> block arrays that can be shared among types representing different types of block arrays. The advantage to this is that it provides a consistent API for block arrays.</p>
<p dir="auto">Secondly, it also implements two different type of block arrays that follow the <code>AbstractBlockArray</code> interface. The type <code>BlockArray</code> stores each block contiguously while the type <code>BlockedArray</code> stores the full matrix contiguously. This means that <code>BlockArray</code> supports fast non copying extraction and insertion of blocks while <code>BlockedArray</code> supports fast access to the full matrix to use in in for example a linear solver.</p>

<p dir="auto">We are excited to release v1.0! There are some important breaking changes from previous versions of BlockArrays.jl:</p>
<ul dir="auto">
<li><code>BlockedArray</code> replaces <code>PseudoBlockArray</code>.</li>
<li>Axes are now typically <code>BlockedOneTo</code> instead of <code>BlockUnitRange</code>.</li>
<li>Support for some simple block-banded matrices has been moved here from BlockBandedMatrices.jl.</li>
<li>The definition of <code>blocksizes(array::AbstractArray)</code> is changed from <code>blocklengths.(axes(array))</code> to an iterator of size <code>blocksize(array)</code> over the sizes of each block of <code>array</code>.</li>
<li><code>BlockedUnitRange</code> is now parametrized by the element type instead of hardcoded to <code>Int</code>.</li>
</ul>

<p dir="auto">Possible ways of contributing to this package include:</p>
<ul dir="auto">
<li>Implement the fusing broadcasting interface for blocked arrays.</li>
<li>Make different Linear Algebra function (like matrix / vector multiplications) with blocked arrays work.</li>
<li>Implement different reductions functionalities, (<code>sum</code> and co.).</li>
<li>Audit the performance and make improvements as needed.</li>
</ul>
