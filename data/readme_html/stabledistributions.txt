<p dir="auto">Generation and estimation of the class of stable distributions (see on <a href="https://en.wikipedia.org/wiki/Stable_distribution" rel="nofollow">Wikipedia</a>) in Julia. It fully complies with the interface of <a href="https://github.com/JuliaStats/Distributions.jl">Distributions.jl</a> package. The algorithms are based on book John P. Nolan, "Univariate Stable Distributions", Springer 2020 and related publications of John P. Nolan.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Defining stable distribution</h2><a id="user-content-defining-stable-distribution" class="anchor" aria-label="Permalink: Defining stable distribution" href="#defining-stable-distribution"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package uses the so-called type-1 parametrisation determined by:</p>
<ul dir="auto">
<li>stability index 0 &lt; α ≤ 2,</li>
<li>skewness parameter -1 ≤ β ≤ 1,</li>
<li>scale 0 &lt; σ,</li>
<li>location μ</li>
</ul>
<p dir="auto">Such distribution is uniquely characterised by its characteristic function (Fourier transform of its pdf)</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4312dad6dd0f8cc790ab9d375d16a6ce">$$\varphi(t; \alpha, \beta, \sigma, \mu) = \exp\big(\mathrm i t\mu -|\sigma t|^\alpha(1-\mathrm i\beta\mathrm{sgn}(t)\Phi(t))\big)$$</math-renderer>
<p dir="auto">with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4312dad6dd0f8cc790ab9d375d16a6ce">$\Phi(t) = -\frac{2}{\pi}\log|t|$</math-renderer> for α = 1 or <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4312dad6dd0f8cc790ab9d375d16a6ce">$\Phi(t) = \tan(\pi\alpha/2)$</math-renderer> for α ≠ 1.</p>
<p dir="auto">To construct stable distribution one can use:</p>
<ul dir="auto">
<li><code>Stable(α)</code> for standard symmetric α-stable distribution equivalent to Stable(α, 0, 1, 0),</li>
<li><code>Stable(α, β)</code> for standard α-stable distribution with skewness parameter β equivalent to Stable(α, β, 1, 0),</li>
<li><code>Stable(α, β, σ, μ)</code> in general case.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Generating values from stable distribution</h2><a id="user-content-generating-values-from-stable-distribution" class="anchor" aria-label="Permalink: Generating values from stable distribution" href="#generating-values-from-stable-distribution"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">One can use standard functions <code>rand(d::Stable)</code> for one value or <code>rand(d::Stable, shape)</code> for a series of values formatted with a given shape.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Utility functions</h2><a id="user-content-utility-functions" class="anchor" aria-label="Permalink: Utility functions" href="#utility-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Probability density function <code>pdf</code>, comultative probability function <code>cdf</code>, moment generating function <code>mgf</code>, characteristic function <code>cf</code> and quantiles <code>quantile</code>, and few ralated functions are also available. Values of <code>pdf</code>, <code>cdf</code> and <code>quantile</code> are approximate and based on numerical approximations of the corresponding integral representions and additional numerical function inversion for <code>quantile</code>. For example, <code>pdf(Stable(1.5), 2)</code> returns pdf of <code>Stable(1.5)</code> at point x = 2 which is approximately <code>0.084</code>.</p>
<p dir="auto">One can multiply stable distributions by scalars and add them, e.g. <code>2Stable(1.5) + 3</code> is a valid code which returns <code>Stable(1.5, 0, 2, 3)</code>. Function <code>convolve</code> is used to convolve two stable distributions with the same α, which is a distribution of the sum of two indepedent stable variables with such distributions. For example <code>convolve(Stable(0.5,1), Stable(0.5,0,2,1))</code> gives approximately <code>Stable(0.5, 0.41, 5.83, 1)</code>. Function <code>support</code> returns support of a given stable distribution, which can be half-bounded for skewed stable distribution with β = 1 or β = -1 and α &lt; 1.</p>
<p dir="auto">Method <code>convert</code> can be used to convert from special cases of Lévy, Cauchy and Gaussian to stable distributions. For example, <code>convert(Stable,Normal(0,1))</code> returns equivalent of <code>Stable(2, 0, √2/2, 1)</code>.</p>

<p dir="auto">Given data sample one can find best fitting stable distribution using method <code>fit(Stable, sample)</code>. It uses algorithm based on finding parameters which best fit sample characteristic function. This methods is considered to be efficient and quick. Alternatively, one can use <code>fit_quantile(Stable, sample)</code> which uses older McCulloch's quantile method in type-0 parametrisation. This method is considered to be generally worse but can be useful for additional checks, e.g. when there are doubts about the reliability of the estimation.</p>
