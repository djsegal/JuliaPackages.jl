<p dir="auto">SASLMR.jl is Julia package, it wrapp <code>sasLM</code> package for R project for ANOVA type I/II/III.</p>
<p dir="auto">Install:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="import Pkg; Pkg.add(url=&quot;https://github.com/PharmCat/SASLMR.jl.git&quot;)"><pre class="notranslate"><code>import Pkg; Pkg.add(url="https://github.com/PharmCat/SASLMR.jl.git")
</code></pre></div>
<p dir="auto">Note:</p>
<p dir="auto">SASLMR.jl doesn't install <code>sasLM</code>. To use SASLMR.jl first install <code>sasLM</code> in your R project enviroment.
Check that R project is included in <code>PATH</code>, and check that RCall.jl builded successfully.</p>

# run ANOVA
