<p dir="auto">A tiny package to read files without making new allocations for each line.</p>
<hr>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">How it works</h3><a id="user-content-how-it-works" class="anchor" aria-label="Permalink: How it works" href="#how-it-works"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We basically implement a buffered reader where the buffer is a vector of UInt8. We then stream the bytes from the file through this buffer and search for newline characters. On top of these vectors we use the amazing  <a href="https://github.com/JuliaStrings/StringViews.jl" title="StringViews">StringViews</a> package to view and compare strings without any allocations. For more detail of the actual implementation see <a href="https://github.com/JuliaStrings/ViewReader.jl/blob/master/src/FileReader.jl"><code>src/FileReader.jl</code></a>. <em>NOTE</em>, for this to work the <code>buffer_size</code> should be bigger than the longest line.</p>

<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">1. eachlineV</h4><a id="user-content-1-eachlinev" class="anchor" aria-label="Permalink: 1. eachlineV" href="#1-eachlinev"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><strong><code>eachlineV(file_path::String; buffer_size::Int=10_000)</code></strong></p>
<p dir="auto">This function can be used just like the base<a href="https://docs.julialang.org/en/v1/base/io-network/#Base.eachline" title=" `eachline` " rel="nofollow"> <code>eachline</code> </a> in Julia. The argument <code>buffer_size</code> determines the size of the underlaying UInt8 vector. The <code>buffer_size</code> should be bigger than the longest line in a file. If this is uknown just use a big number like 1M. This function will throw a warning if no new line is found when the eof is not reached yet - giving a clue to increase the <code>buffer_size</code>.</p>
<p dir="auto"><strong>Example</strong></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="for line in eachlineV(&quot;../data/test.txt&quot;)
