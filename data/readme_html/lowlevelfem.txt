<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">LowLevelFEM</h1><a id="user-content-lowlevelfem" class="anchor" aria-label="Permalink: LowLevelFEM" href="#lowlevelfem"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Solution of a problem in linear elasticity using Finite Element Method consists of solution of the stiffness matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{K}$</math-renderer> and load vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{f}$</math-renderer>, modifying them according to the boundary conditions (getting <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\tilde{\mathbf{K}}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\tilde{\mathbf{f}}$</math-renderer>), solving the displacement field <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{q}$</math-renderer> as the result of the system of equations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\tilde{\mathbf{K}}\mathbf{q}=\tilde{\mathbf{f}}$</math-renderer>, solving the stress field from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{q}$</math-renderer> and visualize them.
The above described steps can be easily performed using the LowLevelFEM package. Each step means a function with the appropriate parameters, while at any step it is possible to perform an arbitrary operation with the quantities calculated in the meantime. For example the strain energy can be solved as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$U=\frac{1}{2}\mathbf{q}^T\mathbf{K}\mathbf{q}$</math-renderer>, for which the code is simply <code>U=q'*K*q/2.</code>(see Examples)</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Features</h1><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Sketching the geometry, making the FE mesh with <a href="https://gmsh.info" rel="nofollow">GMSH</a>.</li>
<li>Solving problems from linear elasticity,
<ul dir="auto">
<li>2D problems,
<ul dir="auto">
<li>Plane stress,</li>
<li>Plane strain,</li>
</ul>
</li>
<li>3D problem (solid body),</li>
</ul>
</li>
<li>which means the creation of the stiffness matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{K}$</math-renderer> of the problem using arbitrary
<ul dir="auto">
<li>element types (line, triangle, rectangle, tetrahedron, hexahedron, pyramid, wedge)</li>
<li>approximation order (up to ten, Lagrange polynomials)</li>
</ul>
</li>
<li>Applying distributed forces on arbitrary <em>physical groups</em> (see <a href="https://gmsh.info" rel="nofollow">GMSH</a>),
<ul dir="auto">
<li>Lines (in 2D: surface force, in 3D: edge force),</li>
<li>Surfaces (in 2D: body force, in 3D: traction),</li>
<li>Volumes (in 3D: body force),</li>
</ul>
</li>
<li>concentrated forces on nodes,</li>
<li>which means the calculation of the load vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{f}$</math-renderer>.</li>
<li>Constraints on physical groups (nodes on points, edges, surfaces and volumes).</li>
<li>Applying initial conditions on arbitrary points, edges, surfaces, volumes and on combinations of them.</li>
<li>Solution of static and dynamic (transient with central difference method) problems,</li>
<li>which means the generations of the mass matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\mathbf{M}$</math-renderer>.</li>
<li>Displaying the results (scalar or vector displacements, scalar or tensor stresses) with <a href="https://gmsh.info" rel="nofollow">GMSH</a>.
<ul dir="auto">
<li>When dynamic problems are solved animations are also possible (click on <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b6cdf441f150c5f44417394e3e6dc35a">$\triangleright$</math-renderer>).</li>
</ul>
</li>
<li>Plotting arbitrary results on paths.</li>
</ul>
