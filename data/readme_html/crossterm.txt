<p dir="auto"><code>Crossterm</code> is a Julia library that provides rich functionality to control and manipulate terminal interfaces using the excellent <a href="https://docs.rs/crossterm/latest" rel="nofollow"><code>crossterm-rs</code></a> crate.
This includes operations like cursor movement, color and style management, and much more.</p>
