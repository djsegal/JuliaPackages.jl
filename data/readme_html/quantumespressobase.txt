<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Package features</h2><a id="user-content-package-features" class="anchor" aria-label="Permalink: Package features" href="#package-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://github.com/MineralsCloud/QuantumESPRESSOBase.jl"><code>QuantumESPRESSOBase.jl</code></a> declares
basic data types and methods for manipulating crystal structures, generating input files for
<a href="https://www.quantum-espresso.org/" rel="nofollow">Quantum ESPRESSO</a>, error checking before running, etc.
It is written purely in the language <a href="https://julialang.org/" rel="nofollow">Julia</a>.</p>
<p dir="auto">Please <a href="https://doi.org/10.1016/j.cpc.2022.108515" rel="nofollow">cite this package</a> as:</p>
<p dir="auto">Q. Zhang, C. Gu, J. Zhuang et al., <code>express</code>: extensible, high-level workflows for swifter <em>ab initio</em> materials modeling, <em>Computer Physics Communications</em>, 108515, doi: <a href="https://doi.org/10.1016/j.cpc.2022.108515" rel="nofollow">https://doi.org/10.1016/j.cpc.2022.108515</a>.</p>
