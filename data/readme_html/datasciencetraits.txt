<p dir="auto">This package provides an alternative implementation to
<a href="https://github.com/JuliaAI/ScientificTypes.jl">ScientificTypes.jl</a>
that is lightweight, with a more sensible set of defaults for data science.
See <a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="1087878089" data-permission-text="Title is private" data-url="https://github.com/JuliaAI/ScientificTypes.jl/issues/180" data-hovercard-type="issue" data-hovercard-url="/JuliaAI/ScientificTypes.jl/issues/180/hovercard" href="https://github.com/JuliaAI/ScientificTypes.jl/issues/180">JuliaAI/ScientificTypes.jl#180</a>.</p>

<p dir="auto">This package is intended for developers of statistical packages
that need to dispatch different algorithms depending on scientific
types:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import DataScienceTraits as DST

reduction(::DST.Continuous) = sum
reduction(::DST.Categorical) = first"><pre><span class="pl-k">import</span> DataScienceTraits as DST

<span class="pl-en">reduction</span>(<span class="pl-k">::</span><span class="pl-c1">DST.Continuous</span>) <span class="pl-k">=</span> sum
<span class="pl-en">reduction</span>(<span class="pl-k">::</span><span class="pl-c1">DST.Categorical</span>) <span class="pl-k">=</span> first</pre></div>
<p dir="auto">Extensions are provided for third-party types such as CoDa.jl
and CategoricalArrays.jl in order to facilitate the integration
with existing software stacks.</p>
