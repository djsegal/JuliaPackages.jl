<p dir="auto">This project represents a set of Julia (<a href="https://julialang.org/" rel="nofollow">https://julialang.org/</a>) bindings to libRoadRunner (<a href="http://libroadrunner.org/" rel="nofollow">http://libroadrunner.org/</a>). libRoadrunner is a SBML compliant high performance and simulation engine for systems and synthetic biology. This RoadRunner.jl package supports SBML and Antimony (<a href="http://antimony.sourceforge.net/" rel="nofollow">http://antimony.sourceforge.net/</a>) files as input.</p>
<p dir="auto"><em><strong>Note that RoadRunner.jl is only applicable on Windows and Linux, so users cannot run it on Mac until an update in the future</strong></em>.</p>
