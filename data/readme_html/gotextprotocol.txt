<p dir="auto">This Julia package implements a subset of the <a href="https://www.lysator.liu.se/~gunnar/gtp/gtp2-spec-draft2/gtp2-spec.html" rel="nofollow">Go Text Protocol (GTP), version 2</a>, as well as keeping track of the Go board (captures, etc). (Here, "Go" refers to the <a href="https://en.wikipedia.org/wiki/Go_(game)" rel="nofollow">board game</a>, not the programming language.)</p>
<p dir="auto">If a Go playing engine is written in Julia, then this package should make it easy to connect it to any <a href="https://senseis.xmp.net/?GoClient" rel="nofollow">Go client</a> that speaks the GTP protocol. That will allow it to play humans or other engines via a GUI or over the internet.</p>

<p dir="auto">All that is needed to create a Go playing engine is to write a function <code>genmove(board, color, info)</code> that decides which move to make, given the <code>board</code> state and <code>color</code> to play (and some additional <code>info</code> like komi and time left.) This function is then passed to the <code>GoTextProtocol.gtp_repl</code> function, which implements the GTP protocol. This REPL can be used directly from the terminal (for testing), but most commonly it will be accessed by a Go client that provides a more friendly user interface.</p>
<p dir="auto">The file <a href="./example_engine.jl">example_engine.jl</a> demonstrates how to write a Julia script that can be used by a Go client. The Go client will typically have an "Add Go engine" option in the settings, where the path to this script can be entered.</p>

<ul dir="auto">
<li>The aim of this package is not to provide a Go playing engine. The example script is barely better than random play!</li>
<li>I have only tested this with a single Go client so far. Please file an issue if you encounter problems.</li>
<li>At the moment, only the bare minimum of GTP commands are supported. PRs are welcome!</li>
</ul>
