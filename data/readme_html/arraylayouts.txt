<p dir="auto">This package implements a trait-based framework for describing array layouts such as column
major, row major, etc. that can be dispatched to appropriate BLAS or optimised Julia linear
algebra routines. This supports a much wider class of matrix types than Julia's in-built
<code>StridedArray</code>. Here is an example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using ArrayLayouts, LinearAlgebra

julia&gt; A = randn(10_000,10_000); x = randn(10_000); y = similar(x);

julia&gt; V = view(Symmetric(A),:,:)';

julia&gt; @time mul!(y, A, x); # Julia does not recognize that V is symmetric
  0.040255 seconds (4 allocations: 160 bytes)

julia&gt; @time muladd!(1.0, V, x, 0.0, y); # ArrayLayouts does and is 3x faster as it calls BLAS
  0.017677 seconds (4 allocations: 160 bytes)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> ArrayLayouts, LinearAlgebra

<p dir="auto">The package is based on assigning a <code>MemoryLayout</code> to every array, which is used for
dispatch. For example,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; MemoryLayout(A) # Each column of A is column major, and columns stored in order
DenseColumnMajor()

julia&gt; MemoryLayout(view(A, 1:3,:))  # Each column of A is column major
ColumnMajor()

julia&gt; MemoryLayout(V) # A symmetric version, whose storage is DenseColumnMajor
SymmetricLayout{DenseColumnMajor}()"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">MemoryLayout</span>(A) <span class="pl-c"><span class="pl-c">#</span> Each column of A is column major, and columns stored in order</span>
<span class="pl-c1">DenseColumnMajor</span>()

julia<span class="pl-k">&gt;</span> <span class="pl-c1">MemoryLayout</span>(<span class="pl-c1">view</span>(A, <span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">3</span>,:))  <span class="pl-c"><span class="pl-c">#</span> Each column of A is column major</span>
<span class="pl-c1">ColumnMajor</span>()

julia<span class="pl-k">&gt;</span> <span class="pl-c1">MemoryLayout</span>(V) <span class="pl-c"><span class="pl-c">#</span> A symmetric version, whose storage is DenseColumnMajor</span>
<span class="pl-c1">SymmetricLayout</span><span class="pl-c1">{DenseColumnMajor}</span>()</pre></div>
<p dir="auto">This is then used by <code>muladd!(α, A, B, β, C)</code>, <code>ArrayLayouts.lmul!(A, B)</code>, and
<code>ArrayLayouts.rmul!(A, B)</code> to lower to the correct BLAS calls via lazy objects
<code>MulAdd(α, A, B, β, C)</code>, <code>Lmul(A, B)</code>, <code>Rmul(A, B)</code> which are materialized, in analogy to
<code>Base.Broadcasted</code>.</p>
<p dir="auto">Note there is also a higher level function <code>mul(A, B)</code> that materializes via <code>Mul(A, B)</code>,
which uses the layout of <code>A</code> and <code>B</code> to further reduce to either <code>MulAdd</code>, <code>Lmul</code>, and
<code>Rmul</code>.</p>
