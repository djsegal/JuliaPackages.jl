<p dir="auto">Show and edit arbitrary Julia objects in a tabular interface. Based on <code>Pluto</code> and <code>PlutoUI</code> for interactivity, <code>Accessors</code> and <code>AccessorsExtra</code> for object modification.</p>
<p dir="auto">Currently, the focus is specifically on tabular UIs for editing objects. <br>
For a basic example, this code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@bind obj ColumnInput(((a=1, b=2), (a=3, b=4), (a=5, b=6)), (
	(@o _[∗].a) =&gt; Slider(0:5, show_value=true),
	(@o _[∗].b) =&gt; Slider(0:15, show_value=true),
))"><pre><span class="pl-c1">@bind</span> obj <span class="pl-c1">ColumnInput</span>(((a<span class="pl-k">=</span><span class="pl-c1">1</span>, b<span class="pl-k">=</span><span class="pl-c1">2</span>), (a<span class="pl-k">=</span><span class="pl-c1">3</span>, b<span class="pl-k">=</span><span class="pl-c1">4</span>), (a<span class="pl-k">=</span><span class="pl-c1">5</span>, b<span class="pl-k">=</span><span class="pl-c1">6</span>)), (
	(<span class="pl-c1">@o</span> _[<span class="pl-k">∗</span>]<span class="pl-k">.</span>a) <span class="pl-k">=&gt;</span> <span class="pl-c1">Slider</span>(<span class="pl-c1">0</span><span class="pl-k">:</span><span class="pl-c1">5</span>, show_value<span class="pl-k">=</span><span class="pl-c1">true</span>),
	(<span class="pl-c1">@o</span> _[<span class="pl-k">∗</span>]<span class="pl-k">.</span>b) <span class="pl-k">=&gt;</span> <span class="pl-c1">Slider</span>(<span class="pl-c1">0</span><span class="pl-k">:</span><span class="pl-c1">15</span>, show_value<span class="pl-k">=</span><span class="pl-c1">true</span>),
))</pre></div>
