<p dir="auto">The following example arises from elastic net regression and smoothing problems. In these cases, the integration constants are not available analytically.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Define function to be sampled
function f(x, μ, λ1, λ2)
      δ = x - μ
      nl = λ1 * abs(δ) + λ2 * δ^2
      return exp(-nl)
end
support = (-Inf, Inf)

# Build the sampler and simulate 10,000 samples
μ, λ1, λ2 = 0.0, 2.0, 1.0
sampler = RejectionSampler(x -&gt; f(x, μ, λ1, λ2), support, max_segments = 5)
@time sim = run_sampler!(sampler, 10000);

# Plot the results and compare to target distribution
x = range(-2.3, 2.3, length=100)
envelop = [eval_envelop(sampler.envelop, xi) for xi in x]

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Tips for numerical stability, use of logdensity</h3><a id="user-content-tips-for-numerical-stability-use-of-logdensity" class="anchor" aria-label="Permalink: Tips for numerical stability, use of logdensity" href="#tips-for-numerical-stability-use-of-logdensity"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Here are some tips:</p>
<ul dir="auto">
<li>Make sure the logdensity is numerically stable in the domain and avoid logdensity values &gt; 25 (since
the evaluation of the envelop requires exponentials);</li>
<li>Use log densities instead of densities using the keyword <code>logdensity=true</code>;</li>
<li>Specify a <code>min_slope</code> and <code>max_slope</code> to find better initial points. The default is 1e-6 and 1e6, respectively.
The <code>min_slope</code> is the minimum slope of the logdensity in the initial points  of the envelop in absolute value. In general,
it is a good idea to leave <code>min_slope</code> with the default and try <code>max_slope=10.0</code> or a smaller number.</li>
<li>Try setting <code>δ</code> to a smaller value in the search_grid. The default is 0.5.</li>
</ul>
<p dir="auto"><g-emoji class="g-emoji" alias="warning">⚠️</g-emoji> <em>Warning</em> <g-emoji class="g-emoji" alias="warning">⚠️</g-emoji>: Using <code>logdensity=true</code> will be the default in v1.0.</p>
