<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>filtermap</code></h2><a id="user-content-filtermap" class="anchor" aria-label="Permalink: filtermap" href="#filtermap"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>filtermap(f, X)</code>: map and filter a collection in one go.
Most useful when the mapped function shares some computations with the filter predicate.</p>
<p dir="auto">Returns same as <code>map(f, X)</code>, dropping elements where <code>f(x)</code> is <code>nothing</code>.
Return <code>Some(nothing)</code> from <code>f</code> to keep <code>nothing</code> in the result.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>flatmap</code>/<code>flatten</code></h2><a id="user-content-flatmapflatten" class="anchor" aria-label="Permalink: flatmap/flatten" href="#flatmapflatten"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">These functions are similar to <code>Iterators.flatmap</code> and <code>Iterators.flatten</code>, but operate on arrays in a more performant and generic manner.</p>
<p dir="auto"><code>flatmap(f, X)</code>: apply <code>f</code> to all elements of <code>X</code> and flatten the result by concatenating all <code>f(x)</code> collections.</p>
<p dir="auto"><code>flatmap(fₒᵤₜ, fᵢₙ, X)</code>: apply <code>fₒᵤₜ</code> to all elements of <code>X</code>, and apply <code>fᵢₙ</code> to the results. Basically, <code>[fᵢₙ(x, y) for x in X for y in fₒᵤₜ(x)]</code>.</p>
<p dir="auto"><code>flatmap(f, X)</code> is similar to <code>mapreduce(f, vcat, X)</code> and <code>SplitApplyCombine.mapmany(f, A)</code>, but more efficient and generic.</p>
<p dir="auto">Defining differences include:</p>
<ul dir="auto">
<li>better result type inference</li>
<li>keeps array types, eg <code>StructArray</code></li>
<li>works with empty collections</li>
<li>supports arbitrary iterators, not only arrays</li>
</ul>
<p dir="auto"><em>Analogous to <code>flat_map</code> in Rust, and <code>SelectMany</code> in C#</em></p>
<p dir="auto"><code>flatten(X)</code>: flatten a collection of collections by concatenating all elements, equivalent to <code>flatmap(identity, X)</code>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>mapview</code> (lazy <code>map</code>)</h2><a id="user-content-mapview-lazy-map" class="anchor" aria-label="Permalink: mapview (lazy map)" href="#mapview-lazy-map"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>mapview(f, X)</code>:</p>
<ul dir="auto">
<li>like <code>map(f, X)</code>, but works lazily, doesn't materialize the result returning a view instead.</li>
<li>like <code>Iterators.map(f, X)</code>, but with better collection support, type stability, etc.</li>
</ul>
<p dir="auto">Works on different collections and arbitrary iterables. Collection types are preserved when possible for ranges, arrays, dictionaires. Passes <code>length</code>, <code>keys</code> and others directly to the parent. Does its best to determine the resulting <code>eltype</code> without evaluating <code>f</code>. Supports both getting and setting values (through <code>Accessors.jl</code>).</p>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto"><code>maprange</code></h1><a id="user-content-maprange" class="anchor" aria-label="Permalink: maprange" href="#maprange"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>maprange(f, start, stop; length)</code>: <code>length</code> values between <code>start</code> and <code>stop</code>, so that <code>f(x)</code> is incremented in uniform steps. Uses <code>mapview</code> in order not to materialize the array.</p>
<p dir="auto"><code>maprange(identity, ...)</code> is equivalent to <code>range(...)</code>. Most common application - log-spaced ranges:</p>
<p dir="auto"><code>maprange(log, 10, 1000, length=5) ≈ [10, 31.6227766, 100, 316.227766, 1000]</code></p>
<p dir="auto">Other transformations can also be useful:</p>
<p dir="auto"><code>maprange(sqrt, 16, 1024, length=5) == [16, 121, 324, 625, 1024]</code></p>
