<p dir="auto">Jlyfish is a package for Julia and Typst that allows you to integrate Julia
computations in your Typst document.</p>

<p dir="auto">You should use Jlyfish if you want to write a Typst document and have some of
the content automatically produced by Julia code but want the source code for
that within your document source.
It fills a similar role as <a href="https://github.com/gpoore/pythontex">PythonTeX</a>
does for Python and LaTeX.
Note that this is different from tools like <a href="https://quarto.org/" rel="nofollow">Quarto</a> where
you write documents in Markdown, also integrate some Julia code, but then might
use Typst only as a backend to produce the final document.</p>
<p dir="auto">See below for a quick introduction or read the
<a href="https://github.com/andreasKroepelin/TypstJlyfish.jl/wiki">wiki</a> for an in depth
explanation.</p>

<p dir="auto">Since Jlyfish builds a bridge between Julia and Typst, we also have to get two
things running.
First, install the Julia package <code>TypstJlyfish</code> from the general registry by
executing</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ]

(@v1.10) pkg&gt; add TypstJlyfish"><pre>julia&gt; ]

(@v1.10) pkg&gt; add TypstJlyfish</pre></div>
<p dir="auto">You only have to do this once.
(It is like installing and using the Pluto notebook system, if you are familiar
with that.)</p>
<p dir="auto">When you want to use Jlyfish in a Typst document (say, <code>your-document.typ</code>),
add the following line at the top:</p>
<div class="highlight highlight-source-typst notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="#import &quot;@preview/jlyfish:0.1.0&quot;: *"><pre><span class="pl-k">#import</span> <span class="pl-s"><span class="pl-pds">"</span>@preview/jlyfish:0.1.0<span class="pl-pds">"</span></span>: *</pre></div>
<p dir="auto">Then, open a Julia REPL and run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import TypstJlyfish

julia&gt; TypstJlyfish.watch(&quot;your-document.typ&quot;)"><pre>julia&gt; <span class="pl-k">import</span> TypstJlyfish

julia&gt; TypstJlyfish<span class="pl-k">.</span><span class="pl-c1">watch</span>(<span class="pl-s"><span class="pl-pds">"</span>your-document.typ<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Jlyfish facilitates the communication between Julia and Typst via a JSON file.
By default, Jlyfish uses the name of your document and adds a <code>-jlyfish.json</code>,
so <code>your-document.typ</code> would become <code>your-document-jlyfish.json</code>.
This can be configured, of course.</p>
<p dir="auto">To let Typst know of the computed data in the JSON file, add the following line
to your document:</p>
<div class="highlight highlight-source-typst notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="#read-julia-output(json(&quot;your-document-jlyfish.json&quot;))"><pre><span class="pl-en">#read-julia-output</span>(json("your-document-jlyfish.json"))</pre></div>
<p dir="auto">You can then place some Julia code in your Typst source using the <code>#jl</code>
function:</p>
<div class="highlight highlight-source-typst notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="What is the sum of the whole numbers from one to a hundred? #jl(`sum(1:100)`)"><pre>What is the sum of the whole numbers from one to a hundred? <span class="pl-en">#jl</span>(<span class="pl-c1">`sum(1:100)`</span>)</pre></div>
<p dir="auto">Head over to the <a href="https://github.com/andreasKroepelin/TypstJlyfish.jl/wiki">wiki</a>
to learn more!</p>
