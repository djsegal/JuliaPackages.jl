<p dir="auto">SummationByParts is a <a href="http://julialang.org" rel="nofollow">Julia</a> package that implements summation-by-parts (SBP) operators, which can be used to construct stable, high-order discretizations of partial differential equations.  SBP operators are finite-difference operators, but they share much in common with finite-element operators. For more information about SBP methods, the following reviews are a great place to start:</p>
<ul dir="auto">
<li>M. Svärd and Jan Nordström, <a href="http://dx.doi.org/10.1016/j.jcp.2014.02.031" rel="nofollow">"Review of summation-by-parts schemes for initial–boundary-value problems,"</a> <em>Journal of Computational Physics</em>, July, 2014.<br><br></li>
<li>D. Del Rey Fernández, J. Hicken, and D. Zingg, <a href="http://dx.doi.org/10.1016/j.compfluid.2014.02.016" rel="nofollow">"Review of summation-by-parts operators with simultaneous approximation terms for the numerical solution of partial differential equations,"</a> <em>Computers &amp; Fluids</em>, May, 2014.<br><br></li>
</ul>
<p dir="auto">This package focuses on multidimensional SBP operators for the triangle and tetrahedral.  For the theory behind multidimensional SBP operators please see</p>
<ul dir="auto">
<li>J. Hicken, D. Del Rey Fernández, and D. Zingg, <a href="http://dx.doi.org/10.1137/15m1038360" rel="nofollow">"Multidimensional Summation-by-Parts Operators: General Theory and Application to Simplex Elements,"</a> <em>SIAM Journal on Scientific Computing</em>, July 06, 2016.<br><br></li>
<li>D. Del Rey Fernández, J. Hicken, and D. Zingg, <a href="https://doi.org/10.1007/s10915-017-0523-7" rel="nofollow">"Simultaneous Approximation Terms for Multi-dimensional Summation-by-Parts Operators,"</a> <em>Journal of Scientific Computing</em>, 2018.<br><br></li>
</ul>
<p dir="auto">SummationByParts also provides functionality to construct high-order symmetric quadrature rules with positive weights on simplices. For details on construction of such quadrature rules, please see:</p>
<ul dir="auto">
<li>Z. Worku, J. Hicken, D. Zingg, <a href="https://arxiv.org/abs/2311.15576" rel="nofollow">"Quadrature Rules on Triangles and Tetrahedra for Multidimensional Summation-By-Parts Operators,"</a> <em>Submitted to Journal of Scientific Computing</em>, 2024.<br><br></li>
</ul>

<p dir="auto">The SBP operators are parametrized; hence, one can specify the their type as examplified by the use of <code>Float64</code>.  This means that the matrix fields inside the <code>sbp</code> type are <code>Float64</code> arrarys.</p>
<p dir="auto">In general, we recommend using the SBP operators with methods provided by the package and that users <em>do not</em> rely on the fields of the sbp type directly.  This is because we may, in the future, change the fields to support different SBP operators (or some fields may become obsolete).  Nevertheless, for those who are curious, here is a partial list of the most important fields.</p>
<ul dir="auto">
<li><code>sbp.degree</code> : maximum polynomial degree for which the derivatives are exact</li>
<li><code>sbp.numnodes</code> : number of nodes for the operator</li>
<li><code>sbp.vtx</code> : vertices of the reference element in computational space</li>
<li><code>sbp.w</code> : cubature weights, i.e. the diagonal SBP norm, stored as an array</li>
<li><code>sbp.Q[:,:,i]</code> : discrete stiffness matrix operator in ith coordinate</li>
</ul>
