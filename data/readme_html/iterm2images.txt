<p dir="auto">This is a Julia package to display graphics inline on terminals that
support <a href="https://iterm2.com/documentation-images.html" rel="nofollow">iTerm2</a> inline
graphics. This is similar to
<a href="https://github.com/eschnett/SixelTerm.jl">SixelTerm.jl</a> but is
optimized for <a href="https://iterm2.com" rel="nofollow">iTerm2</a> terminals.</p>
<p dir="auto">The main advantage of this approach is having usable graphics on
remote connections without having to mess with X or other remote
display connections. This works for Julia running on many remote
platforms. It also supports the <a href="tmux.github.io">tmux</a> terminal
multiplexer.</p>

<p dir="auto">Note that when using it with Plots, you have to do <code>using ITerm2Images</code> after <code>using Plots</code>.
For some reason, Plots.jl adds its own display to the stack, so we need the ITerm2Images
display added last.</p>
