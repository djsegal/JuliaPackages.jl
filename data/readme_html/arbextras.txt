<p dir="auto">This package extends <a href="https://github.com/kalmarek/Arblib.jl">Arblib</a>
with some methods for enclosing roots, enclosing extrema and computing
integrals.</p>
<p dir="auto">The package started development during my PhD with the goal to give
reusable implementations of algorithms that were used in my research.
The type of methods that are implemented and which type of input they
are optimized for has been heavily influenced by the projects that I
worked on during that time.</p>

<p dir="auto">The main functionality provided by the package are methods for
isolating roots and enclosing extrema of univariate real functions. In
addition to this is provides a rudimentary integral routine and a few
minor things.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Enclosing roots</h3><a id="user-content-enclosing-roots" class="anchor" aria-label="Permalink: Enclosing roots" href="#enclosing-roots"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package provides three different functions for isolating and
enclosing roots of univariate, real valued functions:</p>
<ul dir="auto">
<li><code>isolate_roots(f, a::Arf, b::Arf)</code> is used for isolating all roots
of a function <code>f</code> on the interval <code>[a, b]</code>.</li>
<li><code>refine_root(f, root::Arb)</code> is used for refining an initial
enclosure <code>root</code> of a zero to <code>f</code>. It makes use of the interval
Newton method.</li>
<li><code>refine_root_bisection(f, a, b)</code> is used for refining an initial
enclosure <code>[a, b]</code> of a root of <code>f</code>. It requires that <code>f(a)</code> and
<code>f(b)</code> have different signs. It makes use if bisection, checking the
sign of the midpoint in each iteration.</li>
</ul>
<p dir="auto">See the documentation of the respective methods for more details, in
particular the available keyword arguments. The first two methods
require access to the derivative of <code>f</code>, this is computed using
<code>ArbSeries</code> and for that reason <code>f</code> needs to support evaluation of
both <code>Arb</code> and <code>ArbSeries</code>. The <code>refine_root_bisection</code> doesn't
require access to the derivative and can therefore be used when this
is not available.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Enclosing extrema</h3><a id="user-content-enclosing-extrema" class="anchor" aria-label="Permalink: Enclosing extrema" href="#enclosing-extrema"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package provides three families of methods:</p>
<ul dir="auto">
<li><code>extrema_polynomial</code>, <code>minimum_polynomial</code> and <code>maximum_polynomial</code></li>
<li><code>extrema_series</code>, <code>minimum_series</code> and <code>maximum_series</code></li>
<li><code>extrema_enclosure</code>, <code>minimum_enclosure</code> and <code>maximum_enclosure</code></li>
</ul>
<p dir="auto">As indicated by the names they compute either the minimum, the maximum
or both.</p>
<ul dir="auto">
<li><code>extrema_polynomial(p::ArbPoly, a::Arf, b::Arb)</code> is used for
enclosing the extrema of a polynomial <code>p</code> on the interval <code>[a, b]</code>.
This is done by enclosing the roots of the derivative of <code>p</code>.</li>
<li><code>extrema_series(f, a::Arf, b::Arb; degree::Integer = 8)</code> is used for
enclosing the extrema of a function <code>f</code> on the interval <code>[a, b]</code>.
This is done by computing a Taylor series of the given degree. The
extrema of the series is computed using <code>extrema_polynomial</code> and
then an enclosure of the remainder term is added.</li>
<li><code>extrema_enclosure(f, a::Arf, b::Arb)</code> is also
used for enclosing the extrema of a function <code>f</code> on the interval
<code>[a, b]</code>. In this case it is done by iteratively bisecting the
interval and using <code>extrema_series</code> on each subinterval. The
bisection is continued until the result satisfies the required
tolerance.</li>
</ul>
<p dir="auto">See the documentation of the respective methods for more details, in
particular the available keyword arguments. The <code>minimum_</code> and
<code>maximum_</code> versions have the same interface, the only difference being
that they return either the minimum or maximum instead of both.</p>
<p dir="auto">For <code>enclosure_series</code> it is also possible to call it like
<code>enclosure_series(f, x::Arb)</code>, in which case it computes an enclosure
of <code>f(x)</code> by computing the extrema and taking the union of them.</p>
<p dir="auto">The package also provides <code>bounded_by(f, a::Arf, b::Arf, C::Arf)</code>
which checks if the function <code>f</code> is bounded by <code>C</code> on the interval
<code>[a, b]</code>. It is similar to <code>maximum_enclosure</code> but only bisects enough
to be able to check that it is bounded by <code>C</code>. See also the
<code>ubound_tol</code> and <code>lbound_tol</code> arguments to <code>extrema_enclosure</code>.</p>

<p dir="auto">In addition to the above the package also provides some smaller
things:</p>
<ul dir="auto">
<li><code>integrate(f, a::Arb, b::Arb)</code> can be used to compute the integral
of <code>f</code> from <code>a</code> to <code>b</code> using a Gauss-Legendre quadrature of order 2,
combined with bisection. In general the integrator from Arb,
<code>Arblib.integrate</code> performs much better and should be preferred.
This method does however have the benefit that it does not require
evaluation on complex balls, instead it needs access to the fourth
derivative of <code>f</code>, which is computed using <code>ArbSeries</code>. So it can be
of use if there is no implementation of <code>f(::Acb)</code>, but there is one
for <code>f(::ArbSeries)</code>.</li>
<li><code>SpecialFunctions.besselj(ν::Arb, z::ArbSeries)</code> and
<code>SpecialFunctions.bessely(ν::Arb, z::ArbSeries)</code> for computing
Taylor expansions of the Bessel functions.</li>
<li>Utility functions which are mainly for internal use, but could
be useful in other cases as well , see their documentation for
details.
<ul dir="auto">
<li><code>bisect_interval</code>, <code>bisect_interval_recursive</code> and <code>bisect_intervals</code></li>
<li><code>check_tolerance</code></li>
<li><code>check_interval</code></li>
<li><code>format_interval</code></li>
<li><code>taylor_remainder</code></li>
<li><code>enclosure_ubound</code>, <code>enclosure_lbound</code> and <code>enclosure_getinterval</code></li>
<li><code>derivative_function</code></li>
</ul>
</li>
<li>Some "temporary" functions that should possibly be added to
Arblib.jl or even the Arb library itself in the future
<ul dir="auto">
<li><code>iscpx</code></li>
<li><code>compose_zero</code> and <code>compose_zero!</code></li>
</ul>
</li>
</ul>
