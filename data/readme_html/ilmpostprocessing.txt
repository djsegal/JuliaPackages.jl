<p dir="auto">This package contains tools that can be used to post-process and analyze the solutions of partial differential equations computed with the <a href="https://github.com/JuliaIBPM/ImmersedLayers.jl">ImmersedLayers.jl</a> package. Currently implemented methods are</p>
<ul dir="auto">
<li>proper orthogonal decomposition (POD)</li>
<li>dynamic mode decomposition (DMD)</li>
</ul>
<p dir="auto">The examples in the documentation, which have companion notebooks in the <code>examples</code> folder, are the best way to get started.</p>
