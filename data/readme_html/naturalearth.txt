<p dir="auto">This package provides a Julia interface to the <a href="http://www.naturalearthdata.com/" rel="nofollow">Natural Earth</a> dataset. The Natural Earth dataset is a public domain map dataset available at 1:10m, 1:50m, and 1:110 million scales. It is ideal for small-scale thematic mapping and for creating static maps and illustrations.</p>
<p dir="auto">Currently, this package provides a single function, <code>naturalearth</code>, which fetches any <code>.geojson</code> file from <a href="https://github.com/nvkelso/natural-earth-vector/tree/master/geojson">this</a> repository. The function returns a <code>GeoJSON.FeatureCollection</code> object.</p>
<p dir="auto">The data is downloaded on demand and cached using Julia's scratch space system. This means that the first time you fetch a dataset, it will take a while to download, and you will need an internet connection. Subsequent calls will be much faster, even in a new session.</p>

<p dir="auto">You can install the Natural Earth package through the Julia package manager: <code>using Pkg; Pkg.add("NaturalEarth")</code>.  The main entry point is the <code>naturalearth(dataset, [scale])</code> function which returns a <code>GeoJSON.FeatureCollection</code> from <a href="https://github.com/JuliaGeo/GeoJSON.jl">GeoJSON.jl</a>.</p>
