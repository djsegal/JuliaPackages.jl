<p dir="auto">The aim of this package is to standardize common assumptions on and functions
for groups, i.e. to create Group interface. Packages using it include:</p>
<ul dir="auto">
<li><a href="https://github.com/kalmarek/PermutationGroups.jl">PermutationGroups.jl</a></li>
<li><a href="https://github.com/kalmarek/Groups.jl">Groups.jl</a>,</li>
<li><a href="https://github.com/kalmarek/SymbolicWedderburn.jl">SymbolicWedderburn.jl</a>,</li>
</ul>
<p dir="auto">The <a href="https://github.com/oscar-system/Oscar.jl"><code>Oscar.jl</code></a> project no longer
supports <code>GroupsCore.jl</code> interface at version <code>0.5</code>.</p>
