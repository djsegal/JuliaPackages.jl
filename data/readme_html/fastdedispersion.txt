<div align="justify" dir="auto">
<p dir="auto">This package implements the <strong>fast DM transform</strong> (<strong>FDMT</strong>), as described in <a href="https://iopscience.iop.org/article/10.3847/1538-4357/835/1/11" rel="nofollow"><strong>Zackay and Ofek (2014)</strong></a>, in pure Julia. I follow the implementation as laid out in <a href="https://bitbucket.org/vmorello/pyfdmt" rel="nofollow"><strong><code>pyfdmt</code></strong></a>, written by <a href="https://github.com/v-morello"><strong>Vincent Morello</strong></a>, which implements the FDMT in Python using recursion. This approach is different from the pseudocode provided in the original paper, and the code in MATLAB/Python provided by the original authors, which use nested loops.</p>
<p dir="auto">Install it by typing and running:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="] add FastDedispersion"><pre>] add FastDedispersion</pre></div>
<p dir="auto">in the Julia REPL.</p>
<p dir="auto">Here is an example of the DM transform, obtained via <code>FastDedispersion.jl</code>, from 30 seconds of simulated FRB data. The FRB has a DM of 1000 pc cm <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9ddcf754c8952d946ebffff04d67b573">$^{-3}$</math-renderer>, and an arrival time of 5 seconds, and was dedispersed from 900 to 1100 pc cm <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9ddcf754c8952d946ebffff04d67b573">$^{-3}$</math-renderer>. Note that the plot is zoomed-in, so that we may easily see the expected bow-tie pattern:</p>
<br>

<p dir="auto">The simulation was carried out using the <a href="https://bitbucket.csiro.au/projects/PSRSOFT/repos/simulatesearch/browse" rel="nofollow"><strong><code>simulateSearch</code></strong></a> library. The corresponding data file, in the SIGPROC filterbank format, is included in this package as a part of its testing suite <a href="./test/data/frb.fil"><strong>here</strong></a>.</p>
