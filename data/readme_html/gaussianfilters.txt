<p dir="auto">GaussianFilters implements methods to define and run <strong>Kalman</strong>, <strong>Extended Kalman</strong>, <strong>Unscented Kalman</strong>, and <strong>Gaussian-Mixture Probability Hypothesis Density</strong> Filters on simulated data. It also implements simulation functions for the Kalman-class filters.</p>

<p dir="auto">Basic usage follows along defining appropriate models, constructing an appropriate filter, and running the filter with known actions on some measurement data.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GaussianFilters, LinearAlgebra

A = [1 0.1; 0 1]
B = [0; 1]
W = [0.5 0; 0 0.5]
dmodel = LinearDynamicsModel(A, B, W)

# measurement model
measure(x, u) = LinearAlgebra.norm(x, 2)
V = [0.01]
omodel = NonlinearObservationModel(measure, V)

# filtering given some action and measurement
ukf = UnscentedKalmanFilter(dmodel, omodel)

b0 = GaussianBelief([0, 0], [1 0; 0 1])
b1 = update(ukf, b0, action, measurement)"><pre><span class="pl-k">using</span> GaussianFilters, LinearAlgebra
