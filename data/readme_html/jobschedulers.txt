<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Why JobScheduler?</h2><a id="user-content-why-jobscheduler" class="anchor" aria-label="Permalink: Why JobScheduler?" href="#why-jobscheduler"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We may find different tasks or programs use different CPU and memory. Some can run simultaneously, but some have to run sequentially. JobScheduler is stable, useful and powerful for task queuing and workload management, inspired by Slurm/PBS and Crontab.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Package Features</h2><a id="user-content-package-features" class="anchor" aria-label="Permalink: Package Features" href="#package-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Job and task scheduler.</p>
</li>
<li>
<p dir="auto">Local workload manager.</p>
</li>
<li>
<p dir="auto">Support CPU, memory, run time management.</p>
</li>
<li>
<p dir="auto">Support running a job at specific time, or a period after creating (schedule).</p>
</li>
<li>
<p dir="auto">Support recurring/repetitive jobs using <strong>Cron</strong>-like schedule expressions.</p>
</li>
<li>
<p dir="auto">Support deferring a job until specific jobs reach specific states (dependency).</p>
</li>
<li>
<p dir="auto">Support automatic backup and reload.</p>
</li>
<li>
<p dir="auto">Fancy progress meter in terminal.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/assets/progress_meter.png"><img src="docs/src/assets/progress_meter.png" alt="progress meter" style="max-width: 100%;"></a></p>
</li>
</ul>
