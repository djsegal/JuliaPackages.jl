<p dir="auto">Central differencing scheme is defined as</p>
<p dir="auto">$$
\left(\frac{\partial u}{\partial x}\right)<em>{i, j}=\frac{1}{2 \Delta x}\left(u</em>{i+1, j}-u_{i-1, j}\right)+O(\Delta x)
$$</p>

<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Poisson equation</h4><a id="user-content-poisson-equation" class="anchor" aria-label="Permalink: Poisson equation" href="#poisson-equation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="875ae235659ba81a965d1e93a668af73">$$\Delta u = f$$</math-renderer></p>
<p dir="auto">can be discretized to</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="875ae235659ba81a965d1e93a668af73">$$\frac{u_{i+1}-2 u_{i}+u_{i-1}}{\Delta x^{2}}=f_{i}, i = 1, 2, \cdots, N$$</math-renderer></p>
<p dir="auto">In Dirichlet boundary conditions,</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="875ae235659ba81a965d1e93a668af73">$$
\frac{1}{\Delta x^2} \begin{pmatrix}
-2 &amp;      1 &amp;      0 &amp; \cdots &amp; \cdots &amp;      0 \\
1 &amp;     -2 &amp;      1 &amp;      0 &amp; \cdots &amp; \vdots \\
0 &amp;      1 &amp;     -2 &amp;      1 &amp; \cdots &amp; \vdots \\
\vdots &amp; \ddots &amp; \ddots &amp; \ddots &amp; \ddots &amp; \vdots \\
\vdots &amp; \ddots &amp;      1 &amp;     -2 &amp;      1 &amp;      0 \\
\vdots &amp; \ddots &amp;      0 &amp;      1 &amp;     -2 &amp;      1 \\
0 &amp; \cdots &amp; \cdots &amp;      0 &amp;      1 &amp;     -2
\end{pmatrix}
\cdot \begin{pmatrix}
u_1 \ u_2 \ \vdots \ \vdots \ \vdots \ u_{N-1} \ u_N
\end{pmatrix}
= \begin{pmatrix}
f_1 \ f_2 \ \vdots \ \vdots \ \vdots \ f_{N-1} \ f_N
\end{pmatrix}
$$</math-renderer></p>
<p dir="auto">The Poisson problem is converted to solving a matrix equation</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="875ae235659ba81a965d1e93a668af73">$$\mathbf{A} \cdot \mathbf{u} = \mathbf{f}$$</math-renderer></p>
<p dir="auto"><code>PhysicalFDM.jl</code> is here to provide user-friendly tools to generate <code>\mathbf{A}</code> matrix.</p>
<p dir="auto">For example, suppose we have a 1D mesh with 3 points, and for the Poisson problem we have a 2nd-order differencing operator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; A = diff_mat(3,2)
