<p dir="auto">LiftAndLearn.jl is an implementation of the Lift and Learn as well as the operator inference algorithm proposed in the papers listed in <a href="#references">References</a>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Operator Inference (OpInf)</h3><a id="user-content-operator-inference-opinf" class="anchor" aria-label="Permalink: Operator Inference (OpInf)" href="#operator-inference-opinf"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Operator Inference is a scientific machine-learning framework used in data-driven modeling of dynamical systems that aims to learn the governing equations or operators from observed data without explicit knowledge of the underlying physics or dynamics (but with some information such as the structure, e.g., linear, quadratic, bilinear, etc.). To know more about OpInf, please refer to these resources by  <a href="https://github.com/elizqian/operator-inference/tree/master">ACE Lab</a> and <a href="https://kiwi.oden.utexas.edu/research/operator-inference" rel="nofollow">Willcox Research Group</a>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Lift and Learn (LnL)</h3><a id="user-content-lift-and-learn-lnl" class="anchor" aria-label="Permalink: Lift and Learn (LnL)" href="#lift-and-learn-lnl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Lift and Learn is a physics-informed method for learning low-dimensional models for large-scale dynamical systems. Lifting refers to the transformation of the original nonlinear system to a linear, quadratic, bilinear, or polynomial system by mapping the original state space to a new space with additional auxiliary variables. After lifting the system to a more approachable form we can learn a reduced model using the OpInf approach.</p>

<li>julia versions 1.8.5 &gt;</li>
<li>We use <a href="https://github.com/jump-dev/Ipopt.jl">Ipopt</a> for the optimization (e.g., EP-OpInf)
<ul dir="auto">
<li>This requires additional proprietary linear-solvers including <code>ma86</code> and <code>ma97</code>.</li>
<li>You can run the code without it by changing the options. By default Ipopt will use <code>MUMPS</code> but we recommend you obtain and download <code>HSL_jll.jl</code>. You can find the instructions <a href="https://licences.stfc.ac.uk/product/libhsl" rel="nofollow">here</a>.</li>
</ul>
</li>
<li>As this package is designed for model reduction of large-scale models, we recommend using a high-memory machine to run the examples, ideally with more than 32GB of RAM.</li>
</ul>
