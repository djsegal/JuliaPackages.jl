<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package implements a modern version of the “No-U-turn sampler” in the Julia language, mostly as described in <a href="https://arxiv.org/abs/1701.02434" rel="nofollow">Betancourt (2017)</a>, with some tweaks.</p>
<p dir="auto">In contrast to frameworks which utilize a directed acyclic graph to build a posterior for a Bayesian model from small components, this package requires that you code a <em>log-density function</em> of the posterior in Julia. Derivatives can be provided manually, or using <a href="http://www.juliadiff.org/" rel="nofollow">automatic differentiation</a>.</p>
<p dir="auto">Consequently, this package requires that the user is comfortable with the basics of the theory of Bayesian inference, to the extent of coding a (log) posterior density in Julia. This approach allows the use of standard tools like <a href="https://docs.julialang.org/en/v1/manual/profile/" rel="nofollow">profiling</a> and <a href="https://github.com/JuliaCI/BenchmarkTools.jl">benchmarking</a> to optimize its <a href="https://docs.julialang.org/en/v1/manual/performance-tips/" rel="nofollow">performance</a>.</p>
<p dir="auto">The building blocks of the algorithm are implemented using a <em>functional</em> (non-modifying) approach whenever possible, allowing extensive unit testing of components, while at the same time also intended to serve as a transparent, pedagogical introduction to the low-level mechanics of current Hamiltonian Monte Carlo samplers, and as a platform for research into MCMC methods.</p>
<p dir="auto">Please start with the <a href="https://tamaspapp.eu/DynamicHMC.jl/dev/" rel="nofollow">documentation</a>.</p>
