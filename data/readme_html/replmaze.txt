<p dir="auto">Press <code>p</code> to turn on partial observability (i.e., can only see through a 5x5 window).</p>
<ul dir="auto">
<li><code>-</code> to decrease the partially observable window</li>
<li><code>=</code> to increase the partially observable window</li>
<li><code>o</code> to reset the partially observable window</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Controls (wasd)</h2><a id="user-content-controls-wasd" class="anchor" aria-label="Permalink: Controls (wasd)" href="#controls-wasd"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>a</code> and <code>d</code> to apply left and right velocity</li>
<li><code>s</code> to apply down velocity</li>
<li><code>w</code> to apply up velocity</li>
<li><code>backtick</code> to pause, then <code>play()</code> to resume</li>
<li><code>r</code> for a new map</li>
<li><code>p</code> to turn on <em>partial observablility</em> (window)</li>
<li><code>-</code> to decrease the partially observable window</li>
<li><code>=</code> to increase the partially observable window</li>
<li><code>o</code> to reset the partially observable window</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Other options</h2><a id="user-content-other-options" class="anchor" aria-label="Permalink: Other options" href="#other-options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>play(w=25, h=25)</code>: Change the width and height of the generated maze.</li>
<li><code>play(po=true)</code>: Start the game in partially observable mode.</li>
<li><code>play(agent="🐭", flag="🧀")</code>: Set the <code>agent</code> and <code>flag</code> icons (e.g., use <code>\:mouse:&lt;TAB&gt;</code> in the REPL).</li>
</ul>
