<p dir="auto">The ISOKANN.jl package implements the ISOKANN algorithm for the identification of macro-states of molecular systems. Its main features comprise of:</p>
<ul dir="auto">
<li>A flexible implementation of the ISOKANN core (<code>Iso</code>) (supporting 1D and N-D ISOKANN, customizable neural networks on a broad set of <code>SimulationData</code>)</li>
<li>A battery-included interfaces to OpenMM for automated adaptive sampling of molecular dynamics</li>
<li>Different adaptive sampling strategies (extapolation, kde and stratified sampling)</li>
<li>A posteriori analysis tools (plots, reaction path extraction and reaction rate estimation)</li>
</ul>
<p dir="auto">See the <a href="https://axsk.github.io/ISOKANN.jl/dev" rel="nofollow">documentation</a> for details.</p>

<p dir="auto">Install the package via <code>julia&gt; ]add https://github.com/axsk/ISOKANN.jl</code>.</p>
<p dir="auto">If you want to use Julia's built Conda.jl to automatically install OpenMM, you shoud build the package after setting the environment variable
<code>PYTHON=""</code>, e.g. through <code>ENV["PYTHON"]=""; using Pkg; Pkg.build()</code>.</p>
<p dir="auto">The usual pipeline consists of the creation of system simulation, generation of training data, training ISOKANN and a posteriori analysis of the results.</p>

# Define an OpenMMSimulation. The default molecule is the Alanine-Dipeptide.
sim = OpenMMSimulation()

# create the ISOKANN training object

# train for 100 episodes
run!(iso, 100)
