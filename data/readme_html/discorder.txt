<p dir="auto">Write <a href="https://discord.com" rel="nofollow">Discord</a> bots in <a href="https://julialang.org" rel="nofollow">Julia</a>. This package is currently the most complete and up-to-date implementation of the Discord API for Julia.</p>

<p dir="auto">The primary difference between this and other Julia Discord libraries is that it has a separate control plane that primarily works with <a href="https://discord.com/developers/docs/topics/gateway" rel="nofollow">Discord Gateway</a>. This control plane continuously monitor activities from your Discord server and publish events.</p>
<p dir="auto">Discord bots run as separate processes. You may operate multiple bots independently of each other. They all share the same events stream from the control plane.</p>

<p dir="auto">Previous attempts were great but had problem with runtime connection instabilities and difficulties in keeping up with Discord API changes. Learning from those experiences, the goals of this project includes:</p>
<ol dir="auto">
<li>Ability to update to the latest Discord API easily</li>
<li>Have a solid control plane for the gateway interface that is error-resilient and can auto-recover from connectivity problems.</li>
<li>Ability to decouple user code from the control plane, so problems with user code do not necessarily affect the operation of control plane.</li>
<li>Consistency with Discord API reference. For example, when you find <a href="https://discord.com/developers/docs/resources/channel#create-message" rel="nofollow">Create Message</a> from the Discord API documentation, you can find the equivalent <code>create_message</code> function (lowercase, snake case).</li>
<li>High-level API that makes it easy to develop and operate a Discord bot.</li>
</ol>

<p dir="auto"><a href="https://github.com/Xh4H">Xh4H</a> and <a href="https://github.com/christopher-dG">Chris de Graaf</a> previously implemented the <a href="https://github.com/Xh4H/Discord.jl">Xh4H/Discord.jl package</a>, but it was never published in the Julia registry for several reasons.</p>
<p dir="auto">Chris started a <a href="https://github.com/christopher-dG/Discord.jl">new Discord.jl project</a> in 2020 to keep things as simple as possible and minimize extra features in order to maximize maintainability as the Discord API changes. It also aims to be easily extensible, so that packages providing extra features can be written on top of it. However, Chris could not find time to continue working on the project.</p>
<p dir="auto"><a href="https://github.com/xxxAnn">@xxxAnn</a> forked Xh4H's Discord.jl package late 2021 in an attempt to update the API to the latest version. The project is called <a href="https://github.com/Humans-of-Julia/Ekztazy.jl">Ekztazy.jl</a>.</p>
<p dir="auto"><a href="https://github.com/tk3369">Tom</a> forked Chris' project in 2022 in the light of Discord's plan to decommision version 6 of their API. To avoid confusion to Xh4H and Chris' previous implementations, this package has been renamed to Discorder.jl. While this is a fork from Chris' Discord.jl package, there is no plan to upstream changes.</p>
