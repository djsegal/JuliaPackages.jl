<p dir="auto">An incomplete parser for <code>.dae</code> files. Was built to load meshes for a robot model to visualize
the model using GLMakie, and thus supports a small subset of the features of the format, enough
to load simple meshes, materials and visual scenes.</p>
<p dir="auto">Notably it does NOT support light sources, cameras, or textures, but contributions are welcome!</p>
<p dir="auto">To enable DAE loading with FileIO you must run</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using FileIO
using UUIDs
FileIO.add_format(format&quot;DAE&quot;, (), &quot;.dae&quot;, [:DigitalAssetExchangeFormatIO =&gt; UUID(&quot;43182933-f65b-495a-9e05-4d939cea427d&quot;)])"><pre class="notranslate"><code>using FileIO
using UUIDs
FileIO.add_format(format"DAE", (), ".dae", [:DigitalAssetExchangeFormatIO =&gt; UUID("43182933-f65b-495a-9e05-4d939cea427d")])
