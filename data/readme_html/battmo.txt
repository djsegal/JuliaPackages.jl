<p dir="auto">The Battery Modelling Toolbox (<strong>BattMo</strong>) is a resource for continuum modelling of electrochemical devices in MATLAB. The initial development features a pseudo X-dimensional (PXD) framework for the Doyle-Fuller-Newman model of lithium-ion battery cells. This is currently a early release that implements a subset of features from the <a href="https://github.com/BattMoTeam/BattMo">MATLAB version of BattMo</a> with improved numerical performance. <strong>BattMo.jl</strong> is based on <a href="https://github.com/sintefmath/Jutul.jl">Jutul.jl</a> and uses finite-volume discretizations and automatic differentiation to simulate models in 1D, 2D and 3D.</p>
<p dir="auto">The current implementation has two options for setting up simulation cases:</p>
<ul dir="auto">
<li>You can read in input data prepared in the MATLAB version of BattMo (general 3D grids)</li>
<li>Or you can use the common BattMo JSON format to run cases (primarily 1D grids)</li>
</ul>
