<p dir="auto">Sometimes you want to know more <i>about</i> what you’re working with, whether it be a
  function, type, value, or something else entirely.</p>
<p dir="auto">This package is a utility to help answer that question, it exports a single
  function <code>about</code>, which can be applied to any Julia object.</p>
<blockquote>
  <p dir="auto">This makes heavy use of the new <code>AnnotatedString</code> type provided in Julia 1.11.
    While it can be used with Julia 1.9 and 1.10, the package load time is
    dramatically worse.</p>
</blockquote>
