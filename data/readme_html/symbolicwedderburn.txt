<p dir="auto">Amazing package providing symbolic but explicit</p>
<ul dir="auto">
<li>decomposition of group representations into (semi-)simple representations and</li>
<li>the Wedderburn decompositions for endomorphisms of those representations.</li>
</ul>
<p dir="auto">We work with</p>
<ul dir="auto">
<li>a (linear) <strong>unitary</strong> actions of a <strong>finite group</strong> <code>G</code> on <strong>finite dimensional</strong> vector space <code>V</code> over <code>K = ℝ</code> or <code>K = ℂ</code> (i.e. a <code>KG</code>-module <code>V</code>) and</li>
<li>linear, <code>G</code>-equivariant maps (equivariant endomorphisms) <code>f : V → V</code>.</li>
</ul>
<p dir="auto">These objects are of primary inportance in the study of the representation theory for finite groups, but also naturally arise from (non)commutative polynomial optimization with group symmetry. The aim of the package is to facilitate such uses.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">A bit of theory</h2><a id="user-content-a-bit-of-theory" class="anchor" aria-label="Permalink: A bit of theory" href="#a-bit-of-theory"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">By Maschke's theorem <code>V</code> can be decomposed uniquely <code>V ≅ V₁ ⊕ ⋯ ⊕ Vᵣ</code> into isotypic/semisimple subspaces <code>Vᵢ</code> and each of <code>Vᵢ ≅ mᵢWᵢ</code> is (in a non-canonical fashion) isomorphic to a direct sum of <code>mᵢ</code> copies of irreducible/simple subspaces <code>Wᵢ</code>. By (symbolic) computation in (the group algebra) <code>KG</code>, <code>SymbolicWedderburn</code> is capable of producing the exact isomorphism <code>V ≅ V₁ ⊕ ⋯ ⊕ Vᵣ</code> in the form of a collection of projections <code>πᵢ : V → Vᵢ</code> either in the group algebra (lazy, unevaluated form), or in terms of projection matrices, when a basis for <code>V</code> is explicitly given.</p>
<p dir="auto">The isomorphism produces a decomposition of <code>End_G(V)</code> (the set of linear <code>G</code>-equivariant self-maps of <code>V</code>) in the sense of Artin-Wedderburn theorem, i.e. the projections <code>πᵢ</code> block-diagonalize <code>f ≅ f₁ ⊕ ⋯ ⊕ fᵣ</code> where <code>fᵢ : Vᵢ → Vᵢ</code>. In terms of matrices if <code>f</code> is given by <code>n×n</code>-matrix, then we can rewrite it as a block diagonal matrix with blocks of sizes <code>nᵢ×nᵢ</code> where <code>Σᵢ nᵢ = n = dim V</code> and each <code>nᵢ = mᵢ · dim Wᵢ</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Semi-definite constraints</h3><a id="user-content-semi-definite-constraints" class="anchor" aria-label="Permalink: Semi-definite constraints" href="#semi-definite-constraints"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For example, if a basis for a semi-definite constraint admits an action of a finite group, then the semi-definite matrix of a <strong>invariant solution</strong> is such an equivariant endomorphism.
In particular if <code>P</code> is a positive semidefinite constraint, when searching for an <code>G</code>-<strong>invariant</strong> solution we may replace</p>
<blockquote>
<p dir="auto"><code>0 ⪯ P[1:n, 1:n]</code></p>
</blockquote>
<p dir="auto">by a sequence of constraints</p>
<blockquote>
<p dir="auto"><code>0 ⪯ P[1:nᵢ, 1:nᵢ]</code> for <code>i = 1…r</code>,</p>
</blockquote>
<p dir="auto">greatly reducing the computational complexity: the size of the psd constraint is reduced from <code>n²</code> to <code>Σᵢ nᵢ²</code>. Such replacement can be justified if e.g. the objective is symmetric and the set of linear constraints follows a similar group-symmetric structure.</p>
<p dir="auto">If we are only interested in the <em>feasibility</em> of an optimization problem, then such replacement is always justified (i.e. an <em>invariant solution</em> is a <em>honest solution</em> which might not attain the same objective).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Rank one projection to simple components</h3><a id="user-content-rank-one-projection-to-simple-components" class="anchor" aria-label="Permalink: Rank one projection to simple components" href="#rank-one-projection-to-simple-components"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Sometimes even stronger reduction is possible when the acting group <code>G</code> is <em>sufficiently complicated</em> and we have a <em>minimal projection system</em> at our disposal (The package tries to compute such system by a heuristic algorithm. If the approach fails please open an issue!). In such case we can (often) find subsequent projections <code>Vᵢ → K^{mᵢ}</code> (depending only on the multiplicity of the irreducible, <strong>not</strong> on its dimension!). This leads to an equivalent formulation for the psd constraint with <code>nᵢ = mᵢ</code> further reducing its size.</p>
<p dir="auto">Moreover in the case of symmetric optimization problems it's possible to use the symmetry to reduce the number of linear constraints (since in that case only one constraint <strong>per orbit</strong> is needed). <code>SymbolicWedderburn</code> facilitates also this simplification.</p>

<p dir="auto">In <a href="https://arxiv.org/abs/1712.07167" rel="nofollow"><em>Aut(𝔽₅) has property (T)</em></a> we use the trick above to successfully simplify and solve a large semidefinite problem coming from sum-of-squares optimization.</p>
<p dir="auto">The original problem had one (symmetric) psd constraint of size <code>4641×4641</code> and <code>11_154_301</code> linear constraints. By exploiting its (admittedly -- pretty large) symmetry group (of order <code>3840</code>) we can reduce this problem to <code>20</code> (symmetric) psd constraints of sizes</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="[56  38  34  32  27  27  23  23  22  22  18  17  9  8  6  2  1  1  1  1]"><pre class="notranslate"><code>[56  38  34  32  27  27  23  23  22  22  18  17  9  8  6  2  1  1  1  1]
</code></pre></div>
<p dir="auto">which correspond to (the simple) <code>Wᵢ</code> blocks above. In particular, the number of variables in psd constraints was reduced from <code>10_771_761</code> to just <code>5_707</code>.</p>
<p dir="auto">Moreover, the symmetry group has just <code>7 229</code> orbits (when acting on the subspace of linear constraints), so the symmetrized problem has equal number of (a bit denser) linear constraints.</p>
<p dir="auto">The symmetrized problem is solvable in ~20 minutes on an average office laptop (with <code>16GB</code> of RAM).</p>
<p dir="auto">For more examples you may have a look at <a href="https://github.com/kalmarek/SymbolicWedderburn.jl/blob/master/examples/ex_robinson_form.jl">dihedral action example</a>, or different <a href="https://github.com/kalmarek/SymbolicWedderburn.jl/blob/master/examples/sos_problem.jl">sum of squares formulations</a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Other symbolic decompositions</h2><a id="user-content-other-symbolic-decompositions" class="anchor" aria-label="Permalink: Other symbolic decompositions" href="#other-symbolic-decompositions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The main aim of <code>GAP</code> package <a href="https://www.gap-system.org/Manuals/pkg/wedderga/doc/chap0.html" rel="nofollow"><code>Wedderga</code></a> is to</p>
<blockquote>
<p dir="auto">compute the simple components of the Wedderburn decomposition of semisimple group algebras of finite groups over finite fields and over subfields of finite cyclotomic extensions of the rationals.</p>
</blockquote>
<p dir="auto">The focus is thus on symbolic computations and identifying <em>isomorphism type</em> of the simple components.
<code>SymbolicWedderburn</code> makes no efforts to compute the types or defining fields,
it's primary goal is to compute symbolic/numerical Wedderburn-Artin isomorphism in a form usable for (polynomial) optimization. <code>Wedderga</code> also contains much more sophisticated methods for computing <em>a complete set of orthogonal primitive idempotents</em> (i.e. a minimal projection system) through Shoda pairs.
In principle those idempotents could be computed using <a href="https://github.com/oscar-system/Oscar.jl"><code>Oscar</code></a> and used in <code>SymbolicWedderburn</code>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How does <code>SymbolicWedderburn.jl</code> really work (a bit more theory)?</h2><a id="user-content-how-does-symbolicwedderburnjl-really-work-a-bit-more-theory" class="anchor" aria-label="Permalink: How does SymbolicWedderburn.jl really work (a bit more theory)?" href="#how-does-symbolicwedderburnjl-really-work-a-bit-more-theory"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The algorithm of <code>SymbolicWedderburn.jl</code> can be summarised in a few steps. As an example it might be helpful to think of <code>G</code> acting on a polynomial ring by permuting variables.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Defining the action</h3><a id="user-content-defining-the-action" class="anchor" aria-label="Permalink: Defining the action" href="#defining-the-action"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol dir="auto">
<li>Given the action of <code>G</code> on variables the action <code>η</code> on the whole monomial basis is induced and therefore on the whole polynomial ring.</li>
<li>For the concrete <code>G</code>-invariant linear subspace <code>V</code> (given by a fixed set of monomials) of the polynomial ring (a vector space with <code>G</code>-action) we compute the character of representation <code>η:G → 𝒰(V)</code> (we assume that <code>η</code> is unitary, which is automatic for (signed) permutation actions).</li>
</ol>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Computing with characters i.e. isotypical projections</h3><a id="user-content-computing-with-characters-ie-isotypical-projections" class="anchor" aria-label="Permalink: Computing with characters i.e. isotypical projections" href="#computing-with-characters-ie-isotypical-projections"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol start="3" dir="auto">
<li>After computing the character table of <code>G</code> we find the decomposition of <code>(V, η)</code> into irreducibles: <code>η ≅ χ₁ + … + χᵣ</code> by some symbolic magic (i.e. orthogonality relations) in the group ring <code>ℂG</code> (or <code>ℝG</code>). We know that this decomposition corresponds to a decomposition <code>V ≅ V₁ ⊕ ⋯ ⊕ Vᵣ</code>, and we will compute that correspondence explicitely in a moment.</li>
<li>Moreover, we abstractly know that each <code>χᵢ ≅ mᵢϱᵢ</code> (and <code>Vᵢ ≅ mᵢWᵢ</code>) is isomorphic to a multiple <code>mᵢ</code> of irreducible characters <code>ϱᵢ</code>, but we can't use this information yet. These irreducibles lead us later to <code>πᵢ : V → Vᵢ</code>, the projections onto isotypical summands. <details><summary>show me more…</summary>Our implementation of projections is matrix-free. Projections are just idempotent elements (<code>x² = x</code>) in the group algebra. In that sense the projection to an isotypical component is unique in <code>ℂG</code>, but not as <code>πᵢ = η(ϱᵢ)</code>, an element of <code>End_G((V, η))</code> i.e. as a matrix: a matrix representation of a projection already includes a choice of basis (think of the difference of a linear operator vs its matix).</details></li>
</ol>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Minimal projection system</h3><a id="user-content-minimal-projection-system" class="anchor" aria-label="Permalink: Minimal projection system" href="#minimal-projection-system"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol start="4" dir="auto">
<li>
<p dir="auto">Sometimes this step is followed by finding even tighter <em>minimal projection system</em></p><details><summary>show me more…</summary>Finding tighter projections use a lemma of Schur.<p dir="auto"></p>
<blockquote>
<p dir="auto"><strong>Lemma</strong> (Schur) Over an algebraically closed field the commutant of a matrix algebra consist of matrices of a particularly simple form:</p>
<ul dir="auto">
<li>direct sums of endomorphisms of isotypical subspaces (i.e. isotypical subspaces are orthogonal which gives us block structure for endomorphisms),</li>
<li>within isotypical subspace (of character <code>ϱ</code>) the endomorphisms are of the form <code>M⊗Iₙ</code>, where <code>n = degree(ϱ)</code> and <code>M</code> is (square) of size <code>m = multiplicity(ϱ, η)</code>.</li>
</ul>
</blockquote>
<p dir="auto">Here the matrix algebra is the one defined by the image of <code>η</code> and the projections commute with those, so the conclusion is that reconstructing a single projection endomorphism corresponding to an irreducible <code>ϱ</code> requires only <code>m²</code> parameters (regardless of the degree of <code>ϱ</code>!)</p>
<ul dir="auto">
<li>For every irreducible character <code>ϱᵢ</code> we try to find a (non-central) projection <code>pᵢ</code> such that <code>ϱᵢ∘pᵢ(e) = k</code> is as small as possible (desirably just <code>1</code>), so that <code>η(ϱᵢ∘pᵢ) = πᵢ∘η(pᵢ)</code> and therefore <code>rank(πᵢ∘η(pᵢ)) = k</code>. We call those <code>{ϱᵢ∘pᵢ}_{ϱ ∈ Irr(G)}</code> a <strong>minimal projection system</strong>. Note: the existence and complexity of finding the system depends <strong>on the group only</strong>, not on the representation <code>η</code>, its associated action (and hence not on the dimension of <code>V</code>!).</li>
<li>Sometimes the system exists (symmetric, alternating groups etc.) sometimes it doesn’t (e.g. real representations of cyclic groups).</li>
<li>We employ a simple brute-force algorithm to search for <code>pᵢ</code> over all characteristic/alternating projections for small subgroups of <code>G</code>.</li></ul></details></li>


</ol>
