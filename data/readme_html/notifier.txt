<p dir="auto">Before using Notifier.jl, you need to install following softwares in your Linux system.</p>
<ul dir="auto">
<li><code>libnotify</code> for a desktop notification</li>
<li><code>mail</code> for an e-mail notification</li>
<li><code>aplay</code> (Advanced Linux Sound Architecture) for a sound notification</li>
<li><code>espeak</code> for reading a given message aloud</li>
</ul>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ sudo apt install libnotify-bin alsa-utils espeak mailutils heirloom-mailx bsd-mailx"><pre>$ sudo apt install libnotify-bin alsa-utils espeak mailutils heirloom-mailx bsd-mailx</pre></div>
<p dir="auto">This package uses <code>mail</code> command to notify by e-mail. You may need some settings in advance.
If following command works correctly, you don't need further setting.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ echo test | mail -s foo yourmail@example.com"><pre>$ <span class="pl-c1">echo</span> <span class="pl-c1">test</span> <span class="pl-k">|</span> mail -s foo yourmail@example.com</pre></div>
