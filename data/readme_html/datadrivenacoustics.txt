<p dir="auto">This package is built upon the ideas discussed in our journal paper "Data-Aided Underwater Acoustic Ray Propagation Modeling" published on IEEE Journal of Oceanic Engineering (available online: <a href="https://ieeexplore.ieee.org/abstract/document/10224658" rel="nofollow">https://ieeexplore.ieee.org/abstract/document/10224658</a>).</p>
<p dir="auto">Conventional acoustic propagation models require accurate environmental knowledge to be available beforehand. While data-driven techniques might allow us to model acoustic propagation without the need for extensive prior environmental knowledge, such techniques tend to be data-hungry. We propose a physics-based data-driven acoustic propagation modeling approach that enables us to train models with only a small amount of data. The proposed modeling framework is not only data-efficient, but also offers flexibility to incorporate varying degrees of environmental knowledge, and generalizes well to permit extrapolation beyond the area where data were collected.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>DataDrivenUnderwaterEnvironment</code> creates a data-driven environment.</p>
<ul dir="auto">
<li><code>locations</code>: location measurements (in the form of matrix with dimension [dimension of a single location data x number of data points])</li>
<li><code>measurements</code>: acoustic field measurements (in the form of matrix with dimension [1 x number of data points])</li>
<li><code>soundspeed</code>: medium sound speed (default: missing)</li>
<li><code>frequency</code>: source frequency (default: missing)</li>
<li><code>waterdepth</code>: water depth (default: missing)</li>
<li><code>salinity</code>: water salinity (default: 35.0)</li>
<li><code>seasurface</code>: surface property (default: Vacuum)</li>
<li><code>seabed</code>: seabed property (default: SandySilt)</li>
<li><code>tx</code>: source location (default: missing)</li>
<li>set <code>dB</code> to <code>false</code> if <code>measurements</code> are not in dB scale (default: <code>true</code>)</li>
</ul>
<p dir="auto"><code>RayBasis2D</code>: 2D plane wave formulation. This formulation does not require knowledge of channel geometry.</p>
<ul dir="auto">
<li><code>env</code>: data-driven underwater environment</li>
<li><code>calculatefield</code>: function to estimate acoustic field (default: <code>RayBasis2DCal</code>)</li>
<li><code>nrays</code>: number of rays (default: 60)</li>
<li><code>θ</code>: azimuthal angle of arrival rays in radian (default: missing)</li>
<li><code>A</code>: amplitude of arrival rays (default: missing)</li>
<li><code>ϕ</code>: phase of a rays in radian (default: missing)</li>
<li><code>k</code>: angular wavenumber in rad/m (default: missing)</li>
<li><code>trainable</code>: trainable parameters (default: empty)</li>
</ul>
<p dir="auto"><code>RayBasis2DCurv</code>: 2D formulation by modeling curvature of wavefront. This formulation does not require knowledge of channel geometry.</p>
<ul dir="auto">
<li><code>env</code>: data-driven underwater environment</li>
<li><code>calculatefield</code>: function to estimate acoustic field (default: <code>RayBasis2DCurvCal</code>)</li>
<li><code>nrays</code>: number of rays (default: 60)</li>
<li><code>θ</code>: azimuthal angle of arrival ray in radian (default: missing)</li>
<li><code>A</code>: amplitude of arrival rays (default: missing)</li>
<li><code>ϕ</code>: phase of a rays in radian (default: missing)</li>
<li><code>d</code>: distance in meters to help in modeling curvature of wavefront (default: missing)</li>
<li><code>k</code>: angular wavenumber in rad/m (default: missing)</li>
<li><code>trainable</code>: trainable parameters (default: empty)</li>
</ul>
<p dir="auto"><code>RayBasis3D</code>: 3D spherical wave formulation. This formulation allow user to incorporate known channel geometry knowledge by inputting pre-calculated <code>θ</code>, <code>ψ</code> and <code>d</code>. To exclude the error terms from the trainable parameters, set <code>eθ</code>, <code>eψ</code>, and <code>ed</code> to zero if the input values of <code>θ</code>, <code>ψ</code>, and <code>d</code> are accurate.</p>
<ul dir="auto">
<li><code>env</code>: data-driven underwater environment</li>
<li><code>calculatefield</code>: function to estimate acoustic field (default: <code>RayBasis3DCal</code>)</li>
<li><code>nrays</code>: number of rays (default: 60)</li>
<li><code>θ</code>: nominal azimuthal angle of arrival rays in radian (default: missing)</li>
<li><code>ψ</code>: nominal elevation angle of arrival rays in radian (default: missing)</li>
<li><code>d</code>: nominal propagation distance of arrival rays  in meters (default: missing)</li>
<li><code>eθ</code>: error to nominal azimuthal angle of arrival rays in radian (default: missing)</li>
<li><code>eψ</code>: error to nominal elevation angle of arrival rays in radian (default: missing)</li>
<li><code>ed</code>: error to nominal propagation distance of arrival rays in meters (default: missing)</li>
<li><code>A</code>: amplitude of arrival rays (default: missing)</li>
<li><code>ϕ</code>: phase of a rays in radian (default: missing)</li>
<li><code>k</code>: angular wavenumber in rad/m (default: missing)</li>
<li><code>trainable</code>: trainable parameters (default: empty)</li>
</ul>
<p dir="auto"><code>RayBasis3DRCNN</code>: 3D spherical wave formulation with reflection coefficient neural network (RCNN) as part of the model. This formulation requires knowledge of channel geometry (water depth and source location) to pre-calculate nominal ray arrival directions, propagation distances and incident angles. This formulation currently only supports flat bathymetry.</p>
<ul dir="auto">
<li><code>env</code>: data-driven underwater environment</li>
<li><code>RCNN</code>: neural network to model seabed reflections</li>
<li><code>calculatefield</code>: function to estimate acoustic field (default: <code>RayBasis3DRCNNCal</code>)</li>
<li><code>nrays</code>: number of rays (default: 60)</li>
<li><code>eθ</code>: error to nominal azimuthal angle of arrival rays in radian (default: missing)</li>
<li><code>eψ</code>: error to nominal elevation angle of arrival rays in radian (default: missing)</li>
<li><code>ed</code>: error to nominal propagation distance of arrival rays in meters (default: missing)</li>
<li><code>k</code>: angular wavenumber in rad/m (default: missing)</li>
<li><code>trainable</code>: trainable parameters (default: empty)</li>
</ul>
<p dir="auto">These four physics-based data-driven propagation models have optional arguments pertaining to model training setups, in addition to the previously explained model parameters.</p>
<ul dir="auto">
<li>
<code>ini_lr</code>: initial learning rate (default: 0.001)</li>
<li>
<code>trainloss</code>: loss function used in model training (default: <code>rmseloss</code>)</li>
<li>
<code>dataloss</code>: data loss function to calculate benchmarking validation error for early stopping (default: <code>rmseloss</code>)</li>
<li>
<code>ratioₜ</code>: data split ratio = <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8415ebf093875be89ac6f664b943d152">$\frac{\text{number of training data}}{\text{number of training data + number of validation data}}$</math-renderer> (default: 0.7)</li>
<li>set <code>seed</code> to <code>true</code> to seed random data selection order (default: <code>false</code>)</li>
<li>
<code>maxepoch</code>: maximum number of training epochs allowed (default: 10000000)</li>
<li>
<code>ncount</code>: maximum number of attempts without data loss improvement before reducing the learning rate (default: 5000)</li>
<li>model training ends once learning rate is smaller than <code>minlearnrate</code> (default: 1e-6)</li>
<li>learning rate is reduced by <code>reducedlearnrate</code> once <code>ncount</code> is reached (default: 10)</li>
<li>set <code>showloss</code> to true to display training and validation errors during the model training process, if the validation error is historically the best. (default: <code>false</code>)</li>
</ul>
<p dir="auto"><code>GPR</code>: Gaussian process regression model that is capable of handling 2D and 3D regression problems.</p>
<ul dir="auto">
<li><code>env</code>: data-driven underwater environment</li>
<li><code>kern</code>: kernel function</li>
<li><code>mZero</code>: zero mean function (default: <code>MeanZero()</code>)</li>
<li><code>logObsNoise</code>: log standard deviation of observation noise (default: -2.0)</li>
<li><code>ratioₜ</code>: training data split ratio (default: 1.0)</li>
<li>set <code>seed</code> to <code>true</code> to seed random data selection order (default: <code>false</code>)</li>
<li><code>calculatefield</code>: function to estimate acoustic field (default: <code>GPRCal</code>)</li>
</ul>
<p dir="auto"><strong>Example:</strong>
If you have a set of measured pressure amplitudes and their corresponding measurement locations as training and validation data, you can load them directly. The location data should be a matrix with dimension [dimension of a single location data x number of data points]. The field data should be a matrix with dimension [1 x number of data points].</p>
<p dir="auto">Alternatively, you can use the propagation models available in <code>Undertwateracoustic.jl</code>, <code>AcousticRayTracers.jl</code> or <code>AcousticsToolbox.jl</code> to generate synthetic acoustic data.</p>

<p dir="auto">Note that we use 100% of the data (500 measurements) as training data to train the GPR model, as the ratioₜ in GPR is set to 1.0 by default. Our RBNN model, on the other hand, is trained using 350 measurements, while the remaining 150 measurements are used as validation data for early stopping. The provided kernel and hyperparameters yield the best estimated field pattern (determined through visual inspection, as we know the ground truth field pattern) among the various kernels and hyperparameters we experimented with for this specific example. If users lack prior information about the ground truth field pattern, they should allocate some validation data for hyperparameter tuning of the GPR model.</p>
