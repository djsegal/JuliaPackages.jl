<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>QUBOTools.jl</code> package implements codecs for QUBO (<em>Quadratic Unconstrained Binary Optimization</em>) instances.
Its purpose is to provide fast and reliable conversion between common formats used to represent such problems.
This allows for rapid leverage of many emergent computing architectures whose job is to solve this kind of optimization problem.</p>
<p dir="auto">The term QUBO is widely used when referring to <em>boolean</em> problems of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a4e1660493f52e1d57756078b92587d4">$$\begin{array}{rl}
\min &amp; \mathbf{x}'\ Q\ \mathbf{x} \\
\text{s.t.} &amp; \mathbf{x} \in \mathbb{B}^{n}
\end{array}$$</math-renderer></p>
<p dir="auto">with symmetric <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a4e1660493f52e1d57756078b92587d4">$Q \in \mathbb{R}^{n \times n}$</math-renderer>. Nevertheless, this package also fully supports <em>Ising Models</em>, given by</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a4e1660493f52e1d57756078b92587d4">$$\begin{array}{rl}
\min &amp; \mathbf{s}'\ J\ \mathbf{s} + \mathbf{h}'\ \mathbf{s} \\
\text{s.t.} &amp; \mathbf{s} \in \left\lbrace-1, 1\right\rbrace^{n}
\end{array}$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a4e1660493f52e1d57756078b92587d4">$J \in \mathbb{R}^{n \times n}$</math-renderer> is triangular and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a4e1660493f52e1d57756078b92587d4">$\mathbf{h} \in \mathbb{R}^{n}$</math-renderer>.</p>

<p dir="auto">The <a href="https://bqpjson.readthedocs.io" rel="nofollow">BQPJSON</a> format was designed at <a href="https://github.com/lanl-ansi">LANL-ANSI</a> to represent Binary Quadratic Programs in a platform-independet fashion.
This is accomplished by using <code>.json</code> files validated using a well-defined <a href="/src/models/bqpjson.schema.json">JSON Schema</a>.</p>
