<p dir="auto">Lightweight package to print a table that implements the <a href="https://tables.juliadata.org" rel="nofollow">Tables.jl interface</a> in Markdown.</p>
<p dir="auto">Primarily developed for use in <a href="https://fredrikekre.github.io/Literate.jl" rel="nofollow">Literate.jl</a>, as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MarkdownTables #hide
some_table |&gt; markdown_table()"><pre><span class="pl-k">using</span> MarkdownTables <span class="pl-c"><span class="pl-c">#</span>hide</span>
some_table <span class="pl-k">|&gt;</span> <span class="pl-c1">markdown_table</span>()</pre></div>
<p dir="auto">You can directly save the generated ready-to-paste table to your clipboard via:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="some_table |&gt; markdown_table(String) |&gt; clipboard"><pre>some_table <span class="pl-k">|&gt;</span> <span class="pl-c1">markdown_table</span>(String) <span class="pl-k">|&gt;</span> clipboard</pre></div>
