<p dir="auto">This package contains a pager written 100% in Julia. It can be used to scroll through
content that does not fit in the screen. It was developed based on the Linux command <code>less</code>.</p>

<p dir="auto">You can call the pager using the function <code>pager</code> with any object. If it is not a string,
then it will be rendered to one using <code>show</code> with <code>MIME"text/plain"</code>.</p>
