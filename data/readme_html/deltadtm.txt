<p dir="auto">Julia package used to create DeltaDTM</p>
<p dir="auto">In <code>src</code> there's the source code of the package. More useful are the files in <code>scripts</code>, which make use of the <code>src</code> files.
They can be called like so:</p>
<ul dir="auto">
<li><code>julia --project scripts/bias_call</code> to process the bias correction</li>
<li><code>julia --project scripts/dtm_call</code> to generate DeltaDTM tiles</li>
<li><code>julia --project scripts/make_release</code> to generate DeltaDTM zips</li>
</ul>

<p dir="auto">To run this as is, one needs at least CopernicusDEM tiles (used both with and without water masked out), the original CopernicusDEM error and mask files. One also need to download ESA-WorldCover 2021 and subtile the dataset into CopernicusDEM tiles. Last but not least, one needs to download all ICESat-2 and GEDI data for their area of interest (can be done with <code>SpaceLiDAR.jl</code>) and save these as GeoParquet (<code>.pq</code>), also tiled to the CopernicusDEM tiles, by saving multiple GeoParquet files (one for each granule) in a folder per tile.</p>
<p dir="auto">For all these <code>.tif</code> tiles, <code>gdalbuildvrt</code> is run, to include all direct neighbours of such tiles. Each 1 by 1 degree <code>.tif</code> tile thus as a <code>.tif.vrt</code> tile that's 3 by 3 degrees. For the GeoParquet files <code>.pq</code> a similar buffer is made, by making a text (<code>.txt</code>) file containing the paths of all files, including all filepaths in the neighboring tilefolders.</p>
