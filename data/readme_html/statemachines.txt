<p dir="auto">StateMachines package is functional implementation of a <a href="https://en.wikipedia.org/wiki/Finite-state_machine" rel="nofollow">deterministic finite-state machine (DFSM)</a> - also known as a <a href="https://en.wikipedia.org/wiki/Deterministic_finite_automaton" rel="nofollow">deterministic finite automaton (DFA)</a>. It can be used as a simple transition <strong>state system</strong>, as a business <strong>workflow</strong> or as a autonomous <strong>state machine</strong>.</p>
<p dir="auto">Implementation follows the definition of a deterministic finite automaton M that is a 5-tuple, (Q, Σ, δ, q0, F), consisting of:</p>
<ul dir="auto">
<li>a finite set of <strong>states</strong> (Q)</li>
<li>a finite set of inputs - <strong>actions and context</strong> (Σ)</li>
<li>a finite set of <strong>transitions</strong> or transition function (d: Q x Σ -&gt; δ)</li>
<li>an <strong>initial</strong> or start state (q[0])</li>
<li>a set of <strong>accept</strong> or final states (F)</li>
</ul>
