<p dir="auto">Pioran is a Julia package to estimate the power spectrum of any time series using bending power laws. This method is based on Gaussian process regression with the fast algorithm of <a href="https://ui.adsabs.harvard.edu/abs/2017AJ....154..220F/abstract" rel="nofollow">Foreman-Mackey, et al. 2017</a> and by approximating the power spectrum model with basis functions. The method is described in Lefkir, et al. 2023 (in prep).</p>

<p dir="auto">Example scripts are provided in the <a href="./examples">examples</a> directory. To infer the parameters of the power spectrum, I use either <a href="https://github.com/TuringLang/Turing.jl"><code>Turing.jl</code></a> for Hamiltonian Monte Carlo or the Python library <a href="https://github.com/JohannesBuchner/UltraNest"><code>ultranest</code></a> for nested sampling. The scripts are written in a way that you can use either of these libraries.</p>
