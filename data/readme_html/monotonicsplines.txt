<p dir="auto">This package provides high-performance, GPU- and
<a href="https://en.wikipedia.org/wiki/Automatic_differentiation" rel="nofollow">AD</a>-friendly
monotonic spline functions in Julia for use in
<a href="https://en.wikipedia.org/wiki/Flow-based_generative_model" rel="nofollow">Normalizing Flows</a>,
resp. parameter transformations in general.</p>
<p dir="auto">This package currently includes the <em>monotonic rational quadratic splines</em> defined in <a href="https://arxiv.org/abs/1906.04032" rel="nofollow">"Neural Spline Flows, Durkan et al. 2019"</a>.</p>
<p dir="auto">Please see the Documentation linked below for details.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Example usage of rational quadratic spline functions for use in Normalizing Flows</h2><a id="user-content-example-usage-of-rational-quadratic-spline-functions-for-use-in-normalizing-flows" class="anchor" aria-label="Permalink: Example usage of rational quadratic spline functions for use in Normalizing Flows" href="#example-usage-of-rational-quadratic-spline-functions-for-use-in-normalizing-flows"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Given a set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{ \mathbf{x}_i\}$</math-renderer> (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$i = 1,..., N_{\text{samples}}$</math-renderer>) of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$D$</math-renderer> dimensional samples, a (partial) Normalizing Flow <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{f}$</math-renderer> using Splines transforms a number of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$D-d~$</math-renderer>  (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$1 \leq d \leq D$</math-renderer>) components of each sample <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{x}_i$</math-renderer> to obtain a set of partially transformed samples <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{ \mathbf{y}_i\}$</math-renderer>:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$$\begin{align*}
\mathbf{f} : \mathbb{R}^D \rightarrow \mathbb{R}^D, ~~ \mathbf{x} = 
\begin{pmatrix}
x_{1}                   \\\
x_{2}                   \\\
\vdots                  \\\
x_{d-1}                 \\\
x_{d}                   \\\
\vdots                  \\\
x_{D}                   \\\
\end{pmatrix} 
\mapsto
\begin{pmatrix}
x_{1}                   \\\
x_{2}                   \\\
\vdots                  \\\
x_{d-1}                 \\\
f_{\theta_d}(x_d)       \\\
\vdots                  \\\
f_{\theta_{D}}(x_{D})   \\\
\end{pmatrix} 
= \mathbf{y}
\end{align*}$$</math-renderer>
<p dir="auto">Here <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$f_{\theta_j} : \mathbb{R} \rightarrow \mathbb{R} ~~ (j = d,...,D)~$</math-renderer>  denotes a single spline function, characterized by the parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$~\theta_{j} = (\text{pX}_j~, ~\text{heigths}_j~,~\text{dYdX}_j)$</math-renderer> in the case of the rational quadratic spline functions defined in <a href="https://arxiv.org/abs/1906.04032" rel="nofollow">"Neural Spline Flows, Durkan et al. 2019"</a>.</p>
<p dir="auto">Consider a single sample <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{x}_i \in \mathbb{R}^D$</math-renderer> from our sample set.</p>
<p dir="auto">In the context of Normalizing Flows, the set of parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{\theta_j\}$</math-renderer> that characterize the spline functions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{f_{\theta_j}\}$</math-renderer> to transform the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$d$</math-renderer> -th to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$D$</math-renderer> -th components of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{x}_i$</math-renderer> are obtained by processing the output of a neural net <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$NN$</math-renderer>.</p>
<p dir="auto">This neural net takes the first <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$d$</math-renderer> components <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{ x_{i,1},..., x_{i,d}\}$</math-renderer> of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{x}_i$</math-renderer> that are <em>not</em> transformed by the Flow <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{f}$</math-renderer> as input. The output then is a vector of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$(D-d) \cdot (3K-1)$</math-renderer> components, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$K$</math-renderer> is the number of segments in a spline function.</p>
<p dir="auto">These "raw" spline parameters are then processed as described in <a href="https://arxiv.org/abs/1906.04032" rel="nofollow">"Neural Spline Flows, Durkan et al. 2019"</a> to obtain <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{ \theta_j \}$</math-renderer>.</p>
<p dir="auto"><code>MonotonicSplines.jl</code> is designed with parallelism in mind, and this implementation allows for the simultaneous transformation of batches of samples using spline functions.</p>
<p dir="auto">To this end, the parameters for characterizing sets of several spline functions are stored in the same struct.</p>
<p dir="auto">Now consider the task of transforming the entire set of samples <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{\mathbf{x}_i\}$</math-renderer> via the Normalizing Flow <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$f$</math-renderer>.</p>
<p dir="auto">To achieve this, each of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$(D-d) \cdot N_{\text{samples}}$</math-renderer> components to be transformed obtains an individual spline function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$f_{\theta_j}^{(i)}$</math-renderer>.</p>
<p dir="auto">So the spline function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$f_{\theta_j}^{(i)}$</math-renderer> is applied to the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$j$</math-renderer> -th component of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$i$</math-renderer> -th sample.</p>
<p dir="auto">Given the output <code>params_raw</code> of the neural net <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$NN$</math-renderer>, we can obtain the <code>pX</code>, <code>pY</code>, and <code>dYdX</code> to characterize the desired spline function as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; pX, pY, dYdX = rqs_params_from_nn(params_raw, n_dims_to_transform)"><pre>julia<span class="pl-k">&gt;</span> pX, pY, dYdX <span class="pl-k">=</span> <span class="pl-c1">rqs_params_from_nn</span>(params_raw, n_dims_to_transform)</pre></div>
<p dir="auto">Here, <code>params_raw</code> is a <code>3(K-1) * n_dims_to_transform x n_samples</code> -matrix. <code>K</code> again is the number of spline segments and <code>n_dims_to_transform</code> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$~= D-d~$</math-renderer> is the number of components to transform per sample.</p>
<p dir="auto">The <code>i</code> -th column of this matrix <code>params_raw</code> is the output of the neural net <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$NN$</math-renderer> with the first <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$d$</math-renderer> components <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{ x_{i,1},..., x_{i,d}\}$</math-renderer> of the <code>i</code> -th sample <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\mathbf{x}_i$</math-renderer> as the input.</p>
<p dir="auto"><code>pX</code>, <code>pY</code>, and <code>dYdX</code> each are <code>K x n_dims_to_transform x n_samples</code> -arrays. The <code>[:,j,i]</code> entries hold the parameters to characterize <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$f_{\theta_j}^{(i)}$</math-renderer>, the spline function to transform the <code>j</code> -th component of the <code>i</code> -th sample from the sample set.</p>
<p dir="auto">We then define the set of spline functions by:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; rqs_splines = RQSpline(pX, pY, dYdX)"><pre>julia<span class="pl-k">&gt;</span> rqs_splines <span class="pl-k">=</span> <span class="pl-c1">RQSpline</span>(pX, pY, dYdX)</pre></div>
<p dir="auto">An object holding the parameters to characterize <code>n_dims_to_transform x n_samples</code> spline functions.</p>
<p dir="auto">To apply the spline functions characterized by the parameters stored in <code>rqs_splines</code>, we first isolate the components of the sample set that are supposed to be transformed and then do:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; Y_partial = rqs_splines(X_partial)"><pre>julia<span class="pl-k">&gt;</span> Y_partial <span class="pl-k">=</span> <span class="pl-c1">rqs_splines</span>(X_partial)</pre></div>
<p dir="auto"><code>X_partial</code> is a <code>n_dims_to_transform x n_samples</code> -matrix, holding the components of the sample set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{\mathbf{x}_i\}$</math-renderer> that are to be transformed. So the <code>i</code> -th column in <code>X_partial</code> holds the <code>d</code> -th to <code>D</code> -th elements of the <code>i</code> -th sample in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3a47f450641505d16a4456d89b569b2">$\{\mathbf{x}_i\}$</math-renderer>.</p>
<p dir="auto"><code>Y_partial</code> is a <code>n_dims_to_transform x n_samples</code> matrix, where the <code>i,j</code> -th component is the transformed value of the <code>i,j</code> -th entry in <code>X_partial</code>.</p>
<p dir="auto">For further details on the implementation, see the <a href="https://bat.github.io/MonotonicSplines.jl/stable" rel="nofollow">Documentation for stable version</a>.</p>
