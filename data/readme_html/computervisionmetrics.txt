<p dir="auto">ComputerVisionMetrics.jl is a Julia package for evaluating segmentation models using various metrics like Dice and Hausdorff distances. The primary functions are <code>dice_metric()</code> and <code>hausdorff_metric()</code> which evaluate the similarity and dissimilarity between predicted and ground truth segmentations respectively.</p>
