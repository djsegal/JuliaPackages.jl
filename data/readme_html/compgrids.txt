<p dir="auto">Creates computational grids and initializes fields on these grids that can be used with <a href="https://github.com/omlins/ParallelStencil.jl">ParallelStencil.jl</a> or <a href="https://github.com/JuliaParallel/PETSc.jl/tree/jek/gen">PETSc.jl</a></p>
<p dir="auto">The basic idea is that you specify a backend (<code>ParallelStencil</code> or <code>PETSc</code>), after which the grid can be created.
A 2D example using ParallelStencil &amp; ImplicitGlobalGrid:</p>

<p dir="auto">The resulting <code>grid</code> is a structure that holds information about the grid (the global grid in case it is run on one core, and the local portion in case it is run in MPI-parallel). If indicated, it also initializes the fields (as a global vector for the <code>PETSc</code> and as 1D/2D/3D arrays for <code>PS</code>), which you can access with <code>grid.fields.T</code> or <code>grid.fields[:T]</code> (for the examples above).</p>

<p dir="auto">This is work in progress. If you want to get a feel for it, have a look at the <a href="https://github.com/JuliaGeodynamics/CompGrids.jl/tree/main/test">test</a> and <a href="https://github.com/JuliaGeodynamics/CompGrids.jl/tree/main/examples">examples</a> directories.</p>
<ul dir="auto">
<li>The functionality is fairly complete for collocated grids (using <code>PS</code> and <code>PETSc</code>).</li>
<li>Staggered grid support will be added</li>
<li>Support for other types of structurally regular grids (e.g., cylindrical, yin-yang?) should be fairly straightforward to add as well, but as we don't use these grids on a daily basis, we would require volunteers to help with this</li>
<li>Adding interfaces to other types of meshes (finite elements, AMR) could be added as well, but would require external volunteers</li>
</ul>
