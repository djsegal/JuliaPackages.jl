<p dir="auto">Provides a community maintained Julia wrapper to the OpenAI API.
For API functionality see <a href="https://platform.openai.com/docs/api-reference" rel="nofollow">reference documentation</a>.
Autogenerated documentation can be found here: <a href="https://juliaml.github.io/OpenAI.jl/dev/" rel="nofollow">https://juliaml.github.io/OpenAI.jl/dev/</a></p>

<ol dir="auto">
<li>

<p dir="auto">If you have a non-standard setup, such as a local LLM or third-party service that
conforms to the OpenAI interface, you can override parameters using the <code>OpenAIProvider</code>
struct in your application like this:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OpenAI

)

    provider,
    &quot;gpt-3.5-turbo&quot;,
    [Dict(&quot;role&quot; =&gt; &quot;user&quot;, &quot;content&quot; =&gt; &quot;Write some ancient Greek poetry&quot;)]
)"><pre><span class="pl-k">using</span> OpenAI
