<p dir="auto">This package implements <a href="https://en.wikipedia.org/wiki/Tropical_geometry" rel="nofollow">tropical numbers</a> and tropical algebras in Julia. Tropical algebra is also known as the <a href="https://en.wikipedia.org/wiki/Semiring" rel="nofollow">semiring</a> algebra, which is a set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$R$</math-renderer> equipped with two binary operations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\oplus$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\otimes$</math-renderer>, called addition and multiplication, such that:</p>
<ul dir="auto">
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(R, \oplus)$</math-renderer> is a monoid with identity element called <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\mathbb{0}$</math-renderer>;</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(R, \otimes)$</math-renderer> is a monoid with identity element called <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\mathbb{1}$</math-renderer>;</li>
<li>Addition is commutative;</li>
<li>Multiplication by the additive identity <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\mathbb{0}$</math-renderer> annihilates ;</li>
<li>Multiplication left- and right-distributes over addition;</li>
<li>Explicitly stated, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(R, \oplus)$</math-renderer> is a commutative monoid.</li>
</ul>

<p dir="auto">A Topical algebra can be described as a tuple <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(R, \oplus, \otimes, \mathbb{0}, \mathbb{1})$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$R$</math-renderer> is the set, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\oplus$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\otimes$</math-renderer> are the opeartions and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\mathbb{0}$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$\mathbb{1}$</math-renderer> are their identity element, respectively. In this package, the following tropical algebras are implemented:</p>
<ul dir="auto">
<li>
<code>TropicalAndOr</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$([T, F], \lor, \land, F, T)$</math-renderer>;</li>
<li>
<code>Tropical</code> (<code>TropicalMaxPlus</code>): <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(\mathbb{R}, \max, +, -\infty, 0)$</math-renderer>;</li>
<li>
<code>TropicalMinPlus</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(\mathbb{R}, \min, +, \infty, 0)$</math-renderer>;</li>
<li>
<code>TropicalMaxMul</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cda373dbb11bea0b9379e260e5644ce7">$(\mathbb{R}^+, \max, \times, 0, 1)$</math-renderer>.</li>
</ul>

<p dir="auto">Related packages include</p>
<ul dir="auto">

<li><a href="https://github.com/saschatimme/TropicalSemiring.jl">TropicalSemiring.jl</a></li>
</ul>
<p dir="auto">These packages include unnecessary fields in its tropical numbers, such as <code>isinf</code>. However, <code>Inf</code> and <code>-Inf</code> can be used directly for floating point numbers, which is more memory efficient and computationally cheap. <code>TropicalNumbers</code> is designed for high performance matrix multiplication on both CPU and GPU.</p>
