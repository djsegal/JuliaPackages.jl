<p dir="auto">A package to calculate CG-coefficient, Racah coefficient, Wigner 3j, 6j, 9j symbols and Moshinsky brakets.</p>
<p dir="auto">One can get the exact result with <code>SqrtRational</code> type, which use <code>BigInt</code> to avoid overflow. And we also offer float version for numeric calculation, which is about twice faster than <a href="https://www.gnu.org/software/gsl/" rel="nofollow">GNU Scientific Library</a>.</p>
<p dir="auto">I also rewrite the float version with c++ for numeric calculation: <a href="https://github.com/0382/WignerSymbol">WignerSymbol</a>.</p>
<p dir="auto">For more details and the calculation formula, please see the document <a href="https://0382.github.io/CGcoefficient.jl/dev" rel="nofollow"><img src="https://camo.githubusercontent.com/45c316268f541933640ad68f61395986888f4d46bc9641b40e53d337576c6456/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6465762d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-dev-blue.svg" style="max-width: 100%;"></a>.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">API</h3><a id="user-content-api" class="anchor" aria-label="Permalink: API" href="#api"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package contains two types of functions:</p>
<ol dir="auto">
<li>The exact functions return <code>SqrtRational</code>, which are designed for demonstration. They use <code>BigInt</code> in the internal calculation, and do not cache the binomial table, so they are not efficient.</li>
<li>The floating-point functions return <code>Float64</code>, which are designed for numeric calculation. They use <code>Int, Float64</code> in the internal calculation, and you should pre-call <code>wigner_init_float</code> to calculate and cache the binomial table for later calculation. They may give inaccurate result for vary large angular momentum, due to floating-point arithmetic. They are trustworthy for angular momentum number <code>Jmax &lt;= 60</code>.</li>
</ol>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Exact functions</h4><a id="user-content-exact-functions" class="anchor" aria-label="Permalink: Exact functions" href="#exact-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>CG(j1, j2, j3, m1, m2, m3)</code>, CG-coefficient, arguments are <code>HalfInt</code>s, aka <code>Integer</code> or <code>Rational</code> like <code>3//2</code>.</li>
<li><code>CG0(j1, j2, j3)</code>, CG-coefficient for <code>m1 = m2 = m3 = 0</code>, only integer angular momentum number is meaningful.</li>
<li><code>threeJ(j1, j2, j3, m1, m2, m3)</code>, Wigner 3j-symbol, <code>HalfInt</code> arguments.</li>
<li><code>sixJ(j1, j2, j3, j4, j5, j6)</code>, Wigner 6j-symbol, <code>HalfInt</code> arguments.</li>
<li><code>Racah(j1, j2, j3, j4, j5, j6)</code>, Racah coefficient, <code>HalfInt</code> arguments.</li>
<li><code>nineJ(j1, j2, j3, j4, j5, j6, j7, j8, j9)</code>, Wigner 9j-symbol, <code>HalfInt</code> arguments.</li>
<li><code>norm9J(j2, j3, j4, j5, j5, j6, j7, j8, j9)</code>, normalized 9j-symbol, <code>HalfInt</code> arguments.</li>
<li><code>lsjj(l1, l2, j1, j2, L, S, J)</code>, LS-coupling to jj-coupling transform coefficient. It actually equals to a normalized 9j-symbol, but easy to use and faster. <code>j1, j2</code> can be <code>HalfInt</code>.</li>
<li><code>Moshinsky(N, L, n, l, n1, l1, n2, l2, Λ)</code>, Moshinsky brakets, <code>Integer</code> arguments.</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Float functions</h4><a id="user-content-float-functions" class="anchor" aria-label="Permalink: Float functions" href="#float-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For faster numeric calculation, if the angular momentum number can be half-integer, the argument of the functions is actually double of the number. So that all arguments are integers. The doubled arguments are named starts with <code>d</code>.</p>
<ul dir="auto">
<li><code>fCG(dj1, dj2, dj3, dm1, dm2, dm3)</code>, CG-coefficient.</li>
<li><code>fCG0(j1, j2, j3)</code>, CG-coefficient for <code>m1 = m2 = m3 = 0</code>.</li>
<li><code>fCGspin(ds1, ds2, S)</code>, quicker CG-coefficient for two spin-1/2 coupling.</li>
<li><code>f3j(dj1, dj2, dj3, dm1, dm2, dm3)</code>, Wigner 3j-symbol.</li>
<li><code>f6j(dj1, dj2, dj3, dj4, dj5, dj6)</code>, Wigner 6j-symbol.</li>
<li><code>fRacah(dj1, dj2, dj3, dj4, dj5, dj6)</code>, Racah coefficient.</li>
<li><code>f9j(dj1, dj2, dj3, dj4, dj5, dj6, dj7, dj8, dj9)</code>, Wigner 9j-symbol.</li>
<li><code>fnorm9j(dj1, dj2, dj3, dj4, dj5, dj6, dj7, dj8, dj9)</code>, normalized 9j-symbol.</li>
<li><code>flsjj(l1, l2, dj1, dj2, L, S, J)</code>, LS-coupling to jj-coupling transform coefficient.</li>
<li><code>fMoshinsky(N, L, n, l, n1, l1, n2, l2, Λ)</code>, Moshinsky brakets.</li>
<li><code>dfunc(dj, dm1, dm2, β)</code>, Wigner d-function.</li>
</ul>
