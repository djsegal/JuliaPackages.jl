<p dir="auto">AssigningSecondaryStructure provides a way to assign loops, helices, and strands to protein backbones using a simplified version of the <a href="https://swift.cmbi.umcn.nl/gv/dssp/" rel="nofollow">DSSP</a> algorithm.</p>
<p dir="auto">Both the <a href="https://github.com/BioJulia/BioStructures.jl">BioStructures.jl</a> and <a href="https://github.com/m3g/ProteinSecondaryStructures.jl">ProteinSecondaryStructures.jl</a> packages provide interfaces for more sophisticated secondary structure assignment, but they both call the <a href="https://docs.juliahub.com/General/DSSP_jll/stable/" rel="nofollow">DSSP_jll.jl</a> binary under the hood, which requires writing structures to a file with significant overhead.</p>

<p dir="auto">The package is registered in the General registry, and can be installed from the REPL with <code>]add AssigningSecondaryStructure</code>.</p>

<p dir="auto">This package was originally ported from the <a href="https://github.com/ShintaroMinami/PyDSSP">PyDSSP</a> package, created by Shintaro Minami. The code has since been rewritten to look more like the 1983 paper (Kabsch W and Sander C), and to be more Julian, understandable, and efficient, at the cost of it no longer being differentiable like the PyDSSP version. The time complexity is still quadratic, so it may be slow for larger proteins. We plan on making a more efficient version with k-d trees.</p>
