<p dir="auto">This package is part of my master's thesis on FlipGraphs. It is still unfinished and in active developpment.
If you are not yet familiar with what flip graphs are, I recommend you have a look at <a href="https://en.wikipedia.org/wiki/Flip_graph" rel="nofollow">Wikipedia</a>, or the documentation for this package.</p>

<p dir="auto">To install the package, you first need to install <a href="https://julialang.org" rel="nofollow">Julia</a>.
After starting Julia, type the following:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg 
julia&gt; Pkg.add(&quot;FlipGraphs&quot;)"><pre>julia&gt; <span class="pl-k">using</span> Pkg 
julia&gt; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>FlipGraphs<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">You can start using the package as follows:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using FlipGraphs
