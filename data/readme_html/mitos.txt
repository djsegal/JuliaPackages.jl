<p dir="auto">MIToS provides a comprehensive suite of tools for the analysis of protein sequences and structures.
It allows working with <strong>Multiple Sequence Alignments (MSAs)</strong> to obtain evolutionary information in the Julia language [1].
In particular, it eases the analysis of coevoling position in an MSA using <strong>Mutual Information (MI)</strong>, a measure of covariation.
MI-derived scores are good predictors of inter-residue contacts in a protein structure and functional sites in proteins [2,3].
To allow such analysis, MIToS also implements several useful tools for working with protein structures, such as those available in the <strong>Protein Data Bank (PDB)</strong> or predicted by AlphaFold 2.</p>
<p dir="auto">MIToS starting point was an improvement of the algorithm published by Buslje et al. [2].
A BLOSUM62-based pseudo-count strategy, similar to Altschul et al.[4], , was implemented to improve performance in the range of MSAs with a low number of sequences [1].
<strong>MIToS</strong> offers all the tools for using, developing, and testing MI-based scores—in fact, any measure based on reside frequencies in an MSA—in different modules.</p>

<p dir="auto">MIToS tools are separated into different modules for different tasks.</p>
<ul dir="auto">
<li><strong>MSA</strong> This module defines multiple functions and types for dealing with MSAs and
their annotations. It also includes facilities for sequence clustering and shuffling, among others.</li>
<li><strong>PDB</strong> This module defines types and methods to work with protein structures from
different sources, such as PDB or AlphaFold DB. It includes functions to superpose structures,
measure the distance between residues, and much more.</li>
<li><strong>Information</strong> This module defines residue contingency tables and methods on them to
estimate information measures. This allow to measure evolutionary information on MSAs
positions. It includes functions to estimate corrected mutual information (ZMIp, ZBLMIp)
between MSA columns, as well as conservation estimations using Shannon entropy and the
Kullback-Leibler divergence.</li>
<li><strong>SIFTS</strong> This module allows access to SIFTS residue-level mapping of UniProt, Pfam, and
other databases with PDB entries.</li>
<li><strong>Pfam</strong> This module uses the previous modules to work with Pfam MSAs. It also offers
useful functions for parameter optimization using Pfam alignments.</li>
<li><strong>Utils</strong> It exports common utils functions and types used in different modules of this package.</li>
</ul>

<p dir="auto">The <a href="https://github.com/MIToSOrg/MIToS_Scripts.jl">MIToS_Scripts</a> package offers a set of easy-to-use scripts to access some functionalities MIToS offers from the terminal. These scripts are designed for researchers familiar with command-line interfaces (CLI) but without experience coding in Julia. The available scripts include:</p>
<ul dir="auto">
<li><strong>Buslje09.jl</strong>: Calculates corrected Mutual Information (MI/MIp) based on Buslje et al., 2009.</li>
<li><strong>BLMI.jl</strong>: Computes corrected mutual information using BLOSUM62-based pseudo-counts, as described in the MIToS publication [1].</li>
<li><strong>Conservation.jl</strong>: Calculates Shannon entropy and Kullback-Leibler divergence for each MSA column.</li>
<li><strong>Distances.jl</strong>: Computes inter-residue distances in a PDB file.</li>
<li><strong>PercentIdentity.jl</strong>: Calculates the percentage identity between all sequences in an MSA and provides statistical summaries.</li>
<li><strong>MSADescription.jl</strong>: Provides statistics for a given Stockholm file, including clustering information and sequence coverage.</li>
</ul>
<p dir="auto">This list is not exhaustive; more scripts are available in the <a href="https://github.com/MIToSOrg/MIToS_Scripts.jl">MIToS_Scripts.jl repository</a>. Visit the repository for more details and to access these scripts.</p>
