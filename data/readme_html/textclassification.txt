<p dir="auto">This package provides methods to create fast and simple text classifiers, based on the same idea behind <a href="https://github.com/INGEOTEC/microtc">MicroTC</a>.
The main idea is to perform a model selection among a large space of configurations, including preprocessing steps, weighting schemes, tokenizers (combinations), and classifiers. Moreover, <code>TextClassification.jl</code> also includes support for different classifiers and fine-tune them in the search stage; additional support for weighthing shcmes, and a better support for distributed computing thanks to Julia. As the original implementation, this package is designed to be both domain and language independent.</p>
