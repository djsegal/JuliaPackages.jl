<p dir="auto">ToolipsSVG provides SVG components, a <code>Component{:path}</code> mutation interface, a multiple dispatch interface for managing and setting size, shape, and positions of different components, and SVG shapes for <a href="https://github.com/ChifiSource/Toolips.jl">Toolips</a> and <a href="https://github.com/ChifiSource/Gattino.jl">Gattino</a> powered by <a href="https://github.com/ChifiSource/ToolipsServables.jl">ToolipsServables</a>.</p>

<p dir="auto"><code>ToolipsSVG</code> may be used with or without a <code>Toolips</code> server, but will require an SVG display output of some kind --for example an <a href="">IJulia</a>, <a href="">Olive</a>, <a href="">Pluto</a> notebook, or <a href="">Electron</a> window. To show components, call <code>display("text/html", ::AbstractComponent)</code>. This will usually be called whenever a <code>Component</code> is <em>shown</em>, or returned, as well.</p>

<p dir="auto">In addition to just the basic components to work with, <code>ToolipsSVG</code> also includes a parametric shape interface. This interface has support for the following shapes:</p>
<ul dir="auto">
<li><code>:circle</code></li>
<li><code>:rect</code></li>
<li><code>:square</code></li>
<li><code>:polyshape</code></li>
<li><code>:star</code></li>
</ul>
<p dir="auto">The shape interface consists of</p>
<ul dir="auto">
<li><code>get_position</code></li>
