<p dir="auto">This package provides the following features:</p>
<ul dir="auto">
<li>simple plots can be created with the <code>plot()</code> function</li>
<li>an oscilloscope-like plot with multiple channels can be created
with the <code>plotx()</code> function</li>
<li>an XY plot can be created with the <code>plotxy()</code> function</li>
<li>pan and zoom are supported</li>
<li>LaTeX can be used for the labels</li>
<li>the parameters of the plot commands are stored in a struct and returned</li>
<li>this struct can be displayed again or stored in a file and loaded, the labels etc can be edited and a new plot can be displayed or exported</li>
</ul>

<p dir="auto">A video-like display of a particle system (points, connected by lines) can be created with the
function <code>plot2d</code>. Example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ControlPlots

    global x0, z0

    x0 += 0.1; z0 += 0.1
    sleep(0.1)
end"><pre><span class="pl-k">using</span> ControlPlots

<p dir="auto">When the function is called at t=0 the line, dot and text objects are created. Each time afterwords these
objects are just moved/ updated. Therefore, the update is very fast and you can achieve a high frame rate.
With 10 points you can achieve a framerate of 20 Hz or more, depending on the speed of your hardware.</p>
