<p dir="auto">The package SkyDomes provides a function to calculate the solar radiation on a
horizontal surface (for clear skies) as a function of latitude, day of year and
time of the day and for different wavebands. In addition, it can generate light
sources as required by <a href="https://github.com/VirtualPlantLab/VirtualPlantLab.jl">VirtualPlantLab.jl</a> to
simulate the light distribution in a 3D scene.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Solar radiation</h3><a id="user-content-solar-radiation" class="anchor" aria-label="Permalink: Solar radiation" href="#solar-radiation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Use the <code>clear_sky</code> function to calculate the solar radiation on a horizontal
plane as a function of day of year, latitude (in radians) and the relative solar
time of the day (<code>f = 0</code> is sunrise, <code>f = 1</code> is sunset). The function returns
the total solar radiation in W/m² as well as direct and diffuse components. For
example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SkyDomes
lat = 52.0*π/180.0 # latitude in radians
DOY = 182
f = 0.5 # solar noon
Ig, Idir, Idif, theta, phi = clear_sky(lat = lat, DOY = DOY, f = f) # W/m2"><pre><span class="pl-k">using</span> SkyDomes
lat <span class="pl-k">=</span> <span class="pl-c1">52.0</span><span class="pl-k">*</span>π<span class="pl-k">/</span><span class="pl-c1">180.0</span> <span class="pl-c"><span class="pl-c">#</span> latitude in radians</span>
DOY <span class="pl-k">=</span> <span class="pl-c1">182</span>
f <span class="pl-k">=</span> <span class="pl-c1">0.5</span> <span class="pl-c"><span class="pl-c">#</span> solar noon</span>
Ig, Idir, Idif, theta, phi <span class="pl-k">=</span> <span class="pl-c1">clear_sky</span>(lat <span class="pl-k">=</span> lat, DOY <span class="pl-k">=</span> DOY, f <span class="pl-k">=</span> f) <span class="pl-c"><span class="pl-c">#</span> W/m2</span></pre></div>
<p dir="auto">The values <code>Ig</code>, <code>Idir</code> and <code>Idif</code> are the total, direct and diffuse solar
radiation in W/m². The function <code>waveband_conversion</code> can be used to convert
these values to specific wavebands (UV, PAR, NIR, blue, green or red) as well
as converting from W/m² to umol/m²/s, assuming particular spectra for
direct and diffuse solar radiation. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="f_PAR_dir = waveband_conversion(Itype = :direct, waveband = :PAR, mode = :flux)

<p dir="auto">Once the direct and diffuse solar radiation in the relevant wavebands and units
have been calculated, the function <code>SkyDomes</code> can be used to generate the light
sources required by VPL to simulate the light distribution in a 3D scene. For
example, a simple horizontal tile (representing soil) in VPL may be created as
follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using VirtualPlantLab

<p dir="auto">A 3D scene requires adding optical properties (e.g., a black material property)
and linking these to the mesh (for complicated scenes see <a href="http://virtualplantlab.com/" rel="nofollow">VPL documentation</a>
for examples):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="materials = [Black()]

<p dir="auto">If we want to compute the amount of solar radiation absorbed by this tile, we
need to create a series of light sources. The function <code>SkyDomes</code> can be used for
that purpose:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="sources = sky(scene,

<p dir="auto">The function takes the scene as input to ensure that light sources scale with
the scene. Direct solar radiation is represented by a single directional light
source that will emit a number of rays given by <code>nrays_dir</code>. Diffuse solar
radiation is represented by a hemispherical dome of directional light sources
that will emit a total of <code>nrays_dif</code> rays. The angular distribution of the
diffuse solar radiation and the discretization of the SkyDomes dome can be modified
via <code>dome_method</code>, <code>sky_model</code>, <code>ntheta</code> and <code>nphi</code>. See API documentation and
<a href="http://virtualplantlab.com/" rel="nofollow">VPL documentation</a> for details.</p>
<p dir="auto">Once the light sources are created, a ray tracing object can be generated
combining all the elements above:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="settings = RTSettings(parallel = true)
rtobj = RayTracer(scene, sources, settings = settings);"><pre>settings <span class="pl-k">=</span> <span class="pl-c1">RTSettings</span>(parallel <span class="pl-k">=</span> <span class="pl-c1">true</span>)
rtobj <span class="pl-k">=</span> <span class="pl-c1">RayTracer</span>(scene, sources, settings <span class="pl-k">=</span> settings);</pre></div>
<p dir="auto">And the ray tracing can be performed by calling the <code>trace!</code> function:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="trace!(rtobj);"><pre><span class="pl-c1">trace!</span>(rtobj);</pre></div>
<p dir="auto">As expected, the amount of solar radiation absorbed by the tile equals the
total in the scene (<code>Ig</code>):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="power(materials[1])[1]/area(r) ≈ Idir_PAR + Idif_PAR"><pre><span class="pl-c1">power</span>(materials[<span class="pl-c1">1</span>])[<span class="pl-c1">1</span>]<span class="pl-k">/</span><span class="pl-c1">area</span>(r) <span class="pl-k">≈</span> Idir_PAR <span class="pl-k">+</span> Idif_PAR</pre></div>
<p dir="auto">See <a href="http://virtualplantlab.com/" rel="nofollow">VPL documentation</a> for more details and
