<p dir="auto">This package provides the functions for total variation (TV) denoising with gradient projection (GP) and fast gradient projection (FGP). GP/FGP denoises of (volume) image <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathbf{b}$</math-renderer> based on the following minimization problem</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$$\min_{\mathbf{x}\in{C}}\|\mathbf{x} - \mathbf{b}\|^{2}_{F} + 2\lambda\mathrm{TV}(\mathbf{x}),$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$C$</math-renderer> is a convex closed set, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\|\cdot\|_{F}$</math-renderer> is the Frobenius norm, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\lambda$</math-renderer> is the regularization parameter, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathrm{TV}$</math-renderer> is the total variation defined by</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$$\begin{align}
\mathrm{TV}_{I}(\mathbf{x}) &amp;=
\begin{cases}
\sum_{i}\sum_{j}\sqrt{\left(x_{i,j} - x_{i+1,j}\right)^{2} + \left(x_{i,j} - x_{i,j+1}\right)^{2}} &amp; \text{(2D)}\\
\sum_{i}\sum_{j}\sum_{k}\sqrt{\left(x_{i,j,k} - x_{i+1,j,k}\right)^{2} + \left(x_{i,j,k} - x_{i,j+1,k}\right)^{2} + \left(x_{i,j,k} - x_{i,j,k+1}\right)^{2}} &amp; \text{(3D)}
\end{cases},\\
\mathrm{TV}_{l_{1}}(\mathbf{x}) &amp;=
\begin{cases}
\sum_{i}\sum_{j}\left\{\left|x_{i,j} - x_{i+1,j}\right| + \left|x_{i,j} - x_{i,j+1}\right|\right\} &amp; \text{(2D)}\\
\sum_{i}\sum_{j}\sum_{k}\left\{\left|x_{i,j,k} - x_{i+1,j,k}\right| + \left|x_{i,j,k} - x_{i,j+1,k}\right| + \left|x_{i,j,k} - x_{i,j,k+1}\right|\right\} &amp; \text{(3D)}
\end{cases}.
\end{align}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathrm{TV}_{I}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathrm{TV}_{l_{1}}$</math-renderer> express isotropic and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$l_{1}$</math-renderer>-based anisotropic TV, respectively.</p>
<p dir="auto">For more information on the algorithm, please refer to the following reference.</p>
<blockquote>
<p dir="auto"><a href="https://doi.org/10.1109/TIP.2009.2028250" rel="nofollow">Amir Beck and Marc Teboulle, "Fast Gradient-Based Algorithms for Constrained Total Variation Image Denoising and Deblurring Problems," IEEE Trans. Image Process. <strong>18</strong>, 2419-2434 (2009)</a></p>
</blockquote>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Usage</h1><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Import the package first.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using FastGradientProjection"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> FastGradientProjection</pre></div>
<p dir="auto">For example, perform the following to denoise (volume) image <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathbf{b}$</math-renderer> with FGP.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; x = FGP(b, 0.1, 100, lower_bound=0.0, upper_bound=1.0)"><pre>julia<span class="pl-k">&gt;</span> x <span class="pl-k">=</span> <span class="pl-c1">FGP</span>(b, <span class="pl-c1">0.1</span>, <span class="pl-c1">100</span>, lower_bound<span class="pl-k">=</span><span class="pl-c1">0.0</span>, upper_bound<span class="pl-k">=</span><span class="pl-c1">1.0</span>)</pre></div>
<p dir="auto">The second and third arguments are the regularization parameter <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\lambda$</math-renderer> and the number of iterations. The values specified by the keyword arguments <code>lower_bound</code> and <code>upper_bound</code> are the upper and lower bounds of the convex closed set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$C$</math-renderer>. These default values are <code>lower_bound=-Inf</code> and <code>upper_bound=Inf</code>. If <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$\mathbf{b}$</math-renderer> is a complex array, projection to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0636a5f45da39730f3ba0e97f7861bc9">$C$</math-renderer> is not performed. The function FGP performs denoising based on isotropic TV by default; to perform denoising based on anisotropic TV, specify the keyword argument <code>TV="aniso"</code>. Refer to the <a href="https://syoshida1983.github.io/FastGradientProjection.jl/stable/" rel="nofollow">documentation</a> for further information.</p>
