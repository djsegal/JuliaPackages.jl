<p dir="auto">Julia package for the implementation of q-deformed Wigner Symbols. Additionally, this
provides an extension to <a href="https://github.com/Jutho/TensorKit.jl">TensorKit.jl</a> for working
with tensors that have q-deformed SU(2) symmetry.</p>

<p dir="auto">Currently, the package provides the following exported functions that define
<a href="https://en.wikipedia.org/wiki/Q-analog" rel="nofollow">q-analogs</a>:</p>
<ul dir="auto">
<li>
<code>q_number(n::Integer, q::Number)</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d4158ea9586a8ccb16df685a1d7d60b9">$[n]_q = \frac{1 - q^n}{1 - q}$</math-renderer>
</li>
<li>
<code>q_factorial(n::Integer, q::Number)</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d4158ea9586a8ccb16df685a1d7d60b9">$[n]_q! = \prod [k]_q$</math-renderer>
</li>
<li>
<code>q_binomial(n::Integer, k::Integer, q::Number)</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d4158ea9586a8ccb16df685a1d7d60b9">$\binom{n}{k}_q = \frac{[n]_q!}{[k]_q! [n-k]_q!}$</math-renderer>
</li>
</ul>
<p dir="auto">The following functions are exported for the calculation of q-deformed Wigner Symbols, which
serve a similar function as their
<a href="https://github.com/Jutho/WignerSymbols.jl"><code>WignerSymbols.jl</code></a> q-less counterparts:</p>
<ul dir="auto">
<li><code>q_wigner3j(j1, j2, j3, m1, m2, m3, q)</code></li>
<li><code>q_clebschgorda(j1, j2, j3, m1, m2, m3, q)</code></li>
<li><code>q_wigner6j(j1, j2, j3, j4, j5, j6, q)</code></li>
<li><code>q_racahW(j1, j2, J, j3, J12, J23, q)</code></li>
</ul>
<p dir="auto">Finally, these can be utilized to construct q-deformed symmetric tensors, by using
<code>SU2qIrrep{q}</code> as a drop-in replacement for
<a href="https://github.com/Jutho/TensorKit.jl"><code>TensorKit.jl</code></a>'s <code>SU2Irrep</code>:</p>
