<p dir="auto">An interface to various automatic differentiation (AD) backends in Julia.</p>

<p dir="auto">This package provides a unified syntax to differentiate functions.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>First- and second-order operators (gradients, Jacobians, Hessians and more)</li>
<li>In-place and out-of-place differentiation</li>
<li>Preparation mechanism (e.g. to create a config or tape)</li>
<li>Built-in sparsity handling</li>
<li>Thorough validation on standard inputs and outputs (numbers, vectors, matrices)</li>
<li>Testing and benchmarking utilities accessible to users with <a href="https://github.com/gdalle/DifferentiationInterface.jl/tree/main/DifferentiationInterfaceTest">DifferentiationInterfaceTest</a></li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Compatibility</h2><a id="user-content-compatibility" class="anchor" aria-label="Permalink: Compatibility" href="#compatibility"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We support all of the backends defined by <a href="https://github.com/SciML/ADTypes.jl">ADTypes.jl</a>:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaDiff/ChainRulesCore.jl">ChainRulesCore.jl</a></li>
<li><a href="https://github.com/JuliaDiff/Diffractor.jl">Diffractor.jl</a></li>
<li><a href="https://github.com/EnzymeAD/Enzyme.jl">Enzyme.jl</a></li>
<li><a href="https://github.com/brianguenter/FastDifferentiation.jl">FastDifferentiation.jl</a></li>
<li><a href="https://github.com/JuliaDiff/FiniteDiff.jl">FiniteDiff.jl</a></li>
<li><a href="https://github.com/JuliaDiff/FiniteDifferences.jl">FiniteDifferences.jl</a></li>
<li><a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a></li>
<li><a href="https://github.com/JuliaDiff/PolyesterForwardDiff.jl">PolyesterForwardDiff.jl</a></li>
<li><a href="https://github.com/JuliaDiff/ReverseDiff.jl">ReverseDiff.jl</a></li>
<li><a href="https://github.com/JuliaSymbolics/Symbolics.jl">Symbolics.jl</a></li>
<li><a href="https://github.com/withbayes/Tapir.jl">Tapir.jl</a></li>
<li><a href="https://github.com/FluxML/Tracker.jl">Tracker.jl</a></li>
<li><a href="https://github.com/FluxML/Zygote.jl">Zygote.jl</a></li>
</ul>
<p dir="auto">Note that in some cases, going through DifferentiationInterface.jl might be slower than a direct call to the backend's API.
This is mostly true for Enzyme.jl, whose handling of activities and multiple arguments unlocks additional performance.
We are working on this challenge, and welcome any suggestions or contributions.
Meanwhile, if differentiation fails or takes too long, consider using Enzyme.jl directly.</p>
