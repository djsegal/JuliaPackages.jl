<p dir="auto">Anthropic.jl is a Julia package that provides a simple interface to interact with Anthropic's AI models, particularly Claude. It extends the functionality of <a href="https://github.com/svilupp/PromptingTools.jl">PromptingTools.jl</a> to support streaming responses from Anthropic's API.</p>
