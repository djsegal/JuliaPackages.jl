<ul dir="auto">
<li>Create an API specification. Check out <a href="https://github.com/OAI/OpenAPI-Specification">OpenAPI-Spec</a> for specification syntax and examples.</li>
<li>Use <a href="https://openapi-generator.tech/docs/generators" rel="nofollow">instructions</a> provided for the Julia OpenAPI code generator plugin to generate Julia code.</li>
<li>Client:
<ul dir="auto">
<li>Use the generated client in Julia directly to invoke APIs</li>
</ul>
</li>
<li>Server:
<ul dir="auto">
<li>Provide code to handle API invocations on the server side by implementing the Julia methods corresponding to API stubs.</li>
<li>Start a server using HTTP.jl and register the generated request handlers.</li>
</ul>
</li>
</ul>
