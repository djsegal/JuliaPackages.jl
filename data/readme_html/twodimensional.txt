<p dir="auto"><code>TwoDimensional</code> is a <a href="https://julialang.org/" rel="nofollow">Julia</a> package which provides useful types
and methods to define and manipulate 2-dimensional objects (points, rectangles,
circles, polygons, and bounding-boxes) and affine coordinate transforms. This
package also offers methods to build masks from the composition of elementary
shapes.</p>
<p dir="auto">Other related packages:</p>
<ul dir="auto">
<li><a href="https://github.com/FugroRoames/CoordinateTransformations.jl">CoordinateTransformations</a>
for coordinate transformations;</li>
<li><a href="https://github.com/JuliaGeometry/GeometryBasics.jl">GeometryBasics</a> for
basic geometric types;</li>
<li><a href="https://github.com/JuliaGraphics/Graphics.jl">Graphics</a> for basic graphical
objects and methods;</li>
</ul>

<p dir="auto"><code>TwoDimensional</code> is an <a href="https://pkg.julialang.org/" rel="nofollow">official Julia package</a> so you can

the <code>]</code> key to switch to the package manager REPL (you should get a <code>... pkg&gt;</code>
prompt) and type:</p>
