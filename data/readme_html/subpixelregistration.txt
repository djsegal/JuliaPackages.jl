<p dir="auto">Image registration with subpixel precision using an upsampled discrete Fourier transform cross-correlation. This uses an efficient matrix-multiplication algorithm for upsampling the cross-correlation following Guizar-Sicairos, Thurman, and Fienup (2008).<sup><a href="#user-content-fn-1-fc2532729391a9dccff3d18075b3e307" id="user-content-fnref-1-fc2532729391a9dccff3d18075b3e307" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup></p>
