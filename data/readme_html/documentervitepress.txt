<p dir="auto">This package provides a Markdown / MkDocs backend to <a href="https://documenter.juliadocs.org/stable/" rel="nofollow">Documenter.jl</a>.</p>

<p dir="auto">To enable the backend:</p>
<ol dir="auto">
<li>Import the package in <code>make.jl</code>,</li>
<li>Pass <code>format = DocumenterVitepress.MarkdownVitepress(...)</code> to <code>makedocs</code> like so:</li>
</ol>

    )"><pre><span class="pl-k">using</span> Documenter
