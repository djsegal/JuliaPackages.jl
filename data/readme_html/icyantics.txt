<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Proposal</h1><a id="user-content-proposal" class="anchor" aria-label="Permalink: Proposal" href="#proposal"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We propose to develop <code>IcyAntics.jl</code> as a sea ice modeling package for both off-line sea ice simulations with prescribed atmosphere-ocean thermomechanical states, and for coupled ice-ocean and ice-atmosphere-ocean simulations at kilometer to planetary scales.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Mission</h2><a id="user-content-mission" class="anchor" aria-label="Permalink: Mission" href="#mission"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>IcyAntics.jl</code> will enable</p>
<ul dir="auto">
<li>Data-driven sea ice parameterization and model development;</li>
<li><a href="https://github.com/CliMA/OceanLearning.jl">Parameter estimation and uncertainty quantification</a> for new and existing sea ice models;</li>
<li>High resolution, high performance coupled and uncopuled sea ice simulations with a high-level, user-friendly <code>Oceananigans</code>-like interface.</li>
</ul>

<p dir="auto">Core capabilities will rest on existing, tested sea ice modeling paradigms.
We propose independent efforts to implement the following core capabilities:</p>
<ul dir="auto">
<li><code>ContinuumIceModel</code> with <code>ElastoViscoPlastic</code> rheology with either explicit time-stepping or implicit treatment of pseudoelastic dynamics (<a href="https://journals.ametsoc.org/view/journals/phoc/27/9/1520-0485_1997_027_1849_aevpmf_2.0.co_2.xml" rel="nofollow">Hunke and Dukowicz 1997</a>, <a href="https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2018MS001485" rel="nofollow">Koldunov et al. 2019</a>)</li>
<li><code>DiscreteElementIceModel</code> Lagrangian ice model (<a href="https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2021MS002513" rel="nofollow">Chen et al. 2021</a>)</li>
<li><code>ContinuumIceModel</code> with <code>ViscoPlastic</code> rheology and implicit time-stepping with a nonlinear implicit solver (<a href="https://agupubs.onlinelibrary.wiley.com/doi/epdf/10.1029/96JC03744" rel="nofollow">Zhang and Hibler 1997</a>, <a href="https://www.sciencedirect.com/science/article/pii/S1463500309002418?casa_token=7X6zEGzN43EAAAAA:A1PtPqOSnE-8u9aHyvc2rfffv48yv7sJIbAwyhD1PHb3U_rNFcepGKOMa12wMXqXsI5QDlh4zg" rel="nofollow">Losch et al. 2010</a>)</li>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Research directions</h2><a id="user-content-research-directions" class="anchor" aria-label="Permalink: Research directions" href="#research-directions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Research directions are community-defined.
We <em>propose</em> the following:</p>
<ul dir="auto">
<li>Offline parameter estimation of free parameters in sea ice viscoplastic rheologies, elasto-brittle rheologies, damage models, and therodynamic models;</li>
<li>Coupled ice-ocean parameter estimation for sea ice models and ocean turbulence parameterizations;</li>
<li>Extension of discrete element methods to approximate viscoplastic, elasto-brittle, and other sea ice rheology paradigms;</li>
<li>Numerical methods for sea ice modeling including high-order finite volume formulations and semi-Lagrangian finite volume advection schemes.</li>
</ul>

<p dir="auto">The following code from <a href="https://github.com/glwagner/IcyAntics.jl/blob/main/examples/viscoelastic_ice.jl"><code>examples/viscoelastic_ice.jl</code></a> implements a numerical simulation of a "toy" viscoelastic sea ice model with uniform concentration coupled to a barotropic turbulence ocean model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Oceananigans
using Oceananigans.Units
using GLMakie
using IcyAntics
using IcyAntics: time_step!

#####
##### Domain: 2D grid with 100km square extent, ~500m resolution
#####

arch = CPU() # change to GPU() to run coupled simulation on GPU.
Nx = Ny = 256
Lx = Ly = 100kilometers

grid = RectilinearGrid(arch,
                       size = (Nx, Ny),
                       halo = (3, 3),
                       x = (0, Lx),
                       y = (0, Ly),
                       topology = (Periodic, Periodic, Flat))

#####
##### Barotropic turbulence ocean simulation
#####

# Ocean mesoscale closure: biharmonic diffusivity
Δh = grid.Δxᶜᵃᵃ
closure = HorizontalScalarBiharmonicDiffusivity(ν = Δh^4 / 4hour)

ocean_model = NonhydrostaticModel(; grid, closure,
                                  timestepper = :RungeKutta3,
                                  advection = WENO(),
                                  buoyancy = nothing,
                                  tracers = nothing)

# Spin up the ocean model
ϵ(x, y, z) = randn()
set!(ocean_model, u=ϵ, v=ϵ) # random initial velocities
ocean_simulation = Simulation(ocean_model, Δt=2minutes, stop_time=12hours)
run!(ocean_simulation) # generate smooth ocean velocities
ocean_simulation.stop_time = Inf

#####
##### Simple viscoelastic ice model
#####

ocean_state = (; u=ocean_model.velocities.u, v=ocean_model.velocities.v, ρ=1024.0)
rheology = ViscoElasticRheology(modulus=1.0, viscosity=1e4)
@show ice_Δt = 1e-1 * min(Δh / sqrt(rheology.modulus), Δh^2 / (2 * rheology.viscosity))

# Spin up the ice model
ice_model = ContinuumIceModel(; grid, ocean=ocean_state, rheology)
ice_simulation = Simulation(ice_model, Δt=ice_Δt)

#####
##### Construct coupled simulation with substepping
#####

function coupled_time_step!(ocean_simulation, ice_simulation)
    # Floor ice_simulation Δt so `Nsubsteps` ice steps = one ocean step.
    Nsubsteps = ceil(Int, ocean_simulation.Δt / ice_simulation.Δt)
    ice_simulation.Δt = ocean_simulation.Δt / Nsubsteps

    # Substep ice model
    for substep = 1:Nsubsteps
        time_step!(ice_simulation)
    end

    time_step!(ocean_simulation)

    return nothing
end

#####
##### Visualization and coupled run
#####

n = Observable(1) # for visualization

# Ocean vorticity
uo, vo, wo = ocean_model.velocities
ocean_vorticity = Field(∂x(vo) - ∂y(uo))
ocean_vorticity_n = @lift ($n; interior(compute!(ocean_vorticity))[:, :, 1])

# Ice speed
ui, vi = ice_model.velocities
ice_speed = Field(sqrt(ui^2 + vi^2))
ice_speed_n = @lift ($n; interior(compute!(ice_speed))[:, :, 1])

# Make figure
x, y, z = nodes((Center, Center, Center), grid)
fig = Figure(resolution=(800, 400))
ax_i = Axis(fig[1, 1], aspect=1, xlabel=&quot;x (km)&quot;, ylabel=&quot;y (km)&quot;, title=&quot;Ice speed&quot;)
ax_o = Axis(fig[1, 2], aspect=1, xlabel=&quot;x (km)&quot;, ylabel=&quot;y (km)&quot;, title=&quot;Ocean vorticity&quot;)
hm_i = heatmap!(ax_i, 1e-3 * x, 1e-3 * y, ice_speed_n)
hm_o = heatmap!(ax_o, 1e-3 * x, 1e-3 * y, ocean_vorticity_n, colormap=:redblue)
title = @lift ($n; &quot;Coupled ice-ocean simulation after &quot; * prettytime(ice_model.clock.time))
Label(fig[0, :], title)
display(fig)

# Step forward and animate
N = 20
record(fig, &quot;viscoelastic_ice.gif&quot;, 1:N, framerate=12) do i
    @info &quot;Plotting frame $i of $N...&quot;
    @time for _ = 1:10
        coupled_time_step!(ocean_simulation, ice_simulation)
    end
    n[] = 1
end

rheology <span class="pl-k">=</span> <span class="pl-c1">ViscoElasticRheology</span>(modulus<span class="pl-k">=</span><span class="pl-c1">1.0</span>, viscosity<span class="pl-k">=</span><span class="pl-c1">1e4</span>)
<span class="pl-c1">@show</span> ice_Δt <span class="pl-k">=</span> <span class="pl-c1">1e-1</span> <span class="pl-k">*</span> <span class="pl-c1">min</span>(Δh <span class="pl-k">/</span> <span class="pl-c1">sqrt</span>(rheology<span class="pl-k">.</span>modulus), Δh<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">/</span> (<span class="pl-c1">2</span> <span class="pl-k">*</span> rheology<span class="pl-k">.</span>viscosity))

<span class="pl-c"><span class="pl-c">#</span> Spin up the ice model</span>
ice_model <span class="pl-k">=</span> <span class="pl-c1">ContinuumIceModel</span>(; grid, ocean<span class="pl-k">=</span>ocean_state, rheology)
ice_simulation <span class="pl-k">=</span> <span class="pl-c1">Simulation</span>(ice_model, Δt<span class="pl-k">=</span>ice_Δt)

<span class="pl-c"><span class="pl-c">#</span>####</span>
<span class="pl-c"><span class="pl-c">#</span>#### Construct coupled simulation with substepping</span>
<span class="pl-c"><span class="pl-c">#</span>####</span>

<span class="pl-k">function</span> <span class="pl-en">coupled_time_step!</span>(ocean_simulation, ice_simulation)
    <span class="pl-c"><span class="pl-c">#</span> Floor ice_simulation Δt so `Nsubsteps` ice steps = one ocean step.</span>
    Nsubsteps <span class="pl-k">=</span> <span class="pl-c1">ceil</span>(Int, ocean_simulation<span class="pl-k">.</span>Δt <span class="pl-k">/</span> ice_simulation<span class="pl-k">.</span>Δt)
    ice_simulation<span class="pl-k">.</span>Δt <span class="pl-k">=</span> ocean_simulation<span class="pl-k">.</span>Δt <span class="pl-k">/</span> Nsubsteps

    <span class="pl-c"><span class="pl-c">#</span> Substep ice model</span>
    <span class="pl-k">for</span> substep <span class="pl-k">=</span> <span class="pl-c1">1</span><span class="pl-k">:</span>Nsubsteps
        <span class="pl-c1">time_step!</span>(ice_simulation)
    <span class="pl-k">end</span>

    <span class="pl-c1">time_step!</span>(ocean_simulation)

    <span class="pl-k">return</span> <span class="pl-c1">nothing</span>
<span class="pl-k">end</span>

n <span class="pl-k">=</span> <span class="pl-c1">Observable</span>(<span class="pl-c1">1</span>) <span class="pl-c"><span class="pl-c">#</span> for visualization</span>

<span class="pl-c"><span class="pl-c">#</span> Ocean vorticity</span>
uo, vo, wo <span class="pl-k">=</span> ocean_model<span class="pl-k">.</span>velocities
ocean_vorticity <span class="pl-k">=</span> <span class="pl-c1">Field</span>(<span class="pl-c1">∂x</span>(vo) <span class="pl-k">-</span> <span class="pl-c1">∂y</span>(uo))
ocean_vorticity_n <span class="pl-k">=</span> <span class="pl-c1">@lift</span> (<span class="pl-k">$</span>n; <span class="pl-c1">interior</span>(<span class="pl-c1">compute!</span>(ocean_vorticity))[:, :, <span class="pl-c1">1</span>])

<span class="pl-c"><span class="pl-c">#</span> Ice speed</span>
ui, vi <span class="pl-k">=</span> ice_model<span class="pl-k">.</span>velocities
ice_speed <span class="pl-k">=</span> <span class="pl-c1">Field</span>(<span class="pl-c1">sqrt</span>(ui<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">+</span> vi<span class="pl-k">^</span><span class="pl-c1">2</span>))
ice_speed_n <span class="pl-k">=</span> <span class="pl-c1">@lift</span> (<span class="pl-k">$</span>n; <span class="pl-c1">interior</span>(<span class="pl-c1">compute!</span>(ice_speed))[:, :, <span class="pl-c1">1</span>])

<span class="pl-c"><span class="pl-c">#</span> Make figure</span>
x, y, z <span class="pl-k">=</span> <span class="pl-c1">nodes</span>((Center, Center, Center), grid)
fig <span class="pl-k">=</span> <span class="pl-c1">Figure</span>(resolution<span class="pl-k">=</span>(<span class="pl-c1">800</span>, <span class="pl-c1">400</span>))

ax_o <span class="pl-k">=</span> <span class="pl-c1">Axis</span>(fig[<span class="pl-c1">1</span>, <span class="pl-c1">2</span>], aspect<span class="pl-k">=</span><span class="pl-c1">1</span>, xlabel<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>x (km)<span class="pl-pds">"</span></span>, ylabel<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>y (km)<span class="pl-pds">"</span></span>, title<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>Ocean vorticity<span class="pl-pds">"</span></span>)
