<p dir="auto">The <code>parsebasis</code> method takes an XYZ file and returns a list of <code>GaussianBasisSet</code> objects.
The XYZ file is a simple text file that contains the number of atoms in the first line,
followed by the atomic symbols and the Cartesian coordinates of each atom.
For example, the following is the XYZ file for a water molecule:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="3

O 0.000000 -0.007156 0.965491
H 0.000000 0.001486 -0.003471
H 0.000000 0.931026 1.207929"><pre><span class="pl-c1">3</span>
