<p dir="auto"><code>PGA</code> peak ground acceleration.</p>
<p dir="auto"><code>PGV</code> peak ground velocity.</p>
<p dir="auto"><code>PSA</code> peak spectral acceleration.</p>
<p dir="auto"><code>VS30</code> the time-averaged shear-wave velocity to 30 m depth,
<a href="https://earthquake.usgs.gov/data/vs30/" rel="nofollow">data</a>.</p>
<p dir="auto"><code>SSI</code> seismic scale intensity (Russian GOST R 57546-2017, see Appendix 1).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basic Principles of Ground Motion Assessment</h2><a id="user-content-basic-principles-of-ground-motion-assessment" class="anchor" aria-label="Permalink: Basic Principles of Ground Motion Assessment" href="#basic-principles-of-ground-motion-assessment"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Names of GMPE functions looks like: <code>gmpe_{Name_of_gmpe_function}</code>. For
example: <code>gmpe_as2008</code>, where <code>as2008</code> is Abrahamson and Silva 2008 GMPE Model.
The configuration for a model (see <code>examples/*.conf</code>) has <code>ground_motion_type</code>
that can be <code>PGA</code>,<code>PGV</code>,<code>PSA</code> and define the type of output data points.</p>
<p dir="auto">Each GMPE function has at least 2 methods: for calculation based on input
VS30-grid or without any grid (where VS30 is considered to be constant).</p>
<p dir="auto">Although the GMPE field is obtained by modeling using earthquake source
parameters, it can be corrected using observed intensity data such as
measurements at seismic sites or felt reports. To this end, the <code>gmpe_corr</code>
routine is used to calculate a new GMPE PGA/intensity grid using simple the
weighted average method. For technical details see
<a href="https://preprints.ru/article/1013" rel="nofollow">preprint</a> (Russian).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">GRID case</h3><a id="user-content-grid-case" class="anchor" aria-label="Permalink: GRID case" href="#grid-case"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The GMPE function for each grid's point calculates <code>{pga/pgv/psa}</code> values using
<code>latitude</code>, <code>longitude</code> [degrees for WGS84 ellipsoid] and <code>VS30</code> [m/s]. The
output data has return in custom type (depends by config) where latitude and
longitude are copy from input grid and <code>pga/pgv/pgd/psa</code> is calculated by
function.</p>
<p dir="auto">For example: the function <code>gmpe_as2008</code> with parameters</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pga_as2008(
    eq::Earthquake,

)"><pre><span class="pl-c1">pga_as2008</span>(

<p dir="auto">where <code>ground_motion_type = "PGA"</code> at <code>config</code>, returns 1-d is
<code>Array{Point_pga_out}</code> with points based on input grid and <code>pga &gt; min_val</code>
(<code>pga</code> is Acceleration of gravity in percent (%g) rounded to <code>ggg.gg</code>).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Without grid</h3><a id="user-content-without-grid" class="anchor" aria-label="Permalink: Without grid" href="#without-grid"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In case of without any grid GMPE functions return simple 1-d <code>Array{Float64}</code>
with <code>{pga/pgv/pgd/psa}</code> data. It calculates from epicenter to <code>distance</code> with
<code>1</code> [km] step perpendicularly to the epicenter.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pga_as2008(

<code>1:distance</code> values of <code>pga</code> (also rounded to <code>ggg.gg</code>).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">GMPE correction by weighted averaging method</h3><a id="user-content-gmpe-correction-by-weighted-averaging-method" class="anchor" aria-label="Permalink: GMPE correction by weighted averaging method" href="#gmpe-correction-by-weighted-averaging-method"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>gmpe_corr</code> function fan in a computed GMPE filed in <code>Array{Point_pga_out</code>
format and measurements in <code>Array{Point_felt_report}</code> type. The measurements
can be of two types: exact PGA by an seismic station or aggregated felt report.</p>

<p dir="auto">Input:</p>
<ul dir="auto">
<li><code>config</code> configuration of weighted averaging procedure</li>
<li><code>grid</code> GMPE field modeling by any of <code>gmpe_*</code> method</li>

<li><code>intensity_in_pga</code> is the intensity measures in PGA %g.gg units? Otherwise intensity in SSI is assumes.</li>

<p dir="auto"><code>min_val=0</code>, <code>Xvf=0</code> [km] by default. <code>Dl=250</code> [km] by default in case of grid
pass without Dl data.</p>
<p dir="auto">NOTE that <code>gmpe_mf2013</code> has next keyword arguments: <code>min_val</code>, <code>min_val</code>, <code>Dl</code>,
<code>VS30</code>, <code>distance</code>. The keyword arguments should be pass with name. Example:
<code>gmpe_mf2013(eq,config,VS30=500,Xvf=40)</code>.</p>
<p dir="auto">For model parameters see <code>examples/morikawa-fujiwara-2013.conf</code> (<code>PGA</code>, <code>PGV</code>,
<code>PSA</code>). <strong>X</strong> is a distance to hypocenter.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">About Dl variable</h4><a id="user-content-about-dl-variable" class="anchor" aria-label="Permalink: About Dl variable" href="#about-dl-variable"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>Dl</code> is the top depth to the layer whose S-wave velocity is <code>l</code> (in
<code>[m/s]</code>) at the site. Actually it should be another one grid with <code>Dl</code> depths
on each grid point (<code>Point_vs30_dl</code> type). If you pass grid without <code>Dl</code>, then
<code>Dl</code> variable pass to GMPE functions as a constant.</p>
