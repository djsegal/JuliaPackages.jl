<p dir="auto">This package provides a unified interface for simulating and evaluating sequential sampling models (SSMs) in Julia. SSMs describe decision making as a stochastic and dynamic evidence accumulation process in which a decision is triggered by the option whose evidence hits a decision treshold first.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/assets/rdm.gif"><img src="docs/src/assets/rdm.gif" alt="" data-animated-image="" style="max-width: 100%;"></a></p>

<p dir="auto">The core API consists of the following</p>
<ul dir="auto">
<li>rand: generate simulated data</li>
<li>pdf: evaluate the probability density of the data</li>
<li>logpdf: evaluate the log probability density of the data</li>
<li>simulate: generate samples from the internal evidence accumulation process</li>
</ul>

<p dir="auto">SSMs work with the following packages (and possibly more):</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaStats/Distributions.jl">Distributions.jl</a>: functions for probability distributions</li>
<li><a href="http://pigeons.run/dev/" rel="nofollow">Pigeons.jl</a>: Bayesian parameter estimation and Bayes factors</li>
<li><a href="https://github.com/JuliaPlots/Plots.jl">Plots.jl</a>: extended plotting tools for SSMs</li>
<li><a href="https://turinglang.org/dev/docs/using-turing/get-started" rel="nofollow">Turing.jl</a>: Bayesian parameter estimation</li>
</ul>
