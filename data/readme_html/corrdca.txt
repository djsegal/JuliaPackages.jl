<p dir="auto">Simple package that:</p>
<ul dir="auto">
<li>
<p dir="auto">Reads FASTA files and translate it in a numerical matrix</p>
</li>
<li>
<p dir="auto">Computes the reweighting score as described in <a href="https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0092721" rel="nofollow">"Fast and accurate multivariate Gaussian modeling of protein families: Predicting residue contacts and protein-interaction partners"</a> by Carlo Baldassi, Marco Zamparo, Christoph Feinauer, Andrea Procaccini, Riccardo Zecchina, Martin Weigt and Andrea Pagnani, (2014) PLoS ONE 9(3): e92721. doi:10.1371/journal.pone.0092721</p>
</li>
<li>
<p dir="auto">Compute empirical frequency counts (with and without pseudocount)</p>
</li>
</ul>

<p dir="auto">The computation of the sequence weights is typically very expensive computationaly. A considerable speed-up can be achieved by exploiting parallel computation. To do so, just start julia with the <code> -p nprocs</code> argument where <code>nprocs</code> is the number of workers available on your machine. Alternatively, from julia REPL, just do a:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; using Distributed; 
julia&gt; addprocs(8) # put here the number of cores available 
julia&gt; @everywhere using CorrDCA"><pre class="notranslate"><code>julia&gt; using Distributed; 
julia&gt; addprocs(8) # put here the number of cores available 
julia&gt; @everywhere using CorrDCA
</code></pre></div>
