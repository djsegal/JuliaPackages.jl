<p dir="auto">This package lets you load the Allen Neuropixels data in a Julia-oriented format, using e.g. <a href="https://github.com/JuliaData/DataFrames.jl">DataFrames</a> and <a href="https://github.com/rafaqz/DimensionalData.jl">DimArrays</a>. Can load both the 'Visual Coding' and 'Visual Behavior' datasets.</p>
<p dir="auto">Please see <a href="https://github.com/brendanjohnharris/AllenNeuropixels.jl">AllenNeuropixels.jl</a>, which exports all the functionality of this package and adds tools for analyzing and plotting the data.</p>
