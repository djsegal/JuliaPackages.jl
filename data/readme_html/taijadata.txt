<p dir="auto">Once you've reviewed the catalog, select a collection, such as the <code>synthetic</code> dataset collection:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="data_catalogue[:synthetic]"><pre>data_catalogue[<span class="pl-c1">:synthetic</span>]</pre></div>
<p dir="auto">This will display a list of available synthetic datasets. For example, if you wish to import the blobs data:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x, y = load_blobs()"><pre>x, y <span class="pl-k">=</span> <span class="pl-c1">load_blobs</span>()</pre></div>
<p dir="auto">Here, <code>x</code> represents the input features matrix, and <code>y</code> contains the labels for each entry.</p>

<p dir="auto">If you want to fetch a specific number of rows, you can specify the desired count:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x, y = load_blobs(100)"><pre>x, y <span class="pl-k">=</span> <span class="pl-c1">load_blobs</span>(<span class="pl-c1">100</span>)</pre></div>
<p dir="auto">This command fetches 100 rows of data from the blobs dataset.</p>
