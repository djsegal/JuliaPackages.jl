<p dir="auto">Currently this Julia package serves as a multi-platform runner for <a href="http://github.com/m3g/packmol">packmol</a>. In the future this will be an
independent package with a faster and improved version of the Packmol package.</p>

<p dir="auto">Run packmol in your input file with:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Packmol

<p dir="auto">This will open a file browser, from which you can choose the input file for <code>packmol</code>.
Packmol will run immediately once the file is open.</p>
<p dir="auto">Alternativelly, you can provide the path to the file explicitly, with:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; run_packmol(raw&quot;C:\users\my_user\my_files\my_input_file.inp&quot;)"><pre>julia&gt; <span class="pl-c1">run_packmol</span>(<span class="pl-s"><span class="pl-c1">raw</span><span class="pl-pds">"</span>C:<span class="pl-cce">\u</span>sers<span class="pl-cce">\m</span>y_user<span class="pl-cce">\m</span>y_files<span class="pl-cce">\m</span>y_input_file.inp<span class="pl-pds">"</span></span>)</pre></div>

<p dir="auto">For command-line usage, we suggest the following procedure:</p>
<p dir="auto">Start Julia and create an environment where packmol is installed:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg

julia&gt; Pkg.activate(&quot;Packmol&quot;, shared=true)

julia&gt; Pkg.add(&quot;Packmol&quot;)

julia&gt; exit()"><pre>julia&gt; <span class="pl-k">import</span> Pkg

julia&gt; Pkg<span class="pl-k">.</span><span class="pl-c1">activate</span>(<span class="pl-s"><span class="pl-pds">"</span>Packmol<span class="pl-pds">"</span></span>, shared<span class="pl-k">=</span><span class="pl-c1">true</span>)

julia&gt; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Packmol<span class="pl-pds">"</span></span>)

julia&gt; <span class="pl-c1">exit</span>()</pre></div>
<p dir="auto">Next, copy this into a <code>packmol.jl</code> file:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg; Pkg.activate(&quot;Packmol&quot;, shared=true) # Activate Packmol environment

for input_file in ARGS
    run_packmol(input_file)
end"><pre><span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">activate</span>(<span class="pl-s"><span class="pl-pds">"</span>Packmol<span class="pl-pds">"</span></span>, shared<span class="pl-k">=</span><span class="pl-c1">true</span>) <span class="pl-c"><span class="pl-c">#</span> Activate Packmol environment</span>
<span class="pl-k">using</span> Packmol
<span class="pl-k">for</span> input_file <span class="pl-k">in</span> <span class="pl-c1">ARGS</span>
    <span class="pl-c1">run_packmol</span>(input_file)
<span class="pl-k">end</span></pre></div>
<p dir="auto">This script can be executed from the command line with</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia packmol.jl packmol_input1.inp packmol_input2.inp"><pre class="notranslate"><code>julia packmol.jl packmol_input1.inp packmol_input2.inp
</code></pre></div>
<p dir="auto">to run <code>packmol</code> for one or more input files.</p>
<p dir="auto">To keep Packmol up-to-date, use:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.activate(&quot;Packmol&quot;; shared=true); Pkg.update()"><pre>julia&gt; <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">activate</span>(<span class="pl-s"><span class="pl-pds">"</span>Packmol<span class="pl-pds">"</span></span>; shared<span class="pl-k">=</span><span class="pl-c1">true</span>); Pkg<span class="pl-k">.</span><span class="pl-c1">update</span>()</pre></div>
<p dir="auto">(or type <code>] activate @Packmol</code> and then <code>] up</code>, at the <code>julia&gt;</code> prompt).</p>
