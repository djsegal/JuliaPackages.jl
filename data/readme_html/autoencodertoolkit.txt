<p dir="auto">Welcome to the <code>AutoEncoderToolkit.jl</code> GitHub repository. This package provides
a simple interface for training and using <a href="https://fluxml.ai" rel="nofollow">Flux.jl</a>-based
autoencoders and variational autoencoders in Julia.</p>

<p dir="auto">The idea behind <code>AutoEncoderToolkit.jl</code> is to take advantage of Julia's multiple
dispatch to provide a simple and flexible interface for training and using
different types of autoencoders. The package is designed to be modular and allow
the user to easily define and test custom encoder and decoder architectures.
Moreover, when it comes to variational autoencoders, <code>AutoEncoderToolkit.jl</code>
takes a probabilistic perspective, where the type of encoders and decoders
defines (via multiple dispatch) the corresponding distribution used within the
corresponding loss function.</p>
<p dir="auto">For more information, please refer to the
<a href="https://mrazomej.github.io/AutoEncoderToolkit.jl/" rel="nofollow">documentation</a>.</p>
