<p dir="auto">Lucon (<strong>L</strong>oss optimization under <strong>U</strong>nitary <strong>CON</strong>straint) optimizes loss functions mapping a unitary matrix onto a number. A conjugate-gradient algorithm is used following the work by <a href="https://dx.doi.org/10.1016/j.sigpro.2009.03.015" rel="nofollow">T. Abrudan et al., Signal Processing 89 (2009) 1704–1714</a>.</p>
<p dir="auto">The module presents potential applications in various fields. For instance, it can be employed for tasks such as orbital rotations (e.g., orbital localization) in quantum chemistry and materials science, as well as for various tasks in signal processing applications or machine learning algorithms. The main motivation for Lucon.jl is given by orbital localizations for calculations in materials physics and quantum chemistry. These will be referenced here shortly.</p>
<p dir="auto">The code is designed in a way that users can implement arbitrary loss functionals with little effort for optimization with Lucon.jl. As a template the <a href="src/BrockettLoss.jl">BrockettLoss.jl</a> functional can be used (see example below).</p>
<p dir="auto">To provide a very simple and illustrative example of the module's potential use cases, consider the following loss functional that can be used to diagonalize a hermitian matrix.</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$$L(U) = \text{tr}(U^\dagger H U N)$$</math-renderer>
<p dir="auto">Here, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$H$</math-renderer> is a hermitian matrix (to be diagonalized) and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$N$</math-renderer> is a diagonal matrix with distinct entries in ascending order, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$N_{nm} = n\delta_{nm}$</math-renderer>. Lucon finds the optimal <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$U$</math-renderer> which maximizes the loss functional.  For this particular choice of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$L(U)$</math-renderer> (also known as <a href="https://doi.org/10.1016/0024-3795(91)90021-N" rel="nofollow">Brockett criterion</a>), the optimal unitary matrix is the one that diagonalizes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$H$</math-renderer>.</p>

<p dir="auto">In order to use Lucon to optimize a loss functional <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$L(U)$</math-renderer> one has provide a Julia function that calculates the Eucledean derivative <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$\Gamma_{ij} = \partial L / \partial u^*_{ij}$</math-renderer>. For the above example (Brockett criterion) the Eucledean derivative simply reads <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$\Gamma = \partial L /\partial U^\dagger = H U N$</math-renderer>.</p>
<p dir="auto">To this end a sub-type of the abstract type <code>Lucon.LossFunctional</code> has to be defined which can hold all quantities necessary for the loss functional (for the example, it is only the hermitian matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bea9f07cee44cd62bccf7a9e5cf1ec3f">$H$</math-renderer>).
The Eucledean derivative has to be provided by overloading the function <code>Lucon.EuclideanDerivative</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Lucon

struct LossFunctional &lt;: Lucon.LossFunctional
    H::Hermitian{&lt;:Number}
end

function Lucon.EuclideanDerivative(
    L::LossFunctional,
    U::Matrix{T},
    CalcLoss::Bool
)::Tuple{Matrix{T},Float64} where T&lt;:Number
    Γ = zero(similar(U)) # Euclidean derivative has same type and dimension as U
    Loss = 0.0 # the value of the Loss functional
    dim = size(L.H,1)
    N = Diagonal([1.0*n for n=1:dim]) # the N matrix is a diagonal matrix with entries N_nn = n
    Γ = L.H*U*N
    (CalcLoss == true) &amp;&amp; (Loss = real(tr(U'*Γ)))
    return (Γ, Loss)
