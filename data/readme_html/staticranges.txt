<p dir="auto">This package was originally inspired by the StaticArrays package.
It provides a basic <code>srange</code> method that produces a static range with the same syntax and arguments as <code>range</code>.
Similarly, there is <code>mrange</code> constructs mutable ranges.
Currently, much of this package serves as a place to develop traits that are necessary (but not specific to) <a href="https://github.com/Tokazama/AxisIndices.jl">AxisIndices.jl</a>.
As more generally applicable traits and interfaces evolve they are often pushed to <a href="https://github.com/JuliaArrays/ArrayInterface.jl">ArrayInterface.jl</a>.
Therefore, users should consider this package in development and subject to unexpected changes.</p>
