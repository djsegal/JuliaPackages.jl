<p dir="auto">Extents.jl is a small package that defines an <code>Extent</code> object that can be used by the
different Julia spatial data packages. <code>Extent</code> is a wrapper for a NamedTuple of tuples
holding the lower and upper bounds for each dimension of a object. It is used in
<a href="https://github.com/JuliaGeo/GeoInterface.jl/">GeoInterface.jl</a>, as the required return type
for the <code>extent</code> function, and in <a href="https://github.com/rafaqz/DimensionalData.jl">DimensionalData.jl</a>
and <a href="https://github.com/rafaqz/Rasters.jl">Rasters.jl</a> to subset arrays with named dimensions.</p>
