<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg

<p dir="auto">or you use the Pkg prompt by hitting <code>]</code> within the Julia REPL and then type</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(@v1.10) pkg&gt; add QEDprocesses"><pre>(<span class="pl-c1">@v1</span>.<span class="pl-c1">10</span>) pkg<span class="pl-k">&gt;</span> add QEDprocesses</pre></div>

<p dir="auto">To build the documentation of <code>QEDprocesses.jl</code> locally, first clone this
repository. Then, you instantiate the documentation subpackage by hitting</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project=docs -e 'using Pkg; Pkg.instantiate(); Pkg.develop(PackageSpec(path=pwd()))'"><pre>julia <span class="pl-k">--</span>project<span class="pl-k">=</span>docs <span class="pl-k">-</span>e <span class="pl-s"><span class="pl-pds">'</span>using Pkg; Pkg.instantiate(); Pkg.develop(PackageSpec(path=pwd()))<span class="pl-pds">'</span></span></pre></div>
<p dir="auto">in the root directory of this repository. Afterwards, the dokumentation can be
built by running</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project=docs --color=yes docs/make.jl"><pre>julia <span class="pl-k">--</span>project<span class="pl-k">=</span>docs <span class="pl-k">--</span>color<span class="pl-k">=</span>yes docs<span class="pl-k">/</span>make<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">To access the documentation site, just open the file <code>docs/_build/index.html</code> in
your favorite browser.</p>
