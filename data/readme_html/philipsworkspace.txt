<p dir="auto">This package is used to read in <code>workspace.json</code> files that are exported for each scan with the UMCU Raw Export Tool. The workspace contains all parameter values, object and enumerations. This package uses <code>JSON.jl</code> to read in the <code>.json</code> file as a Dict and provides functionality to extract objects and parameters in a convenient (<code>NamedTuple</code>-based) format.</p>
