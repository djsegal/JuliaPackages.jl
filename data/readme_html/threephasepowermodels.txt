<p dir="auto">ThreePhasePowerModels.jl is an extention package of PowerModels.jl for Steady-State Power Distribution Network Optimization.  It is designed to enable computational evaluation of emerging power network formulations and algorithms in a common platform.  The code is engineered to decouple problem specifications (e.g. Power Flow, Optimal Power Flow, ...) from the power network formulations (e.g. AC, linear-approximation, SOC-relaxation, ...).
This enables the definition of a wide variety of power network formulations and their comparison on common problem specifications.</p>
<p dir="auto"><strong>Core Problem Specifications</strong></p>
<ul dir="auto">
<li>Power Flow (pf)</li>
<li>Optimal Power Flow (opf), for the Bus Injection Model (BIM) as well as the Branch Flow Model (BFM)</li>
</ul>
<p dir="auto"><strong>Core Network Formulations</strong></p>
<ul dir="auto">
<li>AC (polar and rectangular coordinates)</li>
<li>SDP BFM relaxation</li>
<li>SOC BFM and BIM relaxation (W-space)</li>
<li>Linear approximation (LinDist3Flow and simplified unbalanced DistFlow)</li>
</ul>
<p dir="auto"><strong>Network Data Formats</strong></p>
<ul dir="auto">
<li>Matlab ".m" files (extended for three-phase)</li>
<li>OpenDSS ".dss" files</li>
</ul>
<p dir="auto"><strong>Warning:</strong> This package is under active development and may change drastically without warning.</p>
