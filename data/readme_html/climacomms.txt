<p dir="auto"><code>ClimaComms.jl</code> is a small package to work with diverse computing devices and
environments (e.g., CPUs/GPUs, single-process/MPI). <code>ClimaComms.jl</code> provides
objects to represent such devices and environments and functions to interact
with them in a unified way. <code>ClimaComms.jl</code> is used extensively through the
<code>CliMA</code> ecosystem to control where and how simulations are run (e.g., on one
CPU, or on several GPUs using with MPI).</p>
<p dir="auto"><code>ClimaComms.jl</code> supports the following <code>Device</code>s:</p>
<ul dir="auto">
<li><code>CPUSingleThreaded</code></li>
<li><code>CPUMultiThreaded</code> (not actively used)</li>
<li><code>CUDADevice</code>
and <code>Context</code>es (i.e., environments for distributed computing):</li>
<li><code>SingletonCommsContext</code></li>
<li><code>MPICommsContext</code></li>
</ul>
<p dir="auto">Refer to the <a href="https://CliMA.github.io/ClimaComms.jl/dev" rel="nofollow">documentation</a> for
more details.</p>
