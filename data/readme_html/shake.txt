<p dir="auto">Implementation of the <a href="https://en.wikipedia.org/wiki/Extendable-output_function" rel="nofollow">extendable-output functions</a> (XOF's) SHAKE128 and SHAKE256 based on the <a href="https://en.wikipedia.org/wiki/SHA-3" rel="nofollow">SHA-3</a> implementation in the Julia Standard Library.</p>

<p dir="auto">Install with the Julia package manager <a href="https://pkgdocs.julialang.org/" rel="nofollow">Pkg</a>, just like any other registered Julia package:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add SHAKE  # Press ']' to enter the Pkg REPL mode."><pre>pkg<span class="pl-k">&gt;</span> add SHAKE  <span class="pl-c"><span class="pl-c">#</span> Press ']' to enter the Pkg REPL mode.</span></pre></div>
<p dir="auto">or</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg; Pkg.add(&quot;SHAKE&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>SHAKE<span class="pl-pds">"</span></span>)</pre></div>

<p dir="auto">Loading the package will export <code>shake128_xof</code> and <code>shake256_xof</code> as well as <code>shake128</code> and <code>shake256</code> and finally also <code>SHAKE128RNG</code> and <code>SHAKE256RNG</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SHAKE"><pre><span class="pl-k">using</span> SHAKE</pre></div>
<p dir="auto">The methods <code>shake128_xof</code> and <code>shake256_xof</code> may be used as infinite iterators:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="for (i, b) in enumerate(shake256_xof(b&quot;Hash me!&quot;))

    <span class="pl-k">if</span> <span class="pl-c1">iszero</span>(b)

        <span class="pl-k">break</span>
    <span class="pl-k">end</span>

<p dir="auto">The random byte generators <code>SHAKE128RNG</code> and <code>SHAKE256RNG</code> subtype <code>AbstractRNG</code> and can be used as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="rng = SHAKE128RNG(b&quot;Hash me!&quot;)

some_random_bytes = rand(rng, UInt8, 47)
more_random_bytes = rand(rng, UInt8, 11)"><pre>rng <span class="pl-k">=</span> <span class="pl-c1">SHAKE128RNG</span>(<span class="pl-s"><span class="pl-pds"><span class="pl-c1">b</span>"</span>Hash me!<span class="pl-pds">"</span></span>)

some_random_bytes <span class="pl-k">=</span> <span class="pl-c1">rand</span>(rng, UInt8, <span class="pl-c1">47</span>)
