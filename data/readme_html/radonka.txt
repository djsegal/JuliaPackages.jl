<p dir="auto">A simple yet sufficiently fast Radon and adjoint Radon (backproject) transform implementation using <a href="https://github.com/JuliaGPU/KernelAbstractions.jl">KernelAbstractions.jl</a>.
It offers multithreading and CUDA support and outperforms any existing Julia Radon transforms (at least the ones we are aware of).
On CUDA it is faster much than Matlab and it offers the same or faster speed than ASTRA.</p>

<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> For 2D and 3D arrays</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> parallel <code>radon</code> and <code>backproject</code> (<code>?RadonParallelCircle</code>)</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> attenuated <code>radon</code> and <code>backproject</code> (see the parameter <code>μ</code>) and see this <a href="https://iopscience.iop.org/article/10.1088/0266-5611/17/1/309/meta" rel="nofollow">paper</a> as reference)</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> arbitrary 2D geometries where starting and endpoint of each ray can be specified (fan beam could be a special case of this) (<code>?RadonFlexibleCircle</code>)</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> different strength weighting of rays</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> based on <a href="https://github.com/JuliaGPU/KernelAbstractions.jl">KernelAbstractions.jl</a> (tested on <code>CPU()</code> and <code>CUDABackend()</code>)</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> registered adjoint rules for both <code>radon</code> and <code>backproject</code> with ChainRulesCore.jl, hence automatic differentiation (AD) compatible.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> high performance however not ultra high performance. On par with ASTRA, on CUDA faster than Matlab.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> simple and extensible API</li>
</ul>

<p dir="auto">There is <a href="https://github.com/CERN/TIGRE">TIGRE</a> and <a href="https://github.com/astra-toolbox/astra-toolbox">ASTRA</a> which both offer more functionality for classic CT problems.
They also feature GPU acceleration, however we did not observe that they outperform this package. Also, they don't allow to calculate the attenuated Radon transform
and don't allow for arbitrary ray geometries, as we do.
The fastest implementation we found, is the <a href="https://github.com/matteo-ronchetti/torch-radon">unmaintained torch-radon</a>. Its kernels are written in CUDA C code and offer a PyTorch interface.
There is a <a href="https://github.com/carterbox/torch-radon">torch-radon fork</a> which allows to run it with newer versions. It offers no attenuated Radon transform.</p>
