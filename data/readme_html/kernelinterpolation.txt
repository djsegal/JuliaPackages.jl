<p dir="auto"><strong>KernelInterpolation.jl</strong> is a <a href="https://julialang.org/" rel="nofollow">Julia</a> package that
implements methods for multivariate interpolation in arbitrary dimension based on symmetric (conditionally) positive-definite kernels
with a focus on radial basis functions. It can be used for classical interpolation of scattered data, as well as for generalized
(Hermite-Birkhoff) interpolation by using a meshfree collocation approach. This can be used to solve partial differential equations both
stationary ones and time-dependent ones by using some time integration method from <a href="https://github.com/SciML/OrdinaryDiffEq.jl">OrdinaryDiffEq.jl</a>.</p>

<p dir="auto">If you have not yet installed Julia, then you first need to <a href="https://julialang.org/downloads/" rel="nofollow">download Julia</a>. Please
<a href="https://julialang.org/downloads/platform/" rel="nofollow">follow the instructions for your operating system</a>. KernelInterpolation.jl
works with Julia v1.10 and newer. KernelInterpolation.jl is a registered Julia package. Therefore, you can install it by
executing the following commands from the Julia REPL</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg

julia<span class="pl-k">&gt;</span> Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>KernelInterpolation<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">For visualizing the results, additionally you need to install <a href="https://github.com/JuliaPlots/Plots.jl">Plots.jl</a>, which can be done by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg

julia&gt; Pkg.add(&quot;Plots&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg

<p dir="auto">To create special node sets, you might also want to install <a href="https://github.com/SciML/QuasiMonteCarlo.jl">QuasiMonteCarlo.jl</a> or
<a href="https://github.com/JuliaGeometry/Meshes.jl">Meshes.jl</a> and for solving time-dependent partial differential equations
<a href="https://github.com/SciML/OrdinaryDiffEq.jl">OrdinaryDiffEq.jl</a> in a similar way as above for Plots.jl. See the documentation for more
examples on how to use these packages in combination with KernelInterpolation.jl.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In the Julia REPL, first load the package KernelInterpolation.jl</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using KernelInterpolation"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> KernelInterpolation</pre></div>
<p dir="auto">In order to interpolate discrete function values of a (potentially) multivariate function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$f: \mathbb{R}^d\to \mathbb{R}$</math-renderer>, we
first need a set of nodes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$X = \{x_1,\ldots,x_n\}\subset\mathbb{R}^d$</math-renderer>, where the function values of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$f$</math-renderer> are known. In KernelInterpolation.jl
we can, e.g., construct a homogeneous grid on a hypercube in 2 dimensions by calling</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; nodeset = homogeneous_hypercube(5, (-2, -1), (2, 1))"><pre>julia<span class="pl-k">&gt;</span> nodeset <span class="pl-k">=</span> <span class="pl-c1">homogeneous_hypercube</span>(<span class="pl-c1">5</span>, (<span class="pl-k">-</span><span class="pl-c1">2</span>, <span class="pl-k">-</span><span class="pl-c1">1</span>), (<span class="pl-c1">2</span>, <span class="pl-c1">1</span>))</pre></div>
<p dir="auto">Here, we specified that the hypercube has 5 nodes along each of the 2 dimensions (i.e. in total we have <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$5^2 = 25$</math-renderer> nodes) and that the
boundaries of the cube are given by the lower left corner located at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$(-2, -1)$</math-renderer> and the upper right corner at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$(2, 1)$</math-renderer>. Similarly,
<code>NodeSet</code>s can be constructed by the functions <code>random_hypercube</code>, <code>random_hypercube_boundary</code>,
<code>homogeneous_hypercube_boundary</code>, <code>random_hypersphere</code> or <code>random_hypersphere_boundary</code> or by directly passing
a set of nodes to the constructor of <code>NodeSet</code>. Besides the <code>nodeset</code>, we need the function values at the nodes. Let's say, we
want to reconstruct the function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$f(x) = \sin(x_1\cdot x_2)$</math-renderer>. Then, we can create the vector of function values by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; f(x) = sin(x[1]*x[2])
julia&gt; ff = f.(nodeset)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-en">f</span>(x) <span class="pl-k">=</span> <span class="pl-c1">sin</span>(x[<span class="pl-c1">1</span>]<span class="pl-k">*</span>x[<span class="pl-c1">2</span>])
julia<span class="pl-k">&gt;</span> ff <span class="pl-k">=</span> <span class="pl-c1">f</span>.(nodeset)</pre></div>
<p dir="auto">Finally, we obtain the <code>Interpolation</code> object by calling <code>interpolate</code>, where we specify the kernel function that is used
for the reconstruction. Here, we take a Gaussian <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$\phi(r) = \exp(-(\varepsilon r)^2)$</math-renderer> with shape parameter <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$\varepsilon = 1/2$</math-renderer> as
radial-symmetric basis function:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; kernel = GaussKernel{dim(nodeset)}(shape_parameter = 0.5)
julia&gt; itp = interpolate(nodeset, ff, kernel)"><pre>julia<span class="pl-k">&gt;</span> kernel <span class="pl-k">=</span> <span class="pl-c1">GaussKernel</span><span class="pl-c1">{dim(nodeset)}</span>(shape_parameter <span class="pl-k">=</span> <span class="pl-c1">0.5</span>)
julia<span class="pl-k">&gt;</span> itp <span class="pl-k">=</span> <span class="pl-c1">interpolate</span>(nodeset, ff, kernel)</pre></div>
<p dir="auto">If the <code>kernel</code> is only conditionally positive definite, the interpolant will be augmented by a polynomial of the corresponding order of
the kernel. Another order can also be passed explicitly with the keyword argument <code>m</code> of <code>interpolate</code>. The result <code>itp</code>
is an object that is callable on any point <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8b002d67330755e469513a609f5e5cad">$x\in\mathbb{R}^d$</math-renderer>, e.g.,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; itp([-1.3, 0.26])
-0.34096946394940986

julia&gt; f([-1.3, 0.26])
-0.33160091709280176"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">itp</span>([<span class="pl-k">-</span><span class="pl-c1">1.3</span>, <span class="pl-c1">0.26</span>])
<span class="pl-k">-</span><span class="pl-c1">0.34096946394940986</span>

julia<span class="pl-k">&gt;</span> <span class="pl-c1">f</span>([<span class="pl-k">-</span><span class="pl-c1">1.3</span>, <span class="pl-c1">0.26</span>])
<span class="pl-k">-</span><span class="pl-c1">0.33160091709280176</span></pre></div>
<p dir="auto">For more sophisticated examples also involving solving stationary or time-dependent partial differential equations, see the
<a href="https://joshualampert.github.io/KernelInterpolation.jl/dev/pdes" rel="nofollow">documentation</a>.
More examples can be found in the <a href="https://github.com/JoshuaLampert/KernelInterpolation.jl/tree/main/examples"><code>examples/</code></a> subdirectory.</p>

<p dir="auto">In order to visualize the results, you need to have <a href="https://github.com/JuliaPlots/Plots.jl">Plots.jl</a> installed and loaded</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Plots"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Plots</pre></div>
<p dir="auto">A <code>NodeSet</code> can simply be plotted by calling</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; plot(nodeset)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">plot</span>(nodeset)</pre></div>
<p dir="auto">An <code>Interpolation</code> object can be plotted by providing a <code>NodeSet</code> at which the interpolation is evaluated. Continuing
the example from above, we can visualize the resulting interpolant on a finer grid</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; nodeset_fine = homogeneous_hypercube(20, 2, (-2, -1), (2, 1))
julia&gt; plot(nodeset_fine, itp)"><pre>julia<span class="pl-k">&gt;</span> nodeset_fine <span class="pl-k">=</span> <span class="pl-c1">homogeneous_hypercube</span>(<span class="pl-c1">20</span>, <span class="pl-c1">2</span>, (<span class="pl-k">-</span><span class="pl-c1">2</span>, <span class="pl-k">-</span><span class="pl-c1">1</span>), (<span class="pl-c1">2</span>, <span class="pl-c1">1</span>))
julia<span class="pl-k">&gt;</span> <span class="pl-c1">plot</span>(nodeset_fine, itp)</pre></div>
<p dir="auto">To visualize the true solution <code>f</code> in the same plot as a surface plot we can call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; plot!(nodeset_fine, f, st = :surface)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">plot!</span>(nodeset_fine, f, st <span class="pl-k">=</span> <span class="pl-c1">:surface</span>)</pre></div>
<p dir="auto">KernelInterpolation.jl also supports exporting (and importing) VTK files, which can be visualized using tools
such as <a href="https://www.paraview.org/" rel="nofollow">ParaView</a> or <a href="https://visit-dav.github.io/visit-website/" rel="nofollow">VisIt</a>. See the documentation
for more details.</p>
