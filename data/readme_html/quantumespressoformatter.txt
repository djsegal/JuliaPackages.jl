<p dir="auto">Format the input files of <a href="https://www.quantum-espresso.org/" rel="nofollow">Quantum ESPRESSO</a> in a more
readable way.</p>
<p dir="auto">The code is <a href="https://github.com/MineralsCloud/QuantumESPRESSOFormatter.jl">hosted on GitHub</a>,
with some continuous integration services to test its validity.</p>
<p dir="auto">This repository is created and maintained by <a href="https://github.com/singularitti">@singularitti</a>.
You are very welcome to contribute.</p>
