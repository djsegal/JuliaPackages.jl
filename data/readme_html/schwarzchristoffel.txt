<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">About the package</h2><a id="user-content-about-the-package" class="anchor" aria-label="Permalink: About the package" href="#about-the-package"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The purpose of this package is to enable easy construction and evaluation of the mapping from the region inside or outside the unit circle to the exterior of a closed polygon.</p>
<p dir="auto">The engine for constructing the mapping and its inverse is based on the work of Driscoll and Trefethen, <a href="http://www.math.udel.edu/~driscoll/research/conformal.html" rel="nofollow">Schwarz-Christoffel Mapping</a>, Cambridge University Press, 2002.</p>

<p dir="auto">This package requires Julia <code>1.0</code> and above.
It is a registered package, so it should be installed with <code>add SchwarzChristoffel</code>
at the package manager prompt.</p>
<p dir="auto">Examples can be found in the <a href="https://jdeldre.github.io/SchwarzChristoffel.jl" rel="nofollow">documentation</a>.</p>
