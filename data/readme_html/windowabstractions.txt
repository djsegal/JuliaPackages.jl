<p dir="auto">Abstractions for windowing APIs. This library is intended for developers, and not for general use. It is currently only used by <a href="https://github.com/JuliaGL/XCB.jl">XCB.jl</a> and <a href="https://github.com/serenity4/Wayland.jl">Wayland.jl</a>, but aims at being applicable to other windowing APIs such as Windows. Julia developers wrapping windowing APIs are encouraged to use and contribute to this library as much as possible.</p>
