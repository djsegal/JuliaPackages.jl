<p dir="auto">This package models an affine group consisting of matrices of the form</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$$χ = \begin{bmatrix}
\mathbf{1} &amp; \mathbf{0} \\\
X &amp; h
\end{bmatrix}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$h$</math-renderer> is a matrix element of some group <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$H$</math-renderer>, represented in dimension <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$n$</math-renderer>,
and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$X$</math-renderer> is a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$n × k$</math-renderer> matrix.
If we denote such an element by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$[X,h]$</math-renderer>,
the multiplication law is</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$$[X,h] [X',h'] = [X+hX';hh']$$</math-renderer>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MultiAffine

<span class="pl-c1">identity_element</span>(G) <span class="pl-c"><span class="pl-c">#</span> ([0.0 0.0; 0.0 0.0], ComplexF64[1.0 + 0.0im 0.0 + 0.0im; 0.0 + 0.0im 1.0 + 0.0im])</span></pre></div>
<p dir="auto">When the group <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1814d0fae676c5966327ce09d54afe45">$H$</math-renderer> is the <a href="https://en.wikipedia.org/wiki/Orthogonal_group" rel="nofollow">special orthogonal group</a>, one can use the alias <code>MultiDisplacementGroup(n,k)</code> to create the group <code>MultiAffineGroup(SpecialOrthogonal(n), k)</code>, for instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="G = MultiDisplacementGroup(3,2)
