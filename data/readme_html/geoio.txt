<p dir="auto">Load/save geospatial data compatible with the
<a href="https://github.com/JuliaEarth/GeoStats.jl">GeoStats.jl</a>
framework.</p>
<p dir="auto">GeoIO.jl uses various backend packages spread across
different Julia organizations to load a universal
representation of geospatial data as discussed in
the book <a href="https://juliaearth.github.io/geospatial-data-science-with-julia" rel="nofollow"><em>Geospatial Data Science with Julia</em></a>.</p>
