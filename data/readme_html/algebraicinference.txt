<p dir="auto">AlgebraicInference.jl is a library for performing Bayesian inference on wiring diagrams,
building on <a href="https://algebraicjulia.github.io/Catlab.jl/dev/" rel="nofollow">Catlab.jl</a>. See the
<a href="https://samuelsonric.github.io/AlgebraicInference.jl/dev/" rel="nofollow">documentation</a> for example
notebooks and an API.</p>

problem = InferenceProblem(wd, hom_map, ob_map)
