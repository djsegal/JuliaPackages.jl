<p dir="auto">This package provides experimental algorithms for globally h-adaptive iterated
integration.</p>
<p dir="auto">The main takeaways of these experiments are that:</p>
<ul dir="auto">
<li>pole-subtraction is superior to quadgk for integration of meromorphic functions</li>
<li>The peak missing problem, which occurs for near singular functions, can be
elegantly solved with auxiliary integrands</li>
<li>nested integrals can be implemented reliably when absolute tolerances for
inner integrals are scaled by the measure of the outer integration domains</li>
<li>nested integrals cannot be reliably replaced by globally-adaptive schemes using
a treap (tree-heap) and any adaptation scheme other than depth-first</li>
</ul>
