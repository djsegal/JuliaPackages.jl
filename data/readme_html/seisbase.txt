<p dir="auto">A minimalist, platform-agnostic package for univariate geophysical data.
This version is a follow up from SeisIO.jl (<a href="https://github.com/jpjones76/SeisIO.jl">https://github.com/jpjones76/SeisIO.jl</a>). It is intended to be an stable community maintained package.</p>

<p dir="auto">Designed for speed, efficiency, and ease of use. Includes web clients, readers for common seismic data formats, and fast file writers. Utility functions allow time synchronization, data merging, padding time gaps, and other basic data processing.</p>
<ul dir="auto">
<li>Web clients: SeedLink, FDSN (dataselect, event, station), IRIS (TauP, timeseries)</li>
<li>File formats: ASDF (r/w), QuakeML (r/w), SAC (r/w), SEED (dataless, mini-SEED, resp), SEG Y (rev 0, rev 1, PASSCAL), StationXML (r/w), Win32</li>
</ul>
