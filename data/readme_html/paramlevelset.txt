<p dir="auto">The ParamLevelSet package is based on the following paper (please cite if you are using the package):</p>
<p dir="auto">Multi-modal 3D Shape Reconstruction Under Calibration Uncertainty using Parametric Level Set Methods, Moshe Eliasof, Andrei Sharf, Eran Treister, 2019. Available at: <a href="https://arxiv.org/abs/1904.10379" rel="nofollow"><code>arXiv</code></a></p>
<p dir="auto">Also based on the original PaLS paper:
A. Aghasi, M. Kilmer, and E. L. Miller, Parametric level set methods for inverse problems, SIAM Journal on Imaging Sciences, 4 (2011), pp. 618–650.</p>
