<p dir="auto">AlpacaMarkets.jl is in the General Registry so you can simply install locally using Pkg.</p>
<p dir="auto">You need to sign up to AlpacaMarkets to obtain your API keys.
Once you've obtained the key and secret you can authenticate manually with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using AlpacaMarkets
AlpacaMarkets.select_account(&quot;PAPER&quot;)
AlpacaMarkets.auth(KEY, SECRET)"><pre><span class="pl-k">using</span> AlpacaMarkets
AlpacaMarkets<span class="pl-k">.</span><span class="pl-c1">select_account</span>(<span class="pl-s"><span class="pl-pds">"</span>PAPER<span class="pl-pds">"</span></span>)
AlpacaMarkets<span class="pl-k">.</span><span class="pl-c1">auth</span>(KEY, SECRET)</pre></div>
<p dir="auto">Rather than setting it manually each time I recommend you add it to your <code>.julia/startup.jl</code> or '.julia/config/startup.jl'</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="ENV[&quot;ALPACA_KEY&quot;] = KEY
ENV[&quot;ALPACA_SECRET&quot;] = SECRET"><pre class="notranslate"><code>ENV["ALPACA_KEY"] = KEY
ENV["ALPACA_SECRET"] = SECRET
</code></pre></div>
<p dir="auto">This is automatically be picked up by AlpacaMarkets.jl each time you start Julia.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Available Functions</h2><a id="user-content-available-functions" class="anchor" aria-label="Permalink: Available Functions" href="#available-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">All the historical market data API functions are available:</p>
<ul dir="auto">
<li><code>stock_bars</code>, <code>stock_bars_latest</code>, <code>stock_quotes</code> and <code>stock_trades</code></li>
<li><code>stock_quotes_latest</code> and <code>stock_trades_latest</code></li>
<li><code>crypto_bars</code>, <code>crypto_quotes</code> and <code>crypto_trades</code></li>
</ul>
<p dir="auto">Plus the interface to their news API</p>
<ul dir="auto">
<li><code>news</code></li>
</ul>
<p dir="auto">Plus I've added helper functions to obtain data between two periods:</p>
<ul dir="auto">
<li><code>get_stock_quotes</code> and <code>get_stock_trades</code></li>
<li><code>get_crypto_trades</code></li>
</ul>
<p dir="auto">So you can pull some historical data as and when needed.</p>
<p dir="auto">Trading API functions are available up to account, orders and positions:</p>
<ul dir="auto">
<li><code>account</code>, <code>get_orders</code>, <code>place_order</code>, <code>place_market_order</code></li>
<li><code>place_limit_order</code>, <code>place_stop_order</code>, <code>place_stop_limit_order</code>,</li>
<li><code>place_trailing_stop_order</code>, <code>place_bracket_order</code>,</li>
<li><code>place_oco_order</code>, <code>place_oto_order</code>, <code>replace_an_order</code>,</li>
<li><code>cancel_order</code>, <code>cancel_all_orders</code>, <code>get_orders_by_order_id</code></li>
<li><code>get_orders_by_client_order_id</code>, <code>get_open_positions</code>,</li>
<li><code>get_position</code>, <code>close_all_positions</code>, <code>close_position</code></li>
</ul>
