<p dir="auto">This package provides an implementation of Yeo Johnson transformation.
See <a href="https://en.wikipedia.org/wiki/Power_transform" rel="nofollow">Wikipedia - Power Transform</a>
for more information.</p>
<p dir="auto">Requires Julia 1.0 or higher version.</p>
