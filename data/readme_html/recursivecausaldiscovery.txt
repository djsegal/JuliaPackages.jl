<p dir="auto">The package so far has only one algorithm implemented: RSL-D, which can be called using the <code>rsld</code> function. The function takes the data matrix/table and a conditional independence test function as input, and returns the completed partially oriented directed acyclic graph (CPDAG) as output.</p>

<p dir="auto">In this example, a csv file named <code>data.csv</code> is loaded, and the RSL-D algorithm is used to learn the CPDAG. The conditional independence test is based on the Fisher's Z-test.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using RecursiveCausalDiscovery
using CSV
using Tables

# load data (columns are variables and rows are samples)
data = CSV.read(&quot;data.csv&quot;, Tables.matrix)

# use a Gaussian conditional independence test
sig_level =  0.01
ci_test = (x, y, cond_vec, data) -&gt;  fisher_z(x, y, cond_vec, data, sig_level)

# learn the oriented causal graph using RSL
cpdag =  rsld(data, ci_test)"><pre><span class="pl-k">using</span> RecursiveCausalDiscovery
<span class="pl-k">using</span> CSV
<span class="pl-k">using</span> Tables

<span class="pl-c"><span class="pl-c">#</span> load data (columns are variables and rows are samples)</span>

<span class="pl-c"><span class="pl-c">#</span> use a Gaussian conditional independence test</span>
