<p dir="auto">This package is the backend of <a href="https://github.com/carstenbauer/ThreadPinning.jl">ThreadPinning.jl</a>. You may use it directly as a more lightweight alternative. Note, however, that you will need to specify the CPU threads - to which the Julia threads should be pinned - by OS indices ("physical" indices).</p>

<ul dir="auto">
<li>Pin Julia threads (get and set their processor affinity), including GC threads (on Julia &gt;= 1.11).</li>
<li>Pin OpenBLAS threads (get and set their processor affinity)</li>
<li>Fake mode (pin threads without actually pinning them, to be used in conjuction with <a href="https://github.com/carstenbauer/SysInfo.jl">SysInfo.jl</a>'s <code>TestSystem</code>s)</li>

</ul>

<p dir="auto"><strong>Only Linux is fully and officially supported.</strong> However, you can install and load the package (<code>using ThreadPinningCore</code>) without any issues on all operating systems. It's only when you call (most) functions that you will see error messages.</p>

<p dir="auto">Noteworthy limitations:</p>
<ul dir="auto">
<li><code>setaffinity(mask)</code>, for a <code>mask</code> that highlights more than one CPU-thread, will randomly choose one of the valid CPU-threads and then fake a single-1 affinity mask. Hence, <code>setaffinity(mask); getaffinity() != mask</code>.</li>
</ul>
