<p dir="auto"><code>regularization=2</code> : change the strength of the regularization from 1-4<br>
<code>erosions=3</code>: number of erosion steps applied to the mask<br>
<code>B0_dir=[0, 0, 1]</code>: direction of the B0 field for oblique orientations</p>
<p dir="auto">For most applications the following options don't have to be adjusted:</p>
<p dir="auto"><code>alpha=[0.002, 0.003]</code>: manually choose regularization parameters (overwrites <code>regularization</code>)<br>
<code>step_size=3</code>: requires less iterations with higher step size, but might lead to artefacts or iteration instabilities. <code>step_size=1</code> is the behaviour of the publication<br>
<code>iterations=1000</code>: manually choose the number of iteration steps<br>
<code>dedimensionalize=false</code>: optionally apply a dedimensionalization step<br>
<code>laplacian=get_laplace_phase_del</code>: options are <code>get_laplace_phase3</code> (corresponds to <a href="http://www.neuroimaging.at/pages/qsm.php" rel="nofollow">Python</a>  version), <code>get_laplace_phase_romeo</code> and <code>get_laplace_phase_del</code> (default). <code>get_laplace_phase_del</code> is selected as default as it improves the robustness when imperfect phase values are present<br>
<code>correct_laplacian=true</code>: subtracts the mean of the Laplacian inside the mask, which avoids edge artefacts in certain cases<br>
<code>original_kernel=false</code> : select the kernel that was used in the <a href="http://www.neuroimaging.at/pages/qsm.php" rel="nofollow">Python</a> version. This doesn't support oblique orientations</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Masking for QSM</h2><a id="user-content-masking-for-qsm" class="anchor" aria-label="Permalink: Masking for QSM" href="#masking-for-qsm"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Masking for QSM is a challenge, since including corrupted phase areas can cause global artefacts in the QSM result. See the publications <a href="https://doi.org/10.1002%2Fmrm.29048" rel="nofollow">QSMxT</a> and <a href="https://doi.org/10.1002/mrm.29368" rel="nofollow">phase based masking</a>.</p>
<p dir="auto">A simple solution is to remove areas based on phase quality using <a href="https://onlinelibrary.wiley.com/doi/10.1002/mrm.28563" rel="nofollow">ROMEO</a></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MriResearchTools
mask_phase = robustmask(romeovoxelquality(phase; mag=mag))
mask_combined = mask_phase .&amp; mask_brain"><pre><span class="pl-k">using</span> MriResearchTools
mask_phase <span class="pl-k">=</span> <span class="pl-c1">robustmask</span>(<span class="pl-c1">romeovoxelquality</span>(phase; mag<span class="pl-k">=</span>mag))
mask_combined <span class="pl-k">=</span> mask_phase <span class="pl-k">.&amp;</span> mask_brain</pre></div>
<p dir="auto">The mask might contain holes, and a more sophisticated approach is taken in the <a href="https://qsmxt.github.io/QSMxT/" rel="nofollow">QSMxT toolbox</a>.</p>
