<p dir="auto">This package allows you to interface the <a href="https://www.graphcore.ai/products/ipu" rel="nofollow">Intelligence Processing Unit (IPU) by Graphcore</a> using the <a href="https://julialang.org/" rel="nofollow">Julia programming language</a>.</p>
<p dir="auto"><em><strong>Disclaimer</strong>: at the moment this is package is in a proof-of-concept stage, not suitable for production usage.</em></p>

<p dir="auto">The package is called <code>IPUToolkit</code> because it provides different tools to interface the IPU from Julia:</p>
<ul dir="auto">
<li>you can use functionalities in the <a href="https://www.graphcore.ai/products/poplar" rel="nofollow">Poplar SDK</a>;</li>
<li>you can use Julia's code generation capabilities to automatically compile native code that can be run on the IPU;</li>
<li>there is a small <a href="https://en.wikipedia.org/wiki/Domain-specific_language" rel="nofollow">embedded Domain-Specific Language</a> (eDSL) to automatically generate the code of a program.</li>
</ul>
<p dir="auto">These approaches are exploratory of the functionalities, and are often limited in scope and are described in more details in the <a href="https://juliaipu.github.io/IPUToolkit.jl/" rel="nofollow">documentation</a>.
For examples of usage of this package, see the <a href="https://github.com/JuliaIPU/IPUToolkit.jl/tree/main/examples"><code>examples/</code></a> directory of the official repository.</p>
