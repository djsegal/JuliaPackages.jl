<p dir="auto"><code>VoxelModel.jl</code> is a Julia module for creating, manipulating, and visualizing 3D voxel geometries. It provides functionalities to create geometric shapes, add or delete them from a voxel grid, and visualize the grid using <a href="https://github.com/JuliaPlots/PlotlyJS.jl"><code>PlotlyJS.jl</code></a> and <a href="https://github.com/akjake616/PlotlyGeometries.jl"><code>PlotlyGeometries.jl</code></a>. This project is dedicated to (hopefully) easy model creation in FDTD/PSTD simulations.</p>

<p dir="auto">Please go to the examples folder for quick understanding of how to use the module:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>ex_basics.jl</code>: This example code illustrates the basic functionalities of the module.</p>
</li>
<li>
<p dir="auto"><code>ex_rotation.jl</code>: See how rotation works.</p>
</li>
<li>
<p dir="auto"><code>ex_advanced.jl</code>: Create more complicated geometries. This example demonstrates the creation of a sphere hollowd by cylinders. The voxel space is saved as a JLD file.</p>
</li>
<li>
<p dir="auto"><code>ex_load.jl</code>: Load voxel space from JLD file and perform further editing.</p>
</li>
<li>
<p dir="auto"><code>ex_assign.jl</code>: Assign grid array to the voxel space.</p>
</li>
</ul>
