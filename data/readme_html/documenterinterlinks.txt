<p dir="auto">A plugin for <a href="https://documenter.juliadocs.org/" rel="nofollow">Documenter.jl</a> that enables linking between projects.</p>
<p dir="auto">The package provides an <a href="http://juliadocs.org/DocumenterInterLinks.jl/stable/api/internals/#DocumenterInterLinks.InterLinks" rel="nofollow"><code>InterLinks</code></a> plugin that loads <a href="#inventories">inventory files</a> from other project documentations built with <a href="https://documenter.juliadocs.org/" rel="nofollow">Documenter</a> or <a href="https://www.sphinx-doc.org/en/master/" rel="nofollow">Sphinx</a>. It then extends Documenter's markdown link syntax to recognize an <code>@extref</code> link target and resolve it with a link to the external project (similarly to the built-in <code>@ref</code> links for internal links), see <a href="#external-references">External References</a>.</p>

<p dir="auto">The resulting plugin object must be passed as an element of the <code>plugins</code> keyword argument to <code>Documenter.makedocs</code>. This then enables <code>@extref</code> links in the project's documentation to be resolved.</p>
<p dir="auto">See <a href="https://github.com/JuliaDocs/DocumenterInterLinks.jl/tree/master/docs/src/inventories"><code>docs/src/inventories</code></a> for some exemplary inventory files in the <a href="https://juliadocs.org/DocInventories.jl/stable/formats/#TOML-Format" rel="nofollow">TOML format</a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Inventories</h2><a id="user-content-inventories" class="anchor" aria-label="Permalink: Inventories" href="#inventories"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Inventory files (<code>objects.inv</code>) are automatically generated by <a href="https://documenter.juliadocs.org/stable/" rel="nofollow">Documenter.jl</a> ≥ <code>v1.3.0</code> and <a href="https://www.sphinx-doc.org/en/master/" rel="nofollow">Sphinx</a>. For projects using <code>Documenter v0.25.0</code>–<code>v1.2.0</code> , the <a href="https://github.com/JuliaDocs/DocumenterInventoryWritingBackport.jl"><code>DocumenterInventoryWritingBackport</code> package</a> provides a backport of the inventory-writing functionality. For these projects, simply loading <code>DocumenterInventoryWritingBackport</code> in the <code>docs/make.jl</code> file will ensure the creation of a <code>objects.inv</code> file.</p>
<p dir="auto">For some projects that do not (or not yet) provide an inventory, manually generated inventory files in human-readable <a href="https://juliadocs.org/DocInventories.jl/stable/formats/#TOML-Format" rel="nofollow"><code>.toml</code> format</a> are collected in the <a href="https://github.com/JuliaDocs/DocumenterInterLinks.jl/wiki/Inventory-File-Repository">Inventory File Repository (Wiki)</a>. Feel free to <a href="http://juliadocs.org/DocumenterInterLinks.jl/stable/howtos/#howto-manual-inventory" rel="nofollow">generate your own inventory files</a> and contribute them. These <code>.toml</code> files can be copied to the source of your project's documentation, and loaded in the <code>InterLinks</code> plugin as local sources of inventory information.</p>
