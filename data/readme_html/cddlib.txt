<p dir="auto"><a href="https://github.com/JuliaPolyhedra/CDDLib.jl">CDDLib.jl</a> is a wrapper for
<a href="https://www.inf.ethz.ch/personal/fukudak/cdd_home/" rel="nofollow">cddlib</a>.</p>
<p dir="auto">CDDLib.jl can be used with C API of cddlib, the higher level interface of <a href="https://github.com/JuliaPolyhedra/Polyhedra.jl">Polyhedra.jl</a>,
or as a linear programming solver with <a href="https://github.com/jump-dev/JuMP.jl">JuMP</a>
or <a href="https://github.com/jump-dev/MathOptInterface.jl">MathOptInterface</a>.</p>

<p dir="auto">As written in the <a href="https://github.com/cddlib/cddlib">README of cddlib</a>:</p>
<blockquote>
<p dir="auto">The C-library  cddlib is a C implementation of the Double Description
Method of Motzkin et al. for generating all vertices (that is, extreme points)
and extreme rays of a general convex polyhedron in R^d given by a system
of linear inequalities:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="P = { x=(x1, ..., xd)^T :  b - A  x  &gt;= 0 }"><pre class="notranslate"><code>P = { x=(x1, ..., xd)^T :  b - A  x  &gt;= 0 }
</code></pre></div>
<p dir="auto">where  A  is a given m x d real matrix, b is a given m-vector
and 0 is the m-vector of all zeros.</p>
<p dir="auto">The program can be used for the reverse operation (that is, convex hull
computation).  This means that  one can move back and forth between
an inequality representation  and a generator (that is, vertex and ray)
representation of a polyhedron with cdd.  Also, cdd can solve a linear
programming problem, that is, a problem of maximizing and minimizing
a linear function over P.</p>
</blockquote>

<p dir="auto">Install CDDLib.jl using the Julia package manager:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg
Pkg.add(&quot;CDDLib&quot;)"><pre><span class="pl-k">import</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>CDDLib<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Building the package will download binaries of <a href="https://github.com/cddlib/cddlib">cddlib</a>
that are provided by <a href="https://github.com/JuliaBinaryWrappers/cddlib_jll.jl">cddlib_jll.jl</a>.</p>

<p dir="auto">Use <code>CDDLib.Optimizer{Float64}</code> to use CDDLib.jl with <a href="https://github.com/jump-dev/JuMP.jl">JuMP</a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP, CDDLib

model <span class="pl-k">=</span> <span class="pl-c1">Model</span>(CDDLib<span class="pl-k">.</span>Optimizer{Float64})</pre></div>
<p dir="auto">When using CDDLib.jl with <a href="https://github.com/jump-dev/MathOptInterface.jl">MathOptInterface</a>,
you can pass a different number type:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MathOptInterface, CDDLib

<p dir="auto">CDDLib.jl uses two global Boolean variables to enable debugging outputs: <code>debug</code> and
<code>log</code>.</p>
<p dir="auto">You can query the value of <code>debug</code> and <code>log</code> with <code>get_debug</code> and <code>get_log</code>,
and set their values with <code>set_debug</code> and <code>set_log</code>.</p>
