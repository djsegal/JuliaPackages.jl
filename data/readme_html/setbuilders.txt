<p dir="auto">Julia Package for Predicate and Enumerable Sets</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">SetBuilders provides Julia users with the power of predicate-based sets.</p>
<p dir="auto">Many programming languages, including Julia, support a type of enumerable
sets but not predicate sets in the mathematical sense. For instance,
in Julia, it's possible to create a set containing integer values, such as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = Set([1,2,3])"><pre>A <span class="pl-k">=</span> <span class="pl-c1">Set</span>([<span class="pl-c1">1</span>,<span class="pl-c1">2</span>,<span class="pl-c1">3</span>])</pre></div>
<p dir="auto">However, creating the following is not possible:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = Set(x ∈ Integer | 0 &lt; x &lt; 4)"><pre>A <span class="pl-k">=</span> <span class="pl-c1">Set</span>(x <span class="pl-k">∈</span> Integer <span class="pl-k">|</span> <span class="pl-c1">0</span> <span class="pl-k">&lt;</span> x <span class="pl-k">&lt;</span> <span class="pl-c1">4</span>)</pre></div>
<p dir="auto">The SetBuilders package enables Julia users to create predicate sets,
combine them using set operations like unions and intersections, and
check if an object is a member of a set.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="I = @setbuild(Integer)           # creates a set from Julia Integer type
A = @setbuild(x ∈  I, 0 &lt; x &lt; 4) # creates a set with the predicate of &quot;0 &lt; x &lt; 4&quot;
B = @setbuild(x in I, 2 &lt; x &lt; 6) # creates a set with the predicate of &quot;2 &lt; x &lt; 6&quot;
C = A ∩ B                        # creates an intersection with the two sets
                                 # As an alternative, &quot;intersect(A, B)&quot; can be used
@assert 3 ∈ C                    # =&gt; true, 3 is a member of the set C
                                 # As an alternative, &quot;3 in C&quot; can be used
@assert !(4 in C)                # =&gt; true, 4 is not a member of the set C"><pre>I <span class="pl-k">=</span> <span class="pl-c1">@setbuild</span>(Integer)           <span class="pl-c"><span class="pl-c">#</span> creates a set from Julia Integer type</span>
A <span class="pl-k">=</span> <span class="pl-c1">@setbuild</span>(x <span class="pl-k">∈</span>  I, <span class="pl-c1">0</span> <span class="pl-k">&lt;</span> x <span class="pl-k">&lt;</span> <span class="pl-c1">4</span>) <span class="pl-c"><span class="pl-c">#</span> creates a set with the predicate of "0 &lt; x &lt; 4"</span>
B <span class="pl-k">=</span> <span class="pl-c1">@setbuild</span>(x <span class="pl-k">in</span> I, <span class="pl-c1">2</span> <span class="pl-k">&lt;</span> x <span class="pl-k">&lt;</span> <span class="pl-c1">6</span>) <span class="pl-c"><span class="pl-c">#</span> creates a set with the predicate of "2 &lt; x &lt; 6"</span>
C <span class="pl-k">=</span> A <span class="pl-k">∩</span> B                        <span class="pl-c"><span class="pl-c">#</span> creates an intersection with the two sets</span>
                                 <span class="pl-c"><span class="pl-c">#</span> As an alternative, "intersect(A, B)" can be used</span>
<span class="pl-c1">@assert</span> <span class="pl-c1">3</span> <span class="pl-k">∈</span> C                    <span class="pl-c"><span class="pl-c">#</span> =&gt; true, 3 is a member of the set C</span>
                                 <span class="pl-c"><span class="pl-c">#</span> As an alternative, "3 in C" can be used</span>
<span class="pl-c1">@assert</span> <span class="pl-k">!</span>(<span class="pl-c1">4</span> <span class="pl-k">in</span> C)                <span class="pl-c"><span class="pl-c">#</span> =&gt; true, 4 is not a member of the set C</span></pre></div>
<p dir="auto">The <code>@setbuild</code> macro in SetBuilders creates various types of sets. In the
above example, the set <code>I</code> is built using the Julia <code>Integer</code> data type.
Meanwhile, the sets <code>A</code> and <code>B</code> are constructed by specifying the domain set
and a predicate using a boolean expression, and the set <code>C</code> is created using
the set intersection operator.</p>

<p dir="auto">The package can be installed using the Julia package manager. From the Julia
REPL, type ] to enter the Pkg REPL mode and run:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add SetBuilders"><pre>pkg<span class="pl-k">&gt;</span> add SetBuilders</pre></div>
<p dir="auto">Alternatively, it can be installed via the Pkg API:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;SetBuilders&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>SetBuilders<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Once installed, the SetBuilders package can be loaded with using SetBuilders.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SetBuilders"><pre><span class="pl-k">using</span> SetBuilders</pre></div>

<p dir="auto">In addition to set creations, set operations, and membership tests shown in the
above example, SetBuilders also provides features such as <strong>set event</strong>,
<strong>set description</strong>, <strong>set element generation</strong>, and <strong>set sharing</strong>.</p>
<p dir="auto">For more information on using the package, see the
<a href="https://grnydawn.github.io/SetBuilders.jl/" rel="nofollow">documentation</a>.</p>
