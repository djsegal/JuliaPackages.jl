<p dir="auto">ArnoldiMethod.jl's Schur decomposition is written in Julia, it does not use LAPACK. This allows
you to use arbitrary number types.</p>
<p dir="auto">We repeat the above example with <a href="https://github.com/JuliaMath/DoubleFloats.jl">DoubleFloats.jl</a>
and more accuracy.</p>
