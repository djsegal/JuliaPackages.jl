<p dir="auto">Points and lines in the rational projective plane. Both are represented using homogenous coordinates.</p>
<blockquote>
<p dir="auto">Homogenous coordinates are triples of rational numbers that are not all zero. The triple <code>(a ,b, c)</code> is the same as the triple <code>(ma, mb, mc)</code> where <code>m</code> is any nonzero rational.</p>
</blockquote>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Creating points and lines</h2><a id="user-content-creating-points-and-lines" class="anchor" aria-label="Permalink: Creating points and lines" href="#creating-points-and-lines"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A point in the projective plane is created by one of the following methods:</p>
<ul dir="auto">
<li><code>PPoint(a,b,c)</code> where <code>a</code>, <code>b</code>, and <code>c</code> are rational numbers that are not all zero.</li>
<li><code>PPoint(a,b)</code> is the same as <code>PPoint(a,b,1)</code>.</li>
<li><code>PPoint([a,b,c])</code> or <code>PPoint([a,b])</code>.</li>
</ul>
<p dir="auto">Likewise, lines are created with <code>PLine</code>.</p>
<p dir="auto">Abbreviations: <code>PP</code> for <code>PPoint</code> and <code>PL</code> for <code>PLine</code>.</p>
<p dir="auto">Points are printed as triples <code>(a : b : c)</code>.
Similarly, lines are printed as <code>[a : b : c]</code>.
The triple is scaled such that <code>a</code>, <code>b</code>, and <code>c</code> are relatively prime integers, and the rightmost nonzero
value is positive.</p>

<p dir="auto">Points and lines are not the same, but it is possible to convert a point to a line
(and vice versa). For a point <code>a</code>, use <code>PLine(a)</code> to create a line with the same
homogenous coordinates as <code>a</code>. Conversely, for a line <code>L</code> use <code>PPoint(L)</code> to create a
point with the same homogenous coordinates as <code>L</code>.</p>
<p dir="auto">The same effect can be accomplished with <code>dual</code>. That is <code>dual</code> of a <code>PPoint</code> gives a
<code>PLine</code> with the same coordinates, and vice versa.</p>

The vector version is scaled such that the last nonzero coordinate is positive and the
greatest common divisior of the components is <code>1</code>.</p>

<ul dir="auto">
<li><code>in(a,L)</code></li>
<li><code>a in L</code></li>
<li><code>a ∈ L</code></li>
<li><code>L ∋ a</code></li>
</ul>

<p dir="auto">The symbol <code>∈</code> is typed <code>\in&lt;tab&gt;</code> and the symbol <code>∋</code> is typed <code>\ni&lt;tab&gt;</code>.</p>
</blockquote>

<p dir="auto">In addition, lines can be construced from two points and points from two lines.
That is, <code>PLine(a,b)</code> is the same as <code>a ∨ b</code> and <code>PPoint(L,M)</code> is the same as
<code>L ∧ M</code>.</p>

<p dir="auto">As an alternative, the syntax <code>M(ob)</code> may be used to mean <code>M*ob</code> where <code>M</code>
is a matrix and <code>ob</code> is a <code>ProjectiveObject</code>. This is useful when one
wishes to transform a list of projective objects like this:
<code>M.(ob_list)</code>.</p>

<p dir="auto">The function <code>transform</code> can be used to create matrices to give desireable
transformations.</p>
<p dir="auto">The function <code>transform(a, aa, b, bb, c, cc)</code> (where the arguments are of type
<code>PPoint</code>) creates a matrix <code>M</code> such that <code>M(a)==aa</code>, <code>M(b)==bb</code>, and <code>M(c)==cc</code>.</p>
<p dir="auto">The shorter form <code>transform(a,b,c)</code> gives a matrix maps <code>a</code> to <code>(1 : 0 : 0)</code>,
<code>b</code> to <code>(0 : 1 : 0)</code>, and <code>c</code> to <code>(0 : 0 : 1)</code>.</p>
