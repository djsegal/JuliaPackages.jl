<p dir="auto">Vous devrez également installer Constellation elle-même, soit l'<a href="https://r%C3%A9seau-constellation.ca/t%C3%A9l%C3%A9chargements" rel="nofollow">interface graphique</a> (le plus facile), soit par la ligne de commande (vous aurez besoin de <a href="https://nodejs.org/fr/" rel="nofollow">Node.js</a> et <a href="https://pnpm.io/" rel="nofollow">pnpm</a>, si vous ne l'avez pas déjà):</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ npm add -g pnpm
$ pnpm add -g @constl/ipa @constl/serveur"><pre>$ npm add -g pnpm
$ pnpm add -g @constl/ipa @constl/serveur</pre></div>
<p dir="auto">Et voilà !</p>
