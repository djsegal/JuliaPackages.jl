<p dir="auto">Jutul is used for several applications. The primary package serves as a common infrastructure for several simulation projects. A examples of simple PDE solvers are included in this repo for testing and inspiration. Implementations are found <a href="https://github.com/sintefmath/Jutul.jl/tree/main/src/applications/test_systems">here</a> and tests for these systems that demonstrate usage are found <a href="https://github.com/sintefmath/Jutul.jl/tree/main/test/test_systems">here</a>.</p>
