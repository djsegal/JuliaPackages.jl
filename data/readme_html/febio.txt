<p dir="auto">Currently FEBio.jl does not ship with the FEBio binaries. Instead users should either obtain them from <a href="https://febio.org/" rel="nofollow">the FEBio website</a>, or compile their own using the <a href="https://github.com/febiosoftware/FEBio">FEBio source</a>.
No special configuration is required at present. However, users do need to specify the path to the FEBio executable at the top of their code, e.g.:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const FEBIO_PATH = &quot;/home/kevin/FEBioStudio/bin/febio4&quot; # Path to FEBio executable"><pre><span class="pl-k">const</span> FEBIO_PATH <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>/home/kevin/FEBioStudio/bin/febio4<span class="pl-pds">"</span></span> <span class="pl-c"><span class="pl-c">#</span> Path to FEBio executable</span></pre></div>
<p dir="auto">Next febio can be called to run the analysis for the input file <code>filename_FEB</code> using:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Run FEBio
runMonitorFebio(filename_FEB,FEBIO_PATH)"><pre><span class="pl-c"><span class="pl-c">#</span> Run FEBio</span>
<span class="pl-c1">runMonitorFebio</span>(filename_FEB,FEBIO_PATH)</pre></div>

<p dir="auto">The <code>examples</code> folder contains several demos on the use of FEBio from Julia with FEBio.jl. For instance <a href="https://github.com/febiosoftware/FEBio.jl/blob/main/examples/demo_febio_0001_cube_uniaxial_hyperelastic.jl"><code>demo_febio_0001_cube_uniaxial_hyperelastic.jl</code></a> which features a demonstration for uniaxial loading of a hyperelastic solid cube.</p>
<p dir="auto">Users are encouraged to use FEBio.jl in combination with the Julia package <a href="https://github.com/COMODO-research/Comodo.jl">Comodo</a> which enables automated geometry processing, meshing, and boundary conditions specification.</p>
