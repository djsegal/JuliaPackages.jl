<p dir="auto">Please type <code>using QMPS</code> and <code>using MSQR</code> to use any functions of this package. <strong>MSQR</strong> relies on a Julia Quantum Computation Simulation Framework package called <a href="https://github.com/QuantumBFS/Yao.jl"><strong>Yao</strong></a> to realize its full functionality and currently compatiple version is <strong>Yao 0.6</strong>. You need to type <code>using Yao</code> in order to interact with MSQR using Yao's functions.</p>
<p dir="auto">For more introductions and tutorials about MSQR's functions please check the <strong>examples</strong> directory in the repository as well as the function documentation using Julia's <a href="https://docs.julialang.org/en/v1/stdlib/REPL/#Help-mode-1" rel="nofollow"><strong><code>Help</code> mode</strong></a>.</p>

<p dir="auto">If your GPU supports <strong><a href="https://developer.nvidia.com/cuda-gpus" rel="nofollow">CUDA</a></strong>, you may also install CUDA-supported version of Yao: <strong><a href="https://github.com/QuantumBFS/CuYao.jl">CuYao</a></strong> to gain significant calculation acceleration for MSQR. After properly installing <strong>CuYao</strong> and typing <code>using CuYao</code>, you can gain GPU acceleration(saved time may vary due to different models of GPU) calling each following functions:</p>
<ul dir="auto">
<li><strong>MSQRtrain!</strong></li>
<li><strong>SWAPtrain!</strong></li>
<li><strong>SWAPtest</strong></li>
<li><strong>MSTtest</strong></li>
<li><strong>MStest</strong></li>
</ul>
<p dir="auto">If you want to manually switch off any above function's CUDA support, just add the optional function argument <code>useCuYao = false</code> when calling the function.</p>
