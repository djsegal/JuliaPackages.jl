<p dir="auto"><code>UVITTools.jl</code> allows FUV/NUV grating spectroscopy and aperture photometry of astronomical sources observed with the <a href="https://uvit.iiap.res.in/" rel="nofollow">Ultra-Violet Imaging Telescope (UVIT)</a> on-board the Indian space observatory <a href="https://www.isro.gov.in/AstroSat.html" rel="nofollow"><em>AstroSat</em></a>.  The package is compatible with the processed data generated  with the <a href="https://iopscience.iop.org/article/10.1088/1538-3873/aa8800" rel="nofollow">CCDLAB pipeline</a>. Check the <a href="https://gulabd.github.io/UVITTools.jl/dev/" rel="nofollow">latest documentation here</a>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using UVITTools"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> UVITTools</pre></div>
<p dir="auto">To find the various tools available, type</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ?UVITTools"><pre>julia<span class="pl-k">&gt;</span> ?UVITTools</pre></div>
<p dir="auto">List of tool to analyze data from the AstroSat/UVIT payload.</p>

<li><code>fuv_grating1_count_spec</code>: Extract 1d count spectrum from FUV-Grating1 image file.</li>
<li><code>fuv_grating1_net_countrate_spec</code>: Derive background-corrected net count rate spectrum from FUV-Grating1 image.</li>

<li><code>fuv_grating1_flux_calib</code>: Perform flux calibration of FUV-Grating1 wavelength-calibrated count spectrum.</li>

<li><code>fuv_grating1_phafile</code>: Generate PHA spectral files from FUV-Grating1 images.</li>
<li><code>fuv_grating1_ea</code> : Print FUV-Grating1 effective area.</li>

<li><code>fuv_grating2_pixel2lamA</code>:  Convert FUV-Grating2 pixel numbers relative to zero order position into wavelength in Å.</li>
<li><code>fuv_grating2_wavelength_calib</code>: Perform wavelength calibration of FUV-Grating2 count sectrum.</li>
<li><code>fuv_grating2_flux_calib</code>: Perform flux calibration of FUV-Grating2 wavelength-calibrated count spectrum.</li>
<li><code>fuv_grating2_fluxed_spec</code>: Generate wavelength and flux calibrated spectrum from FUV-Grating2 images.</li>
<li><code>fuv_grating2_phafile</code>: Generate PHA spectral files from FUV-Grating2 images.</li>
<li><code>fuv_grating2_ea</code>: Print FUV-Grating1 effective area.</li>
<li><code>nuv_grating_m1_count_spec</code>: Extract 1d count spectrum from NUV-Grating image file.</li>
<li><code>nuv_grating_m1_net_countrate_spec</code>: Derive background-corrected net count rate spectrum from NUV-Grating image.</li>

<ul dir="auto">
