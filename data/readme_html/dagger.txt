<p dir="auto">At the core of Dagger.jl is a scheduler heavily inspired by <a href="https://docs.dask.org/en/latest/" rel="nofollow">Dask</a>. It can run computations represented as <a href="https://en.wikipedia.org/wiki/Directed_acyclic_graph" rel="nofollow">directed-acyclic-graphs</a> (DAGs) efficiently on many Julia worker processes and threads, as well as GPUs via <a href="https://github.com/JuliaGPU/DaggerGPU.jl">DaggerGPU.jl</a>.</p>
<p dir="auto"><em>The <strong>DTable</strong> has been moved out of this repository. You can now find it <a href="https://github.com/JuliaParallel/DTables.jl">here</a>.</em></p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Dagger.jl can be installed using the Julia package manager. Enter the Pkg REPL
mode by typing "]" in the Julia REPL and then run:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add Dagger"><pre>pkg<span class="pl-k">&gt;</span> add Dagger</pre></div>
<p dir="auto">Or, equivalently, install Dagger via the Pkg API:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;Dagger&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Dagger<span class="pl-pds">"</span></span>)</pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Once installed, the <code>Dagger</code> package can be loaded with <code>using Dagger</code>, or if
you want to use Dagger for distributed computing, it can be loaded as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Distributed; addprocs() # Add one Julia worker per CPU core
using Dagger"><pre><span class="pl-k">using</span> Distributed; <span class="pl-c1">addprocs</span>() <span class="pl-c"><span class="pl-c">#</span> Add one Julia worker per CPU core</span>
<span class="pl-k">using</span> Dagger</pre></div>
<p dir="auto">You can run the following example to see how Dagger exposes easy parallelism:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# This runs first:
a = Dagger.@spawn rand(100, 100)

# These run in parallel:
b = Dagger.@spawn sum(a)
c = Dagger.@spawn prod(a)

# Finally, this runs:
wait(Dagger.@spawn println(&quot;b: &quot;, b, &quot;, c: &quot;, c))"><pre><span class="pl-c"><span class="pl-c">#</span> This runs first:</span>
a <span class="pl-k">=</span> Dagger<span class="pl-k">.</span><span class="pl-c1">@spawn</span> <span class="pl-c1">rand</span>(<span class="pl-c1">100</span>, <span class="pl-c1">100</span>)

<span class="pl-c"><span class="pl-c">#</span> These run in parallel:</span>
b <span class="pl-k">=</span> Dagger<span class="pl-k">.</span><span class="pl-c1">@spawn</span> <span class="pl-c1">sum</span>(a)
c <span class="pl-k">=</span> Dagger<span class="pl-k">.</span><span class="pl-c1">@spawn</span> <span class="pl-c1">prod</span>(a)

<span class="pl-c"><span class="pl-c">#</span> Finally, this runs:</span>
<span class="pl-c1">wait</span>(Dagger<span class="pl-k">.</span><span class="pl-c1">@spawn</span> <span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>b: <span class="pl-pds">"</span></span>, b, <span class="pl-s"><span class="pl-pds">"</span>, c: <span class="pl-pds">"</span></span>, c))</pre></div>

<p dir="auto">Dagger can support a variety of use cases that benefit from easy, automatic
parallelism, such as:</p>
<ul dir="auto">

<p dir="auto">Contributions are encouraged.</p>
<p dir="auto">There are several ways to contribute to our project:</p>
<p dir="auto"><strong>Reporting Bugs</strong>: If you find a bug, please open an issue and describe the problem. Make sure to include steps to reproduce the issue and any error messages you receive regarding that issue.</p>
<p dir="auto"><strong>Fixing Bugs</strong>: If you'd like to fix a bug, please create a pull request with your changes. Make sure to include a description of the problem and how your changes will address it.</p>
<p dir="auto">Additional examples and documentation improvements are also very welcome.</p>
