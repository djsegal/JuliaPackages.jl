<p dir="auto">A small utility package to emulate executing Julia code, seemingly in a clean <code>Main</code> module.</p>

</div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">API overview</h2><a id="user-content-api-overview" class="anchor" aria-label="Permalink: API overview" href="#api-overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">There are two main parts to the API:</p>
<ol dir="auto">
<li>
<p dir="auto">The <code>Sandbox</code> object: provides a clean, mock Julia Main module, and the related low-level <code>evaluate!</code> function to directly evaluate Julia expressions in the sandbox.</p>
</li>
<li>
<p dir="auto">Higher level functions that can be used to run code in the sandbox in different modes (<code>codeblock!</code> and <code>replblock!</code>).</p>
</li>
</ol>
<div class="markdown-alert markdown-alert-note" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-info mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M0 8a8 8 0 1 1 16 0A8 8 0 0 1 0 8Zm8-6.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM6.5 7.75A.75.75 0 0 1 7.25 7h1a.75.75 0 0 1 .75.75v2.75h.25a.75.75 0 0 1 0 1.5h-2a.75.75 0 0 1 0-1.5h.25v-2h-.25a.75.75 0 0 1-.75-.75ZM8 6a1 1 0 1 1 0-2 1 1 0 0 1 0 2Z"></path></svg>Note</p><p dir="auto">The functions that run code in a sandbox are marked with <code>!</code> because they mutate the sandbox.</p>
</div>
<div class="markdown-alert markdown-alert-warning" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-alert mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M6.457 1.047c.659-1.234 2.427-1.234 3.086 0l6.082 11.378A1.75 1.75 0 0 1 14.082 15H1.918a1.75 1.75 0 0 1-1.543-2.575Zm1.763.707a.25.25 0 0 0-.44 0L1.698 13.132a.25.25 0 0 0 .22.368h12.164a.25.25 0 0 0 .22-.368Zm.53 3.996v2.5a.75.75 0 0 1-1.5 0v-2.5a.75.75 0 0 1 1.5 0ZM9 11a1 1 0 1 1-2 0 1 1 0 0 1 2 0Z"></path></svg>Warning</p><p dir="auto">The code evaluation is not thread/async-safe.

This also affects any code running in parallel in other tasks or threads.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Sandbox</h3><a id="user-content-sandbox" class="anchor" aria-label="Permalink: Sandbox" href="#sandbox"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Constructing a <code>Sandbox</code> object provides you</p>
<p dir="auto">The <code>evaluate!</code> function can be used to evaluate Julia expressions within the context of the sandbox module.
It returns a <code>Result</code> object that contains the captured return value and what was printed into the standard output and error streams.</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; sb = CodeEvaluation.Sandbox();

julia&gt; r = CodeEvaluation.evaluate!(sb, :(x = 40 + 2));

julia&gt; r.value, r.output
(42, &quot;&quot;)

julia&gt; r = CodeEvaluation.evaluate!(sb, :(println(&quot;x = &quot; * string(x))));

julia&gt; r.value, r.output
(nothing, &quot;x = 42\n&quot;)"><pre>julia&gt; sb <span class="pl-k">=</span> CodeEvaluation<span class="pl-k">.</span><span class="pl-c1">Sandbox</span>();

julia&gt; r <span class="pl-k">=</span> CodeEvaluation<span class="pl-k">.</span><span class="pl-c1">evaluate!</span>(sb, :(x <span class="pl-k">=</span> <span class="pl-c1">40</span> <span class="pl-k">+</span> <span class="pl-c1">2</span>));

julia&gt; r<span class="pl-k">.</span>value, r<span class="pl-k">.</span>output
(42, "")

julia&gt; r <span class="pl-k">=</span> CodeEvaluation<span class="pl-k">.</span><span class="pl-c1">evaluate!</span>(sb, :(<span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>x = <span class="pl-pds">"</span></span> <span class="pl-k">*</span> <span class="pl-c1">string</span>(x))));

(nothing, "x = 42\n")</pre></div>
<p dir="auto">As an implementation detail, it uses the <a href="https://github.com/JuliaDocs/IOCapture.jl">IOCapture.jl</a> package underneath to perform output capture of the evaluated code.</p>
<p dir="auto">As an asterisk, as the sandboxes are implemented as anonymous Julia modules, all within the same Julia process, there are limitations to to their independence (e.g. method definitions and other global state modifications can, of course, leak over).
The goal is to be best-effort in terms of providing a seemingly independent Julia session to execute code in.</p>
<div class="markdown-alert markdown-alert-note" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-info mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M0 8a8 8 0 1 1 16 0A8 8 0 0 1 0 8Zm8-6.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM6.5 7.75A.75.75 0 0 1 7.25 7h1a.75.75 0 0 1 .75.75v2.75h.25a.75.75 0 0 1 0 1.5h-2a.75.75 0 0 1 0-1.5h.25v-2h-.25a.75.75 0 0 1-.75-.75ZM8 6a1 1 0 1 1 0-2 1 1 0 0 1 0 2Z"></path></svg>Note</p><p dir="auto">The notion of a sandbox can probably be abstracted.
While a module-based sandbox is very simple, it would be useful to have a way to execute Julia code in a clean process (e.g. to fully enforce the independence of the sandboxes, run code in a different package environment, or multi-threading settings).
However, ideally the high-level API would be the same, irrespective of how the sandbox is implemented.</p>
</div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Evaluating code</h3><a id="user-content-evaluating-code" class="anchor" aria-label="Permalink: Evaluating code" href="#evaluating-code"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Presently, there are two functions that offer a</p>
<ol dir="auto">
<li>
<p dir="auto"><code>codeblock!</code> is meant to offer a simple way to execute a block of Julia code (provided as a simple string, not a parsed expression).
This is roughly meant to correspond to running a Julia script.</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; sb = CodeEvaluation.Sandbox();

(42, &quot;x = 40\n&quot;)"><pre>julia&gt; sb <span class="pl-k">=</span> CodeEvaluation<span class="pl-k">.</span><span class="pl-c1">Sandbox</span>();

       """

</li>
<li>
<p dir="auto"><code>replblock!</code> emulates a REPL session.
The input code is split up and evaluated as if copy-pasted into the REPL line-by-line.
The outputs are then captured as if they would be shown in the REPL.</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; sb = CodeEvaluation.Sandbox();

       """
