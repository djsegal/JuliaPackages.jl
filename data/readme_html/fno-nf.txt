<p dir="auto">All of the software packages used in this paper are fully <em>open source, scalable, interoperable, and differentiable</em>. The readers are welcome to learn about our software design principles from <a href="https://library.seg.org/doi/10.1190/tle42070474.1" rel="nofollow">this open-access article</a>.</p>

<p dir="auto">We use <a href="https://github.com/slimgroup/JUDI.jl">JUDI.jl</a> for wave modeling and inversion, which calls the highly optimized propagators of <a href="https://www.devitoproject.org/" rel="nofollow">Devito</a>.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Multiphase flow</h4><a id="user-content-multiphase-flow" class="anchor" aria-label="Permalink: Multiphase flow" href="#multiphase-flow"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We use <a href="https://github.com/slimgroup/JutulDarcyRules.jl">JutulDarcyRules.jl</a> to solve the multiphase flow equations, which calls the high-performant and auto-differentiable numerical solvers in <a href="https://github.com/sintefmath/Jutul.jl">Jutul.jl</a> and <a href="https://github.com/sintefmath/JutulDarcy.jl">JutulDarcy.jl</a>. <a href="https://github.com/slimgroup/JutulDarcyRules.jl">JutulDarcyRules.jl</a> is designed to interoperate these two packages with other Julia packages in the Julia AD ecosystem via <a href="https://github.com/JuliaDiff/ChainRules.jl">ChainRules.jl</a>.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Scientific machine learning</h4><a id="user-content-scientific-machine-learning" class="anchor" aria-label="Permalink: Scientific machine learning" href="#scientific-machine-learning"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We use <a href="https://github.com/slimgroup/InvertibleNetworks.jl">InvertibleNetworks.jl</a> to train the normalizing flows (NFs). This package implements memory-efficient invertible networks via hand-written derivatives. This ensures that these invertible networks are scalable to realistic 3D problems.</p>
<p dir="auto">We use <a href="https://github.com/slimgroup/FNO4CO2">FNO4CO2.jl</a> to train the Fourier neural operators (FNOs) as learned surrogates for multiphase flow solvers in <a href="https://github.com/slimgroup/JutulDarcyRules.jl">JutulDarcyRules.jl</a>. In order for scaling to realistic 4D problems, we suggest the readers also have a look at the <a href="https://github.com/slimgroup/dfno">dfno</a> package, which implements <a href="https://doi.org/10.1016/j.cageo.2023.105402" rel="nofollow">model-parallel Fourier neural operators</a> that are demonstrated to scale to realistic size 4D problems (input size is over <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2791b169cc311f54e3eeff81a50bedd8">$512\times512\times512\times20$</math-renderer>).</p>

<p dir="auto">First, install <a href="https://julialang.org/" rel="nofollow">Julia</a> and <a href="https://www.python.org/" rel="nofollow">Python</a>. The scripts will contain package installation commands at the beginning so the packages used in the experiments will be automatically installed.</p>
