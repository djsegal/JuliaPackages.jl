<p dir="auto"><code>Hanzi.jl</code> exports two functions: <code>pinyin</code> and <code>wadegiles</code>. Both functions expect a string as input and will product a <code>Vector{Vector{String}}</code>, where each <code>Vector{String}</code> are the possible pronunciations for a given Hanzi. By default, only one pronunciation per character will be returned, meaning each <code>Vector{String}</code> will have only one item. Setting the option <code>multiple=true</code> in the function call will return multiple pronunciations for applicable characters. If non-Hanzi characters are encountered adjacent to each other, they will be returned as single-item <code>Vector{String}</code>s.</p>
