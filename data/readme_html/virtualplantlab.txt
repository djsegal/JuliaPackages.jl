<p dir="auto">This is the main package in the <a href="http://virtualplantlab.com/" rel="nofollow">Virtual Plant Lab</a> that users
are meant to download and use. It is a meta-package that includes all the other packages
in the VirtualPlantLab organization where the different features are implemented. The user
does not need to be aware of the other packages, except in cases where methods need to be
define for user-defined types (currently that is the case for <code>PlantGeomTurtle.feed!()</code>
which is required to generate geometry from user-defined types).</p>

<p dir="auto">To start using VirtualPlantLab.jl, you need to load it first:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using VirtualPlantLab"><pre><span class="pl-k">using</span> VirtualPlantLab</pre></div>
<p dir="auto">The entire API of the Virtual Plant Lab will become available after loading.</p>
<p dir="auto">For people starting, it is recommended to follow the tutorials in the
<a href="http://virtualplantlab.com/" rel="nofollow">documentation</a>. The entire API is also documented there.</p>
