<p dir="auto">Rete is a simple library for implementing rule based systems using the
Rete algorithm.</p>
<p dir="auto">Rete currently implements memory for Julia types, forward chaining
joins, and backward chaining filter and extrema operations.</p>
<p dir="auto">See the documentation linked above.</p>
<p dir="auto">Rete.jl is used extensively in
<a href="https://github.com/MarkNahabedian/SquareDanceReasoning.jl">SquareDanceReasoning.jl</a>.  See the
<a href="https://github.com/MarkNahabedian/SquareDanceReasoning.jl/tree/main/src/formations">formations code</a>
for real examples of rules and the use of Rete.jl.</p>
