<div align="justify" dir="auto">
<p dir="auto">This package implements the <strong>direct dedispersion algorithm</strong> in pure Julia. Quoting from <a href="https://doi.org/10.1111/j.1365-2966.2012.20622.x" rel="nofollow"><strong>Barsdell et al. (2012)</strong></a>:</p>
<blockquote>
<p dir="auto">The direct dedispersion algorithm operates by directly summing frequency channels along a quadratic dispersion trail for each time sample and dispersion measure. In detail, the algorithm computes an array of dedispersed time series <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$D$</math-renderer> from an input data set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$A$</math-renderer> according to the following equation:
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$$\boxed{D_{d, t} = \sum_{\nu}^{N_{\nu}} A_{\nu, t + \Delta t(d, \nu)}}$$</math-renderer>
where the subscripts <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$d$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$t$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$\nu$</math-renderer> represent dispersion measure, time sample and frequency channel, respectively, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0e17f0e8f138374819b739c781d152c0">$N_{\nu}$</math-renderer> is the total number of frequency channels.</p>
</blockquote>
<p dir="auto">Install it by typing and running:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="] add DirectDedispersion"><pre>] add DirectDedispersion</pre></div>
<p dir="auto">in the Julia REPL.</p>

<p dir="auto">The slight incline in both plots is due to the fact that the DM of the simulated FRB is quite high, and the length of the file is low. Thus, we run out of samples to add as we go to lower frequency channels. The simulation was carried out using the <a href="https://bitbucket.csiro.au/projects/PSRSOFT/repos/simulatesearch/browse" rel="nofollow"><strong><code>simulateSearch</code></strong></a> library, and is included in this package as a part of its testing suite <a href="./test/data/frb.fil"><strong>here</strong></a>. The time series from <a href="https://github.com/scottransom/presto"><strong><code>PRESTO</code></strong></a> was obtained by using the following command:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="prepdata -dm 1000.0 -nobary frb.fil -o frb.dedisp"><pre>prepdata -dm 1000.0 -nobary frb.fil -o frb.dedisp</pre></div>
