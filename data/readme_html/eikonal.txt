<p dir="auto">Julia implementations of solvers for general Eikonal equations of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$$\begin{align}
&amp;\left\Vert\nabla \tau\right\Vert = \sigma(x), &amp;&amp; \forall x\in\Omega\subset\mathbb{R}^N,\\
&amp;\tau(x_0) = 0, &amp;&amp; \forall x_0\in\Gamma\subset\Omega,
\end{align}$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$\Omega$</math-renderer> is a rectangular, N-dimensional spatial domain, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$\tau(x)$</math-renderer> represents
the first arrival time at point <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$x$</math-renderer> of a front moving with slowness
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$\sigma$</math-renderer> (i.e. speed <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$1/\sigma$</math-renderer>) and originating from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3fbd4da1bb47fd996178ff838d6d0409">$\Gamma$</math-renderer>.</p>
<p dir="auto">This package provides implementations for two methods</p>
<ul dir="auto">
<li>Fast Sweeping Method (FSM)  [1]</li>
<li>Fast Marching Method (FMM)  [2]</li>
</ul>
<p dir="auto">[1] Zhao, Hongkai (2005-01-01). "A fast sweeping method for Eikonal equations". Mathematics of Computation. 74 (250): 603–627. <a href="https://doi.org/10.1090%2FS0025-5718-04-01678-3" rel="nofollow">DOI: 10.1090/S0025-5718-04-01678-3</a><br>
[2] J.A. Sethian. A Fast Marching Level Set Method for Monotonically Advancing Fronts, Proc. Natl. Acad. Sci., 93, 4, pp.1591--1595, 1996. <a href="https://math.berkeley.edu/~sethian/2006/Papers/sethian.fastmarching.pdf" rel="nofollow">PDF</a></p>

<p dir="auto">This first example uses the Fast Marching method to compute a field of
distances to a set of source points. It is equivalent to the example given by
the <a href="https://github.com/hellemo/FastMarching.jl">FastMarching.jl</a> package.</p>
