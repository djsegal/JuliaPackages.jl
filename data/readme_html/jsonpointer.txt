<p dir="auto"><a href="https://tools.ietf.org/html/rfc6901/" rel="nofollow">JSONPointer</a> is a Unicode string containing a sequence of zero or more reference tokens, each prefixed by a '/' (%x2F) character.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key Features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key Features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>JSONPointer Syntax Support: The package supports the creation and manipulation of JSON Pointers, allowing users to navigate and access elements within JSON data structures.</li>
</ul>
<p dir="auto"><strong>Exported Functions and Types:</strong></p>
<ul dir="auto">
<li><code>@j_str</code>: allowing string literal <code>j"/foo"</code> to construct a JSONPointer</li>
<li><code>PointerDict</code>: A type that extends AbstractDict to support JSON Pointers.</li>
<li><code>has_pointer</code>, <code>get_pointer</code>, <code>set_pointer!</code>: Functions to check if a pointer exists, retrieve a value by pointer, and set a value by pointer, respectively.</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Using JSONPointer with <code>AbstractDict</code></h2><a id="user-content-using-jsonpointer-with-abstractdict" class="anchor" aria-label="Permalink: Using JSONPointer with AbstractDict" href="#using-jsonpointer-with-abstractdict"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To integrate JSONPointer with AbstractDict types in Julia, you have two effective approaches:</p>
<ol dir="auto">
<li>
<p dir="auto">Leveraging JSONPointer Functions: Utilize the newly defined functions specifically for JSONPointer, such as <code>set_pointer!</code>, <code>get_pointer</code>, and <code>has_pointer</code>, to interact with your AbstractDict objects.</p>
</li>
<li>
<p dir="auto">Employing <code>PointerDict</code>: Enclose <code>AbstractDict</code> instances within PointerDict, which seamlessly integrates with the base interface, enabling operations such as <code>doc[key]</code>, <code>doc[key] = value</code>, and <code>haskey(doc, key)</code>.</p>
</li>
</ol>
