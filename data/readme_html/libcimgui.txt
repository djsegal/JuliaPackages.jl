<p dir="auto">Julia language binding for <a href="https://github.com/cimgui/cimgui">cimgui</a>(docking
branch), <a href="https://github.com/cimgui/cimplot">cimplot</a>, and
<a href="https://github.com/cimgui/cimnodes">cimnodes</a>.</p>
<p dir="auto">The code the bindings are generated from come from the
<a href="https://github.com/JuliaPackaging/Yggdrasil/tree/master/C/CImGuiPack">CImGuiPack</a>
JLL, which is built from the
<a href="https://github.com/JuliaImGui/cimgui-pack">cimgui-pack</a> repo. Note that the
versioning of this repo <em>does not</em> exactly match upstream Dear ImGui, we only
match the major and minor version. The patch version is specific to
LibCImGui.jl. See the release notes for the exact Dear ImGui version used for
each LibCImGui.jl release.</p>

<p dir="auto">The bindings for the different platforms in <a href="lib/">lib/</a> are generated by the
files in <a href="gen/">gen/</a>. To update the bindings you'll first need to update
<code>CImGuiPack_jll</code>, then run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project=gen generator.jl"><pre class="notranslate"><code>julia --project=gen generator.jl
</code></pre></div>
<p dir="auto">The first time might take a while since it has to download artifacts for each
platform.</p>
