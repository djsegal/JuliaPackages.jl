<blockquote>
<p dir="auto">Representing DNA sequences as regular tetrahedrals (Simplex)</p>
</blockquote>
<p dir="auto">This packages has a single public function <code>biosimplex</code> that takes a <code>BioSequence</code> and returns a <em>Simplex</em> representation of a <em>BioSequence</em>. The <em>Simplex</em> representation is a 3D representation of the <em>BioSequence</em> where each base can be represented as unit vectors pointing into a regular tetrahedron (Silverman et al., 1986; Coward, 1997).</p>
