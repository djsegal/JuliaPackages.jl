<p dir="auto">This package provides a simple function <code>OpenQASM.parse</code> to parse a QASM string to
its AST according to its BNF specification described in <a href="https://github.com/Qiskit/openqasm/tree/OpenQASM2.x">OpenQASM 2.0</a>.</p>
