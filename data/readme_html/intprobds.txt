<p dir="auto">Julia code to accompany <em>Introduction to Probability for Data Science</em> by Stanley H. Chan <a href="https://probability4datascience.com/index.html" rel="nofollow">https://probability4datascience.com/index.html</a></p>
<p dir="auto">This holds Julia translations of the Matlab and Python code that accompanies the book. This effort has been authorized by Stanley H. Chan.</p>
<p dir="auto">To use this code:</p>
<ul dir="auto">
<li>download or clone the archive to some directory.</li>
<li>Go to that directory, and start Julia with <code>julia --proj</code> to let Julia know which packages are needed.</li>
<li>The first time you do this, enter <code>] instantiate</code> to install all of the needed packages, followed by CTRL-C to go back to the Julia prompt, once the packages have been installed (you may be told to exit and re-start Julia)</li>
<li>once that's done, enter Julia again with <code>julia --proj</code>, and you are ready to run the code.</li>
<li>from the files for each chapter, copy the code block you desire to run, and paste it into the Julia REPL. In a few cases, you will need data files that are available from the book's web site, linked above. Make sure you download the needed files into the working directory before running those blocks of code.</li>
</ul>
