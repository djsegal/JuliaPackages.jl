<p dir="auto">MCMCBenchmarks provides a lightweight yet flexible framework for benchmarking MCMC samplers in terms of runtime, memory usage, convergence metrics and effective sample size. Currently, MCMCBenchmarks provides out of the box support for benchmarking the <a href="http://jmlr.org/papers/volume15/hoffman14a/hoffman14a.pdf" rel="nofollow">No-U-Turn Sampler</a> (NUTS) algorithm as implemented in <a href="https://github.com/StanJulia/CmdStan.jl">CmdStan</a>, <a href="https://github.com/tpapp/DynamicHMC.jl">DynamicHMC</a> and <a href="https://github.com/TuringLang/AdvancedHMC.jl">AdvancedHMC</a> via <a href="https://github.com/TuringLang/Turing.jl">Turing</a>. However, methods can be extended to accommodate other samplers and test models.</p>

<ul dir="auto">
<li>Benchmarking Parameters: vary factors such as sample size, data-generating parameters, prior distributions, and target acceptance rate. The use of optional keywords allows other benchmarking parameters to be varied.</li>
<li>Meta-data: saves relevant benchmarking information regarding package version, Julia version and system specs.</li>
<li>Plotting: generate and save plots comparing samplers in terms of run time, memory usage, convergence diagnostics and effective sample size.</li>
</ul>
