<p dir="auto">COBREXA.jl provides constraint-based reconstruction and analysis tools for
exa-scale metabolic modeling in <a href="https://julialang.org/" rel="nofollow">Julia</a>.</p>
<p dir="auto">For COBREXA.jl releases before version 2.0 (released in 2023 and earlier),
please see <a href="https://github.com/LCSB-BioCore/COBREXA.jl">the legacy COBREXA repository with version 0.x and 1.x</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Why use COBREXA.jl?</h2><a id="user-content-why-use-cobrexajl" class="anchor" aria-label="Permalink: Why use COBREXA.jl?" href="#why-use-cobrexajl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Compared to the other modeling toolkits, COBREXA.jl offers:</p>
<ul dir="auto">
<li>Almost effortless parallelization to scale-up to HPC environments. This
allows the users to quickly run huge analyses.</li>
<li>A straightforward way to construct new kinds of constraint systems by
re-using and re-combining the existing ones with newly implemented
functionality, provided by
<a href="https://github.com/COBREXA/ConstraintTrees.jl">ConstraintTrees.jl</a>
middleware. This vastly simplifies reconstruction of complex systems, such as
multi-compartment ("community") growth-balanced models with both per-member
and global resource-allocation and metabolite availability constraints.</li>
<li>Performance at the level of "raw" user workflow operations, because all
analysis code are compiled and optimized by Julia. This reduces the
computation time and memory required to analyze very large models.</li>
<li>A wide range of pre-implemented HPC-compatible analysis functions, with
<a href="https://cobrexa.github.io/COBREXA.jl/dev/examples/" rel="nofollow">tested examples available in the documentation</a>.</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Installation</h3><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">COBREXA.jl is best installed using Julia's packaging system.</p>
<ol dir="auto">
<li>If you do not have Julia installed, <a href="https://julialang.org/downloads/" rel="nofollow">download it from the official
site</a>.</li>
<li>Start Julia by typing <code>julia</code> into a terminal</li>
<li>Type <code>] add COBREXA</code>. This will install COBREXA automatically, with all
dependencies.</li>
<li>You may want to install <a href="https://jump.dev/JuMP.jl/stable/installation/#Supported-solvers" rel="nofollow">additional constraint-solver software compatible
with JuMP</a>.
Type e.g. <code>] add HiGHS</code> to install the HiGHS solver.</li>
</ol>

<p dir="auto">In the container, you should get a <code>julia</code> shell with the important packages
already installed, and you may immediately import the package with <code>using COBREXA</code>, and start running COBREXA analyses (such as the ones in the
<a href="https://cobrexa.github.io/COBREXA.jl/dev/examples/" rel="nofollow">documentation examples</a>).</p>
<p dir="auto">If you require precise reproducibility, use a tag like <code>v1.2.2</code> instead of
<code>latest</code> (all releases since 1.2.2 are tagged this way).</p>

repository at <a href="https://github.com/LCSB-BioCore/COBREXA.jl">github.com/LCSB-BioCore/COBREXA.jl</a>.</p>
