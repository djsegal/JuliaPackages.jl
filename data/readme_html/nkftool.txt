<p dir="auto">NKFtool is a <a href="https://julialang.org" rel="nofollow">Julia</a> package for guessing and converting
encodings in Japanese text.  This is the wrapper module
to Network kanji (Japanese characters) filter,
aka <a href="https://osdn.net/projects/nkf/" rel="nofollow">nkf</a>,
and provides the interface to use nkf from Julia.</p>

<p dir="auto">NKFtool requires nkf to be installed in your system. Major Unix-like operating systems offer its precompiled version in their package management systems.</p>
<p dir="auto">NKFtool also requires Julia v1.0 or above.</p>
<p dir="auto">To install NKFtool using Julia's packaging system, enter Julia's package manager prompt with <code>]</code>, and run</p>

</code></pre></div>
