<p dir="auto">Right now the package implements only basic methods associated with the service:</p>
<ul dir="auto">
<li>obtaining token via <code>requestBitlyToken</code></li>
<li>link shortening via <code>shorten</code></li>
<li>link expansion via <code>expand</code></li>
<li>click statistics via <code>clicks</code></li>
</ul>
<p dir="auto">This package is very much incomplete, but it does provide the basic functionality. It does what I need it to do.</p>
<p dir="auto">I am open to pull requests that extend or improve existing features.</p>
<p dir="auto">See the <a href="https://tbeason.github.io/Bitly.jl/stable" rel="nofollow">documentation</a> for more information.</p>
