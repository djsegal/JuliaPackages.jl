<p dir="auto">This is a Julia package for using the Hybrid A* algorithm. Hybrid A* algorithm is typically used to find a drivable path for a Dubin's car in an obstacle rich environment. However, it can be used for other problems as well that fall in the same category! (Problems with continuous/discrete state space and finite action space)</p>

<p dir="auto">The function returns a sequence of actions that can be applied to the agent to take it from its starting position to its goal position.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Arguments</h4><a id="user-content-arguments" class="anchor" aria-label="Permalink: Arguments" href="#arguments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>goal::Any</code>: specifies the agent's goal location/set; Any object that supports <code>in(goal, state)</code> can be used.</li>
<li><code>start_state::Any</code>: specifies the agent's starting state</li>
<li><code>actions::AbstractVector</code>: list of available agent actions</li>
<li><code>dynamics::Function</code>: function describing the dynamics of the agent. It takes in the state and an action as inputs and outputs the next resulting state. It will be called like this: <code>next_state = dynamics(state, action)</code></li>
<li><code>discretization::Function</code>: function that is used to discretize the continuous agent state. It takes in the state as an input and outputs the corresponding discrete value. It will be called like this: <code>discrete_key = discretization(state)</code></li>
<li><code>g::Function</code>: function that calculates the cost of transitioning from one state to the other. It takes in the old state, the new state, the applied action and the depth of the new state in the graph as inputs and outputs the corresponding cost. To penalize collision with obstacles in the environment, user should reflect it in this function. <code>g</code> will be called like this: <code>cost = g(old_state, new_state, action, new_depth)</code></li>
<li><code>h::Function</code>: function that calculates the heuristic cost of reaching the goal from any given state. It takes in the state as an input and outputs the corresponding heuristic cost. It will be called like this: <code>heuristic_cost = h(state)</code></li>
</ul>
