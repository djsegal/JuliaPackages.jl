<p dir="auto">This repository contains experimental code for solving linear programming using first-order methods on NVIDIA GPUs.</p>
<p dir="auto">Part of the code utilizes <a href="https://github.com/google-research/FirstOrderLp.jl">https://github.com/google-research/FirstOrderLp.jl</a> which originally stated Apache-2.0 as its license.</p>

<p dir="auto"><code>solve.jl</code> is the recommended script for using cuPDLP. The results are written to JSON and text files. All commands below assume that the current directory is the working directory.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ julia --project scripts/solve.jl \
--instance_path=INSTANCE_PATH --output_directory=OUTPUT_DIRECTORY \
--tolerance=TOLERANCE --time_sec_limit=TIME_SEC_LIMIT"><pre>$ julia --project scripts/solve.jl \
--instance_path=INSTANCE_PATH --output_directory=OUTPUT_DIRECTORY \
--tolerance=TOLERANCE --time_sec_limit=TIME_SEC_LIMIT</pre></div>

<p dir="auto">A table of iteration stats will be printed with the following headings.</p>
<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">runtime</h5><a id="user-content-runtime" class="anchor" aria-label="Permalink: runtime" href="#runtime"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>#iter</code> = the current iteration number.</p>
<p dir="auto"><code>#kkt</code> = the cumulative number of times the KKT matrix is multiplied.</p>
<p dir="auto"><code>seconds</code> = the cumulative solve time in seconds.</p>
<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">residuals</h5><a id="user-content-residuals" class="anchor" aria-label="Permalink: residuals" href="#residuals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>pr norm</code> = the Euclidean norm of primal residuals (i.e., the constraint
violation).</p>
<p dir="auto"><code>du norm</code> = the Euclidean norm of the dual residuals.</p>
<p dir="auto"><code>gap</code> = the gap between the primal and dual objective.</p>
<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">solution information</h5><a id="user-content-solution-information" class="anchor" aria-label="Permalink: solution information" href="#solution-information"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>pr obj</code> = the primal objective value.</p>
<p dir="auto"><code>pr norm</code> = the Euclidean norm of the primal variable vector.</p>
<p dir="auto"><code>du norm</code> = the Euclidean norm of the dual variable vector.</p>
<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">relative residuals</h5><a id="user-content-relative-residuals" class="anchor" aria-label="Permalink: relative residuals" href="#relative-residuals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>rel pr</code> = the Euclidean norm of the primal residuals, relative to the
right-hand-side.</p>
<p dir="auto"><code>rel dul</code> = the Euclidean norm of the dual residuals, relative to the primal
linear objective.</p>
<p dir="auto"><code>rel gap</code> = the relative optimality gap.</p>
