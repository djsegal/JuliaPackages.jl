<p dir="auto">The present package implements the generalized transfer matrix
formalism as presented in [<a href="#References">1-3</a>]. The authors provide a Python
implementation (<a href="https://github.com/pyMatJ/pyGTM">pyGTM</a>), as well as a Matlab
implementation (<a href="https://doi.org/10.5281/zenodo.601496" rel="nofollow">First version (2019)</a>,
<a href="https://zenodo.org/record/3648041" rel="nofollow">Updated version (2020)</a>).</p>

<p dir="auto">The package can be installed with the Julia package manager.
From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add GeneralizedTransferMatrixMethod"><pre class="notranslate"><code>pkg&gt; add GeneralizedTransferMatrixMethod
</code></pre></div>
<p dir="auto">Or, equivalently, via the <code>Pkg</code> API:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;GeneralizedTransferMatrixMethod&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>GeneralizedTransferMatrixMethod<span class="pl-pds">"</span></span>)</pre></div>

)
