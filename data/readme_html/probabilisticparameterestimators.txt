<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Problem Setup</h2><a id="user-content-problem-setup" class="anchor" aria-label="Permalink: Problem Setup" href="#problem-setup"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We assume parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\theta$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\mathbb{R}^m$</math-renderer>, inputs <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$x$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\mathbb{R}^n$</math-renderer>, and observations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\mathbb{R}^l$</math-renderer>, linked by a observation function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$$y = f(x, \theta) + \varepsilon$$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\varepsilon$</math-renderer> is sampled from a known noise distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$p_{\bar{\varepsilon}}$</math-renderer>.
Further assumptions of the noise models are discussed below.
Notice also that <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$x$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y$</math-renderer>, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$theta$</math-renderer> may all be multidimensional, with different dimensions.</p>
<p dir="auto">Given that we have uncertainty in the observations, we are interested in constructing a probabilistic description <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$p_{\bar{\theta}}(\theta \mid y)$</math-renderer> of the parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\theta$</math-renderer>, either as a distribution, or as a set of samples.
We implement three estimators for this task, which map to either samples or a distribution via <code>predictsamples(est, f, xs, ys, paramprior, noisemodel, nsamples)</code> and <code>predictdist(est, f, xs, ys, paramprior, noisemodel)</code>, respectively.
The conversion between samples and a distribution can be done automatically via sampling or fitting a multivariate normal distribution.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">MCMCEstimator</h3><a id="user-content-mcmcestimator" class="anchor" aria-label="Permalink: MCMCEstimator" href="#mcmcestimator"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>MCMCEstimator</code> simply phrases the problem as a Monte-Carlo Markov-Chain inference problem, which we solve using the <code>NUTS</code> algorithm provided by <code>Turing.jl</code>.
Therefore <code>predictdist(::MCMCEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will create <code>nsamples</code> samples (after skipping a number of warmup steps).
<code>predictdist(::MCMCEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will do the same, and then fit a <code>MvNormal</code> distribution.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">LSQEstimator</h3><a id="user-content-lsqestimator" class="anchor" aria-label="Permalink: LSQEstimator" href="#lsqestimator"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>LSQEstimator</code> works by sampling noise <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\varepsilon^{(k)}$</math-renderer> from the noise model and repeatedly solving a least-squares parameter estimation problem for modified observations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y - \varepsilon^{(k)}$</math-renderer>, i.e.
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$$\theta = \arg \min_\theta \sum_i ((y_i - \varepsilon_i^{(k)}) - f(x_i, \theta))^2 \cdot w_i$$</math-renderer>
for uncorrelated noise, where the weights <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$w_i$</math-renderer> are chosen as the inverse variance.
For correlated noise, the weight results from the whole covariance matrix.
The <code>paramprior</code> is used to sample initial guesses for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\theta$</math-renderer>.</p>
<p dir="auto">Therefore <code>predictsamples(::LSQEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will solve <code>nsamples</code> optimization problems and return a sample each.
<code>predictdist(::LSQEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will do the same, and then fit a <code>MvNormal</code> distribution.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">LinearApproxEstimator</h3><a id="user-content-linearapproxestimator" class="anchor" aria-label="Permalink: LinearApproxEstimator" href="#linearapproxestimator"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>LinearApproxEstimator</code> solves the optimization problem above just once, and then constructs a multivariate normal distribution centered at the solution.
The covariance is constructed by computing the Jacobian of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$f(x, \theta)$</math-renderer> and (roughly) multiplying it with the observation uncertainty.
See also <a href="https://en.wikipedia.org/wiki/Non-linear_least_squares#Extension_by_weights" rel="nofollow">this wikipedia link</a>.
The <code>paramprior</code> is used to sample initial guesses for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$\theta$</math-renderer>.</p>
<p dir="auto">Therefore <code>predictdist(::LinearApproxEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will solve one optimization problem and compute one Jacobian, yielding a <code>MvNormal</code> and making it very efficient.
<code>predictsamples(::LinearApproxEstimator, f, xs, ys, paramprior, noisemodel, nsamples)</code> will simply sample <code>nsample</code> times from this distribution, which is also very fast.</p>

<p dir="auto">We are currently considering three different possible noise models.
Consider again how we may have an observation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$(x_i, y_i)$</math-renderer>, and each <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y_i$</math-renderer> may be multi-dimensional.
The first question is: Is noise correlated /across/ multiple observations <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y_i$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$y_j$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9d9f81b3beb3cbd865a1f151327cbbef">$i \neq j$</math-renderer>?</p>
<p dir="auto">If there is <strong>no</strong> correlation between observations, we can use the noise models:</p>
<ul dir="auto">
<li><code>UncorrGaussianNoiseModel</code>: A vector of (possibly multivariate) Gaussian noise distributions, one for each observation.</li>
<li><code>UncorrProductNoiseModel</code> : A vector of univariate noise distributions of any kind. Can not model correlations within a single observation.</li>
</ul>
<p dir="auto">If there <strong>is</strong> correlation between observations, we can provide a single multivariate Gaussian noise model.</p>
<ul dir="auto">
<li><code>CorrGaussianNoiseModel</code>: A single multivariate normal distribution, with a noise component for each component in each observation. Multivariate observations are therefore flattened to correspond to the noise model.</li>
</ul>
<p dir="auto">Here are some examples:</p>
