<p dir="auto"><code>IntervalContractors.jl</code> provides contractors and reverse functions (also called backward functions or relational functions) for interval arithmetic.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Reverse functions</h3><a id="user-content-reverse-functions" class="anchor" aria-label="Permalink: Reverse functions" href="#reverse-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The reverse function of a function <code>f</code> calculates the (interval hull of) its inverse function, <code>f⁻¹</code>.</p>
<p dir="auto">For example, <code>sin_rev(Y::IntervalType, X::IntervalType)</code> calculates the (interval hull of) those <code>x ∈ X</code> such that <code>sin(x) ∈ Y</code>. This can also be thought of as an inverse function, calculating <code>X_new := sin⁻¹(Y) ⊓ X</code>.
The return value is <code>(Y, X_new)</code>.</p>
<p dir="auto">Functions such as <code>mul_rev(C::IntervalType, A::IntervalType, B::IntervalType)</code> take three arguments, and correspond to <code>C = A * B</code>; they return <code>(C, A_new, B_new)</code>, with <code>A_new</code> and <code>B_new</code> similarly defined to be the corresponding inverse images of the multiplication operator in each component.</p>

<p dir="auto">Functions like <code>sin!</code> (currently non-exported) are contractors for the set <code>{(x, y): y = sin(x)}</code>.</p>
<p dir="auto">The list of available functions may be found in the documentation.</p>
<p dir="auto">These functions are designed to be used inside the <a href="https://github.com/JuliaIntervals/IntervalConstraintProgramming.jl"><code>IntervalConstraintProgramming.jl</code></a> library,
and (eventually) to satisfy the section on reverse functions in the IEEE-1788 2015 standard on interval arithmetic.</p>
