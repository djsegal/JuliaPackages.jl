<p dir="auto">Algorithms for Maximum Independent Set, including:</p>
<ol dir="auto">
<li><a href="https://doi.org/10.1016/j.ic.2017.06.001" rel="nofollow">Xiao and Nagamochi (2017)</a>'s branch-and-bound method.</li>
<li><a href="https://arxiv.org/abs/2102.01540" rel="nofollow">Hespe, Lamm, and Schorr (2021)</a>'s branch-and-bound method.</li>

<li>A simple and extremely fast heuristic.</li>
</ol>

<p dir="auto">All three methods return a <code>Tuple{Int64, Vector{Int64}}</code>. The first return value (namely <code>status</code>) takes the value 0 if the solution found is proven optimal, 1 otherwise. The second return value (namely <code>sol</code>) contains the solution found.</p>

<p dir="auto">The upstream code of this library is buggy. The current code may return an infeasible solution. It should not be used if an optimality certificate is required. For an exact method, prefer the Cut-Branching method of Hespe et al. (2021) or the MIP-based solver. For an heuristic solution, prefer the simple yet efficient greedy heuristic.</p>
