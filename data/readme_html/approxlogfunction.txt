<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">About The Input Range</h3><a id="user-content-about-the-input-range" class="anchor" aria-label="Permalink: About The Input Range" href="#about-the-input-range"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Error is well controlled when using IEEE754 floating-point positive <strong>normal</strong> numbers, which is represented as :</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$$
x = 2^{E-B} \ (1 + F × 2^{-|F|})
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$0 &amp;lt; E &amp;lt; (2^{|E|} - 1)$</math-renderer> is the value of exponent part, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$|E|$</math-renderer> is the bit width of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$E$</math-renderer>,  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$F$</math-renderer> is the value of fraction part,  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$|F|$</math-renderer> is the bit width of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$F$</math-renderer>, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$B=(2 ^ {|E| - 1} - 1)$</math-renderer>  is the bias for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$E$</math-renderer>.  So the range for an <code>Approxlog</code> object's input is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$[X_{\rm min}, X_{\rm max}]$</math-renderer>, where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$$
\begin{aligned}
X_{\rm min} &amp;= 2^{1-B} \ (1 + 0 × 2^{-|F|}) &amp;&amp;= 2^{1-B} \\
X_{\rm max} &amp;= 2^{(2^{|E|}-2)-B} \ \big(1 + (2^{|F|}-1) × 2^{-|F|}\big) &amp;&amp;= 2^{B} \ \big(1 + (2^{|F|}-1) × 2^{-|F|}\big)
\end{aligned}
$$</math-renderer></p>
<p dir="auto">In short, for <code>Float16</code>  input, its range is :</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$$
2^{1-15} \le
X_{\rm Float16} \le 2^{15} \ \left( 1 + (2^{10} -1) × 2^{-10} \right)
$$</math-renderer></p>
<p dir="auto">for <code>Float32</code> input :</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$$
2^{1-127} \le
X_{\rm Float32} \le 2^{127} \ \left(1 + (2^{23} -1) × 2^{-23}\right)
$$</math-renderer></p>
<p dir="auto">and for <code>Float64</code> input :</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$$
2^{1-1023} \le
X_{\rm Float64} \le 2^{1023} \ \left(1 + (2^{52} -1) × 2^{-52}\right)
$$</math-renderer></p>
<p dir="auto">As to positive <strong>subnormal</strong> numbers, the result is not reliable.</p>

<p dir="auto">We have mentioned <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$b ≠ 1$</math-renderer>, but base value closing to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$1$</math-renderer> is not recommended, e.g. <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$1.0001$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f35e8eaf8af15addf7eabf7634863c81">$0.9999$</math-renderer>.</p>
