<p dir="auto">Most notably, <a href="https://github.com/carstenbauer/ThreadPinning.jl/">ThreadPinning.jl</a> allows you</p>
<ul dir="auto">
<li>to pin Julia threads to specific CPU-threads ("hardware threads") with <a href="https://carstenbauer.github.io/ThreadPinning.jl/stable/refs/api_pinning/#ThreadPinning.pinthreads" rel="nofollow"><code>pinthreads</code></a> and</li>
<li>to obtain a visual overview of the system topology with <a href="https://carstenbauer.github.io/ThreadPinning.jl/stable/refs/api_querying/#ThreadPinning.threadinfo" rel="nofollow"><code>threadinfo</code></a>.</li>
</ul>
<p dir="auto">There is dedicated support for pinning Julia threads in distributed Julia applications that use MPI.jl or Distributed.jl.</p>

<p dir="auto">The package is registered. Hence, you can simply use</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] add ThreadPinning"><pre class="notranslate"><code>] add ThreadPinning
</code></pre></div>
<p dir="auto">to add the package to your Julia environment.</p>
<p dir="auto">Note that <strong>only Linux is fully supported</strong>. On other operating systems, all pinning calls (e.g. <code>pinthreads</code>) will turn into no-ops but things like <code>threadinfo()</code> should work (with limitations).</p>
