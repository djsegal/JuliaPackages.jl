<p dir="auto">This package implements a direct interface between BLAS library and some types of
<a href="https://github.com/JuliaArrays/StaticArrays.jl">StaticArrays.jl</a>. The purpose of this
approach is to avoid allocations in those situations that
<a href="https://github.com/JuliaArrays/StaticArrays.jl">StaticArrays.jl</a> converts static arrays
into Julia's <code>Array</code> to call functions in <code>Base</code>.</p>
<p dir="auto">The package uses the following approach to call BLAS functions without allocating when the
input is a <code>StaticMatrix</code>:</p>
<ol dir="auto">
<li>Convert the input to <code>MMatrix</code>.</li>
<li>Create all the required data for the BLAS function using <code>MMatrix</code>.</li>
<li>Call the BLAS function.</li>
<li>Convert the result back to <code>StaticMatrix</code>.</li>
</ol>
<p dir="auto">Since the <code>MMatrix</code> does not go outside the scope of the function and we make sure that the
function is type-stable, Julia compiler is clever enough to perform all the required
computations in the stack, avoiding allocations.</p>
<p dir="auto">We currently implemented the direct interface to BLAS in the following situations:</p>
<ol dir="auto">
<li>Single value decomposition of <code>StaticMatrix</code> (<code>Float32</code> and <code>Float64</code>) using the full and
thin algorithms. This support also provided an allocation free pseudo-inverse <code>pinv</code> when
using the supported types.</li>
</ol>
