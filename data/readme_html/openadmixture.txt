<p dir="auto"><a href="https://OpenMendel.github.io/OpenADMIXTURE.jl/dev" rel="nofollow"><img src="https://camo.githubusercontent.com/45c316268f541933640ad68f61395986888f4d46bc9641b40e53d337576c6456/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f646f63732d6465762d626c75652e737667" alt="" data-canonical-src="https://img.shields.io/badge/docs-dev-blue.svg" style="max-width: 100%;"></a></p>
<p dir="auto">This software package is an open-source Julia reimplementation of the <a href="https://dalexander.github.io/admixture/" rel="nofollow">ADMIXTURE</a> package. It estimates ancestry with maximum-likelihood method for a large SNP genotype datasets, where individuals are assumed to be unrelated. The input is binary PLINK 1 BED-formatted file (<code>.bed</code>). Also, you will need an idea of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="42aec285073ee3054139057407c2191f">$K$</math-renderer>, the number of ancestral populations. If the number of SNPs is too large, you may choose to run on a subset of SNPs selected by their information content, using the <a href="https://github.com/kose-y/SKFR.jl">sparse K-means via feature ranking</a> (SKFR) method.</p>
<p dir="auto">With more efficient multi-threading scheme, it is 8 times faster than the original software on a 16-threaded machine. It also supports computation on an Nvidia CUDA GPU. By directly using the data format of the PLINK BED file, the memory usage is 16x-32x smaller than using <code>Float32</code> or <code>Float64</code> type.</p>

<p dir="auto">This package requires Julia v1.9 or later, which can be obtained from
<a href="https://julialang.org/downloads/" rel="nofollow">https://julialang.org/downloads/</a> or by building Julia from the sources in the
<a href="https://github.com/JuliaLang/julia">https://github.com/JuliaLang/julia</a> repository.</p>
<p dir="auto">The package can be installed by running the following code:</p>
