<p dir="auto">This is a lightweight repo that mimics the functionality of SciPy's binned statistic (<a href="https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binned_statistic.html#scipy.stats.binned_statistic" rel="nofollow"><code>scipy.stats.binned_statistic</code></a>) in native Julia. This was coded with performance in mind — it's ~2x as fast as the SciPy implementation when using PyCall, and ~10-30x faster than using a somewhat hacky implementation from the <code>StatsBase</code> Histogram functionality. As of now it only exports the 1D binned statistic function, but I plan to extend this to incorporate multiple dimensions soon! Documentation in progress, but there's a decent doc-string if you type <code>?binnedStatistic</code> at the REPL after importing the module.</p>
