<p dir="auto">This package enables the estimation of various Causal Inference related estimands using Targeted Minimum Loss-Based Estimation (TMLE). TMLE.jl is based on top of <a href="https://alan-turing-institute.github.io/MLJ.jl/dev/" rel="nofollow">MLJ</a>, which means any MLJ compliant machine-learning model can be used here.</p>
