<p dir="auto">A Julia package for piecewise orthogonal polynomials which can be used in p-FEM</p>
<p dir="auto">We can make piecewise integrated-Legendre bases using the quasi-matrix <code>ContinuousPolynomial{1}</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PiecewiseOrthogonalPolynomials, Plots

𝐗 = range(-1,1; length=4)
C = ContinuousPolynomial{1}(𝐗)
plot(C[:,Block(1)])"><pre><span class="pl-k">using</span> PiecewiseOrthogonalPolynomials, Plots

𝐗 <span class="pl-k">=</span> <span class="pl-c1">range</span>(<span class="pl-k">-</span><span class="pl-c1">1</span>,<span class="pl-c1">1</span>; length<span class="pl-k">=</span><span class="pl-c1">4</span>)
C <span class="pl-k">=</span> <span class="pl-c1">ContinuousPolynomial</span><span class="pl-c1">{1}</span>(𝐗)
<span class="pl-c1">plot</span>(C[:,<span class="pl-c1">Block</span>(<span class="pl-c1">1</span>)])</pre></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="plot(C[:,Block.(2:3)])"><pre><span class="pl-c1">plot</span>(C[:,<span class="pl-c1">Block</span>.(<span class="pl-c1">2</span><span class="pl-k">:</span><span class="pl-c1">3</span>)])</pre></div>
<p dir="auto">The mass matrix can be constructed via:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="M = C'C"><pre>M <span class="pl-k">=</span> C<span class="pl-k">'</span>C</pre></div>
<p dir="auto">We can also construct the stiffness matrix:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Δ = weaklaplacian(C)"><pre>Δ <span class="pl-k">=</span> <span class="pl-c1">weaklaplacian</span>(C)</pre></div>
<p dir="auto">We can truncate as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="N = 10
KR = Block.(Base.OneTo(N))
Mₙ = M[KR,KR]
Δₙ = Δ[KR,KR]"><pre>N <span class="pl-k">=</span> <span class="pl-c1">10</span>
KR <span class="pl-k">=</span> <span class="pl-c1">Block</span>.(Base<span class="pl-k">.</span><span class="pl-c1">OneTo</span>(N))
Mₙ <span class="pl-k">=</span> M[KR,KR]
Δₙ <span class="pl-k">=</span> Δ[KR,KR]</pre></div>
<p dir="auto">We can compute the reverse Cholesky in optimal complexity:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MatrixFactorizations
L = reversecholesky(Symmetric(-Δₙ + Mₙ)).L"><pre><span class="pl-k">using</span> MatrixFactorizations
