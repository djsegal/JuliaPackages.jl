<p dir="auto"><strong>Sysexits.jl</strong> is a library that provides the system exit code constants as
defined by <a href="https://man.openbsd.org/sysexits" rel="nofollow"><code>&lt;sysexits.h&gt;</code></a>.</p>
<p dir="auto">This library is a port of <a href="https://crates.io/crates/sysexits" rel="nofollow">sysexits-rs</a>.</p>
