<p dir="auto">Complex Adaptive Dynamics Computer Aided Design (CadCAD) is a language for encoding Generalized Dynamical Systems (GDS) as computer programs. This repository contains the Julia implementation of the software, based on the reference implementation written in <a href="https://github.com/cadCAD-org/cadcad-ri">Python</a>.</p>
