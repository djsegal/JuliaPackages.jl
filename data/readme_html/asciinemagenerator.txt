<p dir="auto">This package provides a single function <code>cast_file</code> that generates the <a href="https://asciinema.org/" rel="nofollow">asciinema</a> live coding from your Julia source code.</p>
<p dir="auto"><strong>Show case</strong>: The Yao Tutorial: <a href="https://giggleliu.github.io/AsciinemaGenerator.jl/?target=https://raw.githubusercontent.com/GiggleLiu/YaoTutorial/munich/clips/yao-v0.8.cast" rel="nofollow">https://giggleliu.github.io/AsciinemaGenerator.jl/?target=https://raw.githubusercontent.com/GiggleLiu/YaoTutorial/munich/clips/yao-v0.8.cast</a></p>

<ol dir="auto">
<li>Prepare a Julia source file, e.g. <a href="examples/yao/yao-v0.8.jl">examples/yao/yao-v0.8.jl</a>. Please check the <a href="#source-file-syntax">Source file Syntax</a> section for the supported syntax.</li>
<li>Run the following code in a Julia REPL:
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using AsciinemaGenerator

     output_file=&quot;examples/yao/yao-v0.8.cast&quot;
 );"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> AsciinemaGenerator
<span class="pl-c"><span class="pl-c">#</span>  Please type `?cast_file` to get help on configurable parameters.</span>
julia<span class="pl-k">&gt;</span> <span class="pl-c1">cast_file</span>(<span class="pl-s"><span class="pl-pds">"</span>examples/yao/yao-v0.8.jl<span class="pl-pds">"</span></span>;
     output_file<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>examples/yao/yao-v0.8.cast<span class="pl-pds">"</span></span>
 );</pre></div>
The generated <code>.cast</code> file is <a href="examples/yao/yao-v0.8.cast">examples/yao/yao-v0.8.cast</a>.
<em>Please make sure the required packages are installed in the current environment.</em></li>
<li>Preview the generated <code>.cast</code> file by either
<ol dir="auto">
<li>locally: install python package <code>asciinema</code> with: <code>pip install asciinema</code> and type <code>asciinema play &lt;path-to-cast-file&gt;</code> in a terminal, or</li>
<li>over web: upload your cast file to the public domain, e.g. the GitHub, then open the url: <a href="https://giggleliu.github.io/AsciinemaGenerator.jl?target=url-to-cast-file" rel="nofollow">https://giggleliu.github.io/AsciinemaGenerator.jl?target=url-to-cast-file</a> (replace the <code>url-to-cast-file</code> with your own cast file url).</li>
</ol>
</li>
</ol>

<p dir="auto">We use comments to control the play speed.</p>
<ol dir="auto">
<li>
<p dir="auto">Wait for a certain time: <code>#+ int</code> (space required). The following example will wait for 5 seconds before executing the next line.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="#+ 5"><pre><span class="pl-c"><span class="pl-c">#</span>+ 5</span></pre></div>
</li>
<li>
<p dir="auto">Change settings: <code>#s key1=value1; key2=value2; ...</code> (space required). The following example will set the delay to 1 second and the output row delay to 0.3 second. Please check <code>?cast_file</code> for the supported settings.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="#s delay=1.0; output_row_delay=0.3"><pre><span class="pl-c"><span class="pl-c">#</span>s delay=1.0; output_row_delay=0.3</span></pre></div>
</li>
</ol>
