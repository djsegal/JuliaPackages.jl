<ul dir="auto">
<li>Code is in <code>src</code>
<ul dir="auto">
<li><code>src/forward.jl</code> defines the linear operator <code>G</code> which convolves with all the PSFs.</li>
<li><code>src/pipeline.jl</code> makes a differentiable pipeline using the physics functions from <code>WavePropagation.jl</code>, the Lasso reconstruction function from <code>ImplicitAdjoints.jl</code>, and the linear operator from <code>src/forward.jl</code>. Everything is composed together in the function <code>loss</code>.</li>
<li><code>src/prepare.jl</code> defines the format of all the input parameters and has utility functions for doing all the precomputation required before optimization.</li>
<li><code>src/optimize.jl</code> provides some functions for running an optimization given the name of a JSON file with parameters.</li>
</ul>
</li>
<li>Parameter files describing an imaging optimization problem are expected in <code>params</code>.</li>
<li>Surrogate data (generated from Python) is expected in <code>surdata</code>.</li>
<li>Optimization data is saved in <code>optdata</code>.</li>
</ul>
