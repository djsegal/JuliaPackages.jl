<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">General-relativistic ray tracing and radiative transfer in arbitrary spacetimes</h2><a id="user-content-general-relativistic-ray-tracing-and-radiative-transfer-in-arbitrary-spacetimes" class="anchor" aria-label="Permalink: General-relativistic ray tracing and radiative transfer in arbitrary spacetimes" href="#general-relativistic-ray-tracing-and-radiative-transfer-in-arbitrary-spacetimes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Documentation is under construction, and is available <a href="https://joaquinpelle.github.io/Skylight.jl/dev" rel="nofollow">here</a>.</p>
<p dir="auto">Skylight works with any spacetime geometry, without the constraints of specific symmetries or the assumption of asymptotic flatness. It is designed with the following goals in mind:</p>
<ul dir="auto">
<li>Fast computational speed</li>
<li>High accuracy</li>
<li>Easy extensibility to user-defined spacetimes and radiative models</li>
</ul>
<p dir="auto">It uses <a href="https://en.wikipedia.org/wiki/Automatic_differentiation" rel="nofollow">automatic differentiation</a> with <a href="https://juliadiff.org/ForwardDiff.jl/stable/" rel="nofollow">ForwardDiff.jl</a> to compute the Christoffel symbols from the spacetime metric, and has built-in multithreading parallelism. The integration of the equations is performed with <a href="https://diffeq.sciml.ai/stable/" rel="nofollow">DifferentialEquations.jl</a>.</p>
<p dir="auto">For a quick start guide, see <a href="https://joaquinpelle.github.io/Skylight.jl/dev/gettingstarted/" rel="nofollow">Getting started</a>.</p>

<p dir="auto">The package is not yet available in the Julia registries. To install it, follow these steps:</p>
<ol dir="auto">
<li>Clone the repository: <code>git clone https://github.com/joaquinpelle/Skylight.jl.git</code></li>
<li>Open the Julia REPL and enter package mode by typing <code>]</code>.</li>
<li>Add Skylight to your Pkg environment: <code>dev \path\to\the\repository</code></li>
<li>Exit package mode with <code>Ctrl + C</code> and import Skylight: <code>using Skylight</code></li>
</ol>
