<p dir="auto">This package provides two main functionalities:</p>
<ul dir="auto">
<li>
<p dir="auto">a macro <code>@sleefmath</code> that works similarly to <code>@fastmath</code>: it transform
an mathematical expression into a faster version based on the
<a href="https://github.com/JuliaSIMD/SLEEFPirates.jl">SLEEFPirates</a>;</p>
</li>
<li>
<p dir="auto">a set of differentiation rules based on
<a href="https://github.com/JuliaDiff/ChainRules.jl">ChainRules</a> and also
working with <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff</a>.</p>
</li>
</ul>

<p dir="auto">A call to <code>@sleefmath expr</code> generates a transformed version of the expression,
which calls functions that may violate strict IEEE semantics and use the
<a href="https://github.com/JuliaSIMD/SLEEFPirates.jl">SLEEFPirates</a> package. This
allows the compiler to use SIMD instructions and other optimizations that
would not be possible with strict IEEE semantics.</p>
<p dir="auto">This macro is effective only within loops or broadcasted expressions. If used
in for loops, it often requires the use of <code>@simd ivdep for</code> loops and
<code>@inbounds</code> to be effective. For broadcasted expressions, it is often
convenient to use <code>@..</code> from the
<a href="https://github.com/YingboMa/FastBroadcast.jl">FastBroadcast</a> package.</p>
