<p dir="auto"><code>Vec.jl</code> provides several vector types, named after their groups. All types are immutable and are subtypes of <a href="https://github.com/JuliaArrays/StaticArrays.jl">'StaticArrays'</a>' <code>FieldVector</code>, so they can be indexed and used as vectors in many contexts.</p>
<ul dir="auto">
<li><code>VecE2</code> provides an (x,y) type of the Euclidean-2 group.</li>
<li><code>VecE3</code> provides an (x,y,z) type of the Euclidean-3 group.</li>
<li><code>VecSE2</code> provides an (x,y,theta) type of the special-Euclidean 2 group.</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="v = VecE2(0, 1)
v = VecSE2(0,1,0.5)
v = VecE3(0, 1, 2)"><pre>v <span class="pl-k">=</span> <span class="pl-c1">VecE2</span>(<span class="pl-c1">0</span>, <span class="pl-c1">1</span>)
v <span class="pl-k">=</span> <span class="pl-c1">VecSE2</span>(<span class="pl-c1">0</span>,<span class="pl-c1">1</span>,<span class="pl-c1">0.5</span>)
v <span class="pl-k">=</span> <span class="pl-c1">VecE3</span>(<span class="pl-c1">0</span>, <span class="pl-c1">1</span>, <span class="pl-c1">2</span>)</pre></div>
<p dir="auto">Additional geometry types include <code>Quat</code> for quaternions, <code>Line</code>, <code>LineSegment</code>, and <code>Projectile</code>.</p>
<p dir="auto">The switch to StaticArrays brings several breaking changes. If you need a backwards-compatible version, please checkout the <code>v0.1.0</code> tag with <code>cd(Pkg.dir("Vec")); run(`git checkout v0.1.0`)</code>.</p>
