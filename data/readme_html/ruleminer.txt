<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">About</h2><a id="user-content-about" class="anchor" aria-label="Permalink: About" href="#about"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">RuleMiner.jl is a Julia package for pattern mining inspired by the <a href="https://github.com/mhahsler/arules">arules</a> R package and <a href="https://www.philippe-fournier-viger.com/spmf/" rel="nofollow">SPMF</a> Java library.</p>
<p dir="auto">Key features of RuleMiner.jl include:</p>
<ul dir="auto">
<li>Support for Julia's native multithreading capabilities for improved performance</li>
<li>Direct interfaces with DataFrames.jl for loading transactional data and exporting results</li>
<li>Flexible handling of either relative (percentage) support or absolute (count) support in minimum support thresholds</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Multithreading</h2><a id="user-content-multithreading" class="anchor" aria-label="Permalink: Multithreading" href="#multithreading"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">RuleMiner.jl makes use of Julia's native multithreading support for significant performance gains. Enabling multithreading is done by using the <code>-t</code> flag when launching Julia and either specifying the number of threads or passing in the <code>auto</code> argument to launch julia with all available threads.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ julia -t auto"><pre>$ julia -t auto</pre></div>
<p dir="auto">Once Julia is launched, you can can view the enabled threads with <code>nthreads()</code> from the <code>Base.Threads</code> module.</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Base.Threads
