<p dir="auto">ReadLIBSVM.jl is Julia package exporting <code>read_libsvm</code> function to parse data stored in the LIBSVM format.</p>

<p dir="auto">Two methods are supported by <code>read_libsvm</code>:</p>
<ol dir="auto">
<li>A path <code>String</code> to the file to be parsed</li>
<li>A <code>Vector{UInt8}</code> containing the raw binary data (as returned by functions like <code>read</code> or returned from an API like AWS S3)</li>
</ol>
