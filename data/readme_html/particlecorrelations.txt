<p dir="auto">A package to calculate typical pair correlations (or structure factor) for disordered particulates, such as Percus-Yevick, and to calculate specific particle configurations from given pair correlation.</p>
<p dir="auto">Pair correlations are used in many fields in physical chemistry, statistical physics, condensed matter physics, material science, and many more. This package aims to be useful and easy to understand for many of these communities.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Pair correlation and Structure factor</h2><a id="user-content-pair-correlation-and-structure-factor" class="anchor" aria-label="Permalink: Pair correlation and Structure factor" href="#pair-correlation-and-structure-factor"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The definition of the pair-correlation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$g$</math-renderer>, for a finite number of multi-species particles, is [1]</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$$
g(\mathbf r_1, \lambda_1; \mathbf r_2, \lambda_2) = \frac{p(\mathbf r_1, \lambda_1; \mathbf r_2, \lambda_2)}{p(\mathbf r_1, \lambda_1)p(\mathbf r_2, \lambda_2)}\frac{J -1}{J}
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$\mathbf r_j$</math-renderer> is the vector position of the centre of particle - <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$j$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$\lambda_j$</math-renderer> represents the size or other distinguishing properties of the type of particle, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$p$</math-renderer> is the probability density function, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$J$</math-renderer> is the total number of particles. Due to the definition of the pair-correlation, when the particles become uncorrelated in the limit <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$|\mathbf r_1 - \mathbf r_2| \to \infty$</math-renderer> we have that</p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$\lim_{|\mathbf r_1 - \mathbf r_2| \to \infty} g(\mathbf r_1, \lambda_1; \mathbf r_2, \lambda_2) = 1$</math-renderer>.</p>
<p dir="auto">So far this package focuses on isotropic and statisticall homogeneous materials. Both these assumptions together imply that</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$$
g(\mathbf r_1, \lambda_1; \mathbf r_2, \lambda_2) = g(|\mathbf r_1 - \mathbf r_2|; \lambda_1, \lambda_2),
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="54fb683c0e8802a41bd249dadf1a9b78">$|\mathbf r_1 - \mathbf r_2|$</math-renderer> is the distance between the particle centres.</p>
