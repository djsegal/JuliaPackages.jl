<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Purpose of SR2StanPluto.jl (v5.7)</h2><a id="user-content-purpose-of-sr2stanplutojl-v57" class="anchor" aria-label="Permalink: Purpose of SR2StanPluto.jl (v5.7)" href="#purpose-of-sr2stanplutojl-v57"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">As stated many times by the author in his <a href="https://www.youtube.com/watch?v=ENxTrFf9a7c&amp;list=PLDcUM9US4XdNM4Edgs7weiyIguLSToZRI" rel="nofollow">online lectures</a>, StatisticalRethinking is a hands-on course. This project is intended to assist with the hands-on aspect of learning the key ideas in StatisticalRethinking.</p>
<p dir="auto">SR2StanPluto is a Julia project that uses Pluto notebooks for this purpose. Each notebook demonstrates Julia versions of <code>code snippets</code> and <code>mcmc models</code> contained in the R package "rethinking" associated with the book <a href="https://xcelab.net/rm/statistical-rethinking/" rel="nofollow">Statistical Rethinking</a> by Richard McElreath.</p>
<p dir="auto">This Julia project uses Stan (the <code>cmdstan</code> executable) as the underlying mcmc implementation. Please see Stan.jl and/or StanSample.jl for details.</p>

<p dir="auto">From v5 onwards the basis will no longer be StatisticalRethinking.jl but RegressionAndOtherStories.jl. Both packages have very similar content, but StatisticalRethinking.jl uses Plots.jl while RegressionAndOtherStories.jl is using (Cairo)Makie.jl.</p>
<p dir="auto">Tagged version 4.2.0 is the last more or less complete set of scripts covering <code>the old</code> chapters 1 to 11.</p>

<p dir="auto">Most notebooks include a line like <code>#Pkg.activate("~/.julie/dev/SR2StanPluto"))</code>. On the Github repo it is usualy commented out. While developing code I run notebooks inside a project environment (by uncommenting that line).  Occasionally I update the package (SR2StanPluto) in the REPL when new versions of the project itself or its dependencies become available. It requires SR2StanPluto.jl to be installed (in e.g. <code>~/.julia/dev</code> in the above example).</p>
<p dir="auto">If you frequently switch between different notebooks, uncommenting (or adding) the <code>Pkg.activate(...)</code> line is also much faster.</p>

<p dir="auto">All "rethinking" data files are stored and maintained in StatisticalRethinking.jl and can be accessed via <code>sr_datadir(...)</code>. See <code>notebooks/00-Preface.jl</code> for an example.</p>
<p dir="auto">By default <code>read_samples(m5_1s)</code> returns a StanTable with the results. In general
it is safer to specify the desired format, i.e. <code>read_samples(m5_1s, :table)</code> as
the Julia eco-sytem is still evolving rapidly with new options.</p>
<p dir="auto">Using <code>read_samples(m5_1s, :...)</code> makes it easy to convert samples to other formats.</p>
<p dir="auto">In version 5 I expect to mainly use the output_formats :dataframe and :nesteddataframe.</p>
<p dir="auto">For InferenceObjects.jl there is a separate function <code>inferencedata(m1_1s)</code>.</p>
<p dir="auto">See the <a href="https://github.com/StanJulia/StanExampleNotebooks.jl">StanExampleNotebooks.jl</a> for an example Pluto notebook.</p>

<p dir="auto">SR2StanPluto.jl is compatible with the 2nd edition of the book. Not all notebooks have been converted to Makie.jl yet. These are in the SR1 subdirectory. In the SR3 subdirectory I've started to look at the SR 2023 lecture examples, mainly as illustrated in the "Statistical Rethinking 2023 Python Notes".</p>
<p dir="auto">Beginning with v5.3.0 StructuralCausalModels.jl is repaced by CausalInference.jl as an extension. To display DAGs, GraphViz.jl and CairoMakie.jl are used. This is a long term project!</p>
<p dir="auto">ParetoSmoothedImportanceSampling.jl is included as a dependency in the StatisticalRethinking.jl v3+ package.</p>
