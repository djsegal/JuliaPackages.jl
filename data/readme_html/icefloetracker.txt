<ol dir="auto">
<li>Update the major or minor version numbers in the corresponding field at the top of <code>Project.toml</code></li>
<li>Add <code>@JuliaRegistrator register</code> in a comment in the commit you wish to use for the release
<ul dir="auto">
<li>this bot will open a PR on the <a href="https://github.com/JuliaRegistries/General/tree/master/I/IceFloeTracker">Julia registry</a> for the package</li>
</ul>
</li>
<li>Wait for feedback from the bot to make sure the new version is accepted and merged to the Julia registry</li>
<li>Create a new version tag
<ul dir="auto">
<li>The bot will generate git commands that you can run in a terminal to add a tag</li>
</ul>
</li>
<li>Create the new release on the <a href="https://github.com/WilhelmusLab/IceFloeTracker.jl/releases">repo console</a>
<ul dir="auto">
<li>Click on <code>Draft a new release</code></li>
<li>Choose the new tag you created</li>
<li>Click on <code>Generate release notes</code> or add a custom description</li>
</ul>
</li>
<li>Head over the <code>ice-floe-tracker-pipeline</code> <a href="https://github.com/WilhelmusLab/ice-floe-tracker-pipeline/blob/main/Project.toml">repo</a> and update the <code>[compat]</code> section of the <code>Project.toml</code> where <code>IceFloeTracker</code> is a dependency.</li>
</ol>
<p dir="auto"><strong>Note:</strong> After the PR for the release is merged, a trigger workflow will force a rebuild of Docker container used in the <a href="https://github.com/WilhelmusLab/ice-floe-tracker-pipeline">pipeline</a>.</p>
