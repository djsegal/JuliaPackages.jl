<p dir="auto">This package exports the <code>BitSetTuple</code> data structure and functions to manipulate them. A <code>BitSetTuple</code> is a tuple of <code>BitSet</code> objects that can be used to efficiently track multiple sets of low cardinality to which we have to concurrently apply set operations.</p>

<p dir="auto">Next, we will write a function that uses a <code>BitSetTuple</code> to track the edges that exist in all graphs:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using BitSetTuples

function edges_in_all_graphs(graphs, n_vertices)
    edges = BitSetTuple(n_vertices)
    for graph in graphs
        g_edges = BitSetTuple(Graphs.neighbors.(Ref(graph), 1:n_vertices))
        intersect!(edges, g_edges)
    end
    return edges
end"><pre><span class="pl-k">using</span> BitSetTuples
