<p dir="auto">Euterpe.jl is a ground-up synthesiser, written in native Julia. This project is a heavy work in progress. Future plans include a suite of effects. THis package uses the high quality Julia packages for FFTs and DiffEqs, making this a perfect language to experiment with instrument simulation as an alternative to sampling. Much of this is yet to come, so watch this space.</p>
