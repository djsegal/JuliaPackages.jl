<p dir="auto"><strong>(It is pronounced "spee-dee" 😊)</strong></p>
<p dir="auto">SpiDy.jl is a Julia package that solves the non-Markovian stochastic dynamics of interacting classical spin vectors and harmonic oscillator networks in contact with a dissipative environment. The methods implemented allow the user to include arbitrary memory effects and colored quantum noise spectra. In this way, SpiDy.jl provides key tools for the simulation of classical and quantum open systems including non-Markovian effects and arbitrarily strong coupling to the environment. Among the wide range of applications, some examples range from atomistic spin dynamics to ultrafast magnetism and the study of anisotropic materials. We provide the user with Julia notebooks to guide them through the various mathematical methods and help them quickly set up complex simulations.</p>

<p dir="auto">To run the code,</p>
<ul dir="auto">
<li>save <a href="https://raw.githubusercontent.com/quantum-exeter/SpiDy.jl/main/runs/run_dynamics.jl" rel="nofollow">run_dynamics.jl</a> and <a href="https://raw.githubusercontent.com/quantum-exeter/SpiDy.jl/main/runs/run_steadystate.jl" rel="nofollow">run_steadystate.jl</a> in your preferred location (open the link -&gt; right click on the page -&gt; save as... should work to save the file)</li>
<li>open the terminal or command line</li>
<li>run the following command,</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia &quot;path-to-your-file&quot;/run_dynamics.jl"><pre>julia <span class="pl-s"><span class="pl-pds">"</span>path-to-your-file<span class="pl-pds">"</span></span><span class="pl-k">/</span>run_dynamics<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">where "path-to-your-file" is the one where you saved your file. Replace <em>run_dynamics.jl</em> with <em>run_steadystate.jl</em> to run the one of your choice.</p>
<p dir="auto"><strong>This last command will run the code and save plots/datafile of the chosen run. CONGRATS, you have just run SpiDy for the first time!</strong></p>
<p dir="auto">NB: the code can exploit parallel computation. To do this, run your files as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia -t 6 &quot;path-to-your-file&quot;/run_dynamics.jl"><pre>julia <span class="pl-k">-</span>t <span class="pl-c1">6</span> <span class="pl-s"><span class="pl-pds">"</span>path-to-your-file<span class="pl-pds">"</span></span><span class="pl-k">/</span>run_dynamics<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">where you want to replace "6" with the number of threads that you wish to use. As a general idea, you do not want to use more than 80% of the number of threads you have available in your machine, e.g. if you have a 4-core CPU, you are likely to have 8 threads and you may want to run the parallelization as indicated above.</p>
