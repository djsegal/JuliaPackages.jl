<p dir="auto">BoundaryValueDiffEq.jl is a component package in the DifferentialEquations ecosystem. It holds the
boundary value problem solvers and utilities. While completely independent
and usable on its own, users interested in using this
functionality should check out <a href="https://github.com/JuliaDiffEq/DifferentialEquations.jl">DifferentialEquations.jl</a>.</p>

<p dir="auto">BoundaryValueDiffEq.jl is part of the SciML common interface, but can be used independently of DifferentialEquations.jl. The only requirement is that the user passes a BoundaryValueDiffEq.jl algorithm to solve. For example, we can solve the <a href="https://docs.sciml.ai/DiffEqDocs/stable/tutorials/bvp_example/" rel="nofollow">BVP tutorial from the documentation</a> using the <code>MIRK4()</code> algorithm:</p>

    du[1] = dθ

    residual[1] = u[:, end ÷ 2][1] + pi / 2

end

<p dir="auto">Precompilation can be controlled via <code>Preferences.jl</code></p>
<ul dir="auto">
<li><code>PrecompileMIRK</code> -- Precompile the MIRK2 - MIRK6 algorithms (default: <code>true</code>).</li>
<li><code>PrecompileShooting</code> -- Precompile the single shooting algorithms (default: <code>true</code>).</li>
<li><code>PrecompileMultipleShooting</code> -- Precompile the multiple shooting algorithms (default: <code>true</code>).</li>
<li><code>PrecompileMIRKNLLS</code> -- Precompile the MIRK2 - MIRK6 algorithms for under-determined and over-determined BVPs (default: <code>true</code>).</li>
<li><code>PrecompileShootingNLLS</code> -- Precompile the single shooting algorithms for under-determined and over-determined BVPs (default: <code>true</code>).</li>
<li><code>PrecompileMultipleShootingNLLS</code> -- Precompile the multiple shooting algorithms for under-determined and over-determined BVPs (default: <code>true</code> ).</li>
</ul>
<p dir="auto">To set these preferences before loading the package, do the following (replacing <code>PrecompileShooting</code> with the preference you want to set, or pass in multiple pairs to set them together):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Preferences, UUIDs
