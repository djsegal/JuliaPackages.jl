<p dir="auto">Julia bindings to BSC's <a href="https://tools.bsc.es/extrae" rel="nofollow"><code>extrae</code></a> HPC profiler.</p>
<p dir="auto">It supports automatic instrumentation (through <code>LD_PRELOAD</code> mechanism, DynInst is on the way) of MPI, CUDA and pthreads, and PAPI/PMAPI hardware counters and callstack sampling.
Generated traces can be viewed with <a href="https://tools.bsc.es/paraver" rel="nofollow">Paraver</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First, you need to set the Extrae configuration using environment variables or XML configuration. An example configuration file can be found in <code>scripts/extrae.xml</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Event emision</h3><a id="user-content-event-emision" class="anchor" aria-label="Permalink: Event emision" href="#event-emision"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Extrae's functionality is very basic: every registered event is just a tuple of 2 integers annotating the event type and the event value.
Some events are automatically registered, such as MPI call names when you are tracing or PAPI hardware counters when performing sampling.
But you can also emit your own custom events using <code>emit</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# emit event 80000 with value 4
emit(80_000, 4)"><pre><span class="pl-c"><span class="pl-c">#</span> emit event 80000 with value 4</span>
<span class="pl-c1">emit</span>(<span class="pl-c1">80_000</span>, <span class="pl-c1">4</span>)</pre></div>
<p dir="auto">Event types are encoded with <code>Int32</code> and the values must always be a <code>Int64</code>.</p>
<p dir="auto">If you want to assign a string descriptor to the event, you should call <code>Extrae.register</code> before initialization.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const BANANAS_TYPECODE::Int32 = 80_000
Extrae.register(BANANAS_TYPECODE, &quot;Bananas&quot;)"><pre><span class="pl-k">const</span> BANANAS_TYPECODE<span class="pl-k">::</span><span class="pl-c1">Int32</span> <span class="pl-k">=</span> <span class="pl-c1">80_000</span>
Extrae<span class="pl-k">.</span><span class="pl-c1">register</span>(BANANAS_TYPECODE, <span class="pl-s"><span class="pl-pds">"</span>Bananas<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Alternatively, you can also add string descriptors to values.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Extrae.register(Int32(80_001), &quot;Monkey name&quot;, Int64[0,1,2], String[&quot;no monkey&quot;, &quot;louis&quot;, &quot;george&quot;])"><pre>Extrae<span class="pl-k">.</span><span class="pl-c1">register</span>(<span class="pl-c1">Int32</span>(<span class="pl-c1">80_001</span>), <span class="pl-s"><span class="pl-pds">"</span>Monkey name<span class="pl-pds">"</span></span>, Int64[<span class="pl-c1">0</span>,<span class="pl-c1">1</span>,<span class="pl-c1">2</span>], String[<span class="pl-s"><span class="pl-pds">"</span>no monkey<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>louis<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>george<span class="pl-pds">"</span></span>])</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Initialization</h3><a id="user-content-initialization" class="anchor" aria-label="Permalink: Initialization" href="#initialization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>Extrae</code> can be initialized just by calling <code>Extrae.init()</code>. If you are planning to use <code>Distributed</code>, you should call</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@everywhere Extrae.init(Val(:Distributed))"><pre><span class="pl-c1">@everywhere</span> Extrae<span class="pl-k">.</span><span class="pl-c1">init</span>(<span class="pl-c1">Val</span>(<span class="pl-c1">:Distributed</span>))</pre></div>
<p dir="auto">to properly initialize the profiler in all workers. If you plan to use MPI, you should use the <code>LD_PRELOAD</code> mechanism.</p>
<p dir="auto">The profiling is finished with <code>Extrae.finish()</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Mark user functions</h3><a id="user-content-mark-user-functions" class="anchor" aria-label="Permalink: Mark user functions" href="#mark-user-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Many times, the profiler catches much more information than we want. One way to filter it is by marking which moments in the trace where devoted to user code. This can be done by calling <code>Extrae.user_function(1)</code> to start and <code>Extrae.user_function(0)</code> to end the marking region.</p>
<p dir="auto">We also provide a <code>Extrae.@user_function</code> for code cleanliness.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Example scripts</h2><a id="user-content-example-scripts" class="anchor" aria-label="Permalink: Example scripts" href="#example-scripts"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In <code>scripts</code> directory you can find the <code>test-distributed-work.jl</code> script that traces a very basic execution of a Distributed program.  This script squares a random 1000x1000 matrix two times in a worker, and then fetches the values.</p>
<p dir="auto">To run it, execute:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="scripts/env.sh julia --project=. scripts/test-distributed-work.jl"><pre>scripts/env.sh julia --project=. scripts/test-distributed-work.jl</pre></div>
<p dir="auto">The <code>env.sh</code> file sets up some environment variables required by the extrae library at load time.</p>
<p dir="auto">Then, to obtain the Paraver trace, we use the script <code>julia2prv</code> which is a wrapper to the <code>mpi2prv</code> tool by extrae. You can create your trace by doing:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="scripts/julia2prv test-distributed.prv JULIATRACE*"><pre>scripts/julia2prv test-distributed.prv JULIATRACE<span class="pl-k">*</span></pre></div>
<p dir="auto">and you will obtain a Paraver trace named <code>test-distributed.prv</code>.</p>
