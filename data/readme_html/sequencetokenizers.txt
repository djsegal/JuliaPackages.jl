<p dir="auto">SequenceTokenizers.jl is a Julia convenience package that offers a simplified and efficient way to tokenize character sequences, wrapping functionality from <a href="https://github.com/FluxML/OneHotArrays.jl">OneHotArrays</a> while handling <code>String</code> sequences and padding automatically. It provides a SequenceTokenizer struct that can:</p>
<ul dir="auto">
<li>Convert characters to integer tokens based on a predefined alphabet</li>
<li>Handle unknown characters with a customizable unknown symbol</li>
<li>Tokenize single characters, arrays of characters, and batches of sequences with <strong>variable length</strong> with automatic padding</li>
<li>Convert token indices back to characters</li>
<li>Create one-hot encoded representations of tokenized sequences</li>
<li>Convert one-hot encoded representations back to characters</li>
</ul>
<blockquote>
<p dir="auto">📘 <strong>Limitations</strong></p>
<ul dir="auto">
<li>It is not a <a href="https://fluxml.ai/Flux.jl" rel="nofollow">Flux</a> layer to keep dependencies minimal, therefore it cannot be placed inside a gradient block.</li>
<li>Single characters must be Char type</li>
<li>Multiple character sequences must be String type</li>
<li>No mixed type arrays are supported, it's either Strings or Chars that produce correct behaviour</li>
</ul>
</blockquote>
