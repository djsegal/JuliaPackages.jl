<p dir="auto"><strong>MixedLRMoE.jl</strong> is an implementation of the Mixed Logit-Reduced Mixture-of-Experts (Mixed LRMoE) model in <code>julia</code>.
This theoretical development of the Mixed LRMoE is given in <a href="https://arxiv.org/abs/2209.15207" rel="nofollow">Fung and Tseung (2022+)</a>, while an application in the automobile insurance context is given in <a href="https://arxiv.org/abs/2209.15212" rel="nofollow">Tseung et al. (2023)</a>.</p>
<p dir="auto">To install the stable version of the package, simply type the following in the <code>julia</code> REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="] add MixedLRMoE"><pre>] add MixedLRMoE</pre></div>
