<p dir="auto"><code>HierarchicalLogging</code> defines the <code>HierarchicalLogger</code> type, a <a href="https://docs.julialang.org/en/v1/stdlib/Logging/" rel="nofollow"><code>Base.Logging</code></a>-compatible logger which can be used to associate a collection of loggers to hierarchically-related objects. E.g., each node <code>N</code> is associated with a <code>.</code>-delimited key</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="key(N) = key₁.key₂. ... .keyₙ"><pre><span class="pl-en">key</span>(N) <span class="pl-k">=</span> key₁<span class="pl-k">.</span>key₂. <span class="pl-k">...</span> <span class="pl-k">.</span>keyₙ</pre></div>
<p dir="auto">and a node <code>P</code> is the parent of node <code>C</code> if <code>startswith(label(C), label(P))</code>.</p>
<p dir="auto">The prototypical example is the <code>module</code> -&gt; <code>submodule</code> relationship in Julia, but you might have your own hierarchically-related objects that you'd like to associate a logger with.</p>
<p dir="auto">Each node has an associated <code>LogLevel</code> which can be set via <code>min_enabled_level!(logger, key, level)</code>, which also recursively sets the level of all children of the node with <code>key</code>. This can be helpful for loggers tied to specific submodules which are particularly noisy.</p>
<p dir="auto">Example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using HierarchicalLogging, Logging

module A
    module B
       module C
       end
    end
end
module A1
    module B1
    end
end
module A2 
end
# Logger attached to the root has the lowest possible logging level 
h = HierarchicalLogger(ConsoleLogger(All))
global_logger(h)
insert_logger!(h, A.B, ConsoleLogger(Warn))
insert_logger!(h, A1, ConsoleLogger(Debug))
@info &quot;Hey&quot; _module=A.B.C _file=nothing _line=1
@warn &quot;Uhoh&quot; _module=A.B.C _file=nothing _line=1
# A was never registered to h, so it will use the root logger to log
@debug &quot;In A&quot; _module=A _file=nothing _line=1"><pre><span class="pl-k">using</span> HierarchicalLogging, Logging
