<p dir="auto"><code>BigRiverQTLPlots.jl</code> is a versatile plotting package built in the Julia programming language. The package consists of specific plotting recipes, designed to streamline data visualization and enhance the process of statistical analysis in genetic studies. It's particularly suited for QTL (Quantitative Trait Loci) and eQTL (expression Quantitative Trait Loci) analyses, providing key features for clear and intuitive data representation.</p>

<p dir="auto">Here are the main functions provided by BigRiverQTLPlots.jl:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>plot_QTL()</code>: This function generates plots for LOD (logarithm of odds) scores with respect to marker positions. It's useful in viewing one genome scan result, or even multiple genome scan results, on a single plot. This helps to provide a broad overview of the QTL landscape.</p>
</li>
<li>
<p dir="auto"><code>plot_eQTL()</code>: This function is specifically designed to plot eQTL analysis results, assisting in visualization of genetic associations with gene expression levels.</p>
</li>
</ul>

<p dir="auto">The colors of the background bars and the threshold lines in the chart can be easily customized.
