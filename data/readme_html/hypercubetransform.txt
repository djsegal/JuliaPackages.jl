<p dir="auto">We love to use nested sampling with the <a href="http://eventhorizontelescope.org/" rel="nofollow">Event Horizon Telescope (EHT)</a>, but it is rather annoying to constantly write the prior transformation. This package will do that for you. It does this by first looking at the types of the
distribution and constructing a transformation function.</p>
