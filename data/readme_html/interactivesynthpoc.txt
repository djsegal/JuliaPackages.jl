<p dir="auto">This package contains some experiments with audio live coding in Julia.
For now all it does is play sine waves using SDL2 as an audio back end, with some primitive "REPL" consisting of user typing some functions
that add, delete or modify sine waves.</p>
<p dir="auto"><em>Try typing</em></p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="supersaw(110)"><pre class="notranslate"><code>supersaw(110)
</code></pre></div>
<p dir="auto"><em>in the prompt.</em></p>
<p dir="auto">The goal is to attempt something similar to Gibber [<a href="https://gibber.cc/" rel="nofollow">https://gibber.cc/</a>] or Extempore [<a href="https://extemporelang.github.io/" rel="nofollow">https://extemporelang.github.io/</a>]</p>
<p dir="auto">In the current implementation I seem to get away with playing about a thousand sine waves with a buffer of size 512</p>
<p dir="auto">WHY ?</p>
<ul dir="auto">
<li>I love Gibber but dislike Javascript.</li>
<li>To learn more about Julia</li>
<li>Julia can be very fast and has a very rich maths library for ODEs, PDEs, SDEs, and other domains. Some fun stuff could be done.</li>
</ul>
