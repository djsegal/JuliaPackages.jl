<p dir="auto">Eternity2Puzzles.jl is an implementation of the <a href="https://en.wikipedia.org/wiki/Eternity_II_puzzle" rel="nofollow">Eternity II puzzle</a> in <a href="https://julialang.org/" rel="nofollow">Julia</a>.
You can either play the puzzle as an interactive game, or attempt to find a solution using a brute-force backtracking search.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Rules</h3><a id="user-content-rules" class="anchor" aria-label="Permalink: Rules" href="#rules"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The goal is to place all 256 pieces on the board, such that the colors and symbols of adjoining pairs of edges match, and with the grey edges around the outside.
Piece number 139 is a mandatory starter-piece with a fixed position on the board, that can neither be moved nor rotated.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Puzzle pieces</h3><a id="user-content-puzzle-pieces" class="anchor" aria-label="Permalink: Puzzle pieces" href="#puzzle-pieces"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">It is unclear to me whether the original pieces of the Eternity II puzzle are allowed to be published, so for now this package doesn't contain the edge color definitions of those pieces.
It is recommended to specify the pieces in form of an input file, provided that you own the real version of the Eternity II puzzle.
Alternatively, if the pieces definition is not given, they are automatically generated with colors from a published benchmark problem from the META 2010 contest.</p>
<p dir="auto">A pieces definition file must be in plain text format (<em>.txt</em>) and contain 256 rows with four color numbers on each row, separated by spaces; for example</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="1 2 0 0
... (255 more rows)"><pre class="notranslate"><code>1 2 0 0
... (255 more rows)
</code></pre></div>
<p dir="auto">The color numbers must be ordered in clockwise direction, starting with the top side (i.e. top, right, bottom, left).
To reproduce the original pieces from the Eternity II puzzle, use the following numbers:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="svg/colors_preview.svg"><img src="svg/colors_preview.svg" alt="Color numbers" style="max-width: 100%;"></a></p>
<p dir="auto">After creating the file, call the <code>initialize_pieces</code> function with the file path:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Eternity2Puzzles

julia&gt; initialize_pieces(&quot;path/to/e2pieces.txt&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Eternity2Puzzles

julia<span class="pl-k">&gt;</span> <span class="pl-c1">initialize_pieces</span>(<span class="pl-s"><span class="pl-pds">"</span>path/to/e2pieces.txt<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">It is sufficient to do this only a single time after installing the package; the given pieces are saved to a persistent cache on disk.
Subsequent calls of <code>initialize_pieces</code> override the cache.</p>

<p dir="auto">The <code>solve!</code> function accepts an optional keyword argument <code>alg</code>, which should be a subtype of <code>Eternity2Solver</code> and selects the algorithm that is used to search for a solution of the given <code>puzzle</code>.</p>
<p dir="auto">To write a custom solve algorithm, define a new subtype of <code>Eternity2Solver</code>, and implement the two-argument <code>solve!</code> method with your solver type as a second <em>positional</em> argument:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="struct MySolver &lt;: Eternity2Solver end

end"><pre><span class="pl-k">struct</span> MySolver <span class="pl-k">&lt;:</span> <span class="pl-c1">Eternity2Solver</span> <span class="pl-k">end</span>
