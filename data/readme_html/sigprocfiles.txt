<div align="justify" dir="auto">
<p dir="auto">This package adds support to load and save <a href="https://sigproc.sourceforge.net" rel="nofollow"><strong><code>SIGPROC</code></strong></a> filterbank (<code>*.fil</code>) and time series (<code>*.tim</code>) files. These formats are used by the <code>SIGPROC</code> library, and are used and supported by a vast number of radio telescopes and libraries. Currently, the following features are already present, or planned for future releases:</p>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Loading SIGPROC filterbank files.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Loading SIGPROC time series data.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Saving SIGPROC filterbank files.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Saving SIGPROC time series data.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Support for 8/32-bit filterbank and time series data.</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Support for 1/2/4-bit filterbank data (via <a href="https://github.com/astrogewgaw/PackedIntegers.jl"><strong><code>PackedIntegers.jl</code></strong></a>).</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Memory mapping, for files too large to be read directly into memory.</li>
</ul>
