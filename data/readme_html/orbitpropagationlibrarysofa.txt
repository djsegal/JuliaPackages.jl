<p dir="auto">A pure Julia implementation of the IAU timing and coordinate tranformation functions, as published in the SOFA routines with supplemental material derived from Vallado.</p>
<p dir="auto">This package is at minimum viable product, and is intended to be used as the timing and coordinate backbone to an Earth orbit propagation library and not explicitly for astronomy the way SOFA is. As such, some function signatures will be different. As more functionality is added (see below), some function signatures will change.</p>
<p dir="auto">In order to maintain compatibility with the USSF standards, initial implementation focuses on IAU-76 and other pre-2000 models.</p>
