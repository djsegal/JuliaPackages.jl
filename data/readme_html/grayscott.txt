<p dir="auto">Julia version of <a href="https://github.com/ornladios/ADIOS2-Examples/blob/master/source/cpp/gray-scott/">the gray-scott C++ and Python</a>
example.</p>
<p dir="auto">This is a 3D 7-point stencil code to simulate the following <a href="https://doi.org/10.1126/science.261.5118.189" rel="nofollow">Gray-Scott
reaction diffusion model</a>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="u_t = Du * (u_xx + u_yy + u_zz) - u * v^2 + F * (1 - u) + noise * randn(-1,1)
v_t = Dv * (v_xx + v_yy + v_zz) + u * v^2 - (F + k) * v"><pre class="notranslate"><code>u_t = Du * (u_xx + u_yy + u_zz) - u * v^2 + F * (1 - u) + noise * randn(-1,1)
v_t = Dv * (v_xx + v_yy + v_zz) + u * v^2 - (F + k) * v
</code></pre></div>
<p dir="auto">This version contains:</p>
<ul dir="auto">
<li>CPU threaded solver using Julia's [multithreading]](<a href="https://docs.julialang.org/en/v1/manual/multi-threading/" rel="nofollow">https://docs.julialang.org/en/v1/manual/multi-threading/</a>)</li>
<li>GPU solvers using <a href="https://github.com/JuliaGPU/CUDA.jl">CUDA.jl</a>, <a href="https://github.com/JuliaGPU/AMDGPU.jl">AMDGPU.jl</a></li>
<li>Parallel I/O using the <a href="https://github.com/eschnett/ADIOS2.jl">ADIOS2.jl</a> Julia bindings to <a href="https://github.com/ornladios/ADIOS2">ADIOS2</a></li>
<li>Message passing interface (MPI) using <a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a> Julia bindings to MPI</li>
<li>Easily switch between float- (Float32) and double- (Float64) precision in the configuration file</li>
</ul>

<p dir="auto">Pre-requisities:</p>
<ul dir="auto">
<li>A recent Julia version: v1.9.0 as of May 2023 from <a href="https://julialang.org/downloads/" rel="nofollow">julialang.org/downloads</a></li>
</ul>

<p dir="auto">To use a system provided ADIOS2 library, see <a href="https://eschnett.github.io/ADIOS2.jl/dev/#Using-a-custom-or-system-provided-ADIOS2-library" rel="nofollow">here</a>.
It just sets the environment variable <code>JULIA_ADIOS2_PATH</code> and build ADIOS2.jl in Julia.</p>
<p dir="auto"><strong>Note</strong>: GrayScott.jl requires the <code>main</code> development version.</p>

<ol start="3" dir="auto">
<li><strong>Running the simulation</strong></li>
</ol>
<ul dir="auto">
<li>
<p dir="auto"><code>CPU threads</code>: launch julia assigning a number of threads (e.g. -t 8):</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia --project -t 8 gray-scott.jl examples/settings-files.json"><pre class="notranslate"><code>$ julia --project -t 8 gray-scott.jl examples/settings-files.json
</code></pre></div>
</li>
<li>
<p dir="auto"><code>CUDA/AMDGPU</code>: set the "backend" option in examples/settings-files.json to either "CUDA" or "AMDGPU"</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia --project gray-scott.jl examples/settings-files.json"><pre class="notranslate"><code>$ julia --project gray-scott.jl examples/settings-files.json
</code></pre></div>
</li>
</ul>
<p dir="auto">This would generate an adios2 file from the output entry in the configuration file (e.g. <code>gs-julia-1MPI-64L-F32.bp</code>)
that can be visualized with ParaView with either the VTX or the FIDES readers.
<strong>Important</strong>: the AMDGPU.jl implementation of <code>randn</code> is currently work in progress.
See related issue <a href="https://github.com/JuliaGPU/AMDGPU.jl/issues/378" data-hovercard-type="issue" data-hovercard-url="/JuliaGPU/AMDGPU.jl/issues/378/hovercard">here</a></p>
<ol start="4" dir="auto">
<li><strong>Running on OLCF Summit and Crusher systems</strong>
The code was tested on the Oak Ridge National Laboratory Leadership Computing Facilities (OLCF): <a href="https://docs.olcf.ornl.gov/systems/summit_user_guide.html" rel="nofollow">Summit</a> and <a href="https://docs.olcf.ornl.gov/systems/crusher_quick_start_guide.html" rel="nofollow">Crusher</a>. Both are used testing a recent version of Julia <a href="https://julialang.org/downloads/#upcoming_release" rel="nofollow">v1.9.0-beta3</a> and a <code>JULIA_DEPOT_PATH</code> is required to install packages and artifacts. <strong>DO NOT USE your home directory</strong>. We are providing configuration scripts in <code>scripts/config_XXX.sh</code> showing the plumming required for these systems. They need to be executed only once per session from the login nodes.</li>
</ol>
<p dir="auto">To reuse these file the first 3 entries must be modified and run on login-nodes and the PATH poiting at a downloaded Julia binary for the corresponding PowerPC (Summit) and x86-64 (Crusher) architectures. Only "CPU" and "CUDA" backends are supported on Summit, while "CPU" and "AMDGPU" backends are supported on Crusher.</p>
