<p dir="auto">Welcome to the <code>NeRCA.jl</code> (<strong>Ne</strong>utrino <strong>R</strong>esearch with <strong>C</strong>osmics in the <strong>A</strong>byss) package documentation. This piece of software was written
for those who like to explore the KM3NeT world with a new, modern and ultra fast
programming language designed for scientific computing: <a href="https://www.julialang.org" rel="nofollow">Julia</a>.
The I/O for KM3NeT related data is provided by <a href="https://git.km3net.de/common/KM3io.jl" rel="nofollow">KM3io.jl</a>.</p>

<p dir="auto"><code>NeRCA.jl</code> was initially registered on the officially Julia package registry but since version 0.11.0, it resides in the <a href="https://git.km3net.de/common/julia-registry" rel="nofollow">KM3NeT Julia Registry</a>. To install the latest version, you first need to add the KM3NeT Julia Registry to your local registries. Follow the instructions in its README!</p>
<p dir="auto"><em>After that</em>, you can install <code>NeRCA.jl</code> just like any other Julia package with <code>Pkg</code>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;NeRCA&quot;)"><pre>using Pkg
Pkg.add("NeRCA")</pre></div>

<p dir="auto"><code>NeRCA.jl</code> started as a hobby project and contained all kinds of KM3NeT related stuff. In 2023, many of the functionalities were extracted to distinct packages. Here are some examples:</p>
<ul dir="auto">
<li><a href="https://git.km3net.de/common/KM3io.jl" rel="nofollow">KM3io.jl</a>: general I/O (reading ROOT, DETX and other KM3NeT files)</li>
<li><a href="https://git.km3net.de/tgal/KM3DB.jl" rel="nofollow">KM3DB.jl</a>: accessing the KM3NeT Oracle Database (StreamDS, run setups, detector calibrations, ...)</li>
<li><a href="https://git.km3net.de/acoustics/KM3Acoustics.jl" rel="nofollow">KM3Acoustics.jl</a>: Acoustics stuff, simulation of acoustic events, calibration procedures, ..</li>
<li><a href="https://git.km3net.de/km3py/km3net-testdata" rel="nofollow">KM3NeTTestData.jl</a>: A collection of KM3NeT related sample files (used for tests)</li>
</ul>
