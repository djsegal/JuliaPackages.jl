<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Definition of the Spherical Harmonics</h3><a id="user-content-definition-of-the-spherical-harmonics" class="anchor" aria-label="Permalink: Definition of the Spherical Harmonics" href="#definition-of-the-spherical-harmonics"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The normalized real spherical harmonics on the unit sphere are defined by</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$Y_{l,m}(\vartheta,\varphi) := 
\begin{cases}
\sqrt{2}K_{l,m} \cos(m\varphi)P_{l,m}(\cos\vartheta) &amp; m &gt; 0\\\
\sqrt{2}K_{l,m} \sin(-m\varphi)P_{l,-m}(\cos\vartheta) &amp; m &lt; 0\\\
K_{l,m}P_{l,m}(\cos \vartheta) &amp; m = 0
\end{cases},$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$l\in\mathbb{N}_0$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$m\in [-l,l]$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\theta$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\phi$</math-renderer> are the spherical angular coordinates,</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$K_{l,m} = \sqrt{\frac{(2l+1)(l-|m|)!}{4\pi(l+|m|)!}},$$</math-renderer>
<p dir="auto">is the normalization factor and</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$P_{l,m}(x) = (1-x^2)^{\frac{m}{2}}\frac{d^m}{dx^m}\left(P_l(x)\right),$$</math-renderer>
<p dir="auto">are the associated Legendre polynomials which can be derived from the Legendre polynomials</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$P_l(x) = \frac{1}{2^ll!}\frac{d^l}{dx^l}\left[(x^2-1)^l\right].$$</math-renderer>
<p dir="auto">Note that you will also find a convention in literature, where the  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$Y_{l,m}$</math-renderer>   are scaled by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$(-1)^m$</math-renderer>  .</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Spherical Harmonics Expansions</h3><a id="user-content-spherical-harmonics-expansions" class="anchor" aria-label="Permalink: Spherical Harmonics Expansions" href="#spherical-harmonics-expansions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Each function  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$f:\Omega \rightarrow \mathbb R$</math-renderer>   satisfying Laplace's equation  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\Delta f = 0$</math-renderer>   in a region  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\Omega\subseteq\mathbb R^3$</math-renderer>   can be written as a spherical harmonic expansion</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$f(\mathbf r) = \sum_{l=0}^{\infty}\sum_{m=-l}^l c_{l,m} r^l Y_l^m{\left(\frac{1}{r}\, \mathbf r\right)},$$</math-renderer>
<div align="center" dir="auto"></div>
<p dir="auto">for all  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\mathbf a\in\Omega$</math-renderer>  , where  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$\mathbf c_{l,m}\in\mathbb R^3$</math-renderer>   denote the spherical coefficients and  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$r=\Vert \mathbf r \Vert_2$</math-renderer>  .</p>
<p dir="auto">The term</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$r^l Y_l^m{\left(\frac{1}{r}\, \mathbf r\right)}$$</math-renderer>
<div align="center" dir="auto"></div>
<p dir="auto">can be transformed from spherical to Cartesian coordinates, where it can be expressed as a homogeneous polynomial of degree  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$l$</math-renderer>  .</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Polynomial Representation of the Spherical Harmonics Expansions</h3><a id="user-content-polynomial-representation-of-the-spherical-harmonics-expansions" class="anchor" aria-label="Permalink: Polynomial Representation of the Spherical Harmonics Expansions" href="#polynomial-representation-of-the-spherical-harmonics-expansions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In case where a function is equal to or can be approximated by a <strong>finite</strong> Spherical harmonic expansion</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$$\sum_{l=0}^{L}\sum_{m=-l}^l c_{l,m} r^l Y_l^m{\left(\frac{1}{r}\, \mathbf r\right)},$$</math-renderer>
<div align="center" dir="auto"></div>
<p dir="auto">with  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$L \in \mathbb N$</math-renderer>   its multivariate polynomial representation has finite degree.</p>
<p dir="auto">Coefficents  <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a6dda935cb56b17e71c541dca26a8cc7">$c_{l,m}$</math-renderer>   can be initialized and populated by <code>c[l,m] = 42.0</code>.</p>
