<p dir="auto">New implementation of the <a href="https://github.com/tudo-physik-e4/EFTfitterRelease">EFTfitter</a> in the <a href="https://julialang.org/" rel="nofollow">Julia languange</a>.</p>
<p dir="auto">EFTfitter is a tool for constraining the parameters of physics models using Bayesian inference by combining measurements of (different) observables.
It is particularly suited for EFT (effective field theory) interpretations, but is not limited to these use cases.</p>
<p dir="auto">Work-in-progress, interfaces and functionalities might be subject to changes.</p>

<p dir="auto">Since version 0.2 of the package, the following new features are available:</p>
<ul dir="auto">
<li>Model uncertainties: The functions giving the predictions for the observable values can now also return a parameter-dependent value quantifying the uncertainty on the prediction. These uncertainties are currently treated as uncorrelated and are added to the total covariance matrix.</li>
<li>The data type of the (inverse) covariance matrix can now be set by the user. This can allow to increase the performance by speeding up the vector-matrix multiplication, e.g. in the case of sparse covariance matrices. The function <code>run_speed_test</code> can be used to determine which data type of the covariance matrix is the most suitable for the current model.</li>
<li><code>MeasurementDistribution</code> is now called <code>BinnedMeasurement</code></li>
</ul>
