<p dir="auto">Install Julia 1.7 or higher using <a href="https://julialang.org/downloads/platform/" rel="nofollow">these instructions</a>.</p>
<p dir="auto">Clone the repository and start julia in project mode for current folder:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="cd Dice.jl
julia --project"><pre><span class="pl-c1">cd</span> Dice.jl
julia --project</pre></div>
<p dir="auto">Install Dice and update dependencies (one can also use <code>precompile</code> or <code>build</code>):</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] up"><pre class="notranslate"><code>] up
</code></pre></div>
<p dir="auto">Press CTRL-C or backspace to exit from the pkg terminal and return to Julia REPL.</p>
<p dir="auto">One can now run a program from the Julia REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="include(&quot;examples/graph_reachability.jl&quot;)"><pre><span class="pl-c1">include</span>(<span class="pl-s"><span class="pl-pds">"</span>examples/graph_reachability.jl<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Or from the command line:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project examples/graph_reachability.jl"><pre class="notranslate"><code>julia --project examples/graph_reachability.jl
</code></pre></div>
