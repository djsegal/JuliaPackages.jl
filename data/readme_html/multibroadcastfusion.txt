<p dir="auto">A Julia package for fusing multiple broadcast expressions together.</p>
<p dir="auto">A motivating example of this package is the following:</p>

<span class="pl-c1">@.</span> y1 <span class="pl-k">=</span> x1 <span class="pl-k">*</span> x2 <span class="pl-k">+</span> x3 <span class="pl-k">*</span> x4
<span class="pl-c1">@.</span> y2 <span class="pl-k">=</span> x1 <span class="pl-k">*</span> x3 <span class="pl-k">+</span> x2 <span class="pl-k">*</span> x4</pre></div>
<p dir="auto">In this example, there are 4 unique reads, and 2 writes. However, because the reads are in two separate broadcast expressions, there are 8 reads total, including redundant ones. Another important note is that <code>y1</code> and <code>y2</code> are stored separately in memory. Fusing these operations can be achieved by changing the memory layout, and adjusting the implementation. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="X = map(x-&gt;Tuple(rand(4)),zeros(3,3));
Y = map(x-&gt;Tuple(rand(2)),zeros(3,3));

foo(x) = (x[1] * x[2] + x[3] * x[4], x[1] * x[3] + x[2] * x[4])
# 4 reads, 2 writes
@. Y = foo(X)"><pre>X <span class="pl-k">=</span> <span class="pl-c1">map</span>(x<span class="pl-k">-&gt;</span><span class="pl-c1">Tuple</span>(<span class="pl-c1">rand</span>(<span class="pl-c1">4</span>)),<span class="pl-c1">zeros</span>(<span class="pl-c1">3</span>,<span class="pl-c1">3</span>));

<span class="pl-en">foo</span>(x) <span class="pl-k">=</span> (x[<span class="pl-c1">1</span>] <span class="pl-k">*</span> x[<span class="pl-c1">2</span>] <span class="pl-k">+</span> x[<span class="pl-c1">3</span>] <span class="pl-k">*</span> x[<span class="pl-c1">4</span>], x[<span class="pl-c1">1</span>] <span class="pl-k">*</span> x[<span class="pl-c1">3</span>] <span class="pl-k">+</span> x[<span class="pl-c1">2</span>] <span class="pl-k">*</span> x[<span class="pl-c1">4</span>])
<span class="pl-c"><span class="pl-c">#</span> 4 reads, 2 writes</span>
<span class="pl-c1">@.</span> Y <span class="pl-k">=</span> <span class="pl-c1">foo</span>(X)</pre></div>
<p dir="auto">However, this is not an objectively better solution:</p>
<ul dir="auto">
<li>The memory layout, and code implementation, had to be changed in order to make this work, and this can be very difficult for a complex codebase.</li>
<li>Memory acces of <code>X</code> and <code>Y</code> is now <em>strided</em>, which could result in less performant code than a single fused loop with more contiguous memory.</li>
</ul>
<p dir="auto">Ideally, we would like for the loops to be fused with the more contiguous data layouts:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x1 = rand(3,3)
x2 = rand(3,3)
x3 = rand(3,3)
x4 = rand(3,3)
y1 = rand(3,3)
y2 = rand(3,3)

# 2 writes, 4 unique reads. The compiler can hoist the redundant memory reads here.
for i in eachindex(x1,x2,x3,x4,y1,y2)
  y1[i] = x1[i] * x2[i] + x3[i] * x4[i]
  y2[i] = x1[i] * x3[i] + x2[i] * x4[i]
end"><pre>x1 <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">3</span>,<span class="pl-c1">3</span>)
x2 <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">3</span>,<span class="pl-c1">3</span>)
x3 <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">3</span>,<span class="pl-c1">3</span>)
x4 <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">3</span>,<span class="pl-c1">3</span>)

<span class="pl-k">for</span> i <span class="pl-k">in</span> <span class="pl-c1">eachindex</span>(x1,x2,x3,x4,y1,y2)

<span class="pl-k">end</span></pre></div>
<p dir="auto">With this package, we can apply <code>@fused_direct</code> to reduce the number of reads and preserve the memory layout:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import MultiBroadcastFusion as MBF

x2 = rand(3,3)

y1 = rand(3,3)
y2 = rand(3,3)

# 4 reads, 2 writes
MBF.@fused_direct begin
  @. y1 = x1 * x2 + x3 * x4
  @. y2 = x1 * x3 + x2 * x4
end"><pre><span class="pl-k">import</span> MultiBroadcastFusion <span class="pl-k">as</span> MBF

<p dir="auto">This is achieved by fusing the loops and inlining with the given data, resulting in the compiler being able to perform Common-SubExpression Elimination (CSE) on the memory loads.</p>

        # does `@inline pair.first[i] = pair.second[i]` for all pairs
