<p dir="auto">This package contains abstracts type definition for loading and manipulating GRIB, NetCDF, geoTiff and Zarr files. This package aims to follow the <a href="https://docs.unidata.ucar.edu/netcdf-c/current/netcdf_data_model.html" rel="nofollow">Common Data Model</a> and the <a href="https://cfconventions.org/" rel="nofollow">CF (climate and forecast models) Metadata Conventions</a>.</p>

<p dir="auto">Features include:</p>
<ul dir="auto">
<li>query and edit metadata of arrays and datasets</li>
<li>virtually concatenating multiple files along a given dimension</li>
<li>create a virtual subset (<code>view</code>) by indices or by values of coordinate variables (<code>CommonDataModel.select</code>, <code>CommonDataModel.@select</code>)</li>
<li>group, map and reduce a variable (<code>CommonDataModel.groupby</code>, <code>CommonDataModel.@groupby</code>) and rolling reductions like running means <code>CommonDataModel.rolling</code>)</li>
</ul>

<p dir="auto">Most users would typically import <a href="https://github.com/JuliaGeo/GRIBDatasets.jl"><code>GRIBDatasets</code></a> and <a href="https://github.com/Alexander-Barth/NCDatasets.jl"><code>NCDatasets</code></a> directly and not <code>CommonDataModel</code>. One should import <code>CommonDataModel</code> only to extent the functionality of <code>GRIBDatasets</code> and <code>NCDatasets</code>.</p>
