<blockquote>
<p dir="auto">"3D antenna pattern processing done easy."</p>
</blockquote>
<p dir="auto">A simple open-source solution to antenna 3D data processing. Why?</p>
<ul dir="auto">
<li>Processing data from measurements is a constant and never-ending struggle.</li>
<li>There are very few tools that allow you to do this easily.</li>
</ul>
