<p dir="auto">Tools for reading and working with simulation output from <a href="https://ui.adsabs.harvard.edu/abs/2011A%26A...531A.154G/abstract" rel="nofollow">The stellar atmosphere simulation code Bifrost</a> in Julia.</p>
<p dir="auto">This Julia package is created for working with <em>Bifrost</em> data <strong>efficiently</strong>.
Load single or multiple simulation snapshots, and analyse data with Julia speed.</p>
<p dir="auto">This package is an extension of <code>Bifrost.jl</code>, a script written by Mikolaj Szydlarski.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Using <code>get_var</code></h3><a id="user-content-using-get_var" class="anchor" aria-label="Permalink: Using get_var" href="#using-get_var"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The function <code>get_var</code> is the main function for reading data from Bifrost simulations.
It can read single or multiple snapshots, and it can read full data cubes or slices.
It can read primary variables or auxiliary variables.</p>
<p dir="auto">The command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="variable = get_var(expname, snap, expdir, variable)"><pre>variable <span class="pl-k">=</span> <span class="pl-c1">get_var</span>(expname, snap, expdir, variable)</pre></div>
<p dir="auto">loads the (primary or auxiliary) variable <code>variable</code> from snapshot <code>snap</code> in the simulation <code>expname</code> located in the directory <code>expdir</code>.</p>
<p dir="auto">By creating a <code>BifrostExperiment</code> object</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="brxp = BifrostExperiment(expname, expdir)"><pre>brxp <span class="pl-k">=</span> <span class="pl-c1">BifrostExperiment</span>(expname, expdir)</pre></div>
<p dir="auto">we can access the mesh file</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="brxp.mesh"><pre>brxp<span class="pl-k">.</span>mesh</pre></div>
<p dir="auto">snapshot numbers</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="brxp.snaps"><pre>brxp<span class="pl-k">.</span>snaps</pre></div>
<p dir="auto">and the calling signature of <code>get_var</code> can be simplified</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="variable = get_var(brxp, snap, variable)"><pre>variable <span class="pl-k">=</span> <span class="pl-c1">get_var</span>(brxp, snap, variable)</pre></div>
<p dir="auto">Using optional keyword-arguments in <code>get_var</code> allows us to convert units, destagger variables, rotate the grid, and read slices of the full cube.</p>
<p dir="auto">The command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="bx = get_var(brxp, snap, &quot;bx&quot;; units=&quot;si&quot;, destagger=true)"><pre>bx <span class="pl-k">=</span> <span class="pl-c1">get_var</span>(brxp, snap, <span class="pl-s"><span class="pl-pds">"</span>bx<span class="pl-pds">"</span></span>; units<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>si<span class="pl-pds">"</span></span>, destagger<span class="pl-k">=</span><span class="pl-c1">true</span>)</pre></div>
<p dir="auto">will load the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="03ce59b837a032ef551b3951e8bdb28b">$x$</math-renderer>-component of the magnetic field in SI units and destagger it to the cell center.</p>
<p dir="auto">See the <a href="https://ITA-Solar.github.io/BifrostTools.jl/dev/" rel="nofollow">documentation</a> for further information and more elaborate example usage.</p>
