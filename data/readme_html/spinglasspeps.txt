<p dir="auto">Welcome to <code>SpinGlassPEPS.jl</code>, a open-source Julia package designed for heuristically solving Ising-type optimization problems defined on quasi-2D lattices and Random Markov Fields on 2D rectangular lattices.</p>
<p dir="auto">The package <code>SpinGlassPEPS.jl</code> includes:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>SpinGlassTensors.jl</code> - Package containing all necessary functionalities for creating and operating on tensors. It allows the use of both CPU and GPU.</p>
</li>
<li>
<p dir="auto"><code>SpinGlassNetworks.jl</code> - Package containing all tools needed to construct a tensor network from a given instance.</p>
</li>
<li>
<p dir="auto"><code>SpinGlassEngine.jl</code> - Package containing the solver itself and tools focused on finding and operating on droplets.</p>

<p dir="auto"><code>SpinGlassPEPS.jl</code> was created to heuristically solve Ising-type optimization problems defined on quasi-2D lattices or Random Markov Fields (RMF) on 2D rectangular lattices. This package combines advanced heuristics to address optimization challenges and employs tensor network contractions to compute conditional probabilities to identify the most probable states according to the Gibbs distribution. <code>SpinGlassPEPS.jl</code> is a tool for reconstructing the low-energy spectrum of Ising spin glass Hamiltonians and RMF Hamiltonians. Beyond energy computations, the package offers insights into spin configurations, associated probabilities, and retains the largest discarded probability during the branch and bound optimization procedure. Notably, <code>SpinGlassPEPS.jl</code> goes beyond ground states, introducing a unique feature for identifying and analyzing spin glass droplets — collective excitations crucial for understanding system dynamics beyond the fundamental ground state configurations.</p>
