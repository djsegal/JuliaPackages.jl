<p dir="auto">To add the package to your environment, open the Julia REPL and type the <code>]</code> to open the package manager.
Add the package by entering:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="add Roentgen"><pre>add Roentgen</pre></div>
<p dir="auto">Once completed, you can exit the package manager by pressing Backspace.</p>
<p dir="auto">You can then use the package by entering:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Roentgen"><pre><span class="pl-k">using</span> Roentgen</pre></div>
<p dir="auto">There are examples for simple use cases and features in the <a href="https://github.com/Image-X-Institute/Roentgen.jl/tree/main/examples">examples</a> folder.</p>

<p dir="auto">The documentation is generated by <a href="https://juliadocs.github.io/Documenter.jl/stable/" rel="nofollow">Documenter.jl</a> and located in the <code>docs/</code> folder.</p>
<p dir="auto">To build:</p>
<ol dir="auto">
<li>Navigate to the project directory in the terminal.</li>
<li>Run <code>julia --project=docs make.jl</code></li>
</ol>
<p dir="auto">This will generate the documentation HTML in <code>docs/build</code>.</p>

<p dir="auto">For developing the documentation, we recommend using LiveServer.jl.
LiverServer will build the docs locally and update them in real-time as they are being edited, serving them on a local webpage.
This is not added to the docs environment so it will need to be installed.</p>
<p dir="auto">From the project directory, run</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project=docs docs/liveserver.jl"><pre>julia --project=docs docs/liveserver.jl</pre></div>
<p dir="auto">This will usually serve the docs at <a href="http://localhost:8000" rel="nofollow">http://localhost:8000</a>, which you can view in your web browser.</p>
