<ul dir="auto">
<li><strong>EasyConfig</strong> provides a friendly-syntax, nested <code>AbstractDict{Symbol, Any}</code> data structure.</li>
<li>The advantages over other <code>AbstractDict/NamedTuple</code>s are:</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">1) Intermediate levels are created on the fly:</h2><a id="user-content-1-intermediate-levels-are-created-on-the-fly" class="anchor" aria-label="Permalink: 1) Intermediate levels are created on the fly:" href="#1-intermediate-levels-are-created-on-the-fly"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>This is quite convenient for working with JSON specs (e.g. <a href="https://github.com/JuliaComputing/PlotlyLight.jl">PlotlyLight.jl</a>).</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">2) Easy to Use Both Interactively and Programmatically</h2><a id="user-content-2-easy-to-use-both-interactively-and-programmatically" class="anchor" aria-label="Permalink: 2) Easy to Use Both Interactively and Programmatically" href="#2-easy-to-use-both-interactively-and-programmatically"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>You can use any combination of <code>String</code>/<code>Symbol</code> with <code>getproperty</code>/<code>getindex</code>.</li>
<li>For working <em>interactively</em>, <code>getproperty</code> is the most convenient to work with.</li>
<li>For working <em>programmatically</em>, <code>getindex</code> is the most convenient to work with.</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# getproperty

<ul dir="auto">
<li>Accessing a property that doesn't exist will create an empty <code>Config()</code>.</li>
<li>Clean up stranded empty <code>Config</code>s with <code>delete_empty!(::Config)</code>.</li>
</ul>
