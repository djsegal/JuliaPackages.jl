<p dir="auto">You can install SpineInterface from the SpineJuliaRegistry as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
pkg&quot;registry add https://github.com/Spine-tools/SpineJuliaRegistry&quot;
pkg&quot;add SpineInterface&quot;"><pre><span class="pl-k">using</span> Pkg
<span class="pl-s"><span class="pl-pds"><span class="pl-c1">pkg</span>"</span>registry add https://github.com/Spine-tools/SpineJuliaRegistry<span class="pl-pds">"</span></span>
<span class="pl-s"><span class="pl-pds"><span class="pl-c1">pkg</span>"</span>add SpineInterface<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">However, for keeping up with the latest developments, it is highly recommended to install directly from the source.
This can be done by downloading the repository on your computer, and then installing the module locally with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.develop(&quot;&lt;PATH_TO_SPINEINTERFACE&gt;&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">develop</span>(<span class="pl-s"><span class="pl-pds">"</span>&lt;PATH_TO_SPINEINTERFACE&gt;<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">where <code>&lt;PATH_TO_SPINEINTERFACE&gt;</code> is the path to the root folder of the SpineInterface repository on your computer <em>(the one containing the <code>Project.toml</code> file)</em>.</p>
<p dir="auto">SpineInterface has been primarily designed to work through <a href="https://github.com/spine-tools/Spine-Toolbox">Spine Toolbox</a>,
and shouldn't require specific setup when being called from Spine Toolbox workflows.</p>
<p dir="auto">When running SpineInterface outside Spine Toolbox <em>(e.g. from a Julia script directly)</em>, however,
SpineInterface relies on the <a href="https://github.com/spine-tools/Spine-Database-API">Spine Database API</a>
Python package, which is accessed using the <a href="https://github.com/JuliaPy/PyCall.jl">PyCall.jl</a> module.
Thus, one needs to configure PyCall.jl to use a Python executable with Spine Database API installed,
which can be done according to the PyCall readme.
If you're using Conda environments for Python, the <code>.configure_pycall_in_conda.jl</code> script can be used to
automatically configure PyCall to use the Python executable of that Conda environment.</p>

<p dir="auto">When the <code>Julia</code> runs under an active <code>Conda</code> environment, updating the <code>Julia</code> environment raises an error.
Make sure to deactivate the <code>Conda</code> environment before updating the <code>Julia</code> environment.
The error is subject to be fixed.</p>

<p dir="auto">SpineInterface may be updated from time to time. To get the most recent version, just:</p>
<ol dir="auto">
<li>
<p dir="auto">Start the Julia REPL (can be done also in the Julia console of Spine Toolbox).</p>
</li>
<li>
<p dir="auto">Copy/paste the following text into the julia prompt:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.update(&quot;SpineInterface&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">update</span>(<span class="pl-s"><span class="pl-pds">"</span>SpineInterface<span class="pl-pds">"</span></span>)</pre></div>
</li>
</ol>
<p dir="auto">NOTE. It seems that Pkg.update does not always guarantee the latest version. <code>Pkg.rm("SpineInterface")</code> followed by <code>Pkg.add("SpineInterface")</code> may help.</p>
<p dir="auto">If you have installed SpineInterface from source locally on your machine, you can update it simply by pulling the latest <code>master</code> from the repository.</p>

<p dir="auto">with <code>import_data</code> and <code>using_spinedb</code> being the key functions for interfacing a Spine Datastore.
<code>import_data</code> is used to create a new Spine Datastore or write data to an existing Spine Datastore.
<code>using_spinedb</code> creates the convenience functions to access the data in the Spine Datastore.</p>
