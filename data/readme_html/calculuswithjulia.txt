<p dir="auto"><code>Julia</code> package to provide notes and features for using <code>Julia</code> to address typical problems from the undergraduate calculus sequence.</p>
<p dir="auto">The notes may be read at <a href="calculuswithjulia.github.io">calculuswithjulia.github.io</a>. Any suggested edits for the notes should be in a pull request to the repository <a href="https://github.com/jverzani/CalculusWithJuliaNotes.jl/">https://github.com/jverzani/CalculusWithJuliaNotes.jl/</a>.</p>
<p dir="auto">The notes expect that this package is installed, as it also provides a handful of conveniences for the task.</p>
<p dir="auto">In addition to the html pages, there are other versions of the same material that can be generated, such as <code>ipynb</code> notebooks or <code>pdf</code> files. See the <code>runtests.jl</code> file for details.</p>
<p dir="auto">The notes may be read at <a href="https://calculuswithjulia.github.io" rel="nofollow">calculuswithjulia.github.io</a>.</p>
