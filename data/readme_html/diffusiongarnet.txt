<p dir="auto">DiffusionGarnet is a Julia package that can be used to do coupled diffusion modelling of major elements on natural garnet data. It currently supports 1D, 2D, 3D, and spherical coordinates.</p>
<p dir="auto">It is built on top of the <a href="https://github.com/SciML/DifferentialEquations.jl">DifferentialEquations.jl</a> package ecosystem and uses <a href="https://github.com/PainterQubits/Unitful.jl">Unitful.jl</a> to allow the user to define appropriate units for their problems. For 2D and 3D models, it uses <a href="https://github.com/omlins/ParallelStencil.jl">ParallelStencil.jl</a> to support multithreading on CPU and parallel computing on GPU.</p>
<p dir="auto">To know more about this package, don't hesitate to refer to the <a href="https://iddingsite.github.io/DiffusionGarnet.jl/dev/" rel="nofollow">documentation</a>.</p>
