<p dir="auto">AliasTables provides the <code>AliasTable</code> type, which is an object that defines a probability
distribution over <code>1:n</code> for some <code>n</code>. They are efficient to construct and very efficient to
sample from.</p>
<p dir="auto">An alias table can be combined with a dense vector of values to create a discrete
distribution over anything.</p>
<p dir="auto">Internally, AliasTables define a mapping from an unsigned integer type to the sampling
domain. To get a random sample according to the AliasTable's distribution, one must provide
a random unsigned integer uniformly at random. One can also provide a <code>Random.AbstractRNG</code>
object instead and a random unsigned integer will be generated using that rng. When using
the random API, this latter approach is taken.</p>
