<p dir="auto">Statistical hypothesis testing via Monte Carlo simulations.</p>
<p dir="auto"><code>MonteCarloTesting.jl</code> performs hypothesis testing based on simulations, even when no analytic solutions are available. The only requirement is to be able to generate synthetic data under the null hypothesis.</p>
<p dir="auto">See the <a href="https://aplavin.github.io/MonteCarloTesting.jl/test/examples.html" rel="nofollow">Pluto notebook</a> for more explanations and usage examples.</p>
