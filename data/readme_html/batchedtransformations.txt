<p dir="auto">This Julia package provides an interface for applying transformations to data in batches, leveraging <a href="https://github.com/FluxML/NNlib.jl">NNlib.jl</a> and <a href="https://github.com/FluxML/Functors.jl">Functors.jl</a> to be GPU-friendly. Lazy inverse and composition types enable optimization through custom chain rules.</p>
