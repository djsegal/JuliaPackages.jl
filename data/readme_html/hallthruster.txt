<p dir="auto">HallThruster.jl is an open-source, 1D fluid Hall thruster code written in Julia. It is developed by <a href="https://thomasmarks.space" rel="nofollow">Thomas Marks</a>, <a href="https://www.linkedin.com/in/paul-schedler-1b3b6b171/" rel="nofollow">Paul Schedler</a> and Declan Brick at the University of Michigan's <a href="https://pepl.engin.umich.edu" rel="nofollow">Plasmadynamics and Electric Propulsion Laboratory</a> and is licensed under the MIT license.</p>

<p dir="auto">To install HallThruster.jl, you must first install Julia 1.7 or above from the <a href="https://julialang.org/downloads/" rel="nofollow">official Julia site</a>, or by using <a href="https://github.com/JuliaLang/juliaup">juliaup</a>. We recommend using the latest Julia release when possible. Once installed, launch Julia and type <code>]</code> to enter the Pkg REPL. To install HallThruster.jl type</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(@v1.9) pkg&gt; add https://github.com/UM-PEPL/HallThruster.jl"><pre>(<span class="pl-c1">@v1</span>.<span class="pl-c1">9</span>) pkg<span class="pl-k">&gt;</span> add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>UM<span class="pl-k">-</span>PEPL<span class="pl-k">/</span>HallThruster<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">This will install HallThruster.jl using Julia's package manager. For details on setting up and running Hall thruster simulations, see <a href="https://UM-PEPL.github.io/HallThruster.jl/dev" rel="nofollow">the official documentation</a>. A Tutorial is available <a href="https://nbviewer.org/github/UM-PEPL/HallThruster.jl/blob/main/HallThrusterTutorial.ipynb" rel="nofollow">here</a>.</p>
