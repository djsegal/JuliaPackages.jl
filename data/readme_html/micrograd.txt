<p dir="auto">A minimal implementation of automatic differentation (AD) based on <a href="https://fluxml.ai/Zygote.jl/" rel="nofollow">Zygote.jl</a> and <a href="https://juliadiff.org/ChainRulesCore.jl/" rel="nofollow">ChainRules.jl</a>.
See <a href="#limitations">limitations</a> below.</p>
<p dir="auto">This package is built on 3 of Julia's main principles: functional programming, multiple dispatch and metaprogramming.</p>
<p dir="auto">It is inspired by Andrej Karpathy's <a href="https://github.com/karpathy/micrograd">micrograd</a> package.
However the internal workings of this package are very different.
Micrograd creates an object (<code>Value</code>) which implements custom versions of mathematical operations that also calculate the derivative.
All operations are only done with those objects.
In this package existing functions and their arguments are dispatched to a derivative function (<code>rrule</code>). Metaprogamming is used to generate code and dispatch it following the rules of differentiation.</p>
<p dir="auto">The two functions exposed are <code>rrule</code> and <code>pullback</code>.</p>
<p dir="auto">Example using <code>rrule</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x = 0.6

Δy2 = 1.0
Δsin, Δy1 = back2(Δy2) # (nothing,  0.67831)
Δcos, Δx = back1(Δy1) # (nothing, -0.38300)"><pre>x <span class="pl-k">=</span> <span class="pl-c1">0.6</span>

<p dir="auto">The <code>pullback</code> function will automatically transform the forward pass and return a <code>Pullback</code> struct that can generate the backward pass:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="foo(x) = sin(cos(x))
z, back = pullback(foo, 0.6) # (0.73477, ∂(foo))
Δfoo, Δx = back(1.0) # (nothing, -0.38300)"><pre><span class="pl-en">foo</span>(x) <span class="pl-k">=</span> <span class="pl-c1">sin</span>(<span class="pl-c1">cos</span>(x))
z, back <span class="pl-k">=</span> <span class="pl-c1">pullback</span>(foo, <span class="pl-c1">0.6</span>) <span class="pl-c"><span class="pl-c">#</span> (0.73477, ∂(foo))</span>
Δfoo, Δx <span class="pl-k">=</span> <span class="pl-c1">back</span>(<span class="pl-c1">1.0</span>) <span class="pl-c"><span class="pl-c">#</span> (nothing, -0.38300)</span></pre></div>
<p dir="auto">Note that <code>pullback</code> returns derivatives for both the function and the arguments and so it is a mimic of <code>Zygote._pullback</code> and not <code>Zygote.pullback</code>.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="images/moons_decision_boundary.png"><img src="images/moons_decision_boundary.png" alt="Decision boundary for moon dataset." style="max-width: 100%;"></a></p>
<p dir="auto">This code can be used to train a simple model.
The above shows the boundary region after training a small multi-layer perceptron model to differentiate between to two half-circles.</p>

<p dir="auto">Because this AD is limited (especially with regards to control flow and broadcasting), explicit activation and loss functions and their <code>rrule</code>s are also provided.
They are based on functions in <a href="https://fluxml.ai/NNlib.jl" rel="nofollow">NNlib.jl</a>.</p>
<p dir="auto">These are:</p>
<ul dir="auto">
<li><code>sigmoid</code></li>
<li><code>tanh_act</code></li>
<li><code>relu</code></li>
<li><code>softmax</code></li>
<li><code>logsoftmax</code></li>
<li><code>mse</code></li>
<li><code>cross_entropy</code></li>
<li><code>logit_cross_entropy</code></li>
<li><code>hinge_loss</code> (max-margin loss)</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Limitations</h2><a id="user-content-limitations" class="anchor" aria-label="Permalink: Limitations" href="#limitations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package has the following limitations.</p>
<ul dir="auto">
<li>Keyword arguments are not supported.</li>
<li>Control flow is not supported.</li>
<li>Like with Zygote.jl, mutating operations and try-catch statements are not supported.</li>
<li>Minimal set of <code>rrule</code>s are implemented. Many core functions from <code>Base</code> are not implemented e.g. generic broadcasting, <code>Base.iterate</code> etc.</li>
<li>The generated reverse code is only tested in limited scenarios and is not guaranteed to be correct in general.</li>
<li>Cannot handle code with superfluous calls. This will result in <code>nothing</code> being passed to callbacks. Zygote overcomes this issue by wrapping the pullbacks with <code>ZBack</code> which returns <code>nothing</code> if the input is <code>nothing</code>. See the "confused" test.</li>
</ul>
<p dir="auto">Further, the <code>reverse_expr</code> code cannot handle:</p>
<ul dir="auto">
<li>Creation of new variables e.g. with <code>map</code>.</li>
<li>Generated code e.g. in the <code>Chain</code> layer in the examples.</li>
</ul>
