<p dir="auto">This package provides basic finite element structures to setup finite element schemes on ExtendableGrids. For a full high-level API
see <a href="https://github.com/chmerdon/ExtendableFEM.jl">ExtendableFEM.jl</a>.</p>
<p dir="auto">This low level structures in the package incorporate:</p>
<ul dir="auto">
<li>Finite element types (Basis functions on reference geometries and dof management for several H1, Hdiv and Hcurl elements)</li>
<li>FESpace (Discrete finite element space with respect to a mesh from ExtendableGrids, knows the Dofmaps)</li>
<li>FEMatrix (block overlay for an ExtendableSparse matrix, where each block corresponds to a coupling between two FESpaces in a system)</li>
<li>FEVector (block overlay for an array, where each block corresponds to a FESpace)</li>
<li>FunctionOperators (primitive linear operators like Identity, Gradient, Divergence) and rules how to evaluate them for for different finite element types</li>
<li>FEEvaluator (finite element basis evaluators for different FunctionOperators and entities of the grid)</li>
<li>QuadratureRule (basic quadrature rules for different ElementGeometries from ExtendableGrids)</li>
<li>interpolations (standard interpolations into the provided finite element spaces, averaging routines and interpolations between meshes/FESpaces)</li>
<li>reconstruction operators (special FunctionOperators that involve an interpolation into a different finite element type)</li>
</ul>
