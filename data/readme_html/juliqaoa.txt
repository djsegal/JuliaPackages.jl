<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The core functionality of JuliQAOA is to take in a set of angles
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="969c368ad4394c9c908981726339b8fe">${\beta_i, \gamma_i}$</math-renderer>, a mixer <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="969c368ad4394c9c908981726339b8fe">$H_M$</math-renderer>, and a cost function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="969c368ad4394c9c908981726339b8fe">$H_C$</math-renderer>, and return the
statevector</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="969c368ad4394c9c908981726339b8fe">$$|\psi(\beta, \gamma)\rangle = e^{-i \beta_p H_M} e^{-i \gamma_p H_C} \dots e^{-i \beta_1 
H_M} e^{-i \gamma_1 H_C} |\psi_0\rangle.$$</math-renderer>
<p dir="auto">Here is a simple example for a 6-qubit MaxCut problem:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuliQAOA, Graphs

n = 6

# 3 rounds with random angles
p = 3
# angles[1:p] = betas, angles[p+1:end] = gammas
angles = rand(2*p)

# transverse field mixer
mixer = mixer_x(n) 

# calculate the MaxCut cost function over all basis states on a random G(n,p) graph
g = erdos_renyi(n, 0.5)
obj_vals = [maxcut(g, x) for x in states(n)]

# calculate the statevector (with |ψ0⟩ = uniform superposition over all states)
statevector(angles, mixer, obj_vals)"><pre><span class="pl-k">using</span> JuliQAOA, Graphs

n <span class="pl-k">=</span> <span class="pl-c1">6</span>

<span class="pl-c"><span class="pl-c">#</span> 3 rounds with random angles</span>
p <span class="pl-k">=</span> <span class="pl-c1">3</span>
<span class="pl-c"><span class="pl-c">#</span> angles[1:p] = betas, angles[p+1:end] = gammas</span>
angles <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">2</span><span class="pl-k">*</span>p)

<span class="pl-c"><span class="pl-c">#</span> transverse field mixer</span>
mixer <span class="pl-k">=</span> <span class="pl-c1">mixer_x</span>(n) 

<span class="pl-c"><span class="pl-c">#</span> calculate the MaxCut cost function over all basis states on a random G(n,p) graph</span>
g <span class="pl-k">=</span> <span class="pl-c1">erdos_renyi</span>(n, <span class="pl-c1">0.5</span>)
obj_vals <span class="pl-k">=</span> [<span class="pl-c1">maxcut</span>(g, x) <span class="pl-k">for</span> x <span class="pl-k">in</span> <span class="pl-c1">states</span>(n)]

<span class="pl-c"><span class="pl-c">#</span> calculate the statevector (with |ψ0⟩ = uniform superposition over all states)</span>
<span class="pl-c1">statevector</span>(angles, mixer, obj_vals)</pre></div>
<p dir="auto">The statevector can then be used to calculate other quantities of interest, e.g. the
expectation value of <code>H_C</code> or ground state probability.</p>

<p dir="auto">QAOA can be simulated in general-purpose quantum simulators, e.g.
<a href="https://qiskit.org/documentation/stable/0.40/tutorials/algorithms/05_qaoa.html" rel="nofollow">Qiskit</a>
and <a href="https://pennylane.ai/qml/demos/tutorial_qaoa_intro/" rel="nofollow">Pennylane</a>, however they will be
significantly slower.</p>
<p dir="auto"><a href="https://github.com/FZJ-PGI-12/QAOA.jl">QAOA.jl</a> is a circuit-based QAOA simulator for
Julia. <a href="https://github.com/jpmorganchase/QOKit/tree/main">QOKit</a> is a Python package which
uses many of the same basic ideas as JuliQAOA, in particular precomputation and caching of
the cost function terms. It is currently more geared towards running highly parallelized
simulations on large computer clusters.</p>
