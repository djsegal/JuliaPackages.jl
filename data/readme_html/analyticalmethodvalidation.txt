<p dir="auto">A small package for analytical method validation, and sample analysis.</p>
<p dir="auto">For command line interfaces, see <a href="https://github.com/yufongpeng/juliaquant"><code>juliaquant</code></a>.</p>

<p dir="auto">These function accept <code>AnalysisTable</code> or <code>Batch</code>.</p>
<ol dir="auto">
<li><code>qc_report</code>: compute statistics of QC samples.</li>
<li><code>ap_report</code>: compute accuracy, repeatability and reproducibility.</li>
<li><code>recovery_report</code>: compute recovery by prespiked/postspiked.</li>
<li><code>me_report</code>: compute matrix effect by with_matrix/std_solution.</li>
<li><code>stability_report</code>: compute stability in different condition and restoration days.</li>
<li><code>sample_report</code>: average each sample.</li>
</ol>

<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$a_{d,j } = \dfrac{c_{d, j}}{conc.}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$\mu_{d} = \sum_{j=1}^{n_d} \dfrac{a_{d, j}}{n_d}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$s_{intra}^2 = \dfrac{1}{p}\sum_{i = 1}^{p}\sum_{j = 1}^{n_i} \dfrac{(a_{i, j} - \mu_i)^2}{n_i - 1}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$accuracy_{intra, d} = \mu_{d}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$rsd_{intra, d} = \dfrac{s_{intra}}{accuracy_{intra, d}}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$p$</math-renderer>: number of days, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$n_i$</math-renderer>: number of repeats of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$i$</math-renderer> th day, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$c_{i, j}$</math-renderer>: measured concentration of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$i$</math-renderer> th day and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$j$</math-renderer> th repeat, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$conc.$</math-renderer>: reference concentration</p>

<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$\mu = \dfrac{1}{p}\sum_{i = 1}^{p}\sum_{j = 1}^{n_i} \dfrac{a_{i, j}}{n_i}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$accuracy_{inter} = \sum_{i = 1}^{p} \dfrac{accuracy_{intra, i}}{p} = \mu$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$repeatability = rsd_{intra} = \dfrac{s_{intra}}{accuracy_{inter}}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$s_{between}^2 = \sum_{i = 1}^{p} \dfrac{(\mu_i - \mu)^2}{n_d - 1}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$s_{inter}^2 = max\ {0, s_{between}^2 - \dfrac{s_{intra}^2}{\hat{n}}\ }$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$\hat{n}=\dfrac{p}{\sum_{i=1}^p\dfrac{1}{n_i}}$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d3a81ddcbc69ff69fbbd1c396a7d58ad">$$reproducibility = rsd_{total} = \dfrac{\sqrt{s_{inter}^2+s_{intra}^2}}{accuracy_{inter}}$$</math-renderer></p>
