<p dir="auto"><code>SelfConcordantSmoothOptimization.jl</code> is a Julia package that implements the self-concordant regularization (SCORE) technique for (nonsmooth) convex optimization. In particular, <code>SelfConcordantSmoothOptimization.jl</code> considers problems of the form</p>
<p align="center" dir="auto">
minimize f(x) + g(x)
</p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{f}\colon \mathbb{R}^n \to \mathbb{R}$</math-renderer> is smooth and convex, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{g}\colon \mathbb{R}^n \to \mathbb{R}$</math-renderer>, which may be nonsmooth, is proper, closed and convex. The smooth part <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{f}$</math-renderer> defines the problem's objective function, such as quantifying a data-misfit, while the nonsmooth part <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{g}$</math-renderer> imposes certain properties, such as sparsity, on the decision variable <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{x}$</math-renderer>. Please see <a href="#implementation-details-and-recommendations">Implementation details and recommendations</a> for functions that are currently supported for each implemented algorithm.</p>

<ol dir="auto">
<li>Faster computations</li>
<li>Avoid the need to define <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="297b02b692688dbcac5112321742b8b1">$\mathrm{f}$</math-renderer> twice when using <code>ProxGGNSCORE</code>
</li>
</ol>
