<p dir="auto">This package provides a Julia client for the <a href="https://docs.datadoghq.com/agent/" rel="nofollow">Datadog Agent</a>.
It supports sending the following metric types to Datadog:</p>
<ul dir="auto">
<li>Increment/Decrement</li>
<li>Count</li>
<li>Gauge</li>
<li>Timing</li>
<li>Set</li>
<li>Histogram</li>
<li>Distribution</li>
</ul>
<p dir="auto">It does support tags.</p>
<p dir="auto">Simple example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DatadogAgentClient
