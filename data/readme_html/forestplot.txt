<p dir="auto">By default plot is logscaled.</p>
<ul dir="auto">
<li><code>ci</code> - vector (iterable) of confidence intervals bounds;</li>
<li><code>source</code> - vector of study names (String);</li>
<li><code>metric</code> - vector of metric estimates;</li>
<li><code>printci</code> - print confidence interval;</li>
<li><code>summary</code> - print summary object (Dict);</li>
<li><code>logscale</code> - if true CI will be transformed (<code>exp</code> function used);</li>
<li><code>cimsz</code> - CI marker size, <code>-1</code> or any value &lt; 0 - auto;</li>
<li><code>cimszwts</code> - CI marker size weights (if <code>nothing</code> - <code>metric</code> will be used);</li>
<li><code>size</code> - size of plot;</li>
<li>metriclabel = "OR" - label for metrics values;</li>
<li>cilabel = "CI95%"- label for intervals values</li>
<li>ps = 10 - font size in points;</li>
</ul>
