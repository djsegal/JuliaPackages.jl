<p dir="auto">Khronos is a GPU-accelerated Maxwell FDTD solver written entirely in Julia.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key Features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key Features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>GPU acceleration compatible with NVIDIA CUDA, AMD ROCm, Intel OneAPI, and Apple Metal (via <a href="https://github.com/JuliaGPU/KernelAbstractions.jl">KernelAbstractions.jl</a>)</li>
<li>100% Julia code (works with Windows, Mac, and Linux)</li>
<li>Specifiable precision (e.g. <code>Float64</code>, <code>Float32</code>)</li>
<li>Parameterizable geometry via GeometryPrimitives.jl</li>
<li>Diagonally anisotropic permittivity (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1b26a6f2fc3ae2c80cc28ae18650a0e4">$\varepsilon$</math-renderer>) and permeability (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1b26a6f2fc3ae2c80cc28ae18650a0e4">$\mu$</math-renderer>), and electric/magnetic conductivity terms (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1b26a6f2fc3ae2c80cc28ae18650a0e4">$\sigma_D$</math-renderer> / <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1b26a6f2fc3ae2c80cc28ae18650a0e4">$\sigma_B$</math-renderer>) for either the permittivity or permeability, respectively.</li>
<li>Predefined current sources (including planewaves and Gaussian beams) and arbitrary curret sources.</li>
<li>
<em>Equivalent</em> sources from predefined electric and magnetic fields (e.g. to inject modes computed from a mode solver).</li>
<li>Continuous-wave and Guassian-pulse time profiles</li>
<li>Arbitrary 1D, 2D, or 3D (rectilinear) DFT monitors</li>
<li>Perfectly matched layer (PML) absorbing boundaries</li>
<li>Predefined simulation runtime functions, including run for an arbitray time and run until the DFT fields have converged.</li>
<li>Simple plotting of visualization cross sections and overlayed field response, DFT monitors, and source frequency responses.</li>
<li>Benchmark tooling to track performance regressions/enhancements on arbitrary hardware</li>
<li>Composable kernel framework allows for the flexible definition of thousands of different kernels</li>
</ul>
