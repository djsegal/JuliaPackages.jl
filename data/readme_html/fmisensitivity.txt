<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is FMISensitivity.jl?</h2><a id="user-content-what-is-fmisensitivityjl" class="anchor" aria-label="Permalink: What is FMISensitivity.jl?" href="#what-is-fmisensitivityjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Unfortunately, FMUs (<a href="http://fmi-standard.org/" rel="nofollow">fmi-standard.org</a>) are not differentiable by design.
To enable their full potential inside Julia, <a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a> makes FMUs fully differentiable, regarding to:</p>
<ul dir="auto">
<li>states and derivatives</li>
<li>inputs, outputs and other observable variables</li>
<li>parameters</li>
<li>event indicators</li>
<li>explicit time</li>
<li>state change sensitivity by event <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bd8584a587e5e43c5396451baf70dfc4">$\partial x^{+} / \partial x^{-}$</math-renderer> (if paired with <em>FMIFlux.jl</em>)</li>
</ul>
<p dir="auto">This opens up to many applications like:</p>
<ul dir="auto">
<li>FMUs in Scientific Machine Learning, for example as part of Neural(O)DEs or PINNs with <a href="https://github.com/ThummeTo/FMIFlux.jl"><em>FMIFlux.jl</em></a></li>
<li>gradient-based optimization of FMUs (typically parameters) with <a href="https://github.com/ThummeTo/FMIFlux.jl"><em>FMI.jl</em></a> (also <em>dynamic</em> optimization)</li>
<li>linearization, linear analysis and controller design</li>
<li>adding directional derivatives for existing FMUs with the power of Julia AD and <a href="https://github.com/ThummeTo/FMIExport.jl"><em>FMIExport.jl</em></a> [Tutorial is WIP]</li>
<li>...</li>
</ul>
<p dir="auto">Supported AD-Frameworks are:</p>
<ul dir="auto">
<li>ForwardDiff</li>
<li>FiniteDiff</li>
<li>ReverseDiff</li>
<li>Zygote [WIP]</li>
</ul>
<p dir="auto">Here, <em>FMISensitivity.jl</em> uses everything the FMI-standard and Julia currently offers:</p>
<ul dir="auto">
<li>FMI built-in directional derivatives [DONE] and adjoint derivatives [WIP]</li>
<li>Finite Differences (by <em>FiniteDiff.jl</em>) for FMUs that don't offer sensitivity information, as well as for special derivatives that are not part of the FMI-standard (like e.g. event-indicators or explicit time)</li>
<li>coloring based on sparsity information shipped with the FMU [WIP]</li>
<li>coloring based on sparsity detection for FMUs without sparsity information [WIP]</li>
<li>implicite differentation</li>
<li>...</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How can I use FMISensitivity.jl?</h2><a id="user-content-how-can-i-use-fmisensitivityjl" class="anchor" aria-label="Permalink: How can I use FMISensitivity.jl?" href="#how-can-i-use-fmisensitivityjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a> is part of <a href="https://github.com/ThummeTo/FMIFlux.jl"><em>FMIFlux.jl</em></a>. If you only need FMU sensitivities without anything around and want to keep the dependencies as small as possible, <a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a> might be the right way to go. You can install it via:</p>
<p dir="auto">1. Open a Julia-REPL, switch to package mode using <code>]</code>, activate your preferred environment.</p>
<p dir="auto">2. Install <a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(@v1) pkg&gt; add FMISensitivity"><pre>(@v1) pkg&gt; add FMISensitivity</pre></div>
<p dir="auto">3. If you want to check that everything works correctly, you can run the tests bundled with <a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(@v1) pkg&gt; test FMISensitivity"><pre>(@v1) pkg&gt; test FMISensitivity</pre></div>
<p dir="auto">4. Have a look inside the <a href="https://github.com/ThummeTo/FMI.jl/tree/examples/examples">examples folder</a> in the examples branch or the <a href="https://thummeto.github.io/FMI.jl/dev/examples/overview/" rel="nofollow">examples section</a> of the documentation of the <a href="https://github.com/ThummeTo/FMI.jl"><em>FMI.jl</em></a> package. All examples are available as Julia-Script (<em>.jl</em>), Jupyter-Notebook (<em>.ipynb</em>) and Markdown (<em>.md</em>).</p>

<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="https://github.com/ThummeTo/FMI.jl/blob/main/docs/src/assets/FMI_JL_family.png?raw=true"><img src="https://github.com/ThummeTo/FMI.jl/raw/main/docs/src/assets/FMI_JL_family.png?raw=true" alt="FMI.jl Family" title="FMI.jl Family" style="max-width: 100%;"></a>
To keep dependencies nice and clean, the original package <a href="https://github.com/ThummeTo/FMI.jl"><em>FMI.jl</em></a> had been split into new packages:</p>
<ul dir="auto">
<li><a href="https://github.com/ThummeTo/FMI.jl"><em>FMI.jl</em></a>: High level loading, manipulating, saving or building entire FMUs from scratch</li>
<li><a href="https://github.com/ThummeTo/FMIImport.jl"><em>FMIImport.jl</em></a>: Importing FMUs into Julia</li>
<li><a href="https://github.com/ThummeTo/FMIExport.jl"><em>FMIExport.jl</em></a>: Exporting stand-alone FMUs from Julia Code</li>
<li><a href="https://github.com/ThummeTo/FMIBase.jl"><em>FMIBase.jl</em></a>: Common concepts for import and export of FMUs</li>
<li><a href="https://github.com/ThummeTo/FMICore.jl"><em>FMICore.jl</em></a>: C-code wrapper for the FMI-standard</li>
<li><a href="https://github.com/ThummeTo/FMISensitivity.jl"><em>FMISensitivity.jl</em></a>: Static and dynamic sensitivities over FMUs</li>
<li><a href="https://github.com/ThummeTo/FMIBuild.jl"><em>FMIBuild.jl</em></a>: Compiler/Compilation dependencies for FMIExport.jl</li>
<li><a href="https://github.com/ThummeTo/FMIFlux.jl"><em>FMIFlux.jl</em></a>: Machine Learning with FMUs</li>
<li><a href="https://github.com/ThummeTo/FMIZoo.jl"><em>FMIZoo.jl</em></a>: A collection of testing and example FMUs</li>
</ul>
