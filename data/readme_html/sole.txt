<p dir="auto">Symbolic learning is machine learning based on symbolic logic. Its peculiarity lies in the fact that the learned models enclose an <strong>explicit knowledge representation</strong>, which offers many opportunities:</p>
<ul dir="auto">
<li>Verifying that the model's thought process is adequate for a given task;</li>
<li>Learning of new insights by simple inspection of the model;</li>
<li>Manual refinement of the model at a later time.</li>
</ul>
<p dir="auto">These levels of <strong>transparency</strong> (or <em>interpretability</em>) are generally not available with standard machine learning methods, thus, as AI permeates more and more aspects of our lives, symbolic learning is becoming increasingly popular. In spite of this, implementations of symbolic algorithms (e.g., extraction of decision trees or rules) are mostly scattered across different languages and machine learning frameworks.</p>
<p dir="auto"><em>Enough with this!</em> The lesser and lesser minoritarian theory of symbolic learning deserves a programming framework of its own!</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The Sole.jl framework</h2><a id="user-content-the-solejl-framework" class="anchor" aria-label="Permalink: The Sole.jl framework" href="#the-solejl-framework"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><em>Sole</em> is a collection of Julia packages for symbolic learning and reasoning.
Although at an embryonic stage, <em>Sole.jl</em> covers a range of functionality that is of interest for the symbolic community, but it also fills some gaps with a few functionalities for standard machine learning pipelines. At the time of writing, the framework comprehends the three core packages:</p>
<ul dir="auto">
<li><a href="https://github.com/aclai-lab/SoleLogics.jl"><em>SoleLogics.jl</em></a> provides the <strong>logical layer</strong> for symbolic learning. It provides a useful codebase for <a href="https://en.wikipedia.org/wiki/Computational_logic" rel="nofollow"><em>computational logic</em></a>, which features easy manipulation of:
<ul dir="auto">
<li>Propositional and (multi)modal logics (atoms, logical constants, alphabet, grammars, fuzzy algebras);</li>
<li><a href="https://en.wikipedia.org/wiki/Well-formed_formula" rel="nofollow">Logical formulas</a> (random generation, parsing, minimization);</li>
<li><a href="https://en.wikipedia.org/wiki/Interpretation_(logic)" rel="nofollow">Logical interpretations</a> (or models, e.g., <a href="https://en.wikipedia.org/wiki/Kripke_structure_(model_checking)" rel="nofollow">Kripke structures</a>);</li>
<li>Algorithms for <a href="https://en.wikipedia.org/wiki/Model_checking" rel="nofollow">model checking</a> (that is, checking that a formula is satisfied by an interpretation).</li>
</ul>
</li>
<li><a href="https://github.com/aclai-lab/SoleData.jl"><em>SoleData.jl</em></a> provides the <strong>data layer</strong> for representing <em>logisets</em>, that is, the logical counterpart to machine learning datasets:
<ul dir="auto">
<li>Optimized data structures, useful when learning models from datasets;
<ul dir="auto">
<li>Support for <a href="https://en.wikipedia.org/wiki/Multimodal_learning" rel="nofollow">multimodal data</a>.</li>
</ul>
</li>
</ul>
</li>
<li><a href="https://github.com/aclai-lab/SoleModels.jl"><em>SoleModels.jl</em></a> defines the building blocks of <strong>symbolic modeling</strong>, featuring:
<ul dir="auto">
<li>Definitions for (logic-agnostic) symbolic models (mainly, decision rules/lists/trees/forests);</li>
<li>Support for mixed, neuro-symbolic computation.</li>
</ul>
</li>
</ul>
<p dir="auto">Additional packages include:</p>
<ul dir="auto">
<li><a href="https://github.com/aclai-lab/SoleDecisionTreeInterface.jl"><em>SoleDecisionTreeInterface.jl</em></a>, which enables the use of Sole on decision trees learned via <a href="https://github.com/JuliaAI/DecisionTree.jl">DecisionTree.jl</a> (e.g., extract and evaluate rules);</li>
<li><a href="https://github.com/aclai-lab/ModalDecisionTrees.jl"><em>ModalDecisionTrees.jl</em></a> which allows you to learn decision trees based on temporal logics on time-series datasets, and spatial logics on (small) image datasets;</li>
<li><a href="https://github.com/aclai-lab/ModalDecisionLists.jl"><em>ModalDecisionLists.jl</em></a> which implements a sequential covering algorithm to learn decision lists;</li>
</ul>
