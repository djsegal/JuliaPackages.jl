<p dir="auto">This is a state-of-the-art implementation of the stochastic series expansion quantum Monte Carlo (QMC) algorithm <a href="#1">[1]</a> with abstract loop updates <a href="#2">[2]</a>, which allow
the efficient simulation of many different bosonic lattice models in different computational bases using the same code.</p>
<p dir="auto">StochasticSeriesExpansion is aimed both at</p>
<ul dir="auto">
<li><strong>Nonspecialists</strong> who want to produce unbiased QMC data for comparison against experiments or other methods,
and</li>
<li><strong>Specialists</strong> who want to extend it to study novel models and phenomena.</li>
</ul>
<p dir="auto">Out of the box, it can simulate common quantum magnet Hamiltonians, but it can be easily extended to arbitrary models by providing a bond Hamiltonian matrix.</p>
<p dir="auto">It is built on the <a href="https://github.com/lukas-weber/Carlo.jl.git">Carlo</a> framework.</p>
