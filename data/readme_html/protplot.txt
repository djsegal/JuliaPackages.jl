<p dir="auto">ProtPlot is a Julia package for rendering 3D protein ribbon using <a href="https://github.com/MakieOrg/Makie.jl">Makie.jl</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">ProtPlot exports the Ribbon plot:</p>
<ul dir="auto">
<li><code>ribbon</code>: makes a static render of the ribbon.</li>
<li><code>ribbon!</code>: renders the ribbon plot within an existing container (e.g., <code>Scene</code> or <code>Axis3</code>).</li>
<li><code>ribbon_scene</code>: creates an interactive Scene to render the ribbon.</li>
</ul>

<p dir="auto">Ribbon plots are constructed from vectors of protein backbones represented as <code>3x3xL</code> arrays.
For convenience, argument conversion methods are defined, and the ribbon constructors can take:</p>
<ul dir="auto">
<li>a <code>3x3xL</code> array of residue backbone atom coordinates (N, Ca, C), or a vector of these for each chain.</li>
<li>a <code>BioStructures.MolecularStructure</code> or <code>BioStructures.Chain</code>.</li>
<li>a PDB file path.</li>
</ul>

<p dir="auto">Use the <code>colors</code> keyword argument to customize colors at the residue level. This argument should be a vector of vectors, where each vector contains either:</p>
<ul dir="auto">
<li>values between 0 and 1, representing the colors of each residue in their respective chains according to the <code>colormap</code>.</li>
<li>a list of <a href="https://github.com/JuliaGraphics/ColorTypes.jl?tab=readme-ov-file#colortypes"><code>Colorant</code>s</a>, one per residue. For example, <code>RGBA(1, 0, 0, 0.5)</code> for a 50% transparent red. Load the <code>ColorTypes</code> or <code>Colors</code> package to create such <code>Colorant</code>s.</li>
</ul>

<p dir="auto">You may customize the geometry of the ribbon by specifying the value of attributes in the keyword arguments of your call. Here's a list of available attributes and their defaults:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>secondary_structures = nothing</code> (gets assigned by an algorithm by default; needs to be a vector of <code>Vector{Int}</code> where <code>1</code> means loop, <code>2</code> means helix, and <code>3</code> means strand)</p>
</li>
<li>
<p dir="auto"><code>colors = nothing</code> (gets assigned <code>range(0, 1, L)</code> for each chain by default, mapping to <code>colormap</code>; overrides colormap if colorants are given)</p>
</li>
<li>
<p dir="auto"><code>colormap = :jet</code> (see the <a href="https://juliagraphics.github.io/ColorSchemes.jl/stable/catalogue/" rel="nofollow">ColorSchemes.jl catalogue</a>; can also be a vector of colorants)</p>
</li>
<li>
<p dir="auto"><code>coil_diameter = 0.4</code></p>
</li>
<li>
<p dir="auto"><code>coil_spline_quality = 20</code></p>
</li>
<li>
<p dir="auto"><code>coil_slice_quality = 20</code></p>
</li>
<li>
<p dir="auto"><code>helix_width = 2.0</code></p>
</li>
<li>
<p dir="auto"><code>helix_thickness = 0.5</code></p>
</li>
<li>
<p dir="auto"><code>helix_spline_quality = 20</code></p>
</li>
<li>
<p dir="auto"><code>helix_slice_quality = 20</code></p>
</li>
<li>
<p dir="auto"><code>strand_width = 2.0</code></p>
</li>
<li>
<p dir="auto"><code>strand_thickness = 0.5</code></p>
</li>
<li>
<p dir="auto"><code>strand_arrow_head_length = 5.0</code></p>
</li>
<li>
<p dir="auto"><code>strand_arrow_head_width = 3.5</code></p>
</li>
<li>
<p dir="auto"><code>strand_spline_quality = 20</code></p>
</li>
</ul>
