<p dir="auto">This repository contains a Julia package that implements various control barrier function (CBFs) techniques based on reduced-order models. The code here is based on a collection of papers (see related works at the end of this readme) and may be used to reconstruct many of the examples from our papers:</p>
<p dir="auto">M. H. Cohen, T. G. Molnar, and A. D. Ames, "<a href="https://www.sciencedirect.com/science/article/pii/S1367578824000166" rel="nofollow">Safety-Critical Control of Autonomous Systems: Control Barrier Functions via Reduced-Order Models</a>," Annual Reviews in Control, vol. 57, pp. 100947, 2024;</p>
<p dir="auto">M. H. Cohen, R. K. Cosner, and A.D. Ames, "<a href="https://ieeexplore.ieee.org/abstract/document/10552758" rel="nofollow">Constructive Safety-Critical Control: Synthesizing Control Barrier Functions for Partially Feedback Linearizable Systems</a>," IEEE Control Systems Letters, 2024.</p>
<p dir="auto">The code corresponding to the examples in the above papers can be found in the examples folder of this repo. If you find this code useful, please consider citing the above papers or some of the works mentioned at the end of this README.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quick tutorial</h2><a id="user-content-quick-tutorial" class="anchor" aria-label="Permalink: Quick tutorial" href="#quick-tutorial"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We'll walk step-by-step through one of the examples that demonstrates the procedure used to construct CBFs via reduced-order models. The objective here is to design a controller for a double integrator to avoid an obstacle by extending a CBF for a single integrator to that for a double integrator</p>
<p dir="auto">First, we need to load the packages we'll use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using LinearAlgebra
using ReducedOrderModelCBFs"><pre><span class="pl-k">using</span> LinearAlgebra
<span class="pl-k">using</span> ReducedOrderModelCBFs</pre></div>
<p dir="auto">Next, we create our reduced-order model -- a 2D single integrator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Σ0 = SingleIntegrator(2)"><pre>Σ0 <span class="pl-k">=</span> <span class="pl-c1">SingleIntegrator</span>(<span class="pl-c1">2</span>)</pre></div>
<p dir="auto">Now, we construct a CBF for this single integrator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="xo = [-1.0, 1.0] # Obstacle center
ro = 0.4 # Obstacle radius
h0(x) = norm(x - xo)^2 - ro^2 # Distance to obstacle
cbf0 = ControlBarrierFunction(h0, s -&gt; s); # CBF for reduced-order model"><pre>xo <span class="pl-k">=</span> [<span class="pl-k">-</span><span class="pl-c1">1.0</span>, <span class="pl-c1">1.0</span>] <span class="pl-c"><span class="pl-c">#</span> Obstacle center</span>
ro <span class="pl-k">=</span> <span class="pl-c1">0.4</span> <span class="pl-c"><span class="pl-c">#</span> Obstacle radius</span>
<span class="pl-en">h0</span>(x) <span class="pl-k">=</span> <span class="pl-c1">norm</span>(x <span class="pl-k">-</span> xo)<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-k">-</span> ro<span class="pl-k">^</span><span class="pl-c1">2</span> <span class="pl-c"><span class="pl-c">#</span> Distance to obstacle</span>
cbf0 <span class="pl-k">=</span> <span class="pl-c1">ControlBarrierFunction</span>(h0, s <span class="pl-k">-&gt;</span> s); <span class="pl-c"><span class="pl-c">#</span> CBF for reduced-order model</span></pre></div>
<p dir="auto">We use this CBF to construct a smooth safety filter for the reduced-order model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="kd0(x) = -x # Desired controller for ROM
k0 = SmoothSafetyFilter(Σ0, cbf0, kd0, formula=&quot;gaussian&quot;, σ=0.1);"><pre><span class="pl-en">kd0</span>(x) <span class="pl-k">=</span> <span class="pl-k">-</span>x <span class="pl-c"><span class="pl-c">#</span> Desired controller for ROM</span>
k0 <span class="pl-k">=</span> <span class="pl-c1">SmoothSafetyFilter</span>(Σ0, cbf0, kd0, formula<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>gaussian<span class="pl-pds">"</span></span>, σ<span class="pl-k">=</span><span class="pl-c1">0.1</span>);</pre></div>
<p dir="auto">This smooth safety filter is now used to construct a CBF for the double-integrator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="μ = 5.0
h(x) = h0(x[1:2]) - (0.5/μ)*norm(x[3:4] - k0(x[1:2]))^2
cbf = ControlBarrierFunction(h, s -&gt; s);"><pre>μ <span class="pl-k">=</span> <span class="pl-c1">5.0</span>
<span class="pl-en">h</span>(x) <span class="pl-k">=</span> <span class="pl-c1">h0</span>(x[<span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">2</span>]) <span class="pl-k">-</span> (<span class="pl-c1">0.5</span><span class="pl-k">/</span>μ)<span class="pl-k">*</span><span class="pl-c1">norm</span>(x[<span class="pl-c1">3</span><span class="pl-k">:</span><span class="pl-c1">4</span>] <span class="pl-k">-</span> <span class="pl-c1">k0</span>(x[<span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">2</span>]))<span class="pl-k">^</span><span class="pl-c1">2</span>
cbf <span class="pl-k">=</span> <span class="pl-c1">ControlBarrierFunction</span>(h, s <span class="pl-k">-&gt;</span> s);</pre></div>
<p dir="auto">Finally, we construct a QP-based safety filter for the double-integrator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="kd(x) = -x[1:2] - 2*x[3:4] # Desired controller for full-order model
k = ReluSafetyFilter(Σ, cbf, kd);"><pre><span class="pl-en">kd</span>(x) <span class="pl-k">=</span> <span class="pl-k">-</span>x[<span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">2</span>] <span class="pl-k">-</span> <span class="pl-c1">2</span><span class="pl-k">*</span>x[<span class="pl-c1">3</span><span class="pl-k">:</span><span class="pl-c1">4</span>] <span class="pl-c"><span class="pl-c">#</span> Desired controller for full-order model</span>
k <span class="pl-k">=</span> <span class="pl-c1">ReluSafetyFilter</span>(Σ, cbf, kd);</pre></div>
<p dir="auto">If we want, we can then simulate the system under this controller:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x0 = [-2.1, 2.0, 0.0, 0.0] # Initial condition
