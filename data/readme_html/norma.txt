<p dir="auto">A Julia prototype for testing algorithms and ideas for coupling and multiphysics mainly in solid mechanics and heat conduction.</p>
<p dir="auto">To install within the package manager (press <code>]</code> in the Julia REPL):</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; activate .
pkg&gt; registry update
pkg&gt; update
pkg&gt; instantiate"><pre class="notranslate"><code>pkg&gt; activate .
pkg&gt; registry update
pkg&gt; update
pkg&gt; instantiate
</code></pre></div>
<p dir="auto">Then press <code>delete</code> to exit the package manager.</p>
<p dir="auto">On MacOS, it is necessary to ignore package hashes for the dependence on Exodus.jl:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="ENV[&quot;JULIA_PKG_IGNORE_HASHES&quot;] = 1"><pre class="notranslate"><code>ENV["JULIA_PKG_IGNORE_HASHES"] = 1
</code></pre></div>
<p dir="auto">To run the code, assuming that Julia is in the executable path:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia --project=@. /path/to/src/Norma.jl input.yaml"><pre class="notranslate"><code>julia --project=@. /path/to/src/Norma.jl input.yaml
</code></pre></div>
