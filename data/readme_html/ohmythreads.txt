<p dir="auto"><a href="https://github.com/JuliaFolds2/OhMyThreads.jl/">OhMyThreads.jl</a> is meant to be a simple, unambitious package that provides user-friendly ways of doing <a href="https://docs.julialang.org/en/v1/base/parallel/" rel="nofollow">task-based</a> multithreaded calculations in Julia. Most importantly, with a
focus on <a href="https://en.wikipedia.org/wiki/Data_parallelism" rel="nofollow">data parallelism</a>, it provides an <a href="https://juliafolds2.github.io/OhMyThreads.jl/stable/refs/api/#Functions" rel="nofollow">API of higher-order functions</a> (e.g. <code>tmapreduce</code>) as well as a <a href="https://juliafolds2.github.io/OhMyThreads.jl/stable/refs/api/#Macros" rel="nofollow">macro API</a> <code>@tasks for ... end</code> (conceptually similar to <code>@threads</code>).</p>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OhMyThreads: tmapreduce, @tasks
using BenchmarkTools: @btime
using Base.Threads: nthreads

# Variant 1: function API
function mc_parallel(N; ntasks=nthreads())
    M = tmapreduce(+, 1:N; ntasks) do i
        rand()^2 + rand()^2 &lt; 1.0
    end
    pi = 4 * M / N
    return pi
end

# Variant 2: macro API
function mc_parallel_macro(N; ntasks=nthreads())
    M = @tasks for i in 1:N
        @set begin
            reducer=+
            ntasks=ntasks
        end
        rand()^2 + rand()^2 &lt; 1.0
    end
    pi = 4 * M / N
    return pi
end

mc_parallel(N) # gives, e.g., 3.14159924
