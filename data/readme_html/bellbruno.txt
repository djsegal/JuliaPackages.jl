<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quick Tutorial</h2><a id="user-content-quick-tutorial" class="anchor" aria-label="Permalink: Quick Tutorial" href="#quick-tutorial"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We are wish to find the derivatives of function composition</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e3331f45ad2c94886ccace69415128e3">$$ h(t) = f(g(t)) = \exp(p~\sin(t))$$</math-renderer></p>
<p dir="auto">up to the order of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3331f45ad2c94886ccace69415128e3">$N=10$</math-renderer>. We assume <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e3331f45ad2c94886ccace69415128e3">$p=0.1$</math-renderer>.</p>
<p dir="auto">The derivative of the outer function is noted as</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e3331f45ad2c94886ccace69415128e3">$$ \frac{d^n}{dx^n} f(x) = p^{n} \exp(p~x)$$</math-renderer></p>
<p dir="auto">and the derivative of the inner function is noted as</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e3331f45ad2c94886ccace69415128e3">$$ \frac{d^n}{dt^n} g(t) = \sin(t+n~\pi/2).$$</math-renderer></p>
<p dir="auto"><strong>Derivative of outer function</strong></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="p = 0.1;
f_der(x,n) = p^n * exp(p*x) "><pre>p <span class="pl-k">=</span> <span class="pl-c1">0.1</span>;
<span class="pl-en">f_der</span>(x,n) <span class="pl-k">=</span> p<span class="pl-k">^</span>n <span class="pl-k">*</span> <span class="pl-c1">exp</span>(p<span class="pl-k">*</span>x) </pre></div>
<p dir="auto"><strong>Inner function and its derivatives</strong></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="g(t) = sin(t)
g_der(t,n) = sin(t+n*π/2)"><pre><span class="pl-en">g</span>(t) <span class="pl-k">=</span> <span class="pl-c1">sin</span>(t)
<span class="pl-en">g_der</span>(t,n) <span class="pl-k">=</span> <span class="pl-c1">sin</span>(t<span class="pl-k">+</span>n<span class="pl-k">*</span>π<span class="pl-k">/</span><span class="pl-c1">2</span>)</pre></div>
