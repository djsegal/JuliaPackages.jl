<p dir="auto">If it quacks like a tabular IO package, then it is a tabular IO package <em>(powered by <code>DuckDB</code>)</em>.</p>
<p dir="auto"><code>QuackIO</code> provides a native Julia interface to DuckDB read/write functions. They support all Julia table types that follow the <code>Tables.jl</code> interface. Reading and writing is most efficient with columnar table types, such as <code>StructArray</code> or <code>columntable</code>.</p>
<ul dir="auto">
<li><code>write_table(filename, table; options...)</code><br>
Executes <code>COPY table TO file (options)</code> in DuckDB. Here, <code>table</code> is an arbitrary Julia table object:</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using QuackIO

write_table(&quot;my_file.csv&quot;, tbl)

<span class="pl-c1">write_table</span>(<span class="pl-s"><span class="pl-pds">"</span>my_file.csv<span class="pl-pds">"</span></span>, tbl)
<span class="pl-c1">write_table</span>(<span class="pl-s"><span class="pl-pds">"</span>my_file.pq<span class="pl-pds">"</span></span>, tbl, format<span class="pl-k">=</span><span class="pl-c1">:parquet</span>)</pre></div>
<ul dir="auto">
<li><code>read_*(tabletype, filename; options...)</code> where <code>*</code> is <code>csv</code>, <code>parquet</code>, or <code>json</code><br>
Calls the corresponding DuckDB function and converts the result to the specified Julia table type.</li>
</ul>

<p dir="auto">Thanks to DuckDB and its Julia integration, <code>QuackIO</code> functions are performant. They can even be faster than native Julia readers for these formats.</p>
