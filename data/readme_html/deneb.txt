<p dir="auto"><strong>Deneb</strong> is the brightest star in the constellation of the <em>Cygnus</em>, and together with <strong>Vega</strong> and <strong>Altair</strong> they form the <em>Summer Triangle</em> asterism.</p>
<p dir="auto"><strong>Deneb.jl</strong> is a convenient Julia API for creating <a href="https://vega.github.io/vega-lite/" rel="nofollow">Vega-Lite</a> visualizations, with high inspiration from Python's <a href="https://altair-viz.github.io/" rel="nofollow">Vega-Altair</a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Why Deneb.jl?</h2><a id="user-content-why-denebjl" class="anchor" aria-label="Permalink: Why Deneb.jl?" href="#why-denebjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The excellent <a href="https://github.com/queryverse/VegaLite.jl/tree/master">VegaLite.jl</a> package, with Julia bindings to Vega-Lite, already exists in the Julia ecosystem. So, why create yet another package to accomplish the same thing?</p>
<p dir="auto">VegaLite.jl allows for the creation of virtually any possible Vega-Lite specification in an elegant manner. However, its strategy for composing plots can be somewhat confusing and obscure (refer to this VegaLite.jl <a href="https://github.com/queryverse/VegaLite.jl/issues/230" data-hovercard-type="issue" data-hovercard-url="/queryverse/VegaLite.jl/issues/230/hovercard">issue</a> for more details). In response to this, I proposed an alternative composition strategy in <a href="https://github.com/queryverse/VegaLite.jl/pull/411" data-hovercard-type="pull_request" data-hovercard-url="/queryverse/VegaLite.jl/pull/411/hovercard">this PR</a>. This, along with an excuse to start a personal project to further explore the Julia language, served as the main motivation to start creating Deneb.jl.</p>
<p dir="auto"><strong>Deneb.jl is not intended as a replacement for VegaLite.jl</strong>. VegaLite.jl benefits from the attention of numerous contributors with vast experience in creating and maintaining Julia packages. In contrast, I am simply a Julia and Vega-Lite enthusiast with limited time to explore Julia's capabilities in my free time. However, if Deneb.jl attracts some interest, I'm willing to continue improving its documentation and other aspects of the package. Of course, contributions from others are always welcome.</p>
<p dir="auto">Below a list of good and not-so-good things about Deneb.jl:</p>
<ul dir="auto">
<li>It provides a coherent API that allows for a convenient and intuitive construction of any Vega-Lite visualization.</li>
<li>Layering and composing single and multi-view charts is intuitive using the operators <code>+</code> (familiar to <a href="https://altair-viz.github.io/" rel="nofollow">Altair</a> users) and <code>*</code> (familiar to <a href="https://github.com/MakieOrg/AlgebraOfGraphics.jl">AlgebraOfGraphics.jl</a> users).</li>
<li>While the documentation may currently lack completeness and coherence, there is a comprehensive set of examples available in the <a href="https://brucala.github.io/Deneb.jl/dev/examples/" rel="nofollow">Gallery</a> section. These examples should serve as a valuable resource to enable any user already familiar with Vega-Lite and/or Altair.</li>
<li>I initially started this project as an exercise to learn more about Julia. Therefore, the internal design of Deneb.jl was primarily driven by my personal learning appetite at the time and might not represent the optimal or most idiomatic design choices. However, things just work.</li>
<li>There are numerous tests in place, although the test coverage is not yet close to 100% in any way.</li>
</ul>
