<p dir="auto">DopplerSpectroscopyCore.jl provides core toolset for simulating Doppler and sub-Doppler spectroscopy
experiments. The main goal is to have ready-to-use, simple-to-understand modeling toolkit with experimenters in mind.
Furthermore, it can be used as introduction to spectroscopy for people with little physics background or
students.</p>

<p dir="auto">Import module:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using RabiRamseySpectroscopy"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> RabiRamseySpectroscopy</pre></div>
<p dir="auto">At first we need to create our experement setup:</p>
<ol dir="auto">
<li>Light source - research instrument. Red laser (wavelenght = 750 nm or approx. 8e-7 m) will fit.
We consider that there is no refracted light to enter the research object in a backward direction
by setting the last parameter to 0</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; laser = LightSource(8e-7, 1, 0)"><pre>julia<span class="pl-k">&gt;</span> laser <span class="pl-k">=</span> <span class="pl-c1">LightSource</span>(<span class="pl-c1">8e-7</span>, <span class="pl-c1">1</span>, <span class="pl-c1">0</span>)</pre></div>
<ol start="2" dir="auto">
<li>Gas cell or a single atom - research object. Lets say it's a <sup>87</sup>Rb atom (mass = 1.4e-25kg)
at room temperature (T = 300 K). Atom's spontaneous relaxation parameter is approx. 2π*5e+6 Hz and
optical relaxation parameter considered to be half of spontaneous in units of it's value (0.5). Other parameters
depends on a light source so we just use our <strong>laser</strong> as an argument</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; atom = Quantum2Level(1.4e-25, 300, 2π*5e+6, 0.5, light)"><pre>julia<span class="pl-k">&gt;</span> atom <span class="pl-k">=</span> <span class="pl-c1">Quantum2Level</span>(<span class="pl-c1">1.4e-25</span>, <span class="pl-c1">300</span>, <span class="pl-c1">2</span>π<span class="pl-k">*</span><span class="pl-c1">5e+6</span>, <span class="pl-c1">0.5</span>, light)</pre></div>
<p dir="auto">Because probing time is long enough, probe pulse will be playing two roles at the same time:</p>
<ol dir="auto">
<li>
<p dir="auto"><em>pump</em> our atom with some probability to excited state</p>
</li>
<li>
<p dir="auto"><em>probe</em> our system to check if atom was actually pumped.</p>
</li>
</ol>
<p dir="auto">(Make a pull request or issue on package's GitHub page if you want more physics details in the intro)</p>
<p dir="auto">Thus said, second step is to probe an atom with the laser:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; probe(0, atom, laser)
0.0189015858908291"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">probe</span>(<span class="pl-c1">0</span>, atom, laser)
<span class="pl-c1">0.0189015858908291</span></pre></div>
<p dir="auto">The output indicates the probability of our atom to be in excited state at zero-detuning
(laser frequency is resonant with transition frequency of an atom).</p>
<p dir="auto">Congrats, you performed your first spectroscopy experiment in Julia!</p>
<p dir="auto">As a third step we'll see a relation between mentioned probability and detuning of a laser light.
For that we need to make a series of probes, varying laser detuning. It can be done by simply applying <strong>probe</strong>
on a range of detuning values:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; detun_range = LinRange(-300, 300, 100)
julia&gt; probes = probe(detun_range, atom, laser)"><pre>julia<span class="pl-k">&gt;</span> detun_range <span class="pl-k">=</span> <span class="pl-c1">LinRange</span>(<span class="pl-k">-</span><span class="pl-c1">300</span>, <span class="pl-c1">300</span>, <span class="pl-c1">100</span>)
julia<span class="pl-k">&gt;</span> probes <span class="pl-k">=</span> <span class="pl-c1">probe</span>(detun_range, atom, laser)</pre></div>
<p dir="auto">Then you can plot this relation yourself with any provided plotting tool: Plots, PlotlyJS, Makie etc.
(maybe will add example pic later)</p>
