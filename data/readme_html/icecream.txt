<p dir="auto">IceCream.jl is a Julia port of the <a href="https://github.com/gruns/icecream">icecream</a> library for Python.</p>
<p dir="auto">Do you ever use <code>print()</code> or <code>println()</code> to debug your code? Of course you do. IceCream, or <code>@ic</code> for short, makes print debugging a little sweeter.</p>
<p dir="auto"><code>@ic()</code> is like <code>println()</code>, but better:</p>
<ul dir="auto">
<li>It prints both expressions/variable names and their values.</li>
<li>It's 60% faster to type.</li>
<li>Data structures are pretty printed.</li>
<li>Output is syntax highlighted.</li>
<li>It optionally includes program context: filename, parent class, parent function, and line number.</li>
</ul>

<p dir="auto">IceCream.jl offers a variety of functions:</p>
<ul dir="auto">
<li><code>@ic</code>: Debugging macro to print variable names and their values.</li>
<li><code>@ic_log</code>: Macro for logging with optional color support.</li>
<li><code>ic_configure</code>: Function to configure global settings.</li>
<li><code>ic_configure_color</code>: Set the color of the printed output.</li>
<li><code>ic_configure_single</code>: Configure individual settings.</li>
<li><code>ic_enable</code>: Enable IceCream debugging.</li>
<li><code>ic_disable</code>: Disable IceCream debugging.</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Configuration options</h3><a id="user-content-configuration-options" class="anchor" aria-label="Permalink: Configuration options" href="#configuration-options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>include_context</code>: Enable/disable the inclusion of program context (must be enabled for the following options to take effect).</li>
<li><code>include_datetime</code>: Enable/disable the inclusion of the current date and time.</li>
<li><code>include_absolute_path</code>: Enable/disable the inclusion of the absolute path to the file.</li>
<li><code>include_filename</code>: Enable/disable the inclusion of the filename.</li>
<li><code>include_modulename</code>: Enable/disable the inclusion of the module name.</li>
<li><code>include_methodname</code>: Enable/disable the inclusion of the method name.  (TODO: this is currently unsupported by Julia; instead, pass the method name as the first symbol to <code>@ic</code>; e.g., <code>@ic :myfunc "Hello"</code>.)</li>
<li><code>include_line_number</code>: Enable/disable the inclusion of the line number.</li>
<li><code>include_color</code>: Enable/disable the inclusion of color.</li>
<li><code>new_prefix</code>: Change the prefix used to indicate new output (default: <code>ic| </code>).</li>
<li><code>enabled</code>: Enable/disable IceCream debugging.</li>
</ul>
