<p dir="auto">ParametrisedConvexApproximators.jl focuses on providing predefined approximators
including parameterized convex approximators.
Note that when approximators receive two arguments, the first and second arguments correspond to
parameter and optimization variable, usually denoted by <code>x</code> and <code>u</code>, respectively.</p>
<p dir="auto">Note that the terms of parameter <code>x</code> and optimization variable <code>u</code> are often referred to as condition and decision from the decision-making point of view <sup><a href="#user-content-fn-3-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-3-3-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.</p>
<p dir="auto">Applications include amortized optimization (learning-based parametric optimization) <sup><a href="#user-content-fn-5-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-5-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup>.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Approximators</h3><a id="user-content-approximators" class="anchor" aria-label="Permalink: Approximators" href="#approximators"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">All approximators in ParametrisedConvexApproximators.jl receive two arguments, namely, <code>x</code> and <code>u</code>.
When <code>x</code> and <code>u</code> are vectors whose lengths are <code>n</code> and <code>m</code>, respectively,
the output of an approximator is <strong>one-length vector</strong>.</p>
<ul dir="auto">
<li>Note that <code>x</code> and <code>u</code> can be matrices, whose sizes are <code>(n, d)</code> and <code>(m, d)</code>,
for evaluations of <code>d</code> pairs of <code>x</code>'s and <code>u</code>'s.
In this case, the output's size is <code>(1, d)</code>.</li>
</ul>
</li>
<li>
<p dir="auto">The list of predefined approximators:</p>
<ul dir="auto">
<li><code>FNN::AbstractApproximator</code>: feedforward neural network</li>
<li><code>MA::ConvexApproximator</code>: max-affine (MA) network <sup><a href="#user-content-fn-1-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-1-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup></li>
<li><code>LSE::ConvexApproximator</code>: log-sum-exp (LSE) network <sup><a href="#user-content-fn-1-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-1-2-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup></li>
<li><code>PICNN::ParametrisedConvexApproximator</code>: partially input-convex neural network (PICNN) <sup><a href="#user-content-fn-2-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-2-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">4</a></sup></li>
<li><code>PMA::ParametrisedConvexApproximator</code>: parametrised MA (PMA) network <sup><a href="#user-content-fn-3-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-3-4-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup></li>
<li><code>PLSE::ParametrisedConvexApproximator</code>: parametrised LSE (PLSE) network <sup><a href="#user-content-fn-3-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-3-5-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>
<ul dir="auto">
<li>The default setting is <code>strict = false</code>.</li>
<li><code>PLSEPlus</code> = <code>PLSE</code> with <code>strict=true</code></li>
</ul>
</li>
<li><code>DLSE::DifferenceOfConvexApproximator</code>: difference of LSE (DLSE) network <sup><a href="#user-content-fn-4-b647411e8ed215e4dfa748438dc4b4a8" id="user-content-fnref-4-b647411e8ed215e4dfa748438dc4b4a8" data-footnote-ref="" aria-describedby="footnote-label">5</a></sup></li>
</ul>
</li>
</ul>

<ul dir="auto">
<li><code>(nn::approximator)(x, u)</code> provides the approximate function value.</li>

<ul dir="auto">
<li>The parameter <code>x</code> can be a vector, i.e., <code>size(x) = (n,)</code>,

</ul>

</ul>
