<blockquote>
<p dir="auto">An inline AI code messenger for Pluto.jl notebooks.</p>
</blockquote>
<p dir="auto">This utility provides access to OpenAI models to have julia code generated via a prompt. Code can be returned as formatted text which can be copied or code can be executed.</p>

<ul dir="auto">
<li>At the moment the OpenAI details, i.e., model and API key, are stored in a global variable of type  <code>NamedTuple{(:apikey, :model), Tuple{String, String}}</code>  this isn't optimal, for a few reasons. Will need to come-up with an improved solution.</li>
<li>Since this utility only provides an interface to OpenAI models without any other tooling (i.e., LangChain), a <code>Hermes.INSTRUCT</code> variable is used to guide the AI to focus only on Julia code for Pluto.jl cells. Therefore other inquires may be dubious.</li>
</ul>

<p dir="auto">The current implementation only provides returned messages within the executed cell. The returned messages can be either shown as formatted text (<code>@hermes</code>) or executed (<code>@hermes_exe</code>), but these are tied toth e runtime Pluto cell. What would be ideal is some javascript that would enable the macro calls to place markdown or julia code in a cell below the cell that makes the call request.</p>
<p dir="auto">On another note, only OpenAI api interface is available, but this should be the case for a robust implementation.</p>
