<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Package features</h2><a id="user-content-package-features" class="anchor" aria-label="Permalink: Package features" href="#package-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Build workflows from jobs. Run, monitor, and get results from them.
This package takes inspiration from packages like
<a href="https://github.com/cihga39871/JobSchedulers.jl">JobSchedulers</a> and
<a href="https://github.com/invenia/Dispatcher.jl">Dispatcher</a> (unmaintained).</p>
<p dir="auto">Please <a href="https://doi.org/10.1016/j.cpc.2022.108515" rel="nofollow">cite this package</a> as:</p>
<p dir="auto">Q. Zhang, C. Gu, J. Zhuang et al., <code>express</code>: extensible, high-level workflows for swifter <em>ab initio</em> materials modeling, <em>Computer Physics Communications</em>, 108515, doi: <a href="https://doi.org/10.1016/j.cpc.2022.108515" rel="nofollow">https://doi.org/10.1016/j.cpc.2022.108515</a>.</p>

<p dir="auto">The package can be installed with the Julia package manager.
From <a href="https://docs.julialang.org/en/v1/stdlib/REPL/" rel="nofollow">the Julia REPL</a>, type <code>]</code> to enter
the <a href="https://docs.julialang.org/en/v1/stdlib/REPL/#Pkg-mode" rel="nofollow">Pkg mode</a> and run:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add SimpleWorkflows"><pre>pkg&gt; add SimpleWorkflows</pre></div>
<p dir="auto">Or, equivalently, via <a href="https://pkgdocs.julialang.org/v1/" rel="nofollow"><code>Pkg.jl</code></a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;SimpleWorkflows&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>SimpleWorkflows<span class="pl-pds">"</span></span>)</pre></div>
