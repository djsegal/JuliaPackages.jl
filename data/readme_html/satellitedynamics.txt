<p dir="auto">SatelliteDynamics package is meant to address the needs of the satellite operator, academic researcher, and public enthusiast communities.</p>
<p dir="auto">Current high-fidelity satellite dynamics modeling software generally falls into two camps:</p>
<ol dir="auto">
<li>It is commercially licensed and closed-source code, making it difficult, if not impossible, to be used by hobbyists and academic researchers.</li>
<li>There is a steep learning curve which makes correct use of the underlying libraries difficult.</li>
</ol>
<p dir="auto">These two challenges make it an unfortunately common occurance that guidance, navigation, and control engineers will frequently reimplement common astrodynamics libraries for each new project.</p>
<p dir="auto">With these two deficienties in mind, SatelliteDynamics.jl aims to provide a open-source, MIT-licensed, high fidelity astrodynamics toolbox to help make it easy to perform high-quality simulation and analysis of satellite attitude and orbit dynamics.</p>
