<p dir="auto">This package provides a Julia language wrapper for
<a href="https://github.com/cimgui/cimgui">cimgui</a>: a thin c-api wrapper
programmatically generated for the excellent C++ immediate mode gui <a href="https://github.com/ocornut/imgui">Dear
ImGui</a>. Dear ImGui is mainly for creating
content creation tools and visualization / debug tools. You could browse
<a href="https://github.com/ocornut/imgui/issues/2265" data-hovercard-type="issue" data-hovercard-url="/ocornut/imgui/issues/2265/hovercard">Gallery</a> to get an idea of its
use cases.</p>
