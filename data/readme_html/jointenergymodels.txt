<p dir="auto"><code>JointEnergyModels.jl</code> is a package for training Joint Energy Models in Julia. Joint Energy Models (JEM) are hybrid models that learn to discriminate between classes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4023eae8f6eff08fca05afd9af06cb44">$y$</math-renderer> and generate input data <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4023eae8f6eff08fca05afd9af06cb44">$x$</math-renderer>. They were introduced in Grathwohl et al. (2020), which provides the foundation for the methodologies implemented in this package.</p>

<p dir="auto">This package is still in its infancy and the API is subject to change. Currently, the package can be used to train JEMs for classification. It is also possible to train pure Energy-Based Models (EBMs) for the generative task only. The package is compatible with <code>Flux.jl</code>. Work on compatibility with <code>MLJ.jl</code> (through <code>MLJFlux.jl</code>) is currently under way.</p>
<p dir="auto">We welcome contributions and feedback at this early stage. To install the development version of the package you can run the following command:</p>
