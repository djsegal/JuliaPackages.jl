<p dir="auto"><a href="https://github.com/kagalenko-m-b/ProblemSet.jl/actions"><img src="https://github.com/kagalenko-m-b/ProblemSet.jl/workflows/CI/badge.svg" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">The goal of this project is to facilitate the creation of problem assignments
for a group of students. A problem set consists of several problem templates with
text and placeholder variables. Percentage signs before and after mark the
placeholder variables within the template text. Function <code>problemset_latex()</code>
then generates the latex source of the assignment and solutions for a vector of students'
names.  In the latex source assigned values replace the placeholder variables.
Every placeholder variable must appear at least once as the left-hand of
an assignment where the tilde replaces the equality sign.</p>
<p dir="auto">This is an example set:</p>

<p dir="auto">After execution of this macro, there's a vector in workspace named <code>my_set</code>
that contains three functions <code>my_set_pool()</code>, <code>my_set_addition()</code> and
<code>my_set_subtraction()</code>. Text-generating function makes use of their
<a href="Generated_methods.md">methods</a>. This is how an assignment may be produced:</p>
