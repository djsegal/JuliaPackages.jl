<p dir="auto"><a href="https://github.com/JoshuaBillson/LandsatExplorer.jl">LandsatExplorer</a> is a pure Julia package for querying and downloading Landsat data from the <a href="https://earthexplorer.usgs.gov/" rel="nofollow">USGS Earth Explorer</a> ecosystem.</p>

<p dir="auto"><code>LandsatExplorer</code> needs access to your USGS Earth Explorer credentials in order to query and download
data. These are passed in via the environment variables <code>LANDSAT_EXPLORER_USER</code> and
<code>LANDSAT_EXPLORER_PASS</code>. You can set them manually each time you run your program by calling
<code>authenticate("my_username", "my_password")</code>, or you can set them once in your <code>startup.jl</code> configuration.</p>
