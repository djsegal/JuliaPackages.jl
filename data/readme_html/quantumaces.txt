<p dir="auto"><code>QuantumACES.jl</code> is a package for designing and simulating scalable and performant Pauli noise characterisation experiments for stabiliser circuits with averaged circuit eigenvalue sampling (ACES).
It is particularly interested in characterising the noise associated with fault-tolerant gadgets in the context of topological quantum error correcting codes, such as surface code syndrome extraction circuits.</p>
<p dir="auto">The methods used in this package are detailed in <a href="https://arxiv.org/abs/2404.06545" rel="nofollow">arXiv:2404.06545</a>, and the code generating the data for this paper can be found in the <code>scalable_aces</code> folder on the <a href="https://github.com/evanhockings/QuantumACES.jl/tree/scalable_aces">scalable_aces</a> branch.
These methods build on the original ACES protocol presented in <a href="https://arxiv.org/abs/2108.05803" rel="nofollow">arXiv:2108.05803</a>.
This package relies on <a href="https://github.com/quantumlib/Stim">Stim</a> for stabiliser circuit simulations.</p>

<p dir="auto">To install this package, run the following command in the Julia REPL.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] add QuantumACES"><pre class="notranslate"><code>] add QuantumACES
</code></pre></div>
<p dir="auto">This package relies on the Python package <a href="https://github.com/quantumlib/Stim">Stim</a> to perform stabiliser circuit simulations.
It calls Stim with <a href="https://github.com/JuliaPy/PythonCall.jl">PythonCall</a>.
By default, PythonCall creates its own Python environment, but you may wish to use an existing Python installation.</p>
<p dir="auto">One helpful method for managing Python versions is <a href="https://github.com/pyenv/pyenv">pyenv</a>, or for Windows, <a href="https://github.com/pyenv-win/pyenv-win">pyenv-win</a>; these are analogous to <a href="https://github.com/JuliaLang/juliaup">Juliaup</a> for Julia.
The following assumes you are using pyenv or pyenv-win.</p>
<p dir="auto">On Windows, to instruct PythonCall to use the Python version set by pyenv, configure PythonCall's environment variables by adding the following to your <code>~/.julia/config/startup.jl</code> file</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ENV[&quot;JULIA_CONDAPKG_BACKEND&quot;] = &quot;Null&quot;

<p dir="auto">On Unix systems, shell commands are parsed directly by Julia and appear to be unaware of your PATH variable, and I am not sure how to work around this.
Therefore, you may need to manually supply <code>python_exe</code> for the Python version <code>&lt;version&gt;</code> as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="python_exe = homedir() * &quot;/.pyenv/versions/&lt;version&gt;/bin/python&quot;"><pre>python_exe <span class="pl-k">=</span> <span class="pl-c1">homedir</span>() <span class="pl-k">*</span> <span class="pl-s"><span class="pl-pds">"</span>/.pyenv/versions/&lt;version&gt;/bin/python<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">Then ensure Stim is installed by running <code>pip install stim</code> in your terminal.</p>
