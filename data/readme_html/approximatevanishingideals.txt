<p dir="auto">This package is a toolbox for polynomial feature extraction and transformation using the Oracle Approximate Vanishing Ideal Algorithm.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The Oracle Approximate Vanishing Ideal (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$\texttt{OAVI}$</math-renderer>) algorithm was designed to compute the vanishing ideal of a set of points. Instead of adopting the common approach of using singular value decomposition, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$\texttt{OAVI}$</math-renderer> finds vanishing polynomials by solving a convex optimization problem of the form</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$$\min_{x \in C} f(x),$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$f$</math-renderer> is a differentiable convex function and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$C$</math-renderer> is a compact and convex set.
Usually <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$f$</math-renderer> will be of the form:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$$f(x) = \frac{1}{m}\|Ax + b\|_2^2.$$</math-renderer>

<p dir="auto">We provide built-in oracles that construct the objective function and feasible region and solve the optimization problem with a version of the Frank-Wolfe (conditional gradients) algorithm implemented in <a href="https://github.com/ZIB-IOL/FrankWolfe.jl/tree/master">FrankWolfe.jl</a>. Obtaining a basic feature transformation for some random data <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6baa5e7c6b0af0fad1b206b64f48660c">$X$</math-renderer> is as simple as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ApproximateVanishingIdeals
using Random

X = rand(10000, 5)
X_transformed, sets = fit_oavi(X);"><pre><span class="pl-k">using</span> ApproximateVanishingIdeals
<span class="pl-k">using</span> Random

X <span class="pl-k">=</span> <span class="pl-c1">rand</span>(<span class="pl-c1">10000</span>, <span class="pl-c1">5</span>)
X_transformed, sets <span class="pl-k">=</span> <span class="pl-c1">fit_oavi</span>(X);</pre></div>
<p dir="auto"><code>X_transformed</code> holds the transformed data and <code>sets</code> keeps track of important sets. It is recommended to adjust some keyword arguments for better results. See the <a href="https://zib-iol.github.io/ApproximateVanishingIdeals.jl/dev/how_to_run/" rel="nofollow">examples</a> section for more information.</p>
