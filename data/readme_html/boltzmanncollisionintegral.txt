<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>BoltzmannCollisionIntegral.jl</code> is a <a href="http://julialang.org/" rel="nofollow">Julia</a> package for the evaluation of the relativistic Boltzmann collision integral for binary interactions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e48ffe189ab2fcabfb8c0343d62a5c44">$(12\rightleftharpoons34)$</math-renderer> (see <a href="https://doi.org/10.1093/rasti/rzae036" rel="nofollow">Everett+Cotter 2024</a>):</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e48ffe189ab2fcabfb8c0343d62a5c44">$$C(\boldsymbol{p}_3)=\int\frac{\mathrm{d}^3\boldsymbol{p}_1}{p_1^0}\frac{\mathrm{d}^3\boldsymbol{p}_2}{p_2^0}\frac{\mathrm{d}^3\boldsymbol{p}_4}{p_4^0}\left[\frac{f(\boldsymbol{p}_1)f(\boldsymbol{p}_2)}{1+\delta_{12}}W(p_1^\mu,p_2^\mu|p_3^\mu,p_4^\mu)- \frac{f(\boldsymbol{p}_3)f(\boldsymbol{p}_4)}{1+\delta_{12}}W(p_3^\mu,p_4^\mu|p_1^\mu,p_2^\mu)\right],$$</math-renderer>
<p dir="auto">via momentum discretisation and Monte-Carlo sampling. The distribution functions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e48ffe189ab2fcabfb8c0343d62a5c44">$f(\boldsymbol{p})$</math-renderer> for the particles involved are assumed to be anisotropic (only axisymmetric is currently implemented). The collision integral is split into two components, an emission spectra dictating the rate of gain of particles emerging from a given binary interaction and an absorption spectra dictating the rate of loss of particles from the same interaction.</p>
<p dir="auto">Evaluation is performed by assuming that the distribution function is constant over some set of discrete domains in phase space and then integrating over those domains using a Monte-Carlo method. For more information see the <a href="https://cneverett.github.io/BoltzmannCollisionIntegral.jl/" rel="nofollow">Documentation</a>.</p>
<p dir="auto">Evaluation currently supports both single and multithreaded operation (with multi-CPU acceleration planned). Data is exported in the <a href="https://github.com/JuliaIO/JLD2.jl">JLD2</a> file format.</p>
<p dir="auto">Since v2.0.0 the evaluation of synchrotron emissions from charged particles orbiting a uniform magnetic field directed along the symmetry axis is also supported. This is achieved via the integration of the following:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e48ffe189ab2fcabfb8c0343d62a5c44">$$\left(\frac{\partial f(\boldsymbol{p}_1)}{\partial t}\right)_{Sync}=\frac{Z\mu^2}{B}\frac{3c^5\sigma_Tm_e^5}{4\pi\hbar^3\mu_0e^3}\int\mathrm{d}^3\boldsymbol{p}_2\frac{p_1}{p^0_2}\left[\left(\frac{p^0_2\cos\theta_1-p_2\cos\theta_2\cos\theta_1}{\sin\theta_1}\right)^2J_{\omega/\omega_0}(x)^2+(p_2\sin\theta_2)^2 J'_{\omega/\omega_0}(x)^2\right]f(\boldsymbol{p}_2).$$</math-renderer>

<p dir="auto"><code>BoltzmannCollisionIntegral.jl</code> is available to download from the <a href="https://pkgdocs.julialang.org/v1/" rel="nofollow">Julia package
manager</a>. Inside a Julia session, enter the package manager with <code>]</code>, then run the command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add BoltzmannCollisionIntegral"><pre>pkg<span class="pl-k">&gt;</span> add BoltzmannCollisionIntegral</pre></div>
<p dir="auto">finally load the package by running</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using BoltzmannCollisionIntegral"><pre><span class="pl-k">using</span> BoltzmannCollisionIntegral</pre></div>
<p dir="auto">To perform an evaluation of the emission and absorption spectra, an example script <code>Run_Integration.jl</code> for selecting the binary interaction, discrete phase space bounds and integration conditions is located under the <code>src/Common/</code> folder of the package. It is recommended to copy this script and place it in your working folder and edit the fields as required. Then simply run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="include(&quot;Run_Integration.jl&quot;)"><pre>include("Run_Integration.jl")</pre></div>
<p dir="auto">To perform an evaluation of the synchrotron emission spectra, an example script <code>Run_Integration_Sync.jl</code> for selecting the emitting particle, discrete phase space bounds and integration conditions is located under the <code>src/Synchrotron/Common/</code> folder of the package. It is recommended to copy this script and place it in your working folder and edit the fields as required. Then simply run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="include(&quot;Run_Integration_Sync.jl&quot;)"><pre>include("Run_Integration_Sync.jl")</pre></div>
<p dir="auto">See <a href="https://cneverett.github.io/BoltzmannCollisionIntegral.jl/dev/quickstart/" rel="nofollow">Getting Started</a> for in depth detail.</p>
