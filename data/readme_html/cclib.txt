<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Parsing outputs from 16 different programs: ADF, DALTON, Firefly, GAMESS (US), GAMESS-UK, Gaussian, Jaguar, Molpro, MOLCAS, MOPAC, NWChem, ORCA, Psi4, NBO, QChem and Turbomole.</p>
</li>
<li>
<p dir="auto">Further analysis of calculation outputs, such as population analysis.</p>
</li>
<li>
<p dir="auto">Integration with <a href="https://github.com/JuliaMolSim/AtomsBase.jl">AtomsBase.jl</a> - an interface for atomic geometries.</p>
<ul dir="auto">
<li>By extension, provides interoperability with libraries that use AtomsBase.jl, such as <a href="https://github.com/JuliaMolSim/DFTK.jl">DFTK.jl</a>, <a href="https://github.com/JuliaMolSim/Molly.jl">Molly.jl</a>, and <a href="https://github.com/cesmix-mit/InteratomicPotentials.jl">InteratomicPotentials.jl</a>.</li>
</ul>
</li>
<li>
<p dir="auto">Integration with <a href="https://github.com/FermiQC/Fermi.jl">Fermi.jl</a> - quantum chemistry framework written in Julia.</p>
</li>
</ul>
