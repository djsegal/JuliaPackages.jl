<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://user-images.githubusercontent.com/22669736/231522505-350b23ba-da4e-4c6b-b56f-0e0075a4233c.png"><img src="https://user-images.githubusercontent.com/22669736/231522505-350b23ba-da4e-4c6b-b56f-0e0075a4233c.png" alt="Untitled drawing" style="max-width: 100%;"></a></p>
<p dir="auto">A multithreaded package to validate, curate, and transform large heterogeneous datasets using reproducible recipes, which can be created both in TOML human readable format, or in Julia.</p>
<p dir="auto">A key aim of this package is that recipes can be read/written by any researcher without the need for being able to write code, making data sharing/validation faster, more accurate, and reproducible.</p>
<p dir="auto">DataCurator is a Swiss army knife that ensures:</p>
<ul dir="auto">
<li>pipelines can focus on the algorithm/problem solving</li>
<li>human readable "recipes" for future reproducibility</li>
<li>validation of huge datasets at high speed</li>
<li>out-of-the-box operation without the need for code or dependencies</li>
</ul>
<p dir="auto">DataCurator requires a command-line interface and is supported on Linux, Windows Subsystem for Linux (WSL2), and MacOS. See <a href="https://github.com/bencardoen/DataCurator.jl/blob/main/README.md#quickstart-with-singularity">Quickstart</a> and <a href="https://github.com/bencardoen/DataCurator.jl/blob/main/docs/src/installation.md">Installation</a> for detail.</p>
