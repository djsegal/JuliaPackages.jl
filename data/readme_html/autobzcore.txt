<p dir="auto">This package provides a common interface to integration algorithms that are
efficient and high-order accurate for computational tasks including
Brillouin-zone integration and Wannier interpolation. For further information on
integrand interfaces, including optimizations for Wannier interpolation, please see <a href="https://lxvm.github.io/AutoBZCore.jl/stable/" rel="nofollow">the
documentation</a>.</p>
