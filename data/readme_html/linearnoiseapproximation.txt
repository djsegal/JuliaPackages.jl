<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Purpose</h2><a id="user-content-purpose" class="anchor" aria-label="Permalink: Purpose" href="#purpose"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides a numerical method to automatically deriving the linear
noise approximation (LNA) for a given stochastic reaction network (SRN) using
<a href="https://github.com/SciML/Catalyst.jl">Catalyst.jl</a>. SRNs have proven their
flexibility beyond chemical systems and across many different fields. These
include biochemistry with gene expression models, epidemiology with
compartmental models, ecology with the Lotka-Volterra equations, condensed
matter and semiconductor physics with diffusion processes, and even sociology.
The derived expanded system can be solved using
<a href="https://github.com/JuliaDiffEq/DifferentialEquations.jl">DifferentialEquations.jl</a>.</p>

moment-based approximation method for stochastic chemical kinetics. For

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Brief introduction to linear noise approximation</h2><a id="user-content-brief-introduction-to-linear-noise-approximation" class="anchor" aria-label="Permalink: Brief introduction to linear noise approximation" href="#brief-introduction-to-linear-noise-approximation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">LNA is a moment-based approximation method for stochastic chemical kinetics
<a href="#1">[1]</a>. A general chemical kinetics reaction can be described as follows:
given a set of chemical species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$X_{i}, i = 1, \ldots, N$</math-renderer>, we define <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$R$</math-renderer>
chemical reactions by the notation</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\begin{equation}
        k_r:\sum_{i=1}^{N}s_{ir}X_{i} \rightarrow
        \sum_{i=1}^{N}s'_{ir}X_{i}, \tag{1}
\end{equation}$$</math-renderer>
<p dir="auto">where the stoichiometric coefficients <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$s_{ir}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$s'_{ir}$</math-renderer> are non-negative
integer numbers denoting the numbers of reactant and product molecules,
respectively. The quantity <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$k_r$</math-renderer> in Equation (1) is called the reaction rate
constant of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$r$</math-renderer>-th reaction. Classically, the dynamics of a chemical
reaction system as in Equation (1) is modelled by the law of mass action. The
law of mass action states that the rate of a reaction is proportional to the
product of the concentrations of reactant molecules, which lead to the
following rate equations as:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\begin{equation}
    \frac{\mathrm{d}}{\mathrm{dt}} \phi_i =
    \sum_{r=1}^{R} S_{ir} g_r(\boldsymbol{\phi}), \tag{2}
\end{equation}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\phi_i$</math-renderer> is the concentration of species <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$X_i$</math-renderer>,</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\boldsymbol{S} = \{S_{ir}\}_{N\times R},\;
S_{ir}=s'_{ir} - s_{ir},\;
i=1,\ldots,N,\; r=1,\ldots,R \notag$$</math-renderer>
<p dir="auto">is the stoichiometric matrix, and</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$g_r(\boldsymbol{\phi}) = k_r \prod_{i=1}^{N} \phi_i^{s_{ir}},$$</math-renderer>
<p dir="auto">is the rate of the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$r$</math-renderer>-th reaction.</p>
<p dir="auto">However, the law of mass action is only valid when the number of molecules is
large. When the number of molecules is small, System (1) can instead be
modelled by a continuous-time Markov jump process to study the probability of
the system being in a particular state at a given time. The dynamics of such a
system can be described by the chemical master equation (CME) <a href="#2">[2]</a>:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\begin{equation}
    \begin{aligned}
        \frac{\mathrm{d}}{\mathrm{dt}} P(\boldsymbol{n}, t) =
        \sum_{r=1}^{R} f_r(\boldsymbol{n} -
        \mathbf{S}_r, t) P(\boldsymbol{n} -
        \mathbf{S}_r, t) -
        \sum_{r=1}^{R} f_r(\boldsymbol{n}, t) P(\boldsymbol{n}, t), \notag
    \end{aligned}
\end{equation}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$P(\boldsymbol{n}, t)$</math-renderer> is the probability of the system being in state
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\boldsymbol{n}$</math-renderer> at time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$t$</math-renderer>,</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$f_r(\boldsymbol{n}, t) =
k_r\Omega \prod_{i=1}^{N} \frac{n_i!}{(n_i-s_{ir})!\Omega^{s_{ir}}}$$</math-renderer>
<p dir="auto">is the propensity function of reaction <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$r$</math-renderer> at state <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\boldsymbol{n}$</math-renderer>, and
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\mathbf{S}_r$</math-renderer> is the stoichiometric vector of reaction <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$r$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\Omega$</math-renderer> is the
system size (or volume of the system).</p>
<p dir="auto">The chemical master equation is written directly from the rate constants and
stoichiometries of all the elementary reactions of a chemical system, but
neither analytical nor numerical solutions are in general available.
Fortunately, the chemical master equation can often be simplified in a linear
noise approximation. Linear noise approximation is an expansion of the CME
taking the inverse system size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$1/\Omega$</math-renderer> as the perturbed variable, which is
originally developed by <a href="#3">[3]</a>. The idea is to separate concentrations into
a deterministic part, given by the solution of the deterministic rate
equations, and a part describing the fluctuations about the deterministic mean</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\frac{n_i}{\Omega} = \phi_i  + \Omega^{-1/2} \epsilon_i,$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\phi_i$</math-renderer> is the solution of the deterministic rate equations (2), and
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\epsilon_i$</math-renderer> represents fluctuations about the deterministic mean. Define
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\boldsymbol{\Sigma}=\left(\epsilon_{ij}\right)_{N\times N}$</math-renderer> to be the
covariance matrix of the fluctuations, the linear noise approximation is given
by:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\begin{equation}
    \partial_t \boldsymbol{\Sigma} =
    \mathbf{A} \boldsymbol{\Sigma} +
    \boldsymbol{\Sigma} \mathbf{A}^T +
    \Omega^{-1} \mathbf{B}, \tag{3}
\end{equation}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\mathbf{A}=\mathbf{A}(\boldsymbol{\phi}),,
\mathbf{B}=\mathbf{B}(\boldsymbol{\phi})$</math-renderer> both depend on the solution
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$\boldsymbol{\phi}$</math-renderer> of the rate equation \eqref{eq:rate_equations}, which are
defined by</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\mathbf{A} = \left(A_{ij}\right)_{N\times N},
 A_{ij}=\sum_{r=1}^{R} S_{ir}\partial_{\phi_j}g_r(\boldsymbol{\phi}),$$</math-renderer>
<p dir="auto">as the Jacobian matrix of the deterministic rate equations, and</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="b2f3efaa3209599cb09dc362157a47a1">$$\mathbf{B} =\left(B_{ij}\right)_{N\times N}, B_{ij} =
\sum_{r=1}^{R} S_{ir}S_{jr}g_r(\boldsymbol{\phi}).$$</math-renderer>
<p dir="auto">In this formulation, the LNA allows for analytical solutions that are locally
valid close to macroscopic trajectories (solution of the rate equations) of
the system. We refer to the review paper <a href="#2">[2]</a> for more details on the CME
and LNA.</p>
