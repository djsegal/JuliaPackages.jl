<p dir="auto"><code>SumOfExpVPMR.jl</code> is a <code>Julia</code> implentation the VPMR method by Zixuan Gao, Jiuyang Liang and Zhenli Xu in <a href="https://link.springer.com/10.1007/s10915-022-01999-1" rel="nofollow">A Kernel-Independent Sum-of-Exponentials Method</a>, which can be used to represent rapid decaying kernels via sum of exponentials.</p>

<p dir="auto">The SOE approach is quite useful since the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d95a08853c62e457275dbd3b67a21986">$\exp(\cdot)$</math-renderer> function is easy to be handled.
One of the most important usage is called the fast exponential transform (FET), which can be used to calculate the summation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d95a08853c62e457275dbd3b67a21986">$\sum_{i,j} q_{1}^{i} q_{2}^{j}  f \left( α^{-1} |x_i - x_j| \right)$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d95a08853c62e457275dbd3b67a21986">$O(N)$</math-renderer> steps.
For details, please see the implentation in <code>src/fast_exp_transform.jl</code>.
Here we compare the cost of calculating <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d95a08853c62e457275dbd3b67a21986">$\sum_{i,j} q_{1}^{i} q_{2}^{j} \exp \left( -(x_i - x_j)^2 \right)$</math-renderer> directly and via FET, as shown in fig below.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="examples/FET.png"><img src="examples/FET.png" alt="" style="max-width: 100%;"></a></p>
