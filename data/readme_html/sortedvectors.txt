<p dir="auto">The only exported symbol is <code>SortedVector</code>. Use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="SortedVector([lt=isless], xs)"><pre><span class="pl-c1">SortedVector</span>([lt<span class="pl-k">=</span>isless], xs)</pre></div>
<p dir="auto">to sort <code>xs</code> and save the result in a vector. <code>xs</code> can be any <code>&lt;: AbstractVector</code>. For immutable types (eg <code>StaticArrays.SVector</code> or <code>UnitRange</code>), <code>setindex!</code> will not work.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Special constructors for checking or skipping sorting</h3><a id="user-content-special-constructors-for-checking-or-skipping-sorting" class="anchor" aria-label="Permalink: Special constructors for checking or skipping sorting" href="#special-constructors-for-checking-or-skipping-sorting"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If your code emits sorted vectors, use the</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="SortedVector(SortedVectors.AssumeSorted(), lt, sorted_contents)"><pre><span class="pl-c1">SortedVector</span>(SortedVectors<span class="pl-k">.</span><span class="pl-c1">AssumeSorted</span>(), lt, sorted_contents)</pre></div>
<p dir="auto">constructor. This will skip checks.</p>
<p dir="auto">If your API accepts sorted vectors, and you want to check them, use the</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="SortedVector(SortedVectors.CheckSorted(), lt, sorted_contents)"><pre><span class="pl-c1">SortedVector</span>(SortedVectors<span class="pl-k">.</span><span class="pl-c1">CheckSorted</span>(), lt, sorted_contents)</pre></div>
<p dir="auto">constructor.</p>
<p dir="auto"><strong>In either case, you are responsible for ensuring that the argument vector is not modified later on. <code>copy</code> if you are unsure.</strong></p>
