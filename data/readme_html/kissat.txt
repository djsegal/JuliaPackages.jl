<p dir="auto">This is a user interface, in Julia, to the <a href="https://github.com/arminbiere/kissat">Kissat</a> SAT solver.</p>
<p dir="auto">It exposes all the functions of the C interface, in the same syntax but without the <code>kissat_</code>, and provides higher-level interfaces:</p>
<ul dir="auto">
<li>A <code>RawSolver</code> object with <code>init</code>, <code>push!</code>, <code>append!</code>, <code>solve</code> and <code>values</code> methods</li>
<li>a one-stop-shop <code>kissat</code> accepting a list of clauses</li>
<li>a solver accepting arbitrary types and converting them to integer variables through a <code>Dict</code>. Variables can have any type except <code>Pair{T,Bool}</code>, and are indicated either as <code>T</code> or as <code>T =&gt; false</code> to indicate a negated variable. Clauses are either <code>Vector</code> with entries in <code>T</code> or <code>Pair{T,Bool}</code>, or special shortcuts <code>Pair{T / NTuple{N,T} / Vector{T},T / false}</code> for Horn clauses.</li>
</ul>
