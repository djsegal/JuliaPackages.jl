<p dir="auto">The <code>StripRTF</code> module exports a single function, <a href="@ref"><code>striprtf(text)</code></a>, that
strips all formatting from a string in <a href="https://en.wikipedia.org/wiki/Rich_Text_Format" rel="nofollow">Rich Text Format (RTF)</a>
to yield "plain text".</p>
<p dir="auto">This code is a Julia port of the Python <a href="https://github.com/joshy/striprtf"><code>striprtf</code> package</a> by
Joshy Cyriac, which in turn is based on <a href="https://stackoverflow.com/questions/188545/regular-expression-for-extracting-text-from-an-rtf-string" rel="nofollow">code posted to StackOverflow</a>
by Markus Jarderot and Gilson Filho.</p>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="striprtf([out::IO,] text::AbstractString)"><pre><span class="pl-c1">striprtf</span>([out<span class="pl-k">::</span><span class="pl-c1">IO</span>,] text<span class="pl-k">::</span><span class="pl-c1">AbstractString</span>)</pre></div>
<p dir="auto">Given a string <code>text</code> in <a href="https://en.wikipedia.org/wiki/Rich_Text_Format" rel="nofollow">Rich Text Format (RTF)</a>,
returns a string of "plain text" with all of the RTF formatting removed.</p>
<p dir="auto">If the optional <code>out</code> argument is supplied, the output is instead written
to this output <code>IO</code> stream, returning <code>out</code>.</p>
