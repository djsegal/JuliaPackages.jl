<p dir="auto">This package contains one main function <code>yao2einsum(circuit; initial_state=Dict(), final_state=Dict(), optimizer=TreeSA())</code>.
It transform a <a href="https://github.com/QuantumBFS/Yao.jl"><code>Yao</code></a> circuit to a generalized tensor network (einsum notation).  The return value is a <code>TensorNetwork</code> object.</p>
<ul dir="auto">
<li><code>initial_state</code> and <code>final_state</code> are for specifying the initial state and final state.
If any of them is not specified, the function will return a tensor network with open legs.</li>
<li><code>optimizer</code> is for optimizing the YaoToEinsum.contraction order of the tensor network. The default value is <code>TreeSA()</code>. Please check the README of <a href="https://github.com/TensorBFS/OMEinsumYaoToEinsum.contractionOrders.jl">OMEinsumYaoToEinsum.contractors.jl</a> for more information.</li>
</ul>
