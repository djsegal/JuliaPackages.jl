<p dir="auto">Huginn.jl is a package containing all the glacier ice flow models and solvers for <a href="https://github.com/ODINN-SciML/ODINN.jl">ODINN.jl</a>. It also provides an accessible API to be easily used by other glacier models, such as the Open Global Glacier Model (<a href="https://github.com/OGGM/oggm">OGGM</a>). This enables OGGM to access the high-performance glacier ice flow solvers in Julia in a seamless manner, via JuliaCall and PyCall.jl.</p>
