<ul dir="auto">
<li>Uses GLMakie's GPU based rendering for fast rendering of large voxel worlds</li>
<li>Uses Julia's multithreading for various tasks</li>
<li>Utilizes Coherent Noise Library for generating terrain</li>
<li>Can be used as testing ground for image processing and computer vision tasks</li>
<li>Has a inbuilt music player using Channels and playing audio with WAV.jl</li>
</ul>
