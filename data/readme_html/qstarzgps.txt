<p dir="auto">Package to load GPS logs from a Qstarz GPS logger into Julia</p>
<p dir="auto"><a href="https://github.com/lwabeke/QstarzGPS.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/lwabeke/QstarzGPS.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">Qstarz(<a href="http://www.qstarz.com/" rel="nofollow">http://www.qstarz.com/</a>)  produces a number of GPS logger units, which are used in various applications, primarily for racing to record the car position on the track. The author has used some of these loggers to instrument various objects to provide a ground truth of where they moved when observing from the various sensors.</p>
<p dir="auto">Qstarz provides (at the time this was created Windows-based) tools to extract and analise the recorded GPS logs, particulary for the case of performing repeated circuits on a racing track with the option to export to CSV files. In the author's experiments it was more useful to get the data directly into Julia for analisis and this allows cross-portable OS usage.</p>
<p dir="auto">This package provides funtionality to reads a QStarz binary log file produced by the BL-1000GT logger in the SESSION\GPSLog\ folder on its internal memory into a array of structure object, which is overloaded to be able to be accessed as structure of arrays.</p>
<p dir="auto">Steps to use:</p>
<ol dir="auto">
<li>Install Julia and this package</li>
<li>Turn on the BL-1000GT to record positions, while being carried in a pocket or strapped to a vehicle.</li>
<li>Ensure that the BL-1000GT is turned off to save the recording</li>
<li>Connect to the BL-1000GT using USB</li>
<li>Locate the recording in the folder SESSION\GPSLog\ on the device after it has mounted
There will have 3 files generated at the same time when device was turned on and saved when device was turned off.
Bin File Name : *.bin (session.bin / session.poi – log POI waypoint ONLY)</li>
<li>Note the filename of the session of interest and load into Julia using the command readQstarzLog</li>
</ol>
<p dir="auto">The filename is the date and time of the start of the session. The code in the package has thus far only been tested with the *.bin files</p>
