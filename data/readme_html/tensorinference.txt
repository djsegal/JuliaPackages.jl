<p dir="auto">
TensorInference is an open source  
    <a href="https://julialang.org" rel="nofollow">
        <img src="https://raw.githubusercontent.com/JuliaLang/julia-logo-graphics/master/images/julia.ico" width="16em" style="max-width: 100%;">
        Julia
    </a>
  package for probabilistic inference over discrete graphical models. It
leverages tensor-based technology for efficiently solving various inference
tasks.
</p>

<p dir="auto">TensorInference supports finding solutions to the most common <a href="https://uaicompetition.github.io/uci-2022/competition-entry/tasks/" rel="nofollow">probability
inference
tasks</a> of
the <a href="https://uaicompetition.github.io/uci-2022/" rel="nofollow">UAI inference competitions</a>,
which include:</p>
<ul dir="auto">
<li><strong>PR</strong>: The partition function or probability of evidence</li>
<li><strong>MAR</strong>: The marginal probability distribution over all variables
given evidence</li>
<li><strong>MAP</strong>: The most likely assignment to all variables given evidence</li>
<li><strong>MMAP</strong>: The most likely assignment to the query variables after
marginalizing out the remaining variables</li>
</ul>
