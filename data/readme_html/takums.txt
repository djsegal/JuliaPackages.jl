<p dir="auto">This package implements <a href="https://arxiv.org/abs/2404.18603" rel="nofollow">takum arithmetic</a>, a new tapered
precision machine number format. Four new data types are defined, namely
<code>Takum8</code>, <code>Takum16</code>, <code>Takum32</code> and <code>Takum64</code>. Internally the reference C99 library
<a href="https://github.com/takum-arithmetic/libtakum">libtakum</a> is used for the
actual computations for the most part.</p>
<p dir="auto">Using this package one is able to evaluate takums for real-world applications
in terms of precision. Given it is a software implementation the performance
is overall worse than the respective usual IEEE 754 floating-point hardware
implementations.</p>

<p dir="auto">The four takum number types <code>Takum8</code>, <code>Takum16</code>, <code>Takum32</code> and <code>Takum64</code>
have been implemented to behave as much as any built-in floating-point
type. They are subtypes of <code>AbstractFloat</code> even though takum itself
is strictly speaking not a floating-point number format, but a
logarithmic number system. However, as the majority of numerical code is
written to accept <code>AbstractFloat</code>s rather than <code>Real</code>s and takums share
many properties of a typical floating-point number system, this decision
was made deliberately and for good reasons.</p>
