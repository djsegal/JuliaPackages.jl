<p dir="auto">The MDP package currently implements the following algorithms</p>
<ul dir="auto">
<li>
<p dir="auto"><strong>Infinite horizon discounted setup</strong></p>
<ul dir="auto">
<li>Value iteration</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Finite horizon setup</strong></p>
<ul dir="auto">
<li>Standard dynamic program</li>
</ul>
</li>
</ul>
<p dir="auto">Other algorithms related to MDPs will be implemented as time permits. Pull
requests welcome.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Specifying a model</h2><a id="user-content-specifying-a-model" class="anchor" aria-label="Permalink: Specifying a model" href="#specifying-a-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">There are two ways to specify the MDP model:</p>
<ol dir="auto">
<li>
<p dir="auto">By specifying the controlled transition matrix and the cost and reward
function.</p>
</li>
<li>
<p dir="auto">By specifying the bellman update operator.</p>
</li>
</ol>
<p dir="auto">Perhaps the easiest way to understand these is by means of examples.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Specifying a model: probabilistic method</h3><a id="user-content-specifying-a-model-probabilistic-method" class="anchor" aria-label="Permalink: Specifying a model: probabilistic method" href="#specifying-a-model-probabilistic-method"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><em>This example is taken from Puterman, "Markov Decision Processes", Wiley 2005
(Chapter 3.1)</em></p>
<p dir="auto">Consider a Markov decision process where</p>
<ul dir="auto">
<li>
<p dir="auto"><strong>States</strong>  S = {1, 2}</p>
</li>
<li>
<p dir="auto"><strong>Actions</strong> A = {1, 2}</p>
</li>
<li>
<p dir="auto"><strong>Rewards</strong> r(s,a) given by</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="r(1,1) = 5      r(1,2) = 10
r(2,1) = -1     r(2,2) = -Inf"><pre class="notranslate"><code>r(1,1) = 5      r(1,2) = 10
r(2,1) = -1     r(2,2) = -Inf
</code></pre></div>
<p dir="auto">Note that <code>r(2,2) = -Inf</code> means that action 2 is infeasible at state 2.</p>
</li>
<li>
<p dir="auto"><strong>Transition probabilities</strong> P(s_next | s_current, action)</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="  P(1 | 1, 1) = 0.5       P(2 | 1, 1) = 0.5
  P(1 | 2, 1) = 0.0       P(2 | 2, 1) = 1.0

  P(1 | 1, 2) = 0.0       P(2 | 1, 2) = 1.0
  P(1 | 2, 2) = 0.5       P(2 | 2, 2) = 0.5"><pre class="notranslate"><code>  P(1 | 1, 1) = 0.5       P(2 | 1, 1) = 0.5
  P(1 | 2, 1) = 0.0       P(2 | 2, 1) = 1.0

  P(1 | 1, 2) = 0.0       P(2 | 1, 2) = 1.0
  P(1 | 2, 2) = 0.5       P(2 | 2, 2) = 0.5
</code></pre></div>
</li>
</ul>
<p dir="auto">This model is specified as follows:</p>
<ul dir="auto">
<li>
<p dir="auto">Specify the rewards as a <code>S x A</code> matrix.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="r = [ 5  10
     -1  -Inf]"><pre>r <span class="pl-k">=</span> [ <span class="pl-c1">5</span>  <span class="pl-c1">10</span>
     <span class="pl-k">-</span><span class="pl-c1">1</span>  <span class="pl-k">-</span><span class="pl-c1">Inf</span>]</pre></div>
</li>
<li>
<p dir="auto">Specify the transition matrix as a list <code>{ P( . | ., 1), P( . | ., 2) }</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="P = Matrix[ [ 0.5  0.5 
              0.0  1.0 ],
            [ 0.0  1.0
              0.5  0.5 ] ]"><pre>P <span class="pl-k">=</span> Matrix[ [ <span class="pl-c1">0.5</span>  <span class="pl-c1">0.5</span> 
              <span class="pl-c1">0.0</span>  <span class="pl-c1">1.0</span> ],
            [ <span class="pl-c1">0.0</span>  <span class="pl-c1">1.0</span>
              <span class="pl-c1">0.5</span>  <span class="pl-c1">0.5</span> ] ]</pre></div>
<p dir="auto">This list may also be specified as a sparse matrix (this can lead to
considerable speedup when the transition matrices are sparse)</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using SparseArrays
P = SparseMatrixCSC[sparse([0.5 0.5; 0.0 1.0]),
                    sparse([0.0 1.0; 0.5 0.5]) ]"><pre class="notranslate"><code>using SparseArrays
P = SparseMatrixCSC[sparse([0.5 0.5; 0.0 1.0]),
                    sparse([0.0 1.0; 0.5 0.5]) ]
</code></pre></div>
</li>
<li>
<p dir="auto">Specify an MDP model</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="model = ProbModel(r, P; objective=:Max)"><pre>model <span class="pl-k">=</span> <span class="pl-c1">ProbModel</span>(r, P; objective<span class="pl-k">=</span><span class="pl-c1">:Max</span>)</pre></div>
<p dir="auto"><code>objective=:Max</code> specifies that we want to maximize reward. To minimize a
cost function, use <code>objective=:Min</code>.</p>
</li>
</ul>
<p dir="auto">To solve this model using value iteration use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(v,g) = valueIteration(model; discount=0.95)"><pre>(v,g) <span class="pl-k">=</span> <span class="pl-c1">valueIteration</span>(model; discount<span class="pl-k">=</span><span class="pl-c1">0.95</span>)</pre></div>
<p dir="auto"><code>v</code> is the value function (stored as a <code>S</code> dimensional vector) nad <code>g</code> is the
policy (again, stored as a <code>S</code> dimensional vector).</p>
<p dir="auto">The optimal arguments for <code>valueIteration</code> are</p>
<ul dir="auto">
<li>
<p dir="auto"><code>discount</code> (default <code>0.95</code>): The discount factor.</p>
</li>
<li>
<p dir="auto"><code>iterations</code> (default <code>1_000</code>): The maximum number of iteration to be
perfermoed.</p>
</li>
<li>
<p dir="auto"><code>tolerance</code> (default <code>1e-4</code>): Stop the iteration when sup-norm of <code>v - v_opt</code>
is less than <code>tolerance</code>, where <code>v_opt</code> is the optimal solution.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="To speed up convergence, we use span seminorm and do a correction before
returning the value function. See Puterman Sec 6.6 for details. "><pre class="notranslate"><code>To speed up convergence, we use span seminorm and do a correction before
returning the value function. See Puterman Sec 6.6 for details. 
</code></pre></div>
</li>
<li>
<p dir="auto"><code>intial_v</code> (default, an all zeros-vector).</p>
</li>
</ul>
<p dir="auto">Here is the full example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MDP

P = Matrix[ [ 0.5  0.5 
              0.0  1.0 ],
            [ 0.0  1.0
              0.5  0.5 ] ]

r = [ 5  10
     -1  -Inf ]

model = ProbModel(r, P; objective=:Max)

(v,g) = valueIteration(model; discount=0.95)

println(g)
println(v)"><pre><span class="pl-k">using</span> MDP

            [ <span class="pl-c1">0.0</span>  <span class="pl-c1">1.0</span>
              <span class="pl-c1">0.5</span>  <span class="pl-c1">0.5</span> ] ]

r <span class="pl-k">=</span> [ <span class="pl-c1">5</span>  <span class="pl-c1">10</span>
     <span class="pl-k">-</span><span class="pl-c1">1</span>  <span class="pl-k">-</span><span class="pl-c1">Inf</span> ]

model <span class="pl-k">=</span> <span class="pl-c1">ProbModel</span>(r, P; objective<span class="pl-k">=</span><span class="pl-c1">:Max</span>)

(v,g) <span class="pl-k">=</span> <span class="pl-c1">valueIteration</span>(model; discount<span class="pl-k">=</span><span class="pl-c1">0.95</span>)

<span class="pl-c1">println</span>(g)
<span class="pl-c1">println</span>(v)</pre></div>
