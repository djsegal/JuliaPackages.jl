<p dir="auto">BioCore.jl provides core definitions that are common to all or many packages
in the BioJulia ecosystem.</p>
<p dir="auto">It also includes a definition of a common IO interface for IO of Bioinformatics
formats in BioJulia packages, and includes some helper functions for generating
file parsers from state machine automata with Automa.jl</p>

issues, improving performance and adding new features.</p>
