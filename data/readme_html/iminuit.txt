<p dir="auto">Julia wrapper of the Python package <a href="https://github.com/scikit-hep/iminuit"><code>iminuit</code></a>, which is the interface to the C++ MINUIT2, widely used in fitting in the high-energy physics community.
Supported <code>iminuit</code> versions: 2.0.0 or later</p>
<p dir="auto">The <code>minuit</code> object in <code>iminuit</code> is defined as an <code>AbstractFit</code>:
if using array parameters, then <code>ArrayFit</code>;
if using individual parameters, then <code>Fit</code>.</p>
<p dir="auto">Install by <code>]add https://github.com/fkguo/IMinuit.jl</code></p>
<blockquote>
<p dir="auto">Remember to point your <code>pycall</code> to the python enviroment where <code>iminuit</code> is installed, then build your <code>pycall</code>. For more information, please refer to the <a href="https://github.com/JuliaPy/PyCall.jl">PyCall</a> documentation.</p>
</blockquote>
