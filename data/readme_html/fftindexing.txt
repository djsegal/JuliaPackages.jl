<p dir="auto">A package providing types that assist with indexing objects in a manner that allows for convenient
interpretation of the results of Fourier transforms.</p>

<p dir="auto">The <code>FFTIndex</code> object serves a purpose analogous to Julia's <code>CartesianIndex</code>, but uses the frequency
bins generated by a Fourier transform instead of the provided array indices. This means there are
two key differences: <code>FFTIndex</code> <em>always</em> provides zero-based indexing for an array, and it
guarantees an inbounds array access due to the periodic boundary conditions assumed by the Fourier
transform. For <code>AbstractArray</code> instances, the exclusive use of <code>FFTIndex</code> for indexing will remove
the bounds check - no <code>@inbounds</code> annotation needed.</p>
<p dir="auto">The <code>FFTAxis</code> object serves a purpose analogous to <code>Base.OneTo</code>, and represents the frequency bins
generated by a Fourier transform. The <code>FFTAxis</code> objects associated with an indexable object <code>A</code> can
be generated with <code>fftaxes(A)</code>.</p>
<p dir="auto">The <code>FFTIndices</code> object serves a purpose analogous to <code>CartesianIndices</code>, and can be constructed
from a <code>Tuple</code> of integers representing sizes or ranges representing axes, or from the indexable
object directly.</p>
