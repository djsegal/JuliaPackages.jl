<p dir="auto">This is a package for efficiently measuring n-point correlators of matrix product states (MPS), built on top of the <a href="https://github.com/ITensor/ITensors.jl">ITensors.jl</a> and <a href="https://github.com/ITensor/ITensorMPS.jl">ITensorMPS.jl</a> libraries.</p>

<p dir="auto">As an example, to compute the correlator <code>&lt;Sz_i Sz_j Sz_k Sz_l&gt;</code> on some set of sites <code>i, j, k, l</code>, you can use the <code>correlator</code> function:</p>

<p dir="auto">Note that currently, when fermionic sites are being used, this package does not handle the case of mixed <code>A</code>- and <code>C</code>-operators acting on the same sites properly (i.e. it doesn't handle inputs <code>(2, 3, 3, 5)</code> properly for <code>("Adagdn", "Adagup", "Cup", "Cdn")</code>, say compared to how that operator would be constructed in the <code>OpSum</code> to <code>MPO</code> converter in ITensorMPS.jl). This is not very common, and generally users should just use <code>C</code>-operators if they want to compute correlators involving fermionic creation and annhilation operators. When <code>C</code>-operators are used with fermionic sites the <code>correlator</code> function will automatically insert the correct Jordan-Wigner strings to handle fermionic statistics.</p>
