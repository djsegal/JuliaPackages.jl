<p dir="auto">This Julia package implements <a href="https://en.wikipedia.org/wiki/Hermite_interpolation" rel="nofollow">Hermite interpolation</a>. It takes a list of interpolation points <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d8feb7e70957dfa8769681cd348d46d">$[x_1, x_2, …, x_n]$</math-renderer> and corresponding labels for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d8feb7e70957dfa8769681cd348d46d">$y(x)$</math-renderer>. Derivative data <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d8feb7e70957dfa8769681cd348d46d">$d^j y/dx^j$</math-renderer> may also be provided up to arbitrary order, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d8feb7e70957dfa8769681cd348d46d">$j = 1, …, m-1$</math-renderer>. Hermite interpolation yields the unique polynomial less than order <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d8feb7e70957dfa8769681cd348d46d">$m n$</math-renderer> that exactly matches the data. Without derivatives, the method is known as Lagrange interpolation.</p>

<p dir="auto">The interpolation function can be evaluated on any type that supports addition and multiplication. For example, <a href="https://github.com/JuliaAlgebra/DynamicPolynomials.jl">DynamicPolynomials.jl</a> can build the polynomial symbolically:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DynamicPolynomials

f_sym = f(X)
# -107.421875 + 246.09375X - 215.625X² + 91.25X³ - 18.75X⁴ + 1.5X⁵

fp_sym = differentiate(f_sym, X)
# 246.09375 - 431.25X + 273.75X² - 75.0X³ + 7.5X⁴

@assert f_sym(1.5) ≈ 1
@assert fp_sym(1.5) ≈ 0"><pre><span class="pl-k">using</span> DynamicPolynomials
