<p dir="auto">Astrodynamics.jl is archived and will not be developed further. A well-maintained alternative in Julia is <a href="https://github.com/JuliaSpace/SatelliteToolbox.jl">SatelliteToolbox.jl</a>.
I (<a href="https://github.com/helgee">@helgee</a>) am working on <a href="https://github.com/lox-space/lox">Lox</a> which is a Rust-based library with a Python interface for interactive use.</p>
