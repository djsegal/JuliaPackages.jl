<p dir="auto">A Julia package for generating Generalized Morse Wavelets (GMW) (see
e.g. (Lilly and Olhede 2012)) and their derivatives.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Theory</h2><a id="user-content-theory" class="anchor" aria-label="Permalink: Theory" href="#theory"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The first order Generalized Morse Wavelets are defined in frequency by:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$$\widehat{\psi}_{a,u,\beta,\gamma}(w) = C_{a,\beta,\gamma}\, (aw)^\beta \exp \left( -(aw)^\gamma -iwu \right)$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$C_{a,\beta,\gamma}$</math-renderer> is a normalization constant, usually a L2
normalization or a frequency peak normalization, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$a$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$u$</math-renderer> are scaling
and translation parameters and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\beta$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\gamma$</math-renderer> are shape
parameters.</p>
<p dir="auto">In practice, Generalized Morse Wavelest can be used to compute
continuous wavelet transforms. Given a signal <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$x$</math-renderer>, its wavelet
coefficients <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\tilde{x}_{a,u}$</math-renderer> are computed at each scale <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$a$</math-renderer> and time
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$u$</math-renderer> with fixed shape parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\beta$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\gamma$</math-renderer> (generally it is
recommended to choose <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\beta$</math-renderer>=1 and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\gamma$</math-renderer>=3 as it gives the wavelet a
good localization in time-frequency space, almost a gaussian-like
localisation, see (Lilly and Olhede 2012) and references therein).</p>
<p dir="auto">The wavelet coefficient of a signal <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$x$</math-renderer> at scale <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$a$</math-renderer> and time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$u$</math-renderer> is
then simply computed using:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$$\tilde{x}[a,u] = \langle x,\psi_{a,u,\beta,\gamma} \rangle$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\psi_{a,u,\beta,\gamma}$</math-renderer> is the wavelet in time.</p>
<p dir="auto">This package also provide Generalized Morse Wavelets at higher order,
although their use is more limited as their properties in frequency are
not yet well understood for varying shape parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\beta$</math-renderer> and
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$\gamma$</math-renderer><sup><a href="#user-content-fn-1-bb9e52cc0485d1c9ec65d795225d0e4f" id="user-content-fnref-1-bb9e52cc0485d1c9ec65d795225d0e4f" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>. For more information, see (Lilly and Olhede 2012).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To generate the analytic part of a first order <code>k=0</code> Generalized Morse
Wavelet, normalized in energy <code>normalization=:L2</code>, with <code>N=1024</code> time
samples, with shape parameters <code>\beta=1</code>,<code>\gamma=3</code>, and at scale <code>a=5</code>
and time index <code>u=512</code>, use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GMW

<p dir="auto">In order to compute continuous wavelet tranforms, we also provide a
handy function <code>gmw_grid</code> to initialize a bank of Generalized Morse
Wavelets whose frequency peaks are logarithmically positionned in
frequency.</p>
<p dir="auto">With the scales <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$a_i$</math-renderer> defined by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$$a_i=a_02^{i/Q},, \forall i=0\dots JQ-1$$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$J$</math-renderer> is the number of octaves and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$Q$</math-renderer> the number of
inter-octaves, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$a_0$</math-renderer> the initial lowest scale such that the highest
frequency peak is positionned at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$w_\mathrm{max}$</math-renderer>.</p>
<p dir="auto">The parameters of the bank are then computed using:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="J=8
Q=4
wmin=0 # Minimum frequency peak allowed
wmax=pi # Maximum frequency peak allowed
normalization=:peak # Wavelet frequency peak normalized to 1

g=gmw(0,g_params[1]...,N,normalization) # Get the first wavelet of the bank (g_params starts from the lowest scale)"><pre>J<span class="pl-k">=</span><span class="pl-c1">8</span>
Q<span class="pl-k">=</span><span class="pl-c1">4</span>

<p dir="auto">The resulting bank of wavelets have their frequency peaks <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$w_i$</math-renderer>
positionned at: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$$w_i=w_\mathrm{max}2^{-i/Q},, \forall i=0\dots JQ-1$$</math-renderer> If a minimum frequency threshold <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$w_\mathrm{min}$</math-renderer> is specified, all
wavelets with frequency peaks below this threshold are removed from the
bank of filters resulting in a bank of size less than <code>JQ</code>.</p>
<p dir="auto">Now given our bank of filters we can compute the continuous wavelet
transform of a given signal <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="bb9e52cc0485d1c9ec65d795225d0e4f">$x$</math-renderer>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="conv(x,g) = irfft(rfft(x) .* g,N) # For simplicity here we only compute the real part of the continuous wavelet transform
