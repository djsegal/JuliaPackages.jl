<p dir="auto">TimeSpans.jl provides a simple <code>TimeSpan</code> type for representing a continuous span between two points in time, along with generic utility functions for common operations on <code>TimeSpan</code>-like types. Importantly, the package exposes a minimal interface (<code>TimeSpans.start</code> and <code>TimeSpans.stop</code>) that any type can implement to enable support for the TimeSpans API.</p>
