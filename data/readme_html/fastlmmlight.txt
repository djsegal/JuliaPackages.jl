<p dir="auto">Lightweight implementation of the <a href="https://europepmc.org/article/med/21892150" rel="nofollow">FaST-LMM algorithm</a> for estimating the parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\beta$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\sigma^2$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\delta$</math-renderer> in a linear <a href="https://en.wikipedia.org/wiki/Mixed_model" rel="nofollow">mixed model</a> or <a href="https://en.wikipedia.org/wiki/Gaussian_process" rel="nofollow">Gaussian process</a> of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$$y \sim N\bigl(X\beta, \sigma^2(K + \delta I) \bigr)$$</math-renderer></p>
<p dir="auto">with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$y\in\mathbb{R}^n$</math-renderer> an observed response vector, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$X\in\mathbb{R}^{n\times d}$</math-renderer> an observed matrix of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$d$</math-renderer> covariates, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$K\in\mathbb{R}^{n\times n}$</math-renderer> a kernel matrix and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$I$</math-renderer> the identity matrix.</p>
<p dir="auto"><em>"Lightweight"</em> refers to two aspects of this implementation:</p>
<ol dir="auto">
<li>
<p dir="auto">The package is agnostic to any application domain. Whereas the <a href="https://fastlmm.github.io/" rel="nofollow">original software</a> and an <a href="https://github.com/sens/FaSTLMM.jl">existing julia implementation</a> contain a lot of code that is specific to working with genetic data, <code>FaSTLMMlight</code> contains only functions that work with the variables defined in the equation above, and nothing else. In other words, the package provides generic functions that other packages can call to solve the parameter estimation problem in specific application domains (for an example, see <a href="https://github.com/tmichoel/SpatialOmicsGPs.jl">SpatialOmicsGPs</a>).</p>
</li>
<li>
<p dir="auto">The package introduces a new, lightweight formulation of the one-parameter cost function (after eliminating <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\beta$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\sigma^2$</math-renderer>). Whereas the original algorithm involves the solution of a linear system in each evaluation of the cost function (to express <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\beta$</math-renderer> as a function of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$\delta$</math-renderer>), <code>FaSTLMMlight</code> uses <a href="https://en.wikipedia.org/wiki/Restricted_maximum_likelihood" rel="nofollow">restricted maximum likelihood</a> properties to avoid this step, resulting in a cost function amenable to <a href="https://julianlsolvers.github.io/Optim.jl/stable/user/gradientsandhessians/#Automatic-differentiation" rel="nofollow">automatic differentiation</a>. This in turns avoids the need for any grid-based optimization. See the documentation pages <a href="https://lab.michoel.info/FaSTLMMlight.jl/dev/svd-fixed-effects/" rel="nofollow">"SVD of the fixed effects"</a> and <a href="https://lab.michoel.info/FaSTLMMlight.jl/dev/fastlmm-fullrank/" rel="nofollow">"FaST-LMM full rank"</a> for details.</p>
</li>
</ol>

<p dir="auto"><code>FaSTLMMlight</code> will implement the FaST-LMM algorithms for full-rank kernel matrices and low-rank kernel matrix factorizations. I am also investigating whether and when the Fourier-space method of <a href="https://arxiv.org/abs/2210.10210" rel="nofollow">Greengard et al.</a> can lead to further speed-up in cases where the kernel matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="15cee7934eb97c1492938d320608dbf4">$K$</math-renderer> is coming from a <a href="https://en.wikipedia.org/wiki/Gaussian_process" rel="nofollow">Gaussian process</a> with translationally invariant kernal.</p>
