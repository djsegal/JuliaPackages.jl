<p dir="auto"><em>A Statistical Toolbox for QTL Analysis</em></p>
<p dir="auto"><code>BigRiverQTL.jl</code> is a package that makes it easier to perform
quantitative trait locus (QTL) analysis in Julia.  It consists of
three components streamline the QTL analysis workflow:
preprocessing, genome scans, and visualization.</p>
<ul dir="auto">
<li>
<p dir="auto"><strong>Preprocessing:</strong> The preprocessing functions are designed to
seamlessly import and convert genomic data into an efficient and
memory-conservative format. This component also offers function
capabilities for quickly calculating kinship matrices, ensuring data
readiness for subsequent analysis phases.</p>
</li>
<li>
<p dir="auto"><strong>Genome Scans:</strong> We provide the capabilities to perform a large
number of univariate genome scans using
<a href="https://github.com/senresearch/BulkLMM.jl"><code>BulkLMM.jl</code></a>. For
analyses involving multiple traits, we provide an interface to
<a href="https://github.com/senresearch/FlxQTL.jl"><code>FlxQTL.jl</code></a> to analyze
longitudinal traits and complex trait correlations.</p>
</li>
<li>
<p dir="auto"><strong>Visualization:</strong> The third component of the package offers
plotting tools designed to visualize genome scans including eQTL
scans using the
<a href="https://github.com/senresearch/BigRiverQTLPlots.jl"><code>BigRiverQTLPlots.jl</code></a>
package.</p>
</li>
</ul>
