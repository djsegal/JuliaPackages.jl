<p dir="auto"><strong>GaussMLE.jl</strong> is a Julia package for performing Maximum Likelihood Estimation (MLE) of Gaussian blob parameters in 2D images under a Poisson noise model.</p>
<p dir="auto">The main functionality is provided through the exported <code>fitstack</code> function, which takes a stack of 2D image boxes and returns the estimated Gaussian parameters for each box along with the uncertainties for each parameter.  Uncertainties are calculated using the Cramér-Rao Lower Bound.</p>
