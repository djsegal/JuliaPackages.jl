<p dir="auto">DeepSimulatedMoments.jl provides an implementation of the methods proposed in <a href="https://www.jldc.ch/uploads/2023_chassot_creel.pdf" rel="nofollow"><em>Constructing Efficient Simulated Moments Using Temporal Convolutional Networks</em> by Chassot, J. and Creel, M. (2023)</a>. The package allows to define your own data-generating processes, set up and train neural networks to generate moment conditions and proceed with simulation-based inference. For information on how to use this package, please refer to the <a href="docs-url">documentation</a></p>
