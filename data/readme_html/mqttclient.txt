<p dir="auto">This library provides a MQTT Client and functions for interfacing with a standard MQTT broker. This includes publishing messages, and subscribing to topics to receive published messages. See the <a href="https://JuliaMessaging.github.io/MQTTClient.jl" rel="nofollow">documentation</a> for more information.</p>
<p dir="auto">This package supports using Transmission Control Protocol (TCP) as well as Unix Domain Sockets (UDS) as the protocol to connect to the MQTT broker over. An example configuration for a <code>Mosquitto</code> broker can be found in the test folder.</p>
