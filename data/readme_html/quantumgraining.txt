<p dir="auto"><strong>QuantumGraining.jl</strong> offers a practical, generalized approach to the time-coarse graining (TCG) method in quantum optics. Often in quantum optics, we are not interested in the short time-scale dynamics -- these are either trivial, or unmeasurable, and keeping track of them is very computationally expensive. The time-coarse graning approach gives an effective, low-frequency description of the time-coarse grained dynamics, without neglecting the effects the high-frequency modes have on this dynamics.</p>
<p dir="auto">One can think of the time-coarse graining method as a generalization of the rotating-wave approximation, where the time-averaging is performed at the propagator level rather than the Hamiltonian level. More technically, while the rotating-wave approximation neglects all contributions due to counter-propagating terms, the time-coarse graining method is able to include <code>k</code>-order terms that can be comprised off these counter-rotating terms,
up to some arbitrary order <code>k</code>.  A familiar example would be virtual processes such as the simultaneous emission of a photon together with the excitation of an atom, followed the immediate absorption and de-excitation of the system.</p>
<p dir="auto">Moreover, the TCG method provides this description in terms of a generalized Linbdladian -- a Hamiltonian and a list of "dissipators" -- that fully generate these processes up to the desired order of approximation. In addition to the obvious benefits of a low-frequency description, this allows one to understand the effects of high-frequency modes directly as emergent dynamics on the relevant modes of interest.</p>

<p dir="auto"><a href="https://github.com/leonbello/QuantumGraining.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/leonbello/QuantumGraining.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">The STCG method is very computationally involved, with the number of terms growing rapidly with the order of truncation. The main object of interest is the "contraction coefficient" which encapsulates the relative weight of each possible <code>k</code>-order process. Each of these coefficients requires the recursive calculation of lower-order contraction coefficients to compute, a process which is the repeated for each frequency mode in the original Hamiltonian.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/imgs/decomp-tree.png"><img src="docs/imgs/decomp-tree.png" width="50%" height="50%" style="max-width: 100%;"></a></p>
<p dir="auto"><strong>QuantumGraining.jl</strong> automates the TCG process, symbolically calculating the effective Lindbladians in terms of abstract operators that are easily integrated into other symbolic packages, such as <strong>QuantumCumulants.jl</strong> and <strong>QuantumOptics.jl</strong>.</p>
<ul dir="auto">
<li>The model (Hamiltonian) is specified, along with the time-coarse graining time-scale.</li>
<li>The effective Lindbladian is calculated, using an efficient, recursive approach. The resulting Lindbladian is stored stored as a symbolic expression using the <a href="https://github.com/JuliaSymbolics/Symbolics.jl"><strong>Symbolics.jl</strong></a> framework, which is also used for any additional simplification and rewriting.</li>
<li>Finally, the symbolic Hamiltonian can be solved in <strong>QuantumOptics.jl</strong> or using <strong>QuantumCumulants.jl</strong>.</li>
</ul>

<p dir="auto"><code>QuantumGraining.jl</code> is  registered in the Julia package registrator, and can be easily installed on using the latest version of Julia.</p>
<ol dir="auto">
<li>Within the Julia REPL, press the <code>]</code> key. This will switch you to the Pkg REPL, indicated by a prompt like <code>(@v1.8) pkg&gt;</code>.</li>
<li>In the Pkg REPL,
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="    add QuantumGraining"><pre class="notranslate"><code>    add QuantumGraining
</code></pre></div>
</li>
<li>Since the operator algebra is handled by <code>QuantumCumulants</code>, you will need to install it as well,
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="     add QuantumCumulants"><pre class="notranslate"><code>     add QuantumCumulants
</code></pre></div>
</li>
<li>Once installed, include <code>QuantumGraining</code> in your code using:
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="    using QuantumGraining
    using QuantumCumulants"><pre class="notranslate"><code>    using QuantumGraining
    using QuantumCumulants
</code></pre></div>
</li>
</ol>
<p dir="auto">After following these steps, you should have successfully installed <code>QuantumGraining.jl</code> and its dependencies.</p>

<p dir="auto">As a simple illustrative example, let us consider the implementation of a second-order time coarse graining of the Rabi model:</p>

<p dir="auto">The code above returns an effective Lindbladian that generates the time-coarse grained evolution of the Rabi-model up to second-order. The input is a list of frequencies and their corresponding operators, and the output is a new list of operators, frequencies and coupling strengths. The <code>drop_high_freqs</code> function is used to remove the high-frequency terms from the effective Hamiltonian and dissipator, to simplify the resulting expressions.</p>
