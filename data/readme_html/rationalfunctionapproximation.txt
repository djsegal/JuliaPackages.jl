<p dir="auto">This package uses the continuous form of the AAA algorithm to adaptively compute rational approximations of functions on intervals and other domains in the complex plane.  For the mathematical description, see <a href="https://arxiv.org/abs/2305.03677" rel="nofollow">AAA rational approximation on a continuum</a>, which is to appear in SISC.</p>
<p dir="auto">The <a href="https://complexvariables.github.io/RationalFunctionApproximation.jl/stable/" rel="nofollow">documentation</a> includes a walkthrough showing off the main capabilities of the package.</p>

<ul dir="auto">
<li>The <a href="https://juliamath.github.io/Polynomials.jl/stable/" rel="nofollow">Polynomials</a> package provides rational functions, but not in a way related to function approximation.</li>
<li>The <a href="https://juliahub.com/ui/Packages/General/BaryRational" rel="nofollow">BaryRational</a> package implements the original (fully discrete) version of the AAA algorithm, as well as Floater–Hormann rational interpolation.</li>
<li>The <a href="https://juliaapproximation.github.io/ApproxFun.jl/stable" rel="nofollow">ApproxFun</a> package provides 1D and multidimensional function approximation using Chebyshev polynomials and Fourier series. It also has extensive functionality for manipulating the approximations and for solving differential equations.</li>
<li>There is an <a href="https://github.com/tomtrogdon/ApproxFunRational.jl">ApproxFunRational</a> package, but it is undocumented.</li>
</ul>
