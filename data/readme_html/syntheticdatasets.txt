<p dir="auto">The SyntheticDatasets.jl package is a library with functions for generating synthetic artificial datasets.</p>

<p dir="auto">The SyntheticDatasets.jl is a library with functions for generating synthetic artificial datasets. The package has some functions are interfaces to the dataset generator of the <a href="https://scikit-learn.org/stable/modules/classes.html#samples-generator" rel="nofollow">ScikitLearn</a>.</p>
