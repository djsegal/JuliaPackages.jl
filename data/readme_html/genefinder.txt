<blockquote>
<p dir="auto">This is a species-agnostic, algorithm extensible, sequence-anonymous (genome, metagenomes) <em>gene finder</em> library framework for the Julia Language.</p>
</blockquote>
<p dir="auto">The <code>GeneFinder</code> package aims to be a versatile module that enables the application of different gene finding algorithms to the <code>BioSequence</code> type, by providing a common interface and a flexible data structure to store the predicted ORFI or genes. The package is designed to be easily extensible, allowing users to implement their own algorithms and integrate them into the framework.</p>

The API is subject to change.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Finding complete and overlapped ORFIs</h2><a id="user-content-finding-complete-and-overlapped-orfis" class="anchor" aria-label="Permalink: Finding complete and overlapped ORFIs" href="#finding-complete-and-overlapped-orfis"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The main package function is <code>findorfs</code>. Under the hood, the <code>findorfs</code> function is an interface for different gene finding algorithms that can be plugged using the <code>finder</code> keyword argument. By default it uses the <code>NaiveFinder</code> algorithm, which is a simple algorithm that finds all (non-outbounded) ORFIs in a DNA sequence (see the <a href="https://camilogarciabotero.github.io/GeneFinder.jl/dev/api/#GeneFinder.NaiveFinder-Union%7BTuple%7BUnion%7BBioSequences.LongDNA%7BN%7D,%20BioSequences.LongSubSeq%7BBioSequences.DNAAlphabet%7BN%7D%7D%7D%7D,%20Tuple%7BN%7D%7D%20where%20N" rel="nofollow">NaiveFinder</a> documentation for more details).</p>
<div class="markdown-alert markdown-alert-note" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-info mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M0 8a8 8 0 1 1 16 0A8 8 0 0 1 0 8Zm8-6.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM6.5 7.75A.75.75 0 0 1 7.25 7h1a.75.75 0 0 1 .75.75v2.75h.25a.75.75 0 0 1 0 1.5h-2a.75.75 0 0 1 0-1.5h.25v-2h-.25a.75.75 0 0 1-.75-.75ZM8 6a1 1 0 1 1 0-2 1 1 0 0 1 0 2Z"></path></svg>Note</p><p dir="auto">The <code>minlen</code> kwarg in the <code>NaiveFinder</code> mehtod has been set to 6nt, so it will catch random ORFIs not necesarily genes thus it might consider <code>dna"ATGTGA"</code> -&gt; <code>aa"M*"</code> as a plausible ORFI.</p>
</div>

<p dir="auto">ORFIs sequences can be scored using different schemes that evaluate them under a biological context. There are two ways to make this possible: by adding a scoring method to the finder algorithm or by using a scoring method after predicting the ORFIs. The first approach is likely more efficient, but the second approach is more flexible. We will showcase the second approach in this example.</p>
<p dir="auto">A commonly used scoring scheme for ORFIs is the <em>log-odds ratio</em> score. This score is based on the likelihood of a sequence belonging to a specific stochastic model, such as coding or non-coding. The <a href="https://github.com/camilogarciabotero/BioMarkovChains.jl">BioMarkovChains</a> package provides a <code>log_odds_ratio_score</code> method (currently imported), also known as <code>lors</code>, which can be used to score ORFIs using the log-odds ratio approach.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="orfs = findorfs(seq, finder=NaiveFinder)"><pre>orfs <span class="pl-k">=</span> <span class="pl-c1">findorfs</span>(seq, finder<span class="pl-k">=</span>NaiveFinder)</pre></div>

<p dir="auto"><code>GeneFinder</code> also now facilitates the generation of <code>FASTA</code>, <code>BED</code>, and <code>GFF</code> files directly from the found ORFIs.
