<p dir="auto">A Julia package for non-smooth optimization algorithms.</p>
<p dir="auto">This package provides algorithms for the minimization of objective functions
that include non-smooth terms, such as constraints or non-differentiable penalties.
Implemented algorithms include:</p>
<ul dir="auto">
<li>(Fast) Proximal gradient methods</li>
<li>Douglas-Rachford splitting</li>
<li>Three-term splitting</li>
<li>Primal-dual splitting algorithms</li>
<li>Newton-type methods</li>
</ul>
<p dir="auto">Check out <a href="https://juliafirstorder.github.io/ProximalAlgorithms.jl/stable/guide/implemented_algorithms/" rel="nofollow">this section</a> for an overview of the available algorithms.</p>
<p dir="auto">Algorithms rely on:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaDiff/AbstractDifferentiation.jl">AbstractDifferentiation.jl</a> for automatic differentiation (but you can easily bring your own gradients)</li>
<li>the <a href="https://github.com/JuliaFirstOrder/ProximalCore.jl">ProximalCore API</a> for proximal mappings, projections, etc, to handle non-differentiable terms (see for example <a href="https://github.com/JuliaFirstOrder/ProximalOperators.jl">ProximalOperators</a> for an extensive collection of functions).</li>
</ul>
