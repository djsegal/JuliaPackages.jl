<p dir="auto"><a href="https://github.com/una-auxme/MeshGraphNets.jl"><em>MeshGraphNets.jl</em></a> is a software package for the Julia programming language that provides an implementation of the <a href="https://arxiv.org/abs/2010.03409" rel="nofollow">MeshGraphNets</a> framework by <a href="https://deepmind.google/" rel="nofollow">Google DeepMind</a> for simulating mesh-based physical systems via graph neural networks:</p>
<blockquote>
<p dir="auto">Tobias Pfaff, Meire Fortunato, Alvaro Sanchez-Gonzalez, and Peter W. Battaglia. 2021. <strong>Learning Mesh-Based Simulation with Graph Networks</strong>. In International Conference on Learning Representations.</p>
</blockquote>
<p dir="auto">You can find the original implementation of MeshGraphNets in their GitHub repository <a href="https://github.com/google-deepmind/deepmind-research/tree/master/meshgraphnets">here</a>.</p>

<p dir="auto"><a href="https://github.com/una-auxme/MeshGraphNets.jl"><em>MeshGraphNets.jl</em></a> is designed to be part of the <a href="https://sciml.ai/" rel="nofollow">SciML</a> ecosystem. The original framework was remodeled into a NeuralODE so that solvers from the <a href="https://docs.sciml.ai/DiffEqDocs/stable/" rel="nofollow">DifferentialEquations.jl</a> can be used to evaluate the system.</p>
<p dir="auto">Base functionality for the <code>Encode-Process-Decode</code> architecture of <code>DeepMind</code> that <em>MeshGraphNets</em> is based on is provided in the core package <a href="https://github.com/una-auxme/GraphNetCore.jl"><em>GraphNetCore.jl</em></a>.</p>
