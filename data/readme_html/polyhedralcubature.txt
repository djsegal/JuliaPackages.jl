<p dir="auto"><em>Multiple integration on convex polytopes.</em></p>
<hr>
<p dir="auto">This package allows to evaluate a multiple integral whose integration
bounds are (roughly speaking) some linear combinations of the variables, e.g.</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$$\int_{-5}^4\int_{-5}^{3-x}\int_{-10}^{6-2x-y} f(x, y, z)\,\text{d}z\,\text{d}y\,\text{d}x.$$</math-renderer></p>
<p dir="auto">In other words, the domain of integration is given by a set of linear
inequalities:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$$\left{\begin{matrix} -5  &amp; \leqslant &amp; x &amp; \leqslant &amp; 4 \\ -5  &amp; \leqslant &amp; y &amp; \leqslant &amp; 3-x \\ -10 &amp; \leqslant &amp; z &amp; \leqslant &amp; 6-2x-y \end{matrix}\right..$$</math-renderer></p>
<p dir="auto">These linear inequalities define a convex polytope (in dimension 3, a
polyhedron).
In order to use the package, one has to get the <em>matrix-vector representation</em>
of these inequalities, of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$$A \begin{pmatrix} x \\ y \\ z \end{pmatrix} \leqslant b.$$</math-renderer></p>
<p dir="auto">More technically speaking, this is called a <em>H-representation</em> of the convex polytope.
The matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$A$</math-renderer> and the vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$b$</math-renderer> appear when one rewrites the linear
inequalities above as:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$$\left{\begin{matrix} -x &amp; \leqslant &amp; 5 \\ x &amp; \leqslant &amp; 4 \\ -y &amp; \leqslant &amp; 5 \\ x+y &amp; \leqslant &amp; 3 \\ -z &amp; \leqslant &amp; 10 \\ 2x+y+z &amp; \leqslant &amp; 6 \end{matrix}\right..$$</math-renderer></p>
<p dir="auto">The matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$A$</math-renderer> is given by the coefficients of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$x$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$y$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$z$</math-renderer> at the
left-hand sides, and the vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="725a5f204649db60aca47a3fc72166dc">$b$</math-renderer> is made of the upper bounds at the
right-hand sides:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = [
  -1  0  0;   # -x
   1  0  0;   # x

   2  1  1    # 2x + y + z

  <span class="pl-k">-</span><span class="pl-c1">1</span>  <span class="pl-c1">0</span>  <span class="pl-c1">0</span>;   <span class="pl-c"><span class="pl-c">#</span> -x</span>
   <span class="pl-c1">1</span>  <span class="pl-c1">0</span>  <span class="pl-c1">0</span>;   <span class="pl-c"><span class="pl-c">#</span> x</span>

<p dir="auto">See the documentation for examples.
The package provides two functions:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>integrateOnPolytope</code>, to integrate an arbitrary function with a desired
tolerance on the error;</p>
</li>
<li>
<p dir="auto"><code>integratePolynomialOnPolytope</code>, to get the exact value of the integral of
a polynomial.</p>
</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Getting <code>A</code> and <code>b</code> (help wanted)</h2><a id="user-content-getting-a-and-b-help-wanted" class="anchor" aria-label="Permalink: Getting A and b (help wanted)" href="#getting-a-and-b-help-wanted"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">It can be a bit annoying to write down the matrix <code>A</code> and the vector <code>b</code>.
In the <a href="https://github.com/stla/polyhedralCubature">R version</a>
and in the <a href="https://github.com/stla/PyPolyhedralCubature">Python version</a>
of this package, I have a way to get <code>A</code> and <code>b</code> from symbolic linear
inequalities. I have found such a way in Julia, but it has an inconvenient:
it returns <code>A</code> and <code>b</code> with the <code>Float64</code> element type, while it is better
to use, when possible, the <code>Int64</code> type or <code>Rational{Int64}</code> or
<code>Rational{BigInt}</code>. Here is an example of this Julia way:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP

model = Model()
@variable(model, x)
@variable(model, y)
@variable(model, z)

@constraint(model, x &gt;= -5)
@constraint(model, x &lt;= 4)
@constraint(model, y &gt;= -5)
@constraint(model, x+y &lt;= 3)
@constraint(model, z &gt;= -10)
@constraint(model, 2*x+y+z &lt;= 6)

relax = relax_integrality(model)
sfm = JuMP._standard_form_matrix(model)
m, p = size(sfm.A)

A = sfm.A[:, 1:(p-m)]"><pre><span class="pl-k">using</span> JuMP

model <span class="pl-k">=</span> <span class="pl-c1">Model</span>()
<span class="pl-c1">@variable</span>(model, x)
<span class="pl-c1">@variable</span>(model, y)
<span class="pl-c1">@variable</span>(model, z)

<span class="pl-c1">@constraint</span>(model, x <span class="pl-k">&gt;=</span> <span class="pl-k">-</span><span class="pl-c1">5</span>)
<span class="pl-c1">@constraint</span>(model, x <span class="pl-k">&lt;=</span> <span class="pl-c1">4</span>)
<span class="pl-c1">@constraint</span>(model, y <span class="pl-k">&gt;=</span> <span class="pl-k">-</span><span class="pl-c1">5</span>)
<span class="pl-c1">@constraint</span>(model, x<span class="pl-k">+</span>y <span class="pl-k">&lt;=</span> <span class="pl-c1">3</span>)
<span class="pl-c1">@constraint</span>(model, z <span class="pl-k">&gt;=</span> <span class="pl-k">-</span><span class="pl-c1">10</span>)
<span class="pl-c1">@constraint</span>(model, <span class="pl-c1">2</span><span class="pl-k">*</span>x<span class="pl-k">+</span>y<span class="pl-k">+</span>z <span class="pl-k">&lt;=</span> <span class="pl-c1">6</span>)

relax <span class="pl-k">=</span> <span class="pl-c1">relax_integrality</span>(model)
sfm <span class="pl-k">=</span> JuMP<span class="pl-k">.</span><span class="pl-c1">_standard_form_matrix</span>(model)
m, p <span class="pl-k">=</span> <span class="pl-c1">size</span>(sfm<span class="pl-k">.</span>A)

A <span class="pl-k">=</span> sfm<span class="pl-k">.</span>A[:, <span class="pl-c1">1</span><span class="pl-k">:</span>(p<span class="pl-k">-</span>m)]</pre></div>
<p dir="auto">This gives <code>A</code>, and it is possible to get <code>b</code> from <code>sfm.lower</code> and <code>sfm.upper</code>.</p>
<p dir="auto">Please let me know if you have an idea for something similar which is not
limited to the <code>Float64</code> element type.</p>
