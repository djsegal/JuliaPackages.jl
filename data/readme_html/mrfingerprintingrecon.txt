<p dir="auto">MRFingerprintingRecon.jl is a Julia package that implements sub-space reconstructions as described by <a href="https://onlinelibrary.wiley.com/doi/abs/10.1002/mrm.26102" rel="nofollow">Jon Tamir et al.</a> and by us in the paper <a href="https://doi.org/10.1002/mrm.26639" rel="nofollow">Low-rank alternating direction method of multipliers reconstruction for MR fingerprinting</a> as <em>low rank inversion</em>.</p>
<p dir="auto">Currently, the package only supports non-Cartesian trajectories, but a Cartesian implementation is under active development. The package is still work in progress and the interface will likely change over time. The ultimate goal of this package is to provide a Julia implemenation of the low-rank ADMM algorithm, similar to our <a href="https://bitbucket.org/asslaender/nyu_mrf_recon" rel="nofollow">Matlab package</a>.</p>
