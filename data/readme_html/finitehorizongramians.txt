<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Associated with the pair of matrices <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$A \in \mathbb{R}^{n \times n}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$B \in \mathbb{R}^{n \times m}$</math-renderer> is the differential Lyapunov equation:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$$
\dot{Q}(\tau) = A Q(\tau) + Q(\tau) A^* + B B^*, \quad Q(0) = 0,\quad \tau \in [0, t].
$$</math-renderer></p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$Q(t)$</math-renderer> is the finite Horizon controllability Gramian of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$(A, B)$</math-renderer>, over the interval <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$[0, t]$</math-renderer>,
and may be equivalently expressed by the function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$Q(t) = G(At, B \sqrt{t})$</math-renderer>, where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$$
G(A, B) = \int_0^1 e^{A t} B B^* e^{A^* t} \mathrm{d} t.
$$</math-renderer></p>
<p dir="auto">The Gramian, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$G(A, B)$</math-renderer>, is positive semi-definite and therefore has an upper triangular Cholesky factor, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$U(A, B)$</math-renderer>.
This package provides algorithms for computing both <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$e^A$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$U(A, B)$</math-renderer>,
without having to form <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$G(A, B)$</math-renderer> as an intermediate step.
This avoids the problem of failing Cholesky factorizations when computing <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$G(A, B)$</math-renderer> directly leads to a numerically non-positive definite matrix.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Application</h2><a id="user-content-application" class="anchor" aria-label="Permalink: Application" href="#application"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Consider the Gauss-Markov process</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$$
\dot{x}(t) = A x(t) + B \dot{w}(t).
$$</math-renderer></p>
<p dir="auto">It can be shown that the process <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$x$</math-renderer> has a transition density given by</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$$
p(t + h, x \mid t, x') = \mathcal{N}\big(x; e^{A h} x', G(A h, \sqrt{h} B) \big).
$$</math-renderer></p>
<p dir="auto">This package offers a method to both compute the transition matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$e^{A h}$</math-renderer> and a Cholesky factor of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a5c9ccfa806ded8f7548d6fa77abdbd7">$G(A h, \sqrt{h} B)$</math-renderer> in a numerically robust way.
This is useful for instance in so called array implementations of Gauss-Markov regression (i.e. square-root Kalman filters etc).</p>
