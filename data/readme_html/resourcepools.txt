<p dir="auto">ResourcePools is a Julia package that enables re-use of "expensive" resources, such as memory allocations, or database connections, by providing functionality for creating and managing pools of such resources. The management of resources is based on reference counting.</p>
<p dir="auto">ResourcePools provides generic types <code>ResourcePool{T}</code>, and <code>PooledResource{T}</code>, as well as an array-specific type, <code>PooledArray{T,N}</code>.</p>
<p dir="auto">ResourcePools is thread-safe.</p>
