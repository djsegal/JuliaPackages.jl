<p dir="auto"><strong>A playground for experimentation with Wannier functions (WFs).</strong></p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Wannierization</p>
<ul dir="auto">
<li>maximal localization for isolated bands, e.g. insulators</li>
<li>disentanglement for entangled bands, e.g. metal</li>
<li>parallel transport gauge</li>
<li>split valence and conduction WFs
<ul dir="auto">
<li>automated initial projection for valence or conduction WFs</li>
</ul>
</li>
<li>constrain WF center</li>
</ul>
</li>
<li>
<p dir="auto">Interpolation of operators, e.g. band structure</p>
</li>
<li>
<p dir="auto">Real space WFs</p>
<ul dir="auto">
<li>output <code>xsf</code> or <code>cube</code> file</li>
<li>evaluate operators in real space</li>
</ul>
</li>
</ul>

just like any other registered Julia package:</p>

<p dir="auto">Additionally, there is a command line interface</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project deps/build.jl install  # install CLI"><pre>julia --project deps/build.jl install  <span class="pl-c"><span class="pl-c">#</span> install CLI</span></pre></div>
<p dir="auto">The executable will be installed in <code>~/.julia/bin/wannier</code>.
After appending <code>~/.julia/bin</code> to your <code>$PATH</code>, you can use the CLI as follows:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ wannier -h


  wannier v0.1.0

Julia package for Wannier functions.

Usage

  wannier &lt;command&gt;
..."><pre>$ wannier -h


  wannier v0.1.0

Julia package <span class="pl-k">for</span> Wannier functions.

Usage

  wannier <span class="pl-k">&lt;</span>command<span class="pl-k">&gt;</span>
...</pre></div>
<p dir="auto">Note since julia needs precompilation of the code, there will be some delay when running the CLI.</p>

<p dir="auto">For example, running a maximal localization can be easily achieved by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Wannier

write_amn(&quot;silicon.amn&quot;, U)"><pre><span class="pl-k">using</span> Wannier

model <span class="pl-k">=</span> <span class="pl-c1">read_w90</span>(<span class="pl-s"><span class="pl-pds">"</span>silicon<span class="pl-pds">"</span></span>)

<span class="pl-c1">write_amn</span>(<span class="pl-s"><span class="pl-pds">"</span>silicon.amn<span class="pl-pds">"</span></span>, U)</pre></div>
<p dir="auto">For a much more detailed overview, please see
<a href="https://qiaojunfeng.github.io/Wannier.jl/stable/user/" rel="nofollow">the User Guide documentation</a>.</p>

<p dir="auto">The docs are maintained in a dedicated repo <a href="https://github.com/qiaojunfeng/WannierDocs.jl">WannierDocs.jl</a>.
This allows us to add large tutorial files (e.g. <code>amn</code>, <code>mmn</code>) without bloating the main repo.
Furthermore, it also contains the docs for another two packages:</p>
<ul dir="auto">
<li><a href="https://github.com/qiaojunfeng/WannierIO.jl">WannierIO.jl</a> for reading and writing files</li>
<li><a href="https://github.com/qiaojunfeng/WannierPlots.jl">WannierPlots.jl</a> for plotting band structure, etc.</li>
</ul>
