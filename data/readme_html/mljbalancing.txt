<p dir="auto">This package allows chaining of resampling methods from <code>Imbalance.jl</code> with classification models from <code>MLJ</code>. Simply construct a <code>BalancedModel</code> object while specifying the model (classifier) and an arbitrary number of resamplers (also called <em>balancers</em> - typically oversamplers and/or undersamplers).</p>

<p dir="auto">Here training data will be passed to <code>balancer1</code> then <code>balancer2</code>, whose output is used to train the classifier <code>model</code>.  When <code>balanced_model</code> is used for prediction, the resamplers <code>balancer1</code> and <code>blancer2</code> are bypassed.</p>
<p dir="auto">In general, any number of balancers can be passed to the function, and the user can give the balancers arbitrary names while passing them.</p>

<p dir="auto">The package also offers an implementation of bagging over probabilistic classifiers where the majority class is repeatedly undersampled <code>T</code> times down to the size of the minority class. This undersampling scheme was proposed in the <em>EasyEnsemble</em> algorithm found in the paper <em>Exploratory Undersampling for Class-Imbalance Learning.</em> by <em>Xu-Ying Liu, Jianxin Wu, &amp; Zhi-Hua Zhou</em> where an Adaboost model was used and the output scores were averaged.</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Construct a BalancedBaggingClassifier</h4><a id="user-content-construct-a-balancedbaggingclassifier" class="anchor" aria-label="Permalink: Construct a BalancedBaggingClassifier" href="#construct-a-balancedbaggingclassifier"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In this you must specify some probabilistic model, and optionally specify the number of bags <code>T</code> and the random number generator <code>rng</code>. If <code>T</code> is not specified it is set as the ratio between the majority and minority counts. If <code>rng</code> isn't specified then <code>default_rng()</code> is used.</p>
