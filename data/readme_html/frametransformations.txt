<p dir="auto">Are you in search of fundamental routines for efficient and extensible frames transformations?<br>
If so, this package is the ideal starting point. FrameTransformations.jl is designed to
provide users with  the ability to create a customized, efficient, flexible, and
extensible axes/point graph models for mission analysis and space mission design purposes.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Convert between different time scales and representations (via <a href="https://github.com/JuliaSpaceMissionDesign/Tempo.jl">Tempo.jl</a>);</li>
<li>Read binary ephemeris files (via <a href="https://github.com/JuliaSpaceMissionDesign/Ephemerides.jl">Ephemerides.jl</a> or <a href="https://github.com/JuliaSpaceMissionDesign/CalcephEphemeris.jl">CalcephEphemeris.jl</a>)</li>
<li>Create custom reference frame systems with both standard and user-defined points and axes.</li>
<li>Transform states and their higher-order derivatives between different frames (up to jerk)</li>
</ul>
<p dir="auto">All of this seamlessly integrated with <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a>.</p>
