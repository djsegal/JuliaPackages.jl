<p dir="auto">GeometryOps.jl is a package for geometric calculations on (primarily 2D) geometries.</p>
<p dir="auto">The driving idea behind this package is to unify all the disparate packages for geometric calculations in Julia, and make them <a href="https://github.com/JuliaGeo/GeoInterface.jl">GeoInterface.jl</a>-compatible. We are focusing primarily on 2/2.5D geometries for now.  All methods in this package will consume any geometry which is compatible with GeoInterface - see its <a href="https://juliageo.org/GeoInterface.jl/stable/reference/integrations/" rel="nofollow">integrations page</a> for more info on that!</p>
<p dir="auto">Most of the use cases are driven by GIS and similar Earth data workflows, so this might be a bit specialized towards that, but methods should always be general to any coordinate space.</p>
<p dir="auto">We welcome contributions, either as pull requests or discussion on issues!</p>

<p dir="auto">GeometryOps tries to offer most of the basic geometry operations you'd need, implemented in pure Julia and accepting any GeoInterface.jl compatible type.</p>
<ul dir="auto">
<li>General geometry methods (OGC methods): <code>equals</code>, <code>extent</code>, <code>distance</code>, <code>crosses</code>, <code>contains</code>, <code>intersects</code>, etc</li>
<li>Targeted function application over large nested geometries (<code>apply</code>) and reduction over geometries (<code>applyreduce</code>)
<ul dir="auto">
<li>Both <code>apply</code> and <code>applyreduce</code> consume arbitrary tables as well, like DataFrames!</li>
</ul>
</li>
<li><code>signed_area</code>, <code>centroid</code>, <code>distance</code>, etc for valid geometries</li>
<li>Line and polygon simplification (<code>simplify</code>)</li>
<li>Polygon clipping, <code>intersection</code>, <code>difference</code> and <code>union</code></li>
<li>Generalized barycentric coordinates in polygons (<code>barycentric_coordinates</code>)</li>
<li>Projection of geometries between coordinate reference systems using <a href="https://github.com/JuliaGeo/Proj.jl">Proj.jl</a></li>
<li>Polygonization of raster images by contour detection (<code>polygonize</code>)</li>
<li>Segmentization/densification of geometry, both linearly and by geodesic paths (<code>segmentize</code>)</li>
</ul>
<p dir="auto">See the "API" page in the docs for a more complete list!</p>

<p dir="auto">GeometryOps' <a href="https://juliageo.org/GeometryOps.jl/stable" rel="nofollow">docs</a> are divided into three main sections: tutorials, explanations and source code.<br>
Documentation and examples for many functions can be found in the source code section, since we use literate programming in GeometryOps.</p>
<ul dir="auto">
<li>Tutorials are meant to teach the fundamental concepts behind GeometryOps, and how to perform certain operations.</li>
<li>Explanations usually contain little code, and explain in more detail how GeometryOps works.</li>
<li>Source code usually contains explanations and examples at the top of the page, followed by annotated source code from that file.</li>
</ul>
