<p dir="auto">This package provides a function <code>Vensim2MTK</code> that can produce a Julia file of a model using ModelingToolkit from an exported Vensim model.</p>
<p dir="auto">Usage of the function:
The function takes 3 arguments:</p>
<ul dir="auto">
<li><code>filepath</code>: the path to the Vensim file that one wants to translate. Default to <code>./examples/Dice.xmile</code>.</li>
<li><code>filename</code>: the name of the output file. Default to the name of the input file with the extension <code>.jl</code> replacing <code>.xmile</code>.</li>
<li><code>overwrite</code>: boolean argument that indicate in the case of the file already existing, if the function aborts or overwrite it(true to overwrite).</li>
</ul>
<p dir="auto">Example of use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Vensim2MTK

<span class="pl-c1">vensim2MTK</span>(filepath, filename, overwrite) </pre></div>
<p dir="auto">This code will write in the file <code>MTKmodel.jl</code> an implementation in ModelingToolkit of the model exported in <code>model.xmile</code> from the Vensim app.</p>

<p dir="auto">There are currently 4 models used as examples for the parser:
DICE, lotka, commitment and community corona 8. Here is a quick explanation of each as well as where we found them:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>Dice</code> is William Nordhaus’ Dice model; the implementation of it was found <a href="https://metasd.com/2010/06/dice/" rel="nofollow">here</a> and is the <code>DICE-heur-7-PLE.mdl</code> version (as Vensim has some issues with exporting some models as xmile files, some version of the models used may not work. Usually, the .mdl works with no issue).</p>
</li>
<li>
<p dir="auto"><code>lotka</code> is the simple Lotka-Voltera predation model, found <a href="http://www.shodor.org/refdesk/BioPortal/model/VSpredatorPrey?level=advanced" rel="nofollow">here</a>.</p>
</li>
<li>
<p dir="auto"><code>commitment</code> is a model that is based on <a href="https://doi.org/10.48550/arXiv.1209.3546" rel="nofollow">an ArXiv paper</a>. The model was published on <a href="https://metasd.com/2012/09/encouraging-moderation/" rel="nofollow">this blog post</a>.</p>
</li>
<li>
<p dir="auto"><code>community corona 8</code> is a model representing the evolution of the coronavirus in a community, and the effectiveness of some method. See <a href="https://metasd.com/2020/03/community-coronavirus-model-bozeman/" rel="nofollow">this blog post</a>.</p>
</li>
</ul>

<p dir="auto">If some variables need to be initialised by other variables that are not directly initialised, the program automatically initialises them with a default value (42). It is necessary to replace these with values that are at least not too far away from the real ones; just so that the model runs correctly without failing. It is then possible to obtain the true initial value and replace these arbitrary values with those calculated by ModelingToolkit; then re-run the model, obtaining from now on the real values for the whole model.</p>
