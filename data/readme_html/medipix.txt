<p dir="auto">This is a control software package for Medipix detectors. Testing of the package is carried out on a quad-chip Medipix-4R detector (<a href="https://quantumdetectors.com/products/merlinem/" rel="nofollow">Merlin EM</a> by QuantumDetector) installed on <a href="https://www.jeol.co.jp/en/products/detail/JEM-ARM300F2.html" rel="nofollow">JEM-ARM300F2 GRAND ARM™2</a> at <a href="https://www.rfi.ac.uk/about/" rel="nofollow">Rosalind Franklin Institute</a>.</p>

<p dir="auto">Remote connection from another computer on the same network can be achieved by supplying the MerlinPC's IP address. Note that only one connection is allowed by the Merlin software. Close any existing connection using the function <code>close_connection</code> before attempting a new connection.</p>
