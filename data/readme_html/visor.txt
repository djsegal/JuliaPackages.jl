<p dir="auto">The scope of <code>Visor</code> is to provide support for reliable, long-running and fault tolerant applications written in Julia.</p>
<p dir="auto"><code>Visor</code> is a tasks supervisor that provides:</p>
<ul dir="auto">
<li>a workflow for ordered shutdown of tasks.</li>
<li>a set of policies to control the logic of tasks restart.</li>
</ul>
<p dir="auto"><code>Visor</code> is influenced by <a href="https://www.erlang.org/doc/design_principles/sup_princ.html#supervision-principles" rel="nofollow">Erlang Supervisor</a> design principles
with the aims to fit as "naturally" as possible into the Julia task system.</p>
<p dir="auto">On Unix hosts Visor manages <code>SIGINT</code> signal in a deterministic way and shutdown tasks in an orderly fashion.</p>

# a descriptor representing the supervised task, in this case `pd` is the 
# descriptor of the `printer` process.
function printer(pd, device)
    println(&quot;(re)starting printer driver&quot;)
    receive(pd) do msg
        device.jobcount += 1
        print(&quot;processing $msg ... &quot;)
        if device.jobcount === 3
            # unexpected printer failure 
            error(&quot;printer service panic error: $msg not printed&quot;)
        end

    end
end

        # send a one-way message to the printer process.

<p dir="auto">The types of nodes that compose a supervision tree are:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>Process</code>: a node running a task.</p>
</li>
<li>
<p dir="auto"><code>Supervisor</code>: a node that supervises other nodes.</p>
</li>
</ul>
<p dir="auto">The supervision tree is controlled with the methods:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>supervise</code>: start a supervision tree.</p>
</li>
<li>
<p dir="auto"><code>startup</code>: start a node.</p>
</li>
<li>
<p dir="auto"><code>shutdown</code>: terminate a node.</p>
</li>
</ul>
<p dir="auto">A supervised task function needs to have as a first argument a task descriptor <code>td</code> for inter-task communication and shutdown requests.</p>
<p dir="auto">In the above example the <code>printer</code> function is the supervised task function of the <code>Process</code> defined by <code>process(printer; args=(PrinterStatus(0),))</code>.</p>
<p dir="auto">Applications messages sent to the task and the <code>Shutdown</code> control message are received from the <code>td.inbox</code> Channel.</p>
<p dir="auto">To check for a termination request use the method <code>isshutdown</code>:</p>

    @info &quot;making $steps steps and checking for SIGINT every $check_interrupt_every steps&quot;

<p dir="auto">To send application messages the standard Channel api may be used or the utilities provided by Visor:</p>
<ul dir="auto">
<li><code>cast(td, "path.to.target", message)</code>: send a message to the node with full name <code>path.to.target</code>.</li>
<li><code>call(td, "path.to.target", request)</code>: send a request to and wait for a response.</li>
<li><code>isrequest(message)</code>: check if <code>message</code> is a request.</li>
<li><code>reply(message, response)</code>: send the <code>response</code> to the <code>call</code> method that issued the <code>message</code> request .</li>
</ul>
<p dir="auto">The following example shows the mechanics of inter-task communication.
Note that the order of tasks shutdown is the reverse of startup order.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# app.jl:

using Visor

struct CounterMsg
    count::Int
end

struct ControllerMsg
    query::String
end 

function db_service(td)
    @info &quot;[$td] starting&quot;
    for msg in td.inbox
        if isshutdown(msg)
            break
        elseif isa(msg, CounterMsg)
            @info &quot;[$td] got message: $msg&quot;
        elseif isrequest(msg)
            if isa(msg.request, ControllerMsg)
                reply(msg, :on)
            end
        end
    end
    @info &quot;[$td] shutting down&quot;
end

function app_counter(td)
    @info &quot;[$td] starting&quot;
    n = 0

    # get the db_service process handle
    db = from(&quot;db_service&quot;)

    while true
        sleep(2)
        if isshutdown(td)
            break
        end
        # send a data message to db_service process
        cast(db, CounterMsg(n))
        n += 1
    end
    @info &quot;[$td] shutting down&quot;
end

function app_controller(td)
    @info &quot;[$td] starting&quot;

    # get the db_service process handle
    db = from(&quot;db_service&quot;)

    while true
        sleep(2)
        if isshutdown(td)
            break
        end

        # send a request to db_service process 
        response = call(db, ControllerMsg(&quot;select status from ...&quot;), -1)
        @info &quot;[$td] current status: $response&quot;
    end
    @info &quot;[$td] shutting down&quot;
end
