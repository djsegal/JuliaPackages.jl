<p dir="auto">BioFindr is an implementation of the <a href="https://github.com/lingfeiwang/findr">Findr software</a> in <a href="https://julialang.org/" rel="nofollow">Julia</a>. See our paper <a href="https://doi.org/10.1371/journal.pcbi.1005703" rel="nofollow">"Efficient and accurate causal inference with hidden confounders from genome-transcriptome variation data"</a><sup><a href="#user-content-fn-Wang2017-9eba03b142825abb6277da5dd7327c24" id="user-content-fnref-wang2017-9eba03b142825abb6277da5dd7327c24" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup> for  details of the methods implemented in BioFindr.</p>
<p dir="auto">If you're new to BioFindr, check out:</p>
<ul dir="auto">
<li>the <a href="https://tmichoel.github.io/BioFindrTutorials" rel="nofollow">BioFindr tutorials website</a></li>
<li>the notebooks in this <a href="https://github.com/tmichoel/causal-inference-short-course">short course on causal inference in drug discovery</a></li>
</ul>
<p dir="auto">More details about the methods and their implementation can be found in the <a href="https://tmichoel.github.io/BioFindr.jl" rel="nofollow">documentation</a>.</p>
