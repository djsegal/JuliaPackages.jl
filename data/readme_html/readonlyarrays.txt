<p dir="auto">This small package provides the <code>ReadOnlyArray</code> type, which wraps any <code>AbstractArray</code> and reimplements the array inferface without the setindex! function. The array can be used in all the usually ways but its elements cannot be modified. Attempting to set an element's value will raise an error. This functionality can be used to protect arrays that are intended to have unchanged values from unintended changes.</p>
<p dir="auto">A <code>ReadOnlyArray</code> is not a <code>StaticArray</code> from <a href="https://github.com/JuliaArrays/StaticArrays.jl"><code>StaticArrays.jl</code></a>. Static arrays are statically sized and also usually immutable, but are intended to accelerate common operations on <em>small</em> arrays. A <code>ReadOnlyArray</code> wraps arrays of any size and does not reimplement any functionality except the usual <a href="https://docs.julialang.org/en/v1/manual/interfaces/#man-interface-array" rel="nofollow">array interface</a>.</p>
<p dir="auto">For convenience, there are also <code>ReadOnlyVector</code> and <code>ReadOnlyMatrix</code> aliases available.</p>
