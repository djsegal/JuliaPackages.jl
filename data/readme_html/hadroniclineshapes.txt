<p dir="auto">The <code>HadronicLineshapes</code> package provides a collection of models for describing hadronic scattering processes in particle physics. It supports the analysis of hadronic resonances by offering various lineshape functions and utilities for flexible mathematical operations.</p>

<p dir="auto">The package exposes the following key types and functions:</p>
<ul dir="auto">
<li>
<p dir="auto"><strong><code>AbstractFlexFunc</code></strong>: Base type for flexible operations on lineshape functions.</p>
</li>
<li>
<p dir="auto"><strong>Utility Types</strong>:</p>
<ul dir="auto">
<li><strong><code>WrapFlexFunction</code></strong>: Wraps functions for extended flexibility.</li>
<li><strong><code>ComposeFlexFunc</code></strong>: Enables the composition of multiple functions.</li>
<li><strong><code>ScaleFlexFunc</code></strong>: Allows scaling of functions.</li>
<li><strong><code>ProductFlexFunc</code></strong>: Facilitates the creation of product functions.</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Form Factors</strong>:</p>
<ul dir="auto">
<li><strong><code>BlattWeisskopf</code></strong>: Describes the Blatt-Weisskopf barrier factors.</li>
<li><strong><code>MomentumPower</code></strong>: Represents momentum-dependent terms in scattering.</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Lineshape Models</strong>:</p>
<ul dir="auto">
<li><strong><code>BreitWigner</code></strong>: Standard Breit-Wigner resonance model.</li>
<li><strong><code>MultichannelBreitWigner</code></strong>: Breit-Wigner model extended to multiple channels.</li>
<li><strong><code>Flatte</code></strong>: Model for resonances near a threshold with coupled channels.</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Functions</strong>:</p>
<ul dir="auto">
<li><strong><code>breakup</code></strong>: Computes breakup momentum in two-body decays.</li>
<li><strong><code>orbital_momentum</code></strong>: Computes the orbital momentum in scattering processes.</li>
</ul>
</li>
</ul>
