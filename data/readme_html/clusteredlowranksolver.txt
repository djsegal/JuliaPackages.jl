<p dir="auto"><a href="https://github.com/nanleij/ClusteredLowRankSolver.jl"><code>ClusteredLowRankSolver.jl</code></a> implements</p>
<ul dir="auto">
<li>a primal-dual interior point method for solving semidefinite programming problems;</li>
<li>a minimal interface to model semidefinite programming problems with (optional) polynomial equality constraints;</li>
<li>functionality for working with sampled polynomials; and</li>
<li>an implementation of a rounding heuristic which can round the numerical output of the solver to an exact optimal solution over rational or algebraic numbers.</li>
</ul>
<p dir="auto">The solver can exploit the low-rank structure of constraint matrices (which arise naturally from enforcing polynomial identities by evaluating both sides at a unisolvent set) but can also work with dense constraint matrices. The solver uses arb for high-precision numerics and the interface integrates with the Nemo computer algebra system.</p>

<p dir="auto">Given a Laplacian <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$L$</math-renderer> of a graph with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$n$</math-renderer> vertices, the semidefinite programming relaxation of the max-cut problem reads</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$$\begin{aligned}
&amp; \text{maximize} &amp; &amp; \left\langle \frac{1}{4}L, X \right\rangle\\\
&amp; \text{subject to} &amp; &amp; \langle E_{ii}, X \rangle = 1, \; i=1,\ldots,n,\\\
&amp;&amp;&amp;X \in S_+^{n}.
\end{aligned}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$E_{ii}$</math-renderer> is the matrix with a one in the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$(i,i)$</math-renderer> entry, and zeros elsewhere. Here <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$\langle \cdot, \cdot \rangle$</math-renderer> denotes the trace inner product.</p>
<p dir="auto">The following code implements this using <code>ClusteredLowRankSolver</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ClusteredLowRankSolver

function goemans_williamson(L::Matrix; eps=1e-40)
    n = size(L, 1)

    # Construct the objective
    obj = Objective(0, Dict(:X =&gt; 1//4 * L), Dict())

    # Construct the constraints
    constraints = []
    for i = 1:n
        M = zeros(Rational{BigInt}, n, n)
        M[i, i] = 1//1
        # the first argument is the right hand side
        push!(constraints, Constraint(1, Dict(:X =&gt; M), Dict()))
    end

    # Construct the problem: Maximize the objective s.t. the constraints hold
    problem = Problem(Maximize(obj), constraints)

    # Solve the problem
    status, primalsol, dualsol, time, errorcode = solvesdp(problem, duality_gap_threshold=eps)

    objvalue(problem, dualsol), matrixvar(dualsol, :X)
end"><pre><span class="pl-k">using</span> ClusteredLowRankSolver

<p dir="auto">To find the minimum of a polynomial <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$f$</math-renderer> of degree <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$2d$</math-renderer>, one can use the following problem</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$$\begin{aligned}
&amp; \text{minimize} &amp; &amp; \lambda\\\
&amp; \text{subject to} &amp; &amp; f - \lambda = s,\\\
\end{aligned}$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$s$</math-renderer> is a sum-of-squares polynomial of degree <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$2d$</math-renderer>.
Let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$m$</math-renderer> be a vector whose entries form a basis of the polynomials up to degree <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$d$</math-renderer>, then we can write <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$s = \langle m(x)m(x)^T, X \rangle$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="ce435eeadbf04fcefc228a49575c106f">$X$</math-renderer> is a positive semidefinite matrix.</p>

<p dir="auto">The semidefinite programming solver and the interface (including sampled polynomials) in <code>ClusteredLowRankSolver.jl</code> have been developed as part of the paper</p>
<ul dir="auto">
<li>Nando Leijenhorst and David de Laat, <a href="https://arxiv.org/abs/2202.12077" rel="nofollow"><em>Solving clustered low-rank semidefinite programs arising from polynomial optimization</em></a>, preprint, 2022. arXiv:2202.12077</li>
</ul>

<ul dir="auto">
<li>David Simmons-Duffin. <a href="https://link.springer.com/article/10.1007/JHEP06(2015)174" rel="nofollow"><em>A semidefinite program solver for the conformal bootstrap</em></a>. J. High Energy Phys. 174 (2015), <a href="https://arxiv.org/abs/1502.02033" rel="nofollow">arXiv:1502.02033</a></li>
</ul>

<ul dir="auto">
<li>Henry Cohn, David de Laat, and Nando Leijenhorst, <a href="https://arxiv.org/abs/2403.16874" rel="nofollow"><em>Optimality of spherical codes via exact semidefinite programming bounds</em></a>, preprint, 2024. arXiv:2403.16874</li>
</ul>
