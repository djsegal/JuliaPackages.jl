<p dir="auto">This package defines an instance of the <code>AbstractFBCModel</code> interface (from the
package
<a href="https://github.com/COBREXA/AbstractFBCModels.jl">AbstractFBCModels.jl</a>) for
models saved as MAT files (typically produced by
<a href="https://opencobra.github.io/cobratoolbox/stable/" rel="nofollow">cobratoolbox</a> and
<a href="https://github.com/SysBioChalmers/RAVEN">RAVEN</a>). This allows you to easily
use the MAT formatted models in constraint-based modeling packages in Julia,
and convert them to other constraint-based metabolic modeling data formats.
<a href="https://github.com/JuliaIO/MAT.jl"><code>MAT.jl</code></a> is used for the lower-level work
with MatLab data.</p>
<p dir="auto">The primary purpose of this is to provide MAT model loading functionality for
<a href="https://github.com/LCSB-BioCore/COBREXA.jl">COBREXA.jl</a> and
<a href="https://github.com/LCSB-BioCore/FBCModelTests.jl">FBCModelTests.jl</a>, but is
otherwise completely generic and can be used independently of these packages.</p>
<p dir="auto">You should be able to load the <code>.mat</code> models (called <code>MATFBCModel</code>) via the
AbstractFBCModels interface:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import AbstractFBCModels as M
import MATFBCModels

model = M.load(&quot;my_model.mat&quot;)"><pre><span class="pl-k">import</span> AbstractFBCModels <span class="pl-k">as</span> M
<span class="pl-k">import</span> MATFBCModels

model <span class="pl-k">=</span> M<span class="pl-k">.</span><span class="pl-c1">load</span>(<span class="pl-s"><span class="pl-pds">"</span>my_model.mat<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Documentation of
<a href="https://github.com/COBREXA/AbstractFBCModels.jl">AbstractFBCModels.jl</a>
provides details on the use of the loaded model.</p>
