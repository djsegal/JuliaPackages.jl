<p dir="auto"><a href="https://github.com/toshiakiasakura/WeibullParetoDist.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/toshiakiasakura/WeibullParetoDist.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">This package enables you to implement the Weibull distribution parameterised to include the Pareto-approximated parameter.</p>
<p dir="auto">The following parameterisation of the Weibull distribution is implemented in Distribution.jl package, and see the source file <a href="https://github.com/JuliaStats/Distributions.jl/blob/master/src/univariate/continuous/weibull.jl">here</a>.<br>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$f(x;\alpha, \theta) = \frac{\alpha}{\theta} \left( \frac{x}{\theta} \right)^{\alpha-1} e^{-(x/\theta)^\alpha}$</math-renderer></p>
<p dir="auto">The Weibull distribution has a property to be power-law if <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\alpha$</math-renderer> takes less than 1 value. Following the definition <a href="https://par.nsf.gov/servlets/purl/10202111" rel="nofollow">Ivan et al., 2018</a> , the power-law distribution is power-law if the complementary cumulative function (that is a survival function), <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\bar{F(k)}$</math-renderer>, follows <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\bar{F}(k)=l(k)k^{-\alpha}$</math-renderer>.  Since the form of the complementary cumulative function for the Weibull distribution is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\bar{F(k)} = e^{-(x/\theta)^\alpha}$</math-renderer>, which satisfies the definition of power-law.</p>
<p dir="auto">However, when the Weibull distribution is fitted to the data which follows the power-law, the order of estimates of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\theta$</math-renderer> becomes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$10{^-3}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$10^{-8}$</math-renderer>. Also, the strong correlation between <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\alpha$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\theta$</math-renderer> is observed, which hampers the stable estimation.</p>
<p dir="auto">As <a href="https://pubmed.ncbi.nlm.nih.gov/36137054/" rel="nofollow">Akira et al., 2022</a> proved in the supplementary material, let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\kappa$</math-renderer> be <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\alpha/\theta^\alpha$</math-renderer>, and replace <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\kappa$</math-renderer> with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\alpha$</math-renderer>. At the region of 0 in log-log plot of the distribution, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\log \bar{F}(k)=-\kappa/\alpha e^{\alpha \log x} $</math-renderer>, the slope becomes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$-\kappa$</math-renderer>, which does not vary so much, and empirically the correlation between <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\alpha$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\kappa$</math-renderer> becomes very week.</p>
<p dir="auto">In this package, we implemented the above-parameterised version of the Weibull distribution.</p>

<p dir="auto">The relationship between <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\kappa$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e9ce8cbe703bbd38f190afcc432edd50">$\theta$</math-renderer>.<br>
