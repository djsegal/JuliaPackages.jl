<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">What is this Package for?</h1><a id="user-content-what-is-this-package-for" class="anchor" aria-label="Permalink: What is this Package for?" href="#what-is-this-package-for"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This is a package for Structural Equation Modeling.
It is still <em>in development</em>.
Models you can fit include</p>
<ul dir="auto">
<li>Linear SEM that can be specified in RAM (or LISREL) notation</li>
<li>ML, GLS and FIML estimation</li>
<li>Regularization</li>
<li>Multigroup SEM</li>
<li>Sums of arbitrary loss functions (everything the optimizer can handle).</li>
</ul>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">What are the merrits?</h1><a id="user-content-what-are-the-merrits" class="anchor" aria-label="Permalink: What are the merrits?" href="#what-are-the-merrits"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We provide fast objective functions, gradients, and for some cases hessians as well as approximations thereof.
As a user, you can easily define custom loss functions.
For those, you can decide to provide analytical gradients or use finite difference approximation / automatic differentiation.
You can choose to mix and match loss functions natively found in this package and those you provide.
In such cases, you optimize over a sum of different objectives (e.g. ML + Ridge).
This mix and match strategy also applies to gradients, where you may supply analytic gradients or opt for automatic differentiation or mix analytical and automatic differentiation.</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">You may consider using this package if:</h1><a id="user-content-you-may-consider-using-this-package-if" class="anchor" aria-label="Permalink: You may consider using this package if:" href="#you-may-consider-using-this-package-if"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>you want to extend SEM (e.g. add a new objective function) and need an extensible framework</li>
<li>you want to extend SEM, and your implementation needs to be fast (because you want to do a simulation, for example)</li>
<li>you want to fit the same model(s) to many datasets (bootstrapping, simulation studies)</li>
<li>you are planning a study and would like to do power simulations</li>
</ul>
<p dir="auto">The package makes use of</p>
<ul dir="auto">
<li>Symbolics.jl for symbolically precomputing parts of the objective and gradients to generate fast, specialized functions.</li>
<li>SparseArrays.jl to speed up symbolic computations.</li>
<li>Optim.jl and NLopt.jl to provide a range of different Optimizers/Linesearches.</li>
<li>FiniteDiff.jl and ForwardDiff.jl to provide gradients for user-defined loss functions.</li>
</ul>
