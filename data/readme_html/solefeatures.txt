<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">In a nutshell</h2><a id="user-content-in-a-nutshell" class="anchor" aria-label="Permalink: In a nutshell" href="#in-a-nutshell"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">SoleFeatures.jl provides tools for filter-based <strong>feature selection</strong> on <a href="https://en.wikipedia.org/wiki/Unstructured_data" rel="nofollow"><em>(un)structured</em> data</a>. At this time, the package provides:</p>
<ul dir="auto">
<li>3 native feature selection methods, plus a wrapper around python implementations from <em>scikit-learn</em> and <em>scikit-feature</em>;</li>
<li>Generalized feature selection methods that also apply to dimensional data (e.g., images or time-series), via a step of window-based flattening;</li>
<li>Specific methods for time-series feature selection, based on <a href="https://github.com/brendanjohnharris/Catch22.jl/">Catch22.jl</a>;</li>
<li>An easily extendible codebase, with abstraction layers similar to those of <em>scikit-learn</em>.</li>
</ul>

<p dir="auto">In machine learning, <em>feature selection</em> is the practice of <strong>reducing the size of a dataset</strong> by selecting only a subset of relevant features. This reduces the time that is necessary for learning models, and it generally leads to models that are more performant (in fact, irrelevant data often misleads machine learning algorithms). Despite the increasing importance of this data processing practice, not only there is not a proper package for it in the Julia environment, but there is also a <a href="https://discourse.julialang.org/t/univariate-feature-selection/87414/2" rel="nofollow">lack of implemented algorithms</a> for it.</p>
<p dir="auto">So, here comes SoleFeatures.jl, which offers a <strong>simple interface for performing feature selection with minimal effort on dataset structures implementing the Table.jl interface</strong>. The package also allows to access partial results of the feature selection processes (e.g., feature importance scores), offering complete control over the whole process. At this time, the package provides 3 native methods based on variance, correlation and statistical hypothesis testing, as well as a wrapper unlocking the majority of <em>filter-based</em> methods available in the python libraries <em>scikit-learn</em> and <em>scikit-feature</em>.</p>
<p dir="auto">These classical feature selection methods are designed for (un)supervised <em>structured</em> datasets, that is, tabular datasets with scalar features; however, an interesting characteristic of this package is the <strong>possibility of using these methods on <a href="https://en.wikipedia.org/wiki/Unstructured_data" rel="nofollow"><em>unstructured</em> data</a> as well</strong>, for example, with time-series and images. This generalization is possible via a prior <em>window-based flattening</em> step, where tailored measures are used to compress the non-scalar components of the data. For example, with time-series data, measures with solid statistical grounds from <a href="https://github.com/brendanjohnharris/Catch22.jl/">Catch22.jl</a> are used.</p>
<p dir="auto">All feature selection methods can also be applied to <a href="https://en.wikipedia.org/wiki/Multimodal_learning" rel="nofollow"><em>multimodal</em></a> datasets as well. Finally, the package offers an <strong>easily extendible codebase</strong>, with abstraction layers similar to those of <em>scikit-learn</em>, and was built as part of <a href="https://github.com/aclai-lab/Sole.jl"><em>Sole.jl</em></a>, a novel programming suite tailored for <em>unstructured symbolic learning</em>.</p>
