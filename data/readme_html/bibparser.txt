<p dir="auto">BibParser is a Julia package for parsing different bibliographic formats. The output are entries following the BibParser.jl structures. Instead of rewriting from scratch existing (and efficient) parsers in Julia, it is preferable to import them.</p>
<p dir="auto">This package is not meant to be used on its own. Please check Bibliography.jl for a package handling both import/export from various bibliographic formats.</p>
<p dir="auto">The output of an example parsing a BibTeX file can be found at <a href="https://baffier.fr/publications.html" rel="nofollow">baffier.fr/publications.html</a>.</p>

<p dir="auto">A new parser is in used since <code>v0.1.12</code>. It is almost complete. Currently missing features follow:</p>
<ul dir="auto">
<li>Applying the LaTeX commands from <code>@preamble</code>s entries to other entries</li>
<li>Storing <code>@preamble</code>, <code>@string</code>, <code>@comment</code>, and free text to enable the reconstruction of the original <code>.bib</code> file</li>
<li>Optional transformation of Unicode &lt;-&gt; LaTeX characters</li>
</ul>
