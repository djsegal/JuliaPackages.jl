<p dir="auto">PlotThemes is a package to spice up the plots made with <a href="https://github.com/JuliaPlots/Plots.jl">Plots.jl</a>. To install:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Pkg.add(&quot;PlotThemes&quot;)"><pre>Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>PlotThemes<span class="pl-pds">"</span></span>)</pre></div>

<p dir="auto">When using Plots, a theme can be set using the <code>theme</code> function:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Plots
theme(thm::Symbol; kwargs...)"><pre><span class="pl-k">using</span> Plots
<span class="pl-c1">theme</span>(thm<span class="pl-k">::</span><span class="pl-c1">Symbol</span>; kwargs<span class="pl-k">...</span>)</pre></div>
<p dir="auto"><code>theme</code> accepts any Plots <a href="https://docs.juliaplots.org/stable/attributes/" rel="nofollow">attribute</a> as keyword argument and sets its value as default for subsequent plots.</p>
<p dir="auto">Themes can be previewed using <code>Plots.showtheme(thm::Symbol)</code>:</p>

<p dir="auto">A theme specifies default values for different Plots <a href="https://docs.juliaplots.org/stable/attributes/" rel="nofollow">attributes</a>.
At the moment these are typically colors, palettes and colorgradients, but any Plots attribute can be controlled by a theme in general.
PRs for new themes very welcome! Adding a new theme (e.g. <code>mytheme</code>) is as easy as adding a new file (mytheme.jl) that contains at least the following line:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="_themes[:mytheme] = PlotTheme(; kwargs...)"><pre>_themes[<span class="pl-c1">:mytheme</span>] <span class="pl-k">=</span> <span class="pl-c1">PlotTheme</span>(; kwargs<span class="pl-k">...</span>)</pre></div>
<p dir="auto">The keyword arguments can be any collection of Plots attributes plus a colorgradient keyword argument.</p>
