<p dir="auto">SigMF - Signal Metadata Format</p>
<p dir="auto">This is a Julia package for working with metadata and storage associated with signals.</p>
<p dir="auto">The official spec may be found here: <a href="https://github.com/gnuradio/SigMF">https://github.com/gnuradio/SigMF</a></p>
<p dir="auto">The documentation serves as the "as-built" specification for the package, and the format is
pre-1.0 so we have reproduced the specifications used to develop the package.</p>
