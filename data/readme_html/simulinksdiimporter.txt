<p dir="auto">Package to import timeseries from a saved SDI Session (<code>.mldatx</code>-file) to julia.</p>
<p dir="auto">Main entry point is the <code>read_data</code> function. Given a SDI state as <code>mldatx</code> file
<code>data.mldatx</code> with contents</p>

<p dir="auto">the command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="read_data(data.mldatx, [r&quot;Voltage&quot;, &quot;Run 1&quot;, &quot;U&quot;])"><pre><span class="pl-c1">read_data</span>(data<span class="pl-k">.</span>mldatx, [<span class="pl-sr"><span class="pl-pds">r"</span>Voltage<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>Run 1<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>U<span class="pl-pds">"</span></span>])</pre></div>
<p dir="auto">will launch MATLAB in the background, export the timeseries to <code>data.export</code>
folder in CSV format and return a <code>DataFrame</code> of the <code>U_INV_dq</code> signal. If the
cached CSV is already available, it reads the CSV directly which is reasonably
fast.</p>
<p dir="auto">The <code>matlab</code> command(path) and the flags can be changed by changing
<code>SimulinkSDIImporter.MATLAB_EXEC</code> and <code>SimulinkSDIImporter.MATLAB_FLAGS</code>.</p>
<p dir="auto">Its possible launch the SDI to check the data without opening the MATLAB SDI
using <code>show_sdi(file)</code>.</p>
<p dir="auto"><code>show_structure(file)</code> prints a tree of all signals in the file.</p>

<p dir="auto">Per default, the data within <code>basedir/example.mldatx</code> will be exported to <code>basedir/example.mldatx.export</code>.
However, if the basedir contains a directory called <code>sdi_exports</code>, the exported data will be stored in <code>basedir/sdi_exports/example.mldatx.export</code>.</p>
