<p dir="auto">RewriteTools.jl is a utility for term rewriting. RewriteTools.jl is a fork of
<a href="https://github.com/JuliaSymbolics/SymbolicUtils.jl">SymbolicUtils.jl</a> version
1.17, preserving and simplifying only the functionality related to term
rewriting. The semantics of matcher and rewriter objects is simplified and more
uniform.  RewriteTools.jl is intended for use with custom ASTs that have syntax
which implements
<a href="https://github.com/willow-ahrens/SyntaxInterface.jl">SyntaxInterface.jl</a>.</p>

<p dir="auto">Rewrite rules match and transform an expression. A rule is written using the <code>@rule</code> macro and creates a callable <code>Rule</code> object.</p>

<p dir="auto">Here is a simple rewrite rule, that uses the formula for the double angle of the sine function:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using RewriteTools
r1 = @rule :call(sin, :call(*, 2, ~x)) =&gt; :(2 * sin($x) * cos($x))
r1(:(sin(2 * z)))"><pre lang="julia:rewrite1" class="notranslate"><code>using RewriteTools
r1 = @rule :call(sin, :call(*, 2, ~x)) =&gt; :(2 * sin($x) * cos($x))
r1(:(sin(2 * z)))
</code></pre></div>
<p dir="auto">The <code>@rule</code> macro pairs a matcher pattern with its consequent (<code>@rule matcher =&gt; consequent</code>). When an expression matches the matcher, it's rewritten to the consequent pattern. This rule signifies: if an expression fits the <code>sin(2x)</code> pattern, it's transformed to <code>2sin(x)cos(x)</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Rewriting</h3><a id="user-content-rewriting" class="anchor" aria-label="Permalink: Rewriting" href="#rewriting"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Rewriters are powerful tools in Julia for transforming expressions. They can be composed and chained together to create sophisticated transformations.</p>

<p dir="auto">A rewriter is any callable object that takes an expression and returns either a new expression or <code>nothing</code>. <code>Nothing</code> indicates no applicable changes. The <code>RewriteTools.Rewriters</code> module provides several types of rewriters:</p>
<ul dir="auto">
<li><code>Empty()</code>: Always returns <code>nothing</code>.</li>
<li><code>Chain(itr)</code>: Chains an iterator of rewriters into a single rewriter. Each rewriter is applied in sequence. If a rewriter returns <code>nothing</code>, it's treated as a no-change.</li>
<li><code>RestartedChain(itr)</code>: Similar to <code>Chain(itr)</code> but restarts from the first rewriter after a successful application.</li>
<li><code>IfElse(cond, rw1, rw2)</code>: Applies <code>rw1</code> if <code>cond</code> returns true, otherwise <code>rw2</code>.</li>
<li><code>If(cond, rw)</code>: Equivalent to <code>IfElse(cond, rw, Empty())</code>.</li>
<li><code>Prewalk(rw)</code>: Performs a pre-order traversal of an expression, applying <code>rw</code> at each step. <code>threaded</code> enables multithreading.</li>
<li><code>Postwalk(rw)</code>: Post-order traversal, applying <code>rw</code>.</li>
<li><code>Fixpoint(rw)</code>: Repeatedly applies <code>rw</code> until no further changes occur.</li>
<li><code>Prestep(rw)</code>: Recursively rewrites each node using <code>rw</code>. Only recurses if <code>rw</code> is not nothing.</li>
<li><code>Rewrite(rw)</code>: If <code>rw(x)</code> returns <code>nothing</code>, <code>Rewrite</code> returns <code>x</code> instead.</li>
<li><code>Cache(rw)</code>: Cache the result of rw.</li>
</ul>
