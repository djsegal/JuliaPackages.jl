<p dir="auto">This minimal package implements an atomic read-write array wrapping a standard <code>Array</code>. The only guarantee is that assignment with
<code>a[i] = v</code> is made atomically, i.e. without interference by reads of <code>a[i]</code> from other threads; that is, it is not possible to read a value while it is being written by another thread. Note that if <code>eltype(a)</code> is mutable, then there is no protection against <em>modifying</em> <code>a[i]</code> while it is being read.</p>
