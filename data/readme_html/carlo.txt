<p dir="auto">Carlo is a framework for developing high-performance, distributed (quantum) Monte Carlo simultations.
Its aim is to take care of model-independent tasks such as</p>
<ul dir="auto">
<li>autocorrelation and error analysis,</li>
<li>Monte-Carlo-aware MPI scheduling, and</li>
<li>checkpointing</li>
</ul>
<p dir="auto">while leaving all the flexibility of implementating Monte Carlo updates and estimators to you.</p>

<p dir="auto">To install the package, type</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg; Pkg.add(&quot;Carlo&quot;)"><pre><span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Carlo<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">The package itself does not include Monte Carlo algorithms. The quickest way to see how to implement one yourself is to check out the reference implementation for the <a href="https://github.com/lukas-weber/Ising.jl">Ising</a> model.</p>
<p dir="auto">If you are a practitioner, stay tuned for a (not yet released) stochastic series expansion or auxiliary field quantum Monte Carlo packages–or let me know if you are interested in testing it pre-release!</p>
