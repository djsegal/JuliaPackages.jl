<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">NamingConventions.jl is a lightweight and flexible Julia package that facilitates the conversion between various naming conventions commonly used in programming. The package supports the following conventions out-of-the-box:</p>
<ul dir="auto">
<li><code>CamelCase</code>: youTube</li>
<li><code>FlatCase</code>: youtube</li>
<li><code>KebabCase</code>: you-tube</li>
<li><code>PascalCase</code>: YouTube</li>
<li><code>ScreamingSnakeCase</code>: YOU_TUBE</li>
<li><code>SnakeCase</code>: you_tube</li>
</ul>
<p dir="auto">The flexibility of this package lies in its extensibility. By implementing your own encoding and decoding logic, you can create tailored naming conventions that fit your specific needs. All you need to do is define a new type that inherits from <code>AbstractNamingConvention</code> and implement the <code>encode</code> and <code>decode</code> functions.</p>

<p dir="auto">You can define your own naming conventions by creating a new type and implementing the required methods:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NamingConventions

struct ReversePascalCase &lt;: AbstractNamingConvention end

function NamingConventions.encode(::Type{ReversePascalCase}, v::AbstractString)
    return join([lowercase(first(s)) * uppercase(s[2:end]) for s in v], &quot;&quot;)
end

function NamingConventions.decode(::Type{ReversePascalCase}, s::AbstractString)
    return lowercase.(split(s, r&quot;(?&lt;=[A-Z])(?=[a-z])|(?&lt;=[a-z])(?=[a-z][A-Z])&quot;))
end

# convert from camelCase to ReversePascalCase
@show NamingConventions.convert(CamelCase, ReversePascalCase, &quot;camelCase&quot;) # output: &quot;cAMELcASE&quot;
