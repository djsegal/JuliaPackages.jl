<p dir="auto">This package implements a Bayesian regression for size-and-shape data, based on "Di Noia, A., Mastrantonio, G., and Jona Lasinio, G., “Bayesian Size-and-Shape regression modelling”, <i>arXiv e-prints</i>, 2023". To install, simply do</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ]

pkg&gt; add BayesSizeAndShape"><pre>julia<span class="pl-k">&gt;</span> ]

pkg<span class="pl-k">&gt;</span> add BayesSizeAndShape</pre></div>
<p dir="auto">at the julia prompt.
At the present moment, the package implements models for two- or three- dimensional data with reflection information. All the objects use <code>Float64</code> and <code>Int64</code> numbers</p>
<p dir="auto">The function to use is <code>SizeAndShapeWithReflectionMCMC</code></p>
<h1 dir="auto"></h1>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><strong>Basic Usage</strong></h2><a id="user-content-basic-usage" class="anchor" aria-label="Permalink: Basic Usage" href="#basic-usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To fix notation, we assume the following</p>
<ul dir="auto">
<li><code>n</code> be the number of objects;</li>
<li><code>k+1</code> be the number of recorded landmark for each object</li>
<li><code>p</code> be the dimension of each landmark (only p=2 or p=3)</li>
</ul>
<p dir="auto">The model estimated is
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$$\text{vec}(\mathbf{Y}_i \mathbf{R}_i') \sim\mathcal{N}_{k p}\left(  \text{vec}\left(\sum_{h=1}^dz_{ih}\mathbf{B}_h\right), \mathbf{I}_p \otimes \boldsymbol{\Sigma}\right), ,\qquad i = 1, \dots , n$$</math-renderer>
where</p>
<ul dir="auto">
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$\mathbf{Y}_i$</math-renderer> is the i-th size-and-shape object;</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$z_{ih}$</math-renderer> is a value of a covariate</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$\mathbf{B}_h$</math-renderer> is a matrix that contains regressive coefficients</li>
<li>
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$\boldsymbol{\Sigma}$</math-renderer> is a covariance matrix</li>
</ul>
<p dir="auto">The prior distributions are
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$$[\mathbf{B}_h]_{jl} \sim N(m,v),\qquad \boldsymbol{\Sigma} \sim IW(\nu, \Psi)$$</math-renderer></p>

<p dir="auto">Posterior samples are obtained with the function <code>SizeAndShapeWithReflectionMCMC</code>.</p>
<p dir="auto">The parameters are (in order)</p>
<ul dir="auto">
<li>a three-dimensional <code>Array</code> of data;</li>
<li>a <code>formula</code>, where on the left-hand side there must be "landmarks" and on the right-hand side there is the actual regressive formula - an intercept is needed;</li>
<li>a <code>DataFrame</code> of covariates. The formula search for the covariates in the <code>DataFrame</code> column names;</li>
<li>a <code>NamedTuple</code> with <code>iter</code>, <code>burnin</code>, and <code>thin</code> values of the MCMC algorithm</li>
<li>a <code>Normal</code> distribution that is used as prior for all regressive coefficients</li>
<li>an <code>InverseWishart</code> distribution that is used as prior for the covariance matrix.</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; outmcmc = SizeAndShapeWithReflectionMCMC(

<p dir="auto">It is possible to predict the <strong>mean configuration</strong> by using

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; predictive_mean = sample_predictive_zbr(outmcmc);"><pre>julia<span class="pl-k">&gt;</span> predictive_mean <span class="pl-k">=</span> <span class="pl-c1">sample_predictive_zbr</span>(outmcmc);</pre></div>
<p dir="auto">which compute the posterior samples of
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8ae59b2698455233aac9a929ce035816">$$\boldsymbol{\mu}_i^* = \text{vec}\left(\sum_{h=1}^dz_{ih}\mathbf{B}_h \mathbf{R}_i\right)$$</math-renderer>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; predictive_obs = sample_predictive_zbr_plus_epsilon(outmcmc);"><pre>julia<span class="pl-k">&gt;</span> predictive_obs <span class="pl-k">=</span> <span class="pl-c1">sample_predictive_zbr_plus_epsilon</span>(outmcmc);</pre></div>
