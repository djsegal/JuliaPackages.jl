<p dir="auto"><code>EwaldSummations.jl</code> is an implementation of the basic Ewald summation algorithm, including Ewald3D and Ewald2D. This package also include the naive approach: sum directly over periodic directions.
Specially, for dielectric confined quasi-2D systems, this package provide a set of tools based on the image charge method, combining with the Ewald2D or Ewald3D-ELC method.</p>
<p dir="auto">This package is designed to provide standard/correct results of electrostatic interaction in charged particle systems, and can be used as a tool box when developing new algorithms.
For some of the implemented methods, the package support parallel computation by <code>Base.Threads</code>, start that by <code>julia -t 8 your_script.jl</code>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Numerical Methods</h2><a id="user-content-numerical-methods" class="anchor" aria-label="Permalink: Numerical Methods" href="#numerical-methods"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In this package, we provide various methods to calculate the electrostatic interaction energy of charged particle systems. For system without dielectric mismatch, the following methods are available:</p>
<ul dir="auto">
<li>Direction summation: sum directly over periodic directions (3D and quasi-2D)</li>
<li>Ewald3D: the standard Ewald summation for 3D systems</li>
<li>Ewald2D: the standard Ewald summation for 2D systems</li>
</ul>
<p dir="auto">Then for quasi-2D systems confined by dielectric mismatch, we combine the image charge method and the methods above, given by</p>
<ul dir="auto">
<li>Image charge reflection: generating the image charge series according to the dielectric mismatch</li>
<li>ICM + direct summation: combining the image charge method and the direct summation</li>
<li>ICM + Ewald2D: combining the image charge method and the Ewald2D method</li>
<li>ICM + Ewald3D + ELC: extending the quasi-2D system as triply periodic, and calculate the energy via Ewald3D and electrostatic layer correction (ELC)</li>
</ul>
<p dir="auto">For detailed numerical formula, please refer to the reference<sup><a href="#user-content-fn-yuan-815df16eca1f2092130755cab238b897" id="user-content-fnref-yuan-815df16eca1f2092130755cab238b897" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.</p>
