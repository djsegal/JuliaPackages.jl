<p dir="auto"><code>PkgMirrors.jl</code> is a client for boosting your download by using a mirror when you have a slow connection to
GitHub (for example, in China).</p>
<p dir="auto">Current supported mirrors (see <a href="./data/mirror_list.txt">mirror_list.txt</a>):</p>
<ul dir="auto">
<li>ZJU (<a href="https://mirrors.zju.edu.cn/julia/" rel="nofollow">https://mirrors.zju.edu.cn/julia/</a>)</li>
<li>USTC (<a href="https://mirrors.ustc.edu.cn/julia/" rel="nofollow">https://mirrors.ustc.edu.cn/julia/</a>)</li>
</ul>

<p dir="auto"><strong>NOTE: This package will only work with Pkg3, which means you need to run Julia 0.7+ to use it.</strong></p>
<p dir="auto">The recommended way to install this package (starting from Julia v1.1):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; # Type &quot;]&quot; to enter Pkg REPL-mode.

<p dir="auto">You can find that the URL of the git repo for General registry has been modified to the one <code>PkgMirrors.jl</code>
provides.</p>
<p dir="auto">If a package is not on the mirror it will have a fallback to use <code>git clone</code> from GitHub.</p>
<p dir="auto">When you exit Julia the changes to your registries will be undone automatically:</p>
