<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is HTTR.jl</h2><a id="user-content-what-is-httrjl" class="anchor" aria-label="Permalink: What is HTTR.jl" href="#what-is-httrjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>HTTR.jl</code> is a 100% Julia implementation of the R <a href="https://github.com/r-lib/httr2">httr2</a> package.</p>
<p dir="auto">The main purpose of <code>HTTR.jl</code> is to bridge the gap between the web and data analysis in Julia, offering a flexible and efficient interface for making HTTP requests while adhering to web standards. It leverages packages like <a href="https://github.com/JuliaIO/EzXML.jl"><code>EzXML.jl</code></a>, <a href="https://github.com/JuliaWeb/HTTP.jl"><code>HTTP.jl</code></a>, <a href="https://github.com/JuliaIO/JLD2.jl"><code>JLD2.jl</code></a>, <a href="https://github.com/quinnj/JSON3.jl"><code>JSON3.jl</code></a>, and <a href="https://github.com/JuliaWeb/URIs.jl"><code>URIs.jl</code></a> to create and handle requests and manage various types of web data.</p>

<p dir="auto">Creating and modifying the request:</p>
<p dir="auto"><strong><code>HTTR.Request</code></strong> is the equivalent to R's <code>httr2_request</code> S3 class. Several functions can be used to modify the request returned by this request. These functions can modify the request's methods, body, headers, etc.</p>
<p dir="auto">The <strong><code>HTTR.request()</code></strong> function creates the <strong><code>HTTR.Request</code></strong> type. Without a body the request method defaults to GET. By using the <strong><code>@chain</code></strong> macro, a request can be performed then the response can be then read as a <strong><code>String</code></strong> using the <strong><code>resp_body_string()</code></strong> function. If no response function is used the request will return the response as the type <a href="https://juliaweb.github.io/HTTP.jl/stable/reference/#HTTP.Messages.Response" rel="nofollow"><strong><code>HTTP.Messages.Response</code></strong></a> from the <code>HTTP.jl</code> package:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using HTTR, Chain

@chain request(&quot;https://dummy.restapiexample.com/api/v1/employees&quot;) begin
    req_perform()
    resp_body_string()
    println()
end"><pre><span class="pl-k">using</span> HTTR, Chain

<p dir="auto">To create a POST request add a request body to the request, one way to do this is using the <strong><code>req_body_json()</code></strong> function and adding the content type of <code>application/json</code>, so that the request can be recognized as json. The response can be then read as a json using the <strong><code>resp_body_json()</code></strong> function:</p>
