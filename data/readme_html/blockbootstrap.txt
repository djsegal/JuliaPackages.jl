<p dir="auto">Statistical block bootstrap library for Julia. Created by William Davis and Maggie Avery.</p>
<p dir="auto"><code>BlockBootstrap.jl</code> is a Julia package for calculating and bootstrapping uncertainties statistics on time-series data.</p>

<p dir="auto">Say we want to estimate the parameter <a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/a717fd6acf0c4cde8c6b796b10c0559b7b3c80ef73e6f9f3a22dd3a7aee0a2a8/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f253543616c706861"><img src="https://camo.githubusercontent.com/a717fd6acf0c4cde8c6b796b10c0559b7b3c80ef73e6f9f3a22dd3a7aee0a2a8/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f253543616c706861" alt="equation" data-canonical-src="https://latex.codecogs.com/gif.latex?%5Calpha" style="max-width: 100%;"></a> from the realization, and we also want to find the incertainties on that estimation. Define a function handle that returns the statistic of choice (in this example it is <code>slopeStatisticSet()</code>, and pass it to the block bootstrapping function <code>bootstrapStatistic()</code>.</p>
