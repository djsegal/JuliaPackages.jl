<p dir="auto">Allows one to fit a gaussian mixture model using Truncated Gaussian Kernels. Works only for Gaussians truncated to lie inside some box.</p>
<blockquote>
<p dir="auto">The algorithm is adapted from <a href="https://www.sciencedirect.com/science/article/abs/pii/S0167947312001156" rel="nofollow">this paper by Lee &amp; Scott</a>, as well as the algorithm for computing the first two moments of a truncated gaussian with full covariances.</p>
</blockquote>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Annealing Schedules</h2><a id="user-content-annealing-schedules" class="anchor" aria-label="Permalink: Annealing Schedules" href="#annealing-schedules"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">One can use annealing schedules to guide fits better, especially for flatter distributions - though the standard vanilla algorithm does a decent job as well. <a href="https://arxiv.org/abs/1206.6427" rel="nofollow">Naim &amp; Gildea</a> propose a deterministic anti-annealing mechanism that alows one to fit better when many of the gaussian components overlap (in the context of non-truncated GMM).</p>
<p dir="auto">An annealing schedule is a list <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5f259a9a0c8d8a6da75c329c334fee03">$\beta_n$</math-renderer>​​, such that it changes the responsibilities of the points for a given proposed GMM:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="5f259a9a0c8d8a6da75c329c334fee03">$$w^{(n)}_{i k}=\frac{\left(\alpha_k^{(n)} P\left(x_i \mid z_i=k, \Theta^{(n)}\right)\right)^{\beta_n}}{\sum_{m=1}^{K} \left(\alpha_m^{(n)} P\left(x_i \mid z_i=m, \Theta^{(n)}\right)\right)^{\beta_n}}$$</math-renderer>
<p dir="auto">Here is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5f259a9a0c8d8a6da75c329c334fee03">$n$</math-renderer> indexes the EM step made. The standard EM-algorithm is the case where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5f259a9a0c8d8a6da75c329c334fee03">$\beta_n = 1$</math-renderer></p>

<p dir="auto">In <code>TruncatedGaussianMixtures.jl</code> the way to add annealing schedules is by instantiating an annealing schedule object with the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5f259a9a0c8d8a6da75c329c334fee03">$\beta_n$</math-renderer> list we would like. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="β = vcat((0.0:0.01:1.5), 1.5:(-0.01):1.0, ones(100))
schedule = AnnealingSchedule(β)"><pre>β <span class="pl-k">=</span> <span class="pl-c1">vcat</span>((<span class="pl-c1">0.0</span><span class="pl-k">:</span><span class="pl-c1">0.01</span><span class="pl-k">:</span><span class="pl-c1">1.5</span>), <span class="pl-c1">1.5</span><span class="pl-k">:</span>(<span class="pl-k">-</span><span class="pl-c1">0.01</span>)<span class="pl-k">:</span><span class="pl-c1">1.0</span>, <span class="pl-c1">ones</span>(<span class="pl-c1">100</span>))
schedule <span class="pl-k">=</span> <span class="pl-c1">AnnealingSchedule</span>(β)</pre></div>
<p dir="auto">We can then use the schedule for fitting the TGMM</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="fit_gmm(X, K, a, b, schedule; cov=:full, tol=1e-3, convergence=false)"><pre><span class="pl-c1">fit_gmm</span>(X, K, a, b, schedule; cov<span class="pl-k">=</span><span class="pl-c1">:full</span>, tol<span class="pl-k">=</span><span class="pl-c1">1e-3</span>, convergence<span class="pl-k">=</span><span class="pl-c1">false</span>)</pre></div>
<p dir="auto">The <code>convergence=false</code> parameter prevents the fitting algorithm from stopping based on some convergence criteria and allows the whole schedule to run its course.</p>
