<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package solves the incompressible Navier-Stokes equations using SUPG and VMS method. VMS has been originally introduced by <a href="@cite">Hughes2000</a>. In specific, a linearized and segregated version of the SUPG (following the steps illustrated by <a href="@cite">Janssens2014</a>) and VMS is solved.</p>
<p dir="auto">The methods belong to the Large Eddy Simulation (LES) family. The package can solve the <code>Taylor Green Vortices</code> (only 2D), <code>Lid Driven Cavity Flow</code> (only 2D), <code>Cylinder vortex shedding</code> (only 2D), and general <code>Airfoils</code> (2D and 3D).</p>
<p dir="auto">It works fully in parallel (tested up to 80-CORES). It is specialized for the resolution of flow over airfoils, testing the capability of detecting the Laminar Separation Bubble. It is equipped with some utility <code>modules</code> for reading the output files and creating proper initial conditions.</p>

<p dir="auto">For a complete and smooth experience is suggested to install the free software <a href="https://www.paraview.org/" rel="nofollow">ParaView</a> which allows to graphically visualize the results and open <code>.vtu</code> and <code>.pvtu</code> files.

<ul dir="auto">
<li>Implementation of SUPG and VMS formulation for same-order elements for velocity and pressure</li>
<li>Solve 3D airfoils geometries, time-dependend, fully parallelized code</li>
<li>Using custom Meshes created with <a href="https://gmsh.info/" rel="nofollow"><code>gmsh</code></a>. For airfoils the package <code>AirfoilGmsh.jl</code> has been developed for speeding up the process</li>
<li>Solve 2D and 3D cases</li>
<li>Possibility of choosing the backend thanks to <code>PartitionedArrays.jl</code>. It can be run in the <code>REPL</code> for debugging or in <code>MPI</code></li>
</ul>
