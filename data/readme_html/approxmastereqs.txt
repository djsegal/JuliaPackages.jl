<p dir="auto">This is a package to perform the numerical integration of some Approximated Master Equations for the dynamics of binary variables in graphs. It contains two different methods: the Cavity Master Equation (CME) <a href="#1">[1]</a> <a href="#2">[2]</a> <a href="#3">[3]</a> and the Conditional Dynamic Approximation (CDA) <a href="#4">[4]</a>. Provided a model and some network representing the interactions, the package estimates the local probabilities of observing a specific configuration of the variables at time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$t$</math-renderer>.</p>
<p dir="auto">The two main functions implemented in the package so far are <code>CME_KSAT</code> and <code>CDA_KSAT</code>, with the following arguments</p>

<p dir="auto">If the user does not provide a graph to the functions <code>CME_KSAT</code> or <code>CDA_KSAT</code>, an empty graph is taken as default. The functions then expect to receive three numbers: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$N$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$K$</math-renderer>, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$\alpha$</math-renderer>. These, together with the optional seed_g (seed for the random generator), are used to create an Erdös-Rényi hypergraph with size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$N$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$K$</math-renderer> nodes per hyperedge and mean node connectivity <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$c=\alpha K$</math-renderer>.</p>
<p dir="auto">The couplings or links for the K-SAT boolean formula can be input via the parameter <code>links::Matrix{Float64}</code>. The indexes are <code>links[he, i]</code> with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$he=1, \ldots, M$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$i=1, \ldots, K$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$M$</math-renderer> is the number of hyperedges in the graph. If the user does not input any matrix of links, the default is to randomly choose one.</p>

# This is the rate of FMS algorithm for KSAT
function rate_FMS_KSAT(Ep::Int64, Em::Int64, eta::Float64, avE::Float64, K::Number, N::Int64)
    dE = Em - Ep
    if dE &gt; 0
        return Ep * N / K / avE * eta ^ dE
    else
        return Ep * N / K / avE
    end
end

<p dir="auto">At this point, the user should be able to run a simple example and collect the output of the functions <code>CME_KSAT</code> or <code>CDA_KSAT</code>. These functions return an object of type <code>SciMLBase.ODESolution</code> (see <a href="https://docs.sciml.ai/DiffEqDocs/stable/types/ode_types/#Solution-Type" rel="nofollow">here</a>) with the solution saved in <code>tspan</code> sampled at intervals of length <code>dts</code>. The latter is a parameter of the functions <code>CME_KSAT</code> and <code>CDA_KSAT</code> (<code>dt_s::Float64=0.1</code>).</p>
<p dir="auto">To get other quantities the user should use callbacks. This is allowed by the package <a href="https://docs.sciml.ai/DiffEqCallbacks/stable/" rel="nofollow">DiffEqCallbacks</a>. A stopping condition is implemented by default that stops the integration when the energy goes below a given value <code>eth</code>. This is also a parameter of the functions <code>CME_KSAT</code> and <code>CDA_KSAT</code> (<code>eth::Float64=1e-6</code>).</p>
<p dir="auto">The following shows how to save some quantity at each integration step. This is implemented via a <code>SavingCallback</code> (see <a href="https://docs.sciml.ai/DiffEqCallbacks/stable/output_saving/#DiffEqCallbacks.SavingCallback" rel="nofollow">here</a>). The general form of a function to be used as a callback is</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function save_something(u, t, integrator)

<p dir="auto">The user could:</p>
<ul dir="auto">
<li>
<code>get_graph(integrator)</code>  returns the <code>graph::HGraph</code> variable</li>
<li>
<code>reshape_u_to_probs_CME(u::Vector{Float64}, integrator)</code>  reshapes the vector <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3bc6e5405d9bb15e24a2a6e9c42adfd9">$u$</math-renderer> to the probabilities involved in the CME: 'p_cav' and 'probi' (see Section 4).</li>
