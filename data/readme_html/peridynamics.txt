<ul dir="auto">
<li>🎯 Dynamic and quasi-static analysis</li>
<li>🪨 Multiple peridynamics formulations and material models</li>
<li>🎳 Multibody contact simulations</li>
<li>🤓 User friendly API that captures many errors before submitting simulations</li>
<li>🚀 Enhanced HPC capabilities with MPI or multithreading</li>
</ul>

<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="add Peridynamics"><pre class="notranslate"><code>add Peridynamics
</code></pre></div>

<p dir="auto">To run the dynamic tensile test simulation shown above, just 7 lines of code are needed:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="body = Body(BBMaterial(), &quot;TensileTestMesh.inp&quot;)

velocity_bc!(t -&gt; -0.6, body, :bottom, 1)
velocity_bc!(t -&gt; 0.6, body, :top, 1)
vv = VelocityVerlet(steps=500)
job = Job(body, vv; path=&quot;results/tension_dynamic&quot;)
submit(job)"><pre>body <span class="pl-k">=</span> <span class="pl-c1">Body</span>(<span class="pl-c1">BBMaterial</span>(), <span class="pl-s"><span class="pl-pds">"</span>TensileTestMesh.inp<span class="pl-pds">"</span></span>)
<span class="pl-c1">material!</span>(body; horizon<span class="pl-k">=</span><span class="pl-c1">0.01</span>, rho<span class="pl-k">=</span><span class="pl-c1">2700</span>, E<span class="pl-k">=</span><span class="pl-c1">70e9</span>, Gc<span class="pl-k">=</span><span class="pl-c1">100</span>)
<span class="pl-c1">velocity_bc!</span>(t <span class="pl-k">-&gt;</span> <span class="pl-k">-</span><span class="pl-c1">0.6</span>, body, <span class="pl-c1">:bottom</span>, <span class="pl-c1">1</span>)
<span class="pl-c1">velocity_bc!</span>(t <span class="pl-k">-&gt;</span> <span class="pl-c1">0.6</span>, body, <span class="pl-c1">:top</span>, <span class="pl-c1">1</span>)

<p dir="auto">Take a look at the <a href="https://kaipartmann.github.io/Peridynamics.jl/stable/generated/tutorial_tension_dynfrac/" rel="nofollow">tutorial of the tensile test</a> for more details on this example.</p>
<p dir="auto">If you want to run this example with multithreading, just start Julia with more than 1 thread.
To use MPI, you can create a script containing the <strong>same code without changes</strong> and run it with:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mpiexec -n 6 julia --project path/to/script.jl"><pre>mpiexec -n 6 julia --project path/to/script.jl</pre></div>
<p dir="auto">Please take a look at the <a href="https://kaipartmann.github.io/Peridynamics.jl/dev/howto_mpi/" rel="nofollow">how-to guide on MPI</a> for more details.</p>
