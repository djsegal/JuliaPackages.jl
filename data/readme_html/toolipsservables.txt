<p dir="auto"><code>ToolipsServables</code> provides an extensible HTML and CSS templating platform centralized on parametric typing and extensibility. This package provides a simple API for creating beautiful websites to write to responses through both files and a <em>julianized</em> API.</p>

<p dir="auto">The most crucial goal of this package is to provide a parametric HTML templating framework for Julia. This is all facilitated through the <code>Component</code>. The <code>Component</code> is equivalent to an <code>HTML</code> element. For example we have the <code>HTML</code> <code>div</code> and the <code>ToolipsServables</code> <code>div</code>:</p>

<p dir="auto">Along with regular HTML element components, <code>ToolipsServables</code> also includes <code>KeyFrames</code> for creating <code>@keyframe</code> CSS animations and <code>Style</code> for creating style classes with CSS. <p dir="auto">There are several ways to contribute to the ParametricProcesses package.</p>
<ul dir="auto">
<li>submitting <a href="https://github.com/ChifiSource/ToolipsServables.jl/issues">issues</a></li>
<li>creating packages which use <code>ToolipsServables</code></li>
<li>forking and pull-requesting your changes to this code</li>
<li>trying other <a href="https://github.com/ChifiSource">chifi</a> projects.</li>
<li>contributing to other <a href="https:://github.com/ChifiSource">chifi</a> projects (gives more attention here).</li>
</ul>
<p dir="auto">We are not super picky on contributions, as the goal of chifi is to get more people involved in computing. However, if you want your code merged there are definitely a few things to be aware of before contributing to this package.</p>
<ul dir="auto">
<li>If there is no issue for what you want to do, create an issue.</li>
<li>If you have multiple issues, submit multiple issues rather than typing each issue into one issue.</li>
<li>Make sure the issue you are solving or feature you want to implement is still feasible on Unstable -- this is the top-level development branch which represents the latest unstable changes.</li>
<li>Please format your documentation using the technique presented in the rest of the file.</li>
<li>Make sure Pkg.test("ToolipsServables") works with your version of ToolipsServables before making a pull-request.</li>
</ul>
