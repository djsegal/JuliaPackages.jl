<p dir="auto">First you need to install <a href="https://docs.julialang.org/en/v1/manual/getting-started/" rel="nofollow">Julia</a>. From within Julia, enter the package manager by typing <code>]</code>. Then install ConicQKD:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add https://github.com/araujoms/ConicQKD.jl"><pre>pkg<span class="pl-k">&gt;</span> add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>araujoms<span class="pl-k">/</span>ConicQKD<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">This will automatically install all dependencies. The main one is the solver <a href="https://github.com/jump-dev/Hypatia.jl">Hypatia</a>, which this package extends.</p>

<p dir="auto">Several examples are available in the <code>examples</code> folder. They are all formulated using the modeller <a href="https://jump.dev/JuMP.jl/stable/tutorials/getting_started/getting_started_with_JuMP/" rel="nofollow">JuMP</a>. To constraint a quantum state <code>ρ</code> to belong to the QKD cone with CP maps <code>Ghat</code> and <code>Zhat</code> the syntax is</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@constraint(model, [h; ρ_vec] in EpiQKDTriCone{T,R}(Ghat, Zhat, 1 + vec_dim; blocks))"><pre><span class="pl-c1">@constraint</span>(model, [h; ρ_vec] <span class="pl-k">in</span> <span class="pl-c1">EpiQKDTriCone</span><span class="pl-c1">{T,R}</span>(Ghat, Zhat, <span class="pl-c1">1</span> <span class="pl-k">+</span> vec_dim; blocks))</pre></div>
<ul dir="auto">
<li><code>model</code> is the JuMP optimization model being used</li>
<li><code>h</code> is a variable which will have the conditional entropy in base e</li>
<li><code>ρ_vec</code> is a vectorization of <code>ρ</code> in the svec format (we provided a function <code>svec</code> to compute it).</li>
<li><code>T</code> is the floating point type to be used (e.g. <code>Float64</code>, <code>Double64</code>, <code>Float128</code>, <code>BigFloat</code>, etc.)</li>
<li><code>R</code> is either equal to <code>T</code>, in order to optimize over real matrices, or equal to <code>Complex{T}</code> in order to optimize over complex matrices.</li>
<li><code>Ghat</code> and <code>Zhat</code> encode the CP maps as vectors of Kraus operators.</li>
<li><code>vec_dim</code> is the number of real parameters of <code>ρ</code>, i.e., either d^2 or d(d+1)/2 for the complex and real cases, respectively.</li>
<li><code>blocks</code> is an optional keyword argument specifying the block structure of <code>Zhat</code> as a vector of vectors. For example, if <code>Zhat</code> maps a 4x4 <code>ρ</code> to a matrix <code>M</code> such that only <code>M[1:2,1:2]</code> and <code>M[3:4,3:4]</code> are nonzero, then <code>blocks</code> should be <code>[1:2, 3:4]</code>. If this argument is omitted the computation will be considerably slower.</li>
</ul>
