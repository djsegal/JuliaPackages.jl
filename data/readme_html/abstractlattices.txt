<p dir="auto">This module defines <code>∨</code> (for join) and <code>∧</code> (for meet)
as binary operators so other modules can import them for their own purposes.</p>
<p dir="auto">We also define <code>dist</code> so distance can be defined in various modules.</p>

<p dir="auto">The  <code>∨</code> and <code>∧</code> operations are explicitly defined for <code>Bool</code> values. That is
<code>true ∨ false</code> evaluates to <code>true</code>, and so forth.</p>
