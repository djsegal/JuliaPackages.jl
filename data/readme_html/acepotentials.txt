<p dir="auto"><code>ACEpotentials.jl</code> facilitates the creation and use of atomic cluster expansion (ACE) interatomic potentials. See <a href="https://acesuit.github.io/ACEpotentials.jl/dev" rel="nofollow">the documentation</a> for installation instructions, tutorials, and more.</p>

<ul dir="auto">
<li>Version 0.6.x uses <code>ACE1.jl</code> as a backend. It is mature and suitable for linear models with few species. This is not longer actively developed, but critical bugfixes can still be provided.  <a href="https://acesuit.github.io/ACEpotentials.jl/v0.6/" rel="nofollow">[docs-v0.6]</a></li>
<li>Version 0.7.x is reserved</li>
<li>Version 0.8.x and onwards provides a new and much more flexible implementation, and integrates with the <a href="https://github.com/JuliaMolSim/AtomsBase.jl">AtomsBase</a> ecosystem. Most but not all features from 0.6.x have been ported to this re-implementation. Usability should be the same or improved for most end-users. For developers this provides a much more flexible framework for experimentation. <a href="https://acesuit.github.io/ACEpotentials.jl/dev/" rel="nofollow">[docs-v0.8]</a></li>
</ul>
