<p dir="auto"><strong>Warning</strong>: This is package is under development and the computed values should be treated with caution.</p>
<p dir="auto">Julia library for computing risk measures for random variables. The random variable represents <em>profits</em> or <em>rewards</em> that are to be maximized. Also the computed risk value is preferable when it is greater.</p>
<p dir="auto">All risk measures get more conservative with an <em>increasing</em> risk level alpha.</p>
<p dir="auto">The following risk measures are currently supported</p>
<ul dir="auto">
<li>VaR: Value at risk</li>
<li>CVaR: Conditional value at risk</li>
<li>ERM: Entropic risk measure</li>
<li>EVaR: Entropic value at risk</li>
</ul>
<p dir="auto">The focus is currently on random variables with categorical (discrete) probability distributions, but continuous probabilty distributions may be supported in the future too.</p>
<p dir="auto">In general, the smaller value of the risk parameter indicates that the risk measure is less risk-averse or that it is closer to the expectation operator.</p>

<p dir="auto">Extended methods <code>VaR_e</code>, <code>CVaR_e</code>, and <code>EVaR_e</code> also return additional statistics and values, such as the distribution that attains the risk value and the optimal <code>β</code> in EVaR.</p>
<p dir="auto">Please see the unit tests for examples of how this package can be used to compute the risk.</p>
