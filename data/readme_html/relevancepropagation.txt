<p dir="auto">Julia implementation of <a href="https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0130140" rel="nofollow">Layerwise Relevance Propagation</a> (LRP)
and <a href="https://www.nature.com/articles/s42256-023-00711-8" rel="nofollow">Concept Relevance Propagation</a> (CRP)
for use with <a href="https://fluxml.ai" rel="nofollow">Flux.jl</a> models.</p>
<p dir="auto">This package is part of the <a href="https://github.com/Julia-XAI">Julia-XAI ecosystem</a> and compatible with
<a href="https://github.com/Julia-XAI/ExplainableAI.jl">ExplainableAI.jl</a>.</p>

<p dir="auto">Let's use LRP to explain why an image of a castle gets classified as such
using a pre-trained VGG16 model from <a href="https://github.com/FluxML/Metalhead.jl">Metalhead.jl</a>:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://raw.githubusercontent.com/Julia-XAI/ExplainableAI.jl/gh-pages/assets/heatmaps/castle.jpg"><img src="https://raw.githubusercontent.com/Julia-XAI/ExplainableAI.jl/gh-pages/assets/heatmaps/castle.jpg" alt="" style="max-width: 100%;"></a></p>
