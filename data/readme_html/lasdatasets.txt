<p dir="auto">A Julia package for reading and writing <em>LAS</em> data. <em>LAS</em> is a public file format for saving and loading 3D point cloud data, and its source repository can be found <a href="https://github.com/ASPRSorg/LAS">here</a>. This package currently supports <em>LAS</em> specifications 1.1-1.4 (see <a href="https://www.asprs.org/wp-content/uploads/2019/03/LAS_1_4_r14.pdf" rel="nofollow">here</a> for the 1.4 spec.)</p>
<p dir="auto">Some key features included in this package are:</p>
<ul dir="auto">
<li>High-level functions for reading and writing <em>LAS</em> data in tabular formats using <a href="https://github.com/JuliaData/TypedTables.jl">TypedTables.jl</a></li>
<li>Automatic detection of <em>LAS</em> point formats from data</li>
<li>Reading and writing <em>Julia</em>-native structs as <em>Variable Length Records</em> (<em>VLRs</em>) and <em>Extended Variable Length Records</em> (<em>EVLRs</em>)</li>
<li>Easy manipulation of file header properties</li>
</ul>
