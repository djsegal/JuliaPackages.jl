<hr>
<p dir="auto"><strong>SystemLevelControl</strong> is a <a href="https://julialang.org/" rel="nofollow">Julia</a> toolbox for synthesizing controllers using the <a href="https://arxiv.org/abs/1904.01634" rel="nofollow">System Level Synthesis</a> (SLS) methodology. We aim at providing a straightforward, <a href="https://docs.julialang.org/en/v1/manual/distributed-computing/" rel="nofollow"><code>@Distributed</code></a>-enabled, interface for optimal and robust control of large-scale cyberphysical systems.</p>

<p dir="auto">The following example illustrates how a spatiotemporal-localized controller can be synthesized using this toolbox. Consider the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$\mathcal{H}_2$</math-renderer> state-feedback SLS problem</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$$\begin{aligned}
\min_{\Phi_x, \Phi_u} &amp;\quad \left| C_1\Phi_x + D_{12} \Phi_u  \right|_{\mathcal{H}_2} \\
\text{s.t.}
&amp; \quad z\Phi_x = A\Phi_x + B_2\Phi_u \\
&amp; \quad \Phi_x, \Phi_u \in \mathcal{L}_d\cap\mathcal{F}_T\cap\mathcal{D}
\end{aligned}$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$A \in \mathbb{R}^{59\times 59}$</math-renderer> is a tri-diagonal matrix, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$B_2 \in \mathbb{R}^{59\times 20}$</math-renderer> has the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$(6n{+}1,~2n{+}1)$</math-renderer>-th and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$(6n{+}2,~2n{+}2)$</math-renderer>-th entries equal to 1 (and zero elsewhere). Furthermore, let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$[C_1\ D_{12}] = I$</math-renderer>. The controller is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$(d,T)$</math-renderer>-localized assuming a localization constraint with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$d = 9$</math-renderer>, finite-impulse response (FIR) constraint with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$T = 29$</math-renderer>, and communication delay <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="339d2d23bd1efbc6af4147a7f8c115e4">$t_c = 1.5$</math-renderer>. (see <a href="https://arxiv.org/abs/1904.01634" rel="nofollow">(Anderson et. al., 2019)</a> for details). This problem can be modelled and solved by the following script:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SystemLevelControl, LinearAlgebra, SparseArrays

<p dir="auto">The above script solves the SLS problem using distributed computation if Julia is started with a desired number of workers (e.g., with <code>julia -p 8</code>, or by using the command <code>addprocs</code> in the REPL). This can dramatically speed up computation and effectively distribute the synthesis problem across multiple CPUs (however, with an increase in memory usage if distributed locally).</p>

<p dir="auto"><strong>This package is under development and is intended to provide a framework for efficiently solving System Level Synthesis problems.</strong> Although general-purpose, the SLS methodology is focused on large-scale cyber-physical systems with sparse communication and actuation networks. As such, our toolbox is designed for linear discrete-time systems, restricted to <code>SparseArrays</code> data-types, and we focus on the linear fractional transformation (LFT) framework (see <a href="https://www.ece.lsu.edu/kemin/essentials.htm" rel="nofollow">Zhou's &amp; Doyle's</a> textbook). We hope to improve <strong>SystemLevelControl.jl</strong> (and the research on SLS methods) so that in the future it can serve as a general-purpose control framework.</p>
<p dir="auto">For doing analysis or solving more general control problems, we recommend other excellent Julia packages:</p>
<ul dir="auto">
<li><a href="https://juliacontrol.github.io/ControlSystems.jl/stable/" rel="nofollow"><code>ControlSystems.jl</code></a> and its associated Ecosystem provide a wide collection of tools for analysis and design of control systems. It provides a similar interface as that of the popular Control Systems Toolbox in MATLAB®.</li>
<li><a href="https://jump.dev/JuMP.jl/stable/" rel="nofollow"><code>JuMP.jl</code></a> is perhaps the most popular modelling framework for mathematical optimization in Julia. A wide class of optimal control problems (including LMIs/SDPs) can be solved with this package. <strong>SystemLevelControl.jl</strong> actually use JuMP to solve SLS problems for the general cases.</li>
<li><a href="http://roboticexplorationlab.org/TrajectoryOptimization.jl/stable/" rel="nofollow"><code>TrajectoryOptimization.jl</code></a> is a popular framework for solving trajectory optimization problems in Julia, specially for applications in robotics. A distinct feature is the possibility to easily model nonlinear control problems.</li>
<li><a href="https://help.juliahub.com/juliasimcontrol/stable/" rel="nofollow"><code>JuliaSimControl.jl</code></a> is the package within the JuliaSim Ecosystem that allows for the modelling, analysis and deployment of control systems in a centralized package.</li>
</ul>
