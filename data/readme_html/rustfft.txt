<p dir="auto">Compute FFTs in Julia using RustFFT. Some parts of this documentation have been quoted from the <a href="https://docs.rs/rustfft/latest/rustfft/" rel="nofollow">RustFFT docs</a>.</p>
<blockquote>
<p dir="auto">RustFFT is a high-performance, SIMD-accelerated FFT library written in pure Rust. It can compute FFTs of any size, including prime-number sizes, in O(nlogn) time.</p>
</blockquote>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">RustFFT.jl implements the generic FFT interface of <a href="https://juliamath.github.io/AbstractFFTs.jl/stable/api/#Public-Interface-1" rel="nofollow">AbstractFFTs.jl</a> but only supports one-dimensional, complex-valued arrays: <code>Vector{ComplexF64}</code> and <code>Vector{ComplexF32}</code>.</p>
<p dir="auto">Forward and inverse FFT:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using RustFFT

data = ones(ComplexF64, 1)
fft!(data)"><pre><span class="pl-k">using</span> RustFFT

data <span class="pl-k">=</span> <span class="pl-c1">ones</span>(ComplexF64, <span class="pl-c1">1</span>)
<span class="pl-c1">fft!</span>(data)</pre></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using RustFFT

data = ones(ComplexF64, 1)
ifft!(data)"><pre><span class="pl-k">using</span> RustFFT

data <span class="pl-k">=</span> <span class="pl-c1">ones</span>(ComplexF64, <span class="pl-c1">1</span>)
<span class="pl-c1">ifft!</span>(data)</pre></div>
<p dir="auto">You can set several options by planning the FFT:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using RustFFT

planner = new_planner(ComplexF64)
data = ones(ComplexF64, 1)
plan = plan_fft!(data; rustfft_checks=IgnoreArrayChecks(), rustfft_gcsafe=GcSafe(), rustfft_planner=planner)
plan * data"><pre><span class="pl-k">using</span> RustFFT

planner <span class="pl-k">=</span> <span class="pl-c1">new_planner</span>(ComplexF64)

plan <span class="pl-k">=</span> <span class="pl-c1">plan_fft!</span>(data; rustfft_checks<span class="pl-k">=</span><span class="pl-c1">IgnoreArrayChecks</span>(), rustfft_gcsafe<span class="pl-k">=</span><span class="pl-c1">GcSafe</span>(), rustfft_planner<span class="pl-k">=</span>planner)
plan <span class="pl-k">*</span> data</pre></div>
<p dir="auto">It's currently not possible to choose the specific algorithm that will be used to compute the transform.</p>

<p dir="auto">RustFFT has been benchmarked against FFTW on a PC with the following specs:</p>
<p dir="auto">OS: Ubuntu 22.04.2 LTS</p>
<p dir="auto">CPU: Intel Core i7-12700H</p>
<p dir="auto">RAM: 32GB</p>
<p dir="auto">Julia: 1.9.2</p>
<p dir="auto">FFTW.jl: 1.7.1</p>
<p dir="auto">RustFFT.jl: 0.2.0</p>
<p dir="auto">The benchmarks performed the following benchmark, with <code>j</code> ranging from 2 up to and including 128 in steps of 1, and from 256 up to and including 4096 in steps of 256:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@btime plan * data setup = (data = ones(ComplexF64, j); plan = plan_fft!(data))"><pre><span class="pl-c1">@btime</span> plan <span class="pl-k">*</span> data setup <span class="pl-k">=</span> (data <span class="pl-k">=</span> <span class="pl-c1">ones</span>(ComplexF64, j); plan <span class="pl-k">=</span> <span class="pl-c1">plan_fft!</span>(data))</pre></div>
