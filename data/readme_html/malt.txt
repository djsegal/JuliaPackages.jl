<p dir="auto">Malt is a multiprocessing package for Julia. It is used by <a href="https://plutojl.org/" rel="nofollow">Pluto.jl</a> to manage the Julia process that notebook code is executed in, as a <a href="https://github.com/fonsp/Pluto.jl/pull/2240" data-hovercard-type="pull_request" data-hovercard-url="/fonsp/Pluto.jl/pull/2240/hovercard">replacement to Distributed</a>.</p>
<p dir="auto">You can find more information on the <a href="https://juliapluto.github.io/Malt.jl" rel="nofollow"><strong>documentation</strong></a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><strong>Malt.jl</strong> vs <strong>Distributed</strong></h2><a id="user-content-maltjl-vs-distributed" class="anchor" aria-label="Permalink: Malt.jl vs Distributed" href="#maltjl-vs-distributed"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Malt.jl is inspired by the <a href="https://docs.julialang.org/en/v1/stdlib/Distributed/" rel="nofollow"><code>Distributed standard library</code></a>, but with a focus on process sandboxing, not distributed computing. Important differences are:</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">API changes</h3><a id="user-content-api-changes" class="anchor" aria-label="Permalink: API changes" href="#api-changes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Malt.jl has different function names, see our <a href="https://juliapluto.github.io/Malt.jl" rel="nofollow"><strong>documentation</strong></a>.</p>
<p dir="auto">One important addition is public API for <strong>evaluating an <code>Expr</code></strong>:</p>

Malt<span class="pl-k">.</span><span class="pl-c1">remote_eval_fetch</span>(worker, :(<span class="pl-c1">sqrt</span>(<span class="pl-c1">123</span>)))</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Nested use</h3><a id="user-content-nested-use" class="anchor" aria-label="Permalink: Nested use" href="#nested-use"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">With Malt.jl, any <strong>worker</strong> process can also be a <strong>host</strong> process to its own workers.</p>
<p dir="auto">In Distributed, only "process 1 can add or remove workers". Malt.jl does not have this limiation. <em>This means that Malt.jl workers can use Distributed (and Malt.jl) like a regular Julia process.</em></p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Process isolation</h3><a id="user-content-process-isolation" class="anchor" aria-label="Permalink: Process isolation" href="#process-isolation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Malt.jl worker processes <strong>do not inherit</strong> <code>ENV</code> variables, command-line arguments or the Pkg environment from their host.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Interrupt on Windows</h3><a id="user-content-interrupt-on-windows" class="anchor" aria-label="Permalink: Interrupt on Windows" href="#interrupt-on-windows"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Malt.jl supports <strong>interrupting a worker process on Windows</strong>, not just on UNIX.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Heterogenous computing</h3><a id="user-content-heterogenous-computing" class="anchor" aria-label="Permalink: Heterogenous computing" href="#heterogenous-computing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Malt.jl does not have API like <code>@everywhere</code> or <code>Distributed.procs</code>: Malt is <strong>not the right tool for heterogenous computing</strong>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Exception handling</h3><a id="user-content-exception-handling" class="anchor" aria-label="Permalink: Exception handling" href="#exception-handling"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Exceptions in Malt.jl workers are converted to plaintext before being rethrown in the host.</p>
<p dir="auto">The original exception object is only available to the worker. In Distributed, the original exception object is serialized and rethrown to the host.</p>
