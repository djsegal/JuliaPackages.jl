<p dir="auto">A package to enable block respecting compression of Matrix Product Operators (MPOs) for use with ITensors.jl.</p>
<p dir="auto">Reference: <em>Daniel E. Parker, Xiangyu Cao, and Michael P. Zaletel Phys. Rev. B 102, 035147</em></p>
<p dir="auto">ITensors has built in support for generating MPOs from local operators. This framework is called <code>AutoMPO</code>.  MPOs
generated by <code>AutoMPO</code> are already compressed, so you only need this package
if you:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="1. Are using MPOs that are created by hand, outside the `AutoMPO` framework.  
2. Want your MPO to be in orthogonal/canonical form.
3. Need to see the bond spectrums throughout the lattice. "><pre class="notranslate"><code>1. Are using MPOs that are created by hand, outside the `AutoMPO` framework.  
2. Want your MPO to be in orthogonal/canonical form.
3. Need to see the bond spectrums throughout the lattice. 
</code></pre></div>
<p dir="auto">Support for compression of infinite lattice MPOs (iMPOs) is in the ITensorInfiniteMPS package
which can be found <a href="https://github.com/ITensor/ITensorInfiniteMPS.jl">here</a>.</p>
<p dir="auto">Technical notes on what this package does can be founs <a href="https://github.com/JanReimers/ITensorMPOCompression.jl/blob/main/docs/TechnicalDetails.pdf">here</a></p>
