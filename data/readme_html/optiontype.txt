<p dir="auto">OptionType.jl is a Julia package that provides a convenient and flexible way to work with optional values, inspired by Rust's Option type. It offers a set of functions and a custom Option type, allowing you to handle optional values more effectively and write cleaner code.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto"><strong>Option type</strong>: The package defines the <code>Option{T}</code> type, which represents an optional value that can either be <code>Some(value)</code> or <code>None</code>. The <code>Option{T}</code> type is generic, allowing you to work with any data type.</p>
</li>
<li>
<p dir="auto"><strong>Functions for option handling</strong>: OptionType.jl provides a collection of functions for working with <code>Option{T}</code> values. These functions include <code>isempty</code>, <code>get</code>, <code>map</code>, <code>and_then</code>, and <code>or_else</code>, allowing you to check for emptiness, retrieve values with fallback options, transform options, and chain operations on options.</p>
</li>
</ul>
