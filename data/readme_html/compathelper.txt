<p dir="auto">Create a file at <code>.github/workflows/CompatHelper.yml</code> with the contents of the <a href=".github/workflows/CompatHelper.yml">CompatHelper.yml</a> that is included in this repository.</p>
<p dir="auto">If you need to use any special arguments for the <code>main</code> function, you can modify this file to add them.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">GitLab</h3><a id="user-content-gitlab" class="anchor" aria-label="Permalink: GitLab" href="#gitlab"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For GitLab you will want to add CompatHelper as a job in your <code>.gitlab-ci.yml</code>
file with the contents of the <a href="examples/gitlab/.gitlab-ci.yml">.gitlab-ci.yml</a> file that is included in this repository.</p>
<p dir="auto">Similarly to the GitHub setup, you can modify the <code>main</code> call here if you need to change any of the default arguments.
You must also remember to add the <code>GITLAB_TOKEN</code> and <code>COMPATHELPER_PRIV</code> CI secrets to the project so that CompatHelper can find them.</p>
