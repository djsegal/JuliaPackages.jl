<p dir="auto">The ImportAll.jl package provides the <code>@importall</code> macro to replace the <a href="https://docs.julialang.org/en/v0.6/manual/modules/" rel="nofollow"><code>importall</code></a> command from Julia 0.6, which was <a href="https://github.com/JuliaLang/julia/issues/22789" data-hovercard-type="issue" data-hovercard-url="/JuliaLang/julia/issues/22789/hovercard">removed in Julia 1.0</a>.</p>
