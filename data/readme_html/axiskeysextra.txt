<p dir="auto">The <a href="https://github.com/mcabbott/AxisKeys.jl">AxisKeys.jl</a> package provides a nice lightweight <code>KeyedArray</code> structure: arrays with keyed/labelled axes, similar to <code>xarray</code> in Python. <br>
It is being maintained, but proposed new features – even simple and self-contained ones – aren't being added (<a href="https://github.com/mcabbott/AxisKeys.jl/pull/110" data-hovercard-type="pull_request" data-hovercard-url="/mcabbott/AxisKeys.jl/pull/110/hovercard">see, e.g.</a>). That's the reason for this package, <code>AxisKeysExtra.jl</code>: it extends <code>AxisKeys</code> with new convenience functions, conversions, Makie plotting recipes.</p>
<p dir="auto">The intended usage is to just do <code>using AxisKeysExtra</code>: it reexports <code>AxisKeys</code>, so one can use both regular <code>AxisKeys</code> functionality and functions defined in this package.<br>
See <a href="https://aplavin.github.io/AxisKeysExtra.jl/test/notebook.html" rel="nofollow">the Pluto notebook</a> for details and examples.</p>
