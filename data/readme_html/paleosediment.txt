<p dir="auto">Sediment components and standalone examples for the <a href="https://github.com/PALEOtoolkit">PALEOtoolkit</a> biogeochemical framework.</p>
<p dir="auto">The <code>PALEOsediment</code> package provides an implementation of sediment transport (PALEO reaction <code>ReactionSedimentTransport</code>) for n x 1D sediment columns.</p>
<p dir="auto">This can then be combined with biogeochemistry implemented by the <code>PALEOaqchem</code> and <code>PALEOboxes</code> packages and solvers from the <code>PALEOmodel</code> package  to create either standalone sediment models or coupled water-column - sediment configurations.</p>
<p dir="auto">The implementation of 1D sediment reaction-transport is standard (eg <a href="https://dx.doi.org/10.2475/ajs.296.3.197" rel="nofollow">Van Cappellen &amp; Wang (1996)</a>, <a href="https://dx.doi.org/10.1016/0098-3004(95)00115-8" rel="nofollow">Boudreau (1996)</a>) and uses the PALEOtoolkit framework to provide:</p>
<ul dir="auto">
<li>extensible configuration for biogeochemical species and reactions defined in a .yaml configuration file</li>
<li>standalone and coupled sediment configurations</li>
<li>fully implicit numerical solution using a combination of sparse automatic differentation to generate Jacobians, and efficient solvers including pseudo-transient-continuation for steady-state solutions.</li>
</ul>

<p dir="auto">To install and run the PALEOsediment examples, clone this github repository to local directory <code>PALEOsediment</code> and run the examples from the Julia REPL.</p>
<p dir="auto">Quickstart assuming a recent Julia installation: from a linux bash prompt or a Windows terminal,</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ git clone https://github.com/PALEOtoolkit/PALEOsediment.jl.git PALEOsediment"><pre class="notranslate"><code>$ git clone https://github.com/PALEOtoolkit/PALEOsediment.jl.git PALEOsediment
</code></pre></div>
<p dir="auto">Start julia and navigate to the <code>PALEOsediment/examples</code> folder, and run <code>setup.jl</code> to configure the <code>PALEOsediment/examples</code>
Julia environment to use the local (downloaded) version of the PALEOsediment package:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; cd(&quot;PALEOsediment/examples&quot;)
julia&gt; include(&quot;setup.jl&quot;) # use the local version of PALEOsediment packages to allow local modifications"><pre class="notranslate"><code>julia&gt; cd("PALEOsediment/examples")
julia&gt; include("setup.jl") # use the local version of PALEOsediment packages to allow local modifications
</code></pre></div>
<p dir="auto">Examples are in subfolders of <code>PALEOsediment/examples</code> and the use the <code>PALEOsediment/examples</code> Julia environment.</p>
<p dir="auto">See <a href="https://paleotoolkit.github.io/PALEOtutorials.jl/dev/ExampleInstallConfig/" rel="nofollow">Installation and getting started</a>
in the <a href="https://github.com/PALEOtoolkit/PALEOtutorials.jl">PALEOtutorials</a> repository for more details including installation and configuration of Julia.</p>
