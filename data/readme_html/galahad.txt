<p dir="auto">GALAHAD is a library of modern Fortran packages for nonlinear optimization with C, Python, Julia and MATLAB interfaces. It contains packages for general constrained and unconstrained optimization, linear and quadratic programming, nonlinear least-squares fitting and global optimization, as well as those for solving a large variety of basic optimization subproblems.</p>

<p dir="auto">GALAHAD can be installed from source using the <a href="https://mesonbuild.com" rel="nofollow">Meson build system</a> (all commands below are to be run from the top of the source tree):</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="meson setup builddir -Dtests=true
meson compile -C builddir
meson install -C builddir
meson test -C builddir"><pre class="notranslate"><code>meson setup builddir -Dtests=true
meson compile -C builddir
meson install -C builddir
meson test -C builddir
</code></pre></div>
<p dir="auto">For more comprehensive Meson options (<code>-Doption=value</code>), including how to specify paths to various libraries and packages, please see <a href="https://github.com/ralna/GALAHAD/blob/master/meson_options.txt">meson_options.txt</a> and <a href="https://github.com/ralna/GALAHAD/blob/master/README.meson">README.meson</a>. We give some examples below for the most important Meson options.</p>
<p dir="auto">GALAHAD supports a large number of optional software packages for enhanced functionality, the most important of these are:</p>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">BLAS/LAPACK</h4><a id="user-content-blaslapack" class="anchor" aria-label="Permalink: BLAS/LAPACK" href="#blaslapack"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">By default GALAHAD will build with <a href="https://github.com/OpenMathLib/OpenBLAS">OpenBLAS</a> if it can locate it (otherwise you may need to pass the OpenBLAS paths via the <code>libblas_path</code> and <code>liblapack_path</code> options to <code>meson setup</code>). You may also wish to use a vendor-specific BLAS/LAPACK implementation such as one of the following:</p>
<ul dir="auto">
<li><a href="https://www.intel.com/content/www/us/en/developer/tools/oneapi/onemkl.html" rel="nofollow">Intel MKL</a></li>
<li><a href="https://www.amd.com/en/developer/aocl/dense.html" rel="nofollow">AMD AOCL</a></li>
</ul>
<p dir="auto">Please see <a href="https://github.com/ralna/GALAHAD/blob/master/README.meson">README.meson</a> for instructions on how to tell Meson where to find these optional dependencies.</p>

<p dir="auto">GALAHAD can also be installed via the "make" command as part of the Optrove
optimization eco-system that also includes
<a href="https://github.com/ralna/CUTEst">CUTEst</a>,
<a href="https://github.com/ralna/SIFDecode">SIFDecode</a> and
<a href="https://github.com/ralna/ARCHDefs">ARCHDefs</a>.
This has the advantage of providing scripts to run CUTEst examples
directly from GALAHAD and allowing calls from Matlab, but suffers from
considerably longer build times.</p>
<p dir="auto">To use this variant, follow the instructions in the GALAHAD
<a href="https://github.com/ralna/GALAHAD/wiki">wiki</a>.</p>
