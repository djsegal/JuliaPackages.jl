<p dir="auto"><code>MillerIndices.jl</code> is a Julia package that provides a convenient way to handle Miller
indices and Miller–Bravais indices in crystallography.</p>
<p dir="auto">The code, which is <a href="https://github.com/MineralsCloud/MillerIndices.jl">hosted on GitHub</a>, is tested
using various continuous integration services for its validity.</p>
<p dir="auto">This repository is created and maintained by
<a href="https://github.com/singularitti">@singularitti</a>, and contributions are highly welcome.</p>

<ol dir="auto">
<li>
<p dir="auto">Representation of indices:</p>
<ul dir="auto">
<li><code>Miller</code>: Represents the Miller indices in real space (crystal directions).</li>
<li><code>ReciprocalMiller</code>: Represents the Miller indices in reciprocal space (planes).</li>
<li><code>MillerBravais</code>: Represents the Miller–Bravais indices in real space (crystal directions).</li>
<li><code>ReciprocalMillerBravais</code>: Represents the Miller–Bravais indices in reciprocal space (planes).</li>
</ul>
</li>
<li>
<p dir="auto">Macro for easy generation:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="m&quot;[-1, 0, 1]&quot;      # Miller

m&quot;(1, 0, -1, 0)&quot;   # ReciprocalMillerBravais"><pre><span class="pl-s"><span class="pl-pds"><span class="pl-c1">m</span>"</span>[-1, 0, 1]<span class="pl-pds">"</span></span>      <span class="pl-c"><span class="pl-c">#</span> Miller</span>
<span class="pl-s"><span class="pl-pds"><span class="pl-c1">m</span>"</span>&lt;2, -1, -1, 3&gt;<span class="pl-pds">"</span></span>  <span class="pl-c"><span class="pl-c">#</span> MillerBravais</span>
<span class="pl-s"><span class="pl-pds"><span class="pl-c1">m</span>"</span>(-1, 0, 1)<span class="pl-pds">"</span></span>      <span class="pl-c"><span class="pl-c">#</span> ReciprocalMiller</span>

</li>
<li>
<p dir="auto">List equivalent directions/planes</p>
</li>
<li>
<p dir="auto">Conversion between Miller and Miller-Bravais representations</p>
</li>
<li>
<p dir="auto">Calculate angles between indices</p>
</li>
<li>
<p dir="auto">Interplanar spacing calculation</p>
</li>
</ol>

<p dir="auto">The package can be installed with the Julia package manager.
From <a href="https://docs.julialang.org/en/v1/stdlib/REPL/" rel="nofollow">the Julia REPL</a>, type <code>]</code> to enter
the <a href="https://docs.julialang.org/en/v1/stdlib/REPL/#Pkg-mode" rel="nofollow">Pkg mode</a> and run:</p>
