<p dir="auto">Thread-safe in memory implementation of Least Frequency Used cache based on min binary heap map. Package provides three policies for calculation of priority key (more information <a href="https://www.hpl.hp.com/techreports/98/HPL-98-173.pdf" rel="nofollow">here</a>)</p>
<ol dir="auto">
<li>LFU policy</li>
<li>LFU with Dynamic Age policy (by default)</li>
<li>GreedyDual-Size with Frequency (GDSF)</li>
</ol>
