<p dir="auto">This Julia package provides learning rate schedule types for training deep learning models.</p>

<p dir="auto">Schedules are iterable, and return the learning rate at each iteration. For example, a linear schedule that decreases the learning rate from 1.0 to 0.6 with 4 steps can be created and used as follows:</p>

       end

<p dir="auto">In this package, schedules are <em>stateless</em>, meaning they are immutable and do not store any information about the current iteration. The schedule state is instead passed around in the underlying <code>iterate</code> calls. A state can still be binded to a schedule using <code>Iterators.Stateful</code> (which is exported by this package) like so:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; linear_with_state = linear_schedule(); # creates a stateful iterator from the linear schedule

julia&gt; next_rate!(linear_with_state)
1.0

julia&gt; next_rate!(linear_with_state)
