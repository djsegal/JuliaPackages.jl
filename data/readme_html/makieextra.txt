<p dir="auto">The included features are either not fleshed out enough to be included into <code>Makie</code> itself, or can only be implemented with some "hacks" at the current moment. Still, they are generally useful, and <code>MakieExtra.jl</code> exists to make them available for use in both scripts and packages.</p>
<p dir="auto">Everyone is welcome to suggest new features and convenience utilities to include into <code>MakieExtra</code>! This package aims to have a lower entry barrier than <code>Makie</code> itself.</p>
<p dir="auto">See <a href="https://aplavin.github.io/MakieExtra.jl/test/examples.html" rel="nofollow">the Pluto notebook</a> for details and examples.</p>
