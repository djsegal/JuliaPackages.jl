<a href="https://docs.scipy.org/doc/numpy/reference/routines.financial.html" rel="nofollow">financial</a> module.</p>

<p dir="auto">This library does not implement any array broadcasting feature as in
NumPy's implementation. Instead, Julia has its own broadcasting feature
so users of this library are encouraged to <em>do it the right way</em>.</p>
