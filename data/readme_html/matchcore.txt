<p dir="auto">A minimal implementation of optimized pattern matching.</p>
<p dir="auto">It is extracted from MLStyle.jl and sightly modified, for users who don't need advanced features like extensible patterns.</p>
<p dir="auto">It's faster to startup, produce efficient and "runtime free" code equivalent to MLStyle.</p>
<p dir="auto">MatchCore lacks of many non-primitive patterns, like <code>Dict</code>s, ranges, view/active patterns.</p>
<p dir="auto">However, expression matching is still available:</p>
