<p dir="auto">Jupyter2Pluto is a Julia package that allows you to convert Jupyter notebooks into <a href="https://github.com/fonsp/Pluto.jl">Pluto.jl</a> notebooks and vice versa.</p>

<p dir="auto">To convert a Jupyter notebook into a Pluto notebook, use the following Julia code snippet after installing Jupyter2Pluto:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Jupyter2Pluto

<p dir="auto">This command will create a new Pluto notebook named <code>sample.jl</code> in your current working directory.</p>

<p dir="auto">If you have a Pluto notebook and want to convert it to a Jupyter notebook, simply use the following Julia code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pluto2jupyter(&quot;sample.jl&quot;)"><pre><span class="pl-c1">pluto2jupyter</span>(<span class="pl-s"><span class="pl-pds">"</span>sample.jl<span class="pl-pds">"</span></span>)</pre></div>
