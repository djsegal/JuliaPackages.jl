<p dir="auto">This package is a quantum circuit simulator written in the <a href="https://julialang.org/" rel="nofollow">Julia programming language</a>, meant to be compatible with the <a href="https://github.com/aws/amazon-braket-sdk-python">Amazon Braket SDK</a>. It can simulate gate-based quantum circuits using both statevectors and density matrices (when noise is present).</p>

<p dir="auto">In order to generate a new set of precompilation instructions, you'll need to comment out the <code>include("precompile.jl")</code> lines in <code>src/BraketSimulator.jl</code> and <code>ext/BraketSimulatorPythonExt/BraketSimulatorPythonExt.jl</code>. Then, <code>cd</code> to <code>precompile</code> and run:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project=../test snoop_compilation.jl"><pre>julia --project=../test snoop_compilation.jl</pre></div>
<p dir="auto">This will run the test suite using <a href="https://timholy.github.io/SnoopCompile.jl/dev/snoopi_deep_parcel/" rel="nofollow"><code>SnoopCompile.jl</code></a> to generate precompilation instructions. Once this is completed, you can <em>un</em>comment <code>include("precompile.jl")</code> lines in <code>src/BraketSimulator.jl</code> and <code>ext/BraketSimulatorPythonExt/BraketSimulatorPythonExt.jl</code>.</p>

<p dir="auto"><code>BraketSimulator.jl</code> has an optional extension to support integration with Python (<code>BraketSimulatorPythonExt</code>).</p>
<p dir="auto">To use <code>BraketSimulatorPythonExt</code>, you will need to install <a href="https://github.com/JuliaPy/PythonCall.jl"><code>PythonCall.jl</code></a>, and then load it before <code>BraketSimulator.jl</code> like so:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PythonCall, BraketSimulator"><pre><span class="pl-k">using</span> PythonCall, BraketSimulator</pre></div>
<p dir="auto"><code>PythonCall.jl</code> will try to install the necessary <strong>Python</strong> dependencies using the <code>CondaPkg.toml</code> present in top-level package folder. If you already have all the necessary Python dependencies installed, you can set the environment variable <code>JULIA_CONDAPKG_BACKEND="Null"</code> to have <code>CondaPkg.jl</code> use your system Python and its installed packages.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage Notes</h2><a id="user-content-usage-notes" class="anchor" aria-label="Permalink: Usage Notes" href="#usage-notes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If you want to use this package <strong>from Python</strong>, see the Python wrapper package <a href="https://github.com/amazon-braket/amazon-braket-simulator-v2-python"><code>amazon-braket-simulator-v2-python</code></a>, which provides a Python interaction layer and will install Julia, this package and other Julia dependencies in a sandboxed virtual environment for you.</p>
<p dir="auto">Launch Julia with the command line option <code>-t auto</code> to have Julia launch and manage threads to parallelize the simulation(s). <code>BraketSimulator.jl</code> will parallelize both across tasks within a batch and inside a single task's evolution.</p>
<p dir="auto">Keep in mind that the first qubit has index <code>0</code>, <strong>not</strong> index <code>1</code>.</p>

    H(ghz_circ, 0)

    end
    return ghz_circ 
end
