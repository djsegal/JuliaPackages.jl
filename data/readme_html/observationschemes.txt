<blockquote>
<p dir="auto">A utility package from the <a href="https://github.com/JuliaDiffusionBayes">JuliaDiffusionBayes</a> suite, used for defining observation schemes for stochastic processes. It is aimed primarily at encoding discrete-time observations of diffusions.</p>
</blockquote>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key Features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key Features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Decorate each observation separately with the information about how it was collected</li>
<li>Support for the following observations:
<ul dir="auto">
<li>Exact observations of all or a subset of all coordinates of the underlying process</li>
<li>Linear translations of the underlying process, disturbed by Gaussian noise: <a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/53e844513caf9e6f4b2d9d23dd4574b7420c2ab27407788da4a5d159da9126d3/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f565f5425354373696d2532302535436d61746863616c2537424e2537442532384c585f542532432532302535435369676d61253239"><img src="https://camo.githubusercontent.com/53e844513caf9e6f4b2d9d23dd4574b7420c2ab27407788da4a5d159da9126d3/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f565f5425354373696d2532302535436d61746863616c2537424e2537442532384c585f542532432532302535435369676d61253239" alt="equation" data-canonical-src="https://latex.codecogs.com/gif.latex?V_T%5Csim%20%5Cmathcal%7BN%7D%28LX_T%2C%20%5CSigma%29" style="max-width: 100%;"></a></li>
<li>First-passage time observations</li>
<li>First-passage time observations with additional "resetting events"</li>
<li>Non-linearly (or linearly) transformed observations with Gaussian or non-Gaussian noise, i.e.: <a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/913a143c6e2f503ed283b4e5e2cbe7ae47504b32443989b78db4bc9dc4a36b7c/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f5625354373696d25323067253238582532392b2535437869"><img src="https://camo.githubusercontent.com/913a143c6e2f503ed283b4e5e2cbe7ae47504b32443989b78db4bc9dc4a36b7c/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f5625354373696d25323067253238582532392b2535437869" alt="equation" data-canonical-src="https://latex.codecogs.com/gif.latex?V%5Csim%20g%28X%29+%5Cxi" style="max-width: 100%;"></a> with general function <code>g</code> and random variable <code>ξ</code></li>
<li>Parameterized versions of all observation types above</li>
</ul>
</li>
<li>Support for ergonomic definitions of
<ul dir="auto">
<li>Multiple observations of a single process</li>
<li>Multiple observations of multiple processes, coming possibly from different laws that share subsets of parameters (mixed-effect models)</li>
</ul>
</li>
<li>Support for defining priors over starting points:
<ul dir="auto">
<li>Degenerate priors corresponding to fixed starting points</li>
<li>Gaussian priors</li>
</ul>
</li>
</ul>

<p dir="auto">ObservationSchemes.jl belongs to a suite of packages in <a href="https://github.com/JuliaDiffusionBayes">JuliaDiffusionBayes</a>, whose aim is to facilitate Bayesian inference for diffusion processes. Some other packages in this suite are as follows:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaDiffusionBayes/DiffusionDefinition.jl">DiffusionDefinition.jl</a>: define diffusion processes and sample from their laws</li>
<li><a href="https://github.com/JuliaDiffusionBayes/GuidedProposals.jl">GuidedProposals.jl</a>: defining and sampling conditioned diffusion processes</li>
<li><a href="https://github.com/JuliaDiffusionBayes/ExtensibleMCMC.jl">ExtensibleMCMC.jl</a>: a modular implementation of the Markov chain Monte Carlo (MCMC) algorithms</li>
<li><a href="https://github.com/JuliaDiffusionBayes/DiffusionMCMC.jl">DiffusionMCMC.jl</a>: Markov chain Monte Carlo (MCMC) algorithms for doing inference for diffusion processes</li>
</ul>
