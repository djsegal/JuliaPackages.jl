<p dir="auto">Approximate the <a href="https://en.wikipedia.org/wiki/Griewank_function" rel="nofollow">Griewank function</a> of 7 variables.
Since the Griewank function oscillates a lot, we have to sample it very finely.
But sampling in that many points is too expensive, so we import <code>approximate_scalar</code> explicitly and extend it with an approximate tensor decomposition from <a href="https://github.com/AndreiChertkov/teneva">teneva</a>.</p>
