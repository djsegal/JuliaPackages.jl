<p dir="auto">SBMLToolkit.jl is a lightweight tool to import models specified in the Systems Biology Markup Language (SBML) into the Julia SciML ecosystem. There are multiple ways to specify the same model in SBML. Please help us improving SBMLToolkit.jl by creating a GitHub issue if you experience errors when converting your SBML model.</p>
<p dir="auto">SBMLToolkit uses the <a href="https://github.com/LCSB-BioCore/SBML.jl">SBML.jl</a> wrapper of the <a href="https://model.caltech.edu/software/libsbml/" rel="nofollow">libSBML</a> library to lower dynamical SBML models into completed dynamical systems. If you would like to import BioNetGen models use the <code>writeSBML()</code> export function or import the <code>.net</code> file with <a href="https://github.com/SciML/ReactionNetworkImporters.jl">ReactionNetworkImporters.jl</a>. For constrained-based modeling, please have a look at <a href="https://github.com/COBREXA/COBREXA.jl">COBREXA.jl</a>. We also recommend trying <a href="https://github.com/sebapersson/SBMLImporter.jl">SBMLImporter.jl</a>. While SBMLToolkit.jl has a slightly cleaner interface, SBMLImporter.jl respects directionality of events, can output concentrations or amounts, and provides better simulation performance for models including time-triggered events and SBML <code>piecewise</code> expressions.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Tutorial</h2><a id="user-content-tutorial" class="anchor" aria-label="Permalink: Tutorial" href="#tutorial"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">SBML models can be simulated with the following steps (note that <code>sol</code> is in absolute quantities rather than concentrations):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SBMLToolkit, OrdinaryDiffEq

odesys = readSBML(&quot;my_model.xml&quot;, ODESystemImporter())

tspan = (0.0, 1.0)
prob = ODEProblem(odesys, [], tspan, [])
sol = solve(prob, Tsit5())"><pre><span class="pl-k">using</span> SBMLToolkit, OrdinaryDiffEq

odesys <span class="pl-k">=</span> <span class="pl-c1">readSBML</span>(<span class="pl-s"><span class="pl-pds">"</span>my_model.xml<span class="pl-pds">"</span></span>, <span class="pl-c1">ODESystemImporter</span>())

tspan <span class="pl-k">=</span> (<span class="pl-c1">0.0</span>, <span class="pl-c1">1.0</span>)
prob <span class="pl-k">=</span> <span class="pl-c1">ODEProblem</span>(odesys, [], tspan, [])
sol <span class="pl-k">=</span> <span class="pl-c1">solve</span>(prob, <span class="pl-c1">Tsit5</span>())</pre></div>
<p dir="auto">While this imports an <code>ODESystem</code> directly, you can also import a Catalyst.jl <code>ReactionSystem</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SBMLToolkit

rs = readSBML(&quot;my_model.xml&quot;, ReactionSystemImporter())"><pre><span class="pl-k">using</span> SBMLToolkit

rs <span class="pl-k">=</span> <span class="pl-c1">readSBML</span>(<span class="pl-s"><span class="pl-pds">"</span>my_model.xml<span class="pl-pds">"</span></span>, <span class="pl-c1">ReactionSystemImporter</span>())</pre></div>
<p dir="auto">One common case where this is useful is if you want to run stochastic instead of ODE simulations.</p>
<p dir="auto">In the very unlikely case that you need fine-grained control over the SBML import, you can create an SBML.jl <code>Model</code> (we strongly recommend manually running <code>checksupport_file("my_model.xml")</code> before)</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SBML

mdl = readSBML(&quot;my_model.xml&quot;, doc -&gt; begin
    set_level_and_version(3, 2)(doc)
    convert_promotelocals_expandfuns(doc)
end)"><pre><span class="pl-k">using</span> SBML

mdl <span class="pl-k">=</span> <span class="pl-c1">readSBML</span>(<span class="pl-s"><span class="pl-pds">"</span>my_model.xml<span class="pl-pds">"</span></span>, doc <span class="pl-k">-&gt;</span> <span class="pl-k">begin</span>
    <span class="pl-c1">set_level_and_version</span>(<span class="pl-c1">3</span>, <span class="pl-c1">2</span>)(doc)
    <span class="pl-c1">convert_promotelocals_expandfuns</span>(doc)
<span class="pl-k">end</span>)</pre></div>
<p dir="auto">The conversion to SBML level 3 version 2 is necessary, because older versions are not well supported in SBMLToolkit. <code>convert_promotelocals_expandfuns</code> basically flattens the SBML before the import. Once you have obtained the <code>Model</code>, you can convert it to a <code>ReactionSystem</code> and <code>ODESystem</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SBMLToolkit

rs = ReactionSystem(mdl)
odesys = convert(ODESystem, rs)"><pre><span class="pl-k">using</span> SBMLToolkit

rs <span class="pl-k">=</span> <span class="pl-c1">ReactionSystem</span>(mdl)
odesys <span class="pl-k">=</span> <span class="pl-c1">convert</span>(ODESystem, rs)</pre></div>
