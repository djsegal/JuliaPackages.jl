<p dir="auto">ModelingToolkitNeuralNets.jl is a package to create neural network blocks defined similar to MTKStandardLibrary components, to use them for solving Universal Differential Equations. It can be plugged to any part of the equations in an ODESystem using <code>RealInputArray</code> and <code>RealOutputArray</code> components which gives a lot of flexibility to add the missing physics only to a part of the model.</p>
