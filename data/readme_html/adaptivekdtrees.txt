<p dir="auto">AdaptiveKDTrees.jl aims to complement some of the functionalities of NearestNeighbors.jl, namely:</p>
<ul dir="auto">
<li>To allow for the progressive inclusion of new data points to the KDTree; and</li>
<li>To allow for range searches with specific search radii not only for the query points, but to each point in the dataset.</li>
</ul>
