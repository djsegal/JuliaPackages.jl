<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">PRONTO.jl</h1><a id="user-content-prontojl" class="anchor" aria-label="Permalink: PRONTO.jl" href="#prontojl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A Julia implementation of the <strong>PR</strong>ojection-<strong>O</strong>perator-Based <strong>N</strong>ewton’s Method for <strong>T</strong>rajectory <strong>O</strong>ptimization (PRONTO). PRONTO is a numerical method for trajectory optimization which leverages variational calculus to solve the optimal control problem directly in infinite-dimensional function space. Consider the optimal control problem:</p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$$\min h(ξ) = p(x(T)) + \int_0^T l(x(t),u(t)) dt$$</math-renderer>
where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$h$</math-renderer> is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$\mathcal{C}^2$</math-renderer> convex function, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$ξ(t) = (x(t),u(t))$</math-renderer> is a trajectory restricted by the dynamics of the system, which lies on the trajectory manifold:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$$\mathcal{T} = \{ ξ ∈(\mathcal{X}\times\mathcal{U})\ |\ \dot{x} = f(x,u),\ x(0)=x_0 \}$$</math-renderer></p>
<p dir="auto">To explore beyond this trajectory manifold, we consider an arbitrary curve <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$η ∈(\mathcal{X}\times\mathcal{U})$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$η(t) = (α(t),μ(t))$</math-renderer>. The projection operator <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$\mathcal{P}:(\mathcal{X}\times\mathcal{U})\rightarrow \mathcal{T}$</math-renderer>, which maps curves onto the trajectory manifold of the system, is used to convert the above constrained optimization problem to the unconstrained problem:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$$g(η) = h(\mathcal{P}(η))$$</math-renderer></p>
<p dir="auto">Given the current trajectory iterate <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$ξ_k$</math-renderer>, we wish to compute the descent direction <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$ζ_k$</math-renderer>, which lies in the tangent space of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$\mathcal{T}$</math-renderer>. This is done by solving the optimization problem:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$$ζ_k = \arg\min Dg(ξ_k)\cdotζ + \frac{1}{2}D^2g(ξ_k)\cdot(ζ,ζ)$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$Dg$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$D^2g$</math-renderer> are the first and second Fréchet derivatives of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$g$</math-renderer>.</p>
<p dir="auto">This optimization problem is first converted into a linear-quadratic optimal control problem, and then solved in one of two ways. First, we try to solve a Newton descent direction, which does not have a guaranteed solution, but provides quadratic convergence. If this fails, we switch to a quasi-Newton descent direction, which has a guaranteed solution and provides super-linear convergence.</p>
<p dir="auto">Because <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$ζ_k$</math-renderer> is computed by local second order approximation, there is no guarantee that <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$g(ξ_k + ζ_k) &amp;lt; g(ξ_k)$</math-renderer>. Consequently we find a step size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$γ_k ≤ 1$</math-renderer> via backtracking line search which enforces the Armijo rule.</p>
<p dir="auto">After calculating a descent direction <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$ζ_k$</math-renderer> and a step size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$γ_k$</math-renderer> the projection operator is used to ensure the next solution iterate lies on the trajectory manifold.</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="f0e8b73a9a8d8f236e53afd53005ba9a">$$ ξ_{k+1} = \mathcal{P}(ξ_k + γ_k ζ_k)$$</math-renderer></p>
<p dir="auto">For the mathematical details of the PRONTO algorithm, please refer to: <a href="https://www.sciencedirect.com/science/article/pii/S1474667015387334" rel="nofollow">(Hauser 2002)</a>, <a href="https://ieeexplore.ieee.org/abstract/document/1243395" rel="nofollow">(Hauser 2003)</a>, and <a href="https://journals.aps.org/pra/abstract/10.1103/PhysRevA.105.032605" rel="nofollow">(Shao et al. 2022)</a></p>

<p dir="auto">Please see the examples folder for usage examples. This API is still very likely to change – especially regarding the symbolic generation of jacobians/hessians and passing them to the solver. Note that upcoming changes in Julia 1.9 should substantially improve the compile time of large generated functions (<a href="https://github.com/JuliaLang/julia/issues/45276" data-hovercard-type="pull_request" data-hovercard-url="/JuliaLang/julia/pull/45276/hovercard">#45276</a>, <a href="https://github.com/JuliaLang/julia/issues/45404" data-hovercard-type="pull_request" data-hovercard-url="/JuliaLang/julia/pull/45404/hovercard">#45404</a>).</p>
<p dir="auto">To see the generated definition of any model function, run, eg. <code>methods(PRONTO.f)</code> and open the temporary file where the definition is stored.</p>
