<ol dir="auto">
<li>
<p dir="auto">Install Julia</p>
<p dir="auto">Please install Julia using the binaries from this page <a href="https://julialang.org" rel="nofollow">https://julialang.org</a>. (Julia 1.9 is recommended)</p>
</li>
<li>
<p dir="auto">Install CompileMRI</p>
<p dir="auto">Start Julia (Type julia in the command line or start the installed Julia executable)</p>
<p dir="auto">Type the following in the Julia REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ] # Be sure to type the closing bracket via the keyboard
