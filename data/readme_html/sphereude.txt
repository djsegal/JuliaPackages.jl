<p dir="auto">SphereUDE.jl is a Julia package for non-parametric regression of data supported in three-dimensional spheres.
It implements a simple universal differential equation (UDE) that naturally constrains trajectories to lie on the surface of a sphere.
This has an important application in Paleomagnetism, where the objective is to fit Apparent Polar Wander Paths (APWPs) to reconstruct continents' past motion.
In addition to sphere regression, SphereUDE.jl implements a series of improvements over previous modeling methods, such as</p>
<ul dir="auto">
<li>Explicit sphere constraint that allows for univesality of regression</li>
<li>Regularization on the path to incorporate physical priors</li>
<li>Incorporation of temporal and spatial uncertainties</li>
<li>Uncertainty quantification capabilities</li>
</ul>

<p dir="auto">To train a model with new unobserved data, we need to define the <em>data</em>, <em>parameters</em>, and <em>regularization</em> we want to use.
Data are defined as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="data = SphereData(times=times_samples, 
                  directions=X_true, 
                  kappas=nothing, 
                  L=L_true)
"><pre>data <span class="pl-k">=</span> <span class="pl-c1">SphereData</span>(times<span class="pl-k">=</span>times_samples, 
                  directions<span class="pl-k">=</span>X_true, 
                  kappas<span class="pl-k">=</span><span class="pl-c1">nothing</span>, 
                  L<span class="pl-k">=</span>L_true)
</pre></div>
<p dir="auto">where <code>times</code> correspond to an array of the sampled times where we observed the three-dimensional vectors in <code>directions</code>.
We can further add an array <code>kappa</code> to specify uncertainty in the directions according to the Fisher distribution in the sphere.</p>
<p dir="auto">It is possible to add different types of regularizations at the same time by specifying an array of the type <code>Regularization</code>, which specifies the type of regularization being used and the <code>diff_mode</code> that specifies the underlying automatic differentiation machinery being used to compute the gradients.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="regs = [Regularization(order=1, power=1.0, λ=0.001, diff_mode=&quot;Finite Differences&quot;),

<p dir="auto">To make plots using Matplotlib, Cartopy, and PMagPy, we install both <a href="https://github.com/JuliaPy/PyCall.jl">PyCall.jl</a> and <a href="https://github.com/JuliaPy/PyPlot.jl">PyPlot.jl</a> and execute Python code directly from Julia. To do this setup manually, you can follow the next steps.</p>
<ul dir="auto">
<li>Create a Python conda environment, based on <a href="https://raw.githubusercontent.com/facusapienza21/SphereUDE.jl/main/environment.yml" rel="nofollow">this conda environment file</a>, with all the required packages using <code>conda env create -f environment.yml</code>.</li>
<li>Inside the Julia REPL, install both <code>PyCall.jl</code> and <code>PyPlot.jl</code> with <code>] add PyCall, Pyplot</code>.</li>
<li>Specify the Python path of the new environment with <code>ENV["PYTHON"] = ...</code>, where you should complete the path of the Python installation that shows when you do <code>conda activate SphereUDE</code>, <code>which python</code>.</li>
<li>Inside the Julia REPL, execute <code>Pkg.build("PyCall")</code> to re-build PyCall with the new Python path.</li>
</ul>
<p dir="auto">You are ready to use Python from your Julia session!</p>
