<p dir="auto">This packages contains models to compute the geomagnetic field vector. We currently have two
models implemented:</p>
<ol dir="auto">
<li>The <a href="https://www.ngdc.noaa.gov/IAGA/vmod/igrf.html" rel="nofollow">International Geomagnetic Reference Field (IGRF)
v13</a>; and</li>
<li>The simplified dipole model.</li>
</ol>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">IGRF</h3><a id="user-content-igrf" class="anchor" aria-label="Permalink: IGRF" href="#igrf"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We have a native Julia implementation of the <a href="https://www.ngdc.noaa.gov/IAGA/vmod/igrf.html" rel="nofollow">International Geomagnetic Reference Field
(IGRF) v13</a> based on <strong>[1]</strong>. This mode can
be accessed by two functions: <code>irgf</code> and <code>irgfd</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function igrfd(date::Number, &lt;r, h&gt;::Number, λ::Number, Ω::Number[, R]; kwargs...)"><pre><span class="pl-k">function</span> <span class="pl-en">igrfd</span>(date<span class="pl-k">::</span><span class="pl-c1">Number</span>, <span class="pl-k">&lt;</span>r, h<span class="pl-k">&gt;</span><span class="pl-k">::</span><span class="pl-c1">Number</span>, λ<span class="pl-k">::</span><span class="pl-c1">Number</span>, Ω<span class="pl-k">::</span><span class="pl-c1">Number</span>[, R]; kwargs<span class="pl-k">...</span>)</pre></div>
<p dir="auto">Compute the geomagnetic field vector [nT] at the date <code>date</code> [Year A.D.] and position (<code>r</code>
or <code>h</code>, <code>λ</code>, <code>Ω</code>).</p>
<p dir="auto">The position representation is defined by <code>R</code>. If <code>R</code> is <code>Val(:geocentric)</code>, the input must
be <strong>geocentric</strong> coordinates:</p>
<ol dir="auto">
<li>Distance from the Earth center <code>r</code> [m];</li>
<li>Geocentric latitude <code>λ</code> ∈ (-90°, +90°); and</li>
<li>Geocentric longitude <code>Ω</code> ∈ (-180°, +180°).</li>
</ol>
<p dir="auto">If <code>R</code> is <code>Val(:geodetic)</code>, the input must be <strong>geodetic</strong> coordinates:</p>
<p dir="auto">1 Altitude above the reference ellipsoid <code>h</code> (WGS-84) [m];
2. Geodetic latitude <code>λ</code> ∈ (-90°, +90°); and
3. Geodetic longitude <code>Ω</code> ∈ (-180°, +180°).</p>
<p dir="auto">If <code>R</code> is omitted, it defaults to <code>Val(:geocentric)</code>.</p>
<blockquote>
<p dir="auto"><strong>Warning</strong>
We must have <code>1900 &lt;= date &lt;= 2030</code>. A warning message is printed for dates greater than
2025 since the output is not reliable anymore. This message can be suppressed by setting
the keyword <code>show_warnings</code> to <code>false</code>.</p>
</blockquote>
<blockquote>
<p dir="auto"><strong>Note</strong>
The output vector will be represented in the same reference system selected by the
parameter <code>R</code> (geocentric or geodetic). The Y-axis of the output reference system always
points East. In case of <strong>geocentric coordinates</strong>, the Z-axis points toward the center of
Earth and the X-axis completes a right-handed coordinate system. In case of <strong>geodetic
coordinates</strong>, the X-axis is tangent to the ellipsoid at the selected location and points
toward North, whereas the Z-axis completes a right-hand coordinate system.</p>
</blockquote>
<p dir="auto">The following keywords are available:</p>
<ul dir="auto">
<li><code>max_degree::Int</code>: Maximum degree used in the spherical harmonics when computing the
geomagnetic field. If it is higher than the available number of coefficients in the IGRF
matrices, it will be clamped. If it is equal of lower than 0, it will be set to 1.
(<strong>Default</strong> = 13)</li>
<li><code>show_warnings::Bool</code>: Show warnings about the data (<strong>Default</strong> = <code>true</code>).</li>
<li><code>P::Union{Nothing, AbstractMatrix}</code>: An optional matrix that must contain at least
<code>max_degree + 1 × max_degree + 1</code> real numbers that will be used to store the Legendre
coefficients, reducing the allocations. If it is <code>nothing</code>, the matrix will be created
when calling the function.</li>
<li><code>dP::Union{Nothing, AbstractMatrix}</code>: An optional matrix that must contain at least
<code>max_degree + 1 × max_degree + 1</code> real numbers that will be used to store the Legendre
derivative coefficients, reducing the allocations. If it is <code>nothing</code>, the matrix will
be created when calling the function.</li>
</ul>
<p dir="auto">This function returns a <code>SVector{3, T}</code>, which is the geomagnetic field vector [nT] at the
desired location represented in the same input reference (geocentric or geodetic). Notice
that the output type <code>T</code> is obtained by promoting <code>T1</code>, <code>T2</code>, and <code>T3</code> to a float.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Simplified dipole model</h3><a id="user-content-simplified-dipole-model" class="anchor" aria-label="Permalink: Simplified dipole model" href="#simplified-dipole-model"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This model assumes that the Earth geomagnetic field is a perfect dipole. The approximation
is not good but it can be sufficient for some analysis, such as those carried out at the
Pre-Phase A of a space mission when the uncertainties are high.</p>
<p dir="auto">The following function computes the geomagnetic field using the simplified dipole model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function geomagnetic_dipole_field(r_e::AbstractVector{T}, year::Number = 2020) where T"><pre><span class="pl-k">function</span> <span class="pl-en">geomagnetic_dipole_field</span>(r_e<span class="pl-k">::</span><span class="pl-c1">AbstractVector{T}</span>, year<span class="pl-k">::</span><span class="pl-c1">Number</span> <span class="pl-k">=</span> <span class="pl-c1">2020</span>) <span class="pl-k">where</span> T</pre></div>
<p dir="auto">Compute the geomagnetic field [nT] using the simplified dipole model at position <code>r_e</code> (ECEF
reference frame) [m]. This function uses the year <code>year</code> to obtain the position of the South
geomagnetic pole (which lies in the North hemisphere) and the dipole moment. If <code>year</code> is
omitted, it defaults to 2020.</p>
<p dir="auto">Notice that:</p>
<ol dir="auto">
<li>The output vector will be represented in the ECEF reference frame.</li>
<li>The returned vector type is obtained by converting <code>T</code> to a float.</li>
<li>The south geomagnetic pole position and dipole moment is obtained by interpolating the
values provided in <strong>[2]</strong>.</li>
</ol>
