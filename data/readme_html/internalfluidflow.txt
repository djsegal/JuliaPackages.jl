<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><strong>Re2f</strong></h3><a id="user-content-re2f" class="anchor" aria-label="Permalink: Re2f" href="#re2f"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>Re2f</code> computes the Darcy friction f factor given the Reynolds number Re and the relative roughness ε.</p>
<p dir="auto">By default, pipe is assumed to be smooth (ε = 0). If ε &gt; 0.05, relative roughness is reset to upper limit ε = 0.05.</p>
<p dir="auto">If fig = true is given a schematic Moody diagram is plotted as a graphical representation of the solution.</p>
<p dir="auto">If lam = false is given
then <code>Re2f</code> disregards the laminar flow bounds (Re &lt; 4e3).</p>
<p dir="auto">If turb = false is given
then <code>Re2f</code> disregards the turbulent flow bounds (Re &gt; 2.3e3).</p>
<p dir="auto"><strong>Syntax:</strong></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Re2f(; # Darcy friction factor

    )"><pre><span class="pl-c1">Re2f</span>(; <span class="pl-c"><span class="pl-c">#</span> Darcy friction factor</span>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><strong>f2Re</strong></h3><a id="user-content-f2re" class="anchor" aria-label="Permalink: f2Re" href="#f2re"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>f2Re</code> computes the Reynolds number Re given the Darcy friction factor f and the relative roughness ε for both laminar and turbulent regime, if possible.</p>
<p dir="auto">By default, pipe is assumed to be smooth (ε = 0). If ε &gt; 0.05, relative roughness is reset to upper limit ε = 0.05.</p>
<p dir="auto">If fig = true is given a schematic Moody diagram is plotted as a graphical representation of the solution.</p>
<p dir="auto">If lam = false is given
then <code>f2Re</code> disregards the laminar flow bounds (Re &lt; 4e3).</p>
<p dir="auto">If turb = false is given
then <code>f2Re</code> disregards the turbulent flow bounds (Re &gt; 2.3e3).</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><strong>h2fRe</strong></h3><a id="user-content-h2fre" class="anchor" aria-label="Permalink: h2fRe" href="#h2fre"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>h2fRe</code> computes the Reynolds number Re and Darcy friction factor f given the head loss h, the pipe hydraulic diameter D or the flow speed v or the volumetric flow rate Q, the pipe length L (default L = 100 cm), the pipe roughness k (default k = 0 cm) or the pipe relative roughness ε (default ε = 0), the fluid density ρ (default ρ = 0.997 g/cc), the fluid dynamic viscosity μ (default μ = 0.0091 g/cm/s), and the gravitational accelaration g (default g = 981 cm/s/s).</p>
<p dir="auto">By default, pipe is assumed to be 1 m long, L = 100 (in cm).</p>
<p dir="auto">By default, pipe is assumed to be smooth (ε = 0). If ε &gt; 0.05, relative roughness is reset to upper limit ε = 0.05.</p>
<p dir="auto">Notice that default values are given in the cgs unit system and, if taken, all other parameters must as well be given in cgs units.</p>
<p dir="auto">If fig = true is given a schematic Moody diagram is plotted as a graphical representation of the solution.</p>
<p dir="auto">If flow speed is given, both laminar and turbulent flow
bounds are considered for possible solutions.</p>
