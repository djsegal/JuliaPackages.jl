<p dir="auto">Hecke is a software package for algebraic number theory maintained by Claus Fieker and Tommy Hofmann.
It is written in <a href="https://www.julialang.org" rel="nofollow">julia</a> and is based on the computer algebra packages <a href="https://github.com/Nemocas/Nemo.jl">Nemo</a> and <a href="https://github.com/Nemocas/AbstractAlgebra.jl">AbstractAlgebra</a>.
Hecke is part of the <a href="https://www.oscar-system.org/" rel="nofollow">OSCAR</a> project and the development is supported by the Deutsche Forschungsgemeinschaft DFG within the Collaborative Research Center TRR 195.</p>
<ul dir="auto">
<li><a href="https://github.com/thofma/Hecke.jl">https://github.com/thofma/Hecke.jl</a> (Source code)</li>
<li><a href="https://thofma.github.io/Hecke.jl/dev/" rel="nofollow">https://thofma.github.io/Hecke.jl/dev/</a> (Online documentation)</li>
</ul>
<p dir="auto">So far, Hecke provides the following features:</p>
<ul dir="auto">
<li>Number fields (absolute, relative, simple and non-simple)</li>
<li>Orders and ideals in number fields</li>
<li>Class and unit group computations of orders</li>
<li>Lattice enumeration</li>
<li>Sparse linear algebra</li>
<li>Class field theory</li>
<li>Abelian groups</li>
<li>Associative algebras</li>
<li>Ideals and orders in (semisimple) associative algebras</li>
<li>Locally free class groups of orders in semisimple algebras</li>
<li>Quadratic and Hermitian forms and lattices</li>
</ul>

<p dir="auto">To use Hecke, a julia version of 1.0 is necessary (the latest stable julia version will do).
Please see <a href="https://julialang.org/downloads/" rel="nofollow">https://julialang.org/downloads/</a> for instructions on how to obtain julia for your system.
Once a suitable julia version is installed, use the following steps at the julia prompt to install Hecke:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg
