<p dir="auto">For using <code>@llvm_play</code> you will need to install <a href="https://github.com/chirlu/sox"><code>sox</code></a>.

<p dir="auto">With the installation done you are ready for some LLVM music delight!
Troubadour can be used via its macros <code>@llvm_midi</code> and <code>@llvm_play</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Troubadour
@llvm_midi sqrt(2)
@llvm_play println(&quot;Dance!&quot;)"><pre><span class="pl-k">using</span> Troubadour
<span class="pl-c1">@llvm_midi</span> <span class="pl-c1">sqrt</span>(<span class="pl-c1">2</span>)
<span class="pl-c1">@llvm_play</span> <span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>Dance!<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">With <code>@llvm_midi</code> you can also record your llvm as an MP3 using the keyword <code>record = true</code></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@llvm_midi 1 + 1 record = true"><pre><span class="pl-c1">@llvm_midi</span> <span class="pl-c1">1</span> <span class="pl-k">+</span> <span class="pl-c1">1</span> record <span class="pl-k">=</span> <span class="pl-c1">true</span></pre></div>
<p dir="auto">The sound file will be saved as "1 + 1.mp3" (the latest summer hit).</p>
