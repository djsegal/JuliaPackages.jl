<p dir="auto">Wrapper of the library
<a href="https://github.com/bartp5/libtexprintf">bartp5/libtexprintf</a> for
printing rendered LaTeX code in the terminal.</p>
<p dir="auto">Given that libtexprintf is licensed under the GPL-3.0 and this library links
dynamically with it, the full work must be GPL-3.0. The LICENCE was changed to
make clear that using this library implies using GPLed code.</p>
