<p dir="auto"><a href="https://github.com/jverzani/SymPyCore.jl">SymPyCore</a> provides a <code>Julia</code>n interface to the <a href="https://www.sympy.org/" rel="nofollow">SymPy</a> library of Python.</p>
<p dir="auto"><a href="https://github.com/jverzani/SymPyPythonCall.jl">SymPyPythonCall</a> utilizes <code>SymPyCore</code> and the <code>PythonCall</code> package (to provide the interop between <code>Julia</code> and <code>Python</code>) to enable access to Python's SymPy library using the practices and idioms of <code>Julia</code>.</p>
<p dir="auto">The package <a href="https://github.com/jverzani/SymPyPyCall.jl">SymPyPyCall</a> does a similar thing with the <code>PyCall</code> package providing the interop.</p>

<p dir="auto">Installing this package should install the <code>SymPyCore</code> package and the <code>PythonCall</code> package. The <code>PythonCall</code> package installs a <code>CondaPkg</code> package that installs the underlying SymPy library for Python.</p>
