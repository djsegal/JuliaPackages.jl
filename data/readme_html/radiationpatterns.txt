<p dir="auto"><code>RadiationPatterns.jl</code> is a Julia package designed for visualizing radiation patterns using <code>PlotlyJS.jl</code>. The package provides functions for creating 2D and 3D plots of radiation patterns, as well as calculating directivity. I hope to confine the settings of the plots to the essential ones using keywords. However, if further modifications are needed, one can always use the API provided by <code>PlotlyJS.jl</code> (such as <code>update!</code>) to modify the figures returned by the API provided by this package (<code>SyncPlot</code> objects are returned in the functions).</p>

<p dir="auto">where <code>U</code> is a 2D meshgrid data representing the radiation pattern with <code>x</code> as the coordinate for the first dimension and <code>y</code> as the coordinate for the second dimension. The data structure is arranged as the following figure:</p>
<p align="center" dir="auto">
  <a target="_blank" rel="noopener noreferrer" href="./media/illus3.png"><img alt="illus3" src="./media/illus3.png" width="40%" height="auto" style="max-width: 100%;"></a>
</p>
<p dir="auto">The following example creates a dipole radiation pattern:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="tht = collect(-180:180)
phi = collect(0:180)

_, T = meshgrid(phi, tht) # uses MeshGrid.jl
U = sind.(T).^2
Pat = Pattern(U, tht, phi)"><pre>tht <span class="pl-k">=</span> <span class="pl-c1">collect</span>(<span class="pl-k">-</span><span class="pl-c1">180</span><span class="pl-k">:</span><span class="pl-c1">180</span>)
phi <span class="pl-k">=</span> <span class="pl-c1">collect</span>(<span class="pl-c1">0</span><span class="pl-k">:</span><span class="pl-c1">180</span>)

_, T <span class="pl-k">=</span> <span class="pl-c1">meshgrid</span>(phi, tht) <span class="pl-c"><span class="pl-c">#</span> uses MeshGrid.jl</span>
U <span class="pl-k">=</span> <span class="pl-c1">sind</span>.(T)<span class="pl-k">.^</span><span class="pl-c1">2</span>
Pat <span class="pl-k">=</span> <span class="pl-c1">Pattern</span>(U, tht, phi)</pre></div>
<p dir="auto">The convention for <code>x</code> associating with <code>theta</code> in degrees and <code>y</code> associating with <code>phi</code> in degrees is used throughout when creating patterns in spherical coordinates.</p>

<p dir="auto">There are two primary plotting functions used by the 2D pattern plotting function (<code>ptn_2d</code>): <code>plot_rect</code> and <code>plot_polar</code>. They are not directly used for pattern plotting; however, these two functions can also be used as a simplified API to draw 2D plots in rectangular and polar coordinates (if you find settings in PlotlyJS very cumbersome 😆). In the following, keyword default value with <code>0</code> (or <code>[0, 0]</code> in ranges) means not specifying these keywords in the plotly plots. Noted that both of the functions support plotting multiple traces in one plot.</p>
