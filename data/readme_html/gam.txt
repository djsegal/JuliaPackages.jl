<p dir="auto"><a href="https://en.wikipedia.org/wiki/Generalized_additive_model" rel="nofollow">Generalised additive models</a> (GAMs) are an incredibly powerful modelling tool for regression practitioners. However, the functionality of the excellent R package <a href="https://cran.r-project.org/web/packages/mgcv/mgcv.pdf" rel="nofollow"><code>mgcv</code></a> is yet to be built in native Julia. This package aims to do just that, albeit at much less complexity given how sophisticated <code>mgcv</code> is.</p>

<p dir="auto">The basic interface to <code>GAM.jl</code> is the <code>gam</code> function, which is as easy as:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="    mod = gam(&quot;Volume ~ s(Girth, k=10, degree=3) + s(Height, k=10, degree=3)&quot;, df)"><pre lang="{julia}" class="notranslate"><code>    mod = gam("Volume ~ s(Girth, k=10, degree=3) + s(Height, k=10, degree=3)", df)
</code></pre></div>
<p dir="auto">by default, <code>gam</code> uses a Normal likliehood and the identity link function. In this example, <code>df</code> is the <code>trees</code> dataset included in R and in Julia through the <a href="https://github.com/JuliaStats/RDatasets.jl"><code>RDatasets</code></a> package. We are using two covariates in <code>df</code> -- <code>Girth</code> and <code>Height</code> -- and we are specifying 10 knots and a polynomial order of 3 for the splines for both. Note the similarity between the formula specification and that used by <code>mgcv</code> in R. Unfortunately, we have not yet solved a symbolic way to represent the formula using a macro instead of a string, but hopefully this will be come in the near future!</p>
<p dir="auto">Users can also control the penalised iteratively reweighted least squares algorithm directly, as well as change the likelihood family and link function:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="mod = gam(&quot;Volume ~ s(Girth, k=10, degree=3) + s(Height, k=10, degree=3)&quot;,        df; Family = &quot;Gamma&quot;, Link = &quot;Log&quot;, 
          Optimizer = NelderMead(), maxIter = 1e5,
          tol = 1e-6)"><pre lang="{julia}" class="notranslate"><code>mod = gam("Volume ~ s(Girth, k=10, degree=3) + s(Height, k=10, degree=3)",        df; Family = "Gamma", Link = "Log", 
          Optimizer = NelderMead(), maxIter = 1e5,
          tol = 1e-6)
</code></pre></div>
<p dir="auto">Note that currently, the following families are supported:</p>
<ul dir="auto">
<li><code>Normal</code></li>
<li><code>Poisson</code></li>
<li><code>Gamma</code></li>
</ul>
<p dir="auto">And the following link functions:</p>
<ul dir="auto">
<li><code>Identity</code></li>
<li><code>Log</code></li>
</ul>
