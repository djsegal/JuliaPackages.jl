<p dir="auto"><a href="https://github.com/PetrKryslUCSD/FinEtools.jl.git"><code>FinEtools</code></a> is a package
for basic operations on finite element meshes. <code>FinEtoolsAcoustics</code> is a package
using <code>FinEtools</code> to solve linear acoustics problems.</p>

<p dir="auto">There are a number of tutorials explaining the use of this package.
Check out the <a href="https://github.com/PetrKryslUCSD/FinEtoolsAcoustics.jl/blob/main/tutorials/index.md">index</a>.
The are tutorials themselves can be executed as
follows:</p>
<ul dir="auto">
<li>Download the package or clone it.</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="git clone https://github.com/PetrKryslUCSD/FinEtoolsAcoustics.jl.git"><pre class="notranslate"><code>git clone https://github.com/PetrKryslUCSD/FinEtoolsAcoustics.jl.git
</code></pre></div>
<ul dir="auto">
<li>Change into the <code>tutorials</code> folder: <code>cd .\FinEtoolsAcoustics.jl\tutorials</code>.</li>
<li>Start Julia: <code>julia</code>.</li>
<li>Activate the environment:</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Pkg; Pkg.activate(&quot;.&quot;); Pkg.instantiate();"><pre class="notranslate"><code>using Pkg; Pkg.activate("."); Pkg.instantiate();
</code></pre></div>
<ul dir="auto">
<li>Execute the desired tutorial. Here <code>name_tut.jl</code> is the name of the tutorial file:</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="include(&quot;name_tut.jl&quot;)"><pre class="notranslate"><code>include("name_tut.jl")
