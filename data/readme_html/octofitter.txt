<p dir="auto">Octofitter is a Julia package for performing Bayesian inference
against a wide variety of exoplanet / binary star data.
You can also use Octofitter from Python using <a href="https://github.com/sefffal/octofitterpy">octofitterpy</a>.</p>
<p dir="auto"><strong>Read the tutorials and documentation <a href="https://sefffal.github.io/Octofitter.jl/" rel="nofollow">here</a></strong>.</p>
