<p dir="auto">Finite MPS and MPO methods based on ITensor (ITensors.jl).</p>
<p dir="auto">This package currently re-exports the MPS and MPO functionality of the <a href="https://github.com/ITensor/ITensors.jl">ITensors.jl</a>, including functionality like DMRG, applying MPO to MPS, applying gates to MPS and MPO, etc. See the <a href="https://itensor.github.io/ITensors.jl/dev" rel="nofollow">ITensor documentation</a> for guides and examples on using this package.</p>
<p dir="auto">Additionally, it re-exports the functionality of the <a href="https://github.com/ITensor/ITensorTDVP.jl">ITensorTDVP.jl</a> package, which provides other DMRG-like MPS solvers such as TDVP and MPS linear equation solving.</p>

<p dir="auto">The goal will be to move the MPS and MPO code from the ITensors.jl package, along with all of the code from the <a href="https://github.com/ITensor/ITensorTDVP.jl">ITensorTDVP.jl</a> package, into this repository. If you are using any MPS/MPO functionality of ITensors.jl, such as the <code>MPS</code> and <code>MPO</code> types or constructors thereof (like <code>randomMPS</code>), <code>OpSum</code>, <code>siteinds</code>, <code>dmrg</code>, <code>apply</code>, etc. you should install the ITensorMPS.jl package with <code>import Pkg; Pkg.add("ITensorMPS")</code> and add <code>using ITensorMPS</code> to your code. Additionally, if you are currently using <a href="https://github.com/ITensor/ITensorTDVP.jl">ITensorTDVP.jl</a>, you should replace <code>using ITensorTDVP</code> with <code>using ITensorMPS</code> in your codes.</p>
