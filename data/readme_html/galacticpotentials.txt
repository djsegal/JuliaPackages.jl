<p dir="auto">Potentials are defined as subtypes of <code>ModelingToolkit.jl</code> models. They can be
converted to <code>ODESystem</code> and <code>ODEProblem</code> types to interact with the rest of the
<code>SciML</code> ecosystem.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Plots
using ModelingToolkit
using DifferentialEquations
using GalacticPotentials

let model = ODESystem(PlummerPotential())

    p = @nonamespace Dict(
        model.G =&gt; 6.6743e-20, # field strength (km³ kg⁻¹ s⁻²)
        model.m =&gt; 6e31,       # mass (kg)
        model.b =&gt; 1e-6        # softening parameter (unitless)
    )

    u0 = @nonamespace Dict(
        model.x =&gt; 11e5,
        model.y =&gt; 5e5,
        model.z =&gt; 0,
        model.Δx =&gt; 1e3,
        model.Δy =&gt; 1e3,
        model.Δz =&gt; 0
    )

    ts = (0.0, 1e6)

    problem = ODEProblem(model, u0, ts, p)
    solution = solve(problem; reltol=1e-14, abstol=1e-14)

    plot(solution; idxs=(:x,:y), label=:none, dpi = 400, aspect_ratio=:equal)
end"><pre><span class="pl-k">using</span> Plots

<p dir="auto">This package is <a href="/gen/gala.jl">bootstrapped</a> off of <a href="http://gala.adrian.pw" rel="nofollow"><code>gala</code></a>
and <a href="https://docs.galpy.org" rel="nofollow"><code>galpy</code></a>, two rich Python packages for galactic dynamics.
I aim to learn about galactic dynamics by integrating the models within these two popular
Python packages into the <a href="https://sciml.ai" rel="nofollow">SciML</a> ecosystem. The Gala license is
pasted below.</p>
