<p dir="auto">Implementation of control methods for analytical parameterized control fields.</p>
<p dir="auto">Part of <a href="https://github.com/JuliaQuantumControl/QuantumControl.jl#readme"><code>QuantumControl.jl</code></a> and the <a href="https://github.com/JuliaQuantumControl">JuliaQuantumControl</a> organization.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Define a <code>QuantumControl.ControlProblem</code> that contains parameterized generators or control fields: <code>get_parameters(problem)</code> must return a vector of control parameters.</p>
</li>
<li>
<p dir="auto">Call <code>QuantumControl.optimize</code> using <code>method=ParameterizedQuantumControl</code>, and give an appropriate backend and optimizer, e.g.,</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="optimize(
    problem;
    method=ParameterizedQuantumControl,
    backend=Optimization,
    optimizer=NLopt.LN_NELDERMEAD(),
)"><pre class="notranslate"><code>optimize(
    problem;
    method=ParameterizedQuantumControl,
    backend=Optimization,
    optimizer=NLopt.LN_NELDERMEAD(),
)
</code></pre></div>
</li>
</ul>
<p dir="auto">Currently, only <a href="https://github.com/SciML/Optimization.jl"><code>Optimization.jl</code></a> is supported as a backend, and only with gradient-free optimizers. In the future, this will be extended to gradient-based optimizers (i.e., the "GOAT" method), as well as specific pulse parametrizations (e.g., CRAB).</p>
