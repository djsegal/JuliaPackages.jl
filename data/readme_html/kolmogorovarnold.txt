<p dir="auto">Julia implementation of the <a href="https://arxiv.org/abs/2404.19756" rel="nofollow">Kolmogorov-Arnold network</a>
for the <a href="https://lux.csail.mit.edu/stable/" rel="nofollow"><code>Lux.jl</code></a> framework.
This implementation is based on <a href="https://github.com/Blealtan/efficient-kan">efficient-kan</a>
and <a href="https://github.com/ZiyaoLi/fast-kan">'FastKAN'</a> which resolve the performance
issues with the <a href="https://github.com/KindXiaoming/pykan">original implementation</a>.
Key implementation details here are:</p>
<ul dir="auto">
<li>We fix our grid to be in <code>[-1, 1]</code> and normalize the the input to lie in that interval with <code>tanh</code> or <code>NNlib.tanh_fast</code>.</li>
<li>We use radial basis functions in place of the spline basis as the former is very efficient to evaluate.</li>
</ul>

<p dir="auto">The performance of KANs improves significantly with <code>use_base_act = false</code>.
Although KANs are currently 2-3x slower than an MLPs with the same number of parameters,
the promise with this architecture is that a small KAN can potentially do the work of a much bigger MLP.
More experiments need to be done to assess the validity of this claim.</p>
<p dir="auto">This package will be actively developed for the time-being.
Once a stable version is figured out, we can consider opening a PR on <a href="https://github.com/LuxDL/Lux.jl"><code>Lux.jl</code></a>.
Feel fre to open issues or create PRs in the meantime with features, comparisons, or performance improvements.</p>
