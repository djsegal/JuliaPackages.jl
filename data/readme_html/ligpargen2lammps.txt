<p dir="auto">Convert LAMMPS data files generated by <a href="http://zarbi.chem.yale.edu/ligpargen/" rel="nofollow">LigParGen</a>
into molecule description and pair/bond/angle/dihedral/improper coeffs section for LAMMPS.</p>
<p dir="auto">The utilities also "compress" atom, bond, angle and dihedral types, i.e. types with the
same mass, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9ad18fd7ead2ae9a717c9a1216a5547e">$\varepsilon$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="9ad18fd7ead2ae9a717c9a1216a5547e">$\sigma$</math-renderer> parameters are added as atoms of the same type
(as opposed to the LigParGen data where each atom has its own type), bonds with the same
parameters are added as the same bond type etc. Additionally, bonds, angles, dihedrals
and impropers with zero energy parameters are excluded from the resulting molecule file.</p>

<p dir="auto">In the below examples, it is assumed that <code>ligpargenfile</code> is a LAMMPS data file generated
by LigParGen.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="read_lpg_data(ligpargenfile[; keywords...])"><pre class="notranslate"><code>read_lpg_data(ligpargenfile[; keywords...])
</code></pre></div>
<p dir="auto">Read the datafile produced by LigParGen from <code>ligpargenfile</code>. <code>ligpargenfile</code> may be an
I/O stream or a file name.</p>

<ul dir="auto">
<li>
<p dir="auto"><code>compress_types::Bool=true</code>: mark particles with the same LJ parameters as the same type</p>
</li>
<li>
<p dir="auto"><code>compress_btypes::Bool=true</code>: mark bonds with the same parameters as the same type</p>
</li>
<li>
<p dir="auto"><code>compress_atypes::Bool=true</code>: mark angles with the same parameters as the same type</p>
</li>
<li>
<p dir="auto"><code>compress_dtypes::Bool=true</code>: mark dihedrals with the same parameters as the same type</p>
</li>
<li>
<p dir="auto"><code>compress_itypes::Bool=true</code>: mark impropers with the same parameters as the same type</p>
</li>
<li>
<p dir="auto"><code>net_charge=nothing</code>: if set to a number, the charges will be tweaked so that the total
charge equals to the specified value. If set to <code>nothing</code>, the charges will be tweaked
so that the net charge is the nearest integer value</p>
<p dir="auto">write_mol(f, ligpargenfile::AbstractString)</p>
</li>
</ul>
<p dir="auto">Read the molecular topology from file named <code>ligpargenfile</code> and write it into <code>f</code>
in a format that can be read by LAMMPS <code>molecule</code> command. <code>f</code> can be an I/O stream
or a filename.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="write_ff(f, ligpargenfile::AbstractString)"><pre class="notranslate"><code>write_ff(f, ligpargenfile::AbstractString)
</code></pre></div>
<p dir="auto">Read the molecular topology from file named <code>ligpargenfile</code> and write its forcefield
into <code>f</code> in a format compatible to LAMMPS input script. <code>f</code> can be an I/O stream
or a filename.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="write_mol_and_ff(fmask::AbstractString, ligpargenfile::AbstractString)"><pre class="notranslate"><code>write_mol_and_ff(fmask::AbstractString, ligpargenfile::AbstractString)
</code></pre></div>
<p dir="auto">Read the molecular topology and forcefield parameters from <code>ligpargenfile</code> and write them
into files "fmask.txt" and "fmask.ff", respectively.</p>
