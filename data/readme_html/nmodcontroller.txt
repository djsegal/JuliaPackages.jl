<p dir="auto">This is a suite for numerically simulating conductance based model when coupled with <a href="https://github.com/SciML/DifferentialEquations.jl"><em>DifferentialEquations.jl</em></a>. The purpose of this package is to supply easy definition and simulation of any conductance based model. Moreover, it permits easy broadcasting of Dynamics Input Conductance theory (<a href="https://www.eneuro.org/content/2/1/ENEURO.0031-14.2015" rel="nofollow">paper</a>) and of a robust neuromodulation controller (<a href="https://orbi.uliege.be/handle/2268/304427" rel="nofollow">paper</a>).</p>
