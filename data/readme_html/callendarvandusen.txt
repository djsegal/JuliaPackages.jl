<p dir="auto">A simple Julia package that implements the <a href="https://en.wikipedia.org/wiki/Callendar%E2%80%93Van_Dusen_equation" rel="nofollow">Callendar Van Dusen equation</a>. This equation applies to Platinum Resistive Thermometers (PRTs), and defines functional relationships between temperature and resistance.</p>
<p dir="auto">This package does not export the main functions <code>R</code> and <code>t</code>, due to possibility of name-clashing. It instead exports <code>CVD</code> as an alias for <code>CallendarVanDusen</code>, allowing users to write <code>CVD.R</code> and <code>CVD.t</code> to access the functions.</p>

<p dir="auto">The first function is <code>CVD.R</code>, which returnes the resistance (in Ohm's), for a given temperature. Let's look at its docstring:</p>

  according to the Callendar Van Dusen equation. The second

<p dir="auto">So let's say we have a given PRT. It will have a resistance at 0 °C, denoted <code>R0</code>. <code>R0</code> is typically given in the datasheet, and determines the second argument to <code>CVD.R</code>. So we can find the resistance at any temperature <code>t</code> within the valid range of (-200 °C, 661 °C) by running <code>CVD.R(t, R0)</code>, assuming that the PRT is up to the relevant industry standard.</p>

<p dir="auto"><code>CVD.t(R_meas, R0)</code> finds and returns the temperature <code>t</code> that corresponds to a resistance of <code>R_meas</code>. It does this by solving <code>CVD.R(t, R0) - R_meas = 0</code> for <code>t</code>, numerically.</p>
