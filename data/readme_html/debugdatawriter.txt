<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Environment based output</h2><a id="user-content-environment-based-output" class="anchor" aria-label="Permalink: Environment based output" href="#environment-based-output"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This is case is zero cost when the environment variable <code>DEBUG_OUTPUT</code> is not defined.
The variable may be initialized in the system environment:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="export DEBUG_OUTPUT=&quot;log | dump&quot;"><pre><span class="pl-k">export</span> DEBUG_OUTPUT=<span class="pl-s"><span class="pl-pds">"</span>log | dump<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">Or be initialized directly in Julia, but BEFORE including the code where macos are used.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ENV[&quot;DEBUG_OUTPUT&quot;] = &quot;log | dump&quot;"><pre><span class="pl-c1">ENV</span>[<span class="pl-s"><span class="pl-pds">"</span>DEBUG_OUTPUT<span class="pl-pds">"</span></span>] <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>log | dump<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">There string contains the same names of modes as in the previous case. It can be any combination of modes: "log", "dump | log", etc.</p>
