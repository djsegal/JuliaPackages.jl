<p dir="auto">A package for parsing <a href="https://www.ldraw.org/" rel="nofollow">LDraw™</a> files. As stated on the LDraw website, LDraw is an open standard for LEGO CAD programs that enables the creation of virtual LEGO models. This package allows you to parse LDraw™ files into a Julia data structure.</p>

<p dir="auto">It is recommended to download the LDraw parts library to get full use out of your models. Functionality still exists without the parts library, including parsing the build steps, but individual part geometry is recommended for most applications. The parts library can be downloaded from <a href="https://library.ldraw.org/updates?latest" rel="nofollow">LDraw™ Parts Library</a>. Place the unzipped library in your desired path. The default path assumed by LDrawParser is <code>joinpath(homedir(), "Documents/ldraw")</code>. It is recommended to download the complete library (~80 MB zipped, ~450 MB unzipped).</p>
<p dir="auto">If you did not place the parts library in the default path, you can change the path LDrawParser uses by the <code>set_part_library_dir!</code> command. For example, if you placed the parts library in the assets directory, you can run the following command in the Julia REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using LDrawParser
