<p dir="auto">From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run:</p>

</code></pre></div>
<p dir="auto">Or, equivalently, via the Pkg API:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;https://github.com/JuliaRobotics/TORA.jl&quot;)"><pre class="notranslate"><code>julia&gt; import Pkg; Pkg.add("https://github.com/JuliaRobotics/TORA.jl")
