<p dir="auto">DynamicStructs is a Julia package that allows you to create structs with dynamic properties. These properties behave similarly to fields of type <code>Any</code> in mutable structs, but are bound to the instance rather than the type, and can be added and deleted at runtime.</p>

end

<ul dir="auto">
<li>Create structs with both fields and dynamic properties using the <code>@dynamic</code> macro.</li>
<li>Use <code>mutable struct</code> to allow for modifying field values.</li>
<li>Type safety for <em>fields</em>.</li>
<li>Add, modify, and delete dynamic properties at runtime.</li>
<li>Check if types and instances are dynamic with <code>isdynamictype</code> and <code>isdynamic</code>:</li>
</ul>
