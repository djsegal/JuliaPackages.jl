<p dir="auto">This package implements a number of state-space models in julia. It take inspiration from the <a href="https://github.com/lindermanlab/ssm">SSM package</a> written in python from the Linderman Lab. Currently, the following models are implemented:</p>
<ul class="contains-task-list">

<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Gaussian Mixture Models</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Poisson Mixture Models</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Binomial Mixture Models</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Negative Binomial Mixture Models</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Student's t Mixture Models</li>
</ul>
</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Hidden Markov Models
<ul class="contains-task-list">
