<p dir="auto">Import the package first.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using QuadraticAberrationCorrector"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> QuadraticAberrationCorrector</pre></div>
<p dir="auto">When the following code is executed, the phase <code>ϕ</code> is corrected by the least squares algorithm and stored in <code>ψ</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ψ = CorrectAberration(ϕ)"><pre>julia<span class="pl-k">&gt;</span> ψ <span class="pl-k">=</span> <span class="pl-c1">CorrectAberration</span>(ϕ)</pre></div>
<p dir="auto">When using the weighted least square algorithm, use the following function.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ψ = WeightedCorrectAberration(ϕ, 10, 10)"><pre>julia<span class="pl-k">&gt;</span> ψ <span class="pl-k">=</span> <span class="pl-c1">WeightedCorrectAberration</span>(ϕ, <span class="pl-c1">10</span>, <span class="pl-c1">10</span>)</pre></div>
