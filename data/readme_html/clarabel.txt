<p dir="auto"><strong>Clarabel.jl</strong> is a Julia implementation of an interior point numerical solver for convex optimization problems using a novel homogeneous embedding.  Clarabel.jl solves the following problem:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$$
\begin{array}{r}
\text{minimize} &amp; \frac{1}{2}x^T P x + q^T x\\[2ex]
\text{subject to} &amp; Ax + s = b \\[1ex]
&amp; s \in \mathcal{K}
\end{array}
$$</math-renderer></p>
<p dir="auto">with decision variables
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$x \in \mathbb{R}^n$</math-renderer>,
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$s \in \mathbb{R}^m$</math-renderer>
and data matrices
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$P=P^\top \succeq 0$</math-renderer>,
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$q \in \mathbb{R}^n$</math-renderer>,
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$A \in \mathbb{R}^{m \times n}$</math-renderer>, and
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$b \in \mathbb{R}^m$</math-renderer>.
The convex set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="3737febbc6741e4a12337ffb2bea6720">$\mathcal{K}$</math-renderer> is a composition of convex cones.</p>
<p dir="auto"><strong>For more information see the Clarabel Documentation (<a href="https://oxfordcontrol.github.io/ClarabelDocs/stable" rel="nofollow">stable</a> |  <a href="https://oxfordcontrol.github.io/ClarabelDocs/dev" rel="nofollow">dev</a>).</strong></p>
<p dir="auto">Clarabel is also available in a Rust implementation with additional language interfaces.  See <a href="https://github.com/oxfordcontrol/Clarabel.rs">here</a>.</p>

<ul dir="auto">
<li><strong>Versatile</strong>: Clarabel.jl solves linear programs (LPs), quadratic programs (QPs), second-order cone programs (SOCPs) and semidefinite programs (SDPs). It also solves problems with exponential, power cone and generalized power cone constraints.</li>
<li><strong>Quadratic objectives</strong>: Unlike interior point solvers based on the standard homogeneous self-dual embedding (HSDE), Clarabel.jl handles quadratic objectives without requiring any epigraphical reformulation of the objective.   It can therefore be significantly faster than other HSDE-based solvers for problems with quadratic objective functions.</li>
<li><strong>Infeasibility detection</strong>: Infeasible problems are detected using a homogeneous embedding technique.</li>
<li><strong>JuMP / Convex.jl support</strong>: We provide an interface to <a href="https://jump.dev/JuMP.jl/stable/moi/" rel="nofollow">MathOptInterface</a> (MOI), which allows you to describe your problem in <a href="https://github.com/jump-dev/JuMP.jl">JuMP</a> and <a href="https://github.com/jump-dev/Convex.jl">Convex.jl</a>.</li>
<li><strong>Arbitrary precision types</strong>: You can solve problems with any floating point precision, for example, Float32 or Julia's BigFloat type, using either the native interface, or via MathOptInterface / Convex.jl.</li>
<li><strong>Open Source</strong>: Our code is available on <a href="https://github.com/oxfordcontrol/Clarabel.jl">GitHub</a> and distributed under the Apache 2.0 License</li>
</ul>
