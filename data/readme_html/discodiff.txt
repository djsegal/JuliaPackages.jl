<p dir="auto">A small package for differentiable discontinuities in Julia. Implements a simple API to generate differentiable discontinuous functions using the pass-through trick. Works both in forward and reverse mode with scalars and arrays.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Main API</h2><a id="user-content-main-api" class="anchor" aria-label="Permalink: Main API" href="#main-api"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To generate a differentiable function version of a discontinuous function <code>f</code> such that the gradient of <code>f</code> is the gradient of <code>g</code>, simply use:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="new_f = construct_diff_version(f,g)"><pre>new_f <span class="pl-k">=</span> <span class="pl-c1">construct_diff_version</span>(f,g)</pre></div>
<p dir="auto">This is used in the case</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$$
\frac{df}{dx}
$$</math-renderer></p>
<p dir="auto">is either not defined or does not have the desired properties. For example where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$f$</math-renderer> is the sign function. Sometimes we want to still be able to propagate gradients trough this. In this case we impose</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$$
\frac{df}{dx} = \frac{dg}{dx}
$$</math-renderer></p>
<p dir="auto">Use it as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="new_f(x)
# control gradient steppes
new_f(2.0, k = 100.0)"><pre><span class="pl-c1">new_f</span>(x)
<span class="pl-c"><span class="pl-c">#</span> control gradient steppes</span>
<span class="pl-c1">new_f</span>(<span class="pl-c1">2.0</span>, k <span class="pl-k">=</span> <span class="pl-c1">100.0</span>)</pre></div>
<p dir="auto">In the second case we have</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$$
\frac{df}{dx}(2.0) = \frac{dg}{dx}(100.0 \cdot 2.0)
$$</math-renderer></p>
<p dir="auto">Note: to avoid type instabilities ensure <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$x$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$k$</math-renderer> are of the same type. The package works both with forward and reverse mode automatic differentiation.</p>

<p dir="auto">The Heaviside function, also known as the step function, is a discontinuous function named after the British physicist Oliver Heaviside. It is often used in control theory, signal processing, and probability theory.</p>
<p dir="auto">The Heaviside function is defined as:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$$
H(x) = \begin{cases}
0 &amp; \text{for } x \leq 0, \\
1 &amp; \text{for } x &gt; 0.
\end{cases}
$$</math-renderer></p>
<p dir="auto">We also implement a differentiable version of the sign function defined as:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="2536a0c6d124d4c870b168b7ffa2cfbc">$$
sign(x) = \begin{cases}
1 &amp; \text{for } x &gt; 0, \\
0 &amp; \text{for } x = 0, \\
-1 &amp; \text{for } x &lt; 0.
\end{cases}
$$</math-renderer></p>

<p dir="auto">We implement a differentiable version of the Heaviside function, where the derivative is the derivative of the sigmoid. This function has a "steepness" parameter that controls the transition smoothness. The function is <code>heaviside(x, k)</code>.</p>
<p dir="auto">We implement a differentiable version of the sign function, where the derivative is the derivative of tanh. This function has a "steepness" parameter that controls the transition smoothness. The function is <code>sign_diff(x, k)</code> to avoid overriding the Base <code>sign</code> function.</p>
<ul dir="auto">
<li><code>x</code>: The input to the function.</li>
<li><code>k</code>: The steepness parameter. Higher values of <code>k</code> make the sigmoid steeper and, hence, closer to the discontinuous function. The default is 1 in all cases.</li>
</ul>
