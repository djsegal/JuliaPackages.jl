<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><code>@amb(state, options...)</code></h3><a id="user-content-ambstate-options" class="anchor" aria-label="Permalink: @amb(state, options...)" href="#ambstate-options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A nondeterminstic choice from the options.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x = @amb state 1 2 3"><pre>x <span class="pl-k">=</span> <span class="pl-c1">@amb</span> state <span class="pl-c1">1</span> <span class="pl-c1">2</span> <span class="pl-c1">3</span></pre></div>
<p dir="auto"><code>x</code> is an Integer, specifically either 1, 2, or 3. Which one depends on what the program does next! <code>require(state, isodd(x))</code> will make it be either <code>1</code>, or <code>3</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><code>require(state, condition)</code></h3><a id="user-content-requirestate-condition" class="anchor" aria-label="Permalink: require(state, condition)" href="#requirestate-condition"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Require a certain condition to be true, if not, backtrack and try the next available set of assignments to <code>@amb</code> variables seen so far.</p>
<p dir="auto"><code>require</code> is implemented as: <code>require(state, cond) = !cond ? @amb(state) : nothing</code></p>
<p dir="auto"><strong>Example: Pythagorean triples</strong></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; function int_between(state, lo, hi)
           require(state, lo &lt;= hi)
           @amb state lo int_between(state, lo+1, hi)
       end

julia&gt; function a_pythagoras_triple(state, lo, hi)
           i = int_between(state, lo, hi)
           j = int_between(state, i, hi)
           k = int_between(state, j, hi)

           require(state, i*i + j*j == k*k)
           return (i, j, k)
       end

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto"><code>ambrun(f)</code></h3><a id="user-content-ambrunf" class="anchor" aria-label="Permalink: ambrun(f)" href="#ambrunf"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Runs a zero-argument function <code>f</code> in the amb-world, where the language knows that it needs to search for a set of assignments to <code>@amb</code> variables that runs the code till the end without rejection. If no such path is found, ambrun returns nothing.</p>
<p dir="auto">In other words, <code>ambrun</code> computes one admissible return value of the function passed to it.</p>
