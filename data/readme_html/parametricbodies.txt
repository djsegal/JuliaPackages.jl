<p dir="auto">A <code>ParametricBody</code> is a subtype of  <code>WaterLily.AbstractBody</code>, defining the <code>measure(body,x,t)</code> function needed to run WaterLily simulations.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Parametric Bodies</h3><a id="user-content-parametric-bodies" class="anchor" aria-label="Permalink: Parametric Bodies" href="#parametric-bodies"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <code>ParametricBody</code> is defined using a parametric function repsentation of that shape. For example, a circle can be defined as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using StaticArrays
curve(θ,t) = SA[cos(θ),sin(θ)]
locate(x::SVector{2},t) = atan(x[2],x[1])
body = ParametricBody(curve,locate)"><pre><span class="pl-k">using</span> StaticArrays
<span class="pl-en">curve</span>(θ,t) <span class="pl-k">=</span> SA[<span class="pl-c1">cos</span>(θ),<span class="pl-c1">sin</span>(θ)]
<span class="pl-en">locate</span>(x<span class="pl-k">::</span><span class="pl-c1">SVector{2}</span>,t) <span class="pl-k">=</span> <span class="pl-c1">atan</span>(x[<span class="pl-c1">2</span>],x[<span class="pl-c1">1</span>])
body <span class="pl-k">=</span> <span class="pl-c1">ParametricBody</span>(curve,locate)</pre></div>
<p dir="auto">The parametric <code>curve</code> function defines the boundary of the circle, and the <code>locate</code> function is a general inverse of <code>curve</code>: locating the value of the parameter <code>θ</code> which is closest to point <code>x</code> at time <code>t</code>. The <code>body</code> can now be used inside a 2D WaterLily simulation.</p>
<p dir="auto">A few important features to note:</p>
<p dir="auto"><strong>First</strong>, the parametric curve should <em>always return an <code>SVector</code>!</em> Returning an array will allocate and won't run on GPUs.</p>
<p dir="auto"><strong>Second</strong>, a 2D curve can either define the <em>boundary</em> of a closed body, or it can define a space-curve body with some finite thickness. The default properties are <code>boundary=true</code> and <code>thk=0</code>, but you can change this by supplying additional arguments. For example, we could model a thin wing section defined by a circular-arc as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="curve(θ,t) = SA[cos(θ),sin(θ)]
locate(x::SVector{2},t) = clamp(atan(x[2],x[1]),π/3,2π/3)
arc = ParametricBody(curve,locate,thk=0.1,boundary=false)"><pre><span class="pl-en">curve</span>(θ,t) <span class="pl-k">=</span> SA[<span class="pl-c1">cos</span>(θ),<span class="pl-c1">sin</span>(θ)]
<span class="pl-en">locate</span>(x<span class="pl-k">::</span><span class="pl-c1">SVector{2}</span>,t) <span class="pl-k">=</span> <span class="pl-c1">clamp</span>(<span class="pl-c1">atan</span>(x[<span class="pl-c1">2</span>],x[<span class="pl-c1">1</span>]),π<span class="pl-k">/</span><span class="pl-c1">3</span>,<span class="pl-c1">2</span>π<span class="pl-k">/</span><span class="pl-c1">3</span>)
arc <span class="pl-k">=</span> <span class="pl-c1">ParametricBody</span>(curve,locate,thk<span class="pl-k">=</span><span class="pl-c1">0.1</span>,boundary<span class="pl-k">=</span><span class="pl-c1">false</span>)</pre></div>
<p dir="auto">A 3D curve can't define the boundary of a 3D volume (that would require a surface, not a curve). We will discuss ways of creating 3D bodies below.</p>
<p dir="auto"><strong>Third</strong>, the functions <code>curve</code> and especially <code>locate</code> can be tricky to define for general curves. The next few sections discuss methods to simplify and automate the construction of these functions.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Hashed Locator &amp; Body</h3><a id="user-content-hashed-locator--body" class="anchor" aria-label="Permalink: Hashed Locator &amp; Body" href="#hashed-locator--body"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <code>HashedLocator</code> struct has been defined to automate locating the closest point on a supplied 2D curve.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="curve(θ,t) = SA[cos(θ),sin(θ)]

<p dir="auto">or the convience constructor</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="body = HashedBody(curve,(0.,2π),step=0.25)"><pre>body <span class="pl-k">=</span> <span class="pl-c1">HashedBody</span>(curve,(<span class="pl-c1">0.</span>,<span class="pl-c1">2</span>π),step<span class="pl-k">=</span><span class="pl-c1">0.25</span>)</pre></div>
<p dir="auto">This locator function samples the curve over the supplied parametric limits and uses a Newton root finding method to locate the parameter value. A 2D array of parameter data (a hash table) is used to supply a good initial guess to the Newton solver.</p>
<p dir="auto">Note that a <code>HashedLocator</code> knows nothing about the details of the <code>curve</code>, and you must test it's accuracy before using it in a WaterLily simulation. Also, the hash must be updated if the curve is time-varying, and must be stored in a GPU array when computing on the GPU. See the example folder. The <code>HashedLocator</code> is currently only available for 2D curves, although it can be used with mapping and <code>PlanarBodies</code>, to define bodies for 3D simulations, see below.</p>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pnts = SA[0. 3. -1. -4  -4.

<p dir="auto">An efficient and accurate <code>NurbsLocator</code> is created automatically for <code>NurbsCurve</code>s. However, it is not as fast as a <code>HashedLocator</code>. If speed is a limiting factor, you can always use <code>body = HashedBody(nurbs,(0,1))</code> to create a fast locator, although it may not be as accurate.</p>

<p dir="auto">Like <code>WaterLily.AutoBodies</code>, the utility of <code>ParametricBodies</code> is greatly increased through an optional <code>map</code> function.</p>
<p dir="auto">Primarily, mapping can be used to move, rotate and scale the body in the simulation. For example, let's place the arc-wing above in a simulation:</p>

<p dir="auto">See the WaterLily repo and the video above for more discussion of this primary use of the map function.</p>
<p dir="auto">A secondary application of the mapping function for <code>ParametricBodies</code> is to map from a 3D x-space to a 2D ξ-space, effectively extruding a 2D parametric curve into a 3D surface. For example, we can make a cylinder or sphere starting from a 2D NURBS circle using</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Make a cylinder
map(x::SVector{3},t) = SA[x[2],x[3]] # extrude along x[1]-axis
cylinder = ParametricBody(circle;map,scale=1f0)

# Make a sphere
map(x::SVector{3},t) = SA[x[1],√(x[2]^2+x[3]^2)] # revolve around x[1]-axis
sphere = ParametricBody(circle;map,scale=1f0)"><pre><span class="pl-c"><span class="pl-c">#</span> Make a cylinder</span>
<span class="pl-en">map</span>(x<span class="pl-k">::</span><span class="pl-c1">SVector{3}</span>,t) <span class="pl-k">=</span> SA[x[<span class="pl-c1">2</span>],x[<span class="pl-c1">3</span>]] <span class="pl-c"><span class="pl-c">#</span> extrude along x[1]-axis</span>
cylinder <span class="pl-k">=</span> <span class="pl-c1">ParametricBody</span>(circle;map,scale<span class="pl-k">=</span><span class="pl-c1">1f0</span>)

<span class="pl-c"><span class="pl-c">#</span> Make a sphere</span>
<span class="pl-en">map</span>(x<span class="pl-k">::</span><span class="pl-c1">SVector{3}</span>,t) <span class="pl-k">=</span> SA[x[<span class="pl-c1">1</span>],<span class="pl-k">√</span>(x[<span class="pl-c1">2</span>]<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">+</span>x[<span class="pl-c1">3</span>]<span class="pl-k">^</span><span class="pl-c1">2</span>)] <span class="pl-c"><span class="pl-c">#</span> revolve around x[1]-axis</span>
sphere <span class="pl-k">=</span> <span class="pl-c1">ParametricBody</span>(circle;map,scale<span class="pl-k">=</span><span class="pl-c1">1f0</span>)</pre></div>
<p dir="auto">and if we started from, say, a NACA profile, the same technique could make a uniform 3D wing or a 3D air-ship hull. Note that the <code>scale</code> argument must be explicitly supplied since the determinant of this mixed dimensional <code>map</code> isn't defined.</p>
<p dir="auto">A mapping is not sufficient to make 3D planar geometries, so a simple wrapper struct <code>PlanarBody</code> is defined for this purpose. For example, a circular disk can be created using</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="disk = PlanarBody(circle;map=(x,t)-&gt;SA[2x[2],2x[3],2x[1]])"><pre>disk <span class="pl-k">=</span> <span class="pl-c1">PlanarBody</span>(circle;map<span class="pl-k">=</span>(x,t)<span class="pl-k">-&gt;</span>SA[<span class="pl-c1">2</span>x[<span class="pl-c1">2</span>],<span class="pl-c1">2</span>x[<span class="pl-c1">3</span>],<span class="pl-c1">2</span>x[<span class="pl-c1">1</span>]])</pre></div>
<p dir="auto">where the mapping has been used to scale and rotate the disk as well.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Dynamic Bodies</h3><a id="user-content-dynamic-bodies" class="anchor" aria-label="Permalink: Dynamic Bodies" href="#dynamic-bodies"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>ParametricBodies</code> have two ways to be dynamic:</p>
<ol dir="auto">
<li>A time-varying parametric curve</li>
<li>A time-varying map</li>
</ol>
<p dir="auto">and these methods can be used together, as demonstrated in the example folder. There are many examples of time varying mappings in the WaterLily repo and the video above, so we'll focus on time-varying curves here.</p>
<p dir="auto">If <code>curve</code> depends explicitly on <code>t</code>, this will automatically be reflected in the position and velocity of the body in a simulation. For example, a spinning circle is easily acheived using</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="curve(θ,t) = SA[cos(θ+t),sin(θ+t)]
locate(x::SVector{2},t) = atan(x[2],x[1])-t
spinning_body = ParametricBody(curve,locate)"><pre><span class="pl-en">curve</span>(θ,t) <span class="pl-k">=</span> SA[<span class="pl-c1">cos</span>(θ<span class="pl-k">+</span>t),<span class="pl-c1">sin</span>(θ<span class="pl-k">+</span>t)]
<span class="pl-en">locate</span>(x<span class="pl-k">::</span><span class="pl-c1">SVector{2}</span>,t) <span class="pl-k">=</span> <span class="pl-c1">atan</span>(x[<span class="pl-c1">2</span>],x[<span class="pl-c1">1</span>])<span class="pl-k">-</span>t
spinning_body <span class="pl-k">=</span> <span class="pl-c1">ParametricBody</span>(curve,locate)</pre></div>
<p dir="auto">If you are using a <code>HashedLocator</code> for a dynamic curve you will need to call <code>update!(body,t)</code> frequently (probably every time step of the simulation) so that the initial guess of the locator reflects the correct position of the body.</p>
<p dir="auto">We supply a special function <code>DynamicNurbsBody</code> for dynamics NURBS which defines a second spline for the velocity. This function also requires calling <code>update!(body,...)</code>, but in this case, the control points for both the position and velocity are updated. Here's an example</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="body = DynamicNurbsBody(circle)
dt,dx = 0.1,0.1                  # time step and uniform displacement
new_pnts = circle.pnts .+ dx     # define updated control points
body = update!(body,new_pnts,Δt) # new body will have unit velocity (dx/dt=1)"><pre>body <span class="pl-k">=</span> <span class="pl-c1">DynamicNurbsBody</span>(circle)
dt,dx <span class="pl-k">=</span> <span class="pl-c1">0.1</span>,<span class="pl-c1">0.1</span>                  <span class="pl-c"><span class="pl-c">#</span> time step and uniform displacement</span>
new_pnts <span class="pl-k">=</span> circle<span class="pl-k">.</span>pnts <span class="pl-k">.+</span> dx     <span class="pl-c"><span class="pl-c">#</span> define updated control points</span>
body <span class="pl-k">=</span> <span class="pl-c1">update!</span>(body,new_pnts,Δt) <span class="pl-c"><span class="pl-c">#</span> new body will have unit velocity (dx/dt=1)</span></pre></div>
