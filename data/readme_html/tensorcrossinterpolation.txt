<p dir="auto">The <a href="https://github.com/tensor4all/TensorCrossInterpolation.jl">TensorCrossInterpolation module</a> implements the <em>tensor cross interpolation</em> algorithm for efficient interpolation of multi-index tensors and multivariate functions.</p>
<p dir="auto">This algorithm is used in the <em>quantics tensor cross interpolation</em> (QTCI) method for exponentially efficient interpolation of functions with scale separation. QTCI is implemented in the <a href="https://github.com/tensor4all/quanticstci.jl">QuanticsTCI.jl</a> module.</p>

<p dir="auto"><em>This section only contains the bare minimum to get you started. An example with more explanation can be found in the <a href="https://tensor4all.github.io/TensorCrossInterpolation.jl/dev" rel="nofollow">user manual</a>.</em></p>
<p dir="auto">Given a multivariate function <code>f</code>, the function <code>crossinterpolate2</code> will generate a tensor cross interpolation for <code>f</code>. For example, to interpolate the 8d lorentzian <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b01adb374f5f8a774a6fa42ec0570c0d">$f(\mathbf v) = 1/(1 + \mathbf v^2)$</math-renderer> on an 8-dimensional lattice of integers, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="b01adb374f5f8a774a6fa42ec0570c0d">$\mathbf{v} \in {1, 2, ..., 10}^8$</math-renderer>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import TensorCrossInterpolation as TCI
f(v) = 1/(1 + v' * v)
# There are 8 tensor indices, each with values 1...10
localdims = fill(10, 8)
tolerance = 1e-8
tci, ranks, errors = TCI.crossinterpolate2(Float64, f, localdims; tolerance=tolerance)"><pre><span class="pl-k">import</span> TensorCrossInterpolation as TCI
<span class="pl-en">f</span>(v) <span class="pl-k">=</span> <span class="pl-c1">1</span><span class="pl-k">/</span>(<span class="pl-c1">1</span> <span class="pl-k">+</span> v<span class="pl-k">'</span> <span class="pl-k">*</span> v)
<span class="pl-c"><span class="pl-c">#</span> There are 8 tensor indices, each with values 1...10</span>
localdims <span class="pl-k">=</span> <span class="pl-c1">fill</span>(<span class="pl-c1">10</span>, <span class="pl-c1">8</span>)
tolerance <span class="pl-k">=</span> <span class="pl-c1">1e-8</span>
tci, ranks, errors <span class="pl-k">=</span> TCI<span class="pl-k">.</span><span class="pl-c1">crossinterpolate2</span>(Float64, f, localdims; tolerance<span class="pl-k">=</span>tolerance)</pre></div>
<p dir="auto">Note:</p>
<ul dir="auto">
<li><code>f</code> is defined as a function that takes a single <code>Vector</code> of integers.</li>
<li>The return type of <code>f</code> (<code>Float64</code> in this case) must be stated explicitly in the call to <code>crossinterpolate2</code>.</li>
</ul>
<p dir="auto">The resulting <code>TensorCI2</code> object can be further manipulated, see <a href="https://tensor4all.github.io/TensorCrossInterpolation.jl/dev" rel="nofollow">user manual</a>.
To evaluate the TCI interpolation, simply call your <code>TensorCI1</code> object like you would call the original function:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="originalvalue = f([1, 2, 3, 4, 5, 6, 7, 8])
interpolatedvalue = tci([1, 2, 3, 4, 5, 6, 7, 8])"><pre>originalvalue <span class="pl-k">=</span> <span class="pl-c1">f</span>([<span class="pl-c1">1</span>, <span class="pl-c1">2</span>, <span class="pl-c1">3</span>, <span class="pl-c1">4</span>, <span class="pl-c1">5</span>, <span class="pl-c1">6</span>, <span class="pl-c1">7</span>, <span class="pl-c1">8</span>])
interpolatedvalue <span class="pl-k">=</span> <span class="pl-c1">tci</span>([<span class="pl-c1">1</span>, <span class="pl-c1">2</span>, <span class="pl-c1">3</span>, <span class="pl-c1">4</span>, <span class="pl-c1">5</span>, <span class="pl-c1">6</span>, <span class="pl-c1">7</span>, <span class="pl-c1">8</span>])</pre></div>
<p dir="auto">The sum of all function values on the lattice can be obtained very efficiently from a tensor train:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="sumvalue = sum(tci)"><pre>sumvalue <span class="pl-k">=</span> <span class="pl-c1">sum</span>(tci)</pre></div>
