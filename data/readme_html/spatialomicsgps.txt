<p dir="auto">A crude (for now) implementation of various Gaussian process models for <a href="https://en.wikipedia.org/wiki/Spatial_transcriptomics" rel="nofollow">spatial transcriptomics</a> data. Currently planned to contain implementations of:</p>
<p dir="auto"><strong>SpatialDE</strong> <a href="https://doi.org/10.1038%2Fnmeth.4636" rel="nofollow">[Svensson et al.]</a>:</p>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Variance parameter estimation in SpatialDE model</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Statistical significance of spatial vs. non-spatial covariance</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Expression histology</li>
</ul>
<p dir="auto"><strong>Spatial Variance Component Analysis (SVCA)</strong> <a href="https://doi.org/10.1016/j.celrep.2019.08.077" rel="nofollow">[Arnol et al.]</a>:</p>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Variance parameter estimation in SVCE model</li>
</ul>
<p dir="auto">The package is developed in parallel with another package, <a href="https://github.com/tmichoel/FaSTLMMlight.jl">FaSTLMMlight</a> that provides the variance parameter estimation methods used here.</p>
