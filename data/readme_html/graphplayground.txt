<p dir="auto">Directly play and manipulate your graphs in Julia! This is hugely inspired by the
<a href="https://d3js.org/d3-force" rel="nofollow">d3-force</a> package. This includes a port of this
package to Julia to handle the force directed layout.</p>

<p dir="auto">This does a few things differently. The defaults are setup for graphs of around 100 nodes.</p>
<ul dir="auto">
<li>The code explicitly creates a force simulation. This is what controls how the graph layout works.</li>
<li>The force simulation is setup to have: link attractive forces, node/charge repulsion forces,
and centering forces.</li>
<li>The LinkForce gives an edge-attraction forces have an ideal distance of 0.5,
the iterations parameter controls how many times we iterate over edges updating velocity vectors.
For grids, we want this to be large, but the default value of 1 is okay unless you have a ton of structure.</li>
<li>The ManyBodyForce handles the node repulsion. strength=-1 is good if you want nodes close by, such as for
a large graph.</li>
<li>The center force / Position force seeks to push all nodes to point (300, 300), this is roughly in the
middle of the display area.</li>
<li>Because the graph is so big, we adjust the default sizes to 2 points for a node and 1 point for an edge.</li>
<li>Finally, we want to keep the simulation "hot" so it doesn't decay too quickly. (Grids take a long time
to settle, so we setup the alpha_target to be 0.5.)</li>
</ul>
<p dir="auto">See the excellent documentation for d3-force for more information on the force simulation and some
of the parameters.</p>
<ul dir="auto">
<li>[<a href="https://d3js.org/d3-force/link" rel="nofollow">https://d3js.org/d3-force/link</a>]</li>
<li>[<a href="https://d3js.org/d3-force/many-body" rel="nofollow">https://d3js.org/d3-force/many-body</a>]</li>
<li>[<a href="https://d3js.org/d3-force/position" rel="nofollow">https://d3js.org/d3-force/position</a>]</li>
</ul>

<p dir="auto">Right now, GraphPlayground is setup with <code>GLMakie.jl</code> to create a window that continuously renders.
This has an odd side effect that it makes printing to the console slow. So you will
see this. Just close the GraphPlayground window and it'll go away.</p>

<ul dir="auto">
<li><code>GLMakie</code>: This is required to implement a window with a callback on each frame.</li>
<li><code>GraphMakie</code>: This is required for the graph plotting code</li>
<li><code>NearestNeighbors</code>: This is required for the balltree to implement the distant cell
approximation in the ManyBodyForce and CollisionForce</li>
<li><code>Graphs</code>: This is what we use to interact with GraphMakie</li>
<li><code>Colors</code>: I guess we need this to specify plot colors</li>
<li><code>Makie</code>: Just general Makie code as well.</li>
</ul>
