<p dir="auto"><em>TwinCopulas</em> is a Julia package for probability distributions and associated functions, focusing on the implementation of copulas. This package includes:</p>
<ul dir="auto">
<li>Probability density/mass functions (pdf).</li>
<li>Sampling from a population or from a distribution.</li>
</ul>
