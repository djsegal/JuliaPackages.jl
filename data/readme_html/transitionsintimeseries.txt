<p dir="auto">TransitionsInTimeseries.jl is a free and open-source software to easily analyse transitions within timeseries in a reproducible, performant, extensible and reliable way. In contrast to other existing software with similar target application, TransitionsInTimeseries.jl defines a generic interface for how to find transitions and how to test for significance. Within this interface, it is easy to expand the software in three orthogonal ways:</p>
<ol dir="auto">
<li>Provide the analysis pipelines with new indicators, which can be either self-written or imported from other packages. In particular, the latter offers thousands of metrics that can indicate transitions right out of the box.</li>
<li>Add new analysis pipelines for finding transitions.</li>
<li>Add new ways for significance testing.</li>
</ol>
<p dir="auto">TransitionsInTimeseries is a registered Julia package and can be installed by running:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] add TransitionsInTimeseries"><pre class="notranslate"><code>] add TransitionsInTimeseries
</code></pre></div>
<p dir="auto">All further information is provided in the documentation, which you can either find <a href="https://juliadynamics.github.io/TransitionsInTimeseries.jl/dev/" rel="nofollow">online</a> or build locally by running the <code>docs/make.jl</code> file.</p>
<p dir="auto"><em>Alternative names for this package could have been: Early Warning Signals / Resilience Indicators / Regime-Shift Identifiers / Change-Point Detectors, or however else you want to call them!</em></p>
