<p dir="auto">FMM2D.jl is a Julia interface for computing N-body interactions using the <a href="https://github.com/flatironinstitute/fmm2d/">Flatiron Institute's FMM2D library</a>.</p>
<p dir="auto">Currently, the wrapper only wraps the Helmholtz and Laplace functionalities.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Helmholtz FMM</h2><a id="user-content-helmholtz-fmm" class="anchor" aria-label="Permalink: Helmholtz FMM" href="#helmholtz-fmm"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$c_s \in \mathbb{C},\ s = 1,\dots,N$</math-renderer> denote a collection of charge strengths, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$v_s \in \mathbb{C},\ s = 1,\dots,N$</math-renderer> denote a collection of dipole strengths, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$d_s\in\mathbb{R}^2,\ s = 1,\dots,N$</math-renderer> denote the corresponding dipole orientation vectors. Furthermore, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$k \in \mathbb{C}$</math-renderer> denotes the wave number. The Helmholtz potential <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$u$</math-renderer> caused by the presence of a collection of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$M$</math-renderer> sources (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$x_s$</math-renderer>) at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$N$</math-renderer> target positions (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$x_t$</math-renderer>) is computed as</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$$
u\left(x_t\right) = \sum_{s=1}^{M} c_sH_0^{(1)}(k|x_t - x_s|) - v_sd_s\cdot\nabla H_0^{(1)}(k|x_t - x_s|), \quad t = 1,\dots, N
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$H_0^{(1)}$</math-renderer> is the Hankel function of the first kind of order 0. When <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$x = x_j$</math-renderer> the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$j$</math-renderer> th term is dropped from the sum. Performing this summation would scale as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$O(NM)$</math-renderer>, but using the Flatiron Insitutes Fast Multipole Library a linear scaling of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$O((N + M)\text{log}(\varepsilon^{-1}))$</math-renderer> can be achieved with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$\varepsilon$</math-renderer> being the desired relative precision. Note that the library also includes the option for computing the gradient and Hessian of the potential.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Laplace</h2><a id="user-content-laplace" class="anchor" aria-label="Permalink: Laplace" href="#laplace"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The Laplace problem in 2D have the following form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$$
u(x) = \sum_{j=1}^{N} \left[c_{j} \text{log}\left(|x-x_{j}|\right) - d_{j}v_{j} \cdot \nabla( \text{log}(|x-x_{j}|) )\right],
$$</math-renderer></p>
<p dir="auto">In the case of complex charges and dipole strengths (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$c_j, v_j \in \mathbb{C}^n$</math-renderer>) the function call <code>lfmm2d</code> has to be used. In the case of real charges and dipole strengths (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="0583b105a8c03ab588b5e27b1578608f">$c_j, v_j \in \mathbb{R}^n$</math-renderer>) the function call <code>rfmm2d</code> has to be used.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Stokes</h2><a id="user-content-stokes" class="anchor" aria-label="Permalink: Stokes" href="#stokes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
