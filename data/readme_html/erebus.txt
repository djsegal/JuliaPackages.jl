<p dir="auto"><code>Erebus.jl</code> is a Julia package for simulating the geophysical evolution of planetesimals, focusing on two-phase fluid flow. It takes into account factors such as composition, mineralogical and hydrodynamic properties, temperature curves, and reaction rates<sup><a href="#user-content-fn-1-9209a080819dd43a6f4c0ae383240178" id="user-content-fnref-1-9209a080819dd43a6f4c0ae383240178" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup><sup><a href="#user-content-fn-2-9209a080819dd43a6f4c0ae383240178" id="user-content-fnref-2-9209a080819dd43a6f4c0ae383240178" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup>.</p>

<p dir="auto">Initiate a simulation run from the terminal as follows:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia -O3 --tauto launch.jl /PATH/TO/OUTPUT/"><pre class="notranslate"><code>julia -O3 --tauto launch.jl /PATH/TO/OUTPUT/
</code></pre></div>
<p dir="auto">The <code>-O3</code> and <code>--tauto</code> flags are used for optimization and automatic threading respectively. All intermediate simulation data is written into HDF-5 compatible <code>.jld2</code> files in the output directory for later analysis and plotting. The log file <code>Erebus_run.log</code> in the output directory contains relevant simulation progress and parameters.</p>

<p dir="auto">Use the helper script <code>generate_plots.jl</code> to generate plots by typing:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia generate_plots.jl /PATH/TO/OUTPUT/"><pre class="notranslate"><code>julia generate_plots.jl /PATH/TO/OUTPUT/
</code></pre></div>
<p dir="auto">The resulting <code>.pdf</code> plot files are stored in the same directory as the simulation output. Generate animations using the helper script <code>generate_animations.jl</code> with the command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia generate_animations.jl /PATH/TO/OUTPUT/"><pre class="notranslate"><code>julia generate_animations.jl /PATH/TO/OUTPUT/
</code></pre></div>
<p dir="auto">The resulting <code>.mp4</code> animation files are stored in the same directory as the simulation output.</p>
<p dir="auto">Note: These helper scripts are independent of the <code>Erebus.jl</code> package and are provided as-is. They have their own dependencies which need to be fulfilled manually based on your Julia installation.</p>
