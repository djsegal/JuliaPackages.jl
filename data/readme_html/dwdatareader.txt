<p dir="auto">Only MSYS2 MinGW toolchain is supported. Please provide PRs for other toolchains (e.g. MSVC).</p>
<p dir="auto">Run this command to install the toolchain (on MSYS2 MINGW64 shell):</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pacman -S --needed base-devel mingw-w64-x86_64-toolchain"><pre>pacman -S --needed base-devel mingw-w64-x86_64-toolchain</pre></div>
<p dir="auto">Make sure these MSYS2 paths are in the $PATH environment variable for the julia process using DWDataReader.jl:</p>
<ul dir="auto">
<li><code>C:\Users\user\opt\msys64\usr\bin</code></li>
<li><code>C:\Users\user\opt\msys64\mingw64\bin</code></li>
</ul>
