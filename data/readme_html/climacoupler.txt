<p dir="auto">Before starting Julia, ensure your environment is properly set up. This includes loading the correct Julia version (specified in the <code>Project.toml</code> file), modules and setting the correct environment variables.</p>
<p dir="auto">Typically (e.g., when running on your local machine) the installation of the required module libraries and specification of environment variables should be automatically handled by the Julia package manager upon running <code>]instantiate</code> and <code>]build</code> in the Julia REPL,
which reads the <code>Project.toml</code> file. Each experiment has its own <code>Project.toml</code> file and <code>Manifest.toml</code> file, which are used to specify the exact environment for the experiment. Once instantiated, the experiment run scripts should be able to run without any further environment setup (e.g., with <code>julia --project --threads 8 experiments/&lt;your_experiment&gt;.jl</code>).</p>
<p dir="auto">For computationally intensive jobs, it is recommended to run the jobs on a cluster using MPI and/or GPU triggered by a SLURM job script.
In this case, we need to load specific MPI and GPU compatible modules and set the correct environment variables. For an example of a SLURM job script, see <code>test/mpi_tests/local_checks.sh</code>.</p>
