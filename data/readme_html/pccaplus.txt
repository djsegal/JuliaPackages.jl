<p dir="auto">A <a href="https://en.wikipedia.org/wiki/KISS_principle" rel="nofollow">KISS</a> style implementation of PCCA+ (Robust Perron Cluster Analysis) [1,2] with support for non-reversible systems [3].
For a similar python implementation see also the <a href="https://github.com/zib-cmd/cmdtools/">cmdtools</a> package.</p>
