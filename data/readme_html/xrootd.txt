<p dir="auto">Julia bindings for the <a href="https://xrootd.slac.stanford.edu" rel="nofollow">XRootD</a> high performance, scalable, and fault tolerant access to data repositories. It facilitates the interface with the XRootD client, by writing Julia code instead of having to write C++.
This package is developed using the <a href="https://github.com/JuliaInterop/CxxWrap.jl">CxxWrap.jl</a> package to wrap C++ types and functions to Julia. Wrapper C++ code is generated with the help of <a href="https://github.com/grasph/wrapit">WrapIt</a> tool that uses of the clang library.</p>
<p dir="auto">The Julia interface has been inspired by the functionality provided by <a href="https://xrootd.slac.stanford.edu/doc/doxygen/5.6.4/python/" rel="nofollow">pyxrootd</a>, which implements a set of simple but pythonic bindings for XRootD. In the case of Julia, we have used the same function names if there was an equivalent in the <code>Base</code> module.</p>

<p dir="auto">The client module <code>XRootD.XrdCl</code> provides the two main types to interact with the XRootD server: the <code>FileSystem</code> to do operations on the file system and <code>File</code> to read and write files. Here is an example session.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using XRootD.XrdCl

#---FileSystem interface---------------------------------------
fs = FileSystem(&quot;root://localhost:1094&quot;)  # create a FileSystem

st, _ = ping(fs)                          # is server alive?
isError(st) &amp;&amp; error(st)

st, statinfo = stat(fs, &quot;/tmp&quot;)           # get statinfo 

if isOK(st) &amp;&amp; isdir(statinfo)              
    st, entries = readdir(fs, &quot;/tmp&quot;)     # ls the directory
    isError(st) &amp;&amp; error(st)
    for f in entries
        println(f)
    end
end

#---File interface--------------------------------------------
f = File()

# create file and write
st, _ = open(f, &quot;root://localhost:1094//tmp/testfile.txt&quot;, OpenFlags.New|OpenFlags.Write)
isError(st) &amp;&amp; error(st)
write(f, &quot;Hello\nWorld\nFolks!&quot;)
close(f)

# re-open file and read
st, _ = open(f, &quot;root://localhost:1094//tmp/testfile.txt&quot;, OpenFlags.Read)
isError(st) &amp;&amp; error(st)
st, lines = readlines(f)
isError(st) &amp;&amp; error(st)
for line in lines
  print(line)
end
close(f)

# delete file (using FileSystem)
st, _ = rm(fs, &quot;/tmp/testfile.txt&quot;)"><pre><span class="pl-k">using</span> XRootD<span class="pl-k">.</span>XrdCl
