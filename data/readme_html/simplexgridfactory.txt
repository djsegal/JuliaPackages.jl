<p dir="auto">Provides <code>SimplexGridBuilder</code>, a convenience  interface to the triangle (via  <a href="https://github.com/JuliaGeometry/Triangulate.jl">Triangulate.jl</a>) and
TetGen (via <a href="https://github.com/JuliaGeometry/TetGen.jl">TetGen.jl</a>) mesh generators.  Code using it  needs to pass the <code>Triangulate</code> resp.
the   <code>TetGen</code>   module   as   parameter  to   the   constructor of <code>SimplexGridBuilder</code>  and thus  needs to
adhere to  their respective license conditions. This package itself is MIT licensed.</p>
