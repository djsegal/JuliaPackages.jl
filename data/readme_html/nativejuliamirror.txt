<p dir="auto">The "native Julia Mirror (NAJM)" can make a mirror repository, including an offline version of Julia packages and registry. The result can be deployed to a network or can be used on a local machine. NAJM works with the Pkg3 Julia package manage and has been tested on Linux and Windows OS.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">some features are:</h3><a id="user-content-some-features-are" class="anchor" aria-label="Permalink: some features are:" href="#some-features-are"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">can handle multiple official or unofficial registries at the same time</p>
</li>
<li>
<p dir="auto">can update and maintain the cloned packages</p>
</li>
<li>
<p dir="auto">can create new registries for users who have access to the packages repo by local paths or through a network</p>
</li>
<li>
<p dir="auto">can make partial registries</p>
</li>
<li>
<p dir="auto">can exclude some packages from the new registry</p>
</li>
<li>
<p dir="auto">can preserve the original link to the package on the GitHub servers in the new registry</p>
</li>
</ul>

<p dir="auto">When the <code>julia make.jl</code> command finished making the mirror depository, regarding your choice of the installation (Installation on the network or local), You must have one or two new registry directories. These new registries will be located in the <code>prefix/registry</code> address. You may find one of the <code>local_access</code>, <code>public_access</code>, or both of those directories in the <code>registry</code> directory.</p>
<p dir="auto">If you want to use the mirror repository using local addresses in your local machine, use the <code>local_access</code> registry. If you're going to use the mirror repository through a network, you should use the <code>public_access</code>registry. This registry must be accessible through the network, or the users will face errors.</p>
<p dir="auto">Open a Julia session and use this code:</p>

<p dir="auto">There is a configuration file in the root directory of this script. This file contains all the configuration parameters for this program, as well as some necessary input values that you must provide for the program.</p>
<p dir="auto">The configuration file has two parts one is marked by <code>[include]</code>, and the other is marked by <code>[options]</code>.</p>

<p dir="auto">The files specified in the include section will be downloaded by the Julia language <code>download</code> command. As it has mentioned in the Julia documentation for the <code>download</code> command, " this function relies on the availability of external tools such as <code>curl</code>, <code>wget</code> or <code>fetch</code> to download". So if your Julia download command works with the local addresses (like in the Windows 10), you can use the local addresses in this section.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Some Considerations</h2><a id="user-content-some-considerations" class="anchor" aria-label="Permalink: Some Considerations" href="#some-considerations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Some packages may ask for credentials. Usually, the URL of these packages is broken; thus, the git clone command thinks that these packages are private and password protected. NAJM can't distinguish between those; Therefore, it will ask for credentials too. To bypass the password request, I recommend using the <code>yes</code> program.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    yes | julia make.jl"><pre>    yes <span class="pl-k">|</span> julia make.jl</pre></div>
</li>
<li>
<p dir="auto">Making or Updating the package repository takes time, so you may consider using tools such as <code>nohup</code> or <code>screen</code>.</p>
</li>
</ul>

<p dir="auto">In order to use mirrored Julia packages on a network, you need to set up a Git server. You can find the available protocols in the <a href="https://git-scm.com/book/en/v2/Git-on-the-Server-The-Protocols" rel="nofollow">Git documentation</a>.</p>
<p dir="auto">I propose using the <code>smart HTTP</code> protocol since the <code>dumb HTTP</code> protocol requires the packages to be <code>bare packages</code>, and my tests showed that Julia could not interact with the bare packages on the server (maybe I'm wrong).</p>
<p dir="auto">Here is a simple configuration for the apache2 webserver (<a href="https://linuxhint.com/git_server_http_ubuntu/" rel="nofollow">Here</a>).
A PDF file of the above tutorial can be found <a href="https://github.com/alirezaghavaminia/nativeJuliaMirror.jl/blob/master/docs/thirdParty/WORKS%20Configure%20Git%20Server%20with%20HTTP%20on%20Ubuntu%20%E2%80%93%20Linux%20Hint.pdf">here</a>.
Please consider the security measures for your server. For example, some of the security tips can be found in <a href="https://github.com/alirezaghavaminia/nativeJuliaMirror.jl/blob/master/docs/thirdParty/Howto%20set%20up%20Git%20over%20Https%20with%20Apache%20on%20Ubuntu%20Server%2014.04%20%E2%80%93%20Creang.pdf">this tutorial</a>.</p>
