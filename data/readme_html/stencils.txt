<p dir="auto">Stencils.jl streamlines working with stencils and neighborhoods -
cellular automata, convolutions and filters, for neighborhoods of any
(smallish) size and shape.</p>
<p dir="auto">Stencils.jl builds on StaticArrays.jl and KernelAbstractions.jl to provide high
performance tools on CPUs and most GPUs, but keep a simple code base.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is a <code>Stencil</code> in Stencils.jl?</h2><a id="user-content-what-is-a-stencil-in-stencilsjl" class="anchor" aria-label="Permalink: What is a Stencil in Stencils.jl?" href="#what-is-a-stencil-in-stencilsjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <code>Stencil</code> is a StaticArrays.jl <code>StaticVector</code> of values cut from an array in the
specified shape, initially it is filled with <code>nothing</code>s. Stencils.jl provides methods to
update stenctil values (by rebuilding) for any center index in an array, handling boundary conditions
by either padding or checking bounds.</p>
<p dir="auto">Stencils.jl also provides functions to retreive the <code>offsets</code>, <code>indices</code>, <code>distances</code>
from the center pixel, and other information about the stencil. These are all compile time
operations, usable in fast inner loops or in GPU kernels. <code>@generated</code>
functions are used in most cases to guarantee compiling performant, type-stable
code for all arbitrary stencil shapes and sizes.</p>

<p dir="auto">The third number - here <code>8</code> - is the calculated length of the Stencil. Note
that no matter what you use for <code>ndims</code>, the stencil is still <code>&lt;: StaticVector</code>,
because the potential for missing positions mean we need to collapse the
dimensions into one to keep things generic.</p>

<p dir="auto">Stencils.jl defines only direct methods, no FFTs. But it's very fast at
mapping direct kernels over arrays. The <code>StencilArray</code> provides a wrapper
for these operations that will properly handle boundary conditions.</p>

<p dir="auto">Or</p>
<p dir="auto">Stencils can be used standalone, outside of <code>mapstencil</code>. For example
in iterative cost-distance models. Stencils provides a <code>stencil</code> method
to fill a stencil for a particular location <code>stencil(A, I)</code>. It also has an
<code>indices(A, I)</code> method to retreive array indices for the stencil, so you can use them to
write values into an array for the stencil shape around your specified center index.</p>
