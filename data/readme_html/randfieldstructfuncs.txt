<p dir="auto">This package is to deal with structure functions of random fields with stationary
increments in Julia.</p>
<p dir="auto">The structure function of a random field <code>φ</code> is defined by:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Dᵩ(Δr) = ⟨[φ(r + Δr) - φ(r)]²⟩"><pre><span class="pl-en">Dᵩ</span>(Δr) <span class="pl-k">=</span> ⟨[<span class="pl-c1">φ</span>(r <span class="pl-k">+</span> Δr) <span class="pl-k">-</span> <span class="pl-c1">φ</span>(r)]²⟩</pre></div>
<p dir="auto">where <code>⟨…⟩</code> denotes expectation while <code>r</code> and <code>Δr</code> are absolute and relative positions. If
<code>φ</code> has stationary increments, its structure function does not depend on <code>r</code>, only on <code>Δr</code>.</p>
<p dir="auto">This package let you build structure function objects, generate the associated covariance
matrix, and simulate random fields having a given structure function <code>Dᵩ</code> and piston
standard deviation <code>σ</code>. If <code>σ &gt; 0</code> holds, the covariance of <code>φ</code> is invertible.</p>
<p dir="auto">This <a href="notes/structure-functions.tex">LaTeX file</a> provides some mathematical background.</p>

<p dir="auto">To measure empirically a structure function:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Create structure function object with support S.
A = EmpiricalStructFunc(S)
for ϕₜ in Φ
    # Integrate structure function.
    push!(A, ϕₜ)
end
T = nobs(A);     # get the number of observations
D_ϕ = values(A); # compute the structure function"><pre><span class="pl-c"><span class="pl-c">#</span> Create structure function object with support S.</span>
A <span class="pl-k">=</span> <span class="pl-c1">EmpiricalStructFunc</span>(S)
<span class="pl-k">for</span> ϕₜ <span class="pl-k">in</span> Φ
    <span class="pl-c"><span class="pl-c">#</span> Integrate structure function.</span>
    <span class="pl-c1">push!</span>(A, ϕₜ)
<span class="pl-k">end</span>
T <span class="pl-k">=</span> <span class="pl-c1">nobs</span>(A);     <span class="pl-c"><span class="pl-c">#</span> get the number of observations</span>
D_ϕ <span class="pl-k">=</span> <span class="pl-c1">values</span>(A); <span class="pl-c"><span class="pl-c">#</span> compute the structure function</span></pre></div>
<p dir="auto">At any moment:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="a = A.den; # get the denominator: `a = S ⊗ S`
fft_b =  A.num; # get the numerator in the frequency domain"><pre>a <span class="pl-k">=</span> A<span class="pl-k">.</span>den; <span class="pl-c"><span class="pl-c">#</span> get the denominator: `a = S ⊗ S`</span>

<p dir="auto">It is also possible to define theoretical structure functions. For example, Kolmogorov
structure function for Fried's parameter <code>r0</code> is built by:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="D = KolmogorovStructFunc(r0);"><pre>D <span class="pl-k">=</span> <span class="pl-c1">KolmogorovStructFunc</span>(r0);</pre></div>
<p dir="auto">which yields a callable object <code>D</code> such that <code>D(r)</code> returns the value of the structure
function at position <code>r</code>. Note that <code>r</code> and <code>r0</code> are assumed to have the same units if
<code>r0</code> has no units; otherwise; <code>r</code> must have the same unit dimensions as <code>r0</code>.</p>
