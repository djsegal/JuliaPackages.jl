<p dir="auto">A <code>TupleDict</code> can be constructed by passing in a tuple of <code>Dict</code>s, and it preserves the association of each keytype to its correspdonding valtype.</p>
<p dir="auto">These <code>Dict</code>s can then be treated as one single <code>Dict</code>, while maintaining type stable retrieval</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ConcreteTupleDicts

d1 = Dict(1 =&gt; 2)
d2 = Dict(2.0 =&gt; 3.0)
d3 = Dict(&quot;three&quot; =&gt; 4)

ds = (d1, d2, d3)

td = TupleDict(ds)

@inferred td[1]        # Properly infers Int
@inferred td[2.0]      # Properly infers Float64
@inferred td[&quot;three&quot;]  # Properly infers Int"><pre><span class="pl-k">using</span> ConcreteTupleDicts

<p dir="auto">These <code>Dict</code>s must not have overlapping key types in order to permit an unambiguous mapping from a given keytype to a valtype.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="d1 = Dict(1 =&gt; 2)
