<p dir="auto"><em>SoleData.jl</em> defines optimized structures for representing
<em>logisets</em>, that is, sets of logical interpretations.
Logisets are the symbolic counterpart to Machine Learning datasets.</p>

<p dir="auto">Symbolic AI treats tabular dataset (e.g., the <a href="https://en.wikipedia.org/wiki/Iris_flower_data_set" rel="nofollow">Iris flower dataset</a>)
as a set of propositional interpretations (or propositional <em>logiset</em>), onto which formulas of propositional logic are interpreted.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Modal Logic</h2><a id="user-content-modal-logic" class="anchor" aria-label="Permalink: Modal Logic" href="#modal-logic"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Symbolic AI treats non-tabular datasets (e.g., datasets of time-series or images) as sets of interpretations (<em>logisets</em>) of more-than-propositional logics,
that can express <em>relational patterns</em>.
In the following example, a time-series dataset such as <a href="http://www.timeseriesclassification.com/description.php?Dataset=NATOPS" rel="nofollow">NATOPS</a> is interpreted via a modal logic formalism based on intervals and <a href="https://en.wikipedia.org/wiki/Allen%27s_interval_algebra" rel="nofollow">Allen's (or Interval Algebra) relations</a>.
On each time series in NATOPS, we hereby check the following temporal property, encoded via a modal logical formula:
<em>"there an interval where V1 is always higher than -0.54, and such that there exists a later interval where either V3 is lower than -0.78, or V5 is higher than -0.84."</em></p>
