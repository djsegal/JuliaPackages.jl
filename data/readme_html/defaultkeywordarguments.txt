<p dir="auto"><strong>DefaultKeywordArguments.jl</strong> is a package to handle <em>default keyword arguments</em> in Julia. It has been developed to support <a href="https://github.com/PdIPS/CBX.jl">CBX.jl</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The <code>@default</code> Macro</h2><a id="user-content-the-default-macro" class="anchor" aria-label="Permalink: The @default Macro" href="#the-default-macro"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In Julia, functions can have keyword arguments with a default value. The function</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="with_keywords(x; a = 2.0, b = 3.0, c = 4.0) = (a * x + b) / c;"><pre><span class="pl-en">with_keywords</span>(x; a <span class="pl-k">=</span> <span class="pl-c1">2.0</span>, b <span class="pl-k">=</span> <span class="pl-c1">3.0</span>, c <span class="pl-k">=</span> <span class="pl-c1">4.0</span>) <span class="pl-k">=</span> (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b) <span class="pl-k">/</span> c;</pre></div>
<p dir="auto">will return <code>(2.0 * x + 3.0) / 4.0</code> unless you specify a different value of <code>a</code>, <code>b</code>, or <code>c</code>.</p>
<p dir="auto">When you're writing a complex piece of software, you may have multiple functions that use the keyword arguments <code>a</code>, <code>b</code>, and <code>c</code>, and which should all use the same default value. For instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="with_keywords(x; a = 2.0, b = 3.0, c = 4.0) = (a * x + b) / c;

yet_another_with_keywords(x; a = 2.0, b = 3.0, c = 4.0) = round(Int, c / (a * x + b));"><pre><span class="pl-en">with_keywords</span>(x; a <span class="pl-k">=</span> <span class="pl-c1">2.0</span>, b <span class="pl-k">=</span> <span class="pl-c1">3.0</span>, c <span class="pl-k">=</span> <span class="pl-c1">4.0</span>) <span class="pl-k">=</span> (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b) <span class="pl-k">/</span> c;
<span class="pl-en">another_with_keywords</span>(x; a <span class="pl-k">=</span> <span class="pl-c1">2.0</span>, b <span class="pl-k">=</span> <span class="pl-c1">3.0</span>, c <span class="pl-k">=</span> <span class="pl-c1">4.0</span>) <span class="pl-k">=</span> <span class="pl-c1">round</span>(Int, (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b) <span class="pl-k">/</span> c);
<span class="pl-en">yet_another_with_keywords</span>(x; a <span class="pl-k">=</span> <span class="pl-c1">2.0</span>, b <span class="pl-k">=</span> <span class="pl-c1">3.0</span>, c <span class="pl-k">=</span> <span class="pl-c1">4.0</span>) <span class="pl-k">=</span> <span class="pl-c1">round</span>(Int, c <span class="pl-k">/</span> (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b));</pre></div>
<p dir="auto">If you have many functions and many keyword arguments, maintaining consistency of the default values can soon become cumbersome. One sensible option would be to collect all the default values in a single place:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const default_values = (; a = 2.0, b = 3.0, c = 4.0);

<span class="pl-en">another_with_keywords</span>(x; a <span class="pl-k">=</span> default_values<span class="pl-k">.</span>a, b <span class="pl-k">=</span> default_values<span class="pl-k">.</span>b, c <span class="pl-k">=</span> default_values<span class="pl-k">.</span>c) <span class="pl-k">=</span> <span class="pl-c1">round</span>(Int, (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b) <span class="pl-k">/</span> c);
<span class="pl-en">yet_another_with_keywords</span>(x; a <span class="pl-k">=</span> default_values<span class="pl-k">.</span>a, b <span class="pl-k">=</span> default_values<span class="pl-k">.</span>b, c <span class="pl-k">=</span> default_values<span class="pl-k">.</span>c) <span class="pl-k">=</span> <span class="pl-c1">round</span>(Int, c <span class="pl-k">/</span> (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b));</pre></div>
<p dir="auto">However, writing <code>a = default_values.a</code>, <code>b = default_values.b</code>, and <code>c = default_values.c</code> over and over is tedious, and can clutter your code.</p>
<p dir="auto">The <code>@default</code> macro offers an alternative:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const default_values = (; a = 2.0, b = 3.0, c = 4.0);

<span class="pl-c1">@default</span> default_values <span class="pl-en">with_keywords</span>(x; a, b, c) <span class="pl-k">=</span> (a <span class="pl-k">*</span> x <span class="pl-k">+</span> b) <span class="pl-k">/</span> c;

<p dir="auto">You can write non-compact functions instead:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const default_values = (; a = 2.0, b = 3.0, c = 4.0);

<p dir="auto">You can also write type annotations and default values as usual. Furthermore, you can overwrite the default values of each keyword argument individually, if required. These are all valid:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const default_values = (; a = 2.0, b = 3.0, c = 4.0);

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function first_call(config)

<p dir="auto">This code is verbose and repetitive. However, it can be generated by the <code>@config</code> macro instead:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const default_config = (; a = 2.0, b = 3.0, c = 4.0);

@config default_config function first_call(; a, b)
  # some code
  return second_call(config)
end

@config default_config function second_call(; a, c)
  # some more code
end"><pre><span class="pl-k">const</span> default_config <span class="pl-k">=</span> (; a <span class="pl-k">=</span> <span class="pl-c1">2.0</span>, b <span class="pl-k">=</span> <span class="pl-c1">3.0</span>, c <span class="pl-k">=</span> <span class="pl-c1">4.0</span>);

<span class="pl-c1">@config</span> default_config <span class="pl-k">function</span> <span class="pl-en">first_call</span>(; a, b)
  <span class="pl-c"><span class="pl-c">#</span> some code</span>
  <span class="pl-k">return</span> <span class="pl-c1">second_call</span>(config)
<span class="pl-k">end</span>

<span class="pl-c1">@config</span> default_config <span class="pl-k">function</span> <span class="pl-en">second_call</span>(; a, c)
  <span class="pl-c"><span class="pl-c">#</span> some more code</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">To avoid repetition, <strong>you don't even have to specify the <code>config</code> argument</strong> on each function. Calling <code>my_config = (; a = 1.0); first_call(my_config)</code> will behave as in the previous code.</p>
<p dir="auto">Once again, you are allowed to have extra arguments, type annotations, or default values, as you would in any other Julia function.</p>
<p dir="auto"><g-emoji class="g-emoji" alias="warning">⚠️</g-emoji> The code pattern generated by <code>@config</code> allocates some heap memory. This macro should be used for high-level functions that are not performance-critical.</p>
