<p dir="auto"><strong>Math Programming Incidence</strong> Graph Analysis.
Tools for constructing and analyzing the
incidence graph or matrix of variables and constraints in a JuMP model.</p>
<p dir="auto">These tools can be used to detect whether and (approximately) why the
Jacobian of equality constraints is structurally or numerically singular,
which commonly happens as the result of a modeling error.
See the <a href="https://lanl-ansi.github.io/MathProgIncidence.jl/dev/" rel="nofollow">documentation</a>
for more information and examples.</p>
