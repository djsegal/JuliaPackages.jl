<p dir="auto">To train an NMF model, first load MLJ and this package</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MLJ, MLJNonnegativeMatrixFactorization"><pre><span class="pl-k">using</span> MLJ, MLJNonnegativeMatrixFactorization</pre></div>
<p dir="auto">The NMF can then be instantiated in the usual way for an unsupervised model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="nmf = NMF()
mach = machine(nmf, df)
fit!(mach)"><pre>nmf <span class="pl-k">=</span> <span class="pl-c1">NMF</span>()
mach <span class="pl-k">=</span> <span class="pl-c1">machine</span>(nmf, df)
<span class="pl-c1">fit!</span>(mach)</pre></div>
<p dir="auto">Calling <code>fitted_params</code> on the trained machine will return a tuple containing the factor matrix (a.k.a. endmembers) <code>W</code> and the factor loading matrix (a.k.a. abundances) <code>H</code>.</p>
<p dir="auto">The NMF can be used for feature extraction via <code>W</code> or for dimensionality reduction to the factor loadings via</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Ĥ = MLJ.transform(mach, X)"><pre>Ĥ <span class="pl-k">=</span> MLJ<span class="pl-k">.</span><span class="pl-c1">transform</span>(mach, X)</pre></div>
