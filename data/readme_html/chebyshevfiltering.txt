<p dir="auto">A Julia code for high-performance Chebyshev polynomial diagonalization. In the current version, the package is built with the purpose to find all the eigenvalues and the corresponding eigenvectors, lying in a chosen interval <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0983b7b590fd17e6cd286e8cd053016">$\left[\lambda_{\mathrm{min}}, \ \lambda_{\mathrm{max}} \right]$</math-renderer>, - for a given <em>sparse</em> and <em>Hermitian</em> (real or complex) matrix.</p>
<p dir="auto">The code makes use of multithreading to speed up the computation and so it works at its best on single-node, multicore, configurations. From its very definition, the algorithm works in such a way to keep the sparsity of the problem at every step, and it works at its best when the interval chosen, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0983b7b590fd17e6cd286e8cd053016">$\left[\lambda_{\mathrm{min}}, \ \lambda_{\mathrm{max}} \right]$</math-renderer>, contains just few hundreds of eigenvalues. In particular, it <em>does not</em> work well in finding large chunks of eigenvalues and eigenvectors.</p>
<p dir="auto">Mathematically, it uses the algorithm developed in <a href="https://www.sciencedirect.com/science/article/abs/pii/S0021999116303837?via%3Dihub" rel="nofollow">Journal of Computational Physics 325, 226 (2016)</a>. As such, it renormalizes authomatically the matrix such that its spectrum lies in the interval <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="d0983b7b590fd17e6cd286e8cd053016">$\left[-1, \ 1 \right]$</math-renderer>. The current Julia implementation has been used in <a href="https://arxiv.org/abs/2302.00917" rel="nofollow">"From Dyson Models to Many-Body Quantum Chaos", arXiv:2302.00917 [quant-ph]</a> to discuss the quantum chaotic properties of a family of impurity SYK models.</p>

<p dir="auto">In the current version, the package provides the function:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="eigen_cheb(hamiltonian_matrix; lambda_min::Float64=-0.1, lambda_max::Float64=0.1, n_chunks_thread::Int64=2, n_first_iterations::Int64=3, epsilon_convergence::Float64=10^(-7), log_path=&quot;none&quot;, log_file_name=&quot;none&quot;, search_target_ratio::Float64=3.0, max_degree_KPM::Int64=150, stochastic_dimension_KPM::Int64=30, N_0::Float64=6.23)"><pre class="notranslate"><code>eigen_cheb(hamiltonian_matrix; lambda_min::Float64=-0.1, lambda_max::Float64=0.1, n_chunks_thread::Int64=2, n_first_iterations::Int64=3, epsilon_convergence::Float64=10^(-7), log_path="none", log_file_name="none", search_target_ratio::Float64=3.0, max_degree_KPM::Int64=150, stochastic_dimension_KPM::Int64=30, N_0::Float64=6.23)
</code></pre></div>
<p dir="auto">that requires as input the sparse and hermitian matrix <code>hamiltonian_matrix</code> of interest and gives back a tuple made by a vector with all the eigenvalues found in the interval between <code>lambda_min</code> and <code>lambda_max</code> and by another vector containing all the corresponding eigenvectors. Optionally, the user can provide the path to the folder where the log file is located and the name of the log file itself. The extra variables <code>search_target_ratios</code>, <code>max_degree_KPM</code>, <code>stochastic_dimension_KPM</code>, <code>N_0</code> and <code>epsilon_convergence</code> are all defined in <a href="https://www.sciencedirect.com/science/article/abs/pii/S0021999116303837?via%3Dihub" rel="nofollow">Journal of Computational Physics 325, 226 (2016)</a>. The default values should work optimally for most eigenvalue problems of interest in many-body physics.
The variable <code>n_chunks_thread</code> set the number of chunks that a single thread should work on during parallelization, and the the variable <code>n_first_iteration</code> set the number of filtering steps the algorithm performs before checking for convergence of the Ritz vectors.</p>
