<p dir="auto">Might as well take a look at <a href="https://docs.julialang.org/en/v1/devdocs/cartesian/#Anonymous-function-expressions-as-macro-arguments" rel="nofollow"><code>Base.@nexpr</code></a>, <a href="https://github.com/cstjean/Unrolled.jl"><code>Unrolled.jl</code></a> and <a href="https://juliagpu.github.io/KernelAbstractions.jl/stable/extras/unrolling/" rel="nofollow"><code>KernalAbstractions.jl</code></a>.</p>
<p dir="auto">This package provides the <code>unroll</code> and <code>tuplegen</code> macros.
The <code>unroll</code> macro in Julia unrolls simple for-loops.  For example,
the following code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@unroll for i = 1 : 2
   x += a[i]
end"><pre><span class="pl-c1">@unroll</span> <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">2</span>
   x <span class="pl-k">+=</span> a[i]
<span class="pl-k">end</span></pre></div>
<p dir="auto">will macro-expand as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x += a[1]
x += a[2]"><pre>x <span class="pl-k">+=</span> a[<span class="pl-c1">1</span>]
x <span class="pl-k">+=</span> a[<span class="pl-c1">2</span>]</pre></div>
<p dir="auto">For this to be possible, the loop bounds must be known at the time
of macro-expansion.  A common case is that they are literal
constant values as in
the above example.<br>
The loop bounds may include symbolic constants that are global
within the module:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const LOOPBOUND = 2
function myfunct()
   @unroll for i = 1 : LOOPBOUND
      &lt;etc&gt;
   end
end"><pre><span class="pl-k">const</span> LOOPBOUND <span class="pl-k">=</span> <span class="pl-c1">2</span>
<span class="pl-k">function</span> <span class="pl-en">myfunct</span>()
   <span class="pl-c1">@unroll</span> <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> LOOPBOUND
      <span class="pl-k">&lt;</span>etc<span class="pl-k">&gt;</span>
   <span class="pl-k">end</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">The <code>unroll</code> macro can be nested.</p>
<p dir="auto">Finally, the <code>unroll</code> macro will search for conditionals that
depend on the loop counter and unroll these as well.  For example,
the call:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@unroll for i = 1 : 4
   if mod(i,2) == 1
      a += b[i]
   else
      a += 2*b[i]
   end
end"><pre><span class="pl-c1">@unroll</span> <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">4</span>
   <span class="pl-k">if</span> <span class="pl-c1">mod</span>(i,<span class="pl-c1">2</span>) <span class="pl-k">==</span> <span class="pl-c1">1</span>
      a <span class="pl-k">+=</span> b[i]
   <span class="pl-k">else</span>
      a <span class="pl-k">+=</span> <span class="pl-c1">2</span><span class="pl-k">*</span>b[i]
   <span class="pl-k">end</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">will macro-expand to:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="a += b[1]
a += 2*b[2]
a += b[3]
a += 2*b[4]"><pre>a <span class="pl-k">+=</span> b[<span class="pl-c1">1</span>]
a <span class="pl-k">+=</span> <span class="pl-c1">2</span><span class="pl-k">*</span>b[<span class="pl-c1">2</span>]
a <span class="pl-k">+=</span> b[<span class="pl-c1">3</span>]
a <span class="pl-k">+=</span> <span class="pl-c1">2</span><span class="pl-k">*</span>b[<span class="pl-c1">4</span>]</pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The tuplegen macro</h2><a id="user-content-the-tuplegen-macro" class="anchor" aria-label="Permalink: The tuplegen macro" href="#the-tuplegen-macro"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>tuplegen</code> macro generates fixed-length tuples using comprehension-like
syntax.  For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="v = @tuplegen [(i==2)? i * 6 : i for i = 1 : 4]"><pre>v <span class="pl-k">=</span> <span class="pl-c1">@tuplegen</span> [(i<span class="pl-k">==</span><span class="pl-c1">2</span>)? i <span class="pl-k">*</span> <span class="pl-c1">6</span> <span class="pl-k">:</span> i <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">4</span>]</pre></div>
<p dir="auto">macro-expands to:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="v = (1, 2*6, 3, 4)"><pre>v <span class="pl-k">=</span> (<span class="pl-c1">1</span>, <span class="pl-c1">2</span><span class="pl-k">*</span><span class="pl-c1">6</span>, <span class="pl-c1">3</span>, <span class="pl-c1">4</span>)</pre></div>
<p dir="auto">and therefore generates the tuple <code>(1,12,3,4)</code>.<br>
Without the <code>@tuplegen</code> call, this
same statement would generate the array <code>[1,12,3,4]</code>.  It is possible
to generate tuples from comprehensions
via the following standard
statement:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="v = tuple([(i==2)? i * 6 : i for i = 1 : 4]...)"><pre>v <span class="pl-k">=</span> <span class="pl-c1">tuple</span>([(i<span class="pl-k">==</span><span class="pl-c1">2</span>)? i <span class="pl-k">*</span> <span class="pl-c1">6</span> <span class="pl-k">:</span> i <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">4</span>]<span class="pl-k">.</span><span class="pl-k">..</span>)</pre></div>
<p dir="auto">but this statement is less efficient because it creates a heap-allocated
array as a temporary.</p>
<p dir="auto">Here is a more complicated example of <code>@tuplegen</code>.  Suppose 2-by-2
matrices are represented as 2-tuples of 2-tuples, e.g., <code>((1,2),(5,7))</code>
stands for:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="  1  2
  5  7"><pre class="notranslate"><code>  1  2
  5  7
</code></pre></div>
<p dir="auto">Then 2-by-2 matrix multiplication may be defined by:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mtxmult(a,b) = @tuplegen [@tuplegen [a[i][1]*b[1][j] + a[i][2]*b[2][j] 
                                       for j = 1 : 2]
                           for i = 1 : 2]"><pre><span class="pl-en">mtxmult</span>(a,b) <span class="pl-k">=</span> <span class="pl-c1">@tuplegen</span> [<span class="pl-c1">@tuplegen</span> [a[i][<span class="pl-c1">1</span>]<span class="pl-k">*</span>b[<span class="pl-c1">1</span>][j] <span class="pl-k">+</span> a[i][<span class="pl-c1">2</span>]<span class="pl-k">*</span>b[<span class="pl-c1">2</span>][j] 
                                       <span class="pl-k">for</span> j <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">2</span>]
                           <span class="pl-k">for</span> i <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">:</span> <span class="pl-c1">2</span>]</pre></div>
<p dir="auto">This definition generates unrolls into four expressions on the right-hand side and
works as expected:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; mtxmult(((1,2),(5,7)),((4,1),(2,8)))
((8,17),(34,61))"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">mtxmult</span>(((<span class="pl-c1">1</span>,<span class="pl-c1">2</span>),(<span class="pl-c1">5</span>,<span class="pl-c1">7</span>)),((<span class="pl-c1">4</span>,<span class="pl-c1">1</span>),(<span class="pl-c1">2</span>,<span class="pl-c1">8</span>)))
((<span class="pl-c1">8</span>,<span class="pl-c1">17</span>),(<span class="pl-c1">34</span>,<span class="pl-c1">61</span>))</pre></div>
<p dir="auto">As with the <code>@unroll</code>
macro, the loop bounds for <code>@tuplegen</code>
must be known at macro-expansion time.
In particular, the following plausible attempt to define a generic function for
addition of arbitrary
fixed-length tuples (so that <code>(1,7)+(-2,3)</code> yields <code>(-1,10)</code>) does not work::</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="+{N}(a::NTuple{N}, b::NTuple{N}) = @tuplegen [a[i]+b[i] for i=1:N]"><pre><span class="pl-k">+</span>{N}(a<span class="pl-k">::</span><span class="pl-c1">NTuple{N}</span>, b<span class="pl-k">::</span><span class="pl-c1">NTuple{N}</span>) <span class="pl-k">=</span> <span class="pl-c1">@tuplegen</span> [a[i]<span class="pl-k">+</span>b[i] <span class="pl-k">for</span> i<span class="pl-k">=</span><span class="pl-c1">1</span><span class="pl-k">:</span>N]</pre></div>
<p dir="auto">because the type parameter <code>N</code> is not known at the time of macro expansion; instead
it is determined later by the dispatch mechanism.  If someone knows how to fix
this, please create an issue or pull request.  (It is possible to write generic
addition for tuples via the more complicated generated-function mechanism.)</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Cautionary notes</h2><a id="user-content-cautionary-notes" class="anchor" aria-label="Permalink: Cautionary notes" href="#cautionary-notes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>The
loop index must be a simple variable (e.g., the loop cannot be
of the form <code>for (k,v) in mydict</code> or something similar).</li>
<li>The loop index is matched symbolically by the macro.  This
means that the same symbol may not be used in the loop body
with a different meaning (e.g., qualified by a different module name).</li>
<li>If the loop index is somehow concealed inside the loop body,
say with an eval/parse statement, then the macro will fail.</li>
<li>The macro calls <code>eval</code> to obtain the loop bounds and also
to check whether <code>if</code> conditions are satisfied.  This means
that the loop should not include statements with side effects
(like <code>print</code>) in either the loop bounds or in conditionals,
since these statements may get unexpectedly executed during
the macro expansion phase.</li>
</ul>
