<p dir="auto">Implements one public type, <code>WeakKeyIdDict</code>. It constructs a hash table where the keys are weak references to objects that may be garbage collected even when referenced in a hash table. Like <a href="https://docs.julialang.org/en/v1/base/collections/#Base.WeakKeyDict" rel="nofollow"><code>WeakKeyDict</code></a> it only supports keys that are mutable objects (all objects satisfying <code>ismutable(obj) == true</code>, such as Strings, Arrays and objects defined with <code>mutable struct</code>). Like <a href="https://docs.julialang.org/en/v1/base/collections/#Base.IdDict" rel="nofollow"><code>IdDict</code></a> the keys are hashed by <code>objectid</code>.</p>
<p dir="auto">A dictionary with weak keys is useful when we wish to store information about an object that survives only for the life-time of that object, usually to avoid memory leaks. For instance, if we wish to cache some hard-to-compute value associated with the keys of the dictionary.</p>

<p dir="auto">Avoid assuming a key exists in a <code>WeakKeyIdDict</code>, especially when allocation occurs. Keys can be removed any time garbage collection occurs. Favor the methods <code>get!</code> and <code>get</code> over <code>getindex</code>.</p>
