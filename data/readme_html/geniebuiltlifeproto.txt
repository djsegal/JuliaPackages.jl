<p dir="auto">This project is an attempt to create a foundation for an open source system for managing life insurance policies by an insurer.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">1. design goals</h3><a id="user-content-1-design-goals" class="anchor" aria-label="Permalink: 1. design goals" href="#1-design-goals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">of this project are:</p>
<ul dir="auto">
<li>open source development</li>
<li>performant and highly scalable web app for* dialog processing of insurance contracts and.</li>
<li>provision of services for operation</li>
<li>runnability on laptops as well as on servers</li>
<li>use of cloud development environments</li>
<li>Use of collaboration platforms in the cloud</li>
<li>Product-agnostic management system, i.e. maximum encapsulation of product-specific knowledge in product-specific components
<ul dir="auto">
<li>bases of calclulation</li>
<li>Tariff functions</li>
<li>Metadata of tariff functions for use in interfaces for dialogs and services.</li>
<li>control and validation of inputs for product-specific business processes</li>
</ul>
</li>
<li>Use of an actuary-friendly development environment with regard to programming language and existing libraries</li>
<li>Use of an application stack that is as coherent as possible and supports tests across all levels from actuarial functions to persistence to the browser, i.e. no environmental break, between actuarial product development of and development of the management system.</li>
<li>Use of existing actuarial software <a href="https://github.com/JuliaActuary/LifeContingencies.jl">https://github.com/JuliaActuary/LifeContingencies.jl</a></li>
<li>Audit-proof storage of contracts through bitemporal persistence: <a href="https://github.com/Actuarial-Sciences-for-Africa-ASA/BitemporalPostgres.jl">https://github.com/Actuarial-Sciences-for-Africa-ASA/BitemporalPostgres.jl</a></li>
</ul>
