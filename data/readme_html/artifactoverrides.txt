<p dir="auto"><em>Build ~/.julia/artifacts/Overrides.toml for operating system</em></p>
<p dir="auto">Instead of depending on <a href="https://pkgdocs.julialang.org/v1/artifacts" rel="nofollow">artifacts</a> downloaded by the Julia language package manager, this package links artifacts to the operating system binaries by building the necessary <code>~/.julia/artifacts/Overrides.toml</code> file for detected operating systems.
This makes it easier to maintain and share consistent binary artifact interoperability with an operating system.</p>
<p dir="auto">Currently supported operating systems: <code>Arch Linux</code>.</p>
<p dir="auto"><strong>Usage</strong>: Clear the <code>~/.julia/artifacts</code> directory, then run</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; build ArtifactOverrides"><pre>pkg<span class="pl-k">&gt;</span> build ArtifactOverrides</pre></div>
<p dir="auto">Note that it seems to be necessary to clear the directory first, otherwise the downloaded artifacts may still be linked instead of the operating system binaries.
When loading a package depending on an artifact linked to the operating system, an error may occur because the operating system installation is missing the linked binary.
Such an error may be fixed by installing the necessary package to the operating system.</p>
<p dir="auto"><strong>Maintenance</strong>: For <code>Arch Linux</code> it is currently sufficient that the path is simply redirected to <code>/usr/</code>, so this package <code>build.jl</code> script merely iterates through <code>pkgs</code> maintained in <code>src/arch.jl</code> having the format <code>"$(uuid)"=&gt;"$(name)"</code> per element.</p>
<p dir="auto"><strong>Future work</strong>: The initial list of artifacts linked to operating systems binaries is not complete, it will be updated and revised over time.
Additional operating systems will not be supported unless there are contributors who wish to initialize or maintain a list of artifacts linked to that operating system.</p>
