<p dir="auto">A Julia package for solving three-term recurrence relationships</p>
<p dir="auto">This package implements simple algorithms for computing solutions to recurrence relationships,
including forward recurrence for initial value-problems, <a href="https://dlmf.nist.gov/3.6#v" rel="nofollow">Olver's algorithm</a> for two-point boundary
value problems, and <a href="https://en.wikipedia.org/wiki/Clenshaw_algorithm" rel="nofollow">Clenshaw's algorithm</a> for computing dot products with a given vector as needed for
evaluating expansions in orthogonal polynomials.</p>

<p dir="auto">Clenshaw's algorithm is an efficient way to compute expansions in orthogonal polynomials. Here we compute
$$
∑_{k=0}^{n-1} {U_k(x) \over k+1}
$$
for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="fc5a506f6a89251a2970492cea432314">$x = 0.1$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="fc5a506f6a89251a2970492cea432314">$n = 1,000,000$</math-renderer>:</p>
