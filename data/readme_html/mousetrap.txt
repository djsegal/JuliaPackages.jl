<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/assets/banner.png"><img src="docs/src/assets/banner.png" alt="" style="max-width: 100%;"></a></p>
<p dir="auto">Mousetrap is a GUI library designed for Julia. It fully wraps <a href="https://docs.gtk.org/gtk4/" rel="nofollow">GTK4</a> (which is written in C), <em>vastly</em> simplifying its interface to improve ease-of-use without sacrificing flexibility.</p>
<p dir="auto">It aims to give developers of all skill levels the tools to start creating complex GUI applications with little time and effort, while taking full advantage of Julias idiosyncrasies.</p>
<blockquote>
<p dir="auto"><strong>Note</strong>: Mousetrap is under active development. Consider participating in the development by <a href="https://github.com/clemapfel/mousetrap.jl">opening an issue</a> when you encounter an error, bug, question, or missing feature.</p>
</blockquote>
<blockquote>
<p dir="auto"><strong>Note</strong>: February 8th, 2024: I've been having some health issues at the moment, it may take me some time to get to open issues. Mousetrap is still usable and (mostly) stable, the repo will be maintained in the immediate future to the best of my abilities. Thank you for your understanding, C.</p>
</blockquote>

<ul dir="auto">
<li>Create complex GUI application for Linux, Windows, and macOS</li>
<li>Choose from over 40 different kinds of pre-made widgets, or create your own</li>
<li>Supports mice, keyboards, touchscreens, touchpads, and stylus devices</li>
<li>Image processing facilities, well-suited for image manipulation programs</li>
<li>Built using OpenGL, allowing for high-performance, hardware-accelerated rendering, and integration of other OpenGL-based libraries such as <a href="https://github.com/MakieOrg/Makie.jl">GLMakie</a></li>
<li><a href="https://clemens-cords.com/mousetrap" rel="nofollow">Hand-written manual and extensive documentation</a>: every exported symbol is documented</li>
</ul>

<p dir="auto">In order of priority, highest first:</p>
<ul dir="auto">
<li>Allow bundling of Mousetrap apps using <a href="https://github.com/JuliaLang/PackageCompiler.jl"><code>PackageCompiler.jl</code></a></li>
<li>Implement installation of .desktop files on end-user computers</li>
<li>Implement drag-and-drop for files, images, and widgets</li>
<li>Allow filtering and searching of selectable widget containers such as <code>ListView</code> and <code>ColumnView</code></li>
<li>Allow adding custom signals that use the GLib marshalling system</li>
<li>Make all functions that modify the global state thread-safe</li>
</ul>
