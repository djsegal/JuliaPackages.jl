<p dir="auto">Efficient multi-XPU parallel random field generator for large 2D and 3D problems</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/Fig_exp_gauss_3D.png"><img src="docs/Fig_exp_gauss_3D.png" alt="3D random fields with Gaussian and exponential covariance" style="max-width: 100%;"></a></p>
<p dir="auto">ParallelRandomFields enables to sample spatial realisations of 2D or 3D random fields with given power spectrum. The method allows for fast and accurate generation of Gaussian random fields with anisotropic exponential (left figure pane) and isotropic Gaussian (right figure pane) covariance functions. The method is fast, accurate and fully local. We use <a href="https://github.com/omlins/ParallelStencil.jl">ParallelStencil.jl</a> to provide an architecture-agnostic high-level CPU and GPU implementation, and <a href="https://github.com/eth-cscs/ImplicitGlobalGrid.jl">ImplicitGlobalGrid.jl</a> for multi-XPU support (distributed memory parallelisation).</p>
<p dir="auto">The implementation builds upon an approach proposed in [<a href="https://doi.org/10.1016/j.cageo.2019.06.007" rel="nofollow">1</a>] and employs a parallel implementation of the method based on spectral representation described in [<a href="https://cds.cern.ch/record/295430" rel="nofollow">2</a>]. Advantages of this method are the possibility of random field simulation on an arbitrary grid and the simplicity of parallel implementation of the algorithm. The method is flexible and is also applicable for arbitrary anisotropic spectrum.</p>
<p dir="auto">ParallelRandomFields.jl is the Julia version with additional multi-XPU support of the original CUDA C implementation <a href="https://bitbucket.org/lraess/grfs/src/master/" rel="nofollow">accessible here</a>, published in Computers &amp; Geosciences:</p>

<p dir="auto">Parallel random fields can be interactively generated within the <a href="https://docs.julialang.org/en/v1/stdlib/REPL/" rel="nofollow">Julia REPL</a> using the 2D or 3D generator functions <code>generate_grf2D()</code>, <code>generate_grf3D()</code> available from the selected submodule depending on the number of dimensions (2D, 3D) and backend (<code>Threads</code>, <code>CUDA</code>). Consult the submodule and function documentation callable from the <a href="https://docs.julialang.org/en/v1/stdlib/REPL/" rel="nofollow">Julia REPL</a> or in <a href="https://github.com/JuliaLang/IJulia.jl">IJulia</a> for further details.</p>

<p dir="auto">The 2D generator function <code>generate_grf2D()</code> calls random field realisation functions <code>grf2D_expon!()</code> (exponential covariance) and <code>grf2D_gauss!()</code> (Gaussian covariance) on the chosen backend (CPU/GPU).</p>

</li>

<p dir="auto">ParallelRandomFields builds upon <a href="https://github.com/omlins/ParallelStencil.jl">ParallelStencil.jl</a> and thus supports the default <code>Threads</code> backend as well as the <code>CUDA</code> backend for GPU acceleration. Multi-threading is enabled upon export of the <a href="https://docs.julialang.org/en/v1.0.0/manual/environment-variables/#JULIA_NUM_THREADS-1" rel="nofollow">JULIA_NUM_THREADS</a> variable.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Multi-XPU implementation</h2><a id="user-content-multi-xpu-implementation" class="anchor" aria-label="Permalink: Multi-XPU implementation" href="#multi-xpu-implementation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The advantage of the iterative random field generation algorithm is the trivial distributed memory parallelisation. The generation algorithm does not perform any communication among neighbouring cells nor global operations making it highly suitable for an efficient distributed memory parallelisation implementation using <a href="https://github.com/eth-cscs/ImplicitGlobalGrid.jl">ImplicitGlobalGrid.jl</a> (relying on <a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a> and <a href="https://github.com/JuliaGPU/CUDA.jl">CUDA.jl</a> for CUDA-aware MPI features).</p>
<p dir="auto">The <a href="#main-functionalities">random field realisation functions</a> are multi-XPU ready and can be called in codes relying on ParallelStencil and IMplicitGlobalGrid. See <a href="scripts/runme2D_multixpu.jl">this example</a> for a 2D multi-XPU implementation. The <a href="scripts/runme2D_multixpu.jl"><code>runme2D_multixpu.jl</code></a> script can be launched as following upon installing the <code>mpiexecjl</code> wrapper from <code>MPI.jl</code> (<a href="https://juliaparallel.github.io/MPI.jl/stable/configuration/#Julia-wrapper-for-mpiexec" rel="nofollow">install infos</a>):</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mpiexecjl -n 2 -host localhost julia --project runme2D_multixpu.jl"><pre>mpiexecjl -n 2 -host localhost julia --project runme2D_multixpu.jl</pre></div>
<p dir="auto">Note: refer to the documentation of your Supercomputing Centre for instructions to run Julia at scale. Instructions for running on the Piz Daint GPU supercomputer at the <a href="https://www.cscs.ch/computers/piz-daint/" rel="nofollow">Swiss National Supercomputing Centre</a> can be found <a href="https://user.cscs.ch/tools/interactive/julia/" rel="nofollow">here</a> and for running on the octopus GPU supercomputer at the <a href="https://wp.unil.ch/geocomputing/octopus/" rel="nofollow">Swiss Geocomputing Centre</a> can be found <a href="https://gist.github.com/luraess/45a7a4059d8ace694812e7e301f1a258">here</a>. (The <a href="scripts/julia_setup_multixpu.sh"><code>julia_setup_multixpu.sh</code></a> script provides a multi-GPU node config, to then launch the <a href="scripts/runme2D.sh"><code>runme2D.sh</code></a> script which will call <a href="scripts/submit_julia.sh"><code>submit_julia.sh</code></a> to launch <a href="scripts/runme2D_multixpu.jl"><code>runme2D_multixpu.jl</code></a>.)</p>
<p dir="auto">Note also that previous standalone multi-XPU scripts can be found in the <a href="scripts/standalone_scripts/ParallelRandomFields_multixpu">ParallelRandomFields_multixpu</a> directory.</p>
