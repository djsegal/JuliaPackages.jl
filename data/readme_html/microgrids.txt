<p dir="auto">The <code>Microgrids.jl</code> package allows simulating the energetic operation of an isolated microgrid,
returning economic and operation indicators.</p>

<p dir="auto">To install the latest released version of Microgrids.jl: <code>] add Microgrids</code>.</p>
<p dir="auto">To install the lastest development version, follow the <a href="http://pkgdocs.julialang.org/v1/managing-packages/#Adding-unregistered-packages" rel="nofollow">instructions for unregistered packages</a>.
In particular, you can clone this repository and then, from the Julia command line,
navigate to the folder of your local copy and run:</p>
<ul dir="auto">
<li>either <code>] add .</code> to install from the <code>main</code> branch of that local repository, but without tracking file changes</li>
<li>or <code>] dev .</code> to install from that local repository <em>with</em> tracking file changes (see <a href="https://pkgdocs.julialang.org/v1/managing-packages/#developing" rel="nofollow">dev</a> install)</li>
</ul>
<p dir="auto">The unit tests which ship with the package can be run with <code>] test Microgrids</code>.</p>

<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="https://github.com/Microgrids-X/Microgrids-artwork/raw/main/svg/microgrid_sizing.svg"><img alt="Microgrid sizing illustration" src="https://github.com/Microgrids-X/Microgrids-artwork/raw/main/svg/microgrid_sizing.svg" width="250px" style="max-width: 100%;"></a></p>
<p dir="auto"><code>Microgrids.jl</code> can model a microgrid project consisting of:</p>
<ul dir="auto">
<li>One load (described by a time series)</li>
<li>One dispatchable generator (e.g. Diesel or hydrogen-powered)</li>
<li>One energy storage (battery)</li>
<li>Any number of non-dispatchable sources, typically renewable like wind or solar power,
also modeled from time series</li>
</ul>
<p dir="auto">The energy dispatch at each instant of the simulated operation is a simple
“load following” rule-based control.
The load is power in priority from the dispatchable sources,
then the battery, and only using the dispatchable generator as a last recourse.</p>
<p dir="auto"><code>Microgrids.jl</code> is part of the <a href="https://github.com/Microgrids-X/">Microgrids.X</a> project
which provides sibling packages in other languages (e.g. in Python)
to better serve the need of different users (e.g. students).</p>
<p dir="auto">The work on the Julia package specifically focuses on:</p>
<ul dir="auto">
<li>
<p dir="auto"><strong>simulation speed</strong> (about 0.2 ms to evaluate one microgrid project,
using 1 year of load/solar/wind data at an hourly timestep), way better than pure Python (11 ms for the same task).
See the <a href="perf">perf</a> folder for simulation performance benchark.</p>
</li>
<li>
<p dir="auto"><strong>differentiable model</strong>: the exact gradient on the objective function
(with respect to sizing parameters) can be computed using
<a href="http://www.juliadiff.org/ForwardDiff.jl/" rel="nofollow">ForwardDiff</a>.</p>
<ul dir="auto">
<li>Thanks to our careful treatment of types (and thanks to ForwardDiff and Julia),
computing the gradient with respect to n=3 parameters with ForwardDiff should run
faster than with finite differences (which take n+1 = 4× simulation time)</li>
</ul>
</li>
</ul>
