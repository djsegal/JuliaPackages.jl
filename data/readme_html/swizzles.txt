<p dir="auto">Lightweight package meant to provide functionality and syntax for <a href="https://en.wikipedia.org/wiki/Swizzling_(computer_graphics)" rel="nofollow">swizzling</a> operations.</p>
<p dir="auto">Swizzling is defined for any linearly indexable object, the main example of which are <code>AbstractVector</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Swizzles

julia&gt; v = [10, 20, 30, 40];

julia&gt; swizzle(v, 3, 1)
2-element Vector{Int64}:
 30
 10"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Swizzles

julia<span class="pl-k">&gt;</span> v <span class="pl-k">=</span> [<span class="pl-c1">10</span>, <span class="pl-c1">20</span>, <span class="pl-c1">30</span>, <span class="pl-c1">40</span>];

julia<span class="pl-k">&gt;</span> <span class="pl-c1">swizzle</span>(v, <span class="pl-c1">3</span>, <span class="pl-c1">1</span>)
<span class="pl-c1">2</span><span class="pl-k">-</span>element Vector{Int64}<span class="pl-k">:</span>
 <span class="pl-c1">30</span>
 <span class="pl-c1">10</span></pre></div>
<p dir="auto">Besides extracting vector components, swizzling may be used for mutation, with <code>swizzle!</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; v = [10, 20, 30, 40];

julia<span class="pl-k">&gt;</span> <span class="pl-c1">swizzle!</span>(v, [<span class="pl-c1">1</span>, <span class="pl-c1">2</span>], <span class="pl-c1">4</span>, <span class="pl-c1">2</span>)
