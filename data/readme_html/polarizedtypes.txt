<p dir="auto">This defines the basic for polarized types for use in VLBI, including:</p>
<ul dir="auto">
<li><code>StokesParams</code> for the stokes parameters</li>
<li><code>CoherencyMatrix</code> for coherency matrices in arbitrary bases, including a mixed basis.</li>
</ul>
