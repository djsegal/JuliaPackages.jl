<p dir="auto">First order eccentricity transit timing variations (TTVs) computed in Agol &amp; Deck (2015)
<a href="https://ui.adsabs.harvard.edu/abs/2016ApJ...818..177A/abstract" rel="nofollow"><img src="https://camo.githubusercontent.com/bc8a11b8a549ce55da38f9733cf03cee7d8c8f2b1a64b95417dd43719d77959c/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f4144532d3230313641504a2e2e2e3831382e2e2e313737412d626c7565" alt="ADS" data-canonical-src="https://img.shields.io/badge/ADS-2016APJ...818...177A-blue" style="max-width: 100%;"></a> <a href="http://arxiv.org/abs/1509.01623" rel="nofollow"><img src="https://camo.githubusercontent.com/5de61bf0f840f6446886b8dbc1a8bf736b9e8b65138d560ad19277e0f5b67ad1/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f61725869762d313530392e30313632332d627269676874677265656e" alt="arXiv" data-canonical-src="https://img.shields.io/badge/arXiv-1509.01623-brightgreen" style="max-width: 100%;"></a></p>
<p dir="auto">This implements equation (33) from that paper by computing the Laplace
coefficients using a series solution due to Jack Wisdom, computing
the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$f_{1,j}^{(\pm k)}$</math-renderer> coefficients given in equation (34) using the functions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$u$</math-renderer> and
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$v_{\pm}$</math-renderer> with coefficients given in Table 1.</p>

<p dir="auto">In its current state, the package computes the TTVs of a multi-transiting planetary system where at least 2 planets are observed to be transiting.
If you intend to modify the source code for any reason, please create a GitHub fork to develop your own version.</p>

<p dir="auto">TTVFaster computes TTVs with respect to 5 properties for each planet: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$\mu$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$T_0$</math-renderer> , <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$P$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$e \cos(\omega)$</math-renderer> , <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$e \sin(\omega)$</math-renderer>;
where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$\mu$</math-renderer> is the mass ratio of the planet to the star (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$m_p/M_{\star}$</math-renderer>), <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$T_0$</math-renderer> is the initial transit time (of the averaged orbit), <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$P$</math-renderer> is the mean orbital period, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$e$</math-renderer> is the eccentricity, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$\omega$</math-renderer> is the longitude of periastron.</p>

<p dir="auto">This computes the TTVs and writes them to the files inner_ttv.txt and outer_ttv.txt in the examples/ directory.
Note that the TTVs are stored in the variables ttv1 and ttv2, as well.
The test_ttv.jl routine accepts jmax (the maximum <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8d1187c60d8583806ab2d11de8e41b22">$j$</math-renderer> to sum to, in this example 5),
ntrans1 (number of transits of the inner planet), ntrans2 (the number of transits of the outer planet),
and data which contains the parameters of both planets.</p>
