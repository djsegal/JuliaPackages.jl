<p dir="auto">Cross-platform app to manage and edit scanning probe microscopy (SPM) images and spectra.
It supports scanning tunneling microscopy (STM) and atomic force microscopy (AFM) images and spectra.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Load and display SPM images: grid and zoom views</li>
<li>Load and display spectra</li>
<li>Fast navigation: dropdown menus or keyboard shortcuts</li>
<li>Cycle through channels, switch between forward and backward directions</li>
<li>Different types of background corrections</li>
<li>Various color palettes</li>
<li>Non-destructive edits: Gaussian, Laplacian, Fourier Filter, etc.</li>
<li>Line profiles</li>
<li>Star-rating and keyword systems</li>
<li>Powerful search and filtering (e.g., by keywords, data type, location, scan size)</li>
<li>Overview and position-based filtering</li>
<li>Export to <a href="https://en.wikipedia.org/wiki/OpenDocument" rel="nofollow">OpenDocument presentation</a>
(compatible with <a href="https://www.libreoffice.org/" rel="nofollow">LibreOffice</a>, <a href="https://www.openoffice.org/" rel="nofollow">OpenOffice</a>, <a href="https://en.wikipedia.org/wiki/Microsoft_PowerPoint" rel="nofollow">PowerPoint</a>, etc.)</li>
<li>Everything is experimental. And we all like experiments.</li>
</ul>

<p dir="auto"><em>Currently, the app should be considered experimental. It has undergone limited testing and I can not guarantee that it will work flawlessly. It is conceivable that some of the calculations potentially give erroneous results under certain circumstances.</em></p>
<p dir="auto"><em>The app never modifies or deletes your original data. However, in case of any unexpected problems, you might lose the modifications saved within the app. Even though this has never happened to me, I still advice to backup the database regularly (I personally do not do that, though). The app creates a database in each project directory under <code>_spmimages_cache/db.jld2</code> (some older versions of this file are kept as well). This file contains all your edits, keywords, etc. and can be copied as a backup. Any filesystem backup solution should handle this.</em></p>

<p dir="auto"><em>Please only use the app if you read the disclaimer above and feel brave enough to do so.</em></p>
<p dir="auto">Use <a href="https://github.com/alexriss/SpmImageTycoonInstaller.jl">SpmImage Tycoon Installer</a>. It will install a compiled version of SpmImage Tycoon with much improved startup speed. Furthermore, it can create startmenu and desktop shortcuts. This way of installation also allows to copy the app from one computer to another, by simply copying the installation directory.</p>
<p dir="auto">Usage is simple:</p>
<ol dir="auto">
<li>Install <a href="https://julialang.org/" rel="nofollow">Julia</a></li>
<li>Start Julia and type the following two commands:</li>
</ol>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg

<p dir="auto">This will install a compiled version of SpmImage Tycoon.
The installation will typically take 10 to 20 minutes and take up around 1 GB of space.
The same procedure can be used to update to the latest version.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Tips and tricks</h2><a id="user-content-tips-and-tricks" class="anchor" aria-label="Permalink: Tips and tricks" href="#tips-and-tricks"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Fast access to the file system is crucial - do not use this app on a slow networked file system.</li>
<li>The first startup after installation (or update) can be slow - it is due to initial compilations. I am working on a solution to this.</li>
<li>To gain a significant speedup through mutlithreading, start Julia with multiple threads, e.g.: <code>julia --threads=auto</code>. This is automatically done by the <a href="https://github.com/alexriss/SpmImageTycoonInstaller.jl">SpmImage Tycoon Installer</a>.</li>
<li>There is a small overhead to apply color schemes; for performance it is best to use the standard "gray" color scheme.</li>
<li>Extra settings (such as default channels and the default color scheme) can be changed in the <code>&lt;homedir&gt;/.spmimagetycoon/settings.toml</code> file.</li>
</ul>
