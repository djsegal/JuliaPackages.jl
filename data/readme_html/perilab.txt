<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features ⭐</h2><a id="user-content-features-" class="anchor" aria-label="Permalink: Features ⭐" href="#features-"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">🚀 <strong>Easy Installation</strong>: PeriLab's straightforward installation process makes it accessible for researchers and engineers without extensive computational expertise.</p>
</li>
<li>
<p dir="auto">✒️ <strong>Modularization</strong>: The software is designed with a modular architecture that allows users to easily integrate their own material and damage models.</p>
</li>
<li>
<p dir="auto">🎨 <strong>Formulations</strong>: Bond-based, bond-associated, as well as oridnary and non-ordinary state-based peridynamic formulations can be used with PeriLab.</p>
</li>
<li>
<p dir="auto">🔩 <strong>Material models</strong>: PeriLab supports various material models, such as elastic, plastic, and more, enabling simulation of complex materials and structures.</p>
</li>
<li>
<p dir="auto">🔨 <strong>Damage models</strong>: Damage models such as critical stretch or an energy based criterium are included to simulate different types of damage, such as crack propagation or delamination, in their peridynamic simulations.</p>
</li>
<li>
<p dir="auto">🔥 <strong>Additive Manufacturing</strong>: PeriLab supports additive manufacturing, allowing users to create custom additive models for their simulations.</p>
</li>
<li>
<p dir="auto">🧲 <strong>Multimodels</strong>: PeriLab supports multimodels simulations, combining different types of peridynamics and damage models to create a comprehensive simulation environment.</p>
</li>
<li>
<p dir="auto">⚡ <strong>MPI</strong>: PeriLab supports parallel computing using Message Passing Interface (MPI) technology to improve simulation performance on high-performance clusters.</p>
</li>
<li>
<p dir="auto">💻 <strong>HPC capabilities</strong>: PeriLab is designed for high-performance computing (HPC) environments, allowing users to run large-scale simulations efficiently.</p>
</li>
<li>
<p dir="auto">📤📥 <strong>Exodus Input/Output</strong>: PeriLab uses the Exodus II data format for input and output, enabling easy transfer of data between simulation tools.</p>
</li>
<li>
<p dir="auto">🧮 <strong>Abaqus Input</strong>: PeriLab supports Abaqus input files, allowing users to create custom Abaqus models for their simulations.</p>
</li>
<li>
<p dir="auto">➗ <strong>Bond filter</strong>: The bond filter feature allows users to apply specific conditions to the bonds between particles in a simulation, influencing their behavior and interaction with other particles.</p>
</li>
<li>
<p dir="auto">🔧 <strong>User specified Input/Output</strong>: PeriLab provides flexible options for users to specify custom input and output files, enabling easy data manipulation and analysis.</p>
</li>
<li>
<p dir="auto">🧪 <strong>Test Pipeline</strong>: The PeriLab Source Code will be tested in a test pipeline to ensure its correctness and performance.</p>
</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installing with Docker 🐳</h2><a id="user-content-installing-with-docker-" class="anchor" aria-label="Permalink: Installing with Docker 🐳" href="#installing-with-docker-"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To install PeriLab using the official Perihub/Perilab Docker image, follow these steps:</p>
<ol dir="auto">
<li>
<p dir="auto"><strong>Install Docker</strong>: Before you begin, ensure that you have Docker installed on your system. You can download and install Docker from the official website (<a href="https://www.docker.com/" rel="nofollow">https://www.docker.com/</a>). Make sure your system meets the minimum requirements for running Docker.</p>
</li>
<li>
<p dir="auto"><strong>Pull the Perihub/Perilab Docker image</strong>: Use the following command in a terminal or command prompt to pull the latest Perihub/Perilab Docker image from the Docker Hub repository:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker pull perihub/perilab"><pre>docker pull perihub/perilab</pre></div>
</li>
<li>
<p dir="auto"><strong>Run the Docker container</strong>: Once the image has been downloaded, create a new directory for your PeriLab simulations and navigate to it in the terminal or command prompt. Run the following command to start the Docker container:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker run -it --rm -v &lt;path_to_local_simulations_directory&gt;:/app/simulations perihub/perilab bash"><pre>docker run -it --rm -v <span class="pl-k">&lt;</span>path_to_local_simulations_directory<span class="pl-k">&gt;</span>:/app/simulations perihub/perilab bash</pre></div>
<p dir="auto">Replace <code>&lt;path_to_local_simulations_directory&gt;</code> with the absolute path to a local directory where you want to store your PeriLab simulations. This command will open a new terminal session inside the Docker container.</p>
</li>
</ol>
<p dir="auto">Now, you've successfully installed PeriLab using the official Perihub/Perilab Docker image. You can start running your own peridynamic simulations within the container.</p>
