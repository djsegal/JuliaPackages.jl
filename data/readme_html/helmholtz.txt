<p dir="auto">A package for defining and solving the Helmholtz equation using the shifted Laplacian multigrid solver.
This is done using the geometric MG version in Multigrid.jl.</p>
<p dir="auto">This package is used in the following paper for solving the Helmholtz equation for multiple right-hand-sides (see Section 4 and 5.3):</p>
<p dir="auto">Eran Treister and Eldad Haber, Full waveform inversion guided by travel time tomography, SIAM Journal on Scientific Computing, 39 (5), S587-S609, 2017.</p>

<p dir="auto">Also available in this package is the sub-package <code>ForwardHelmholtz.PointSourceADR</code> for the solution of the Helmholtz equation for a point source, as described in the paper:</p>
<p dir="auto">Eran Treister, Eldad Haber, A multigrid solver to the Helmholtz equation with a point source based on travel time and amplitude.</p>
<p dir="auto">To use this sub-package type <code>using Helmholtz.PointSorceADR</code>. This sub-package also requires the FactoredEikonalFastMarching package, which can be installed by <code>Pkg.clone("https://github.com/JuliaInv/FactoredEikonalFastMarching.jl","FactoredEikonalFastMarching")</code></p>
