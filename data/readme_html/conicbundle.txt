<p dir="auto">This repository contains Julia bindings of Christoph Helmberg's
<a href="https://www-user.tu-chemnitz.de/~helmberg/ConicBundle/Manual/index.html" rel="nofollow">ConicBundle</a>, version 1.a.2.
The source code itself is almost unchanged, but an additional set of export functions have been provided for a lot of the C++
interface.
It should be used in conjuction with my <a href="https://github.com/projekter/ConicBundle">GitHub clone</a>, which contains the
modifications necessary for these bindings. The binary artifacs are shipped with the Julia package.</p>
