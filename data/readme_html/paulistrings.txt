<p dir="auto">PauliStrings.jl is a Julia package for many-body quantum mechanics with Pauli string represented as binary integers (as in <a href="https://journals.aps.org/pra/abstract/10.1103/PhysRevA.68.042318" rel="nofollow">https://journals.aps.org/pra/abstract/10.1103/PhysRevA.68.042318</a>).
It is particularly adapted for running Lanczos, time evolving noisy systems and simulating spin systems on arbitrary graphs.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Truncate, Cutoff, Trim, Noise</h2><a id="user-content-truncate-cutoff-trim-noise" class="anchor" aria-label="Permalink: Truncate, Cutoff, Trim, Noise" href="#truncate-cutoff-trim-noise"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>ps.truncate(H,M)</code> removes Pauli strings longer than M (returns a new Operator)
<code>ps.cutoff(H,c)</code> removes Pauli strings with coeficient smaller than c in absolute value (returns a new Operator)
<code>ps.trim(H,N)</code> keeps the first N trings with higest weight (returns a new Operator)
<code>ps.prune(H,alpha)</code> keeps terms with probability 1-exp(-alpha*abs(c)) (returns a new Operator)</p>
<p dir="auto"><code>ps.add_noise(H,g)</code> adds depolarizing noise that make each strings decay like <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a89cb16e4c90b8c6bd615bab2daf66f5">$e^{gw}$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a89cb16e4c90b8c6bd615bab2daf66f5">$w$</math-renderer> is the lenght of the string. This is usefull when used with <code>trim</code> to keep the number of strings manageable during time evolution.</p>

<p dir="auto"><code>ps.rk4(H, O, dt; hbar=1, heisenberg=false)</code> performs a step of Runge Kutta and returns the new updated O(t+dt)</p>
<p dir="auto">H can be an Operator, or a function that takes a time and return an Operator. In case H is a function, a time also needs to be passed to <code>rk4(H, O, dt, t)</code>. O is an Observable or a density matrix to time evolve.
If evolving an observable in the heisenberg picture, set <code>heisenberg=true</code>.</p>
<p dir="auto">An example is in <code>time_evolve_example.jl</code>.
The following will time evolve O in the Heisenberg picture. At each step, we add depolarizing noise and trim the operator to keep the number of strings manageable</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function evolve(H, O, M, times, noise)
    dt = times[2]-times[1]
    for t in times
        O = ps.rk4(H, O, dt; heisenberg=true, M=M) #preform one step of rk4, keep only M strings
        O = ps.add_noise(O, noise*dt) #add depolarizingn noise
        O = ps.trim(O, M) # keep the M strings with the largest weight
    end
    return O
