<p dir="auto">If you have questions about Ferrite.jl you're welcome to reach out to us on the <a href="https://julialang.org/slack/" rel="nofollow">Julia
Slack</a> under <code>#ferrite-fem</code> or on <a href="https://julialang.zulipchat.com/" rel="nofollow">Zulip</a> under <code>#Ferrite.jl</code>.
Alternatively you can start a <a href="https://github.com/Ferrite-FEM/Ferrite.jl/discussions/new">new discussion</a> in the discussion forum on the
repository. Feel free to ask us even if you are not sure the problem is with Ferrite.jl.</p>
<p dir="auto">If you encounter what you think is a bug please report it, see
<a href="CONTRIBUTING.md#reporting-issues">CONTRIBUTING.md</a> for more information.</p>

<p dir="auto">The following registered packages are part of the <code>Ferrite.jl</code> ecosystem in addition to Ferrite itself:</p>
<ul dir="auto">
<li><a href="https://github.com/Ferrite-FEM/Tensors.jl">Tensors.jl</a>: Used throughout Ferrite for efficient tensor manipulation.</li>
<li><a href="https://github.com/Ferrite-FEM/FerriteViz.jl">FerriteViz.jl</a>: <a href="https://docs.makie.org/stable/" rel="nofollow">Makie.jl</a>-based visualization of Ferrite data.</li>
<li><a href="https://github.com/Ferrite-FEM/FerriteGmsh.jl">FerriteGmsh.jl</a>: Create, interact with, and import <a href="https://gmsh.info/" rel="nofollow">Gmsh</a> meshes into Ferrite.</li>
<li><a href="https://github.com/Ferrite-FEM/FerriteMeshParser.jl">FerriteMeshParser.jl</a>: Parse the mesh from Abaqus input files into a Ferrite mesh.</li>
</ul>
