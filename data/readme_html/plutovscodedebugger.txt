<p dir="auto">This package provides a very experimental connection between a Pluto Notebook
and the Debugger on a running VSCode instance (the VSCode instance must be
running on the same machine as the Pluto Server)</p>
<p dir="auto">To connect VSCode to Pluto and exploit the <code>@run</code> and <code>@enter</code> commands, follow the steps below:</p>
<ul dir="auto">
<li>Copy the julia code to connect an external REPL from your VSCode window by calling the VSCode command <code>Julia: Connect external REPL</code>.</li>
<li>Bring this package into the notebook scope by having a cell with <code>using PlutoVSCodeDebugger</code></li>
<li>Connect VSCode by calling the <code>@connect_vscode</code> macro by giving as an argument a <code>begin...end</code> block that contains the code pasted at point 1.</li>
</ul>

<p dir="auto">After succesfull connection you can directly start using the <code>@enter</code> and
<code>@run</code> macros inside your Pluto notebook.</p>
<p dir="auto">You can also use the exported <code>@vscedit</code> to jump at function definitions
in VSCode from the Pluto notebook for convenience of setting up breakpoints.
This function works similarly to the <code>@edit</code> macro from InteractiveUtils.</p>
<p dir="auto">Check the <a href="https://disberd.github.io/PlutoVSCodeDebugger.jl/" rel="nofollow">documentation</a> for more details on how to use this package.</p>
