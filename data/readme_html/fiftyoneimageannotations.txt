<p dir="auto">FiftyOneImageAnnotations provides a Julia interface to the <a href="https://voxel51.com/docs/fiftyone/" rel="nofollow">FiftyOne</a> toolkit, that enables curating datasets, evaluating models, finding annotation mistakes, visualizing embeddings etc.</p>

<p dir="auto">The embedded MongoDB process is left running after the Julia session is closed. Stop the process manually - or, preferable, <a href="https://docs.voxel51.com/user_guide/config.html#configuring-a-mongodb-connection" rel="nofollow">use an external MongoDB instance</a>.</p>
<p dir="auto">The MongoDB process <a href="https://www.mongodb.com/docs/manual/tutorial/manage-mongodb-processes/#use-kill" rel="nofollow">can be terminated</a> using:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="kill -3 `ps | grep fiftyone | grep -v service/main.py | grep mongod | cut -d &quot; &quot; -f 1`"><pre class="notranslate"><code>kill -3 `ps | grep fiftyone | grep -v service/main.py | grep mongod | cut -d " " -f 1`
</code></pre></div>
<p dir="auto">This is somewhat <strong>unsafe</strong>: The MongoDB documentation says that signal 2/INT should be used, but it seems 3/QUIT actually works.</p>
