<p dir="auto">We hope that eventually these three packages can evolve into a single one that is best at everything. Until then, we recommend <a href="https://github.com/JuliaEarth/CoordRefSystems.jl">CoordRefSystems</a> as the default choice due to its professional maintenance and long feature list, but we also warmly invite you to keep an eye on this package as a testbed for highly powerful and flexible coordinate arithmetic.</p>

<ul dir="auto">
<li>
<p dir="auto">Any reasonable coordinate conversion can be performed using the constructor of the target coordinate type.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; WebMercator(LatLon(0, 45)) # Convert surface coordinates

</li>
<li>

</li>
<li>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="X(y,z) = X(typeof(y)(z) + y) - X(z)"><pre><span class="pl-en">X</span>(y,z) <span class="pl-k">=</span> <span class="pl-c1">X</span>(<span class="pl-c1">typeof</span>(y)(z) <span class="pl-k">+</span> y) <span class="pl-k">-</span> <span class="pl-c1">X</span>(z)</pre></div>

<p dir="auto">Example: One degree latitude is about 110.5 km at the equator, but 111.7 km at the poles.</p>

<li>

<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">Computing distances</h5><a id="user-content-computing-distances" class="anchor" aria-label="Permalink: Computing distances" href="#computing-distances"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto"><code>tdist(x,y) = norm(SVector(ECEF(x) - ECEF(y)))</code> computes the straight-line distance between two points. The <code>t</code> in <code>tdist()</code> stands for "tunnel" since traveling along the path measured by <code>tdist()</code> typically requires tunneling through the earth. Like <code>ECEF()</code>, <code>tdist()</code> accepts an optional altitude which defaults to 0.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; tdist(EastNorth(0,0), EastNorth(3,0))  # Both altitudes default to 0

</code></pre></div>
</li>
<li>
<p dir="auto">We may add a function <code>sdist(x,y)</code> at some point to compute surface distance (also known as great-circle or geodesic distance).</p>
</li>
</ul>
