<p dir="auto"><code>TidierStrings.jl </code>is a 100% Julia implementation of the R stringr package.</p>
<p dir="auto"><code>TidierStrings.jl</code> has one main goal: to implement stringr's straightforward syntax and of ease of use for Julia users. While this package was developed to work seamlessly with <code>TidierData.jl</code> functions and macros, it also works independently as a standalone package.</p>

<p dir="auto">'str_detect()' checks if a pattern exists in a string. It takes a string and a pattern as arguments and returns a boolean indicating the presence of the pattern in the string. This can be used inside of <code>@filter</code>, <code>@mutate</code>, <code>if_else()</code> and <code>case_when()</code>. <code>str_detect</code> supports logical operators | and &amp;.
case_when() with filter() and str_detect()</p>
