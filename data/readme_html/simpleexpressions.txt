<p dir="auto">A <em>very</em> lightweight means to create callable functions using expressions. For more performant and advanced requirements see <a href="https://juliahub.com/ui/Packages/General/DynamicExpressions" rel="nofollow">DynamicExpressions</a> and <a href="https://juliahub.com/ui/Packages/General/SimpleExpressions" rel="nofollow">CallableExpressions</a>.</p>
<p dir="auto">The <a href="@ref"><code>@symbolic</code></a> macro, the lone export, can create a symbolic variable and optional symbolic parameter. When expressions are created with these variables, evaluation is deferred until the expression is called like a function. The expressions subtype <code>Function</code> so are intended to be useful with <code>Julia</code>'s higher-order functions.</p>
<p dir="auto">The expressions can be called as a univariate function, <code>u(x)</code>, a univariate function with parameter, <code>u(x, p)</code>, or as a bivariate function, <code>u(x,y)</code> (with <code>y</code> being a parameter). These are all typical calling patterns when a function is passed to a numeric routine. These calls substitute in for the symbolic value (and parameter) when not specified as <code>nothing</code>. (To substitute in for just the parameter, either <code>u(nothing, value)</code> <em>or</em> <code>u(:,value)</code>.)</p>
<p dir="auto">There are no performance claims, this package is all about convenience. Similar convenience is available in some form with <code>SymPy</code>, <code>SymEngine</code>, <code>Symbolics</code>, etc. As well, placeholder syntax is available in <code>Underscores.jl</code>, <code>Chain.jl</code>, <code>DataPipes.jl</code> etc., This package only has value in that it is very lightweight and, hopefully, intuitively simple.</p>
<p dir="auto">An extension is provided for functions in <code>SpecialFunctions</code>.</p>
<p dir="auto">An extension is provided for <code>TermInterface</code> which should allow the use of <code>Metatheory</code> to rewrite terms.</p>
<p dir="auto">An extension is provided for <code>AbstractTrees</code>.</p>
