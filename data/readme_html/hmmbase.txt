<p dir="auto">HMMBase is not maintained anymore. It will keep being available as a Julia package but we encourage existing and new users to migrate to <a href="https://github.com/gdalle/HiddenMarkovModels.jl">HiddenMarkovModels.jl</a> which offers a similar interface. For more information see <a href="https://discourse.julialang.org/t/ann-hiddenmarkovmodels-jl-when-did-hmms-get-so-fast/100191" rel="nofollow">HiddenMarkovModels.jl: when did HMMs get so fast?</a>.</p>

<p dir="auto">HMMBase provides a lightweight and efficient abstraction for hidden Markov models in Julia. Most HMMs libraries only support discrete (e.g. categorical) or Normal distributions. In contrast HMMBase builds upon <a href="https://github.com/JuliaStats/Distributions.jl">Distributions.jl</a> to support arbitrary univariate and multivariate distributions.<br>
See <a href="https://discourse.julialang.org/t/ann-hmmbase-jl-a-lightweight-and-efficient-hidden-markov-model-abstraction/21604" rel="nofollow">HMMBase.jl - A lightweight and efficient Hidden Markov Model abstraction</a> for more details on the motivation behind this package.</p>
<p align="center" dir="auto">
  <a target="_blank" rel="noopener noreferrer" href="/benchmark/benchmark_summary.png"><img src="/benchmark/benchmark_summary.png" width="640" style="max-width: 100%;"></a><br>
  <a href="/benchmark">Benchmark</a> of HMMBase against <a href="https://github.com/hmmlearn/hmmlearn">hmmlearn</a> and <a href="https://github.com/mattjj/pyhsmm">pyhsmm</a>.
</p>
<p dir="auto"><strong>Features:</strong></p>
<ul dir="auto">
<li>Supports any observation distributions conforming to the <a href="https://juliastats.org/Distributions.jl/latest/types/" rel="nofollow">Distribution</a> interface.</li>
<li>Fast and stable implementations of the forward/backward, EM (Baum-Welch) and Viterbi algorithms.</li>
</ul>
<p dir="auto"><strong>Non-features:</strong></p>
<ul dir="auto">
<li>Multi-sequences HMMs, see <a href="https://github.com/mmattocks/MS_HMMBase.jl">MS_HMMBase</a></li>
<li>Bayesian models, probabilistic programming, see <a href="https://github.com/TuringLang/Turing.jl">Turing</a></li>
<li>Nonparametric models (HDP-H(S)MM, ...)</li>
</ul>

<p dir="auto">Given a version number MAJOR.MINOR.PATCH, increment the:</p>
<ol dir="auto">
