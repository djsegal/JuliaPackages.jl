<p dir="auto">OptiFloat.jl rewrites floating point expressions to more accurate alternatives.
It is a pure <strong>Julia implementation of <a href="https://herbie.uwplse.org/" rel="nofollow">Herbie</a></strong>.
To learn more about what OptiFloat does, how to use it, and how it works check out the <a href="https://nmheim.github.io/OptiFloat.jl/" rel="nofollow"><strong>documentation</strong></a>.</p>

<p dir="auto"><code>OptiFloat.jl</code> is built on top of a number of great Julia packages. Most notably:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaSymbolics/Metatheory.jl"><code>Metatheory.jl</code></a> for everything related to expression rewriting &amp; simplification.</li>
<li><a href="https://github.com/SymbolicML/DynamicExpressions.jl"><code>DynamicExpressions.jl</code></a> for computing local errors of floating point expressions.</li>
<li><a href="https://github.com/JuliaIntervals/IntervalArithmetic.jl"><code>IntervalArithmetic.jl</code></a> to evaluate expressions on <code>Interval{BigFloat}</code> with arbitrary precision.</li>
</ul>
