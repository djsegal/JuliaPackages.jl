<p dir="auto">To use for example the mach number dependent model by <a href="https://arxiv.org/pdf/1212.3246.pdf" rel="nofollow">Kang &amp; Ryu (2013)</a>, combined with the shock obliquity model by <a href="http://arxiv.org/abs/1907.04300" rel="nofollow">Pais et. al. (2019)</a></p>

X_cr = 0.0         # X_cr = P_cr / P_th -&gt; in this case no pre-existing CRs

# magnetic field angle dependent acc. efficiency
ηB   = ηB_acc_p(θ_B)  

# Mach number dependent acc. efficiency
ηM   = η_Ms(ηM_model, Mach, X_cr)

# total efficiency
η_tot = ηB * ηM"><pre><span class="pl-k">using</span> DiffusiveShockAccelerationModels
