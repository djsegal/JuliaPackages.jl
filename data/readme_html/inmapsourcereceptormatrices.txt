<p dir="auto">Provides a julia interface to access the <strong>In</strong>tervention <strong>M</strong>odel for <strong>A</strong>ir <strong>P</strong>ollution (InMAP) <strong>S</strong>ource <strong>R</strong>eceptor <strong>M</strong>atrix (SRM).  Uses <a href="https://github.com/JuliaCloud/AWS.jl">AWS.jl</a> and <a href="https://github.com/JuliaIO/Zarr.jl">Zarr.jl</a> to access the compressed version of the matrix from <code>s3://inmap-model/isrm_v1.2.1.zarr/</code>.  Source-receptor matrices allow users to approximate an air quality model simulation without having to run a full air quality model simulation.</p>
<p dir="auto">For information about InMAP, see their website at <a href="https://inmap.run/" rel="nofollow"><code>https://inmap.run/</code></a>.</p>
