<p dir="auto"><code>SimulationBasedInference.jl</code> aims to bring together a variety of different methods for <em>simulation-based inference</em> (SBI), i.e. statistical inference with simulator-like models, in the Julia programming language. Although SBI can be applied to both Bayesian and Frequentist inference frameworks, this package focuses on the Bayesian approach.</p>
<p dir="auto">Please note that this package is still very much under construction and things may break or change without prior notice.</p>
<p dir="auto">If you would like to use this package in your work, please let us know by creating an issue on GitHub or sending an email to <a href="mailto:brian.groenke@awi.de">brian.groenke@awi.de</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Simulator-type models are ubiquitous in science and engineering.</p>
<p dir="auto">Most simulator-type models require some kind of input, e.g boundary conditions (forcings), physical properties or constants, etc.</p>
<p dir="auto">Often, these parameters are not fully known <em>a priori</em>... but usually we know something!</p>
<p dir="auto">Bayesian inference provides a natural framework for constraining this uncertainty using observed data:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$$
p(\boldsymbol{\theta} | \mathbf{y}) = \frac{p(\mathbf{y}|\boldsymbol{\theta})p(\boldsymbol{\theta})}{p(\mathbf{y})}
$$</math-renderer></p>
<p dir="auto">The <strong>posterior distribution</strong> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$p(\boldsymbol{\boldsymbol{\theta}} | \mathbf{y})$</math-renderer> represents our best estimate (with uncertainty) of the unknown parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\boldsymbol{\theta}$</math-renderer> after observing <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\mathbf{y}$</math-renderer>.</p>
<p dir="auto"><strong>Simulation-based inference</strong> (SBI) [1] refers to the problem of performing <strong>statistical inference</strong> (Bayesian or otherwise) of unknown parameters <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\boldsymbol{\theta}$</math-renderer> where the forward model <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\mathcal{M}$</math-renderer>:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$$
y = \mathcal{M}(\boldsymbol{\theta}) + \epsilon
$$</math-renderer></p>
<p dir="auto">is a dynamical model or physics-based <em>simulator</em> mapping from parameters to noisy (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\epsilon$</math-renderer>) observations.</p>
<p dir="auto">There are two fundamental challenges with this problem:</p>
<ol dir="auto">
<li>The forward model <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\mathcal{M}$</math-renderer> is very often <strong>nonlinear</strong> and typically has no closed-form solution.</li>
<li>Evaluating the forward map <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4f64c251fa5b00b1f662b603b14336af">$\mathcal{M}(\boldsymbol{\theta})$</math-renderer> is usually non-trivial, i.e. <strong>computationally expensive</strong> or at least inconvenient.</li>
</ol>
<p dir="auto">Thus, classical statistical methods that rely on either analytical or numerical methods to derive the posterior distribution are generally difficult (or impossible) to apply.</p>

<p dir="auto"><code>SimulationBasedInference</code> extends the basic <a href="https://docs.sciml.ai/SciMLBase/stable/interfaces/Problems/" rel="nofollow">SciML interface</a> to SBI problems.</p>
<p dir="auto">The first basic building block is <code>SimulatorForwardProblem</code>, which wraps either an arbitrary function <code>f(x)</code>, where <code>x</code> are the input parameters, or another <code>SciMLProblem</code>.</p>
<p dir="auto">The purpose of the <code>SimulatorForwardProblem</code> abstraction is to provide a general interface for defining observables and interacting with the simulator.</p>
<p dir="auto">To illustrate this, we start with the <a href="examples/linearode/linearode.jl">linear ODE example</a>. We first define an <code>ODEProblem</code> describing the dynamical model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ode_func(u,p,t) = -p[1]*u;
α_true = 0.2
ode_p = [α_true];
tspan = (0.0,10.0);
odeprob = ODEProblem(ode_func, [1.0], tspan, ode_p)"><pre><span class="pl-en">ode_func</span>(u,p,t) <span class="pl-k">=</span> <span class="pl-k">-</span>p[<span class="pl-c1">1</span>]<span class="pl-k">*</span>u;

ode_p <span class="pl-k">=</span> [α_true];
tspan <span class="pl-k">=</span> (<span class="pl-c1">0.0</span>,<span class="pl-c1">10.0</span>);
odeprob <span class="pl-k">=</span> <span class="pl-c1">ODEProblem</span>(ode_func, [<span class="pl-c1">1.0</span>], tspan, ode_p)</pre></div>
<p dir="auto">We can then define <em>observables</em> of the system which should be sampled over the course of the simulation. In this case, we will define a trivial observable that just returns the state of the ODE integrator:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="tsave = tspan[1]+0.1:0.2:tspan[end];

<p dir="auto">We are now ready to construct a forward problem from <code>odeprob</code> and <code>observable</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="forward_prob = SimulatorForwardProblem(odeprob, observable)"><pre>forward_prob <span class="pl-k">=</span> <span class="pl-c1">SimulatorForwardProblem</span>(odeprob, observable)</pre></div>
<p dir="auto">which can then be solved normally using the <code>solve</code> or <code>init</code> interface from SciML:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="forward_sol = solve(forward_prob, ode_solver);

<p dir="auto">For the purposes of demonstration, we construct artificial noisy observations from this forward solution:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="true_obs = get_observable(forward_sol, :y)
noisy_obs = true_obs .+ 0.05*randn(rng, n_obs);"><pre>true_obs <span class="pl-k">=</span> <span class="pl-c1">get_observable</span>(forward_sol, <span class="pl-c1">:y</span>)

<p dir="auto">The next step is defining a <code>SimulatorInferenceProblem</code>. We first define priors using <a href="https://juliastats.org/Distributions.jl/stable/" rel="nofollow">Distributions.jl</a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="model_prior = prior(α=Beta(2,2));
noise_scale_prior = prior(σ=Exponential(0.1));"><pre>model_prior <span class="pl-k">=</span> <span class="pl-c1">prior</span>(α<span class="pl-k">=</span><span class="pl-c1">Beta</span>(<span class="pl-c1">2</span>,<span class="pl-c1">2</span>));

<p dir="auto">then we assign a likelihood:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="lik = IsotropicGaussianLikelihood(observable, noisy_obs, noise_scale_prior);"><pre>lik <span class="pl-k">=</span> <span class="pl-c1">IsotropicGaussianLikelihood</span>(observable, noisy_obs, noise_scale_prior);</pre></div>
<p dir="auto">and finally construct the inference problem:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="inference_prob = SimulatorInferenceProblem(forward_prob, ode_solver, model_prior, lik);"><pre>inference_prob <span class="pl-k">=</span> <span class="pl-c1">SimulatorInferenceProblem</span>(forward_prob, ode_solver, model_prior, lik);</pre></div>
<p dir="auto">We can solve the inference problem with one of the simplest methods, <em>ensemble importance sampling</em>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const rng = Random.MersenneTwister(1234);
