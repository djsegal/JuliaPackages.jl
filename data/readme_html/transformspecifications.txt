<p dir="auto">TransformSpecifications.jl provides tools to define explicitly-specified transformation components. Such components can then be used to construct pipelines and DAGs that are themselves composed of individual explicitly-specified components. Additionally, they can be easily wrapped to catch and nicely handle both expected and unexpected specification and transformation violations.</p>

<p dir="auto">A <code>NoThrowDAG</code> facilitates composing multiple specified transforms (<code>DAGStep</code>s) into a <a href="https://en.wikipedia.org/wiki/Directed_acyclic_graph" rel="nofollow">DAG</a>, such that any errors errors encountered during the application of the DAG will be returned "nicely" (i.e., as a <code>NoThrowResult</code> object with the source of failure noted in the <code>violations</code> field) rather than thrown as an exception:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Legolas: @schema, @version

           var::String
       end

julia&gt; @version HoorayV1 begin
           var1::String
           var2::String
       end

julia&gt; fn_a(x::HuzzahV1) = HuzzahV1(; var=x.var * &quot;_a&quot;)
julia&gt; fn_b(x::HuzzahV1) = HuzzahV1(; var=x.var * &quot;_b&quot;)
julia&gt; fn_c(x::HoorayV1) = HuzzahV1(; var=x.var1 * x.var2 * &quot;_c&quot;)

# First, specify these functions as transforms: what is the specification of the
# function's input and output?
julia&gt; step_a_transform = NoThrowTransform(HuzzahV1, HuzzahV1, fn_a)
julia&gt; step_b_transform = NoThrowTransform(HuzzahV1, HuzzahV1, fn_b)
julia&gt; step_c_transform = NoThrowTransform(HoorayV1, HuzzahV1, fn_c)

# Next, set up the DAG between the upstream outputs into each step's input:
julia&gt; step_b_assembler = input_assembler(upstream -&gt; (; var=upstream[&quot;step_a&quot;][:var]))
julia&gt; step_c_assembler = input_assembler(upstream -&gt; (; var1=upstream[&quot;step_a&quot;][:var],
                                                       var2=upstream[&quot;step_b&quot;][:var]))

julia&gt; steps = [DAGStep(&quot;step_a&quot;, nothing, step_a_transform),
                DAGStep(&quot;step_b&quot;, step_b_assembler, step_b_transform),
