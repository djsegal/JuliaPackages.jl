<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Encoding BioSequences</h2><a id="user-content-encoding-biosequences" class="anchor" aria-label="Permalink: Encoding BioSequences" href="#encoding-biosequences"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides a simple and fast way to encode biological sequences into Voss representations. The main <code>struct</code> provided by this package is <code>VossEncoder</code> which is a wrapper of <code>BitMatrix</code> that encodes a biological sequence into a bit matrix and its corresponding alphabet. The following example shows how to encode a DNA sequence into a Voss matrix.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using BioSequences, BioVossEncoder
"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> BioSequences, BioVossEncoder
</pre></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; seq = dna&quot;ACGT&quot;

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Creating a Voss vector of a sequence</h2><a id="user-content-creating-a-voss-vector-of-a-sequence" class="anchor" aria-label="Permalink: Creating a Voss vector of a sequence" href="#creating-a-voss-vector-of-a-sequence"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Sometimes it proves to be useful to encode a sequence into a Voss vector representation (i.e a bit vector of the sequence from the corresponding molecule alphabet).</p>
<p dir="auto">This package provides a function <code>vossvector</code> that returns a Voss vector of a sequence given a <code>BioSequence</code> and the specific molecule (<code>BioSymbol</code>) that could be <code>DNA</code> or <code>AA</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; vossvector(seq, DNA_A)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">vossvector</span>(seq, DNA_A)</pre></div>

<p dir="auto">Note that the output is actually using behind the scenes a view of the <code>BitMatrix</code> representation of the sequence. This is done for performance reasons.</p>
