<p dir="auto">Welcome to <code>MuJoCo.jl</code>! This package contains a Julia wrapper for  DeepMind's general-purpose physics engine <a href="https://github.com/google-deepmind/mujoco">MuJoCo</a>, allowing users to simulate robotic systems, their controllers, and their interactions with surrounding environments, all in native Julia. Please visit our <a href="https://jamiemair.github.io/MuJoCo.jl/dev/" rel="nofollow">docs page</a> for more information.</p>

<p dir="auto">To install <code>MuJoCo.jl</code>, run the following code in a Julia REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg

<p dir="auto">This will download and install the package, along with the underlying C library. You should now be able to simulate MuJoCo models and visualise their motion. The following example loads a humanoid robot model and simulates its motion under passive or controlled dynamics through our in-built visualiser.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MuJoCo

# Load a model of a humanoid
model, data = MuJoCo.sample_model_and_data()

# Define a controller
function ctrl!(model, data)
    data.ctrl .= 2*rand(model.nu) .- 1
end

# Run the visualiser (press F1 for available options)
visualise!(model, data, controller=ctrl!)"><pre><span class="pl-k">using</span> MuJoCo
