<p dir="auto">A Julia wrapper for <a href="https://github.com/algoim/algoim">algoim</a>, providing algorithms for implicitly defined geometry, level set methods, and Voronoi implicit interface methods</p>
<p dir="auto"><strong>If you use this package, please cite algoim, according to the guidelines on the <a href="https://algoim.github.io" rel="nofollow">algoim Github page</a>.</strong></p>
<p dir="auto">This code wraps algoim's</p>
<ul dir="auto">
<li>high-order quadrature algorithms for domains implicitly-defined by multivariate polynomials and</li>
<li>high-order accurate algorithms for computing closest points on implicitly-defined surfaces.</li>
</ul>
<p dir="auto">When using the <strong>quadrature algorithms</strong>, please cite:</p>
<blockquote>
<p dir="auto"><a href="https://doi.org/10.1016/j.jcp.2021.110720" rel="nofollow">R. I. Saye, High-order quadrature on multi-component domains implicitly defined by multivariate polynomials, Journal of Computational Physics, 448, 110720 (2022).</a></p>
</blockquote>
<p dir="auto">When using the <strong>closest-point algorithms</strong>, please cite:</p>
<blockquote>
<p dir="auto"><a href="http://dx.doi.org/10.2140/camcos.2014.9.107" rel="nofollow">R. I. Saye, High-order methods for computing distances to implicitly defined surfaces, Communications in Applied Mathematics and Computational Science, 9(1), 107-141 (2014).</a></p>
</blockquote>
