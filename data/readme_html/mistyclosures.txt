<p dir="auto">Marginally less opaque closures.</p>
<p dir="auto">Specifically, a <code>MistyClosure</code> is comprises an <code>OpaqueClosure</code> paired with the <code>IRCode</code> that defines it.
This is useful if you generate an <code>OpaqueClosure</code>, and want to be able to retrieve the <code>IRCode</code> later on.</p>

<p dir="auto">Sometimes you'll already have an <code>OpaqueClosure</code> lying around, and not want to produce a new one from an <code>IRCode</code> (as this often takes a surprisingly large amount of time).
If ths is the case, you can simply use the default constructor for <code>MistyClosure</code>.
That is, write</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mc = MistyClosure(existing_opaque_closure, ir)"><pre>mc <span class="pl-k">=</span> <span class="pl-c1">MistyClosure</span>(existing_opaque_closure, ir)</pre></div>
<p dir="auto">Of course, it is <em>your</em> responsibility so ensure that <code>ir</code> and <code>existing_opaque_closure</code> are in agreement.</p>
