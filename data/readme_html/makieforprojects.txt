<p dir="auto">MakieForProjects.jl has two purposes:</p>
<ol dir="auto">
<li>Increase productivity when creating figures for (typically academic) papers or presentations within a self-contained project.</li>
<li>Provide beautiful themes that maximize clarity. Different themes can be used for different projects and one can easily switch between light and dark background themes.</li>
</ol>
<p dir="auto">You are more than welcomed to use this to benefit from the themes,
or the convenience functions within.
Feel free to contribute PRs adding your own themes or more convenience functions.</p>
<p dir="auto">Besides themeing, this package also provides several convenience functions
for accelerating writing code for creating a figure in a (typically academic) project.
Highlight is the <code>axesgrid</code>, <code>figuretitle!</code> and <code>label_axes!</code> functions.
MakieForProjects.jl also integrates with DrWatson and overloads <code>wsave</code> for <code>Makie.Figure</code> objects.</p>
<p dir="auto">For all other information, see the online docs.</p>
