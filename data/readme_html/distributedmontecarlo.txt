<p dir="auto">A Monte Carlo implementation in the julia language using <a href="https://docs.julialang.org/en/v1/stdlib/Distributed/" rel="nofollow">Distributed.jl</a> and <a href="https://github.com/baxmittens/AltInplaceOpsInterface.jl">AltInplaceOpsInterface.jl</a></p>
<p dir="auto">This code is rather slow. Its purpose is to be able to perform Monte Carlo analyses that, at one time, would not fit in main memory or where the snapshots need to be computed on distributed infrastructures.</p>
<p dir="auto"><a href="https://github.com/baxmittens/AltInplaceOpsInterface.jl">AltInplaceOpsInterface.jl</a> provides in-place operation for the Monte Carlo return type and is used due to compatibility to old julia code and could be replaced by implementing the proper <a href="https://docs.julialang.org/en/v1/manual/interfaces/" rel="nofollow">interface functions</a>. Any return type used with this package need to implement the AltInplaceOpsInterface.</p>
