<p dir="auto">This is a simple package to declare abstract types with default fields and their values in Julia. The idea of having this as base functionality is <a href="https://github.com/JuliaLang/julia/issues/4935" data-hovercard-type="issue" data-hovercard-url="/JuliaLang/julia/issues/4935/hovercard">somewhat disputed</a> in the Julia community. I just find it handy sometimes to have a family of types without copypasting blocks of field declarations around.</p>
<p dir="auto">The macro <code>@with_fields</code> defines an abstract type and its default fields.
It then creates another macro to declare subtypes of this abstract type. The default fields are appended to type-particular field definitions.</p>
