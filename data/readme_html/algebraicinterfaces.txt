<p dir="auto">AlgebraicInterfaces.jl exports common names for the methods extended by various
packages in the <a href="https://www.algebraicjulia.org/" rel="nofollow">AlgebraicJulia</a> ecosystem.<br>
Contains declarations for the following functions:</p>
<ul dir="auto">
<li>Categories: <code>dom</code>, <code>codom</code>, <code>compose</code>, <code>id</code>, <code>Ob</code>, <code>ob</code>, <code>Hom</code>, <code>hom</code></li>
<li>Monoidal: categories: <code>munit</code>, <code>mcompose</code></li>
<li>Operads: <code>ocompose</code>, <code>oapply</code></li>
<li>Attributed CSets: <code>attr</code>, <code>attrtypes</code></li>
<li>Generic functions: <code>generators</code>, <code>equations</code>, <code>getvalue</code></li>
</ul>
