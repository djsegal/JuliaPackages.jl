<p dir="auto">A Julia package to simulate multivariate time series, e.g. model-based ERPs, fMRI activity, pupil dilation etc.
UnfoldSim.jl provides multi-channel support via EEG-forward models. Moreover, it is possible to simulate overlapping event-related activity and to add noise of a certain type e.g. Pink noise.</p>
<p dir="auto">Many tutorials, guides, how-tos and references are available in the <a href="https://unfoldtoolbox.github.io/UnfoldSim.jl/dev/" rel="nofollow">documentation</a>!</p>

using Random

# Start by defining the design / events data frame

    SingleSubjectDesign(; conditions = Dict(:condA =&gt; [&quot;levelA&quot;, &quot;levelB&quot;])) |&gt;
    d -&gt; RepeatDesign(d, 10);
