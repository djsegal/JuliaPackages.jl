<p dir="auto">Oceanostics is a Julia package created to facilitate obtaining diagnostic quantities in
<a href="https://github.com/CliMA/Oceananigans.jl">Oceananigans</a> simulations. It was created solely as a
companion package to <a href="https://github.com/CliMA/Oceananigans.jl">Oceananigans</a>, so we refer users
first to the <a href="https://clima.github.io/OceananigansDocumentation/stable/" rel="nofollow">Oceananigans documentation</a>
before getting started with Oceanostics.</p>
