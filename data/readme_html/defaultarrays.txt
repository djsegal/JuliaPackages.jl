<p dir="auto">It can be used like any other common julia array:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="M=DefaultArray(0.0,100,100) #0.0 is the default value
M.=rand([zeros(50);1],100,100)

for i in eachnondefault(M)
    M[i]=rand()
end
Q=sin.(M)

sum(Q)  #-&gt;  some random value
length(Q.elements) #-&gt; MUCH less space occupied than 100*100 = 10000"><pre>M<span class="pl-k">=</span><span class="pl-c1">DefaultArray</span>(<span class="pl-c1">0.0</span>,<span class="pl-c1">100</span>,<span class="pl-c1">100</span>) <span class="pl-c"><span class="pl-c">#</span>0.0 is the default value</span>
