<p dir="auto">To build a surface for ray tracing, one may use:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using PolySignedDistance: RayTracing

surf = RayTracing.Surface(
    points, # matrix (ndims, npts)
    simplices; # matrix (ndims, nsimps)

    ray_reference = nothing,
    reference_isin = false,
    digits = 12
)
</code></pre></div>
<ul dir="auto">
<li><code>points</code> indicates surface points;</li>
<li><code>simplices</code> indicates simplices in the triangulated surface;</li>
<li><code>leaf_size</code> indicates a max. leaf size for the bounding box tree;</li>
<li><code>ray_reference</code> indicates a standard reference (origin) point for the ray tracing. Defaults to a point far away from the surface if <code>nothing</code>;</li>
<li><code>reference_isin</code>: whether said ray reference is within the surface;</li>
<li><code>digits</code>: number of digits for point merging precision. We advise the user not to change this.</li>
</ul>
