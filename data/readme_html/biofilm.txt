<ol dir="auto">
<li>Install Julia
<ul dir="auto">
<li>Follow instructions at <a href="https://julialang.org/" rel="nofollow">https://julialang.org/</a></li>
</ul>
</li>
<li>Add Biofilm.jl package
<ul dir="auto">
<li>Start Julia from the terminal using <code>&gt;&gt; julia</code></li>
<li>Add Biofilm.jl using <code>julia&gt; using Pkg; Pkg.add("Biofilm")</code>.  Note this will take many minutes to complete as many dependent packages will need to be downloaded and compiled.</li>
</ul>
</li>
<li>Run an example
<ul dir="auto">
<li>Download <a href="https://raw.githubusercontent.com/markowkes/Biofilm.jl/main/examples/Case1.jl" rel="nofollow">Case1.jl</a> by right clicking and choosing Save Link As. Save the file to your Downloads folder (or other location of your choice)</li>
<li>In the terminal, change the directory to the location you downloaded Case1.jl e.g., <code>&gt;&gt; cd ~/Downloads</code></li>
<li>Start Julia in that directory using <code>&gt;&gt; julia</code></li>
<li>Run the example using <code>julia&gt; include("Case1.jl")</code>.  Note that the first time you run this command it may take a long time since it needs to compile Biofilm.jl.</li>
</ul>
</li>
<li>Edit Case 1 or try other <a href="https://markowkes.github.io/Biofilm.jl/examples/" rel="nofollow">examples</a>.</li>
</ol>
<p dir="auto">More detailed <a href="https://markowkes.github.io/Biofilm.jl/installation" rel="nofollow">installation instructions</a> are available in the documentation.</p>
