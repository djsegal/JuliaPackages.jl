<p dir="auto">MicroTracker.jl is a feature-complete <a href="https://julialang.org/" rel="nofollow">Julia</a> package that tracks and analyzes moving <a href="https://www.nature.com/articles/s41467-020-19322-7" rel="nofollow">microbots</a> in microscopy video. This package tracks critical microbot metrics including size, velocity, and rotation rate. Combined with easy batch processing of videos, MicroTracker enables high-throughput analysis across multiple global experimental variables. For more information on microbots and this package, please see the short <a href="https://joss.theoj.org/papers/10.21105/joss.05804#" rel="nofollow">paper</a>.</p>

<p dir="auto">MicroTracker is built for collaboration and use across the microbot research field. To get started contributing and improving the package, see the <a href="https://czimm79.github.io/MicroTracker.jl/dev/settingupdev/" rel="nofollow">setup guide</a>. To report an issue, use the Issues tab 👆. Lastly, to seek support or discuss MicroTracker, please use the Discussions tab.</p>

<p dir="auto">Various components of MicroTracker have been used in scholarly works<sup><a href="#user-content-fn-1-214040de85b673392b5990511e246f57" id="user-content-fnref-1-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup><sup><a href="#user-content-fn-2-214040de85b673392b5990511e246f57" id="user-content-fnref-2-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup><sup><a href="#user-content-fn-3-214040de85b673392b5990511e246f57" id="user-content-fnref-3-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup><sup><a href="#user-content-fn-4-214040de85b673392b5990511e246f57" id="user-content-fnref-4-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">4</a></sup>. This package open sources, combines, and tests the tools written for microbot tracking as part of Coy Zimmermann's PhD thesis work 2018-2023 on magnetically propelled microwheels. This work was performed in the <a href="https://chemeng.mines.edu/project/marr-david/" rel="nofollow">Marr Group</a> at the Colorado School of Mines and with collaboration of the <a href="https://neeveslab.com/" rel="nofollow">Neeves Lab</a> at the University of Colorado Denver, Anschutz Medical Campus. MicroTracker uses and builds on work from colloidal science researchers<sup><a href="#user-content-fn-5-214040de85b673392b5990511e246f57" id="user-content-fnref-5-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">5</a></sup><sup><a href="#user-content-fn-6-214040de85b673392b5990511e246f57" id="user-content-fnref-6-214040de85b673392b5990511e246f57" data-footnote-ref="" aria-describedby="footnote-label">6</a></sup>.</p>
