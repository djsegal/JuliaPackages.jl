<ul dir="auto">
<li><strong>Object-oriented</strong>: <code>LimberJack.jl</code>  mimics <code>CCL.py</code> class structure by using <code>Julia</code>'s <code>structures</code>.</li>
<li><strong>Transparency</strong>: <code>LimberJack.jl</code>  is fully written in <code>Julia</code> without needing to inerface to any other programming language (<code>C</code>, <code>Python</code>...) to compute thoretical predictions. This allows the user full access to the code from input to output.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Goals</h2><a id="user-content-goals" class="anchor" aria-label="Permalink: Goals" href="#goals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><strong>Gradients</strong>: one order of magnitude faster gradients than finite differences.</li>
<li><strong>Precision</strong>: sub-percentage error with respect to <code>CCL</code>.</li>
<li><strong>Speed</strong>: <code>C</code>-like performance.</li>
</ul>

<p dir="auto">In order to run <code>LimberJack.jl</code> you will need <code>Julia-1.7.0</code> or newer installed in your system.
Older versions of <code>Julia</code> might be compatible but haven't been tested.
You can find instructions on how to install <code>Julia</code> here: <a href="https://julialang.org/downloads/" rel="nofollow">https://julialang.org/downloads/</a>.</p>
<p dir="auto">Once you have installed <code>Julia</code> you can install <code>LimberJack.jl</code> following these steps:</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Challenges</h2><a id="user-content-challenges" class="anchor" aria-label="Permalink: Challenges" href="#challenges"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol dir="auto">
<li>
<strong>Parallelization</strong>: the current threading parallelization of <code>LimberJack.jl</code> is far away from the optimal one over number of threads scaling. Future works could study alternative parallalization schemes or  possible inneficiencies in the code.</li>
<li>
<strong>GPU's</strong>: <code>LimberJack.jl</code> currently cannot run on GPU's which are known to significantly speed-up cosmological inference. Future works could study implementing <code>Julia</code> GPU libraries such as <code>CUDA.jl</code>.</li>
<li>
<strong>Backwards-AD</strong>: currently <code>LimberJack.jl</code>'s preferred AD mode is forward-AD. However, the key computation of cosmological inference, obtaining the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="675cdd6b8f92e7abb7276a1e87b03a51">$\chi^2$</math-renderer>, is a map from N parameters to a scalar. For a large number of parameters, backwards-AD is in theory the preferred AD mode and should significantly speed up the computation of the gradient. Future works could look into making <code>LimberJack.jl</code> compatible with the latest <code>Julia</code> AD libraries such as <code>Zygote.jl</code> to implement efficient backwards-AD.</li>
</ol>
