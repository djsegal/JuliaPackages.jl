<p dir="auto">Julia wrapper of the <a href="https://gloapi.gitkraken.com/v1/docs/#/" rel="nofollow">Glo-board API</a>.
Developer documentation is <a href="https://support.gitkraken.com/developers/overview/" rel="nofollow">here</a>.</p>
<p dir="auto">Endpoints become functions, if IDs are involved you have to wrap them in the corresponding ID type and pass them to the function.
POST methods take the post message as first argument, and DELETE methods take ! as first argument.
No names are exportet.</p>
