<p dir="auto"><a href="https://github.com/medyan-dev/MEDYANSimRunner.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/medyan-dev/MEDYANSimRunner.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">Manage long running restartable MEDYAN.jl simulations.</p>
<p dir="auto">Simulations run using julia code in a <code>main.jl</code> script and write outputs to an <code>output</code> directory.</p>
<p dir="auto">Inspired by how build scripts work in <a href="https://github.com/JuliaPackaging/BinaryBuilder.jl">https://github.com/JuliaPackaging/BinaryBuilder.jl</a></p>

<p dir="auto">A vector of jobs to run. Each job represents one variant of the simulation that can be run.
This is useful if many simulations need to be run in parallel. The <code>"--batch=&lt;job index&gt;"</code> argument
can be used to pick just one job to run.</p>
<p dir="auto">The selected <code>job</code> string gets passed to the <code>setup</code> function in <code>main.jl</code>.
The <code>job</code> string is also used to seed the default RNG right before <code>setup</code> is called.</p>
