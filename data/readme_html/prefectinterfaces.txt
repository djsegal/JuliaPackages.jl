<p dir="auto">This is a small package that helps you connect to a Prefect instance from a Julia process. This enables integrating your Julia code into your existing workflow orchestration managed by Prefect. Included in the package is a bootstrapped installation of a local Prefect instance, and an example <code>Dataset</code> type to demonstrate a concrete use-case.</p>
