<p dir="auto"><code>Copulas.jl</code> brings most standard <a href="https://en.wikipedia.org/wiki/Copula_(probability_theory)" rel="nofollow">copula</a> features into native Julia: random number generation, pdf and cdf, fitting, copula-based multivariate distributions through Sklar's theorem, etc. Since copulas are distribution functions, we fully comply with the <a href="https://github.com/JuliaStats/Distributions.jl"><code>Distributions.jl</code></a> API. This allows interoperability with the broader ecosystem, based on this API, such as, e.g., <a href="https://github.com/TuringLang/Turing.jl"><code>Turing.jl</code></a>.</p>
<p dir="auto">Usually, people that use and work with copulas turn to R, because of the amazing package <a href="https://cran.r-project.org/web/packages/copula/copula.pdf" rel="nofollow"><code>R::copula</code></a>. While well-maintained and regularly updated, <code>R::copula</code> is a mixture of obscure, heavily optimized <code>C</code> code and more standard <code>R</code> code, which makes it a complicated code base for readability, extensibility, reliability and maintenance.</p>
<p dir="auto">This is an attempt to provide a very light, fast, reliable and maintainable copula implementation in native Julia. One of the notable benefits of such a native implementation (among others) is the floating point type agnosticity, i.e. compatibility with <code>BigFloat</code>, <a href="https://github.com/JuliaMath/DoubleFloats.jl"><code>DoubleFloats</code></a>, <a href="https://github.com/dzhang314/MultiFloats.jl"><code>MultiFloats</code></a>, etc.</p>
<p dir="auto">The package revolves around two main types:</p>
<ul dir="auto">
<li><code>Copula</code>, an abstract mother type for all the copulas in the package</li>
<li><code>SklarDist</code>, a distribution type that allows construction of a multivariate distribution by specifying the copula and the marginals through <a href="https://en.wikipedia.org/wiki/Copula_(probability_theory)#Sklar's_theorem" rel="nofollow">Sklar's theorem</a>.</li>
</ul>
<p dir="auto"><strong>Warning: This is fairly experimental work, use with caution.</strong></p>

<p dir="auto">The API contains random number generation, cdf and pdf evaluation, and the <code>fit</code> function from <code>Distributions.jl</code>. A typical use case might look like this:</p>

D = SklarDist(C,(X₁,X₂,X₃)) # The final distribution

simu = rand(D,1000) # Generate a dataset

<p dir="auto">The list of availiable copula models is <em>very</em> large, check it out on our <a href="https://lrnv.github.io/Copulas.jl/stable" rel="nofollow">documentation</a> !</p>
<p dir="auto">The general implementation philosophy is for the code to follow the mathematical boundaries of the implemented concepts. For example, this is the only implementation we know (in any language) that allows for <strong>all</strong> Archimedean copulas to be sampled: we use the Williamson transformation for non-standard generators, including user-provided black-box ones.</p>

<p dir="auto">There are competing packages in Julia, such as <a href="https://github.com/AnderGray/BivariateCopulas.jl"><code>BivariateCopulas.jl</code></a> which only deals with a few models in bivariate settings but has very nice graphs, or <a href="https://github.com/iitis/DatagenCopulaBased.jl"><code>DatagenCopulaBased.jl</code></a>, which only provides sampling and does not have exactly the same models as <code>Copulas.jl</code>. While not fully covering out both of these package's functionality (mostly because the three projects chose different implementation paths), <code>Copulas.jl</code> brings, as a key feature, the compliance with the broader ecosystem.
