<p dir="auto">A basic transformer package. This repository is meant for learning and is paired with these blog posts:</p>
<ul dir="auto">
<li><a href="https://liorsinai.github.io/coding/2022/05/18/transformers.html" rel="nofollow">Transformers from first principles in Julia</a>.</li>
<li><a href="https://liorsinai.github.io/coding/2024/03/23/transformers-gpt.html" rel="nofollow">Generative transformer from first principles in Julia</a>.</li>
</ul>
<p dir="auto">For a much more comprehensive package with APIs for HuggingFace, optimizations and more, please see Transformers.jl at <a href="https://github.com/chengchingwen/Transformers.jl">github.com/chengchingwen/Transformers.jl</a>.</p>
<p dir="auto">This package is designed to work with <a href="https://github.com/FluxML/Flux.jl">Flux</a>. It implements multi-head attention as described in the paper <a href="https://arxiv.org/abs/1706.03762" rel="nofollow">Attention is all you need</a>.</p>
<p dir="auto">It comes with the following layers:</p>
<ul dir="auto">
<li><code>Indexer</code>: map tokens to indices.</li>
<li><code>PositionEncoding</code>: a fixed sinusodial layer as described in <a href="https://arxiv.org/abs/1706.03762" rel="nofollow">Attention is all you need</a> paper.</li>
<li><code>MultiHeadAttention</code>: similar to but differs from <code>Flux.MultiHeadAttention</code>.</li>
<li><code>MeanLayer</code></li>
<li><code>FlattenLayer</code></li>
<li><code>TransformerBlock</code>: this encompasses a <code>MultiHeadAttention</code> layer followed by a dense feed forward network, with dropout and normalization.</li>
</ul>
<p dir="auto">The <code>mul4d</code> function is provided for 4D batch multiplication such that <code>A×B</code> results in <code>C[:,:,k,l] == A[:,:,k,l] * B[:,:,k,l]</code>.
The same calculation can be done with <code>NNlib.batched_mul</code> which is at least 1.5× faster than <code>mul4d</code>.</p>
<p dir="auto">These layers can be used together with <code>Flux.Chain</code>. For convenience, the following models are also provided:</p>
<ul dir="auto">
<li><code>TransformerClassifier</code>: a transformer encoder followed by some aggregation layer (use <code>MeanLayer</code> or <code>Dense</code>), a <code>FlattenLayer</code> and a <code>Dense</code> layer for the head.</li>
<li><code>TransformerGenerator</code>: a transformer decoder with masking followed by a <code>Dense</code> layer for the head.</li>
</ul>
