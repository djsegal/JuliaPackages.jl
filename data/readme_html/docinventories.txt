<p dir="auto"><a href="https://github.com/JuliaDocs/DocInventories.jl#readme">DocInventories.jl</a> is a package for reading and writing inventory files such as the <code>objects.inv</code> file written by <a href="https://github.com/JuliaDocs/Documenter.jl">Documenter.jl</a> ≥ <code>v1.3.0</code> and <a href="https://www.sphinx-doc.org/en/master/" rel="nofollow">Sphinx</a>.</p>
<p dir="auto">These inventory files are used by <a href="https://github.com/JuliaDocs/DocumenterInterLinks.jl#readme">DocumenterInterLinks.jl</a> and <a href="https://www.sphinx-doc.org/en/master/usage/extensions/intersphinx.html" rel="nofollow">Intersphinx</a> to enable linking between the documentation of two projects.</p>
<p dir="auto">The <code>DocInventories</code> package also allows to convert the <code>objects.inv</code> format to an <code>inventory.toml</code> format that is designed to be human-readable and to allow maintaining custom inventories by hand.</p>

Sphinx originated the <code>objects.inv</code> inventory file format now also generated for Julia projects by <code>Documenter</code>.</li>
<li><a href="https://sphobjinv.readthedocs.io/en/stable/" rel="nofollow">sphobjinv</a> – The Python-equivalent of this project, allowing to read, explore and manipulate the data in <code>objects.inv</code> inventory file. Note that this does not include support for the <code>inventory.toml</code> format, which is unique to <code>DocInventories</code>.</li>
