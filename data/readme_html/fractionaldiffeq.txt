<p dir="auto">FractionalDiffEq.jl provides FDE solvers to <a href="https://diffeq.sciml.ai/dev/" rel="nofollow">DifferentialEquations.jl</a> ecosystem, including FODE(Fractional Ordinary Differential Equations), FDDE(Fractional Delay Differential Equations) and many more. There are many performant solvers available, capable of solving many kinds of fractional differential equations.</p>

<p dir="auto">FractionalDiffEq.jl is a powerful tool to solve a system of fractional differential equations, if you are familiar with <a href="https://github.com/SciML/DifferentialEquations.jl">DifferentialEquations.jl</a>, it would be just like out of the box.</p>
<p dir="auto">Let's see if we have a Chua chaos system:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="d04ce3b5f94ba2328c14308da7724156">$$ \begin{cases}D^{\alpha_1}x=10.725[y-1.7802x-[0.1927(|x+1|-|x-1|)]\\
D^{\alpha_2}y=x-y+z\\
D^{\alpha_3}z=-10.593y-0.268z\end{cases} $$</math-renderer></p>
<p dir="auto">By using the <code>NonLinearAlg</code> algorithms to solve this problem:</p>

    du[2] = x[1]-x[2]+x[3]
    du[3] = -b*x[2]-c*x[3]
end
