<p dir="auto">Microeconometric estimation in Julia.</p>
<p dir="auto">Currently supported estimators:</p>
<ul dir="auto">
<li>Linear regression
<ul dir="auto">
<li>Ordinary least squares</li>
<li>Two-stage least squares</li>
<li>Linear GMM</li>
</ul>
</li>
<li>Binary choice
<ul dir="auto">
<li>Logit</li>
<li>Probit</li>
<li>Complementary log-log</li>
<li>Gompit</li>
</ul>
</li>
<li>Count data
<ul dir="auto">
<li>Poisson</li>
<li>IV Poisson with additive errors</li>
<li>IV Poisson with multiplicative errors</li>
</ul>
</li>
<li>Reweighting methods
<ul dir="auto">
<li>Inverse probability weighting</li>
<li>Abadie (2003)</li>
<li>Frölich and Melly (2013)</li>
<li>Tan (2006)</li>
</ul>
</li>
</ul>
