<p dir="auto">This package contains routines to initialize reference element operators, physical mesh arrays, and connectivity arrays for nodal discontinuous Galerkin (DG) methods. The codes are roughly based on <em>Nodal Discontinuous Galerkin Methods</em> by Hesthaven and Warburton (2007). The original port from Matlab to Julia was by <a href="https://github.com/yiminllin">Yimin Lin</a>, with subsequent modifications by Jesse Chan and other contributors.</p>
<p dir="auto">This package is registered and can be installed via <code>] add StartUpDG</code> or <code>using Pkg; Pkg.add("StartUpDG")</code>.</p>

<p dir="auto">Variables are contained within structs <code>rd::RefElemData</code> and <code>md::MeshData</code>, which contain quantities from <code>Globals1D, Globals2D, Globals3D</code> in the Nodal DG book codes. These can be used to compute DG derivatives, and are useful for matrix-free implementations of DG methods using explicit time-stepping.</p>
