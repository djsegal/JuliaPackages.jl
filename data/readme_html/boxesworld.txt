<p dir="auto">A scalable MOMDP that mirrors a box-searching task for an item.
As a MOMDP, the agent will always know their <code>location</code> (represented by a <code>Point</code>), but
their belief will vary over the contents of the given boxes.</p>
<p dir="auto">Suppose that:</p>
<ul dir="auto">
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$B = \{ \text{Box(1, 5)}, \text{Box(5, 5)}, \text{Box(5, 1)} \}$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$L = \{ \text{Point(1, 1)}, \text{Point(1, 5)}, \text{Point(5, 5)}, \text{Point(5, 1)} \}$</math-renderer></li>
<li><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$I = \{ 🍋, 🍓, 🥝, 🍍 \}$</math-renderer></li>
</ul>
<p dir="auto"><strong>Note:</strong> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$\text{Point(1, 1)}$</math-renderer> is the spawn location.</p>
<ul dir="auto">
<li>Action space (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$\mathcal{A}$</math-renderer>): <code>[[Move(box) for box in B]..., Take()]</code>
<ul dir="auto">
<li>
<code>Move(box)</code> will move the agent from its current location to the targeted <code>box</code>.</li>
<li>
<code>Take()</code> will take the contents at the current box. At the spawn location, this is
an invalid action which does not transition to a new state.</li>
</ul>
</li>
<li>Observation space (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$\mathcal{O}$</math-renderer>): <code>[item for item in I]</code>
<ul dir="auto">
<li>
<p dir="auto"><code>item</code> only has the requirement that it's a <code>Symbol</code>. Thus, the agent may observe
whatever items you specify are allowed to be in the boxes.</p>
<p dir="auto"><strong>Note</strong> that <code>BoxesWorld</code> does not support items only being in certain boxes (e.g.,
lemons (🍋) are only allowed in odd-number boxes).</p>
</li>
</ul>
</li>
<li>State space (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$\mathcal{S}$</math-renderer>): Each state is a known location drawn from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$L$</math-renderer> and
potential box contents, drawn from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$I$</math-renderer> spread across the given boxes, thus there
are <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$|B|^{|I|}$</math-renderer> combinations of items <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$I$</math-renderer> in boxes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$B$</math-renderer>.
The state-space is always <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$|L| \times |B|^{|I|}$</math-renderer> where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$|L|$</math-renderer> is the number of locations, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$|B|$</math-renderer> is
the number of boxes, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1e84f18e9057ba6be948f62c381a388c">$|I|$</math-renderer> is the number of items.</li>
</ul>

<p dir="auto">Example code in <code>examples/boxes=3-fruits=🍋🍓🥝🍍</code></p>
<p dir="auto">The world is rotated by 45 degrees to accentuate costs, but is set in a 5x5 grid-like
world. Specifically, there are 3 boxes at <code>(1, 5)</code>, <code>(5, 5)</code>, and <code>(5, 1)</code>. Each box
may contain only one fruit, but collectively there may be any combination of fruits.</p>
<ul dir="auto">
<li>Action space: <code>[Move(1), Move(2), Move(3), Take()]</code></li>
<li>Observation space: <code>[:🍋, :🍓, :🥝, :🍍]</code></li>
<li>State space:</li>
</ul>

be modified so represent non-uniform initial beliefs!</p>

<p dir="auto">On the left, we have an agent in a 3-box world with a kiwi (🥝), lemon (🍋), and
strawberry (🍓) in boxes 1, 2, and 3, respectively. The agent cannot observe the
contents of the box until it visits the box.</p>
<p dir="auto">On the right, we have an agent in a similar world but with lemons (🍋) in boxes 1
and 2, and a kiwi (🥝) in box 3. The agent took actions <code>Move(2), Move(3), Take()</code>.
Thus, the agent observed a lemon (🍋) in Box 2, then a strawberry (🍓) in Box 3, and took the
strawberry (🍓) in Box 3.</p>
