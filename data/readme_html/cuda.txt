<p dir="auto">The CUDA.jl package is the main programming interface for working with NVIDIA CUDA GPUs
using Julia. It features a user-friendly array abstraction, a compiler for writing CUDA
kernels in Julia, and wrappers for various CUDA libraries.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quick start</h2><a id="user-content-quick-start" class="anchor" aria-label="Permalink: Quick start" href="#quick-start"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Before all, make sure you have a recent NVIDIA driver. On Windows, also make sure you have
the <a href="https://aka.ms/vs/16/release/vc_redist.x64.exe" rel="nofollow">Visual C++ redistributable</a> installed.
You do not need to install the CUDA Toolkit.</p>
<p dir="auto">CUDA.jl can be installed with the Julia package manager. From the Julia REPL, type <code>]</code> to
enter the Pkg REPL mode and run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add CUDA"><pre class="notranslate"><code>pkg&gt; add CUDA
</code></pre></div>
<p dir="auto">Or, equivalently, via the <code>Pkg</code> API:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add(&quot;CUDA&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>CUDA<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">For an overview of the CUDA toolchain in use, you can run the following command after
importing the package:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using CUDA

julia&gt; CUDA.versioninfo()"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> CUDA

julia<span class="pl-k">&gt;</span> CUDA<span class="pl-k">.</span><span class="pl-c1">versioninfo</span>()</pre></div>
<p dir="auto">This may take a while, as it will precompile the package and download a suitable version of
the CUDA toolkit. If your GPU is not fully supported, the above command (or any other
command that initializes the toolkit) will issue a warning.</p>
<p dir="auto">For more usage instructions and other information, please refer to <a href="https://juliagpu.github.io/CUDA.jl/stable/" rel="nofollow">the
documentation</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Requirements</h2><a id="user-content-requirements" class="anchor" aria-label="Permalink: Requirements" href="#requirements"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The latest development version of CUDA.jl requires <strong>Julia 1.10</strong> or higher. If you are
using an older version of Julia, you need to use a previous version of CUDA.jl. This will
happen automatically when you install the package using Julia's package manager.</p>
<p dir="auto">Note that CUDA.jl may not work with a custom build of Julia; it is recommended that you
install Julia using the <a href="https://julialang.org/downloads/" rel="nofollow">official binaries</a> or
<a href="https://github.com/JuliaLang/juliaup">juliaup</a>.</p>
<p dir="auto">The latest version of CUDA.jl also has certain requirements that cannot be enforced by the
package manager:</p>
<ul dir="auto">
<li>Host platform: only 64-bit Linux and Windows are supported;</li>
<li>Device hardware: only NVIDIA GPUs with <strong>compute capability 3.5</strong> (Kepler) or higher are
supported;</li>
<li>NVIDIA driver: a driver for <strong>CUDA 11.0</strong> or newer is required;</li>
<li>CUDA toolkit (in case you need to use your own): only <strong>CUDA toolkit 11.4</strong> or newer are
supported.</li>
</ul>
<p dir="auto">If you cannot meet these requirements, you may need to install an older version of CUDA.jl:</p>
<ul dir="auto">
<li>CUDA.jl v5.3 is the last version with support for PowerPC (removed in v5.4)</li>
<li>CUDA.jl v4.4 is the last version with support for CUDA 11.0-11.3 (deprecated in v5.0)</li>
<li>CUDA.jl v4.0 is the last version to work with CUDA 10.2 (removed in v4.1)</li>
<li>CUDA.jl v3.13 is the last version to work with CUDA 10.1 (removed in v4.0)</li>
<li>CUDA.jl v1.3 is the last version to work with CUDA 9-10.0 (removed in v2.0)</li>
</ul>
