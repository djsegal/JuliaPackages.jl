<p dir="auto">Julia package of reduced biquaternions.</p>
<p dir="auto"><a href="https://github.com/ivanslapnicar/RBiQuaternions.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/ivanslapnicar/RBiQuaternions.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">A reduced biquaternion <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$a \in\mathbb{Q}_\mathbb{R}$</math-renderer> can be uniquely expressed as</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$$
a = a_0 + a_1 \mathbf{i} + a_2 \mathbf{j} + a_3 \mathbf{k},$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$a_i \in \mathbb{R}$</math-renderer> for
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$i = 0, 1, 2, 3$</math-renderer>, and</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$$
\mathbf{i}^2 = \mathbf{k}^2 = −1,\quad \mathbf{j}^2 = 1,\quad
\mathbf{i}\mathbf{j} = \mathbf{j}\mathbf{i} = \mathbf{k},\quad
\mathbf{j}\mathbf{k} = \mathbf{k}\mathbf{j} = \mathbf{i},\quad
\mathbf{k}\mathbf{i} = \mathbf{i}\mathbf{k} = −\mathbf{j}.$$</math-renderer></p>
<p dir="auto">The absolute value of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$a$</math-renderer> is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$|a| = \sqrt{a^2_0 + a^2_1+a^2_2+a^2_3}$</math-renderer></p>
<p dir="auto">The conjugate of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$a$</math-renderer> is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$\bar{a}=a_0 - a_1 \mathbf{i} + a_2 \mathbf{j} - a_3 \mathbf{k}$</math-renderer>.</p>
<p dir="auto">Two basic singular (non-invertible) reduced biquaternions are</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="95f584cd48c16dce3d9303a5194fffec">$$
e_1=\frac{1}{2}+\frac{1}{2}\mathbf{j}\quad \textrm{and} \quad e_2=\frac{1}{2}+\frac{1}{2}\mathbf{j}.$$</math-renderer></p>
