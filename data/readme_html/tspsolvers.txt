<p dir="auto">A common interface to a few solvers for the Traveling Salesman Problem: <a href="https://github.com/chkwon/Concorde.jl">Concorde.jl</a>, <a href="https://github.com/chkwon/LKH.jl">LKH.jl</a>, <a href="https://github.com/evanfields/TravelingSalesmanHeuristics.jl">TravelingSalesmanHeuristics.jl</a>, and <a href="https://github.com/chkwon/Hygese.jl">Hygese.jl</a>.</p>
<p dir="auto">To install:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="] add TSPSolvers"><pre>] add TSPSolvers</pre></div>

<p dir="auto">The distance matrix M must be symmetric and integer-valued.
It can be asymmetric for the LKH solver only.
Note that the output <code>tour</code> does not repeat the first city at the end of the tour.</p>
<p dir="auto">Also supports the TSPLIB input:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="tour, tour_len = solve_tsp(&quot;gr17.tsp&quot;)"><pre>tour, tour_len <span class="pl-k">=</span> <span class="pl-c1">solve_tsp</span>(<span class="pl-s"><span class="pl-pds">"</span>gr17.tsp<span class="pl-pds">"</span></span>)</pre></div>
