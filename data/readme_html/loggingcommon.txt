<p dir="auto">Provides some definitions that are useful as the basis for creating a generic logging framework, slightly extending the types and methods introduced in <a href="https://docs.julialang.org/en/v1/stdlib/Logging/" rel="nofollow"><code>Base.Logging</code></a>.</p>

<p dir="auto">This package adds additional log level aliases to the standard ones from <code>Base.Logging</code>. In total, the available log levels are (in order) <code>NotSet</code>, <code>All</code>, <code>Trace</code>, <code>Debug</code>, <code>Info</code>, <code>Notice</code>, <code>Warn</code>, <code>Error</code>, <code>Critical</code>, <code>Alert</code>, <code>Emergency</code>, <code>Fatal</code>, <code>AboveMax</code>, and <code>Off</code>.</p>
<p dir="auto">These aliases can be represented as a <code>NamedLogLevel</code>, which maps a <code>Symbol</code> to a particular <code>Base.LogLevel</code> via the <code>log_level</code> function.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Log Records</h2><a id="user-content-log-records" class="anchor" aria-label="Permalink: Log Records" href="#log-records"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The generic <code>LogRecord</code> type represents a generic logging record. It contains both the record itself, as well as static + runtime metatdata associated to it. This type can be used in a generic logging framework, such as <a href="https://github.com/JuliaLogging/LoggingExtras.jl"><code>LoggingExtras</code></a>, to format log message outputs without extraneous logging boilerplate.</p>
<p dir="auto">Message records can be created via <code>message_log_record</code>, which associates a single <code>String</code> message to a log record. Stacktrace records can be created via <code>stacktrace_log_record</code>, which associates a <code>Base.StackTraces.StackTrace</code> (and an optional <code>Exception</code>) to a log record.</p>
<p dir="auto">For each log record, there are two types introduced representing metadata-values associated to a particular log record -- <code>StaticLogRecordMetadata</code> and <code>RuntimeLogRecordMetadata</code>. These types record log message information available at compile time (e.g., originating module, line number, etc., ) and at runtime (e.g., datetime, thread id, distributed worker id), respectively.</p>
