<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basics</h2><a id="user-content-basics" class="anchor" aria-label="Permalink: Basics" href="#basics"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A factor graph is a set of variable and factor vertices connected by edges.
In the spirit of <a href="https://github.com/stecrotti/IndexedGraphs.jl">IndexedGraphs.jl</a>, here each edge comes with an index, which can be used to access edge properties (e.g. messages in a message-passing algorithm).</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Graph construction</h3><a id="user-content-graph-construction" class="anchor" aria-label="Permalink: Graph construction" href="#graph-construction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A <code>FactorGraph</code> can be constructed starting from an adjacency matrix, with the convention that rows represent factor vertices and columns represent variable vertices</p>

<p dir="auto">Given a factor graph with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$N$</math-renderer> variables and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$M$</math-renderer> factors, variables are indexed by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$i\in{1,\ldots,N}$</math-renderer>, factors are indexed by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$a\in{1,\ldots,M}$</math-renderer>.
Properties of a vertex can be queried by wrapping the vertex index in a <code>variable</code> or <code>factor</code>. For example, the list of neighbors of variable <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$i=2$</math-renderer> is found by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ∂i = neighbors(g, variable(2));

julia&gt; collect(∂i)
2-element Vector{Int64}:
 1
 3"><pre>julia<span class="pl-k">&gt;</span> ∂i <span class="pl-k">=</span> <span class="pl-c1">neighbors</span>(g, <span class="pl-c1">variable</span>(<span class="pl-c1">2</span>));

julia<span class="pl-k">&gt;</span> <span class="pl-c1">collect</span>(∂i)
<span class="pl-c1">2</span><span class="pl-k">-</span>element Vector{Int64}<span class="pl-k">:</span>
 <span class="pl-c1">1</span>
 <span class="pl-c1">3</span></pre></div>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$1,3$</math-renderer> are to be interpreted as indices of factor vertices.</p>
<p dir="auto">The list of edges adjacent to factor <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="72ce228cfc0306dedfabb6f7d231c4a0">$a=1$</math-renderer> is found by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ea = inedges(g, factor(1));

julia&gt; collect(ea)
3-element Vector{IndexedGraphs.IndexedEdge{Int64}}:
 Indexed Edge 1 =&gt; 1 with index 1
 Indexed Edge 2 =&gt; 1 with index 2
 Indexed Edge 5 =&gt; 1 with index 6"><pre>julia<span class="pl-k">&gt;</span> ea <span class="pl-k">=</span> <span class="pl-c1">inedges</span>(g, <span class="pl-c1">factor</span>(<span class="pl-c1">1</span>));

julia<span class="pl-k">&gt;</span> <span class="pl-c1">collect</span>(ea)
<span class="pl-c1">3</span><span class="pl-k">-</span>element Vector{IndexedGraphs<span class="pl-k">.</span>IndexedEdge{Int64}}<span class="pl-k">:</span>
 Indexed Edge <span class="pl-c1">1</span> <span class="pl-k">=&gt;</span> <span class="pl-c1">1</span> with index <span class="pl-c1">1</span>
 Indexed Edge <span class="pl-c1">2</span> <span class="pl-k">=&gt;</span> <span class="pl-c1">1</span> with index <span class="pl-c1">2</span>
 Indexed Edge <span class="pl-c1">5</span> <span class="pl-k">=&gt;</span> <span class="pl-c1">1</span> with index <span class="pl-c1">6</span></pre></div>
