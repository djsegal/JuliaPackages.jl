<p dir="auto">Install via the package manager.</p>
<p dir="auto">Check out the <a href="https://jutho.github.io/TensorKit.jl/stable/man/tutorial/" rel="nofollow">tutorial</a> and the full <a href="https://jutho.github.io/TensorKit.jl/stable" rel="nofollow">documentation</a>.</p>
<p dir="auto">While most common symmetries are already shipped with TensorKit.jl, there exist several extensions: <a href="https://github.com/maartenvd/SUNRepresentations.jl">SUNRepresentations.jl</a> provides support for SU(N), while <a href="https://github.com/lkdvos/CategoryData.jl">CategoryData.jl</a> incorporates a large collection of <em>small</em> fusion categories.
Additionally, for libraries that implement tensor network algorithms on top of TensorKit.jl, check out <a href="https://github.com/maartenvd/MPSKit.jl">MPSKit.jl</a>, <a href="https://github.com/mhauru/MERAKit.jl">MERAKit.jl</a> and <a href="https://github.com/quantumghent/PEPSKit.jl">PEPSKit.jl</a>.</p>
