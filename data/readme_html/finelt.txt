<p dir="auto"><strong>This package is no longer maintained.  You might be interested in
<a href="https://github.com/billmclean/SimpleFiniteElements.jl">this newer replacement</a>.</strong></p>
<p dir="auto">A simple package for a first course in finite element methods.</p>
<p dir="auto">These Julia routines rely on <a href="http://geuz.org/gmsh/" rel="nofollow">Gmsh</a> for mesh generation and
visualization.  Please see the Quick Start Guide (under doc/) for
examples illustrating the use of FinElt.</p>
<p dir="auto">Note that FinElt supports only msh file format version 2.2 so you need
to use the <code>-format msh22</code> command-line option for <code>gmsh</code>.</p>
