<p dir="auto">This module contains utilities for interpolations of functions in the quantics TCI / quantics tensor train (QTT) format. It is a small wrapper around <a href="https://github.com/tensor4all/TensorCrossInterpolation.jl">TensorCrossInterpolation.jl</a> and <a href="https://github.com/tensor4all/QuanticsGrids.jl">QuanticsGrids.jl</a> with more convenient functionality intended to cover the most common use cases. For more advanced or unusual use cases, it is likely that you will need to rely on those two libraries directly.</p>

<p dir="auto"><em>This section only contains the bare minimum to get you started. More examples, including more advanced use cases, can be found in the <a href="https://tensor4all.github.io" rel="nofollow">the tensor4all website</a>. For a documentation of the API, see the <a href="https://tensor4all.github.io/QuanticsTCI.jl/dev/index.html" rel="nofollow">package documentation</a>.</em></p>
<p dir="auto">The easiest way to construct a quantics tensor train is the <code>quanticscrossinterpolate</code> function. For example, the function <code>f(x, y) = (cos(x) - cos(x - 2y)) * abs(x + y)</code> can be interpolated as follows.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using QuanticsTCI
f(x, y) = (cos(x) - cos(x - 2y)) * abs(x + y)
xvals = range(-6, 6; length=256)
yvals = range(-12, 12; length=256)
qtt, ranks, errors = quanticscrossinterpolate(Float64, f, [xvals, yvals]; tolerance=1e-8)"><pre><span class="pl-k">using</span> QuanticsTCI
<span class="pl-en">f</span>(x, y) <span class="pl-k">=</span> (<span class="pl-c1">cos</span>(x) <span class="pl-k">-</span> <span class="pl-c1">cos</span>(x <span class="pl-k">-</span> <span class="pl-c1">2</span>y)) <span class="pl-k">*</span> <span class="pl-c1">abs</span>(x <span class="pl-k">+</span> y)
xvals <span class="pl-k">=</span> <span class="pl-c1">range</span>(<span class="pl-k">-</span><span class="pl-c1">6</span>, <span class="pl-c1">6</span>; length<span class="pl-k">=</span><span class="pl-c1">256</span>)
yvals <span class="pl-k">=</span> <span class="pl-c1">range</span>(<span class="pl-k">-</span><span class="pl-c1">12</span>, <span class="pl-c1">12</span>; length<span class="pl-k">=</span><span class="pl-c1">256</span>)
qtt, ranks, errors <span class="pl-k">=</span> <span class="pl-c1">quanticscrossinterpolate</span>(Float64, f, [xvals, yvals]; tolerance<span class="pl-k">=</span><span class="pl-c1">1e-8</span>)</pre></div>
<p dir="auto">The output object <code>qtt</code> now represents a quantics tensor train. It can then be evaluated a function of indices enumerating the <code>xvals</code> and <code>yvals</code> arrays:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@show qttvalue = qtt(212, 92)
@show truevalue = f(xvals[212], yvals[92])
@show error = abs(qttvalue - truevalue)"><pre><span class="pl-c1">@show</span> qttvalue <span class="pl-k">=</span> <span class="pl-c1">qtt</span>(<span class="pl-c1">212</span>, <span class="pl-c1">92</span>)
<span class="pl-c1">@show</span> truevalue <span class="pl-k">=</span> <span class="pl-c1">f</span>(xvals[<span class="pl-c1">212</span>], yvals[<span class="pl-c1">92</span>])
<span class="pl-c1">@show</span> error <span class="pl-k">=</span> <span class="pl-c1">abs</span>(qttvalue <span class="pl-k">-</span> truevalue)</pre></div>
<p dir="auto">Output:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="qttvalue = qtt(212, 92) = -0.2525252152789011
truevalue = f(xvals[212], yvals[92]) = -0.2525252152789314
error = abs(qttvalue - truevalue) = 3.0309088572266774e-14"><pre class="notranslate"><code>qttvalue = qtt(212, 92) = -0.2525252152789011

<p dir="auto">The output shows that the approximation has an error of only <code>3 * 10^-14</code> at <code>[212, 92]</code>.</p>
