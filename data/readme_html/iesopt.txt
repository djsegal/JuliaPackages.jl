<p dir="auto"><strong>IESopt</strong> (<em>Integrated Energy System Optimization</em>) is a modeling and optimization framework for integrated energy
systems.</p>
<p dir="auto">It is developed and maintained at the <strong>Center for Energy</strong> at
<a href="https://www.ait.ac.at/" rel="nofollow">AIT Austrian Institute of Technology GmbH</a>. The framework is designed to support the
optimization of energy systems that are characterized by a high degree of integration between different energy carriers
and sectors. It focuses on offering a modular and adaptable tool for modelers, that does not compromise on performance,
while still being user-friendly. This is enabled by reducing energy system assets to abstract building blocks, that are
supported by specialized implementation, and can be combined into complex systems without the need of a detailed
understanding of mathematical modeling or proficiency in any coding-language.</p>

<p dir="auto">IESopt has been in development at AIT since 2021, and was moved to GitHub in June, 2024, based on a cleaned version with
slightly more than 1000 commits. IESopt has been applied in a variety of projects, ranging from small-scale energy
system optimization, to large-scale models spanning multiple sectors and regions. Check out the
<a href="https://ait-energy.github.io/IESopt.jl/dev/pages/references/" rel="nofollow">list of references</a> for more information.</p>

<p dir="auto">Make sure to check out the detailed <a href="https://ait-energy.github.io/IESopt.jl/dev/#Installation" rel="nofollow">installation guides</a>
in the documentation, both for Python and Julia. Depending on your use-case, and choice of programming language / setup,
there are different ways to get started. If you are experienced with Julia, and want to interact with the core model
itself, then using <code>IESopt.jl</code> directly will suit you best. If you are looking for a more user-friendly interaction, or
are new to energy system modeling and/or coding at all, you might want to check out the Python wrapper
<a href="https://github.com/ait-energy/iesopt-py">iesopt-py</a>.</p>

<p dir="auto">The basic workflow to get results from a model, defined by a top-level configuration file <code>config.iesopt.yaml</code>, is as
follows:</p>
<ol dir="auto">
<li>Parse, generate, and build the model from <code>config.iesopt.yaml</code>.</li>
<li>Optimize the model (the chose solver is specified in <code>config.iesopt.yaml</code>).</li>
<li>Get the results from the model.</li>
</ol>
<p dir="auto">Steps 1. and 2. can be combined in a single call, which the convenience function <code>run(...)</code> provides.</p>
