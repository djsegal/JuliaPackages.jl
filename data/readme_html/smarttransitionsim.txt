<p dir="auto">The framework was optimized in terms of performance. Major performance tweaks include:</p>
<ul dir="auto">
<li>Yen's algorithm is based on custom, fast A-star implementation - 5 times performance improvement over a standard Julia implementation,</li>
<li>routes calculated by the k-shortest paths algorithm are saved for future re-use (memoization technique) - leading to up to 15 times faster simulation execution in comparison to no-memoization,</li>
<li>simulations use common, separately generated agents pools - halved overall running time.</li>
</ul>
<p dir="auto">We have designed the simulation tool in such a way that the simulations can be executed in a distributed fashion. Additionally the simulation model has been adjusted to work with KissCluster software <a href="https://github.com/pszufe/KissCluster">KissCluster</a> that can be used to manage the distributed simulation execution and the data collection process in the Amazon Web Service cloud.</p>
