<p dir="auto"><a href="https://github.com/una-auxme/GraphNetCore.jl"><em>GraphNetCore.jl</em></a> is a software package for the Julia programming language that provides an the core functionality of the <a href="https://github.com/una-auxme/MeshGraphNets.jl"><em>MeshGraphNets.jl</em></a> package. Some parts are based on the implementation of the <a href="https://arxiv.org/abs/2010.03409" rel="nofollow">MeshGraphNets</a> framework by <a href="https://deepmind.google/" rel="nofollow">Google DeepMind</a> for simulating mesh-based physical systems via graph neural networks:</p>
<blockquote>
<p dir="auto">Tobias Pfaff, Meire Fortunato, Alvaro Sanchez-Gonzalez, and Peter W. Battaglia. 2021. <strong>Learning Mesh-Based Simulation with Graph Networks</strong>. In International Conference on Learning Representations.</p>
</blockquote>
