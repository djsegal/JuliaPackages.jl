<p dir="auto">Microstructure.jl is a Julia package for fast and probabilistic microstructure imaging. It features flexible and extendable compartment modeling with diffusion MRI and combined diffusion-relaxometry MRI and provides generic estimators including Markov Chain Monte Carlo (MCMC) sampling methods and Monte Carlo dropout with neural networks.</p>
<p dir="auto">Microstructure.jl is under active development, testing and optimization and updates will be shared throughout this process. You are welcome to try it out and provide feedback on any issues encountered. Microstructure.jl has a developing <a href="https://tinggong.github.io/Microstructure.jl/dev/" rel="nofollow">documentation website</a> introducing functional API and features of the package. More tutorials and recommendations will be coming soon.</p>
<p dir="auto"><strong>Updates!</strong> We have a <a href="https://arxiv.org/abs/2407.06379" rel="nofollow">preprint</a> if you are interested in knowing more:
Gong, T., &amp; Yendiki, A. (2024). Microstructure. jl: a Julia Package for Probabilistic Microstructure Model Fitting with Diffusion MRI. arXiv preprint arXiv:2407.06379.</p>

<p dir="auto">To install Microstructure.jl, open Julia and enter the package mode by typing <code>]</code>, then add the package:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ]
(@v1.8) pkg&gt; add Microstructure"><pre>julia<span class="pl-k">&gt;</span> ]
(<span class="pl-c1">@v1</span>.<span class="pl-c1">8</span>) pkg<span class="pl-k">&gt;</span> add Microstructure</pre></div>
<p dir="auto">You can check if your installation is the latest version by typing <code>status</code> in the package mode and upgrade to the latest version using <code>up</code> in the package mode:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="(@v1.8) pkg&gt; up Microstructure"><pre>(<span class="pl-c1">@v1</span>.<span class="pl-c1">8</span>) pkg<span class="pl-k">&gt;</span> up Microstructure</pre></div>

<p dir="auto">Microstructure.jl focuses on tissue microstructure estimation. If you are also interested in fiber orientation and tractography, please check out <a href="https://github.com/lincbrain/Fibers.jl">Fibers.jl</a>. Additional, Microstructure.jl uses I/O functions from Fibers.jl for reading and writing NIfTI image files.</p>
