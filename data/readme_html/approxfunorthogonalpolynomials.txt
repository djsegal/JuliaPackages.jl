<p dir="auto"><a href="https://github.com/JuliaApproximation/ApproxFun.jl">ApproxFun.jl</a> is a package for approximating functions. This package implements orthogonal polynomial based spaces to ApproxFun, including Chebyshev, Jacobi, Laguerre, and Hermite.</p>
