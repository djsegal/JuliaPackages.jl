<p dir="auto"><code>LuxAMDPU.jl</code> was used previously as a means to load <code>AMDGPU</code> specific extensions in
<code>Lux.jl</code>. However in most recent versions of <code>Lux.jl</code>, these functionalities can be
directly accessed by simply loading <code>AMDGPU.jl</code>. This package is now deprecated.</p>
<p dir="auto">To use the <code>LuxAMDGPU.functional()</code> functionality, use <code>MLDataDevices.functional(LuxAMDGPUDevice)</code>.</p>
<p dir="auto">If you are not using <code>LuxAMDGPU.jl</code> as a direct dependency, please consider
opening an issue on any packages you are using that do use it as a dependency.
From Julia 1.9 onwards, you can query <code>]why LuxAMDGPU</code> to figure out which
package originally brings it in as a dependency.</p>
</div>
<p dir="auto"><code>LuxAMDGPU</code> is meant to be used as a trigger package for all AMDGPU dependencies in <code>Lux</code>.
Users requiring AMDGPU support should install <code>LuxAMDGPU</code> and load it alongside <code>Lux</code>.</p>
