<p dir="auto">In Computer Adaptive Testing (CAT), examinees are given tailored tests which at
each stage present questions chosen to estimate their ability accurately, based
on a provisional estimate. For a brief introduction, see <a href="https://en.wikipedia.org/wiki/Computerized_adaptive_testing" rel="nofollow">the Wikipedia
page</a>.</p>
<p dir="auto">This package gives implementations of well-known approaches to CAT in Julia,
which are fast enough to support interactive use when scaling to large item
banks. It also provides flexible scaffolding to support new approaches to CAT
as well as non-standard item banks and difficulty-ability scales.</p>
<p dir="auto">For a more in-depth introduction to CATs, I recommend the following article
(which outlines the basic definitions before introducing and R package mirtCAT)
and book (which contains various topical chapters detailing different aspects
of CATs).</p>
<p dir="auto"><a href="https://doi.org/10.18637/JSS.V071.I05" rel="nofollow">Chalmers, R. P. (2016).
<em>Generating adaptive and non-adaptive test interfaces for multidimensional item
response theory applications.</em>
Journal of Statistical Software, 71, 1-38.</a></p>
<p dir="auto"><a href="https://doi.org/10.1007/978-0-387-85461-8" rel="nofollow">van der Linden, W. J. &amp; Glas C. A. W. (Eds.) (2010).
<em>Elements of adaptive testing.</em>
Statistics for Social and Behavioral Sciences.</a></p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How does this package differ from the alternatives?</h2><a id="user-content-how-does-this-package-differ-from-the-alternatives" class="anchor" aria-label="Permalink: How does this package differ from the alternatives?" href="#how-does-this-package-differ-from-the-alternatives"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The main (open source software library) alternatives are
<a href="https://cran.r-project.org/web/packages/catR/index.html" rel="nofollow">catR</a> and
<a href="https://cran.r-project.org/web/packages/mirtCAT/index.html" rel="nofollow">mirtCAT</a> in R and
<a href="https://github.com/douglasrizzo/catsim">catsim</a> in Python.</p>
<p dir="auto">Of these, mirtCAT is the most complete. At the moment, mirtCAT is more complete
than ComputerAdaptiveTesting.jl. However, this package is already beginning to
have some advantages in terms of flexibility:</p>
<ul dir="auto">
<li>Flexibility in allowing the lowest level "building blocks" of the algorithm,
namely optimization and integration algorithms to be freely configured and
replaced, allowing various levels of speed/accuracy trade off to be reached.</li>
<li>Flexibility in allowing a wide variety of item banks to be used. The
architecture supports (TODO: implement) for example, item banks with
parameter estimation uncertainties (e.g. from MCMC estimation) and item
banks with item banks based on hierarchical modelling.</li>
</ul>
<p dir="auto">There are two long term goals for the project. The first is to allow and
provide fast implementations of otherwise computationally heavy scenarios and
techniques such as those with large item banks, high dimensionality or many-ply
lookaheads. The second is composability with complimentary Julia packages to
allow for item banks based a wide variety of ways of mixing and matching
model-based and machine learning -based techniques to utilised for CATs and
evaluated in a CAT setting.</p>
