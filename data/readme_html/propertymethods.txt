<p dir="auto">PropertyMethods is a small package that allows one to add computed
properties to a struct by defining a <code>Val</code> specialized method for each
property.  Unrelated properties no longer need to be enumerated in the
conditioonal tree of a single <code>getproperty</code> method.</p>
<p dir="auto">Properties defined in this way will automatically be
recognized by the struct's <code>propertynames</code> and <code>hasproperty</code> methods.</p>
<p dir="auto">This mackage also provide a macro to generate trampoline methods for
the <em>Delegation</em> pattern.</p>
<p dir="auto">See the documentation linked above for details.</p>
