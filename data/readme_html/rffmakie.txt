<p dir="auto">Theming and color guidance for Resources for the Future comes from <a href="https://media.rff.org/documents/RFFDigitalBrand-Guidelines.pdf" rel="nofollow">here</a>.  This package exports <code>theme_rff</code> to be used with Makie using the <code>set_theme!</code> function.</p>

<p dir="auto">RFFMakie is a very simple package that re-exports Makie and CairoMakie (its publication quality backend).  RFFMakie defines colors and gives a theme called <code>theme_rff</code>.  To learn how to use Makie.jl, see the extensive <a href="https://docs.makie.org/stable/" rel="nofollow">Makie documentation</a>.</p>
