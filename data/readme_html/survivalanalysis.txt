<p dir="auto">Survival analysis interface in Julia, still very experimental. Tries to build on my R experience with <a href="https://github.com/mlr-org/mlr3proba">mlr3proba</a> and <a href="https://github.com/alan-turing-institute/distr6">distr6</a>.</p>

<ul dir="auto">
<li><a href="https://github.com/JuliaStats/Survival.jl">JuliaStats/Survival.jl</a> implements right-censored time-to-event types, Cox PH, Kaplan-Meier and Nelson-Aalen estimators. Last commit 2022.</li>
<li><a href="https://github.com/Testispuncher/Survival.jl">Testispuncher/Survival.jl</a> implements non-parametric estimators and some plots. Last commit 2017.</li>
<li><a href="https://github.com/kkholst/EventHistory.jl">kkholst/EventHistory.jl</a> implements different censoring and truncation types and Cox PH. Last commit 2018.</li>
</ul>
