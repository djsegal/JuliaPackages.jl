<p dir="auto">ShiftedProximalOperators is a library of proximal operators associated with proper
lower-semicontinuous functions such as those implemented in
<a href="https://github.com/JuliaFirstOrder/ProximalOperators.jl">ProximalOperators.jl</a>
for use in the algorithms implemented in <a href="https://github.com/JuliaSmoothOptimizers/RegularizedOptimization.jl">RegularizedOptimization.jl</a>.</p>
<p dir="auto">The main difference between the proximal operators implemented in
<a href="https://github.com/JuliaFirstOrder/ProximalOperators.jl">ProximalOperators.jl</a>
is that those implemented here involve a translation of the nonsmooth term.
Specifically, this package considers proximal operators defined as</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="argmin { ½ ‖t - q‖₂² + ν h(x + s + t) + χ(s + t; ΔB) | t ∈ ℝⁿ },"><pre class="notranslate"><code>argmin { ½ ‖t - q‖₂² + ν h(x + s + t) + χ(s + t; ΔB) | t ∈ ℝⁿ },
</code></pre></div>
<p dir="auto">where q is given, x and s are fixed shifts, h is the nonsmooth term with respect
to which we are computing the proximal operator, and χ(.; ΔB) is the indicator of
a ball of radius Δ defined by a certain norm.</p>
