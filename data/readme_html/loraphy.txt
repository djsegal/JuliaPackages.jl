<p dir="auto">This Julia package provides a comprehensive implementation of a LoRA (Long Range) Physical Layer (PHY) with Hamming encoding, interleaving, CSS modulation, and associated decoding algorithms. LoRA technology is known for its efficient long-range communication capabilities, making it ideal for IoT (Internet of Things) and other low-power, wide-area network applications.</p>

<p dir="auto">This creates a binary sequence, modulates with LoRa, and applies some additive white Gaussian noise. The Bit Error Rate can be deduced by calculating the number of differences between the emitted sequence and the received one.</p>
<p dir="auto">The important LoRa parameters are as follows:</p>
<ul dir="auto">
<li><code>SF</code> is the Spreading Factor as defined in the LoRa norm: a value between 7 and 12.</li>
<li><code>BW</code> is the bandwidth: The LoRa devices can use 125, 250, or 500kHz, but the LoRaWAN standard mandates 125k for data rates 1 to 5, and 250k for DR6</li>
<li><code>Fs</code> sampling frequency: this should be a multiple of <code>BW</code> (or Fs=BW to have no oversampling)</li>
</ul>

<p dir="auto">The output parameters are:</p>
<ul dir="auto">
<li><code>sig</code>: LoRa signal as a complex vector in the time domain.</li>
<li><code>bitSeq</code>: Binary sequence (info bits) used for generation (of size <code>N x SF</code>)</li>
<li><code>bitEnc</code>: Sequence of bits after Hamming74 encoding (of size <code>N / 4 x 7</code>)</li>
<li><code>bitInter</code>: Sequence of bits after Hamming74 encoding and interleaver (of size <code>N / 4 x 7</code>)</li>
</ul>
