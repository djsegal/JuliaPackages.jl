<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package is an implementation of Ulam's method <sup><a href="#user-content-fn-1-cb60718694d06bf6f6f89cb1666cfc4a" id="user-content-fnref-1-cb60718694d06bf6f6f89cb1666cfc4a" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup> <sup><a href="#user-content-fn-2-cb60718694d06bf6f6f89cb1666cfc4a" id="user-content-fnref-2-cb60718694d06bf6f6f89cb1666cfc4a" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup> (see also Galerkin projection <sup><a href="#user-content-fn-3-cb60718694d06bf6f6f89cb1666cfc4a" id="user-content-fnref-3-cb60718694d06bf6f6f89cb1666cfc4a" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup>) for the discretization of a stochastic operator using pure Julia. Given a set of one-step trajectories</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="cb60718694d06bf6f6f89cb1666cfc4a">$$\mathbf{x}_{0, 1} \to  \mathbf{x}_{T, 1}, \mathbf{x}_{0, 2} \to  \mathbf{x}_{T, 2} \dots$$</math-renderer>
<p dir="auto">defined in a subset of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cb60718694d06bf6f6f89cb1666cfc4a">$\mathbb{R}^N$</math-renderer>, the essential goal of Ulam's method is to partition the domain into a series of non-intersecting regions and construct a transition probability matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cb60718694d06bf6f6f89cb1666cfc4a">$P$</math-renderer> on these regions.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Features</h3><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Built on the <a href="https://github.com/JuliaGeometry/Meshes.jl">Meshes.jl</a> computational geometry framework.</li>
<li>Supports trajectory data in arbitrary dimensions.</li>
<li>Supports automatic boundary construction.</li>
<li>Multiple 2D algorithms for partitioning to triangles, rectangles, hexagons and adaptively sized <a href="https://en.wikipedia.org/wiki/Voronoi_diagram" rel="nofollow">Voronoi cells</a>.</li>
<li>Multiple stochasticization algorithms.</li>
<li>One-line plotting conveniences in 2D for easy visualization.</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Applying Ulam's method</h3><a id="user-content-applying-ulams-method" class="anchor" aria-label="Permalink: Applying Ulam's method" href="#applying-ulams-method"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The highest level function is</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ulam_method(traj, nbins; nirvana)"><pre><span class="pl-c1">ulam_method</span>(traj, nbins; nirvana)</pre></div>
<p dir="auto">where</p>
<ul dir="auto">
<li><code>traj</code>: A <code>Trajectories</code> object, holding the short-range trajectory data.</li>
<li><code>nbins</code>: The number of bins requested. When using this high-level convenience function, these will be uniform segements (1D), rectangles (2D) and hypercubes (≥3D).</li>
<li><code>nirvana</code>: The boundary of the bins will be set such that the fraction of data in nirvana<sup><a href="#user-content-fn-4-cb60718694d06bf6f6f89cb1666cfc4a" id="user-content-fnref-4-cb60718694d06bf6f6f89cb1666cfc4a" data-footnote-ref="" aria-describedby="footnote-label">4</a></sup> is equal to this value. In other words, a fraction <code>nirvana</code> of the data will be outside of the binned region.</li>
</ul>
<p dir="auto">In general, your trajectory data can be loaded simply as <code>traj = Trajectories(x0, xT)</code>, where <code>x0</code> and <code>xT</code> are <code>Dim x N</code> matrices such that <code>Dim</code> is the dimension of the data and <code>N</code> is the number of points. For testing, the function <code>Trajectories(Dim, N)</code> is provided that generates random trajectories automatically. We will generate <code>1000</code> trajectories in 2D and apply Ulam's method with <code>200</code> bins.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using UlamMethod
import Random; Random.seed!(1234) # reproducible randomness

traj = Trajectories(2, 1000)
ulam = ulam_method(traj, 200)"><pre><span class="pl-k">using</span> UlamMethod
<span class="pl-k">import</span> Random; Random<span class="pl-k">.</span><span class="pl-c1">seed!</span>(<span class="pl-c1">1234</span>) <span class="pl-c"><span class="pl-c">#</span> reproducible randomness</span>

traj <span class="pl-k">=</span> <span class="pl-c1">Trajectories</span>(<span class="pl-c1">2</span>, <span class="pl-c1">1000</span>)
ulam <span class="pl-k">=</span> <span class="pl-c1">ulam_method</span>(traj, <span class="pl-c1">200</span>)</pre></div>

<p dir="auto">After computing <code>ulam</code>, use the following functions:</p>
<ul dir="auto">
<li><code>P_closed(ulam)</code> gives the full transition probability matrix.</li>
<li><code>bins(ulam)</code> gives the bins and <code>points(bins(ulam))</code> gives their vertices.</li>
<li><code>membership(points, ulam)</code> returns the bin membership of a <code>Dim x n_points</code> matrix <code>points</code>.</li>
</ul>
