<p dir="auto">This repo is the starter kit for your replication study for the <a href="https://floswald.github.io/NumericalMethods/" rel="nofollow">Numerical Methods</a> course. Please check back with the requirements on the <a href="https://floswald.github.io/NumericalMethods/#term_project" rel="nofollow">course website</a>.</p>

<ol dir="auto">
<li>Make sure you have a working <code>git</code> setup on your computer and an active account on Github.com:
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="# type ; to go into shell mode

shell&gt; git config --global user.name
Florian Oswald

florian.oswald@gmail.com

# if those return nothing, set with

</code></pre></div>
</li>
<li>clone this repo to your computer. <em>clone</em>, not <em>fork</em>. Let's say you clone it into your home directory under the name <code>Replicate</code>, like so:
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="cd
git clone https://github.com/floswald/Replicate.jl Replicate"><pre class="notranslate"><code>cd
git clone https://github.com/floswald/Replicate.jl Replicate
</code></pre></div>
</li>
<li>choose a suitable name for your replication package. Some reference to the original author's/paper's name is probably a good idea. I will call it <code>your_package_name</code> for now.</li>
<li>Open <code>~/Replicate</code> in VScode</li>
<li>Do this:
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="] 
activate .
instantiate"><pre class="notranslate"><code>] 
activate .
instantiate
</code></pre></div>
</li>
<li>Then, back in julia command mode
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="include(&quot;template.jl&quot;)"><pre class="notranslate"><code>include("template.jl")
</code></pre></div>
</li>
<li>Create your template with
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="my_template = make_template(your_gh_user,your_location)"><pre class="notranslate"><code>my_template = make_template(your_gh_user,your_location)
</code></pre></div>
where <code>your_gh_user</code> is your github.com username and <code>your_location</code> is the directory on your computer where you want to create the new package (defaults to your home at <code>"~/"</code>). For example, I used it like so:
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; my_template = make_template(&quot;floswald&quot;, &quot;/Users/floswald/SomeFolder&quot;)"><pre class="notranslate"><code>julia&gt; my_template = make_template("floswald", "/Users/floswald/SomeFolder")
</code></pre></div>
</li>
<li>Choose your package name, and create it!
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="my_template(&quot;MyNewPackage&quot;)"><pre class="notranslate"><code>my_template("MyNewPackage")
</code></pre></div>
</li>

<li>You can <code>Cmd+click</code> on this 👆 filepath to start working on your new package now in VSCode!</li>
<li>Finally, you need to create a repository called <code>MyNewPackage.jl</code> (don't forget the <code>.jl</code>!) on <code>github.com</code>.</li>
<li>After that is done, you can immediately from the console of your new package do
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="git push -u origin main"><pre class="notranslate"><code>git push -u origin main
</code></pre></div>
(this works only if there are some commits to push.)</li>
<li>Notice that this will run your tests in <code>test</code> as well as build the package documentation from the doc strings you have added to your functions.</li>
<li>You need to tell the github repo to deploy the docs from the <code>gh-pages</code> branch. I did on this here <a href="https://github.com/floswald/MyNewPackage.jl/settings/pages">https://github.com/floswald/MyNewPackage.jl/settings/pages</a> (select <em>deploy from branch</em> and then select the <em>gh-pages</em> branch). You probably don't have access to that URL.</li>
<li>After a couple of minutes, you should be able to view your documentation online under your user space on github spaces, i.e. for me the repo looks like <a href="https://github.com/floswald/MyNewPackage.jl">this</a> and the docs look like <a href="https://floswald.github.io/MyNewPackage.jl/dev/" rel="nofollow">that</a>. Notice that only the <code>dev</code> version of the docs is deployed.</li>
