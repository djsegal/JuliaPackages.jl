<p dir="auto">PcoCameras is a Julia interface for PCO cameras.
This package is based on a experimental IO framework <a href="https://github.com/ehgus/ExternalDeviceIOs.jl">ExternalDeviceIOs.jl</a> and also offers direct access to low-level APIs of PCO cameras (PCO_SDK and PCO_Recorder).</p>
<p dir="auto">There are packages offering similar features:</p>
<ul dir="auto">
<li><a href="https://gitlab.com/mnkmr/Ionimaging.jl" rel="nofollow">Ionimaging.jl</a> is the first Julia package for PCO cameras. The following reasons have decided me to make this new package.
<ul dir="auto">
<li>It does not work with GigE PCO cameras.</li>
<li>It searches for cameras available when loading the package. It is time-consuming and unnecessary for some purposes.</li>
<li>Camera API should be implemented consistently.</li>
</ul>
</li>
<li><a href="https://pypi.org/project/pco/" rel="nofollow">pco</a> is a offical python package. <code>PcoCameras.jl</code>'s internal structure is similar to the Python package.</li>
</ul>

<p dir="auto">You need to pre-install pco.sdk and pco.recorder to use the package. The development kits are available on the <a href="https://www.pco-imaging.com/" rel="nofollow">PCO website</a>.
When installing the development kits, they should be installed system-wide for now.</p>
<p dir="auto">It additionally requires <code>ExternalDeviceIOs</code>.Therefore, to install this package, you should type</p>

<p dir="auto">The default library path is set supposing you install the recent Recorder library for all users.
You can check and change the path using <code>get_library_path</code> and <code>set_library_path!</code>.
The directory should contains 'sc2_cam.dll' and 'pco_recorder.dll'.</p>
