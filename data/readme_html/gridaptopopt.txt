<p dir="auto">GridapTopOpt is computational toolbox for level set-based topology optimisation implemented in Julia and the <a href="https://github.com/gridap/Gridap.jl">Gridap</a> package ecosystem. See the documentation and following publication for further details:</p>
<blockquote>
<p dir="auto">Zachary J. Wegert, Jordi Manyer, Connor Mallon, Santiago Badia, and Vivien J. Challis (2024). "GridapTopOpt.jl: A scalable Julia toolbox for level set-based topology optimisation". <a href="https://arxiv.org/abs/2405.10478" rel="nofollow">arXiv:2405.10478</a>.</p>
</blockquote>
