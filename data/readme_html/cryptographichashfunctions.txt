<p dir="auto">This package provides fast implementations of many <a href="https://en.wikipedia.org/wiki/Cryptographic_hash_function" rel="nofollow">cryptographic hash functions</a> for use in Julia.
Its high-level interface is designed to match the one of Julia's standard library package <a href="https://docs.julialang.org/en/v1/stdlib/SHA/" rel="nofollow">SHA</a>.
In particular, it can effortlessly replace <a href="https://github.com/JuliaCrypto/SHA.jl">SHA.jl</a> where performance is relevant.</p>

<p dir="auto">The supported hash functions and <a href="https://en.wikipedia.org/wiki/Extendable-output_function" rel="nofollow">extendable-output functions</a> (XOF) include:</p>
<ul dir="auto">
<li><a href="https://en.wikipedia.org/wiki/SHA-1" rel="nofollow">SHA-1</a></li>
<li><a href="https://en.wikipedia.org/wiki/SHA-2" rel="nofollow">SHA-2 family</a></li>
<li><a href="https://en.wikipedia.org/wiki/SHA-3" rel="nofollow">SHA-3 family</a></li>
<li><a href="https://en.wikipedia.org/wiki/MD2_(hash_function)" rel="nofollow">MD2</a></li>
<li><a href="https://en.wikipedia.org/wiki/MD4" rel="nofollow">MD4</a></li>
<li><a href="https://en.wikipedia.org/wiki/MD5" rel="nofollow">MD5</a></li>
<li><a href="https://en.wikipedia.org/wiki/RIPEMD" rel="nofollow">RIPEMD-160</a></li>
<li><a href="https://en.wikipedia.org/wiki/BLAKE_(hash_function)#BLAKE2" rel="nofollow">BLAKE2 family</a></li>
<li><a href="https://en.wikipedia.org/wiki/GOST_(hash_function)" rel="nofollow">GOST family</a></li>
<li><a href="https://en.wikipedia.org/wiki/SM3_(hash_function)" rel="nofollow">SM3</a></li>

<li><a href="https://en.wikipedia.org/wiki/Whirlpool_(hash_function)" rel="nofollow">WHIRLPOOL</a></li>
</ul>
