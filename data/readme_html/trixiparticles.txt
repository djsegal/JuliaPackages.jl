<p dir="auto"><strong>TrixiParticles.jl</strong> is a numerical simulation framework designed for particle-based numerical methods, with an emphasis on multiphysics applications, written in <a href="https://julialang.org" rel="nofollow">Julia</a>.
A primary goal of the framework is to be user-friendly for engineering, science, and educational purposes. In addition to its extensible design and optimized implementation, we prioritize the user experience, including installation, pre- and postprocessing.
Its features include:</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Incompressible Navier-Stokes
<ul dir="auto">
<li>Methods: Weakly Compressible Smoothed Particle Hydrodynamics (WCSPH), Entropically Damped Artificial Compressibility (EDAC)</li>
<li>Models: Surface Tension, Open Boundaries</li>
</ul>
</li>
<li>Solid-body mechanics
<ul dir="auto">
<li>Methods:  Total Lagrangian SPH (TLSPH), Discrete Element Method (DEM)</li>
</ul>
</li>
<li>Fluid-Structure Interaction</li>
<li>Particle sampling of complex geometries from <code>.stl</code> and <code>.asc</code> files.</li>
<li>Output formats:
<ul dir="auto">
<li>VTK</li>
</ul>
</li>
</ul>

<p dir="auto">If you have not yet installed Julia, please <a href="https://julialang.org/downloads/platform/" rel="nofollow">follow the instructions for your

<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; trixi_include(joinpath(examples_dir(), &quot;fluid&quot;, &quot;hydrostatic_water_column_2d.jl&quot;))"><pre lang="jldoctest" class="notranslate"><code>julia&gt; trixi_include(joinpath(examples_dir(), "fluid", "hydrostatic_water_column_2d.jl"))
