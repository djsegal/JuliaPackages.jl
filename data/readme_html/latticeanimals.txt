<p dir="auto">This packages generates random lattice animals (or sometimes called <a href="https://en.wikipedia.org/wiki/Polyform" rel="nofollow">polyforms</a>) from the standard percolation model using the <a href="https://en.wikipedia.org/wiki/Metropolis%E2%80%93Hastings_algorithm" rel="nofollow">Metropolis-Hasting</a> algorithm.</p>
<p dir="auto">The polyform is specified by its lattice basis matrix and a list of neighbours, where each entry is a linear combination of basis vectors leading to a neighbouring lattice point. So for example the square tesselation of the polyomino squares has the basis matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="74b0dc7c0942315f61b7baf4908616a3">$B$</math-renderer> and neighbours <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="74b0dc7c0942315f61b7baf4908616a3">$N$</math-renderer>:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="74b0dc7c0942315f61b7baf4908616a3">$$B = \begin{pmatrix}1 &amp; 0 \\0 &amp; 1 \end{pmatrix} \quad \quad \quad N = \left\{\begin{pmatrix}1 \\0 \end{pmatrix}, \begin{pmatrix}0 \\1 \end{pmatrix}, \begin{pmatrix}-1 \\0 \end{pmatrix}, \begin{pmatrix}0 \\-1 \end{pmatrix}\right\}$$</math-renderer>
<p dir="auto">The following functions are exported:</p>
<ul dir="auto">
<li>
<p dir="auto"><code>Poly(n, p, basis, neighbours)</code>: Generate a random polyform - specified in the basis-neighbours notation - of size n and percolation factor p</p>
</li>
<li>
<p dir="auto"><code>Polyomino(n, p)</code>: Generate a random polyomino of size n and percolation factor p</p>
</li>
<li>
<p dir="auto"><code>Polyhex(n, p)</code>: Generate a random polyhex of size n and percolation factor p</p>
</li>
<li>
<p dir="auto"><code>polyPlot(tiles, basis, path)</code>: Draw the polyform as a scatter plot and save to path</p>
</li>
<li>
<p dir="auto"><code>setDimension(d)</code>: Change the number of dimensions (default value: 2), a Julia restart is required afterwards</p>
</li>
</ul>
