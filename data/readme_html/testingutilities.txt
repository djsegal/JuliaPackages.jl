<p dir="auto"><code>TestingUtilities</code> provides macros for improving the visibility into your failing tests.</p>

<p dir="auto">The <code>@test_cases</code> macro allows you to compactly evaluate test expressions on test cases with the same underlying data fields, but differing values. The values of the specific test cases that cause each test expression to fail will be printed, similar to <code>@Test</code>.</p>
<p dir="auto">If run as a standalone macro invocation, the tests will terminate at the first instance of failure, e.g.,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @test_cases begin

<p dir="auto">The <code>@test_eventually</code> is used to test that a given test expression eventually returns true (i.e., passes within a prescribed timeout). You can use it to test, for instance, that blocking expressions eventually return within a given time limit or will throw a <code>TestTimedOutException</code> in your test set instead.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @testset &quot;Timing Out Test&quot; begin

        @test_eventually timeout=1s sleep=10ms f(done)
        
        # Test passes within the allotted timeout
        g = @async (sleep(0.3); done[] = true)

    end"><pre>    <span class="pl-c1">@testset</span> <span class="pl-s"><span class="pl-pds">"</span>Timing Out Test<span class="pl-pds">"</span></span> <span class="pl-k">begin</span>

<p dir="auto">If your test (using either of the above two macros) involves comparing the equality of two values <code>x::T</code> and <code>y::T</code>, if <code>T</code> is one of the types specified below, a failing test will show a nicely formatted message outlining the specific differences between them.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">String</h2><a id="user-content-string" class="anchor" aria-label="Permalink: String" href="#string"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
