<p dir="auto"><code>CellScopes.jl</code> is a toolkit built using the Julia programming language, designed for the analysis of single cell and spatial transcriptomic data. It offers a range of functionalities including data normalization, dimensional reduction, cell clustering and visualization, all tailored to various types of data generated by scRNA-seq, scATAC-seq, Visium, Xenium, Slide-seq, MERFISH, seqFISH, STARmap and Cartana. The current version of <code>CellScopes.jl</code> is structured as follows:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="https://github.com/HaojiaWu/CellScopes.jl/blob/main/data/CellScopes2.png"><img src="https://github.com/HaojiaWu/CellScopes.jl/raw/main/data/CellScopes2.png" width="1000" style="max-width: 100%;"></a> <br></p>

<p dir="auto">To install <code>CellScopes.jl</code>, you will need to have Julia 1.6 or higher installed. It is recommended to use Julia 1.7.3 or higher to avoid issues with dependencies. Here we will show how to install Julia in the Linux system.</p>
<p dir="auto">Assume you have access to the directory <code>/home/users/doe</code>. Here is how to install <code>Julia 1.7.3</code>.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="cd /home/users/doe/
wget https://julialang-s3.julialang.org/bin/linux/x64/1.7/julia-1.7.3-linux-x86_64.tar.gz
tar xvf julia-1.7.3-linux-x86_64.tar.gz"><pre><span class="pl-c1">cd</span> /home/users/doe/
wget https://julialang-s3.julialang.org/bin/linux/x64/1.7/julia-1.7.3-linux-x86_64.tar.gz

<p dir="auto">Then add Julia to PATH. Assume you have a <code>~/.bashrc</code> file, then append the following code to the end of the <code>~/.bashrc</code> file.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="export PATH=/home/users/doe/julia-1.7.3/bin:$PATH"><pre><span class="pl-k">export</span> PATH=/home/users/doe/julia-1.7.3/bin:<span class="pl-smi">$PATH</span></pre></div>

<p dir="auto"><strong>Note</strong>: If your operating system is Ubuntu 24.04, we recommend installing CellScopes with Julia 1.8.4. Earlier versions of Julia may not detect the 'libR.so' file when installing the <code>RCall</code> dependency.</p>
