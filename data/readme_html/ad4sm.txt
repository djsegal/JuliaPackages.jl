<p dir="auto"><em>Automatic Differentiation for Solid Mechanics in Julia</em></p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="/images/SpringFineMeshNHb.png"><img src="/images/SpringFineMeshNHb.png" height="280" style="max-width: 100%;"></a> <a target="_blank" rel="noopener noreferrer" href="/images/3DSpringFineMeshNHb.png"><img src="/images/3DSpringFineMeshNHb.png" height="300" style="max-width: 100%;"></a></p>
<p dir="auto">This repository implements an alternative approach for the derivation of the Finite Element Method for solid mechanics, which is based on obtaining the residual force vector and the tangent stiffness matrix directly as the gradient and the hessian of the free energy of the body.</p>
<p dir="auto">For any given configuration, the free energy of the body is evaluated by means of the same discretization of the traditional Finite Element approaches, by subdividing the domain into elements and using shape functions to interpolate the nodal values of the unknown fields onto the integration points.</p>
<p dir="auto">In the present implementation it is not necessary to explicitly evaluate the entries of the stress tensor or of the stiffness tensor, with significant complexity reduction in programming and debugging. In addition, since this approach is based entirely on the weak form of the equilibrium it is more general, and can also be used in the cases where not strong form of equilibrium is available.</p>
<p dir="auto">Also, this method accommodates all types of non-linearities—geometric, material, and constraint-based.</p>
<p dir="auto">Details on the theory behind this methodology can be found in:</p>
<p dir="auto"><a href="https://rdcu.be/b0yx2" rel="nofollow">Vigliotti A., Auricchio F., "Automatic differentiation for solid mechanics", Archives of Computational Methods in Engineering, 2020, In the press, DOI 10.1007/s11831-019-09396-y</a>.</p>
<p dir="auto">Preprint available <a href="https://arxiv.org/pdf/2001.07366" rel="nofollow">here</a>.</p>

<p dir="auto">This repository contains the following modules implementing an automatic differentiation system for the solution of solid mechanics problems in <a href="https://github.com/JuliaLang/julia">Julia</a>:</p>
<ul dir="auto">
<li>adiff.jl		is the module implementing the automatic differentitation system</li>
<li>materials.jl  is the module implementing the strain energy evaluation functions for the materials</li>
<li>elements.jl   is the module implementing the energy evaluation functions for the single elements and for the model, and the functions for solving a finite element problem</li>
</ul>
<p dir="auto">The implementation of the forward mode automatic differentiation of this package is based on the <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a> package. The essential difference in the implementation developed here is that the calculation of the entries of the Hessian is explicitly addressed taking advantage of its simmetry, with the consequent improvement in computational cost.</p>
<p dir="auto">The package can be installed from the Julia prompt as follows:</p>
