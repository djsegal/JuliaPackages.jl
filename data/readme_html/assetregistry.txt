<p dir="auto">AssetRegistry allows you to serve arbitrary files and
folders, using a global registry. Now packages like
<a href="https://github.com/JuliaWeb/Mux.jl"><code>Mux</code></a> and
<a href="https://github.com/JuliaLang/IJulia.jl"><code>IJulia</code></a> can
look up this registry and serve these files while
packages like <a href="https://github.com/JuliaGizmos/WebIO.jl"><code>WebIO</code></a>
and <a href="https://github.com/piever/InteractBase.jl"><code>InteractBase</code></a>
can register assets to be served to implement web-based UIs.</p>

<p dir="auto">You can register an asset with the package by doing:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="key = AssetRegistry.register(&quot;path/to/asset&quot;)"><pre>key <span class="pl-k">=</span> AssetRegistry<span class="pl-k">.</span><span class="pl-c1">register</span>(<span class="pl-s"><span class="pl-pds">"</span>path/to/asset<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">This <code>key</code> is the unique URL where the asset
can be accessed. For example:</p>
