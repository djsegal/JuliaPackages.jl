<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Term Frequency - Inverse Document Frequency (TF-IDF)</h2><a id="user-content-term-frequency---inverse-document-frequency-tf-idf" class="anchor" aria-label="Permalink: Term Frequency - Inverse Document Frequency (TF-IDF)" href="#term-frequency---inverse-document-frequency-tf-idf"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://github.com/LiorSinai/TermFrequencyInverseDocumentFrequency.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/LiorSinai/TermFrequencyInverseDocumentFrequency.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">A model based on term frequency and inverse document frequency.</p>
<ul dir="auto">
<li>Term frequency: number of times a term/word/token appears in a document.</li>
<li>Document frequency: 1 if appears in a document; 0 otherwise.</li>
</ul>
<p dir="auto">These are calculated per document and the results are stored in a <code>TermMatrix</code> where each column <code>j</code> is for a document, each row <code>i</code> is for a term, and <code>term_matrix[i, j]</code> is the number of times term <code>i</code> appears in document <code>j</code>. This is most commonly a sparse matrix so for efficiency it is represented in the <code>SparseMatrixCSC</code> format from <code>SparseArrays</code>.</p>
<p dir="auto">The document frequency is then <code>df=sum(term_matrix .&gt; 0, dims=2)</code>. The inverse document frequency is the reciprocal of this. Here it is also normalized and shifted by one: <code>idf=log.((1 + ndocuments)./(1 .+ df)) .+ 1</code>.</p>
<p dir="auto">These two values multiplied together give the TF-IDF: <code>term_matrix .* idf</code>. For efficiency, this calculation is not done using a broadcast but rather by iterating over the sparse matrix arrays. A model can then use the TF-IDF as the input feature.</p>
