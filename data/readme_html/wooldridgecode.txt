<p dir="auto">Julia code for <a href="https://www.cengage.uk/c/introductory-econometrics-a-modern-approach-7e-wooldridge/9781337558860/" rel="nofollow">"Introductory Econometrics" A Modern Approach", Seventh Edition</a> by Jeffrey M. Wooldridge</p>
<ul dir="auto">
<li>The code cover <em>Part 1: "Regression Analysis with Cross-Sectional Data"</em> of the book (chapters 1 to 9).</li>
<li>The code cover all examples, problems, and computer problems given in the book.</li>
<li>In the code the GLM.jl package is used.</li>
<li>The <em>init_example.jl</em> file contains helper functions that were needed to make the code complete
(getting data and functionalities currently missing in GLM.jl).</li>
<li>For each chapter a file called <em>chapter_XX.jl</em> is provided, where <em>XX</em> is chapter number.</li>
</ul>
<p dir="auto">The code were tested under Julia 1.9.2 and Project.toml/Manifest.toml configuration provided in this repository.</p>
<p dir="auto">When you run the code please consider that:</p>
<ul dir="auto">
<li>A project environment is properly activated in your Julia session
(it is simplest to do it by running <code>julia --project</code> in the folder where you downloaded this repository).</li>
<li>The code downloads source R files from <a href="https://github.com/JustinMShea/wooldridge">https://github.com/JustinMShea/wooldridge</a> and stores them in a working directory.</li>
<li>It is assumed that code for each chapter is executed in a separate Julia session sequentially
(i.e. there might be some variables defined in the code for a given chapter that are used in several places)</li>
</ul>
