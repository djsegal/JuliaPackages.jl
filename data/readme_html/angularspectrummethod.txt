<p dir="auto">This package provides the functions for diffraction calculations based on the angular spectrum method (ASM).
In addition to the standard diffraction calculation with ASM, various diffraction calculations with band-limited, scalable, scaled, shifted, and tilted ASM are available.
In-place versions of each function are also provided. When using the in-place version functions, append an <code>!</code> to the end of each function name.</p>

<p dir="auto">The function <code>ASM</code> returns the diffracted field by the angular spectrum method (ASM).
Evanescent waves are not eliminated but attenuated as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$\exp(-2{\pi}wz)$</math-renderer>.
Without attenuation, the total energy <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$\iint|u|\mathrm{d}x\mathrm{d}y$</math-renderer> is conserved.</p>

<p dir="auto">The function <code>ScalableASM</code> returns automatically scaled diffraction field by the scalable ASM (see Ref. 2).
The sampling pitch in the destination plane <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$\Delta_{d}$</math-renderer> is <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$\Delta_{d}=\dfrac{\lambda z}{pN\Delta_{s}}$</math-renderer>,
where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$\Delta_{s}$</math-renderer> is the sampling pitch in the source plane, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$N$</math-renderer> is the number of pixels in the source or destination plane, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$p=2$</math-renderer> is the padding factor.</p>

<p dir="auto">The function <code>TiltedASM</code> returns a tilted diffraction field for a rotation matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="af95db28897c6e1c6c2ea416544dbb65">$T$</math-renderer> by the tilted ASM (see Ref. 5, 6).
