<p dir="auto">A Julia port of <a href="https://pydantic-docs.helpmanual.io/" rel="nofollow">pydantic</a>.
Data validation and settings management <del>using python type annotations</del> just work in Julia with <a href="https://Roger-luo.github.io/Configurations.jl" rel="nofollow">Configurations</a>. Thus this package just provide you some convenient validation tools and some syntax sugars for defining validations.</p>
<p dir="auto">It reexports the interface of <code>Configurations</code>, thus you don't have to depend on <code>Configurations</code> explicitly. If you only need a lightweight setting/configuration/option definition without strict validation use <code>Configurations</code>.</p>
