<p dir="auto"><em>A 6DOF beam finite element model</em></p>
<p dir="auto">Author: Andrew Ning</p>
<p dir="auto">This is a finite element code for beam-like structures. The methodology uses Euler-Bernoulli beam elements with 6 degrees of freedom at each node (3 translation and 3 rotational). Structural properties can vary linearly across each element.  BeamFEA can estimate structural mass, deflections in all degrees of freedom, coupled natural frequencies, critical global axial buckling loads, and axial stress/strain. All inputs and outputs are given about the elastic center and in principal axes in order to remove cross-coupling terms.</p>
