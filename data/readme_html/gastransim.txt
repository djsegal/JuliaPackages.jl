<p dir="auto">This Julia package implements an explicit staggered grid method to perform forward simulation of the full transient gas flow dynamics in a pipeline network.
<code>GasTranSim.jl</code> is a registered Julia package and can be installed using</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;GasTransSim&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>GasTransSim<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">For usage, please refer to the documentation or the <code>examples/</code> and <code>test/</code> directories. The json schemas for the data with the validator is provided in the <code>schemas/</code> folder.</p>
