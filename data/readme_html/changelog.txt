<p dir="auto">The core idea of this package is to make it convenient to write changelog entries with
references to pull requests/issues and let Changelog.jl generate the full URLs.</p>
<p dir="auto">The typical workflow is as follows:</p>
<ol dir="auto">
<li>Write a changelog entry in the changelog file (e.g. <code>CHANGELOG.md</code>):
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="- Description of new feature with reference to pull request ([#123])."><pre class="notranslate"><code>- Description of new feature with reference to pull request ([#123]).
</code></pre></div>
</li>
<li>Run the command
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Changelog.generate(
    Changelog.CommonMark(),          # output type
    &quot;CHANGELOG.md&quot;;                  # input and output file
    repo = &quot;JuliaDocs/Changelog.jl&quot;, # default repository for links
)"><pre>Changelog<span class="pl-k">.</span><span class="pl-c1">generate</span>(
    Changelog<span class="pl-k">.</span><span class="pl-c1">CommonMark</span>(),          <span class="pl-c"><span class="pl-c">#</span> output type</span>
    <span class="pl-s"><span class="pl-pds">"</span>CHANGELOG.md<span class="pl-pds">"</span></span>;                  <span class="pl-c"><span class="pl-c">#</span> input and output file</span>
    repo <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>JuliaDocs/Changelog.jl<span class="pl-pds">"</span></span>, <span class="pl-c"><span class="pl-c">#</span> default repository for links</span>
)</pre></div>
This scans the input for link tokens, generates the full URLs, and inserts a link list at
the bottom. A tip is to add the command above as a Makefile target. The output would be
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="- Description of new feature with reference to pull request ([#123]).

&lt;!-- Links generated by Changelog.jl --&gt;
[#123]: https://github.com/JuliaDocs/Changelog.jl/issues/123"><pre class="notranslate"><code>- Description of new feature with reference to pull request ([#123]).

&lt;!-- Links generated by Changelog.jl --&gt;
[#123]: https://github.com/JuliaDocs/Changelog.jl/issues/123
</code></pre></div>
</li>
<li>Commit the result.</li>
<li>Run the following command to integrate the changelog into documentation built with
<a href="https://github.com/JuliaDocs/Documenter.jl">Documenter</a>:
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# In docs/make.jl, before makedocs(...)
Changelog.generate(
    Changelog.Documenter(),                 # output type
    joinpath(@__DIR__, &quot;../CHANGELOG.md&quot;),  # input file
    joinpath(@__DIR__, &quot;src/CHANGELOG.md&quot;); # output file
    repo = &quot;JuliaDocs/Changelog.jl&quot;,        # default repository for links
)"><pre><span class="pl-c"><span class="pl-c">#</span> In docs/make.jl, before makedocs(...)</span>
Changelog<span class="pl-k">.</span><span class="pl-c1">generate</span>(
    Changelog<span class="pl-k">.</span><span class="pl-c1">Documenter</span>(),                 <span class="pl-c"><span class="pl-c">#</span> output type</span>
    <span class="pl-c1">joinpath</span>(<span class="pl-c1">@__DIR__</span>, <span class="pl-s"><span class="pl-pds">"</span>../CHANGELOG.md<span class="pl-pds">"</span></span>),  <span class="pl-c"><span class="pl-c">#</span> input file</span>
    <span class="pl-c1">joinpath</span>(<span class="pl-c1">@__DIR__</span>, <span class="pl-s"><span class="pl-pds">"</span>src/CHANGELOG.md<span class="pl-pds">"</span></span>); <span class="pl-c"><span class="pl-c">#</span> output file</span>
    repo <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>JuliaDocs/Changelog.jl<span class="pl-pds">"</span></span>,        <span class="pl-c"><span class="pl-c">#</span> default repository for links</span>
)</pre></div>
The output in would be
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="- Description of new feature with reference to pull request
  ([#123](https://github.com/JuliaDocs/Changelog.jl/issues/123))."><pre class="notranslate"><code>- Description of new feature with reference to pull request
  ([#123](https://github.com/JuliaDocs/Changelog.jl/issues/123)).
</code></pre></div>
</li>
</ol>
