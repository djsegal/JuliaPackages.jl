<p dir="auto">OCTHaGOn (Optimal Classification Trees with Hyperplanes for Global Optimization) is a <a href="https://julialang.org/" rel="nofollow">Julia</a> package that allows for the solution of global optimization problems using mixed-integer (MI) linear and convex approximations. It is an implementation of the methods detailed in <a href="https://1ozturkbe.github.io/data/ozturk-bozturk-PhD-AeroAstro-2022-thesis.pdf" rel="nofollow">Chapter 2 of this thesis</a> and submitted to <em>Operations Research</em>. OCTHaGOn is licensed under <a href="https://github.com/1ozturkbe/OCTHaGOn.jl/blob/master/LICENSE">the MIT License</a>.</p>
<p dir="auto">OCTHaGOn leans on the <a href="https://github.com/jump-dev/JuMP.jl">JuMP.jl</a>
modeling language in its backend, and it develops MI approximations using
<a href="https://www.interpretable.ai/" rel="nofollow">Interpretable AI</a>, with a free academic license.
The problems can then be solved by JuMP-compatible solvers, depending on
the type of approximation. OCT's default solver in tests is <a href="https://www.ibm.com/analytics/cplex-optimizer" rel="nofollow">CPLEX</a>,
which is free with an academic license as well.</p>
<p dir="auto"><a href="https://1ozturkbe.github.io/OCTHaGOn.jl/" rel="nofollow">Documentation</a> is available and under development.<br>
If you have any burning questions or applications, or are having problems with OCTHaGOn, please <a href="https://github.com/1ozturkbe/OCTHaGOn.jl/issues">create an issue</a>!</p>
