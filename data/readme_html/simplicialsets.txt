<p dir="auto">This packages provides types and functions to work with simplicial sets. Various kinds
of simplicial sets are supported, including symbolic simplices, products,
bar constructions and Kan loop groups.
The Eilenberg–Zilber maps and interval cut operations are also implemented.</p>
<p dir="auto">The package uses <a href="https://github.com/matthias314/LinearCombinations.jl">LinearCombinations.jl</a>
to represent formal linear combinations of simplices. By default, coefficients are of type <code>Int</code>.</p>
<p dir="auto">The package comes with an extensive <a href="https://matthias314.github.io/SimplicialSets.jl/dev/" rel="nofollow">documentation</a>.</p>
