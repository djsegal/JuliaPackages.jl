<p dir="auto">This is a package for solving the "inverse problem" for multifrequency acoustic backscatter
in a Bayesian probabilistic framework. In other words, given observed echoes from
one or more types of scatterers, this package will help you infer 1) <strong>what</strong> they were,
2) <strong>how many</strong> of them were present, and 3) <strong>how sure</strong> you can be about (1) and (2). We
call this approach Automatic Probabilistic Echo Solving, or APES.</p>
<p dir="auto">Refer to the <a href="https://ElOceanografo.github.io/ProbabilisticEchoInversion.jl/stable/" rel="nofollow">documentation</a>
for more details on how to use the package. Several fully-worked examples on both simulated
and real fisheries acoustic data can also be found in the
<a href="https://github.com/ElOceanografo/APESExamples">APES Examples</a> repository.</p>
<p dir="auto">If you use this package in your own research, please cite the following publication:</p>
