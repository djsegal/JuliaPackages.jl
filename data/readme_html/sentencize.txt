<p dir="auto"><strong>Text to sentence splitter using a heuristic algorithm.</strong></p>
<p dir="auto">This module is a port of the <a href="https://github.com/berkmancenter/mediacloud-sentence-splitter">Python package <code>sentence-splitter</code></a>.</p>
<p dir="auto">The module allows the splitting of text paragraphs into sentences. It is based on scripts developed by Philipp Koehn and Josh Schroeder for processing the <a href="http://www.statmt.org/europarl/" rel="nofollow">Europarl corpus</a>.</p>

<p dir="auto">The module uses punctuation and capitalization clues to split plain text into a list of sentences :</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Sentencize
