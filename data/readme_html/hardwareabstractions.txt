<p dir="auto"><strong>Work in progress</strong></p>
<p dir="auto">An interface to communicate with hardware devices for the purposes of automatic control. This package does not do much itself other than defining the interface for other packages to implement.</p>
<p dir="auto">The interface is defined by <a href="https://github.com/baggepinnen/HardwareAbstractions.jl/blob/main/src/interface.jl"><code>interface.jl</code></a></p>

<p dir="auto">The package also contains some utilities for working with hardware devices and control loops, such as</p>
<ul dir="auto">
<li><code>@periodically</code>: Ensures that the body is run with an interval of <code>h &gt;= 0.001</code> seconds.</li>
<li><code>SysFilter</code>: Returns an object used for filtering signals through LTI systems.</li>
<li><code>rk4</code>: A Runge-Kutta 4 integrator.</li>
</ul>
