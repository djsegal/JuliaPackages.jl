<p dir="auto">IntervalTrees provides the type: <code>IntervalTree{K, V}</code>.
It implements an associative container mapping <code>(K, K)</code> pairs to to values of type <code>V</code>.
<code>K</code> may be any ordered type, but only pairs <code>(a, b)</code> where <code>a ≤ b</code> can be stored.
In other words they are associative contains that map intervals to values.</p>

<p dir="auto">You can install the IntervalTrees package from the <a href="https://docs.julialang.org/en/v1/manual/getting-started/" rel="nofollow">Julia REPL</a>.
Press <code>]</code> to enter <a href="https://docs.julialang.org/en/v1/stdlib/Pkg/" rel="nofollow">pkg mode</a>, then enter the following command:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="add IntervalTrees"><pre>add IntervalTrees</pre></div>
<p dir="auto">If you are interested in the cutting edge of the development, please check out the <a href="https://github.com/BioJulia/IntervalTrees.jl/tree/master">master branch</a> to try new features before release.</p>
