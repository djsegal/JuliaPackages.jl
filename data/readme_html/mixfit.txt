<p dir="auto">MixFit.jl is a Julia package for fitting finite mixture models, and for nonparametric density estimation via finite mixture models (<a href="https://doi.org/10.1177/1471082X1001200104" rel="nofollow">Wang &amp; Chee, 2012</a>).  Models are fitted using random-swap expectation maximization (<a href="https://doi.org/10.1016/j.patrec.2012.06.017" rel="nofollow">Zhao, Hautamäki, Kärkkäinen, &amp; Fränti, 2012</a>), which avoids the problem of local optimums by randomly replacing components and using the final maximum.  By default, MixFit.jl supports normal, gamma, lognormal, and gumbel mixtures, but it is easy to use your own density function instead.  If you use this, it <em>would be nice</em> if you cited me, but I'm putting it under public domain so you can do whatever you want with it.</p>
