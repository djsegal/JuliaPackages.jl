<p dir="auto">SimulationParameters.jl provides handing of hierarchical input simulation parameters</p>
<ul dir="auto">
<li>enforcing type</li>
<li>with descriptions</li>
<li>with units</li>
<li>with checks</li>
</ul>
<p dir="auto">There are three key abstract parameters types:</p>
<ul dir="auto">
<li><code>AbstractParameters</code> define hierarchical containers (think of dictionaries)</li>
<li><code>AbstractParametersVector</code> hold arrays of hierarchical containers</li>
<li><code>AbstractParameter</code> hold individual parameters</li>
</ul>
<p dir="auto">There are two concrete types of <code>AbstractParameter</code>:</p>
<ul dir="auto">
<li><code>Entry</code> where the value can be set by the user</li>
<li><code>Switch</code> which allows users to select from a limited se of <code>SwitchOption</code>s</li>
</ul>
<p dir="auto">Both <code>Entry</code> and <code>Switch</code> support the definition of ranges/functions that can be used by optimizers to vary values for each of the parameters.</p>
