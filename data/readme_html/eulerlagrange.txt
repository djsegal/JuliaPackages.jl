<p dir="auto">This package generates code for the Euler-Lagrange equations as well as Hamilton's equations for <a href="https://github.com/JuliaGNI/GeometricIntegrators.jl">GeometricIntegrators.jl</a> and related packages.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basic usage</h2><a id="user-content-basic-usage" class="anchor" aria-label="Permalink: Basic usage" href="#basic-usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Using EulerLagrange.jl is very simple and typically consists of four to five steps:</p>
<ol dir="auto">
<li>Obtain symbolic variables for a Lagrangian or Hamiltonian system of a given dimension.</li>
<li>Obtain a symbolic representation of the parameters of the system if it has any.</li>
<li>Build the Lagrangian or Hamiltonian using those symbolic variables and parameters.</li>
<li>Construct a <code>LagrangianSystem</code> or <code>HamiltonianSystem</code>, which is where the actual code generation happens.</li>
<li>Generate a <code>LODEProblem</code> or <code>HODEProblem</code> that can then be solved with <a href="https://github.com/JuliaGNI/GeometricIntegrators.jl">GeometricIntegrators.jl</a>.</li>
</ol>
<p dir="auto">In the following, we showcase this procedure for a particle in a square potential.</p>
<p dir="auto">Before any use, we need to load <code>EulerLagrange</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using EulerLagrange"><pre><span class="pl-k">using</span> EulerLagrange</pre></div>
<p dir="auto">Next, we generate symbolic variables for a one-dimensional system:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="t, x, v = lagrangian_variables(1)"><pre>t, x, v <span class="pl-k">=</span> <span class="pl-c1">lagrangian_variables</span>(<span class="pl-c1">1</span>)</pre></div>
<p dir="auto">With those variables, we can construct a Lagrangian</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="L = v ⋅ v / 2 - x ⋅ x / 2"><pre>L <span class="pl-k">=</span> v <span class="pl-k">⋅</span> v <span class="pl-k">/</span> <span class="pl-c1">2</span> <span class="pl-k">-</span> x <span class="pl-k">⋅</span> x <span class="pl-k">/</span> <span class="pl-c1">2</span></pre></div>
<p dir="auto">This Lagrangian together with the symbolic variables is then used to construct a <code>LagrangianSystem</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="lag_sys = LagrangianSystem(L, t, x, v)"><pre>lag_sys <span class="pl-k">=</span> <span class="pl-c1">LagrangianSystem</span>(L, t, x, v)</pre></div>
<p dir="auto">The constructor computes the Euler-Lagrange equations and generates the corresponding Julia code.
In the last step, we can now construct a <code>LODEProblem</code> from the <code>LagrangianSystem</code> and some appropriate initial conditions, a time span to integrate over and a time step:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="tspan = (0.0, 10.0)
tstep = 0.01

q₀ = [1.0]
p₀ = [0.5]

lprob = LODEProblem(lag_sys, tspan, tstep, q₀, p₀)"><pre>tspan <span class="pl-k">=</span> (<span class="pl-c1">0.0</span>, <span class="pl-c1">10.0</span>)
tstep <span class="pl-k">=</span> <span class="pl-c1">0.01</span>

q₀ <span class="pl-k">=</span> [<span class="pl-c1">1.0</span>]
p₀ <span class="pl-k">=</span> [<span class="pl-c1">0.5</span>]

lprob <span class="pl-k">=</span> <span class="pl-c1">LODEProblem</span>(lag_sys, tspan, tstep, q₀, p₀)</pre></div>
<p dir="auto">Should we fancy so, we can integrate this system using GeometricIntegrators:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GeometricIntegrators
integrate(lprob, ExplicitMidpoint())"><pre><span class="pl-k">using</span> GeometricIntegrators
<span class="pl-c1">integrate</span>(lprob, <span class="pl-c1">ExplicitMidpoint</span>())</pre></div>
