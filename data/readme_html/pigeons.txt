<p dir="auto"><code>Pigeons</code> is a Julia package to approximate challenging posterior distributions, and more broadly, Lebesgue integration problems. Pigeons can be used in a multi-threaded context, and/or distributed over hundreds or thousands of MPI-communicating machines.</p>
<p dir="auto"><a href="https://pigeons.run/dev/" rel="nofollow">For more information, see the documentation.</a></p>
