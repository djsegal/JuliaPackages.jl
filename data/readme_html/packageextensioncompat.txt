<p dir="auto"><a href="https://github.com/cjdoris/PackageExtensionCompat.jl/actions/workflows/tests.yml"><img src="https://github.com/cjdoris/PackageExtensionCompat.jl/actions/workflows/tests.yml/badge.svg" alt="Tests" style="max-width: 100%;"></a></p>
<p dir="auto">Julia introduced
<a href="https://pkgdocs.julialang.org/v1.9/creating-packages/#Conditional-loading-of-code-in-packages-(Extensions)" rel="nofollow">package extensions</a>
in v1.9. This package makes these extensions backwards-compatible to earlier Julia versions,
with zero overhead on new versions.</p>
<p dir="auto">Internally, this uses
<a href="https://github.com/JuliaPackaging/Requires.jl">Requires.jl</a>
on earlier versions, automating
<a href="https://pkgdocs.julialang.org/v1.9/creating-packages/#Requires.jl" rel="nofollow">this strategy</a>
in the Pkg.jl docs.</p>
<p dir="auto">Supports all versions of Julia from 1.0 upwards.</p>

<p dir="auto">Supposing you have a package called <code>Foo</code>:</p>
<ol dir="auto">
<li>
<p dir="auto">Set up package extensions for <code>Foo</code> as usual. This means adding <code>[weakdeps]</code> and
<code>[extensions]</code> to <code>Project.toml</code> and adding extension code to <code>ext/</code>.</p>
</li>
<li>
<p dir="auto">Add <code>PackageExtensionCompat</code> as a dependency to <code>Foo</code>.</p>
</li>
<li>
<p dir="auto">Add the following code to <code>src/Foo.jl</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PackageExtensionCompat
function __init__()
    @require_extensions
end"><pre><span class="pl-k">using</span> PackageExtensionCompat
<span class="pl-k">function</span> <span class="pl-en">__init__</span>()
    <span class="pl-c1">@require_extensions</span>
<span class="pl-k">end</span></pre></div>
</li>
</ol>
<p dir="auto">That's it! Your package extensions will now be loaded as expected on any Julia version!</p>
