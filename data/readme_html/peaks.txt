<ul dir="auto">
<li>Find peak (maxima or minima) locations, height, prominence, and width
<ul dir="auto">
<li>Filter peaks by peak spacing (window size), height, prominence, and width (including "Full Width Half Maximum (FWHM)")</li>
</ul>
</li>
<li>Fully supports <code>NaN</code>/<code>missing</code> with optional tolerance using keyword arg <code>strict</code>:
<ul dir="auto">
<li>Conventional handling/propagation of <code>NaN</code>/<code>missing</code> when <code>strict = true</code> (the default)</li>
<li>Reasonable alternatives when <code>strict = false</code></li>
</ul>
</li>
</ul>
