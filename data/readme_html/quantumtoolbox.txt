<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Introduction</h2><a id="user-content-introduction" class="anchor" aria-label="Permalink: Introduction" href="#introduction"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://github.com/qutip/QuantumToolbox.jl">QuantumToolbox.jl</a> is a cutting-edge Julia package designed for quantum physics simulations, closely emulating the popular Python <a href="https://github.com/qutip/qutip">QuTiP</a> package. It uniquely combines the simplicity and power of Julia with advanced features like GPU acceleration and distributed computing, making simulation of quantum systems more accessible and efficient.</p>
<p dir="auto"><em>With this package, moving from Python to Julia for quantum physics simulations has never been easier</em>, due to the similar syntax and functionalities.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">QuantumToolbox.jl is equipped with a robust set of features:</p>
<ul dir="auto">
<li><strong>Quantum State and Operator Manipulation:</strong> Easily handle quantum states and operators with a rich set of tools, with the same functionalities as QuTiP.</li>
<li><strong>Dynamical Evolution:</strong> Advanced solvers for time evolution of quantum systems, thanks to the powerful <a href="https://github.com/SciML/DifferentialEquations.jl">DifferentialEquations.jl</a> package.</li>
<li><strong>GPU Computing:</strong> Leverage GPU resources for high-performance computing. For example, you run the master equation direclty on the GPU with the same syntax as the CPU case.</li>
<li><strong>Distributed Computing:</strong> Distribute the computation over multiple nodes (e.g., a cluster). For example, you can run hundreds of quantum trajectories in parallel on a cluster, with, again, the same syntax as the simple case.</li>
<li><strong>Easy Extension:</strong> Easily extend the package, taking advantage of the Julia language features, like multiple dispatch and metaprogramming.</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Brief Example</h2><a id="user-content-brief-example" class="anchor" aria-label="Permalink: Brief Example" href="#brief-example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We now provide a brief example to demonstrate the similarity between <a href="https://github.com/qutip/QuantumToolbox.jl">QuantumToolbox.jl</a> and <a href="https://github.com/qutip/qutip">QuTiP</a>.</p>
<p dir="auto">Let's consider a quantum harmonic oscillator with a Hamiltonian given by:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$$
\hat{H} = \omega \hat{a}^\dagger \hat{a}
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\hat{a}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\hat{a}^\dagger$</math-renderer> are the annihilation and creation operators, respectively. We can define the Hamiltonian as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using QuantumToolbox

N = 20 # cutoff of the Hilbert space dimension
ω = 1.0 # frequency of the harmonic oscillator

a = destroy(N) # annihilation operator

H = ω * a' * a"><pre><span class="pl-k">using</span> QuantumToolbox

N <span class="pl-k">=</span> <span class="pl-c1">20</span> <span class="pl-c"><span class="pl-c">#</span> cutoff of the Hilbert space dimension</span>
ω <span class="pl-k">=</span> <span class="pl-c1">1.0</span> <span class="pl-c"><span class="pl-c">#</span> frequency of the harmonic oscillator</span>

a <span class="pl-k">=</span> <span class="pl-c1">destroy</span>(N) <span class="pl-c"><span class="pl-c">#</span> annihilation operator</span>

H <span class="pl-k">=</span> ω <span class="pl-k">*</span> a<span class="pl-k">'</span> <span class="pl-k">*</span> a</pre></div>
<p dir="auto">We now introduce some losses in a thermal environment, described by the Lindblad master equation:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$$
\frac{d \hat{\rho}}{dt} = -i [\hat{H}, \hat{\rho}] + \gamma \mathcal{D}[\hat{a}] \hat{\rho}
$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\hat{\rho}$</math-renderer> is the density matrix, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\gamma$</math-renderer> is the damping rate, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\mathcal{D}[\hat{a}]$</math-renderer> is the Lindblad dissipator, defined as:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$$
\mathcal{D}[\hat{a}]\hat{\rho} = \hat{a}\hat{\rho}\hat{a}^\dagger - \frac{1}{2}\hat{a}^\dagger\hat{a}\hat{\rho} - \frac{1}{2}\hat{\rho}\hat{a}^\dagger\hat{a}
$$</math-renderer></p>
<p dir="auto">We now compute the time evolution of the system using the <code>mesolve</code> function, starting from the initial state <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\ket{\psi (0)} = \ket{3}$</math-renderer>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="γ = 0.1 # damping rate

ψ0 = fock(N, 3) # initial state

tlist = range(0, 10, 100) # time list

c_ops = [sqrt(γ) * a]
e_ops = [a' * a]

sol = mesolve(H, ψ0, tlist, c_ops, e_ops = e_ops)"><pre>γ <span class="pl-k">=</span> <span class="pl-c1">0.1</span> <span class="pl-c"><span class="pl-c">#</span> damping rate</span>

ψ0 <span class="pl-k">=</span> <span class="pl-c1">fock</span>(N, <span class="pl-c1">3</span>) <span class="pl-c"><span class="pl-c">#</span> initial state</span>

tlist <span class="pl-k">=</span> <span class="pl-c1">range</span>(<span class="pl-c1">0</span>, <span class="pl-c1">10</span>, <span class="pl-c1">100</span>) <span class="pl-c"><span class="pl-c">#</span> time list</span>

c_ops <span class="pl-k">=</span> [<span class="pl-c1">sqrt</span>(γ) <span class="pl-k">*</span> a]
e_ops <span class="pl-k">=</span> [a<span class="pl-k">'</span> <span class="pl-k">*</span> a]

sol <span class="pl-k">=</span> <span class="pl-c1">mesolve</span>(H, ψ0, tlist, c_ops, e_ops <span class="pl-k">=</span> e_ops)</pre></div>
<p dir="auto">We can extract the expectation value of the number operator <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32dc267435f882b5c98e3544a8705a38">$\hat{a}^\dagger \hat{a}$</math-renderer> with the command <code>sol.expect</code>, and the states with the command <code>sol.states</code>.</p>
