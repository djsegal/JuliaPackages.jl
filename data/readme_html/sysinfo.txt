<p dir="auto">This package is the backend of <a href="https://github.com/carstenbauer/ThreadPinning.jl">ThreadPinning.jl</a>. However, you may use it directly to obtain core information about the compute system at hand (number of physical cores, NUMA domains, etc.).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Get a compact summary of the system (topology and key figures).</li>
<li>Query various properties of the system, including the number of CPU-threads, physical CPU-cores, and NUMA domains.</li>
<li>Supports identifying different CPU-core kinds (e.g. "efficiency core" and "performance cores").</li>
<li>Two backends: <a href="https://github.com/JuliaParallel/Hwloc.jl">Hwloc.jl</a> and <code>lscpu</code>.</li>
<li>Fake mode: Simulate being on a different system (useful in conjuction with <a href="https://github.com/carstenbauer/ThreadPinningCore.jl">ThreadPinningCore.jl</a>'s fake mode).</li>
</ul>

<p dir="auto">SysInfo.jl uses <a href="https://github.com/JuliaParallel/Hwloc.jl">Hwloc.jl</a> as the source of truth. It also has a <code>lscpu</code>-based backend that can be used as a replacement or for consistency checks (at least on Linux).</p>

<p dir="auto">We fake-run the test suite of this package on a bunch of interesting systems (e.g. with interesting CPUs or topologies). <strong>You can readily add your interesting system to the list</strong>, which helps us ensure that this package (as well as <a href="https://github.com/carstenbauer/ThreadPinning.jl">ThreadPinning.jl</a>) is working on your system.</p>
<p dir="auto">(Please only add your system if you think it is worth testing on.)</p>
