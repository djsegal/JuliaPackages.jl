<p dir="auto">The motivation behind the <code>StatisticalGraphics</code> package is the desire to develop a powerful, yet easy-to-use solution for creating statistical graphics in Julia.
The package uses <a href="https://vega.github.io/vega/" rel="nofollow"><code>vega</code></a> (see also <a href="https://d3js.org/" rel="nofollow">D3</a>) for producing the final outputs.</p>
<p dir="auto">See <a href="https://sl-solution.github.io/StatisticalGraphics.jl/stable/" rel="nofollow">documentation</a> for more information.</p>
