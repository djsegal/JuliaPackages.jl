<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><strong>Grumps.jl</strong> is a package for computing random coefficients demand models using consumer and product level data. The main estimators are introduced in <a href="http://joris.pinkse.org/paper/grumps/" rel="nofollow">Grieco, Murry, Pinkse, and Sagl (2022)</a>, including:</p>
<ol dir="auto">
<li>
<p dir="auto">the conformant likelihood with exogeneity restrictions (CLER) estimator</p>
</li>
<li>
<p dir="auto">an asymptotically equivalent less expensive alternative thereof</p>
</li>
<li>
<p dir="auto">the mixed data likelihood estimator (MDLE)</p>
</li>
<li>
<p dir="auto">the share constrained likelihood estimator</p>
<p dir="auto">In addition, other estimators have been implemented:</p>
</li>
<li>
<p dir="auto">mixed logit models (consumer level data only)</p>
</li>
<li>
<p dir="auto">multinomial logit models (consumer level data only)</p>
</li>
<li>
<p dir="auto">GMM type random coefficient models in the style of Berry, Levinsohn, and Pakes (2004) (in process, not recommended)</p>
</li>
</ol>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="81b327af6de1e95a2a65c0ad441cb91e">$(\hat\delta,\hat\theta,\hat\beta) = \text{argmin}_{\delta,\theta,\beta} \big( - \log \hat L(\delta,\theta) + \hat\Pi(\delta,\beta) \big),$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="81b327af6de1e95a2a65c0ad441cb91e">$\log \hat L$</math-renderer> is the sum of a micro loglikelihood and a macro loglikelihood and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="81b327af6de1e95a2a65c0ad441cb91e">$\hat\Pi$</math-renderer> is a quadratic penalty term.  Any of the three components can be omitted if so desired.</p>
<p dir="auto">Typically, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="81b327af6de1e95a2a65c0ad441cb91e">$\log \hat L$</math-renderer> is a sum over markets, products, and consumers whereas <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="81b327af6de1e95a2a65c0ad441cb91e">$\hat\Pi$</math-renderer> is a GMM-style squared norm of a vector-valued sum over markets.  Please see <a href="http://joris.pinkse.org/paper/grumps/" rel="nofollow">Grieco, Murry, Pinkse, and Sagl (2022)</a> for details.</p>
<p dir="auto">Several extensions are possible, which may require additions to the code.</p>

<p dir="auto">This documentation describes the use of the Grumps computer package.  It does not describe the estimators or algorithms.  Please refer to <a href="http://joris.pinkse.org/paper/grumps/" rel="nofollow">Grieco, Murry, Pinkse, and Sagl (2022)</a> for that.  In addition, the code itself is documented, also.</p>

<p dir="auto">This is still a preliminary version of Grumps, so please advise <a href="mailto://pinkse@gmail.com" rel="nofollow">Joris Pinkse</a> of any bugs, problems, shortcomings, missing features, etcetera.  Features it does not currently possess include:</p>
<ol dir="auto">
<li>sparse quadrature or similar integration methods</li>
<li>distributed computing</li>
<li>GPUs</li>
<li>statistics other than coefficients, e.g. elasticities</li>
<li>integration methods for the micro portion of the GMM estimator other than quadrature</li>
<li>traditional GMM; see <a href="http://joris.pinkse.org/paper/grumps/" rel="nofollow">Grieco, Murry, Pinkse, and Sagl (2022)</a> for details</li>
<li>standard errors for some of the estimators</li>
<li>detailed sanity checks</li>
</ol>
