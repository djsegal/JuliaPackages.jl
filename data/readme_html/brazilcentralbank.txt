<p dir="auto">BrazilCentralBank.jl é uma interface na linguagem de programação Julia para a API de dados do Banco Central do Brasil.<br>
O projeto foi inspirado por <a href="https://github.com/wilsonfreitas/python-bcb">python-bcb</a> criado por wilsonfreitas@GitHub.</p>
<p dir="auto">BrazilCentralBank.jl is an interface in the Julia programming language for the data API of Brazil's Central Bank (BCB).<br>
The project was inspired by <a href="https://github.com/wilsonfreitas/python-bcb">python-bcb</a> created by wilsonfreitas@GitHub.</p>

<p dir="auto">Based on the python-bcb package for python, BrazilCentralBank.jl aims to provide the same level of features to the Julia Language. Currently the package can interact with the foreign exchange (FOREX) prices as shows in the time series availiable in the Brazil's Central Bank (BCB) website.</p>
<p dir="auto">Right now the project is in its early days and the implementation still resembles a lot the original python project. Future updates include the addition other data sources from the BCB's site such as interest rates, inflation, etc.</p>
<p dir="auto">The final goal is for this to be a comprehensive set of tools for anyone trying to analyse the brazilian economy using Julia!</p>
