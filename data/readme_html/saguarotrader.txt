<p dir="auto">SaguaroTrader.jl is a flexible, schedule-driven backtesting library tailored for long-short equity and ETF-based systematic trading strategies. Signal generation operates independently from portfolio construction, risk management, execution, and simulated brokerage accounting. This library originated as a Julia port of the Python library <a href="https://github.com/mhallsmoore/qstrader">qstrader</a>.</p>
