<p dir="auto"><strong>PiecewiseInference.jl</strong> is a library to enhance the convergence of dynamical model parameter inversion methods. It provides features such as</p>
<ul dir="auto">
<li>a segmentation strategy,</li>
<li>the independent estimation of initial conditions for each segment,</li>
<li>parameter transformation,</li>
<li>parameter and initial conditions regularization</li>
<li>mini-batching</li>
</ul>
<p dir="auto">Taken altogether, these features regularize the inference problem and permit to solve it efficiently.</p>
