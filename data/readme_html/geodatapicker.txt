<p dir="auto">Interpreting 3D geological and geophysical data in a consistent manner is non-straightforward. The <a href="https://github.com/JuliaGeodynamics/GeophysicalModelGenerator.jl">GeophysicalModelGenerator</a> package provides a number of useful tools to combine and visualize datasets.
<code>GeoDataPicker</code> is a web-based graphical user interface build on top of GMG, which allows creating interactive interpretations from such data.</p>
<p dir="auto">The main features are:</p>
<ul dir="auto">
<li>Import volumetric data (e.g., seismic tomography), surfaces (e.g., Moho depth), points (e.g., earthquake), topography or screenshots from published papers from remote or local locations.</li>
<li>Switch easily between different datasets (e.g., different tomography models).</li>
<li>Interactively add your interpretation to profiles through the datasets (e.g. top of the European or Appenninic slabs).</li>
<li>Visualize your interpretations in 3D.</li>
</ul>
