<p dir="auto">This package defines julia implementations for the common types <code>Option</code> (aka <code>Maybe</code>), <code>Either</code> and <code>Try</code>, as well as one extra type <code>ContextManager</code> which mimics Python's <code>with</code>-ContextManager.</p>

<p dir="auto">Here an example using <code>Try</code> to handle errors programmatically. Similar to <code>Option</code>, a <code>Try</code> is either a <code>Const</code>, denoting an error, or an <code>Identity</code>
value, which denotes success.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DataTypesBasic  # defines Try

@Try div(1, 0)  # Const(Thrown(DivideError()))
@Try div(8, 3)  # Identity(2)"><pre><span class="pl-k">using</span> DataTypesBasic  <span class="pl-c"><span class="pl-c">#</span> defines Try</span>

<span class="pl-c1">@Try</span> <span class="pl-c1">div</span>(<span class="pl-c1">1</span>, <span class="pl-c1">0</span>)  <span class="pl-c"><span class="pl-c">#</span> Const(Thrown(DivideError()))</span>
<span class="pl-c1">@Try</span> <span class="pl-c1">div</span>(<span class="pl-c1">8</span>, <span class="pl-c1">3</span>)  <span class="pl-c"><span class="pl-c">#</span> Identity(2)</span></pre></div>
<p dir="auto">Using another helper package <a href="https://github.com/JuliaFunctional/Monadic.jl/tree/main"><code>Monadic</code></a>. We can combine these
into nice syntax.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Monadic  # defines @monadic

# flatmap is also defined in TypeClasses.jl
flatmap(f, x) = Iterators.flatten(map(f, x))
tryit = @monadic map flatmap begin
  a = @Try div(8, 3)
  b = @Try isodd(a) ? 100 + a : error(&quot;fail&quot;)
  @pure a, b
end
