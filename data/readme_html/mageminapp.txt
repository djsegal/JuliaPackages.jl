<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://raw.githubusercontent.com/ComputationalThermodynamics/repositories_pictures/main/MAGEMinApp/MAGEMin_app.png?raw=true"><img src="https://raw.githubusercontent.com/ComputationalThermodynamics/repositories_pictures/main/MAGEMinApp/MAGEMin_app.png?raw=true" alt="drawing" width="820" style="max-width: 100%;"></a></p>
<p dir="auto"><code>MAGEMinApp.jl</code> provides an easy-to-use web-based graphical user interface for <code>MAGEMin</code>. Available features:</p>
<ol dir="auto">
<li>Compute Pressure-Temperature iso-chemical phase diagrams (P-T phase diagrams)</li>
<li>Compute Pressure and/or Temperature versus variable composition diagrams (P-X, T-X, PT-X phase diagrams)</li>
<li>Display iso-contour of phase fractions, densities, seismic velocities etc.</li>
<li>Automatic labeling of the phase fields including listing the stable phase assemblage when the field is too small.</li>
<li>Compute Pressure-Temperature path diagrams for fractional melting and crystallization.</li>
<li>Save generated diagrams/figures as vector files (svg format).</li>
<li>Export single point and whole grid information as table (ascii format)</li>
</ol>
<p dir="auto">As for <code>MAGEMin</code>, you can choose among several thermodynamic dataset: Metapelite (White et al., 2014), Metabasite (Green et al., 2016), Igneous (Holland et al., 2018) or Ultramafic (Evans &amp; Frost, 2021).</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">How to load custom bulk-rock composition</h3><a id="user-content-how-to-load-custom-bulk-rock-composition" class="anchor" aria-label="Permalink: How to load custom bulk-rock composition" href="#how-to-load-custom-bulk-rock-composition"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">MAGEMinApp is designed is such a way that bulk-rock composition must be entered in a <code>*.dat</code> file and loaded in the simulation tab. An example of valid bulk-rock composition file is given in <code>examples/bulk-rock_ref.dat</code></p>
<ul dir="auto">
<li>Commented lines must start with a <code>#</code></li>
<li>Bulk-rock composition line must contain <code>title; comments; db; sysUnit; oxide; frac; frac2</code></li>
<li>A valid example of bulk-rock composition entry is for instance:<br>
<code>title; comments; db; sysUnit; oxide; frac; frac2</code><br>
<code>Test 2;Moo et al., 2000;ig;mol;[SiO2, Al2O3, CaO, MgO, FeO, K2O, Na2O, TiO2, O, Cr2O3, H2O];[48.97, 11.76, 13.87, 4.21, 8.97, 1.66, 10.66, 1.36, 1.66, 0.0, 5.0];</code>\</li>
</ul>
<div class="markdown-alert markdown-alert-important" dir="auto"><p class="markdown-alert-title" dir="auto"><svg class="octicon octicon-report mr-2" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="M0 1.75C0 .784.784 0 1.75 0h12.5C15.216 0 16 .784 16 1.75v9.5A1.75 1.75 0 0 1 14.25 13H8.06l-2.573 2.573A1.458 1.458 0 0 1 3 14.543V13H1.75A1.75 1.75 0 0 1 0 11.25Zm1.75-.25a.25.25 0 0 0-.25.25v9.5c0 .138.112.25.25.25h2a.75.75 0 0 1 .75.75v2.19l2.72-2.72a.749.749 0 0 1 .53-.22h6.5a.25.25 0 0 0 .25-.25v-9.5a.25.25 0 0 0-.25-.25Zm7 2.25v2.5a.75.75 0 0 1-1.5 0v-2.5a.75.75 0 0 1 1.5 0ZM9 9a1 1 0 1 1-2 0 1 1 0 0 1 2 0Z"></path></svg>Important</p><p dir="auto"><code>db</code> must be either <code>mp</code> (metapelite, White et al., 2014), <code>mb</code> (metabasite, Green et al., 2016), <code>ig</code> (igneous, Holland et al., 2018) or <code>um</code> (ultramafic, Frost &amp; Evans, 2021).</p>
<p dir="auto"><code>sysUnit</code> must be <code>mol</code> or <code>wt</code>. Note that if <code>wt</code> is provided, the composition is converted and subsequently displayed in <code>mol</code> in <code>MAGEMinApp</code>.</p>
<p dir="auto"><code>oxide</code> is the <strong>complete</strong> list of oxides of the selected database. You are not allowed to leave oxides out. If you don't need all oxides of the database simply set them to 0.0. Note, that either <code>FeO</code> and <code>O</code> <strong>or</strong> <code>FeO</code> and <code>Fe2O3</code> can be provided. In the first case <code>FeO</code> = <code>FeOt</code>.</p>
<p dir="auto"><code>frac</code> is the <code>sysUnit</code> proportion of oxides. Set the oxide content to 0.0 to reduce the chemical system. If possible, the calculation will be performed in a fully reduced chemical system, otherwise a low value will be automatically set (around 0.01 <code>mol%</code>). Generally, <code>TiO2</code>, <code>Cr2O3</code>, <code>MnO</code>, <code>O</code> and <code>H2O</code> can be effectively set to 0.0.</p>
<p dir="auto"><code>frac2</code> is used only when computing T-X or P-X diagrams.</p>
</div>
