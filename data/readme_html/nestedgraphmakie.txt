<p dir="auto">A package for <a href="https://github.com/UniStuttgart-IKR/NestedGraphs.jl">NestedGraphs.jl</a> to make easy visualizations.</p>
<p dir="auto">This package exports <code>ngraphplot</code>, which provides some extra features on top of <code>GraphMakie.graphplot</code>.
All features of <code>GraphMakie.graphplot</code> can be accesssed whatsoever.
See the <a href="https://unistuttgart-ikr.github.io/NestedGraphMakie.jl/dev/API/" rel="nofollow">API</a> docs.</p>
<p dir="auto">Some examples of <code>NestedGraph</code> visualizations:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Graphs, NestedGraphs, NestedGraphsMakie, GLMakie

  g4 = complete_graph(4)

  ng = NestedGraph([g1,g2,g3,g4], eds, both_ways=true)

end
