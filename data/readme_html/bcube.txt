<p dir="auto">Bcube is a Julia library providing tools for the spatial discretization of partial differential equation(s) (PDE). It offers a high-level API to discretize linear or non-linear problems on unstructured mesh using continuous or discontinuous finite elements (FEM - DG).</p>
<p dir="auto">The main features are:</p>
<ul dir="auto">
<li>high-level api : <code>a(u, v) = ∫(η * ∇(u) ⋅ ∇(v))dΩ</code></li>
<li>1D, 2D, 3D unstructured mesh with high-order geometrical elements (gmsh format)</li>
<li>Lagrange (continuous &amp; discontinuous) and Taylor (discontinuous) finite elements (line, quad, tri, hexa, penta)</li>
<li>arbitrary order for hypercube Lagrange elements</li>
</ul>
<p dir="auto">Browse the <a href="https://bcube-project.github.io/Bcube.jl" rel="nofollow">documentation</a> for more information about the code architecture and API. Commented tutorials as well as various examples can be found in the dedicated project <a href="https://github.com/bcube-project/BcubeTutorials.jl">BcubeTutorials.jl</a>.</p>
