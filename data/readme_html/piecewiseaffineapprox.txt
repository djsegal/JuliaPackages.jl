<p dir="auto">Add convex (or concave) piecewise linear approximations of functions or a set of points to optimization models modelled in <a href="https://jump.dev/" rel="nofollow">JuMP</a>.</p>
<p dir="auto">This package provides three main methods to fit a set of points:</p>
<ol dir="auto">
<li>creates and solves a MILP to fit a set of points, and adds the resulting linear constraints to the optimization model. This method is partially based on <a href="https://doi.org/10.1016/j.ejor.2011.12.030" rel="nofollow">Toriello &amp; Vielma, 2012</a>.</li>
<li>uses a heuristic to fit the set of points. This method is based on <a href="https://doi.org/10.1007/s11081-008-9045-3" rel="nofollow">Magnani &amp; Boyd, 2009</a>.</li>
<li>a progressive heuristic to add planes until a certain accuracy is met. This method is based on <a href="https://doi.org/10.1016/j.ejor.2023.07.026" rel="nofollow">Kazda &amp; Li, 2024</a></li>
</ol>
<p dir="auto">For non-convex functions, consider using <a href="https://github.com/joehuchette/PiecewiseLinearOpt.jl">PiecewiseLinearOpt.jl</a>.</p>

# Minimize
@objective(m, Min, z)
# Check approximation/solution at x = 0.5

<p dir="auto">To keep dependencies light, PiecewiseAffineApprox does not include plotting by default. If the <code>Makie</code> or <code>Plots</code> package is loaded
before using the module, some simple plotting routines will be available</p>
<p dir="auto">The following demonstrates how this can be achieved:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using PiecewiseAffineApprox, CairoMakie, HiGHS
