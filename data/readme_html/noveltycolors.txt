<p dir="auto">This package is intended to be a lightweight package for non-standard color palettes. Unlike <a href="https://github.com/JuliaLang/Color.jl">Color.jl</a>, there is not (necessarily) any theoretical underpinnings to these palettes. Color palettes provided within this package may represent Internet memes, generalized color palettes seen in advertising or on television/movies, or just aesthetically pleasing colors.</p>
<p dir="auto">If you are visualizing data for presentation or publication, you should validate that any of these color schemes provide acceptable contrast when printed in Black &amp; White, are appropriate for colorblind individuals and any other considerations.</p>
<p dir="auto">The color palettes are stored and exported in a plain Julia <code>Dict</code> type, named <code>ColorDict</code></p>
