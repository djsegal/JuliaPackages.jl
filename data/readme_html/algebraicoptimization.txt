<p dir="auto">This package is designed for building large optimization problems out of simpler subproblems and automatically compiling them to a distributed solver.</p>

<p dir="auto">Now, to compose these subproblems, we need to make them into <em>open</em> problems. An open problem specifies which components of a problem's domain are open to composition with other problems. We do this as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Make open problems.
# The first argument is the primal objective we are wrapping, the second argument is a function
# specifying which components of the objective are exposed. 
p1 = Open{PrimalObjective}(FinSet(5), PrimalObjective(FinSet(5),f), FinFunction([2,4], 5))
p2 = Open{PrimalObjective}(FinSet(3), PrimalObjective(FinSet(3),g), id(FinSet(3)))
p3 = Open{PrimalObjective}(FinSet(4), PrimalObjective(FinSet(4),h), FinFunction([1,3,4]))"><pre><span class="pl-c"><span class="pl-c">#</span> Make open problems.</span>

<p dir="auto">Now, we can solve the composite problem with distributed gradient descent:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Arguments are problem, initial guess, step size, and number of iterations
sol = solve(composite, repeat([100.0], dom(composite_prob).n), 0.1, 100)"><pre><span class="pl-c"><span class="pl-c">#</span> Arguments are problem, initial guess, step size, and number of iterations</span>
sol <span class="pl-k">=</span> <span class="pl-c1">solve</span>(composite, <span class="pl-c1">repeat</span>([<span class="pl-c1">100.0</span>], <span class="pl-c1">dom</span>(composite_prob)<span class="pl-k">.</span>n), <span class="pl-c1">0.1</span>, <span class="pl-c1">100</span>)</pre></div>
<p dir="auto">Currently, we just support unconstrained and equality constrained problems with plans to add support for inequality constrained and disciplined convex programs.</p>
<p dir="auto">More complete documentation and quality of life improvements are also on the way.</p>
<p dir="auto">This package is an implementation of <a href="https://arxiv.org/abs/2403.05711" rel="nofollow">A Compositional Framework for First-Order Optimization</a>.</p>
