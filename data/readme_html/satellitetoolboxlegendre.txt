<p dir="auto">This package exports two methods to compute the Legendre associated functions: <code>legendre</code>
and <code>legendre!</code>.</p>
<hr>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="legendre(N, ϕ::T, n_max::Integer, m_max::Integer = -1; ph_term::Bool = false) where T&lt;:Number -&gt; Matrix{float(T)}"><pre><span class="pl-c1">legendre</span>(N, ϕ<span class="pl-k">::</span><span class="pl-c1">T</span>, n_max<span class="pl-k">::</span><span class="pl-c1">Integer</span>, m_max<span class="pl-k">::</span><span class="pl-c1">Integer</span> <span class="pl-k">=</span> <span class="pl-k">-</span><span class="pl-c1">1</span>; ph_term<span class="pl-k">::</span><span class="pl-c1">Bool</span> <span class="pl-k">=</span> <span class="pl-c1">false</span>) <span class="pl-k">where</span> T<span class="pl-k">&lt;:</span><span class="pl-c1">Number</span> <span class="pl-k">-&gt;</span> Matrix{<span class="pl-c1">float</span>(T)}</pre></div>
<p dir="auto">Compute the associated Legendre function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$P_{n,m}\left[\cos(\phi)\right]$</math-renderer>. The maximum
degree that will be computed is <code>n_max</code> and the maximum order is <code>m_max</code>. Notice that if
<code>m_max</code> is higher than <code>n_max</code> or negative (default), it is set to <code>n_max</code>.</p>
<p dir="auto">The parameter <code>N</code> selects the normalization. The following values are valid:</p>
<ul dir="auto">
<li><code>Val(:full)</code>: Compute the fully normalized associated Legendre function.</li>
<li><code>Val(:schmidt)</code>: Compute the Schmidt quasi-normalized associated Legendre function.</li>
<li><code>Val(:unnormalized)</code>: Compute the unnormalized associated Legendre function.</li>
</ul>
<p dir="auto">This function has the following keywords:</p>
<ul dir="auto">
<li>
<code>ph_term::Bool</code>: If <code>true</code>, the Condon-Shortley phase term <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$(-1)^m$</math-renderer> will be included.
(<strong>Default</strong> = <code>false</code>)</li>
</ul>
<p dir="auto">It returns a <code>Matrix{float(T)}</code> with the Legendre associated functions
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$P_{n,m}\left[\cos(\phi)\right]$</math-renderer>.</p>

<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$P_{n,m}\left[\cos(\phi)\right]$</math-renderer> with respect to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$\phi$</math-renderer> [rad]:</p>

<p dir="auto">This function has the following keywords:</p>

<p dir="auto">Compute the first-order derivative of the associated Legendre function
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$P_{n,m}\left[\cos(\phi)\right]$</math-renderer> with respect to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$\phi$</math-renderer> [rad]:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$$\frac{\partial P_{n,m} \left[\cos(\phi)\right]}{\partial\phi}$$</math-renderer></p>
<p dir="auto">The maximum degree and order that will be computed are given by the parameters <code>n_max</code> and
<code>m_max</code>. If they are negative (default), the dimensions of matrix <code>dP</code> will be used:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="maximum degree -&gt; number of rows - 1
maximum order  -&gt; number of columns - 1"><pre class="notranslate"><code>maximum degree -&gt; number of rows - 1
maximum order  -&gt; number of columns - 1
</code></pre></div>
<p dir="auto">The derivatives will be stored in the matrix <code>dP</code>. Hence, this function can be used to reduce
allocations.</p>
<p dir="auto">The parameter <code>N</code> selects the normalization. The following values are valid:</p>
<ul dir="auto">
<li><code>Val(:full)</code>: Compute the fully normalized associated Legendre function.</li>
<li><code>Val(:schmidt)</code>: Compute the Schmidt quasi-normalized associated Legendre function.</li>
<li><code>Val(:unnormalized)</code>: Compute the unnormalized associated Legendre function.</li>
</ul>
<p dir="auto">This algorithm needs the matrix <code>P</code> with the values of the associated Legendre function
using the same normalization <code>N</code>, which can be computed using the function <code>legendre</code>.</p>
<blockquote>
<p dir="auto"><strong>Warning</strong>
The user is responsible to pass a matrix <code>P</code> with the correct values. For example, if
<code>ph_term</code> is <code>true</code>, <code>P</code> must also be computed with <code>ph_term</code> set to <code>true</code>.</p>
</blockquote>
<p dir="auto">This function has the following keywords:</p>
<ul dir="auto">
<li>
<code>ph_term::Bool</code>: If <code>true</code>, the Condon-Shortley phase term <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$(-1)^m$</math-renderer> will be included.
(<strong>Default</strong> = <code>false</code>)</li>
</ul>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Full normalization</h3><a id="user-content-full-normalization" class="anchor" aria-label="Permalink: Full normalization" href="#full-normalization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This algorithm was based on <strong>[1]</strong>. Our definition of fully normalized associated Legendre
function can be seen in <strong>[2, p. 546]</strong>. The conversion is obtained by:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$$K_{n,m} = \sqrt{k \cdot \frac{(n - m)! \cdot (2n + 1)}{(n + m)!}}~,$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$k = 1$</math-renderer> if <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$m = 0$</math-renderer> or <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$k = 2$</math-renderer> otherwise. Hence:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$$P^f_{n,m} = P_{n,m} \cdot K_{n,m}$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$P^f_{n,m}$</math-renderer> is the fully normalized Legendre associated function.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Schmidt quasi-normalization</h3><a id="user-content-schmidt-quasi-normalization" class="anchor" aria-label="Permalink: Schmidt quasi-normalization" href="#schmidt-quasi-normalization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This algorithm was based on <strong>[3, 4]</strong>. The conversion is obtained by:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$$K_{n,m} = \sqrt{k \cdot \frac{(n - m)!}{(n + m)!}}~,$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$k = 1$</math-renderer> if <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$m = 0$</math-renderer> or <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$k = 2$</math-renderer> otherwise. Hence:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="8194cd31a16cb9031c95c4ba2de1f9c3">$$P^s_{n,m} = P_{n,m} \cdot K_{n,m}$$</math-renderer></p>
