<p dir="auto">ProfileSVG allows you to export profiling data as an SVG file.
It can be used to display profiling results in
Jupyter/<a href="https://github.com/JuliaLang/IJulia.jl">IJulia</a> notebooks,
<a href="https://github.com/fonsp/Pluto.jl">Pluto</a> or any other SVG viewer.</p>
<p dir="auto">An alternative visualization package is the GTK-based
<a href="https://github.com/timholy/ProfileView.jl">ProfileView</a>.
That package offers more interactive features.
See the <a href="https://kimikage.github.io/ProfileSVG.jl/dev/#Other-tools-for-displaying-profiles" rel="nofollow">documentation</a> for other visualization tools.</p>
<p dir="auto">ProfileSVG is a package built on top of
<a href="https://github.com/timholy/FlameGraphs.jl">FlameGraphs</a>.
Among the Julia packages, ProfileView currently has the most comprehensive
tutorial on how to interpret a flame graph.</p>
