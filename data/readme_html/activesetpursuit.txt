<p dir="auto"><code>ActiveSetPursuit</code> is a Julia package providing a framework for solving several variations of the sparse optimization problem:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="3f7f5b5bc7c60fe93151b82483fa3f1d">$$\underset{x}{\text{minimize}} \hspace{0.5em}  \lambda ||x||_1 + \frac{1}{2} ||Ax - b||^2_2$$</math-renderer></p>

<p dir="auto">The <code>asp_bpdn</code> function within the <code>ActiveSetPursuit</code> package efficiently solves the basis pursuit denoising problem.</p>
<p dir="auto">Ensure that the following inputs are defined before running the <code>asp_bpdn</code> function:</p>
<ul dir="auto">
<li><strong><code>A</code></strong>: The matrix or linear operator, size <code>m</code>-by-<code>n</code>.</li>
<li><strong><code>b</code></strong>: The vector of observations or measurements, size <code>m</code>.</li>
<li><strong><code>λin</code></strong>: A nonnegative scalar that serves as the regularization parameter.</li>
</ul>
<p dir="auto">To solve the basis pursuit denoising problem, execute the following command in Julia:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="N, M = 1000, 300
A = randn(N, M)
xref = zeros(M)
xref[randperm(M)[1:20]] = randn(20)  # 20 non-zero entries
b = A * xref
const λin = 0.0
tracer = asp_bpdn(A, b, λin, traceFlag = true)"><pre>N, M <span class="pl-k">=</span> <span class="pl-c1">1000</span>, <span class="pl-c1">300</span>

xref <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(M)
xref[<span class="pl-c1">randperm</span>(M)[<span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">20</span>]] <span class="pl-k">=</span> <span class="pl-c1">randn</span>(<span class="pl-c1">20</span>)  <span class="pl-c"><span class="pl-c">#</span> 20 non-zero entries</span>
