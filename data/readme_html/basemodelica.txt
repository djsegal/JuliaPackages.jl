<p dir="auto">A parser for the <a href="https://github.com/modelica/ModelicaSpecification/tree/MCP/0031/RationaleMCP/0031">Base Modelica</a> format. Contains utilities to parse Base Modelica model files in to Julia objects, and to convert Base Modelica models to <a href="https://docs.sciml.ai/ModelingToolkit/stable/" rel="nofollow">ModelingToolkit</a> models.</p>
<p dir="auto">Base Modelica is as of yet only a proposal with no concrete specification, so the grammar and features of the language are subject to change.
There is no support for Records, custom types, or custom functions. Any <a href="https://github.com/modelica/ModelicaSpecification/blob/MCP/0031/RationaleMCP/0031/functions.md">built in BaseModelica functions</a> are not yet supported. Array variables and accessing elements of an array are not yet supported. Only models with real scalar parameters, real scalar variables, and equations consisting of simple arithmetic equations and first order derivatives are able to be translated to an MTK model at this time.</p>
