<p align="center" dir="auto">
Julia data dashboard powered by Stipple and Genie. <a href="https://learn.genieframework.com/app-gallery" rel="nofollow">App gallery</a>
</p>
<p dir="auto">Part of <a href="https://genieframework.com" rel="nofollow">Genie Framework</a>, Stipple is a reactive UI library for building interactive data applications in pure Julia.
It uses <a href="https://github.com/GenieFramework/Genie.jl">Genie.jl</a> on the server side and <a href="https://vuejs.org/" rel="nofollow">Vue.js</a> on the client. Stipple uses a high performance architecture that automatically synchronizes the state two-way (server -&gt; client and client -&gt; server), sending only JSON data over the wire.</p>

<p dir="auto">Besides the low-code API provided by Stipple, you can also use <a href="https://learn.genieframework.com/docs/genie-builder/quick-start" rel="nofollow">Genie Builder</a> to build your reactive UIs. Genie Builder is a plugin for VSCode to help you create interactive Genie apps much faster using its visual drag-and-drop editor.</p>
<p dir="auto">To learn more about Stipple and Genie Framework, visit the <a href="https://learn.genieframework.com/docs/guides" rel="nofollow">documentation</a>, and the <a href="https://learn.genieframework.com/app-gallery" rel="nofollow">app gallery</a>.</p>
<p dir="auto">If you need help with anything, you can find us on <a href="https://discord.com/invite/9zyZbD6J7H" rel="nofollow">Discord</a>.</p>
<hr>
<p dir="auto">The Stipple ecosystem also includes:</p>
<ul dir="auto">
<li><a href="https://github.com/GenieFramework/StippleUI.jl">StippleUI.jl</a> - the UI library for <code>Stipple.jl</code>, providing access to 30+ reactive UI elements of the <a href="https://quasar.dev" rel="nofollow">Quasar Framework</a>, including forms, lists, tables, as well as layout.</li>
<li><a href="https://github.com/GenieFramework/StipplePlotly.jl">StipplePlotly.jl</a> - Plotting library for <code>Stipple.jl</code> based on <a href="https://plotly.com/javascript/" rel="nofollow">Plotly</a>'s Graphing Library including event forwarding for interactive plots.</li>
<li><a href="https://github.com/GenieFramework/StipplePlotlyExport.jl">StipplePlotlyExport.jl</a> - add-on for <code>StipplePlotly.jl</code> to allow server side generation and exporting of plots.</li>
<li><a href="https://github.com/GenieFramework/StippleLatex.jl">StippleLatex.jl</a> - support for reactive Latex content based on the <a href="https://github.com/lucpotage/vue-katex">Vue-Katex</a> plugin.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">News: Vue 3 / Quasar 2</h2><a id="user-content-news-vue-3--quasar-2" class="anchor" aria-label="Permalink: News: Vue 3 / Quasar 2" href="#news-vue-3--quasar-2"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">From version 0.30 on Stipple has upgraded the front-end libraries to Vue3 / Quasar 2, as Vue-2 has reached its end-of-life.
We recommend to use at least v0.30.3, as we have fixed some relevant bugs.
(Some of these bugs were also present in previous Vue2 versions.
we therefore recommend to use at least v0.29.1 for legacy Vue2 support.)</p>
<p dir="auto">We have put lots of effort in making migration as easy as possible. Nevertheless, there are some places where advanced apps might need a little tweeking.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Main Changes for version &gt;= v0.30</h2><a id="user-content-main-changes-for-version--v030" class="anchor" aria-label="Permalink: Main Changes for version &gt;= v0.30" href="#main-changes-for-version--v030"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First of all, basic applications continue to function properly without any changes.</p>
<p dir="auto">However, if you have developed applications with external plugins or components you might need to do some adaptations.
We have introduced a vue2compat layer to make the migration as easy as possible.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Components</h3><a id="user-content-components" class="anchor" aria-label="Permalink: Components" href="#components"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Components can no longer be registered in Vue, but rather in the app instance. If you are using legacy components, e.g. by including Vue libraries, you can verify whether they have been recognized by entering <code>vueLegacy</code> in the browser console once the page has been loaded (right-click -&gt; 'Inspect'). Under the field "components" you will find the components to be registered. Registering is then done by adding <code>Stipple.register_global_component("&lt;component name&gt;", legacy = true)</code> to your app.</li>
<li>Vue-2 components often use <code>this.$set(this.field, key, value)</code> to set object fields, which is incompatible with Vue-3 syntax. Use a normal assignment instead, e.g. <code>field[key] = value</code></li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Plugins</h3><a id="user-content-plugins" class="anchor" aria-label="Permalink: Plugins" href="#plugins"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If libraries install plugins, they need to be added to the app via <code>Stipple.add_plugin(MyApp, "&lt;plugin name&gt;")</code>.
If you are using explicit models replace 'MyApp' by the model type, otherwise use the module's name.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Component Attributes</h3><a id="user-content-component-attributes" class="anchor" aria-label="Permalink: Component Attributes" href="#component-attributes"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Vue-2 syntax for synchronizing additional fields other than the v-model has changed from <code>&lt;fieldname&gt;.sync</code> to <code>v-model:&lt;fieldname&gt;</code>, e.g. from <code>:pagination.sync = "myvar</code> to <code>v-model:pagination = "myvar"</code>. In StippleUI we had offered "paginationsync = :myvar" which will be automatically translated to the new syntax. If want to explicitly enter the original form, you can do so by using the var"" syntax, " , e.g. <code>table(:mytable, var"v-model:pagination" = "test")</code></p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Templates</h3><a id="user-content-templates" class="anchor" aria-label="Permalink: Templates" href="#templates"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">In Vue-3 <code>v-if</code> and <code>v-for</code> precedence have change. So if you use both attributes in one component make sure to split your component in a container with a <code>v-for</code> attribute and a component, e.g. <code>div</code> or <code>span</code> with a <code>v-if</code> attribute.
In StippleUI syntax <code>v-if</code> corresponds to <code>@if("...")</code>and <code>v-for</code>  corresponds to <code>@for("...")</code></p>

<p dir="auto">This snippet below illustrates the structure of a reactive UI built with Stipple. See its <a href="https://learn.genieframework.com/docs/reference/reactive-ui/introduction" rel="nofollow">documentation page</a> for a detailed explanation.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="module App
#setup of the Genie Framework environment
using GenieFramework
@genietools

# reactive code
@app begin
    # reactive variables synchronised between server and browser
    @in N = 0
    @out msg = &quot;&quot;
    #reactive handler, executes code when N changes
    @onchange N begin
        msg = &quot;N = $N&quot;
    end
end

# UI components
function ui()
    [
        cell([
                p(&quot;Enter a number&quot;)
                # variables are bound to a component using their symbol name
                textfield(&quot;N&quot;, :N )

  Stipple has a component called btn which is a button with a few extra useful features. For instance, it comes in two shapes:
  rectangle (default) and round. It also has the material ripple effect baked in (which can be disabled).

  The button component also comes with a spinner or loading effect. You would use this for times when app execution may cause a      
  delay and you want to give the user some feedback about that delay. When used, the button will display a spinning animation as     
  soon as the user clicks the button.

  When not disabled or spinning, btn emits a @click event, as soon as it is clicked or tapped.
