<blockquote>
<p dir="auto">Input and output widgets for <code>Pluto</code>, those that didn't get into <code>PlutoUI.jl</code>: too narrow of a usecase, implementation not general enough, etc. <br>
Following <a href="https://github.com/JuliaPluto/PlutoUI.jl/pull/257#issuecomment-1577995821" data-hovercard-type="pull_request" data-hovercard-url="/JuliaPluto/PlutoUI.jl/pull/257/hovercard">Fons's advice</a>, these widgets are put into a separated package, <code>PlutoUIExtra</code>.</p>
</blockquote>
<p dir="auto"><code>PlutoUIExtra</code> reexport everything from <code>PlutoUI</code> (and adds extra). There's no need to manually import both in your code.</p>
<p dir="auto">For now, contains the following widgets:</p>
<ul dir="auto">
<li><code>Sidebar</code>: <a href="https://aplavin.github.io/PlutoUIExtra.jl/src/sidebar.html" rel="nofollow">usage &amp; implementation</a>, <a href="https://github.com/JuliaPluto/PlutoUI.jl/pull/257" data-hovercard-type="pull_request" data-hovercard-url="/JuliaPluto/PlutoUI.jl/pull/257/hovercard">PlutoUI PR</a></li>
<li><code>Slider</code>: <a href="https://aplavin.github.io/PlutoUIExtra.jl/src/slider.html" rel="nofollow">usage &amp; implementation</a>
<ul dir="auto">
<li>CSS styling: <a href="https://github.com/JuliaPluto/PlutoUI.jl/pull/258" data-hovercard-type="pull_request" data-hovercard-url="/JuliaPluto/PlutoUI.jl/pull/258/hovercard">PlutoUI PR</a></li>
<li>trigger on mouse release: <a href="https://github.com/JuliaPluto/PlutoUI.jl/pull/268" data-hovercard-type="pull_request" data-hovercard-url="/JuliaPluto/PlutoUI.jl/pull/268/hovercard">PlutoUI PR</a></li>
</ul>
</li>
<li><code>Select</code> with specified <code>size</code> (height): <a href="https://aplavin.github.io/PlutoUIExtra.jl/src/select.html" rel="nofollow">usage &amp; implementation</a></li>
<li><code>Radio</code> with specified <code>orientation</code>: <a href="https://aplavin.github.io/PlutoUIExtra.jl/src/radio.html" rel="nofollow">usage &amp; implementation</a></li>
<li><code>TextField</code> with an autocomplete list (<code>options</code>): <a href="https://aplavin.github.io/PlutoUIExtra.jl/src/textfield.html" rel="nofollow">usage &amp; implementation</a></li>
</ul>
<p dir="auto">Feel free to suggest more!</p>
