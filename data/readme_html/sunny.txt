<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Sunny is a Julia package for modeling atomic-scale magnetism. Through spin dynamics simulations, it enables direct comparison with experimental scattering data, e.g., neutrons or x-rays. Ease of use is a priority, with tools for symmetry-guided modeling and interactive visualization.</p>
<p dir="auto">At low-temperatures, Sunny supports the usual linear spin wave theory of spin dipoles, and its <a href="https://arxiv.org/abs/1307.7731" rel="nofollow">multi-flavor generalization</a>. At finite temperatures, Sunny can calculate the dynamical structure factor using classical spin dynamics with <a href="https://arxiv.org/abs/2310.19905" rel="nofollow">quantum corrections</a>. Langevin coupling to a thermal bath makes possible the study of non-equilibrium dynamics, e.g., thermal transport, pump-probe experiments, and spin-glass relaxation. Sunny also provides powerful Monte Carlo algorithms for collecting statistics in thermal equilibrium.</p>
<p dir="auto">A unique feature of Sunny is its treatment of spins as <a href="https://arxiv.org/abs/2106.14125" rel="nofollow">SU(<em>N</em>) coherent states</a>. This theory generalizes Landau-Lifshitz spin dynamics to a <a href="https://arxiv.org/abs/2204.07563" rel="nofollow">nonlinear Schrödinger equation</a>, which retains <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="5566c05b387d646c8db2fe927fa1f151">$N=2s+1$</math-renderer> levels for each quantum spin-<em>s</em> state. The generalization is important for models with strong single-ion anisotropy (see the <strong><a href="https://sunnysuite.github.io/Sunny.jl/stable/examples/03_LSWT_SU3_FeI2.html" rel="nofollow">FeI₂ tutorial</a></strong>) and for <a href="https://arxiv.org/abs/2405.16315" rel="nofollow">localized "units" of strongly entangled spins</a>.  Efficient simulation is enabled by <a href="https://github.com/SunnySuite/Sunny.jl/wiki/Sunny-literature">several algorithmic advances</a>.</p>

<p dir="auto"><a href="https://github.com/SunnySuite/Sunny.jl/wiki/Getting-started-with-Julia">Install Sunny</a> and try the <strong><a href="https://sunnysuite.github.io/Sunny.jl/stable/examples/01_LSWT_CoRh2O4" rel="nofollow">Tutorials</a></strong>. For traditional linear spin wave theory, see also the <strong><a href="https://sunnysuite.github.io/Sunny.jl/stable/examples/spinw/SW01_FM_Heseinberg_chain.html" rel="nofollow">SpinW ports</a></strong>.</p>
<p dir="auto">See <a href="https://sunnysuite.github.io/Sunny.jl/dev/versions" rel="nofollow">Version History</a> for new features and breaking changes. To install a specific version of Sunny, say <code>v0.x</code>, use the command <code>add Sunny@0.x</code>.</p>
