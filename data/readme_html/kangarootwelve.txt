<p dir="auto">A pure-Julia implementation of the <a href="https://keccak.team/kangarootwelve.html" rel="nofollow">KangarooTwelve</a> hashing scheme, so named
  because it consists of 12 rounds of <a href="https://keccak.team/keccak.html" rel="nofollow">Keccak</a> (<a href="https://keccak.team/turboshake.html" rel="nofollow">TurboSHAKE</a>128) with kangaroo
  hopping, allowing for parallel <a href="https://en.wikipedia.org/wiki/Merkle_tree" rel="nofollow">tree</a>-ish hashing termed “leaves stapled to a pole”.</p>
<p dir="auto">This scheme presents a particularly good balance of:</p>
<ul dir="auto">
  <li>Simplicity (Keccak + sponge + hopping)</li>
  <li>Security (128-bit)</li>
  <li>Speed (up to ~2bytes/cycle)</li>
</ul>
<p dir="auto">It is currently an <a href="https://datatracker.ietf.org/doc/draft-irtf-cfrg-kangarootwelve/" rel="nofollow">IETF draft</a>.</p>
