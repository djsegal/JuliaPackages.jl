<p dir="auto">A simple library which allows you to do algebraic manipulations on neural
network models/layers defined in <a href="https://github.com/LuxDL/Lux.jl">Lux.jl</a>, for
example if <code>l1</code> and <code>l2</code> are Lux layers, then</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="l3 = @lift_nn 2*l1 + l2"><pre>l3 <span class="pl-k">=</span> <span class="pl-c1">@lift_nn</span> <span class="pl-c1">2</span><span class="pl-k">*</span>l1 <span class="pl-k">+</span> l2</pre></div>
<p dir="auto">defines a Lux layer <code>l3</code> such that for an input <code>x</code>, the layer produces an output
<code>l3(x) = 2*l1(x) + l2(x)</code>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Technical Motivation</h2><a id="user-content-technical-motivation" class="anchor" aria-label="Permalink: Technical Motivation" href="#technical-motivation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Given two real-valued functions <code>f</code> and <code>g</code> which have the same domain, we can
define an algebra over the real numbers such that <code>h=f+g</code> defines another
real-valued function <code>h</code>. Because parameterized neural networks can be defined
as real-valued functions over the real numbers (excluding their parameters), then
we can <a href="https://en.wikipedia.org/wiki/Lift_(mathematics)" rel="nofollow">"lift"</a> this algebra
to an algebra over neural networks.</p>

<ul dir="auto">
<li>Works generically for any function call, not just algebraic operators (i.e.,
recall that in Julia even arithmetic operations like <code>a+b+c</code> are themselves simply
n-ary function calls <code>+(a,b,c)</code>)</li>
<li>Does not introduce any new state or learnable parameters</li>
</ul>
