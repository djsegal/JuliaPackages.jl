<p dir="auto">ChaoticDynamicalSystemLibrary.jl is a collection of chaotic dynamical systems for the Julia <a href="https://sciml.ai/" rel="nofollow">SciML</a> ecosystem.</p>
<p dir="auto">The package is a partial port of the <a href="https://github.com/williamgilpin/dysts"><code>dysts</code></a> Python package developed by <a href="https://github.com/williamgilpin">William Gilpin</a>.
It implements many (but not all) of the same systems, but does not provide any functionality to simulate them.
In contrast to <a href="https://github.com/williamgilpin/dysts"><code>dysts</code></a>, the main focus of this package is not to be a benchmark for general time-series ML models, but only to provide a collection of ODEs.
Their simulation is left to other packages, such as <a href="https://diffeq.sciml.ai/stable/" rel="nofollow">DifferentialEquations.jl</a>.</p>
<hr>
<p dir="auto"><strong><a href="https://github.com/williamgilpin"><strong>William Gilpin</strong></a> deserves most of the credit for this package.
He is the original author of the <a href="https://github.com/williamgilpin/dysts"><code>dysts</code></a>, and without <a href="https://github.com/williamgilpin/dysts"><code>dysts</code></a> this package would not exist.</strong></p>
