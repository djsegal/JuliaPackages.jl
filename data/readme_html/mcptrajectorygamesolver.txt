<p dir="auto">This package provides a thin wrapper around the <a href="https://github.com/lassepe/ParametricMCPs.jl">ParametricMCPs.jl</a> package to solve trajectory games from
<a href="https://github.com/JuliaGameTheoreticPlanning/TrajectoryGamesBase.jl">TrajectoryGamesBase.jl</a>.</p>
<p dir="auto">By exploiting the implicit function theorem, game solutions can be differentiated with respect to the game parameters.
This sensitivity information can be used to fit a game-theoretic model to observed behavior as we explore in our work <a href="https://xinjie-liu.github.io/projects/game/" rel="nofollow">Learning to Play Trajectory Games Against Opponents with Unknown Objectives</a>.</p>

<p dir="auto">Installation is as simple as running:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="]add MCPTrajectoryGameSolver"><pre>]add MCPTrajectoryGameSolver</pre></div>
<p dir="auto">This package uses PATH solver (via <a href="https://github.com/chkwon/PATHSolver.jl">PATHSolver.jl</a>) under the hood. Larger-sized problems require to have a license key. By courtesy of Steven Dirkse, Michael Ferris, and Tudd Munson, temporary license keys are available free of charge. For more details about the license key, please consult <a href="https://github.com/chkwon/PATHSolver.jl">PATHSolver.jl</a> (License section). Note that, when no license is loaded, PATH does not report an informative error and instead may just report a wrong result. Thus, make sure that the license is loaded correctly before using the solver.</p>

<p dir="auto">The original solver implementation and experiment code used in our research <a href="https://arxiv.org/pdf/2211.13779.pdf" rel="nofollow">Learning to Play Trajectory Games Against Opponents with Unknown Objectives</a> can be found <a href="https://github.com/xinjie-liu/DifferentiableAdaptiveGames.jl">here</a>. This repository provides a more optimized implementation of the differentiable game solver. We kindly ask you to cite our paper if you use either of the implementations in your research. Thanks!</p>
