<p dir="auto"><code>ParametricDFNOs.jl</code> is a Julia Language-based scientific library designed to facilitate training Fourier Neural Operators involving large-scale data using <a href="https://github.com/slimgroup/ParametricOperators.jl"><code>ParametricOperators.jl</code></a>. We offer support for distributed 2D and 3D time varying problems.</p>
