<p dir="auto">Struct and constructor for ThreadSafeDict. There is one lock per Dict struct. All functions lock this lock, pass
arguments to the d member Dict, unlock the spinlock, and then return what is returned by the Dict.</p>
<p dir="auto">If there are going to be a large number of threads competing to update the <code>Dict</code>, causing most of the threads to
be blocked at any given time, you may be better off keeping a <code>Dict</code> in a separate thread which accepts updates
via a <code>Channel</code> of <code>Pair</code>s.  YMMMV.</p>

<p dir="auto">All of the above methods work as in those of the base <code>Dict</code> type. However, they all
lock a spinlock prior to passing the arguments to a base <code>Dict</code> within the struct, then
unlock the base <code>Dict</code> prior to returning the function call results. Thus, with a single
thread the functions are equivalent to those of a base <code>Dict</code>, but with multiple threads
thread access to the underlying <code>Dict</code> is serialized per <code>ThreadSafeDict</code>.</p>
