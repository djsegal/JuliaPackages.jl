<p dir="auto">The first step is to chose whether we want to run our simulation on the CPU or Nvidia or AMD GPUs. This is done by setting the <code>backend</code> variable to either <code>CUDABackend</code>, <code>AMDGPUBackend</code> or <code>CPUBackend</code>. In the following we will assume that we are running on a Nvidia GPU.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const backend = CUDABackend # Options: CPUBackend, CUDABackend, AMDGPUBackend"><pre><span class="pl-k">const</span> backend <span class="pl-k">=</span> CUDABackend <span class="pl-c"><span class="pl-c">#</span> Options: CPUBackend, CUDABackend, AMDGPUBackend</span></pre></div>
<p dir="auto">and load the required packages:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JustPIC, JustPIC._2D

<p dir="auto">The velocity field is defined by the stream function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="c577c81c24bdc8819e47a715e1c9917e">$\psi=\frac{250}{\pi}\sin(\pi x)\cos(\pi y)$</math-renderer>, so that the analytical velocity field at the particle <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="c577c81c24bdc8819e47a715e1c9917e">$p=p(x,y)$</math-renderer> is given by</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="vx_stream(x, y) =   250 * sin(π*x) * cos(π*y)
vy_stream(x, y) =  -250 * cos(π*x) * sin(π*y)"><pre><span class="pl-en">vx_stream</span>(x, y) <span class="pl-k">=</span>   <span class="pl-c1">250</span> <span class="pl-k">*</span> <span class="pl-c1">sin</span>(π<span class="pl-k">*</span>x) <span class="pl-k">*</span> <span class="pl-c1">cos</span>(π<span class="pl-k">*</span>y)
<span class="pl-en">vy_stream</span>(x, y) <span class="pl-k">=</span>  <span class="pl-k">-</span><span class="pl-c1">250</span> <span class="pl-k">*</span> <span class="pl-c1">cos</span>(π<span class="pl-k">*</span>x) <span class="pl-k">*</span> <span class="pl-c1">sin</span>(π<span class="pl-k">*</span>y)</pre></div>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Vx = TA(backend)([vx_stream(x, y) for x in grid_vx[1], y in grid_vx[2]]);
