<p dir="auto">This package builds a web-scraping and web-crawling library atop the <a href="https://github.com/ChifiSource/Toolips.jl">toolips</a> web-development framework. This package prominently features high-level syntax atop the <code>Toolips</code> <code>Component</code> structure.</p>

<p dir="auto"><code>ToolipsCrawl</code> usage centers around the <code>Crawler</code> type. This constructor is never called directly in conventional usage of the package, <strong>instead</strong> we use the high-level methods for <code>scrape</code> and <code>crawl</code>.</p>
<ul dir="auto">
<li><code>scrape(f::Function, address::String)</code> -&gt; <code>::Crawler</code></li>
<li><code>scrape(f::Function, address::String, components::String ...)</code> -&gt; <code>::Crawler</code></li>
<li><code>crawl(f::Function, address::String)</code> -&gt; <code>::Crawler</code></li>
<li><code>crawl(f::Function, addresses::String ...)</code> -&gt; <code>::Crawler</code></li>
</ul>
<p dir="auto">Each of these functions returns a <code>Crawler</code>, and each <code>f</code> takes that same <code>Crawler</code> as its single positional argument. A <code>Crawler</code> is used for two things -- firstly, to turn an HTML page into a <code>Vector{Servable}</code>. Secondly, find any URLs within that page and crawl to them. The former is done with both <code>scrape</code> and <code>crawl</code>, whereas the latter is exclusively done with <code>crawl</code>. <strong>Scraping</strong> will give us an easy way to view one page and aggregate its data, <strong>crawling</strong> will give us an easy way to collect data from pages indefinitely -- or until we run out of links, at which point our <code>Crawler</code> will <code>kill!</code> itself.</p>

<p dir="auto">Scraping with <code>ToolipsCrawl</code> is done using the <code>scrape</code> function. There are two <code>scrape</code> methods, one takes a <code>String</code> (the address) and a <code>Vector{String}</code>. This function will grab exclusively the components in this <code>Vector</code>. Providing only the address will read all components. Consider the following example,</p>

Crawling works the same as scraping, only it is recurring and searches for additional addresses on each page.</p>

<p dir="auto"><code>ToolipsCrawl</code> provides a basic filtering API for the <code>Vector{Servable}</code> type. This API revolves around the <code>Toolips.get</code> <code>Function</code>, which we provide with a <code>Crawler</code>, a <code>ComponentFilter</code>, and a <code>String</code>. The <code>ComponentFilter</code> determines the operation and the <code>String</code> determines the value. This may also be done by simply getting the index of a <code>Crawler</code> with a <code>ComponentFilter</code></p>
