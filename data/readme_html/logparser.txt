<p dir="auto">LogParser.jl is a package for parsing server logs. Currently, only server logs having the <a href="http://httpd.apache.org/docs/2.2/logs.html#combined" rel="nofollow">Apache Combined</a> format are supported (although <a href="http://httpd.apache.org/docs/2.2/logs.html#common" rel="nofollow">Apache Common</a> may parse as well). Additional types of logs may be added in the future as well.</p>
<p dir="auto">LogParser.jl will attempt to handle the log format even if it is mangled, returning partial matches as best as possible. For example, if the end of the log entry is mangled, you may still get an IP address returned, timestamp and other parts that were able to be parsed.</p>
