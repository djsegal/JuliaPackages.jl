<p dir="auto">This package provides functionality for converting PLEXOS 8 .zip solution files
into H5PLEXOS-formatted HDF5 files (using H5PLEXOS format version 0.6).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Installing this package requires adding the
<code>NREL</code> Julia package registry. If you've never used Julia before,
run <code>update</code> in the package management prompt to make sure the <code>General</code>
registry is installed first:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; update"><pre>pkg<span class="pl-k">&gt;</span> update</pre></div>
<p dir="auto">Now you can add the NREL registry:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; registry add https://github.com/NREL/JuliaRegistry.git"><pre>pkg<span class="pl-k">&gt;</span> registry add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>NREL<span class="pl-k">/</span>JuliaRegistry<span class="pl-k">.</span>git</pre></div>
<p dir="auto">Once this is done the package can be installed normally.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add H5PLEXOS"><pre>pkg<span class="pl-k">&gt;</span> add H5PLEXOS</pre></div>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Processing solutions</h2><a id="user-content-processing-solutions" class="anchor" aria-label="Permalink: Processing solutions" href="#processing-solutions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The module exports the  function <code>process</code> which handles conversion. For
example, to convert a file named <code>plexossolution.zip</code> to <code>plexossolution.h5</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using H5PLEXOS
process(&quot;plexossolution.zip&quot;, &quot;plexossolution.h5&quot;)"><pre><span class="pl-k">using</span> H5PLEXOS
<span class="pl-c1">process</span>(<span class="pl-s"><span class="pl-pds">"</span>plexossolution.zip<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>plexossolution.h5<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">If processing the file is all you need to do in Julia, you may find it simpler
to call the function directly from the shell, rather than writing a script:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia -e 'using H5PLEXOS; process(&quot;plexossolution.zip&quot;, &quot;plexossolution.h5&quot;)'"><pre>julia -e <span class="pl-s"><span class="pl-pds">'</span>using H5PLEXOS; process("plexossolution.zip", "plexossolution.h5")<span class="pl-pds">'</span></span></pre></div>
<p dir="auto">To include bash variables in the above command, the correct synatx involves escape characters like so:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project -e &quot;using H5PLEXOS; process(\&quot;$dir/Model $model Solution.zip\&quot;,\&quot;$dir/Model $model Solution.h5\&quot;)&quot;"><pre>julia --project -e <span class="pl-s"><span class="pl-pds">"</span>using H5PLEXOS; process(<span class="pl-cce">\"</span><span class="pl-smi">$dir</span>/Model <span class="pl-smi">$model</span> Solution.zip<span class="pl-cce">\"</span>,<span class="pl-cce">\"</span><span class="pl-smi">$dir</span>/Model <span class="pl-smi">$model</span> Solution.h5<span class="pl-cce">\"</span>)<span class="pl-pds">"</span></span></pre></div>
<p dir="auto">The function accepts a number of keyword arguments to customize the process:</p>
<p dir="auto"><code>compressionlevel</code>: Set the level of compression to be used (0-9).
Default is <code>1</code>.</p>
<p dir="auto"><code>strlen</code>: PLEXOS object and category names are saved in the HDF5 file as
fixed-length strings. Use this parameter to adjust the length of those strings
(if long names are being truncated, for example). Default is <code>128</code>.</p>
<p dir="auto"><code>dateformat</code>: A Julia <code>DateFormat</code> object explaining how to parse localized
timestamps reported by PLEXOS. Default is <code>DateFormat("d/m/y H:M:S")</code>.</p>
<p dir="auto"><code>sample</code>: A <code>String</code> providing the name of the stochastic sample to be
processed. Defaults to <code>"Mean"</code>.</p>

<p dir="auto">The package does does not currently provide tools for querying the generated
files (see the <a href="https://github.com/NREL/h5plexos">h5plexos</a> Python package
for that). If you would be interested in having this functionality in Julia,
leave an issue or email Gord to let him know. Of course, you can always read
the HDF5 data directly with <a href="https://github.com/JuliaIO/HDF5.jl">HDF5.jl</a>.</p>
