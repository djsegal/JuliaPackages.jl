<p dir="auto"><em>Why does this exist?</em></p>
<p dir="auto">Imagine you're writing a blog post. Or a <a href="https://plutojl.org" rel="nofollow">Pluto</a> notebook.
Or a <a href="https://jupyter.org" rel="nofollow">Jupyter</a> notebook. Or whatever! You're writing words
alongside content, and you'd like to license your work. The license needs to
stand <em>alone</em> with your document; the "naive" solution is to find the contents
of your standard license file, and paste the license into a block of text
somewhere in your document. Cool. Two weeks later you're writing <em>another</em> blog
post, or whatever. You need to re-find the contents of this license. Not a big
deal, but this gets a bit cumbersome, right?</p>
<p dir="auto">Enter: <code>CommonLicenses.jl</code>. This package provides every standard license tracked
by the <a href="https://spdx.org/licenses/" rel="nofollow">SPDX License List</a>, so all you need to do is
install this package, and print your desired license wherever you want it!</p>

<p dir="auto"><em>Built on top of lots of helpful projects!</em></p>
<p dir="auto">This package was developed independently of
<a href="https://github.com/JuliaPackaging/PkgLicenses.jl/tree/master"><code>PkgLicenses.jl</code></a>,
though it does look like <code>JuliaPackaging</code> got there first! This package adds
goodies on top of the functionality of <code>PkgLicenses.jl</code>, including <code>MIME</code> type
support, and licenses for non-software projects such as Creative Commons.</p>
<p dir="auto">The <a href="https://spdx.org/licenses/" rel="nofollow">SPDX License List</a> is used to fetch the
contents for each requested license. The GitHub
<a href="https://docs.github.com/en/rest/licenses">License API</a> is used to find
additional metadata for each license, if available.</p>
