<p dir="auto"><a href="https://github.com/JoshuaBillson/RemoteSensingToolbox.jl">RemoteSensingToolbox</a> is a pure Julia package built
on top of <a href="https://github.com/rafaqz/Rasters.jl">Rasters.jl</a> for reading, visualizing, and processing remotely
sensed imagery. Users may refer to the Tutorials section in the
<a href="https://JoshuaBillson.github.io/RemoteSensingToolbox.jl/stable/" rel="nofollow">docs</a> for examples on how to use this package.</p>

<p dir="auto">To install this package, first start the Julia REPL and then open the package manager by typing <code>]</code>.
You can then download <code>RemoteSensingToolbox</code> directly from the official Julia repository like so:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(@v1.9) pkg&gt; add RemoteSensingToolbox"><pre class="notranslate"><code>(@v1.9) pkg&gt; add RemoteSensingToolbox

<p dir="auto">Once <code>RemoteSensingToolbox</code> has been installed, you can import it like any other Julia package. Please
note that many features require you to also import the <code>Rasters</code> package.</p>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Quickstart Example</h1><a id="user-content-quickstart-example" class="anchor" aria-label="Permalink: Quickstart Example" href="#quickstart-example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Typically, the first step in a workflow is to read the desired layers from disk. To do so, we first need to place
our product within the appropriate context; in this case <code>Landsat8</code>. With this done, we can load whichever
layers we desire by simply requesting them by name. A complete list of all available layers can be acquired by
calling <code>layers(Landsat8)</code>. We typically use a <code>Raster</code> to load a single layer, while a <code>RasterStack</code> is used
to load multiple layers at once. By default, <code>RasterStack</code> will read all of the band layers when none are
specified. We can also set <code>lazy=true</code> to avoid reading everything into memory up-front.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using RemoteSensingToolbox, Rasters

# Read Landsat Bands
src = Landsat8(&quot;data/LC08_L2SP_043024_20200802_20200914_02_T1&quot;)
stack = RasterStack(src, lazy=true)"><pre><span class="pl-k">using</span> RemoteSensingToolbox, Rasters

<span class="pl-c"><span class="pl-c">#</span> Read Landsat Bands</span>
src <span class="pl-k">=</span> <span class="pl-c1">Landsat8</span>(<span class="pl-s"><span class="pl-pds">"</span>data/LC08_L2SP_043024_20200802_20200914_02_T1<span class="pl-pds">"</span></span>)
stack <span class="pl-k">=</span> <span class="pl-c1">RasterStack</span>(src, lazy<span class="pl-k">=</span><span class="pl-c1">true</span>)</pre></div>
<p dir="auto">Now let's visualize our data to see what we're working with. The <code>true_color</code> method uses the red, green, and
blue bands to produce an image that is familiar to the human eye. In most other frameworks, we would have to specify
each of these bands individually, which in turn requires knowledge about the sensor in question. However, because
we have placed our scene within a <code>Landsat8</code> context, <code>true_color</code> is smart enough to figure this out on its own.
As an alternative, we could have also called <code>true_color(Landsat8, stack; upper=0.90)</code>, which requires passing in
the sensor type as the first agument and a <code>RasterStack</code> containing the required bands as the second. Many
other methods in <code>RemoteSensingToolbox</code> follow this same pattern.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="true_color(src; upper=0.90)"><pre><span class="pl-c1">true_color</span>(src; upper<span class="pl-k">=</span><span class="pl-c1">0.90</span>)</pre></div>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="https://github.com/JoshuaBillson/RemoteSensingToolbox.jl/blob/main/docs/src/figures/true_color.jpg?raw=true"><img src="https://github.com/JoshuaBillson/RemoteSensingToolbox.jl/raw/main/docs/src/figures/true_color.jpg?raw=true" alt="" style="max-width: 100%;"></a></p>
<p dir="auto">You may have noticed that we set the keyword <code>upper</code> to 0.90. This parameter defines the upper quantile that
is used during histogram adjustment and is set to 0.98 by default. However, the presence of bright clouds
requires us to lower it in order to prevent the image from appearing too dark. We can remove these clouds by
passing the cloud and cloud shadow masks into the <code>apply_masks</code> method. As with other layers, we can simply
request them by name.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Mask Clouds

shadow_mask = Raster(src, :cloud_shadow)

# Visualize in True Color
true_color(Landsat8, masked)"><pre><span class="pl-c"><span class="pl-c">#</span> Mask Clouds</span>

<p dir="auto">Now let's try to visualize some other band combinations. The <code>Agriculture</code> band combination is commonly used to
emphasize regions with healthy vegetation, which appear as various shades of green.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="agriculture(src; upper=0.90)"><pre><span class="pl-c1">agriculture</span>(src; upper<span class="pl-k">=</span><span class="pl-c1">0.90</span>)</pre></div>

<p dir="auto">We'll finish this example by computing a few different land cover indices. Each index expects two bands as input,
such as green and swir (MNDWI), red and nir (NDVI), or nir and swir (NDMI). As with visualization, we do
not need to specify these bands manually so long as the sensor type is known. In general, each index has
three forms: one that requires only a single <code>AbstractSatellite</code> instance, a second that expects both the type
of satellite and a <code>RasterStack</code>, and a third which expects a <code>Raster</code> for each band.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Extract Region of Interest
roi = @view masked[X(5800:6800), Y(2200:3200)]

mosaic = mosaicview([tc, indices...]; npad=10, fillvalue=0.0, ncol=2, rowmajor=true)"><pre><span class="pl-c"><span class="pl-c">#</span> Extract Region of Interest</span>
