<p dir="auto"><code>Eglob</code> provides extended globbing functions that support a recursive <code>**</code>
wildcard pattern, similar to the <code>**</code> supported by the
<a href="https://www.gnu.org/software/bash/" rel="nofollow">Bash</a> (version 4+) <code>globstar</code> option
and by <a href="http://www.zsh.org/" rel="nofollow">Zsh</a>. This package is built on top of
<a href="https://github.com/vtjnash/Glob.jl">Glob.lj</a>.</p>
<ul dir="auto">
<li><code>eglob()</code>: An extended globbing function that supports leading <code>~</code> expansion
and a recursive <code>**</code> wildcard pattern</li>
<li><code>eglobt()</code>: A Task- and Channel-based version of <code>eglob()</code>.</li>
</ul>
