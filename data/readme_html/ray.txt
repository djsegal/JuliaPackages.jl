<p dir="auto">Make sure the appropriate Python environment (i.e. <code>source venv/bin/activate</code>) is active (wherever you <a href="https://beacon-biosignals.github.io/Ray.jl/stable/installation/" rel="nofollow"><code>pip install</code>ed the Ray CLI</a>) and then do:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ray start --head"><pre>ray start --head</pre></div>
<p dir="auto">to start and</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ray stop"><pre>ray stop</pre></div>
<p dir="auto">to stop.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Where can I find log files?</h3><a id="user-content-where-can-i-find-log-files" class="anchor" aria-label="Permalink: Where can I find log files?" href="#where-can-i-find-log-files"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The directory <code>/tmp/ray/session_latest/logs</code> contains logs for the current or last ran ray backend.</p>
<p dir="auto">The <code>raylet.err</code> is particularly informative when debugging workers failing to start, since error output before connecting to the Ray server is printed there.</p>
<p dir="auto">Driver logs generated by Ray are printed in <code>julia-core-driver-$(JOBID)_$(PID).log</code>, and julia worker logs are in <code>julia_worker_$(PID).log</code> (although this may change).</p>

<p dir="auto">Check the raylet logs in <code>/tmp/ray/session_latest/logs/raylet.err</code>.  If you see something about Revise (or another package) not being found, make sure you're not doing something like unconditionally <code>using Revise</code> in your <code>~/.julia/config/startup.jl</code> file; it's generally a good idea to wrap any <code>using</code>s in your startup.jl in a <code>try</code>/<code>catch</code> block <a href="https://timholy.github.io/Revise.jl/stable/config/#Using-Revise-by-default-1" rel="nofollow">like the Revise docs recommend</a>.</p>
