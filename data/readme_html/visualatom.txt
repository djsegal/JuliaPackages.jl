<p dir="auto">Having trouble installing Julia? You can save yourself the trouble of installation by using a Docker container.</p>
<div class="highlight highlight-text-shell-session notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ make &amp;&amp; docker compose run --rm shell julia --procs auto run.jl"><pre>$ <span class="pl-s1">make <span class="pl-k">&amp;&amp;</span> docker compose run --rm shell julia --procs auto run.jl</span></pre></div>
<p dir="auto">The entrypoint script <code>run.jl</code> uses parallel processing via <code>Distributed</code> module (Julia's standard library).</p>
<p dir="auto">For those who want to run with multiple threads, use <code>run_mt.jl</code>:</p>
<div class="highlight highlight-text-shell-session notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ make &amp;&amp; docker compose run --rm shell julia --threads auto run_mt.jl"><pre>$ <span class="pl-s1">make <span class="pl-k">&amp;&amp;</span> docker compose run --rm shell julia --threads auto run_mt.jl</span></pre></div>
<p dir="auto">You can adjust the number of threads using the <code>-t</code> or <code>--threads</code> option:</p>
<div class="highlight highlight-text-shell-session notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="-t, --threads {N|auto}     Enable N threads; &quot;auto&quot; currently sets N to the number of local
                            CPU threads but this might change in the future"><pre><span class="pl-c1">-t, --threads {N|auto}     Enable N threads; "auto" currently sets N to the number of local</span>
<span class="pl-c1">                            CPU threads but this might change in the future</span></pre></div>
