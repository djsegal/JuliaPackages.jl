<p dir="auto">This repository holds a component using the <a href="https://www.mimiframework.org" rel="nofollow">Mimi</a> framework which provides parameters from the Resources for the Future (RFF) RFF Socioeconomic Projections (RFF SPs). These include socioeconomic (population and GDP) and emissions (CO2, CH4, and CH4), to be connected with as desired with other Mimi components and run in Mimi models.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">The <code>id</code> parameter and Monte Carlo Simulations</h3><a id="user-content-the-id-parameter-and-monte-carlo-simulations" class="anchor" aria-label="Permalink: The id parameter and Monte Carlo Simulations" href="#the-id-parameter-and-monte-carlo-simulations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>id</code> parameter in this component (default id of 6546) which allows one to run the model with a specified parameter set of ID <code>id</code> within the data.  By nature of these projections, this component should be run using a Monte Carlo Simulation sampling over the IDs in order to obtain a representative distribution of plausible outcomes, but providing an ID may be useful for debugging purposes.</p>
<p dir="auto">The <code>get_mcs</code> function defines a simple Monte Carlo simulation. It returns a <code>Mimi.SimulationDef</code> obect, which can be <code>run</code> and explore using the <a href="https://www.mimiframework.org/Mimi.jl/stable/howto/howto_3/#.-The-%5Brun%5D(@ref)-function-1" rel="nofollow"><code>run</code> function</a> and more generally the <a href="https://www.mimiframework.org/Mimi.jl/stable/howto/howto_3/" rel="nofollow">Mimi API for Monte Carlo Simulations</a>. By default the mcs assigns random variable taking on values of 1 through 10,000 with equal probability to the sample ID <code>id</code>, alternatively the user may provide a predetermined vector of <code>sampling_ids</code> holding the Integer values of the samples they would like run, in order.</p>

<p dir="auto">If a user wants to connect the <code>m[:SPs, :population]</code> output variable to another Mimi component that requires population at a more aggregated regional level, the <code>RegionAggregatorSum</code> component can be helpful. This helper component aggregates countries to regions with a provided mapping via the <code>sum</code> function (other functions can be added as desired, this is a relatively new and nimble component). You will need to provide a mapping between the input regions (countries here) and output regions (regions here) in a Vector of the length of the input regions and each element being one of the output regions. Note that this component is not yet optimized for performance.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Start with the model `m` from above and add the component with the name `:PopulationAggregator`
