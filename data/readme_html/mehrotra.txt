<p dir="auto">A solver for cone-constrained feasibility problems. The main application for this solver is implicit integration of contact dynamics.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Standard form</h2><a id="user-content-standard-form" class="anchor" aria-label="Permalink: Standard form" href="#standard-form"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Problems of the following form:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="find         x = [y, z, s]

subject to   f(y,z,s; p) = 0,
             z ∘ s = κ
             z, s in K = R+ x Q^1 x ... x Q^k"><pre class="notranslate"><code>find         x = [y, z, s]

subject to   f(y,z,s; p) = 0,
             z ∘ s = κ
             z, s in K = R+ x Q^1 x ... x Q^k
</code></pre></div>
<p dir="auto">can be optimized for</p>
<ul dir="auto">
<li>x = [y, z, s]: decision variables</li>
<li>y: primal variables</li>
<li>z: dual variables</li>
<li>s: slack variables</li>
<li>p: problem parameters</li>
<li>κ: central-path parameter</li>
<li>∘: cone product</li>
<li>K: Cartesian product of convex cones; nonnegative orthant R+ and second-order cones Q are currently implemented</li>
</ul>
