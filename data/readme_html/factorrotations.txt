<p dir="auto"><a href="https://github.com/p-gw/FactorRotations.jl">FactorRotations.jl</a> implements factor rotations by the gradient projections algorithms described
in Bernaards &amp; Jennrich (2005).</p>

<p dir="auto">FactorRotations.jl provides methods to rotate factor loading matrices, e.g. from
exploratory factor analysis or principle component analysis.</p>
<p dir="auto">Assume you aquired a factor loading matrix <code>L</code> then you can rotate the matrix by calling
the <code>rotate</code> function. The <code>rotate</code> function takes the factor loading matrix as the first
argument and an instance of a rotation method as the second argument.</p>
