<p dir="auto">PlutoPDF.jl is just a combination of other software:</p>
<ul dir="auto">
<li>Pluto: besides running notebooks, the Pluto editor is designed to look nice when printed. When you use Pluto's export to Static PDF button (top right in the editor), the button just tells the browser to open the Print window.</li>
<li>Chromium web browser: Pluto has CSS styling specific for printing. But it is the browser that has the ability to take HTML and CSS and make a PDF from it.</li>
<li>PlutoSliderServer: this package makes it easy to "convert <code>.jl</code> to <code>.html</code>." It can open a notebook, run it, and generate the export HTML all from the command line, so you don't need to click buttons in Pluto.</li>
