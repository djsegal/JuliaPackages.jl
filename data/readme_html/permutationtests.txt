<p dir="auto">A fast pure-<a href="https://julialang.org/" rel="nofollow"><strong>julia</strong></a> package for <em>univariate</em> and <em>multiple comparisons</em> statistical <em>hypothesis testing</em> based on <em>permutation theory</em>.</p>
<p dir="auto">Besides featuring an API with many tests, this package allows you to create your own permutation tests.</p>
<hr>

<p dir="auto">All tests have a <em>univariate</em> and <em>multiple comparisons</em> version:</p>
<ul dir="auto">
<li>Pearson product-moment correlation</li>
<li>Trend correlation (fit of any kind of regression)</li>
<li>Point bi-serial correlation*</li>
<li>Student's t for independent samples</li>
<li>1-way ANOVA for independent samples</li>
<li>Χ² for 2xK contingency tables*</li>
<li>Fisher exact test* (2x2 contingency tables)</li>
<li>Student's t for repeated-measures</li>
<li>1-way ANOVA for repeated-measures</li>
<li>Cochran Q*</li>
<li>McNemar*</li>
<li>One-sample Student's t</li>
<li>Sign*</li>
</ul>
<p dir="auto">(* for dicothomous data)</p>
