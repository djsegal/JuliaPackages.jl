<p dir="auto">This Julia package aims at performing <strong>automatic bifurcation analysis</strong> of PDE solved using the Finite Elements Method (FEM) with the Julia package <a href="https://github.com/gridap/Gridap.jl">Gridap.jl</a>.</p>
<blockquote>
<p dir="auto">I would like to thank <strong>Santiago Badia</strong> and <strong>Francesc Verdugo</strong> for their help in developing this package.</p>
</blockquote>
