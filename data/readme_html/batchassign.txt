<p dir="auto">The <code>BatchAssign.jl</code> module provides a convenient way to perform batch assignments in Julia using the macro <code>@all</code>. By leveraging metaprogramming techniques in Julia, this macro can assign a single value to multiple variables in one line, making your code cleaner and more concise.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First, include the module in your script:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using BatchAssign"><pre><span class="pl-k">using</span> BatchAssign</pre></div>
<p dir="auto">Then, you can use the <code>@all</code> macro for batch assignments:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@all a b c = 1"><pre><span class="pl-c1">@all</span> a b c <span class="pl-k">=</span> <span class="pl-c1">1</span></pre></div>
<p dir="auto">This line will assign the value <code>1</code> to variables <code>a</code>, <code>b</code>, and <code>c</code> simultaneously, and is equivalent to the following:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="a, b, c, = 1, 1, 1 # or, 
a = b = c = 1"><pre>a, b, c, <span class="pl-k">=</span> <span class="pl-c1">1</span>, <span class="pl-c1">1</span>, <span class="pl-c1">1</span> <span class="pl-c"><span class="pl-c">#</span> or, </span>
a <span class="pl-k">=</span> b <span class="pl-k">=</span> c <span class="pl-k">=</span> <span class="pl-c1">1</span></pre></div>
<p dir="auto">It is noted that calling the following will assign disctinct random values for the variables:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@all a b c = rand()"><pre><span class="pl-c1">@all</span> a b c <span class="pl-k">=</span> <span class="pl-c1">rand</span>()</pre></div>
<br>
<p dir="auto">The macro is particularly useful for batch assignment of array to several variables:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@all A B C = zeros(2, 3) # case 1"><pre><span class="pl-c1">@all</span> A B C <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(<span class="pl-c1">2</span>, <span class="pl-c1">3</span>) <span class="pl-c"><span class="pl-c">#</span> case 1</span></pre></div>
<p dir="auto">The above is <em><strong>NOT</strong></em> the same as the following:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A = B = C = zeros(2, 3) # case 2"><pre>A <span class="pl-k">=</span> B <span class="pl-k">=</span> C <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(<span class="pl-c1">2</span>, <span class="pl-c1">3</span>) <span class="pl-c"><span class="pl-c">#</span> case 2</span></pre></div>
<p dir="auto">since changing the elements in one of the array in case 2 will affect the others (Julia arrays are assigned by reference).</p>
<br>
<p dir="auto">The <code>@all</code> macro also supports compound assignments such as +=, -=, *=, and /= (and also the broadcasted ones). This allows you to update multiple variables simultaneously:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@all a b c += 1"><pre><span class="pl-c1">@all</span> a b c <span class="pl-k">+=</span> <span class="pl-c1">1</span></pre></div>
<p dir="auto">For more examples, please refer to <a href="./test/runtests.jl"><code>runtest.jl</code></a> in the test folder.</p>

<ul dir="auto">
<li><strong>Conciseness:</strong> Reduce multiple lines of assignments to a single line.</li>
<li><strong>Readability:</strong> Enhance code readability by minimizing repetitive assignment lines.</li>
<li><strong>Efficiency:</strong> Simplify the process of initializing multiple variables to the same value.</li>
</ul>
