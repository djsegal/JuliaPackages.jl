<p dir="auto">A simple module to perform dispatch on the value of an expression using the
<code>@dispatch</code> macro.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="    @dispatch expr begin
        v::Type1 -&gt; body1...
        v::Type2 -&gt; body2...
    end"><pre>    <span class="pl-c1">@dispatch</span> expr <span class="pl-k">begin</span>
        v<span class="pl-k">::</span><span class="pl-c1">Type1</span> <span class="pl-k">-&gt;</span> body1<span class="pl-k">...</span>
        v<span class="pl-k">::</span><span class="pl-c1">Type2</span> <span class="pl-k">-&gt;</span> body2<span class="pl-k">...</span>
    <span class="pl-k">end</span></pre></div>
<p dir="auto">Perform a dispatch on the value of <code>expr</code>.</p>
<p dir="auto">The dispatch uses the anonymous functions in the block as methods, and returns
the value of the appropriate body expression. The order of the functions doesn't
matter, the most specific match is chosen, as customary with Julian dispatch.</p>
