<p dir="auto">This repo provides Julia based benchmarks for ML algo on tabular data.
It was developed to support both <a href="https://github.com/Evovest/NeuroTreeModels.jl">NeuroTreeModels.jl</a> and <a href="https://github.com/Evovest/EvoTrees.jl">EvoTrees.jl</a> projects.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Methodology</h2><a id="user-content-methodology" class="anchor" aria-label="Permalink: Methodology" href="#methodology"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For each dataset and algo, the following methodology is followed:</p>
<ul dir="auto">
<li>Data is split in three parts: <code>train</code>, <code>eval</code> and <code>test</code></li>
<li>A random grid of 16 hyper-parameters is generated</li>
<li>For each parameter configuration, a model is trained on <code>train</code> data until the evaluation metric tracked against the <code>eval</code> stops improving (early stopping)</li>
<li>The trained model is evaluated against the <code>test</code> data</li>
<li>The metric presented in below are the ones obtained on the <code>test</code> for the model that generated the best <code>eval</code> metric.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Datasets</h2><a id="user-content-datasets" class="anchor" aria-label="Permalink: Datasets" href="#datasets"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The following selection of common tabular datasets is covered:</p>
<ul dir="auto">
<li><a href="https://archive.ics.uci.edu/dataset/203/yearpredictionmsd" rel="nofollow">Year</a>: min squared error regression</li>
<li><a href="https://www.microsoft.com/en-us/research/project/mslr/" rel="nofollow">MSRank</a>: ranking problem with min squared error regression</li>
<li><a href="https://webscope.sandbox.yahoo.com/" rel="nofollow">YahooRank</a>: ranking problem with min squared error regression</li>
<li><a href="https://archive.ics.uci.edu/dataset/280/higgs" rel="nofollow">Higgs</a>: 2-level classification with logistic regression</li>
<li><a href="https://juliaml.github.io/MLDatasets.jl/stable/datasets/misc/#MLDatasets.BostonHousing" rel="nofollow">Boston Housing</a>: min squared error regression</li>
<li><a href="https://juliaml.github.io/MLDatasets.jl/stable/datasets/misc/#MLDatasets.Titanic" rel="nofollow">Titanic</a>: 2-level classification with logistic regression</li>
</ul>
