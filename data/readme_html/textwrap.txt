<p dir="auto">This <a href="http://julialang.org" rel="nofollow">Julia</a> package allows to wrap long lines of text to fit within a given width.</p>

<p dir="auto">The other exported functions are <code>wrap</code> (returns a string) and <code>print_wrapped</code>.
See the documentation for more advanced settings.</p>
