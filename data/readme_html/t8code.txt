<p dir="auto"><a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> is a Julia package
that wraps <a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a>, a C/C++ library to manage
multiple connected adaptive quadtrees or octrees in parallel and with possibly mixed
element types.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If you have not yet installed Julia, please <a href="https://julialang.org/downloads/platform/" rel="nofollow">follow the instructions for your
operating system</a>.
<a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> works with Julia v1.6
and later.</p>
<p dir="auto"><a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> is a registered Julia
package. Hence, you can install it by executing the following commands in the
Julia REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; import Pkg; Pkg.add([&quot;T8code&quot;, &quot;MPI&quot;])"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">import</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>([<span class="pl-s"><span class="pl-pds">"</span>T8code<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>MPI<span class="pl-pds">"</span></span>])</pre></div>
<p dir="auto">With this command, you install both
<a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> and
<a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a>.
Currently, <a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> supports
only builds of the C/C++ library <a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a>
with MPI support, so you need to initialize MPI appropriately as described
in the <a href="#usage">Usage</a> section below.</p>
<p dir="auto"><a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> depends on the binary
distribution of the <a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a> library,
which is available in the Julia package T8code_jll.jl and which is automatically
installed as a dependency. The binaries provided by T8code_jll.jl support MPI
and are compiled against the default MPI binaries of MPI.jl. At the time of
writing, these are the binaries provided by MicrosoftMPI_jll.jl on Windows and
MPICH_jll.jl on all other platforms.</p>
<p dir="auto">By default, <a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> provides
pre-generated Julia bindings to all exported C interface functions of the underlying
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a> library. If you want/need to
generate new bindings, please follow the instructions in the <code>dev</code> folder and
copy the generated files to the appropriate places in <code>src</code>.</p>

<p dir="auto"><a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a> needs to be compiled against the
same MPI implementation used by
<a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a>. Thus, if you want to
configure <a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a> to not use the
default MPI binary provided by JLL wrappers, you also need to build
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a> locally using the same MPI
implementation. This is typically the situation on HPC clusters. If you are
just using a single workstation, the default installation instructions should
be sufficient.</p>
<p dir="auto"><a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> allows using a
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a> binary different from the default
one provided by T8code_jll.jl.
To enable this, you first need to obtain a local binary installation of
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a>. Next, you need to configure
<a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a> to use the same MPI
implementation used to build your local installation of
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a>, see
<a href="https://juliaparallel.org/MPI.jl/stable/configuration/" rel="nofollow">the documentation of MPI.jl</a>.
At the time of writing, this can be done by first setting up the
<a href="https://github.com/JuliaPackaging/Preferences.jl">Preferences.jl</a>
setting containing the path to your local build of the shared library of
<a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage</h2><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://github.com/DLR-AMR/T8code.jl">T8code.jl</a> provides Julia bindings for three
libraries:</p>
<ul dir="auto">
<li><a href="https://github.com/DLR-AMR/t8code"><code>t8code</code></a></li>
<li><a href="https://github.com/cburstedde/p4est"><code>p4est</code></a></li>
<li><a href="https://github.com/cburstedde/libsc"><code>libsc</code></a></li>
</ul>
<p dir="auto">The bindings for <code>t8code</code> are imported by default to the global namespace. They all
start wit the prefixes <code>t8_*</code> or <code>T8_*</code>. The bindings for <code>p4est</code> and <code>libsc</code> are
not exported and must be qualified by their full namespace. I.e.:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="T8code.Libt8.sc_some_function(...)

<p dir="auto">It is highly recommended to use Julia <code>v1.9</code> or newer. Older versions showed
some issues like extremely long computing times (basically hanging) when
initializing some structs defined by <code>t8code</code>. Nevertheless, most functionality
has been tested with older Julia versions and should work just fine.</p>
<p dir="auto">The <code>compat</code> entry is set to <code>julia = "1.6"</code> for broader support of other
packages using <code>T8code.jl</code>. In the future, this workaround will be dropped when
Julia <code>v1.9</code> (or newer) is more widely established in the community.</p>
