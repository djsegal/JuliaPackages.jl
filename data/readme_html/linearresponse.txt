<p dir="auto"><a href="https://juliastellardynamics.github.io/LinearResponse.jl/" rel="nofollow"><img src="https://github.com/JuliaStellarDynamics/LinearResponse.jl/actions/workflows/documentation.yml/badge.svg?branch=documentation" alt="image" style="max-width: 100%;"></a></p>
<p dir="auto"><strong>LinearResponse.jl</strong> is a package written in Julia to perform Linear Response calculations. The software is described in <a href="https://ui.adsabs.harvard.edu/abs/2023arXiv231110630P/abstract" rel="nofollow">Petersen et al. (2024)</a>. To see an example of the results from the software, see <a href="https://github.com/michael-petersen/LinearResponse-paper/tree/main">this repository</a>, which reproduces all the figures from Petersen et al. (2024).</p>
<hr>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installation</h2><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To fully use <strong>LinearResponse.jl</strong>, you will need <strong>OrbitalElements.jl</strong>, <strong>FiniteHilbertTransform.jl</strong>, and <strong>AstroBasis.jl</strong>. This installation assumes that you have not installed any of the four libraries; if you have already installed any of the others (globally, not locally) you may skip that portion of the installation.</p>
<p dir="auto">The libraries under the JuliaStellarDynamics organisation are currently unregistered<sup><a href="#user-content-fn-1-75e15f9c9de3b5e65def1157295425e7" id="user-content-fnref-1-75e15f9c9de3b5e65def1157295425e7" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>. To add them to your julia<sup><a href="#user-content-fn-2-75e15f9c9de3b5e65def1157295425e7" id="user-content-fnref-2-75e15f9c9de3b5e65def1157295425e7" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup> registry, follow these steps:</p>
<p dir="auto">You may add all the packages<sup><a href="#user-content-fn-3-75e15f9c9de3b5e65def1157295425e7" id="user-content-fnref-3-75e15f9c9de3b5e65def1157295425e7" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup> at once with this command:
<code>julia -e 'using Pkg; Pkg.add(url="https://github.com/JuliaStellarDynamics/FiniteHilbertTransform.jl.git"); Pkg.add(url="https://github.com/JuliaStellarDynamics/OrbitalElements.jl.git"); Pkg.add(url="https://github.com/JuliaStellarDynamics/AstroBasis.jl.git"); Pkg.add(url="https://github.com/JuliaStellarDynamics/LinearResponse.jl.git")'</code></p>
<p dir="auto">You can confirm the current version with <code>status LinearResponse</code> in the julia package manager.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quickstart</h2><a id="user-content-quickstart" class="anchor" aria-label="Permalink: Quickstart" href="#quickstart"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To reproduce the Plummer radial orbit instability calculation, see the example script in <code>examples/PlummerE/runExamplePlummer.jl</code>. Download the file by running:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="wget https://github.com/JuliaStellarDynamics/LinearResponse.jl/blob/main/examples/PlummerE/runExamplePlummer.jl"><pre class="notranslate"><code>wget https://github.com/JuliaStellarDynamics/LinearResponse.jl/blob/main/examples/PlummerE/runExamplePlummer.jl
</code></pre></div>
<p dir="auto">This script will compute the location of the unstable radial orbit instability mode, using a simplified version of the calculation from <a href="https://ui.adsabs.harvard.edu/abs/2023arXiv231110630P/abstract" rel="nofollow">Petersen et al. (2024)</a> (<code>n1max=1</code> instead of <code>n1max=10</code>, which results in a factor of 10 speedup). The outputs will all be cached (appearing as several files with the <code>.h5</code> extension in the folder where the script is run), so re-running the example is inexpensive. This script will take approximately one minute to run.</p>
<p dir="auto">Run the first example code with the following command:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ julia path/to/runExamplePlummer.jl"><pre class="notranslate"><code>$ julia path/to/runExamplePlummer.jl
</code></pre></div>
<p dir="auto">This example will first install some required libraries (<code>Plots</code>). These installations might take a few minutes when first called.</p>
<p dir="auto">The resulting plot will be created with the name <code>ROIdeterminant.png</code>.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="examples/PlummerE/ROIdeterminant.png"><img src="examples/PlummerE/ROIdeterminant.png" alt="Plummer ROI demonstration" style="max-width: 100%;"></a></p>
<p dir="auto">In this image and test, we are highlighting two key results:</p>
<ol dir="auto">
<li>
<p dir="auto"><strong>Measurement of an unstable mode</strong>, which is the pole located at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="75e15f9c9de3b5e65def1157295425e7">$\omega=0.0+0.043i$</math-renderer>. This mode location is verified against <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="75e15f9c9de3b5e65def1157295425e7">$N$</math-renderer>-body simulations in <a href="https://ui.adsabs.harvard.edu/abs/2023arXiv231110630P/abstract" rel="nofollow">Petersen et al. (2024)</a>.</p>
</li>
<li>
<p dir="auto"><strong>False poles in the lower half-plane</strong>. All poles in the lower half-plane for this model are false poles owing to approximation of the function for linear response. We include them in this example as a caution against interpreting poles without validating via convergence tests.</p>
</li>
</ol>
<p dir="auto">An extension of this script, where the growth rate is computed for a range of radial anisotropy parameters, is Figure 1 in <a href="https://ui.adsabs.harvard.edu/abs/2023arXiv231110630P/abstract" rel="nofollow">Petersen et al. (2024)</a>.</p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Other examples</h3><a id="user-content-other-examples" class="anchor" aria-label="Permalink: Other examples" href="#other-examples"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>examples</code> directory also includes several other basic calculations for the Isochrone, Plummer, and Zang disc models. For example, to (very nearly) reproduce the Isochrone damped dipole mode calculation from Fouvry &amp; Prunet (2022), see the example driver script in <code>examples/IsochroneE/runlinearresponseIsochroneISO.jl</code>. Note that this mode is not converged: adjusting parameters (in particular <code>n1max</code>) will result in different pole locations. The example <code>examples/IsochroneA/runlinearresponseIsochroneISO.jl</code> is precisely the calculation performed by <a href="https://ui.adsabs.harvard.edu/abs/2022MNRAS.509.2443F/abstract" rel="nofollow">Fouvry &amp; Prunet (2022)</a> -- that is, with the analytic isochrone relations. This example will take substantially more computational effort, and can take up to twenty minutes to complete.</p>

<p dir="auto">First start by removing the packages from the environment by running</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia -e 'using Pkg; Pkg.rm(&quot;OrbitalElements&quot;); Pkg.rm(&quot;AstroBasis&quot;);Pkg.rm(&quot;FiniteHilbertTransform&quot;);Pkg.rm(&quot;LinearResponse&quot;);'"><pre class="notranslate"><code>julia -e 'using Pkg; Pkg.rm("OrbitalElements"); Pkg.rm("AstroBasis");Pkg.rm("FiniteHilbertTransform");Pkg.rm("LinearResponse");'
</code></pre></div>
<p dir="auto">If you worked in a test environment (that you do not want to keep) you can also simply erase the folder using <code>rm -r /path/to/my_env</code>.</p>
<p dir="auto">Then to fully erase the package (installed in ~/.julia), run</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia -e 'using Pkg; using Dates; Pkg.gc(collect_delay=Day(0));'"><pre class="notranslate"><code>julia -e 'using Pkg; using Dates; Pkg.gc(collect_delay=Day(0));'
</code></pre></div>
<p dir="auto">It will erase all the packages which are not known in any of your "active" (i.e., for which the Manifest.toml file is reachable) project/environments, in particular <code>LinearResponse</code>.</p>
