<p dir="auto">Catalyst.jl is a symbolic modeling package for analysis and high-performance
simulation of chemical reaction networks. Catalyst defines symbolic
<a href="https://docs.sciml.ai/Catalyst/stable/catalyst_functionality/programmatic_CRN_construction/" rel="nofollow"><code>ReactionSystem</code></a>s,
which can be created programmatically or easily
specified using Catalyst's domain-specific language (DSL). Leveraging
<a href="https://github.com/SciML/ModelingToolkit.jl">ModelingToolkit.jl</a> and
<a href="https://github.com/JuliaSymbolics/Symbolics.jl">Symbolics.jl</a>, Catalyst enables
large-scale simulations through auto-vectorization and parallelism. Symbolic
<code>ReactionSystem</code>s can be used to generate ModelingToolkit-based models, allowing
the easy simulation and parameter estimation of mass action ODE models, Chemical
Langevin SDE models, stochastic chemical kinetics jump process models, and more.
Generated models can be used with solvers throughout the broader Julia and
<a href="https://sciml.ai" rel="nofollow">SciML</a> ecosystems, including higher-level SciML packages (e.g.
for sensitivity analysis, parameter estimation, machine learning applications,
etc).</p>

<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Features of Catalyst</h4><a id="user-content-features-of-catalyst" class="anchor" aria-label="Permalink: Features of Catalyst" href="#features-of-catalyst"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><a href="https://docs.sciml.ai/Catalyst/stable/model_creation/dsl_basics/" rel="nofollow">The Catalyst DSL</a> provides a simple and readable format for manually specifying reaction network models using chemical reaction notation.</li>
<li>Catalyst <code>ReactionSystem</code>s provides a symbolic representation of reaction networks, built on <a href="https://docs.sciml.ai/ModelingToolkit/stable/" rel="nofollow">ModelingToolkit.jl</a> and <a href="https://docs.sciml.ai/Symbolics/stable/" rel="nofollow">Symbolics.jl</a>.</li>
<li>The <a href="http://docs.sciml.ai/Catalyst/stable/api/catalyst_api" rel="nofollow">Catalyst.jl API</a> provides functionality for building networks programmatically and for composing multiple networks together.</li>
<li>Leveraging ModelingToolkit, generated models can be converted to symbolic reaction rate equation ODE models, symbolic Chemical Langevin Equation models, and symbolic stochastic chemical kinetics (jump process) models. These can be simulated using any <a href="https://docs.sciml.ai/DiffEqDocs/stable/" rel="nofollow">DifferentialEquations.jl</a> <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/simulation_introduction/" rel="nofollow">ODE/SDE/jump solver</a>, and can be used within <code>EnsembleProblem</code>s for carrying out <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/ensemble_simulations/" rel="nofollow">parallelized parameter sweeps and statistical sampling</a>. Plot recipes are available for <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/simulation_plotting/" rel="nofollow">visualization of all solutions</a>.</li>
<li>Non-integer (e.g. <code>Float64</code>) stoichiometric coefficients <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/dsl_basics/#dsl_description_stoichiometries_decimal" rel="nofollow">are supported</a> for generating ODE models, and symbolic expressions for stoichiometric coefficients <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/parametric_stoichiometry/" rel="nofollow">are supported</a> for all system types.</li>
<li>A <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/network_analysis/" rel="nofollow">network analysis suite</a> permits the computation of linkage classes, deficiencies, reversibility, and other network properties.</li>
<li><a href="https://docs.sciml.ai/Catalyst/stable/model_creation/conservation_laws/" rel="nofollow">Conservation laws can be detected and utilized</a> to reduce system sizes, and to generate non-singular Jacobians (e.g. during conversion to ODEs, SDEs, and steady state equations).</li>
<li>Catalyst reaction network models can be <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/constraint_equations/" rel="nofollow">coupled with differential and algebraic equations</a> (which are then incorporated during conversion to ODEs, SDEs, and steady state equations).</li>
<li>Models can be <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/constraint_equations/#constraint_equations_events" rel="nofollow">coupled with events</a> that affect the system and its state during simulations.</li>
<li>By leveraging ModelingToolkit, users have a variety of options for generating optimized system representations to use in solvers. These include construction of <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/ode_simulation_performance/#ode_simulation_performance_sparse_jacobian" rel="nofollow">dense or sparse Jacobians</a>, <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/ode_simulation_performance/#ode_simulation_performance_parallelisation" rel="nofollow">multithreading or parallelization of generated derivative functions</a>, <a href="https://docs.sciml.ai/JumpProcesses/stable/jump_types/#jump_types" rel="nofollow">automatic classification of reactions into optimized jump types for Gillespie type simulations</a>, <a href="https://docs.sciml.ai/JumpProcesses/stable/jump_types/#Jump-Aggregators-Requiring-Dependency-Graphs" rel="nofollow">automatic construction of dependency graphs for jump systems</a>, and more.</li>
<li><a href="https://github.com/JuliaSymbolics/Symbolics.jl">Symbolics.jl</a> symbolic expressions and Julia <code>Expr</code>s can be obtained for all rate laws and functions determining the deterministic and stochastic terms within resulting ODE, SDE, or jump models.</li>
<li><a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/homotopy_continuation/" rel="nofollow">Steady states</a> (and their <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/steady_state_stability_computation/" rel="nofollow">stabilities</a>) can be computed for model ODE representations.</li>
</ul>
<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Features of Catalyst composing with other packages</h4><a id="user-content-features-of-catalyst-composing-with-other-packages" class="anchor" aria-label="Permalink: Features of Catalyst composing with other packages" href="#features-of-catalyst-composing-with-other-packages"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><a href="https://github.com/SciML/OrdinaryDiffEq.jl">OrdinaryDiffEq.jl</a> Can be used to numerically solver generated reaction rate equation ODE models.</li>
<li><a href="https://github.com/SciML/StochasticDiffEq.jl">StochasticDiffEq.jl</a> can be used to numerically solve generated Chemical Langevin Equation SDE models.</li>
<li><a href="https://github.com/SciML/JumpProcesses.jl">JumpProcesses.jl</a> can be used to numerically sample generated Stochastic Chemical Kinetics Jump Process models.</li>
<li>Support for <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/ode_simulation_performance/#ode_simulation_performance_parallelisation" rel="nofollow">parallelization of all simulations</a>, including parallelization of <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/ode_simulation_performance/#ode_simulation_performance_parallelisation_GPU" rel="nofollow">ODE simulations on GPUs</a> using <a href="https://github.com/SciML/DiffEqGPU.jl">DiffEqGPU.jl</a>.</li>
<li><a href="https://korsbo.github.io/Latexify.jl/stable/" rel="nofollow">Latexify</a> can be used to <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/model_visualisation/#visualisation_latex" rel="nofollow">generate LaTeX expressions</a> corresponding to generated mathematical models or the underlying set of reactions.</li>
<li><a href="https://graphviz.org/" rel="nofollow">Graphviz</a> can be used to generate and <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/model_visualisation/#visualisation_graphs" rel="nofollow">visualize reaction network graphs</a> (reusing the Graphviz interface created in <a href="https://algebraicjulia.github.io/Catlab.jl/stable/" rel="nofollow">Catlab.jl</a>).</li>
<li>Model steady states can be <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/homotopy_continuation/" rel="nofollow">computed through homotopy continuation</a> using <a href="https://github.com/JuliaHomotopyContinuation/HomotopyContinuation.jl">HomotopyContinuation.jl</a> (which can find <em>all</em> steady states of systems with multiple ones), by <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/nonlinear_solve/#steady_state_solving_simulation" rel="nofollow">forward ODE simulations</a> using <a href="https://github.com/SciML/SteadyStateDiffEq.jl">SteadyStateDiffEq.jl</a>, or by <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/nonlinear_solve/#steady_state_solving_nonlinear" rel="nofollow">numerically solving steady-state nonlinear equations</a> using <a href="https://github.com/SciML/NonlinearSolve.jl">NonlinearSolve.jl</a>.</li>
<li><a href="https://github.com/bifurcationkit/BifurcationKit.jl">BifurcationKit.jl</a> can be used to <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/bifurcation_diagrams/" rel="nofollow">compute bifurcation diagrams</a> of model steady states (including finding periodic orbits).</li>
<li><a href="https://github.com/JuliaDynamics/DynamicalSystems.jl">DynamicalSystems.jl</a> can be used to compute model <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/dynamical_systems/#dynamical_systems_basins_of_attraction" rel="nofollow">basins of attraction</a>, <a href="https://docs.sciml.ai/Catalyst/stable/steady_state_functionality/dynamical_systems/#dynamical_systems_lyapunov_exponents" rel="nofollow">Lyapunov spectrums</a>, and other dynamical system properties.</li>
<li><a href="https://github.com/SciML/StructuralIdentifiability.jl">StructuralIdentifiability.jl</a> can be used to <a href="https://docs.sciml.ai/Catalyst/stable/inverse_problems/structural_identifiability/" rel="nofollow">perform structural identifiability analysis</a>.</li>
<li><a href="https://github.com/SciML/Optimization.jl">Optimization.jl</a>, <a href="https://github.com/SciML/DiffEqParamEstim.jl">DiffEqParamEstim.jl</a>, and <a href="https://github.com/sebapersson/PEtab.jl">PEtab.jl</a> can all be used to <a href="https://sebapersson.github.io/PEtab.jl/stable/Define_in_julia/" rel="nofollow">fit model parameters to data</a>.</li>

<p dir="auto">In the above example, we used basic Catalyst workflows to simulate a simple
model. Here we instead show how various Catalyst features can compose to create
a much more advanced model. Our model describes how the volume of a cell (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$V$</math-renderer>)
is affected by a growth factor (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$G$</math-renderer>). The growth factor only promotes growth
while in its phosphorylated form (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$G^P$</math-renderer>). The phosphorylation of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$G$</math-renderer> (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$G \to G^P$</math-renderer>)
is promoted by sunlight (modeled as the cyclic sinusoid $k_a (\sin(t) + 1)$),
which phosphorylates the growth factor (producing <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$G^P$</math-renderer>). When the cell reaches a
critical volume (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$V_m$</math-renderer>) it undergoes cell division. First, we declare our model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Catalyst

    <span class="pl-c1">@equations</span> <span class="pl-k">begin</span>

    <span class="pl-k">end</span>

<p dir="auto">We now study the system as a Chemical Langevin Dynamics SDE model, which can be generated as follows</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="u0 = [:V =&gt; 25.0, :G =&gt; 50.0, :Gᴾ =&gt; 0.0]

<p dir="auto">This problem encodes the following stochastic differential equation model:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$$\begin{align*}
dG(t) &amp;=  - \left( \frac{k_p(\sin(t)+1)}{V(t)} G(t) + \frac{k_i}{V(t)} G^P(t) \right) dt - \sqrt{\frac{k_p (\sin(t)+1)}{V(t)} G(t)} \, dW_1(t) + \sqrt{\frac{k_i}{V(t)} G^P(t)} \, dW_2(t) \\\
dG^P(t) &amp;= \left( \frac{k_p(\sin(t)+1)}{V(t)} G(t) - \frac{k_i}{V(t)} G^P(t) \right) dt + \sqrt{\frac{k_p (\sin(t)+1)}{V(t)} G(t)} \, dW_1(t) - \sqrt{\frac{k_i}{V(t)} G^P(t)} \, dW_2(t) \\\
dV(t) &amp;= \left(g \, G^P(t)\right) dt
\end{align*}$$</math-renderer>
<p dir="auto">where the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$dW_1(t)$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="32362009b0163ad90eab4f22be9b16bf">$dW_2(t)$</math-renderer> terms represent independent Brownian Motions, encoding the noise added by the Chemical Langevin Equation. Finally, we can simulate and plot the results.</p>

<p dir="auto">Some features we used here:</p>
<ul dir="auto">
<li>The cell volume was <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/constraint_equations/#constraint_equations_coupling_constraints" rel="nofollow">modeled as a differential equation, which was coupled to the reaction network model</a>.</li>
<li>The cell divisions were created by <a href="https://docs.sciml.ai/Catalyst/stable/model_creation/constraint_equations/#constraint_equations_events" rel="nofollow">incorporating events into the model</a>.</li>
<li>We designated a specific numeric <a href="https://docs.sciml.ai/Catalyst/stable/model_simulation/simulation_introduction/#simulation_intro_solver_options" rel="nofollow">solver and corresponding solver options</a>.</li>
