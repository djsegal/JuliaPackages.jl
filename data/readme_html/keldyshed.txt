<p dir="auto">Equilibrium Exact Diagonalization solver for finite fermionic models that can
also compute Green's functions on the Keldysh contour.</p>
<p dir="auto">Copyright (C) 2019-2024 Igor Krivenko <a href="mailto:igor.s.krivenko@gmail.com">igor.s.krivenko@gmail.com</a></p>
<p dir="auto">Copyright (C) 2015 P. Seth, I. Krivenko, M. Ferrero and O. Parcollet</p>
<p dir="auto">The initial public version of this package was a simplified Julia port of
the <a href="https://triqs.github.io/triqs/latest/documentation/manual/triqs/atom_diag/contents.html" rel="nofollow">TRIQS/atom_diag</a>
library, but has since acquired a few new features.</p>
<p dir="auto">Special thanks to Joseph Kleinhenz for reviewing my code, as well as for writing
the <a href="https://github.com/kleinhenz/Keldysh.jl">Keldysh.jl</a> library, which <code>KeldyshED.jl</code>
depends on.</p>

<p dir="auto">KeldyshED.jl can be installed by typing the following command in Julia's <code>Pkg</code> REPL:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add KeldyshED"><pre class="notranslate"><code>pkg&gt; add KeldyshED

<p dir="auto">Some usage examples can be found in the <a href="test">test</a> subdirectory.
An API reference is available at the <a href="https://krivenko.github.io/KeldyshED.jl" rel="nofollow">documentation website</a>.</p>
