<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Details</h2><a id="user-content-details" class="anchor" aria-label="Permalink: Details" href="#details"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ol dir="auto">
<li>Quantum Exact Simulation Toolkit is a high performance simulator of quantum circuits, state-vectors and density matrices.</li>
<li>
<code>QuEST.jl</code> is a wrapper for <a href="https://github.com/QuEST-Kit/QuEST"><code>QuEST</code></a>, which is written in <code>C</code>. <code>QuEST.jl</code> was compiled using <a href="https://github.com/JuliaPackaging/BinaryBuilder.jl/tree/master"><code>BinaryBuilder.jl</code></a>, which is a system for the compilation of binary dependencies --whose aim it to <em>just work</em> anywhere the official Julia distribution does.</li>
<li>Function calls, enumerators, structs, etc were wrapped automatically using <a href="https://github.com/JuliaInterop/Clang.jl"><code>Clang.jl</code></a>, which provided the needed <code>C</code> bindings for the Julia interface.</li>
<li>
<strong>Note:</strong> Julia is indexed starting at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$1$</math-renderer> and goes until <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$N$</math-renderer> items in an <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$N-$</math-renderer> element list. <code>C</code> indexes an <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$N-$</math-renderer> element list from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$0$</math-renderer> to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$N-1$</math-renderer>.</li>
<li>To give the Julia user uniform interface, every <code>QuEST</code> call using an integer index, will first shift the index to be in the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="88861c7f2ab49766994773f68c27f5b5">$0$</math-renderer> indexed form inside the Julia function. The user should be aware of this, but it is the aim of the <code>QuEST.jl</code> parckage wrapper writer(s) to handle this for the user.</li>
</ol>

<p dir="auto">To maintain QuEST.jl with future releases of QuEST:</p>
<ol dir="auto">
<li>go to <a href="https://docs.binarybuilder.org/stable/" rel="nofollow">BinaryBuilder.jl doc's page</a></li>
<li>Follow instructions to pre-compile the latest version of QuEST according hardware requirements</li>
<li>The <code>build_tarballs.jl</code> file showcasing how to precompile QuEST is found on the <a href="https://github.com/JuliaPackaging/Yggdrasil/blob/master/Q/QuEST/build_tarballs.jl">Yggdrasil package page here</a></li>
<li>Best to follow instructions from (1) and use the wizard</li>
<li>Once this is done the updated pacakge <code>QuEST_jll.jl</code> will automatically update with the latest precompiled version. Found on the <a href="https://github.com/JuliaBinaryWrappers">Julia binary wrapper organisation (JuliaBinaryWrapper)</a>, check the repositories for your package (<a href="https://github.com/JuliaBinaryWrappers/QuEST_jll.jl"><code>QuEST_jll.jl</code></a>).</li>
<li>Now if there are any updated funcation names or new interfaces, this package <a href="https://github.com/fieldofnodes/QuEST.jl"><code>QuEST.jl</code></a> will need to be updated. See example:</li>

<p dir="auto">The line starting with <code>@ccall...</code> is calling the function by accessing the precompiled binary. To presenve segmentation faults and hence prevent Julia crashing at function call I assert the <code>targetQubit</code>, which is an integer and is in the set of qubits contained in the <code>qureg</code>, if not, then an error is thrown. Calls to <code>C</code> need to ensure indices are shifted to the <code>0</code>-index, which is done with <code>c_shift_index</code>.</p>
<p dir="auto">Then follow standard Julia package management and release for new version.</p>
