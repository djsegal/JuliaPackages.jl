<p dir="auto">Interactive visualization of historical price (currently only in EUR), health metrics, candlestick
and volume data for various cryptocurrencies. Data are obtained via API queries to Alpha Vantage.
The app is written in Julia and makes use of Dash.jl along with its react framework to generate a
dashboard style view accessible via a browser. Different moving averages are also calculated and
plotted along with the daily average price data. Averaging window can be selected by the user.</p>
<p dir="auto">Functionality of the app will be extended in the future by adding more technical indicators.
<strong>Contributions are most welcome!</strong></p>

<p dir="auto">This package is available via the General registry. Add it to your working Julia
environment by doing the following in the REPL:</p>
<ul dir="auto">
<li>Press ']' to enter Pkg prompt</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add CryptoDashApp"><pre>pkg<span class="pl-k">&gt;</span> add CryptoDashApp</pre></div>
<p dir="auto">Once all the packages are downloaded, you can make use of the <strong>CryptoDashApp</strong>
module from the REPL itself or within a script by executing:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using CryptoDashApp

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Running as a Docker container (for versions &gt; 0.6.0)</h3><a id="user-content-running-as-a-docker-container-for-versions--060" class="anchor" aria-label="Permalink: Running as a Docker container (for versions &gt; 0.6.0)" href="#running-as-a-docker-container-for-versions--060"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Assuming that you have Docker installed, and have generated both API keys, a Docker image
can be created using the following steps:</p>
<ul dir="auto">
<li>
<p dir="auto">Clone this repository and cd to the directory</p>
</li>
<li>
<p dir="auto">Build the Docker image (Here <code>my_app</code> is the name of the generated image)</p>
</li>
</ul>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker build --build-arg key_av=&quot;YOUR_KEY&quot; --build-arg key_cg=&quot;YOUR_KEY&quot; -t my_app ."><pre>docker build --build-arg key_av=<span class="pl-s"><span class="pl-pds">"</span>YOUR_KEY<span class="pl-pds">"</span></span> --build-arg key_cg=<span class="pl-s"><span class="pl-pds">"</span>YOUR_KEY<span class="pl-pds">"</span></span> -t my_app <span class="pl-c1">.</span></pre></div>
<ul dir="auto">
<li>Once the image is successfully generated, start a container (port 8010 is hard-coded
in the Dockerfile, can also be changed if needed):</li>
</ul>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker run -dp 127.0.0.1:8010:8010 my_app"><pre>docker run -dp 127.0.0.1:8010:8010 my_app</pre></div>
<ul dir="auto">
<li>Check log output:</li>
</ul>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker logs --follow &lt;container id&gt;"><pre>docker logs --follow <span class="pl-k">&lt;</span>container id<span class="pl-k">&gt;</span></pre></div>
<p dir="auto">First plot will take a few seconds to appear, wait patiently! If you are running this app for the
first time, or on a different date, new data will be retrieved from Alpha Vantage, and then saved
to CSV files on disk. Keep in mind that the free API key imposes a limit of five calls/minute,
which means you won't be able to load data for more than five currencies in quick succession. In
case you see an error, wait for a while and then try again.</p>
