<p dir="auto"><code>VIDA.jl</code> or the <em>Variational Image Domain Analysis</em> provides a interface to extracting features from fits images created for the EHT, using the notion of probability divergences similar to variational inference. This package has been used extensively in the most recent EHT publications of <a href="https://iopscience.iop.org/journal/2041-8205/page/Focus_on_First_Sgr_A_Results" rel="nofollow">Sgr A*</a>.</p>
<p dir="auto">As of <strong>version 0.11</strong> VIDA now uses the <a href="https://ptiede.github.io/Comrade.jl/dev/base_api/" rel="nofollow"><code>ComradeBase</code></a> and <a href="https://ehtjulia.github.io/VLBISkyModels.jl/dev/interface/" rel="nofollow"><code>VLBISkyModels</code></a> interface. This implies that any model that satisifies this interface can
now be used as a VIDA template.</p>
<p dir="auto">For more information on how to use VIDA please refer to the <a href="https://ptiede.github.io/VIDA.jl/stable" rel="nofollow">documentation</a></p>

<p dir="auto"><code>VIDA.jl</code> is registered so to install it just go into the REPL and type <code>]add VIDA</code>.</p>
