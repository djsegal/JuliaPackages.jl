<p dir="auto">A Julia package for orthogonal polynomials on algebraic curves</p>
<p dir="auto">This package contains ongoing research on orthogonal polynomials on
algebraic curves. That is, given an algebraic curve in 2D defined by
<code>S = {(x,y) : p(x,y) = 0}</code> for some bivariate polynomial <code>p</code> we wish
to construct polynomials orthogonal with respect to an inner product
supported on a  subset <code>Ω ⊆ S</code>. Note to avoid degenerecies  these polynomials need to
be thought of as polynomials modulo the vanishing ideal <code>I(S)</code> associated to <code>S</code>.
The general theory and construction is not at yet possible, so we
outline some specific cases that we have implemented below.</p>
<p dir="auto">This is funded by a Leverhulme Trust Research Project Grant on
"Constructive approximation on algebraic curves and surfaces".</p>

<p dir="auto">We can construct orthogonal polynomials on an arc, that is,
<code>Ω = {(cos(θ), sin(θ)) : a ≤ θ ≤ b}</code>, which is a subset of
the circle <code>{(x,y) : x^2 + y^2 = 1}</code>.
We parameterise points on the circle by angle, using a special
type <code>CircleCoordinate(θ)</code>:</p>
