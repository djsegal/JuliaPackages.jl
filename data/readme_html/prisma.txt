<p dir="auto"><code>PRISMA.jl</code> is a Julia package and <a href="https://prisma-jl.onrender.com" rel="nofollow">web application</a> powered by <a href="https://react.dev/" rel="nofollow"><code>React.js</code></a> and <a href="https://github.com/OxygenFramework/Oxygen.jl"><code>Oxygen.jl</code></a> for generating checklists and flow diagrams based on <a href="https://doi.org/10.1186/s13643-021-01626-4" rel="nofollow">the 2020 <strong>P</strong>referred <strong>R</strong>eporting <strong>I</strong>tems for <strong>S</strong>ystematic <strong>R</strong>eviews and <strong>M</strong>eta-<strong>A</strong>nalyses (PRISMA) statement (Page et al., 2021).</a></p>
<p dir="auto"><strong>Features:</strong></p>
<ul dir="auto">
<li>NLP to generate 2020 PRISMA checklists.</li>
<li>upload study data to generate 2020 PRISMA flow diagrams.</li>
<li>interactive web app that requires zero programming knowledge.</li>
</ul>
<p dir="auto"><strong>Installation:</strong> use this command in the Julia REPL: <code>using Pkg; Pkg.add("PRISMA")</code></p>
