<p dir="auto">A Julia Framework for Quantum Dynamics and Control.</p>
<p dir="auto">The <a href="https://github.com/JuliaQuantumControl/QuantumControl.jl"><code>QuantumControl</code></a> package is a high-level interface for the <a href="https://github.com/JuliaQuantumControl#packages">packages</a> in the <a href="https://github.com/JuliaQuantumControl">JuliaQuantumControl</a> organization and provides a coherent <a href="https://juliaquantumcontrol.github.io/QuantumControl.jl/dev/api/quantum_control/#QuantumControlAPI" rel="nofollow">API</a> for solving quantum control problems. See the <a href="https://github.com/JuliaQuantumControl#readme">organization README</a> for details.</p>

<p dir="auto">The <a href="https://github.com/JuliaQuantumControl/QuantumControl.jl"><code>QuantumControl.jl</code></a> package can be installed via the <a href="https://docs.julialang.org/en/v1/stdlib/Pkg/" rel="nofollow">standard Pkg manager</a>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add QuantumControl"><pre class="notranslate"><code>pkg&gt; add QuantumControl
</code></pre></div>
<p dir="auto">You will also want to install the <a href="https://github.com/JuliaQuantumControl/QuantumPropagators.jl"><code>QuantumPropagators</code> package</a></p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add QuantumPropagator"><pre class="notranslate"><code>pkg&gt; add QuantumPropagator
</code></pre></div>
<p dir="auto">to access a suitable dynamic solver for your problem (e.g. <code>using QuantumPropagators: Cheby</code>); as well as at least one package for a specific optimization method you are planning to use:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add Krotov
pkg&gt; add GRAPE"><pre class="notranslate"><code>pkg&gt; add Krotov
pkg&gt; add GRAPE
</code></pre></div>
<p dir="auto">See the <a href="https://github.com/JuliaQuantumControl#packages">list of packages</a> of the <a href="https://github.com/JuliaQuantumControl">JuliaQuantumControl</a> organization.</p>
