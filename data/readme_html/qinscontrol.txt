<p dir="auto">QInsControl is designed for controling instruments and data acquiring, which is based on the NI VISA and provides a
friendly GUI and a flexible script written mannar to keep both the convenience and universality.
See <a href="https://FaresX.github.io/QInsControl.jl/dev/" rel="nofollow">docs</a> here or 视频【QInsControl.jl 开源的可编程仪器控制和数据采集工具】 <a href="https://www.bilibili.com/video/BV1Y2421N75d/?share_source=copy_web&amp;vd_source=9bb5f2e2197b605d0d141ae8f55c67c7" rel="nofollow">https://www.bilibili.com/video/BV1Y2421N75d/?share_source=copy_web&amp;vd_source=9bb5f2e2197b605d0d141ae8f55c67c7</a></p>

<p dir="auto">Block mode and text mode can be changed from each other. Block mode is better for selecting instruments, addresses and quantities and some more useful functions. Text mode is better for reading and copying codes. Only block mode is supported to be compiled to executable tasks and run them.
