<p dir="auto">Gattino is Toolips-based, extensible plotting for Julia. <code>Gattino</code> features ...</p>
<ul dir="auto">
<li>composable, <strong>fully-featured</strong> data-visualization</li>
<li>an <em>extension ecosystem</em></li>
<li><a href="https://github.com/ChifiSource/Toolips.jl">toolips</a> compatibility</li>
<li>powerful <strong>layout</strong> syntax</li>
</ul>
<p dir="auto">There is currently a lot underway when it comes to <a href="https://github.com/ChifiSource/">Chifi</a> packages, so this package is currently a <strong>work in progress</strong>.</p>

<p dir="auto">While <code>Gattino</code> plots are completely composable and can be made by composing <a href="#context-plotting">context plotting</a> elements together, the module also comes with some high-level functions which may be used to produce standard visualizations we are likely familiar with. These examples currently include <code>scatter</code>, <code>line</code>, and <code>hist</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="scatter(x::Vector, y::Vector, divisions::Int64 = 4, title::String = &quot;&quot;)

<p dir="auto">The <code>hist</code> function is just a passthrough to <code>hist!</code>, which is a <a href="#context-plotting">context plotting</a> function that creates a histogram. Notably, <code>hist</code> will create a new <code>Context</code> for us and <code>hist!</code> expects us to provide an <code>AbstractContext</code> as an argument. The <code>line</code> and <code>scatter</code> equivalence to this is found in <code>scatter_plot!</code> and <code>line_plot!</code>. That being said, if we want to add a visualization to a <code>Context</code> that already exists, we would use these methods, rather than the high-level method. When using <code>hist!</code> we will want to add our histogram to an old plot, when using <code>hist</code> we will be making a new plot with a new window. Here, I will use the <code>context</code> and <code>group!</code> functions to compose a scatter with the <code>scatter_plot!</code> method.</p>

<p dir="auto">Graphics in <code>Gattino</code> are scaled using the <code>Context</code> and <code>Group</code> types. A <code>Context</code> represents a window, whereas a <code>Group</code> represents an area in that window. To create a context, we use the <code>context</code> method.</p>
<ul dir="auto">
<li><code>context(f::Function, width::Int64 = 1280, height::Int64= 720, margin::Pair{Int64, Int64} = 0 =&gt; 0)</code></li>
</ul>

<p dir="auto">This <code>Context</code> can now be used with <a href="#context-plotting">context plotting</a> methods. There are two different types of <code>group</code> which we can use on our project,
<code> </code>group!<code>is the mutating group -- this will add anything drawn to the group to the</code>Context`.</p>
<ul dir="auto">
<li><code>group</code> is non-mutating group -- anything we draw will not be drawn onto the window.</li>
</ul>
<p dir="auto">The methods are</p>
<ul dir="auto">
<li><code>group(f::Function, c::AbstractContext, w::Int64, h::Int64, margin::Pair{Int64, Int64})</code></li>
<li>`group!(f::Function, c::AbstractContext, name::String, w::Int64, h::Int64, margin::Pair{Int64, Int64})</li>
</ul>
<p dir="auto">These dispatches are for the most part the same as the <code>context</code> method. The <code>width</code>, <code>height</code>, and <code>margin</code> will all default to those of the provided <code>AbstractContext</code>. Additionally, <code>group!</code> will take the name of the layer as the second positional argument.
These two forms of group are used in tandem to organize the layers of our <code>Context</code>. <code>group</code> is used to define new <code>AbstractContext</code> dimensions without adding a layer, whereas <code>group!</code> will add a new layer in those dimensions. For example.</p>

<p dir="auto">Once an animation is registered into a <code>Context</code>, it is there until that <code>Context</code> is recreated, or can be cleared manually from <code>Context.window.extras</code>. A defined animation can be set again when using <a href="https://github.com/ChifiSource/GattinoInteractive.jl">GattinoInteractive</a> or a similar interactive extension package for <code>Gattino</code>.</p>
