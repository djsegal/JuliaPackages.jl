<p dir="auto">Built on top of Plotly.js, React and HTTP.jl, <a href="https://plotly.com/dash/" rel="nofollow">Dash</a> ties modern UI elements like dropdowns, sliders, and graphs directly to your analytical Julia code.</p>
<p dir="auto">Just getting started? Check out the <a href="https://dash.plotly.com/julia" rel="nofollow">Dash for Julia User Guide</a>! If you can't find documentation there, then check out the unofficial <a href="https://github.com/plotly/Dash.jl/issues/50" data-hovercard-type="issue" data-hovercard-url="/plotly/Dash.jl/issues/50/hovercard">contributed examples</a> or check out source code from <a href="https://dash.gallery" rel="nofollow">demo applications</a> in Python and then reference the Julia syntax style.</p>

<ul dir="auto">
<li>You can make your Dash app interactive by registering callbacks with the <code>callback!</code> function.</li>
<li>Outputs and inputs (and states, see below) of callback can be <code>Output</code>, <code>Input</code>, <code>State</code> objects or splats / vectors of this objects.</li>
<li>Callback functions must have the signature <code>(inputs..., states...)</code>, and provide a return value with the same number elements as the number of <code>Output</code>s to update.</li>
</ul>

<ul dir="auto">
<li><code>Vector</code>s and <code>Tuple</code>s to JSON arrays</li>
<li><code>Dict</code>s and <code>NamedTuple</code>s to JSON objects</li>
</ul>
