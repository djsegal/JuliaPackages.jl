<p dir="auto">The goal of this package is to provide a Julian interface for representing
the objects and structures in ("Western") music theory (based on semitones).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Contents of the package</h2><a id="user-content-contents-of-the-package" class="anchor" aria-label="Permalink: Contents of the package" href="#contents-of-the-package"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>

<p dir="auto">A motivating example for writing this package was to be able to do the following types of
computations.</p>
<p dir="auto">When playing the violin, it's common to have a scale in thirds: take a scale and for each
scale tone, play the note two steps above it in the scale at the same time.</p>
<p dir="auto">Question: Which combinations of half/whole steps and pairs of major/minor thirds
are possible?</p>
<p dir="auto">Answer:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; scale = Scale(C[4], major_scale)

julia&gt; notes = Base.Iterators.take(scale, 10) |&gt; collect

julia&gt; thirds = zip(notes, notes[3:end]) |&gt; collect

julia&gt; thirds_intervals = Interval.(thirds)

julia&gt; note_intervals = Interval.(zip(notes, notes[2:end]))

julia&gt; combinations =
        [ (note_intervals[i], thirds_intervals[i], thirds_intervals[i+1])
            for i in 1:(length(thirds)-1)
        ]

julia&gt; result = unique(combinations)
4-element Vector{Tuple{Interval, Interval, Interval}}:
 (Major 2nd, Major 3rd, Minor 3rd)
 (Major 2nd, Minor 3rd, Minor 3rd)
 (Minor 2nd, Minor 3rd, Major 3rd)
 (Major 2nd, Major 3rd, Major 3rd)"><pre>julia<span class="pl-k">&gt;</span> scale <span class="pl-k">=</span> <span class="pl-c1">Scale</span>(C[<span class="pl-c1">4</span>], major_scale)
