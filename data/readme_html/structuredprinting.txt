<p dir="auto">A simple Julia package for printing structs in a structured way, while offering a way to filter and highlight specified information. This package was developed for debugging.</p>
<details>
  <summary>The story of how this started</summary>
<p dir="auto">One day, I was trying to find out if <code>UnionAll</code> objects existed in a very large OrdinaryDiffEq integrator. I ended up writing:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Crayons
function getpropertyviz(obj, pc = (), indent = &quot;&quot;)
    for pn in propertynames(obj)
        prop = getproperty(obj, pn)
        pc_full = (pc..., &quot;.&quot;, pn)
        pc_string = string(join(pc_full))
        if prop isa UnionAll || prop isa DataType
            pc_colored = Crayons.Box.RED_FG(pc_string)
            println(&quot;$indent $pc_colored :: $(typeof(prop)), FLAGME!&quot;)
        else
            println(&quot;$indent $pc_string :: $(typeof(prop))&quot;)
            getpropertyviz(prop, pc_full, indent*&quot;  &quot;)
        end
    end
end

<p dir="auto">Which ended up highlighting 3 (of the thousands of) structs that were either <code>UnionAll</code>, or <code>DataType</code>, and this helped me to identify which structs were responsible for hurting compiler inference in a large codebase.</p>
<p dir="auto">Since this code was so generic, I thought it might be useful to write a small tool for it and add some bells and whistles. Enter StructuredPrinting.jl.</p>
