<p dir="auto">Julia wrapper for the Telegram library <a href="https://core.telegram.org/tdlib" rel="nofollow">TDLib</a>:</p>
<blockquote>
<p dir="auto">TDLib (Telegram Database Library) is a cross-platform, fully functional Telegram client. We designed it to help third-party developers create their own custom apps using the Telegram platform.</p>
</blockquote>
<p dir="auto">Relies on <code>TDLib_jll</code> package to provide TDLib binaries.</p>

<p dir="auto">Having created a <code>Client</code>, perform its connection and authorization workflow:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; TG.connect_authorize(tg, timeout_each=1);"><pre>julia&gt; TG<span class="pl-k">.</span><span class="pl-c1">connect_authorize</span>(tg, timeout_each<span class="pl-k">=</span><span class="pl-c1">1</span>);</pre></div>
<p dir="auto">This may ask for the authentication code if connecting for the first time. By default, the code is asked interactively via <code>Base.prompt()</code>. This can be changed in an  <code>AuthParameters</code> field: <code>AuthParameters(..., get_authentication_code=() -&gt; Base.prompt("Authentication code"))</code>.</p>
<p dir="auto">The client is finally ready:</p>

true</pre></div>
<p dir="auto">Now, one can call any API methods with <code>send</code>, <code>send_method</code>, <code>execute</code>, <code>execute_method</code>, and receive responses or updates with <code>receive</code>.</p>
