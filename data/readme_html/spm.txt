<p dir="auto"><code>SPM.jl</code> is a <a href="https://julialang.org/" rel="nofollow">Julia</a> package alongside
the <a href="https://www.fil.ion.ucl.ac.uk/spm/" rel="nofollow">SPM software</a>, designed
for the analysis of brain imaging data sequences.</p>

<p dir="auto"><code>SPM.jl</code> is available for Julia v1.6 and later releases.  It can be installed
with <a href="https://julialang.github.io/Pkg.jl/stable/" rel="nofollow">Julia built-in package
manager</a>.  In a Julia session, after
entering the package manager mode with <code>]</code>, run the command</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; update
pkg&gt; add https://github.com/spm/SPM.jl"><pre>pkg<span class="pl-k">&gt;</span> update
pkg<span class="pl-k">&gt;</span> add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>spm<span class="pl-k">/</span>SPM<span class="pl-k">.</span>jl</pre></div>
<p dir="auto">To exit from the Pkg REPL mode press the backspace key, or <code>Ctrl + C</code>.</p>
<p dir="auto"><code>SPM.jl</code> also requires a shared library <code>libSPM</code> (see
<a href="https://github.com/spm/spm/blob/main/src/Makefile">SPM Makefile</a>).
A compiled library <code>libSPM.so</code> is provided for 64-bit Linux environments.</p>
