<p dir="auto"><em>Lexicon</em> is a <a href="http://www.julialang.org" rel="nofollow">Julia</a> package documentation generator
and viewer.</p>
<p dir="auto">It provides access to the documentation created by the <code>@doc</code> macro from
<a href="https://github.com/MichaelHatherly/Docile.jl"><em>Docile</em></a>. <em>Lexicon</em> allows querying of package documentation from
the Julia REPL and building standalone documentation that can be hosted on GitHub
Pages or <a href="https://readthedocs.org/" rel="nofollow">Read the Docs</a>.</p>
<p dir="auto"><em>Lexicon</em> separates the non-essential parts from <em>Docile</em> so that
package load times are not impacted when documenting packages using
<code>@doc</code>. See <a href="https://github.com/MichaelHatherly/Docile.jl/issues/27" data-hovercard-type="issue" data-hovercard-url="/MichaelHatherly/Docile.jl/issues/27/hovercard">this issue</a> for details regarding the split.</p>
