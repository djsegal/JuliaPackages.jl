<p dir="auto">LibMseed.jl is a Julia wrapper around the
<a href="https://github.com/EarthScope/libmseed">libmseed</a> library for reading
and writing data in the miniSEED format.</p>

<p dir="auto">You can install LibMseed.jl from Julia's package manager like so:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg; Pkg.add(&quot;LibMseed&quot;)"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>LibMseed<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">You do not need to separately install the <code>libmseed</code> library.  Instead,
LibMseed.jl installs its own version automatically.</p>

<p dir="auto"><code>LibMseed</code> exports several functions with common names, such as <code>read_file</code>
and <code>write_file</code>.  It is recommended to either explicitly import the functions
you need, or always prepend names with <code>LibMseed</code>.</p>

<p dir="auto"><code>read_file</code> and <code>read_buffer</code> support the <code>startdate</code>, <code>enddate</code> and
<code>channels</code> keyword arguments.</p>
<p dir="auto"><code>startdate</code> and <code>enddate</code> limit the time window read, but the underlying
libmseed library does not ensure that the first sample of the traces
returned is at the start date requested, so you may need to further trim
traces:</p>

<p dir="auto"><code>channels</code> is a string which is matched against the
<a href="http://docs.fdsn.org/projects/source-identifiers/en/v1.0/" rel="nofollow">FDSN source ID</a>
of each channel to determine whether to read it.  <code>*</code> indicates any number
of any character (including zero), while <code>?</code> indicates exactly one character
of any kind.  E.g., <code>FDSN:GB_*Z</code> matches all vertical channels in the
GB network.</p>

<p dir="auto">The time of the first sample (the <code>starttime</code> in the example above,
or the property <code>starttime</code> of a segment) is stored to nanosecond
precision in the miniSEED file.  The standard library <code>Dates</code> module
cannot handle nanosecond resolution <code>Dates.DateTime</code>s, and so time is
implemented in LibMseed.jl via the <code>LibMseed.NanosecondDateTime</code> type.</p>
<p dir="auto">You can convert a <code>NanosecondDateTime</code> to the nearest <code>Dates.DateTime</code>
(precise to the millisecond) with <code>LibMseed.nearest_datetime</code>.  Use
<code>Dates.Time</code> to obtain the time of day to full nanosecond resolution.</p>
