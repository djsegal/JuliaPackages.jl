<p dir="auto">DataToolkit is a batteries-included family of packages for robustly managing
  data. The particular package(s) you want to use will depend on the project.</p>
<ul dir="auto">
  <li>Use <a href="https://tecosaur.github.io/DataToolkit.jl/main/" rel="nofollow">DataToolkit</a> for analysis projects and scripts</li>
  <li>Use <a href="https://tecosaur.github.io/DataToolkit.jl/base/" rel="nofollow">DataToolkitBase</a> when making a package that needs data
    <ul dir="auto">
      <li>Optionally, use <a href="https://github.com/tecosaur/DataToolkitDocumenter.jl">DataToolkitDocumenter</a> too to document the datasets</li>
    </ul>
  </li>
  <li>Use <a href="https://tecosaur.github.io/DataToolkit.jl/core/" rel="nofollow">DataToolkitCore</a> when making a package extending DataToolkit, and possibly
    <a href="https://tecosaur.github.io/DataToolkit.jl/store/" rel="nofollow">DataToolkitStore</a> too.</li>
</ul>
<p dir="auto">For now, this set of packages around the beta stage of development. No major
  changes to the core functionality or structure are anticipated, but small
  expansions in the data-CLI functionality and set of transformers and plugins
  provided by <i>DataToolkitCommon</i> are expected prior to the 1.0 release, and larger
  changes may occur if there is good reason for them.</p>
