<p dir="auto">This repository aims to generate fancy fractal objects using an algorithm <a href="https://catalys1.github.io/fractal-pretraining/" rel="nofollow">based on the SVD-based approach for sampling IFS (Iterated Function Systems), as Connor Anderson and Ryan Farrell proposed</a>. While the original authors implemented the algorithm they suggested using Python, our implementation adopts JuliaLang, a JIT-compiled language.</p>
