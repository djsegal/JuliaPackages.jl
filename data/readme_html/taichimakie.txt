<ul dir="auto">
<li>The notorious time-to-first-plot (TTFP) issue.
<ul dir="auto">
<li>To mitigate this, you can use <code>deps/create_sysimage.jl</code> to create a sysimage for TaichiMakie. This will significantly reduce the TTFP.</li>
<li>After creating the sysimage, you can use <code>julia --sysimage=taichi_makie.so</code> to start Julia with the sysimage.</li>
</ul>
</li>
<li>Taichi GGUI does not support the following features:
<ul dir="auto">
<li>anti-aliasing</li>
<li>alpha</li>
</ul>
</li>
<li>Support for meshes is still erroneous.</li>
</ul>
