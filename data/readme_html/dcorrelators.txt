<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Discrete space and time Fourier transforms</h3><a id="user-content-discrete-space-and-time-fourier-transforms" class="anchor" aria-label="Permalink: Discrete space and time Fourier transforms" href="#discrete-space-and-time-fourier-transforms"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">If the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$x$</math-renderer> variable has only discrete values (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$x=na$</math-renderer>, for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$n=1,2,3,...,N$</math-renderer>) and finite length <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$L$</math-renderer> (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$L=Na$</math-renderer>), the expansion of the function is</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$f_n=\sum_{m=1}^{N} A_{q} e^{iq_m x_n},\quad q=\frac{2\pi}{L}m,$$</math-renderer></p>
<p dir="auto">where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$A_{q}=\frac{1}{N}\sum^N_{n=1}f_n e^{-iq_mx_n}. $$</math-renderer></p>
<p dir="auto">Dividing <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$A_{q}$</math-renderer> by the mode <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$\frac{2\pi}{L}$</math-renderer>, the Fourier amplitudes with a per unit spacial interval is</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$ A(q) = \frac{L}{2\pi}A_q=\frac{a}{2\pi}\sum^N_{n=1}f_ne^{-iqx_n}.$$</math-renderer></p>
<p dir="auto">If the times <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$t$</math-renderer> are discrete times (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$t=l\Delta t$</math-renderer>, for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$l=0,1,2,...,N$</math-renderer>) and the final evolutionary time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$t_{\mathrm{end}}=N\Delta t$</math-renderer>, the expansion of the function is</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$ f_l=\sum_{p=1}^N A_{\omega} e^{-i\omega_p t_l},\quad \omega=\frac{2\pi}{t_{\mathrm{end}}}p,$$</math-renderer></p>
<p dir="auto">where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$A_{\omega}=\frac{1}{N}\sum_{l=1}^N f_l e^{i\omega_p t_l}.$$</math-renderer></p>
<p dir="auto">To make it a per unit frequency interval, one need to divide by the spacing of the discrete frequency mode and the Fourier amlitudes are given by,</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$A(\omega)=\frac{t_{\mathrm{end}}}{2\pi}A_{\omega}=\frac{\Delta t}{2\pi}\sum_{l=1}^N f_l e^{i\omega t_l}.$$</math-renderer></p>
<p dir="auto">Although a Fourier series is designed to represent functions that are periodic, one can assume that the finite data sequence can be periodically repeated, which leads to the time at index <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$l=N$</math-renderer> is identified with the time at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$l=0$</math-renderer>. However, the small errors made at the end of a period will be irrelevant as long as the primary correlations decay in less time than <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$t_{\mathrm{end}}$</math-renderer>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Space and time correlations</h3><a id="user-content-space-and-time-correlations" class="anchor" aria-label="Permalink: Space and time correlations" href="#space-and-time-correlations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">By use of double Fourier transforms, one can obtain the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$k-\omega$</math-renderer> space correlation function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$G(k,\omega)$</math-renderer>,</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$G(k,\omega)=\frac{1}{(2\pi)^2}\Delta t\sum_{l=1}^{N_t} a\sum_{n=1}^{N_L} G(x, t) e^{-i(kx-\omega t)}.$$</math-renderer></p>
<p dir="auto">With</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$\Delta t \sum_{l=1}^{N_t}\to \int_0^{t_{\mathrm{end}}}dt,\quad a\sum_{n=1}^{N_L}\to \int_0^L dx,$$</math-renderer></p>
<p dir="auto">the continuous form is as follows</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$ G(k,\omega) = \frac{1}{(2\pi)^2} \int_0^{t_{\mathrm{end}}}dt \int_0^L dx G(x, t) e^{-i(kx-\omega t)}. $$</math-renderer></p>
<p dir="auto">The real-space and real-time correlation function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$G(x, t)$</math-renderer> is given by,</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$ \begin{aligned}G\left( x_{n},t\right) &amp;=\frac{1}{N_t}\sum_{l=1}^{N_t}\frac{1}{N_{L}}\sum_{m=1}^{N_{L}}\langle 0 | C\left( x_{m}+x_{n},t_{l}+t\right) C^{\dagger}\left( x_{m},t_{l}\right) | 0\rangle \\
&amp;=\frac{1}{N_t}\sum_{l=1}^{N_t}\frac{1}{N_{L}}\sum_{m=1}^{N_L}\langle 0| e^{iH(t_{l}+t)}C\left( x_{m}+x_{n}\right) e^{-iH(t_l+t) }e^{iHt_{l}}C^{\dagger}\left( x_{m}\right) e^{-iHt_{l}}| 0\rangle \\
&amp;=\frac{1}{N_{L}}\sum_{m=1}^{N_{L}}e^{iE_{0}t}\langle 0| C\left( x_{m}+x_{n}\right) e^{-iHt}C^{\dagger}\left( x_{m}\right) | 0\rangle. \end{aligned}$$</math-renderer></p>
<p dir="auto">Finally, one gets,</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$$ G(k,\omega)=\frac{1}{(2\pi)^2}\Delta t\sum_{l=1}^{N_t} a\sum_{n=1}^{N_L} \frac{1}{N_{L}}\sum_{m=1}^{N_{L}}e^{iE_{0}t}\langle 0| C\left( x_{m}+x_{n}\right) e^{-iHt}C^{\dagger}\left( x_{m}\right) | 0\rangle e^{-i(kx_n-\omega t)}. $$</math-renderer></p>
<p dir="auto">Here, the matrix-product states time evolution methods are implemented to solve the state <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="1a9aa7c56f49cf9b1dccc56039042429">$e^{-iHt}C^{\dagger}\left( x_{m}\right) | 0\rangle$</math-renderer>.</p>
