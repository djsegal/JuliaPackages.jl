<p dir="auto">To use a proxy for all your HTTP and HTTPS requests in <code>EasyCurl</code>, you can set the following environment variables:</p>
<ul dir="auto">
<li><code>all_proxy</code>: Proxy for all protocols</li>
<li><code>http_proxy</code>: Proxy for HTTP requests</li>
<li><code>https_proxy</code>: Proxy for HTTPS requests</li>
<li><code>no_proxy</code>: Domains to exclude from proxying</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# 'your_proxy_username' your proxy account's username
