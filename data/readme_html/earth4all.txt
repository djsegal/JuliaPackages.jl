<p dir="auto">Repository of the Julia implementation of the <a href="https://earth4all.life/the-science-rp/" rel="nofollow">Earth4All model</a> using the <a href="https://github.com/worlddynamics/WorldDynamics.jl">WorldDynamics framework</a>, based on the <a href="https://web.archive.org/web/20220830093115/https://earth4all.life/the-science/" rel="nofollow">April 2023 Vensim version</a> available <a href="https://stockholmuniversity.app.box.com/s/uh7fjh52pvh7yx1mqfwqcyxdcvegrodf/folder/170558692760" rel="nofollow">here</a> (a copy is also available in the <code>vensim_source</code> folder of the current repository).</p>

<p dir="auto">After starting the Julia REPL in the repository folder, we can instantiate the environment by running</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using Pkg
julia&gt; Pkg.activate(&quot;.&quot;)
julia&gt; Pkg.instantiate()"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Pkg
julia<span class="pl-k">&gt;</span> Pkg<span class="pl-k">.</span><span class="pl-c1">activate</span>(<span class="pl-s"><span class="pl-pds">"</span>.<span class="pl-pds">"</span></span>)
julia<span class="pl-k">&gt;</span> Pkg<span class="pl-k">.</span><span class="pl-c1">instantiate</span>()</pre></div>
<p dir="auto">We can then load the <code>Earth4All</code> module and run a scenario (e.g. "Too Little Too Late") with</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; include(&quot;src/Earth4All.jl&quot;)
julia&gt; sol = Earth4All.run_tltl_solution()"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">include</span>(<span class="pl-s"><span class="pl-pds">"</span>src/Earth4All.jl<span class="pl-pds">"</span></span>)
julia<span class="pl-k">&gt;</span> sol <span class="pl-k">=</span> Earth4All<span class="pl-k">.</span><span class="pl-c1">run_tltl_solution</span>()</pre></div>
<p dir="auto">To obtain the plots of the main variables, we can run</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; Earth4All.fig_baserun_tltl() # for the Too Little Too Late scenario
julia&gt; Earth4All.fig_baserun_gl() # for the Giant Leap scenario"><pre>julia<span class="pl-k">&gt;</span> Earth4All<span class="pl-k">.</span><span class="pl-c1">fig_baserun_tltl</span>() <span class="pl-c"><span class="pl-c">#</span> for the Too Little Too Late scenario</span>
julia<span class="pl-k">&gt;</span> Earth4All<span class="pl-k">.</span><span class="pl-c1">fig_baserun_gl</span>() <span class="pl-c"><span class="pl-c">#</span> for the Giant Leap scenario</span></pre></div>
