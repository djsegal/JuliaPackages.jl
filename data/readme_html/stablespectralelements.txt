</p><p dir="auto"><strong>StableSpectralElements.jl</strong> (formerly <strong>CLOUD.jl</strong>) is a Julia framework for the numerical solution of hyperbolic and mixed hyperbolic-parabolic conservation laws on general unstructured grids using provably stable discontinuous spectral-element methods of arbitrary order, with an emphasis on dispatched strategies for the evaluation of a broad class of discretization operators. StableSpectralElements.jl supports shared-memory parallelization through multithreading.</p>
