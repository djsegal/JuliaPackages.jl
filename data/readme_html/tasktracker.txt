<p dir="auto">TaskTracker.jl is a Julia package that helps you track and visualize your tasks from a todo file. It parses a markdown file, calculates the completion percentage of each task, and generates a Gantt chart using PlantUML.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Parse markdown files to extract tasks and subtasks</li>
<li>Calculate completion percentage of each task</li>
<li>Generate Gantt charts using PlantUML</li>
<li>Support for custom project start date</li>
<li>Support for multiple todo files in a directory</li>
<li>Export Gantt charts in various formats (pdf, png, svg, xml, plain)</li>
</ul>

<p dir="auto">Create a todo file in markdown format (e.g., <code>todo.md</code>) with the following syntax:</p>
<ul dir="auto">
<li>Tasks start with <code>- [ ] </code> or <code>- [x] </code> for incomplete or complete tasks, respectively.</li>
<li>Tasks can have subtasks through indentation.</li>
<li>Tasks can have a start date and duration in days specified in the format <code>Task name | yyyy-mm-dd | duration</code>.</li>
<li>Alternatively, tasks can start after another task has been completed using the format <code>Task name | after Task2 | duration</code>.</li>
<li>You can specify a custom project start date at the top of the file using the format <code>#project start date: yyyy-mm-dd</code>.</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Generating a Gantt chart</h3><a id="user-content-generating-a-gantt-chart" class="anchor" aria-label="Permalink: Generating a Gantt chart" href="#generating-a-gantt-chart"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Run <code>julia -e 'using TaskTracker; generate_gantt("todo.md"; output_file="gantt.svg")'</code> in the terminal, replacing <code>todo.md</code> with your todo file name if necessary.</li>
<li>A Gantt chart will be generated as <code>gantt.svg</code> in the same directory.</li>
</ul>

<ul dir="auto">
<li>If you have multiple todo files in a directory, you can generate a combined Gantt chart for all of them by running <code>julia -e 'using TaskTracker; generate_gantt_for_dir("path/to/directory"; output_file="combined_gantt.png")'</code> in the terminal, replacing <code>path/to/directory</code> with your directory path if necessary.</li>
