<p dir="auto">Spacetime generic, general relativistic ray-tracing (GRRT) in Julia. See our <a href="https://astro-group-bristol.github.io/Gradus.jl/dev/" rel="nofollow">documentation</a> for more details and usage.</p>
<p align="center" dir="auto"> <i> This package is in development and subject to rapid breaking changes, with documentation updates lagging behind features.</i> </p>

<p dir="auto">Gradus.jl is a suite of tools related to tracing geodesics and calculating observational signatures. Gradus.jl requires only a specification of the non-zero metric components of a chosen spacetime in order to solve the <a href="https://en.wikipedia.org/wiki/Solving_the_geodesic_equations" rel="nofollow">geodesic equation</a> and compute a wide variety of trajectories and orbits. Various algorithms for calculating physical quantities are implemented generically, so they may be used with different classes of spacetime with minimal implementation.</p>
<p dir="auto">Currently, Gradus.jl can be used for any static, axis-symmetric spacetime to calculate:</p>
<ul dir="auto">
<li>geodesic orbits and special radii (event horizon shapes, ISCO radii, etc.)</li>
<li>null / time / space like trajectories including for charged particles</li>
<li>black hole shadows</li>
<li>redshift images</li>
<li>Cunningham transfer functions</li>
<li>line profiles and spectra</li>
<li>reverberation transfer functions</li>
<li>time-lags from different coronal models</li>
<li>emissivity profiles on the accretion disc</li>
<li>covariant radiative transfer</li>
<li>various toy accretion models (thin disc, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="18648d4429d50ef3b66dfad6cd57243b">$\alpha$</math-renderer>-discs, rotationally-supported polish doughnut, etc)</li>
<li>non-symmetric disc geometries</li>
<li>mesh file geometry</li>
</ul>
<p dir="auto">The library is written to make adding new features as effortless as possible. See <a href="https://astro-group-bristol.github.io/Gradus.jl/dev/examples/" rel="nofollow">Examples</a> for more. Many new features are currently being developed as our research advances.</p>
<p dir="auto">Gradus.jl uses <a href="https://github.com/SciML/DifferentialEquations.jl">DifferentialEquations.jl</a> and <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff.jl</a> as the backend for integrating and solving the geodesic equation for arbitrary metrics, and vendors the DifferentialEquations.jl solver and callback system, making Gradus.jl easy to extend for new problems. Gradus.jl currently supports multi-CPU integration and analysis, with GPU support on the horizon.</p>

<p dir="auto">We assume you already have Julia &gt;1.6.</p>
<p dir="auto">All non-General dependencies for Gradus.jl are in the <a href="https://github.com/astro-group-bristol/AstroRegistry">AstroRegistry</a> which can be added to Julia with:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt;] registry add https://github.com/astro-group-bristol/AstroRegistry"><pre>julia<span class="pl-k">&gt;</span>] registry add https<span class="pl-k">:</span><span class="pl-k">//</span>github<span class="pl-k">.</span>com<span class="pl-k">/</span>astro<span class="pl-k">-</span>group<span class="pl-k">-</span>bristol<span class="pl-k">/</span>AstroRegistry</pre></div>
<p dir="auto">NB: the <a href="https://github.com/JuliaRegistries/General">Julia General Registry</a> is required to install Gradus, however this should be configured by default with any Julia installation.</p>
<p dir="auto">Gradus.jl can then be fetched easily:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt;] add Gradus
julia&gt; using Gradus"><pre>julia<span class="pl-k">&gt;</span>] add Gradus
julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> Gradus</pre></div>
<p dir="auto">See <a href="https://astro-group-bristol.github.io/Gradus.jl/dev/getting-started/" rel="nofollow">GettingStarted</a> for setting up your first traces.</p>
