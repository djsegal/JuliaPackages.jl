<p dir="auto">This package also could be called "DocumenterAndTestExampleHandler.jl". It helps to maintain comprehensive complete (i.e. ready to download and run) code examples in Documenter.jl documentation.</p>
<p dir="auto">Code examples could be in plain Julia scripts, Julia scripts containing modules or pluto notebooks and serve three purposes:</p>
<ul dir="auto">
<li>Ready to be run by users</li>
<li>Part of CI tests</li>
<li>Well integrated into documenter based documentation (via <a href="https://github.com/fredrikekre/Literate.jl">Literate.jl</a>, <a href="https://github.com/rikhuijzer/PlutoStaticHTML.jl">PlutoStaticHTML.jl</a> or <a href="https://github.com/JuliaPluto/PlutoSliderServer.jl">PlutoSliderServer.jl</a>)</li>
</ul>
<p dir="auto">Maintaining a list of examples leads to considerable boilerplate ("example juggling" - that is why the name ...) in <code>test/runtest.jl</code> and <code>docs/make.jl</code>.
This package helps to hide this boilerplate behind its API.</p>

<li>v2.0.0: Moved all direct and indirect dependencies on Pluto into extensions. Correspondingly, one needs to
