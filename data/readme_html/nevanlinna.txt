<p dir="auto">The package can be installed with the Julia package manager. From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add Nevanlinna"><pre class="notranslate"><code>pkg&gt; add Nevanlinna
</code></pre></div>
<p dir="auto">This will install a Command Line Interface (CLI) script, <code>nevanlinna</code>, into <code>~/.julia/bin</code>.
You can add this directory to your PATH in a bash shell by adding the following line into <code>~/.bashrc</code>:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="export PATH=&quot;$HOME/.julia/bin:$PATH&quot;"><pre><span class="pl-k">export</span> PATH=<span class="pl-s"><span class="pl-pds">"</span><span class="pl-smi">$HOME</span>/.julia/bin:<span class="pl-smi">$PATH</span><span class="pl-pds">"</span></span></pre></div>
<p dir="auto">This command needs input parameter TOML file.
These files can be downloaded from <a href="https://github.com/SpM-lab/Nevanlinna.jl/blob/comonicon/comonicon/bare/config.toml">here</a>.
