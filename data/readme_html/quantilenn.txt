<p dir="auto">This Julia package implements the nonparametric
<a href="https://arxiv.org/abs/2012.01758" rel="nofollow">quantile regression approach</a>
of Ye and Padilla (2020).</p>

<p dir="auto">The following example simulates heteroscedastic data and estimates
the 20th, 50th,and 80th conditional quantiles.</p>

p = 3

X[:, 1] .= 1
y = X[:, 2] + (1 .+ 2*abs.(X[:, 2])) .* randn(n)
