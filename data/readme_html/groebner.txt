<p dir="auto">Groebner.jl is a Julia package for computing Groebner bases over fields.
Groebner.jl is distributed under GNU GPL v2.</p>
<p dir="auto">For documentation please check out <a href="https://sumiya11.github.io/Groebner.jl" rel="nofollow">https://sumiya11.github.io/Groebner.jl</a>.
For a simple example, see below.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How to use Groebner.jl?</h2><a id="user-content-how-to-use-groebnerjl" class="anchor" aria-label="Permalink: How to use Groebner.jl?" href="#how-to-use-groebnerjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The main function provided by Groebner.jl is <code>groebner</code>.
It works with polynomials from AbstractAlgebra.jl, DynamicPolynomials.jl, and Nemo.jl.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">with AbstractAlgebra.jl</h3><a id="user-content-with-abstractalgebrajl" class="anchor" aria-label="Permalink: with AbstractAlgebra.jl" href="#with-abstractalgebrajl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">We create a ring of polynomials in 3 variables</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using AbstractAlgebra

R, (x1, x2, x3) = QQ[&quot;x1&quot;, &quot;x2&quot;, &quot;x3&quot;]"><pre><span class="pl-k">using</span> AbstractAlgebra

R, (x1, x2, x3) <span class="pl-k">=</span> QQ[<span class="pl-s"><span class="pl-pds">"</span>x1<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>x2<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>x3<span class="pl-pds">"</span></span>]</pre></div>
<p dir="auto">Then, we can define a simple polynomial system</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="system = [
  x1 + x2 + x3,
  x1*x2 + x1*x3 + x2*x3,
  x1*x2*x3 - 1
]"><pre>system <span class="pl-k">=</span> [
  x1 <span class="pl-k">+</span> x2 <span class="pl-k">+</span> x3,
  x1<span class="pl-k">*</span>x2 <span class="pl-k">+</span> x1<span class="pl-k">*</span>x3 <span class="pl-k">+</span> x2<span class="pl-k">*</span>x3,
  x1<span class="pl-k">*</span>x2<span class="pl-k">*</span>x3 <span class="pl-k">-</span> <span class="pl-c1">1</span>
]</pre></div>
<p dir="auto">And compute the Groebner basis by passing the system to <code>groebner</code></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Groebner

G <span class="pl-k">=</span> <span class="pl-c1">groebner</span>(system)</pre></div>
