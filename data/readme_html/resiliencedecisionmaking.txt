<p dir="auto">The main interface of the resilience decision making method is the <code>grid_search</code> method which returns the computed resilience values as a <code>Dict</code> of the endowment configurations, the coefficient of variation and the pareto front. To explain we use the example of the multistage high-speed axial compressor as presented in the paper. First, we define a system representation in this case the adjacency matrix of the system as</p>

<p dir="auto">Finally, we define the recovery behaviour of the components through the <code>recovery!</code> function. This function must update the <code>components</code> and <code>recovery_times</code> vectors in place (!) and return <code>nothing</code>. Note, that in this example recovery is independent of <code>η</code>. See the other <code>demo</code> example for how to use <code>η</code> to influence the recovery of components.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="r_max = 21

function recovery!(components, recovery_times, η)
    for (i, (c, r)) in enumerate(zip(components, recovery_times))
        if ~c
            if r &gt;= r_max - 11
                components[i] = true
                recovery_times[i] = 1
            else
                recovery_times[i] = recovery_times[i] + 1
            end
        end
    end

    return nothing
end"><pre>r_max <span class="pl-k">=</span> <span class="pl-c1">21</span>

<span class="pl-k">function</span> <span class="pl-en">recovery!</span>(components, recovery_times, η)
    <span class="pl-k">for</span> (i, (c, r)) <span class="pl-k">in</span> <span class="pl-c1">enumerate</span>(<span class="pl-c1">zip</span>(components, recovery_times))
        <span class="pl-k">if</span> <span class="pl-k">~</span>c
            <span class="pl-k">if</span> r <span class="pl-k">&gt;=</span> r_max <span class="pl-k">-</span> <span class="pl-c1">11</span>
                components[i] <span class="pl-k">=</span> <span class="pl-c1">true</span>
                recovery_times[i] <span class="pl-k">=</span> <span class="pl-c1">1</span>
            <span class="pl-k">else</span>
                recovery_times[i] <span class="pl-k">=</span> recovery_times[i] <span class="pl-k">+</span> <span class="pl-c1">1</span>
            <span class="pl-k">end</span>
        <span class="pl-k">end</span>
    <span class="pl-k">end</span>

    <span class="pl-k">return</span> <span class="pl-c1">nothing</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">Finally, we can run the <code>grid_search</code> where configurations are accepted if the resilience value is above <code>α = 0.85</code>. We also pass a structure function evaluating of the system is currently working (s-t-connectivity) and the number of samples (500) to use per resilience computation.</p>
