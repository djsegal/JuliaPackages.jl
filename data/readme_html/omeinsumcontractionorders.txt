<p dir="auto">OMEinsumContractionOrders is a Julia package that provides an <code>optimize_code</code> function for finding optimal contraction orders for tensor networks. It is designed to work with multiple tensor network packages, such as: <a href="https://github.com/under-Peter/OMEinsum.jl/issues">OMEinsum.jl</a> package and <a href="https://github.com/mtfishman/ITensorNetworks.jl">ITensorNetworks.jl</a>.</p>

<p dir="auto">To install OMEinsumContractionOrders, please follow these steps:</p>
<ol dir="auto">
<li>Open Julia's interactive session (known as <a href="https://docs.julialang.org/en/v1/manual/getting-started/" rel="nofollow">REPL</a>) by typing <code>julia</code> in your terminal.</li>
<li>Press the <kbd>]</kbd> key in the REPL to enter the package mode.</li>
<li>Type <code>add OMEinsumContractionOrders</code> to install the stable release of the package.</li>
<li>(Optional) If you want to use the <code>KaHyParBipartite</code> optimizer, which is based on the KaHyPar library, type <code>add KaHyPar</code>. Note that this step is optional because some users may have issues with the binary dependencies of KaHyPar (please check issues: <a href="https://github.com/kahypar/KaHyPar.jl/issues/12" data-hovercard-type="issue" data-hovercard-url="/kahypar/KaHyPar.jl/issues/12/hovercard">this</a> and <a href="https://github.com/kahypar/KaHyPar.jl/issues/19" data-hovercard-type="issue" data-hovercard-url="/kahypar/KaHyPar.jl/issues/19/hovercard">this</a>).</li>
</ol>

<p dir="auto">The contraction order optimizer is implemented in the <code>optimize_code</code> function. It takes three arguments: <code>code</code>, <code>size</code>, and <code>optimizer</code>. The <code>code</code> argument is the <a href="https://numpy.org/doc/stable/reference/generated/numpy.einsum.html" rel="nofollow">einsum notation</a> to be optimized. The <code>size</code> argument is the size of the variables in the einsum notation. The <code>optimizer</code> argument is the optimizer to be used. The <code>optimize_code</code> function returns the optimized contraction order. One can use <code>contraction_complexity</code> function to get the time, space and rewrite complexity of returned contraction order.</p>
