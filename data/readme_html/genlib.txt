<p dir="auto"><em>Tools for pedigree analysis.</em></p>
<p dir="auto">A pure Julia port of <a href="https://cran.r-project.org/web/packages/GENLIB/index.html" rel="nofollow">R's GENLIB</a> genetics and genealogical library.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Package Features</h2><a id="user-content-package-features" class="anchor" aria-label="Permalink: Package Features" href="#package-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Basic functions that use the same syntax as R's GENLIB, sometimes faster than the original implementations;</li>
<li>A function that computes the most recent common ancestors several magnitudes faster than <code>gen.findMRCA</code> in R's GENLIB;</li>
<li>The fastest available implementation to compute pairwise kinship coefficients, based on the algorithm by <a href="https://gphmorin.github.io/GenLib.jl/dev/bibliography/#Karigl,-1981" rel="nofollow">Karigl, 1981</a>;</li>
<li>The fastest available implementation to compute a square matrix of kinship coefficients, based on the algorithms by <a href="https://gphmorin.github.io/GenLib.jl/dev/bibliography/#Karigl,-1981" rel="nofollow">Karigl, 1981</a> and <a href="https://gphmorin.github.io/GenLib.jl/dev/bibliography/#Kirkpatrick-et-al.,-2019" rel="nofollow">Kirkpatrick et al., 2019</a>.</li>
</ul>
