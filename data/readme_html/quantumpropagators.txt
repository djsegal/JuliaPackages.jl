<p dir="auto">For standalone use, the <code>QuantumPropagators</code> package can be installed with <a href="https://pkgdocs.julialang.org/v1/" rel="nofollow">Pkg</a> as</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add QuantumPropagators"><pre class="notranslate"><code>pkg&gt; add QuantumPropagators
</code></pre></div>
<p dir="auto">Otherwise, the package should be installed as part of <a href="https://github.com/JuliaQuantumControl/QuantumControl.jl#readme"><code>QuantumControl.jl</code></a>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="pkg&gt; add QuantumControl"><pre class="notranslate"><code>pkg&gt; add QuantumControl
</code></pre></div>
<p dir="auto">For development usage, see the <a href="https://github.com/JuliaQuantumControl#development">organization development notes</a>.</p>
