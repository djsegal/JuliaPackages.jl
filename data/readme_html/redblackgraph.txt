<p dir="auto">Red-Black Graphs are a specific type of graph, a directed acyclic graph of interleaved binary trees. This data
structure resulted from exploration of efficient representations for family history. This package presents and
implements the underlying linear algebra as well as discusses some interesting applications.</p>
<p dir="auto">This Julia module is a port/rewrite of the <a href="https://github.com/rappdw/redblackgraph">python implementation</a></p>
