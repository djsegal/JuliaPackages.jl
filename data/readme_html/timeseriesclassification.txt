<ul dir="auto">
<li><a href="https://link.springer.com/article/10.1007/BF01074755" rel="nofollow">DTW</a> (without any search space limitations)</li>
<li>DTW with <a href="https://www.irit.fr/~Julien.Pinquier/Docs/TP_MABS/res/dtw-sakoe-chiba78.pdf" rel="nofollow">Sakoe-Chiba band</a></li>
<li>DTW with <a href="https://www.ee.columbia.edu/~dpwe/papers/Itak75-lpcasr.pdf" rel="nofollow">Itakura parallelogram</a></li>
<li>Your own function</li>
</ul>
</li>
<li>Lower Bounding
<ul dir="auto">
<li>None (without any lower bounding)</li>
<li><a href="https://www.cs.ucr.edu/~eamonn/LB_Keogh.htm" rel="nofollow">LB_Keogh</a></li>
<li>Your own function</li>
</ul>
</li>
</ul>
</li>
</ul>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Performance</h2><a id="user-content-performance" class="anchor" aria-label="Permalink: Performance" href="#performance"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Benchmarks were done on 113 datasets from the <a href="https://www.timeseriesclassification.com/index.php" rel="nofollow">UCR Time Series Archive</a>.</p>
<p dir="auto">When compared to <a href="https://www.sktime.net/" rel="nofollow">sktime</a> (a Python package for machine learning with time series, optimized using <a href="https://numba.pydata.org/" rel="nofollow">Numba</a> and based on <a href="https://scikit-learn.org/stable/index.html" rel="nofollow">scikit-learn</a>) the MiniRocket implementation in Julia was 8.5 times faster and KNN was 17.8 faster.</p>
<p dir="auto">Tests were done on Intel Core i7-11700 8c/16t @ 2.5 GHz with DDR4 RAM of 32 GB @ 3600 MHz, CL17.</p>
