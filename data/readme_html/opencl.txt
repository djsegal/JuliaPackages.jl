<p dir="auto"><em>Julia interface for the OpenCL parallel computation API</em></p>
<p dir="auto">This package aims to be a complete solution for OpenCL programming in Julia, similar in
scope to [PyOpenCL] for Python. It provides a high level API for OpenCL to make programing
hardware accelerators, such as GPUs, FPGAs, and DSPs, as well as multicore CPUs much less
onerous.</p>
<p dir="auto"><strong>OpenCL.jl needs your help! If you can help maintaining this package, please reach out on
the <a href="https://julialang.org/slack/" rel="nofollow">JuliaLang Slack</a> #gpu channel</strong></p>
<p dir="auto"><strong>Also note: OpenCL.jl is currently undergoing major changes. If you have old code,
developed for OpenCL.jl v0.9, please check <a href="NEWS.md"><code>NEWS.md</code></a> for an overview of the
changes.</strong></p>

<p dir="auto">The traditional way of using OpenCL is by writing kernel source code in OpenCL C. For
example, a simple vector addition:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OpenCL, pocl_jll

const source = &quot;&quot;&quot;
   __kernel void vadd(__global const float *a,
                      __global const float *b,
                      __global float *c) {
      int gid = get_global_id(0);
      c[gid] = a[gid] + b[gid];
    }&quot;&quot;&quot;

a = rand(Float32, 50_000)
b = rand(Float32, 50_000)

d_a = CLArray(a; access=:r)
d_b = CLArray(b; access=:r)
d_c = similar(d_a; access=:w)

p = cl.Program(; source) |&gt; cl.build!
k = cl.Kernel(p, &quot;vadd&quot;)

clcall(k, Tuple{Ptr{Float32}, Ptr{Float32}, Ptr{Float32}},
       d_a, d_b, d_c; global_size=size(a))

c = Array(d_c)

@assert a + b ≈ c"><pre><span class="pl-k">using</span> OpenCL, pocl_jll

<p dir="auto">If your platform supports SPIR-V, it's possible to use Julia functions as kernels:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using OpenCL, pocl_jll

function vadd(a, b, c)
    gid = get_global_id(1)
    @inbounds c[gid] = a[gid] + b[gid]
    return
end

a = rand(Float32, 50_000)
b = rand(Float32, 50_000)

d_a = CLArray(a; access=:r)
d_b = CLArray(b; access=:r)
d_c = similar(d_a; access=:w)

@opencl global_size=size(a) vadd(d_a, d_b, d_c)

c = Array(d_c)

@assert a + b ≈ c"><pre><span class="pl-k">using</span> OpenCL, pocl_jll
