<p dir="auto">JudiLingMeasures enables easy calculation of measures in Discriminative Lexicon Models developed with <a href="https://github.com/quantling/JudiLing.jl">JudiLing</a> (Luo, Heitmeier, Chuang and Baayen, 2024).</p>
<p dir="auto">Most measures in JudiLingMeasures are based on R implementations in WpmWithLdl (Baayen et al., 2018) and <a href="https://github.com/dosc91/LDLConvFunctions">LdlConvFunctions</a> (Schmitz, 2021) and the Python implementation in <a href="https://github.com/msaito8623/pyldl">pyldl</a> (Saito, 2022) (but all errors are my own). The conceptual work behind this package is therefore very much an effort of many people (see <a href="https://quantling.github.io/JudiLingMeasures.jl/dev/index.html#Bibliography" rel="nofollow">Bibliography</a>). I have tried to acknowledge where each measure is used/introduced, but if I have missed anything, or you find any errors please let me know: maria dot heitmeier at uni dot tuebingen dot de.</p>
<p dir="auto">You can find the documentation <a href="https://quantling.github.io/JudiLingMeasures.jl/dev/index.html" rel="nofollow">here</a>.</p>
