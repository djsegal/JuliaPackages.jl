<p dir="auto">Julia interface to <a href="https://catboost.ai/" rel="nofollow">CatBoost</a>. This library is a wrapper CatBoost's Python package via <a href="https://github.com/cjdoris/PythonCall.jl">PythonCall.jl</a>.</p>
<p dir="auto">For a nice introduction to the package, see the <a href="https://github.com/JuliaAI/CatBoost.jl/blob/main/examples/">examples</a>.</p>

<p dir="auto">By default, <code>CatBoost.jl</code> installs the latest compatible version of <code>catboost</code> (version <code>&gt;=1.1</code>) in your current <code>CondaPkg.jl</code> environment. To install a specific version, create a <code>CondaPkg.toml</code> file using <code>CondaPkg.jl</code>. Below is an example for specifying <code>catboost</code> version <code>v1.1</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using CondaPkg
CondaPkg.add(&quot;catboost&quot;; version=&quot;=1.1&quot;)"><pre><span class="pl-k">using</span> CondaPkg
CondaPkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>catboost<span class="pl-pds">"</span></span>; version<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>=1.1<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">This will create a <code>CondaPkg.toml</code> file in your current envrionment with the restricted <code>catboost</code> version. For more information on managing Conda environments with <code>CondaPkg.jl</code>, refer to the <a href="https://github.com/cjdoris/CondaPkg.jl">official documentation</a>.</p>
