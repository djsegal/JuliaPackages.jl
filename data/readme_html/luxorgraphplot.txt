<p dir="auto">A minimum package for displaying a graph and configurations defined on graphs.
It is the <a href="https://github.com/JuliaGraphics/Luxor.jl"><code>Luxor</code></a> version of <a href="https://github.com/JuliaGraphs/GraphPlot.jl"><code>GraphPlot</code></a>.</p>
<p dir="auto">Install by typing <code>using Pkg; Pkg.add("LuxorGraphPlot")</code> in a julia REPL.</p>
<p dir="auto">(NOTE: After implementing this package, I noticed there is a similar package with more features: <a href="https://github.com/cormullion/Karnak.jl">https://github.com/cormullion/Karnak.jl</a>.)</p>

        text(&quot;y&quot;, c1)
        text(&quot;x&quot;, c2)
        text(&quot;z&quot;, offset(c3, (10, 0)))
        line(c1, c2)
        line(midpoint(c1, c2), c3)
        end
    end"><pre><span class="pl-k">using</span> LuxorGraphPlot, LuxorGraphPlot<span class="pl-k">.</span>Luxor
