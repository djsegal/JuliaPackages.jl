<p dir="auto">A package for haplotype reconstruction in connected polyploid F1 populations</p>
<p dir="auto">See <a href="https://github.com/chaozhi/PolyOriginCmd">PolyOriginCmd</a> for running PolyOrigin in command line interface</p>
<p dir="auto">See <a href="https://github.com/chaozhi/PolyOriginR">PolyOriginR</a> for running PolyOrigin in R</p>

<ul dir="auto">
<li>Apply to connected F1 in tetraploid (TODO for higher ploidy levels. Limited tests for diploids.)</li>
<li>Apply to SNP array and GBS data</li>
<li>Robust to dosage errors in SNP array data</li>
<li>Robust to dosage uncertainties in low read depth GBS data</li>
<li>Robust to errors in input genetic or physical map</li>
</ul>
