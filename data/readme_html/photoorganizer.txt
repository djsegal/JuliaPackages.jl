<p dir="auto">PhotoOrganizer is designed to organize photos (and videos) into a fixed directory structure archive (since manually managing photos is a waste of time).</p>
<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Usage:</h1><a id="user-content-usage" class="anchor" aria-label="Permalink: Usage:" href="#usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="organize_photos(src_dirs, dst_root, rm_src, dry_run)"><pre class="notranslate"><code>organize_photos(src_dirs, dst_root, rm_src, dry_run)
</code></pre></div>
<p dir="auto">Move and rename photos in <code>src_dirs</code> source directories to an organized <code>dst_root</code> destination directory.</p>
<p dir="auto">The destination directory is organized as follows:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="&lt;root&gt;/YYYY/&lt;season&gt;/YYYYMMDD_HHMMSS.SSS_&lt;camera_model&gt;.&lt;extension&gt;"><pre class="notranslate"><code>&lt;root&gt;/YYYY/&lt;season&gt;/YYYYMMDD_HHMMSS.SSS_&lt;camera_model&gt;.&lt;extension&gt;
</code></pre></div>
<p dir="auto">where <code>season</code> is <code>Spring</code>, <code>Summer</code>, <code>Fall</code> or <code>Winter</code> (depending of photo's date).</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Arguments</h2><a id="user-content-arguments" class="anchor" aria-label="Permalink: Arguments" href="#arguments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>src_dirs::Vector{String}</code>: dirctories containing photos to organize.</li>
<li><code>dst_root:String</code>: the destination directory of organized photos.</li>
<li><code>rm_src::Bool</code>: delete source photo if true.  Useful if coming from SD card.</li>
<li><code>dry_run::Bool</code>: if true then don't change anything, just print what would happen.</li>
</ul>
