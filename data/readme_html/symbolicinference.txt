<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Chaotic, non-linear systems and recurrence analysis</h3><a id="user-content-chaotic-non-linear-systems-and-recurrence-analysis" class="anchor" aria-label="Permalink: Chaotic, non-linear systems and recurrence analysis" href="#chaotic-non-linear-systems-and-recurrence-analysis"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">See the <a href="https://osf.io/preprints/osf/3ws85" rel="nofollow">white-paper</a> and it's <a href="https://github.com/fargolo/paper-vignettes/">repo</a></p>
<p dir="auto">The recurrence of states, in the meaning that states are again arbitrarily close after some time of divergence, is a fundamental property of deterministic dynamical systems and is typical for nonlinear or chaotic systems.</p>
<p dir="auto">Poincaré discusse this property in 1890 and it was later proved by Constantin Carathéodory (see Poincaré recurrence theorem). Further on, several techniques address recurrences in dynamical systems for inference.</p>
<p dir="auto">Recurrence plots (RPs) were creature to capture such patterns and several parameters that caractherize the underlying time-series can be obtained with recurrence quantification analysis (RQA).</p>
<p dir="auto">Since each pair of states is mapped into a binary value ('close enough',1, or 'not close enough',0), making probabilistic inference with symbolic methods is straightforward.</p>
<p dir="auto">The procedure in <code>rec_matrix_motifs()</code> iterates over <a href="https://juliadynamics.github.io/DynamicalSystemsDocs.jl/recurrenceanalysis/stable/" rel="nofollow">recurrence matrices</a> diagonals and checks for repeated motifs. Specifically, whether the size of the longest consecutive sequence in each off-diagonal is unexpectedly large. This may hint at underlying patterns, such as autocorrelations and periodic components.</p>
