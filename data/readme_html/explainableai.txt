<p dir="auto">Explainable AI in Julia.</p>
<p dir="auto">This package implements interpretability methods for black-box classifiers,
with an emphasis on local explanations and attribution maps in input space.
The only requirement for the model is that it is differentiable<sup><a href="#user-content-fn-1-238595e73b4e9f5accda9297f307caca" id="user-content-fnref-1-238595e73b4e9f5accda9297f307caca" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.
It is similar to <a href="https://github.com/pytorch/captum">Captum</a> and <a href="https://github.com/chr5tphr/zennit">Zennit</a> for PyTorch
and <a href="https://github.com/albermax/innvestigate">iNNvestigate</a> for Keras models.</p>

<p dir="auto">Depending on the method, the applied heatmapping defaults differ:
sensitivity-based methods (e.g. <code>Gradient</code>) default to a grayscale color scheme,
whereas attribution-based methods (e.g. <code>InputTimesGradient</code>) default to a red-white-blue color scheme.
Red color indicates regions of positive relevance towards the selected class,
whereas regions in blue are of negative relevance.
More information on heatmapping presets can be found in the <a href="https://julia-xai.github.io/XAIDocs/XAIDocs/dev/generated/heatmapping/" rel="nofollow">Julia-XAI documentation</a>.</p>
