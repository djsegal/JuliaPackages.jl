<p dir="auto">To download data into an IO stream from a special URL of the form
<code>url = "https://docs.google.com/uc?export=download&amp;id=1GqmszfSB_LHGQEQpSjoiPyDROZ5a8Ls4"</code>,
use the following code:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Downloads: download
io = IOBuffer()
download(url, io)
str = String(take!(io)) # (this line for text data only)"><pre><span class="pl-k">using</span> Downloads<span class="pl-k">:</span> download
io <span class="pl-k">=</span> <span class="pl-c1">IOBuffer</span>()
<span class="pl-c1">download</span>(url, io)

<p dir="auto">To download data from a typical Google Drive URL of the form
<code>url = "https://drive.google.com/file/d/1GqmszfSB_LHGQEQpSjoiPyDROZ5a8Ls4"</code>,
use the following code
that converts the URL internally for convenience:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GoogleDrive: google_download
