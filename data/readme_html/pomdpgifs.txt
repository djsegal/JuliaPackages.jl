<p dir="auto">Currently, there are two utilities:</p>
<ul dir="auto">
<li>A <code>GifSimulator</code> to be used with the <code>simulate</code> function.</li>
<li>A <code>makegif</code> convenience function to (1) run a simulation and create a gif, or (2) create a gif from a model.</li>
</ul>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">GifSimulator</h3><a id="user-content-gifsimulator" class="anchor" aria-label="Permalink: GifSimulator" href="#gifsimulator"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>GifSimulator(kwargs...)</code>. Create a simulator for producing a gif output by calling <code>POMDPTools.render</code> at each step.</p>
<p dir="auto"><strong>Keyword Arguments</strong></p>
<ul dir="auto">
<li><code>filename::String=tempname()*".gif"</code></li>
<li><code>fps::Int=2</code>: frames per second</li>
<li><code>spec::Any</code>: specification for which elements of a step to render (see <code>POMDPTools.eachstep</code>)</li>
<li><code>max_steps::Int=nothing</code></li>
<li><code>rng::AbstractRNG=GLOBAL_RNG</code></li>
<li><code>show_progress::Bool</code></li>
<li><code>extra_initial::Bool</code> if set to true, the simulator adds an extra step at time 0 (before first transition)</li>
<li><code>extra_final::Boll</code> if set to true, the simulator adds an extra setp at the end (after the last transition)</li>
<li><code>render_kwargs</code>: keyword args to be fed to <code>POMDPTools.render</code></li>
</ul>

<p dir="auto">Create a gif of a single simulation of a POMDP or MDP by calling <code>POMDPTools.render</code> at each step.</p>
<p dir="auto"><strong>Arguments:</strong></p>
<ul dir="auto">
<li><code>m::Union{POMDP,MDP}</code>: the model to be simulated</li>
</ul>
<p dir="auto">All other positional arguments, for instance a policy, updater, initial state, etc. will be fed to the <code>simulate</code> function. See <a href="https://juliapomdp.github.io/POMDPs.jl/stable/POMDPTools/simulators/" rel="nofollow">POMDPTools Simulators documentation</a> for more info.</p>
<p dir="auto"><strong>Keyword Arguments</strong>
All keyword arguments are fed to the <code>GifSimulator</code> constructor. See its documentation for more info.</p>
