<p dir="auto">Drop-in replacement for <a href="https://github.com/JuliaDatabases/SQLite.jl">SQLite.jl</a>, but uses <a href="https://github.com/sqlcipher/sqlcipher">SQLCipher</a> instead of plain SQLite. This is a fork of <code>SQLite.jl</code>, keeping the same underlying code and package versions.</p>
<p dir="auto">See <code>SQLite.jl</code> docs for the interface and usage information, and SQLCipher docs for details on encryption features.</p>
<p dir="auto">Briefly, encryption is enabled by running</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="SQLite.execute(db, &quot;&quot;&quot;PRAGMA key=&quot;&lt;your password&gt;&quot; &quot;&quot;&quot;)"><pre>SQLite<span class="pl-k">.</span><span class="pl-c1">execute</span>(db, <span class="pl-s"><span class="pl-pds">"""</span>PRAGMA key="&lt;your password&gt;" <span class="pl-pds">"""</span></span>)</pre></div>
<p dir="auto">after opening the database.</p>
