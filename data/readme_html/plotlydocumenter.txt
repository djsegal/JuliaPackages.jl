<p dir="auto">This package exports a single function <code>to_documenter</code> that takes a Plot object from one the following packages:</p>
<ul dir="auto">
<li>PlotlyBase</li>
<li>PlotlyJS</li>
<li>PlotlyLight</li>
</ul>
<p dir="auto">and returns an object that will show an interactive plot on the HTML pages generated by Documenter.jl.</p>
<p dir="auto">See the <a href="https://disberd.github.io/PlotlyDocumenter.jl/" rel="nofollow">documentation</a> for more details.</p>
