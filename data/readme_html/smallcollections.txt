<p dir="auto">This Julia package defines three immutable collections types, <code>SmallVector</code>,
<code>PackedVector</code> and <code>SmallBitSet</code>. They don't allocate and are often much faster
than their allocating counterparts <code>Vector</code> and <code>BitSet</code>. Unlike the static vectors
provided by <a href="https://github.com/JuliaArrays/StaticArrays.jl">StaticArrays.jl</a>,
<a href="https://github.com/chakravala/StaticVectors.jl">StaticVectors.jl</a> and
<a href="https://github.com/eschnett/SIMD.jl">SIMD.jl</a>,
the length of a <code>SmallVector</code> or <code>PackedVector</code> is variable with a user-defined limit.</p>
<p dir="auto">If the package <a href="https://github.com/JuliaFolds2/BangBang.jl">BangBang.jl</a>
is loaded, then many functions defined by this package are also available
in a <code>!!</code>-form. For example, both <code>push</code> and <code>push!!</code> add an element
to a <code>SmallVector</code>, <code>PackedVector</code> or <code>SmallBitSet</code>.</p>
<p dir="auto">Below are <a href="#examples">examples</a> and <a href="#benchmarks">benchmarks</a>. For details see
the <a href="https://matthias314.github.io/SmallCollections.jl/stable/" rel="nofollow">documentation</a>.</p>

<p dir="auto">A vector of type <code>SmallVector{N,T}</code> can hold up to <code>N</code> elements of type <code>T</code>.
Both <code>N</code> and <code>T</code> can be arbitrary. (If <code>T</code> is not a concrete type, however,
then creating a small vector does allocate.)</p>

<p dir="auto">A <code>PackedVector</code> can store bit integers or <code>Bool</code> values.
The elements of a <code>PackedVector{U,M,T}</code> are stored in a common bit mask of type <code>U</code>
with <code>M</code> bits for each entry. When retrieving elements, they are of type <code>T</code>.</p>
<p dir="auto">Compared to a <code>SmallVector</code>, a <code>PackedVector</code> may have faster insert and delete operations.
Arithmetic operations are usually slower unless <code>M</code> is the size of a hardware integer.</p>
