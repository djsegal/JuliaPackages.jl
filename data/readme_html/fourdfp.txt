<p dir="auto">This package implements a simple 4dfp-reading function <code>Fourdfp.load(filename)</code> for the Julia language.</p>
<p dir="auto">4dfp is a format for storing volumetric fMRI images, developed at Washington University in St. Louis by Avi Snyder. For further information, see its <a href="https://4dfp.readthedocs.io/en/latest/format.html" rel="nofollow">documentation</a>.</p>

<p dir="auto">Just call <code>Fourdfp.load(filename)</code>, optionally with a <code>byte_order</code> keyword argument (<code>LittleEndian</code> or <code>BigEndian</code>). If the latter is omitted, the package will attempt to determine your file's byte order by parsing its .ifh (inter-file header) file. Since 4dfp files come in sets of 3 or 4 (.4dfp.img, .4dfp.ifh, .4dfp.hdr), the filename you specify can be any one of that set or for brevity you can just omit the .4dfp.* file extension.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using Fourdfp

my_data_array = Fourdfp.load(filename; byte_order = LittleEndian)
</code></pre></div>
<p dir="auto">The return value will be an Array{Float32, 4}, where the dimensions represent x, y, z, and time.</p>
