<p dir="auto">A Julia implementation of boosted trees with CPU and GPU support.
Efficient histogram based algorithms with support for multiple loss functions (notably multi-target objectives such as max likelihood methods).</p>
<p dir="auto"><a href="https://github.com/Evovest/EvoTrees">R binding available</a>.</p>

<p dir="auto">When using a DataFrames as input, features with elements types <code>Real</code> (incl. <code>Bool</code>) and <code>Categorical</code> are automatically recognized as input features. Alternatively, <code>fnames</code> kwarg can be used to specify the variables to be used as features.</p>
<p dir="auto"><code>Categorical</code> features are treated accordingly by the algorithm: ordered variables are treated as numerical features, using <code>≤</code> split rule, while unordered variables are using <code>==</code>. Support is currently limited to a maximum of 255 levels. <code>Bool</code> variables are treated as unordered, 2-levels categorical variables.</p>
