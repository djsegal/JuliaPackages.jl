<p dir="auto">This package provides common transformation operations related to matrix vectorization.</p>
<ul dir="auto">
<li><code>vech</code> provides the half-vectorization</li>
<li><code>duplication_matrix</code> and <code>elimination_matrix</code> allow transformation between <code>vec(A)</code> and <code>vech(A)</code></li>
<li><code>commutation_matrix</code> transforms <code>vec(A)</code> into <code>vec(A')</code></li>
<li><code>symmetrizer_matrix</code> transforms <code>vec(A)</code> into <code>vec((A + A')/2)</code></li>
</ul>
<p dir="auto">The matrix transformations are returned as sparse arrays to improve performance.</p>
<p dir="auto">Refer to the function docstrings for additional detail.</p>
