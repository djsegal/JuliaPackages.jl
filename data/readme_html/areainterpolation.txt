<p dir="auto">AreaInterpolation.jl is a package to perform "areal interpolation", that is, interpolating values associated with one set of polygons, to another set of polygons that overlap the first set <sup><a href="#user-content-fn-GISTBOK-b3b9717141a3d7dc9fe71b7ace785a27" id="user-content-fnref-gistbok-b3b9717141a3d7dc9fe71b7ace785a27" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.</p>
<p dir="auto">Similar implementations in other languages can be found in <sup><a href="#user-content-fn-areal-b3b9717141a3d7dc9fe71b7ace785a27" id="user-content-fnref-areal-b3b9717141a3d7dc9fe71b7ace785a27" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup> (R), <sup><a href="#user-content-fn-sf-b3b9717141a3d7dc9fe71b7ace785a27" id="user-content-fnref-sf-b3b9717141a3d7dc9fe71b7ace785a27" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup> (R), and <sup><a href="#user-content-fn-tobler-b3b9717141a3d7dc9fe71b7ace785a27" id="user-content-fnref-tobler-b3b9717141a3d7dc9fe71b7ace785a27" data-footnote-ref="" aria-describedby="footnote-label">4</a></sup> (Python).</p>

<p dir="auto">The main entry point is the <code>AreaInterpolation.interpolate([alg], source, dest; extensive = (:col_a, :col_b), intensive = (:col1, :col2))</code>.</p>
