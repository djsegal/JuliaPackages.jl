<p dir="auto">OpticalFibers is a package that allows to compute modes of optical fibers. Different methods are implemented to find scalar or vector modes:</p>
<ul dir="auto">
<li>A semi-analytical solver (based on Bessel functions) for multi-step index fibers.</li>
<li>Finite element method (using <code>Gridap.jl</code>) for any kind of isotropic or anisotropic fiber</li>
</ul>
