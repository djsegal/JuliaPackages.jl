<p dir="auto">Targets RME v1.0, and provides some convenience functions for outplanting interventions.
All other functions are accessible via the <code>@RME</code> macro.</p>
<p dir="auto">The RME library, accompanying dataset, and RME documentation has to be requested from RME developers.</p>
