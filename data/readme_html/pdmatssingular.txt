<p dir="auto">This package allows to use <code>PDMats</code> with singular covariance matrices.</p>
<p dir="auto">For instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Σ = covariance_from([1; 0;;])"><pre>Σ <span class="pl-k">=</span> <span class="pl-c1">covariance_from</span>([<span class="pl-c1">1</span>; <span class="pl-c1">0</span>;;])</pre></div>
<p dir="auto">Then:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Matrix(Σ)"><pre><span class="pl-c1">Matrix</span>(Σ)</pre></div>
<p dir="auto">gives</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="2×2 Matrix{Int64}:
 1  0
 0  0"><pre class="notranslate"><code>2×2 Matrix{Int64}:
 1  0
 0  0
</code></pre></div>
<p dir="auto">The random variable with this covariance can be sampled as follows.
With</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="rng = Random.default_rng()"><pre>rng <span class="pl-k">=</span> Random<span class="pl-k">.</span><span class="pl-c1">default_rng</span>()</pre></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="sample(rng, Σ)"><pre><span class="pl-c1">sample</span>(rng, Σ)</pre></div>
<p dir="auto">gives samples with the singular covariance above, that is, the second component is guaranteed to be zero.</p>
