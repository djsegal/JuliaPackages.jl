<p dir="auto">You can find the documentation <a href="https://dsb-lab.github.io/CellBasedModels.jl/stable/" rel="nofollow"><strong>here!</strong></a></p>
<p dir="auto">The CellBasedModels.jl package aims to help fast-designing and simulation of agent-based models with possibilities to be run in CPU and NVidia GPUs for the efficient computation of large-scale systems.</p>
<p dir="auto">The following methods can be implemented in the model:</p>
<ul dir="auto">
<li>ODEs</li>
<li>SDEs</li>
<li>Division</li>
<li>Death</li>
<li>Coupling to continuum models evolving with PDEs</li>
<li>Random events</li>
</ul>
<p dir="auto">Check the
Examples to get an idea of the capabilities of the package.</p>

<p dir="auto">At the present stage of development, the library is not capable of working on batches of data. That means that the size of the simulated models will be limited by the memory disponibility in RAM or the GPU, depending on the platform in which the simulations are being tested.</p>
<p dir="auto">Moreover, we can only use GPUs from NVidia as the GPU implementation is based on CUDA.jl.</p>
