<p dir="auto">The ClausenFunctions.jl package provides Julia implementations of the
Standard Clausen functions and Glaisher-Clausen functions of integer
order for real or complex arguments.</p>

<p dir="auto">The implementation of the Standard Clausen function <code>cl(n,x)</code> for real
<code>x</code> follows the approach presented in [Jiming Wu, Xiaoping Zhang,
Dongjie Liu, "An efficient calculation of the Clausen functions
Cl_n(θ)(n &gt;= 2)", Bit Numer Math 50, 193-206 (2010)
<a href="https://doi.org/10.1007/s10543-009-0246-8" rel="nofollow">https://doi.org/10.1007/s10543-009-0246-8</a>].</p>
