<p dir="auto">A single file Julia libray using <code>pack(1)</code> alignment to pack value-typed instances into UInt8 arrays.</p>
<p dir="auto">This is useful when sending data over the network or sharing data with other computer despite different endianness.</p>
<p dir="auto">The motivation for this project was to teach <a href="https://docs.julialang.org/en/v1/manual/metaprogramming/#Generated-functions" rel="nofollow">Julia-generated functions</a> to achieve high performance computations.</p>
