<p dir="auto">This package allows to use machine learning in Julia through a graphical user interface.</p>
<p dir="auto">NB! This is a beta version. Bugs and breaking changes should be expected.</p>
<p dir="auto">The package will be updated to Julia 1.7 as soon as <a href="https://github.com/barche/QML.jl">QML.jl</a> is updated.</p>
<p dir="auto">If you are interested in the package and would like to contribute then write here: <a href="mailto:a_ill@outlook.com">a_ill@outlook.com</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">It is possible to:</p>
<ul dir="auto">
<li>Design a neural network</li>
<li>Train a neural network</li>
<li>Validate a neural network</li>
<li>Apply a neural network to new data</li>
</ul>
<p dir="auto">Classification, regression and segmentation on images are currently supported.</p>
<p dir="auto"><a href="https://github.com/FluxML/Flux.jl">Flux.jl</a> machine learning library is used under the hood.</p>
