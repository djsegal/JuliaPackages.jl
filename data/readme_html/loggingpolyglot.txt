<p dir="auto">A minimal and opinionated way to deal with compositional loggers built with LoggingExtras.jl.</p>
<p dir="auto">The package also helps users to deal with logs in multiple languages.</p>

<li><code>min_level_console</code>: Minimum level shown in console. Default: Logging.Info</li>
<li><code>min_level_file</code>: Minimum level shown in file. Default: Logging.Debug</li>
<li><code>append_log</code>: Boolean input to append logs in existing log file (if true) or overwrite/create log file (if false). Default is false</li>
<li><code>bracket_dict</code>: select the brackets for each LogLevel. As default,</li>
</ul>
