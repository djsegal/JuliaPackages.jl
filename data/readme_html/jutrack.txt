<p dir="auto">A Julia-based package that enables advanced auto differentiation (AD) for symplectic 6-D particle tracking in particle accelerators.</p>

<p dir="auto">Multi-threading is available for multi-particle tracking. Before using it, one has to set up the number of threads.</p>
<p dir="auto">On Linux or macOS:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="export JULIA_NUM_THREADS=N"><pre class="notranslate"><code>export JULIA_NUM_THREADS=N
</code></pre></div>
<p dir="auto">or add the above line to your .bashrc file. Change N to the desired number of threads.</p>
<p dir="auto">On Windows:
Maually add JULIA_NUM_THREADS as the variable name and N (the number of threads) as the variable value in system variable.</p>
<p dir="auto">It is recommended to use Visual Studio Code to permanently set up the Julia environment.
Open the command palette (Ctrl+Shift+P or Cmd+Shift+P on macOS).
Type "Preferences: Open Settings (JSON)" and select it to open the settings file.
Add or modify the Julia settings to include the environment variable like this:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="&quot;julia.executablePath&quot;: &quot;path/to/julia&quot;, // change it to your Julia path

    &quot;JULIA_NUM_THREADS&quot;: &quot;48&quot; // Adjust the number to the desired number of threads
}"><pre class="notranslate"><code>"julia.executablePath": "path/to/julia", // change it to your Julia path
"julia.environmentVariables": {
    "JULIA_NUM_THREADS": "48" // Adjust the number to the desired number of threads

</code></pre></div>
<p dir="auto">To check if the multi-threading is set up correctly, open the Julia REPL, and type:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="println(&quot;Number of threads in use: &quot;, Threads.nthreads())"><pre class="notranslate"><code>println("Number of threads in use: ", Threads.nthreads())
</code></pre></div>
