<p dir="auto"><strong>Fast and flexible nonadiabatic molecular dynamics in Julia!</strong></p>
<ul dir="auto">
<li>🚗 <strong>Fast:</strong> uses <a href="https://diffeq.sciml.ai/stable/" rel="nofollow">DifferentialEquations.jl</a> for efficient dynamics.</li>
<li>🪚 <strong>Extensible:</strong> plenty of room for more methods.</li>
<li>⚛️ <strong>Transferable:</strong> handles both simple models and atomistic systems.</li>
<li>👩‍🏫 <strong>Helpful:</strong> extended documentation with plenty of examples.</li>
</ul>
<p align="center" dir="auto">
<a href="https://nqcd.github.io/NQCDynamics.jl/stable/" rel="nofollow"><strong>Explore the NQCDynamics.jl docs 📚</strong></a>
</p>
<hr>
<p dir="auto">With this package you can generate the initial conditions and perform the dynamics for your nonadiabatic dynamics simulations.
Tight integration with <a href="https://diffeq.sciml.ai/stable/" rel="nofollow">DifferentialEquations.jl</a>
makes the implementation of new methods relatively simple since we
build upon an already successful package providing a vast array of features.
We hope that the package will be of use to new students and experienced researchers alike, acting as a tool for learning and for developing new methods.</p>
