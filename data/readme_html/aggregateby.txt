<p dir="auto"><strong>NOTE</strong>: AggregateBy is not registered. For a registered package with similar functionality, see <a href="https://github.com/JuliaData/SplitApplyCombine.jl">https://github.com/JuliaData/SplitApplyCombine.jl</a>.</p>
<p dir="auto">AggregateBy supports simple aggregation operations on iterable containers. Functions that might (in other languages) be called <code>countby</code> and <code>groupby</code> are instead composed of two pieces, (1) an aggregation command and (2) a <code>By(fkey, fval)</code> elementwise operator that generates key, value pairs for aggregation. Some examples may help explain the general concept.</p>
