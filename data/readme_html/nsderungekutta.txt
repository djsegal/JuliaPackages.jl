<p dir="auto">Let's say that we want to solve the <a href="https://en.wikipedia.org/wiki/Pendulum_(mathematics)#Simple_gravity_pendulum" rel="nofollow">simple gravity pendulum problem</a> using the <a href="https://en.wikipedia.org/wiki/Midpoint_method" rel="nofollow">midpoint method</a>. Here is one way to do it with NSDERungeKutta.jl:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NSDERungeKutta
f(u, t) = [u[2]; -sin(u[1])]
u0 = [0.0; π/4]
tspan = (0.0, 2π/3 * √9.81)
problem = IVP(f, u0, tspan)
solver = Midpoint(h = 1e-2)
solution = solve(problem, solver)"><pre><span class="pl-k">using</span> NSDERungeKutta
<span class="pl-en">f</span>(u, t) <span class="pl-k">=</span> [u[<span class="pl-c1">2</span>]; <span class="pl-k">-</span><span class="pl-c1">sin</span>(u[<span class="pl-c1">1</span>])]
u0 <span class="pl-k">=</span> [<span class="pl-c1">0.0</span>; π<span class="pl-k">/</span><span class="pl-c1">4</span>]
tspan <span class="pl-k">=</span> (<span class="pl-c1">0.0</span>, <span class="pl-c1">2</span>π<span class="pl-k">/</span><span class="pl-c1">3</span> <span class="pl-k">*</span> <span class="pl-k">√</span><span class="pl-c1">9.81</span>)

<p dir="auto">We can plot the obtained <code>solution</code> by extracting its fields <code>u</code> and <code>t</code>, e.g. using the convenient macro <code>@↓ u, t = solution</code> from <a href="https://github.com/giancarloantonucci/ArrowMacros.jl">ArrowMacros.jl</a>. Alternatively, we can use the available predefined recipes:</p>

<p dir="auto">This package currently supports the following methods:</p>
<p dir="auto"><strong>Explicit</strong>:</p>
<ul dir="auto">
<li><code>Euler</code>/<code>ExplicitEuler</code>, <code>Heun2</code>, <code>Midpoint</code>/<code>ExplicitMidpoint</code>, <code>Ralston2</code>, <code>Heun3</code>, <code>RungeKutta3</code>/<code>RK3</code>, <code>Ralston3</code>, <code>SSPRK3</code>, <code>Ralston4</code>, <code>RungeKutta4</code>/<code>RK4</code>, <code>Rule38</code>, <code>Butcher5</code>, <code>KuttaNystrom5</code>, <code>Butcher6</code>, <code>Butcher7</code>,</li>
<li>(Embedded) <code>HeunEuler</code>, <code>BogackiShampine</code>, <code>Fehlberg45</code>, <code>DormandPrince54</code>, <code>Verner65</code>, <code>Fehlberg78</code>.</li>
</ul>
<p dir="auto"><strong>Diagonally Implicit</strong>:</p>
<ul dir="auto">
<li><code>BackwardEuler</code>/<code>ImplicitEuler</code>, <code>ImplicitMidpoint</code>/<code>GaussLegendre2</code>, <code>SDIRK2</code>, <code>LobattoIII2</code>, <code>CrankNicolson</code>/<code>LobattoIIIA2</code>, <code>SDIRK3</code>, <code>RadauI3</code>, <code>RadauII3</code>, <code>SDIRK4</code>, <code>LobattoIII4</code>.</li>
</ul>
<p dir="auto"><strong>Implicit</strong>:</p>
<ul dir="auto">
<li><code>LobattoIIIC2</code>, <code>RadauIA3</code>, <code>RadauIIA3</code>, <code>GaussLegendre4</code>, <code>LobattoIIIA4</code>, <code>LobattoIIIB4</code>, <code>LobattoIIIC4</code>, <code>RadauI5</code>, <code>RadauIA5</code>, <code>RadauII5</code>, <code>RadauIIA5</code>, <code>GaussLegendre6</code>.</li>
</ul>
