<p dir="auto">A fast and easy to use Julia implementation of the model described in <a href="https://www.sciencedirect.com/science/article/abs/pii/S0165188914001572" rel="nofollow"><em>Emergent dynamics of a macroeconomic agent based model with capital and credit</em></a>.
The package can be used to simulate the original model or as a base for extensions. If you are not familiar with Julia and the way in which multiple dispatch allows for powerful extensions, don't hesitate to get in touch!</p>
