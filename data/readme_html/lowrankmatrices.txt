<p dir="auto">This package is an offshoot of <code>LowRankApprox.jl</code>, and provides the <code>LowRankMatrix</code> type that is used in that package. It should be a lightweight dependency if you only need to use a <code>LowRankMatrix</code> without the functionality provided by <code>LowRankApprox.jl</code>.</p>
<p dir="auto">Currently, the package only defines and exports <code>LowRankMatrix</code>, although this might change in the future.</p>
