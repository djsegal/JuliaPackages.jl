<p dir="auto">This is a Julia package for solving partial differential equations (PDEs) of the form</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$$
\dfrac{\partial u(\boldsymbol x, t)}{\partial t} + \boldsymbol{\nabla} \boldsymbol{\cdot} \boldsymbol{q}(\boldsymbol x, t, u) = S(\boldsymbol x, t, u), \quad (x, y)^{\mkern-1.5mu\mathsf{T}} \in \Omega \subset \mathbb R^2,t&gt;0,
$$</math-renderer></p>
<p dir="auto">in two dimensions using the finite volume method, with support also provided for steady-state problems and for systems of PDEs of the above form. In addition to this generic form above, we also provide support for specific problems that can be solved in a more efficient manner, namely:</p>
<ol dir="auto">
<li>
<code>DiffusionEquation</code>s: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$\partial_tu = \boldsymbol\nabla\boldsymbol\cdot[D(\boldsymbol x)\boldsymbol\nabla u]$</math-renderer>.</li>
<li>
<code>MeanExitTimeProblem</code>s: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$\boldsymbol\nabla\boldsymbol\cdot[D(\boldsymbol x)\boldsymbol\nabla T(\boldsymbol x)] = -1$</math-renderer>.</li>
<li>
<code>LinearReactionDiffusionEquation</code>s: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$\partial_tu = \boldsymbol\nabla\boldsymbol\cdot[D(\boldsymbol x)\boldsymbol\nabla u] + f(\boldsymbol x)u$</math-renderer>.</li>
<li>
<code>PoissonsEquation</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$\boldsymbol\nabla\boldsymbol\cdot[D(\boldsymbol x)\boldsymbol\nabla u] = f(\boldsymbol x)$</math-renderer>.</li>
<li>
<code>LaplacesEquation</code>: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="e98e16c6832f9a9299eb24956629a6e2">$\boldsymbol\nabla\boldsymbol\cdot[D(\boldsymbol x)\boldsymbol\nabla u] = 0$</math-renderer>.</li>
</ol>
<p dir="auto">See the documentation for more information.</p>
<p dir="auto">If this package doesn't suit what you need, you may like to review some of the other PDE packages shown <a href="https://github.com/JuliaPDE/SurveyofPDEPackages">here</a>.</p>
<p dir="auto">As a very quick demonstration, here is how we could solve a diffusion equation with Dirichlet boundary conditions on a square domain using the standard <code>FVMProblem</code> formulation; please see the docs for more information.</p>
