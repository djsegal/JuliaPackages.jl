<p dir="auto">General purpose motif discovery package that includes the discovery of flexible (long or gapped) motifs.</p>
<p dir="auto">This code repository corresponds to the paper <a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Finding Motifs Using DNA Images Derived From Sparse Representations</a>, which has been published in Oxford Bioinformatics.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Motivation</h2><a id="user-content-motivation" class="anchor" aria-label="Permalink: Motivation" href="#motivation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Traditional methods such as <a href="https://meme-suite.org/meme/doc/streme.html" rel="nofollow">STREME</a> and <a href="http://homer.ucsd.edu/homer/motif/" rel="nofollow">HOMER</a> excel at efficiently finding the primary motifs of a transcription factor. This raises the question: why do we require an additional motif discovery method?</p>
<p dir="auto">Because there may be more patterns in the datasets that aren't fully captured. This is especially evident for context-dependent binding sites, such as C2H2 zinc finger, and cooperative binding patterns observed in in-vivo datasets from ChIP-Seq.</p>
<p dir="auto">Our work reveals that over half of the ChIP-Seq datasets selected from the <a href="https://jaspar.genereg.net/" rel="nofollow">JASPAR 2022</a> database contain transposable elements that overlap the primary binding sites. For instance, see <a href="https://en.wikipedia.org/wiki/NFE2L2" rel="nofollow">NFE2L2</a>, <a href="https://en.wikipedia.org/wiki/YY1" rel="nofollow">YY1</a>, <a href="https://en.wikipedia.org/wiki/STAT1" rel="nofollow">STAT1</a>, <a href="https://en.wikipedia.org/wiki/Serum_response_factor" rel="nofollow">SRF</a>, <a href="https://en.wikipedia.org/wiki/Androgen_receptor" rel="nofollow">AR</a> (<a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Manuscript Figure 4</a>):</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="./imgs/long_1.png"><img src="./imgs/long_1.png" alt="image info" style="max-width: 100%;"></a></p>
<p dir="auto">These long patterns present challenges for traditional k-mer-based methods due to their exponential time and space complexity.</p>
<p dir="auto">Furthermore, many datasets exhibit a large presence of gapped motifs. For example, we found that ChIP-Seq datasets from both <a href="https://jaspar.genereg.net/" rel="nofollow">JASPAR</a> and <a href="https://www.factorbook.org/" rel="nofollow">Factorbook</a> often contains gapped motifs (<a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Manuscript Figure 6</a>):</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="./imgs/gapped.png"><img src="./imgs/gapped.png" alt="image info" style="max-width: 100%;"></a></p>
<p dir="auto">and the spacers that characterized the gapped motifs <a href="./imgs/gaps.png">can be widely varied (Supplementary Material Figure 2)</a>.</p>
<p dir="auto">Last, there are cooperative binding patterns, e.g., (<a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Manuscript Figure 5</a>):</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="./imgs/avsec3.png"><img src="./imgs/avsec3.png" alt="image info" style="max-width: 100%;"></a></p>
<p dir="auto">for which we see consecutive occurrences of <a href="https://en.wikipedia.org/wiki/Oct-4" rel="nofollow">Oct4</a> and cooccurrence of <a href="https://en.wikipedia.org/wiki/Oct-4" rel="nofollow">Oct4</a> and <a href="https://en.wikipedia.org/wiki/ZIC3" rel="nofollow">Zic3</a>, in addition to the Oct4-Sox2 motif. The presence of gapped motifs and cooperative binding patterns presents challenges for k-mer-based methods as well, as these methods are primarily designed to detect ungapped motifs.</p>

<p dir="auto">Once the motif discovery process is complete, a summary.html page is generated in the output folder, providing a comprehensive overview of the results.</p>
<p dir="auto">For instance, here is an example result page showcasing data from the  <a href="https://jaspar.genereg.net/matrix/MA0079.3/" rel="nofollow">SP1 transcription factor from JASPAR</a>:</p>
<blockquote>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="./imgs/re_top.png"><img src="./imgs/re_top.png" alt="image info" style="max-width: 100%;"></a></p>
</blockquote>
<p dir="auto">The top of the result page has</p>
<ul dir="auto">
<li><strong>Number of sequences</strong>: The total number of DNA sequences in the dataset.</li>
<li><strong>Label</strong>: A label assigned for each discovered motifs.
<ul dir="auto">
<li>Each label is hyperlinked to a text file in TRANSFAC format that can be parsed.</li>
</ul>
</li>
<li><strong>P-value</strong>: The satistical significance of the discovered motif using Fisher exact test (<a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Manuscript section 2.7.2</a>).</li>
<li><strong># instances</strong>: An estimate of the number of occurrences in the dataset (<a href="https://academic.oup.com/bioinformatics/advance-article-abstract/doi/10.1093/bioinformatics/btad378/7192989?utm_source=advanceaccess&amp;utm_campaign=bioinformatics&amp;utm_medium=email" rel="nofollow">Manuscript section 2.7.3</a>).</li>
<li><strong>Logo</strong>: Position weight matricies.
<ul dir="auto">
<li>Press the <code>Reverse complement</code> button to view the logo in alternative orientation.</li>
</ul>
</li>
</ul>
<p dir="auto">Note that in in-vivo datasets, especially for zinc-finger proteins, a large number of motifs can be observed, often characterized by variable spacings in their binding sites.</p>
