<p dir="auto">GridapSolvers provides algebraic and non-algebraic solvers for the Gridap ecosystem, designed with High Performance Computing (HPC) in mind.</p>
<p dir="auto">Solvers follow a modular design, where most blocks can be combined to produce PDE-taylored solvers for a wide range of problems.</p>

<ul dir="auto">
<li><strong>Krylov solvers</strong>: We provide a (short) list of Krylov solvers, with full preconditioner support and HPC-first implementation.</li>
<li><strong>Block preconditioners</strong>: We provide full support for block assembly of multiphysics problems, and a generic API for building block-based preconditioners for block-assembled systems.</li>
<li><strong>Multilevel support</strong>: We provide a generic API for building multilevel preconditioners.</li>
<li><strong>Geometric Multigrid</strong>: We provide a full-fledged geometric multigrid solver. Highly scalable adaptivity and redistribution of meshes, provided by <code>p4est</code> through <code>GridapP4est.jl</code>.</li>
<li><strong>PETSc interface</strong>: Full access to PETSc algebraic solvers, through <code>GridapPETSc.jl</code>, with full interoperability with the rest of the aforementioned solvers.</li>
</ul>

<p dir="auto">GridapSolvers is a registered package in the official <a href="https://github.com/JuliaRegistries/General">Julia package registry</a>.  Thus, the installation of GridapSolvers is straight forward using the <a href="https://julialang.github.io/Pkg.jl/v1/" rel="nofollow">Julia's package manager</a>. Open the Julia REPL, type <code>]</code> to enter package mode, and install as follows</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add GridapSolvers
pkg&gt; build"><pre>pkg<span class="pl-k">&gt;</span> add GridapSolvers
pkg<span class="pl-k">&gt;</span> build</pre></div>
<p dir="auto">Building is required to link the external artifacts (e.g., PETSc, p4est) to the Julia environment.</p>

<p dir="auto">The previous installations steps will setup GridapSolvers to work using Julia's pre-compiled artifacts for MPI, PETSc and p4est. However, you can also link local copies of these libraries. This might be very desirable in clusters, where hardware-specific libraries might be faster/more stable than the ones provided by Julia. To do so, follow the next steps:</p>
<ul dir="auto">
<li><a href="https://juliaparallel.org/MPI.jl/stable/configuration/" rel="nofollow">MPI.jl</a></li>
<li><a href="https://github.com/gridap/GridapPETSc.jl">GridapPETSc.jl</a></li>
<li><a href="https://github.com/gridap/GridapP4est.jl">GridapP4est.jl</a>, and <a href="https://github.com/gridap/p4est_wrapper.jl">P4est_wrapper.jl</a></li>
</ul>
