<p dir="auto">Aqua.jl provides functions to run a few automatable checks for Julia packages:</p>
<ul dir="auto">
<li>There are no method ambiguities.</li>
<li>There are no undefined <code>export</code>s.</li>
<li>There are no unbound type parameters.</li>
<li>There are no stale dependencies listed in <code>Project.toml</code>.</li>
<li>Check that test target of the root project <code>Project.toml</code> and test project (<code>test/Project.toml</code>) are consistent.</li>
<li>Check that all external packages listed in <code>deps</code> have corresponding <code>compat</code> entries.</li>
<li>There are no "obvious" type piracies.</li>
<li>The package does not create any persistent Tasks that might block precompilation of dependencies.</li>
</ul>
<p dir="auto">See more in the <a href="https://juliatesting.github.io/Aqua.jl/" rel="nofollow">documentation</a>.</p>
<p dir="auto">For a detailed list of changes please refer to the <a href="CHANGELOG.md">changelog</a>.</p>
