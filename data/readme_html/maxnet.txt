<p dir="auto">This is a Julia implementation of the <a href="https://github.com/mrmaxent/maxnet">maxnet algorithm</a>, with all core functionality in the original R package.</p>
<p dir="auto">Maxnet transforms input data in various ways and then uses the GLMnet algorithm to fit a lasso path, selecting the best variables and transformations.</p>
<p dir="auto">Maxnet is closely related to the Java MaxEnt application, which is widely used in species distribution modelling. Maxnet was introduced in <a href="https://doi.org/10.1111/ecog.03049" rel="nofollow">this publication</a>, which goes more into details about the algorithm.</p>
<p dir="auto">Also see the Maxent page on the site of the <a href="https://biodiversityinformatics.amnh.org/open_source/maxent/" rel="nofollow">American Museum for Natural History</a>.</p>
<p dir="auto">A basic example, using a toy dataset included in the package:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Maxnet

prediction = predict(bradypus_model, env)"><pre><span class="pl-k">using</span> Maxnet
p_a, env <span class="pl-k">=</span> Maxnet<span class="pl-k">.</span><span class="pl-c1">bradypus</span>()

<p dir="auto">Maxnet integrates with <a href="https://github.com/alan-turing-institute/MLJ.jl">MLJ</a> through the <code>MaxnetBinaryClassifier</code> type.</p>
