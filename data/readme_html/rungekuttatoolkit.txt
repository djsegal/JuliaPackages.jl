<p dir="auto"><strong>RungeKuttaToolKit.jl</strong> is a Julia package that provides tools for constructing and analyzing Runge–Kutta methods. It includes optimized, SIMD-accelerated code for enumerating rooted trees, building instruction tables, and computing Butcher weights <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="377af71410ac0f0c4f3496077d713379">$\Phi_t(A)$</math-renderer> and their derivatives.</p>
<blockquote>
<p dir="auto">The algorithms that underlie <strong>RungeKuttaToolKit.jl</strong> are described in <strong><a href="https://link.springer.com/article/10.1007/s11075-024-01783-2" rel="nofollow">this paper</a></strong>, which is <strong><a href="https://rdcu.be/dz7sy" rel="nofollow">freely available in read-only form</a></strong>.</p>
</blockquote>
<p dir="auto"><strong>RungeKuttaToolKit.jl</strong> is closely related to its sister repository, <strong><a href="https://github.com/dzhang314/RKTK">RKTK</a></strong>.</p>
<ul dir="auto">
<li>
<p dir="auto"><strong>RungeKuttaToolKit.jl</strong> (this repository) implements the core mathematical operations of the algebraic theory of Runge–Kutta methods, such as computing Butcher weights <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="377af71410ac0f0c4f3496077d713379">$\Phi_t(A)$</math-renderer> and evaluating the gradient of the sum-of-squares residual function. <strong>RungeKuttaToolKit.jl</strong> is intended to be useful to all researchers studying Runge–Kutta methods and is <a href="https://juliahub.com/ui/Packages/General/RungeKuttaToolKit" rel="nofollow">registered in the Julia General package registry</a>, so it can be installed into any Julia environment with the command <code>]add RungeKuttaToolKit</code>.</p>
</li>
<li>
<p dir="auto"><strong><a href="https://github.com/dzhang314/RKTK">RKTK</a></strong> contains parallel search and nonlinear optimization scripts that specifically target the discovery of new Runge–Kutta methods. In contrast to the pure mathematical operations in <strong>RungeKuttaToolKit.jl</strong>, the programs in <strong>RKTK</strong> establish a number of RKTK-specific conventions regarding optimization hyperparameters and file structure. Consequently, <strong>RKTK</strong> is not a registered Julia package.</p>
</li>
</ul>
<p dir="auto">Both <strong>RungeKuttaToolKit.jl</strong> and <strong>RKTK</strong> are designed with reproducibility as an explicit goal. The <a href="https://github.com/dzhang314/RKTK/blob/master/RKTKSearch.jl">RKTKSearch.jl</a> program has been tested to produce bit-for-bit identical results across multiple architectures (i686, x86-64, ARMv8) and multiple CPU generations (Haswell, Skylake, Rocket Lake, Zen 5).</p>
