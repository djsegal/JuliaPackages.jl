<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Icogrid</h3><a id="user-content-icogrid" class="anchor" aria-label="Permalink: Icogrid" href="#icogrid"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="icogrid(;N=nothing, sepAng=nothing, unit=:rad, height=nothing, type=:lla)"><pre class="notranslate"><code>icogrid(;N=nothing, sepAng=nothing, unit=:rad, height=nothing, type=:lla)
</code></pre></div>
<p dir="auto">This function returns a <code>Vector</code> of <code>Point2</code> or <code>LLA</code> elements, for a <code>N</code> points Global grid built with the <strong>Fibonacci Spiral</strong> method.</p>
<p dir="auto">The grid can be generated starting fom the number of point requested on the grid (<code>N</code>) or by the minimum separation angle requested for the points (<code>sepAng</code>).</p>
<p dir="auto">The problem of how to evenly distribute points on a sphere has a very long history. Unfortunately, except for a small handful of cases, it still has not been exactly solved. Therefore, in nearly all situations, we can merely hope to find near-optimal solutions to this problem.</p>
<p dir="auto">Of these near-optimal solutions, one of the most common simple methods is one based on the <strong>Fibonacci lattice</strong> or <strong>Golden Spiral</strong> or <strong>Fibonacci Spiral</strong>. Furthermore, unlike many of the other iterative or randomised methods such a simulated annealing, the Fibonacci spiral is one of the few direct construction methods that works for arbitrary <code>N</code>.</p>
<p dir="auto">This method of points distribution is <strong>Area Preserving</strong> but not distance preserving.</p>
<p dir="auto">When the selected output type is <code>Point2</code>, as convention it has been considered: <code>LAT=x</code>, <code>LON=y</code> and the output can be returned either in <code>:deg</code> or <code>:rad</code> units.</p>

<p dir="auto">This function determines if a given point belongs to a 2-dimensional <code>Meshes.Domain</code> object. The <code>Meshes.Domain</code> object represents a geometric domain, which is essentially a 2D region in space, specified by its bounds and discretization.</p>

<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="extract_countries(r::GeoRegion)"><pre class="notranslate"><code>extract_countries(r::GeoRegion)
</code></pre></div>
<p dir="auto">Extracts the countries from a given region. The output represents the field <code>domain</code> of <code>GeoRegion</code>.</p>
<p dir="auto">It first gets the field names of the <code>GeoRegion</code> type, excluding the <code>:regionName</code>, then maps these field names to their corresponding values in the <code>GeoRegion</code> instance <code>r</code>, creating a collection of pairs. It filters out any pairs where the value is empty. It converts this collection of pairs into a <code>NamedTuple</code>, finally, it calls <code>GeoGrids.extract_countries</code> with the <code>NamedTuple</code> as keyword arguments.</p>
<p dir="auto">This function is an overload of <code>GeoGrids.extract_countries</code> that takes a <code>GeoRegion</code> object as input. It extracts the countries from the given region and returns them.</p>

<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="_meshgrid(xin,yin)"><pre class="notranslate"><code>_meshgrid(xin,yin)
</code></pre></div>
<p dir="auto">Create a 2D grid of coordinates using the input vectors <code>xin</code> and <code>yin</code>.
The output, in the form of <code>SVector(xout,yout)</code>, contains all possible combinations of the elements of <code>xin</code> and <code>yin</code>, with <code>xout</code> corresponding to the horizontal coordinates and <code>yout</code> corresponding to the vertical coordinates.</p>

<p dir="auto">This is the base function used by <code>icogrid</code>. This function generates <code>N</code> uniformly distributed points on the surface of a unitary sphere using the classic Fibonacci Spiral.</p>
<p dir="auto">The output can be returned as a <code>SVector</code> of either, spherical or cartesian coordinates.</p>
