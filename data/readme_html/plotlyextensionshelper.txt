<p dir="auto">The primary objective of this package is to enable package authors to integrate plotting functionality within their packages through extensions that support multiple plotting libraries with a single extension. This package is designed to be compatible with plotting libraries based on <a href="https://github.com/sglyon/PlotlyBase.jl">PlotlyBase.jl</a>, such as PlotlyBase, PlotlyJS, and PlutoPlotly.</p>
<p dir="auto">Support for other plotly-based packages might be considered in the future.</p>
<p dir="auto">The principal way of using this package is to have <code>PlotlyExtensionsHelper</code> as dependency of the target package, and then provide a single extensions with PlotlyBase.jl as trigger.
The extension should implement the specific plotting functionality and generate its output (the plot) using <code>PlotlyExtensionsHelper.plotly_plot</code> rather than using <code>PlotlyBase.Plot</code>.</p>
<p dir="auto"><code>PlotlyExtensionsHelper.plotly_plot</code> will simply forward all argument and keyword arguments provided to it to the relevant function on the 3 supported packages depending on what is loaded and on the priority specified in <code>PlotlyExtensionsHelper.PLOT_FUNC_PRIORITY</code></p>
<p dir="auto">The default priority is in this order:</p>
<ul dir="auto">
<li>PlutoPlotly (highest priority)</li>
<li>PlotlyJS</li>
<li>PlotlyBase (lowest priority)</li>
</ul>
<p dir="auto">You can find a more clarifying example on how to implement plotting in a package using <code>PlotlyExtensionsHelper</code> in the test folder within its <a href="test/ExampleEnvironment/">ExampleEnvironment</a> subfolder.
The example package providing some plotting functionality is within the <a href="test/ExampleEnvironment/ExamplePackage">ExamplePackage</a> folder, while example of its use with <em>seamelss</em> plotting package switching can be checked by either including the <a href="test/ExampleEnvironment/test_include.jl"><code>test_include.jl</code></a> file in the REPL, or by opening the <a href="test/ExampleEnvironment/test_notebook.jl"><code>test_notebook.jl</code></a> within Pluto</p>
<p dir="auto">The first file will use PlotlyJS to show the plot, while the second example (the notebook) will use PlutoPlotly to show the plot.</p>
