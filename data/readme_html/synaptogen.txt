<p dir="auto"><a href="https://zenodo.org/doi/10.5281/zenodo.10942560" rel="nofollow"><img src="https://camo.githubusercontent.com/b81e4824a1be587e63178a9700ec0f9b00c0dd1ccaf0bfa0856d3d7216733959/68747470733a2f2f7a656e6f646f2e6f72672f62616467652f3631393037393235302e737667" alt="DOI" data-canonical-src="https://zenodo.org/badge/619079250.svg" style="max-width: 100%;"></a></p>
<p dir="auto">This is a fast generative model for stochastic memory cells.  It helps determine how real-world devices would perform in large-scale circuits, for example when used as resistive weights in a neuromorphic system.</p>
<p dir="auto">The model is trained on measurement data and closely replicates</p>
<ul dir="auto">
<li>cross-correlations and history dependence of switching parameters</li>
<li>cycle-to-cycle and device-to-device distributions</li>
<li>multi-level resistance states</li>
<li>resistance non-linearity</li>
</ul>
<p dir="auto">It is currently implemented in</p>
<ul dir="auto">
<li>Julia for machine learning and general purpose programming (<a href="Synaptogen.jl">Synaptogen.jl</a>)</li>
<li>Python (NumPy) (<a href="Synaptogen.py">Synaptogen.py</a>)</li>
<li>Verilog-A for circuit-level simulations (<a href="Synaptogen.va">Synaptogen.va</a>)</li>
</ul>
