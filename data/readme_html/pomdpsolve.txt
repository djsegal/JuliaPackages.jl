<p dir="auto">This is a Julia wrapper for the POMDP-Solve program, orginally developed at Brown University that uses the <a href="https://github.com/JuliaPOMDP/POMDPs.jl">POMDPs.jl</a> interface. This package uses the <a href="https://github.com/JuliaBinaryWrappers/POMDPSolve_jll.jl">POMDPSolve_jll</a> package, which was build using modifications from the code available from Tony Cassandra's <a href="http://www.pomdp.org/code/index.html" rel="nofollow">pomdp.org page</a>. The modfications are available in the <a href="https://github.com/JuliaPOMDP/pomdp-solve">JuliaPOMDP fork of pomdp-solve</a>.</p>
<p dir="auto">The pomdp-solve program solves partially observable Markov decision
processes (POMDPs), taking a model specification and producing a value
function and action policy.  It employs many different algorithms,
some exact and some approximate.</p>
