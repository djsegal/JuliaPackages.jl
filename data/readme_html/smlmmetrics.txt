<p dir="auto">SMLMMetrics is a Julia package for analyzing single molecule super-resolution data. It provides metrics to evaluate the accuracy and precision of your SMLM coordinate data.</p>

<ul dir="auto">
<li>Jaccard Index calculation for comparing localization sets</li>
<li>Root Mean Square Error (RMSE) calculation for evaluating localization accuracy</li>
<li>Dimensional weighting for RMSE calculations</li>
<li>Flexible support for various data dimensions</li>
</ul>
