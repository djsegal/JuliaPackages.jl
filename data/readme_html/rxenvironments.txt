<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">RxEnvironments</h1><a id="user-content-rxenvironments" class="anchor" aria-label="Permalink: RxEnvironments" href="#rxenvironments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>RxEnvironments</code> contains all boilerplate code to create reactive environments for self-learning agents, allowing for state transitions with variable time between state updates.<code>RxEnvironments</code> exports the <code>RxEnvironment</code> and <code>RxEntity</code> wrapper structs, that facilitate all plumbing to make an environment fully reactive. Under the hood, <code>RxEnvironments</code> uses <a href="https://www.github.com/biaslab/Rocket.jl">Rocket.jl</a>.</p>

<p dir="auto">When using RxEnvironments, you only have to specify the dynamics of your environment. Let's create the Bayesian Thermostat environment in <code>RxEnvironments</code>. For this example, you need <code>Distributions.jl</code> installed in your environment as well.</p>
<p dir="auto">Let's create the basics of our environment:</p>

    env.temperature += diff

        set_temperature!(env, min_temp(env))
    elseif temperature(env) &gt; max_temp(env)
        set_temperature!(env, max_temp(env))
    end

<p dir="auto">By implementing <code>RxEnvironments.receive!</code>, <code>RxEnvironments.what_to_send</code> and <code>RxEnvironments.update!</code> for our environment, we can fully specify the behaviour of our environment, and <code>RxEnvironments</code> will take care of the rest. The <code>RxEnvironments.receive!</code> and <code>RxEnvironments.what_to_send</code> functions have a specific signature: <code>RxEnvironments.receive!(receiver, emitter, action)</code> takes as arguments the recipient of the action (in this example the environment), the emitter of the action (in this example the agent) and the action itself (in this example the change in temperature). The <code>receive!</code> function thus specifiec how an action from <code>emitter</code> to <code>recipient</code> affects the state of <code>recipient</code>. Always make sure to dispatch on the types of your environments, agents and actions, as <code>RxEnvironments</code> relies on Julia's multiple dispatch system to call the correct functions. Similarly for <code>what_to_send</code>, which takes the <code>recipient</code> and <code>emitter</code> (and potentially <code>observation</code>) as arguments, that computes the observation from <code>emitter</code> presented to <code>recipient</code> (when emitter has received <code>observation</code>). In our Bayesian Thermostat example, these functions look as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# When the environment receives an action from the agent, we add the value of the action to the environment temperature.
RxEnvironments.receive!(recipient::BayesianThermostat{T}, emitter::ThermostatAgent, action::T) where {T} = add_temperature!(recipient, action)

# The environment sends a noisy observation of the temperature to the agent.
RxEnvironments.what_to_send(recipient::ThermostatAgent, emitter::BayesianThermostat) = temperature(emitter) + rand(noise(emitter))

# The environment cools down over time.
RxEnvironments.update!(env::BayesianThermostat, elapsed_time)= add_temperature!(env, -0.1 * elapsed_time)"><pre><span class="pl-c"><span class="pl-c">#</span> When the environment receives an action from the agent, we add the value of the action to the environment temperature.</span>

<p dir="auto">Now we've fully specified our environment, and we can interact with it. In order to create the environment, we use the <code>RxEnvironment</code> struct, and we add an agent to this environment using <code>add!</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="environment = RxEnvironment(BayesianThermostat(0.0, -10.0, 10.0); emit_every_ms = 900)
agent = add!(environment, ThermostatAgent())"><pre>environment <span class="pl-k">=</span> <span class="pl-c1">RxEnvironment</span>(<span class="pl-c1">BayesianThermostat</span>(<span class="pl-c1">0.0</span>, <span class="pl-k">-</span><span class="pl-c1">10.0</span>, <span class="pl-c1">10.0</span>); emit_every_ms <span class="pl-k">=</span> <span class="pl-c1">900</span>)
agent <span class="pl-k">=</span> <span class="pl-c1">add!</span>(environment, <span class="pl-c1">ThermostatAgent</span>())</pre></div>
