<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">DuckDB</h2><a id="user-content-duckdb" class="anchor" aria-label="Permalink: DuckDB" href="#duckdb"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">DuckDB is a high-performance analytical database system. It is designed to be fast, reliable, portable, and easy to use. DuckDB provides a rich SQL dialect, with support far beyond basic SQL. DuckDB supports arbitrary and nested correlated subqueries, window functions, collations, complex types (arrays, structs, maps), and <a href="https://duckdb.org/docs/guides/sql_features/friendly_sql" rel="nofollow">several extensions designed to make SQL easier to use</a>.</p>
<p dir="auto">DuckDB is available as a <a href="https://duckdb.org/docs/api/cli/overview" rel="nofollow">standalone CLI application</a> and has clients for <a href="https://duckdb.org/docs/api/python/overview" rel="nofollow">Python</a>, <a href="https://duckdb.org/docs/api/r" rel="nofollow">R</a>, <a href="https://duckdb.org/docs/api/java" rel="nofollow">Java</a>, <a href="https://duckdb.org/docs/api/wasm/overview" rel="nofollow">Wasm</a>, etc., with deep integrations with packages such as <a href="https://duckdb.org/docs/guides/python/sql_on_pandas" rel="nofollow">pandas</a> and <a href="https://duckdblabs.github.io/duckplyr/" rel="nofollow">dplyr</a>.</p>
<p dir="auto">For more information on using DuckDB, please refer to the <a href="https://duckdb.org/docs/" rel="nofollow">DuckDB documentation</a>.</p>

<p dir="auto">For development, DuckDB requires <a href="https://cmake.org" rel="nofollow">CMake</a>, Python3 and a <code>C++11</code> compliant compiler. Run <code>make</code> in the root directory to compile the sources. For development, use <code>make debug</code> to build a non-optimized debug version. You should run <code>make unit</code> and <code>make allunit</code> to verify that your version works properly after making changes. To test performance, you can run <code>BUILD_BENCHMARK=1 BUILD_TPCH=1 make</code> and then perform several standard benchmarks from the root directory by executing <code>./build/release/benchmark/benchmark_runner</code>. The details of benchmarks are in our <a href="benchmark/README.md">Benchmark Guide</a>.</p>
<p dir="auto">Please also refer to our <a href="https://duckdb.org/dev/building" rel="nofollow">Build Guide</a> and <a href="CONTRIBUTING.md">Contribution Guide</a>.</p>
