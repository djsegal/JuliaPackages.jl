<p dir="auto">DJUICE.jl is a Julia package designed for differentiable ice sheet modeling, leveraging the power of <a href="https://github.com/EnzymeAD/Enzyme.jl">Enzyme.jl</a> for automatic differentiation. This package employs the Finite Element method (FEM) and follows the structure of the <a href="https://issm.jpl.nasa.gov/" rel="nofollow">ice-sheet and Sea-level System Model (ISSM)</a>, which is the C++ counterpart for ice sheet modeling.</p>

xmax=maximum(md.mesh.x)
