<p dir="auto">Coluna is a branch-and-price-and-cut framework written in Julia.
You write an original MIP that models your problem using the
<a href="https://github.com/jump-dev/JuMP.jl">JuMP</a> modeling language and our specific extension
<a href="https://github.com/atoptima/BlockDecomposition.jl">BlockDecomposition</a> offers a syntax
to specify the problem decomposition. Then, Coluna reformulates the original MIP and
optimizes the reformulation using the algorithms you choose.
Coluna aims to be very modular and tweakable so that you can define the behavior of
your customized branch-and-price-and-cut algorithm.</p>

<p dir="auto">We aim to integrate into Coluna the state-of-the-art techniques used for
branch-and-cut-and-price algorithms.</p>
<ul dir="auto">
<li><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/3ad9f97ecd16eb9a8723e3a2c8f849d2b907a37ba11ec46491f8cee26b93a09b/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d737461626c652d627269676874677265656e"><img src="https://camo.githubusercontent.com/3ad9f97ecd16eb9a8723e3a2c8f849d2b907a37ba11ec46491f8cee26b93a09b/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d737461626c652d627269676874677265656e" alt="Stable" data-canonical-src="https://img.shields.io/badge/-stable-brightgreen" style="max-width: 100%;"></a> Features which are well-tested (but performance may still be improved).
<ul dir="auto">
<li>Dantzig-Wolfe decomposition</li>
<li>Branch-and-bound algorithm (with branching in master)</li>
<li>Column generation (MILP pricing solver/pricing callback)</li>
</ul>
</li>
<li><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/fa47b07f50dc550b9ed258e677d19965acec01803d097b9374086eb69a776c8d/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d626574612d677265656e"><img src="https://camo.githubusercontent.com/fa47b07f50dc550b9ed258e677d19965acec01803d097b9374086eb69a776c8d/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d626574612d677265656e" alt="Beta" data-canonical-src="https://img.shields.io/badge/-beta-green" style="max-width: 100%;"></a> Features that work well but need more tests/usage and performance review before being stable:
<ul dir="auto">
<li>Strong branching (with branching in master)</li>
<li>Stabilization for column generation</li>
<li>Cut generation (robust and non-robust)</li>
<li>Benders decomposition</li>
<li>Preprocessing (presolve) of formulations and reformulations</li>
</ul>
</li>
<li><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/a027f6700c51bbbf7944d465b3040d498eee47c378783f79c1e26c4ecf1cae5e/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d616c7068612d79656c6c6f77"><img src="https://camo.githubusercontent.com/a027f6700c51bbbf7944d465b3040d498eee47c378783f79c1e26c4ecf1cae5e/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d616c7068612d79656c6c6f77" alt="Alpha" data-canonical-src="https://img.shields.io/badge/-alpha-yellow" style="max-width: 100%;"></a> Features that should work. Structural work is done but these features may have bugs:
<ul dir="auto">
<li>Benders cut generation</li>
</ul>
</li>
<li><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/2e6702d5b0c49dcbd9575c12722ca56b273ed8d404b27c1d1250ab3e260d100b/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d6465762d6f72616e6765"><img src="https://camo.githubusercontent.com/2e6702d5b0c49dcbd9575c12722ca56b273ed8d404b27c1d1250ab3e260d100b/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2d6465762d6f72616e6765" alt="Dev" data-canonical-src="https://img.shields.io/badge/-dev-orange" style="max-width: 100%;"></a> Features in development.
<ul dir="auto">
<li>Clean-up of the master formulation (removal of unpromising columns and cuts)</li>
<li>Saving/restoring LP basis when changing a node in branch-and-bound</li>
</ul>
</li>
</ul>
