<p dir="auto">The ChainRulesOverloadGeneration package provides a suite of methods for using <a href="https://github.com/JuliaDiff/ChainRulesCore.jl">ChainRulesCore.jl</a> rules in operator overloading AD systems.
It tracks what rules are defined at any point in time, and lets you trigger functions to which can use <code>@eval</code> in order to define the matching operator overloads.</p>
