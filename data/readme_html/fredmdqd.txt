<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What are Fred MD and Fred QD?</h2><a id="user-content-what-are-fred-md-and-fred-qd" class="anchor" aria-label="Permalink: What are Fred MD and Fred QD?" href="#what-are-fred-md-and-fred-qd"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://research.stlouisfed.org/econ/mccracken/fred-databases/" rel="nofollow">Fred MD and Fred QD</a> are curated sets of monthly and quarterly indicators by Michael W. McCracken at the Federal Reserve Bank of St. Louis. Fred MD comprises 126 monthly indicators, while Fred QD consists of 245 quarterly indicators.Observations start in January 1959 for Fred MD and in Q1 1959 for Fred QD.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How do I load Fred MD or Fred QD data?</h2><a id="user-content-how-do-i-load-fred-md-or-fred-qd-data" class="anchor" aria-label="Permalink: How do I load Fred MD or Fred QD data?" href="#how-do-i-load-fred-md-or-fred-qd-data"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>FredMDQD</code> offers straightforward methods to load Fred MD/QD data. The simplest approach loads the most recent version of either dataset.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FredMDQD
using DataFrames

fmd = FredMD()  # Loads most recent version of Fred MD
fqd = FredQD()  # Loads most recent version of Fred QD"><pre><span class="pl-k">using</span> FredMDQD
<span class="pl-k">using</span> DataFrames

fmd <span class="pl-k">=</span> <span class="pl-c1">FredMD</span>()  <span class="pl-c"><span class="pl-c">#</span> Loads most recent version of Fred MD</span>
fqd <span class="pl-k">=</span> <span class="pl-c1">FredQD</span>()  <span class="pl-c"><span class="pl-c">#</span> Loads most recent version of Fred QD</span></pre></div>
<p dir="auto">The returned objects contain:</p>
<ul dir="auto">
<li><code>original::DataFrame</code>: Untouched Fred MD/QD data.</li>
<li><code>transformed::DataFrame</code>: Data transformed according to McCracken's recommended stationarity adjustments.</li>
<li><code>tcodes::Vector{Int}</code>: Transformation codes for each variable except the date. More information on transformation codes can be found using <code>@doc FredMDQD.fred_transform</code></li>
</ul>
<p dir="auto">For loading specific vintage data, provide a date as an argument:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Dates

d = Date(&quot;2022/03&quot;, dateformat&quot;yyyy/mm&quot;)

fqd = FredQD(d)"><pre><span class="pl-k">using</span> Dates

d <span class="pl-k">=</span> <span class="pl-c1">Date</span>(<span class="pl-s"><span class="pl-pds">"</span>2022/03<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds"><span class="pl-c1">dateformat</span>"</span>yyyy/mm<span class="pl-pds">"</span></span>)
fmd <span class="pl-k">=</span> <span class="pl-c1">FredMD</span>(d)
fqd <span class="pl-k">=</span> <span class="pl-c1">FredQD</span>(d)</pre></div>
<p dir="auto">Manual downloads of Fred MD/QD data can be loaded using file paths:</p>

<p dir="auto">Fred MD/QD use abbreviations for variables that are not always intuitive. To find the meaning behind an abbreviation, or to find an abbreviation corresponding to a specific indicator, the <code>seach_appendix</code> function can be used. <code>search_appendix</code> searches through the Fred MD/QD appendices to find a specific search term. For example, Fred MD includes the indicator 'DPCERA3M086SBEA'. To find the meaning behind this indicator, run</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="search_appendix(:MD, &quot;DPCERA3M086SBEA&quot;)"><pre><span class="pl-c1">search_appendix</span>(<span class="pl-c1">:MD</span>, <span class="pl-s"><span class="pl-pds">"</span>DPCERA3M086SBEA<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">This returns a <code>DataFrame</code> of search results matching the search criteria. The indicator 'DPCERA3M086SBEA' corresponds to "Real personal consumption expenditures".</p>
<p dir="auto">Similarly, to find an indicator in Fred QD corresponding to house prices, search for 'house' to see if any such indicators exist.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="search_appendix(:QD, &quot;house&quot;)"><pre><span class="pl-c1">search_appendix</span>(<span class="pl-c1">:QD</span>, <span class="pl-s"><span class="pl-pds">"</span>house<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">The search results indicate that Fred QD includes USSTHPI corresponding to "All-Transactions House Price Index for the United States (Index 1980 Q1=100)".</p>
