<p dir="auto">Muninn.jl is a package providing glacier mass balance models for <a href="https://github.com/ODINN-SciML/ODINN.jl">ODINN.jl</a>. It currently includes basic temperature-index models, with 1 or 2 degree-day factors. In the future, it will also accommodate machine learning models to simulate glacier surface mass balance in a data-driven way, including some physical constraints.</p>
