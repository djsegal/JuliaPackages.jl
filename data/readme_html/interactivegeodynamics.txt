<p dir="auto">This package provides a range of graphical user interfaces (GUI's) to study and experiment with different geodynamic problems without need to program. It uses <a href="https://julialang.org" rel="nofollow">julia</a> and <a href="https://dash.plotly.com/julia" rel="nofollow">Dash</a> and automatically installs the required geodynamic software (such as <a href="https://github.com/JuliaGeodynamics/LaMEM.jl">LaMEM</a>) in the background.</p>
<p dir="auto">This is particularly useful for teaching.
We currently have the following examples included:</p>
<ul dir="auto">
<li><code>sill_intrusion_1D()</code> - 1D thermal model of sill intrusion in the crust</li>
<li><code>convection()</code> - 2D mantle  (or magma chamber) convection</li>
<li><code>rayleigh_taylor()</code> - density driven instability</li>
<li><code>rising_sphere()</code> - rising stokes sphere example</li>
<li><code>subduction()</code> - subduction of a single plate</li>
<li><code>folding()</code> - folding of one or more viscous layers</li>
</ul>
