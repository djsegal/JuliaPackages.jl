<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="MapAxis(args...; origin, kwargs...) -&gt; axis::Makie.Axis"><pre class="notranslate"><code>MapAxis(args...; origin, kwargs...) -&gt; axis::Makie.Axis
</code></pre></div>
<p dir="auto">Create a new <code>Axis</code> showing OpenStreetMap.</p>
<p dir="auto">The object returned by this function is a plain <code>Makie.Axis</code> and can be used to plot additional data like any other <code>Axis</code>. The map is shown in <code>MapMaths.WebMercator</code> coordinates shifted by <code>-WebMercator(origin)</code>.</p>
<p dir="auto">All positional arguments and any keyword arguments other than the ones mentioned below are forwarded to <code>Axis()</code>.</p>
<div class="markdown-heading" dir="auto"><h5 class="heading-element" dir="auto">Keyword arguments</h5><a id="user-content-keyword-arguments" class="anchor" aria-label="Permalink: Keyword arguments" href="#keyword-arguments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto"><code>origin::MapMaths.Coordinate{2}</code>: Map origin.</p>
<p dir="auto">This parameter serves two purposes:</p>
<ol dir="auto">
<li>Avoid the loss of precision that would otherwise be incurred for locations at high latitudes and longitudes due to Makie performing most computations in <code>Float32</code>. See also <a href="https://github.com/MakieOrg/Makie.jl/issues/1196" data-hovercard-type="issue" data-hovercard-url="/MakieOrg/Makie.jl/issues/1196/hovercard">Loss of precision when plotting large floats in Makie</a> and related issues in Makie.jl.</li>
<li>Set the origin for the x- and y-ticks if <code>ticks_coordinate</code> is <code>EastNorth</code> (see <code>ticks_coordinate</code> below).</li>
</ol>
</li>
<li>
<p dir="auto"><code>ticks_coordinate = WebMercator</code>: The coordinate system in which to show the x- and y-ticks.</p>
<p dir="auto">Can be any subtype of <code>MapMaths.Coordinate{2}</code>, or <code>(MapMaths.EastNorth, unit)</code> where <code>unit</code> is either a plain number denoting meters, a <code>Unitful.LengthUnits</code> or a <code>Unitful.Length</code>. <code>EastNorth</code> ticks are shown relative to <code>origin</code>, all other ticks are shown using their global values.</p>
</li>
<li>
<p dir="auto"><code>limits = ((-1,1), (-1,1))</code>: Axis limits.</p>
<p dir="auto">Follows the same format as <code>Makie.Axis()</code>, except that any number can also be a <code>MapMaths.EastWestCoordinate</code> or <code>MapMaths.NorthSouthCoordinate</code> as appropriate. <code>East</code> and <code>North</code> limits are applied relative to <code>origin</code>, all other limits are applied as global values.</p>
</li>
<li>
<p dir="auto"><code>tile_provider = TileProviders.OpenStreetMap()</code>: Any tile provider from the <code>TileProviders</code> package.</p>
</li>
</ul>

<p dir="auto">MapMakie dynamically loads the map tiles required from <a href="https://tile.openstreetmap.org/" rel="nofollow">https://tile.openstreetmap.org/</a>. Users of this package must therefore adhere to <a href="https://operations.osmfoundation.org/policies/tiles/" rel="nofollow">OpenStreetMap's Tile Usage Policy</a>. The most-recently used 100 MB of map tiles are cached in memory using <a href="https://github.com/JuliaCollections/LRUCache.jl">LRUCache.jl</a>.</p>
