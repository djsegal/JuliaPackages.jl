<p dir="auto"><a href="https://github.com/TuringLang/AdvancedVI.jl">AdvancedVI</a> provides implementations of variational inference (VI) algorithms, which is a family of algorithms aiming for scalable approximate Bayesian inference by leveraging optimization.
<code>AdvancedVI</code> is part of the <a href="https://turinglang.org/stable/" rel="nofollow">Turing</a> probabilistic programming ecosystem.
The purpose of this package is to provide a common accessible interface for various VI algorithms and utilities so that other packages, e.g. <code>Turing</code>, only need to write a light wrapper for integration.
For example, integrating <code>Turing</code> with  <code>AdvancedVI.ADVI</code> only involves converting a <code>Turing.Model</code> into a <a href="https://github.com/tpapp/LogDensityProblems.jl"><code>LogDensityProblem</code></a> and extracting a corresponding <code>Bijectors.bijector</code>.</p>

<p dir="auto"><code>AdvancedVI</code> works with differentiable models specified as a <a href="https://github.com/tpapp/LogDensityProblems.jl"><code>LogDensityProblem</code></a>.
For example, for the normal-log-normal model:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="e174e94e4abe4cd8e772c483238cc462">$$
\begin{aligned}
x &amp;\sim \mathrm{LogNormal}\left(\mu_x, \sigma_x^2\right) \\
y &amp;\sim \mathcal{N}\left(\mu_y, \sigma_y^2\right),
\end{aligned}
$$</math-renderer></p>
<p dir="auto">a <code>LogDensityProblem</code> can be implemented as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using LogDensityProblems

struct NormalLogNormal{MX,SX,MY,SY}
    μ_x::MX
    σ_x::SX
    μ_y::MY
    Σ_y::SY
end

    (; μ_x, σ_x, μ_y, Σ_y) = model
    logpdf(LogNormal(μ_x, σ_x), θ[1]) + logpdf(MvNormal(μ_y, Σ_y), θ[2:end])
end

function LogDensityProblems.dimension(model::NormalLogNormal)
    length(model.μ_y) + 1
end

function LogDensityProblems.capabilities(::Type{&lt;:NormalLogNormal})
    LogDensityProblems.LogDensityOrder{0}()
end"><pre><span class="pl-k">using</span> LogDensityProblems

<p dir="auto">Since the support of <code>x</code> is constrained to be positive and VI is best done in the unconstrained Euclidean space, we need to use a <em>bijector</em> to transform <code>x</code> into unconstrained Euclidean space. We will use the <a href="https://github.com/TuringLang/Bijectors.jl"><code>Bijectors.jl</code></a> package for this purpose.
This corresponds to the automatic differentiation variational inference (ADVI) formulation<sup><a href="#user-content-fn-KTRGB2017-e174e94e4abe4cd8e772c483238cc462" id="user-content-fnref-ktrgb2017-e174e94e4abe4cd8e772c483238cc462" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Bijectors

function Bijectors.bijector(model::NormalLogNormal)
    (; μ_x, σ_x, μ_y, Σ_y) = model
    Bijectors.Stacked(
        Bijectors.bijector.([LogNormal(μ_x, σ_x), MvNormal(μ_y, Σ_y)]),
        [1:1, 2:1+length(μ_y)])
end"><pre><span class="pl-k">using</span> Bijectors

<span class="pl-k">function</span> Bijectors<span class="pl-k">.</span><span class="pl-en">bijector</span>(model<span class="pl-k">::</span><span class="pl-c1">NormalLogNormal</span>)
    (; μ_x, σ_x, μ_y, Σ_y) <span class="pl-k">=</span> model
    Bijectors<span class="pl-k">.</span><span class="pl-c1">Stacked</span>(
        Bijectors<span class="pl-k">.</span><span class="pl-c1">bijector</span>.([<span class="pl-c1">LogNormal</span>(μ_x, σ_x), <span class="pl-c1">MvNormal</span>(μ_y, Σ_y)]),
        [<span class="pl-c1">1</span><span class="pl-k">:</span><span class="pl-c1">1</span>, <span class="pl-c1">2</span><span class="pl-k">:</span><span class="pl-c1">1</span><span class="pl-k">+</span><span class="pl-c1">length</span>(μ_y)])

<p dir="auto">A simpler approach is to use <code>Turing</code>, where a <code>Turing.Model</code> can be automatically be converted into a <code>LogDensityProblem</code> and a corresponding <code>bijector</code> is automatically generated.</p>
<p dir="auto">Let us instantiate a random normal-log-normal model.</p>

<p dir="auto">We can perform VI with stochastic gradient descent (SGD) using reparameterization gradient estimates of the ELBO<sup><a href="#user-content-fn-TL2014-e174e94e4abe4cd8e772c483238cc462" id="user-content-fnref-tl2014-e174e94e4abe4cd8e772c483238cc462" data-footnote-ref="" aria-describedby="footnote-label">2</a></sup><sup><a href="#user-content-fn-RMW2014-e174e94e4abe4cd8e772c483238cc462" id="user-content-fnref-rmw2014-e174e94e4abe4cd8e772c483238cc462" data-footnote-ref="" aria-describedby="footnote-label">3</a></sup><sup><a href="#user-content-fn-KW2014-e174e94e4abe4cd8e772c483238cc462" id="user-content-fnref-kw2014-e174e94e4abe4cd8e772c483238cc462" data-footnote-ref="" aria-describedby="footnote-label">4</a></sup> as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Optimisers
using ADTypes, ForwardDiff
using AdvancedVI

# ELBO objective with the reparameterization gradient
n_montecarlo = 10
elbo         = AdvancedVI.RepGradELBO(n_montecarlo)

# Mean-field Gaussian variational family
d = LogDensityProblems.dimension(model)
μ = zeros(d)
L = Diagonal(ones(d))
q = AdvancedVI.MeanFieldGaussian(μ, L)

# Match support by applying the `model`'s inverse bijector
b             = Bijectors.bijector(model)
binv          = inverse(b)
q_transformed = Bijectors.TransformedDistribution(q, binv)


# Run inference
max_iter = 10^3
q_avg, _, stats, _ = AdvancedVI.optimize(
    model,
    elbo,
    q_transformed,
    max_iter;
    adtype    = ADTypes.AutoForwardDiff(),
    optimizer = Optimisers.Adam(1e-3)
)

# Evaluate final ELBO with 10^3 Monte Carlo samples
estimate_objective(elbo, q_avg, model; n_samples=10^4)"><pre><span class="pl-k">using</span> Optimisers
