<p dir="auto">The user can chose different algorithms to train the MKL model, e.g., <code>QCQP()</code> to solve the dual problem directly (which is a quadratically constrained quadratic program) or <code>HessianMKL()</code> to alternately optimize the kernel coefficients according to the second order information and solve a standard single kernel OCSVM. Here we choose the latter algorithm:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# algor = QCQP(verbose=false)
algor = HessianMKL(verbose=false)

algor <span class="pl-k">=</span> <span class="pl-c1">HessianMKL</span>(verbose<span class="pl-k">=</span><span class="pl-c1">false</span>)
model <span class="pl-k">=</span> <span class="pl-c1">mklocsvmtrain</span>(Kernels, X; algorithm<span class="pl-k">=</span>algor, ν<span class="pl-k">=</span><span class="pl-c1">0.01</span>, μ<span class="pl-k">=</span><span class="pl-c1">0.5</span>);</pre></div>
<p dir="auto">Please see the <a href="https://doi.org/10.1016/j.ejor.2020.11.027" rel="nofollow">paper</a> for more information about the algorithms and the statistical meaning of the hyper-parameters.</p>

num_batch = 3

model = pmap(
    ks -&gt; mklocsvmtrain(ks, X; algorithm=algor, ν=0.01/num_batch, μ=0.5), 
    Kernels_inbat
)
mklocsvmplot(model; backend=GLMakie)"><pre><span class="pl-k">using</span> Distributed
