<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Create labels containing QR-codes and human-readable codes for your experiments!</h2><a id="user-content-create-labels-containing-qr-codes-and-human-readable-codes-for-your-experiments" class="anchor" aria-label="Permalink: Create labels containing QR-codes and human-readable codes for your experiments!" href="#create-labels-containing-qr-codes-and-human-readable-codes-for-your-experiments"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package exports one function only, <code>labelyst()</code>, which takes a <code>Julia</code> DataFrame and some additional parameters as inputs and translates it into a <a href="https://typst.app/" rel="nofollow">Typst</a> file which is then, if desired, compiled into a PDF. To work with <code>Labelyst.jl</code> you need Typst installed on your computer, learn about installation <a href="https://github.com/typst/typst">here</a>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basic usage</h2><a id="user-content-basic-usage" class="anchor" aria-label="Permalink: Basic usage" href="#basic-usage"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package is registered at the General registry and can be installed with <code>add Labelyst</code>. The input <code>DataFrame</code> needs to have one column named <code>ID</code> and one column named <code>label</code>. The <code>ID</code> column will be used to make the QR-code, it is advisable not to use too long IDs (e.g. for 500 samples, just use <em>s001-s500</em> or something similar). The column <code>label</code> will be used for the human-readable part of the label: here one can add information about treatments, blocks or similar. Depending on the input parameters provided, one of the defined methods of <code>labelyst()</code> will be called to flexibly produce labels for different situations (i.e. pot labels, adhesive labels, ...)</p>
