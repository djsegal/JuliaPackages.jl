<p dir="auto">This is a simple repository to select a short exercise to do for roughly 5 minutes every hour</p>
<p dir="auto">Example run:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using SwoLeios
superset = SwoLeios.create_superset(&quot;exercises/core.dat&quot;, &quot;exercises/mobility.dat&quot;, &quot;exercises/arms.dat&quot;, &quot;exercises/legs.dat&quot;)
(set, reps) = cycle_set!(superset)"><pre class="notranslate"><code>using SwoLeios
superset = SwoLeios.create_superset("exercises/core.dat", "exercises/mobility.dat", "exercises/arms.dat", "exercises/legs.dat")
(set, reps) = cycle_set!(superset)
</code></pre></div>
<p dir="auto"><code>cycle_set(superset)</code> will give the next set, but will also decrease its priority and resort the superset.
If you want to get the next set without changing the superset, use <code>next_set(superset)</code>.</p>
<p dir="auto">Also, the following commands are available:</p>

set = decrease_difficulty(set)
shuffle!(superset)
</code></pre></div>
