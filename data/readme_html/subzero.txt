<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><em>Fast and Flexible Sea Ice Dynamics</em></h2><a id="user-content-fast-and-flexible-sea-ice-dynamics" class="anchor" aria-label="Permalink: Fast and Flexible Sea Ice Dynamics" href="#fast-and-flexible-sea-ice-dynamics"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Subzero.jl is a native <a href="https://julialang.org/" rel="nofollow">Julia</a> discrete-element model (DEM) for exploring fine-scale sea ice dynamics,
reimplementing and enhancing MATLAB model <a href="https://doi.org/10.1029/2022MS003247" rel="nofollow">SubZero by Manucharyan and Montemuro</a>.</p>
<ul dir="auto">
<li>🚀 Runs over <strong>35 times faster</strong> that original MATLAB model for title simulation!</li>
<li>🧩 Modular simulation model makes it easy to <strong>customize simulations</strong>!
<ul dir="auto">
<li>Enable and disable physical processes such as fracturing, ridging, and welding</li>
<li>Choose algorithms for key processes (or add your own!)</li>
</ul>
</li>
</ul>
