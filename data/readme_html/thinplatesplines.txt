<p dir="auto">This small module implements <a href="https://en.wikipedia.org/wiki/Thin_plate_spline" rel="nofollow">thin-plate splines</a> for Julia. Thin-plate splines are a very useful technique for representing smooth, continuous deformations in 2, 3, or N-dimensional space. They are often used in data interpolation, shape matching, and geometric design. Thin-plate splines allow you to specify a deformation on the entire space by specifying a set of 'control points' - their original and deformed positions. You can then 'extrapolate' the resulting deformation to the rest of the space, in a way that minimizes the bending energy over the entire space.</p>
<p dir="auto">In this module, deformations are represented using the <code>ThinPlateSpline</code> type. Three functions are exposed:</p>
<ol dir="auto">
<li><code>tps_solve</code>, which takes as input a set of control points and deformed control points, and a stiffness coefficient, and produces a deformation.</li>
<li><code>tps_deform</code>, which takes as input as set of points and a deformation, and deforms the points according to the deformation.</li>
<li><code>tps_energy</code>, a utility function which returns the bending energy of a thin-plate spline. This function is useful when you want to compare different deformations to each other.</li>
</ol>

<p dir="auto">How about a more general example? How about deforming <em>continuous lines</em>, not just points? <code>tps_deform</code> is general enough to be able to do that, without having to actually discretize the line as a lot of points. We can represent lines parametrically using linear functions of some variable <code>t</code>, with the <a href="https://github.com/JuliaDiff/TaylorSeries.jl">TaylorSeries</a> package. For example, let's represent the line in the plane given by <code>x(t) = 2 + t, y(t) = 1 + t/2</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using TaylorSeries
t = Taylor1([0,1],15)
line = [2 + t, 1 + 0.5*t]'"><pre><span class="pl-k">using</span> TaylorSeries
t <span class="pl-k">=</span> <span class="pl-c1">Taylor1</span>([<span class="pl-c1">0</span>,<span class="pl-c1">1</span>],<span class="pl-c1">15</span>)
line <span class="pl-k">=</span> [<span class="pl-c1">2</span> <span class="pl-k">+</span> t, <span class="pl-c1">1</span> <span class="pl-k">+</span> <span class="pl-c1">0.5</span><span class="pl-k">*</span>t]<span class="pl-k">'</span></pre></div>
<p dir="auto">We can deform this line just as we can with points:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="deformed_line = tps_deform(line, tps)"><pre>deformed_line <span class="pl-k">=</span> <span class="pl-c1">tps_deform</span>(line, tps)</pre></div>
<p dir="auto">This will look something like: [<code>2.4 + 1.25 t + O(t¹⁶)</code>,  <code>2.0 + 1.25 t + O(t¹⁶)</code>]. In this case, since the transform is fully affine, the result is also a straight line, and so no terms higher than <code>t</code> exist. In general tps transforms, higher-order terms may exist. For instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="x1 = [0.0 1.0
      1.0 0.0
      1.0 1.0
      1.0 2.0]

      1.1 0.1
      1.2 1.5
      1.3 2.0]
tps_deform(line,tps_solve(x1,x2,1.0))"><pre>x1 <span class="pl-k">=</span> [<span class="pl-c1">0.0</span> <span class="pl-c1">1.0</span>
      <span class="pl-c1">1.0</span> <span class="pl-c1">0.0</span>
      <span class="pl-c1">1.0</span> <span class="pl-c1">1.0</span>
      <span class="pl-c1">1.0</span> <span class="pl-c1">2.0</span>]
x2 <span class="pl-k">=</span> [<span class="pl-c1">0.0</span> <span class="pl-c1">1.0</span>
      <span class="pl-c1">1.1</span> <span class="pl-c1">0.1</span>
      <span class="pl-c1">1.2</span> <span class="pl-c1">1.5</span>
      <span class="pl-c1">1.3</span> <span class="pl-c1">2.0</span>]
<span class="pl-c1">tps_deform</span>(line,<span class="pl-c1">tps_solve</span>(x1,x2,<span class="pl-c1">1.0</span>))</pre></div>
<p dir="auto">Gives a more complicated curve, with <code>y(t) = 1.472 + 0.603 t - 0.009 t² + ...</code>. Note that this general idea can be extended to planes in 3D (or, indeed, higher-order dimensions) or even deformation of general geometric objects like spheres, etc.</p>
