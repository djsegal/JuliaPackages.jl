<p dir="auto">Biogeochemistry model for Clima-Ocean.</p>
<p dir="auto">Goals for year 1:</p>
<ol dir="auto">
<li>Develop and implement a trainable (bio)geochemical ocean carbon cycle model with changable free parameters.
For an example of one possible model, see the
<a href="https://mitgcm.readthedocs.io/en/latest/examples/global_oce_biogeo/global_oce_biogeo.html#sub-global-oce-biogeo" rel="nofollow">MITgcm documentation</a>.</li>
</ol>
<p dir="auto">See also</p>
<ul dir="auto">
<li><a href="https://agupubs.onlinelibrary.wiley.com/doi/pdfdirect/10.1029/2005GL024987" rel="nofollow">https://agupubs.onlinelibrary.wiley.com/doi/pdfdirect/10.1029/2005GL024987</a></li>
<li><a href="https://agupubs.onlinelibrary.wiley.com/doi/pdfdirect/10.1029/2004GB002280" rel="nofollow">https://agupubs.onlinelibrary.wiley.com/doi/pdfdirect/10.1029/2004GB002280</a></li>
</ul>
<ol start="2" dir="auto">
<li>Calibrate the carbon cycle model together with the ocean dynamical core to reproduce observed ocean circulation and carbon cycle.</li>
</ol>

especially figure 13.)</li>
</ol>
