<p dir="auto">Moshi is the pattern in Chinese （模式）. This package is the refactor of MLStyle with</p>
<ul dir="auto">
<li>more correct pattern language for pattern match with <code>@match</code></li>
<li>type-stable algebra data type/tagged union with generics via <code>@data</code></li>
<li>traits, derive macro <code>@derive</code> from rust</li>
</ul>

<p dir="auto">This project is in the early stage of development. The macro syntax has been iterated acorss several packages including Expronicon, MLStyle. The syntax are mostly stable. However, the API and features are subject to change.</p>
