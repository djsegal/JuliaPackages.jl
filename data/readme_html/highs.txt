<p dir="auto"><a href="https://github.com/jump-dev/HiGHS.jl">HiGHS.jl</a> is a wrapper for the
<a href="https://highs.dev" rel="nofollow">HiGHS</a> solver.</p>
<p dir="auto">It has two components:</p>
<ul dir="auto">
<li>a thin wrapper around the complete C API</li>
<li>an interface to <a href="https://github.com/jump-dev/MathOptInterface.jl">MathOptInterface</a></li>
</ul>

<p dir="auto">Install HiGHS as follows:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg

<p dir="auto">HiGHS uses a global scheduler that is shared between threads.</p>
<p dir="auto">Before changing the number of threads using <code>MOI.Threads()</code>, you must call
<code>Highs_resetGlobalScheduler(1)</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using JuMP, HiGHS
model = Model(HiGHS.Optimizer)
Highs_resetGlobalScheduler(1)
set_attribute(model, MOI.NumberOfThreads(), 1)"><pre><span class="pl-k">using</span> JuMP, HiGHS
model <span class="pl-k">=</span> <span class="pl-c1">Model</span>(HiGHS<span class="pl-k">.</span>Optimizer)
<span class="pl-c1">Highs_resetGlobalScheduler</span>(<span class="pl-c1">1</span>)
<span class="pl-c1">set_attribute</span>(model, MOI<span class="pl-k">.</span><span class="pl-c1">NumberOfThreads</span>(), <span class="pl-c1">1</span>)</pre></div>
<p dir="auto">If modifying the number of HiGHS threads across different Julia threads, be sure
to read the docstring of <code>Highs_resetGlobalScheduler</code>. In particular, resetting
the scheduler is not thread-safe.</p>
