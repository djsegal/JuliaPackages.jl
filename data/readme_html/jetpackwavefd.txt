<p dir="auto"><code>JetPackWaveFD</code> is a <code>Jets.jl</code> wave propagation operator pack which includes a reference implementation of isotropic and anisotropic second order in time pseudo- visco- acoustic variable density self adjoint operators and related infrastructure. These operators rely on the <code>WaveFD</code> package to supply high performance c++ kernels for the propagators.</p>
