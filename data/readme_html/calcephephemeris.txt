<p dir="auto">This package is a lightweight wrapper around <a href="https://github.com/JuliaBinaryWrappers/CALCEPH_jll.jl">CALCEPH_jll.jl</a> that implements the <a href="https://github.com/JuliaSpaceMissionDesign/JSMDInterfaces.jl">JSMDInterfaces.jl</a> interfaces to extract data from SPICE and INPOP ephemeris kernels.</p>
