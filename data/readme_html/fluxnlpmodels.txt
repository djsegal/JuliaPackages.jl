<p dir="auto">This package serves as an NLPModels interface to the <a href="https://github.com/FluxML/Flux.jl">Flux.jl</a> deep learning framework. It enables seamless integration between Flux's neural network architectures and NLPModels' optimization tools for non-linear programming (NLP) problems.</p>
