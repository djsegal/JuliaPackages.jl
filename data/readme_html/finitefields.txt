<p dir="auto"><a id="user-content-finitefields" href="#FiniteFields">#</a>
<strong><code>FiniteFields</code></strong> — <em>Module</em>.</p>
<p dir="auto">This   package  introduces  finite  fields   using  the  GAP  syntax.  This compatibility   with  GAP  is  the  motivation  not  to  use  the  existing <code>GaloisFields</code>.  The  speed  is  comparable  with  <code>GaloisFields</code>, slightly slower  for prime fields and faster for composite fields. Lke GAP3, we only implement  fields  of  order  less  than  2^16. This package comes with the module  <code>Modulo</code> implementing modular arithmetic without restriction on the modulus (the modulus can be a <code>BigInt</code>).</p>
<p dir="auto">This only dependency of this package is <code>Primes</code>.</p>
<p dir="auto">The Galois field with <code>p^n</code> elements is obtained as <code>GF(p^n)</code>. All elements of  Galois fields of characteristic <code>p</code>  have the same type, the parametric type   <code>FFE{p}</code>.  The  function   <code>Z(p^n)</code>  returns  a   generator  of  the multiplicative group of <code>GF(p^n)</code>. Other elements of <code>GF(p^n)</code> are obtained as  powers of <code>Z(p^n)</code>, except <code>0</code>, obtained as <code>0*Z(p^n)</code>. Elements of the prime  field can  also be  obtained as  <code>FFE{p}(n)</code> (which  is the  same as <code>n*Z(p)^0</code>).</p>

<p dir="auto"><a id="user-content-finitefields.ffe-tuple{integer}" href="#FiniteFields.FFE-Tuple{Integer}">#</a>
<strong><code>FiniteFields.FFE</code></strong> — <em>Method</em>.</p>
<p dir="auto"><code>FFE{p}(i)</code>  for <code>i</code> an integer or a fraction with denominator prime to <code>p</code> returns the reduction mod <code>p</code> of <code>i</code>, an element of the prime field <code>𝔽ₚ</code>.</p>

<p dir="auto"><a id="user-content-finitefields.z-tuple{any}" href="#FiniteFields.Z-Tuple{Any}">#</a>
<strong><code>FiniteFields.Z</code></strong> — <em>Method</em>.</p>
<p dir="auto"><code>Z(p^d)</code></p>
<p dir="auto">returns  a  generator  of  the  multiplicative  group  of  the finite field <code>𝔽_{pᵈ}</code>,  where    <code>p</code>  must  be  prime  and <code>pᵈ</code> smaller than <code>2¹⁵</code>. This multiplicative  group  is  cyclic  thus  <code>Z(pᵈ)ᵃ</code>  runs  over it for <code>a</code> in <code>0:pᵈ-1</code>.  The zero  of the  field is  <code>0*Z(p)</code> (the  same as <code>0*Z(pᵈ)</code>; we automatically lower an element to the smallest field which contains it).</p>
<p dir="auto">The  various generators returned by <code>Z</code> for finite fields of characteristic <code>p</code>  are compatible. That  is, if the  field <code>𝔽_{pⁿ}</code> is  a subfield of the field <code>𝔽_{pᵐ}</code>, that is, <code>n</code> divides <code>m</code>, then <code>Z(pⁿ)=Z(pᵐ)^div(pᵐ-1,pⁿ-1)</code>.  This is  achieved by  choosing <code>Z(p)</code> as the smallest  primitive root  modulo <code>p</code>  and <code>Z(pⁿ)</code>  as a  root of the <code>n</code>-th Conway polynomial of characteristic <code>p</code>. Those polynomials where defined by J.H.~Conway and computed by R.A.~Parker.</p>

<p dir="auto"><a id="user-content-finitefields.modulo" href="#FiniteFields.Modulo">#</a>
<strong><code>FiniteFields.Modulo</code></strong> — <em>Module</em>.</p>
<p dir="auto">This module introduces modular arithmetic.</p>
<p dir="auto">The  integer <code>x</code> mod. <code>n</code> is constructed  by the function <code>Mod(x,n)</code>. If <code>n isa  Int</code> the result is of type <code>Mod{UInt64}</code>. If <code>n isa BigInt</code> the result is  of  type  <code>Mod{BigInt}</code>.  Since  <code>n</code>  is  not  encoded in the type, the elements  <code>0</code> and <code>1</code> mod.  <code>n</code> cannot be constructed  from the type, which causes  some problems for some Julia functionality (for instance <code>inv</code> on a matrix does not work). For prime moduli <code>p</code>, the type <code>FFE{p}</code> in <code>FiniteFields</code> does not have such limitations.</p>
