<p dir="auto">Julia implementations for consistent (spectral) approximations of Koopman operators, following <a href="https://doi.org/10.48550/arXiv.2309.00732" rel="nofollow">arXiv:2309.00732</a> that includes a <em>very</em> limited implementation of nonlinear Laplacian spectral analysis or NLSA and related kernel algorithms. (The full and original package — implemented in Matlab — can be found here: <a href="https://github.com/dg227/NLSA">NLSA</a>.)</p>
<p dir="auto">See the examples folder and <a href="https://github.com/clairevalva/ConsistentKoopman.jl/blob/main/examples/flattorus.jl">flattorus.jl</a> for the computation of approximate Koopman eigenfunctions of the flat torus system:
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6099088f953893de83f8573d9590e996">$$\Phi^t: \mathbf{T}^2 \to \mathbf{T}^2,  \Phi^t(\theta_1, \theta_2) = (\theta_1 + \alpha_1 t, \theta_2 + \alpha_2 t)  \mathrm{mod} 2\pi$$</math-renderer>
for which eigenfunctions should resemble fourier modes and the eigenvalues should be integer linear combinations of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6099088f953893de83f8573d9590e996">$\alpha_1$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="6099088f953893de83f8573d9590e996">$\alpha_2$</math-renderer>.</p>
<p dir="auto">Further functionality — kernel options and more computational batching flexibility, for when memory is more limited/large datasets — to be added.</p>
