<p dir="auto">This julia package provide a basis for inteoperability between different implementations of permutations in julia.
The interface is based on four preconditions:</p>
<ul dir="auto">
<li>subtyping <code>AbstractPermutations.AbstractPermutation</code>, and</li>
<li>implementing a constructor from vector of <code>images</code>, and</li>
<li>implementing methods for
<ul dir="auto">
<li><code>AbstractPermutations.degree(::AbstractPermutation)</code> and</li>
<li><code>Base.^(::Integer, ::AbstractPermutation)</code>,</li>
</ul>
</li>
</ul>
<p dir="auto">and two conventions:</p>
<ul dir="auto">
<li><code>AbstractPermutations</code> are finitely supported bijections of <code>N</code> (the positive integers)</li>
<li><code>AbstractPermutations</code> act on <code>N</code> from the right (and therefore <code>(1,2)·(1,2,3) == (1,3)</code>).</li>
</ul>
<p dir="auto">With implementing the interface one receives not only consistent arithmetic <strong>across</strong> different implementations of the interface but also the possibility to run permutation groups algorithms from package following the interface</p>
<p dir="auto">The packages following <code>AbstractPermutation</code> interface:</p>
<ul dir="auto">
<li><a href="https://github.com/kalmarek/PermutationGroups.jl"><code>PermutationGroups.jl</code></a></li>
<li><a href="https://github.com/jmichel7/PermGroups.jl/"><code>PermGroups.jl</code></a> (to be confirmed).</li>
</ul>
<blockquote>
<p dir="auto">Note that <a href="https://github.com/scheinerman/Permutations.jl"><code>Permutations.jl</code></a> <strong>do not</strong> implement the <code>AbstractPermutations.jl</code> interface due to the fact that they act on integers <strong>on the left</strong>. See <a href="https://github.com/scheinerman/Permutations.jl/issues/42#issuecomment-1826868005" data-hovercard-type="issue" data-hovercard-url="/scheinerman/Permutations.jl/issues/42/hovercard">these</a> <a href="https://github.com/scheinerman/Permutations.jl/issues/42#issuecomment-1830242636" data-hovercard-type="issue" data-hovercard-url="/scheinerman/Permutations.jl/issues/42/hovercard">comments</a>.</p>
</blockquote>
