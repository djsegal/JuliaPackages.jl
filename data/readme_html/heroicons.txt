<ul dir="auto">
<li>This package provides access to the <a href="https://heroicons.com" rel="nofollow">https://heroicons.com</a> collection of SVG icons from Julia.</li>
<li>Any <code>HeroIcons.Icon</code> will display as expected in <code>MIME"text/html"</code> environments (like <a href="https://github.com/fonsp/Pluto.jl">Pluto</a>!).</li>
</ul>

<p dir="auto">HeroIcons come in four sizes/styles: <code>outline</code>, <code>solid</code>, <code>mini</code>, and <code>micro</code>.  Each size/style has its own set of icons.</p>
<ul dir="auto">
<li>You can retrieve the raw SVG string via <code>raw_outline(:arrow_down)</code> (similarly for <code>solid</code>, <code>mini</code>, and <code>micro</code>).</li>
<li>The <code>Icon</code> object (<code>Icon(icon_name::Symbol, style::Symbol)</code>) displays the SVG in <code>MIME"text/html"</code> environments.</li>
<li>Icons are "queryable" via <code>HeroIcons.outline.&lt;TAB&gt;</code> (similarly for <code>solid</code>, <code>mini</code>, and <code>micro</code>).  E.g. <code>HeroIcons.outline.arrow_down</code> will return the <code>Icon</code> object for the icon <code>arrow_down</code>.</li>
</ul>
