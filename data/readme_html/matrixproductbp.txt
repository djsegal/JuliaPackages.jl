<p dir="auto">This repository contains the code relative to the paper <em>Matrix Product Belief Propagation for reweighted stochastic dynamics over graphs</em> (<a href="https://www.pnas.org/doi/10.1073/pnas.2307935120" rel="nofollow">PNAS</a>, <a href="https://arxiv.org/abs/2303.17403" rel="nofollow">arxiv</a>).
When possible, variable names match the notation used there.
An <a href="errata.md">errata</a> file is also found here.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package is based on <a href="https://github.com/stecrotti/TensorTrains.jl">TensorTrains.jl</a> for the operations on tensor trains (a.k.a. matrix product states).</p>
<p dir="auto">The directory is organized as follows:</p>
<ul dir="auto">
<li>
<p dir="auto">The main module <code>MatrixProductBP</code> implements the BP equations.
Essential ingredients are:</p>
<ul dir="auto">
<li>An <code>IndexedBiDiGraph</code> on which the system is defined  (for more details, see the <a href="https://stecrotti.github.io/IndexedGraphs.jl/stable/bidigraph/" rel="nofollow">documentation of IndexedGraphs.jl</a>)</li>
<li>
<code>BPFactor</code>s living on the factor nodes of the graph. Any concrete subtype (e.g. <code>SISFactor</code>) must implement a method <code>(fᵢ::SISFactor)(xᵢᵗ⁺¹::Integer, xₙᵢᵗ::Vector{&lt;:Integer}, xᵢᵗ::Integer)</code> that computes the contribution of that factor to the joint probability as a function of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="eef09e36db43300bf4f7fa9bc7bab1e0">$x_i^{t+1},\boldsymbol{x}_{\partial i}^{t}, x_i^{t}$</math-renderer>.</li>
<li>Optionally, single-node reweightings <code>ϕ</code> and edge reweightings <code>ψ</code>
</li>
</ul>
<p dir="auto">Some allowed operations:</p>
<ul dir="auto">
<li><code>iterate!(bp::MPBP; kw...)</code></li>
<li><code>pair_beliefs(bp::MPBP)</code></li>
<li><code>beliefs(bp::MPBP)</code></li>
<li><code>bethe_free_energy(bp::MPBP)</code></li>
</ul>
<p dir="auto">There is some montecarlo (Soft Margin) utility in <code>src/sampling/</code>:</p>
<ul dir="auto">
<li>
<code>sample(bp::MPBP, nsamples::Integer)</code>: draw samples from the prior weighted with their likelihood</li>
<li>
<code>draw_node_observations!(bp::MPBP, nobs::Integer)</code>: draw samples from the prior and add them to the <code>MPBP</code> object as reweighting</li>
</ul>
<p dir="auto">Code for computing probabilities exactly by exhaustive enumeration in <code>src/exact/</code> (only for small system size and final time):</p>
<ul dir="auto">
<li><code>exact_prob(bp::MPBP)</code></li>
</ul>
</li>
<li>
<p dir="auto">A submodule <code>Models</code> that can be included with</p>
</li>
</ul>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using MatrixProductBP.Models"><pre><span class="pl-k">using</span> MatrixProductBP<span class="pl-k">.</span>Models</pre></div>
<p dir="auto">that implements two models: Glauber dynamics and the SIS model of epidemic spreading.
It contains model definitions and specialized versions of the BP equations that are more efficient than the generic one.</p>
<ul dir="auto">
<li>
<p dir="auto">A <code>test</code> folder with small examples</p>
</li>
<li>
<p dir="auto">A <code>notebooks</code> folder where results and plots are produced. The notebooks generating the results contained in the article output generate some data in .jld format that is then read by <code>notebooks/plots_for_paper.ipynb</code> which produces the figures in the article.</p>
</li>
</ul>
