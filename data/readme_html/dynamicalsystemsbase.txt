<p dir="auto">A Julia package that defines the <code>DynamicalSystem</code> interface and many concrete implementations used in the DynamicalSystems.jl ecosystem.</p>
<p dir="auto">To install it, run <code>import Pkg; Pkg.add("DynamicalSystemsBase")</code>.
Typically, you do not want to use <code>DynamicalSystemsBase</code> directly,
as downstream analysis packages re-export it.</p>
<p dir="auto">All further information is provided in the documentation, which you can either find online or build locally by running the <code>docs/make.jl</code> file.</p>
