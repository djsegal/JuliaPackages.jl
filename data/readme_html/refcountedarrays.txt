<p dir="auto">RefCountedArrays.jl provides a reference-counted array, the <code>RCArray</code>, which
uses <code>malloc</code>-backed memory and supports being freed eagerly with
<code>RefCountedArrays.unsafe_free!</code>, just like CUDA.jl and other GPU array types.</p>

<p dir="auto">Unlike Julia's venerable <code>Array</code>, which is GC-managed and thus lazily
collected, the <code>RCArray</code> can be freed the moment that the user or library that
allocated it knows that it's no longer used. When used correctly, this feature
can allow for very tight control of memory, which is especially valuable for
library authors who know the "lifetime" of the arrays that their library
allocates.</p>
