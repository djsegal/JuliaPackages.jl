<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Everything is the same, just smaller</h2><a id="user-content-everything-is-the-same-just-smaller" class="anchor" aria-label="Permalink: Everything is the same, just smaller" href="#everything-is-the-same-just-smaller"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The <code>MiniMods</code> module defines the <code>MiniMod</code> type that behaves
exactly the same as <code>Mod</code> (from the <code>Mods</code> module) except that
moduli are restricted to lie between 2 and 255. In this way, a
<code>MiniMod</code> only takes up one byte of memory, whereas a <code>Mod</code> uses
eight.</p>

<p dir="auto">While it is not clear why one would like to mix expressions with both <code>Mod</code> and
<code>MiniMod</code> types, this is permitted so long as the moduli of the numbers are the same. The result of such a mixed expression is <code>MiniMod</code> because this is the more
space efficient type.</p>

<p dir="auto">We envision that users of this module will be primarily using very small
moduli, so the upper bound of 255 won't (we hope) be a problem. However,
users may elect to modify the code to work with larger integers (but smaller
than <code>Int</code>).</p>
<p dir="auto">In the source file <code>MiniMods.jl</code> find the line</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const SmallInt = UInt8"><pre><span class="pl-k">const</span> SmallInt <span class="pl-k">=</span> UInt8</pre></div>
<p dir="auto">and change <code>UInt8</code> to another integer type. For example, use <code>UInt16</code> to expand
the range of moduli to 65535.</p>
