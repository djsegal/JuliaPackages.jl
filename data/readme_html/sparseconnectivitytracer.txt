<p dir="auto">For functions <code>y = f(x)</code> and <code>f!(y, x)</code>, the sparsity pattern of the Jacobian can be obtained
by computing a single forward-pass through the function:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using SparseConnectivityTracer

julia&gt; x = rand(3);

julia&gt; f(x) = [x[1]^2, 2 * x[1] * x[2]^2, sin(x[3])];

julia&gt; jacobian_sparsity(f, x, detector)
3×3 SparseArrays.SparseMatrixCSC{Bool, Int64} with 4 stored entries:
 1  ⋅  ⋅
 1  1  ⋅
 ⋅  ⋅  1"><pre>julia&gt; <span class="pl-k">using</span> SparseConnectivityTracer

<p dir="auto"><code>TracerSparsityDetector</code> returns conservative sparsity patterns over the entire input domain of <code>x</code>.
It is not compatible with functions that require information about the primal values of a computation (e.g. <code>iszero</code>, <code>&gt;</code>, <code>==</code>).</p>
<p dir="auto">To compute a less conservative sparsity pattern at an input point <code>x</code>, use <code>TracerLocalSparsityDetector</code> instead.
Note that patterns computed with <code>TracerLocalSparsityDetector</code> depend on the input <code>x</code> and have to be recomputed when <code>x</code> changes:</p>

<p dir="auto">SparseConnectivityTracer uses <a href="https://github.com/SciML/ADTypes.jl">ADTypes.jl</a>'s interface for <a href="https://sciml.github.io/ADTypes.jl/stable/#Sparsity-detector" rel="nofollow">sparsity detection</a>,

In fact, the functions <code>jacobian_sparsity</code> and <code>hessian_sparsity</code> are re-exported from ADTypes.</p>
