<p dir="auto"><code>AlgebraicPetri.jl</code> is a Julia package for building Petri Net models
compositionally. This package depends on <a href="https://github.com/AlgebraicJulia/Catlab.jl">Catlab.jl</a>
which provides a framework for applied category theory (ACT) in Julia, and is
part of the <a href="https://www.algebraicjulia.org/" rel="nofollow">AlgebraicJulia organization</a>,
which develops ACT-based software to improve scientific and technical
computing.</p>
<p dir="auto"><code>AlgebraicPetri.jl</code> defines the category of open Petri nets as described in [<a href="https://arxiv.org/abs/1808.05415" rel="nofollow">Baez 2018</a>],
and implements composition and stratification methods for such Petri nets
from <a href="https://doi.org/10.1098/rsta.2021.0309" rel="nofollow">[Libkind 2022]</a>.</p>

<p dir="auto">Please visit the <a href="https://algebraicjulia.github.io/AlgebraicPetri.jl/dev/" rel="nofollow">documentation</a>
to learn more about how to use the package. For more details on the underlying theory,
please consult [<a href="https://arxiv.org/abs/1808.05415" rel="nofollow">Baez 2018</a>] or <a href="https://doi.org/10.1098/rsta.2021.0309" rel="nofollow">[Libkind 2022]</a>,
with the latter being more oriented towards applied practitioners.</p>
<p dir="auto">Tutorials are organized by theme. Currently examples from epidemiology are the most
developed. The basic tutorial introduces the main themes of modeling with open Petri nets,
followed by a detailed tutorial on model stratification, and a detailed example
of developing a complex model with multiple strains of a directly-transmitted disease
with vaccines.</p>
