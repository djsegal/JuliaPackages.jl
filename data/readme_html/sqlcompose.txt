<p dir="auto">The goal of this package is to use julia's means of abstraction to built SQL queries.
The SQL language has no good built-in abstraction methods. By using julia methods for abstraction it
is such easier to built complex queries.</p>
<p dir="auto">Also retrieving the data of the queried julia structure is supported.</p>
<p dir="auto">Supports generating query code from existing database.</p>
<p dir="auto">See <a href="https://github.com/robertsmit/SQLCompose.jl/blob/main/test/samples.jl">Samples</a>.</p>
