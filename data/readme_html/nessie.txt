<p dir="auto"><code>NESSie.jl</code> is a software package for the popular <a href="https://julialang.org" rel="nofollow">Julia language</a>,
providing efficient numerical solvers for local and nonlocal protein electrostatics
computations in structured solvents.</p>

<p dir="auto">This version of <code>NESSie.jl</code> requires Julia 1.6 or above. In the Julia shell, switch to the
<code>Pkg</code> shell by pressing <code>]</code> and enter the following command:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add NESSie"><pre>pkg<span class="pl-k">&gt;</span> add NESSie</pre></div>
<p dir="auto">Analogously, the <code>NESSie.jl</code> can be removed at any time using the following command in the
<code>Pkg</code> shell:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; rm NESSie"><pre>pkg<span class="pl-k">&gt;</span> rm NESSie</pre></div>

<p dir="auto">The following Julia code shows how to compute and print the nonlocal reaction field energy
of a single Na+ ion (modeled as a spherically-symmetric, vacuum-filled system) in water:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NESSie

# I. Create model
model           = readoff(&quot;data/born/na.off&quot;)
model.charges   = readpqr(&quot;data/born/na.pqr&quot;)
model.params.εΩ = 1   # dielectric constant for vacuum model
model.params.εΣ = 78  # dielectric constant for water

# II. Apply nonlocal solver
bem = solve(NonlocalES, model)

# III. Apply postprocessor
val = rfenergy(bem)
println(&quot;Reaction field energy: $val kJ/mol&quot;)"><pre><span class="pl-k">using</span> NESSie

<a href="https://tkemmer.github.io/NESSie.jl/dev/" rel="nofollow">online</a>.</p>
<p dir="auto">You can also build the same documentation manually using the following command in the
<code>docs/</code> directory:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="shell&gt; julia make.jl"><pre>shell<span class="pl-k">&gt;</span> julia make.jl</pre></div>
<p dir="auto">Please note that this additionally requires the
<a href="http://github.com/JuliaDocs/Documenter.jl"><code>Documenter.jl</code></a> package to be installed. This can be achieved by using the following command in the <code>Pkg</code> shell:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add Documenter"><pre>pkg<span class="pl-k">&gt;</span> add Documenter</pre></div>
<p dir="auto">After the build process has finished successfully, the documentation can be
found in the <code>docs/build/</code> directory.</p>

<p dir="auto"><code>NESSie.jl</code> ships with the following extra tools:</p>
<ul dir="auto">
<li><strong>Converter.jl</strong>, a simple Julia script to convert surface and volume meshes into
different formats</li>
<li><strong>Mesher</strong>, a wrapper application for the <a href="http://www.fetk.org/codes/gamer/" rel="nofollow">GAMer</a>
library to create surface and volume meshes from <a href="https://www.rcsb.org/pdb" rel="nofollow">PDB</a> files</li>
</ul>
<p dir="auto">Please refer to the respective tool's README file for more details.</p>
