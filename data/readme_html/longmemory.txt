<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">About</h2><a id="user-content-about" class="anchor" aria-label="Permalink: About" href="#about"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><strong>LongMemory.jl</strong> is a package for time series long memory modelling in <a href="https://julialang.org/" rel="nofollow"><em><strong>Julia</strong></em></a>.</p>
<p dir="auto">The package provides functions for <em>generating long memory</em>, <em>estimating the parameters of the models</em>, and <em>forecasting</em>.</p>
<p dir="auto">Generating methods include <em>fractional differencing</em>, <em>stochastic error duration</em>, and <em>cross-sectional aggregation</em>.</p>
<p dir="auto">Estimators include <em>classic</em> ones used to estimate the Hurst effect, those inspired by the <em>log-periodogram regression</em>, and <em>parametric</em> ones.</p>
<p dir="auto">Forecasting is provided for all parametric estimators.</p>
<p dir="auto">Moreover, the package adds <em>plotting capabilities</em> to illustrate long memory dynamics and forecasting.</p>
<p dir="auto">Finally, the package includes the <em>Nile River minima</em> and <em>Northern Hemisphere Temperature Anomalies</em> data sets to illustrate the use of the functions.</p>

<p dir="auto">The package is registered in the Julia General registry and can be installed with the Julia package manager.</p>
<p dir="auto">From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add LongMemory"><pre>pkg<span class="pl-k">&gt;</span> add LongMemory</pre></div>
<p dir="auto">Or, equivalently, via the <code>Pkg</code> API:</p>
