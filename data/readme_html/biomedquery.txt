<p dir="auto">Julia utilities to process and save results from BioMedical databases/APIs.</p>
<p dir="auto"><a href="https://github.com/BioJulia/BioServices.jl">BioServices.jl</a> (part of BioJulia) provides the basic interface to some of the APIs, while BioMedQuery helps parse and save results into MySQL, SQLite, DataFrames, CSV etc.</p>
<p dir="auto">Supported APIs include:</p>
<p dir="auto"><strong>National Library of Medicine (NLM)</strong></p>
<ul dir="auto">
<li>Entrez Programming Utilities <a href="http://www.ncbi.nlm.nih.gov/books/NBK25501/" rel="nofollow">(E-Utilities)</a></li>
<li>Unified Medical Language System <a href="https://uts.nlm.nih.gov//license.html" rel="nofollow">(UMLS)</a></li>
<li>Clinical Trials <a href="https://clinicaltrials.gov/" rel="nofollow">(clinicaltrials.gov)</a></li>
<li>MEDLINE <a href="https://www.nlm.nih.gov/databases/download/pubmed_medline.html" rel="nofollow">(PubMed MEDLINE)</a></li>
</ul>
