<div align="justify" dir="auto">
<p dir="auto">This package implements <strong>epoch folding</strong> in pure Julia. Epoch folding is a technique used to determine the periodicity of pulsed emission, as seen from sources like pulsars, magnetars, and others. Quoting from <a href="https://iopscience.iop.org/article/10.3847/1538-4357/abda4a" rel="nofollow"><strong>Bachetti et a. (2021)</strong></a>:</p>
<blockquote>
<p dir="auto">Let <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$(t _{j}, X _{j}) \forall j = 1, \dots N$</math-renderer> be pairs of flux measurements <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$X _{j}$</math-renderer> at times <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$t _{j}$</math-renderer>. If we define <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$f$</math-renderer> as the candidate, and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$\dot f, \ddot f, \dots$</math-renderer> as the frequency derivatives measured at a reference time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$t _{\mathrm{ref}}$</math-renderer>, we calculate the pulse phase of each <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$X _{j}$</math-renderer> as:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$$\phi _{j}(t) = \phi _{0} + f(t _{j} - t _{\mathrm{ref}}) + 0.5 \dot{f} (t _{j} - t _{\mathrm{ref}})^{2} + \cdots ,$$</math-renderer></p>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$\phi _{0}$</math-renderer> is the pulse phase at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$t _{\mathrm{ref}}$</math-renderer>, which is set to zero for unknown or candidate pulsars. [...] The folded or pulsed profile is then a histogram of these phases falling into <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$N _{\mathrm{bin}}$</math-renderer> equal phase bins between zero and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$2\pi$</math-renderer>, weighted by the flux in each sample:</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$$p _{i} = \sum _{j = 1} ^{N} X _{j} \theta (\phi _{j} - \phi _{\mathrm{mid}, i}), \quad i = 1, \dots, N _{\mathrm{bin}},$$</math-renderer></p>
<p dir="auto">where</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$$\phi _{\mathrm{mid}, i} = 2\pi \frac{i - 0.5}{N _{\mathrm{bin}}}$$</math-renderer></p>
<p dir="auto">is the phase corresponding to the middle of bin <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$i$</math-renderer> and</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$$
\theta (x) =
\begin{cases}
1, &amp; \text{if}\ |x| &lt; 0.5 / N _{\mathrm{bin}} \\
0, &amp; \text{otherwise.}
\end{cases}
$$</math-renderer></p>
</blockquote>
<p dir="auto">While the approach described above is the most common way to fold radio data, some software packages like <a href="https://github.com/scottransom/presto"><strong><code>PRESTO</code></strong></a> use a slightly different approach: they assume that each sample is finite in duration and "drizzle" it over the appropriate pulse phase bins. Both approaches are implemented in this package; in fact, the code for both approaches is almost directly inspired from the code in <code>PRESTO</code>, with the occasional change made for Julia. Like <code>PRESTO</code>, this code also calculates and returns the statistics associated with the folded profile, including the <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="a1d8c1a40d44d5d11ccd22e0d0b821bb">$\chi^{2}$</math-renderer> statistic (<a href="https://ui.adsabs.harvard.edu/abs/1983ApJ...272..256L/abstract" rel="nofollow"><strong>Leahy et al. 1983</strong></a>).</p>
