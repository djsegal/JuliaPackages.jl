<p dir="auto">This package provides algorithms to solve autonomous Generalized Differential Riccati Equations (GDRE)</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="260a125f9a35a3e4f3e3514cfee09372">$$\left\{
\begin{aligned}
E^T \dot X E &amp;= C^T C + A^T X E + E^T X A - E^T X BB^T X E,\\\
X(t_0) &amp;= X_0.
\end{aligned}
\right.$$</math-renderer>
<p dir="auto">More specifically:</p>
<ul dir="auto">
<li>Dense Rosenbrock methods of orders 1 to 4</li>
<li>Low-rank symmetric indefinite (LRSIF) Rosenbrock methods of order 1 and 2, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="260a125f9a35a3e4f3e3514cfee09372">$X = LDL^T$</math-renderer>
</li>
</ul>
<p dir="auto">In the latter case, the (generalized) Lyapunov equations arizing in the Rosenbrock stages
are solved using a LRSIF formulation of the Alternating-Direction Implicit (ADI) method,
as described by <a href="https://doi.org/10.1016/j.laa.2015.04.006" rel="nofollow">LangEtAl2015</a>.
The ADI uses the self-generating parameters described by <a href="https://hdl.handle.net/11858/00-001M-0000-0029-CE18-2" rel="nofollow">Kuerschner2016</a>.</p>
<blockquote>
<p dir="auto"><strong>Warning</strong>
The low-rank 2nd order Rosenbrock method suffers from the same problems as described by <a href="https://doi.org/10.1016/j.laa.2015.04.006" rel="nofollow">LangEtAl2015</a>.</p>
</blockquote>
<p dir="auto">The user interface hooks into <a href="https://github.com/SciML/CommonSolve.jl">CommonSolve.jl</a> by providing the <code>GDREProblem</code> problem type
as well as the <code>Ros1</code>, <code>Ros2</code>, <code>Ros3</code>, and <code>Ros4</code> solver types.</p>

<p dir="auto">The easiest setting is perhaps the dense one,
i.e. the system matrices <code>E</code>, <code>A</code>, <code>B</code>, and <code>C</code>
as well as the solution trajectory <code>X</code> are dense.
First, load the system matrices from e.g. <code>test/Rail371.mat</code>
(see <a href="#license">License</a> section below)
and define the problem parameters.</p>
