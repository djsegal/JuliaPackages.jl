<p dir="auto"><code>NEOs.jl</code> is a Julia package for high-accuracy orbit determination and propagation of
Near-Earth Objects. <code>NEOs.jl</code> exploits jet transport techniques via
<a href="https://github.com/PerezHz/TaylorIntegration.jl">TaylorIntegration.jl</a>.</p>

<p dir="auto">The <code>pha</code> directory contains the <code>apophis.jl</code> script which performs an
orbit determination for asteroid (99942) Apophis from optical and radar astrometry. In order
to run this script, the environment corresponding to the <code>Project.toml</code> contained in the
<code>pha</code> directory has to be active and instantiated. This can be done, for example, by running
the following command from the <code>pha</code> directory:</p>
<p dir="auto"><code>julia -e `import Pkg; Pkg.activate(); Pkg.instantiate()` # run this from the `pha` directory </code></p>
<p dir="auto">Once the <code>pha</code> environment is active, this script may be called from the <code>pha</code> directory
with the default settings as:</p>
<p dir="auto"><code>julia --project apophis.jl</code></p>
<p dir="auto">The <code>--help</code> option can be passed to see a list of the customizable settings</p>
<p dir="auto"><code>julia --project apophis.jl --help</code></p>
<p dir="auto"><code>NEOs.propagate</code> also supports multi-threading:</p>
<p dir="auto"><code>julia -t &lt;number-of-threads&gt; --project apophis.jl --help</code></p>
