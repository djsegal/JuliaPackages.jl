<p dir="auto">Right now, mostly all endpoint wrapper functions have been written, tested and organized by sub-modules as defined in Spotify's <a href="https://developer.spotify.com/documentation/web-api" rel="nofollow">documentation</a>. The documentation was <a href="https://developer.spotify.com/blog/2023-03-27-introducing-the-new-spotify-for-developers" rel="nofollow">reworked</a> in March 2023, but most documentation links still work.</p>
<p dir="auto">Any missing endpoints, e.g. 'queue', 'repeat', 'volume' and 'shuffle', could be accessed more directly through calls like <code>spotify_request("recommendations/available-genre-seeds")</code>.</p>

<ul dir="auto">
<li>play music and prune your playlists through a mini-player REPL mode</li>

<li>fix your taste profile after that kid's party</li>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Wrapper API</h2><a id="user-content-wrapper-api" class="anchor" aria-label="Permalink: Wrapper API" href="#wrapper-api"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Wrapper functions require different permission scopes, which you grant as needed by pressing 'Accept' in a browser tab which pops up when needed. A granted scope lasts for one hour.</p>
<p dir="auto">The wrapper functions are duck-typed and will accept strings, vectors of strings or the types below.
Functions leniently convert input to these string-like types:</p>
<ul dir="auto">
<li><code>SpPlaylistId</code>, <code>SpArtistId</code>, <code>SpTrackId</code>, <code>SpAlbumId</code></li>
<li><code>SpShowId</code>, <code>SpEpisodeId</code>, <code>SpId</code>, <code>SpCategoryId</code></li>
</ul>
<p dir="auto">Ouput from all wrapper functions is a tuple: (<code>JSON3 object</code>, <code>wait_seconds</code>).</p>
<ul dir="auto">
<li><code>wait_seconds</code> is zero except if the API rate limit is temporarily exceeded</li>
<li><code>JSON3 object</code> is an <code>object</code> / <code>dictionary</code> which is easy and fast to inspect and use. See the examples for some ideas</li>
</ul>
<p dir="auto">Control of text feedback is provided, see <code>?LOGSTATE</code>.</p>
