<p dir="auto">CoordRefSystems.jl provides conversions between Coordinate Reference Systems (CRS) in native Julia.
It was designed to work with units from <a href="https://github.com/PainterQubits/Unitful.jl">Unitful.jl</a>,
respects projection bounds catalogued in <a href="https://epsg.io" rel="nofollow">https://epsg.io</a>, and is very fast thanks to advanced
parametrizations at compile-time.</p>
<p dir="auto">This package addresses various design issues encountered in previous attempts such as
<a href="https://github.com/JuliaGeo/Geodesy.jl">Geodesy.jl</a> and <a href="https://github.com/subnero1/MapMaths.jl">MapMaths.jl</a>.
Our <a href="benchmark/output.csv">benchmarks</a> show that CoordRefSystems.jl is sometimes faster than <a href="https://github.com/OSGeo/PROJ">PROJ</a>,
which is the most widely used software library for cartography in the world (written in C/C++).</p>

<p dir="auto">CRS are most useful to locate objets in the physical world.
Given an ellipsoid of revolution and a standardized origin
(a.k.a. datum), it is possible assign coordinates to points
without ambiguity.</p>
