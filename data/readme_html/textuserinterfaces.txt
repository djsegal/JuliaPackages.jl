<p dir="auto"><strong>WARNING</strong>: This package should be considered alpha!</p>
<p dir="auto">This package wraps the C library <strong>ncurses</strong> and provide a Julia-like API to build text user
interfaces. The development was highly based on the package
<a href="https://github.com/tonyhffong/TermWin.jl">TermWin.jl</a>.</p>
<p dir="auto">If you want to use this package as a NCurses wrap, it should work well. Notice that if you
want a function that is not available, please submit an issue or (better) a pull request.
For the vast majority of cases, this should be a very easy modification.</p>
<p dir="auto">If you want to use this package expecting a good Julia API to create text-based windows and
widgets, you should wait a little. The API is not ready yet. However, help is very welcome!
We have a proof of concept in <code>examples</code> folder of a Tic Tac Toe game creating using the
current API.</p>
