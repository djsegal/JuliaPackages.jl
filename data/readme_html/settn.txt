<p dir="auto">A prototype of the series-expansion thermal tensor network (SETTN) algorithm [<a href="https://doi.org/10.1103/PhysRevB.95.161104" rel="nofollow">PRB <strong>95</strong>, 161104</a>] is illustrated for the XY chain. Other models can be easily customized thanks to <code>ITensors.jl</code>'s <code>OpSum</code> function.</p>
<blockquote>
<p dir="auto">This package is also an essential ingredient for more advanced thermal tensor network algorithms, such as <a href="https://link.aps.org/doi/10.1103/PhysRevX.8.031082" rel="nofollow">XTRG</a> and <a href="https://link.aps.org/doi/10.1103/PhysRevLett.130.226502" rel="nofollow">tanTRG</a>. In particular, <strong>two-site variational MPO sum and product</strong> discussed in <a href="https://doi.org/10.1103/PhysRevB.95.161104" rel="nofollow">PRB <strong>95</strong>, 161104</a> and <a href="https://doi.org/10.1103/PhysRevX.8.031082" rel="nofollow">PRX <strong>8</strong>, 031082</a> are implemented, which can be used in other modules via:</p>
</blockquote>

<p dir="auto">Two-site variational MPO sum <code>+</code> and product <code>contract</code>, are extensions from <a href="https://github.com/ITensor/ITensors.jl">ITensors.jl</a> with <code>::Algorithm"variational"</code>, more details can be found in <code>./src/mpo.jl</code>; also check the relevant part of source code in <code>ITensors.jl</code> package. Note the sweep scheme for variational sum and product follows the same one for <code>ITensors.jl</code>'s <code>dmrg</code> function.</p>
