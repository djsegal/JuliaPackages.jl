<p dir="auto">This project contains several <a href="#packages">packages</a> which ease the
processes of ephemeris sourcing and parsing, and one top-level package:
<code>EphemerisSources.jl</code>. For usage examples, and instructions, please see
the project's <a href="https://juliaastro.org/EphemerisSources.jl/docs" rel="nofollow">stable
documentation</a>. Any
potential new features for this package will be released very quickly
after they are developed; the stable documentation will always track the
<a href="https://JuliaAstro.org/EphemerisSources.jl/docs/dev" rel="nofollow">in-development
documentation</a>
closely.</p>

<p dir="auto">Currently, this project only supports the fetching and parsing of
Cartesian state vectors from two ephemeris sources: NASA JPL's <a href="https://naif.jpl.nasa.gov/naif/data_generic.html" rel="nofollow">Generic
Kernels</a>, and NASA
JPL's <a href="https://ssd.jpl.nasa.gov/horizons/" rel="nofollow">Horizons</a> platform.
In addition, <code>EphemerisSources.jl</code> is very new, and test coverage is another
major opportunity for improvement. This project welcomes all contributions and comments.
If you would like to help add tests or parsing for the two other common ephemeris
formats — observer tables and osculating orbital elements — please add a
comment in an
<a href="https://github.com/JuliaAstro/EphemerisSources.jl/issues/41" data-hovercard-type="issue" data-hovercard-url="/JuliaAstro/EphemerisSources.jl/issues/41/hovercard">issue</a>! If
you find bugs, want to request features, or if you have any other
comments about the project's capabilities and code, please file an
<a href="https://github.com/JuliaAstro/EphemerisSources.jl/issues/new">issue</a>. Please
treat all contributors with respect, as described in the project's
<a href="CODE_OF_CONDUCT.md">Code of Conduct</a>.</p>

<p dir="auto">This repository includes the top-level documentation for several solar
system ephemeris tools, all written with the Julia Programming Language.
To learn more about how to use these tools, consult the <a href="https://juliaastro.org/EphemerisSources.jl" rel="nofollow">documentation
website</a>.</p>
