<p dir="auto"><a href="https://rafaqz.github.io/Rasters.jl/dev/" rel="nofollow">Rasters.jl</a> provides excellent methods for reading, analysing and plotting for geospatial data.
This package provides empirical distribution fitting for <code>Raster</code> data structures aiming to provide functionality similar to python's <a href="https://xhistogram.readthedocs.io/en/latest/index.html" rel="nofollow">xhistogram</a> for <a href="https://docs.xarray.dev/en/stable/" rel="nofollow">xarray</a> in Julia.</p>
