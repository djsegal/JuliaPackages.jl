<p dir="auto">This package can be used to access, analyze, process, and simulate data generated by <em>ocean robots</em>. These ocean observing platforms collect observations in the field, and allow us to monitor climate.</p>
<p dir="auto"><code>OceanRobots.jl</code> includes profiling floats, drifters, gliders, and moorings as illustrated in the examples listed below. It provides a unified and simple user interface to each of these data sets.</p>
