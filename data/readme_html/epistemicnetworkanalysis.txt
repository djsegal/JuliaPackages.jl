<p dir="auto"><strong>Author: Mariah A. Knowles (@snotskie)</strong></p>
<p dir="auto">A port of <a href="https://rdrr.io/cran/rENA/" rel="nofollow">rENA</a> version 0.2.0.1 into native Julia, with substantial API changes to fit Julia style, and with addition of new rotation methods.</p>
<p dir="auto">Original R package by <a href="http://www.epistemicnetwork.org/" rel="nofollow">http://www.epistemicnetwork.org/</a>.</p>
<p dir="auto"><strong>This package is in BETA -- It is stable enough for exploratory work and ready for user feedback</strong></p>

<p dir="auto">I recommend installing <a href="https://code.visualstudio.com/docs/languages/julia" rel="nofollow">Julia for Visual Code</a> first. If you are in a country where downloading resources from GitHub is difficult, you may install Julia using the <a href="https://pypi.org/project/jill/" rel="nofollow">Python jill package</a> and following the advice linked in the <a href="https://discourse.julialang.org/t/why-is-it-so-hard-to-install-packages-in-julia-from-china/87566" rel="nofollow">Julia forums for users in China</a></p>
<p dir="auto">Then to install this package, run the following in Julia:</p>
