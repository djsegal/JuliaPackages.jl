<p dir="auto">This package serves only one purpose.
To provide a bilinear interpolation or nearest neighbour based image rotation which works with CUDA and multithreaded CPUs
(thanks to <a href="https://github.com/JuliaGPU/KernelAbstractions.jl">KernelAbstractions.jl</a>).
It can rotate images but also 3D arrays with a trailing batch dimension.</p>
<p dir="auto">Further, it has registered adjoints with <a href="https://github.com/JuliaDiff/ChainRulesCore.jl">ChainRulesCore.jl</a>.
The functionality of this package is now included in <a href="https://fluxml.ai/NNlib.jl/dev/reference/#Rotation" rel="nofollow">NNlib.jl</a>.</p>

<p dir="auto">There is <code>imrotate</code> by <a href="https://github.com/JuliaImages/ImageTransformations.jl">ImageTransformations.jl</a>.
For standard image processing rather use this. It has better handling and way more options.
But, it doesn't run with <code>CuArrays</code> and does not provide an adjoint/gradient rule.</p>
<p dir="auto">There is <code>rotate</code> by <a href="https://nanoimaging.de/FourierTools.jl/dev/rotate/" rel="nofollow">FourierTools.jl</a>.
It's based on FFTs. It is based on a sinc interpolation.</p>
<p dir="auto">The functionality of this package is now included in <a href="https://fluxml.ai/NNlib.jl/dev/reference/#Rotation" rel="nofollow">NNlib.jl</a>.</p>
