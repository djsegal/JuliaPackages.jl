<p dir="auto">This is a project that builds around the <a href="https://docs.julialang.org/en/v1/stdlib/Dates/" rel="nofollow">Dates</a> module to allow complex date operations.</p>
<p dir="auto">The aim is to provide a standard toolset to allow you to answer questions such as <em>when is the next Easter</em> or <em>what is the 3rd Wednesday of March next year?</em></p>

<ul dir="auto">
<li>A generic, extendable algebra for date operations with a rich set of primitives.</li>
<li>A composable design to allow complex combinations of relative date operations.</li>
<li>An extendable parsing library to provide a language to describe relative dates.</li>
<li>An interface for integrating holiday calendar systems.</li>
</ul>

<p dir="auto">RDates can be installed using the Julia package manager. From the Julia REPL, type <code>]</code> to enter the Pkg REPL mode and run</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; add RDates"><pre>pkg&gt; add RDates</pre></div>
<p dir="auto">At this point you can now start using RDates in your current Julia session using the following command</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using RDates"><pre>julia&gt; <span class="pl-k">using</span> RDates</pre></div>
