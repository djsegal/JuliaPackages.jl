<p dir="auto">Need to solve a very large multi-physics problem on many GPUs in parallel? Just Relax!</p>
<p dir="auto"><code>JustRelax.jl</code> is a collection of accelerated iterative pseudo-transient solvers using MPI and multiple CPU or GPU backends. It's part of the <a href="https://ptsolvers.github.io" rel="nofollow">PTSolvers organisation</a> and
developed within the <a href="https://www.pasc-ch.org/projects/2021-2024/gpu4geo/" rel="nofollow">GPU4GEO project</a>. Current publications, outreach and news can be found on the <a href="https://ptsolvers.github.io/GPU4GEO/" rel="nofollow">GPU4GEO website</a>.</p>
<p dir="auto">The package relies on other packages as building blocks and parallelisation tools:</p>
<ul dir="auto">
<li><a href="https://github.com/omlins/ParallelStencil.jl">ParallelStencil.jl</a></li>
<li><a href="https://github.com/omlins/ImplicitGlobalGrid.jl">ImplicitGlobalGrid.jl</a></li>
<li><a href="https://github.com/JuliaGeodynamics/GeoParams.jl">GeoParams.jl</a></li>
<li><a href="https://github.com/JuliaGeodynamics/JustPIC.jl">JustPIC.jl</a></li>
</ul>
<p dir="auto">The package serves several purposes:</p>
<ul dir="auto">
<li>
<p dir="auto">It provides a collection of solvers to be used in quickly developing new applications</p>
</li>
<li>
<p dir="auto">It provides some standardization so that application codes can</p>
<ul dir="auto">
<li>more easily handle local material properties through the use of GeoParams.jl</li>
<li>more easily switch between a pseudo-transient solver and another solvers (e.g. an explicit thermal solvers)</li>
</ul>
</li>
<li>
<p dir="auto">It provides a natural repository for contributions of new solvers for use by the larger community</p>
</li>
</ul>
<p dir="auto">We provide several miniapps, each designed to solve a well-specified benchmark problem, in order to provide</p>
<ul dir="auto">
<li>examples of usage in high-performance computing</li>
<li>basis on which to build more full-featured application codes</li>
<li>cases for reference and performance tests</li>
</ul>

<p dir="auto">Available miniapps can be found in the <a href="miniapps">miniapps folder</a> and will be updated regularly. The miniapps are designed to be simple and easy to understand, while still providing a good basis for more complex applications. The miniapps are designed to be run on a single node, but can be easily extended to run on multiple nodes using <a href="https://github.com/omlins/ImplicitGlobalGrid.jl">ImplicitGlobalGrid.jl</a> and <a href="https://github.com/JuliaParallel/MPI.jl">MPI.jl</a>.</p>
