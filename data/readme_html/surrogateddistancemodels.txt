<p dir="auto">This package contains methods that can be used to replace big metric databases and its related metric function by a more light weight encoding and distance function. This package is designed to be used with <a href="https://github.com/sadit/SimilaritySearch.jl"><code>SimilaritySearch.jl</code></a> but can be used without it.</p>
<p dir="auto">In particular, it contains the following methods/types:</p>
<ul dir="auto">
<li><code>BinPerms</code>: Binary encoding based on Brief permutations (with shift-based encoding)</li>
<li><code>BinPermsDiffEnc</code>: Binary encoding based on Brief permutations with differential encoding</li>
<li><code>HyperplaneEncoding</code>: Hyperplane-based binary encoding</li>
<li><code>HighEntropyHyperplanes</code>: Binary encoding based on high entropy hyperplanes</li>
<li><code>NearestReference</code>: String-based encoding using references</li>
<li><code>Perms</code>: Vector-based encoding of Permutations</li>
<li><code>PCAProjection</code>: Vector-based encoding just using <code>PCA</code> from <code>MultivariateStats</code> package.</li>
<li><code>RandomProjection</code>: Vector-based encoding using Gaussian random projections.</li>
</ul>
<p dir="auto">All methods use <code>fit</code> and <code>predict</code> methods with reasonable default parameters.</p>
