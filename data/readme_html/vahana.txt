<p dir="auto">Vahana is a high-performance, agent-based modelling library developed
in Julia, specifically (but not only) designed for large-scale
simulations of complex social networks. It leverages the power of Graph
Dynamical Systems, coupled with advanced parallel computing
methodologies, to provide a robust framework for the exploration of
network-based systems.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Key Features</h2><a id="user-content-key-features" class="anchor" aria-label="Permalink: Key Features" href="#key-features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Efficient and Scalable: Vahana uses Message Passing Interface (MPI)
for distributed memory parallelism, allowing for efficient scaling
to thousands of cores.</p>
</li>
<li>
<p dir="auto">Expressive Interface: Despite its high-performance capabilities,
Vahana is designed with an accessible and expressive interface,
making the construction of complex models intuitive and easy.</p>
</li>
<li>
<p dir="auto">Network-Oriented Approach: Vahana's design focuses on network
dynamics, making it an excellent tool for simulations involving
complex interactions and dependencies between agents.</p>
</li>
<li>
<p dir="auto">Graph Dynamical Systems: Leveraging the principles of Graph
Dynamical Systems, Vahana provides a solid theoretical foundation
for modelling agent-based systems.</p>
</li>
<li>
<p dir="auto">Integration into the Julia Ecosystem: Vahana interacts seamlessly
with other Julia libraries, such as DataFrames and Graphs.</p>
</li>
<li>
<p dir="auto">HDF5 Data Persistence: For efficient data storage and access, Vahana
utilises the Hierarchical Data Format version 5 (HDF5), including
optional support for parallel HDF5.</p>
</li>
</ul>

the configuration/installation sections of the
<a href="https://juliaparallel.org/MPI.jl/stable/configuration/" rel="nofollow">MPI.jl</a> and
<a href="https://juliaio.github.io/HDF5.jl/stable/#Installation" rel="nofollow">HDF5.jl</a>
libraries.</p>
