<p dir="auto">This package provides a library of functions useful for neural networks, such as softmax, sigmoid, batched multiplication, convolutions and pooling. Many of these are used by <a href="https://github.com/FluxML/Flux.jl">Flux.jl</a>, which loads this package, but they may be used independently.</p>
<p dir="auto">For use with automatic differentiation, this package defines gradients using <a href="https://github.com/JuliaDiff/ChainRules.jl">ChainRules.jl</a>. These will be seen by various packages including <a href="https://github.com/FluxML/Zygote.jl">Zygote.jl</a>.</p>
<p dir="auto">GPU support is provided as package extensions (see the <code>ext/</code> folder). In order to load the extensions, use the imports</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NNlib, CUDA, cuDNN"><pre><span class="pl-k">using</span> NNlib, CUDA, cuDNN</pre></div>
<p dir="auto">for CUDA support, or</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NNlib, AMDGPU"><pre><span class="pl-k">using</span> NNlib, AMDGPU</pre></div>
<p dir="auto">for AMDGPU support.</p>
