<p dir="auto">DeepAR is a Julia module designed for probabilistic forecasting using autoregressive recurrent networks, based on the concept introduced in the paper <a href="https://arxiv.org/pdf/1704.04110.pdf" rel="nofollow">DeepAR: Probabilistic Forecasting with Autoregressive Recurrent Networks</a>.</p>

<p dir="auto">DeepAR allows the training and use of deep learning models for time series forecasting. Key features include:</p>
<ul dir="auto">
<li>Time series forecasting using autoregressive models.</li>
<li>Training and prediction with custom hyperparameters.</li>
</ul>

<p dir="auto">Define the hyperparameters for the DeepAR model using <code>DeepARParams</code>:</p>
<ul dir="auto">
<li><code>η::Float64</code>: Learning rate for model training. Default is <code>1e-2</code>.</li>
<li><code>n_mean::Int</code>: Number of samples used for computing the predictive mean. Default is <code>100</code>.</li>
</ul>
