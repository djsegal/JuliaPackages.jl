<p dir="auto">This package implements:</p>
<ol dir="auto">
<li><a href="https://arxiv.org/abs/1611.01144" rel="nofollow">Gumbel-Softmax</a></li>
<li><a href="https://arxiv.org/abs/2010.04838" rel="nofollow">Rao-Blackwellized Gumbel-Softmax</a></li>
</ol>
<p dir="auto">in the Julia programming language. The package supports both forward-mode automatic differentiation (AD) and reverse-mode AD through
<a href="https://github.com/FluxML/Zygote.jl">Zygote</a> and <a href="https://github.com/JuliaDiff/ForwardDiff.jl">ForwardDiff</a> respectively.</p>

<p dir="auto">The expected input shape is <code>(latent_dimension, categorical_dimension, batch_dimension)</code>. As an example, let's suppose we have 4 Categorical distributions with 3 classes and we want to sample 10 times. In this case, <code>latent_dimension=4</code>, <code>categorical_dimension=3</code>, and <code>batch_dimension=10</code>.</p>
