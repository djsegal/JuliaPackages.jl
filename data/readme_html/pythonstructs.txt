<p dir="auto">PythonStructs.jl implements a similar API to Python's <a href="https://docs.python.org/3/library/struct.html" rel="nofollow"><code>struct</code> standard library</a> in Julia. This package does not use any Python components and does not depend on PyCall.jl or PythonCall.jl.</p>
<p dir="auto">The current design centers around the <code>PythonStruct{T,M}</code> type. <code>T</code> represents the underlying Julia struct type. <code>M</code> is a <code>PythonStructs.Modifier</code> type that has type parameters for byte order, size mapping, and alignment.</p>
