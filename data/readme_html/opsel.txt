<p dir="auto">Efficient optimal selection for tree breeding</p>
<p dir="auto">Optimal selection problems are to find optimum of selection of genotypes that maximizes genetic gains under a constraint on genetic diversity which involves Wright's numerator relationship matrix.</p>
<p dir="auto">Using a conic programming approach, this package provides efficient numerical methods for optimal selection problems arising from tree breeding. This package now implements two methods</p>
<ol dir="auto">
<li>the compact SOCP formulation for unequally deployment problem</li>
<li>the steepest-ascent method for equally deployment problem</li>
</ol>

<p dir="auto">The columns of the input CSV file should be:
<code>i(id), p(parent1), p(parent2), g(EBV), u(upperbound), h(inbreeding)</code>
For example, the following line in a CSV
<code>1040, 782, 751, 3.1313800000000001, 50, 0.0410156250000000</code>
indicates that the parents of 1040 are 782 and 751. The EBV of 1040 is 3.13138, and the upperbound is 50 (this will be divided by 2800) and the inbreeding value is 0.041015625.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Basic Formulation</h2><a id="user-content-basic-formulation" class="anchor" aria-label="Permalink: Basic Formulation" href="#basic-formulation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An unequally-type of optimization problem is of form:</p>
<p dir="auto"><a href="https://www.codecogs.com/eqnedit.php?latex=\max:&amp;space;g^T&amp;space;x&amp;space;\&amp;space;\&amp;space;\text{subject&amp;space;to:}&amp;space;x^TAx&amp;space;\le&amp;space;2\theta,&amp;space;e^T&amp;space;x&amp;space;=&amp;space;1,&amp;space;l\le&amp;space;x&amp;space;\le&amp;space;u" rel="nofollow"><img src="https://camo.githubusercontent.com/9aaf3fe26f81dd970396345c53937603f9126a593c524731931f48d5f1f4d8fe/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f5c6d61783a2673706163653b675e542673706163653b782673706163653b5c2673706163653b5c2673706163653b5c746578747b7375626a6563742673706163653b746f3a7d2673706163653b2673706163653b785e5441782673706163653b5c6c652673706163653b325c74686574612c2673706163653b655e542673706163653b782673706163653b3d2673706163653b312c2673706163653b6c5c6c652673706163653b782673706163653b5c6c652673706163653b75" title="\max: g^T x \ \ \text{subject to:} \  x^TAx \le 2\theta, e^T x = 1, l\le x \le u" data-canonical-src="https://latex.codecogs.com/gif.latex?\max:&amp;space;g^T&amp;space;x&amp;space;\&amp;space;\&amp;space;\text{subject&amp;space;to:}&amp;space;&amp;space;x^TAx&amp;space;\le&amp;space;2\theta,&amp;space;e^T&amp;space;x&amp;space;=&amp;space;1,&amp;space;l\le&amp;space;x&amp;space;\le&amp;space;u" style="max-width: 100%;"></a></p>
<p dir="auto">Here, the decision variable is <a href="https://www.codecogs.com/eqnedit.php?latex=x&amp;space;\in&amp;space;\mathbb{R}^Z" rel="nofollow"><img src="https://camo.githubusercontent.com/d7b5855f9a661676eb92f4e95ac4ae9e08bc6fc17600b8a5b82c249111786cb1/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f782673706163653b5c696e2673706163653b5c6d61746862627b527d5e5a" title="x \in \mathbb{R}^Z" data-canonical-src="https://latex.codecogs.com/gif.latex?x&amp;space;\in&amp;space;\mathbb{R}^Z" style="max-width: 100%;"></a>. The constant vector <a href="https://www.codecogs.com/eqnedit.php?latex=g&amp;space;\in&amp;space;\mathbb{R}^Z" rel="nofollow"><img src="https://camo.githubusercontent.com/2c15c1ae8e4c03aa2d43f892053746b7a1f72f396fa2008ea2618fbfdd7b7555/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f672673706163653b5c696e2673706163653b5c6d61746862627b527d5e5a" title="g \in \mathbb{R}^Z" data-canonical-src="https://latex.codecogs.com/gif.latex?g&amp;space;\in&amp;space;\mathbb{R}^Z" style="max-width: 100%;"></a> is estimated breeding values.
The matrix <a href="https://www.codecogs.com/eqnedit.php?latex=A" rel="nofollow"><img src="https://camo.githubusercontent.com/e4a8c11c572b1e9f3cb23248d6dc7d53a8f977ad3a08c6fd6c0385e712acbeec/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f41" title="A" data-canonical-src="https://latex.codecogs.com/gif.latex?A" style="max-width: 100%;"></a> is Wright's numerator relationship matrix, and the theta is a threashold.
The vector <a href="https://www.codecogs.com/eqnedit.php?latex=e&amp;space;\in&amp;space;\mathbb{R}^Z" rel="nofollow"><img src="https://camo.githubusercontent.com/0086d577f3cec7f7c1dc53b1fb282ce81b5867ac7955acb989a90c3aaf0d14d3/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f652673706163653b5c696e2673706163653b5c6d61746862627b527d5e5a" title="e \in \mathbb{R}^Z" data-canonical-src="https://latex.codecogs.com/gif.latex?e&amp;space;\in&amp;space;\mathbb{R}^Z" style="max-width: 100%;"></a> is the vector of all ones. The vectors <a href="https://www.codecogs.com/eqnedit.php?latex=l&amp;space;\in&amp;space;\mathbb{R}^Z" rel="nofollow"><img src="https://camo.githubusercontent.com/91263db0c648eb9779f8d4ac2d023516e63cf1c219b0255411c29a16f6a787c3/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f6c2673706163653b5c696e2673706163653b5c6d61746862627b527d5e5a" title="l \in \mathbb{R}^Z" data-canonical-src="https://latex.codecogs.com/gif.latex?l&amp;space;\in&amp;space;\mathbb{R}^Z" style="max-width: 100%;"></a> and <a href="https://www.codecogs.com/eqnedit.php?latex=u&amp;space;\in&amp;space;\mathbb{R}^Z" rel="nofollow"><img src="https://camo.githubusercontent.com/5072a681ba9c3220d708c3282ff311003826ca94da4a3e160c42ab389dcfee5b/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f752673706163653b5c696e2673706163653b5c6d61746862627b527d5e5a" title="u \in \mathbb{R}^Z" data-canonical-src="https://latex.codecogs.com/gif.latex?u&amp;space;\in&amp;space;\mathbb{R}^Z" style="max-width: 100%;"></a> are the lower and upper bounds of <a href="https://www.codecogs.com/eqnedit.php?latex=x" rel="nofollow"><img src="https://camo.githubusercontent.com/29063c1640be5cda2ad7b5969cd718f5341e4fd02492a9c4946c59ba530d6e8c/68747470733a2f2f6c617465782e636f6465636f67732e636f6d2f6769662e6c617465783f78" title="x" data-canonical-src="https://latex.codecogs.com/gif.latex?x" style="max-width: 100%;"></a>, respectively.</p>
