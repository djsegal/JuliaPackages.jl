<p dir="auto">Currently functions for reading NFx (i.e., *.nf3, *.nf6), NSx, and NEV files are implemented. I'm currently using the specs provided by Ripple to build these functions, and so they may not be fully compatible with other versions of these formats from Blackrock systems.</p>
<p dir="auto"><g-emoji class="g-emoji" alias="warning">⚠️</g-emoji> the NEV implementation is fairly limited right now. I'm not doing spike recordings, so I only implemented the digital events.</p>

<p dir="auto">Regardless of whether the original file is NSx or NFx, the data are loaded into a <code>NxFile</code> object, which contains a <code>NxHeader</code>, a <code>Vector</code> of <code>NxChannelHeader</code>'s (one for each channel), and a <code>Vector</code> of <code>NxPacket</code>'s containing the actual data. Data is contained in a <code>Matrix</code>
with each channel in a column, with time progressing down the rows.</p>
