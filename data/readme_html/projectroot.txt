<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Getting Started</h2><a id="user-content-getting-started" class="anchor" aria-label="Permalink: Getting Started" href="#getting-started"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The package provides a single macro, <code>@projectroot</code>, that can be used to reference files in your project. The idea is to in some file <code>A.jl</code> be able to reference another file <code>B.jl</code> somewhere else in your project without having to care where file <code>A.jl</code> is or need to update the reference if you move <code>A.jl</code> somewhere else.</p>
<p dir="auto">Take this example project:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="MyProject
├── scripts
│   └── A.jl
├── src
│   └── B.jl
└── Project.toml"><pre class="notranslate"><code>MyProject
├── scripts
│   └── A.jl
├── src
│   └── B.jl
└── Project.toml
</code></pre></div>
<p dir="auto">If you want to include <code>B.jl</code> from <code>A.jl</code>, all you need to do is this:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="include(@projectroot(&quot;src&quot;, &quot;B.jl&quot;))"><pre><span class="pl-c1">include</span>(<span class="pl-c1">@projectroot</span>(<span class="pl-s"><span class="pl-pds">"</span>src<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>B.jl<span class="pl-pds">"</span></span>))</pre></div>
<p dir="auto">Now, calling <code>A.jl</code> from anywhere in your project will work as expected. And if you move <code>A.jl</code> to another folder, say <code>scripts/subfolder</code>, the import will still work.</p>
<p dir="auto"><code>@projectroot</code> also handles calling lines from <code>A.jl</code> through the REPL, by fetching the current working directory.</p>
