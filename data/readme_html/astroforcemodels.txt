<p dir="auto">This package contains the dominant astrodynamics forces affecting the orbital trajectory of a satellite. Currently this package implements:</p>
<ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Zonal Harmonics</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Solar Radiation Pressure</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Drag</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Third Body Gravity</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox" checked=""> Relativistic</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Albedo</li>
<li class="task-list-item"><input type="checkbox" id="" disabled="" class="task-list-item-checkbox"> Solid Tides</li>
</ul>
<p dir="auto">This first implementation is just to get a set of working models, the next steps are to get everything allocation-free and working with automatic differentiation. Furthermore, the plan is likely to merge this effort into Julia Space Mission Design's AstroModels -- <a href="https://github.com/JuliaSpaceMissionDesign/AstroModels.jl">https://github.com/JuliaSpaceMissionDesign/AstroModels.jl</a>. But plans are still under disccusion there.</p>
