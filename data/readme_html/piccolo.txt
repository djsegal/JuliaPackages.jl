<p dir="auto">To develop locally, clone this repo and then instantiate the environment in the REPL by running first</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; activate ."><pre>pkg<span class="pl-k">&gt;</span> activate .</pre></div>
<p dir="auto">and then,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="pkg&gt; instantiate "><pre>pkg<span class="pl-k">&gt;</span> instantiate </pre></div>
<p dir="auto">Both commands should be run in pkg mode, which is activated by typing <code>]</code> in the REPL.</p>
<p dir="auto">To start julia with the current environment, run</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia --project"><pre>julia --project</pre></div>
<p dir="auto">from the Piccolo.jl directory.</p>
<p dir="auto">To run the scripts use, e.g.,</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia -t &lt;num_threads&gt; --project examples/three_qubit_swap/swap.jl"><pre>julia -t <span class="pl-k">&lt;</span>num_threads<span class="pl-k">&gt;</span> --project examples/three_qubit_swap/swap.jl</pre></div>
<p dir="auto">where <code>&lt;num_threads&gt;</code> is the number of threads you want to use as QuantumCollocation.jl takes advantage of multithreading.  The <code>--project</code> flag is necessary to make sure the correct environment is loaded.</p>
