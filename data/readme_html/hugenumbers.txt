<p dir="auto">A package for working with <strong>huge or tiny numbers</strong> beyond the dynamic range of
ordinary floating point numbers.</p>
<p dir="auto">Exports the number type <code>Huge{T} &lt;: Real</code> which is a lot like a floating point number,
except it has an exponentially larger range.</p>
<p dir="auto">You can use this for calculating extremely small probabilities, which would normally
underflow a float, or extremely large quantities which would normally overflow.</p>

<p dir="auto">To convert a number <code>x</code> to a <code>Huge</code> number:</p>
<ul dir="auto">
<li>Do <code>convert(Huge, x)</code> or <code>Huge(x)</code>.</li>
<li>If you already know <code>ix = hlog(x)</code> then <code>hexp(Huge, ix)</code> is faster.</li>
<li>If you already know <code>lx = log(x)</code> then <code>exp(Huge, lx)</code> is faster.</li>
</ul>
<p dir="auto">The following operations are implemented and accurate:</p>
<ul dir="auto">
<li><strong>Arithmetic:</strong> <code>+</code>, <code>-</code>, <code>*</code>, <code>/</code>, <code>^</code>, <code>inv</code>.</li>
<li><strong>Ordering:</strong> <code>==</code>, <code>&lt;</code>, <code>cmp</code>, <code>isequal</code>, <code>isless</code>, <code>sign</code>, <code>signbit</code>, <code>abs</code>.</li>
<li><strong>Logarithm:</strong> <code>log</code>, <code>log2</code>, <code>log10</code>].</li>
<li><strong>Conversion:</strong> <code>float</code>, <code>widen</code>, <code>big</code>.</li>
<li><strong>Special values:</strong> <code>zero</code>, <code>one</code>, <code>typemin</code>, <code>typemax</code>.</li>
<li><strong>Predicates:</strong> <code>iszero</code>, <code>isone</code>, <code>isinf</code>, <code>isfinite</code>, <code>isnan</code>.</li>
<li><strong>IO:</strong> <code>show</code>, <code>read</code>, <code>write</code>.</li>
<li><strong>Misc:</strong> <code>nextfloat</code>, <code>prevfloat</code>, <code>hash</code>.</li>
<li><strong>Note:</strong> Any functions not mentioned here might be inaccurate.</li>
</ul>

<p dir="auto">It is natural to use this package in conjunction with other packages which return
logarithms. The general pattern is that you can use <code>exp(Huge, logfunc(args...))</code>
instead of <code>func(args...)</code> to get the answer as a logarithmic number. Here are some
possibilities for <code>func</code>:</p>
<ul dir="auto">
<li><a href="https://github.com/JuliaStats/StatsFuns.jl">StatsFuns.jl</a>:
<code>normpdf</code>, <code>normcdf</code>, <code>normccdf</code>, plus equivalents for other distributions.</li>
<li><a href="https://github.com/JuliaStats/Distributions.jl">Distributions.jl</a>:
<code>pdf</code>, <code>cdf</code>, <code>ccdf</code>.</li>
<li><a href="https://github.com/JuliaMath/SpecialFunctions.jl">SpecialFunctions.jl</a>:
<code>gamma</code>, <code>factorial</code>, <code>beta</code>, <code>erfc</code>, <code>erfcx</code>.</li>
</ul>

<p dir="auto">Whereas a logarithmic number stores <code>log(x)</code>, we store a different quantity <code>hlog(x)</code>.
This is the inverse of <code>hexp(x)</code>, which has the following nice properties:</p>
<ul dir="auto">
<li>It is an increasing, continuous, differentiable, invertible function on the real numbers.</li>
<li>It grows exponentially for large <code>x</code> and shrinks exponentially for small <code>x</code>.</li>
<li><code>hexp(x) = x</code> for <code>x</code> in <code>-Inf</code>, <code>-1</code>, <code>0</code>, <code>1</code> and <code>Inf</code>.</li>
<li><code>-hexp(x) = hexp(-x)</code>.</li>
<li><code>1/hexp(x) = hexp(1/x)</code>.</li>
</ul>
<p dir="auto">The crucial difference between <code>log(x)</code> and <code>hlog(x)</code> is that the former is only valid
for positive numbers. This means that a logrithmic number requires an extra sign bit if you
need to store a sign, whereas a <code>Huge{T}</code> can be negative provided <code>T</code> can be negative.</p>
<p dir="auto">The other properties mean that many arthmetic and comparison operations are trivial to
implement - often much simpler than with logarithmic numbers.</p>
<p dir="auto"><code>hexp(x)</code> is defined as:</p>
<ul dir="auto">
<li><code>exp(x - 1)</code> if <code>x ≥ 1</code></li>
<li><code>exp(1 - 1/x)</code> if <code>x ≥ 0</code></li>
<li><code>-exp(1 + 1/x)</code> if <code>x ≥ -1</code></li>
<li><code>-exp(-x - 1)</code> otherwise</li>
</ul>
