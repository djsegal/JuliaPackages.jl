<p dir="auto">Introduction</p>
<p dir="auto"><code>.tfw</code> files are used to input wave-shape data to the oscilloscopes.
The original python codes are from the web forum of Tektronix <a href="https://forum.tek.com/viewtopic.php?t=140915" rel="nofollow">Python Read/Write AFG TFW</a>, authored by Carl M.</p>
<p dir="auto">This package is just a julia version of these codes.</p>
</li>
<li>
<p dir="auto">Usages</p>
<ul dir="auto">
<li>
<p dir="auto"><code>Writetfw(Target::String, DacValues::Vector{&lt;:Integer}; EnvelopeFlag::Bool=true)</code></p>
<p dir="auto">Use this function to write tfw files.</p>
<p dir="auto"><code>Target</code> should be something like <code>Example.tfw</code>.</p>
<p dir="auto"><code>DacValues</code> should be a vector of integers, with minima as 0 and maxima as 16382.</p>
</li>
<li>
<p dir="auto"><code>NormalVector(Values::Vector{&lt;:Real})</code></p>
<p dir="auto">This function helps you to convert a vector into the one which satisfies the requirements of <code>DacValues</code>.</p>
</li>
<li>
<p dir="auto"><code>ExampleUsage(;File::String="Example.tfw")</code></p>
<p dir="auto">Write a file named as <code>Example.tfw</code>.</p>
</li>
</ul>
</li>
</ul>
