<p dir="auto">Flux samplers for
<a href="https://github.com/LCSB-BioCore/COBREXA.jl/">COBREXA.jl</a>,
accelerated on GPUs via <a href="https://github.com/JuliaGPU/CUDA.jl">CUDA.jl</a>.</p>
<p dir="auto">The repository contains the following modules with samplers:</p>
<ul dir="auto">
<li>Affine-combination-directed Hit&amp;Run (module <code>CuFluxSampler.AffineHR</code>)</li>
<li>Artificially-Centered Hit&amp;Run (module <code>CuFluxSampler.ACHR</code>)</li>
</ul>
<p dir="auto">Both modules export a specific function for running the sampler atop COBREXA.jl
<code>MetabolicModel</code> structure, typically called <code>sample</code>. See the code comments
and documentation for details.</p>
<p dir="auto">Samplers support many options that can be turned on and off, in general:</p>
<ul dir="auto">
<li>Number of points used for mixing the new run directions in <code>AffineHR</code> may be
changed by <code>mix_points</code> parameter, and you can alternatively supply your own
mixing matrix in <code>mix_mtx</code>.</li>
<li>You can turn on/off the stoichiometry checks with <code>check_stoichiometry</code> and
tune it with <code>epsilon</code> (in both <code>ACHR</code> and <code>AffineHR</code>)</li>
<li>You can add tolerance bounds on stoichiometry in order to expand the feasible
region a little to allow randomized runs to succeed; see
<code>check_stoichiometry</code> and <code>direction_noise_max</code> parameters.</li>
<li>You can set a seed for the GPU-generated random numbers using <code>seed</code></li>
</ul>
<p dir="auto">Running the package code and tests requires a CUDA-capable GPU.</p>
