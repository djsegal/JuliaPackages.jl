<p dir="auto">This is sphericart, a multi-language library for the efficient calculation of real
spherical harmonics and their derivatives in Cartesian coordinates.</p>
<p dir="auto">For instructions and examples on the usage of the library, please refer to our
<a href="https://sphericart.readthedocs.io/en/latest/" rel="nofollow">documentation</a>.</p>

</p>

less performant than they could be on a specific processor. To generate
libraries that are optimized for the target system, you can build from source:</p>

<p dir="auto">Building from source is also necessary to use sphericart's PyTorch GPU
functionalities, and it requires a CUDA compiler.</p>

<p dir="auto">A native Julia implementation of <code>sphericart</code> is provided, called <code>SpheriCart</code>.
Install the package by opening a REPL, switch to the package manager by
typing <code>]</code> and then <code>add SpheriCart</code>.
See <a href="julia/README.md">julia/README.md</a> for usage.</p>

<p dir="auto">The following cmake configuration options are available:</p>
<ul dir="auto">
<li><code>-DSPHERICART_BUILD_TORCH=ON/OFF</code>: build the torch bindings in addition to the main library</li>
<li><code>-DSPHERICART_BUILD_TESTS=ON/OFF</code>: build C++ unit tests</li>
<li><code>-DSPHERICART_BUILD_EXAMPLES=ON/OFF</code>: build C++ examples and benchmarks</li>
<li><code>-DSPHERICART_OPENMP=ON/OFF</code>: enable OpenMP parallelism</li>
<li><code>-DCMAKE_INSTALL_PREFIX=&lt;where/you/want/to/install&gt;</code> set the root path for installation</li>
</ul>

<p dir="auto">Tests and the local build of the documentation can be run with <code>tox</code>.
The default tests, which are also run on the CI, can be executed by simply running</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="tox"><pre>tox</pre></div>
<p dir="auto">in the main folder of the repository.</p>
<p dir="auto">To run tests in a CPU-only environment you can set the environment variable
<code>PIP_EXTRA_INDEX_URL</code> before calling tox, e.g.</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="PIP_EXTRA_INDEX_URL=https://download.pytorch.org/whl/cpu tox -e docs"><pre>PIP_EXTRA_INDEX_URL=https://download.pytorch.org/whl/cpu tox -e docs</pre></div>
<p dir="auto">will build the documentation in a CPU-only environment.</p>

<p dir="auto">Although sphericart natively calculates real solid and spherical harmonics from
Cartesian positions, it is easy to manipulate its output it to calculate complex
spherical harmonics and/or to accept spherical coordinates as inputs. You can see
examples <a href="https://sphericart.readthedocs.io/en/latest/spherical-complex.html" rel="nofollow">here</a>.</p>
