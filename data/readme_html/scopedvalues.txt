This package was primarly inspired by <a href="https://github.com/tkf/ContextVariablesX.jl">ContextVariablesX.jl</a>,
it's corresponding <a href="https://github.com/JuliaLang/julia/pull/35833" data-hovercard-type="pull_request" data-hovercard-url="/JuliaLang/julia/pull/35833/hovercard">pull-request to Julia base</a>, and

<p dir="auto">It has been submitted to Julia as a <a href="https://github.com/JuliaLang/julia/pull/50958" data-hovercard-type="pull_request" data-hovercard-url="/JuliaLang/julia/pull/50958/hovercard">JULEP</a>.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Usage with logging</h2><a id="user-content-usage-with-logging" class="anchor" aria-label="Permalink: Usage with logging" href="#usage-with-logging"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Before Julia 1.11, this package implements scoped variables by using a special "payload" logger
(just like <a href="https://github.com/tkf/ContextVariablesX.jl">ContextVariablesX.jl</a>). Therefore,
changing the logger from within a dynamic scope can clobber the scoped values. To avoid this, use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ScopedValues.with_logger"><pre>ScopedValues<span class="pl-k">.</span>with_logger</pre></div>
<p dir="auto">as a replacement for <code>Logging.with_logger</code>. Likewise, if you need to access the logger, use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ScopedValues.current_logger()"><pre>ScopedValues<span class="pl-k">.</span><span class="pl-c1">current_logger</span>()</pre></div>
<p dir="auto">which will unwrap the special ScopedValues's "payload" logger to provide you with the actual logging-logger.</p>
<p dir="auto">Note that there is no issue with setting a logger <em>outside</em> of the dynamic scope. For example, a common usage is to set the global logger at the start of the program (and to not change it mid-execution). In this case, there is no issue clash with ScopedValues.jl, and e.g. <code>Logging.global_logger()</code> may be used to set the logger. There is only concern when modifying or accessing the logger from within a dynamic scope provided by ScopedValues.jl (i.e. within a <code>with</code> block).</p>
<p dir="auto">There is also no issue with logging to a logger (e.g. <code>@info</code>, etc), within a dynamic scope or elsewhere. ScopedValues "payload" logger will pass log messages through to the active logger.</p>
