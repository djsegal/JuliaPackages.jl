<p dir="auto">A Julia package for orthogonal polynomials on an annulus.</p>
<p dir="auto">This code used to be part of <a href="https://github.com/JuliaApproximation/AlgebraicCurveOrthogonalPolynomials.jl">AlgebraicCurveOrthogonalPolynomials.jl</a>.</p>
<p dir="auto">This experimental package implements <code>ZernikeAnnulus</code> and <code>ComplexZernikeAnnulus</code>,
families of orthogonal polynomials on the annulus <code>{ρ² ≤ x² + y² ≤ 1}</code>
with respect to the weight <code>(r² - ρ²)ᵃ * (1-r²)ᵇ</code>. This builds on top of
<a href="https://github.com/JuliaApproximation/SemiclassicalOrthogonalPolynomials.jl">SemiclassicalOrthogonalPolynomials.jl</a> and <a href="https://github.com/JuliaApproximation/MultivariateOrthogonalPolynomials.jl">MultivariateOrthogonalPolynomials.jl</a>.</p>
