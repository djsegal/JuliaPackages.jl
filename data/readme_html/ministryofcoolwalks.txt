<p dir="auto">Central repository of the <code>CoolWalks</code> project. Here we combine buildings, streets and trees to find the CoolWalkability of cities.</p>

<p dir="auto">The relevant code for graph, building and tree loading is spread across multiple other packages. If you are interested in these, please refer to:</p>
<ul dir="auto">
<li><a href="https://github.com/SuperGrobi/ShadowGraphs.jl">ShadowGraphs.jl</a> (Loading of OSM Data and processing it into a <code>MetaDiGraph</code>, and all kinds of functions to work with the edge geometry)</li>
<li><a href="https://github.com/SuperGrobi/CompositeBuildings.jl">CompositeBuildings.jl</a> (Code to load and preprocess the various building datasets used in this study, and shadow casting)</li>
<li><a href="https://github.com/SuperGrobi/TreeLoaders.jl">TreeLoaders.jl</a> (Code to load and preprocess the various tree datasets not (yet) used in this study, and shadow casting)</li>
<li><a href="https://github.com/SuperGrobi/Folium.jl">Folium.jl</a> (Our hacked together wrapper around <code>Folium</code>, the python wrapper around <code>Leaflet.js</code>. (It is surprisingly fast and interactive and seems to work quite well. In the future, we should direct this effort towards <a href="https://github.com/JuliaGeo/Leaflet.jl"><code>Leaflet.jl</code></a>))</li>
<li><a href="https://github.com/SuperGrobi/CoolWalksUtils.jl">CoolWalksUtils.jl</a> (Utilities used throughout the above packages. Owns many of the functions to which we add specialisations in the other packages.)</li>
</ul>
