<p dir="auto">TextParse uses Julia's generated functions to generate efficient specialized parsers for text files. Right now, there is a good set of features for reading CSV files (see <a href="https://www.queryverse.org/TextParse.jl/stable/" rel="nofollow">the documentation</a>). Parsing packages can use TextParse as a framework for implementing parsers for other formats.</p>
