<p dir="auto">This is a package containing macros/functions to help develop Packages using <a href="https://github.com/fonsp/Pluto.jl">Pluto</a> notebooks testing/prototyping aids.</p>
<p dir="auto">The major feature contribution of this package is the <code>@fromparent</code> macro, which allows to load a local package in Pluto and have its code re-parsed and updated upon manual re-run of the cell containing the macro call.
This is simlar to a <code>Revise</code>-based workflow but provides a few notable advantages:</p>
<ul dir="auto">
<li>Package code can be re-evaluated correctly without requiring a julia restart even when re-defining structs or constants</li>
<li>Local code reload, triggered manually via a floating button in the Pluto notebook, automatically triggers execution of all dependent cells, simplifying the process of testing changes of code on specific runtime paths</li>
<li>Possibilty of adding packages to the notebook environment which are not dependencies of the local package, very useful for testing plotting or benchmarking of the local package code without having to put the related packages in either the global or package-local environment</li>
<li>Support for the package extensions functionality added in julia 1.9, which together with the point on notebook environment above simplify the testing and development of extensions on the local package under development.</li>
</ul>
<p dir="auto">See the <a href="https://disberd.github.io/PlutoDevMacros.jl/" rel="nofollow">documentation</a> for more details.</p>
