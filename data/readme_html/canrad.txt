<p dir="auto">The Canopy Radiation Model (CanRad) calculates direct and diffuse shortwave radiation transmission in forest canopies using either airborne lidar data (L2R) or a canopy height model (C2R). An additional module is available that calculates radiation transmission using only terrain data (T2R).</p>
<p dir="auto">For a detailed description of L2R, see:
Webster C, Mazzotti G, Essery E and Jonas T 2020, <a href="https://doi.org/10.1016/j.rse.2020.112017" rel="nofollow">Enhancing airborne lidar data for improved forest structure representation in shortwave transmission models</a>, Remote Sensing of Environment</p>
<p dir="auto">L2R is an optimised and improved version of <a href="https://github.com/c-webster/Lidar2HemiEval">Lidar2HemiEval</a>, which was based on <a href="https://github.com/Tobias-Jonas-SLF/Lidar2Hemi">Lidar2Hemi</a>, written in MATLAB.</p>
<p dir="auto">For a detailed description of C2R, see:
Webster, C, Essery E, Mazzotti G and Jonas T, 2023 <a href="https://doi.org/10.1016/j.agrformet.2023.109429" rel="nofollow">Using just a canopy height model to obtain lidar-level accuracy in 3D forest canopy shortwave transmissivity estimates</a>, Agricultural and Forest Meteorology</p>
<p dir="auto">Both models require some additional preperatory steps. Scripts to easily carry out these steps are currently under development to facilitate easy implementation for different sites/users and will be added ~/examples/prep/ as they are completed. In the meantime, please contact the author if you wish to have earlier access.</p>
<p dir="auto">Both models can be run on an HPC to cover large domains. An example implementation will be added to ~/examples/cluster/. Feel free to contact the author for more information.</p>
