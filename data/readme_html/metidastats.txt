<p dir="auto">Keywords:</p>
<ul dir="auto">
<li><code>skipmissing</code> - drop NaN and Missing values, default = true;</li>
<li><code>skipnonpositive</code> - drop non-positive values (and NaN, Missing) for "log-statistics" - :geom, :geomean, :logmean, :logvar, :geocv;</li>
<li><code>stats</code> - default set <code>stats = [:n, :mean, :sd, :se, :median, :min, :max]</code>;</li>
<li><code>corrected</code> - use corrected var (true);</li>
<li><code>level</code> - level for confidence intervals (0.95);</li>
</ul>
<p dir="auto">Possible values for <code>stats</code> is:</p>
<ul dir="auto">
<li>:n - number of observbations;</li>
<li>:posn - positive (non-negative) number of observations;</li>
<li>:mean - arithmetic mean;</li>
<li>:var - variance;</li>
<li>:bvar - variance with no correction;</li>
<li>:geom - geometric mean;</li>
<li>:logmean - arithmetic mean for log-transformed data;</li>
<li>:logvar - variance for log-transformed data;</li>
<li>:sd - standard deviation (or σ);</li>
<li>:se - standard error;</li>
<li>:cv - coefficient of variation;</li>
<li>:geocv - coefficient of variation for log-transformed data;</li>
<li>:lci - lower confidence interval;</li>
<li>:uci - upper confidence interval;</li>
<li>:lmeanci - lower confidence interval for mean;</li>
<li>:umeanci - lower confidence interval for mean;</li>
<li>:median - median;</li>
<li>:min - minimum;</li>
<li>:max - maximum;</li>
<li>:range - range;</li>
<li>:q1 - lower quartile;</li>
<li>:q3 - upper quartile;</li>
<li>:iqr - inter quartile range;</li>
<li>:kurt - kurtosis;</li>
<li>:skew - skewness;</li>
<li>:harmmean - harmonic mean;</li>
<li>:ses standard error of skewness;</li>
<li>:sek - standard error of kurtosis;</li>
<li>:sum - sum.</li>
</ul>
