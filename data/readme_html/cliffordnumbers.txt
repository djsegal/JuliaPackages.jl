<p dir="auto"><a href="https://github.com/brainandforce/CliffordNumbers.jl">CliffordNumbers.jl</a> is a simple, statically sized multivector (Clifford number)
implementation for Julia using graded representations. This allows for common multivector
operations, particularly the various products of geometric algebra, to be easily implemented with
extremely high performance (faster than matrix multiplications of matrix representations) without
depending on any linear algebra library. Additionally, the multivectors provided by this package can
be stored inline in arrays or other data structures.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Why use Clifford numbers?</h2><a id="user-content-why-use-clifford-numbers" class="anchor" aria-label="Permalink: Why use Clifford numbers?" href="#why-use-clifford-numbers"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Clifford algebras are algebras of orthonormality: they expand a real or complex vector space with a
notion of normal vectors (those with unit square, or unit magnitude) and orthogonal vectors.</p>
<p dir="auto">The term "<a href="https://en.wikipedia.org/wiki/Geometric_algebra" rel="nofollow">geometric algebra</a>" is synonymous in a mathematical sense with Clifford
algebra, but is used by a practicioners of a new pedagogical movement to emphasize their use in
applied mathematics. In particular, <em>additive representations</em> are favored over matrix
representations for reasons of clarity, and the package implements all representations of elements
and operations on them in this manner.</p>
<p dir="auto">If you work with 3D graphics, you may already be familiar with the use of Clifford algebras: the
quaternions used to represent rotation are a Clifford algebra. Specifically, they are isomorphic to
the even subalgebra of the <a href="https://en.wikipedia.org/wiki/Algebra_of_physical_space" rel="nofollow">algebra of physical space</a>, and the elements represent
rotations in 3D. The full algebra of physical space augments rotations with reflections, allowing
any point isometry (combined with dilations) to be represented.</p>
<p dir="auto">Clifford algebras are also ubiquitous in physics, as the orthonormality relationship applies to 3D
space and (3+1)D spacetime. The Pauli matrices are a matrix representation of the algebra of
physical space, and the Dirac matrices are a matrix representation of the
<a href="https://en.wikipedia.org/wiki/Spacetime_algebra" rel="nofollow">spacetime algebra</a>. These Clifford algebras naturally extend vector algebra, and
even allow for calculus to be done with them.</p>
<p dir="auto">Here is a short guide to the most commonly used algebras, which can be extended to any number of
dimensions.</p>
<ul dir="auto">
<li><strong>VGA (vanilla geometric algebra):</strong> A drop-in replacement for standard vector algebra, suitable
for classical and quantum physics. Common operations like the cross product and dot product have
equivalents in VGA, and can be extended to spaces of arbitrary dimension.</li>
<li><strong>PGA (projective geometric algebra):</strong> Extends VGA with a degenerate dimension so that points,
lines, planes, and related objects can be represented at arbitrary offsets from the origin. Not
only can it represents point isometries, it can also seamlessly combine them with arbitrary
translations.</li>
<li><strong>CGA (conformal geometric algebra):</strong> Extends VGA with one positive squaring and one negative
squaring dimension, and allows for the representation of <em>k</em>-spheres. Two-dimensional CGA is
the algebra of compass and straightedge constructions.</li>
<li><strong>STA (spacetime algebra):</strong> The algebra of Minkowski space, with spatial dimensions squaring to
values of the opposite sign of temporal dimensions.</li>
</ul>
<p dir="auto">Elements of all of the above algebras are constructible in this package.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Types</h2><a id="user-content-types" class="anchor" aria-label="Permalink: Types" href="#types"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package exports <code>AbstractCliffordNumber{Q,T}</code> and its subtypes, which describe the behavior of
multivectors with algebra <code>Q</code> and scalar type <code>T&lt;:Union{Real,Complex}</code>. This is a subtype of
<code>Number</code>, and therefore acts as a scalar for the purpose of broadcasting. For this reason, we
provide an <code>nblades</code> function separate from <code>Base.length</code> to count the number of blades represented
by a type.</p>
<p dir="auto">To index an <code>AbstractCliffordNumber</code>, we provide the <code>BitIndex{Q}</code> type, which allows for arbitrary
components to be indexed, and the <code>BitIndices{Q,C&lt;:AbstractCliffordNumber{Q}}</code> type, which provides
all valid indices of instances of <code>C</code> that are not constrained to be zero. Indexing with ordinary
integers is disallowed, but <code>Tuple(::AbstractCliffordNumber)</code> obtains the backing <code>Tuple</code>.</p>
<p dir="auto"><code>AbstractCliffordNumber{Q,T}</code> includes the following concrete subtypes:</p>
<ul dir="auto">
<li><code>CliffordNumber{Q,T,L}</code>, which represents the coefficients associated with all basis blades.</li>
<li><code>EvenCliffordNumber{Q,T,L}</code> and <code>OddCliffordNumber{Q,T,L}</code>, which represents multivectors with
only basis blades of even or odd grade being nonzero. These are especially important when dealing
with physically realizable Euclidean transformations (rotations and translations).</li>
<li><code>KVector{K,Q,T,L}</code>, which represents multivectors with only basis blades of grade <code>K</code> being
nonzero. This is especially useful for representing common vectors, bivectors, pseudovectors, etc.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Promotion and conversion</h2><a id="user-content-promotion-and-conversion" class="anchor" aria-label="Permalink: Promotion and conversion" href="#promotion-and-conversion"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The type promotion system is heavily leveraged to minimize the memory footprint needed to represent
the results of various operations. Promotion can convert the numeric types associated with two
<code>AbstractCliffordNumber{Q}</code> instances (for instance, the sum of <code>KVector{1,APS,Int}</code> and
<code>KVector{1,APS,Float64}</code> is <code>KVector{1,APS,Float64}</code>), but it can also leverage grade information to
promote to smaller types: the sum of <code>KVector{1,APS,Int}</code> and <code>KVector{3,APS,Int}</code> is an
<code>OddCliffordNumber{APS,Int}</code>, but the sum of <code>KVector{1,APS,Int}</code> and <code>KVector{2,APS,Int}</code> is a
<code>CliffordNumber{APS,Int}</code>.</p>
<p dir="auto">We provide the <code>scalar_promote</code> and <code>scalar_convert</code> functions to allow for promotion of the scalar
types backing an <code>AbstractCliffordNumber</code> without needlessly expanding the represented grades.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Indexing</h2><a id="user-content-indexing" class="anchor" aria-label="Permalink: Indexing" href="#indexing"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Although <code>AbstractCliffordNumber</code> instances are scalars, the <code>BitIndex{Q}</code> type can be used to
retrieve coefficients associated with specific basis blades. The full set of <code>BitIndex{Q}</code> types for
some <code>x::AbstractCliffordNumber</code> can be generated with <code>BitIndices(x)</code>, and this is a binary ordered
vector of <code>BitIndex{Q}</code> objects.</p>
<p dir="auto">Mathematical operations are defined generically by working with the <code>BitIndex{Q}</code> objects associated
with an <code>AbstractCliffordNumber{Q,T}</code>. Elementwise operations on each element of a <code>BitIndices</code>
instance returns a <code>TransformedBitIndices</code>, a wrapper which lazily associates a function with a
<code>BitIndices</code> object, and this can be used to implement grade dependent operations, such as
(anti)automorphisms.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Operations</h2><a id="user-content-operations" class="anchor" aria-label="Permalink: Operations" href="#operations"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The following mathematical operations are supported by this package:</p>
<ul dir="auto">
<li>Addition (<code>+</code>), subtraction and negation (<code>-</code>) between algebra elements, or between algebra
elements and scalars</li>
<li>Products of the Clifford algebra:
<ul dir="auto">
<li>The geometric product  (<code>*</code>)</li>
<li>The wedge product (<code>∧</code>) and regressive product (<code>∨</code>)</li>
<li>Left (<code>⨼</code>) and right (<code>⨽</code>) contractions</li>
<li>The dot product and the Hestenes dot product</li>
<li>The commutator product (<code>×</code>) and anticommutator product (<code>⨰</code>)</li>
</ul>
</li>
<li>Inverses for Clifford numbers which have them</li>
<li>Scalar left (<code>/</code>) and right (<code>\</code>) division, including rational division (<code>//</code>)</li>
<li>Efficient <code>muladd</code> operations involving scalars and multivectors</li>
<li>Involutions and duals
<ul dir="auto">
<li>The reverse (using <code>Base.adjoint</code>/<code>'</code> or <code>Base.reverse</code>),</li>
<li>Main involution (<code>grade_involution</code>)</li>
<li>Clifford conjugation (using <code>Base.conj</code>)</li>
<li>Left and right complements (<code>left_complement</code> and <code>right_complement</code>)</li>
</ul>
</li>
<li>The modulus and absolute value (with <code>abs2</code> and <code>abs</code>)</li>
<li>Exponentiation
<ul dir="auto">
<li>Efficiently raising multivectors to integer powers</li>
<li>Natural exponentials of multivectors</li>
</ul>
</li>
</ul>
<p dir="auto">Some of the names or implementations of various operations may change in the near future.</p>
<p dir="auto">Note that <code>AbstractCliffordNumber{Q,T}</code> is a scalar type, so dotted operators do not apply any
operations to each coefficient individually. However, they can be used to perform elementwise
operations on collections of Clifford numbers.</p>
