<p dir="auto"><code>SimipleCTypes.jl</code> is a zero-dependency Julia package that provides some simple definitions of C types, specifically:</p>
<ul dir="auto">
<li><code>CfuncPtr</code> for C function pointers</li>
<li><code>Carray</code> for fixed-size C arrays</li>
<li><code>Cunion</code> for C-style unions</li>
</ul>
<p dir="auto">It is mainly used in the type definitions of Julia bindings for C libraries.
All types are immutable so that they can have the same memory layout as in C.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>CfuncPtr</code> and <code>@cfunc</code></h2><a id="user-content-cfuncptr-and-cfunc" class="anchor" aria-label="Permalink: CfuncPtr and @cfunc" href="#cfuncptr-and-cfunc"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>CfuncPtr</code> can be used to replace <code>Ptr{Cvoid}</code> in <code>ccall</code> and struct definitions,
so that you can pass a function pointer around in a type-safe way.
It takes two type parameters, the return type and the argument types of the function.</p>
<div class="highlight highlight-source-c notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="struct foo {
    int (*f)(int, int);
};"><pre><span class="pl-k">struct</span> <span class="pl-smi">foo</span> {
    <span class="pl-smi">int</span> (<span class="pl-c1">*</span><span class="pl-c1">f</span>)(<span class="pl-smi">int</span>, <span class="pl-smi">int</span>);
};</pre></div>
<p dir="auto">can be defined in Julia as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="struct Foo
    f::CfuncPtr{Cint,Tuple{Cint,Cint}}
end"><pre><span class="pl-k">struct</span> Foo
    f<span class="pl-k">::</span><span class="pl-c1">CfuncPtr{Cint,Tuple{Cint,Cint}}</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">You can use <code>@cfunc</code> to create a <code>CfuncPtr</code> from a Julia function,
its usage is the same as <code>@cfunction</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="f(x) = 2x
fptr, _ = @cfunc(f, Cint, (Cint,))
fptr2, cf = @cfunc($f, Cint, (Cint,))"><pre><span class="pl-en">f</span>(x) <span class="pl-k">=</span> <span class="pl-c1">2</span>x
fptr, _ <span class="pl-k">=</span> <span class="pl-c1">@cfunc</span>(f, Cint, (Cint,))
fptr2, cf <span class="pl-k">=</span> <span class="pl-c1">@cfunc</span>(<span class="pl-k">$</span>f, Cint, (Cint,))</pre></div>
<p dir="auto">When using a clousure, you need to use <code>$</code> to interpolate the function into the macro,
and the second return value of <code>@cfunc</code> (<code>cf</code> in the example) should be referenced somewhere
to prevent the GC from collecting it.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>Carray</code> and <code>@Carray</code></h2><a id="user-content-carray-and-carray" class="anchor" aria-label="Permalink: Carray and @Carray" href="#carray-and-carray"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>Carray</code> is similar to <code>StaticArrays.SArray</code>, representing a fixed-size immutable array.
Usually you only need to use <code>@Carray</code> whenever you need a C array. For example,</p>
<div class="highlight highlight-source-c notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="int[3] a = {1,2,3};
struct bar {
    double x[2][4];
};"><pre><span class="pl-smi">int</span><span class="pl-s1"></span>[<span class="pl-c1">3</span>] <span class="pl-s1">a</span> <span class="pl-c1">=</span> {<span class="pl-c1">1</span>,<span class="pl-c1">2</span>,<span class="pl-c1">3</span>};
<span class="pl-k">struct</span> <span class="pl-smi">bar</span> {
    <span class="pl-smi">double</span> <span class="pl-c1">x</span>[<span class="pl-c1">2</span>][<span class="pl-c1">4</span>];
};</pre></div>
<p dir="auto">can be defined in Julia as:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="a = @Carray(Cint[1,2,3])
struct Bar
    x::@Carray{Cdouble,2,4}
end"><pre>a <span class="pl-k">=</span> <span class="pl-c1">@Carray</span>(Cint[<span class="pl-c1">1</span>,<span class="pl-c1">2</span>,<span class="pl-c1">3</span>])
<span class="pl-k">struct</span> Bar
    x<span class="pl-k">:</span>:<span class="pl-c1">@Carray</span>{Cdouble,<span class="pl-c1">2</span>,<span class="pl-c1">4</span>}
<span class="pl-k">end</span></pre></div>
<p dir="auto">Note that the array will be stored in row-major order, so when you pass a Julia array to <code>@Carray</code>, the dimension order is reversed.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto"><code>Cunion</code> and <code>@Cunion</code></h2><a id="user-content-cunion-and-cunion" class="anchor" aria-label="Permalink: Cunion and @Cunion" href="#cunion-and-cunion"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>Cunion</code> represents a C-style union. You need to use <code>@Cunion begin ... end</code> to declare a union type.
For example,</p>
<div class="highlight highlight-source-c notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="union Baz {
    union {
        uint64_t x;
        unsigned char y[8];
    } a;
    uint b[2];
} baz = { .a = { .x = 0x123456789abcdef0 } };"><pre><span class="pl-k">union</span> <span class="pl-smi">Baz</span> {
    <span class="pl-k">union</span> {
        <span class="pl-smi">uint64_t</span> <span class="pl-c1">x</span>;
        <span class="pl-smi">unsigned <span class="pl-smi">char</span></span> <span class="pl-c1">y</span>[<span class="pl-c1">8</span>];
    } <span class="pl-c1">a</span>;
    <span class="pl-smi">uint</span> <span class="pl-c1">b</span>[<span class="pl-c1">2</span>];
} <span class="pl-s1">baz</span> <span class="pl-c1">=</span> { .<span class="pl-c1">a</span> <span class="pl-c1">=</span> { .<span class="pl-c1">x</span> <span class="pl-c1">=</span> <span class="pl-c1">0x123456789abcdef0</span> } };</pre></div>
<p dir="auto">should be:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="const Baz = @Cunion begin
    a::@Cunion begin
        x::Cuint64
        y::@Carray{Cuchar,8}
    end
    b::Carray{Cuint,2}
end
baz = Baz(a=(; x=0x123456789abcdef0))"><pre><span class="pl-k">const</span> Baz <span class="pl-k">=</span> <span class="pl-c1">@Cunion</span> <span class="pl-k">begin</span>
    a<span class="pl-k">:</span>:<span class="pl-c1">@Cunion</span> <span class="pl-k">begin</span>
        x<span class="pl-k">::</span><span class="pl-c1">Cuint64</span>
        y<span class="pl-k">:</span>:<span class="pl-c1">@Carray</span>{Cuchar,<span class="pl-c1">8</span>}
    <span class="pl-k">end</span>
    b<span class="pl-k">::</span><span class="pl-c1">Carray{Cuint,2}</span>
<span class="pl-k">end</span>
baz <span class="pl-k">=</span> <span class="pl-c1">Baz</span>(a<span class="pl-k">=</span>(; x<span class="pl-k">=</span><span class="pl-c1">0x123456789abcdef0</span>))</pre></div>
<p dir="auto">And the usage of <code>baz</code> is almost the same as in C, except that <code>Cunion</code>s and <code>Carray</code>s are all immutable.</p>
