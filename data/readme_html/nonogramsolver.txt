<p dir="auto">This package provides a Julia module for formulating <a href="https://en.wikipedia.org/wiki/Nonogram" rel="nofollow">nonogram
puzzles</a> (a.k.a. Picross,
paint-by-number, and crucipixel), and for solving these puzzles using
integer linear programming (ILP) via
<a href="https://jump.dev/JuMP.jl/stable/" rel="nofollow">JuMP</a>. A <a href="https://doi.org/10.1109/TG.2020.3036687" rel="nofollow">new effective ILP
formulation</a> by Khan is
employed.</p>
<p dir="auto">Monochrome and multicolored puzzles are both supported. If a
puzzle has multiple solutions, then only one will be identified. If a
puzzle has no solutions, then this will be identified, and a fake solution will be returned with no cells colored.</p>
<p dir="auto">A simple example is included below; for further information and API details, please see the package's documentation linked above.</p>
<p dir="auto">If you make use of this implementation in your own work, please cite
the accompanying article:</p>
<blockquote>
<p dir="auto">Kamil A. Khan, Solving nonograms using integer programming without
coloring, <em>IEEE Transactions on Games</em>, 14(1): 56-63, 2022.
doi:<a href="https://doi.org/10.1109/TG.2020.3036687" rel="nofollow">10.1109/TG.2020.3036687</a></p>
</blockquote>

<p dir="auto">The goal of this puzzle is to color certain cells in a rectangular grid,
in a manner that is consistent with clues pertaining to each row and each column. Each
row's clues include a number for each block of contiguous colored
cells in that row. The numerical value in this clue indicates how many cells
are in the corresponding contiguous block. Columns' clues are analogous.</p>
<p dir="auto">For example, the following puzzle instance:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/examplePrompt.jpg"><img src="docs/src/examplePrompt.jpg" alt="Puzzle prompt" style="max-width: 100%;"></a></p>
<p dir="auto">has the unique solution:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/exampleSolution.jpg"><img src="docs/src/exampleSolution.jpg" alt="Puzzle solution" style="max-width: 100%;"></a></p>
<p dir="auto">While "real-world" instances are often deliberately designed to be
solvable by hand, this puzzle in general is NP-complete.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Example</h2><a id="user-content-example" class="anchor" aria-label="Permalink: Example" href="#example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">With the package installed, we may solve the above example problem as
follows in Julia. For more details, refer to the API documentation.</p>
<ol dir="auto">
<li>
<p dir="auto">Load the package's module:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using NonogramSolver"><pre><span class="pl-k">using</span> NonogramSolver</pre></div>
</li>
<li>
<p dir="auto">Enter the row clues as a <code>Vector{Vector{Int}}</code>, and the column
clues similarly. Note that an uncolored row (or column), with no
numerical clues at all, is entered as <code>Int[]</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="rowClues = [[1,1], [1,1], Int[], [1,2], [3]]
colClues = [[1], [2,1], [1], [2,2], [1]]"><pre>rowClues <span class="pl-k">=</span> [[<span class="pl-c1">1</span>,<span class="pl-c1">1</span>], [<span class="pl-c1">1</span>,<span class="pl-c1">1</span>], Int[], [<span class="pl-c1">1</span>,<span class="pl-c1">2</span>], [<span class="pl-c1">3</span>]]
colClues <span class="pl-k">=</span> [[<span class="pl-c1">1</span>], [<span class="pl-c1">2</span>,<span class="pl-c1">1</span>], [<span class="pl-c1">1</span>], [<span class="pl-c1">2</span>,<span class="pl-c1">2</span>], [<span class="pl-c1">1</span>]]</pre></div>
</li>
<li>
<p dir="auto">Construct a <code>Puzzle</code> object to hold the puzzle's formulation:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="p = Puzzle(rowClues, colClues)"><pre>p <span class="pl-k">=</span> <span class="pl-c1">Puzzle</span>(rowClues, colClues)</pre></div>
</li>
<li>
<p dir="auto">Use JuMP to solve this puzzle as an integer linear program, using
the freely available solver GLPK by default.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="solution = solve_puzzle(p; verbosity=0)"><pre>solution <span class="pl-k">=</span> <span class="pl-c1">solve_puzzle</span>(p; verbosity<span class="pl-k">=</span><span class="pl-c1">0</span>)</pre></div>
<p dir="auto">You can customize the
choice of solver and its options. Without <code>verbosity=0</code>, JuMP's
solution summary would be printed as well.</p>
</li>
<li>
<p dir="auto">If the previous step was carried out in Julia's REPL, then the
solution has already been displayed using colored-square emojis. Otherwise, retrieve the
solution in one of three ways:</p>
<ul dir="auto">
<li>
<p dir="auto">displayed to the REPL/terminal, via:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@show solution"><pre><span class="pl-c1">@show</span> solution</pre></div>
</li>
<li>
<p dir="auto">as a <code>String</code> containing the printed solution, with:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="stringOutput = repr(solution)"><pre>stringOutput <span class="pl-k">=</span> <span class="pl-c1">repr</span>(solution)</pre></div>
</li>
<li>
<p dir="auto">as a <code>Matrix</code> of <code>0</code>s and <code>1</code>s, with:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="matrixOutput = solution.z"><pre>matrixOutput <span class="pl-k">=</span> solution<span class="pl-k">.</span>z</pre></div>
</li>
</ul>
</li>
</ol>
