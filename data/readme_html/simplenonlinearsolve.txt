<p dir="auto">Fast implementations of root finding algorithms in Julia that satisfy the SciML common interface.
SimpleNonlinearSolve.jl focuses on low-dependency implementations of very fast methods for
very small and simple problems. For the full set of solvers, see
<a href="https://github.com/SciML/NonlinearSolve.jl">NonlinearSolve.jl</a>, of which
SimpleNonlinearSolve.jl is just one solver set.</p>
<p dir="auto">For information on using the package,
<a href="https://docs.sciml.ai/NonlinearSolve/stable/" rel="nofollow">see the stable documentation</a>. Use the
<a href="https://docs.sciml.ai/NonlinearSolve/dev/" rel="nofollow">in-development documentation</a> for the version of
the documentation which contains the unreleased features.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Breaking Changes in v1.0.0</h2><a id="user-content-breaking-changes-in-v100" class="anchor" aria-label="Permalink: Breaking Changes in v1.0.0" href="#breaking-changes-in-v100"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Batched solvers have been removed in favor of <code>BatchedArrays.jl</code>. Stay tuned for detailed
tutorials on how to use <code>BatchedArrays.jl</code> with <code>NonlinearSolve</code> &amp; <code>SimpleNonlinearSolve</code>
solvers.</li>
<li>The old style of specifying autodiff with <code>chunksize</code>, <code>standardtag</code>, etc. has been
deprecated in favor of directly specifying the autodiff type, like <code>AutoForwardDiff</code>.</li>
<li><code>Broyden</code> and <code>Klement</code> have been renamed to <code>SimpleBroyden</code> and <code>SimpleKlement</code> to
avoid conflicts with <code>NonlinearSolve.jl</code>'s <code>GeneralBroyden</code> and <code>GeneralKlement</code>, which
will be renamed to <code>Broyden</code> and <code>Klement</code> in the future.</li>
<li><code>LBroyden</code> has been renamed to <code>SimpleLimitedMemoryBroyden</code> to make it consistent with
<code>NonlinearSolve.jl</code>'s <code>LimitedMemoryBroyden</code>.</li>
</ul>
