<p dir="auto">WatchJuliaBurn aims at destroying the look of your code by adding emojis like 😄 and kaomojis like c╯°□°ↄ╯ instead of your favorite Julia functions.
For a serious use of unicode characters see also <a href="https://gitlab.com/ExpandingMan/Ueauty.jl" rel="nofollow">Ueauty.jl</a></p>

<p dir="auto">Don't hesitate to add your worst creations via PR. All you need to do is to add the function and emoji to the <code>😃📖</code> internal <code>📖</code> in <code>src/📖.jl</code>. Don't touch the <code>README</code>!
It will be automatically generated after your PR is merged. Also tests are optional since tests are for losers!</p>

<p dir="auto">You can use the <code>emojify</code> function to recursively emojify all the files in a given path. <code>emojify</code> will replace all functions for which an alias is known
by the corresponding emoji (a random one is picked every ⏲️ if multiple options are possible).
For example:</p>
