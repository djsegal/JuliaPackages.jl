<p dir="auto">Version 0.8.3 also introduced the virtual codec <code>ZstdFrameCompressor</code> which stores the decompressed content size in the frame header. Currently, <code>ZstdFrameCompressor</code> is an alternate constructor for <code>ZstdCompressor</code>, but that is an implementation detail which should not be relied upon.</p>
<p dir="auto">See docstrings and <a href="https://github.com/JuliaIO/TranscodingStreams.jl">TranscodingStreams.jl</a> for details.</p>
