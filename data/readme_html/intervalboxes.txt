<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Multi-dimensional interval boxes in Julia</h2><a id="user-content-multi-dimensional-interval-boxes-in-julia" class="anchor" aria-label="Permalink: Multi-dimensional interval boxes in Julia" href="#multi-dimensional-interval-boxes-in-julia"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An <strong>interval box</strong> is a Cartesian product of <code>Interval</code>s (or <code>BareInterval</code>s), as defined in <a href="https://github.com/JuliaIntervals/IntervalArithmetic.jl">IntervalArithmetic.jl</a>.
An interval box of dimension <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2788abf256305a024f62f2a1ac4ec94b">$n$</math-renderer> thus represents an axis-aligned <em>set</em> in Euclidean space <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="2788abf256305a024f62f2a1ac4ec94b">$\mathbb{R}^n$</math-renderer>.</p>

<p dir="auto">We treat <code>IntervalBox</code>es as sets as much as possible, and extend Julia's set operations
to act on these objects:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; X ⊓ Y

<p dir="auto">Note that the <code>⊔</code> operator produces the <em>interval hull</em> of the union
(i.e. the smallest interval box that contains the union).</p>

(These set operations are deliberately not defined in <code>IntervalArithmetic.jl</code>.)</p>

<p dir="auto">Interval arithmetic allows us to compute an enclosure (in general, an over-estimate)
of the range of a multi-dimensional function. E.g.:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; f((x, y)) = x + y;

julia&gt; f(X)
[5.0, 9.0]"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-en">f</span>((x, y)) <span class="pl-k">=</span> x <span class="pl-k">+</span> y;

julia<span class="pl-k">&gt;</span> <span class="pl-c1">f</span>(X)
[<span class="pl-c1">5.0</span>, <span class="pl-c1">9.0</span>]</pre></div>
<p dir="auto">Note that in order to use numbers in functions like this, the numbers must be wrapped
in <code>ExactReal</code> to specify that they are exact representations.
Alternatively the complete definition can be annotated with <code>@exact</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; g1((x, y)) = ExactReal(2) * x + ExactReal(3) * y;

julia&gt; g1(X)

julia&gt; @exact g2((x, y)) = 2x + 3y;

julia&gt; g2(X)
[14.0, 24.0]_com"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-en">g1</span>((x, y)) <span class="pl-k">=</span> <span class="pl-c1">ExactReal</span>(<span class="pl-c1">2</span>) <span class="pl-k">*</span> x <span class="pl-k">+</span> <span class="pl-c1">ExactReal</span>(<span class="pl-c1">3</span>) <span class="pl-k">*</span> y;

julia<span class="pl-k">&gt;</span> <span class="pl-c1">g1</span>(X)

julia<span class="pl-k">&gt;</span> <span class="pl-c1">@exact</span> <span class="pl-en">g2</span>((x, y)) <span class="pl-k">=</span> <span class="pl-c1">2</span>x <span class="pl-k">+</span> <span class="pl-c1">3</span>y;

julia<span class="pl-k">&gt;</span> <span class="pl-c1">g2</span>(X)
