<p dir="auto">The usage of the package is extremely simple.
The user can naviagate on <a href="http://airfoiltools.com/" rel="nofollow">airfoiltools</a> and find the profile of interest and copy the url.
The function <code>from_url_to_csv</code> locally creates a <code>.csv</code> file.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using AirfoilGmsh
url = &quot;https://m-selig.ae.illinois.edu/ads/coord/c141a.dat&quot;
filename = from_url_to_csv(url)"><pre><span class="pl-k">using</span> AirfoilGmsh
url <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>https://m-selig.ae.illinois.edu/ads/coord/c141a.dat<span class="pl-pds">"</span></span>
filename <span class="pl-k">=</span> <span class="pl-c1">from_url_to_csv</span>(url)</pre></div>
<p dir="auto">It is possible to skip the previous step is you already have the <code>.csv</code> file.
The software tries to re-order the sequence of points in anti-clockwise order and starting from the top point at the trailing edge. If you experience any trouble, it is better to manually format you file of points following this order.
Finally you can easily create the <code>.geo</code> file.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="create_geofile(filename)

<p dir="auto">Please see the <a href="https://carlodev.github.io/AirfoilGmsh.jl/" rel="nofollow">Documentation</a> for more detailed examples and description of the package features.
Finally, the <code>.geo</code> can be opened with <a href="https://gmsh.info/" rel="nofollow">GMSH</a>, an open source mesh generator.</p>

<li>In 3D case GMSH can have problems in re-creating the periodic mapping. It happens when the refinement is too high, lowering the <code>P_refinement</code> parameters can solve the problem (but keeping always &gt;= 1)</li>
<li>When using custom csv file is better to start from the top point of the leading edge in anti-clockwise sense, passing from the top side, to the leading edge and then the lower side (XFOIL format).</li>
</ul>
