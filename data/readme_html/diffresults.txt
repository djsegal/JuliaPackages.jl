<p dir="auto">Many differentiation techniques can calculate primal values and multiple orders of
derivatives simultaneously. In other words, there are techniques for computing <code>f(x)</code>,
<code>∇f(x)</code> and <code>H(f(x))</code> in one fell swoop!</p>
<p dir="auto">For this purpose, DiffResults provides the <code>DiffResult</code> type, which can be passed
to in-place differentiation methods instead of an output buffer. The method
then loads all computed results into the given <code>DiffResult</code>, which the user
can then query afterwards.</p>
