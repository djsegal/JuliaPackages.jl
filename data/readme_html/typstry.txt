<p dir="auto">Typstry.jl is the interface to convert the computational power of Julia into beautifully formatted Typst documents.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">What is Typst?</h3><a id="user-content-what-is-typst" class="anchor" aria-label="Permalink: What is Typst?" href="#what-is-typst"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Typst is an open-source and relatively new typesetting system (written in Rust 🦀🚀),
<a href="https://typst.app/about" rel="nofollow">designed to improve upon the performance and usability of LaTeX</a>.
See also the Typst <a href="https://github.com/typst/typst">repository</a> and
<a href="https://typst.app/docs" rel="nofollow">documentation</a> for examples and how to get started.</p>
