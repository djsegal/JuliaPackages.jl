<p dir="auto">This guide assumes that you have already set up PromptingTools.jl! At the very least, you need to have <code>OPENAI_API_KEY</code> set in your environment.</p>
<ol dir="auto">
<li>Clone the repository</li>
<li>Run the following command to install the necessary dependencies:</li>
</ol>

<p dir="auto">For the purists: simply run <code>julia --project -t auto main.jl</code> in your terminal (once installed)!</p>
<p dir="auto">How to start? Type <code>Say hi!</code> in the question box on the Chat tab and click Submit (or press CTRL+ENTER).</p>

<p dir="auto">Imagine you're walking your dog and suddenly come up with a brilliant idea for a code snippet you need urgently.</p>
<p dir="auto">Using ChatGPT on your phone is feasible, but slow and cumbersome—typing out or dictating a precise prompt can be a real hassle, not to mention you can't close the app or run the code to see if it works.</p>
<p dir="auto">Enter <strong>ProToPortal</strong>: Select the JuliaExpertAsk template, use speech-to-text on your phone to dictate your needs, enable auto-fixing with Monte-Carlo Tree Search (<code>airetry!</code>), and watch as your phone processes 6 iterations of the code before ChatGPT generates its first response!</p>
<p dir="auto">For a preview, see the video: <code>docs/src/videos/screen-capture-code-fixing.mp4</code></p>

<ul dir="auto">
<li><strong>Accessible Anywhere</strong>: Use it on any device—laptop, phone, etc.—with numerous prompt templates designed to save your keystrokes.</li>
<li><strong>Code Evaluation and Fixing</strong>: The only GUI that lets you evaluate and fix your Julia code directly, saving you from the hassle of copy-pasting.</li>
<li><strong>Automatic Replies</strong>: Automate standard replies to refine responses, either through fixed messages or critic templates mimicking a separate agent.</li>
</ul>

<ul dir="auto">
<li>
<p dir="auto"><strong>Advanced Settings</strong>:</p>
<ul dir="auto">
<li>Rewind conversations by deleting messages you dislike or to restart the conversation.</li>
<li>Control creativity with model temperature settings.</li>
<li>Enable code evaluation (<code>AICode</code>) and auto-fixing using advanced algorithms like <code>airetry!</code> and Monte-Carlo Tree search.</li>
<li>Automate replies with pre-configured templates (~critic agents) or custom messages.</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Templates</strong>:</p>
<ul dir="auto">
<li>Begin conversations from a template, opening new input fields interpolated into text variables.</li>
<li>Add your templates by placing them in the <code>templates/</code> folder for automatic loading.</li>
</ul>
</li>
<li>
<p dir="auto"><strong>Chat</strong>:</p>
<ul dir="auto">
<li>Submit your question by clicking "Submit" or via CTRL+ENTER.</li>
<li>Edit any message in the conversation (simply click on it and make a change).</li>
<li>Delete unwanted messages with ease (accidental deletions made difficult by hiding the button in the "Advanced Settings").</li>
<li>Copy the text of any message (see top right corner icon).</li>
<li>Start "new chat" with conversations automatically saved both on disk and in history.</li>
</ul>
</li>
</ul>
