<p dir="auto">The purpose of this package is to detect topological classification of a
triangular surface mesh. For instance, the orientation of the triangles can be
unified across the surface mesh. The topological faces can be identified.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="sample_normals50.png"><img src="sample_normals50.png" alt="Sample of unified normals" style="max-width: 100%;"></a>
<a target="_blank" rel="noopener noreferrer" href="sample_topology50.png"><img src="sample_topology50.png" alt="Sample of detected topological faces" style="max-width: 100%;"></a></p>

<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">When used with MeshCore</h3><a id="user-content-when-used-with-meshcore" class="anchor" aria-label="Permalink: When used with MeshCore" href="#when-used-with-meshcore"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Given an incidence relation, <code>t2v</code> (triangles to vertices),
we can produce an oriented surface:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="orientedt2v, orientable = orient_surface_mesh(t2v)"><pre class="notranslate"><code>orientedt2v, orientable = orient_surface_mesh(t2v)
</code></pre></div>
<p dir="auto">And, when the triangles tile a single surface, we can check that all the triangles have been classified on surface 1:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="@test length(unique(attribute(orientedt2v.left, &quot;surfid&quot;))) == 1"><pre class="notranslate"><code>@test length(unique(attribute(orientedt2v.left, "surfid"))) == 1
</code></pre></div>
<p dir="auto">Given an incidence relation, <code>t2v</code> (triangles to vertices),
we can classify the triangles on oriented surfaces:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="t2v = make_topo_faces(t2v)"><pre class="notranslate"><code>t2v = make_topo_faces(t2v)
</code></pre></div>
<p dir="auto">In this instance, we would expect the triangles to represent four distinct topological surfaces. We can check the <code>"tfid"</code> attribute of the incidence relation <code>t2v</code>:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="@test length(unique(attribute(t2v.left, &quot;tfid&quot;))) == 4"><pre class="notranslate"><code>@test length(unique(attribute(t2v.left, "tfid"))) == 4
</code></pre></div>
<p dir="auto">The topological classification may be visualized with</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="t2v = make_topo_faces(t2v)
vtkwrite(&quot;mt008-classified&quot;, t2v, [(name = &quot;tfid&quot;, )])"><pre class="notranslate"><code>t2v = make_topo_faces(t2v)
vtkwrite("mt008-classified", t2v, [(name = "tfid", )])
</code></pre></div>
<p dir="auto">The topological surfaces will be labeled with the attribute <code>"tfid"</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">When used with FinEtools</h3><a id="user-content-when-used-with-finetools" class="anchor" aria-label="Permalink: When used with FinEtools" href="#when-used-with-finetools"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The boundary triangles of the triangulated surface of a solid part may be classified into topological faces with:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="fens, bfes = make_topo_faces(fens, bfes)"><pre class="notranslate"><code>fens, bfes = make_topo_faces(fens, bfes)
</code></pre></div>
<p dir="auto">Here <code>bfes.label</code> records the numbers of the topological surfaces.</p>
<p dir="auto">The classification may be visualized with</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="VTK.vtkexportmesh(&quot;mt013.vtk&quot;, connasarray(bfes), fens.xyz, VTK.T3; scalars=[(&quot;topological_face&quot;, bfes.label)]);"><pre class="notranslate"><code>VTK.vtkexportmesh("mt013.vtk", connasarray(bfes), fens.xyz, VTK.T3; scalars=[("topological_face", bfes.label)]);
</code></pre></div>
<p dir="auto">The library may be also used to create partition of the topological faces into individual patches.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="surfids, partitionids = create_partitions(fens, fes, 50)"><pre class="notranslate"><code>surfids, partitionids = create_partitions(fens, fes, 50)
</code></pre></div>
<p dir="auto">The classification into topological faces and the partitioning may then be viewed with</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="VTK.vtkexportmesh(&quot;mt016_part.vtk&quot;, connasarray(fes), fens.xyz, VTK.T3; scalars=[(&quot;topological_face&quot;, surfids), (&quot;partitioning&quot;, partitionids)]);"><pre class="notranslate"><code>VTK.vtkexportmesh("mt016_part.vtk", connasarray(fes), fens.xyz, VTK.T3; scalars=[("topological_face", surfids), ("partitioning", partitionids)]);
</code></pre></div>

<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="    orient_surface_mesh(t2v)

Orient surface mesh.

Return
- `orientedt2v`: oriented incidence relation
- `orientable`: Can the surface mesh be oriented? Bool flag.
    This would be false for a Mobius strip, for instance.

This is a purely topological operation. Creases in the surface are not
recognized as edges. The operation proceeds by flooding the surface across
manifold edges, stopping at sheet or non-manifold edges.

The incidence relation `orientedt2v` includes an attribute for each triangle
that provides the surface id to which the triangle belongs
(`orientedt2v.left.attributes[&quot;surfid&quot;]`)."><pre class="notranslate"><code>    orient_surface_mesh(t2v)

Orient surface mesh.

Return
- `orientedt2v`: oriented incidence relation
- `orientable`: Can the surface mesh be oriented? Bool flag.
    This would be false for a Mobius strip, for instance.

This is a purely topological operation. Creases in the surface are not
recognized as edges. The operation proceeds by flooding the surface across
manifold edges, stopping at sheet or non-manifold edges.

The incidence relation `orientedt2v` includes an attribute for each triangle
that provides the surface id to which the triangle belongs
(`orientedt2v.left.attributes["surfid"]`).
</code></pre></div>
