<p dir="auto">Implementation of Smooth Local Projections (SLP) based on <a href="https://www.mitpressjournals.org/doi/abs/10.1162/rest_a_00778" rel="nofollow">Barnichon and Brownlees (2019)</a> - "Impulse Response Estimation by Smooth Local Projections." Original method of Local Projections is first introduced by <a href="https://www.aeaweb.org/articles?id=10.1257/0002828053828518" rel="nofollow">Òscar Jordà (2005)</a></p>
<p dir="auto">The code was translated from MATLAB code published from the replication file made available by <a href="https://github.com/ctbrownlees/MATLAB-package-lproj">C. Brownlees</a>.</p>

<p dir="auto">Each stripped sub/co-routine is a plot of impulse response functions, (1 - blue line) local projection using <a href="https://www.aeaweb.org/articles?id=10.1257/0002828053828518" rel="nofollow">Òscar Jordà (2005)</a>; (2 - purple line) smoothed local projection using (λ = 100, for example presented below); (3 - red lines) smoothed local projection using optimal λ estimated using cross-validation method as shown in <a href="https://www.mitpressjournals.org/doi/abs/10.1162/rest_a_00778" rel="nofollow">Barnichon and Brownlees (2019)</a> (red solid line is a point estimate, dashed red lines are estimated 90% confidence set).</p>
<p dir="auto">Following example is a replication of <a href="https://www.mitpressjournals.org/doi/abs/10.1162/rest_a_00778" rel="nofollow">Barnichon and Brownlees (2019)</a> estimation of the impulse response of Gross Domestic Product (GDP) to identified positive monetary policy shock.</p>
