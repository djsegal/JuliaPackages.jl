<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Convert between WGS84 coordinates and British National Grid references</h2><a id="user-content-convert-between-wgs84-coordinates-and-british-national-grid-references" class="anchor" aria-label="Permalink: Convert between WGS84 coordinates and British National Grid references" href="#convert-between-wgs84-coordinates-and-british-national-grid-references"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><code>BritishNationalGrid</code> provides the type <code>BNGPoint</code> to convert between
longitude-latitude and grid references in the <a href="https://en.wikipedia.org/wiki/Ordnance_Survey_National_Grid" rel="nofollow">British National Grid system</a>.
It assumes your points are geodetic longitude and latitude in decimal
degrees using the WGS84 ellipsoid.</p>
<p dir="auto">This package is reliable to within a metre or so.  Advanced users needing
greater accuracy will probably already know how to convert between different
systems, but any additions to the package that remain easy to use will
be welcome.</p>

<p dir="auto">The <code>lonlat2bng</code> and <code>bng2lonlat</code> functions convert directly between the
two coordinate systems, but <strong>do not check that points are actually in the
National Grid</strong>; therefore use these functions with caution.</p>
