<p dir="auto">A <a href="http://julialang.org" rel="nofollow">Julia</a> package to bound the range of real-valued functions. The following article showcases the basic functionality, highlighting some of the key design choices:</p>
<blockquote>
<p dir="auto">Luca Ferranti, Marcelo Forets, and Christian Schilling. <em>RangeEnclosures.jl: A framework to bound function ranges</em> <a href="https://doi.org/10.21105/jcon.00122" rel="nofollow">Proceedings of the JuliaCon Conferences</a> (2024).</p>
</blockquote>
<p dir="auto">See <a href="#how-to-cite">below</a> for how to cite it.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Quickstart</h2><a id="user-content-quickstart" class="anchor" aria-label="Permalink: Quickstart" href="#quickstart"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">An <em>enclosure</em> of the <a href="https://en.wikipedia.org/wiki/Range_of_a_function" rel="nofollow">range</a>
of a function <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="09ad3e02daab2c554990e96698ffbeec">$f : D \subset \mathbb{R}^n \to \mathbb{R}$</math-renderer> is an interval that
contains the global minimum and maximum of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="09ad3e02daab2c554990e96698ffbeec">$f$</math-renderer> over its domain <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="09ad3e02daab2c554990e96698ffbeec">$D$</math-renderer>.
<code>RangeEnclosures</code> offers an API to easily bound the range of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="09ad3e02daab2c554990e96698ffbeec">$f$</math-renderer> with different
algorithms. Here is a quick example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; f(x) = -x^3/6 + 5x

julia&gt; dom = 1 .. 4
[1, 4]

julia&gt; enclose(f, dom, BranchAndBoundEnclosure())
[4.83333, 10.5709]"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-en">f</span>(x) <span class="pl-k">=</span> <span class="pl-k">-</span>x<span class="pl-k">^</span><span class="pl-c1">3</span><span class="pl-k">/</span><span class="pl-c1">6</span> <span class="pl-k">+</span> <span class="pl-c1">5</span>x

julia<span class="pl-k">&gt;</span> dom <span class="pl-k">=</span> <span class="pl-c1">1</span> <span class="pl-k">..</span> <span class="pl-c1">4</span>
[<span class="pl-c1">1</span>, <span class="pl-c1">4</span>]

julia<span class="pl-k">&gt;</span> <span class="pl-c1">enclose</span>(f, dom, <span class="pl-c1">BranchAndBoundEnclosure</span>())
[<span class="pl-c1">4.83333</span>, <span class="pl-c1">10.5709</span>]</pre></div>
