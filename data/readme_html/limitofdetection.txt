<p dir="auto">The limit of detection (LoD) is the lowest value of a variable <code>x</code> at which an event can
be detected with a given sensitivity. For example, a smoke detector that triggers at a
concentration of 15,000 particles per cm^3 with 95% probability has a 95%-LoD of 15,000.</p>
<p dir="auto">This package uses a probit or logit model from the <a href="https://github.com/JuliaStats/GLM.jl">GLM</a> package to estimate the LoD, taking as input a vector
containing the values of the variable considered (e.g. smoke concentration) and the corresponding boolean detection status (<code>true</code> = detected).
In addition it performs sampling using <a href="https://github.com/mvihola/AdaptiveMCMC.jl">AdaptiveMCMC</a> to provide error estimates on the LoD, and
a plot recipee is provided to visualize the results.</p>
