<p dir="auto"><code>MatrixCorrectionTools</code> is a lightweight package that offers a straightforward function called <code>correction!</code>.
This function is designed to correct specific properties of a matrix using predefined strategies.</p>
<p dir="auto">For instance, if a matrix contains zero diagonal entries, this package provides the means to replace (correct)
them using either fixed predefined values or a more advanced algorithm based on SVD decomposition.</p>
<p dir="auto">To learn more about the available correction strategies and see practical examples, please refer to the <a href="https://reactivebayes.github.io/MatrixCorrectionTools.jl/stable/" rel="nofollow">documentation</a>.</p>
