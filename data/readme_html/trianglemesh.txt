<p dir="auto">To build TriangleMesh you need the Visual Studio Community Edition 2017 which you can get <a href="https://www.techspot.com/downloads/6278-visual-studio.html" rel="nofollow">here</a>. It is for free and easy to install.</p>
<p dir="auto">You can also use a newer version of Visual Studio (and at any rate it is only important that you have the build tools installed) but then you will have to modify the environment variable in the 'compile.bat' script in the 'deps/src/' directory:</p>
<blockquote>
<p dir="auto">set VS150COMNTOOLS=C:\Program Files (x86)\Microsoft Visual Studio\2017\Community\Common7\Tools\</p>
</blockquote>
<p dir="auto">for example becomes</p>
<blockquote>
<p dir="auto">set VS150COMNTOOLS=C:\Program Files (x86)\Microsoft Visual Studio\2019\Community\Common7\Tools\</p>
</blockquote>
