<p dir="auto">Module for parsing and processing various types of input files used in geo-energy reservoir simulation (geothermal, carbon storage, gas storage, oil and gas recovery).</p>
<p dir="auto">Currently contains two main features:</p>
<ul dir="auto">
<li>Parser for .DATA reservoir simulation cases. The format originated with the Eclipse reservoir simulator produced by SLB and is now used by many reservoir simulators. The most useful publicly available description of one such dialect is found in the <a href="https://opm-project.org/?page_id=955" rel="nofollow">OPM Flow manual</a>.</li>
<li>A corner-point grid processor that converts parsed GRDECL files into unstructured meshes that handles general faults through the unstructured mesh from <a href="https://github.com/sintefmath/Jutul.jl">Jutul.jl</a>.</li>
</ul>
<p dir="auto">Here is an example mesh parsed from the <a href="https://doi.org/10.1007/s10596-020-10003-4" rel="nofollow">OLYMPUS Optimization Benchmark Challenge</a>:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="docs/src/assets/olympus_small.gif"><img src="docs/src/assets/olympus_small.gif" alt="image" data-animated-image="" style="max-width: 100%;"></a></p>
<p dir="auto">The supported file formats contain a great number of possible keywords. Not all keywords are supported. For keywords with limited support, a warning will be emitted. Contributions for additional keywords or other relevant input formats are welcome. If you have an example that you'd like to get working, please post it under the <a href="https://github.com/sintefmath/GeoEnergyIO.jl/issues">issues tab</a>. GeoEnergyIO.jl originated as a part of the Julia reservoir simulation package <a href="https://github.com/sintefmath/JutulDarcy.jl">JutulDarcy.jl</a> where it enables reservoir simulation of simulation cases read from input files.</p>

<p dir="auto">Once the module is installed you can read a <code>.DATA</code> file with all include files:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using GeoEnergyIO

<p dir="auto">Units will automatically be converted to strict SI by default. If you want</p>
<p dir="auto">You can also read <code>.GRDECL</code> files that contain a specification of a corner point grid:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="grdecl = parse_grdecl_file(&quot;MY_GRID.GRDECL&quot;)"><pre>grdecl <span class="pl-k">=</span> <span class="pl-c1">parse_grdecl_file</span>(<span class="pl-s"><span class="pl-pds">"</span>MY_GRID.GRDECL<span class="pl-pds">"</span></span>)</pre></div>

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="g = mesh_from_grid_section(grdecl)"><pre>g <span class="pl-k">=</span> <span class="pl-c1">mesh_from_grid_section</span>(grdecl)</pre></div>
