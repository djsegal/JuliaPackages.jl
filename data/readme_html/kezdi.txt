<p dir="auto">Kezdi.jl is a Julia package that provides a Stata-like interface for data manipulation and analysis. It is designed to be easy to use for Stata users who are transitioning to Julia.<sup><a href="#user-content-fn-stata-c7af99144c7e3ddeb91f9e02e12d3511" id="user-content-fnref-stata-c7af99144c7e3ddeb91f9e02e12d3511" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup></p>
<p dir="auto">It imports and reexports <a href="https://csv.juliadata.org/stable/" rel="nofollow">CSV</a>, <a href="https://dataframes.juliadata.org/stable/" rel="nofollow">DataFrames</a>, <a href="https://fixedeffectmodelsjl.readthedocs.io/en/latest/" rel="nofollow">FixedEffectModels</a>, <a href="https://github.com/nalimilan/FreqTables.jl">FreqTables</a>, <a href="https://github.com/piever/ReadStatTables.jl">ReadStatTables</a>, <a href="https://docs.julialang.org/en/v1/stdlib/Statistics/" rel="nofollow">Statistics</a>, and <a href="https://juliastats.org/StatsBase.jl/stable/" rel="nofollow">StatsBase</a>. These packages are not covered in this documentation, but you can find more information by following the links.</p>

<p dir="auto">To install the package, run the following command in Julia's REPL:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg; Pkg.add(&quot;Kezdi&quot;)"><pre><span class="pl-k">using</span> Pkg; Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>Kezdi<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">Every Kezdi.jl command is a macro that begins with <code>@</code>. These commands operate on a global <code>DataFrame</code> that is set using the <code>setdf</code> function. Alternatively, commands can be executed within a <code>@with</code> block that sets the <code>DataFrame</code> for the duration of the block.</p>

    <span class="pl-k">return</span> <span class="pl-c1">exp</span>(<span class="pl-c1">sum</span>(<span class="pl-c1">log</span>.(x)) <span class="pl-k">/</span> n)

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Differences to standard Julia and DataFrames syntax</h2><a id="user-content-differences-to-standard-julia-and-dataframes-syntax" class="anchor" aria-label="Permalink: Differences to standard Julia and DataFrames syntax" href="#differences-to-standard-julia-and-dataframes-syntax"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To maximize convenience for Stata users, Kezdi.jl has a number of differences to standard Julia and DataFrames syntax.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Everything is a macro</h3><a id="user-content-everything-is-a-macro" class="anchor" aria-label="Permalink: Everything is a macro" href="#everything-is-a-macro"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">While there are a few convenience functions, most Kezdi.jl commands are macros that begin with <code>@</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@tabulate Gear"><pre><span class="pl-c1">@tabulate</span> Gear</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Comma is used for options</h3><a id="user-content-comma-is-used-for-options" class="anchor" aria-label="Permalink: Comma is used for options" href="#comma-is-used-for-options"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Due to this non-standard syntax, Kezdi.jl uses the comma to separate options.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@regress log(MPG) log(Horsepower), robust"><pre><span class="pl-c1">@regress</span> <span class="pl-c1">log</span>(MPG) <span class="pl-c1">log</span>(Horsepower), robust</pre></div>
<p dir="auto">Here <code>log(MPG)</code> and <code>log(Horsepower)</code> are the dependent and independent variables, respectively, and <code>robust</code> is an option. Options may also have arguments, like</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@regress log(MPG) log(Horsepower), cluster(Cylinders)"><pre><span class="pl-c1">@regress</span> <span class="pl-c1">log</span>(MPG) <span class="pl-c1">log</span>(Horsepower), <span class="pl-c1">cluster</span>(Cylinders)</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Automatic variable name substitution</h3><a id="user-content-automatic-variable-name-substitution" class="anchor" aria-label="Permalink: Automatic variable name substitution" href="#automatic-variable-name-substitution"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Column names of the data frame can be used directly in the commands without the need to prefix them with the data frame name or using a Symbol.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@generate logHP = log(Horsepower)"><pre><span class="pl-c1">@generate</span> logHP <span class="pl-k">=</span> <span class="pl-c1">log</span>(Horsepower)</pre></div>
<blockquote>
<p dir="auto">Other data manipulation packages in Julia require column names to be passed as symbols or strings. Kezdi.jl does not require this, and it will not work if you try to use symbols or strings.</p>
</blockquote>
<blockquote>
<p dir="auto">Julia reserved words, like <code>begin</code>, <code>export</code>, <code>function</code> and standard types like <code>String</code>, <code>Int</code>, <code>Float64</code>, etc., cannot be used as variable names in Kezdi.jl. If you have a column with a reserved word, rename it <em>before</em> passing it to Kezdi.jl.</p>
</blockquote>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Automatic vectorization</h3><a id="user-content-automatic-vectorization" class="anchor" aria-label="Permalink: Automatic vectorization" href="#automatic-vectorization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">All functions are automatically vectorized, so there is no need to use the <code>.</code> operator to broadcast functions over elements of a column.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@generate logHP = log(Horsepower)"><pre><span class="pl-c1">@generate</span> logHP <span class="pl-k">=</span> <span class="pl-c1">log</span>(Horsepower)</pre></div>
<p dir="auto">If you want to turn off automatic vectorization, use the <code>~</code> notation,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@generate logHP = ~log(Horsepower)"><pre><span class="pl-c1">@generate</span> logHP <span class="pl-k">=</span> <span class="pl-k">~</span><span class="pl-c1">log</span>(Horsepower)</pre></div>
<p dir="auto">The exception is when the function operates on Vectors, in which case Kezdi.jl understands you want to apply the function to the entire column.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@collapse mean_HP = mean(Horsepower), by(Cylinders)"><pre><span class="pl-c1">@collapse</span> mean_HP <span class="pl-k">=</span> <span class="pl-c1">mean</span>(Horsepower), <span class="pl-c1">by</span>(Cylinders)</pre></div>
<p dir="auto">If you need to apply a function to individual elements of a column, you need to vectorize it with adding <code>.</code> after the function name:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@generate words = split(Model, &quot; &quot;)
@generate n_words = length.(words)"><pre><span class="pl-c1">@generate</span> words <span class="pl-k">=</span> <span class="pl-c1">split</span>(Model, <span class="pl-s"><span class="pl-pds">"</span> <span class="pl-pds">"</span></span>)
<span class="pl-c1">@generate</span> n_words <span class="pl-k">=</span> <span class="pl-c1">length</span>.(words)</pre></div>
<blockquote>
<p dir="auto">Here, <code>words</code> becomes a vector of vectors, where each element is a vector of words in the corresponding <code>Model</code> string. The function <code>legth.</code> will operate on each cell in <code>words</code>, counting the number of words in each <code>Model</code> string. By contrast, <code>length(words)</code> would return the number of elements in the <code>words</code> vector, which is the number of rows in the DataFrame.</p>
</blockquote>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">The <code>@if</code> condition</h3><a id="user-content-the-if-condition" class="anchor" aria-label="Permalink: The @if condition" href="#the-if-condition"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Almost every command can be followed by an <code>@if</code> condition that filters the data frame. The command will only be executed on the subset of rows for which the condition evaluates to <code>true</code>. The condition can use any combination of column names and functions.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@summarize MPG @if Horsepower &gt; median(Horsepower)"><pre><span class="pl-c1">@summarize</span> MPG <span class="pl-c1">@if</span> Horsepower <span class="pl-k">&gt;</span> <span class="pl-c1">median</span>(Horsepower)</pre></div>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Handling missing values</h3><a id="user-content-handling-missing-values" class="anchor" aria-label="Permalink: Handling missing values" href="#handling-missing-values"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
