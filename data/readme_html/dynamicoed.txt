<p dir="auto">Repository for optimal experimental design for differential equations using optimal control.</p>
<p dir="auto"><code>DynamicOED.jl</code> uses multiple packages of Julia's <a href="https://sciml.ai/" rel="nofollow">SciML</a> ecosystem, especially <a href="https://github.com/SciML/ModelingToolkit.jl">ModelingToolkit.jl</a>, <a href="https://github.com/SciML/DifferentialEquations.jl">DifferentialEquations.jl</a> and <a href="https://github.com/SciML/Optimization.jl">Optimization.jl</a> to define <a href="https://doi.org/10.1137/110835098" rel="nofollow">optimal experimental design problems using optimal control</a>.</p>

<ul dir="auto">
<li>Currently we support Ordinary Differential Equations and Differential Algebraic Equations.</li>
<li>Relaxed and Integer formulations of the underlying problem</li>
<li>Unknown initial conditions</li>
<li>Continuous and discrete controls (in terms of the variable)</li>
<li>Variable (measurement) rates for observed and control variables</li>
<li>Custom constraints</li>
</ul>

using Optimization, OptimizationMOI, Ipopt

# Define the differential equations
@variables t
@variables x(t)=1.0 [description = &quot;State&quot;]
@parameters p[1:1]=-2.0 [description = &quot;Fixed parameter&quot;, tunable = true]
@variables obs(t) [description = &quot;Observed&quot;, measurement_rate = 10]
D = Differential(t)

@named simple_system = ODESystem([
        D(x) ~ p[1] * x,
    ], tspan = (0.0, 1.0),
    observed = obs .~ [x.^2])

@named oed = OEDSystem(simple_system)
oed = structural_simplify(oed)

# Augment the original problem to an OED problem
oed_problem = OEDProblem(structural_simplify(oed), FisherACriterion())

# Define an MTK Constraint system over the grid variables
optimization_variables = states(oed_problem)
        
constraint_equations = [
      sum(optimization_variables.measurements.w₁) ≲ 3,
]

@named constraint_set = ConstraintsSystem(constraint_equations, optimization_variables, Num[])

# Initialize the optimization problem
optimization_problem = OptimizationProblem(oed_problem, AutoForwardDiff(),
      constraints = constraint_set,
      integer_constraints = false)

solve(optimization_problem, Ipopt.Optimizer())"><pre><span class="pl-k">using</span> DynamicOED
