<p dir="auto">This package gives provides support for finding solutions to the <a href="https://en.wikipedia.org/wiki/Pell's_equation#Generalized_Pell's_equation" rel="nofollow">generalized</a> <a href="https://en.wikipedia.org/wiki/Pell's_equation" rel="nofollow">Pell's equation</a>.
More specifically, give an integer <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cabc25bbc8ae632f2ec3d079b6374350">$N$</math-renderer> and an integer <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cabc25bbc8ae632f2ec3d079b6374350">$D \geq 0$</math-renderer>,
this package will find all nonnegative integer solutions <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cabc25bbc8ae632f2ec3d079b6374350">$(x, y)$</math-renderer> to the diophantine equation
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="cabc25bbc8ae632f2ec3d079b6374350">$x^2 - Dy^2 = N$</math-renderer>.</p>
<p dir="auto">To do this, you can call <code>pellseqn(D, N=1)</code>.
This will return a (possibly infinite) iterator whose eltype is <code>Tuple{BigInt,BigInt}</code>.</p>
