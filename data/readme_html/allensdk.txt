<p dir="auto">This small package creates a basic interface to the AllenSDK python package using PythonCall. It exports the top-level <code>allensdk</code> module, which can be used to import other submodules. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using AllenSDK
using PythonCall
ecephyscache = pyimport(&quot;allensdk.brain_observatory.ecephys.ecephys_project_cache&quot;)
cache = ecephyscache.EcephysProjectCache # This can be used to access neuropixels data
units = cache.get_units() # E.g. get a python dataframe of neuropixels units"><pre><span class="pl-k">using</span> AllenSDK
<span class="pl-k">using</span> PythonCall
ecephyscache <span class="pl-k">=</span> <span class="pl-c1">pyimport</span>(<span class="pl-s"><span class="pl-pds">"</span>allensdk.brain_observatory.ecephys.ecephys_project_cache<span class="pl-pds">"</span></span>)
cache <span class="pl-k">=</span> ecephyscache<span class="pl-k">.</span>EcephysProjectCache <span class="pl-c"><span class="pl-c">#</span> This can be used to access neuropixels data</span>
units <span class="pl-k">=</span> cache<span class="pl-k">.</span><span class="pl-c1">get_units</span>() <span class="pl-c"><span class="pl-c">#</span> E.g. get a python dataframe of neuropixels units</span></pre></div>
<p dir="auto">For more complex usage, please see <a href="https://www.github.com/brendanjohnharris/AllenNeuropixels.jl">AllenNeuropixels.jl</a>, which builds on this package by providing a more Julia-oriented interface to the AllenSDK.</p>
<p dir="auto">You should have no problems installing this package as usual on Linux and Windows. On MacOS, you may need to install the Python dependencies manually (see <code>CondaPkg.toml</code>) in some environment, then set:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="ENV[&quot;JULIA_CONDAPKG_ENV&quot;] = &quot;/path/to/some/environemt/&quot;
ENV[&quot;JULIA_CONDAPKG_OFFLINE&quot;] = true"><pre><span class="pl-c1">ENV</span>[<span class="pl-s"><span class="pl-pds">"</span>JULIA_CONDAPKG_ENV<span class="pl-pds">"</span></span>] <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>/path/to/some/environemt/<span class="pl-pds">"</span></span>
<span class="pl-c1">ENV</span>[<span class="pl-s"><span class="pl-pds">"</span>JULIA_CONDAPKG_OFFLINE<span class="pl-pds">"</span></span>] <span class="pl-k">=</span> <span class="pl-c1">true</span></pre></div>
<p dir="auto">These environment variables tell <a href="https://github.com/JuliaPy/CondaPkg.jl">CondaPkg.jl</a> to use a manual python installation and avoid updating.</p>
