<p dir="auto">This repository provides implementations of Mondrian random forests in Julia,
based on methods detailed in
<a href="https://arxiv.org/abs/2310.09702" rel="nofollow">Cattaneo, Klusowski and Underwood, 2023, arXiv:2310:09702</a>.
This package provides:</p>
<ul dir="auto">
<li>Fitting (debiased) Mondrian random forests</li>
<li>Selecting a lifetime parameter with polynomial estimation or generalized cross-validation</li>
</ul>
