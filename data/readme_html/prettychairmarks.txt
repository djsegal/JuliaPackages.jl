<p dir="auto">This package extends
<a href="https://github.com/LilithHafner/Chairmarks.jl">Chairmarks</a> by defining a new
macro <code>@bs</code> that shows statistical results of the execution, much like the
<code>@benchmark</code> macro from
<a href="https://github.com/JuliaCI/BenchmarkTools.jl">BenchmarkTools</a>.</p>
<p dir="auto">In fact, the code is just an adaptation of the BenchmarkTools code.</p>
<p dir="auto">Note that this package re-export the <code>@b</code> and <code>@be</code> macros of Chairmarks:
therefore, there is no need to load also Chairmarks.</p>
