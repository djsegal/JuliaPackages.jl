<p dir="auto">Looking for a simple way to run binaries from the <a href="https://github.com/JuliaPackaging/Yggdrasil">YggDrasil</a> repo? <code>RunBinary.jl</code> has you covered!</p>
<p dir="auto">Under the hood, it performs the following steps:</p>
<ul dir="auto">
<li>Activate a temporary environment, as in <code>]activate --temp</code>.</li>
<li>Add the required jll package to this env.</li>
<li>Import the jll and run the target executable.</li>
</ul>

<p dir="auto"><code>RunBinary.jl</code> exports a single macro, <code>@run</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using RunBinary"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-k">using</span> RunBinary</pre></div>
<p dir="auto">Most basic usage: run a binary from a jll package with <code>@run &lt;package&gt;.&lt;binary&gt;</code>. Here, <code>package</code> can be specified either with or without the <code>_jll</code> suffix.
For example,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; @run SQLCipher.sqlcipher

julia&gt; @run ImageMagick_jll.identify"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">@run</span> SQLCipher<span class="pl-k">.</span>sqlcipher

julia<span class="pl-k">&gt;</span> <span class="pl-c1">@run</span> ImageMagick_jll<span class="pl-k">.</span>identify</pre></div>
<p dir="auto">Can omit the binary name if the package contains only a single binary:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; @run SQLCipher"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">@run</span> SQLCipher</pre></div>
<p dir="auto"><code>RunBinary.jl</code> passes command-line arguments to the binary:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; @run ImageMagick_jll.identify `-version`"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">@run</span> ImageMagick_jll<span class="pl-k">.</span>identify <span class="pl-s"><span class="pl-pds">`</span>-version<span class="pl-pds">`</span></span></pre></div>
<p dir="auto">The binary is started in the current directory by default. The working directory can be set to a temporary directory (same as the activated environment) if desired:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; @run SQLCipher tempdir=true"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">@run</span> SQLCipher tempdir<span class="pl-k">=</span><span class="pl-c1">true</span></pre></div>
