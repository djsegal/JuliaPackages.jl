<p dir="auto">Interoperate <a href="https://github.com/sintefmath/Jutul.jl">Jutul.jl</a> and <a href="https://github.com/sintefmath/JutulDarcy.jl">JutulDarcy.jl</a> to other Julia packages via <a href="https://github.com/JuliaDiff/ChainRules.jl">ChainRules.jl</a>. We welcome you to read the open-access article, <a href="https://library.seg.org/doi/10.1190/tle42070474.1" rel="nofollow">"Learned multiphysics inversion with differentiable programming and machine learning"</a>, for the design principle of this software package.</p>
