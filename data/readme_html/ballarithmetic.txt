<p dir="auto">This package implements Ball Arithmetic, with a focus on Numerical Linear Algebra.</p>
<p dir="auto">Ball Arithmetic introduces a type, called <code>Ball</code>,
which represents a subset of the real numbers of the type <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="87490a41b7b0f31b1f7fd922f3980fa2">$(c-r, c+r)$</math-renderer>
such that the computed sum of two balls <code>X, Y</code> is guaranteed to
contain the set <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="87490a41b7b0f31b1f7fd922f3980fa2">${x+y \mid x\in X, y\in Y}$</math-renderer> of all the possible
sums of elements of <code>X</code> and <code>Y</code>; this operation may return a bigger set,
due to rounding, etc...
Due to this inclusion property, we can use these computed entities
to control the error of numercial operations and even prove theorems in Mathematics.
Other packages implementing a similar phylosophy are
<a href="https://github.com/JuliaIntervals/IntervalArithmetic.jl">IntervalArithmetic.jl</a>, which implements Interval Arithmetic, and <a href="https://jeffreysarnoff.github.io/ArbNumerics.jl/stable/" rel="nofollow">ArbNumerics</a> which uses
Ball Arithmetic and wraps <a href="https://arblib.org/" rel="nofollow">Arb</a>.</p>
<p dir="auto">The library does not limit itself to the sum, but implements
all the other arithmetic operations, but our main interest is to implement
linear algebra operations following the ideas of <a href="https://link.springer.com/article/10.1023/A:1022374804152" rel="nofollow">Rump, BIT, 1999</a>.</p>
<p dir="auto">The fundamental idea is that, exchanging precision with speed, to use optimized Blas operations acting on matrices to compute enclosures
of matrix-vector and matrix-matrix products.
To do so, we introduce a type <code>BallMatrix</code>, which contains
a matrix of centers and a matrix of radiuses.
The implementation then guarantees that the result of a matrix-matrix
product or a matrix vector product is contained in the set defined by the
resulting BallMatrix or BallVector.</p>
