<p dir="auto">Julia wrapper for <a href="https://github.com/devinamatthews/tblis">tblis</a> with <a href="https://github.com/Jutho/TensorOperations.jl">TensorOperations.jl</a>.</p>

<p dir="auto">Currently provides implementations of <code>tensorcontract!</code>, <code>tensoradd!</code> and <code>tensortrace!</code> for
<code>StridedArray{&lt;:BlasFloat}</code>. These can be accessed through the backend system of
TensorOperations, i.e.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using TensorOperations
using TensorOperationsTBLIS

tblisbackend = tblisBackend()
α = randn()
A = randn(5, 5, 5, 5, 5, 5)
B = randn(5, 5, 5)
C = randn(5, 5, 5)
D = zeros(5, 5, 5)

@tensor backend = tblisbackend begin
    D2[a, b, c] = A[a, e, f, c, f, g] * B[g, b, e] + α * C[c, a, b]
    E2[a, b, c] := A[a, e, f, c, f, g] * B[g, b, e] + α * C[c, a, b]
end"><pre><span class="pl-k">using</span> TensorOperations
<span class="pl-k">using</span> TensorOperationsTBLIS

tblisbackend <span class="pl-k">=</span> <span class="pl-c1">tblisBackend</span>()
α <span class="pl-k">=</span> <span class="pl-c1">randn</span>()
A <span class="pl-k">=</span> <span class="pl-c1">randn</span>(<span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>)
B <span class="pl-k">=</span> <span class="pl-c1">randn</span>(<span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>)
C <span class="pl-k">=</span> <span class="pl-c1">randn</span>(<span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>)
D <span class="pl-k">=</span> <span class="pl-c1">zeros</span>(<span class="pl-c1">5</span>, <span class="pl-c1">5</span>, <span class="pl-c1">5</span>)

<span class="pl-c1">@tensor</span> backend <span class="pl-k">=</span> tblisbackend <span class="pl-k">begin</span>
    D2[a, b, c] <span class="pl-k">=</span> A[a, e, f, c, f, g] <span class="pl-k">*</span> B[g, b, e] <span class="pl-k">+</span> α <span class="pl-k">*</span> C[c, a, b]
    E2[a, b, c] <span class="pl-k">:=</span> A[a, e, f, c, f, g] <span class="pl-k">*</span> B[g, b, e] <span class="pl-k">+</span> α <span class="pl-k">*</span> C[c, a, b]
<span class="pl-k">end</span></pre></div>

<ul dir="auto">
<li>This implementation of tblis for TensorOperations.jl is only supported from v5 of
TensorOperations.jl onwards. For v4, an earlier version of this package exists.
For older versions, you could look for
<a href="https://github.com/xrq-phys/BliContractor.jl">BliContractor.jl</a> or
<a href="https://github.com/FermiQC/TBLIS.jl">TBLIS.jl</a>.</li>
