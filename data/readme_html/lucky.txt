<p dir="auto">Lucky is a trading framework for Julia designed to</p>
<ul dir="auto">
<li>rapidly test and deploy trading statregies with next to zero code change between the two.</li>
<li>run fast by leveraging Julia's multiple dispatch paradigm and <a href="https://github.com/ReactiveBayes/Rocket.jl">Rocket.jl</a> as its <strong>asynchronous</strong> and <strong>reactive</strong> core.</li>
<li>being super simple to start with although remaining modular to tailor and extend to different needs.</li>
<li>accomodate different kind of strategies, data or experiements (market making, random process simulation, etc.) leveraging Julia's powerful math libraries ecosystem.</li>
</ul>
