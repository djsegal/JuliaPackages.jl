<p dir="auto"><code>DataViewer</code> is not registered (yet), so you need to provide its full URL to the Julia package manager.</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; ] # enter Pkg mode
pkg&gt; add https://github.com/triscale-innov/DataViewer.jl.git"><pre>julia&gt; ] <span class="pl-c"><span class="pl-c">#</span> enter Pkg mode</span>
pkg&gt; add https://github.com/triscale-innov/DataViewer.jl.git</pre></div>
<p dir="auto">Then, whenever there is some data structure that you want to explore:</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Use as a standalone application</h2><a id="user-content-use-as-a-standalone-application" class="anchor" aria-label="Permalink: Use as a standalone application" href="#use-as-a-standalone-application"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">After having installed the <code>DataViewer</code> package, you can ask it to install a standalone application, callable from the command-line:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using DataViewer

julia&gt; DataViewer.install()"><pre>julia&gt; <span class="pl-k">using</span> DataViewer

julia&gt; DataViewer<span class="pl-k">.</span><span class="pl-c1">install</span>()</pre></div>
<p dir="auto">By default, a launcher named <code>dataviewer</code> will be placed in the <code>~/.julia/bin</code> directory, which you should add to your <code>PATH</code> environment variable. Afterwards, you can run this new command from a shell.</p>
<p dir="auto">Without argument, a file picker window will pop up to ask for a file to open:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ dataviewer"><pre>$ dataviewer</pre></div>
<p dir="auto">With one argument, the given file will be viewed:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ dataviewer sample.hdf5"><pre>$ dataviewer sample.hdf5</pre></div>
<p dir="auto">A second argument allows specifying the file type if the extension is not enough to guess it:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="$ dataviewer sample JSON"><pre>$ dataviewer sample JSON</pre></div>
