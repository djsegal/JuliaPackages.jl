<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Installation</h1><a id="user-content-installation" class="anchor" aria-label="Permalink: Installation" href="#installation"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Installation is straightforward.  First, install the Julia programming language on your computer.  To do this, download Julia here: <a href="https://julialang.org" rel="nofollow">https://julialang.org</a>, and follow the instructions for your operating system.</p>
<p dir="auto">Next, open the Julia application that you just installed. It should look similar to the image below. This interface is referred to as the <code>Julia REPL</code>.</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://camo.githubusercontent.com/3187e9b0de254a575a034751df0c1b2dc98b3fe9240ec6cba1058cd01c24de6d/68747470733a2f2f73332e616d617a6f6e6177732e636f6d2f637572726963756c6172616e616c79746963732e6a6c2f6a756c69612d636f6d6d616e642d6c696e652e706e67"><img src="https://camo.githubusercontent.com/3187e9b0de254a575a034751df0c1b2dc98b3fe9240ec6cba1058cd01c24de6d/68747470733a2f2f73332e616d617a6f6e6177732e636f6d2f637572726963756c6172616e616c79746963732e6a6c2f6a756c69612d636f6d6d616e642d6c696e652e706e67" alt="Julia termain" data-canonical-src="https://s3.amazonaws.com/curricularanalytics.jl/julia-command-line.png" style="max-width: 100%;"></a></p>
<p dir="auto">Next, enter Pkg mode from within Julia by hitting the <code>]</code> key, and then type:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="  pkg&gt; add CurricularAnalytics CurricularVisualization"><pre>  pkg&gt; add CurricularAnalytics CurricularVisualization</pre></div>
<p dir="auto">This will install the CurricularAnalytics toolbox (if not already installed) and the visualization software, along with the other Julia packages needed to run it. To load and use the visualization, hit the <code>backspace</code> key to return to the Julia REPL. Now type:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="  julia&gt; using CurricularAnalytics, CurricularVisualization"><pre>  julia&gt; using CurricularAnalytics, CurricularVisualization</pre></div>
<p dir="auto">The visualization software must be loaded again via <code>using CurricularAnalytics, CurricularVisualization</code> every time you restart Julia.</p>
<p dir="auto">For more information about installing the toolbox, including the steps neccessary to utilize degree plan optimization, please see the <a href="https://curricularanalytics.github.io/CurricularAnalytics.jl/latest/install.html" rel="nofollow">INSTALLING.md</a></p>
