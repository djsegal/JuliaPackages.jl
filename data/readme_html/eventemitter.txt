<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Getting started</h2><a id="user-content-getting-started" class="anchor" aria-label="Permalink: Getting started" href="#getting-started"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">First run</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using EventEmitter"><pre><span class="pl-k">using</span> EventEmitter</pre></div>
<p dir="auto">Construct an <code>Event</code></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="myevent = Event()"><pre>myevent <span class="pl-k">=</span> <span class="pl-c1">Event</span>()</pre></div>
<p dir="auto">You can pass callback functions as arguments</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="myfunction() = println(&quot;function&quot;)
myevent = Event(myfunction, () -&gt; println(&quot;Arrow function&quot;))"><pre><span class="pl-en">myfunction</span>() <span class="pl-k">=</span> <span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>function<span class="pl-pds">"</span></span>)
myevent <span class="pl-k">=</span> <span class="pl-c1">Event</span>(myfunction, () <span class="pl-k">-&gt;</span> <span class="pl-c1">println</span>(<span class="pl-s"><span class="pl-pds">"</span>Arrow function<span class="pl-pds">"</span></span>))</pre></div>
<p dir="auto">Listeners are <code>on</code> by default. change this by setting <code>once</code></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="myevent = Event((x) -&gt; print(x); once=true)"><pre>myevent <span class="pl-k">=</span> <span class="pl-c1">Event</span>((x) <span class="pl-k">-&gt;</span> <span class="pl-c1">print</span>(x); once<span class="pl-k">=</span><span class="pl-c1">true</span>)</pre></div>
<p dir="auto">Or construct listeners manually and pass them</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Listener(callback, once)
myevent = Event(Listener(() -&gt; 1), Listener(() -&gt; 2, true))"><pre><span class="pl-c"><span class="pl-c">#</span> Listener(callback, once)</span>
myevent <span class="pl-k">=</span> <span class="pl-c1">Event</span>(<span class="pl-c1">Listener</span>(() <span class="pl-k">-&gt;</span> <span class="pl-c1">1</span>), <span class="pl-c1">Listener</span>(() <span class="pl-k">-&gt;</span> <span class="pl-c1">2</span>, <span class="pl-c1">true</span>))</pre></div>
<p dir="auto">Use <code>on!()</code> or <code>once!()</code> to add listeners</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="on!(myevent) do
  return &quot;called everytime&quot;
end
once!(myevent) do
  return &quot;called once&quot;
end"><pre><span class="pl-c1">on!</span>(myevent) <span class="pl-k">do</span>
  <span class="pl-k">return</span> <span class="pl-s"><span class="pl-pds">"</span>called everytime<span class="pl-pds">"</span></span>
<span class="pl-k">end</span>
<span class="pl-c1">once!</span>(myevent) <span class="pl-k">do</span>
  <span class="pl-k">return</span> <span class="pl-s"><span class="pl-pds">"</span>called once<span class="pl-pds">"</span></span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">Emit an event by calling it or using <code>emit!()</code></p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="myevent() # [1, 2, &quot;called everytime&quot;, &quot;called once&quot;]
emit!(myevent) # [1, &quot;called everytime&quot;]"><pre><span class="pl-c1">myevent</span>() <span class="pl-c"><span class="pl-c">#</span> [1, 2, "called everytime", "called once"]</span>
<span class="pl-c1">emit!</span>(myevent) <span class="pl-c"><span class="pl-c">#</span> [1, "called everytime"]</span></pre></div>
<p dir="auto">Listeners are called in order</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="myevent = Event(() -&gt; 1, () -&gt; 2)
on!(myevent, () -&gt; 3)

myevent() # [1, 2, 3]"><pre>myevent <span class="pl-k">=</span> <span class="pl-c1">Event</span>(() <span class="pl-k">-&gt;</span> <span class="pl-c1">1</span>, () <span class="pl-k">-&gt;</span> <span class="pl-c1">2</span>)
<span class="pl-c1">on!</span>(myevent, () <span class="pl-k">-&gt;</span> <span class="pl-c1">3</span>)

<span class="pl-c1">myevent</span>() <span class="pl-c"><span class="pl-c">#</span> [1, 2, 3]</span></pre></div>
<p dir="auto">Use <code>prependlisteners!()</code> to prepend listeners</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="prependlisteners!(myevent, () -&gt; 4, () -&gt; 5)
myevent() # [4, 5, 1, 2, 3]"><pre><span class="pl-c1">prependlisteners!</span>(myevent, () <span class="pl-k">-&gt;</span> <span class="pl-c1">4</span>, () <span class="pl-k">-&gt;</span> <span class="pl-c1">5</span>)
<span class="pl-c1">myevent</span>() <span class="pl-c"><span class="pl-c">#</span> [4, 5, 1, 2, 3]</span></pre></div>
<p dir="auto">Use <code>off!()</code> to remove a <code>Listener</code></p>
<p dir="auto">*<code>off!()</code> returns the <code>Listener</code> it removes, so doing <code>off!(event)()</code> will call it*</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="off!(myevent)() # 3 - (last) equivalent to `off!(myevent, 0)()`
off!(myevent, 1)() # 4 - (first)
off!(myevent, -1)() # 1 - (before last)
myevent() # [5, 2]"><pre><span class="pl-c1">off!</span>(myevent)() <span class="pl-c"><span class="pl-c">#</span> 3 - (last) equivalent to `off!(myevent, 0)()`</span>
<span class="pl-c1">off!</span>(myevent, <span class="pl-c1">1</span>)() <span class="pl-c"><span class="pl-c">#</span> 4 - (first)</span>
<span class="pl-c1">off!</span>(myevent, <span class="pl-k">-</span><span class="pl-c1">1</span>)() <span class="pl-c"><span class="pl-c">#</span> 1 - (before last)</span>
<span class="pl-c1">myevent</span>() <span class="pl-c"><span class="pl-c">#</span> [5, 2]</span></pre></div>
<p dir="auto">Construct collections of <code>Event</code>s (arrays, tuples, named tuples and dictionaries)</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="event1 = Event(() -&gt; 1)
event2 = Event(() -&gt; 2)
arr = [event1, event2]
tuple = (event1, event2)
namedtuple = (a=event1, b=event2)
dict = Dict(:a =&gt; event1, :b =&gt; event2)"><pre>event1 <span class="pl-k">=</span> <span class="pl-c1">Event</span>(() <span class="pl-k">-&gt;</span> <span class="pl-c1">1</span>)
event2 <span class="pl-k">=</span> <span class="pl-c1">Event</span>(() <span class="pl-k">-&gt;</span> <span class="pl-c1">2</span>)
arr <span class="pl-k">=</span> [event1, event2]
tuple <span class="pl-k">=</span> (event1, event2)
namedtuple <span class="pl-k">=</span> (a<span class="pl-k">=</span>event1, b<span class="pl-k">=</span>event2)
dict <span class="pl-k">=</span> <span class="pl-c1">Dict</span>(<span class="pl-c1">:a</span> <span class="pl-k">=&gt;</span> event1, <span class="pl-c1">:b</span> <span class="pl-k">=&gt;</span> event2)</pre></div>
<p dir="auto">Emit the collections</p>
<p dir="auto">*emitting a dict will give almost random order for the events*</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="emit!(arr) # [[1], [2]]
emit!(tuple) # [[1], [2]]
emit!(namedtuple) # [[1], [2]]
emit!(dict) # [[1], [2]]"><pre><span class="pl-c1">emit!</span>(arr) <span class="pl-c"><span class="pl-c">#</span> [[1], [2]]</span>
<span class="pl-c1">emit!</span>(tuple) <span class="pl-c"><span class="pl-c">#</span> [[1], [2]]</span>
<span class="pl-c1">emit!</span>(namedtuple) <span class="pl-c"><span class="pl-c">#</span> [[1], [2]]</span>
<span class="pl-c1">emit!</span>(dict) <span class="pl-c"><span class="pl-c">#</span> [[1], [2]]</span></pre></div>
