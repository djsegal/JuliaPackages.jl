<p dir="auto">A framework for approximating functions, operators and solving operator equations</p>
<p dir="auto">This is largely motivated by ApproxFun.jl and is a reimplemenation of many of those ideas with an eye towards minimizing dependencies.</p>
<p dir="auto">An example:</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="using OperatorApproximation, Plots, SpecialFunctions

<p dir="auto">The structure of the code is as follows:</p>
<ul dir="auto">
<li>The core of the code is the Domain and Bases.   The Bases directory contains one file for each basis that is implemented.  This has the specific functions for performing all the core tasks for a given basis.</li>
<li>The implementation of operators occurs in two steps.  The first is the definition of an AbstractOperator that is then turned to a ConcreteOperator of an appropriate type when it acts on a Basis.</li>
<li>The details of this conversion should be implemented for each AbstractOperator in a file in the subdirectory of the Operators directory corresponding to the basis under consideration.  When implementing a new operator, it should be categorized by basis on which it acts.</li>
</ul>
