<p dir="auto">VueJS.jl is a Julia package that facilitates the creation of reactive, interactive web applications by leveraging the Vue.js (v3) framework directly from Julia. It allows you to combine the flexibility and simplicity of Vue.js with the computational power of Julia, making it an excellent tool for building dynamic web applications with ease.
It uses <a href="https://vuetifyjs.com/en/" rel="nofollow">Vuetify</a> (v3) as main Vue Framework, but also leverages on Echarts through Julia Namtso package and others.
The main philosofy is to pass through to the frameworks all of the introduced arguments with several automations and special cases.</p>
