<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">DOLPHYN is a configurable, <a href="https://github.com/macroenergy/Dolphyn.jl/blob/README_Doc_Update/LICENSE">open source</a> energy system optimization model developed to explore interactions between multiple energy vectors and emerging technologies across their supply chains as part of a future integrated low-carbon energy system.</p>
<p dir="auto">The DOLPHYN model evaluates investments and operations across the electricity and Hydrogen (H2) supply chains, including production, storage, transmission, conditioning, and end-use consumption. Importantly, the model is able to capture interactions between electricity and hydrogen infrastructure through: a) using hydrogen for power generation and b) production of hydrogen using electricity. The model is set up as a single-stage investment planning model and determines the least-cost mix of electricity and H2 infrastructure to meet electricity and H2 demand subject to a variety of operational, policy and carbon emission constraints. The DOLPHYN model incorporates the <a href="https://github.com/GenXProject/GenX">GenX</a> electricity system model to characterize electricity system operations and investments (v0.3.6). Periodically, the electricity system representation is regularly updated to the latest GenX version.</p>
<p dir="auto">DOLPHYN is designed to be highly flexible and configurable, for use in a variety of applications from academic research and technology evaluation to public policy and regulatory analysis and resource planning. We are currently working to add biofuel supply chains and carbon capture, transport, and storage to the model.</p>
<p dir="auto">We welcome you to add new features and resources to DOLPHYN for use in your own work and to <a href="https://github.com/macroenergy/Dolphyn.jl/pulls">share them here for others</a>. If you have issues using DOLPHYN <a href="https://github.com/macroenergy/Dolphyn.jl/issues">please let us know by opening an issue</a>.</p>

<p dir="auto">DOLPHYN is written in <a href="https://julialang.org/" rel="nofollow">Julia</a>. We recommend using the <a href="https://julialang.org/downloads/" rel="nofollow">latest version of Julia</a> to run DOLPHYN but will support all versions back to the current long term stable version.</p>
<p dir="auto">You need a mathematical programme solver to run DOLPHYN. DOLPHYN comes packaged with <a href="https://highs.dev/" rel="nofollow">HiGHS</a>, a free open-source solver. This will be installed automatically by the <a href="https://github.com/jump-dev/HiGHS.jl">HiGHS.jl</a> package when you use DOLPHYN.</p>
<p dir="auto">DOLPHYN also works with several other open-source and commercial solvers via the <a href="https://jump.dev" rel="nofollow">JuMP.jl</a> package. DOLPHYN is most extensively tested using <a href="https://www.gurobi.com" rel="nofollow">Gurobi</a>, a commercial solver requiring a paid commercial license or free academic license</p>
<p dir="auto">DOLPHYN also has limited support for:</p>
<ul dir="auto">
<li><a href="https://www.ibm.com/analytics/cplex-optimizer" rel="nofollow">CPLEX</a> - a commercial solver requiring a paid commercial license or free academic license</li>
<li><a href="https://github.com/jump-dev/Clp.jl">Clp</a> - a free open-source solver</li>
<li><a href="https://github.com/jump-dev/Cbc.jl">Cbc</a> - a free open-source solver</li>
</ul>

<p dir="auto">DOLPHYN is available as a Julia package. To install DOLPHYN, open the Julia REPL and run:</p>
<p dir="auto"><code>using Pkg</code></p>
<p dir="auto"><code>Pkg.add("Dolphyn")</code></p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Running your first example</h3><a id="user-content-running-your-first-example" class="anchor" aria-label="Permalink: Running your first example" href="#running-your-first-example"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Download the example systems by downloading or cloning the Dolphyn.jl repository by <a href="#if-you-are-doing-a-fresh-install">following the instruction here</a>. Navigate to one of the example systems, e.g.:</p>
<p dir="auto"><code>julia&gt; cd("Example_Systems/SmallNewEngland/OneZone")</code></p>
<p dir="auto">Here you will find:</p>
<ul dir="auto">
<li>Input data contained in several CSV files</li>
<li>A settings folder containing:
<ul dir="auto">
<li>global_model_settings.yml: settings across all sectors</li>
<li>gens_settings.yml: setting for the electricity sector</li>
<li>hsc_settings.yml: settings for the hydrogen sector</li>
<li>solver settings, e.g. highs_settings.yml</li>
</ul>
</li>
<li>A Run.jl file which constructs, runs, and outputs the model</li>
</ul>
<p dir="auto">To run the model, ensure you are not in the package manager by hitting the backspace key, then execute the Run.jl file:</p>
<p dir="auto"><code>julia&gt; include("Run.jl")</code></p>
<p dir="auto">Once the model has completed running, results will be written into the "Results" folder. The hydrogen sector results are saved inthe Results/Results_HSC folder.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Installing Gurobi or an alternative solver</h2><a id="user-content-installing-gurobi-or-an-alternative-solver" class="anchor" aria-label="Permalink: Installing Gurobi or an alternative solver" href="#installing-gurobi-or-an-alternative-solver"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">HiGHS will be automatically downloaded and installed when you install DOLPHYN so you do not need to download it separately. However if you would like to use a specific version of have a separate copy, it can be downloaded from: <a href="https://highs.dev/" rel="nofollow">https://highs.dev/</a>.</p>
<p dir="auto">If you wish to use another solver you will need to install it separately and add the corresponding Julia package to your Julia environment. Most <a href="https://jump.dev/JuMP.jl/stable/packages/solvers/" rel="nofollow">solvers supported by JuMP.jl</a> should be compatible. The instructions below are for Gurobi, but the process is similar for other solvers.</p>
<p dir="auto">To use Gurobi instead of HiGHS to solve the <code>.../SmallNewEngland/OneZone</code> example:</p>
<ul dir="auto">
<li>Download and install the latest version of the Gurobi Optimizer from: <a href="https://www.gurobi.com/downloads/gurobi-software/" rel="nofollow">https://www.gurobi.com/downloads/gurobi-software/</a></li>
<li>Install the Gurobi Julia package by running the following commands in the Julia REPL:
<ul dir="auto">
<li><code>using Pkg</code></li>
<li><code>Pkg.add("Gurobi")</code></li>
<li><code>Pkg.build("Gurobi")</code></li>
</ul>
</li>
<li>In the <code>Settings/global_model_settings.yml</code> file, change the solver to Gurobi by changing the line <code>Solver: HiGHS</code> to <code>Solver: Gurobi</code></li>
<li>Add the following line to the <code>Run.jl</code> file:
<ul dir="auto">
<li><code>using Gurobi</code></li>
</ul>
</li>
</ul>
<p dir="auto">If the step to build Gurobi fails, the most likely cause is that the Gurobi installation cannot be found. <a href="https://support.gurobi.com/hc/en-us/articles/13443862111761-How-do-I-set-system-environment-variables-for-Gurobi-" rel="nofollow">Use the following instructions</a> to define the "GUROBI_HOME" and "GRB_LICENSE_FILE" environment variables on your computer. For example, for Gurobi 10.0 on Ubuntu they should point to:</p>
<ul dir="auto">
<li>GUROBI_HOME = ...path to Gurobi install/gurobi1000/linux64</li>
<li>GRB_LICENSE_FILE = ...path to Gurobi install/gurobi1000/gurobi.lic</li>
</ul>
<p dir="auto">Once you have successfully built Gurobi.jl, run the model as described above. The model should now run using Gurobi instead of HiGHS.</p>

<p dir="auto">The first time you run DOLPHYN, you must instantiate the Julia environment. This will download and install all the required packages.</p>
<p dir="auto">In your command terminal (not the Julia REPL), navigate to your DOLPHYN folder then run the following commands:</p>
<ul dir="auto">
<li><code>julia --project=.</code> (this starts the Julia REPL using the environment file found in the current directory)</li>
<li><code>julia&gt; ]</code> (Enter ']' at the prompt)</li>
<li><code>(DOLPHYN) pkg&gt; instantiate</code> (you should see DOLPHYN project name here, if not, enter <code>activate .</code>)</li>
</ul>
<p dir="auto">If you plan to use Gurobi or another solver other than HiGHS, you should add the corresponding Julia package to your Julia environment, <a href="#installing-gurobi-or-an-alternative-solver">as described in the section above</a>.</p>
