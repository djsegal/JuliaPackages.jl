<p dir="auto"><strong>This package is still in development</strong></p>
<p dir="auto">This package contains modules describing different ecophysiological functions of
plants, including processes such as photosynthesis, respiration, transpiration
or phenology. They may be used as standalone or as a component of a plant growth
model.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Photosynthesis</h2><a id="user-content-photosynthesis" class="anchor" aria-label="Permalink: Photosynthesis" href="#photosynthesis"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The module Photosynthesis contains functions to calculate leaf CO2 assimilation
and stomatal conductance for C3 and C4 species, based on the work by <a href="https://www.tandfonline.com/doi/full/10.1016/j.njas.2009.07.001" rel="nofollow">Yin &amp; Struik (2009, NJAS)</a>.
To create a model, use the corresponding function (<code>C3()</code> or <code>C4()</code>) and pass the
parameters as keyword arguments (they all have default values that correspond to Tables 2 the original publication):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Ecophys
c3 = C3(Vcmax25 = 140.0)
c4 = C4(Vcmax25 = 140.0)"><pre><span class="pl-k">using</span> Ecophys
c3 <span class="pl-k">=</span> <span class="pl-c1">C3</span>(Vcmax25 <span class="pl-k">=</span> <span class="pl-c1">140.0</span>)
c4 <span class="pl-k">=</span> <span class="pl-c1">C4</span>(Vcmax25 <span class="pl-k">=</span> <span class="pl-c1">140.0</span>)</pre></div>
<p dir="auto">To compute CO2 assimilation and stomatal conductance, use the <code>photosynthesis()</code> function,
passing the photosynthesis model and the environmental conditions as inputs (with
defaults):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A_c3, gs_c3  = photosynthesis(c3, PAR = 100.0)
A_c4, gs_c4  = photosynthesis(c4, PAR = 100.0)"><pre>A_c3, gs_c3  <span class="pl-k">=</span> <span class="pl-c1">photosynthesis</span>(c3, PAR <span class="pl-k">=</span> <span class="pl-c1">100.0</span>)
A_c4, gs_c4  <span class="pl-k">=</span> <span class="pl-c1">photosynthesis</span>(c4, PAR <span class="pl-k">=</span> <span class="pl-c1">100.0</span>)</pre></div>
<p dir="auto">It is also possible to work with physical units using the Unitful.jl package. In
such case, the functions <code>C3Q()</code> and <code>C4Q</code> should be used to create the model but
now the parameters are stored as <code>Quantity</code> objects:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Unitful.DefaultSymbols # import symbols for units
c3Q = C3Q(Vcmax25 = 140.0μmol/m^2/s)
c4Q = C4Q(Vcmax25 = 140.0μmol/m^2/s)"><pre><span class="pl-k">using</span> Unitful<span class="pl-k">.</span>DefaultSymbols <span class="pl-c"><span class="pl-c">#</span> import symbols for units</span>
c3Q <span class="pl-k">=</span> <span class="pl-c1">C3Q</span>(Vcmax25 <span class="pl-k">=</span> <span class="pl-c1">140.0</span>μmol<span class="pl-k">/</span>m<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>s)
c4Q <span class="pl-k">=</span> <span class="pl-c1">C4Q</span>(Vcmax25 <span class="pl-k">=</span> <span class="pl-c1">140.0</span>μmol<span class="pl-k">/</span>m<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>s)</pre></div>
<p dir="auto">And the environmental conditions should be passed as <code>Quantity</code> objects (defaults
are updated accordingly, see Unitful.jl documentation for details on how to
create <code>Quantity</code> objects):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="A_c3, gs_c3  = photosynthesis(c3Q, PAR = 100.0μmol/m^2/s)
A_c4, gs_c4  = photosynthesis(c4Q, PAR = 100.0μmol/m^2/s)"><pre>A_c3, gs_c3  <span class="pl-k">=</span> <span class="pl-c1">photosynthesis</span>(c3Q, PAR <span class="pl-k">=</span> <span class="pl-c1">100.0</span>μmol<span class="pl-k">/</span>m<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>s)

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Leaf Energy Balance</h2><a id="user-content-leaf-energy-balance" class="anchor" aria-label="Permalink: Leaf Energy Balance" href="#leaf-energy-balance"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Ecophys may also compute the leaf energy balance to couple photosynthesis,
transpiration and leaf temperature. In addition to the models of photosynthesis
and stomatal conductance mentioned in the above, additional models of boundary
layer conductance and leaf optical properties are required.</p>
<p dir="auto">Currently, only a simple model of optical properties is avaiable that defines
the leaf absorptance in PAR and NIR and its emmisivity in the thermal domain.
This model is created using the <code>SimpleOptical()</code> function (defaults are provided):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Ecophys
opt = SimpleOptical(αPAR = 0.80)"><pre><span class="pl-k">using</span> Ecophys
opt <span class="pl-k">=</span> <span class="pl-c1">SimpleOptical</span>(αPAR <span class="pl-k">=</span> <span class="pl-c1">0.80</span>)</pre></div>
<p dir="auto">Two models to compute the boundary layer conductance are available. They differ
in the amount of information used regarding the geometry of the leaf. A simple
model only accounts for the leaf characteristic length and is the most common
approach (as before, a version that supports <code>Quantity</code> objects is also available):</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="gb = simplegb(d = 0.1)
gbQ = simplegbQ(d = 0.1m)"><pre>gb <span class="pl-k">=</span> <span class="pl-c1">simplegb</span>(d <span class="pl-k">=</span> <span class="pl-c1">0.1</span>)
gbQ <span class="pl-k">=</span> <span class="pl-c1">simplegbQ</span>(d <span class="pl-k">=</span> <span class="pl-c1">0.1</span>m)</pre></div>
<p dir="auto">The second model is more complex as it takes into account the aspect ratio (length/width) of
the leaf as well as its inclination angle. It will also distinguish between the
boundary layer conductance of the front and back side of the leaf. This model
relies on unpublished equations fitted to the data reviewed by
<a href="https://nph.onlinelibrary.wiley.com/doi/10.1111/j.1469-8137.1993.tb03898.x" rel="nofollow">Schuepp (1993, New Phyto)</a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="gbang = gbAngle(d = 0.1, ang = π/4, ar = 0.1)
gbangQ = gbAngleQ(d = 0.1m, ang = π/4, ar = 0.1)"><pre>gbang <span class="pl-k">=</span> <span class="pl-c1">gbAngle</span>(d <span class="pl-k">=</span> <span class="pl-c1">0.1</span>, ang <span class="pl-k">=</span> π<span class="pl-k">/</span><span class="pl-c1">4</span>, ar <span class="pl-k">=</span> <span class="pl-c1">0.1</span>)
gbangQ <span class="pl-k">=</span> <span class="pl-c1">gbAngleQ</span>(d <span class="pl-k">=</span> <span class="pl-c1">0.1</span>m, ang <span class="pl-k">=</span> π<span class="pl-k">/</span><span class="pl-c1">4</span>, ar <span class="pl-k">=</span> <span class="pl-c1">0.1</span>)</pre></div>
<p dir="auto">The leaf energy balance is then computed using <code>solve_energy_balance()</code> which
will compute the leaf temperature that closes the energy balance as well as the
corresponding CO2 assimilation and transpiration:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="Tleaf, A, Tr = solve_energy_balance(c3; gb = gb, opt = opt, PAR = 100.0, ws = 5.0)
TleafangQ, AangQ, TrangQ = solve_energy_balance(c3Q; gb = gbangQ, opt = opt, PAR = 100.0μmol/m^2/s, ws = 5.0m/s)"><pre>Tleaf, A, Tr <span class="pl-k">=</span> <span class="pl-c1">solve_energy_balance</span>(c3; gb <span class="pl-k">=</span> gb, opt <span class="pl-k">=</span> opt, PAR <span class="pl-k">=</span> <span class="pl-c1">100.0</span>, ws <span class="pl-k">=</span> <span class="pl-c1">5.0</span>)
TleafangQ, AangQ, TrangQ <span class="pl-k">=</span> <span class="pl-c1">solve_energy_balance</span>(c3Q; gb <span class="pl-k">=</span> gbangQ, opt <span class="pl-k">=</span> opt, PAR <span class="pl-k">=</span> <span class="pl-c1">100.0</span>μmol<span class="pl-k">/</span>m<span class="pl-k">^</span><span class="pl-c1">2</span><span class="pl-k">/</span>s, ws <span class="pl-k">=</span> <span class="pl-c1">5.0</span>m<span class="pl-k">/</span>s)</pre></div>
