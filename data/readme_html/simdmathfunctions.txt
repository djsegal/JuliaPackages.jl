<p dir="auto">The primary goal of <code>SIMDMathFunctions</code> is to provide efficient methods for mathematical functions with <code>SIMD.Vec</code> arguments. Under the hood, optimized implementations provided by <code>SLEEFPirates.jl</code> are used. This allows explicitly vectorized code using <code>SIMD.jl</code> to benefit from fast vectorized math functions.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using SIMD: VecRange

function exp!(xs::Vector{T}, ys::Vector{T}) where {T}
    @inbounds for i in eachindex(xs,ys)
        xs[i] = @fastmath exp(ys[i])
    end
end

function exp!(xs::Vector{T}, ys::Vector{T}, ::Val{N}) where {N, T}
    @assert length(ys) == length(xs)
    @assert length(xs) % N == 0
    @assert is_supported(@fastmath exp)
    @inbounds for istart in 1:N:length(xs)
        i = VecRange{N}(istart)
        xs[i] = @fastmath exp(ys[i])
    end
end

<p dir="auto"><code>is_supported(fun)</code> returns <code>true</code> if function <code>fun</code> supports <code>SIMD.Vec</code> arguments. Similarly <code>is_fast(fun)</code> returns <code>true</code> if <code>fun</code> has an optimized implementation.</p>
<p dir="auto"><code>fast_functions([ninputs])</code> returns a vector of functions benefitting from a fast implementation, restricted to those accepting <code>ninputs</code> input arguments if <code>ninputs</code> is provided.</p>
<p dir="auto"><code>SIMDMathFunctions</code> also provides a helper function <code>vmap</code> to vectorize not-yet-supported mathematical functions. For example :</p>

<p dir="auto">The default <code>vmap</code> method simply calls <code>erf</code> on each element of <code>x</code>. There is no performance benefit, but it allows generic code to use <code>erf</code>. If <code>erf_SIMD</code> is optimized for vector inputs, you can provide a specialized method for <code>vmap</code>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using VectorizationBase: verf # vectorized implementation
using SIMDMathFunctions: SIMDVec, VBVec # VectorizationBase &lt;=&gt; SIMD conversion

erf_SIMD(x) = SIMDVec(verf(VBVec(x)))
vmap(::typeof(erf), x) = erf_SIMD(x)

@benchmark erf($x)"><pre><span class="pl-k">using</span> VectorizationBase<span class="pl-k">:</span> verf <span class="pl-c"><span class="pl-c">#</span> vectorized implementation</span>
