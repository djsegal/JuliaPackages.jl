<p dir="auto">MERA is a package for working with large 3D AMR/uniform-grid and N-body particle data sets from astrophysical simulations.
It is entirely written in the language <a href="https://julialang.org" rel="nofollow">Julia</a> and currently supports the hydrodynamic code <a href="https://bitbucket.org/rteyssie/ramses/overview" rel="nofollow">RAMSES</a>. With this package, I intend to provide essential functions to load and prepare the simulation data for calculations but try to avoid too high-level abstraction (black boxes).</p>
<blockquote>
<p dir="auto"><strong>Note</strong>
To get a first impression, look at the <code>Hands-On Session RUM2023</code> with downloadable simulation examples:
<a href="https://github.com/ManuelBehrendt/RUM2023">https://github.com/ManuelBehrendt/RUM2023</a></p>
</blockquote>

<p dir="auto">We are developing <strong>unit-test</strong> and <strong>end-to-end</strong> testing strategies to encounter bugs like general errors, incorrect data returns, and functionality issues. After new commits are pushed to GitHub, <strong>different operating system environments</strong> and <strong>Julia versions</strong> run <strong>automated tests</strong>, e. g. on outputs from various RAMSES simulations, to ensure important functionalities of MERA. The <em>test</em> folder contains all tests with the main function in the <strong>runtest.jl</strong> file.</p>

<p dir="auto">Reproducibility is an essential requirement of the scientific process. Therefore, I recommend working with environments.
Create independent projects that contain their list of used package dependencies and their versions.
The possibility of creating projects ensures reproducibility of your programs on your or other platforms if, e.g. the code is shared (toml-files are added to the project folder). For more information see Julia environments.

<p dir="auto">In scientific computing, we are dealing with a steadily increasing amount of data. Highest performance is required, and therefore, most science-related libraries are written in low-level languages like C or Fortran with relatively long development times. The reduced data is often processed in a high-level language like Python.
Julia is a relatively new and modern language, and it combines high-level programming with high-performance numerical computing. The syntax is simple and great for math. The just-in-time compilation allows for interactive coding and to achieve an optimized machine code on the fly. Both enhance prototyping and code readability. Therefore, complex projects can be realized in relatively short development times.
﻿​
Further features:</p>
<ul dir="auto">
<li>Package manager</li>
<li>Runs on multiple platform</li>
<li>Multiple dispatch</li>
<li>Build-in parallelism</li>
<li>Metaprogramming</li>
<li>Directly call C, Fortran, Python (e.g. Matplotlib), R libraries, ...
….</li>
</ul>
