<p dir="auto">This is a very simple but yet useful package which helps to generate strings with values and their corresponding error followed in brackets, e. g., <code>23.56(12)(30)</code> stands for <code>23.56 ± 0.12 ± 0.30</code>.</p>
<p dir="auto">This is common notation in science and this package provides a function to generate these strings.
The reading is the following: the error denoted with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4c209c1c84370d912f0f59ed49349881">$N$</math-renderer> digits describes the error in the last <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4c209c1c84370d912f0f59ed49349881">$N$</math-renderer> shown digits of the value. E. g., <code>0.345(56) = 0.345 ± 0.56</code> or <code>1234567890(123) = 1234567890 ± 123</code>.</p>

<p dir="auto">The errors are always rounded with <code>ceil</code> while the value is rounded with <code>round</code>. This rule is a usual conservative case for rounding errors.</p>
<p dir="auto">By default the errors will have 2 digits in the brackets. See next section for more explanations.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Customize Output</h2><a id="user-content-customize-output" class="anchor" aria-label="Permalink: Customize Output" href="#customize-output"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">With some keywords you can customize the output.</p>
<ul dir="auto">
<li><code>dec::Int = 2</code>: number of decimals to round the errors to</li>
<li><code>suff::NTuple{String} = ("", ...)</code>: optional suffix after the brackets (Tuple can be omitted when using with only one error)</li>
<li><code>bracket::NTuple{Symbol} = (:r, ...)</code>: type of the brackets (Tuple can be omitted when using with only one error)</li>
</ul>
<p dir="auto"><code>bracket</code> can take the values: <code>[:a, :l, :s, :r, :c, :_, :^]</code> (angular, line, square, round, curly, subscript, superscript) which correspond to <code>["&lt;&gt;", "||", "[]", "()", "{}", "_{}", "^{}"]</code>.
The last two are useful for LaTeX output.
However, note that this is <strong>not</strong> a common way of printing the errors.
In such cases one usually prints the real error like in this example:
<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4c209c1c84370d912f0f59ed49349881">$$0.1234 \pm 0.056 \pm 0.12 = 1.234(56)(12) = 1.234_{\pm 0.056}^{\pm 0.012}$$</math-renderer>
and <strong>not</strong> <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4c209c1c84370d912f0f59ed49349881">$1.234_{56}^{12}$</math-renderer>.
But feel free to use it and annotate how to read it (it is the shortest one ;)).
It is also possible that you use it for lower and upper error bound, where it makes much more sense and is common notation.</p>
<p dir="auto"><math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4c209c1c84370d912f0f59ed49349881">$$ 0.1234 +0.056 -0.012 = 0.1234_{56}^{12}$$</math-renderer></p>
