<p dir="auto">IntervalArithmetic.jl is a Julia package for validated numerics. All calculations are carried out using <a href="https://en.wikipedia.org/wiki/Interval_arithmetic" rel="nofollow">interval arithmetic</a> where quantities are treated as intervals. The final result is a rigorous enclosure of the true value.</p>
<p dir="auto">The IntervalArithmetic library is compliant with the <a href="https://standards.ieee.org/findstds/standard/1788-2015.html" rel="nofollow">IEEE 1788-2015 standard for interval arithmetic</a>.</p>
<p dir="auto">The IntervalArithmetic library is part of the <a href="https://juliaintervals.github.io" rel="nofollow">JuliaInterval organisation</a>.</p>
