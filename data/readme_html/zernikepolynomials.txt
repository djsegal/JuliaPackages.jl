<p dir="auto">This package provides functionality to work with <a href="https://en.wikipedia.org/wiki/Zernike_polynomials" rel="nofollow">Zernike polynomials</a>.</p>
<p dir="auto">It features the following:</p>
<ul dir="auto">
<li>functions to convert between common serial indices of Zernike polynomials</li>
<li>functions to evaluate the polynomials on a grid</li>
<li>functions to estimate Zernike coefficients in a least squares sense from a user-provided input.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Conversion to and between (Noll &amp; OSA/ANSI) sequential indices</h2><a id="user-content-conversion-to-and-between-noll--osaansi-sequential-indices" class="anchor" aria-label="Permalink: Conversion to and between (Noll &amp; OSA/ANSI) sequential indices" href="#conversion-to-and-between-noll--osaansi-sequential-indices"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package provides conversion utility functions between three common ways of specifying a Zernike polynomial.
Numbering conventions are implemented as subtypes of the abstract type <code>ZernikeIndex</code>.</p>
<p dir="auto">The first is to use <code>NM(n, m)</code> to specify the polynomial <code>Zₙᵐ(ρ,θ)</code>, where <code>n</code> and <code>m</code> are integers with <code>n ≥ abs(m)</code> (further, <code>n - abs(m)</code> must be even), and <code>(ρ,θ)</code> are polar coordinates (radius and angle).</p>
<p dir="auto">The second (sequential) index is the OSA/ANSI standard index (0,1,2,3,...), specified as <code>OSA(j)</code>.</p>
<p dir="auto">The third is Noll's sequential index (1,2,3,...), specified as <code>Noll(j)</code>.</p>
<p dir="auto">Invalid inputs to the <code>ZernikeIndex</code> constructors result in an <code>ArgumentError</code>, which ensures that you can only construct valid indexes. You can convert between types by calling the constructor or using <code>convert</code>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; using ZernikePolynomials

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Evaluating Zernike polynomials</h2><a id="user-content-evaluating-zernike-polynomials" class="anchor" aria-label="Permalink: Evaluating Zernike polynomials" href="#evaluating-zernike-polynomials"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The Zernike polynomials <code>(ρ,θ) -&gt; Zₙᵐ(ρ,θ)</code> or <code>(x,y) -&gt; Zₙᵐ(x,y)</code> can be obtained as a function as follows:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; zernike(NM(1,1))
&gt;&gt; zernike(NM(1,1),coord=:polar)
&gt;&gt; Z = zernike(Noll(5),coord=:cartesian) # 5th polynomial by Noll's numbering
&gt;&gt; Z = zernike(NM(1,1),coord=:cartesian)
&gt;&gt; Z(0.5,0.2) # evaluate the function at cartesian coordinate (0.5,0.2)"><pre>&gt;&gt; zernike(NM(1,1))
&gt;&gt; zernike(NM(1,1),coord=:polar)
&gt;&gt; Z = zernike(Noll(5),coord=:cartesian) # 5th polynomial by Noll's numbering
&gt;&gt; Z = zernike(NM(1,1),coord=:cartesian)
&gt;&gt; Z(0.5,0.2) # evaluate the function at cartesian coordinate (0.5,0.2)</pre></div>
<p dir="auto">Polar coordinates are used by default. The functions return 0 for ρ &gt; 1.</p>
<p dir="auto">Zernike polynomials and affine combination thereof can easily be evaluated on a grid of points using the function <code>evaluatezernike()</code>.</p>
<p dir="auto">For example, to evaluate 0.5<em>Z_2 + 0.3</em>Z_3 (by OSA numbering) on a 256x256 grid, use the following</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; evaluatezernike(256, OSA.([2, 3]), [0.5, 0.3])"><pre>&gt;&gt; evaluatezernike(256, OSA.([2, 3]), [0.5, 0.3])</pre></div>
<p dir="auto">To evaluate it on a (square) grid with predefined coordinates, use for example</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; x = LinRange(-2,2,256)
&gt;&gt; ϕ = evaluatezernike(x, OSA.([2, 3]), [0.5, 0.3])
&gt;&gt; using Plots
&gt;&gt; heatmap(ϕ)"><pre>&gt;&gt; x = LinRange(-2,2,256)
&gt;&gt; ϕ = evaluatezernike(x, OSA.([2, 3]), [0.5, 0.3])
&gt;&gt; using Plots
&gt;&gt; heatmap(ϕ)</pre></div>
<p dir="auto">Here the range <code>x</code> is a range that gives the x and y coordinates.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Zernike polynomial normalization</h3><a id="user-content-zernike-polynomial-normalization" class="anchor" aria-label="Permalink: Zernike polynomial normalization" href="#zernike-polynomial-normalization"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The Zernike polynomials are normalized according to Thibos et al. - "Standards for Reporting the Optical Aberrations of Eyes", i.e.
$$
N_n^m = \sqrt{2 (n+1) / (1 + δ(m,0))}
$$
where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="24496b0072777326de67be85b479c1d9">$δ(m,0) = 1$</math-renderer> for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="24496b0072777326de67be85b479c1d9">$m = 0$</math-renderer> and 0 otherwise.
These normalization constants can be obtained by <code>normalization(m,n)</code>:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; [normalization(NM(OSA(i))) for i in 0:5]"><pre>&gt;&gt; [normalization(NM(OSA(i))) for i in 0:5]</pre></div>
<p dir="auto">Note that the definition on the <a href="https://en.wikipedia.org/wiki/Zernike_polynomials" rel="nofollow">Wikipedia page on Zernike polynomials</a> is different. Here the polynomials are normalized between [-1,1].
When using or reporting (estimated) Zernike coefficients, it is important to be aware of which normalization has been used.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Estimating Zernike coefficients in a least squares sense</h2><a id="user-content-estimating-zernike-coefficients-in-a-least-squares-sense" class="anchor" aria-label="Permalink: Estimating Zernike coefficients in a least squares sense" href="#estimating-zernike-coefficients-in-a-least-squares-sense"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">A common use for Zernike polynomials is to approximate a given 2D input.
Since Zernike polynomials are often used in optics to approximate a 2D phase, this is the term used in the function documentation.</p>
<p dir="auto">The function <code>zernikecoefficients()</code> estimates (in a least-squares sense) the optimal coefficients for a sum of Zernike polynomials. A vector of (sequential) indices should be provided to specify which coefficients should be estimated</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; ϕ = evaluatezernike(256, OSA.([2, 3]), [0.5, 0.3])
&gt;&gt; zernikecoefficients(ϕ, OSA.([2, 3])) # ≈ [0.5, 0.3]"><pre>&gt;&gt; ϕ = evaluatezernike(256, OSA.([2, 3]), [0.5, 0.3])
&gt;&gt; zernikecoefficients(ϕ, OSA.([2, 3])) # ≈ [0.5, 0.3]</pre></div>
<p dir="auto">It is also possible to specify on which coordinates the phase is defined:</p>
<div class="highlight highlight-source-julia-console notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="&gt;&gt; x = LinRange(-2,2,256)
&gt;&gt; ϕ = evaluatezernike(x, Noll.([2, 3]), [0.5, 0.3])
&gt;&gt; zernikecoefficients(x, ϕ, Noll.([1, 3])) # ≈ [0.0, 0.3]"><pre>&gt;&gt; x = LinRange(-2,2,256)
&gt;&gt; ϕ = evaluatezernike(x, Noll.([2, 3]), [0.5, 0.3])
&gt;&gt; zernikecoefficients(x, ϕ, Noll.([1, 3])) # ≈ [0.0, 0.3]</pre></div>
<p dir="auto">Note that in this last example the coefficient for the Zernike polynomial with Noll index 1 is estimated, but this is not present in ϕ. Therefore the estimated coefficient is 0.</p>
