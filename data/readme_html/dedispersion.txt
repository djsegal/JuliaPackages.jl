<div align="justify" dir="auto">
<p dir="auto">As radio waves travel through space, they pass through a lot of ionised gas, or plasma. This plasma acts, in many ways, like a prism; that is, it slows down radio waves at lower frequencies. Thus, radio waves at higher frequencies arrive earlier than those at lower frequencies. These delays introduce a smearing effect into time-domain data. <strong>Dedispersion</strong> is a technique used to undo this smearing effect, allowing us to detect both single and/or periodic pulses from sources such as pulsars, rotational radio transients (or RRATs), and fast radio bursts (or FRBs). <code>Dedispersion.jl</code> is a meta-package that brings together packages implementing various dedispersion algorithms in pure Julia. Currently, these are:</p>
<ul dir="auto">
<li><a href="https://github.com/astrogewgaw/DirectDedispersion.jl"><strong><code>DirectDedispersion.jl</code></strong></a></li>
<li><a href="https://github.com/astrogewgaw/RollingDedispersion.jl"><strong><code>RollingDedispersion.jl</code></strong></a></li>
<li><a href="https://github.com/astrogewgaw/FastDedispersion.jl"><strong><code>FastDedispersion.jl</code></strong></a></li>
</ul>
<p dir="auto">with more packages in development. More information on how to use this package can be found in the documentation of each of the individual packages above. More comprehensive documentation is on the way.</p>
