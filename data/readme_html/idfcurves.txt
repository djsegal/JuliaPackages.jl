<p dir="auto">IDFCurves.jl is a package in the <strong>Julia</strong> programming language ecosystem. It specializes in the statistical estimation of Intensity-Duration-Frequency curves. It provides exhaustive, high-performance functions by leveraging the multiple-dispatch capabilities in <strong>Julia</strong>. In particular, the package implements:</p>
<ul dir="auto">
<li>Estimating several scaling models for IDF curves</li>
<li>Performing goodness-of-fit tests for scaling models</li>
<li>Modelling the dependence of maxima across durations</li>
<li>Estimating the uncertainty of IDF curves</li>
<li>Displaying IDF curve estimates and their uncertainty</li>
</ul>
<p dir="auto">IDFCurves.jl leverage on <a href="https://github.com/jojal5/Extremes.jl">Extremes.jl</a> for the analysis of extreme values.</p>
