<p dir="auto"><code>CartesianDomains.jl</code> is a lightweight library used to work with Cartesian domains and provide conveinent indexing functions. This arose from a need to write dimension-agnostic code for stencil-like operations and halo-aware domains.</p>
<p dir="auto">The currently exported functions include:</p>
<ul dir="auto">
<li><code>shift</code>: Shift a <code>CartesianIndex</code> by <code>n</code> along a given axis. This is useful for getting indices like <code>[i+1,j,k]</code> but in a dimension agnostic manner</li>
<li><code>expand</code>: Expand a <code>domain:CartesianIndices{N}</code> by <code>n</code> (or contract by <code>-n</code>) along all <code>axes</code> or a specified <code>axis</code></li>
<li><code>expand_lower</code>: Expand a <code>domain:CartesianIndices{N}</code> by <code>n</code> (or contract by <code>-n</code>) along the lower bound on all along all <code>axes</code> or a specified <code>axis</code></li>
<li><code>expand_upper</code>: Expand a <code>domain:CartesianIndices{N}</code> by <code>n</code> (or contract by <code>-n</code>) along the upper bound on all along all <code>axes</code> or a specified <code>axis</code></li>
<li><code>extract_from_lower</code>: Extract a subdomain at the lower bound from <code>domain:CartesianIndices{N}</code> along all axes or a give <code>axis</code> with a width of <code>n</code></li>
<li><code>extract_from_upper</code>: Extract a subdomain from the upper bound from <code>domain:CartesianIndices{N}</code> along all axes or a give <code>axis</code> with a width of <code>n</code></li>
<li><code>haloedge_regions</code>: Extract halo and corresponding edge regions from a domain along a given axis, where the subdomain has a size <code>nhalo</code> along a given <code>axis</code>. The user can also specify <code>nedge</code> if the edge region needs to be a smaller size than <code>nhalo</code></li>
</ul>
