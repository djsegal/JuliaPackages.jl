<p align="center" dir="auto"><b>DepotDelivery</b> bundles a Julia project into a standalone depot that can run in air-gapped environments.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features</h2><a id="user-content-features" class="anchor" aria-label="Permalink: Features" href="#features"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>Bundles all necessary Julia code and artifacts needed to run without internet access.</li>
<li>Build for platforms other than the host platform.</li>
<li>Can build multiple packages/projects into a single path.</li>
<li>Can precompile all dependencies to built path.</li>
</ul>

<p dir="auto">This example shows how to build a depo path from different Project.toml files, enabling precompilation as needed.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using DepotDelivery: build

# We can provide a depot_path to share DEPOT_PATH 
depot_path = &quot;path/to/depot/&quot;

# Assumes `path/Project.toml` exists (or `path/JuliaProject.toml`) in each entry of first argument, and force precompilation.
path = build([&quot;path/project-1&quot;, &quot;path-2/project-2&quot;]; depot=depot_path, precompiled=true)"><pre><span class="pl-k">using</span> DepotDelivery<span class="pl-k">:</span> build

<span class="pl-c"><span class="pl-c">#</span> We can provide a depot_path to share DEPOT_PATH </span>
depot_path <span class="pl-k">=</span> <span class="pl-s"><span class="pl-pds">"</span>path/to/depot/<span class="pl-pds">"</span></span>

<span class="pl-c"><span class="pl-c">#</span> Assumes `path/Project.toml` exists (or `path/JuliaProject.toml`) in each entry of first argument, and force precompilation.</span>
path <span class="pl-k">=</span> <span class="pl-c1">build</span>([<span class="pl-s"><span class="pl-pds">"</span>path/project-1<span class="pl-pds">"</span></span>, <span class="pl-s"><span class="pl-pds">"</span>path-2/project-2<span class="pl-pds">"</span></span>]; depot<span class="pl-k">=</span>depot_path, precompiled<span class="pl-k">=</span><span class="pl-c1">true</span>)</pre></div>
<p dir="auto">Be aware that <code>build</code> will copy everything inside those directories to <code>depot_path/dev/</code>. Avoid populating those directories with unnecessary files. For example, when starting a new project, it's better to run <code>julia --project=./isolated_folder/</code> rather than <code>julia --project=.</code>, as in the latter case the <code>Project.toml</code> file will coexist with other stuff.</p>
