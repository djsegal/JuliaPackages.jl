<p dir="auto">Thin Julia wrapper around <a href="https://github.com/newren/git-filter-repo">https://github.com/newren/git-filter-repo</a> (Python). Provides both the raw <code>git-filter-repo</code> API, and several convenience functions on top of it.</p>

<p dir="auto">No additional setup is required after installation: the Python module gets automatically downloaded using the <code>Artifacts</code> system.</p>
