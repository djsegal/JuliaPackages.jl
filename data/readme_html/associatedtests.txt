<p dir="auto">The <code>@tests</code> macro is very simple; it essentially just expands as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@tests add1 begin
  @test add1(1) == 2
end

=&gt;

function __runtest__(::Val{add1})
  @testset &quot;add1&quot; begin
    @test add1(1) == 2
  end
end"><pre><span class="pl-c1">@tests</span> add1 <span class="pl-k">begin</span>
  <span class="pl-c1">@test</span> <span class="pl-c1">add1</span>(<span class="pl-c1">1</span>) <span class="pl-k">==</span> <span class="pl-c1">2</span>
<span class="pl-k">end</span>

<span class="pl-k">=&gt;</span>

<span class="pl-k">function</span> <span class="pl-en">__runtest__</span>(<span class="pl-k">::</span><span class="pl-c1">Val{add1}</span>)
  <span class="pl-c1">@testset</span> <span class="pl-s"><span class="pl-pds">"</span>add1<span class="pl-pds">"</span></span> <span class="pl-k">begin</span>
    <span class="pl-c1">@test</span> <span class="pl-c1">add1</span>(<span class="pl-c1">1</span>) <span class="pl-k">==</span> <span class="pl-c1">2</span>
  <span class="pl-k">end</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">This means that <code>__runtest__</code> will get reloaded by Revise without any special effort, and doesn't pollute the global namespace with any local variables defined in the tests.</p>
<p dir="auto">Then <code>test(f) = parentmodule(f).__runtest__(Val{f}())</code>. One can also pass in two arguments to <code>test</code> in order to run tests in a module other than the parent module. For instance:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="module MyVectors

struct MyVector
  ...
end

function Base.getindex(v::MyVector, i)
  ...
end

@tests getindex begin
  ...
end"><pre><span class="pl-k">module</span> MyVectors

<span class="pl-k">struct</span> MyVector
  <span class="pl-k">...</span>
<span class="pl-k">end</span>

<span class="pl-k">function</span> Base<span class="pl-k">.</span><span class="pl-en">getindex</span>(v<span class="pl-k">::</span><span class="pl-c1">MyVector</span>, i)
  <span class="pl-k">...</span>
<span class="pl-k">end</span>

<span class="pl-c1">@tests</span> getindex <span class="pl-k">begin</span>
  <span class="pl-k">...</span>
<span class="pl-k">end</span></pre></div>
<p dir="auto">You can then run these tests with <code>test(MyVectors, getindex) = MyVectors.__runtest__(getindex)</code>.</p>
<p dir="auto"><code>test(MyVectors)</code> iterates through all of the defined methods of <code>MyVectors.__runtest__</code> and calls them all.</p>
