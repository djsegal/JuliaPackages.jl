<p dir="auto"><em>Fast &amp; flexible processing of lidar data</em></p>
<p dir="auto"><a href="https://github.com/efpl-columbia/PointClouds.jl">PointClouds.jl</a> lets you
query publicly available lidar point-cloud datasets, download the data for
regions of interest, and explore &amp; process the data locally. You can access all
attributes stored in <a href="https://en.wikipedia.org/wiki/LAS_file_format" rel="nofollow">LAS/LAZ</a>
files and construct purpose-built processing pipelines that extract information
about the local environment from point-cloud data.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Features &amp; Goals</h2><a id="user-content-features--goals" class="anchor" aria-label="Permalink: Features &amp; Goals" href="#features--goals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto"><a href="https://docs.mfsch.dev/PointClouds.jl/" rel="nofollow"><img src="https://camo.githubusercontent.com/001230040594030023ef3b5556dfbd530fbc6d69d1b4e77ef2f189698cbcb2d8/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f2546302539462539352541452d4f6e6c696e655f446f63756d656e746174696f6e2d324336424143" alt="Online Documentation" data-canonical-src="https://img.shields.io/badge/%F0%9F%95%AE-Online_Documentation-2C6BAC" style="max-width: 100%;"></a></p>
<p dir="auto">PointClouds.jl aims to provide all functionality for an ergonomic,
high-performance workflow to acquire and process point-cloud data. The initial
development is focused on producing robust primitives for such a workflow.
Over time, we expect the functionality to expand, building out a comprehensive
library of point-cloud processing algorithms similar to
<a href="https://pdal.io/" rel="nofollow">PDAL</a> and <a href="https://r-lidar.github.io/lidRbook/" rel="nofollow">lidR</a>.</p>
<ul dir="auto">
<li>spatial queries of the <a href="https://www.usgs.gov/3d-elevation-program" rel="nofollow">USGS 3DEP lidar
data</a> with near-total coverage of
the United States</li>
<li>reading &amp; writing <a href="https://en.wikipedia.org/wiki/LAS_file_format" rel="nofollow">LAS/LAZ</a>
files (v1.0 – v1.4), including files that do not fit into memory</li>
<li>lazy filtering &amp; updating of LAS/LAZ points</li>
<li>parsing LAS coordinate reference system (CRS) data in WKT &amp; GeoTIFF formats;
coordinate transforms</li>
<li>multi-threaded in-memory processing of point-cloud data, including
neighborhood-based processing</li>
<li>rasterization of point-cloud data based on points within pixel footprint,
points within radius of pixel center, and <em>k</em> nearest neighbors of pixel
center</li>
</ul>
<p dir="auto">For more details, see the <a href="https://docs.mfsch.dev/PointClouds.jl" rel="nofollow">documentation</a>.</p>
