<p dir="auto">IterGP uses the <a href="https://github.com/JuliaGaussianProcesses/AbstractGPs.jl">AbstractGPs</a> interface.</p>

<p dir="auto">The IterGP API builds around <code>AbstractGPs.AbstractGP</code>, and exposes policies that can be used to call <code>IterGP.posterior</code>, which is where the magic happens.</p>
<p dir="auto">As a way to cache computations (such as preconditioners), the policy object itself is not called in the innermost loop. Instead, the policy is used to create an /actor/ which is then called in the inner loop until a convergence criteria is met.</p>
