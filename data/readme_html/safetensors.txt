<p dir="auto">This packages loads data stored in <a href="https://huggingface.co/docs/safetensors/index" rel="nofollow">safetensor format</a>.
Since Python is row-major and Julia is column-major, the dimensions are permuted such the tensor has the same shape as in python, but everything is correctly ordered. This includes a performance penalty in sense that we cannot be completely copy-free.</p>
<p dir="auto">The main function is <code>load_safetensors</code> which returns a <code>Dict{String,V}</code> where keys are names of tensors and values are tensors. An example from <code>runtests</code> is as follows</p>
