<p dir="auto">Genie.jl is the backbone of the <a href="https://genieframework.com" rel="nofollow">Genie Framework</a>, which provides a streamlined and efficient workflow for developing modern web applications. It builds on Julia's strengths (high-level, high-performance, dynamic, JIT compiled), exposing a rich API and a powerful toolset for productive web development.</p>
<p dir="auto">Genie Framework is composed of four main components:</p>
<ul dir="auto">
<li><strong><a href="https://github.com/GenieFramework/Genie.jl">Genie.jl</a></strong>: the server backend, providing features for routing, templating, authentication, and much more.</li>
<li><strong><a href="https://github.com/GenieFramework/Stipple.jl">Stipple.jl</a></strong>: a package for building reactive UIs with a simple and powerful low-code API in pure Julia.</li>
<li><strong><a href="https://learn.genieframework.com/docs/genie-builder/quick-start" rel="nofollow">Genie Builder</a></strong>: a VSCode plugin for building UIs visually in a drag-and-drop editor.</li>
<li><strong><a href="https://github.com/GenieFramework/SearchLight.jl">SearchLight.jl</a></strong>: a complete ORM solution, enabling easy database integration without writing SQL queries.</li>
</ul>
<p dir="auto">To learn more about Genie, visit the <a href="https://learn.genieframework.com/docs/guides" rel="nofollow">documentation</a>, and the <a href="https://learn.genieframework.com/app-gallery" rel="nofollow">app gallery</a>.</p>
<p dir="auto">If you need help with anything, you can find us on <a href="https://discord.com/invite/9zyZbD6J7H" rel="nofollow">Discord</a>.</p>

<p dir="auto">🛠<strong>Genie Router:</strong> Genie has a really powerful
💪 <code>Router</code>. Matching web requests to functions, extracting and setting up the request's variables and the execution environment, and invoking the response methods. Features include:</p>
<ul dir="auto">
<li>Static, Dynamic, Named routing</li>
<li>Routing parameters</li>
<li>Linking routes</li>
<li>Route management (Listing, Deleting, Modifying) support</li>
<li>Routing methods (<code>GET</code>, <code>POST</code>, <code>PUT</code>, <code>PATCH</code>, <code>DELETE</code>, <code>OPTIONS</code>)</li>
<li>and more ...</li>
</ul>
