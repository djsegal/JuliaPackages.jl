<p dir="auto">Welcome to CedarEDA. Cedar is a modern green-field EDA stack, currently focused on analog design verification. You may find the Cedar source code in a number of packages at <a href="https://github.com/CedarEDA">https://github.com/CedarEDA</a>. This package (CedarEDA.jl) is the integration package. It provides high level APIs for various common tasks, end-to-end examples, as well as the code to build production images for juliahub.com (both commerical and open source versions).</p>
<p dir="auto">To get started, please see the documentation at <a href="https://help.juliahub.com/cedareda/" rel="nofollow">https://help.juliahub.com/cedareda/</a>. You may also be interested in exploring various component packages:</p>
<ul dir="auto">
<li><a href="https://github.com/CedarEDA/CedarSim.jl">CedarSim</a> is our fast analog simulator</li>
<li><a href="https://github.com/CedarEDA/CedarWaves.jl">CedarWaves</a> is our waveform processing framework</li>
<li>The documentation (<a href="https://help.juliahub.com/cedareda/" rel="nofollow">https://help.juliahub.com/cedareda/</a>) has a rendered version of the examples gallery (<code>examples</code> in this package). Live versions are also available in the public juliahub.com image.</li>
<li>To get started with designing your circuit in a particular PDK, please see the PDK-specific documentation: <a href="https://github.com/CedarEDA/Sky130PDK.jl">Skywater 130nm</a> or <a href="https://github.com/CedarEDA/GF180MCUPDK.jl">GF 180nm</a></li>
</ul>
