<p dir="auto">AIHelpMe harnesses the power of Julia's extensive documentation and advanced AI models to provide tailored coding guidance. By integrating with PromptingTools.jl, it offers a unique, AI-assisted approach to answering your coding queries directly in Julia's environment.</p>

<ul dir="auto">
<li><strong>AI-Powered Assistance</strong>: Get context-aware answers to your coding questions.</li>
<li><strong>Easy-to-Use Interface</strong>: Simple function and macro to input your questions.</li>
<li><strong>Flexible Querying</strong>: Use different AI models for varied insights and performance versus cost trade-offs.</li>
<li><strong>Cost-Effective</strong>: Download pre-embedded documentation to save on API calls.</li>
<li><strong>Uniquely Tailored</strong>: Leverage the currently loaded documentation, regardless of whether it's private or public.</li>
</ul>

<p dir="auto"><strong>Prerequisites:</strong></p>
<ul dir="auto">
<li>Julia (version 1.10 or later).</li>
<li>Internet connection for API access.</li>
<li>OpenAI API keys with available credits. See <a href="#how-to-obtain-api-keys">How to Obtain API Keys</a>.</li>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">How it works</h2><a id="user-content-how-it-works" class="anchor" aria-label="Permalink: How it works" href="#how-it-works"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">AIHelpMe leverages <a href="https://github.com/svilupp/PromptingTools.jl">PromptingTools.jl</a> to communicate with the AI models.</p>
<p dir="auto">We apply a Retrieval Augment Generation (RAG) pattern, ie,</p>
<ul dir="auto">
<li>we pre-process all available documentation (and "embed it" to convert text snippets into numbers)</li>
<li>when a question is asked, we look up the most relevant documentation snippets</li>
<li>we feed the question and the documentation snippets to the AI model</li>
<li>the AI model generates the answer</li>
</ul>
<p dir="auto">This ensures that the answers are not only based on general AI knowledge but are also specifically tailored to Julia's ecosystem and best practices.</p>
<p dir="auto">The "knowledge packs" are sourced from documentation sites and then processed with <a href="https://github.com/JuliaGenAI/DocsScraper.jl">DocsScraper.jl</a>.</p>

<p dir="auto"><strong>Q: Is it expensive to embed all my documentation?</strong>
A: No, embedding a comprehensive set of documentation is surprisingly cost-effective. Embedding around 170 modules, including all standard libraries and more, costs approximately 8 cents and takes less than 30 seconds.
To save you money, we have already embedded the Julia standard libraries and made them available for download via Artifacts.
We expect that any further knowledge base extensions should be at most a few cents (see <a href="#extending-the-knowledge-base">Extending the Knowledge Base</a>).</p>
<p dir="auto"><strong>Q: How much does it cost to ask a question?</strong>
A: Each query incurs only a fraction of a cent, depending on the length and chosen model.</p>
<p dir="auto"><strong>Q: Can I use the Cohere Trial API Key for commercial projects?</strong>
A: No, a trial key is only for testing purposes. But it takes only a few clicks to switch to Production API. The cost is only $1 per 1000 searches (!!!) and has many other benefits.</p>
<p dir="auto"><strong>Q: How accurate are the answers?</strong>
A: Like any other Generative AI answers, ie, it depends and you should always double-check.</p>
<p dir="auto"><strong>Q: Can I use it without the internet?</strong>
A: Not at the moment. It might be possible in the future, as PromptingTools.jl supports local LLMs.</p>
<p dir="auto"><strong>Q: Why do we need Cohere API Key?</strong>
A: Cohere's API is used to re-rank the best matching snippets from the documentation. It's free to use in limited quantities (ie, ~thousand requests per month), which should be enough for most users. Re-ranking improves the quality and accuracy of the answers.</p>
<p dir="auto"><strong>Q: Why do we need Tavily API Key?</strong>
A: Tavily's API is used to search the best matching snippets from the documentation. It's free to use in limited quantities (ie, ~thousand requests per month), which should be enough for most users. Searching improves the quality and accuracy of the answers.</p>
<p dir="auto"><strong>Q: Can we use Ollama (locally-hosted) models?</strong>
A: Yes, see the Advanced section in the docs.</p>
<p dir="auto"><strong>Q: How can I build knowledge packs for my package(s)?</strong>
A: Check out package <a href="https://github.com/JuliaGenAI/DocsScraper.jl">DocsScraper.jl</a>. It's what we use to build the knowledge packs loaded in this package!</p>
