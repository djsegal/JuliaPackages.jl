<p dir="auto">A <a href="https://en.wikipedia.org/wiki/Parareal" rel="nofollow">parareal</a> orchestrator written in Julia.</p>

<a href="https://gitlab.mpi-magdeburg.mpg.de/jschulze/ParaReal.jl/commits/main" rel="nofollow"><img src="https://camo.githubusercontent.com/ae8d21e4142a885affefe4409866a785a3950402921f9573bbedc30b2806f84b/68747470733a2f2f6769746c61622e6d70692d6d61676465627572672e6d70672e64652f6a736368756c7a652f506172615265616c2e6a6c2f6261646765732f6d61696e2f636f7665726167652e737667" alt="Coverage" data-canonical-src="https://gitlab.mpi-magdeburg.mpg.de/jschulze/ParaReal.jl/badges/main/coverage.svg" style="max-width: 100%;"></a></p>
<p dir="auto">It has been tested on a <a href="https://slurm.schedmd.com/" rel="nofollow">Slurm</a> allocation using 450 cores on 29 nodes.</p>
<p dir="auto">Main features:</p>
<ul dir="auto">
<li>Arbitrary problem and solution types</li>
<li>Lazy data management (does not implicitly send data to calling process)</li>
<li>Heterogeneous parareal values/iterates w.r.t. storage size and data type</li>
<li>Parallel warm-up of solvers</li>
<li>Logging solver start and stop times</li>
</ul>

<p dir="auto">Check out the demo and test files:</p>
<ul dir="auto">
<li><code>demo/riccati.jl</code> solves a differential Riccati equation (DRE) having a low-rank solution</li>
<li><code>demo/counting.jl</code> counts solver applications (demo for custom types)</li>
<li><code>test/problems/diffeq-ode.jl</code> solves a linear ordinary differential equation (ODE) using <a href="https://github.com/SciML/OrdinaryDiffEq.jl">OrdinaryDiffEq.jl</a></li>
<li><code>test/problems/non-diffeq.jl</code> counts time discretization points (test for custom types)</li>
</ul>
