<p dir="auto">This package is an overlay  for FinEtools-based application packages. It can be
used to parallelize certain finite element operations with multithreading.</p>
<p dir="auto">Currently, sparse matrix operators can be assembled in parallel on multiple threads. Please refer to the documentation.</p>
