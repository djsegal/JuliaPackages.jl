<p dir="auto">Linear combinations of parameters for <a href="https://github.com/FixedEffects/FixedEffectModels.jl"><code>FixedEffectModels.jl</code></a> and <a href="https://github.com/xiaobaaaa/EventStudyInteracts.jl"><code>EventStudyInteracts.jl</code></a> like Stata package <code>lincom</code>. As Stata package <code>lincom</code> help document explains:</p>
<blockquote>
<p dir="auto"><code>lincom</code> computes point estimates, standard errors, t or z statistics, p-values, and confidence intervals for linear combinations of coefficients after any estimation command, including survey estimation. Results can optionally be displayed as odds ratios, hazard ratios, incidence-rate ratios, or relative-risk ratios.</p>
</blockquote>
<p dir="auto"><code>lincom</code> can be used to aggregating event study estimates and estimate the average effect when use the Stata package <a href="https://github.com/lsun20/EventStudyInteract"><code>eventstudyinteract</code></a> provided by <a href="https://www.sciencedirect.com/science/article/abs/pii/S030440762030378X" rel="nofollow">Sun and Abraham (2021)</a>.</p>
<p dir="auto">I wrote the <a href="https://github.com/FixedEffects/FixedEffectModels.jl"><code>EventStudyInteracts.jl</code></a> package, which is a Julia replication of the Stata package <a href="https://github.com/lsun20/EventStudyInteract"><code>eventstudyinteract</code></a> provided by <a href="https://www.sciencedirect.com/science/article/abs/pii/S030440762030378X" rel="nofollow">Sun and Abraham (2021)</a>. However, there is currently no package in Julia similar to lincom, so I wrote this package.</p>
<p dir="auto">This package can also be used for t-tests of linear combinations of results from FixedEffectModels.jl.</p>

<p dir="auto">The package is registered in the <a href="https://github.com/JuliaRegistries/General"><code>General</code></a> registry and so can be installed at the REPL with <code>] add LinComs</code>.</p>
