<p dir="auto">CLIPS is an architecture for pragmatic instruction following and goal assistance via cooperative Bayesian inverse planning with language model likelihoods.</p>
<p dir="auto">Using CLIPS, you can build assistive agents that infer the goals of humans from both their actions and instructions. This allows CLIPS to interpret ambiguous instructions, because an agent's actions or goals may help to disambiguate such instructions.</p>
<p align="center" dir="auto">

</p>
<p dir="auto">This repository contains a Julia implementation of CLIPS built using the <a href="https://github.com/probcomp/Gen.jl">Gen.jl</a> probabilistic programming system, the <a href="https://github.com/JuliaPlanners/PDDL.jl">PDDL.jl</a> planning library, and the <a href="https://github.com/probcomp/InversePlanning.jl">InversePlanning.jl</a> library for Bayesian inverse planning.</p>
<p dir="auto">For more details about CLIPS, see <a href="https://arxiv.org/abs/2402.17930" rel="nofollow">our paper</a>:</p>
<blockquote>
<p dir="auto">Tan Zhi-Xuan, Lance Ying, Vikash Mansinghka, and Joshua B. Tenenbaum. 2024. <strong>Pragmatic Instruction Following and Goal Assistance via Cooperative Language-Guided Inverse Planning.</strong> In Proc. of the 23rd International Conference on Autonomous Agents and Multiagent Systems (AAMAS 2024).</p>
</blockquote>

<p dir="auto">This repository contains code for the multi-agent Doors, Keys &amp; Gems domain in the <code>doors-keys-gems</code> folder, and code for our VirtualHome experiments in <code>virtual-home</code>. For each domain, there is a:</p>
<ul dir="auto">
<li><code>dataset</code> folder, containing the PDDL domain, problems, observed actions and utterances, and for <code>doors-keys-gems</code>, a set of visual stimuli for our human experiments.</li>
<li><code>src</code> folder, containing reusable code (utterance models, planner configurations, inference algorithms and baselines)</li>
<li><code>experiments.jl</code>, a script that runs CLIPS and the other baselines on the full dataset of goal assistance problems.</li>
<li><code>testbed.jl</code>, a script that allows for experimenting with and reconfiguring CLIPS for a single goal assistance problem.</li>
</ul>
<p dir="auto">The <code>doors-keys-gems</code> folder also contains a <code>stimuli.jl</code> script for generating the stimuli GIFs used in our human experiments.</p>
