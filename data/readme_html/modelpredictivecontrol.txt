<p dir="auto">An open source <a href="https://en.wikipedia.org/wiki/Model_predictive_control" rel="nofollow">model predictive control</a>
package for Julia.</p>
<p dir="auto">The package depends on <a href="https://github.com/JuliaControl/ControlSystems.jl"><code>ControlSystemsBase.jl</code></a>
for the linear systems and <a href="https://github.com/jump-dev/JuMP.jl"><code>JuMP.jl</code></a> for the solving.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Getting Started</h2><a id="user-content-getting-started" class="anchor" aria-label="Permalink: Getting Started" href="#getting-started"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">To construct model predictive controllers (MPCs), we must first specify a plant model that
is typically extracted from input-output data using <a href="https://github.com/baggepinnen/ControlSystemIdentification.jl">system identification</a>.
The model here is linear with one input, two outputs and a large time delay in the first
channel:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="42e109bbab1acf84ca424f6434adda1a">$$\mathbf{G}(s) = \frac{\mathbf{y}(s)}{\mathbf{u}(s)} = 
\begin{bmatrix}
    \frac{2e^{-20s}}{10s + 1} \\[3pt]
    \frac{10}{4s +1}
\end{bmatrix}$$</math-renderer>
<p dir="auto">We first construct the plant model with a sample time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="42e109bbab1acf84ca424f6434adda1a">$T_s = 1$</math-renderer> s:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ModelPredictiveControl, ControlSystemsBase
G = [ tf( 2 , [10, 1])*delay(20)
      tf( 10, [4,  1]) ]
Ts = 1.0
model = LinModel(G, Ts)"><pre><span class="pl-k">using</span> ModelPredictiveControl, ControlSystemsBase
G <span class="pl-k">=</span> [ <span class="pl-c1">tf</span>( <span class="pl-c1">2</span> , [<span class="pl-c1">10</span>, <span class="pl-c1">1</span>])<span class="pl-k">*</span><span class="pl-c1">delay</span>(<span class="pl-c1">20</span>)
      <span class="pl-c1">tf</span>( <span class="pl-c1">10</span>, [<span class="pl-c1">4</span>,  <span class="pl-c1">1</span>]) ]
Ts <span class="pl-k">=</span> <span class="pl-c1">1.0</span>
model <span class="pl-k">=</span> <span class="pl-c1">LinModel</span>(G, Ts)</pre></div>
<p dir="auto">Our goal is controlling the first output <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="42e109bbab1acf84ca424f6434adda1a">$y_1$</math-renderer>, but the second one <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="42e109bbab1acf84ca424f6434adda1a">$y_2$</math-renderer> should never exceed
35:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="mpc = LinMPC(model, Mwt=[1, 0], Nwt=[0.1])
mpc = setconstraint!(mpc, ymax=[Inf, 35])"><pre>mpc <span class="pl-k">=</span> <span class="pl-c1">LinMPC</span>(model, Mwt<span class="pl-k">=</span>[<span class="pl-c1">1</span>, <span class="pl-c1">0</span>], Nwt<span class="pl-k">=</span>[<span class="pl-c1">0.1</span>])
mpc <span class="pl-k">=</span> <span class="pl-c1">setconstraint!</span>(mpc, ymax<span class="pl-k">=</span>[<span class="pl-c1">Inf</span>, <span class="pl-c1">35</span>])</pre></div>
<p dir="auto">The keyword arguments <code>Mwt</code> and <code>Nwt</code> are the output setpoint tracking and move suppression
weights, respectively. A setpoint step change of five tests <code>mpc</code> controller in closed-loop.
The result is displayed with <a href="https://github.com/JuliaPlots/Plots.jl"><code>Plots.jl</code></a>:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Plots
ry = [5, 0]
res = sim!(mpc, 40, ry)
plot(res, plotry=true, plotymax=true)"><pre><span class="pl-k">using</span> Plots
ry <span class="pl-k">=</span> [<span class="pl-c1">5</span>, <span class="pl-c1">0</span>]
res <span class="pl-k">=</span> <span class="pl-c1">sim!</span>(mpc, <span class="pl-c1">40</span>, ry)
<span class="pl-c1">plot</span>(res, plotry<span class="pl-k">=</span><span class="pl-c1">true</span>, plotymax<span class="pl-k">=</span><span class="pl-c1">true</span>)</pre></div>
