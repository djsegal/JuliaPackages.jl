<p dir="auto"><code>RobustTDA.jl</code> provides a robust and flexible framework for computing persistent homology from point-cloud data in the presence of noise. RobustTDA uses the blazing fast <a target="_blank" rel="noopener noreferrer" href="https://github.com/mtsch/Ripserer.jl"><img src="https://github.com/mtsch/Ripserer.jl" alt="Ripserer.jl" style="max-width: 100%;"></a> backend for computing persistent homology.</p>
<p dir="auto">Please see the <a target="_blank" rel="noopener noreferrer" href=""><img src="" alt="documentation" style="max-width: 100%;"></a> for further information, usage and examples.</p>
