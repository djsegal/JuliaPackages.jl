<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">About Comodo</h1><a id="user-content-about-comodo" class="anchor" aria-label="Permalink: About Comodo" href="#about-comodo"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Comodo is a <a href="https://julialang.org/" rel="nofollow">Julia</a> package for <strong>computational (bio)mechanics and computational design</strong>, and offers functionality for geometry processing, meshing, finite element analysis, automated design, topology optimisation, and image-based modelling.</p>
<p dir="auto">Loosely Comodo could stand for <strong>Com</strong>putational <strong>Mo</strong>delling for <strong>D</strong>esign <strong>O</strong>ptimization. A more philosophical angle would be to say that <strong>DO</strong> is like <em>-do</em> in the Japanese art <em>Judo</em> (ju=柔=gentle, do=道=way), so in this sense Comodo stands for <em>"the way of computational modelling"</em>. Comodo is perhaps best defined by its scope. Comodo aims to be a "one-stop-shop" for researchers in computational (bio)mechanics and computational design. It will feature tools for geometry processing, meshing, automated design / topology optimization, finite element analysis, as well as (e.g. medical) image processing and segmentation.</p>
<p dir="auto">Comodo.jl started out as a modern re-implementation in Julia of the MATLAB toolbox <a href="https://github.com/gibbonCode/GIBBON">GIBBON</a>. However, rather than literally porting each functional unit, it instead aims to follow a similar philosophy and cover similar but more advanced core functionaly.</p>

<p dir="auto">For finite element analysis users are encouraged to combine the Comodo capabilities with the open source C++ solver <a href="https://febio.org/" rel="nofollow">FEBio</a>, e.g. based on the Julia wrapper <a href="https://github.com/febiosoftware/FEBio.jl">FEBio.jl</a>. In addition, users may want to explore the Julia packages <a href="https://github.com/gridap/Gridap.jl">Gridap.jl</a> and <a href="https://github.com/Ferrite-FEM/Ferrite.jl">Ferrite.jl</a>.</p>
