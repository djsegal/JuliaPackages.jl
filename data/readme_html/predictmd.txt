<p dir="auto"><a href="https://predictmd.net" rel="nofollow">PredictMD</a> is a free and open-source Julia package that provides a uniform interface for machine learning.</p>
<p dir="auto">PredictMD makes it easy to automate machine learning workflows and create reproducible machine learning pipelines.</p>
<p dir="auto">It is the official machine learning framework of the <a href="https://github.com/bcbi">Brown Center for Biomedical Informatics</a>.</p>

<p dir="auto">Alternatively, you can use the PredictMD Docker image for easy installation. Download and start the container by running the following line:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker run --name predictmd -it dilumaluthge/predictmd /bin/bash"><pre>docker run --name predictmd -it dilumaluthge/predictmd /bin/bash</pre></div>
<p dir="auto">Once you are inside the container, you can start Julia by running the following line:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia"><pre>julia</pre></div>
<p dir="auto">In Julia, run the following line to load PredictMD:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import PredictMDFull"><pre><span class="pl-k">import</span> PredictMDFull</pre></div>
<p dir="auto">You can run the test suite by running the following four lines in Julia:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="import Pkg
Pkg.test(&quot;PredictMDExtra&quot;)
Pkg.test(&quot;PredictMDFull&quot;)
Pkg.test(&quot;PredictMD&quot;)"><pre><span class="pl-k">import</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">test</span>(<span class="pl-s"><span class="pl-pds">"</span>PredictMDExtra<span class="pl-pds">"</span></span>)
Pkg<span class="pl-k">.</span><span class="pl-c1">test</span>(<span class="pl-s"><span class="pl-pds">"</span>PredictMDFull<span class="pl-pds">"</span></span>)
Pkg<span class="pl-k">.</span><span class="pl-c1">test</span>(<span class="pl-s"><span class="pl-pds">"</span>PredictMD<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">After you have exited the container, you can return to it by running the following line:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker start -ai predictmd"><pre>docker start -ai predictmd</pre></div>
<p dir="auto">To delete your container, run the following line:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker container rm -f predictmd"><pre>docker container rm -f predictmd</pre></div>
<p dir="auto">To also delete the downloaded image, run the following line:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="docker image rm -f dilumaluthge/predictmd"><pre>docker image rm -f dilumaluthge/predictmd</pre></div>
