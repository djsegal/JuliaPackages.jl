<p dir="auto">This package provides a set of tools to work with Markov Processes defined on a 1-dimensional grid</p>

<p dir="auto">The package allows you to compute compute expectations involving Markov processes</p>

<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">Additive Functionals</h1><a id="user-content-additive-functionals" class="anchor" aria-label="Permalink: Additive Functionals" href="#additive-functionals"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><code>M = AdditiveFunctional(X, μm, σm)</code> creates, given a discretized Markov Process, the Additive Functional with drift  <code>μm</code> and volatility <code>σm</code></li>
<li><code>generator(M)</code> returns its associated generator (i.e. the operator <code>f -&gt; ∂_tE[e^{m}f(x_t)|x_0=x]</code>)</li>
<li><code>cgf(m)</code> returns the long run scaled CGF of <code>m</code></li>
<li><code>tail_index(m)</code> returns the tail index of the stationary distribution of <code>e^m</code></li>
</ul>

<p dir="auto">The package also allows you to compute (lazy) first and second derivatives of a function on a grid using a finite difference schemes</p>

<p dir="auto">The argument <code>bc</code> refers to the value of the first-derivative at each limit of the grid. This argument defaults to zero, which is the right condition when solving problems with reflecting boundaries.</p>
