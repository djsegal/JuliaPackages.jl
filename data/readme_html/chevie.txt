<p dir="auto">This is my attempt to port the Chevie package from GAP3 to Julia. I started
this  project at the end of  2018 and it is still  in flux so some function
names or interfaces may still change. Pull requests and issues are welcome.</p>
<p dir="auto">I  have implemented the  GAP functionality (infrastructure)  needed to make
Chevie  work.  I  have  already  registered  most of this infrastructure as
separate  packages; the  following packages  are loaded  and re-exported so
that  their functionality is automatically available when you use <code>Chevie</code>.
In other words, <code>Chevie</code> is a meta-package for the following packages:</p>
<ul dir="auto">
<li>(univariate) <a href="https://github.com/jmichel7/LaurentPolynomials.jl">LaurentPolynomials</a> (and rational fractions)</li>
<li>(multivariate) <a href="https://github.com/jmichel7/PuiseuxPolynomials.jl">PuiseuxPolynomials</a> (and rational fractions when there are no fractional exponents)</li>
<li><a href="https://github.com/jmichel7/CyclotomicNumbers.jl">CyclotomicNumbers</a>(elements of cyclotomic fields)</li>
<li><a href="https://github.com/jmichel7/ModuleElts.jl">ModuleElts</a> (elements of a free module over some ring)</li>
<li><a href="https://github.com/jmichel7/Combinat.jl">Combinat</a> (combinatorics and some basic number theory)</li>
<li><a href="https://github.com/jmichel7/PermGroups.jl">PermGroups</a> (permutations, groups, permutations groups. It contains the modules <code>Perms</code> and <code>Groups</code> which could be separate packages)</li>
<li><a href="https://github.com/jmichel7/SignedPerms.jl">SignedPerms</a> (signed permutations)</li>
<li><a href="https://github.com/jmichel7/MatInt.jl">MatInt</a> (Integer matrices and lattices)</li>
<li><a href="https://github.com/jmichel7/CycPols.jl">CycPols</a> (cyclotomic polynomials)</li>
<li><a href="https://github.com/jmichel7/GenLinearAlgebra.jl">GenLinearAlgebra</a> (linear algebra on any field/ring)</li>
<li><a href="https://github.com/jmichel7/FinitePosets.jl">FinitePosets</a> (finite posets)</li>
<li><a href="https://github.com/jmichel7/FiniteFields.jl">FiniteFields</a> (finite fields)</li>
<li><a href="https://github.com/jmichel7/GroupPresentations.jl">GroupPresentations</a> (presentations of groups, and groups defined by generators and relations)</li>
<li><a href="https://github.com/jmichel7/UsingMerge.jl">UsingMerge</a> (Automatically compose several packages)</li>
</ul>
<p dir="auto">Have  a look at the  documentation of the above  packages to see how to use
their   features.</p>
<p dir="auto">I  have implemented  some other  infrastructure which  currently resides in
<code>Chevie</code> but may eventually become separate packages:</p>
<ul dir="auto">
<li>factorizing polynomials over finite fields (module <a href="@ref"><code>FFfac</code></a>)</li>
<li>factorizing polynomials over the rationals (module <a href="@ref"><code>Fact</code></a>)</li>
<li>Number fields which are subfields of the Cyclotomics (module <a href="@ref"><code>Nf</code></a>)</li>
</ul>
<p dir="auto">For permutation groups I have often replaced GAP's sophisticated algorithms
with  naive  but  easy-to-write  methods  suitable  only  for  small groups
(sufficient  for the rest of  the package but perhaps  not for your needs).
Otherwise  the infrastructure code  is often competitive  with GAP, despite
using  much less code (often  100 lines of Julia  replace 1000 lines of C);
and I am sure it could be optimised better than I did. Comments on code and
design  are welcome. For functions that are too inefficient or difficult to
implement (such as character tables of arbitrary groups), <code>Chevie</code> uses the
<code>GAP</code>  package  as  an  extension.  This  means  that if you have the <code>GAP</code>
package  installed,  <code>Chevie</code>  will  automatically  call <code>GAP</code> to implement
these functions.</p>
<p dir="auto">Functions  in the  <code>Chevie.jl</code> package  are often  10 times faster than the
equivalent functions in GAP3/Chevie (after the maddeningly long compilation
time on the first run --- Julia's TTFP).</p>
<p dir="auto">The  <code>Chevie</code>  package  currently  contains  about  95%  of the GAP3 Chevie
functionality.  If you  are a  user of  GAP3/Chevie, the <code>gap</code> function can
help  you to  find the  equivalent functionality  in <code>Chevie.jl</code>  to a Gap3
function:  it takes a string and  gives you Julia translations of functions
in Gap3 that match that string.</p>

<p dir="auto">You can then access online help for the functions you have found.</p>
<p dir="auto">The  port to Julia is not complete in the sense that 80% of the code is the
data library from Chevie, which was automatically ported by a transpiler so
its  code is "strange".  When the need  to maintain the  <code>GAP3</code> and <code>Julia</code>
versions  simultaneously subsides,  I will  do a  proper translation of the
data library, which should give an additional speed boost.</p>

<p dir="auto">This is a registered package that can be installed/upgraded in the standard
way.  For Julia newbies,  we will remind  you what this  is. To install, do
this at the REPL command line:</p>
<ul dir="auto">
<li>enter package mode with ]</li>
<li>do the command</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(@v1.10) pkg&gt; add Chevie"><pre class="notranslate"><code>(@v1.10) pkg&gt; add Chevie
</code></pre></div>
<ul dir="auto">
<li>exit package mode with backspace and then do</li>
</ul>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="julia&gt; using Chevie"><pre class="notranslate"><code>julia&gt; using Chevie
</code></pre></div>
<p dir="auto">and you are set up. For first help, type "?Chevie".</p>
<p dir="auto">To update later to the latest version, do</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="(@v1.10) pkg&gt; update"><pre class="notranslate"><code>(@v1.10) pkg&gt; update
</code></pre></div>
<p dir="auto"><code>Chevie.jl</code> requires julia 1.10 or later.</p>
