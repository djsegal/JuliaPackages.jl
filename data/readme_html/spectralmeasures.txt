<p dir="auto">SpectralMeasures.jl is a Julia package for computing spectra and spectral measures of self-adjoint operators with structured, infinite-dimensional matrix representations. The package enables a canonical eigendecomposition for these operators, and a functional calculus too. A key point to make is that all of this is done in tailor-made data structures representing structured infinite-dimensional operators, with no error-inducing, finite-dimensional truncations.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Syntactically, the familiar function for matrices, <code>eig</code>, will be implemented for as many operators as we can. It returns a multiplication operator, <code>D</code>, which acts on <code>Fun</code>s whose domain is the spectrum of the operator, and "spectral map", <code>U</code>, which takes vectors to <code>Fun</code>s in the same <code>Space</code> as the that associated with <code>D</code>. In Julia code, this means that if you have an operator <code>A</code>, and type</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="D,U = eigen(A)"><pre class="notranslate"><code>D,U = eigen(A)
</code></pre></div>
<p dir="auto">then the following identity holds (to machine precision):</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="A = U \ D * U"><pre class="notranslate"><code>A = U \ D * U
</code></pre></div>
<p dir="auto">This is analogous to what happens in finite dimensional linear algebra, where <code>D</code> is a diagonal matrix and <code>U</code> is the matrix of eigenvectors (transposed). You can also try <code>eigvals(A)</code> or <code>spectrum(A)</code> to return the spectrum of <code>A</code> as an ApproxFun <code>Domain</code> type.</p>
<p dir="auto">The operators <code>D</code> and <code>U</code> enable a functional calculus. The following is the application of the operator <code>exp(1.3*A)</code> to a random vector.</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="v = randn(100)
expAtv = U \ exp(1.3*D) *  U * v"><pre class="notranslate"><code>v = randn(100)
expAtv = U \ exp(1.3*D) *  U * v
</code></pre></div>
<p dir="auto">Also, specific to infinite-dimensional operators, there is a function called <code>spectralmeasure</code>. This function produces either a <code>Fun</code> or a <code>RatFun</code> (a quotient of two <code>Fun</code>s), representing a measure supported on the spectrum of the operator --- specifically, a representation of the spectral measure from the Spectral Theorem for selfadjoint operators. At a discrete eigenvalue of the operator, the spectral measure has a Dirac delta.</p>
<p dir="auto">The implementation of the package is based on a combination of connection coefficient matrices between orthogonal polynomials (See Webb-Olver 2018, "Spectra of Jacobi operators via connection coefficients matrices") and infinite dimensional QL iterations (See Olver-Webb 2018, "The infinite dimensional QL algorithm"  (in prep.)).</p>

<p dir="auto">We can compute a QL decomposition in the expected way. However, note that QL decompositions do not exist if the continuous spectrum contains zero (see Olver-Webb 2018, "The infinite dimensional QL algorithm"). Therefore, we must use a shift.</p>
