<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Overview</h2><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This software provides tools for partial differential equations on periodic domains using
Fourier-based pseudospectral methods. A central intent of the software's design is also to
provide a framework for writing new, fast solvers for new physical problems. The code is
written in <a href="https://julialang.org/" rel="nofollow">Julia</a>.</p>
<p dir="auto">For more details refer to the <a href="https://fourierflows.github.io/FourierFlowsDocumentation/stable/" rel="nofollow">documentation</a>.</p>

<p dir="auto">For now, FourierFlows.jl is restricted to run on either a single CPU or single GPU. Multi-threading
can enhance performance for the Fourier transforms. By default, FourierFlows.jl will use the
maximum number of threads available on your machine. You can set the number of threads used by
FourierFlows.jl by setting the environment variable, e.g.,</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="$ export JULIA_NUM_THREADS=4"><pre class="notranslate"><code>$ export JULIA_NUM_THREADS=4
</code></pre></div>
<p dir="auto">For more information on multi-threading users are directed to the <a href="https://docs.julialang.org/en/v1/manual/multi-threading/" rel="nofollow">Julia Documentation</a>.</p>
<p dir="auto">If your machine has more than one GPU available, then functionality within CUDA.jl package
enables the user to choose the GPU device that FourierFlows.jl should use. The user is referred
to the <a href="https://juliagpu.github.io/CUDA.jl/stable/lib/driver/#Device-Management" rel="nofollow">CUDA.jl Documentation</a>;
in particular, <a href="https://juliagpu.github.io/CUDA.jl/stable/lib/driver/#CUDA.devices" rel="nofollow"><code>CUDA.devices</code></a>
and <a href="https://juliagpu.github.io/CUDA.jl/stable/lib/driver/#CUDA.CuDevice" rel="nofollow"><code>CUDA.CuDevice</code></a>.</p>

We welcome any contribution, no matter how big or small! It's always great to have new people
look at the code with fresh eyes: you will see errors that other developers have missed.</p>
<p dir="auto">Let us know by <a href="https://github.com/FourierFlows/FourierFlows.jl/issues/new">open an issue</a>
or <a href="https://github.com/FourierFlows/FourierFlows.jl/discussions/new">start a discussion</a>

than happy to help along the way.</p>
