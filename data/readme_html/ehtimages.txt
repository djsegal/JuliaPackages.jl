<p dir="auto">This module provides data types and implements basic functions to handle five-dimensional astronomical images for radio interferometry. The module aims to provide the following features, meeting the needs for multi-dimensional high-resolution imaging, particularly for Very Long Baseline Interferometry (e.g., Event Horizon Telescope) and millimeter interferometry (e.g., ALMA) in the regime of narrow field of views.</p>
<p dir="auto">The package currently implements:</p>
<ul dir="auto">
<li>Provides abstract types and methods to handle both in-memory and disk-based image cubes.</li>
<li>Offers native support for five-dimensional images (x, y, frequency, polarization, time) in a self-descriptive data format.
<ul dir="auto">
<li>Supports non-equidistant grid in time for the application of dynamic imaging methods (e.g., Johnson et al., 2017, Bouman et al., 2017).</li>
<li>Supports non-equidistant grid in frequency for the application of multi-frequency imaging methods (e.g., Chael et al., 2023).</li>
<li>Supports both in-memory and disk-based (lazily-loaded) image files.
<ul dir="auto">
<li>In-memory data is stored in a self-descriptive data type powered by <a href="https://github.com/EHTJulia/EHTDimensionalData.jl">EHTDimensionalData.jl</a> (an extension of the powerful <a href="https://github.com/rafaqz/DimensionalData.jl">DimensionalData.jl</a>).</li>
<li>Disk-based data is based on NetCDF (on HDF5) accessed by <a href="https://github.com/Alexander-Barth/NCDatasets.jl">NCDatasets.jl</a>, allowing lazy access to data suitable for a large image cube that may not fit into memory and also for containing multiple image data sets inside a single file.</li>
</ul>
</li>
<li>Includes a FITS writer and loader compatible with the eht-imaging library (Chael et al., 2016, 2018) and SMILI (Akiyama et al., 2017a, b) for the EHT community, as well as with more traditional packages including AIPS, DIFMAP, and CASA software packages.</li>
</ul>
</li>
<li>Provides interactive plotting tools powered by <a href="https://github.com/JuliaPy/PythonPlot.jl">PythonPlot.jl</a>.</li>
<li>Offers interactive tools to analyze, edit, and transform images using pure Julia native functions.</li>
</ul>

<p dir="auto">Assuming that you already have Julia correctly installed, it suffices to import EHTImages.jl in the standard way:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using Pkg
Pkg.add(&quot;EHTImages&quot;)"><pre><span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>EHTImages<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">EHTImages.jl uses <a href="https://github.com/stevengj/PythonPlot.jl">PythonPlot.jl</a> for the image visulization.
You can use a custom set of perceptually uniform colormaps implemented in the Python's <a href="https://github.com/liamedeiros/ehtplot">ehtplot</a> library, which
has been used in the publications of the EHT Collaboration, by installing it through <a href="https://github.com/cjdoris/CondaPkg.jl">CondaPkg.jl</a> and
import it using <a href="https://github.com/cjdoris/PythonCall.jl">PythonCall.jl</a>. For example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="# Install CondaPkg.jl and  PythonCall.jl: (need to run only once in your local/global Julia enviroment)

Pkg.add(&quot;CondaPkg&quot;)
Pkg.add(&quot;PythonCall&quot;)

# Install ehtplot (again need to run only once in your local/global Julia enviroment)
using CondaPkg
CondaPkg.add_pip(&quot;ehtplot&quot;, version=&quot;@git+https://github.com/liamedeiros/ehtplot&quot;)"><pre><span class="pl-c"><span class="pl-c">#</span> Install CondaPkg.jl and  PythonCall.jl: (need to run only once in your local/global Julia enviroment)</span>
<span class="pl-k">using</span> Pkg
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>CondaPkg<span class="pl-pds">"</span></span>)
Pkg<span class="pl-k">.</span><span class="pl-c1">add</span>(<span class="pl-s"><span class="pl-pds">"</span>PythonCall<span class="pl-pds">"</span></span>)

<span class="pl-c"><span class="pl-c">#</span> Install ehtplot (again need to run only once in your local/global Julia enviroment)</span>
<span class="pl-k">using</span> CondaPkg
CondaPkg<span class="pl-k">.</span><span class="pl-c1">add_pip</span>(<span class="pl-s"><span class="pl-pds">"</span>ehtplot<span class="pl-pds">"</span></span>, version<span class="pl-k">=</span><span class="pl-s"><span class="pl-pds">"</span>@git+https://github.com/liamedeiros/ehtplot<span class="pl-pds">"</span></span>)</pre></div>
<p dir="auto">After installing ehtplot, you can import and utilize it for image visualization in EHTImages.jl. See the documentation.</p>
