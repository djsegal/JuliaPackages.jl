<p dir="auto"><a href="https://github.com/cometscome/FluxKAN.jl/actions/workflows/CI.yml?query=branch%3Amain"><img src="https://github.com/cometscome/FluxKAN.jl/actions/workflows/CI.yml/badge.svg?branch=main" alt="Build Status" style="max-width: 100%;"></a></p>
<p dir="auto">This is a Julia version of the <a href="https://github.com/1ssb/torchkan">TorchKAN</a>.
In the TorchKAN,</p>
<blockquote>
<p dir="auto">TorchKAN introduces a simplified KAN model and its variations, including KANvolver and KAL-Net, designed for high-performance image classification and leveraging polynomial transformations for enhanced feature detection.</p>
</blockquote>
<p dir="auto">In the original TorchKAN, the package uses the PyTorch.
In the FluxKAN, this package uses the Flux.jl.</p>
<p dir="auto">I rewrote the TorchKAN with the Julia language. Now this package has</p>
<ul dir="auto">
<li>KAL-Net: Utilizing Legendre Polynomials in Kolmogorov Arnold Legendre Networks</li>
</ul>
<p dir="auto">In addition, I implemented Chebyshev polynomials in KAN.</p>
<ul dir="auto">
<li>KAC-Net: Utilizing Chebyshev Polynomials in Kolmogorov Arnold Chebyshev Networks</li>
</ul>
<p dir="auto">I implemented the Gaussian Radial Basis Functions introduced in <a href="https://github.com/ZiyaoLi/fast-kan">fastkan</a>:</p>
<ul dir="auto">
<li>KAG-Net: Utilizing Gaussian radial basis functions in Kolmogorov Arnold Gaussian Networks (non-trainable grids)</li>
<li>KAGL-Net: (Experimental) Utilizing Gaussian radial basis functions in Kolmogorov Arnold Gaussian Networks (trainable grids)</li>
</ul>

<p dir="auto">You can use <code>KALnet</code> layer like <code>Dense</code> layer in Flux.jl.
For example, the model is defined as</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FluxKAN

<p dir="auto">or</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FluxKAN

<p dir="auto">If you want to use the Chebyshev polynomials, you can use <code>KACnet</code>.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FluxKAN

<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using FluxKAN

<p dir="auto">In the KAGnet, the grid points are fixed.</p>
<p dir="auto">I implemented the Gaussian function with learnable grid points. But this is experimental. You can use <code>KAGLnet</code>.</p>
