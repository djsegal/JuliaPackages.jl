<div class="markdown-heading" dir="auto"><h1 class="heading-element" dir="auto">RogueWaveInfiniteNLS.jl</h1><a id="user-content-roguewaveinfinitenlsjl" class="anchor" aria-label="Permalink: RogueWaveInfiniteNLS.jl" href="#roguewaveinfinitenlsjl"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Julia package for computing the general rogue waves of infinite order for the focusing nonlinear Schrödinger equation.
This is a family of special solutions of the focusing nonlinear equation denoted by <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\Psi(X,T;\mathbf{G},\beta)$</math-renderer>, whose exact and asymptotic properties (in different regimes where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$(X,T)\in\mathbb{R}^2$</math-renderer> becomes large) were studied recently in the manuscript</p>
<p dir="auto"><em>General rogue waves of infinite order: exact properties, asymptotic behavior, and effective numerical computation</em> [D. Bilman &amp; P. D. Miller, 2024].</p>
<p dir="auto">Importantly these solutions all lie in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$L^2(\mathbb{R})\setminus L^1(\mathbb{R})$</math-renderer> and they exhibit quite slow temporal decay: <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\Psi(X,T;\mathbf{G},\beta)\sim |T|^{-1/3}$</math-renderer> as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$T\to\pm\infty$</math-renderer>. In the sense that they decay slower than pure radiation generated by generic initial data in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$L^1(\mathbb{R})$</math-renderer> (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\sim t^{-1/2}$</math-renderer>).</p>
<p dir="auto">The family of solutions is parametrized by a <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$2\times 2$</math-renderer> matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\mathbf{G}$</math-renderer> and a scalar <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\beta&amp;gt;0$</math-renderer>. The matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\mathbf{G}$</math-renderer> is given by</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$$\mathbf{G}=\mathbf{G}(a,b)=\frac{1}{\sqrt{|a|^2+|b|^2}}\begin{bmatrix} a &amp; b^* \\ -b &amp; a^* \end{bmatrix},\quad a,b\in\mathbb{C}\setminus\{0\},$$</math-renderer>
<p dir="auto">where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$c^*$</math-renderer> denotes the complex conjugate of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$c\in\mathbb{C}$</math-renderer>.</p>
<p dir="auto">The main routine is <code>psi</code>. The command</p>
<div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="psi(0.8, 1.2, 1, 2im, 1)"><pre lang="code" class="notranslate"><code>psi(0.8, 1.2, 1, 2im, 1)
</code></pre></div>
<p dir="auto">computes <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\Psi(X,T;\mathbf{G},\beta)$</math-renderer> at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$(X,T)=(0.8,1.2)$</math-renderer> with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$a=1$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$b=2i$</math-renderer>, and scalar <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\beta=1$</math-renderer>. So the syntax for the end user is <code>psi(X, T, a, b, beta)</code>.</p>
<p dir="auto"><math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\Psi(X,T;\mathbf{G},\beta)$</math-renderer> is defined in terms of the solution of a Riemann-Hilbert problem that depends parametrically on the arguments <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$(X,T;\mathbf{G},\beta)$</math-renderer>.
Depending on the location of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$(X,T)$</math-renderer> in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\mathbb{R}^2$</math-renderer>, a suitably regularized (deformed using the noncommutative steepest descent techniques) Riemann-Hilbert problem implemented as part of this package is picked automatically and it is solved numerically using <a href="https://github.com/tomtrogdon/OperatorApproximation.jl/">OperatorApproximation.jl</a>.</p>

<p dir="auto">The variable <code>outpsiX</code> holds a vector of (complex) values of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$\Psi(X,T=0,a=0.8i,b=1,\beta=1)$</math-renderer> for <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$-16\leq X \leq 16$</math-renderer> with a mesh-size of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="04dfbb4a0dcf81667128ef44ef731d2b">$dX=0.05$</math-renderer>.
