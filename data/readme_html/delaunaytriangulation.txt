<p dir="auto">This is a package for constructing Delaunay triangulations and Voronoi tessellations of planar point sets. Supports unconstrained and constrained triangulations, weighted triangulations, mesh refinement, triangulation of curve bounded domains, Voronoi tessellations, power diagrams, and clipped and centroidal Voronoi tessellations. To install the package, do</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt;] add DelaunayTriangulation"><pre>julia<span class="pl-k">&gt;</span>] add DelaunayTriangulation</pre></div>
<p dir="auto">Many features are available, some of these being:</p>
<ul dir="auto">
<li>Unconstrained and constrained Delaunay triangulations, supporting many types of domains.</li>
<li>Weighted Delaunay triangulations.</li>
<li>Computation of Voronoi tessellations, clipped Voronoi tessellations where the Voronoi tiles get clipped to a convex polygon, and centroidal Voronoi tessellations where each Voronoi tile's generator is the tile's centroid.</li>
<li>Power diagrams.</li>
<li>Mesh refinement, with support for custom angle and area constraints, as well as refinement of curve-bounded domains.</li>
<li>Dynamic point insertion, point deletion, and segment insertion, amongst many other operations.</li>
<li>Computation of convex hulls.</li>
<li>Triangulation of convex polygons.</li>
<li>Point location.</li>
<li>Computation of the pole of inaccessibility.</li>
<li>The interface for defining geometric primitives is fully customisable.</li>
</ul>
<p dir="auto">To ensure that the algorithms are robust, by default we make use of <a href="https://github.com/JuliaGeometry/AdaptivePredicates.jl">AdaptivePredicates.jl</a> to use
adaptive arithmetic for all geometric predicates in this package. This choice can be configured, allowing for the additional choices of <a href="https://github.com/lairez/ExactPredicates.jl">ExactPredicates.jl</a> or no adaptive or exact arithmetic at all; see the documentation. Much of the work in this package is derived from the book <a href="https://people.eecs.berkeley.edu/~jrs/meshbook.html" rel="nofollow"><em>Delaunay Mesh Generation</em> by Cheng, Dey, and Shewchuk (2013)</a>. Please see the documentation for much more information.</p>
<p dir="auto">Some examples are below (and in the documentation), but if you would also like to see how DelaunayTriangulation.jl is used in other packages, see <a href="https://github.com/SciML/FiniteVolumeMethod.jl">FiniteVolumeMethod.jl</a> (solving 2D PDEs) and <a href="https://github.com/DanielVandH/NaturalNeighbours.jl">NaturalNeighbours.jl</a> (scattered data interpolation).</p>
<p dir="auto">If you would like to make an issue or contribute, please see the <a href="CONTRIBUTING.md">CONTRIBUTING.md</a> file. For feature requests, please see the discussions tab.</p>

<p dir="auto">This is not the only Delaunay triangulation package available. Some others are:</p>
<ul dir="auto">
<li>
<a href="https://github.com/JuliaGeometry/VoronoiDelaunay.jl">VoronoiDelaunay.jl</a>: A pure Julia library that constructs planar triangulations and tessellations like in this package, although no support for constrained triangulations / mesh refinement or clipped / centroid tessellations. Restricts points to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="62456f61b01c0eb0b9cfd327e9d6b3da">$[1, 2] \times [1, 2]$</math-renderer>.</li>
<li>
<a href="https://github.com/JuliaGeometry/VoronoiCells.jl">VoronoiCells.jl</a>: A pure Julia library that extends VoronoiDelaunay.jl. This package provides useful tools for constructing and working with Voronoi tessellations. Supports clipping Voronoi cells to a specified rectangle. Like VoronoiDelaunay.jl, restricts points to <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="62456f61b01c0eb0b9cfd327e9d6b3da">$[1, 2] \times [1, 2]$</math-renderer>.</li>
<li>
<a href="https://github.com/eschnett/Delaunay.jl">Delaunay.jl</a>: Wraps Python's main Delaunay triangulation library, <a href="https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.Delaunay.html" rel="nofollow"><code>scipy.spatial.Delaunay</code></a>, for computing Delaunay triangulations in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="62456f61b01c0eb0b9cfd327e9d6b3da">$\mathbb R^N$</math-renderer>. I don't believe constrained triangulations or mesh refinement is available here.</li>
<li>
<a href="https://github.com/gridap/MiniQhull.jl">MiniQhull.jl</a>: Wraps <a href="http://www.qhull.org/" rel="nofollow">Qhull</a> for computing unconstrained Delaunay triangulations in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="62456f61b01c0eb0b9cfd327e9d6b3da">$\mathbb R^N$</math-renderer>. No support is provided for mesh refinement.</li>
<li>
<a href="https://github.com/JuhaHeiskala/DirectQhull.jl/">DirectQhull.jl</a>: Similar to MiniQhull.jl, although also provides support for convex hulls and Voronoi tessellations from Qhull.</li>
<li>
<a href="https://github.com/JuliaGeometry/Delaunator.jl">Delaunator.jl</a>: A pure Julia library modelled after the <a href="https://github.com/mapbox/delaunator">JavaScript Delaunator library</a>. This package can construct unconstrained triangulations of planar point sets. No support is available for constrained triangulations or mesh refinement, although support exists for computing the dual Voronoi tessellation. Centroidal tessellations are not implemented, although the Voronoi cells can be clipped to a bounding box.</li>
<li>
<a href="https://github.com/konsim83/TriangleMesh.jl">TriangleMesh.jl</a>, <a href="https://github.com/JuliaGeometry/Triangulate.jl">Triangulate.jl</a>, <a href="https://github.com/cvdlab/Triangle.jl">Triangle.jl</a>: Interfaces to <a href="https://www.cs.cmu.edu/~quake/triangle.html" rel="nofollow">Shewchuk's Triangle library</a>.</li>
<li>
<a href="https://github.com/JuliaGeometry/TetGen.jl">TetGen.jl</a>: This is for Delaunay tetrahedralisation, wrapping <a href="https://wias-berlin.de/software/index.jsp?id=TetGen" rel="nofollow">TetGen</a>.</li>
<li>
<a href="https://github.com/GenericMappingTools/GMT.jl">GMT.jl</a>: A wrapper of <a href="https://github.com/GenericMappingTools/gmt">GMT</a>, allowing for <a href="https://www.generic-mapping-tools.org/GMTjl_doc/documentation/modules/triangulate/index.html#triangulate" rel="nofollow">unconstrained Delaunay triangulations in two dimensions</a>, and for <a href="https://www.generic-mapping-tools.org/GMTjl_doc/documentation/modules/sphtriangulate/index.html#sphtriangulate" rel="nofollow">spherical triangulation, i.e. triangulation of points lying on a sphere</a>.</li>
<li>
<a href="https://github.com/augustt198/Quickhull.jl">Quickhull.jl</a>: A pure Julia library for unconstrained triangulations, Voronoi tessellations, and convex hulls in <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="62456f61b01c0eb0b9cfd327e9d6b3da">$N$</math-renderer> dimensions.</li>
</ul>
