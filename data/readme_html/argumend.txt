<p dir="auto">ArguMend.jl injects a function with logic
to help with mistyped keyword arguments.</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="@argumend function f(a, b; niterations=10, kw2=2)
    a + b - niterations + kw2
end"><pre><span class="pl-c1">@argumend</span> <span class="pl-k">function</span> <span class="pl-en">f</span>(a, b; niterations<span class="pl-k">=</span><span class="pl-c1">10</span>, kw2<span class="pl-k">=</span><span class="pl-c1">2</span>)
    a <span class="pl-k">+</span> b <span class="pl-k">-</span> niterations <span class="pl-k">+</span> kw2
<span class="pl-k">end</span></pre></div>
<p dir="auto">This results in a nicer mechanism for MethodErrors:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="julia&gt; f(1, 2; iterations=1)
ERROR: SuggestiveMethodError: in call to `f`, found unsupported
       keyword argument: `iterations`, perhaps you meant `niterations`"><pre>julia<span class="pl-k">&gt;</span> <span class="pl-c1">f</span>(<span class="pl-c1">1</span>, <span class="pl-c1">2</span>; iterations<span class="pl-k">=</span><span class="pl-c1">1</span>)
ERROR<span class="pl-k">:</span> SuggestiveMethodError<span class="pl-k">:</span> <span class="pl-k">in</span> call to <span class="pl-s"><span class="pl-pds">`</span>f<span class="pl-pds">`</span></span>, found unsupported
       keyword argument<span class="pl-k">:</span> <span class="pl-s"><span class="pl-pds">`</span>iterations<span class="pl-pds">`</span></span>, perhaps you meant <span class="pl-s"><span class="pl-pds">`</span>niterations<span class="pl-pds">`</span></span></pre></div>
<p dir="auto">This becomes increasingly useful when calling into a
large interface with many possible options.</p>
<p dir="auto">This mechanism has (very likely) zero runtime cost, as it relies on adding splatted
keyword arguments to the function call, which will re-compile the function
if any keyword arguments change, skipping the ArguMend functions altogether.</p>
<p dir="auto">You can also set this up manually, without a macro:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using ArguMend: suggest_alternative_kws, SuggestiveMethodError

    end

    # Do other stuff
end"><pre><span class="pl-k">using</span> ArguMend<span class="pl-k">:</span> suggest_alternative_kws, SuggestiveMethodError

<p dir="auto">The core function used for computing candidate keywords is <code>extract_close_matches</code>,
which is a clean-room pure-Julia re-implementation of Python's
difflib.get_close_matches.</p>
