<p dir="auto">This package facilitates one of the many ways <a href="https://github.com/JuliaDynamics/DrWatson.jl">DrWatson.jl</a> enables users to set up and run simulations, and to store and retrieve the results of these simulations.</p>
<p dir="auto">The workflow targeted by <code>BakerStreet.jl</code> has the following structure:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using BakerStreet
using DataFrames

function adder(;a, b)
    return (;c = a+b)
end

a = [1,2,3]
@runsims adder a b=[10,20]

df = @collect_results"><pre><span class="pl-k">using</span> BakerStreet
<span class="pl-k">using</span> DataFrames

<span class="pl-k">function</span> <span class="pl-en">adder</span>(;a, b)
    <span class="pl-k">return</span> (;c <span class="pl-k">=</span> a<span class="pl-k">+</span>b)
<span class="pl-k">end</span>

a <span class="pl-k">=</span> [<span class="pl-c1">1</span>,<span class="pl-c1">2</span>,<span class="pl-c1">3</span>]
<span class="pl-c1">@runsims</span> adder a b<span class="pl-k">=</span>[<span class="pl-c1">10</span>,<span class="pl-c1">20</span>]

df <span class="pl-k">=</span> <span class="pl-c1">@collect_results</span></pre></div>
<p dir="auto">The simulation is started on by macro <code>@runsims</code>. A configuration is created and the payload method <code>adder</code> is called over the Cartesian product of parameter ranges <code>(a,b)</code>. The dictionary that is written to disk is the merge of the inputs and outputs of adder (so in this case the keys are <code>(a,b,c)</code>). The results are written in a subdirectory of <code>DrWatson.datadir()</code> with name <code>splitext(@__FILE__)[1]</code>. Likewise, <code>@collect_results</code> looks for output data in this directory.</p>
