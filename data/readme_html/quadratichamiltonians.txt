<p dir="auto">This calculates meanfields of the Hamiltonian with quadratic terms in superconductors.
With the use of this package, you do not have to think about a matrix of the Hamiltonian that you want to consider. To construct the Hamiltonian, just add the operators.</p>
<p dir="auto">We implemented two kinds of methods.</p>
<ul dir="auto">
<li>Chebyshev Polynomial method: Yuki Nagai, Yukihiro Ota, and Masahiko Machida, Efficient Numerical Self-Consistent Mean-Field Approach for Fermionic Many-Body Systems by Polynomial Expansion on Spectral Density, <a href="https://journals.jps.jp/doi/10.1143/JPSJ.81.024710" rel="nofollow">J. Phys. Soc. Jpn. 81, 024710 (2012)</a></li>
<li>Reduced-Shifted Conjugate-Gradient Method method: Yuki Nagai et al., Reduced-Shifted Conjugate-Gradient Method for a Green’s Function: Efficient Numerical Approach in a Nano-Structured Superconductor, <a href="https://journals.jps.jp/doi/10.7566/JPSJ.86.014708" rel="nofollow">J. Phys. Soc. Jpn. 86, 014708 (2017)</a>. In the RSCG method, we use the sparse modeling technique proposed by <a href="https://github.com/SpM-lab/SparseIR.jl">SparseIR.jl</a>.</li>
</ul>
<p dir="auto">And also we implemented the following method:</p>
<ul dir="auto">
<li>
<ol dir="auto">
<li>LK-BdG solver: Yuki Nagai, N-independent Localized Krylov–Bogoliubov-de Gennes Method: Ultra-fast Numerical Approach to Large-scale Inhomogeneous Superconductors <a href="https://journals.jps.jp/doi/10.7566/JPSJ.89.074703" rel="nofollow">J. Phys. Soc. Jpn. 89, 074703 (2020) </a></li>
</ol>
</li>
</ul>
<p dir="auto">We consider the Hamiltonian only with quadratic form terms in real space.</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\hat{H} \equiv \sum_{i j} \sum_{\alpha \beta} H_{ij} c_{i \alpha}^{\dagger} c_{j \beta}$$</math-renderer>
<p dir="auto">or</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\hat{H}_{\rm BdG} \equiv \sum_{i j} \sum_{\alpha \beta} H_{ij} c_{i \alpha}^{\dagger} c_{j \beta} + \sum_{i j} \sum_{\alpha \beta} \bar{H}_{ij} c_{i \alpha} c_{j \beta}^{\dagger} + + \sum_{i j} \sum_{\alpha \beta} \Delta_{ij} c_{i \alpha}^{\dagger} c_{j \beta}^{\dagger} +  \sum_{i j} \sum_{\alpha \beta} \bar{\Delta}_{ij} c_{i \alpha} c_{j \beta}$$</math-renderer>
<p dir="auto">if the keyword <code>isSC</code> is <code>true</code>. Here <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$i$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$j$</math-renderer> are indices of real-space grid and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\alpha$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\beta$</math-renderer> are indices of internal degree of freedom (like spins,orbitals or bands).
If you want to consider a superconducting BdG Hamiltonian, you need the relations:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\begin{align}
\bar{H}_{ij} &amp;= - H_{ij}^{\ast}, \\\
\bar{\Delta}_{ij} &amp;= \Delta_{ji}^{\ast}.
\end{align}$$</math-renderer>
<p dir="auto">Now this package can</p>
<ul dir="auto">
<li>construct the matrix of the Hamiltonian.</li>
<li>display the creation and anihilation operators in the Hamiltonian.</li>
<li>calculate meanfields defined as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\langle c_i^{\dagger} c_j \rangle$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\langle c_i^{\dagger} c_j^{\dagger} \rangle$</math-renderer> , <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\langle c_i c_j^{\dagger} \rangle$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$\langle c_i c_j \rangle$</math-renderer>. You can choose the Chebyshev polynomial method or RSCG method for calculating meanfields.  Now only a Hermitian Hamiltonian is supported.</li>
<li>calculate Green's functions defined as <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$G_{ij}(z) \equiv \langle c_i^{\dagger} [z \hat{I} - \hat{H}]^{-1} c_j \rangle = \left[ [z \hat{I} - \hat{H}]^{-1} \right]_{ij}$</math-renderer>. Here <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$z$</math-renderer> is a complex frequency. Now only a Hermitian Hamiltonian is supported. The local density of states can be caluculated by the imaginary part of diagonal elements of the Green's function.</li>
</ul>

<p dir="auto">If the Hamiltonian is expressed as the sum of the quadratic terms, the Green's function defined as</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\begin{align}
G_{ij}(z) \equiv \langle c_i^{\dagger} [z \hat{I} - \hat{H}]^{-1} c_j \rangle
\end{align}$$</math-renderer>
<p dir="auto">can be calculated by</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\begin{align}
G_{ij}(z) = \left[ (z \hat{I} - \hat{H})^{-1} \right]_{ij}
\end{align}$$</math-renderer>
<p dir="auto">The local density of states at site <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$i$</math-renderer> can be calculated by the Green's function:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="60691eb4da77657d4c0ad59c55a2ca3a">$$\begin{align}
N_i(\omega) = -\frac{1}{\pi} {\rm Im} \: \lim_{\eta \rightarrow 0+} G_{ii}(\omega + i \eta) 
\end{align}$$</math-renderer>

function make_hamiltonian(Nx, Ny, μ, Δs)
    N = Nx * Ny
    ham = Hamiltonian(N, isSC=true)
    t = -1
    hops = [(+1, 0), (-1, 0), (0, +1), (0, -1)]
    for ix = 1:Nx
        for iy = 1:Ny
            i = (iy - 1) * Nx + ix
            ci = FermionOP(i)
            for (dx, dy) in hops
                jx = ix + dx
                jx += ifelse(jx &gt; Nx, -Nx, 0)
                jx += ifelse(jx &lt; 1, Nx, 0)
                jy = iy + dy
                jy += ifelse(jy &gt; Ny, -Ny, 0)
                jy += ifelse(jy &lt; 1, Ny, 0)
                j = (jy - 1) * Nx + jx
                cj = FermionOP(j)
                ham += -1 * (ci' * cj - cj * ci')
            end
            ham += -μ * (ci' * ci - ci * ci')
            ham += Δs[i] * ci' * ci' + Δs[i] * ci * ci
        end
    end
    return ham
end

function update!(m, Δs)
    N, _ = size(m.hamiltonian)
    for i = 1:(N÷2)
        ci = FermionOP(i)
        update_hamiltonian!(m, Δs[i], ci', ci')
        update_hamiltonian!(m, Δs[i], ci, ci)
    end
end

function make_TSC_hamiltonian(Nx, Ny, μ, Δs, h, α, isPBC)
    N = Nx * Ny
    ham = Hamiltonian(ComplexF64, N, num_internal_degree=2, isSC=true)
    hops = [(+1, 0), (-1, 0), (0, +1), (0, -1)]
    for ix = 1:Nx
        for iy = 1:Ny
            i = (iy - 1) * Nx + ix
            for ispin = 1:2
                ci = FermionOP(i, ispin)
                σy = ifelse(ispin == 1, -im, im)
                σx = 1
                σz = ifelse(ispin == 1, 1, -1)

                for (dx, dy) in hops
                    jx = ix + dx
                    if isPBC
                        jx += ifelse(jx &gt; Nx, -Nx, 0)
                        jx += ifelse(jx &lt; 1, Nx, 0)
                    end
                    jy = iy + dy
                    if isPBC
                        jy += ifelse(jy &gt; Ny, -Ny, 0)
                        jy += ifelse(jy &lt; 1, Ny, 0)
                    end

                    if 1 &lt;= jx &lt;= Nx &amp;&amp; 1 &lt;= jy &lt;= Ny
                        j = (jy - 1) * Nx + jx
                        jspin = ispin
                        cj = FermionOP(j, jspin)
                        ham += -1 * (ci' * cj - cj * ci')

                        jspin = ifelse(ispin == 1, 2, 1)
                        cj = FermionOP(j, jspin)

                        if dy == 0
                            if dx == 1
                                ham += (α / (2im)) * (ci' * cj - cj * ci') * σy
                            else
                                ham += -1 * (α / (2im)) * (ci' * cj - cj * ci') * σy
                            end
                        elseif dx == 0
                            if dy == 1
                                ham += (α / (2im)) * (ci' * cj - cj * ci') * σx
                            else
                                ham += -1 * (α / (2im)) * (ci' * cj - cj * ci') * σx
                            end
                        end
                    end
                end
                ham += (-μ - h * σz) * (ci' * ci - ci * ci')
            end
            ciup = FermionOP(i, 1)
            cidown = FermionOP(i, 2)
            ham += Δs[i] * ciup' * cidown' + Δs[i] * cidown * ciup
            ham += -Δs[i] * cidown' * ciup' - Δs[i] * ciup * cidown
        end
    end


    return ham
end

function update!(m, Δs)
    N, _ = size(m.hamiltonian)
    for i = 1:(N÷4)
        ciup = FermionOP(i, 1)
        cidown = FermionOP(i, 2)
        update_hamiltonian!(m, -Δs[i], ciup', cidown')
        update_hamiltonian!(m, Δs[i], cidown', ciup')
        update_hamiltonian!(m, Δs[i], ciup, cidown)
        update_hamiltonian!(m, -Δs[i], cidown, ciup)
    end
end



function main()
    Nx = 16
    Ny = 16
    μ = 3.5
    Δ0 = 3
    Δs = Δ0 * ones(Nx * Ny)
    Δsnew = similar(Δs)
    T = 0.01
    U = -5.6
    h = 1
    α = 1

    isPBC = false
    ham = make_TSC_hamiltonian(Nx, Ny, μ, Δs, h, α, isPBC)
    m = Meanfields_solver(ham, T)

    for it = 1:100
        @time Gs = map(i -&gt; calc_meanfields(m, FermionOP(i, 1), FermionOP(i, 2)), 1:Nx*Ny)
        Δsnew .= real(U * Gs)
        res = sum(abs.(Δsnew .- Δs)) / sum(abs.(Δs))
        println(&quot;$(it)-th $(Δsnew[1]) $res&quot;)
        if res &lt; 1e-4
            break
        end
        update!(m, Δsnew)
        Δs .= Δsnew
    end

end
