<p dir="auto">LRSLib.jl is a wrapper for <a href="http://cgm.cs.mcgill.ca/~avis/C/lrs.html" rel="nofollow">lrs</a>. This module can either be used in a "lower level" using the <a href="http://cgm.cs.mcgill.ca/~avis/C/lrslib/lrslib.html" rel="nofollow">API of lrslib</a> or using the higher level interface of <a href="https://github.com/JuliaPolyhedra/Polyhedra.jl">Polyhedra.jl</a>.</p>
<p dir="auto">As written in the <a href="http://cgm.cs.mcgill.ca/~avis/C/lrslib/USERGUIDE.html#Introduction" rel="nofollow">user guide of lrs</a>:</p>
<blockquote>
<p dir="auto">A polyhedron can be described by a list of inequalities (H-representation) or as by a list of its vertices and extreme rays (V-representation). lrs is a C program that converts a H-representation of a polyhedron to its V-representation, and vice versa.  These problems are known respectively at the vertex enumeration and convex hull problems.</p>
</blockquote>
<p dir="auto">I have <a href="https://github.com/blegat/lrslib">forked lrs</a> to add a few functions to help doing the wrapper.
These changes are not upstream yet so this version is used instead of the upstream version.</p>
