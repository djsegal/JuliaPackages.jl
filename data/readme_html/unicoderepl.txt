<p dir="auto">This is a small <a href="https://julialang.org" rel="nofollow">Julia</a> package that enables the user
to obtain any Unicode character in the Julia REPL if the
<a href="https://codepoints.net" rel="nofollow">Unicode codepoint</a> is known (and if the system fonts
can display it).</p>

<p dir="auto">In the Julia REPL type:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="using UnicodeREPL"><pre><span class="pl-k">using</span> UnicodeREPL</pre></div>
<p dir="auto">Herafter you can use the docstring (by typing <code>?UnicodeREPL</code>) to get a
quick overview of how to use UnicodeREPL.</p>
<p dir="auto">The main feature is "unicode repl" mode, which can be entered by typing
the <code>^</code> character at the start of a line.
When the <code>Tab</code> key is pressed in "unicode repl" mode, patterns matching
<code>\u(XXXX)</code> will be
converted to the Unicode character corresponding to <code>XXXX</code>, where <code>XXXX</code> is a
string of any length containing the hexadecimal
<a href="https://codepoints.net" rel="nofollow">Unicode codepoint</a> of a valid Unicode character.</p>
<p dir="auto">Pressing the <code>Backspace</code> key when the cursor is on the first character of a
"unicode repl" mode line reverts back to "julia" mode while preserving
the contents of the input line.</p>
<p dir="auto">"unicode repl" mode has most features that "julia" mode has.</p>

<p dir="auto">The first "unicode repl" line shows what happens when merely pressing
<code>Enter</code> in this mode.</p>
<p dir="auto">The second "unicode repl" line shows what would happen if the <code>Tab</code> key
was pressed when the cursor was on the second <code>\</code> character of the first
"unicode repl" line: The <code>Tab</code> key immediately substitutes to the left
of the cursor. Hereafter <code>Enter</code> was pressed.</p>
<p dir="auto">The third "unicode repl" line is what most people want: It was
initially identical to the first "unicode repl" line, hereafter the
<code>Tab</code> key was pressed when the cursor was at the end of the line followed by
the <code>Enter</code> key.</p>
<p dir="auto">The next two "unicode repl" lines show that leading zeros and both
upper and lower case codepoints are allowed.</p>
<p dir="auto">The final "unicode repl" line shows the effect of pressing the <code>Tab</code>
key at the end of either of the previous two input lines.</p>
<p dir="auto">Note that while any Unicode character can be entered in this way, characters
such as <code>°</code> that can be handled in "julia" mode should normally be entered
using <a href="https://docs.julialang.org/en/v1/manual/unicode-input/" rel="nofollow">standard tab completion sequences</a>
as this minimises the risk of confusion with similar looking characters.</p>
