<p dir="auto">The <code>HazReg</code> Julia package implements the following parametric hazard-based regression models for (overall) survival data.</p>
<ul dir="auto">
<li>
<p dir="auto">General Hazard (GH) model.</p>
</li>
<li>
<p dir="auto">Accelerated Failure Time (AFT) model.</p>
</li>
<li>
<p dir="auto">Proportional Hazards (PH) model.</p>
</li>
<li>
<p dir="auto">Accelerated Hazards (AH) model.</p>
</li>
</ul>
<p dir="auto">These models are fitted using the Julia package <code>Optim</code>, with methods "NM" (NelderMead), "N" (Newton), "LBFGS" (LBFGS), "CG" (ConjugateGradient), "GD" (GradientDescent). Thus, the user needs to specify the initial points and to check the convergence of the optimisation step, as usual.</p>
<p dir="auto">To install the package, use:</p>

<p dir="auto">The current version of the <code>HazReg</code> Julia package implements the following parametric baseline hazards for the models discussed in the previous section, using the command <code>GHMLE</code>.</p>
<ul dir="auto">
<li>
<p dir="auto"><a href="http://rpubs.com/FJRubio/PGW" rel="nofollow">Power Generalised Weibull</a> (PGW) distribution.</p>
</li>
<li>
<p dir="auto"><a href="http://rpubs.com/FJRubio/EWD" rel="nofollow">Exponentiated Weibull</a> (EW) distribution.</p>
</li>
<li>
<p dir="auto"><a href="http://rpubs.com/FJRubio/GG" rel="nofollow">Generalised Gamma</a> (GenGamma) distribuiton.</p>
</li>
<li>
<p dir="auto"><a href="https://en.wikipedia.org/wiki/Gamma_distribution" rel="nofollow">Gamma</a> (Gamma) distribution.</p>
</li>
<li>
<p dir="auto"><a href="https://en.wikipedia.org/wiki/Log-normal_distribution" rel="nofollow">Lognormal</a> (LogNormal) distribution.</p>
</li>
<li>
<p dir="auto"><a href="https://en.wikipedia.org/wiki/Log-logistic_distribution" rel="nofollow">Log-logistic</a> (LogLogistic) distribution.</p>
</li>
<li>
<p dir="auto"><a href="https://en.wikipedia.org/wiki/Weibull_distribution" rel="nofollow">Weibull</a> (Weibull) distribution. (only for AFT, PH, and AH models)</p>
</li>
</ul>
<p dir="auto">All positive parameters are transformed into the real line using a <code>log</code> link (reparameterisation).</p>
