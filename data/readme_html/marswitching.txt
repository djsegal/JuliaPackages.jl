<p dir="auto">MarSwitching.jl is a package for estimating Markov switching dynamic models (also called regime switching) in Julia.</p>
<p dir="auto"><strong>Author</strong>: <a href="https://github.com/m-dadej">Mateusz Dadej</a>, m.dadej {at} unibs.it</p>
<p dir="auto">Please check the <a href="https://m-dadej.github.io/MarSwitching.jl/dev" rel="nofollow">documentation</a> for examples and information on using the package.</p>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Markov regime switching model in a nutshell</h2><a id="user-content-markov-regime-switching-model-in-a-nutshell" class="anchor" aria-label="Permalink: Markov regime switching model in a nutshell" href="#markov-regime-switching-model-in-a-nutshell"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The Markov switching models are a class of models that allow for the parameters to change over time, depending on the unobservable state like economic recession, high volatility on financial markets or epidemiologic outbreak. The state follows a Markov process with a given probability transition matrix for each of <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$k$</math-renderer> states:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\begin{equation*}
P(S_t = i | S_{t-1} = j) = 
\begin{pmatrix}
p_{1,1} &amp; p_{1,2} &amp; \cdots &amp; p_{1,k} \\\
p_{2,1} &amp; p_{2,2} &amp; \cdots &amp; p_{2,k} \\\
\vdots  &amp; \vdots  &amp; \ddots &amp; \vdots  \\\
p_{k,1} &amp; p_{k,2} &amp; \cdots &amp; p_{k,k} 
\end{pmatrix}
\end{equation*}$$</math-renderer>
<p dir="auto">Satisfying standard Markovian properties. The general model is defined as follows:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\begin{align*}
\mathbf{y}_t &amp;= \mathbf{\mu}_S + \mathbf{X}_t \mathbf{\beta}_{S} + \mathbf{Z}_t \mathbf{\gamma} + \mathbf{\epsilon}_t, &amp; \mathbf{\epsilon} \sim f(0,\mathcal{\Sigma}_s)\\\
\end{align*}$$</math-renderer>
<p dir="auto">Where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$\mathbf{y}_t$</math-renderer> is vector of dependent variables, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$\mathbf{\mu}_s$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$\mathbf{\beta}_s$</math-renderer> are model parameters dependent on the state <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$S_t$</math-renderer>, <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$\mathbf{\gamma}$</math-renderer> is a vector of parameters for exogenous variables. The error is distributed according to some distribution <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$f$</math-renderer> with state dependent covariance matrix <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$\mathcal{\Sigma}_s$</math-renderer>.</p>
<p dir="auto">Because of the unobserved nature of the state, the model is estimated by maximum likelihood. The likelihood function is calculated using the method described in Hamilton, 1989.</p>
<p dir="auto">The package also provide time-varying transition probabilities (TVTP) (Filardo, 1994) which allows for the transition matrix to change over time, depending on exogenous variables. Each transition probability has a following form:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$p_{i,j,t} = \dfrac{exp(\mathbf{Z}_t \delta_{i,j})}{\textstyle \sum_{j=1} exp(\mathbf{Z}_t \delta_{i,j})}$$</math-renderer>
<p dir="auto">For more thorough introduction to the Markov switching models, see 9th chapter of Guidolin and Pedio, 2018.</p>

<li>Currently available:
<ul dir="auto">
<li>Markov switching model with <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$k$</math-renderer> regimes and combinations of switching/non-switching:

<p dir="auto"><code>MarSwitching.jl</code> is 6,7 times faster than <code>statsmodels</code> implementation in <code>Python</code>/<code>Cython</code>, 8,2 times faster than <code>MSwM</code> in <code>R</code> and 42 times faster than <code>MS_Regress</code> in <code>MATLAB</code>/<code>MEX</code>, although MATLAB package is also calculating standard errors during function call. Every implementation had virtually the same error of estimated parameters.</p>
<p dir="auto">Software versions: MarSwitching.jl v0.2.2, Statsmodels v0.14.1, MSwM v1.5, MS_Regress v1.11. The programming languages versions were: Julia v1.10.1, Python v3.12.2, R v4.2.1 and MATLAB vR2024a. <p dir="auto">Following example will first generate artificial data and then estimate a simple Markov switching model with regime dependent intercept, exogenous variable and variance. The model is defined as follows:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\begin{align*}
    y_t &amp;= \mu_s + \beta_s x_t + \epsilon_t, &amp; \epsilon &amp;\sim \mathbb{N}(0,\mathcal{\Sigma}_s) \\\
\end{align*}$$</math-renderer>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\begin{equation*}
    P(S_t = i | S_{t-1} = j) = \begin{bmatrix}
        p_1 &amp; 1 - p_2\\\
        1 - p_1 &amp; p_2
        \end{bmatrix}
\end{equation*}$$</math-renderer>

               exog_tvtp<span class="pl-k">::</span><span class="pl-c1">Matrix{Float64}</span>)           <span class="pl-c"><span class="pl-c">#</span> optional matrix of exogenous variables for time-varying transition matrix</span></pre></div>
<p dir="auto">The <code>predict()</code> function can be used to calculate instantaneous or one step ahead predictions from estimated model:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="predict(model::MSM,                            # estimated model

<p dir="auto">Which is the probability weighted average of predictions of each state equation:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\hat{y}_t = \sum_{i=1}^{k} \hat{\xi}_{i,t}X_{t}'\hat{\beta}_{i}$$</math-renderer>
<p dir="auto">And for one step ahead, the state probabilities have to be predicted themselves:</p>
<math-renderer class="js-display-math" style="display: block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$$\hat{y}_{t+1} = \sum_{i=1}^{k} (P\hat{\xi}_{i,t})X_{t+1}'\hat{\beta}_{i}$$</math-renderer>
<p dir="auto">The one step ahead prediction will return a vector of size <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$(T-1) \times 1$</math-renderer>, as the observation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$t-1$</math-renderer> is used to forecast state probability (<math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$P\hat{\xi}_{i,t}$</math-renderer>)</p>
<p dir="auto">The provided new data needs to match the data used for estimation (with except of observations size). If not provided the prediction is done on the data used for estimation. For one step ahead forecast, there is no look-ahead bias, the y vector needs to be provided in order to calculate the state probabilities at time <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="4bc8c4020c22a876ada22872b73ad369">$t$</math-renderer>.</p>
<p dir="auto">The <code>summary_msm(model::MSM; digits::Int64=3)</code> function outputs a summary table that is built from 4 functions:</p>
<ul dir="auto">
<li><code>transition_mat(model::MSM; digits::Int64=2)</code> - prints transition matrix</li>
<li><code>coeftable_tvtp(model::MSM; digits::Int64=3)</code> - prints coefficient table for time-varying transition matrix</li>
<li><code>state_coeftable(model::MSM, state::Int64; digits::Int64=3)</code> - prints coefficient table for given state</li>
<li><code>expected_duration(model::MSM; digits::Int64=2)</code> - prints expected duration of each state, or a time series of expected duration for TVTP model</li>
</ul>
