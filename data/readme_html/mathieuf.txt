<p dir="auto">Julia package for Mathieu Functions with function forms similar to Mathieu related functions in Mathematica.</p>
<p dir="auto">Mathieu functions are the eigenvalues and eigenfunction of <em>Mathieu's
equation</em> (for more details, see <a href="http://dlmf.nist.gov/28" rel="nofollow">NIST's Digital Library of
Mathematical Functions</a>).</p>
<p dir="auto">Related Package: <a href="https://github.com/BBN-Q/MathieuFunctions.jl">MathieuFunctions.jl</a></p>

<ul dir="auto">
<li>Support Fourier coefficients of non-integer order eigenfunctions</li>
<li>Support a,q as input, see <a href="https://atoms.scilab.org/toolboxes/Mathieu/4.0.61" rel="nofollow">Mathieu functions toolbox</a></li>
<li>Support output of the related Wronskian.</li>
</ul>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Examples</h2><a id="user-content-examples" class="anchor" aria-label="Permalink: Examples" href="#examples"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="nu,ck=MathieuExponent(a,q)"><pre>nu,ck<span class="pl-k">=</span><span class="pl-c1">MathieuExponent</span>(a,q)</pre></div>
<p dir="auto">where <code>nu</code> is the characteristic exponent and vector <code>ck</code> is the Fourier coefficients of the eigenfunction with <code>norm(ck)≈1</code>.
Note that <code>nu</code> is reduced to the interval <code>[0,2]</code> and <code>c0</code> corresponds to <code>ck[(length(ck)-1)÷2]</code> with the reduced <code>nu</code>. (For <code>nu</code> is real, the procedure actually reduces <code>nu</code> into <code>[0,1]</code>).</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="W=MathieuWron(nu,ck::Vector,index::Int)"><pre>W<span class="pl-k">=</span><span class="pl-c1">MathieuWron</span>(nu,ck<span class="pl-k">::</span><span class="pl-c1">Vector</span>,index<span class="pl-k">::</span><span class="pl-c1">Int</span>)</pre></div>
<p dir="auto">where <code>W</code> is the Wronskian of the eigenfunction with and <code>index</code> refers to the index of <code>c0</code> in <code>ck</code>.
For example,</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="a=0.1;q=0.5;
nu,ck=MathieuExponent(a,q)
idx=(length(ck)-1)÷2+1
W=MathieuWron(nu,ck,idx)"><pre>a<span class="pl-k">=</span><span class="pl-c1">0.1</span>;q<span class="pl-k">=</span><span class="pl-c1">0.5</span>;
nu,ck<span class="pl-k">=</span><span class="pl-c1">MathieuExponent</span>(a,q)
idx<span class="pl-k">=</span>(<span class="pl-c1">length</span>(ck)<span class="pl-k">-</span><span class="pl-c1">1</span>)<span class="pl-k">÷</span><span class="pl-c1">2</span><span class="pl-k">+</span><span class="pl-c1">1</span>
W<span class="pl-k">=</span><span class="pl-c1">MathieuWron</span>(nu,ck,idx)</pre></div>
<p dir="auto">In some cases, <code>W</code> could be negative. One can replace <code>nu</code> with <code>-nu</code> and reverse <code>ck</code>, i.e., <code>reverse!(ck)</code>, to get a positive <code>W</code>.
If one prefers a positive <code>nu</code>, one can further shift <code>nu</code> with <code>nu+=2</code> and <code>idx</code> with <code>idx+=1</code>.
Code example:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="nu=2-nu
reverse!(ck)
idx+=1
W_new=MathieuWron(nu,ck,idx)"><pre>nu<span class="pl-k">=</span><span class="pl-c1">2</span><span class="pl-k">-</span>nu
<span class="pl-c1">reverse!</span>(ck)
idx<span class="pl-k">+=</span><span class="pl-c1">1</span>
W_new<span class="pl-k">=</span><span class="pl-c1">MathieuWron</span>(nu,ck,idx)</pre></div>
<p dir="auto">It can be verified that <code>W_new==-W</code>.</p>
<p dir="auto">If one knows <code>nu</code> (not reduced) and <code>q</code>, one can use</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="W=MathieuWron(nu,q)"><pre>W<span class="pl-k">=</span><span class="pl-c1">MathieuWron</span>(nu,q)</pre></div>
<p dir="auto">During my test, the result is positive with such method.</p>
