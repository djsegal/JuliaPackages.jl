<p dir="auto">TruncatedStreams provides types that meet the following four criteria:</p>
<ol dir="auto">
<li>Inherit from <code>Base.IO</code>;</li>
<li>Transparently pass all basic IO methods through to a wrapped <code>IO</code> object, except...</li>
<li>Lie about <code>eof</code>, and...</li>
<li>Do not read a single byte more from the wrapped <code>IO</code> object than what is necessary to determine EOF.</li>
</ol>

<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">Lie to me</h2><a id="user-content-lie-to-me" class="anchor" aria-label="Permalink: Lie to me" href="#lie-to-me"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Julia basically offers two methods for reading some but not all the bytes from an IO object:</p>
<ul dir="auto">
<li><code>read(::IO, ::Integer)</code>, which reads up to some number of bytes from an IO object, allocating and appending to a <code>Vector{UInt8}</code> to hold everything it reads; or</li>
<li><code>readuntil(::IO, ::Vector{UInt8})</code>, which reads bytes from an IO object until a sentinel vector is found, again allocating and appending to a <code>Vector{UInt8}</code> to hold everything it reads.</li>
</ul>
<p dir="auto">But what if you find yourself in the following situation:</p>
<ol dir="auto">
<li>You want to read values of many different types from an IO object.</li>
<li>You know you can safely read some number of bytes from the IO object (either a fixed number or until some sentinel is reached).</li>
<li>You do not want to (or cannot) read everything from the IO object into memory at once.</li>
</ol>
<p dir="auto">This may seem like a contrived situation, but consider an IO object representing a concatenated series of very large files, like what you might see in a TAR or ZIP archive:</p>
<ol dir="auto">
<li>You want to treat each file in the archive like a file on disk, reading an arbitrary number of values of arbitrary types from the file.</li>
<li>The file either starts with a header that tells you how many bytes long the file is or ends with a sentinel so you know when to stop reading.</li>
<li>You do not want to (or cannot) read the entire file into memory before parsing.</li>
</ol>
<p dir="auto">Enter <code>TruncatedStreams</code>. This package exports types that inherit from <code>Base.IO</code> and wrap other <code>Base.IO</code> objects with one purpose in mind: to lie about EOF. This means you can wrap your IO object and blindly read from it until it signals EOF, just like you would any other IO object. And, if the wrapped IO object supports it, you can write to the stream, seek to a position, skip bytes, mark and reset positions, or do whatever basic IO operation you can think of and not have to worry about whether you remembered to add or subtract the right number of bytes from your running tally, or whether your buffered read accidentally captured half of the sentinel at the end.</p>
<p dir="auto">Abstraction is ignorance, and ignorance is bliss.</p>
