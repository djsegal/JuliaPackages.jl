<p dir="auto">This library helps in the development of reactive frontends and can be
used alongside <strong>WGLMakie</strong> and <strong>JSServe</strong>.</p>
<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">The functions you care about</h2><a id="user-content-the-functions-you-care-about" class="anchor" aria-label="Permalink: The functions you care about" href="#the-functions-you-care-about"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Most frequently you will be using the <code>hstack</code> (row of items), <code>vstack</code> (column of items), and <code>zstack</code> functions to <strong>create your HTML/CSS layout</strong>. You will be wrapping your figures in HTML div tags with <code>wrap</code>.</p>
<p dir="auto">When stacking things with <code>zstack</code> you will want to select which one is currently viewable with the <code>active</code> function and the <code>activeidx</code> keyword argument. <strong>Transitions</strong> between the states can also be enabled with the <code>anim</code> keyword argument. One can select <code>[:default]</code>, <code>[:whoop]</code>, <code>[:static]</code> , <code>[:opacity]</code> or a valid combination of the four.</p>
<p dir="auto"><strong>Hover animations</strong> are available with the <code>hoverable</code> function with the specified <code>anim</code> keyword. One can select <code>[:default]</code>, <code>[:border]</code> or a combination of the two.</p>
<p dir="auto">And for convenience you can create <strong>clickable buttons</strong> that navigate the layout with <code>modifier</code>.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">The workflow can be defined as such:</h3><a id="user-content-the-workflow-can-be-defined-as-such" class="anchor" aria-label="Permalink: The workflow can be defined as such:" href="#the-workflow-can-be-defined-as-such"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li>
<p dir="auto">Reactiveness centers around the <code>observable</code> objects.</p>
</li>
<li>
<p dir="auto">There are three kinds of CSSMakieLayout elements: <strong>static</strong>, <strong>modifiers</strong> and <strong>modifiable</strong></p>
</li>
<li>
<p dir="auto">The <strong>static</strong> elements are purely for styling, with no reactive component. For example <code>hstack</code>, <code>vstack</code>, <code>wrap</code> and <code>hoverable</code> if no observable is set for the <em>stayactiveif</em> parameter</p>
</li>
<li>
<p dir="auto">The <strong>modifiers</strong> are the ones that modify the observables that in turn modity the <strong>modifiable</strong> elements. For now there exists only one <strong>modifier element</strong> that is luckily called <strong>modifier</strong>. It takes the observable to be modified as the <code>parameter</code> keyword, and the way in which to modify it as the <code>action</code> keyword (which can be <code>:toggle</code>, <code>:increase</code>, <code>:decrease</code>, <code>:increasecap</code>, <code>:decreasecap</code>, <code>:increasemod</code>, <code>:decreasemod</code>)</p>
</li>
<li>
<p dir="auto">The <strong>modifiable</strong> elements are the ones that get modified by an observable: <code>zstack</code>, <code>hoverable</code> with the <code>stayactiveif</code> observable set and <code>selectclass</code></p>
</li>
</ul>

<p dir="auto">For example let's say we want to create a view in which we can visualize
one of three figures (<strong>a</strong>, <strong>b</strong> and <strong>c</strong>) in a slider manner.
We also want to control the slider with two buttons: <code>LEFT</code> and <code>RIGHT</code>. The
<code>RIGHT</code> button slided to the next figure and the <code>LEFT</code> one slides to the
figure before.</p>
<p dir="auto">The layout would look something like this:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer" href="https://github.com/adrianariton/CssMMakieLayout/blob/master/examples/assets/example1.gif?raw=true"><img src="https://github.com/adrianariton/CssMMakieLayout/raw/master/examples/assets/example1.gif?raw=true" alt="&quot;&lt; (left) | 1 | (right) &gt;&quot;" data-animated-image="" style="max-width: 100%;"></a></p>
<p dir="auto">By acting on the buttons, one moves from one figure to the other.</p>
