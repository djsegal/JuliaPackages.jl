<div class="markdown-heading" dir="auto"><h2 class="heading-element" dir="auto">What is Endatabas?</h2><a id="user-content-what-is-endatabas" class="anchor" aria-label="Permalink: What is Endatabas?" href="#what-is-endatabas"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<ul dir="auto">
<li><a href="https://www.endatabas.com/" rel="nofollow">Endatabas</a> is one of the most fascinating databases I've encountered recently.</li>
<li>It's schemaless
<ul dir="auto">
<li>...but it can be queried with SQL.</li>
</ul>
</li>
<li>You can just start inserting data and tables will autovivify.
<ul dir="auto">
<li>The rows you insert can contain nested data.</li>
<li>Rows are structured documents.</li>
</ul>
</li>
<li>Its dialect of SQL can have a JSON-ish accent at times which feels natural if you're accustomed to JSON.</li>
<li>It maintains an "immutable" history of the database, and you can query the database about past states.</li>
<li>It was written by the developer of <a href="https://github.com/xtdb/xtdb">XTDB</a> which is another database that cares about time and history.</li>
<li>It's implemented in a combination of Rust and Common Lisp.</li>
<li>They have a docker container that makes it really easy to get started with it.</li>
</ul>
