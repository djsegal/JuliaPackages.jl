<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Overview</h3><a id="user-content-overview" class="anchor" aria-label="Permalink: Overview" href="#overview"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">This package aims to simplify the construction of diffusion denoising models by providing a standardized approach, based on endpoint-conditioned diffusion "bridge" sampling. We provide a number of processes to handle continuous Euclidean variables, discrete variables, angles, and rotations, and a simplified framework and interface to construct new diffusions over custom spaces.</p>
<p dir="auto">The approach requires the user to build a model (typically a neural network) that takes as input a noised observation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$x_t$</math-renderer>, and predicts (in some sense - see below) the denoised observation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$x_0$</math-renderer>. The typical training setup involves a large set of samples from some target distribution, which are noised under the selected diffusion process, and the model is trained to minimize a loss, predicting the denoised observation.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Spaces and loss functions</h3><a id="user-content-spaces-and-loss-functions" class="anchor" aria-label="Permalink: Spaces and loss functions" href="#spaces-and-loss-functions"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">For the standard continuous Euclidean case, the least-squares loss allows a trained model to recover the expectation <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$E[x_0|x_t]$</math-renderer>. With a perfect model, this would provide exact sampling of the target distribution when the diffusion process is run in reverse. For trickier manifolds, the exact target distribution is not exactly recovered by this approach, but can be approximated well-enough when a suitable loss function is chosen.</p>
<p dir="auto">The discrete case, where an observation is a collection of discrete variables, is slightly different. Instead of providing a point estimate of some expectation, the cross-entropy loss must be used, and a sample from the resulting categorical distribution taken for each variable. Even though these samples are taken independently, the reverse diffusion can recover the joint distribution with a sufficiently capable model.</p>
<p dir="auto">Importantly, multiple different kinds of diffusion can be combined, and jointly diffused and reconstructed together.</p>
<div class="markdown-heading" dir="auto"><h3 class="heading-element" dir="auto">Reversing the diffusion</h3><a id="user-content-reversing-the-diffusion" class="anchor" aria-label="Permalink: Reversing the diffusion" href="#reversing-the-diffusion"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">The inverse diffusion works by using the trained model to predict <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$\hat{x_0} = E[x_0|x_t]$</math-renderer>, and then constructs an endpoint-conditioned sample along a stochastic bridge between <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$\hat{x_0}$</math-renderer> and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$x_t$</math-renderer>, at <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$x_{t-\epsilon}$</math-renderer>, from <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$P(x_{t-\epsilon}|\hat{x_0},x_t,D)$</math-renderer>, where <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$D$</math-renderer> is the diffusion process itself and <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$0 &amp;lt; t-\epsilon &amp;lt; t$</math-renderer>. This is visualized below, for a single variable under Ornstein–Uhlenbeck diffusion, showing multiple steps (with an exaggerated step size), clarifying how the randomness injected with each "bridge" influences the final sample:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://user-images.githubusercontent.com/1152087/224138792-15dd802b-3e23-43bc-8e11-e332ce41d7a9.svg"><img src="https://user-images.githubusercontent.com/1152087/224138792-15dd802b-3e23-43bc-8e11-e332ce41d7a9.svg" width="650" style="max-width: 100%;"></a></p>
<p dir="auto">Even though each variable is diffused independently, for extremely strongly correlated variables the joint distribution can be recovered:</p>
<p dir="auto"><a target="_blank" rel="noopener noreferrer nofollow" href="https://user-images.githubusercontent.com/1152087/224140026-870a42bb-94bf-48be-86ce-a639b44cd199.gif"><img src="https://user-images.githubusercontent.com/1152087/224140026-870a42bb-94bf-48be-86ce-a639b44cd199.gif" width="450" data-animated-image="" style="max-width: 100%;"></a></p>
<p dir="auto">The motivation for this framing, where the model predicts <math-renderer class="js-inline-math" style="display: inline-block" data-static-url="https://github.githubassets.com/static" data-run-id="91837105f50bb1cd47cc1b4f63d08a2f">$x_0$</math-renderer> and the reverse diffusion occurs via a diffusion bridge, is that we can achieve diffusion denoising for more structured kinds of data, so long as we can simulate or approximate a "bridge". For example, we can define a noise process over rotations, and train a model to sample from a distribution over rotations:</p>

<div class="markdown-heading" dir="auto"><h4 class="heading-element" dir="auto">Self-conditioning</h4><a id="user-content-self-conditioning" class="anchor" aria-label="Permalink: Self-conditioning" href="#self-conditioning"><svg class="octicon octicon-link" viewBox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path d="m7.775 3.275 1.25-1.25a3.5 3.5 0 1 1 4.95 4.95l-2.5 2.5a3.5 3.5 0 0 1-4.95 0 .751.751 0 0 1 .018-1.042.751.751 0 0 1 1.042-.018 1.998 1.998 0 0 0 2.83 0l2.5-2.5a2.002 2.002 0 0 0-2.83-2.83l-1.25 1.25a.751.751 0 0 1-1.042-.018.751.751 0 0 1-.018-1.042Zm-4.69 9.64a1.998 1.998 0 0 0 2.83 0l1.25-1.25a.751.751 0 0 1 1.042.018.751.751 0 0 1 .018 1.042l-1.25 1.25a3.5 3.5 0 1 1-4.95-4.95l2.5-2.5a3.5 3.5 0 0 1 4.95 0 .751.751 0 0 1-.018 1.042.751.751 0 0 1-1.042.018 1.998 1.998 0 0 0-2.83 0l-2.5 2.5a1.998 1.998 0 0 0 0 2.83Z"></path></svg></a></div>
<p dir="auto">Self-conditioning is a technique to enhance the quality of generated
samples<sup><a href="#user-content-fn-Chen22-91837105f50bb1cd47cc1b4f63d08a2f" id="user-content-fnref-chen22-91837105f50bb1cd47cc1b4f63d08a2f" data-footnote-ref="" aria-describedby="footnote-label">1</a></sup>. Self-conditioning takes the previously estimated <code>x_0</code> along
with the diffused sample <code>x_t</code> to update the current estimate. In
Diffusions.jl, this can be achieved using a closure that retains the latest
estimate of <code>x_0</code> during backward sampling. The following code demonstrates how
to generate 28-by-28 grayscale images (with a batch of 64 samples) using
self-conditioning:</p>
<div class="highlight highlight-source-julia notranslate position-relative overflow-auto" dir="auto" data-snippet-clipboard-copy-content="function selfcondition(x)
    # Initialize x_0
    x_0 = zero(x)  
    function (x_t, t)
        # Update the estimate and return it
        x_0 = model(x_t, x_0, t)
        return x_0
    end
end

x = randn(Float32, (28, 28, 64))
x_0 = samplebackward(selfcondition(x), diffusion, timesteps, x)"><pre><span class="pl-k">function</span> <span class="pl-en">selfcondition</span>(x)

        <span class="pl-c"><span class="pl-c">#</span> Update the estimate and return it</span>

    <span class="pl-k">end</span>

<p dir="auto">Note that the model must be trained to accept the previous estimate as
additional data, which is usually represented as <code>model(x_t, zero(x_t), t)</code> or
<code>zero(x_t)</code> with a 50% probability for each. The training code will look like:</p>
