<p dir="auto">Parameters:</p>
<ul dir="auto">
<li><code>A</code>: the input matrix of size (m, n)</li>
<li><code>k</code>:  the target rank of truncated SVD, k ≤ min(m,n)</li>
<li><code>p_max</code>:  the upper bound of power parameter <code>p</code>, default = 1000</li>
<li><code>s</code>: the oversampling parameter, <strong>min(m,n) ≥ k + s</strong>, default = <code>k/2</code></li>
<li><code>tol</code>: the error tolerance for PVE, default = 1e-2</li>
</ul>
<p dir="auto">Returns:</p>
<ul dir="auto">
<li><code>U</code>: the matrix of size (m, k) containing the first <code>k</code> left singular vectors of <code>A</code></li>
<li><code>S</code>: the vector of size (k, ) containing the <code>k</code> largest singular values of <code>A</code> in <strong>ascending</strong> order.</li>
<li><code>V</code>: the matrix of size (n, k) containing the first <code>k</code> right singular vectors of <code>A</code></li>
</ul>
