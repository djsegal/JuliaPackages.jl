<p dir="auto">Julia wrapper around the <a href="https://www.labri.fr/perso/pelegrin/scotch/" rel="nofollow">SCOTCH</a> library.</p>
<p dir="auto">SCOTCH is downloaded through the <a href="https://juliahub.com/ui/Packages/General/SCOTCH_jll" rel="nofollow">SCOTCH_jll</a>,
therefore there is no need to build the library manually.
<a href="https://docs.binarybuilder.org/stable/jll/#Overriding-the-artifacts-in-JLL-packages" rel="nofollow">See here</a> to use
a local installation instead.</p>
